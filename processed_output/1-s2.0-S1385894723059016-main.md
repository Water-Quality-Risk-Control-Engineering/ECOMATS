# . Introduction

Water pollution has become an urgent challenge to be overcome worldwide [13]. Beside the established methods such as adsorption [46], ion-exchange [7,8], membrane filtration [9,10] and biological degradation [11,12], advanced oxidation processes (AOPs) have gained attention as chemical approaches for water treatment [1318]. AOPs use highly reactive oxidizing species (ROS), such as hydroxyl radicals $( ^ { \bullet } \mathrm { O H } )$ and sulfate radicals $( \mathrm { { S O } _ { 4 } ^ { \bullet } ) }$ , for degrading organic pollutants in aqueous solution [1922].

At present, AOPs using sulfate radicals are considered promising for removing organic compounds [23,24]. The sulfate radical can be preferred over hydroxyl radical due to its longer lifetime and a higher selectivity for oxidation by electron transfer [2426]. The latter reactivity is clearly an advantage when degrading pollutants with no reactive C-H-bonds, such as perfluorinated carboxylic acids (PFCAs). PFCAs are not degradable by OH-driven AOPs, whereas they are degradable by attack of sulfate radicals [2729]. Peroxydisulfate (PS, $S _ { 2 } O _ { 8 } ^ { 2 - } )$ and peroxymonosulfate $\mathrm { ( H S O _ { 5 } ^ { - } ) }$ are the major sources of $S O _ { 4 } ^ { \bullet \bullet }$ [25]. In particular, PS with an O-O-bond energy of $1 4 0 \mathrm { \ k J \ m o l ^ { - 1 } }$ [30] is manageable at ambient temperature and affordable in terms of economic cost. PS itself has a low reactivity towards many organic compounds, hence the copresence of an activator or an energy source are advisable in order to generate $S O _ { 4 } ^ { \bullet \cdot }$ from PS [3138]. In the recent years, significant efforts have been devoted towards development of suitable homogeneous and heterogeneous catalysts for activating PS [3941], with particular attention dedicated to transition-metal-based catalysts [29,42,43]. Various metals such as Fe, Co, Al and Cu have been used for this purpose [44,45]. Recently, Sühnholz et al. [4648] have investigated FeS as an adsorbent and catalyst for heterogeneous activation of PS. The basic mechanistic hypothesis is that PS reacts as an oxidant on the surface of iron sulfide/oxide particles, in addition to a free sulfate radical mechanism.

Among other transition-metal-based catalysts, manganese oxides $\left( \mathbf { M n O _ { x } } \right)$ have been reported as promising catalysts to couple with PS due to their redox cycle $( \mathrm { M n ^ { 3 + / 4 + } } )$ hydrosphere, and low toxicity [4953]. It is noteworthy that $\mathbf { M n O _ { X } }$ are themselves able to act as oxidants [5457]. Recently, Wang et al. [58] reported on high oxidative activity of $\delta \mathrm { - } \mathbf { M } \mathbf { n } \mathbf { O } _ { 2 }$ for a variety of organic pollutants. Notably, the reactivity of $\mathrm { { M n O } _ { 2 } }$ , as opposed to that of PS, is appreciable even at low temperatures. Some recent studies on $\mathbf { M n O } _ { 2 }$ and its combination with PS as oxidants are considered in the following in more detail.

Fenti et al. [59]investigated the effect of $\mathbf { M n O _ { 2 } }$ on the oxidation of diuron by PS in the temperature range $3 0 { - } 5 5 ~ ^ { \circ } \mathrm { C }$ They found an only small acceleration effect by suspended $\mathrm { M n O } _ { 2 } ,$ which was a factor of 1.2 $\pm \ : 0 . 2$ in the zero-order rate constants of diuron degradation at $3 0 ~ ^ { \circ } \mathrm { C } .$ . Sulfate radicals are able to degrade diuron. This means that the $\gamma { \mathrm { - } } \mathbf { M } \mathbf { n } \mathbf { O } _ { 2 }$ used in this study is not active in generation of free sulfate radicals from PS.

Zhou et al. [57] studied the oxidation of sulfamethoxazol (SMX), an aniline derivative, by the combined application of PS and $\mathrm { { M n O } _ { 2 } }$ in the temperature range $3 0 { - } 7 0 \ ^ { \circ } \mathrm { C }$ . $\mathrm { { M n O } _ { 2 } }$ alone was found not to be active in SMX oxidation, whereas the combination of $\mathrm { P S } + \mathrm { M n O } _ { 2 }$ was. The authors deduced that this combination works effectively only under the assistance of heat, i.e. at elevated temperatures $( \geq 5 0 \mathrm { ~ } ^ { \circ } \mathrm { C } )$ . From quenching experiments (with MeOH, tert-BuOH, azide, and benzoquinone), the authors concluded that free sulfate radicals are the dominant reactive species in this system. $\mathbf { M n O } _ { 2 }$ was considered as catalyst for PS activation by the classical redox-shuttlemechanim $( \mathrm { M n } ^ { 3 + / 4 + } )$ , not as "oxidation catalyst" for the SMX substrate.

Li et al. [60] have investigated for the first time the oxidation of 4- hydroxybenzoic acid (HBA) and its methyl ester (methylparaben) with amorphous $\mathrm { M n O } _ { 2 } ( d _ { \mathrm { p a r t i c l e } } = 2 4 0 \mathrm { n m }$ , specific surface area $\overline { { S } } S A = 3 1 0 \mathrm { m } ^ { 2 }$ $g ^ { - 1 } )$ at ambient temperature in the absence of PS. They observed fast depletion of the two phenols $( \tau _ { 1 / 2 } \approx 2 0 ~ \mathrm { m i n }$ with $5 0 0 ~ { \mu \mathrm { M } }$ suspended $\mathrm { { M n O } _ { 2 } }$ at $\mathrm { p H } = 5$ , $k _ { \mathrm { H B A , M n O 2 } } = 5 0 \mathrm { ~ L ~ g ^ { - 1 } ~ h ^ { - 1 } ) }$ accompanied by extensive formation of oligomeric products. The oxidation capacity of $\mathrm { M n O } _ { 2 } ,$ however, was limited to about $1 . 5 \%$ of the total amount. This limitation and an estimated increased ecotoxicity of the formed oligomers indicate that $\mathrm { { M n O } _ { 2 } }$ alone is not efficient for detoxification of phenolic water pollutants [60].

Kinetic and mechanistic aspects are also important when considering the potential of $\mathrm { { { M n O } _ { x } } }$ generated in situ as an oxidation zone or PS activator in a contaminated aquifer. The aquifer itself, with all its limitations (temperature, pH value, slow reagent mixing etc.), functions there as chemical reactor. Based on the above considerations, in the present work we report experimental results of HBA oxidation under the influence of combined PS and $\mathbf { M n O } _ { 2 }$ dosage, temperature, pH value, radical scavengers and salt effects. Special focus is on the interactions of PS with $\mathbf { M n O _ { 2 } }$ under low-temperature conditions (at $1 5 ~ ^ { \circ } \mathrm { C } )$ which are relevant in an aquifer. We propose a reaction mechanism wherein $\mathbf { M n O } _ { 2 }$ is the primary oxidant for HBA conversion with PS as a secondary oxidant for $\mathbf { M n O } _ { 2 }$ regeneration. In contrast to literature studies, we use $\gamma { \mathrm { - } } \mathbf { M } \mathbf { n } \mathbf { O } _ { 2 }$ , which is considered less active than $\alpha \cdot$ and $\beta { \mathrm { - M n O } } _ { 2 }$ as PS activators [52].

HBA has been selected as model substrate in the present study by two reasons: (i) it is a technically relevant chemical applied in several largescale manufacturing processes [4,61,62] and (ii) it has been detected in natural and wastewaters [63]. Therefore, development of effective technologies for HBA degradation has become a concern for the water treatment community[64,65].

From the chemical point of view, HBA is highly reactive towards radical attack due to its aromatic ring and phenolic OH-group. Therefore, HBA conversion is not specific to any particular radical such as 'OH or $S O _ { 4 } ^ { \bullet \bullet }$ and it is also reactive toward singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ as reactive species [52]. It is likely that PS activation generates sulfate radicals as primary radical species [57]. Therefore, we have tested this hypothesis by investigating perfluorooctanoic acid (PFOA, $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { C O O ^ { - } } )$ as target compound. PFOA is known to be resistant against 'OH and many other radicals as well as singlet oxygen, whereas it is reactive towards $S O _ { 4 } ^ { \bullet \cdot }$ [27].

The present study aims at understanding of interactions between the two oxidants PS and $\mathrm { M n O } _ { 2 }$ ,i.e. $\mathrm { M n O _ { 2 } }$ as catalyst or primary oxidant. In addition, the role of temperature for an efficient cooperation between PS and $\mathrm { M n O _ { 2 } }$ is elucidated. The relevance of this issue is obvious, when looking at the option of an in situ aquifer remediation.

# 3.4. HBA degradation in the co-presence of PS and $M n O _ { 2 }$

The positive effect of combining PS with $\mathrm { { M n O } _ { 2 } }$ is known from the literature [52,57,69,81,82]. This effect is usually ascribed to a catalytic activation of PS (as oxidant) by $\mathbf { M n O } _ { 2 }$ (as catalyst), followed by radical chemistry in the water phase. In the present study, however, we have collected evidence for a different distribution of roles.

HBA can be degraded in solution by a number of radicals such as $S O _ { 4 } ^ { \bullet \cdot }$ and $\cdot _ { \mathrm { O H } }$ as well as by heterogeneous reactions at the $\mathrm { M n O _ { 2 } }$ surface. Fig. 6 shows the kinetics of HBA oxidation in the co-presence of $\mathbf { M n O } _ { 2 }$ and PS with (i) no scavengers, (ii) $t { \mathrm { - B u O H } }$ , and (iii) MeOH at ${ 1 5 ^ { \circ } \mathrm { C } }$ and $4 5 ^ { \circ } \mathrm { C }$ .

# 3.6. Products and possible mechanism of HBA degradation

In all the experimental conditions investigated (i.e. in the presence of $\scriptstyle \mathrm { M n O _ { 2 } } ,$ , or PS, or of both oxidants), BQ was the only cyclic degradation product of HBA detectable by LC-MS analysis in significant amounts $\leq 2$ mol $\%$ of converted HBA). It was further oxidized to carboxylic acids such as formic and oxalic acid. These latter compounds were found in trace levels at the end of the experiments, suggesting that the converted HBA was largely mineralized. Zrinyi and Pham [32] found that oxidation of benzoic acid by thermally activated PS yields recoveries of detectable products (e.g. hydroxylated benzoic acids and phenol) of only $3 5 \mathrm { - } 5 0 \ \%$ . # 4. Summary and conclusions

We have shown that the combined use of $\mathbf { M n O } _ { 2 }$ and PS is an effective method to degrade HBA as a typical representative of reactive organic water contaminants. The two oxidants act synergetically. $\mathbf { M n O } _ { 2 }$ and PS play different roles, as primary and secondary oxidants, respectively. We consider $\mathbf { M n O } _ { 2 }$ as a primary oxidant rather than a catalyst. The twocomponent oxidant system $\mathrm { P S } + \mathrm { M n O } _ { 2 }$ possesses a remarkable property: it is still active at low temperatures (e.g. at ${ 1 5 ~ ^ { \circ } \mathrm { C } } ,$ see Fig. 4A) prevailing in aquifers. This property is different from the PS reactivity alone, which needs thermal or chemical activation. The HBA degradation is accelerated in the two-component system by one to two orders of magnitude, depending on the reaction temperature $4 5 ~ ^ { \circ } \mathrm { C }$ to $1 5 ~ ^ { \circ } \mathrm { C } )$ , compared with the PS application only. $\mathrm { M n O _ { 2 } }$ alone is a powerful oxidant even at low temperatures. However, it has a very limited oxidation capacity, $< 1 ~ \%$ of the stoichiometric capacity, due to nonavailability of the bulk solid material. PS can overcome this limitation by re-oxidation of reduced Mn-oxides. This is the role of a secondary oxidant. Elucidation of the temperature dependent interplay between $\mathbf { M n O } _ { 2 }$ and PS as primary and secondary oxidants, rather than catalyst and oxidant, is the main novelty of this study.

The two-component system is largely $\mathtt { p H }$ tolerant $\left( \mathbf { p } \mathbf { H } = 3 \mathbf { - } 9 \right)$ and insensitive towards water matrix constituents such as chloride (for detailed data see SI part). The latter is due to the heterogeneous nature of the rate controlling step.

$\mathbf { M n O } _ { 2 }$ is a moderately selective oxidant (see e.g. [52,56,79]) which reacts preferentially with electron-rich target compounds, such as phenols. This makes it appropriate for selective destruction of such contaminants in complex water matrices rich in inorganic salts (e.g. chloride, sulfate etc.), but less practical as a broad-band tool. Despite this selectivity, we observed a high potential for mineralization of HBA in the two-component system.

The extent of oligomer/polymer products formation from phenolic substrates is an open issue, requiring deeper investigation.

The low-temperature activity of $\mathrm { M n O } _ { 2 } + \mathrm { P S }$ opens an option for insitu application of the two-component system in contaminated aquifers. In a first step, a $\mathrm { { M n O } _ { 2 } }$ coating on the aquifer sediment is prepared by flushing with dilute permanganate solution. Then, low concentrations of PS are injected in the pre-treated aquifer in order to degrade organic pollutants during their passage through the catalytically activated permeable zone. Ubiquitously present matrix components such as chloride are not crucial. Note that no temperature increase is necessary for PS activation. Further studies including column experiments with aquifer sediments and in situ generated $\mathbf { M n O } _ { 2 }$ coatings are necessary in order to substantiate this idea.
