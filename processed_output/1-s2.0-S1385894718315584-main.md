Sulfamethazine (SMT) is widely used in human and veterinary medicine as growth promoters and antibacterial drugs and it can pose potential threats to human and ecosystem health. In this study, removal of SMT by ultrasound pre-magnetized $\mathrm { F e } ^ { 0 } / \mathrm { P S }$ process was investigated for the first time. Degradation rate for removing SMT increased 3.3 folds and the synergy factor increased from 1.2 to 2.7 compared with ${ \mathrm { U S } } / { \mathrm { F e } } ^ { 0 } / { \mathrm { P S } }$ process. Affecting factors such as $\mathsf { p H }$ (3–10), $\mathrm { F e } ^ { 0 }$ dosage $\mathbf { \left( 0 - 0 . 8 m M \right) }$ and initial SMT concentration $( 0 { - } 1 0 \mathrm { m g L } ^ { - 1 } )$ were studied. Stronger signals of DMPO–OH and DMPO– $S O _ { 4 }$ adduct also illustrated more and faster $s 0 _ { 4 } \cdot -$ and % OH radicals produced in the system. FeOOH was detected through the mossbauer spectrum which could both enhance the catalysis of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and activation of PS. The intermediates of the SMT degradation were investigated, and a degradation pathway was proposed. Higher correlation factor $\neg \triangle k$ and $\triangle { s } )$ in US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ system illustrated the good synergistic effect between US input power and magnetic field. Moreover, the process could efficiently remove SMT in municipal wastewater and keep pH neutral. So, US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process is a energy saving and promising approach to remove antibiotics in real wastewater.

# 1. Introduction

Nowadays, sulfamethazine (SMT) as one of the typical antibiotics is widely used in human and veterinary medicine as growth promoters and antibacterial drugs [1]. And, the concentrations of SMT in the environment generally range from $\mathrm { n g / L }$ to $\mu \mathrm { g } / \mathrm { L }$ [2]. Conventional processes designed for common pollutants cannot efficiently remove SMT [3]. Adsorption [4], membrane filtration [5] and advanced oxidation processes (AOPs) were conducted to remove SMT. Compared with these processes, AOPs such as photolysis [6,7], Fenton oxidation [8] and ozonation [9], are admitted to be one of the most effective methods for the treatment of SMT due to the generation of high oxidizing hydroxyl radical (% OH) $( \mathrm { E } _ { 0 } = 2 . 8 \mathrm { V } )$ [10,11]. However, performances of AOPs for the municipal wastewater treatment have been inhibited by many reasons such as narrow working pH and short life span of the oxidative species [12–15].

Sulfate radical $\mathrm { ( } \mathrm { S O _ { 4 } } ^ { \cdot \cdot \mathrm { ~ - ~ } } \mathrm { ) }$ with high oxidizing ability could be another radical to degrade different refractory pollutants. The radical has longer life span than of % OH, more selective toward environmental containments and the wide application of pH (2–8) [16–18]. $S O _ { 4 } ^ { \cdot \cdot - }$ radical can be produced via activation of persulfate (PS) by ultraviolet light [19], sonolysis [20], base [21] and transit metals [22]. Among these methods, $\mathrm { F e } ^ { 0 }$ -activated PS catches researchers’ attention since $\mathrm { F e } ^ { 0 }$ is cheap, abundant and non-toxic. Moreover, $\mathrm { F e } ^ { 2 + }$ generated from $\mathrm { F e } ^ { 0 }$ via Eqs. (1)–(3) can also react with persulfate then generate $S O _ { 4 } ^ { \cdot \cdot - }$ radical via Eq. (4) [16,18].

$$
\mathrm { F e ^ { 0 } + O _ { 2 } + 2 H ^ { + }  F e ^ { 2 + } + H _ { 2 } O _ { 2 } }
$$

$$
\mathrm { F e ^ { 0 } } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + 2 \mathrm { H ^ { + } }  \mathrm { F e ^ { 2 + } } + 2 \mathrm { H } _ { 2 } \mathrm { O }
$$

$$

$$

The heterogeneous $\mathrm { F e } ^ { 0 } / \mathrm { P } S$ Fenton-like system has been employed to remove various contaminants such as bentazon [17], sulfadiazine [18] and $p$ -chloroaniline [23]. However, compared with other $\mathrm { F e } ^ { 0 }$ -based $S O _ { 4 } ^ { \cdot \cdot - }$ radical system like nano- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ [24,25] and ultrasound $\mathsf { F e } ^ { 0 } / \mathsf { P S }$ [26], the performance of $\mathsf { F e } ^ { 0 } / \mathsf { P S }$ system was generally limited by low release of $\mathrm { F e } ^ { 2 + }$ and slow heterogeneous reactions.

Ultrasound (US) as a very efficient physiochemical technology could increase the production of sonochemical micro bubbles in the aqueous system under the presence of solid particles [26–28]. It is widely used to improve the reaction of AOPs, especially heterogeneous Fenton-like systems [18,25,29]. It was reported that the combination of US and $\mathrm { F e } ^ { 0 } / \mathrm { P } S$ process could largely increase the removal of Direct Red 23 [25], Acid Orange 7 [29] and sulfadiazine [18]. However, previous US/ $\mathrm { F e } ^ { 0 } / \mathrm { P } S$ systems also presented some drawbacks: i) high reagent dosages (PS and $\mathsf { F e } ^ { 0 } )$ increased both the cost for reagent dosages and waste disposal ${ ( S O _ { 4 } } ^ { 2 - }$ and $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + } )$ ; and ii) it was not clearly demonstrated the mechanisms for $S O _ { 4 } ^ { \cdot \cdot - }$ and % OH radicals generated under different US input powers [18]. Meanwhile, pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process could greatly increase the degradation of various contaminants compared with conventional $\mathrm { F e } ^ { 0 } / \mathrm { P } S$ process [30]. However, whether the combination of US and pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ (US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ ) process can keep the positive performance has not been investigated yet, as well as the synergetic effect between magnetization and US.

In the present study, the combination of US with pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process was investigated to remove SMT. Objectives of this paper were to (1) investigate the roles of magnetization and US to enhance the activation of PS by $\mathrm { F e } ^ { 0 }$ ; (2) investigate the mechanism enhanced SMT removal; (3) propose pathway of SMT degradation; (4) explore the performance to degrade antibiotics in real municipal effluent.

# 2. Materials and methods

# 2.1. Chemicals

Sulfamethazine, HPLC-grade methanol, $\mathrm { H } _ { 2 } S 0 _ { 4 } ,$ , NaOH, $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ and $\boldsymbol { \mathrm { F e } } ^ { 0 }$ powder were purchased from the Sinopharm Group Chemical Reagent Co., Ltd.

# 2.2. Batch experiments

Pre-magn- $\mathbf { \cdot } \mathbf { F e } ^ { 0 }$ preparation was as follows: A certain amount of $\mathrm { F e } ^ { 0 }$ particles were placed in a glass bottle and magnetized by a static and uniform magnetic field (MF) for $2 \mathrm { m i n }$ at different magnetic field $\left( 0 { - } 5 0 0 \mathrm { m T } \right)$ . The MF was generated with an electromagnet (EM3) purchased from East Changing Technologies, Inc. (Beijing). The sonication of solution was conducted by an ultrasonic generator and the frequency of ultrasound was $4 0 \mathbf { k H z }$ (KQ3200DB, Tianjin Xingke Instrument and Meter Co., Ltd). All experiments were conducted open to the air. The influence of US input power, $\mathrm { F e } ^ { 0 }$ dosage, initial SMT concentration and pH for the treatment performance were conducted. The batch experiments were initiated by adding pre-magn- $\cdot \mathrm { F e } ^ { 0 }$ and PS to $5 0 0 \mathrm { m L }$ SMT solution and mixing the solution at $3 5 0 \mathrm { r / m i n }$ with a mechanical stirrer (D2004W, Shanghai Sile Instrument Co. Ltd) and the initial temperature of the experiments was $2 5 ^ { \circ } \mathrm { C } .$ $2 . 5 \mathrm { m L }$ SMT sample suspensions were taken at given time intervals, immediately filtered through a $0 . 2 2 \mu \mathrm { m }$ membrane filter, then analyzed with high-performance liquid chromatography (HPLC) (Ultimate 3000, USA).

# 2.3. Analytical methods

Concentration of SMT was measured at $2 6 5 \mathrm { n m }$ by HPLC (Ultimate 3000, USA) installed with a BEH C18 column $( 1 . 7 \mu \mathrm { m }$ , $\Phi ^ { 2 . 1 } \times 1 0 0 \mathrm { m m } )$ and a diode array detector. The mobile phase was methanol and water $( \% \mathrm { V } / \mathrm { V } = 5 5 ; 4 5 )$ and the flow rate was $0 . 1 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ . Concentration of $\mathrm { F e } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + }$ ions were monitored with the 1,10-phenanthroline method at $5 1 0 \mathrm { n m }$ using a spectrophotometer (Shimadzu UV-2600, Japan) [30]. The concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was monitored by spectrophotometer using the potassium titanium (IV) oxalate method [11]. Electron Paramagnetic Resonance (EPR) analysis was carried out with an EPR spectrometer (Magnettech MiniScope 400, Germany).

The transmission Mossbauer spectroscopy was analyzed with a spectrometer CMTE model MA250 using a 57 Co/Rh source at room temperature. The Mossbauer spectroscopy of the samples was analyzed using the MossWin 4.0 program. Gas chromatography/mass spectrometry (GC/MS) (Agilent 7890A, USA) used to detect intermediate products. It was implemented with a gas chromatography/single quadrupole mass spectrometry (Agilent 5975C) system using a HPMS-5 column $( 3 0 \mathrm { m } \times 0 . 2 5 \mathrm { m m } \times 0 . 2 5 \mu \mathrm { m } )$ . The temperature was held at $5 0 ~ ^ { \circ } \mathrm { C }$ for $2 \mathrm { { m i n } }$ then increased to $8 0 ~ ^ { \circ } \mathrm { C }$ at $6 . 0 \ ^ { \circ } \mathbf { C } \operatorname* { m i n } ^ { - 1 }$ $( 3 \mathrm { { m i n } ) }$ then increased to $3 0 0 ^ { \circ } \mathrm { C }$ at $6 . 0  { ^ \circ } \mathbf { C } \operatorname* { m i n } ^ { - 1 }$ $( 2 \mathrm { m i n } )$ .

# 3. Results and discussion

# 3.1. Synergistic removal of SMT

As shown in Fig. 1a, the individual US, ${ \mathrm { U S / F e } } ^ { 0 }$ , US/pre-magn- $\mathbf { \cdot } \mathbf { F e } ^ { 0 }$ and US/PS processes presented $1 . 6 \%$ , $4 . 1 \%$ , $6 . 2 \%$ and $7 . 2 \%$ SMT removal, respectively, after $^ { 1 \mathrm { h } }$ reaction. The results indicated that only US irradiation, $\mathsf { F e } ^ { 0 }$ or pre-magn- $\cdot \mathrm { F e } ^ { 0 }$ in the US irradiation and PS activated by US irradiation could not efficiently remove SMT. Only $4 . 1 \%$ and $6 . 2 \%$ SMT could be removed by ${ \mathrm { U S } } / { \mathrm { F e } } ^ { 0 }$ and US/pre-magn- $\mathrm { \cdot } \mathrm { F e } ^ { 0 }$ , which indicated that $\mathrm { Z V I / O _ { 2 } / H ^ { + } }$ process could also play marginal role for SMT removal in our system. The combination of magnetization and $\mathsf { F e } ^ { 0 } / \mathsf { P S }$ process increased the removal of SMT from $2 3 . 2 \%$ to $4 9 . 3 \%$ within $^ { 1 \mathrm { h } }$ , which was agreement with our previous report [30]. The employment of US could enhance the efficiency of $\mathrm { F e } ^ { 0 } / \mathrm { P } S$ and premagn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ processes, $4 9 . 8 \%$ and $9 8 . 3 \%$ SMT removal for the former and latter processes, respectively.

Corrosion of $\boldsymbol { \mathrm { F e } } ^ { 0 }$ can release $\mathrm { F e } ^ { 2 + }$ and the generation of $\mathrm { F e } ^ { 2 + }$ critically influences the efficiency of the $\mathrm { F e } ^ { 0 } / \mathrm { P } S$ -based systems [31]; however, $\mathrm { F e } ^ { 2 + }$ produced was fast oxidized by PS and ${ \bf O } _ { 2 }$ [29]. We measured total Fe to indicate the corrosion of $\mathrm { F e } ^ { 0 }$ in various systems. As shown in Fig. 1b, the concentration of total Fe was $0 . 0 5 7 \mathrm { m M }$ in US/ pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ system while only $0 . 0 2 7 \mathrm { m M }$ in ${ \mathrm { U S / F e } } ^ { 0 } / { \mathrm { P S } }$ and $0 . 0 3 1 \mathrm { m M }$ in pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ systems, indicating a larger corrosion rate in the former system, which mainly owing to the reactivity of $\mathsf { F e } ^ { 0 }$ enhanced by US irradiation [25] and the magnetization based on “magnetic memory” could enhance the release of $\mathsf { F e } ^ { 2 + }$ [30]. # 3.2. Factors influencing SMT removal

# 3.2.1. Initial pH

pH can significantly affect the release of $\mathrm { F e } ^ { 2 + }$ and play a major role in $s 0 _ { 4 } \cdot -$ and % OH based systems [32]. Therefore, the pH (3–10) effect on the SMT degradation was investigated. As shown in Fig. 2a and b, the degradation of SMT at all initial $\mathsf { p H }$ values increased with time. While, the removal decreased with increasing pH from 3 to 7. The value of $k$ at $\mathrm { p H } 7$ was smaller than that at $\mathrm { p H } 3$ and 5, which was mainly because the acid condition promoted the generation of $\mathrm { F e } ^ { 2 + }$ from premagn- $\mathbf { \cdot } \mathbf { F e } ^ { 0 }$ , herein enhanced the reaction rate. While, the values of $k$ at $\mathsf { p H 9 }$ and 10 were higher than at $\mathrm { p H } 7$ . One reason was mainly because PS could be faster activated by $\mathsf { F e } ^ { 2 + }$ and direct dissociation of persulfate into sulfate radicals could be easily achieved at alkaline pH [29]. The other reason was $S O _ { 4 } \cdot -$ radical was easily transformed to % OH radical via Eq. (8) at alkaline condition [18]. In other studies, for example, the removal of sulfadiazine by ${ \mathrm { U S } } / { \mathrm { F e } } ^ { 0 } / { \mathrm { P S } }$ process decreased from $9 5 . 7 \%$ to $3 5 . 7 \%$ when the $\mathsf { p H }$ increased from 7 to 10 [33]; the value of $k$ in pre-magn- $\mathrm { \cdot } \mathrm { F e } ^ { 0 } / \mathrm { P S }$ system to remove Orange G decreased from $0 . 0 3 6 \mathrm { { m i n } ^ { - 1 } }$ to $0 . 0 1 9 \mathrm { { m i n } } ^ { - 1 }$ while the $\mathtt { p H }$ increased from 7 to 9 [30]. The results suggested that US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process has the better performance for pollutants removal at $\mathtt { p H 1 0 }$ indicating the applicability of the process to remove municipal wastewater.

# 3.3. The reaction mechanism in US/pre-magn- ${ \cdot } F e ^ { O } / P S$ system

# 3.3.1. The main oxidative species

EPR tests with DMPO were applied to detect $S O _ { 4 } ^ { \cdot \cdot - }$ and % OH radicals generated in the different systems (see Fig. 3a). Both DMPO-OH adduct signals and $\mathrm { D M P O } { \cdot } S 0 _ { 4 }$ adduct signals were detected in these systems. While, both higher intensities of $S O _ { 4 } \cdot -$ and % OH radicals were detected in US/pre-magn- $\mathrm { \cdot F e } ^ { 0 } / \mathrm { P S }$ system suggested that both more $s 0 _ { 4 } \cdot -$ and % OH radicals were produced in the system. Moreover, radical scavenging experiments were conducted using the scavengers methanol (MA) and tert-butyl alcohol (TBA) to confirm the generation of the oxidative species. # 3.3.5. Proposed degradation pathway

Intermediates formed in the removal of SMT were analyzed by GC/ MS (Fig. S5). The extracts of intermediates were eluted with methanol (Fig. S5a) and methylene chloride (Fig. S5b). Some short chain carboxylic acids such as oxalic acid $( m / z = 9 0 )$ ), malonic acid $( m / z = 1 0 4 )$ ) and acetic acid $( m / z = 6 0 )$ ) (Table 1) were also detected.

The possible pathway of SMT degradation is shown in Fig. 8. The $\mathsf { s } { \mathrm { - N } }$ bond in sulfamethazine can be oxidized by $s 0 _ { 4 } \cdot -$ and/or % OH to form 2-amino-4,6-dimethylpyrimidine and sulfanilic acid, which is consistent with the results of the treatment of SMT by electro-Fenton process [6]. Sulfanilic acid will be further oxidized to 4-aminophenol. The result is consistent with the treatment of SMT by sonophotolytic goethite/oxalate Fenton-like process [45]. The aniline and 2-amino-4,6- dimethylpyrimidine can be further decomposed by the $S O _ { 4 } ^ { \cdot \cdot - }$ and % OH oxidation then formed short chain of carboxylic acids and finally $\mathrm { C O } _ { 2 }$ and $_ \mathrm { H _ { 2 } O }$ .

$5 \mathrm { m g / L }$ and $5 0 0 \mu \mathrm { g } / \mathrm { L }$ SMT were spiked into a real municipal wastewater respectively, (the wastewater quality parameters are shown in Table S5) which then were treated by different processes. As shown in Fig. 10a, $9 8 . 5 \%$ of SMT $\mathrm { 5 } \mathrm { m g / L ) }$ was removed by the US/pre-magn$\mathrm { F e } ^ { 0 } / \mathrm { P } S$ within $^ { 1 \mathrm { h } }$ , while only $7 4 . 1 \%$ , $6 3 . 6 \%$ and $6 8 . 8 \%$ removal were observed by the ${ \mathrm { U S } } / { \mathrm { F e } } ^ { 0 } / { \mathrm { P S } }$ , pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ and $\mathrm { U S / F e } ^ { 2 + } / \mathrm { P S }$ systems, respectively. Only $0 . 2 \mathrm { m M }$ PS and $0 . 0 8 \mathrm { m M } \mathrm { F e } ^ { 0 }$ were applied for the treatment of the effluent with $5 0 0 \mu \mathrm { g / L }$ SMT (see Fig. 10b). It was found $9 9 . 6 \%$ of SMT was removed by the US/pre-magn- $\mathrm { \cdot } \mathrm { F e } ^ { 0 } / \mathrm { P S }$ system within $^ { 1 \mathrm { h } }$ , while only $8 0 . 7 \%$ , $6 6 . 1 \%$ and $7 5 . 6 \%$ removal could be observed by the ${ \mathrm { U S } } / { \mathrm { F e } } ^ { 0 } / { \mathrm { P S } }$ , pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ and $\mathrm { U S / F e } ^ { 2 + } / \mathrm { P S }$ system, respectively. pH would decrease from 7 to 3–4 after reaction in deionized water in traditional $\mathrm { F e } ^ { 0 }$ -based PS system [30] and the pH decreased to 3.4 after reaction by US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process in deionized water in our study (see Table S6). While, the pH only changed from 7.3 to 7.4 and 7.5 for the treatment of $5 \mathrm { m g / L }$ and $5 0 0 \mu \mathrm { g } / \mathrm { L }$ SMT in municipal wastewater in the system, respectively.

A possible reason was that the municipal wastewater had different ions, especially buffer ions (such as $\mathrm { H C O } _ { 3 } ^ { - }$ and ${ \mathsf { C O } } _ { 3 } { } ^ { 2 - } \mathbf { \bar { \Phi } }$ . These buffer ions consume $\mathrm { H } ^ { + }$ via Eqs. (19) and (20). $\mathrm { H C O } _ { 3 } ^ { - }$ with a higher concentration than $\mathsf { C O _ { 3 } } ^ { 2 - }$ in the secondary wastewater plays a more significant role to maintain the $\mathsf { p H }$ . To verify this, we investigated the influence of different ions on the SMT removal and the pH variation. We chose the $\mathrm { \bf N a C l }$ , ${ \mathrm { N a } } _ { 2 } S { \mathrm { O } } _ { 4 }$ and ${ \mathrm { N a H C O } } _ { 3 }$ which are generally present in municipal wastewaters and the concentrations of these ions were similar with municipal wastewater. The degradation rates $( k )$ increased while adding NaCl and ${ \mathrm { N a } } _ { 2 } S { 0 } _ { 4 }$ and decreased while adding $\mathrm { N a H C O _ { 3 } }$ (Fig. S6). On the one hand, the presence of $\operatorname { H C O } _ { 3 } ^ { - }$ and $\mathbf { C l } ^ { - }$ could react with $S O _ { 4 } \cdot -$ radicals then to produce some less reactive radicals through Eq. (21) and Eq. (22) [50] and ${ \mathsf { S O } _ { 4 } } ^ { 2 - }$ could intensively decrease Oxidation Reduction Potential (ORP) of $\mathrm { S O _ { 4 } } ^ { \cdot - } / \mathrm { S O _ { 4 } } ^ { 2 - }$ then lead to less efficient activation of PS [18]. On the other hand, the corrosion of pre-magn- $\cdot \mathrm { F e } ^ { 0 }$ could be highly enhanced in the presence of Cl- and ${ \mathsf { S O } _ { 4 } } ^ { 2 - }$ because the magnetic field gradient force [51]. The positive of Cl- and ${ \mathsf { S O } _ { 4 } } ^ { 2 - }$ support the good performance of US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ system in secondary wastewater. Meanwhile, the finial pH in the presence of NaCl (3.2) and ${ \mathrm { N a } } _ { 2 } S { \mathrm { O } } _ { 4 }$ (3.3) were almost the same as that in the deionized water (3.4) while the final pH was 7.6 in the presence of ${ \mathrm { N a H C O } } _ { 3 }$ , indicating that the presence of $\mathrm { N a H C O _ { 3 } }$ might be one of the major reasons to keep the stability of $\mathrm { p H }$ . Therefore, NaCl and ${ \mathrm { N a } } _ { 2 } S { \mathrm { O } } _ { 4 }$ play the positive effect to enhance the degradation of SMT and $\mathrm { N a H C O _ { 3 } }$ keeps the stability of pH for treatment of municipal. As a result, US/premagn- $\cdot \mathrm { F e } ^ { 0 } / \mathrm { P } S$ process could improve the removal of SMT in municipal wastewater, save the chemical reagents and waste disposal cost without the adjustment of $\mathsf { p H }$ before and after treatment.

# 4. Conclusion

In this study, obvious synergetic effect was achieved by ultrasound radiation combining with pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process. Degradation rate to remove SMT could increase 3.3 folds and the synergy factor enhanced from 1.2 to 2.7. The stronger signals of $\mathrm { D M P O } { - } S 0 _ { 4 }$ and DMPO–OH adduct illustrated that more and faster $S O _ { 4 } ^ { \cdot \cdot - }$ and % OH radicals produced in the system. SMT could be efficiently removed at low $\mathsf { F e } ^ { 0 }$ dosage, high initial pH and low initial SMT concentration. Possible pathway of SMT removal was proposed. The value of EE/O in the system was much lower than those in other US-based systems. The process could also maintain the performance to remove SMT in municipal wastewater. So, US/pre-magn- $\mathbf { \cdot F e ^ { 0 } } / \mathbf { P S }$ process was a promising and energy saving approach to remove antibiotics in real wastewater.
