In this work, Prussian blue analogues (CuFe-PBA) derived copper-iron sulfides/N-doped porous carbon composite (CuFe-NC-SP-x) was prepared as an effective peroxymonosulfate (PMS) activator to degrade sulfadiazine (SDZ). A strategy that kills two birds with one stone was proposed to construct CuFe-NC-SP- $x ,$ i.e., S-etched CuFePBA (CuFe-PBA-S) was annealed with $\mathrm { N a H _ { 2 } P O _ { 2 } }$ in $\Nu _ { 2 }$ atmosphere to simultaneously introduce sulfur vacancy (Sv) and phosphorus doping. $4 0 ~ \mu \mathrm { M }$ SDZ was completely removed by CuFe-NC-SP-2/PMS in $2 0 \ \mathrm { m i n }$ $_ { ( 0 . 2 ~ g / \mathrm { L } }$ catalyst and $0 . 5 ~ \mathrm { m M }$ PMS). The $k _ { \mathrm { o b s } }$ value obtained by CuFe-NC-SP-2 $( 0 . 4 8 \mathrm { m i n } ^ { - 1 } \cdot$ ) was nearly 33 and 17 times higher than that of CuFe-PBA $( 0 . 0 1 4 ~ \mathrm { m i n } ^ { - 1 } )$ ) and CuFe-PBA-S $\left( 0 . 0 2 8 \mathrm { \ m i n } ^ { - 1 } \right) .$ ), respectively. Quenching tests, electron paramagnetic resonance (EPR) analysis indicated that PMS activation in the system involved radical pathway $2 6 . 1 ~ \%$ • OH and $2 2 . 7 \ \% \ S 0 _ { 4 . } ^ { * - }$ ) and non-radical pathway $( 1 7 . 8 ~ \% ~ ^ { 1 } 0 _ { 2 }$ and $3 3 . 4 ~ \%$ electron transfer process). • OH, ${ \mathrm { S O } } _ { 4 } ^ { * - }$ and $^ 1 0 _ { 2 }$ were mainly produced by S enhanced metal sites for PMS activation. The synergistic effect of Sv and P doping enabled the powerful electron transfer mechanism. Electrochemical tests and DFT calculations demonstrated that Sv existing in CuFe-NC-SP- $_ x$ improved the electron donor ability and increased the adsorption energy toward PMS, and phosphorus doping accelerated the electron transport from SDZ to PMS. This work not only provides a novel strategy to synthesize a high effective PMS activator by introducing Sv and phosphorous doing in one step, but also manages to comprehensively understand the electron transfer activation mechanisms of PMS facilitated by Sv and phosphorous doping.

# 1. Introduction

In the past decade, advanced oxidation processes (AOPs) based on sulfate radicals $( S O _ { 4 } ^ { * - } )$ ) have aroused increasing interest owing to the high redox potential $( 2 . 5 \substack { - 3 . 1 \mathrm { V } } )$ , longer half-life $( 3 0 { - } 4 0 ~ \mu s )$ to address current water pollution challenges [1–4]. Overall, the practical application of homogeneous PMS activation by transition metal ions is greatly restricted due to secondary pollution by these metal ions [2]. Consequently, much efforts have been made to develop low-cost solid catalysts with high efficiency, non-toxicity, and good stability for PMS activation.

Metal oxides and sulfides, such as $\mathrm { F e _ { 2 } O _ { 3 } }$ , $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ , CuO, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } ,$ . ${ \mathrm { { M n O } } } _ { \mathrm { { x } } } ,$ FeS, CuS, $\mathtt { C u } _ { 2 } s$ and $\mathrm { C o } { \mathbf { S } } _ { 2 }$ , have been used for PMS activation due to the low cost and simple synthesis [5–9]. In contrast with metal oxides, the strongly reductive sulfur species $( \mathsf { S } ^ { 2 - }$ and $S _ { 2 } ^ { 2 - } )$ in metal sulfides have been proven to promote metal redox cycles, thereby improving the catalytic activity [10,11]. Multi-metal sulfides can exert the activation ability and synergistic effect of multiple metals, exhibiting higher catalytic activity than single metal sulfides [12]. Yet, metal sulfides synthesized via reaction of metal ions with sulfur sources usually have a low specific surface area, and metal active sites inside sulfide particles cannot be fully utilized, thus probably limiting the activation efficiency.

Using precursors with ordered structures to construct metal sulfides or loading metal sulfides on porous supports can effectively solve the above problem [13]. Prussian blue and its analogues (PBAs), representing as $\mathrm { M } _ { 3 } ( \mathrm { I I ) [ M ( I I I ) ( C N ) } _ { 6 } ] _ { 2 }$ frameworks, are a type of coordination polymer composed of two kinds of metal centers/clusters surrounded by six cyanide groups $( - \mathrm { C } \mathrm { \equiv } \mathrm { N } )$ in an octahedral configuration. Porous carbon frameworks with double metal reactive sites can be synthesized from PBA through high-temperature pyrolysis. The obtained carbonbased materials not only have a large surface area and interconnected pores, but also contains abundant N atom doping. This is beneficial to adjust the electron donor properties of the carbon material, thereby enhancing the catalytic activity [14]. A novel carbon-based Fe-Co oxide derived from PBA developed by Liu et al., has a high specific surface area, enabling the metal oxide nanoparticles to get better dispersion [15]. Yang et al, used CuFe-PBA as precursor to synthesize a carbonbased material containing ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ and CuO, and achieved efficient removal of bisphenol S by regulating the charge balance [16]. However, the slow generation rate of low-valent metals restricted the improvement of activation efficiency of these catalysts. In addition, during activation process, these catalysts mainly active PMS to produce nonselective free radicals, which are easily interfered by environmental factors.

Defect engineering is also employed to modulate the electronic structure in nanomaterials synthesis. Sulfur vacancies (Sv) in metal sulfides have been successfully employed to regulate the electron distribution so as to expose more metal active sites and improve the adsorption energy between PMS and metal sulfides [17,18]. Sv in $\mathrm { F e S } _ { 2 } @ \mathrm { M o S } _ { 2 }$ derived from MIL-100(Fe) developed by Peng et al. possessed favorable affinity toward PMS and enhanced the contribution of non-radicals to $4 5 . 5 ~ \%$ [2]. Wang, et al. found the content Sv in chalcopyrite could switch radical to non-radical pathways and enhanced the degradation of pollutants on the chalcopyrite surface [19]. Thermal annealing in an inert atmosphere is a common technique to induce these vacancies. This is especially effective when a reducing gas (such as $\mathrm { H } _ { 2 } )$ is introduced into the annealing atmosphere, as the S element in materials are more easily reduced to $\mathrm { H } _ { 2 } S$ and escape [20,21]. On the other hand, it is reported that the electronic state of solid catalysts can be tuned by non-metal atoms doping. Phosphorus (P) has a larger atomic size and higher electron-donating ability, making it an intriguing dopant candidate to improve the catalytic activity by regulating the coordination environment and electronic structure of metal active center [22–24]. Sodium hypophosphite $\mathrm { ( N a H _ { 2 } P O _ { 2 } ) }$ can easily decompose at high temperatures to yield extremely reducing gases of $\mathrm { H } _ { 2 }$ and $\mathrm { P H } _ { 3 }$ [25]. On the basis of the above discussion, we proposed a “two birds with one stone” strategy, that is, the joint calcination treatment of metal sulfides with $\mathrm { N a H _ { 2 } P O _ { 2 } }$ is expected to introduce Sv and $\mathbf { P }$ doping at the same time (Fig. S1 in Supplementary Material).

In this study, using S-etched CuFe-PBA (CuFe-PBA-S) as a precursor to pyrolysis in the presence of $\mathrm { N a H _ { 2 } P O _ { 2 } }$ , we constructed a N-doped carbon-based CuFe sulfides nanocomposite (CuFe-SP-NC-x) with Sv and P-doping for PMS activation to eliminate emerging contaminants from aqueous solutions. Sulfadiazine (SDZ) is a widely used antibiotic that has been frequently detected in the aquatic environment worldwide (the concentration in some areas has been reached to $\mu \mathrm { g } / \mathrm { L }$ level), threatening people’s health [26]. Therefore, SDZ was selected as a target pollutant. To achieve the best catalytic performance, the content of Sv and P doping degree were modulated by altering the mass of $\mathrm { N a H _ { 2 } P O _ { 2 } }$ . The morphology and physicochemical properties of CuFe-SP-NC- $x$ was characterized. Various influencing parameters on SDZ removal was systematically studied. The involved mechanisms were thoroughly investigated through quenching tests, EPR spectroscopy, electrochemical analysis, and density functional theory (DFT) calculations. Compared with traditional metal oxides-loaded carbon materials derived from PBA, CuFe-NC-SP in this work has two main advantages. On the one hand, the reducing S species accelerate the generation of lowvalent metals, thereby promoting the redox cycles of metals. On the other hand, the synergistic effect of Sv and P doping triggered a powerful electron transfer mechanism. This work paves the way for the development of high-efficient catalysts containing precisely regulated S vacancies and P doping for PMS activation.

# 2.2. Catalyst synthesis

# 2.2.1. Synthesis of CuFe-PBA

$0 . 6 \mathrm { \ m m o l }$ $\mathrm { C u ( C H _ { 3 } C O O ) _ { 2 } }$ and $0 . 5 8 \mathrm { \ m m o l }$ $\mathrm { C _ { 6 } H _ { 5 } N a _ { 3 } O _ { 7 } { \cdot } 2 H _ { 2 } O }$ were dissolved in $4 0 ~ \mathrm { m L }$ deionized water to form solution a. 0.4 mmol $\mathrm { K _ { 3 } F e }$ $( \mathrm { C N } ) _ { 6 }$ was dissolved in $6 0 ~ \mathrm { m l }$ deionized water to form solution b. Solution b was then slowly dissolved in solution a. After stirring at $8 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ , the brownish red precipitate was collected by centrifugation, washed several times with deionized water and dried under vacuum at $6 0 ~ ^ { \circ } \mathrm { C }$ overnight. The product was named CuFe-PBA

# 2.2.2. Synthesis of CuFe-PBA-S

CuFe-PBA was ultrasonically dispersed evenly in ethanol. $\mathrm { N a _ { 2 } s }$ was then added into the above solution. The resultant solution was stirred vigorously for $1 0 \mathrm { { m i n } }$ and then transferred to the Teflon-lined autoclave, calcined at $1 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 6 \mathrm { ~ h ~ } }$ , and then cooled to room temperature naturally. The brown-black precipitate was washed three times with deionized water and ethanol, and finally dried at $6 0 ~ ^ { \circ } \mathrm { C }$ overnight under vacuum. The product was named CuFe-PBA-S.

# 2.2.3. Synthesis of CuFe-NC-SP- $x$ and CuFe-NC-S

$5 0 ~ \mathrm { m g }$ CuFe-PBA-S was placed downstream in a quartz boat with $\mathrm { N a H _ { 2 } P O _ { 2 } }$ at the upstream of a tube furnace to obtain a P-doped sample. Then, the sample was heated to $4 5 0 ^ { \circ } \mathrm { C }$ at a ramping rate of $5 ^ { \circ } \mathrm { C } / \mathrm { m i n }$ and held for $^ { 2 \mathrm { ~ h ~ } }$ under $\mathrm { N } _ { 2 }$ atmosphere. The products calcined with 0, 5, 10, 15, 50 and $1 0 0 \mathrm { m g N a H _ { 2 } P O _ { 2 } { \cdot } H _ { 2 } O }$ were named as CuFe-NC-S, CuFe-NCSP-1, CuFe-NC-SP-2, CuFe-NC-SP-3, CuFe-NC-SP-4, and CuFe-NC-SP-5, respectively. For comparison, CuFe-NC and CuFe-NC-P- $x$ were synthesized via the same procedure using CuFe-PBA as the precursor. And the solids obtained by calcining with 0, 5, 10, 15, 50 and $1 0 0 ~ \mathrm { m g ~ N a H _ { 2 } }$ - $\mathrm { P O } _ { 2 } { \cdot } \mathrm { H } _ { 2 } \mathrm { O }$ were denoted as CuFe-NC, CuFe-NC-P-1, CuFe-NC-P-2, CuFeNC-P-3, CuFe-NC-P-4, and CuFe-NC-P-5, respectively.

# 2.4. Experimental procedure

Typically, $1 0 \mathrm { m } \mathrm { g }$ of the catalyst was mixed with $5 0 \mathrm { m L }$ of $4 0 \mu \mathrm { M }$ SDZ solution. After that, $0 . 5 \mathrm { m M }$ PMS was added to initiate the degradation process. # 3. Results and discussion

# 3.1. Characterization

The microstructure and surface morphology of CuFe-PBA and CuFeNC-SP were determined by SEM and TEM and shown in Fig. 1 b–i. The particle size distribution of them were shown in Fig. S2. CuFe-PBA had a uniform cubic morphology with an average size of $7 8 \ \mathrm { n m }$ and smooth surface (Fig. 1 b and Fig. S2 a). With the S etching and P doping reaction, the as-synthesized CuFe-NC-SP still hold the cubic shape, while the surface became rough and depressed (Fig. 1 c). The average particle size of CuFe-NC-SP increased a little to $8 2 \mathrm { n m }$ , suggesting a slight aggregation occurred during the heat treatment (Fig. S2 b). According to the HAADF-STEM and EDS elemental mapping images in Fig. 1 d-i, Cu, Fe, S, and P elements are uniformly distributed throughout CuFe-NC-SP. The crystalline structures of synthesized materials was analyzed via X-ray diffraction (XRD) patterns as shown in Fig. 1 j and k. The characteristic peaks of the synthesized CuFe-PBA located at $1 7 . 7 ^ { \circ }$ , $2 5 . 1 ^ { \circ }$ , $3 5 . 9 ^ { \circ }$ , $4 0 . 3 ^ { \circ }$ and $4 4 . 3 ^ { \circ }$ were correspond to the crystal plane (2 0 0), (2 2 0), (4 0 0), (4 2 0), and (4 2 2) of the typical PBA $( \mathrm { P D F } \# 8 6 . 0 5 1 4 )$ ), respectively. CuFe-PBA-S still maintained the characteristic peaks of CuFe-PBA without impurity phases, suggesting that the S etching reaction did not destroy the crystal structure of CuFe-PBA. Being treated by hightemperature pyrolysis in the presence of $\mathrm { N a H _ { 2 } P O _ { 2 } }$ , characteristic peaks belonging to CuFe-PBA disappears, while some new peaks correlated with $\mathrm { F e C u } _ { 4 }$ $( \mathrm { P D F } \# 6 5  – 7 0 0 2 )$ , $\mathrm { C u _ { 2 } s }$ $( \mathrm { P D F } \# 2 9 . 0 5 7 8 )$ and $\mathrm { C u P } _ { 3 }$ $( \mathrm { P D F } \# 6 5 { \cdot } 1 9 7 3 )$ shows up in XRD patterns of CuFe-NC-SP- $_ x$ (Fig. $1 \ \mathbf { k } )$ . The crystal planes of (1 0 2), (1 1 0), (0 1 3), and (2 0 3) located at $3 5 . 5 ^ { \circ }$ , $4 4 . 2 ^ { \circ }$ , $4 5 . 7 ^ { \circ }$ , and $6 5 . 5 ^ { \circ }$ are related to $\mathrm { C u P } _ { 3 }$ in CuFe-NC-SP-4 and CuFe-NC-SP-5 further confirms this. Similarly, along with the degree of P doping increased, P atoms would replace part of S atoms, causing the intensity drop in characteristic peaks of $\mathtt { C u } _ { 2 } s .$ . The textural properties of the prepared catalysts were calculated by $\mathrm { N } _ { 2 }$ adsorption and desorption isotherm (Fig. S3). The BET surface areas were calculated using the BET method, and the results were shown in Table S2. All samples presented a typical type IV isotherm with hysteresis loops in the range of $0 . 8 \mathrm { - } 1 . 0 \mathrm { P } / \mathrm { P } _ { 0 } .$ indicating the existence of mesopores. The BET surface area of CuFe-NCS $( 2 7 . 0 0 \ \mathrm { m } ^ { 2 } / \mathrm { g } )$ was higher than CuFe-NC $( 5 . 3 3 \ \mathrm { m } ^ { 2 } / \mathrm { g } )$ and CuFe-PBA $( 1 7 . 8 4 ~ \mathrm { m } ^ { 2 } / \mathrm { g } )$ , indicating that S etching could increase the surface area and expose more active sites. However, the specific surface area of CuFeNC-SP-2 decreased to $5 . 9 5 ~ \mathrm { m } ^ { 2 } / \mathrm { g }$ . This might be related to the blockage of some pores by phosphates produced during pyrolysis. After catalysis reaction, the specific surface area of CuFe-NC-SP-2 increased to 13.62 $\mathrm { m } ^ { 2 } / \mathrm { g }$ , which may be due to the dissolution of phosphates on the surface making pores unobstructed and the erosion of active ROS on the carbon skeleton of catalysts.

The surface functional groups of CuFe-NC-S and CuFe-NC-SP-x were identified by FTIR (Fig. 2a). The peaks centered at 2104 and $5 9 6 ~ \mathrm { c m } ^ { - 1 }$ are attributed to the $\mathrm { c } { \equiv } \mathrm { N }$ stretching frequencies and Fe–CN bending modes derived from ferricyanine groups of CuFe-PBA [27]. The peaks at $1 3 8 4 . 2 8 \mathrm { - } 1 4 0 0 . 6 0 \mathrm { c m } ^ { - 1 }$ are related to the stretching vibration peaks of the $\mathrm { C - N }$ and $\mathrm { C } { = } \mathrm { N }$ groups stretching vibration, evidencing the formation of N-doped carbon skeleton [28]. A series of characteristic peaks of P-O bonds can be identified at approximately $1 0 0 0 ~ \mathrm { { c m } ^ { - 1 } }$ in CuFe-NC-SP- $_ x$ [29], suggesting the presence of $\mathfrak { p }$ element in the catalysts.

The chemical composition and valence states of CuFe-NC-SP- $_ x$ was examined via XPS analysis. Firstly, four main peaks were found in the high-resolution XPS spectrum of Cu 2p, as shown in Fig. 2b, including Cu $\boldsymbol { 2 } \mathsf { p } _ { 1 / 2 }$ at $9 5 2 . 8 8 ~ \mathrm { e V }$ , Cu 2p3/2 at $9 3 3 . 0 8 \ \mathrm { e V }$ and two satellite peaks at $9 6 2 . 2 8 \mathrm { e V }$ and $9 4 2 . 1 8 \mathrm { e V }$ . The peak of $\mathrm { C u } 2 \mathsf { p } 3 / 2$ was further divided into two sub-peaks located at 934.68 eV and 932.88 eV. The peak at 934.68 eV belongs to $\operatorname { C u } ( \operatorname { I I } )$ . The Auger electron spectroscopy (AES) of Cu was used to further distinguish if the peak at 932.88 eV belongs to Cu(I) or $\operatorname { C u } ( 0 )$ because the difference is only $0 . 1 \ \mathrm { e V }$ [30]. Therefore, the Auger electron spectroscopy (AES) of Cu was used to further distinguish $\operatorname { C u } ( 0 )$ and Cu(I). Through the least squares fitting, no $\operatorname { C u } ( 0 )$ was found in the spectrum of CuLM-2 (Fig. 2c) The result indicates that the main states of Cu in the samples are $\operatorname { C u } ( \operatorname { I I } )$ and $\mathrm { { C u ( I ) } }$ . The high-resolution Fe $\mathsf { 2 p }$ spectrum includes two peaks contributing to Fe $\boldsymbol { 2 } \mathsf { p } _ { 3 / 2 }$ and Fe $\boldsymbol { 2 } \mathsf { p } _ { 1 / 2 }$ (Fig. 2d). The Fe $\boldsymbol { 2 } \mathsf { p } _ { 3 / 2 }$ peak are resolved into three main sub-peaks, i.e., ${ \mathrm { F e } } ( 0 )$ at $7 0 8 . 2 8 \ : \mathrm { e V }$ , Fe(II) at $7 1 0 . 1 8 \ \mathrm { e V }$ , and Fe(III) at $7 1 3 . 4 8 \ \mathrm { e V }$ [31]. The occurrence of low valent metals including $\mathrm { { C u ( I ) } }$ , Fe(II) and $\mathrm { F e } ( 0 )$ mainly resulted from the reduction reaction of $\mathrm { P H } _ { 3 }$ and $\mathrm { H } _ { 2 }$ produced by the decomposition of $\mathrm { N a H _ { 2 } P O _ { 2 } }$ during the calcination treatment. As for the high-resolution S 1s spectra (Fig. 2e), three main peaks detected at 162.5 eV, 163.7 eV, 168.5 eV, corresponds to $S ^ { 2 - }$ , $S _ { \mathrm { n } } ^ { 2 - }$ , $S O _ { \mathrm { x } } ^ { 2 - }$ , respectively [32]. It is well believed that the reducing sulfur species $( S ^ { 2 - } , S _ { \mathrm { n } } ^ { 2 - } )$ are strong electron donors for the regeneration of the low valent metal in PMS activation [10]. The high-resolution XPS spectrum of $\mathrm { ~ P ~ } 2 \mathbf { p }$ , as depicted in Fig. 2f, mainly divided into two peaks assigned to P-O at $1 3 3 . 3 8 \ \mathrm { e V }$ and P-metal at $1 3 0 . 4 8 \ \mathrm { e V }$ [33], suggesting the successful P doping. In the high-resolution C 1 s spectra (Fig. 2g), the characteristic peaks at 284.8, 285.2, 287.0 and 288.7 eV were ascribed to sp2 graphitic-C $( \mathsf { C } - \pi )$ , $\mathrm { c } { = } \mathrm { N }$ , Fe–C and C–N structures, respectively [34]. This observation agrees well with FTIR analysis, and further proves that CuFe sulfides are anchored in the N-doped carbon framework. The highresolution N 1s spectra (Fig. 2h) could be well deconvoluted into five peaks with binding energies of 398.1, 398.9, 400.1, 401.3 and $4 0 3 . 7 \ \mathrm { e V }$ , corresponding to pyridinic-N, Cu/Fe–N, pyrrolic-N, graphitic-N and oxidized-N species, respectively [35]. Note that, N heteroatoms (graphitic, pyrrolic, and pyridinic N) existing in carbon-based catalysts usually play the role as Lewis basic sites to facilitate PMS adsorption and electron-transfer reaction via manipulating the neighboring carbon atoms to be positively charged [36].

In addition, the electron paramagnetic resonance (EPR) was preformed to recognize the existence of vacancy in the prepared catalysts. As depicted in Fig. 2i, CuFe-NC-S and CuFe-NC-SP- $_ x$ all show a set of strong signals with a $g$ -factor of 2.003, which can be attributed to Sv [2,37,38]. Of note, compare to CuFe-NC-S, CuFe-NC-SP- $x$ exhibits higher signal strength, suggesting that P doping can improve the content of Sv. More vacancies in the catalyst, much more exposed active metal sites, and much higher activation activity for PMS. Interestingly, the signal intensity is not always proportionate to the increase of $\mathrm { N a H _ { 2 } P O _ { 2 } }$ amount during the synthesis process. CuFe-NC-SP-2 shows the maximum intensity. Excessive P doping would cause some P atoms to occupy Sv position, resulting in the formation of metal phosphides with lower reactivity and even the destruction of sulfides. This is consistent with XRD patterns in Fig. 1k, in which a decreased intensity in characteristic peaks of metal sulfides and the appearance of metal phosphides.

# 3.2. Catalytic performance tests

Firstly, various CuFe-NC-SP- $x$ were used to activate PMS for the degradation of SDZ. As shown in Fig. 3a, Obviously, $\mathrm { N a H _ { 2 } P O _ { 2 } }$ mass significantly affected the activation activity of CuFe-NC-SP- $x$ . A complete SDZ removal was achieved by CuFe-NC-SP-2/PMS in $2 0 \mathrm { { m i n } }$ , while only $5 1 . 4 ~ \%$ of SDZ was eliminated by CuFe-NC-SP-5/PMS under the identical conditions. The calculated reaction rate constant $( k _ { \mathrm { o b s } } )$ of CuFe-NC-SP-2 is $0 . 4 8 \ \mathrm { m i n } ^ { - 1 }$ , which is much higher than CuFe-NC-SP-1 $( 0 . 2 3 \ \mathrm { \ m i n } ^ { - 1 } )$ , CuFe-NC-SP-3 $( 0 . 1 8 ~ \mathrm { \ m i n } ^ { - 1 } )$ , CuFe-NC-SP-4 (0.16 $\operatorname* { m i n } ^ { - 1 } )$ , and CuFe-NC-SP-5 $( 0 . 0 8 \mathrm { m i n } ^ { - 1 } )$ (Fig. 3d). This trend in the $k _ { \mathrm { o b s } }$ is consistent with the trend in the content of Sv as shown in Fig. 2i, suggesting Sv have an positive effect on the performance of catalysts. Notably, the catalytic activity of CuFe-NC-SP-5 was the lowest, which was related to the deconstruction of sulfides and generation of $\mathrm { C u P } _ { 3 }$ with weak catalytic ability because of the excessive P atoms (Fig. 1k). Fig. 3b compares the catalytic performance of CuFe-NC-SP-2 with CuFe-PBA, CuFe-PBA-S, CuFe-NC, CuFe-NC-S, and CuFe-NC-P-2. As seen, CuFePBA/PMS exhibited a very poor removal for SDZ $( 1 4 . 4 ~ \% )$ . A slightly enhancement was achieved by S etching as $2 0 \ \%$ of SDZ could be removed by CuFe-PBA-S/PMS. With the calcination treatment in $\Nu _ { 2 }$ atmosphere, the activity of catalysts was suddenly improved, with SDZ removal of $3 3 . 2 ~ \%$ by CuFe-NC/PMS and $6 5 . 2 ~ \%$ by CuFe-NC-S/PMS. This was due to the transformation of cyanide group in PBA to $_ \mathrm { N }$ doped carbon, which introduced abundant pores and exposed metal active sites [30,39,40]. The $k _ { \mathrm { o b s } }$ value obtained by CuFe-NC-SP-2/PMS $( 0 . 4 8 \ \mathrm { \ m i n } ^ { - 1 } )$ ) was 3.5 times that of CuFe-NC-S/PMS $( 0 . 1 3 \mathrm { \ m i n } ^ { - 1 } )$ ) (Fig. 3e), indicating that P doping could significantly improve the catalytic activity. Meanwhile, the performance of various carbon and metal based materials reported recently for the degradation of sulfonamides via PMS activation were compared with CuFe-NC-SP-2 in Table S3 and Fig. S4. # 3.3. Reactive species identification

# 3.3.1. Reactive oxygen species

To identify the main reactive oxygen species produced by CuFe-NCSP/PMS, EPR tests were performed using spin-trapping reagents of DMPO and TEMP to detect the generation of free radicals and singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ accordingly. As depicted in Fig. 4a, a set of increasing signals over time attributed to •OH and $\mathrm { { s o } _ { 4 } ^ { \bullet - } }$ were detected, showing that •OH and $S O _ { 4 } ^ { - }$ were continuously produced in the system. Besides, the appearance of peaks belonging to $\cdot _ { \mathrm { O _ { 2 } ^ { - } } }$ (Fig. 4b) and $^ 1 0 _ { 2 }$ (Fig. 4c) proved the formation of $\cdot _ { 0 _ { 2 } }$ and $^ 1 0 _ { 2 }$ in the system. Furthermore, quenching experiments were carried to determine the contribution of different ROS to the degradation of SDZ in the system. Firstly, the radical pathway was investigated with common scavengers of MeOH, TBA and BQ. MeOH could quench both ${ \mathrm { 8 O } } _ { 4 } ^ { \bullet - }$ $\mathbf { k } = 3 . 2 \times \bar { 1 0 ^ { 6 } } \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ and •OH (k $= 9 . 7 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } \bar { s } ^ { - 1 } )$ , while TBA was an effective scavenger of • OH $( \mathbf { k } =$ $6 . 0 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ . As shown in Fig. 4d, the removal of SDZ slightly decreased to $8 2 . 6 \%$ when an excess amount of TBA was added into the system, suggesting that •OH only made a weak contribution to the degradation of SDZ. Yet, the addition of MeOH caused the removal of SDZ dropped to $7 0 . 3 \%$ , indicating the contribution of $S O _ { 4 } ^ { - }$ was similar to •OH. Additionally, BQ and FFA were commonly used to trap $\mathbf { \cdot } _ { \mathbf { 0 } _ { 2 } ^ { - } }$ and $^ 1 0 _ { 2 }$ in the PMS activation system. BQ and FFA prevented $3 2 . 4 ~ \%$ and $3 4 . 7 ~ \%$ of SDZ degradation, respectively. This result seems to indicate that $\mathbf { \cdot } _ { \mathbf { 0 } _ { 2 } ^ { - } }$ and $^ 1 0 _ { 2 }$ contributed more to SDZ degradation than •OH and $\mathrm { { s o } _ { 4 } ^ { \bullet - } }$ . However, $\cdot _ { 0 _ { 2 } }$ is hardly to oxide the pollutants in PMS activation process due to the its weak oxidation ability [41,42]. $\cdot _ { 0 _ { 2 } }$ would intend to be quenched quickly by $_ \mathrm { H _ { 2 } O }$ to produce $^ 1 0 _ { 2 } [ 4 3 ]$ . Thus, $\cdot _ { 0 _ { 2 } }$ is considered to hold a limited contribution. The inhibition of SDZ degradation by BQ was attributed to that BQ blocked the conversion of $\mathbf { \cdot } _ { \mathbf { 0 } _ { 2 } ^ { - } }$ to $^ 1 0 _ { 2 }$ and consumed PMS through direct reaction with PMS [44]. As soon as FFA was added into the system, $k _ { \mathrm { o b s } }$ value dropped from 0.48 to $0 . 1 6 \mathrm { ~ m i n } ^ { - 1 }$ (Fig. 4e). The second-order rate constants of FFA with •OH and $\mathrm { { s o } _ { 4 } ^ { - } }$ are $1 . { \overset { \cdot } { 3 } } \times 1 0 ^ { 1 0 } \mathbf { M } ^ { - 1 } s ^ { - 1 }$ and $1 . 5 \times 1 0 ^ { 1 0 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ , which is much higher than that of TBA with •OH $( \mathbf { k } = 6 . 0 \times 1 0 ^ { 8 } \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ and MeOH with $\mathrm { { \ s O } _ { 4 } ^ { \bullet - } }$ $( \mathrm { k } = 3 . 2 \times 1 0 ^ { 6 } \mathrm { ~ M } ^ { - 1 } \mathrm { ~ s } ^ { - 1 } )$ [45]. Consequently, FFA would preferentially consume • OH and $\mathrm { { 8 O _ { 4 } ^ { * - } } }$ than $^ 1 0 _ { 2 }$ . Further, nitrobenzene (NB), benzoic acid (BA) and furfuryl alcohol (FFA) were used as probe compounds to quantitatively analyze the concentration of main ROS (•OH, $\mathrm { { 8 O _ { 4 } ^ { \bullet - } } }$ and $^ 1 0 _ { 2 } )$ generated in the system. The degradation of these probe compounds and the concentration of these ROS were shown in Fig. S11. The concentrations of ROS generated in the system was quantitative calculation via the method in Text S3 [46,47]. Although the concentration of $^ 1 0 _ { 2 } ( 2 . 5 0 \times 1 0 ^ { - 1 2 } \mathrm { M } )$ is one order of magnitude higher than that of • OH $( 5 . 6 7 \times 1 0 ^ { - 1 3 } \mathrm { ~ M } )$ and $S O _ { 4 } ^ { - }$ $( 1 . 0 6 \times 1 0 ^ { - 1 3 } \mathrm { ~ M } )$ , its second-order reaction rate constant $( k _ { 1 O _ { 2 } , \mathrm { { S D Z } } } = 8 . 9 \times 1 0 ^ { 6 } \mathrm { { \bf ~ M } } ^ { - 1 } s ^ { - 1 } )$ is much lower than those of •OH and $\mathrm { { \ s O } _ { 4 } ^ { \bullet - } }$ $( k _ { \mathrm { \cdot O H , S D Z } } = ( 3 . 7 \pm 0 . 5 ) \times 1 0 ^ { 9 }$ $\mathbf { M } ^ { - 1 } s ^ { - 1 } [ 4 8 ]$ and $\mathfrak { c } _ { S O _ { 4 } ^ { \bullet - } , \mathrm { { , } \mathrm { { ~ S D Z } } } } = 4 . 1 6 \pm 0 . 4 6 \times 1 0 ^ { 1 0 } \mathrm { { \bf { M } } ^ { - 1 } \mathrm { { \bf { s } } ^ { - 1 } } }$ [49]), so its contribution to SDZ degradation is very limited. # 3.3.2. Other pathway

As methyl phenyl sulfoxide (PMSO) would be oxidized by highvalent metal-oxo species $( \mathbf { M } ^ { \mathrm { I V } } ( \mathrm { O } ) / \mathbf { M } ^ { \mathrm { V } } ( \mathrm { O } ) )$ to produce $\mathrm { P M S O _ { 2 } }$ through an oxygen-atom-transfer reaction, it is commonly used as the probe to identify $\mathbf { M } ^ { \mathrm { I V } } ( \mathrm { O } ) / \mathbf { M } ^ { \mathrm { V } } ( \mathrm { O } )$ in AOPs. As shown in Fig. 5a, when PMS presented alone, $5 0 ~ \mu \mathrm { M }$ PMSO was oxidized and $4 0 . 5 ~ \mu \mathrm { M }$ $\mathrm { P M S O } _ { 2 }$ was detected within $6 0 \ \mathrm { m i n }$ , suggesting PMS could also oxidizes PMSO to $\mathrm { P M S O _ { 2 } }$ [50]. Although CuFe-NC/PMS, CuFe-NC-S/PMS and CuFe-NCSP/PMS consumed more PMSO than PMS alone, the corresponding $\mathrm { P M S O _ { 2 } }$ amount generated in the former three systems were almost the same as that of PMS alone, proving that almost no Fe(IV) and Fe(V) were produced. The excessive consumption of PMSO was attributed to its oxidation by the formed ROS. Thus, other non-radical pathways in the activation system needed to be further studied.

Electrochemical tests are generally used to unveil the mechanism of electrons transfer pathways (ETP) in PMS activation. Electrochemical response of different catalysts towards PMS and SDZ were recorded by open-circuit potential (OCP) experiments, as shown in Fig. 5b. As soon as PMS was added into the solution, the potential increased sharply, which was resulted from that PMS was adsorbed on the catalyst surface to form surface active complexes [51,52]. Later, the potential value reached a stable state, following the order of CuFe-NC-SP $( 1 . 1 8 ~ \mathrm { V } ) >$ CuFe-NC-P (0.81 V) $>$ CuFe-NC-S $( 0 . 7 0 \mathrm { V } ) >$ CuFe-NC (0.45 V). It was concluded that both S etching (CuFe-NC-S) and P doping (CuFe-NC-P) enhanced the electron distribution of CuFe-NC, thereby improving the ability to adsorb PMS. Yet, the highest potential obtained by CuFe-NCSP may be attributed to the presence of Sv on the catalyst surface.

As seen, both BPA and PCM could be completely eliminated in 5 min due to their lower electrophilicity index (Table S4). They preferred to donate electrons to the catalyst-PMS complexes and were degraded via ETP. The results further proved that ETP occupied a dominant position in the studied CuFe-NC-SP/PMS system.

# 3.4. Possible catalytic mechanisms

The chemical composition and valence states of the fresh and used CuFe-NC-SP was studied via XPS analysis to elucidate the catalytic mechanism in CuFe-NC-SP/PMS system. Transition metals of Cu and Fe in catalysts can serve as pivotal active sites to activate PMS to generate radicals of •OH and $\mathrm { { s o } _ { 4 } ^ { \bullet - } }$ according to Eqs. (1)–(6) [1]. Unlike traditional metal oxide catalysts where the valence states of metals increased due to electron loss for PMS activation, the valence states of Cu and Fe in the CuFe-NC-SP had a reduction after reaction. Specifically, the relative ratio of Cu(I) was increased from $5 1 . 4 ~ \%$ to $5 7 . 3 ~ \%$ (Fig. 6a), and the relative ratio of ${ \mathrm { F e } } ( 0 )$ and Fe(II) were also increased from $2 3 . 0 ~ \%$ and $3 2 . 5 ~ \%$ to $2 4 . 7 ~ \%$ and $3 3 . 7 ~ \%$ (Fig. 6b), respectively, suggesting their involvement in the PMS activation process. The reduction of the valence of the metal sites is conducive to the continuous activation process of PMS via radical pathway to maintain the catalytic activity. This reduction is attributed to the strong electron-donating capacity of sulfur species $( S ^ { 2 - } , S _ { \mathrm { n } } ^ { 2 - } )$ within the metal sulfides, facilitating the regeneration of low-valence metals (Eqs. (7)–(8) [56]. Correspondingly, the content of $S O _ { \mathbf { x } } ^ { 2 - }$ species increased after the reaction (Fig. 6c). The similar phenomenon was also found in studies by others [10,57–59]. Besides, the synergistic effect between different valent metals promoted the activation efficiency of PMS (Eqs. (9)–(10)) [60]. Moreover, the process of PMS activation via metal sites often coupled with the generation of $\cdot _ { 0 _ { 2 } }$ and $^ 1 0 _ { 2 }$ (Eqs. (11)–(13)) [1]. Note that the reduction of metals might also be related to the electron transfer mechanism. Specifically, SDZ molecules and PMS molecules were adsorbed on the surface of on the surface of CuFe-NC-SP simultaneously. The electrons of SDZ could transfer to the PMS molecules through the catalysts. Cu and Fe, serving as active sites, accepted electrons from SDZ to yield their reduced states.

In addition to the metal active sites, the N-doped carbon skeleton also could promote the activation of PMS. The graphitic-C (Fig. 6d) with free-flowing $\textstyle \pi - \pi$ electrons is beneficial to improving the conductivity of the material and accelerating electron conduction, and is also beneficial to improving the non-radical activation of PMS to mainly produce $^ 1 0 _ { 2 } [ 6 1 ]$ . The content of graphitic-C was decreased from $5 2 . 2 \%$ to 48.6 $\%$ after reaction. Besides, the graphitic-N content was decreased from $1 3 . 9 ~ \%$ to $4 . 1 \ \%$ (Fig. 6e), implying its participation in the catalytic reaction. On one hand, graphitic N can activate PMS to generate $\mathrm { \dot { ^ 1 } O _ { 2 } }$ through a non-radical pathway [62–64]. On the other hand, it possesses the highest electron density among pyridinic N, pyrrolic N, and graphitic N, which can attract more electrons from the neighboring C atoms [65]. Thus, graphitic N in CuFe-NC-SP promoted the electron transport between the catalyst and PMS. The content of P-O increased by $1 1 . 5 ~ \%$ (Fig. 6f), which was attributed to the oxidation of P by ROS produced in the activation process.

According to the discussion about results of ROS identification, electrochemical tests, and XPS analysis above, possible PMS activation mechanism by CuFe-NC-SP for SDZ degradation was proposed in Fig. 7. Firstly, radical pathway mainly involves • OH and ${ \mathrm { 8 O } } _ { 4 } ^ { \bullet - }$ generated by the activation of PMS at metal sites (Cu and Fe) and the synergistic effect between Cu and Fe. The reducing S species acted as a powerful electron donor and promoted the redox cycles of metals. Radical pathway accounted for $4 8 . 7 \%$ of SDZ degradation as shown in Fig. 4f. Secondly, non-radical pathways involving $^ 1 0 _ { 2 }$ formation and ETP accounted for the rest $5 1 . 3 \%$ of SDZ degradation. The $^ 1 0 _ { 2 }$ was mainly formed from the PMS activation by the metal active sites, graphitic C and graphitic N sites. The powerful ETP process that dominated SDZ degradation was mainly due to the synergistic effect of Sv and P doping. Sv in CuFe-NC-SP increased the adsorption energy between PMS and CuFe-NC-SP, and P doping promoted the electron transport reaction between SDZ and PMS molecules. The radical and non-radical pathways guaranteed the complete elimination of SDZ.

# 3.5. Degradation pathways and toxicity assessment of intermediates

The degradation intermediates of SDZ were identified by HPLC-MS analysis. A total of eight intermediates were identified as shown in Table S5 and Fig. S14. Four possible pathways were proposed in Fig. 8. Ecological structure activity relationship (ECOSAR) model was operated to determine the bio-toxicity of SDZ and intermediates [3]. Acute toxicity and Chronic toxicity were selected as evaluation indicators as shown in Fig. S15. The details about degradation pathways and intermediates toxicity assessment were detailed discussed in Text S5. In summary, SDZ was mainly degraded to small molecule products via pyrimidine ring opening, $\mathrm { { S O } _ { 2 } }$ extrusion, benzene ring opening and continuous hydroxylation. Among the eight main intermediates, the toxicity of them is no more than SDZ (except for P3 and P4 intermediates), indicating that the CuFe-NC-SP/PMS system can deal with SDZ pollution. In practical applications, the reaction time should be appropriately extended to improve the oxidation capacity of the system and remove products P4 and P5 as much as possible.

Although CuFe-NC-SP has achieved excellent catalytic performance for the removal of SDZ, it still faces problems to meet the needs of practical applications. Specifically, a) CuFe-NC-SP is not easy to separate from water; b) CuFe-NC-SP/PMS system dominated by electron transfer mechanism is effective in removing lower electrophilic index pollutants but not ideal for the pollutants with higher electrophilic index. The following measures are expected to be taken to address above problems in future work: a) Combining CuFe-NC-SP with magnetic materials to achieve rapid magnetic separation, or with a membrane to construct membrane materials with catalytic function; b) Combining CuFe-NC-SP with other materials based on other activation pathway, or coupling with a variety of advanced oxidation processes (including photocatalysis, electrocatalysis, etc.) to remove various emerging contaminants.

# 4. Conclusions

In summary, a novel catalyst CuFe-NC-SP with Sv and P doping were constructed by co-heating with ${ \mathrm { N a H } } _ { 2 } { \mathrm { P O } } _ { 4 }$ using PBA as precursor to active PMS for SDZ degradation. The degree of Sv and P doping can be conveniently tuned according to the amount of ${ \mathrm { N a H } } _ { 2 } { \mathrm { P O } } _ { 4 }$ . CuFe-NC-SP-2 displayed high tolerance to wide pH range of 5–11 and maintained excellent recyclability for in five consecutive cycles. Mechanisms investigation suggested the PMS activation by CuFe-NC-SP was facilitated via S-enhanced the redox cycles of $\mathtt { C u ( I ) / C u ( I I ) }$ and Fe(II)/Fe(III), and a dominant electron transfer process (ETP). The strong ETP was mainly attributed to the enhanced adsorption of PMS by Sv and the improved electron transfer between SDZ and PMS driven by P doping. Owing to the strong synergistic effect between Sv and P doping, CuFeNC-SP performed much better than CuFe-NC, CuFe-NC-S and CuFeNC-P. This work not only advances the design of catalysts with precise control of S vacancies and P doping, but also provides insight into how S vacancies and P doping improve the electron transfer mechanisms in PMS activation.
