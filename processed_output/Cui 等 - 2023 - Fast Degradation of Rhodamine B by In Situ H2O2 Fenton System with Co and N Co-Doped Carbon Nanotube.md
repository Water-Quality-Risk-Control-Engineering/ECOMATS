Abstract: In this study, an E-fenton oxidation system based on Co-N co-doped carbon nanotubes (Co-N-CNTs) was designed. The Co-N-CNTs system showed fast degradation efficiency and reusability for the degradation of rhodamine B (RhB). The XRD and SEM results showed that the Co-N codoped carbon nanotubes with diameters ranging from 40 to $4 0 0 \mathrm { n m }$ were successfully prepared. The E-Fenton degradation performance of Co-N-CNTs was investigated via CV, LSV and AC impedance spectroscopy. The yield of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ could reach $8 0 ~ \mathrm { m g / L / h }$ within $6 0 \mathrm { m i n } ,$ , and the optimal voltage and preparation temperature for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ yield in this system was $- 0 . 7 \mathrm { V }$ (vs. SCE) and $8 0 0 ^ { \circ } \mathrm { C }$ . For the target pollutant of RhB, the fast removal of RhB was obtained via the Co-N-CNTS/E-Fenton system (about $9 1 \%$ RhB degradation occurred during $6 0 \mathrm { m i n } )$ ), and the •OH played a major role in the RhB degradation. When the $\mathrm { F e } ^ { 2 + }$ concentrations increased from 0.3 to $0 . 4 \mathrm { m M }$ , the RhB degradation efficiency decreased from $9 1 \%$ to about $8 7 \%$ . The valence state of Co in the Co-N-C catalyst drove a $\mathrm { C o } ^ { 2 + } / \mathrm { C o } ^ { 3 + }$ cycle, which ensured the catalyst had good E-Fenton degradation efficiency. This work provides new insight into the mechanism of an E-Fenton system with carbon-based catalysts for the efficient degradation of RhB.

Keywords: carbon nanotubes; E-Fenton; rhodamine B; degradation; mechanism

# 1. Introduction

The electro-Fenton process based on hydroxyl radicals has attracted widespread attention due to its environmental friendliness, high efficiency and energy-saving properties [1,2], during which, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is formed in situ by the reaction of the two-electron reduction of $\mathrm { O } _ { 2 }$ (2e-ORR) on the cathode [3,4]. Then, the in situ-produced $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ reacts with the metal catalyst to produce radical •OH. The potential explosion hazard in the process of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production and transportation could be avoided by the on-site electrosynthesis of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ during the electro-Fenton process [5]. Lower energy consumption for organic pollutants’ elimination could be obtained by higher $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ selectivity and regeneration rates of $\mathrm { F e } ^ { 2 + }$ which are also the two key factors to promote the E-Fenton application [6,7].

Although excellent ORR catalytic activity and high $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ selectivity have been achieved by using noble-metal-based catalysts [8], their practical application in wastewater treatment was hindered by their scarcity and high cost [9].

Alternatively, carbon materials, especially biochar catalysts, have attracted increasing attention owing to their abundance, environmental sustainability, lost-cost and ease of fabrication [10]. In addition, carbon-based catalysts have attracted more attention due to their environmental sustainability, ease of manufacturing, low cost and abundance [11,12]. Moreover, the surface chemistry and pore structure of carbon-based catalysts can be easily adjusted to obtain more accessible active sites and faster mass transfer according to the preparation conditions [13,14]. The doping of metal, nitrogen and oxygen functional groups has been proved to be an effective strategy to improve their catalytic activity and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ selectivity, which will significantly affect the oxidation performance. Co-based catalysts embedded in carbon matrixes, which have large specific surface areas, can effectively improve the catalytic activity and prevent Co from leaching [8,15]. The removal mechanism of rhodamine B via adsorption and catalysis has been investigated by many researchers [16–19]. Carbon nanotubes and graphene are typical carbonaceous materials [20–22], which are widely used for the removal of pollutants via catalysis and adsorption due to their large surface area and good Fenton efficiency.

Herein, a convenient and quick pyrolyzing process was used to prepare Co-N co-doped carbon nanotubes (Co-N-CNTs) as catalysts for the E-Fenton process. Electrochemical analyses were used to explore the degradation mechanism of RhB via E-Fenton [12]. The effects of different reaction conditions on RhB degradation were also investigated, including different preparation temperatures, $\mathrm { F e } ^ { 2 + }$ concentrations and voltages [23].

# 2. Material and Methods

# 2.1. Synthesis of Co-N-C Composite Catalyst and Characterization

Some chemicals were purchased from Aladdin chemistry Co. Ltd. (Shanghai, China), such as rhodamine B (RhB, $\mathrm { A R } , \geq 9 5 . 0 \%$ ), and 5,5-Dimethyl-1-pyrroline N-oxide (DMPO, AR, $\geq 9 7 . 0 \%$ ). Urea, $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ (AR, $\geq 9 8 . 5 \%$ ), sulfuric acid $\mathrm { \cdot H } _ { 2 } \mathrm { S O } _ { 4 } .$ , AR, $9 5 . 0 { \sim } 9 8 . 0 \% )$ and sodium hydroxide $( \mathrm { N a O H } , \mathrm { A R } , \geq 9 6 . 0 \% )$ were obtained from Sinopharm Chemical Reagent Co., Ltd. (Shanghai, China).

The Co-N-C composite catalysts were prepared by pyrolyzing the metal and carbon precursors $( \mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ and dicyandiamide) in $\Nu _ { 2 }$ [11]. Typically, the mass ratio of $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ and dicyandiamide were kept at 1:10. A uniform pink paste was formed after adding suitable ethanol and continuously grinding in a crucible boat. Then, the paste was pyrolyzed at $8 0 0 ~ ^ { \circ } \mathrm { C }$ with a heating rate of $3 \ ^ { \circ } \mathsf { C } . \mathsf { m i n } ^ { - 1 }$ under $\Nu _ { 2 }$ atmosphere. Dicyandiamide $\mathrm { ( C _ { 2 } H _ { 4 } N _ { 4 } ) }$ ) was used as a C and $_ \mathrm { N }$ source during the pyrolysis process. The $C o ^ { 2 + }$ was reduced by dicyandiamide to form $\boldsymbol { \mathrm { C o } } ^ { 0 }$ , which would act as a catalyst to promote the formation of carbon nanotubes. After cooling down to room temperature, the products were leached in 0.5 M $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ at $9 0 ^ { \circ } \mathrm { C }$ for $5 \mathrm { h }$ to remove the undesirable impurities outside the carbon nanotubes, followed by being washed with PI water several times. Then, the catalysts were dried at $6 0 ~ ^ { \circ } \mathrm { C }$ and characterized by $\mathsf { X }$ -ray diffraction (XRD, D8 advance, Bruker, Karlsruhe, Germany), scanning electron microscopy (FE-SEM, SU8200, HITACHI, Tokyo, Japan), X-ray photoelectron spectroscopy (XPS, ESCALAB $2 5 0 \mathrm { { X i } , }$ Thermo Fisher Scientific, Waltham, MA, USA) and $\Nu _ { 2 }$ sorption/desorption analysis (ASAP2020-HD88, Micromeritics, Atlanta, GA, USA).

# 2.2. The Preparation of Electrode and Electrocatalytic Production of $H _ { 2 } O _ { 2 }$

The preparation of the cathode for the electrocatalytic production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was carried out as follows: $5 ~ { \mathrm { m g } } ~ { \mathrm { C o - N - C } }$ powders were well dispersed into a mixed solution of isopropanol $( 0 . 9 5 \mathrm { m L } )$ and polytetrafluoroethylene suspension (PTFE, $0 . 0 5 \mathrm { m L }$ , $6 0 \mathrm { w t \% }$ ) [24]. Slurry-like specimens were formed by heating in an $8 0 ^ { \circ } \mathrm { C }$ water bath, and then, the resulting black slurry was uniformly coated on the nickel foam collector. The working electrode was then dried at $6 0 ^ { \circ } \mathrm { C }$ for $6 \mathrm { { h } }$ and pressed into tablets for use. The schematic diagram of the electro-Fenton experimental process is shown in Figure 1.

The concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in situ produced by the cathode under different conditions was tested using a spectrophotometer using the potassium titanium oxalate photometric method [25]. Then, $1 . 0 0 \mathrm { m L }$ of a ${ \mathrm { H } } _ { 2 } { \mathrm { S O } } _ { 4 }$ solution $( 3 \mathrm { ~ M } )$ and $1 . 0 0 ~ \mathrm { m L }$ of a ${ \mathrm { K } } _ { 2 } \mathrm { T i O } ( { \mathrm { C } } _ { 2 } { \mathrm { O } } _ { 4 } ) _ { 2 }$ solution $( 0 . 0 5 \mathbf { M } )$ were added into $2 \mathrm { m L }$ of the tested solution.
