# A B S T R A C T

Keywords: Advanced oxidation process Heterogeneous catalysis Persulfate activation Pd/Fe nanocatalysts Rhodamine B degradation

Nanocatalysts prepared by immobilizing Pd nanoparticles on mesoporous iron oxides (ferrihydrite, goethite and $\alpha$ -hematite) were used in persulfate activation for the rapid oxidative degradation of an organic dye, Rhodamine B. Pd nanoparticles were prepared by dendrimer encapsulation and were then immobilized on the three iron oxide supports by wet impregnation. The Pd nanoparticles were seen to be on the surface of mono-dispersed iron oxide nanoparticle aggregates as characterized by scanning electron microscopy (SEM) and transmission electron microscopy (TEM). The nanomaterials were active catalysts for the rapid oxidation of the organic dye Rhodamine B with persulfate as the oxidant in a Fenton-like mechanism. Under optimized conditions Pd on ferrihydrite was the most active catalyst followed by $\mathrm { P d } / \alpha$ -hematite then Pd/goethite. The activation energies $\left( E _ { A } \right)$ were 43.3 $\mathrm { k J \cdot m o l ^ { - 1 } }$ , $9 8 . 6 ~ \mathrm { k J \cdot m o l ^ { - 1 } }$ and $7 5 . 1 \ \mathrm { k J \cdot m o l ^ { - 1 } }$ for Pd/ferrihydrite, $\mathrm { P d } / \alpha$ -hematite and Pd/goethite, respectively, correlating with the observed order of activity. The reaction followed Langmuir-Hinshelwood kinetics with surface rate constants of $k = 3 . 3 5 \times 1 0 ^ { - 5 } \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } s ^ { - 1 }$ , $1 . 5 5 \times 1 0 ^ { - 5 } \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } \mathrm { s } ^ { - 1 }$ and $2 . 8 0 \times 1 0 ^ { - 5 } \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } s ^ { - 1 }$ for the three catalysts, respectively.

# 1. Introduction

Rhodamine B (RhB), like other commercial dyes used in the textile and dye industry, is discharged into water streams leading to water pollution. In addition to its use in the textile and dye industry, Rhodamine B, a xanthene dye, is also used in the food industry as a colorant and due to its fluorescence properties, is also used in biology and biotechnology as a staining dye as well as in techniques such as fluorescence microscopy, flow cytometry and fluorescence correlation spectroscopy. The wide use of RhB means large quantities are discharged into water streams which make it hazardous and harmful to public health and therefore the need to remove and degrade RhB from industrial effluents. Although techniques such as adsorption, biological treatment and filtration processes have been successfully developed and used over the years, emerging techniques such as Advanced Oxidation Processes (AOPs) [1] have in recent years been the focus of research investigation as a potential remediation and treatment technology for decolorizing and degrading organic pollutants in water.

Oxidants traditionally used in AOPs include $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [2], $\mathrm { O } _ { 3 }$ [3–5], $\mathrm { K M n O } _ { 4 }$ [6], ${ \mathrm { K B r O } } _ { 3 }$ [7,8], $\mathrm { K C l O _ { 3 } }$ and activated $\mathrm { O } _ { 2 }$ [9,10]. Over the past couple of decades the use of persulfate as an emerging oxidant has received increasing investigation to address organic pollution of water sources [11–14]. The persulfate ion is one of the strongest known oxidants in aqueous solution $( \mathbf { E } ^ { 0 } = 2 . 0 1 \ \mathrm { V } )$ ). Additional advantages of persulfate over other oxidants are its ease of storage, high stability, high aqueous solubility and a relatively low cost. In addition, persulfate has greater capability of degrading several organic pollutants as it generates two radicals $( S O _ { 4 } ^ { \bullet \mathrm { ~ - ~ } }$ and •OH) upon activation. The formed sulphate radical is an even stronger oxidant with an oxidation-reduction potential between 2.5 and $3 . 1 \mathrm { ~ V ~ }$ [15,16] leading to an enhanced oxidation efficiency of the activated persulfate system. When combined with active metal nanoparticles, persulfate activation generates highly reactive radicals $( S O _ { 4 } ^ { \bullet \mathrm { ~ - ~ } }$ and •OH) that effectively break down organic pollutants, including dyes. Well-dispersed Pd nanoparticles, particularly when supported on mesoporous metal oxides, such as $\mathrm { F e _ { x } O _ { y } }$ enhance the efficiency of persulfate activation, leading to faster and complete dye degradation. This synergistic effect is mostly attributed to the high dispersion and reactivity of Pd nanoparticles, as well as the potential for surface-mediated reactions that facilitate dyes degradation. Methods of persulfate activation that have been investigated include; alkaline activation [17,18], UV-irradiation [19–21], thermal activation [22–24], ultrasound irradiation [25,26], microwave activation [27], electron beam activation [28] and transition metal activation [29–32].

Transition metal oxides have been previously reported in the literature [33,34] for the activation of persulfate, albeit with low catalytic activity. Supporting noble metal nanoparticles on the metal oxides enhances the persulfate activation resulting in increased catalytic activity [35]. A various number of materials were also recently used for photocatalytic degradation of pollutant dyes. The mixed-phase of titania polymorphs on the fixed substrate obtained from $\mathrm { N a ^ { + } }$ pre-treated procedures showed significant photocatalytic activity for the degradation of methylene blue, with the relative ratio of $\mathrm { T i O } _ { 2 } ( \mathrm { B } )$ and anatase $\mathrm { T i O } _ { 2 }$ phases (1:4) in the $0 . 2 5 ~ \mathrm { M } ~ \mathrm { N a }$ sample being one of the key factors to promote photocatalytic activity [36]. A study by Somdee and Wannapop reported on the degradation of methylene blue using Au, $\mathrm { Z n W O _ { 4 } }$ , and $\mathrm { A u / Z n W O _ { 4 } }$ decorated $\mathrm { Z n O }$ nanorod photocatalysts under UV radiation. The results showed that the coating materials can enhance the photocatalytic properties of the $\mathrm { Z n O }$ nanorods. The improvement was due to the $\mathrm { { A u } } / \mathrm { { Z n O } }$ , $\mathrm { Z n W O _ { 4 } / Z n O }$ , and $\mathrm { A u / Z n W O _ { 4 } / Z n O }$ having more efficient charge carrier separation efficiency in order to degrade the methylene blue in water [37]. Another study by Hui and Zhang presents a synthesis of undoped and Fe-doped $\mathrm { Z r O _ { 2 } }$ nanoparticles as photocatalysts for degradation of Rhodamine B dye. The undoped and doped $\mathrm { Z r O _ { 2 } }$ photocatalysts were successfully synthesized using co-precipitation process, and the results of photodegradation showed that the complete removal of $1 0 0 ~ \mathrm { { m g / l } }$ Rhodamine B was obtained after $5 5 \mathrm { { m i n } }$ UV irradiation for the $8 \ \mathrm { w t } \%$ Fe-doped $\mathrm { Z r O _ { 2 } }$ . The maximum photodegradation efficiency on $8 \mathrm { w t } \%$ Fe-doped $\mathrm { Z r O _ { 2 } }$ than undoped $\mathrm { Z r O _ { 2 } }$ could be related to the $\mathrm { F e ^ { 3 + } }$ ions that act as a sink and trap and transfer holes and electrons to minimize recombination of photoexcited electrons and holes [38]. In this work we synthesized mesoporous iron oxide materials using the inverse surfactant method reported in the literature [39] and subsequently immobilized Pd nanoparticles prepared by the dendrimer template method also reported in the literature [40]. The performance of the nanomaterials was then tested for their ability to activate the persulfate ion for the catalytic oxidation of Rhodamine B.

# 2.2. Synthesis of $P d / F e _ { x } O _ { y }$ nanocatalysts

The porous iron oxide supports (ferrihydrite, goethite and $\alpha$ -hematite) were prepare following a procedure from literature [41], with slight modifications. Shortly, a gel was formed by mixing P123 $( 5 . 0 ~ \mathrm { g } , 8 . 6 ~ \times$ $1 0 ^ { - 4 } \mathrm { m o l } )$ ), $0 . 6 6 \mathrm { m o l } )$ , $\mathrm { H N O } _ { 3 }$ $\left[ 4 . 8 \ g , 0 . 0 7 6 \ \mathrm { m o l } \right]$ ), $\mathrm { F e ( N O _ { 3 } ) _ { 3 } } { \cdot } 9 \mathrm { H } _ { 2 } \mathrm { O }$ $_ { 1 0 } g ,$ $0 . 0 3 5 \mathrm { m o l } \mathrm { }$ ) and 1-butanol $3 4 \ g$ , with vigorous stirring. The gel formed was then heated to $9 0 ~ ^ { \circ } \mathrm { C }$ over $^ { 3 \mathrm { ~ h ~ } }$ , followed by washing the resultant powder several times with ethanol, then drying at $6 0 ~ ^ { \circ } \mathrm { C }$ . The final powders were then calcined at $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ to give ferrihydrite $( \mathrm { F e } _ { 0 . 3 9 } \mathrm { O } _ { 0 . 5 9 5 } )$ and further heated to $2 5 0 ^ { \circ } \mathrm { C }$ for four hours to give goethite $\mathrm { ( F e O _ { 2 } ) }$ and to $4 5 0 ^ { \circ } \mathrm { C }$ for two hours to give hematite $\left( \mathrm { F e } _ { 2 } \mathrm { O } _ { 3 } \right)$ . A protocol reported in literature [40] was used to synthesis Pd nanoparticles as follows; G4-OH dendrimer $( 7 6 0 \mu \mathrm { l } .$ , $9 . 8 \%$ in methanol) was pipetted into a round-bottomed flask and methanol removed in vacuo. The resultant dendrimer was diluted to $1 0 \ \mathrm { m l }$ with Milli-Q water to make $0 . 5 ~ \mathrm { m M }$ stock solution of the dendrimer. Then this dendrimer stock solution $( 1 2 5 \mu \mathrm { l } )$ was pipetted and dissolved in Milli-Q water $( 9 . 8 \mathrm { m l } )$ ). After that potassium tetrachloropalladate, $\mathrm { K _ { 2 } P d C l } _ { 4 }$ $( 2 5 ~ \mu \mathrm { l } , ~ 0 . 1 ~ \mathrm { \sf ~ M } )$ was added slowly whilst stirring and left stirring for $^ { 1 \mathrm { ~ h ~ } }$ . This was followed by the slow addition of the freshly prepared sodium borohydride, $\mathrm { N a B H } _ { 4 }$ (50 μL, 1.0 M). To prepare the $\mathrm { P d / F e _ { x } O _ { y } }$ heterogeneous catalysts, the previously prepared iron oxides $_ { ( 0 . 5 ~ g ) }$ were added into the colloidal Pd nanoparticles, and the mixture sonicated for $^ { 3 \mathrm { ~ h ~ } }$ . The resulting mixture was centrifuged and the resulting powder dried in an oven at $8 0 ~ ^ { \circ } \mathrm { C }$ to obtain the $\mathrm { P d / F e _ { x } O _ { y } }$ heterogeneous catalysts.

# 2.3. Procedure for degradation of RhB

Degradation reactions were carried out by first stirring the organic dye with the catalyst in the reaction medium for $2 4 \mathrm { h }$ to allow adsorption equilibrium to take place. The oxidation reaction was then initiated by adding the oxidant. For temperature control the reactions were carried out in a jacketed flask. The reaction was followed by monitoring the decrease in absorbance at the wavelength of maximum absorption $\mathtt { ( \lambda _ { m a x } }$ $= 5 5 3 \mathrm { n m } )$ ) for RhB using UV–vis spectrophotometry by taking readings every three or five minutes.

# 3. Results and discussion

# 3.1. Synthesis and characterization of $P d / F e _ { x } O _ { y }$ nanocatalysts

Palladium dendrimer-encapsulated nanoparticle synthesis and characterization has been well studied and documented in the literature [40]. We prepared Pd-DENs with well dispersed particles with an average diameter of $3 . 5 \ \mathrm { n m }$ as estimated from TEM (details are in the Supporting Information) and immobilized the nanoparticles on mesoporous iron oxides. We used p-XRD, $\mathrm { N } _ { 2 }$ sorption/desorption, electron microscopy (SEM and TEM) and $\mathrm { H } _ { 2 }$ -TPR for the characterization of the $\mathrm { P d / F e _ { x } O _ { y } }$ heterogeneous catalysts.

Fig. 1 shows the powder $\mathbf { p }$ -XRD analysis results for the different nanocatalysts used in this study. The material calcined to $1 5 0 ^ { \circ } \mathrm { C }$ had the crystalline iron oxide phase of ferrihydrite (JCPDS: 96–901-2763); the one calcined to $2 5 0 ~ ^ { \circ } \mathrm { C }$ matched the iron phase of goethite (JCPDS: 96–901-1413 while the sample calcined to $4 5 0 ~ ^ { \circ } \mathrm { C }$ matched $\alpha$ -hematite (JCPDS 96–591-0083). The catalysts are, therefore, going to be referred to as Pd/ferrihydrite for the sample calcined to $1 5 0 ~ ^ { \circ } \mathrm { C }$ , Pd/goethite for the sample calcined to $2 5 0 ^ { \circ } \mathrm { C }$ and $\mathrm { P d } / \alpha$ -hematite for the sample calcined to $4 5 0 ^ { \circ } \mathrm { C }$ for the rest of the discussion. As seen in Fig. 1a, $\mathrm { P d } / \alpha$ -hematite (calcined to $4 5 0 ~ ^ { \circ } \mathrm { C } )$ exhibits XRD patterns with sharper diffraction peaks, indicating that the particles became larger. Low angle diffraction patterns seen in Fig. 1b were evidence of the existence of mesostructures in the materials [42]. The diffraction line for Pd/goethite and $\mathbf { P d } / \alpha$ -hematite appeared at lower 2θ values compared to that of $\mathrm { P d } /$ ferrihydrite, an indication that the particle sizes of the materials become bigger with increasing the final calcination temperature. XRD spectra for a commercial sample of $\mathrm { F e _ { 2 } O _ { 3 } }$ are included for comparison with our prepared materials. Peaks due to the loaded Pd nanoparticles could not be detected in the XRD analysis due to the low nominal percentage of $0 . 2 ~ \%$ Pd. (See Table 1.)

Nitrogen sorption experiments revealed all the three materials, Pd/ ferrihydrite, Pd/goethite and $\mathrm { P d } / \alpha$ -hematite, to exhibit Type IV adsorption isotherms, with a Type I hysteresis loop characteristic of materials with an ordered porous structure (Fig. 1c). The pore diameters of the materials increased from 9.07 to $3 4 . 6 \ \mathrm { n m }$ in the order Pd/ferrihydrite $< \mathrm { P d } ,$ /goethite $< \mathrm { P d } / \alpha$ -hematite, corresponding to the increasing final calcination temperatures. When comparing the pore diameters of the Pd-loaded with the unloaded iron oxides, we observed that the diameters decreased from 11 to $9 . 0 7 \mathrm { n m }$ for ferrihydrite and from 16.3 to $1 4 . 0 \ \mathrm { n m }$ for goethite while an increase in pore size was observed upon loading Pd onto hematite and the commercial $\mathrm { F e _ { 2 } O _ { 3 } }$ samples. The pore volumes of all materials however, decreased upon loading with Pd indicating that the palladium occupied the mesopores of the iron oxides. The surface area of the materials decreased significantly with an increase in the final calcination temperature for the unloaded iron oxides, while an increase in surface area was observed upon immobilizing Pd nanoparticles.

The mesoporisity and surface morphology of our catalysts was analysed by SEM and TEM microscopic methods of analysis. SEM images are presented in the Supplementary Information. The increase in crystallite size observed from BET calculations was clearly seen in the representative TEM images in Fig. 2. Supported Pd nanoparticles were observed on the TEM images, particularly on the large crystallite sized Pd/hematite. The sizes of the nanoparticles as can be observed from the size distribution histogram of $\mathrm { P d } / \alpha$ -hematite (Fig. 2d) are in the range of 2 nm to $_ { 6 \mathrm { n m } }$ , with the average size of $3 . 9 \pm 0 . 6 \ : \mathrm { n m }$ . As determined from their respective size distribution histograms, the average diameter of the mono-dispersed supported palladium nanoparticles corresponds to the average diameter of the colloidal palladium dendrimer-encapsulated nanoparticles $( 3 . 5 ~ \mathrm { n m }$ ), again showing the effectiveness of the synthesis method used in this study.

From EDX analysis (Supplementary Information) the elemental composition of our catalysts was confirmed to be Fe, O and Pd as expected.

The redox properties of the Pd/Fe nanocatalysts were investigated by performing hydrogen temperature programmed reduction analysis (Fig. 3). The relatively small peaks observed between 100 and $2 0 0 ~ ^ { \circ } \mathrm { C }$ (Fig. 3) can be attributed to the decomposition of palladium hydride which is formed during the purging of the TPR apparatus with $\mathrm { H } _ { 2 }$ prior to the analysis [43–45]. The remaining two peaks correspond to the twostage reduction of $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e } ^ { 0 }$ with the peak appearing around $2 5 0 ~ ^ { \circ } \mathrm { C }$ - $3 0 0 ~ ^ { \circ } \mathrm { C }$ being attributed to the reduction of $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e } ^ { 2 + }$ or partial reduction to $\mathsf { \overline { { F e } } } ^ { 3 + }$ and $\mathrm { F e } ^ { 2 + }$ [44]. Peaks appearing between $5 0 0 ~ ^ { \circ } \mathrm { C }$ - $6 0 0 ~ ^ { \circ } \mathrm { C }$ are due to the reduction to zero-valent iron. From Fig. 3, we observe that reduction temperatures for Pd/ferrihydrite are shifted to lower temperatures relative to Pd/Goethite and $\mathrm { P d } / \alpha$ -hematite, an observation that can be explained to be due to the increase in particle size and decrease in surface area for the three nanocatalysts. To investigate the effect of loading Pd we ran TPR for the unloaded mesoporous iron oxide (hematite). We observed shifts of peaks to lower temperatures for all Pd loaded catalysts, with a shift from 740 to $5 7 0 ~ ^ { \circ } \mathrm { C }$ for $\mathrm { P d } /$ $\alpha$ -hematite, 635 to $5 7 0 ~ ^ { \circ } \mathrm { C }$ for Pd/goethite while the Pd/ferrihydrite reduction peak was shifted from 550 to $5 2 0 ^ { \circ } \mathrm { C } .$ A similar effect of noble metals on the redox properties of transition metal oxides was reported by Berry et al. [44].

The characterization results demonstrated the successful preparation of well dispersed (Pd-DENs) Pd dendrimer-encapsulated nanoparticles and ordered mesoporous Pd/FexOy nanocatalysts. The poly(amidoamine) dendrimers with hydroxyl terminal groups (G4-OH dendrimers) have a high affinity for Pd nanoparticles due to the strong interaction between the Pd surface and the hydroxyl groups of the dendrimers. The hydroxyl groups on the dendrimer’s surface act as ligands, coordinating with Pd atoms and stabilizing the nanoparticles. The linkage between dendrimer with the attached Pd nanoparticles and the iron oxide support was believed to be achieved through the covalent attachment of the dendrimer to the iron oxide surface. This proposed mechanism is similar to those reported in the literature [46,47], where dendrimer can act as a spacer, preventing Pd nanoparticles aggregation and improving dispersion on the iron oxide surface. In addition, the iron oxide support can provide structural stability to the Pd nanoparticles and enhance their resistance to sintering.

# 3.2. RhB degradation over $P d / F e _ { x } O _ { y }$ heterogeneous catalysts

The catalytic oxidation of the organic dye Rhodamine B using activated persulfate was investigated by varying different reaction conditions. The degradation of RhB was monitored by following the change in absorbance at the wavelength of maximum absorbance for RhB $( \lambda _ { \operatorname* { m a x } } =$ $5 5 3 ~ \mathrm { n m }$ ). Results using the three catalysts are shown in Fig. 4a, along with results for when no catalyst was used as well as Pd free iron oxide (ferrihydrite). As observed from Fig. 4a both reactions carried out without Pd loaded catalyst showed no significant decrease in absorbance at $\lambda _ { \operatorname* { m a x } } = 5 5 3 \ \mathrm { n m }$ , showing that these are poor catalysts for persulfate activation for the oxidation of RhB. The other two iron oxide supports, goethite and $\alpha$ -hematite gave similar results as ferrihydrite support. On supporting Pd on the iron oxides, a significant increase in catalytic activity was observed with order being Pd/ferrihydrite $> { \mathrm { P d } } / \alpha$ -hematite $>$ Pd/goethite. The catalytic activity of ferrihydrite is superior to that of goethite and hematite due to its unique structure and surface properties [48,49]. The surface of ferrihydrite contains abundant iron-associated hydroxyl groups, which act as key catalytic sites, facilitating the decomposition of persulfate into $S O _ { 4 } ^ { \bullet \mathrm { ~ - ~ } }$ and $\bullet { \cal O } H$ radicals. In addition, ferrihydrite is metastable, it’s not the most stable form of iron oxide and can transform over time into more stable forms like goethite and hematite. This instability can also contribute to its reactivity [48,49]. The results for the different catalysts were shown to follow first-order kinetics with respect to RhB (Fig. 4b) according to Eq. $1 . # 3.3. Investigation of the effect of catalyst dosage

On investigating the effect of catalyst loading on the oxidation of RhB, we observed that the catalytic activity increased with the amount of catalyst (Fig. 5) indicating that the reaction was indeed catalytic. From the results in Fig. 5, we chose to use $0 . 6 \ g / \mathrm { L }$ as the optimum catalysts concentration as this gave sufficiently fast reaction times without the use of a large amount of catalyst.

# 3.4. Investigation of effect of initial pH

Due to the dependence of both $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ system and the solution chemistry of the dye RhB, it was essential to experimentally determine the effect of the initial pH of the reaction mixture. We varied the pH from 2.4 to 10.8 while all other conditions were maintained constant. The different species of RhB in aqueous solution, namely zwitterionic, cationic and lactone form [51] also have a significant influence on the degradation of the dye. From Fig. 6, the reaction was slow at low pH values, increasing to a maximum around pH values of 6–7 and then decreasing again at higher pH values. From these observations, the pH of the original RhB was unadjusted for further reactions as the pH values were between six and seven.

# 3.7. Stability and recyclability of $P d / F e _ { x } O _ { y }$ catalysts

The stability and recyclability of our catalysts was investigated by recovering the catalysts by filtration, washing and drying and then reusing the catalyst. Only Pd/ferrihydrite was used to demonstrate the reusability of our catalysts by repeating the oxidation of RhB with $\mathrm { P d } /$ ferrihydrite catalyst five times. Fig. 9a shows that the apparent rate constants did not significantly change from the initial value obtained for the original run after the fifth cycle. This reusability up to five times showed the robustness of our catalyst. From Fig. 9b we also observed from the TEM image that the surface morphology and porous nanostructure of the catalyst was not significantly changed, again showing the stability of the catalyst. Leaching studies using by ICP analysis showed no significant amount of Pd or Fe, indicating heterogeneous catalysis was the main mechanism and again showing our catalysts’ stability and suitability for use as catalysts for the activation of persulfate for the oxidation of organic dyes such as Rhodamine B. Fig. 9b shows the high-angle diffraction pattern of the recycled Pd/ferrihydrite. The diffraction pattern of the recycled Pd/ferrihydrite corresponded to the one of the fresh Pd/ferrihydrite (Fig. 1a), with a JCPDS reference card 96–901-2763. This is an indication that the structural integrity of the Pd/ferrihydrite is not compromised after the fifth run, again showing the stability of the catalyst. The low-angle diffraction pattern of the recycled Pd/ferrihydrite as represented in Fig. 9b showed a diffraction peak at lower angle, indicative of a mesoporous nature. This also revealed that porous nanostructure of the catalysts was not significantly changed after recycling. These features make the synthesized materials good catalysts for various applications.

# 3.8. Proposed mechanism and degradation pathway

Activation of persulfate by iron based catalysts has been the subject of study and several reports propose the following Fenton- like mechanism [12,56,57]:

$$
2 - = F e ^ { 3 + } + - = P d ^ { 0 }  2 - = F e ^ { 2 + } + - = P d ^ { 2 + }
$$

$$
- = F e ^ { 2 + } + S _ { 2 } O _ { 8 } { } ^ { 2 - }  - F e ^ { 3 + } + S O _ { 4 } { } ^ { - * } + S O _ { 4 } { } ^ { 2 - }
$$

$$
{ S O _ { 4 } } ^ { - \bullet } + H _ { 2 } O {  } { \bullet } O H { + } H ^ { + } + { S O _ { 4 } } ^ { 2 - }
$$

In eqs. 1, 2 and 3, $- =$ represents the surface of the $\mathrm { P d / F e _ { x } O _ { y } }$ catalysts. At the surface the $\mathrm { F e } ^ { 3 + }$ is reduced to $\mathrm { F e } ^ { 2 + } \left( \mathrm { E q . 1 } \right)$ which then reacts with the persulfate ion, $S _ { 2 } O _ { 8 } { } ^ { 2 - }$ to form the sulphate radical, $S O _ { 4 } ^ { \bullet } { } ^ { - } \left( \operatorname { E q } . \right.$ . 2). The sulphate radical can then be involved in the dye degradation. Furthermore, the sulphate radical is capable of reacting with water forming the hydroxyl, •OH radical (Eq. 3) which also oxidizes the organic dye, ensuring enhanced degradation, thus the term ‘advanced oxidation process.

In order to have an insight into the possible degradation mechanism of RhB using our catalyst system, we performed LC-MS analysis. We collected samples at time intervals and the LC-MS chromatograms are shown in Fig. 10. The initial chromatogram (Fig. 10a; time $= 0$ mins) shows the major peak for RhB at a $\mathrm { t } _ { \mathrm { R } } = 1 7$ mins, with some minor peaks attributed to contaminants in the dye. After $3 \ \mathrm { m i n }$ the chromatogram (Fig. 10b) shows the appearance of peaks labeled 2 and 3 at $\mathrm { t } _ { \mathrm { R } } = 7 . 5$ mins and $\mathrm { t _ { R } } = 8 . 7 5$ mins, respectively. After 6 mins (Fig. 10c) peaks 2 and 3 disappear and several small peaks appear with more small peaks appearing after 15 mins (Fig. 10d) and are highlighted by a rectangle in Figs. 10(c) and (d). From the $m / z$ values obtained for 2 $( \mathbf { m } / \mathbf { z } = 2 5 4 )$ ) and $3 ( \mathrm { m / z } = 3 0 0 )$ ) as well as for some of the peaks in highlighted rectangle, a mechanism for the degradation of RhB using our $\mathrm { P d } / \mathrm { F e _ { x } O _ { y } } / \mathrm { P S }$ catalyst system is proposed in Scheme 1. Some of the intermediates identified from LC-MS included adipic acid, glutaric acid, phthalic acid, benzoic acid, glycerol, 2-hydroxypropanoic acid and 2-hydroxybutanol. Some of these intermediates were also observed in the oxidative degradation of RhB by Lu et al. [57].

# 4. Conclusions

Palladium nanoparticles supported on mesoporous iron oxides were synthesized and characterized by p-XRD, BET, SEM, TEM, and EDX analyses. Three mineral forms of iron oxide namely ferrihydrite, goethite and $\alpha$ -hematite were identified by XRD depending on the final calcination temperature. The materials were thus named Pd/ferrihydrite, Pd/goethite, and $\mathrm { P d } / \alpha$ -hematite. The prepared nanomaterials were used in the activation of persulfate for the oxidation of the organic dye Rhodamine B in a Fenton-like advanced oxidation process. Pd/ferrihydrite was found to be most catalytically active in the oxidation of RhB. The catalyst system used here was comparable to other Fe based systems used for the oxidation of RhB and were shown to have a higher catalytic activity when compared to $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Our catalyst system (Pd/ ferrihydrite/PS) was compared to three systems which were reported in the literature. The polyhydroquinoline (PHQ) used as an electron shuttle in the activation of PS by Leng et al reported a rate constant of $4 \times 1 0 ^ { - 4 }$ $s ^ { - 1 }$ for the degradation of RhB. For our work, we used Pd as an electron shuttle and managed to obtain a rate constant of $2 . 2 \times 1 0 ^ { - 3 } { { s } ^ { - 1 } }$ . Yuan et $^ { a l }$ using the $\mathrm { P d / F e ^ { 2 + } / H _ { 2 } O _ { 2 } }$ system got a rate constant of $1 . 8 2 \times { 1 0 } ^ { - 3 } { s } ^ { - 1 }$ and Lu et al using the $\mathrm { F e } ^ { 3 + } / \mathrm { P S }$ system got a rate constant of $1 . 4 5 \times 1 0 ^ { - 4 }$ $s ^ { - 1 }$ . The activity of the catalysts was Pd/ferrihydrite $> \mathrm { P d } / \alpha$ -hematite $>$ Pd/goethite with the activation energy respectively being $4 3 . 3 \mathrm { ~ k J }$ . $\mathrm { m o l } ^ { - 1 }$ , $7 5 . 1 \ \mathrm { K j . m o l } ^ { - 1 }$ , and $9 8 . 6 \mathrm { k J . m o l } ^ { - 1 }$ , correlating with the order of activity which was observed. The reaction followed LangmuirHinshelwood kinetics with $\mathbf { k } ~ = ~ 3 . 3 5 ~ \times ~ 1 0 ^ { - 5 } ~ \mathbf { m o l } { \cdot } \mathbf { m } ^ { - 2 } { \cdot } s ^ { - 1 }$ , $2 . 8 0 ~ \times$ $1 0 ^ { - 5 } \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } s ^ { - 1 }$ and $1 . 5 5 \times 1 0 ^ { - 5 } \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } s ^ { - 1 }$ for Pd/ferrihydrite, $\mathrm { P d } /$ $\alpha$ -hematite and Pd/goethite catalysts, respectively.

The possible degradation pathway was determined from LC-MS analysis, showing various intermediates like glycerol and diacids that could be important fine chemicals. Overall, the results show the use of an alternative oxidant that can be used in a typical advanced oxidation process (AOP) in the remediation and treatment technologies used for decolorizing and degrading organic pollutants in water and wastewaters.
