# Facile green synthetic graphene-based Co-Fe Prussian blue analogues as an activator of peroxymonosulfate for the degradation of levofloxacin hydrochloride

Yunqing Pi ⇑ , Lingjia Ma, Peng Zhao, Yangdan Cao, Huiqin Gao, Chunfeng Wang, Qilu Li ⇑ , Shuying Dong, Jianhui Sun

Key Laboratory for Yellow River and Huai River Water Environment and Pollution Control, Ministry of Education, Henan Key Laboratory for Environmental Pollution Control, School of Environment, Henan Normal University, Xinxiang, Henan 453007, PR China

# GRAPHICAL ABSTRACT

Proposed mechanism of Co-FePBAs@rGO/PMS system. Facile synthesis of magnetic Co-Fe PBAs@reduced graphene oxide (rGO) hybrid (Co-Fe PBAs@rGO) nanocomposites is reported, with first-time usage of these novel nanocomposites for the application of antibiotic degradation. The Co-Fe PBAs@rGO composites showed high efficient to activate PMS to degrade LVF.

A kind of Co-Fe Prussian blue analogues (Co-Fe PBAs), cobalt hexacyanoferrate $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ , and graphene oxide (GO) were combined to synthesize magnetically separable Co-Fe PBAs@rGO nanocomposites through a simple two-step hydrothermal method. The crystalline structure, morphology and textural properties of the Co-Fe PBAs@rGO nanocomposites were characterized. The catalytic performance of the nanocomposites was evaluated by PMS activation, with Levofloxacin Hydrochloride (LVF) as the target contaminant. Synergistic interactions between the Co-Fe PBAs and rGO prevented the aggregation of the Co-Fe PBAs nanoparticles, which resulted in enhanced degradation efficiencies. The influence of several critical parameters was investigated, including the reaction temperature, PMS and Co-Fe PBAs@rGO catalyst concentrations, solution pH and salt content. LVF degradation was favored at higher catalyst and PMS concentrations, high temperatures, and in neutral or weak acidic solutions. Sulphate radicals were the dominant active species in the Co-Fe PBAs@rGO/PMS system. In addition, the Co-Fe PBAs@rGO exhibited no significant decrease in LVF degradation efficiency following five catalytic cycles. Thus, the as-prepared Co-Fe PBAs@rGO nanocomposite catalyst might be applied to the removal of hard-to-degrade organics owing to its high catalytic ability to activate PMS, as well as its good reusability and recyclability.

# 1. Introduction

As one of the largest groups of pharmaceutical compounds, antibiotics are used extensively in human and veterinary medicine. However, antibiotics cannot be absorbed completely by the human body or by animals in the course of use; hence, a large portion is discharged into the environment in the form of metabolic products. Traditional biological treatments are insufficient for the removal of antibiotics in wastewater due to the extensive array of chemical products that are generated by drug manufacturing plants. There have been many recent investigations on advanced oxidation processes (AOPs) in refractory organic wastewater treatment, which are based on the generation of highly reactive radical species, such as hydroxyl radicals (OH ), superoxide radicals $( \mathrm { O } _ { 2 } ^ { - } , \mathrm { H O } _ { 2 } ^ { - } )$ , and sulfate radicals $( \mathrm { S O } _ { 4 } ^ { \cdot - } )$ ) [1–3]. Compared to OH , which has a redox potential of $1 . 8 \mathrm { - } 2 . 7 \ : \mathrm { V }$ , sulphate radicals $( \mathsf { S O } _ { 4 } ^ { . - } )$ are comparable to, or even higher, with a standard reduction potential of $2 . 5 { - } 3 . 1 \ V$ [4]. Sulphate radicals may be obtained from peroxymonosulfate (PMS) through activation with metal ions [5], metal oxides and derived composites [6–8], non-metal catalysts (e.g., graphene-based materials) [9,10], graphitic carbon nitride (CN) [11,12], or phenols and quinines [13,14]. Co(II) was found to be the most efficient catalyst for the activation of PMS in the oxidation of organic compounds [15]. To date, various cobalt containing catalysts have been developed to activate PMS [16–18]. For example, Anipsitakis et al. found that ${ \cal C } _ { } 0 _ { 3 } 0 _ { 4 }$ was a good catalyst for the degradation of 2,4-dichlorophenol [17]. Ren et al. reported that the sequence for catalyst reducibility in PMS was $\mathrm { C o F e _ { 2 } O _ { 4 } } > \mathrm { C u F e _ { 2 } O _ { 4 } } >$ $\mathrm { M n F e } _ { 2 } \mathrm { O } _ { 4 } > \mathrm { Z n F e } _ { 2 } \mathrm { O } _ { 4 } ,$ . Therefore, among the four catalytic oxidation systems, ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ possesses the highest catalytic activity toward PMS for the degradation of DBP [18].

Recently, crystalline inorganic-organic hybrids, known as metal organic frameworks (MOFs), have been evaluated as emerging porous catalysts [19–22]. Metal-organic ligand complexes, which may be considered as an MOF subset, have hierarchical structures and ordered configurations of metal sites within defined frameworks, making them attractive for adsorption and catalysis applications [23–25]. Prussian blue analogues (PBAs), a type of metalcontaining coordination polymer, have been recently evaluated as PMS-activating catalysts. Lin et al. prepared $[ \mathsf { F e } ( \mathsf { C N } ) _ { 6 } ]$ and [Co $( \mathsf { C N } ) _ { 6 } ]$ -based PBAs containing Co, Cu, Fe, Mn, or Ni and evaluated their ability to activate PMS for the degradation of rhodamine B. The most effective catalysts in that study were $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ (Co-Fe) and $\mathrm { C o } _ { 3 } [ \mathrm { C o } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ (Co-Co) [26]. PBAs may also be employed as precursors in the preparation of magnetic catalysts with hierarchical pore structures. Li et al. prepared magnetic, porous $\mathrm { F e _ { x } C o _ { 3 - x } O _ { 4 } }$ nanocages with tunable sizes and morphologiers by heating nanospheres of the PBA Fey $\mathbf { C o } _ { 1 }$ $\mathrm { 0 _ { 1 } { - } y [ \mathsf { C o } ( C N ) _ { 6 } ] _ { 0 . 6 7 } { \cdot } n H _ { 2 } O }$ [27]. A magnetic carbon/cobalt/iron (MCCI) nanocomposite was synthesized via the one-step carbonization of $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ [28].

Graphene boasts an extensive surface area of ${ \sim } 2 6 0 0 \mathrm { m } ^ { 2 } / \mathrm { g }$ good mechanical flexibility, high chemical stability, and excellent electrical conductivity. It has therefore been regarded as a promising substrate for the loading of metallic nanoparticles as catalysts [29]. Several researchers have observed that the combination of cobalt species with GO (rGO) results in synergistic effects on the catalytic activity of PMS activation, and the degradation of organic compounds [30]. Xu et al. reported that graphene-based ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ was more efficient than ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ for the activation of PMS in the degradation of dimethyl phthalate [31].

According to related reports that have been studied, for the most part Prussian blue analogues were synthesized directly, or used as precursor in the preparation of porous nanomaterials, while they have rarely been studied as being combined with the substrate to catalyze PMS [26–28]. Therefore, a simple two-step hydrothermal method was developed to load Prussian blue analogues onto graphene, with the subsequent synthesis of separable magnetic Co-Fe PBAs@rGO nanocomposites. The crystalline structures, morphologies, and textural properties of the as-prepared Co-Fe $\mathrm { P B A s @ r G O }$ were characterized through various techniques. The catalytic performance of the nanocomposites was evaluated via PMS activation with levofloxacin hydrochloride (LVF) as the target contaminant, which is a widely used human and veterinary quinolone. The effects of several important parameters were also investigated and a reaction mechanism for the degradation of LVF was proposed. The stability and reusability of the catalysts were also estimated.

# 2.2. Sample preparation

# 2.2.1. Preparation of $C o _ { 3 } / F e ( C N ) _ { 6 } ] _ { 2 }$

The synthesis of $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ was performed according to reported protocols [32,33]. Typically, 3 mmol of ${ \mathsf { C o C l } } _ { 2 } { \cdot } 6 { \mathsf { H } } _ { 2 } 0$ was dissolved in $4 0 ~ \mathrm { m L }$ deionized water under vigorous stirring. Subsequently, $4 0 ~ \mathrm { m L }$ of an aqueous $\mathrm { K } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ solution $( 2 \mathrm { m m o l } / \mathrm { L } )$ was added dropwise. The solution was stirred under ambient conditions for $^ { 2 4 \mathrm { h } }$ , where after the precipitate was centrifuged, rinsed a minimum of three times with a mixture of ethanol and deionized water, and dried in an oven at $3 3 3 \mathrm { K }$ for $2 0 \mathrm { h }$ to yield $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ .

# 2.2.2. Preparation of Co-Fe PBAs@rGO nanocomposite

Graphene oxide (GO) was generated through the oxidation of graphite powder according to a modified Hummers’ method [34]. Co-Fe PBAs@rGO nanocomposites were synthesized via a facile, one-pot hydrothermal method. $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ b $1 0 0 \mathrm { m g } )$ and GO $( 4 0 \mathrm { m g } )$ were mixed in $7 0 ~ \mathrm { m L }$ of deionized water and ultrasonicated for $^ { 2 \mathrm { ~ h ~ } }$ . Subsequently, $1 ~ \mathrm { m L }$ of ammonia and $0 . 1 ~ \mathrm { m L }$ of hydrazine hydrate $\left( \mathrm { N } _ { 2 } \mathrm { H } _ { 4 } { \cdot } \mathrm { H } _ { 2 } 0 \right)$ were added to the mixture followed by

$3 0 \mathrm { { m i n } }$ of stirring. The resulting mixture was transferred to a Teflon-lined stainless steel autoclave $( 1 0 0 \mathrm { m L } )$ and heated to 180 $^ \circ \mathsf { C }$ for $^ { 1 0 \mathrm { h } }$ . After cooling to room temperature, the obtained precipitate was centrifuged, rinsed at least three times with a mixture of ethanol and deionized water, and dried at $6 0 ^ { \circ } \mathsf C$ for $^ { 1 2 \mathrm { ~ h ~ } }$ . The obtained sample was denoted as Co-Fe PBAs@rGO.

# 2.4. Catalytic activity measurements

The catalytic performance of the Co-Fe PBAs@rGO was evaluated according to its ability to activate PMS $( 0 . 1 \ \mathrm { g } \mathrm { L } ^ { - 1 } )$ for the degradation of LVF in water $( 2 0 \mathrm { m g L } ^ { - 1 } )$ at $\mathsf { p H } ~ 5 . 5$ (initial pH of LVF aqueous solution). If required, the pH was adjusted through the addition of either a $0 . 1 \mathrm { m o l / L }$ HCl or NaOH aqueous solution, and recorded with a pH meter. The concentrations of leached iron and cobalt were measured by ICP-MS.

In all experiments, $5 \mathrm { m g }$ of catalyst was added to $1 0 0 ~ \mathrm { { m L } }$ of the LVF solution $( 2 0 \mathrm { m g L ^ { - 1 } } .$ and stirred for $1 0 \mathrm { { m i n } }$ to establish adsorption-desorption equilibrium. The reaction was initiated by adding various quantities of aqueous PMS. At predetermined reaction times, 5-mL aliquots were withdrawn with a syringe and passed through a $0 . 2 2 \mathrm { - } \mu \mathrm { m }$ filter prior to measuring by HPLC. The $\mathrm { C o F e _ { 2 } O _ { 4 } / r G O }$ was prepared based on a reported protocol [35] and evaluated in this study for comparison against $\mathrm { P B A s @ r G O }$ . For each recyclability test, the catalyst was collected using a magnet, rinsed thoroughly with deionized water, and dried at $6 0 ^ { \circ } \mathsf C$ .

The catalytic degradation of LVF followed a pseudo-first-order kinetic model, as described by the following equation:

$$

where $C _ { \mathrm { t } }$ and $C _ { 0 }$ are the instantaneous and initial concentrations of LVF, respectively, $k _ { 1 }$ is the rate constant, and t is the reaction time. To further examine the catalytic mechanism, the effects of various inhibitors, i.e. radical scavengers, including ascorbic acid $( 5 \mathrm { m m o l } / \mathrm { L } )$ , methanol $( 0 . 5 \mathrm { m o l / L } )$ , and tert-butyl alcohol (TBA) $( 0 . 5 \mathrm { m o l / L } )$ , on PMS activation were investigated.

Quaternary N with a higher electronegativity than C atoms can cause electron transfer from adjacent C atoms to the N atom, thereby breaking the inertness of the $\mathsf { s p } ^ { 2 }$ bonded carbon network and leading to positively charged neighboring C atoms and negatively charged N atoms, as active sites to initiate PMS via a non-radical pathway [51].

Co-Fe PBAs@rGO yielded an IUPAC type IV isotherm, which indicated a mesoporous structure. The shape of the hysteresis loop was type $\mathrm { H } _ { 2 }$ , which indicated a slit-type pore structure [54]. The BET specific surface area and pore volume of Co-Fe PBAs@rGO were $1 8 6 . 8 4 \mathrm { m } ^ { 2 } / \mathrm { g }$ and $0 . 3 8 \mathrm { c m } ^ { 3 } / \mathrm { g } ,$ respectively. The inset of Fig. 6 shows the corresponding BJH PSD of the Co-Fe $\operatorname { P B A s @ r G O }$ composite, revealing a sharp maximum at ${ \sim } 3 . 4 \ \mathrm { n m }$ , which further confirmed the mesoporous nature of the nanocomposite. The large surface area afforded high catalytic activity through the provision of additional sites for adsorption.

# 3.2. Activation of PMS by Co-Fe PBAs@rGO for LVF degradation

The catalytic performance of the Co-Fe PBAs@rGO composite was evaluated according to its ability to activate PMS toward the degradation of LVF. Fig. 6(a) shows the degradation of LVF as a function of time under different reaction systems. After $3 0 \mathrm { { m i n } }$ , the adsorbed LVF into rGO and Co-Fe PBAs@rGO were only $1 . 9 \%$ and $4 . 1 \%$ , respectively, which revealed their negligible adsorption capacity. The degradation of LVF was negligible $( 0 . 3 \% )$ in the presence of PMS alone. This was consistent with the limited oxidation capacity of PMS $\left( \mathrm { E } _ { 0 } = 1 . 8 2 \ : \mathrm { V } \right)$ [42]. The introduction of the Co-Fe PBAs@rGO composite into a PMS/ LVF system resulted in a $9 7 . 6 \%$ degradation of LVF after 30 min This revealed that PMS could be activated by ${ \mathsf { C o } } ( \mathrm { I I } )$ and $\mathsf { F e } ( \mathrm { I I I } )$ on the surface of Co-Fe PBAs@rGO to produce $S O _ { 4 } ^ { - }$ [41,44]:

$$
\begin{array} { r l } & { \mathrm { H S O _ { 5 } ^ { - } ~ + ~ C o ( I I )  C o ( I I I ) + S O _ { 4 } ^ { - - } ~ + ~ O H ^ { - } } } \\ & { } \\ & { \mathrm { H S O _ { 5 } ^ { - } ~ + ~ C o ( I I I )  C o ( I I I ) + S O _ { 5 } ^ { - } ~ + ~ H ^ { + } ~ } } \\ & { } \\ & { \mathrm { H S O _ { 5 } ^ { - } ~ + ~ F e ( I I I )  F e ( I I I ) + S O _ { 5 } ^ { - } ~ + ~ H ^ { + } ~ } } \\ & { } \\ & { \mathrm { H S O _ { 5 } ^ { - } ~ + ~ F e ( I I I )  F e ( I I I ) + S O _ { 5 } ^ { - } ~ + ~ O H ^ { - } ~ } } \end{array}

In this study, the LVF degradation kinetics could be fitted to a pseudo-first-order kinetic mode as follows (Eq. (1)). The rate constant of LVF degradation using Co-Fe PBAs@rGO-activated PMS was $0 . 1 0 9 \mathrm { { m i n } } ^ { - 1 }$ , while those of pure Co-Fe PBAs/PMS and $\mathrm { C o F e _ { 2 } O _ { 4 } @ r G O / P M S }$ were $0 . 0 5 3 7 \mathrm { m i n } ^ { - 1 }$ and $0 . 0 3 5 5 \mathrm { m i n } ^ { - 1 }$ , respectively. These data implied that Co-Fe PBAs@rGO was a more effective PMS catalyst than were Co-Fe PBAs or $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } @ \mathrm { r } \mathrm { G O }$ .

# 3.3. Mineralization study

TOC was used in this study to determine whether there were any byproducts in the reaction and the degree of LVF degradation. Fig. S2 indicated that the TOC removal efficiency was $\sim 3 5 \%$ in 30 min, which suggested that some of the LVF were mineralized to inorganic compounds. The TOC and HPLC data confirmed that byproducts were formed in the degradation reaction. Intermediates in the $S O _ { 4 } ^ { . - } .$ - and $\mathrm { O H }$ -driven degradation of LVF were demonstrated by our research group [2,55].

# 3.4. Effects of reaction parameters on LVF degradation

# 3.4.1. Effect of catalyst dosage

The catalyst dosage significantly influenced the degradation efficiency as the catalyst provided both Fe(III) and $C o ( \mathrm { { I I } ) }$ , which were the primary species that activated PMS to generate $S 0 _ { 4 } ^ { - }$ Fig. 6(b) shows the degradation of LVF by PMS at different Co-Fe PBAs@rGO catalyst dosages, increasing from 25 to $2 0 0 \mathrm { m g / L }$ . The rate of LVF degradation decreased significantly after the first $5 \mathrm { { m i n } }$ . The LVF degradation rate increased with higher catalyst concentrations $( 2 5 { - } 2 0 0 ~ \mathrm { m g / L } )$ . However, only a slight increase the degradation efficiency could be observed with continual increases in the catalyst concentration $( 5 0 - 2 0 0 \mathrm { m g / L ) }$ . With a $5 0 ~ \mathrm { m g / L }$ concentration of Co-Fe $\mathrm { P B A s @ r G O }$ , the degradation efficiency was $9 7 . 6 \%$ , which was close to that observed at $1 0 0 ~ \mathrm { { m g / L } }$ . In consideration of both catalytic efficiency and cost, the $5 0 ~ \mathrm { m g / L }$ concentration was used in subsequent experiments.

# 3.4.3. Effects of reaction temperature

As shown in Fig. 6(d), when the reaction temperature was raised from $2 5 ~ ^ { \circ } \mathsf C$ to $5 0 ^ { \circ } \mathsf C$ , the degradation efficiency of LVF was increased from $9 6 . 7 \%$ to $1 0 0 \%$ , and the rate constant increased from 0.109 to $0 . 1 5 1 \mathrm { ~ m i n } ^ { - 1 }$ . High temperatures contributed to the decomposition of PMS in the generation of reactive radicals. This, in turn, increased the collision frequency between molecules at the catalyst surface, thereby accelerating the reaction rates. The impacts of temperature could be estimated by evaluating the activation energy of the reaction via the Arrhenius equation (Eq. (8)):

$$
\ln k _ { 1 } = \ln A - E a / \ R T
$$

Where $k _ { 1 }$ is the measured first-order rate constant, A is a frequency factor, Ea is the activation energy, R is the ideal gas constant, and $\mathrm { T }$ is temperature in Kelvin (K).

The activation energy for the degradation of LVF was calculated as $3 1 . 2 \mathrm { k J } / \mathrm { m o l }$ . Considering the practical applications of the system, $2 5 ^ { \circ } C$ was selected for all subsequent experiments.

# 3.4.4. Effect of initial $p H$

The catalytic degradation of LVF was performed at $\mathsf { p H 3 } , 7$ , and 11 to represent acidic, neutral, and basic conditions, respectively. Fig. 6(d) shows that at $\mathsf { p H } \ 3$ , the degradation efficiency was $7 6 . 5 \%$ , which increased to $9 8 . 1 \%$ at $\mathsf { p H } ~ 7$ with a corresponding rate constant of $0 . 1 1 0 \mathrm { m i n } ^ { - 1 }$ . While the degradation rates at pH 5.5 and 7 were similar, the kinetics of the degradation at $\mathsf { p H 7 }$ were relatively slow in contrast to those observed at an initial pH of 5.5, which yielded a $k _ { 1 }$ of $0 . 1 0 9 \mathrm { { m i n } } ^ { - 1 }$ . At $\mathsf { p H } 1 1$ , the LVF degradation was negligible, with a rate constant of $0 . 0 1 1 2 \mathrm { m i n } ^ { - 1 }$ . These data indicated that near-neutral or weakly acidic conditions were favorable for the catalytic degradation of LVF. The observed inhibition at $\mathsf { p H } 1 1$ was likely due to the oxidation of $\mathrm { O H ^ { - } }$ by $S 0 _ { 4 } ^ { - }$ and the subsequent conversion to OH [57]:

# 3.4.5. Effects of inorganic salts

The composition of organic wastewater is complex and contains a variety of inorganic ions. To some extent, the presence of inorganic salt ions is likely to impact the generation of sulphate radicals [59]. Chloride ions are not only common in wastewater, but are also a constituent of LVF; hence, NaCl was selected as a representative salt to investigate the effects of salt through a concentration range of from 0 to $5 0 0 0 \mathrm { m g / L } ,$ , as shown in Fig. 6(f). High concentrations of NaCl had a negative effect on the degradation of LVF. At a NaCl concentration of $1 0 0 0 \mathrm { { m g / L } } ,$ , the degradation efficiency and rate constant were $7 6 . 7 \%$ and $0 . 0 2 5 6 \mathrm { m i n } ^ { - 1 }$ , respectively. This is because $\mathrm { C l ^ { - } }$ is oxidized by $S 0 _ { 4 } ^ { - }$ to the much less reactive Cl (Eq. (12)) [60]. However, when the concentration of NaCl was increased to $2 0 0 0 \mathrm { m g / L }$ , the effect of $\mathtt { C l } ^ { - }$ was altered from inhibitory to mildly promotional. This may have be due to the generation of high levels of Cl , which would increase the rate of degradation. As the NaCl concentration was increased to $5 0 0 0 \mathrm { m g / L }$ , the LVF degradation efficiency approached $7 6 \%$ , which was similar to that observed at $[ \mathrm { N a C l } ] = 1 0 0 0 \mathrm { m g / L }$ . This may have been due to the consumption of less reactive Cl by $\mathbb { C } 1 ^ { - }$ , as shown in Eq. (13) [58].

# 3.5. Effects of inhibitors and possible degradation mechanism

Three radical scavengers (ascorbic acid, methanol, and t-butanol (TBA)), were employed to reveal the mechanism of LVF degradation via PMS activation by Co-Fe PBAs@rGO. Fig. 7(a) shows that in the presence of ascorbic acid, which a universal radical scavenger, the degradation efficiency of LVF was completely quenched. This revealed that oxidizing radicals originated from the Co-Fe PBAs@rGO-activated PMS. In aqueous solution, sulphate radicals $( \mathsf { S O } _ { 4 } ^ { - } )$ derived from PMS oxidized $_ \mathrm { H } \mathrm { _ 2 O }$ into OH (Eq. (14)). When TBA (a common probe reagent for hydroxyl radicals), was added to the reaction solution, the efficiency of LVF degradation remained unchanged, indicating that the effects of the as-derived hydroxyl radicals were insignificant.

$$
\mathrm { S O _ { 4 } } ^ { - } + \mathrm { H } _ { 2 } \mathrm { O } \longrightarrow \mathrm { S O _ { 4 } } ^ { 2 - } + \mathrm { H } ^ { + } + \mathrm { O H } ^ { - }
$$

When methanol (a typical scavenger for both OH and $S 0 _ { 4 } ^ { - }$ ), was added to the reaction solution, both the degradation efficiency and the rate constant $( k _ { 1 } = 0 . 0 1 1 4 \mathrm { { m i n } } ^ { - 1 }$ ) decreased significantly, indicating that sulphate radicals $( { \mathsf { S O } } _ { 4 } ^ { - } )$ played a major role in the degradation of LVF.

However, it should also be noted that the reaction did not cease immediately with the addition of methanol; hence, we assumed that the methanol concentration was not sufficient for the complete termination of the reaction, or there may have been other radicals involved in the reaction. The influence of the methanol concentration on LVF degradation was investigated as depicted in Fig. S4. The higher the methanol concentration was, the more obvious the inhibition effect was. When the methanol concentration was increased to $5 \mathsf { M }$ , the reaction was almost completely terminated. This result demonstrated that sulphate radicals played a major role in the degradation of LVF, while the role of other active radicals that were possibly generated during the reaction could be neglected.

According to these results and those in the literature, a possible reaction mechanism was proposed for the Co-Fe PBAs@rGO/PMS system. First, a sulphate radical was formed through the activation of PMS by ${ \mathsf { C o } } ( \mathrm { I I } )$ and Fe(III) (Eqs. (2) and (4)), which were regenerated via Eqs. (3) and (4), respectively. In addition, the Co(III) could be reduced by Fe(II) [57]:

$$
\mathrm { F e ( I I ) } + \mathrm { C o ( I I I ) } \longrightarrow \mathrm { F e ( I I I ) } + \mathrm { C o ( I I ) }
$$

The sulphate radical was then generated through the conversion of $\mathsf { F e } ( \mathrm { I I } )$ or ${ \mathsf { C o } } ( \mathrm { I I } )$ .

# 3.6. Recyclability of Co-Fe PBAs@rGO

The recyclability of the Co-Fe PBAs@rGO was evaluated via five sequential reaction cycles, with the results shown in Fig. 7(b). Following five consecutive runs, the degradation efficiency was $8 3 . 7 \%$ after $3 0 \mathrm { { m i n } }$ . This represented only a $1 3 . 9 \%$ decrease relative to the efficiency of the initial run, which indicated that the activity of CoFe $\mathrm { P B A s @ r G O }$ was not significantly reduced through reuse. The decreases in activity might be attributed to the adsorption of reaction intermediates at the catalyst surface. By comparing the reaction rates of subsequent runs, it was revealed that the reaction intermediates attached to catalyst surface could not be removed by a simple water rinsing process [61]. It was also possible that during each recovery experiment, the catalyst might have undergone a slight overflow of metal ions, which led to a decrease in the activity of the catalyst.

These results demonstrated the high recyclability and reusability of the Co-Fe PBAs $\ @ \mathrm { r G O }$ catalyst system, which were also supported by the low levels of metals that leached from the catalyst. When the Co-Fe PBAs@rGO was employed as a PMS-activating catalyst, the detected concentrations of iron and cobalt leachates were 0.08 and $0 . 3 ~ \mathrm { m g / L }$ , respectively, which are within the legal limits $( 2 \mathrm { m g } / \mathrm { L } )$ established by the environmental directives of China [62].

To verify the stability of the Co-Fe $\mathrm { P B A s @ r G O }$ catalyst under acidic and neutral conditions, we quantified the released concentrations of iron and cobalt ions, as shown in Fig. S5. Whether under $\mathsf { p H } 3$ or 11 conditions, the quantities of leached Co and Fe were negligible $( < 1 \ \mathrm { m g / L } )$ , which suggesting the high stability of the Co-Fe $\mathrm { P B A s @ r G O }$ for pollutant degradation through the activation of PMS. N-doped graphene had been demonstrated to be high stability for the supported catalyst than pure graphene [63].

# 4. Conclusion

For this study, $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ , which is a $[ \mathsf { F e } ( \mathsf { C N } ) _ { 6 } ] _ { 2 }$ -based PBA, was successfully loaded onto rGO using a hydrothermal method to create a Co-Fe $\mathrm { P B A s @ r G O }$ composite catalyst for the activation of PMS. Co-Fe $\mathrm { P B A s @ r G O }$ was more effective than $\mathrm { C o } _ { 3 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ in activating PMS, and more efficient than $\mathrm { C o F e } _ { 2 } 0 _ { 4 } @ \Gamma \mathrm { G O }$ in the degradation of LVF. The degradation efficiency of LVF was dependent on the reaction temperature, dosage of PMS and Co-Fe $\mathrm { P B A s @ r G O }$ catalyst, pH, and the concentration of chloride ions. Higher catalyst and PMS concentrations were favorable for the degradation of LVF, as were higher temperatures and neutral or weakly acidic conditions. Recyclability tests revealed that Co-Fe $\mathrm { P B A s @ r G O }$ was stable and reusable. Sulphate radicals were the dominant active species in the Co-Fe PBAs@rGO/PMS system. This study demonstrated the feasibility of synthesizing a nanocomposite catalyst by loading PBAs onto rGO, for the activation of PMS in the effective degradation of organic pollutants.
