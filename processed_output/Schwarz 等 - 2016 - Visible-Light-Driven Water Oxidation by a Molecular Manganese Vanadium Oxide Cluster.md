# Visible-Light-Driven Water Oxidation by a Molecular Manganese Vanadium Oxide Cluster

Benjamin Schwarz, Johannes Forster, McKenna K. Goetz, Duygu Yücel, Claudia Berger, Timo Jacob, and Carsten Streb\*

Abstract: Photosynthetic water oxidation in plants occurs at an inorganic calcium manganese oxo cluster, which is known as the oxygen evolving complex (OEC), in photosystem II. Herein, we report a synthetic OEC model based on a molecular manganese vanadium oxide cluster, $I M n _ { 4 } V _ { 4 } O _ { I 7 } ( O A c ) _ { 3 } J ^ { 3 - }$ . The compound is based on a $I M n _ { 4 } O _ { 4 } J ^ { 6 + }$ cubane core, which catalyzes the homogeneous, visible-light-driven oxidation of water to molecular oxygen and is stabilized by a tripodal $I V _ { 4 } O _ { I 3 } J ^ { 6 - }$ polyoxovanadate and three acetate ligands. When combined with the photosensitizer $I R u ( b p y ) _ { 3 } J ^ { 2 + }$ and the oxidant persulfate, visible-light-driven water oxidation with turnover numbers of approximately 1150 and turnover frequencies of about $1 . 7 5 \ : s ^ { - 1 }$ is observed. Electrochemical, massspectrometric, and spectroscopic studies provide insight into the cluster stability and reactivity. This compound could serve as a model for the molecular structure and reactivity of the OEC and for heterogeneous metal oxide water-oxidation catalysts.

T and molecular hydrogen provides sustainable access to nonfossil-based fuels.[1,2] The four-electron oxidation of water to molecular oxygen is the more challenging half-reaction in water splitting. Water oxidation requires homogeneous[3-5] or heterogeneous[69] water oxidation catalysts (wOCs) that are both highly stable under oxidizing conditions and able to undergo multiple proton-coupled electron transfers.[3,10] $\operatorname { I n }$ nature, light-driven water oxidation is accomplished by the oxygen evolving complex (OEC), the pentanuclear calcium manganese oxo cluster $\left[ \mathrm { C a M n } _ { 4 } \mathrm { O } _ { 5 } \right]$ (Figure 1), located within a large protein assembly, namely photosystem II (PS II) [11, 12] In vivo, the OEC is coordinatively stabilized by carboxylateand imidazole-based amino acids.[13]

Since the first structural reports, the OEC has stimulated the development of synthetic molecular WOCs where metal oxo cores are stabilized by organic ligands.[14] Groundbreaking research focused on manganese ox0 dimers,1518] whereas later studies used elaborately designed ligands to stabilize tetranuclear manganese oxo cubanes as functional OEC models[192] Recently, ligand-stabilized calcium manganese oxo units such as $[ \dot { \mathrm { C a M n } _ { 3 } } \mathrm { O } _ { 4 } ] ^ { 6 + [ 2 3 ] }$ and $\mathrm { [ C a M n _ { 4 } O _ { 4 } ] ^ { 9 + [ 2 4 ] } }$ have been used to understand the influence of calcium on the OEC activity.

The oxidative degradation of organic ligands under the harsh water-oxidation conditions is often perceived as a limitation of synthetic wOCs[25] To address this challenge, molecular metal oxides that are stable towards oxidation, so-called polyoxometalates (POMs), have been introduced as highly robust ligands. POMs are early-transition-metal oxo clusters and typically based on vanadium, molybdenum, or tungsten in high oxidation states; their reactivity can be tuned by theincorporation of reactive metal centers.[6,] Startin 20 Bonchio, Sartorel et al.2,29] and Hillet al3,31] reorted the WOC activity of a ruthenium polyoxotungstate, $\mathrm { [ R u _ { 4 } O _ { 4 } }$ . $\mathrm { ( O H ) } _ { 2 } \mathrm { ( H } _ { 2 } \mathrm { O ) } _ { 4 } \mathrm { ( \gamma \mathrm { - } S i W _ { 1 0 } O _ { 3 6 } ) } _ { 2 } \mathrm { ] } ^ { 1 0 - }$ , under chemical[28,30] or photochemical conditions.[29, 31]

In 2010, Hill et al. reported the first non-precious-metalbased POM WOC, $[ \mathrm { C o } _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 2 } ( \mathrm { a } \mathrm { - } \mathrm { P W } _ { 9 } \mathrm { O } _ { 3 4 } ) _ { 2 } ] ^ { 1 0 - }$ [32,33]Under visible-light irradiation and in the presence of $[ \mathrm { R u ( b p y ) } _ { 3 } ] ^ { 2 + }$ as a photosensitizer and ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 - }$ as an oxidant, WOC activity with turnover numbers (TONs) up to 220 and turnover frequencies (TOFs) up to $0 . 2 5 { \mathrm { s } } ^ { - 1 }$ was observed[32] Recently, Kortz, Bonchio, Scandola et al. reported the first manganese tungstate WOC, $[ \mathrm { M n } _ { 4 } \mathrm { O } _ { 3 } ( \mathrm { O A c } ) _ { 3 } ( \mathrm { S i W } _ { 9 } \mathrm { O } _ { 3 4 } ) ] ^ { 6 - }$ , as a functional OEC model, where a defective manganese oxo cubane, $\{ { \bf M } { \bf n } _ { 3 } ^ { \mathrm { I I I } } { \bf M } { \bf n } ^ { \mathrm { I V } } { \bf O } _ { 3 } \}$ , is stabilized by coordination to a lacunary silicotungstate anion and acetate ligands.[34]

Thus far, POM WOCs featuring polynuclear transitionmetal oxo reaction sites have only been stabilized by tungstate ligands, and very little is known about the WOC activity of non-tungstate-based POM WOC3,3 Building on our experience in metal-functionalized vanadates, e investigated the incorporation of polynuclear manganese oxo units in vanadium oxide clusters and their use as OEC models.

Herein, we report the stabilization of an OEC-related, mixed-valent manganese oxo cubane in a manganese vanadium oxide cluster and its activity in visible-light-driven water oxidation. The title compound $( n \mathbf { B } \mathbf { u } _ { 4 } \mathbf { N } ) _ { 3 } [ \mathbf { M } \mathbf { n } _ { 4 } \mathbf { V } _ { 4 } \mathbf { O } _ { 1 7 } -$ $\mathrm { ( O A c ) } _ { 3 } ] { \cdot } 3 \mathrm { H } _ { 2 } \mathrm { O }$ $( = ( n \mathbf { B } \mathbf { u } _ { 4 } \mathbf { N } ) _ { 3 } \mathbf { 1 } { \cdot } 3 \mathrm { H } _ { 2 } \mathrm { O } )$ is formed from readily available precursors by one-pot self-assembly: The reaction of $( n \mathbf { B } \mathbf { u } _ { 4 } \mathbf { N } ) _ { 4 } [ \mathbf { V } _ { 4 } \mathbf { O } _ { 1 2 } ]$ , $\mathrm { M n } ( \mathrm { O A c } ) _ { 3 } { \cdot } 2 \mathrm { H } _ { 2 } \mathrm { O }$ ,and $( n { \bf B u } _ { 4 } { \bf N } ) { \bf M n O } _ { 4 }$ in acetonitrile gives 1 as deep-brown single crystals in a yield of approximately $5 3 \%$ . The elemental composition was determined by elemental analysis, flame atomic absorption spectroscopy, and thermogravimetric analysis (see the Supporting Information). Single-crystal X-ray diffraction of 1 showed an anionic octanuclear cluster composed of a central $\mathrm { [ M n _ { 4 } O _ { 4 } ] ^ { 6 + } }$ cubane stabilized by a tripodal $[ \mathrm { { V } } _ { 4 } \mathrm { { O } } _ { 1 3 } ] ^ { 6 - }$ ligand and three acetate ligands (Figure 1). The $\mathrm { [ M n _ { 4 } O _ { 4 } ] ^ { 6 + } }$ unit is structurally related to the OEC, and similar ${ \bf { M } } { \bf { n } } ^ { - } { \bf { O } }$ bond lengths were observed $( d _ { \mathrm { M n - o } } ( \mathbf { 1 } ) \approx 1 . 8 – 2 . 1 \mathring { \mathrm { A } }$ $d _ { \mathrm { { M n - O } } } ( \mathrm { { O E C } } ) { \approx } 1 . 8 – 2 . 0 \mathring \mathrm { { A } } \mathrm { { ; } }$ . The unique tripodal vanadate ligand $[ \mathrm { V } _ { 4 } \mathrm { O } _ { 1 3 } ] ^ { 6 - }$ interacts with three manganese centers of the cubane through six ${ \bf V } { \bf - } { \bf O } { \bf - } { \bf M } { \bf n }$ coordination bonds. Notably, long-range attractive electrostatic interactions between one cubane oxo ligand and the four vanadium centers are observed, resulting in an elongation of the corresponding ${ \bf { M } } { \bf { n } } ^ { - } { \bf { O } }$ bonds (ca. $2 . 1 \mathring \mathrm { \ A }$ ) whereas the remaining ${ \bf { M } } { \bf { n } } { - \bf { O } }$ distances are significantly shorter (ca. $1 . 8 \mathrm { - } 1 . 9 \mathring { \mathrm { A } } ,$ . The cubane coordination sphere is completed by three acetate ligands, leading to an idealized $C _ { 3 \nu }$ symmetry for 1 (Figure 1). Empirical bond valence sum (BVS) calculations based on crystallographic data gave a $+ 5$ oxidation state for all vanadium centers. For the manganese ions, an average oxidation state of approximately 3.6 was calculated, suggesting a mixed-valent $\mathrm { [ M n ^ { I I I } } _ { 2 } \mathbf { M n ^ { I V } } _ { 2 } \mathbf { O } _ { 4 } ] ^ { 6 + }$ cubane, which would correspond to the $\mathrm { S } _ { 1 }$ state of the OEC as assigned in the Kok cycle.[46]

Native 1 is EPR-silent and has a diamagnetic ground state; this is expected for mixed-valent $\mathrm { [ M n ^ { I I I } , M n ^ { I V } , O _ { 4 } ] ^ { 6 + } }$ cubanes and has been observed before.[47] In contrast, a complex EPR signal was observed for the one-electron-oxidized species; the signal is similar to those described in previous reports on related manganese oxo cubanes by Dismukes et al.[48] The twoelectron-oxidized bulk-electrolysis species is EPR-silent (Figure $^ { 2 \mathrm { b } }$ ; see also the Supporting Information, for details).

ESI mass spectrometry of 1 in acetonitrile demonstrates the cluster stability in the solution/gas phase. Based on $m / z$ and isotopic-pattern analysis, all three cluster-related signals feature mixed-valent manganese oxo cubanes: For example, at m/z 557.38 (calcd 557.38), the native species $( n \mathrm { B u _ { 4 } N ) [ M n ^ { I I I } } _ { 2 } \mathrm { M n ^ { I V } } _ { 2 } \mathrm { V ^ { v } } _ { 4 } \mathrm { O _ { 1 7 } ( O A c ) _ { 3 } ] ^ { 2 - } }$ was observed (Figure 2b). The native cluster therefore represents a model compound of the $\mathrm { S } _ { 1 }$ state of the OEC, and our data suggest that electrochemical access to the $\mathrm { S } _ { 2 }$ and $\mathrm { S } _ { 3 }$ states of the Kok cycle is possible.

To identify optimal conditions for studying the WOC activity of 1, cyclic voltammetry of 1 in acetonitrile/water mixtures of various compositions was performed. As shown in Figure 2c, the highest oxidative current densities (at $E =$ $1 . 5 \mathrm { V }$ VS. $\mathrm { F c / F c ^ { + } }$ were observed for an acetonitrile/water ratio of 9:1 (v/v), and the onset of the electrocatalytic water oxidation was observed at $E \approx 0 . 9 5 \ : \mathrm { V }$ VS. $\mathrm { F c / F c ^ { + } }$ (see Figure 2 c and the Supporting Information). The following WOC studies were therefore performed in this solvent mixture.

The visible-light-driven WOC activity of 1 was examined by combining 1 $( 0 . 3 \mathrm { - } 1 0 \mu \mathrm { { M } } )$ with the photosensitizer [Ru$( \mathrm { b p y } ) _ { 3 } ] ^ { 2 + }$ (1 mM) and the electron acceptor $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - }$ $\left( 1 0 \mathrm { m M } \right)$ in deoxygenated acetonitrile/water (9:1, v/v). The system was irradiated with visible light (LED light source, $\lambda _ { \operatorname* { m a x } } = 4 7 0 \operatorname { n m }$ , and the oxygen evolution was continuously measured with a fiber-optic oxygen sensor in the reaction mixture (Figure 3).

Oxygen evolution followed a sigmoidal trace, reaching a plateau after $t _ { \mathrm { i r r a d i a t i o n } } \approx 1 5$ min. An initial induction phase (ca. $3 \mathrm { m i n }$ ) was observed, which might be related to a catalyst activation step where the loss of acetate ligands is necessary to generate water-binding sites on the manganese oxo cubane. Similar behavior has been reported for a related phosphinatestabilized manganese oxo catalyst.[20] Oxygen evolution is dependent on the catalyst concentration (Figure 3), and the maximum TONs (ca. 1150) and TOFs (ca. $1 . 7 5 \mathrm { s ^ { - 1 } }$ were observed at $\mathbf { [ 1 ] } = 0 . 3 ~ \mu \mathrm { M }$ (see the Supporting Information).

The reduced turnover numbers at increased catalyst concentrations could be related to the aggregation of the anionic catalyst with the cationic photosensitizer, resulting in colloid formation. At low concentrations of 1 $( 0 . 6 \mu \mathrm { { M } } )$ , no colloids were detected before and after irradiation by dynamic light scattering (DLS), microfiltration, and UV/Vis spectroscopy (see the Supporting Information),[49] highlighting that the reaction solution is homogeneous. In contrast, for high catalyst concentrations $( 1 0 \mu \mathrm { M } )$ , colloid formation by ion aggregation was detected, which is in line with previous reports[3,9] s the colloidal particle are catalylly inactive, a significant decrease in WOC activity was observed (the TON decreased by ca. $9 5 \%$ ). These results highlight the need for truly homogeneous conditions for high WOC activity in photosensitized polyoxometalate-based water-oxidation catalysis.[49,51] As the study was performed in non-buffered $\mathrm { M e C N / H _ { 2 } O }$ solution (owing to solubility issues with 1 in buffered solutions), the solution $\mathrm { p H }$ value drops upon water oxidation, eventually leading to a loss of catalytic activity. This is possibly associated with protonation of the manganese oxo core of 1 as indicated by pH-dependent UV/Vis spectroscopy, which has been previously observed for related manganese oxo species (see the Supporting Information).[,

Initial catalyst recovery/recycling experiments showed the principal possibility of catalyst recycling, and three consecutive standard WOC runs $( [ \mathbf { 1 } ] = 0 . 6 ~ \mu \mathbf { M } )$ with a sum total TON of about 780 were performed. However, after run 3, a significant loss of catalytic activity (a decrease in TOF of ca. $7 0 \%$ ) was observed, indicating catalyst deactivation during catalysis (see the Supporting Information).

In summary, we have reported the first molecular manganese vanadium oxide water-oxidation catalyst, $\mathrm { \small { [ M n _ { 4 } V _ { 4 } O _ { 1 7 } ( O A c ) _ { 3 } ] ^ { 3 - } } }$ . Under visible-light irradiation, the cluster shows high wOC activity $\mathrm { \Delta T O N } \approx 1 1 5 0$ ,TOF ${ \approx } 1 . 7 5 ~ \mathrm { s ^ { - 1 } }$ ). Furthermore, this compound could serve as a model system for the oxygen-evolving complex in photosystem II as it features a mixed-valent manganese oxo cubane, $\mathrm { [ { \dot { M } n } ^ { I I I } { } _ { 2 } M n ^ { I V } { } _ { 2 } O _ { 4 } ] ^ { 6 + } }$ , corresponding to the $\mathrm { S } _ { 1 }$ state of the Kok cycle. The higher oxidation states $\mathrm { S } _ { 2 }$ and $\mathrm { S } _ { 3 }$ are accessible by electrochemical oxidation. Future work will investigate the mechanistic aspects of electron transfer and oxygen evolution to assess whether this cluster can be used to gain insight into the electronic processes within the OEC during water oxidation.
