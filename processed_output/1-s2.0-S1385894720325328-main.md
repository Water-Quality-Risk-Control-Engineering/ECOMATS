# A B S T R A C T

For the first time, the fate of radicals generated in heterogeneous chemical oxidation treatment systems has been accounted for and used to assess treatment performance in three reaction compartments; reaction with the target compound, rhodamine B (RhB), the aqueous phase scavengers, and the solid phase scavengers. Radicals formed during the ultra-violet (UV) activation of hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ (UV-AHP) and persulfate $( \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } )$ (UVAPS) include hydroxyl (•OH) and sulfate radicals $( S O _ { 4 } ^ { \bullet - } )$ , respectively. •OH and $\mathrm { { \le 0 } } _ { 4 } \mathrm { { \dot { ~ } - } }$ , used in oxidation treatment systems to degrade a broad spectrum of environmental contaminants, may also react with non-target chemical species (scavengers) that limit treatment efficiency. UV-AHP and UV-APS treatment systems were amended with solid phase alumina to assess scavenging by solid surfaces. The overall rate of reaction and rate of radical scavenging was greater for •OH than $\mathrm { S O } _ { 4 } \mathrm { ^ { * - } }$ . Scavenging by dissolved constituents was dominated by the oxidant used $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } , \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - } )$ ; and the rate of radical scavenging by alumina was greater than the rate of RhB oxidation in all cases. Treatment efficiency was lower in the UV-AHP than in the UV-APS treatment system and was attributed to greater aqueous and solid phase scavenging rates. The cost of commercially available $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $( \$ 0.031\ m o l ^ { - 1 } )$ and PS $( \$ 0.24 \mathrm { ~ m o l } ^ { - 1 } )$ ) was used in conjunction with the overall treatment efficiency to assess specific cost of treatment. The specific cost to treat the probe compound with UV-AHP was greater than UV-APS and was attributed to the much lower treatment efficiency with UV-AHP. The much-desired high reaction rate constants between •OH and environmental contaminants, relative to $\mathrm { S O } _ { 4 } \mathrm { \Sigma } ^ { \bullet - }$ , may come at the cost of greater combined scavenging rates, and consequently lower treatment efficiency.

# 1. Introduction

Chemical oxidation processes utilizing activated hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ and persulfate $( \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } ^ { 2 - } )$ (PS) are common methods for treatment of contaminated water, wastewater and aquifer media [1–4]. The reactive intermediates formed during $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PS activation involve hydroxyl radicals (•OH) and sulfate radicals $( S O _ { 4 } ^ { \cdot - } )$ , respectively, both capable of reacting with a broad spectrum of environmental contaminants [5–9]. Although both radicals are strong electrophiles and reactions with the majority of contaminants are highly favorable, the reaction of these radicals are uniquely different and involve non-target reactive species (i.e., scavengers).

The kinetics of contaminant transformation reactions involving •OH and $\ S O _ { 4 } ^ { \cdot - }$ are strongly influenced by the presence of scavengers in the treatment system. Aqueous and solid phase scavengers compete with the contaminant for •OH and $\ S O _ { 4 } ^ { \cdot - }$ and contribute to treatment inefficiency. Until recently, only radical scavenging in the aqueous phase has been quantified [10–13], predominantly utilizing the concentrations of the dissolved species and the second-order rate constants. Recently, laboratory and competition kinetics methods have been developed to estimate the surface scavenging reaction rate constants $( \mathbf { k } _ { \equiv } s )$ between solid phase mineral species $( \equiv S _ { \mathrm { i } } )$ and •OH [14], and $\ S O _ { 4 } ^ { \cdot - }$ [15]. A description of the method of kinetic analysis is provided in the Supporting Information (S.1). The radical-specific surface scavenging rate constants estimated in these studies [14,15] were used to quantify the relative roles of solid and aqueous phase scavengers in the activated $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and activated PS treatment systems. Results indicated that in heterogeneous systems, surface scavenging significantly reduced the rate of contaminant degradation and was the leading cause of treatment efficiency.

Alumina $\left( \mathsf { A l } _ { 2 } \mathsf { O } _ { 3 } \right)$ , a naturally occurring mineral in soil and aquifer systems [16,17], was selected as model mineral and tested. The physicochemical properties of alumina were previously established and used in this study (S.2; Table S1; Fig. S1) [14,15]. The previous studies involved heterogeneous UV-activated persulfate (UV-APS) and UV-activated hydrogen peroxide (UV-AHP) treatment conditions using alumina suspensions $( [ \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 } ] = 1 0 \mathrm { ~ g ~ L } ^ { - 1 } )$ were conducted using similar experimental procedures and methods of competition kinetics analysis. Additional treatment experiments were conducted in this study to augment the kinetic parameters used in the analysis. Rhodamine B dye (RhB) served as the target compound and was used as an indicator of radical activity for •OH and $S O _ { 4 } ^ { \cdot - }$ . Reactions and rate constants involving UV activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ , and associated reactions in the heterogeneous oxidative treatment system are summarized (Table 1).

Previously, only reaction rate constants involving dissolved reactive species in aqueous solutions have been quantified and used to determine the fate of •OH and $\mathrm { { } ^ { S O _ { 4 } } } ^ { \bullet - }$ with respect to radical scavenging, and to assess treatment inefficiency. To our knowledge, the reaction rate constants for solid phase media and •OH or $\mathrm { { } ~ } S 0 _ { 4 } ^ { \cdot - }$ have not been measured and published, and thus, never considered in treatment efficiency assessments. Collectively, the data and information developed in these studies [14,15] provided a unique opportunity to establish and to contrast radical production and reaction, treatment efficiency, and the cost associated with these two oxidants in heterogeneous treatment systems. The objective of this research was to utilize the kinetic parameters from the two studies involving radical production and reaction, and to contrast treatment efficiency and cost metrics. This would establish the underlying basis for a detailed critical assessment of UV-AHP and UV-APS heterogeneous treatment systems and provide a better understanding of the strengths and limitations of each system.

# 2. Experimental

# 2.1. Experimental conditions

RhB was selected as a probe due to the favorable properties that allow rapid analysis and processing of samples, thus eliminating the quenching step of the remaining oxidant (PS). RhB is non-volatile, hydrophilic and adsorbs poorly to alumina surfaces at $\mathtt { p H }$ conditions applied in the study, which minimizes non-oxidative losses and simplifies the kinetic analysis [15]. RhB $( \lambda _ { \mathrm { m a x } } = 5 5 6 ~ \mathrm { n m } )$ concentrations were determined $\left( \mathbf { n } = 3 \right)$ spectrophotometrically on the Jenway 6505. A spectrophotometric method was also used for analyzing the persulfate concentration $( \lambda _ { \operatorname* { m a x } } = 4 5 0 ~ \mathrm { n m } )$ [18]. Regression analysis of the spectrophotometric response and the concentration of RhB and PS yielded linear calibration curves $( { \bf r } ^ { 2 } ~ = ~ 0 . 9 9 )$ . The method detection limits (MDL) for RhB was $0 . 0 0 1 5 ~ \mathrm { m g / L }$ . All samples were analyzed in replicate or triplicate. The $\mathsf { p H }$ was measured using the Orion Star A215 pH meter (EPA Method 150.1). The $9 5 \%$ confidence intervals were used as a statistical metric to assess the range of potential values of the measured parameter. The experiments were carried out at room temperature $( 2 2 . 0 ~ \pm ~ 0 . 5 ~ ^ { \circ } \mathrm { C } )$ . The UV-AHP and UV-APS tests were conducted in $4 0 \ \mathrm { \ m L }$ borosilicate volatile organic analysis (VOA) vials (temperature $2 1 - 2 3 \mathrm { ~ ~ } ^ { \circ } \mathrm { C } )$ under a UV Lamp (High-Performance UVP Transilluminator, Model TFM-20) containing 4 UV-A tube bulbs (25 W bulbs, 115 V, $6 0 \ \mathrm { H z }$ , 2.0 amps, $3 6 5 \mathrm { n m }$ ), where $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ both undergo photolytic cleavage of the peroxo bond under UV activation. The UV wavelength used resulted in different rates of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PS activation. However, the approach used in this critical analysis was to contrast the relative radical activity and fate, once formed, in the alumina-amended heterogeneous systems. Normalization of parameter values in this manner allows a direct comparison method of analysis.

Reaction conditions were established to quantify differences between the two systems originating from aqueous phase scavenging (i.e. reaction between •OH and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ; $\mathrm { { \thinspace 8 O _ { 4 } } ^ { \bullet - } }$ and $\mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } )$ , and solid phase scavenging. Specifically, the second-order reaction rate constants for the reaction between RhB, and •OH and $\ S O _ { 4 } ^ { \cdot - }$ , are quite different $( \mathbf { k } _ { 2 } = 2 . 5 \times 1 0 ^ { 1 0 } \mathbf { M } ^ { - 1 } s ^ { - 1 }$ , R2, Table $1 ; 1 _ { 8 } = 3 . 0 2 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ , R8, Table 1). It was assumed that the rate of RhB loss could potentially be much greater in the UV-AHP treatment system. Further, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ are notorious scavengers of •OH $( \mathbf { k } _ { 4 } = 2 . 7 \times 1 0 ^ { 7 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ , R4, Table 1) and $\mathrm { { } ^ { S O _ { 4 } } \Sigma ^ { - } }$ $\mathit { \bar { \Psi } } ( k _ { 1 0 } = 6 . 1 \times 1 0 ^ { 5 } \mathrm { \bf ~ M } ^ { - 1 } \mathrm { \bf ~ s } ^ { - 1 } $ , R10, Table 1), respectively. Consequently, experimental conditions were used where $[ \mathrm { R h B } ] _ { 0 }$ and [alumina] were constant in all test systems. Oxidant concentrations were designed such that the rate of reaction between •OH and the aqueous scavenger, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , and the reaction between •OH and RhB were less than a factor of 6; similarly, the rate of reaction between $\ S O _ { 4 } ^ { \bullet - }$ and the aqueous scavenger, $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ , and the reaction between $\ S O _ { 4 } ^ { \bullet - }$ and RhB were less than a factor of 6 (i.e., $\mathbf { k } _ { 4 } \ [ \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ] / \mathrm { k } _ { 2 }$ [RhB] and $k _ { 1 0 } [ { \mathrm { S } _ { 2 } } { \mathrm { O } _ { 8 } } ^ { 2 - } ] / { \mathrm { k } _ { 8 } }$ [RhB] $< ~ 6 )$ . Through this method, it was assured that neither reaction would predominate by masking scavenging reactions in either system, and that potential effects from scavenging by the solid phase media could be measured. Additional experiments were carried out for comparison purposes where equimolar concentrations of oxidants, $\mathrm { [ H _ { 2 } O _ { 2 } ] _ { 0 } / [ S _ { 2 } O _ { 8 } ^ { ~ 2 - } ] _ { 0 } }$ = 1, were used $( \mathrm { [ H _ { 2 } O _ { 2 } ] _ { 0 } ~ = ~ [ S _ { 2 } O _ { 8 } } ^ { 2 - } \mathrm { ] _ { 0 } ~ = ~ 2 9 . 4 ~ \ m M } ) $ . The chemicals, experimental procedures, and controls are described in detail (S.3; Figs. S2–S3). Through these experiments, direct comparison between the UV-AHP and UV-APS systems could be carried out. Parameter values, •OH and $S O _ { 4 } ^ { \cdot - }$ activity, and scavenging rate constants used to contrast oxidation results from the UV-APS and UV-AHP heterogeneous treatment systems are tabulated (Table 2). These parameters were further used to calculate kinetic parameters including the radical production rates, normalized reaction rates, reaction rate constants, relative rates of reaction, and estimation of cost efficiency. These parameters served as the basis to contrast treatment results between the UV-AHP and UV-APS systems.

# 3.4. Treatment efficiency calculations

Activation-dependent radical formation in the UV-AHP $\left( \operatorname { E } _ { 1 } \right)$ was less efficient than in the UV-APS treatment system $\left( \operatorname { E } _ { 3 } \right)$ (Table 3). This indicated that $\ S O _ { 4 } ^ { \bullet - }$ were produced more efficiently than •OH and was due to fewer non-productive reactions in the UV-APS system. Similarly, the efficiency of radical reaction with the target compound was lower in the UV-AHP treatment system $\left( \operatorname { E } _ { 2 } \right)$ , than in the UV-APS treatment system $\left( \operatorname { E } _ { 4 } \right)$ (Table 3). Despite ${ \bf k } _ { 2 } \gg { \bf k } _ { 8 }$ (Table 1), greater scavenging of •OH by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { { A l } } _ { 2 } \mathrm { { O } } _ { 3 }$ occurred than in the UV-APS system. Examination of the overall treatment efficiency (η), the UV-AHP was less efficient in RhB oxidation (Table 3) and was attributed to greater scavenging of •OH; $( \eta _ { \mathrm { S O 4 } } . . / \eta . _ { \mathrm { O H } } ) \sim 1 1$ in the non-equimolar, and $( \eta _ { s o 4 } . . . /$ $\eta _ { \mathrm { \cdot o H } } ) \sim 8$ in the equimolar oxidant conditions (Table 3). The cost of commercially available oxidant $( \ S \mathrm { ~ \ m o l ^ { - 1 } ~ H _ { 2 } O _ { 2 } ; ~ \ S ~ \ m o l ^ { - 1 } ~ { \ S } _ { 2 } O _ { 8 } } ^ { 2 }$ ; Table 3), in conjunction with the treatment efficiency $( \mathfrak { n . o H } , \mathfrak { n } _ { \mathtt { S O 4 } \cdot \mathrm { - } } )$ , was used as a metric to estimate the specific cost of RhB transformation. Using this approach, $\$ 1$ ranged from $\$ 12.6~\mathrm{ m o l } ^ { - 1 }$ RhB $( 2 . 1 \ \mathrm { m M } \ \mathrm { P S } )$ to $\$ 17.3\mathrm { \ m o l } ^ { - 1 }$ RhB $2 9 . 4 \ \mathrm { m M }$ PS); and $\$ 1202$ was $\$ 18.2\mathrm { ~ m o l } ^ { - 1 }$ RhB $( 2 9 . 4 \ : \mathrm { m M } \ : \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ (Eqs. (18)–(19); Table 3). On this basis, the low cost of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the UV-AHP treatment system was offset by the much lower overall treatment efficiency $\left( \eta _ { \cdot \mathrm { O H } } \right)$ . Further, the much greater treatment efficiency associated with the UV-APS $\left( \mathfrak { n } _ { \mathrm { s o 4 } } . . \right)$ offset the higher cost of PS contributing to a more favorable specific cost. In general, the muchdesired high reaction rate of •OH with environmental contaminants, relative to $\ S O _ { 4 } ^ { \bullet - }$ , comes at the cost of a greater combined scavenging rate, and lower treatment efficiency. The cost of oxidant in this manner is one factor to consider in oxidant selection. In other oxidation systems involving radical formation and reaction, additional factors must be considered that play a key role in oxidant selection including contaminant specificity, oxidant transport and persistence, oxidant delivery and loading requirements, etc. [1,3].

# 3.5. Environmental implications

It is evident that •OH and $\mathrm { { \thinspace 8 O _ { 4 } } ^ { \bullet - } }$ scavenging reactions attributed to solid surfaces is a leading cause of treatment inefficiency, even in relatively clean systems (i.e., in the absence of anions, organic matter, higher solids content). It is anticipated that in subsurface treatment systems involving unconsolidated porous media, surface scavenging will play an even greater role given the high solids to water ratio. For example, assuming ISCO in $1 ~ \mathrm { m } ^ { 3 }$ aquifer material, and common parameter values for porosity $( 3 0 \% )$ and bulk density $( 1 . 6 \mathrm { ~ g ~ c m } ^ { - 3 } )$ , the solids to liquid ratio is high $( 1 6 0 0 \mathrm { k g } \mathrm { L } ^ { - 1 } )$ . Whereas the solids to liquid ratio used here was comparatively lower $( 1 0 \mathrm { ~ g ~ L ~ } ^ { - 1 } \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 } )$ . The sheer magnitude of aquifer solids and mineral surfaces in aquifer systems, compared to the dilute suspensions in this study, will strongly amplify the role of surface scavenging.

Contrasting scavenging results with the non-radical based oxidant, permanganate $( \bf M n O _ { 4 } ^ { - } )$ , suggests that more efficient treatment would likely occur with respect to contaminant loss than radical-based oxidants. For example, results indicate that repeated and aggressive PS treatments of the alumina (i.e., $5 0 \ g \mathrm { P S / k g }$ alumina $\left( \times 3 \right)$ ; $1 5 0 \mathrm { ~ g ~ P S / k g }$ alumina), did not significantly diminish the rate of $\ S O _ { 4 } ^ { \cdot - }$ scavenging by the alumina surfaces indicating that this source of treatment inefficiency is not easily eliminated for solid phase media [15]. Silicon (Si) and aluminum (Al) are unlikely species that scavenge •OH, as these elements exhibit their highest oxidation state. Surface hydroxyl groups or surface defect sites are abundant and can serve as potential electron donors and surface scavenging sites [22–25]. Conversely, in $\mathrm { M n O _ { 4 } } ^ { - }$ treatment systems, the background oxidant demand often attributed to natural organic matter is finite [26–27] despite being greater than the demand expressed by the target contaminants [28–29]. Consequently, contaminant oxidation efficiency is inversely correlated with the natural oxidant demand. Specifically, improved oxidation efficiency using $\mathrm { M n O _ { 4 } } ^ { - }$ occurs as background oxidant demand diminishes, $\mathrm { M n O _ { 4 } } ^ { - }$ persistence improves, and greater contact occurs between the oxidant and contaminant.

# 4. Conclusions

The rates at which •OH and $\ S O _ { 4 } ^ { \cdot - }$ were produced and reacted under heterogeneous UV-AHP and UV-APS treatment conditions were examined. Kinetic parameters used in this analysis were derived from this laboratory study, and from previous studies involving similar oxidative treatment conditions [14–15]. These parameters included the surface scavenging rate constants for alumina $( \mathbf { k } _ { \equiv } s )$ , steady state •OH and $S O _ { 4 } ^ { \cdot - }$ concentrations, and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ and RhB degradation rate constants. The reactions were differentiated based upon the rates at which the radicals reacted with the probe compound, aqueous phase scavengers $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } , \mathrm { ~ } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - } )$ , and the mineral surfaces of solid phase alumina $\left( \mathsf { A l } _ { 2 } \mathsf { O } _ { 3 } \right)$ . In comparing the overall reaction rate for the three classes of reactants (i.e., probe, aqueous scavenger, solid phase scavenger), the overall reaction rate was greater for •OH than $\ S O _ { 4 } ^ { \bullet - }$ (i.e., $\Nu . _ { \mathrm { O H } } , \ \Nu _ { S O 4 \bullet . } )$ . This result was supported by the fact that the secondorder reaction rate constants for the RhB, oxidant, and surface scavenging were all greater for the •OH than $\ S O _ { 4 } ^ { \cdot - }$ . Consequently, the rate of scavenging was also greater for $\mathbf { \nabla \cdot } \mathrm { O H }$ than $\ S O _ { 4 } ^ { \cdot - }$ . Scavenging by dissolved constituents in the aqueous phase was dominated by the oxidant used to form the radicals (i.e., $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } , \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - } )$ . Although reaction rate constants (i.e., $\mathbf { k } _ { 4 } , k _ { 1 0 } )$ are not necessarily high for these oxidants, the elevated concentrations of oxidants in these treatment systems was the main cause for aqueous phase radical scavenging. The rate of radical scavenging by alumina was greater than the rate of probe oxidation in all cases; persulfate scavenging dominated alumina scavenging in the UV-APS under the condition where high initial persulfate concentration was present $( [ \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } ^ { 2 - } ] _ { 0 } = 2 9 . 4 \mathrm { \ m M } )$ . Overall, a low concentration of suspended $\mathrm { { A l } } _ { 2 } \mathrm { { O } } _ { 3 }$ solids (i.e., $1 0 \mathrm { ~ g ~ L ~ } ^ { - 1 } .$ ) caused significant radical scavenging effects in both the UV-AHP and UV-APS laboratory-based treatment systems. In aquifer systems where the solids content is much higher, the solid surface scavenging reaction rates will be amplified, and treatment efficiencies are projected to be much lower than measured in the slurry treatment systems.

Activation-dependent radical formation in UV-AHP $\left( \operatorname { E } _ { 1 } \right)$ was less efficient than in the UV-APS treatment system $\left( \operatorname { E } _ { 3 } \right)$ . This was attributed to the non-productive consumption of oxidant which diminished radical production. The radical reaction with the target compound was also less efficient in the UV-AHP treatment system $\left( \operatorname { E } _ { 2 } \right)$ , than in the UV-APS treatment system $\left( \operatorname { E } _ { 4 } \right)$ and was attributed to greater aqueous and solid phase scavenging rates. The price of commercially available $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $( \$ 0.031\ m o l ^ { - 1 }$ ) was less costly than $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ $( \$ 0.24 \mathrm { ~ m o l } ^ { - 1 } )$ . However, using these oxidant costs, in conjunction with the overall treatment efficiency $\ l ( \eta )$ , indicated that the specific cost to treat the probe compound with UV-AHP was greater than with UV-APS $( \$ 120 2,456,78$ $\mathrm { m o l } ^ { - 1 }$ RhB oxidized). In summary, the low cost of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the UV-AHP system was diminished by the low treatment efficiency relative to much greater treatment efficiency in the UV-APS. The much-desired, high reaction rate constants between •OH and environmental contaminants, relative to $\ S O _ { 4 } ^ { \cdot - }$ , may come at the cost of greater combined scavenging rate, and consequently lower treatment efficiency.
