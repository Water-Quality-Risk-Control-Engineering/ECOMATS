# Abstract

The heterogeneous catalyst Mackinawite (FeS) was applied to activate periodate $\left( \mathrm { I O } 4 ^ { - } \right)$ to degrade endocrine disruptors bisphenol AF (BPAF). This study investigated the influence of FeS dosage, periodate dosage, BPAF concentration, initial pH value and inorganic ions on BPAF degradation by $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system. The results showed that the BPAF was effectively degraded by $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system. The acidic pH exhibited higher efficiency in BPAF degradation compared with alkaline and neutral conditions. Furthermore, the BPAF degradation was dramatically promoted in the presence of $\mathrm { C l ^ { - } }$ and $\mathrm { S O } _ { 4 } { } ^ { 2 - }$ , whereas $\mathrm { C O } _ { 3 } { } ^ { 2 \cdot }$ inhibited BPAF degradation. The radical scavenging tests and EPR indicated that singlet oxygen $( ^ { 1 } \mathrm { O } _ { 2 } )$ , superoxide radicals $( \mathrm { O } _ { 2 } ^ { \bullet - } )$ and $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ were committed to the degradation of BPAF, among which ${ \mathrm { O } } _ { 2 } ^ { * - } , \quad { } ^ { 1 } { \mathrm { O } } _ { 2 }$ were predominant radicals. The separate experiments showed that $\mathrm { F e ( I I ) }$ participated in the activation of periodate. Furthermore, the effects of sulfur species (including the $\mathrm { S } ^ { 2 - }$ , $\mathrm { S O } _ { 3 } { } ^ { 2 - } )$ on BPAF degradation by $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system were studied. The radical quenching tests suggested that $S ^ { 2 - }$ and $\mathrm { S O } _ { 3 } { } ^ { 2 - }$ were responsible for producing $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ . The findings of this study elucidated an approach for the removal of micro−pollutants in the water environment through heterogeneous activation of periodate by FeS.

Keywords: periodate; Mackinawite (FeS); superoxide radical; singlet oxygen; sulfate radicals; sulfur species

# 1. Introduction

Bisphenol A (BPA) has been extensively adopted in polycarbonate and epoxy plastics as a type of industrial chemical and more than 4.5 million tons were produced annually [1, 2]. Nevertheless, BPA is considered as an endocrine−disrupting chemical (EDC), adversely affecting the genital system and embryo development of the organism [3-5]. Thus, both the sale and application of BPA have been strictly restricted in a number of countries over the past few decades [6, 7]. In present studies, microbiological biodegradation [8], adsorption [9], photocatalytic [10-12] and chemical oxidation [13, 14] have been reported to have the ability to remove BPA from wastewater, whereas the degradation of BPA analogues has been rarely studied. Bisphenol AF (BPAF) exhibits a similar structure with BPA. It has been extensively adopted as a substitute for BPA in the market. Recent studies suggested that BPAF could also lead to endocrine disruption which exists in a range of environments [15,

16]. BPAF has been widely used in the fields of fluoroelastomers, food processing, optical fiber and electronic equipment [17]. The maximal concentration of BPAF was ascertained with up to $1 5 . 3 ~ \mu \mathrm { g / g }$ in the river, the dry weight was $0 . 2 ~ { \mu \mathrm { g / g } }$ in the sediment, the dry weight concentration of indoor dust reached up to $0 . 7 3 9 ~ { \mu \mathrm { g } } / { \mathrm { g } }$ , and the well water concentration was $0 . 3 ~ { \mu \mathrm { g / g } }$ [7]. Based on previous studies, traditional biological treatment techniques and photocatalysis cannot effectively degrade BPAF [18]. Therefore, it is meaningful to seek an appropriate treatment method. Advanced Oxidation Processes (AOPs) can effectively produce highly reactive free radicals to degrade organic matter in solution by chemical oxidation, including the oxidants below: hydrogen peroxide $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ , ozone $( \mathbf { O } _ { 3 } )$ and peroxymonosulfate $\left( \mathrm { H S O 5 ^ { - } } \right)$ , peroxydisulfate $( \mathbf { S } _ { 2 } \mathbf { O } _ { 8 } ^ { 2 - } )$ and periodate $\left( \mathrm { I O } _ { 4 } ^ { - } \right)$ ) [19-22]. Periodate exhibits high oxidation with an oxidation−reduction potential of $+ 1 . 6 0 \mathrm { V } ,$ , whereas its activation is required to produce highly reactive intermediates [23]. The activation of periodate to generate reactive radical intermediates by means of UV $\mathrm { { U V / I O _ { 4 } } ^ { - } }$ process) or ultrasonic radiation has been performed to lower the chemical oxygen demand in organic pollutants and industrial wastewater [19, 24-26]. Recently, a study from Bokare et al., alkali−mediated $\mathrm { ( p H ) } 8 _ { , }$ ) activation of $\mathrm { I O } _ { 4 } ^ { - }$ , singlet oxygen $( ^ { 1 } \mathrm { O } _ { 2 } )$ acted as the dominant radical of $\mathrm { O H ^ { - } / I O _ { 4 } ^ { - } }$ system was produced by spontaneous reaction between periodate and $\mathrm { O H ^ { - } }$ (Eqs. 1−3) [27]. Meantime, Choi et al. reported that periodate could be activated by being frozen to degrade pollutants [28]. Li et al. used I −GAC as catalyst to activate periodate, thus generating $\mathrm { I O } _ { 3 } { } ^ { \cdot }$ radicals to degrade AO7 [4, 29]. Additionally, Lee et al. showed that bimetallic $\mathrm { n F e ^ { 0 } }$ could effectively activate $\mathrm { I O } _ { 4 } ^ { - }$ to generate $\mathrm { I O } _ { 3 } { } ^ { \cdot }$ by single electron reduction of $\mathrm { n F e } ^ { 0 } { \mathrm { - } } \mathrm { C u }$ (or Ni), while nFe0 without adding Ni or Cu only cause $\mathrm { { I O } _ { 4 } } ^ { - }$ reduction rather than degradation of pollutants. Thus, periodate must be activated to produce highly active intermediates for removing pollutants [30]. Recently, $\mathbf { M } \mathbf { n } ^ { 2 + } .$ −mediated activated periodate to degrade contaminants without external energy, which superoxide radicals were considered as the main reactive species to decompose contaminants [31]. In the above case, periodate has limited ability oxidization by degrading contaminants individually and selectively.

On the whole, transition metals are economically effective activators in the contrast of other substances. Especially, iron−based materials are characterized by relative efficiency, less pollution and lower costs, while the activation of periodate by $\mathrm { F e } ^ { 2 + }$ has poor degradation effect on pollutants [31]. Mackinawite (FeS) is formed by biological reduction of sulfate. FeS acts as an innocuous metastable mineral. It is also one of the sulfide minerals with considerable ferrous ions [32, 33]. $\mathrm { F e S } _ { 2 }$ acts as a source of Fe(II), Fe(II) activated persulfate $( \mathbf { S } _ { 2 } \mathbf { O } _ { 8 } ^ { 2 - } )$ to produce $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ , noticeably oxidizing methyl tert−butyl ether (MTBE) [34]. Moreover, • OH was produced by $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ oxidation at the sulfur deficiency site and through two−electron reduction of $\mathrm { O } _ { 2 }$ on the surface of pyrite in the presence of oxygen [35]. Liu et al. reported that molecular oxygen activation was caused by $\mathrm { F e } ^ { 2 + }$ on the surface of $\mathrm { s y n - F e S } _ { 2 }$ , accelerating the mutual

conversion between $\mathrm { F e ( I I ) }$ and $\mathrm { F e ( I I I ) }$ on the surface to promote more decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to produce • OH [36]. As Fan et al. reported, the $\mathrm { F e ( I I ) }$ could be regenerated by the $\mathbf { S } ( - \mathrm { I I } )$ species on the surface of FeS, which reduced the decomposition of persulfate (PS) and promoted PCA degradation [37]. The recent studies have found that $\mathrm { S O } _ { 3 } \mathrm { } ^ { 2 - }$ , $S { _ { 5 } } ^ { 2 - }$ , ${ \mathrm { S } } _ { 8 } ^ { 0 }$ and $\mathrm { S } _ { 2 } \mathrm { O } _ { 3 } { } ^ { 2 - }$ intermediates were formed by sulfur transformation in the peroxymonosulfate (PMS)−FeS system, in which $\mathrm { S O } _ { 3 } \mathrm { } ^ { 2 - }$ induced the formation of $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ . The conversion of sulfur should be understood in terms of free radical generation, since the interaction between the sulfur intermediate, activator and oxidant impacts the production of highly reactive radical intermediates and the degradation of pollutants [38]. However, the study on the degradation effect and mechanisms of pollutants in the $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system has not been conducted. Besides, the role of S species has not been investigated comprehensively.   
In this work, the process in which FeS activates periodate to degrade BPAF was studied. The major aims of this study include: 1) to evaluate the effects of various operating parameters (including the FeS dosage, periodate dosage, different initial pH values, BPAF concentration and inorganic ions) on BPAF degradation; 2) to determine the major free radicals with the reaction process, the electron paramagnetic resonance (EPR) and free radical quenching experiments were performed; 3) to elucidate the impact of sulfur species (including the $S ^ { 2 - }$ and $\mathrm { S O } _ { 3 } { } ^ { 2 - }$ ) in periodate activated by FeS, X−ray photoelectron spectroscopy (XPS) and radical quenching experiments were performed.

# 2.2 Experimental procedure

The degradation experiments were conducted at ambient temperature $( 2 4 \pm 4 ^ { \circ } \mathrm { C } )$ in 250 mL conical flask. Each $2 0 0 ~ \mathrm { m L }$ reaction solution was performed using magnetic agitator for $1 2 0 ~ \mathrm { \ m i n }$ . BPAF stock solution and periodate stock solution with pre−determined volume were injected into the reaction solution. Subsequently, the predetermined dosage of FeS was added in mixed liquor to initiate the reaction. The baseline condition of the test covered $2 0 \mu \mathrm { M }$ of BPAF, $1 \ \mathrm { m M }$ periodate and $1 \ \mathrm { g / L }$ FeS. The initial pH of the experiment was 5.5 without being regulated except for discussing the effect of $\mathrm { p H }$ on BPAF degradation. Considering the influence of $\mathrm { C l ^ { - } }$ on the system, nitric acid (HNO3) and sodium hydrate (NaOH) solutions were adopted to regulate the value of $\mathrm { p H }$ . During the BPAF degradation reaction, the samples of $4 \mathrm { m L }$ were withdrawn from the reactor by $5 \ \mathrm { m L }$ syringe at designed time intervals and filtered through a $0 . 2 2 ~ { \mu \mathrm { m } }$ PES. The samples were not degraded within 24 hours. Therefore, no quenching agent was employed for degradation experiment. ${ \mathrm { N a N } } _ { 3 }$ and p−Benzoquinone as radical scavenger were applied to verify the primary reactive species in the quenching experiment. To identify the effect of the dissolved oxygen on reaction, air or nitrogen was purged into the deionized water for $3 0 ~ \mathrm { m i n }$ before the experiment. Nitrogen was continuously purged to maintain the anoxic condition during the reaction. The tests were overall performed at least twice and error bars represented deviations from the average value.

# 3. Results and discussion

# 3.1 Effect of FeS dosage on BPAF degradation

To evaluate the influence of FeS $( 0 { - } 4 ~ \mathrm { g / L } )$ dose on the degradation of BPAF, parallel experiments were carried out by adding FeS to reaction solution. As shown in Fig. 1, the BPAF degradation was less than $4 \%$ over $1 2 0 ~ \mathrm { m i n }$ in the absence of FeS. The result indicated that the BPAF was hardly degrade by periodate without any activator. However, the BPAF was remarkably degraded in $\mathrm { F e S / \Sigma }$ system. With the FeS dose varied from $0 . 2 5 ~ \mathrm { g / L }$ to $1 \ \mathrm { g / L }$ , the removal efficiency of BPAF was $4 5 . 6 \%$ , $7 7 . 6 \%$ and $9 8 . 6 \%$ after $1 2 0 \ \mathrm { m i n }$ , respectively. Moreover, when the dosage of FeS increased from $1 \ \mathrm { g / L }$ to $4 \ \mathrm { g / L }$ , the reaction time for complete BPAF degradation reduced from $1 2 0 \ \mathrm { m i n }$ to $2 0 \ \mathrm { m i n }$ . This might ascribe to that as increment of FeS dosage, more active sites on the surface of FeS were used to generate active species to efficiently degrade BPAF. Furthermore, the release of ferrous ions concentration increased with increasing of mackinawithe dosage (Fig. S2), which may accelerate the activation of periodate by ferrous ions and increase the amount of active species [30].

# 3.2 Effect of periodate concentration on BPAF degradation

The effect of different concentration periodate ranging from $0 { \mathrm { - } } 4 \ \mathrm { \ m M }$ on degradation of BPAF was presented in Fig. 2. The removal rate of BPAF was only $3 \%$ in the absence of periodate, suggesting that FeS could not efficiently adsorb BPAF. Besides, BPAF concentration decreased dramatically upon the addition of $0 . 5 ~ \mathrm { m M }$ periodate solution. These results indicated that the coexistence of periodate and FeS were essential for the oxidative degradation of BPAF. When the concentration of periodate increased from 0.5 to $1 \ \mathrm { m M }$ , the decomposition rate of BPAF increased progressively. The effect might be associated with increased amount of active species produced from $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system. It can be observed that BPAF was completely removed within 60 minutes when periodate concentration increased to $4 ~ \mathrm { m M }$ ,which might be attributed to that the periodate were not completely occupied the active sites on the FeS surface [4].

# 3.4 Effect of pH on BPAF degradation

# 3.9 Mechanism of periodate activation by FeS

Based on the analysis of the above experiments, the possible mechanism of BPAF degradation in the $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system was proposed, as illustrated in Fig. 10. After the FeS was added to an aqueous solution containing periodate, surface Fe(II) (unstable ionic species attached to the catalyst surface) or $\mathrm { F e } ^ { 2 + }$ reacted with periodate to produce $\mathrm { O } _ { 2 } ^ { \bullet - }$ and $^ 1 { \bf O } _ { 2 }$ . At the same time, $\mathbf { S } ( - \mathrm { I I } )$ on the surface of FeS was oxidized by $\mathrm { { I O } _ { 4 } } ^ { - }$ to form polysulfide $( \mathrm { S n } ^ { 2 - } )$ , elemental sulfur $( \mathsf { S } ^ { 0 } )$ and $\mathrm { S O } _ { 4 } ^ { \bullet - }$ . The $\mathrm { S O } _ { 3 } \mathrm { } ^ { 2 - }$ was produced by electron transfer and oxidation of $S ^ { 2 - }$ in solution. Fe(III) oxidated $\mathrm { S O } _ { 3 } { } ^ { 2 - }$ to produce $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ . In summary, the reaction of $\mathrm { F e ( I I ) / I O _ { 4 } } ^ { - }$ contributed to the generation of $\mathrm { O } _ { 2 } ^ { \bullet - }$ and $^ 1 { \bf O } _ { 2 }$ in $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system. Meanwhile, $\mathrm { S } ^ { 2 - } / \mathrm { I O } _ { 4 } ^ { - }$ and $\mathrm { F e ( I I I ) } / \mathrm { S O } _ { 3 } { } ^ { 2 - }$ system could generate $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ .

# 4. Conclusion

In this study, an efficient approach was proposed to degrade BPAF by $\mathrm { F e S / I O _ { 4 } } ^ { - }$ system. Compared with the addition of single FeS or periodate addition, the removal efficiency of BPAF in FeS/periodate system reached $9 7 . 7 \%$ . Meanwhile, the degradation efficiency increased with increasing the dosages of FeS or periodate. The pH of the solution exerted certain effect on BPAF degradation and the acidic $\mathrm { p H }$ was more effective than neutral or alkaline. The influence of various inorganic anions on the removal efficiency of BPAF was also investigated. The presence of $\mathrm { C l ^ { - } }$ and $\mathrm { S O } _ { 4 } { } ^ { 2 - }$ had a positive influence on the removal of BPAF. The effect of ${ \mathrm { N O } } _ { 3 } ^ { - }$ was very weak and $\mathrm { C O } _ { 3 } { } ^ { 2 - }$ showed a marked inhibition effect.

Through ESR tests and radicals quenching experiments demonstrated that $\mathrm { O } _ { 2 } ^ { \bullet - }$ , $^ 1 { \bf O } _ { 2 }$ and $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ were produced in the FeS/periodate system, while $\mathrm { O } _ { 2 } ^ { \bullet - }$ and $^ 1 { \bf O } _ { 2 }$ acted as the dominant active species. Fe(II) or $\mathsf { \equiv F e ( I I ) }$ could activate $\mathrm { I O } _ { 4 } ^ { - }$ effectively. The XPS spectrum indicated that the content of different sulfur species varied during the oxidation reaction of $\mathrm { F e S / I O _ { 4 } } ^ { - }$ . Moreover, the quenching experiments showed that the oxidation reaction of $\mathrm { S } ^ { 2 - }$ and periodate played an significant role in the generation of $\mathrm { S O } _ { 4 } ^ { \bullet - }$ . In addition, $\mathrm { F e ( I I I ) }$ can effectively activate $\mathrm { S O } _ { 3 } { } ^ { 2 - }$ to trigger the radical chain reaction to produce $\mathrm { { S O } _ { 4 } } ^ { \bullet - }$ .
