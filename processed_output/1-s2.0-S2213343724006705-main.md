# . Introduction

Recently, advanced oxidation processes (AOPs) have been comprehensively studied for the elimination of emerging contaminants in wastewater treatment applications [1,2]. Among AOPs, sulfate radical $( S O _ { 4 } ^ { \bullet - } )$ -based AOPs have outstanding performance due to the high redox potential of $S O _ { 4 } ^ { \bullet - }$ (2.53.1 V), long half-life $( 3 0 - 4 0 ~ \mu s )$ , and high adaptability over a wide operation pH range (28) [3,4]. $S O _ { 4 } ^ { \bullet - }$ can be produced from the activation of peroxydisulfate (PDS) and peroxymonosulfate (PMS) via different methods, including UV irradiation [5], heating [6], ultrasonic irradiation [7], and heterogeneous processes [8]. In addition, PMS is more easily activated than PDS because of its asymmetric structure. Magnetic spinel-type copper ferrite $\mathrm { ( C u F e _ { 2 } O _ { 4 } ) }$ can be a viable catalyst for the removal of refractory contaminants through the activation of PMS due to its capable separation properties and high efficiency [9]. However, the agglomeration of magnetic nanomaterials restricts their application in real wastewater treatment processes [10]. To address this issue, biochar (BC), a green and sustainable carbonaceous material, can be used as a supportive medium for the immobilization of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanomaterials [11].

The metallic states of nanomaterials play a crucial role in the PMS activation process. For instance, the transformation of $\mathbf { M } ^ { \mathrm { n + } }  \mathbf { M } ^ { \mathrm { n + 1 } }$ in metal-based catalysts can create a loop for the release and consumption of electrons [12]. However, the poor reduction rate of high-valence metal ions (e.g., $\mathrm { F e } ^ { 3 + }$ ) in nanocomposites during the PMS activation process can reduce the removal efficiency of pollutants due to the low conversion rates of redox pairs (e.g., $\mathrm { F e } ^ { \bar { 3 } + } / \mathrm { F e } ^ { 2 + } )$ [13]. To date, many attempts have been made to solve this issue. The introduction of chelating/reducing agents into the nanomaterial/PMS system is an ideal

For instance, hydroxylamine [14], ethylene-diaminetetraacetic acid [15], citric acid [16], ascorbic acid $\mathrm { ( H _ { 2 } A ) }$ [17], and L-cysteine (LC) [18] have been confirmed to significantly improve the degradation efficiency of organic pollutants in metal-based nanomaterial AOPs. Among these agents, $\mathrm { H _ { 2 } A , }$ known as vitamin C, and amino acid LC can be highly recommended due to their economical and environmentally friendly properties and because they are widely present in natural environments. Although both $\mathrm { H _ { 2 } A }$ and LC can considerably boost the degradation efficiency of pollutants, the degradation mechanisms, degradation pathways, and environmental effects may vary. Therefore, there is a need to study and compare the effects of $\mathrm { H _ { 2 } A }$ and LC in the B $\mathrm { C - C u F e _ { 2 } O _ { 4 } / P M S }$ system on the removal of persistent organic pollutants.

Furthermore, the recycling and reuse of nanomaterials is still a challenging issue when considering such catalytic oxidation processes for practical wastewater treatment applications. Catalysts embedded into either membranes [19] or ball substrates [20] can facilitate their easy separation and subsequent reuse. However, there are no reports comparing catalytic membranes and catalytic balls in terms of their degradation efficiency, environmental effects, and stability. Hence, it is highly recommended to investigate the difference between catalytic membranes and balls in the wastewater treatment process to promote commercialization pathways.

In this study, a BC-CuFeO nanocomposite catalyst was fabricated and employed for the activation of PMS for the degradation of CBZ. Both $\mathrm { H _ { 2 } A }$ and LC were applied to improve the CBZ degradation efficiency in the BC-CuFeO/PMS system. The operating conditions (e.g., nanomaterial dosage, PMS concentration, $\mathrm { H _ { 2 } A / L C }$ concentration, CBZ concentration, initial pH) in the system were studied by designing experiments using the Taguchi approach, and the effects of water matrices (e.g., Cl', $\mathrm { N O } _ { 3 } ^ { - } ,$ . $\mathrm { H C O } _ { 3 } ^ { - } )$ on CBZ removal were also examined. The generation and contribution of predominant species were also explored. The byproducts of CBZ, pathways, and possible toxicity were also determined in the BC$\mathrm { C u F e O / P M S / H _ { 2 } A }$ and BC-CuFeO/PMS/LC systems. Moreover, a nanomaterial-based catalytic membrane and catalytic balls were fabricated and applied for the activation of PMS for the degradation of CBZ in the presence of $\mathrm { H _ { 2 } A / L C }$ , and their stability and applicability were evaluated.

# ..Synthesis of the biochar $C u F e _ { 2 } O _ { 4 } / F e _ { 2 } O _ { 3 } / C u O$ (BC-CuFeO) catalyst

Walnut shell biochar $\mathrm { . C u F e _ { 2 } O _ { 4 } / F e _ { 2 } O _ { 3 } / C u O }$ (BC-CuFeO) materials were synthesized using a combined sol-gel/pyrolysis process, as shown in Fig. 1a. Typically, $1 6 . 1 5 8 \ g$ of iron nitrate nonahydrate, $4 . 8 3 2 ~ \mathrm { g }$ of copper nitrate hydrate, $1 1 . 5 2 8 \ g$ of citric acid, and $_ { 5 } \mathrm { ~ g ~ }$ of walnut shell were dispersed into $2 0 0 ~ \mathrm { m L }$ of water and then stirred for $2 4 \ \mathrm { h }$ Afterwards, the mixture was put in an oven $( 1 0 5 ^ { \circ } \mathrm { C } )$ for subsequent gel formation and solidification. Subsequently, the solid products were crushed and then calcined at $5 5 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ at a heating rate of $5 ^ { \circ } \mathrm { C } / \mathrm { m i n }$ under a nitrogen atmosphere. The powder was collected after naturally cooling to room temperature for further characterization and use.

The catalytic membrane and balls were fabricated by a phase inversion process. Typically, PES $( 2 . 4 \ g )$ and PEG $( 4 \ g )$ were added to DMF solution $( 1 3 . 6 ~ \mathrm { g } )$ , and then, the solution was heated at $6 0 ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ under stirring conditions. Subsequently, $0 . 8 \ : g$ of BC-CuFeO nanocomposite was added to the above solution. Thereafter, the mixture was mixed on a vortex mixer at $2 2 0 0 \mathrm { r p m / m i n }$ for $1 0 \mathrm { m i n }$ for the formation of a homogenous solution. For the preparation of balls, the obtained solution was added to water drop by drop for the generation of catalytic balls. For the fabrication of the membrane, the homogenous solution was uniformly placed over a glass plate to a membrane thickness of $6 0 0 \mu \mathrm { m }$ by using a casting knife (Elcometer 3580, Netherlands). Then, the glass plate was soaked in a water bath until the membrane detached spontaneously from the plate. The prepared balls and membrane were immersed in water for $2 4 \ \mathrm { h }$ to remove residual organic solvents, and then the catalytic balls and membrane were dried completely at room temperature prior to use.

# 3.2. Degradation of CBZ in different systems

The CBZ removal efficiencies were evaluated in different systems under the same conditions $( 0 . 3 \ g / \mathrm { L }$ BC-CuFeO, $4 \mathrm { m g } / \mathrm { L }$ CBZ, 1 mM PMS, $0 . 5 \mathrm { m M } \mathrm { H } _ { 2 } \mathrm { A } / \mathrm { L C } )$ . However, a slight increase $( 1 4 \% )$ was observed in the simultaneous presence of $\mathrm { H _ { 2 } A }$ and PMS, which can be attributed to the fact that $\mathrm { H _ { 2 } A }$ can activate PMS, generating the active species that facilitate the degradation of organic pollutants in the system, albeit without considerable enhancement (Eqs. 12) [29]. # 3.3. Influence of operating conditions on CBZ degradation

The effects of the operating parameters (i.e., nanomaterial dosage, PMS concentration, $\mathrm { H _ { 2 } A }$ concentration, CBZ concentration, and initial pH) on CBZ removal in the BC-CuFeO, $\mathrm { \ P M S / H _ { 2 } A }$ system were studied by the Taguchi experimental design, as presented in Table S2-S3, Fig. S3, and Fig. 3a. The S/N ratios indicated that the initial solution pH was the most statistically significant factor affecting the $\mathrm { B C - C u F e O / P M S / H _ { 2 } A }$ system, followed by the CBZ concentration, PMS concentration, nanomaterial dosage, and $\mathrm { H _ { 2 } A }$ concentration. This suggests that PMS activation by BC-CuFeO was the primary process, while the role of $\mathrm { H _ { 2 } A }$ was less significant than that of other factors. This can be attributed to the limited functionality of $\mathrm { H _ { 2 } A }$ just promoting the valence transformation of metal ions on the materials and the low interaction with PMS for the degradation of CBZ. Fig. 3 shows that the optimal conditions for CBZ degradation were $0 . 4 ~ \& / \mathrm { L }$ catalyst, $1 . 3 \mathrm { m M }$ PMS, 0.5 mM $\mathrm { H _ { 2 } A }$ $2 \mathrm { m g } / \mathrm { L }$ CBZ, and $\mathtt { p H } { = } 3$ in the $\mathrm { B C - C u F e O / P M S / H _ { 2 } A }$ system because it had the highest S/N ratio. More active sites will be available for the activation of PMS at a relatively high dosage of catalyst, resulting in more active species being generated for the degradation of organic pollutants [35]. High PMS concentrations are also beneficial for greater generation of active species, and less active species are needed at lower CBZ concentrations [36], improving CBZ degradation efficiency. In addition, the objective of the Taguchi method is to identify the parameter with the most significant influence on the target by comparing the $s / \Nu$ ratio of each parameter and finally determining the optimal conditions [37]. Hence, the effect of CBZ concentration on removal efficiency was also explored by single-factor experiments, as illustrated in Fig. S5a. The removal efficiency decreased from $8 5 \%$ to $6 2 \%$ as the CBZ concentration increased from $2 \mathrm { m g } / \mathrm { L }$ to $8 \mathrm { m g } / \mathrm { L }$ . This can be mainly due to more active species being needed at higher concentrations of CBZ in solution, wherein the degradation products can also compete with CBZ for the active species, resulting in a low degradation efficiency [38]. However, the optimal value of $0 . 5 \mathrm { m M }$ was identified for the $\mathrm { H _ { 2 } A }$ concentration, and a lower concentration of $\mathrm { H _ { 2 } A }$ can facilitate the conversion between different valences of the metal ions through one-electron reduction, thus accelerating the generation of active species in the medium. However, excess $\mathrm { H _ { 2 } A }$ can act as a scavenger for active radicals (e.g., $\mathrm { { \bf S } O _ { 4 } ^ { \bullet - \cdot } }$ (Eqs. 56), resulting in the active species being insufficient for the degradation of contaminants in the medium [39]. # 3.Reusability and stability of the catalysts

The reusability and stability of the BC-CuFeO/PMS/H2A and BCCuFeO/PMS/LC systems were also investigated through the collection, further reuse and characterization of the spent catalysts. As illustrated in Fig. S7, both the BC-CuFeO/PMS/ $\mathrm { \mathrm { { H _ { 2 } A } } }$ and BC-CuFeO/PMS/LC systems displayed high CBZ degradation efficiencies after three cycles of degradation, and no noticeable decrease in CBZ degradation efficiency was observed, confirming the high stability of these systems. In addition, the FTIR spectra (Fig. S8) of pristine and used BC-CuFeO exhibited similar characteristic peaks, revealing that the surface functional groups and structures of BC-CuFeO were not damaged during CBZ degradation. As illustrated in Fig. S9, the concentrations of leached copper ions were $3 . 5 \mathrm { m g } / \mathrm { L }$ and $1 . 8 \mathrm { m g / L }$ in the $\mathrm { B C - C u F e O / P M S / H _ { 2 } A }$ system and BCCuFeO/PMS/LC system, respectively, while the leached iron ions in the medium were insignificant for both systems $( < 0 . 0 6 \mathrm { m g / L } )$ . According to the World Health Organization (WHO), the recommended concentration of copper ions in drinking water is $2 \mathrm { m g } / \mathrm { L }$ [54]. In this regard, the BC-CuFeO/PMS/LC system is a more sustainable technology than the BC-CuFeO/ $\mathrm { P M S } / \mathrm { H } _ { 2 } \mathrm { A }$ system.

# 3.7. Degradation products and toxicity assessment

The CBZ transformation products in the BC-CuFeO/PMS/H2A and BC-CuFeO/PMS/LC systems were detected by Q-TOF-MS. The retention times, molecular weights, proposed molecular formulas and structures of these products are summarized in Table S5. Nine degradation products were observed in the BC-CuFeO/PMS/H2A system and BC-CuFeO/ PMS/LC system. However, P6 and P1o only existed in the BC-CuFeO/ $\mathrm { P M S } / \mathrm { H } _ { 2 } \mathrm { A }$ system and BC-CuFeO/PMS/LC system, respectively. As illustrated in Fig. 6a, the olefinic double bond of CBZ can be easily attacked by the active species due to its high frontier electron density, resulting in the formation of P1 and P2. P3 can be produced from P2 through a heterocyclic ring-opening process. P2 can also be transformed into P4 and further oxidized into P5. Both P6 and P7 can be generated from P5 through decarboxylation/oxidation and decarboxylation/ dehydroxylation, respectively. P7 can be further oxidized for the generation of P8 and P9, and P9 can also be produced from P8 through the cleavage of double bonds. As shown in Fig. 6b, most of the degradation processes are similar between the $\mathrm { B C - C u F e O / P M S / H _ { 2 } A }$ system and BCCuFeO/PMS/LC system, which can be attributed to the similar dominant active species being available in these systems. Additionally, P10 can be formed from P5 through hydroxylation/decarboxylation, and P10 can be further transformed into P7 through the dehydroxylation process.

The toxicity of CBZ and CBZ degradation products were also investigated under different conditions, including acute toxicity, bioconcentration factor, developmental toxicity, and mutagenicity. The acute toxicity was estimated by the $\mathrm { L C } _ { 5 0 }$ (mg/L), which refers to the chemical content in water that causes $5 0 \%$ of Daphnia magna to die after 48 hours. The bioconcentration factor is the ratio of a chemical concentration in an organism as a result of steady-state absorption via the respiratory surface in water. The term developmental toxicity refers to whether a substance causes developmental toxicity in humans or animals. If a substance produces revertant colony formation in any strain of Salmonella typhimurium, it is mutagenic. As illustrated in Fig. 7a, most of the intermediates (except P2 and P6) demonstrated a lower toxicity level than CBZ. In addition, the bioconcentration factor (Fig. 7b) of the degradation products, except for P6-P9, significantly decreased, and the developmental toxicity (Fig. 7c) of these products, except P1-P5, was markedly reduced compared with that of CBZ. The mutagenicity results (Fig. 7d) demonstrated that P1, P3, P8, and P10 were mutagenically negative. It is worth mentioning that some degradation products displayed a higher toxicity level than CBZ (e.g., acute toxicity of P2); hence, more attention should be given to preventing the generation of these highly toxic products.

# 3.8. BC-CuFeO immobilization on balls and membranes

To further increase the applicability of BC-CuFeO, nanocomposites were incorporated into ball/membrane structures to solve the recycling issue of nanomaterials. In Fig. 8a-b, the catalytic ball and membrane demonstrated low adsorption efficiencies of $3 \%$ and $8 \%$ ,respectively. The catalytic membrane exhibited a higher CBZ degradation efficiency than the catalytic ball in the presence of $0 . 7 \mathrm { m M }$ PMS $( 2 5 \% > 1 0 \% )$ , while the CBZ degradation efficiency did not significantly improve as the PMS concentration further increased to $1 \ \mathrm { m M }$ in the ball-andmembrane system, revealing the insufficiency of active sites for the activation of PMS in such systems. In addition, the ball, $\mathrm { \cdot P M S / H _ { 2 } A }$ system presented a better CBZ degradation efficiency than did the ball/ PMS/LC system $( 8 5 \% > 7 3 \% )$ ), and the membrane, $\mathrm { \cdot P M S / H _ { 2 } A }$ system also showed a higher CBZ degradation efficiency than did the membrane/ PMS/LC system $9 0 \% > 7 2 \%$ . For the $\mathrm { P M S } / \mathrm { H } _ { 2 } \mathrm { A }$ based system, the performance of the catalytic membrane was greater than that of the ball $( 9 0 \% > 8 5 \% )$ , while the CBZ degradation efficiency was similar for both the catalytic ball and membrane in the PMS/LC system $( 7 3 \% { \sim } 7 2 \% )$ . This can be explained by the following factors. First, the membrane has a greater CBZ adsorption capacity than the balls, which is beneficial for the degradation of CBZ in the $\mathrm { P M S } / \mathrm { H _ { 2 } A }$ based system. Second, compared with catalytic membranes and balls, LC plays a pivotal role in the activation of PMS, thus serving as the crucial step for CBZ degradation in PMS/LC-based systems. Furthermore, the recycling and reuse experiments (Fig. S10) confirmed that all the PMS/LC- and $\mathrm { P M S / H _ { 2 } A } \cdot$ . based systems were highly stable and efficient for the degradation of CBZ based on the minimal decrease $( < 1 0 \% )$ observed in these systems.

# 4. Conclusions

In this research, the BC-CuFeO/PMS system demonstrated a moderate CBZ degradation efficiency $( 3 0 \% )$ , which was further improved to $8 0 \%$ and $5 8 \%$ by the addition of $\mathrm { H _ { 2 } A }$ or LC, respectively, under the conditions of $0 . 3 { \ g } / \mathrm { L }$ nanomaterials, $4 \mathrm { m g } / \mathrm { L }$ CBZ, 1 mM PMS, $0 . 5 \mathrm { m M } \mathrm { H } _ { 2 } \mathrm { A }$ or $0 . 5 \mathrm { m M }$ LC. The Taguchi results revealed the following sequence for the impact of the parameters on CBZ degradation efficiency in the $\mathrm { B C - C u F e O / P M S / H _ { 2 } A }$ system: initial solution $\mathrm { p H } > \mathrm { C B Z }$ concentration $>$ PMS concentration $>$ nanomaterial dosage $\mathrm { > H _ { 2 } A }$ concentration. Conversely, in the BC-CuFeO/PMS/LC system, the order of significance was LC concentration $>$ initial solution $\mathrm { p H } >$ nanomaterial dosage $>$ PMS concentration $\mathrm { > C B Z }$ concentration. A mechanistic study confirmed that $^ 1 0 _ { 2 }$ ,OH, $\mathrm { O } _ { 2 } ^ { \bullet - }$ ,and $S O _ { 4 } ^ { \bullet - }$ were the dominant species for CBZ removal in the BC-CuFeO/PMS/H2A system, while $0 \mathbf { \dot { 2 } } ^ { - }$ , $^ 1 0 _ { 2 } ,$ and ·OH were the major species in the BC-CuFeO/PMS/LC system. It has also been proven that both $\mathrm { H _ { 2 } A }$ and LC can promote the conversion of $\Longrightarrow { \mathrm { F e } }$ (III) and ${ \equiv } \mathrm { C u ( I I I ) }$ to $\equiv \mathrm { F e ( I I ) }$ and ${ \equiv } \mathrm { C u ( I I ) }$ , which can continuously consume PMS for the generation of active species and further increase CBZ degradation efficiency. Additionally, degradation products and pathways were proposed in both systems, and the possible toxicity of these products was assessed through Toxicity Estimation Software Tool analysis. Furthermore, the easily recyclable catalytic membranes and balls exhibited high CBZ degradation efficiency and stability after three cycles of recycling. Overall, this work provides new insights for improving the removal efficiency of emerging contaminants in wastewater through sustainable and green approaches.
