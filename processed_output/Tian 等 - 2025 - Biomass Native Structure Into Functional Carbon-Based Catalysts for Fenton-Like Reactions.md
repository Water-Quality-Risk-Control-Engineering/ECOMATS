# Biomass Native Structure Into Functional Carbon-Based Catalysts for Fenton-Like Reactions

Wenje Tian,\* Jingkai Lin, Zhihao Tian, Selusiwe Ncube, Huayang Zhang, Emiliano Cortés,\* Hongqi Sun, and Shaobin Wang\*

Advancing biomass-derived carbon materials requires a systematic understanding of how distinct biomass structures influence their properties and functionality. To address this, eight 2D flaky and 1D acicular plant biomasses is systematically compared to synthesize pristine carbon, N-doped carbon, and cobalt/graphitic carbon for Fenton-like peroxymonosulfate (PMS) activation. Biomass pyrolysis under $5 \% \mathsf { N H } _ { 3 }$ generates surface N-doped amorphous carbon, facilitating a selective electron transfer pathway (ETP), where high N incorporation, specific surface area, and atomic-level control over O groups synergistically enhance its efficiency. While COOH groups contribute positively, excessive defects and $\scriptstyle \mathbf { c } = \mathbf { o }$ groups hinder ETP performance. Notably, compared to 2D biomass, 1D acicular biomass induces tubular carbon with lower $\scriptstyle \mathbf { c } = \mathbf { o }$ content, promoting the ETP regime. 2D flaky biomass facilitates Co nanoparticle incorporation in cobalt/graphitic carbon, where high contents of N, Co, defects, and oxygen groups $\scriptstyle 1 \mathsf { C } = 0 / \mathsf { C } - \mathsf { O } / \mathsf { C } \mathsf { O } \mathsf { O } \mathsf { H } )$ enhance sulfate radical $( \mathsf { S O } _ { 4 } ^ { \bullet - } )$ . dominated catalysis, whereas excessive $\mathsf { s p } ^ { 2 } \mathsf { C } _ { \mathrm { \ell } } ( > 7 5 { \mathrm { - } } 8 0 \mathsf { a t . } \% )$ negatively affects performance. Through structural characterization, mechanistic analysis, and quantitative linear fitting correlations, this study identifies biomass-derived key active site interactions governing electron transfer and $\$ 0_ { 4} ^ { \bullet- }$ -driven oxidation mechanisms. These insights establish a framework for sustainable, biomass-structure-driven carbon design for environmental catalysis.

# 1. Introduction

This era has experienced a significant escalation in the need for advanced materials, clean energy, food, and water, driven by the growth of the world population and the swift advancement of technological innovations.[1] The growing environmental and ecological issues arising from the utilization of petroleum-based chemicals and products have highlighted the importance of creating functional materials from natural resources. Biomass stands out as a particularly promising resource, owing to its inherent characteristics, renewable nature, and plentiful availability.[12] ${ \approx } 5 5 0$ gigatons of carbon (Gt-C) in biomass are distributed across various kingdoms of life, with plants accounting for the majority at ${ \approx } 4 5 0$ Gt-C.[3] Converting plant biomass to functional carbonaceous materials has been suggested as a sustainable way to help alleviate resource shortage, reduce waste accumulation, and mitigate global warming by biomass decomposition or burning.[4] Notably, the strategic utilization of biomass for carbon-based catalyst design is crucial, as carbon-based Fenton-like catalysis via peroxymonosulfate (PMS) activation has gained significant attention in recent decades for water decontamination.[5] The differences in material properties lead to varied PMS activation mechanisms and reaction pathways by biomass-derived carbon catalysts.[6] The reactive oxygen species (ROS), including hydroxyl $( ^ { \bullet } \mathrm { O H } )$ , sulfate $( \mathrm { S O _ { 4 } } ^ { \bullet - } )$ , superoxide ion $( \mathrm { O } _ { 2 } ^ { \bullet - } )$ radicals, and electrophilic singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , or electron-transfer processes (ETPs), represent multiple degradation pathways.[7]

Due to the high redox potential (2.53.1 V, vs NHE),18] $\mathrm { S O _ { 4 } ^ { \bullet - } }$ - based systems were demonstrated as the strongest oxidant, promoting the research for more effective and economical methods in efficiently generating $\mathrm { S O _ { 4 } ^ { \bullet - } }$ for removing refractory organic pollutants.[9] However, on the other hand, free radicals suffer from a short life $( 1 0 ^ { - 6 } { - } 1 0 ^ { - 9 } { \bf s } )$ ,[10] while other routes, such as ETP, overcome this lifetime limitation and exhibit a rapid pollutant removal[11] with mild oxidative potential. ETP also demonstrates strong selectivity and electrophilicity to remove electrons from electron-rich pollutants, and robust resistance to interference from complex aquatic surroundings.[11] Although there have been numerous reports of Fenton-like systems dominated by ETP, many of these systems have suffered from the generation of various ROS,[12] rendering the performance target-dependent with reduced selectivity. Selective ETP-based studies have been reported on carbon nanotubes[13] and bimetallic MOF-derived graphitic carbon-loaded dual-atom catalysts.[11] However, selective ETP mechanisms utilizing biomass-derived materials that offer much simpler and more sustainable synthesis than these catalysts have not been guided. To accommodate different mechanistic designs, we aim to control carbon-based catalytic systems tailored to realize $\mathrm { S O _ { 4 } ^ { \bullet - } }$ -based and ETP-based Fenton-like catalysis, employing a family of biomasses for systematic structure and performance optimization.

For carbon-based materials, different biomass structures can produce distinct morphological features, physicochemical properties, and surface functionalities. In addition to their structural tunability and cost-effectiveness, biomass-derived carbon materials offer environmental advantages, aligning with the principles of green chemistry and sustainable catalyst design. While biomass-derived carbon-based materials have been widely studied,[14] the existing research has focused on a specific biomass without comparing the impact of biomass native structures. Many natural plant biomasses exhibit unique microscale structures that are adapted to their environments, which also offer valuable opportunities for designing carbon-based materials. To date, limited efforts have been made to systematically correlate the intrinsic morphology of biomass precursors with the resulting carbon-based structures and the catalytic behavior in PMS activation systems. Here, we select eight ubiquitous plant biomasses of 2D flaky and 1D acicular structures to investigate the impacts on crbon-based material engineering and catalysis. Our findings indicate that the 2D and 1D biomass sources, impact the morphology (bulk or tubular), specific surface areas (SSAs), ratios and contents of functional O species $scriptstyle ( \mathrm { C = O } / \mathrm { C - O } )$ , and/or N contents, Co nanoparticles loading in pristine carbon, N-doped carbon or cobalt/graphitic carbon composites, which control the reaction pathway/efficiency in PMS activation. A carbonaceous Fenton-like catalysis with $100 \%$ selectivity in ETP was demonstrated, while a $\mathrm { S O _ { 4 } ^ { \bullet - } }$ -dominated pathway was observed in cobalt/graphitic carbon systems. Also, through thorough characterizations, experimental data, in-depth mechanism investigations, and linear fitting analysis, a comprehensive examination of multiple factors has been conducted for catalysis. Although correlations between active sites and PMS activation or reactive species have been reported or reviewed in carbon-based catalyst systems,[14] diverse experimental conditions (e.g., pollutant, oxidant, and catalyst types and their concentrations, catalyst surface properties) in different studies may result in fragmented insights on similar catalysts. This emphasizes the importance of correlating carbon properties with PMS activation performance and pathways in a comparable manner, which has been rarely explored experimentally in existing research on biomass-based carbons. This research not only underscores the significance of carefully selecting plant biomass for the development of carbon-based catalysts but also offers crucial guidelines for augmenting active sites and refining selective catalytic pathways in both amorphous and graphitic forms of carbon.

The functional electron-donating sites (e.g., N species,[26] C—OH, and COOH)[27] are equally important, which will be analyzed in Figure 5.

Possibly due to directional structure orientation for an electron flow, tubular morphology is considered beneficial for facilitating mass transfer and diffusion kinetics,[17] which may improve electron transfer in an ETP regime. Considering the wide applicability of carbon-based materials in electrocatalytic oxygen reduction reaction (ORR),[15,28] the performance of these samples is also compared. As depicted in Figure $4 \mathrm { l - n }$ , NC5 to NC8 delivers higher limiting disk current densities at $0 . 2 \mathrm { ~ V ~ }$ versus RHE, lower ring current, and lower $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ selectivity than NC1 to NC4. NC6 exhibits the highest limiting disk current among all catalyst systems and maintains the lowest $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ selectivity over a wide potential range of $0 . 2 \mathrm { - } 0 . 7 5 \mathrm { ~ V ~ }$ versus RHE, revealing a highly selective $4 \mathrm { e ^ { - } }$ pathway.

We assessed the oxidation capability of $\mathrm { C } 6 /$ , $\mathrm { N C 6 } /$ , and CoNC1/PMS systems by adding pure DMPO to the reaction solution. The peaks of oxidized DMPO were detected with high sensitivity (Figure S42, Supporting Information), in contrast to those shown in Figure 4j, which utilized $5 0 ~ \mathrm { m m }$ DMPO. In this condition, oxidized DMPO was also observed in NC6/PMS, but the peak intensity is the weakest, indicating the milder oxidation capability of the ETP regime, compared to $\mathrm { S O _ { 4 } ^ { \bullet - } }$ with high oxidation potential. In contrast, Co-NC1/PMS, despite the higher oxidation ability indicated by EPR, showed lower TOC removal of phenol, which would release some degradation products into water. Therefore, $\mathsf { s p } ^ { 2 } \mathrm { \sf C }$ content, and defect level worked differently for PMS activation and pathway generation in NCi and Co-NCi. This difference may arise from the different electronic properties in amorphous or graphitic carbon forms. In graphitic carbon, $\mathsf { s p } ^ { 2 }$ C with delocalized $\pi$ -electrons is conducive to electrical conductivity and can donate free electrons to PMS.[30] However, if $\mathsf { s p } ^ { 2 } \mathsf { C }$ content is very high (e.g., $7 5 - 8 0 \mathrm { a t . } \%$ in CoNC2-8 in this study), the $\pi$ -electrons are highly delocalized over the extended planar sheets of the lattice, which contributes to the structure stability and inertness[31] and impedes surface catalytic reactions. Co-NC1 with lower $\mathsf { s p } ^ { 2 } \mathsf { C }$ content $( 6 3 \mathrm { a t . \% } )$ showed better performance in Co-NCi, with its higher structural defects, O, N atoms to break the inertness and continuity of the delocalized $\pi$ -electron system and create unpaired localized electrons to improve surface reactivity and interact with reactants. That illustrates the highly positive role of surface O, N doping, and defects in Co-NCi. This was also verified by representative electrochemically active surface area (ECSA) results (Figure 5kn). Except for Co-NC1, the ECSAs of these catalysts typically adhere to the following hierarchy: NCi>Ci>Co-(N)Ci. NCi exhibit the highest ECSAs, offering a larger area for the reversible adsorption of reaction species, thereby enhancing the pathway for exclusive ETP. Co-(N)Ci catalysts with higher $\mathsf { s p } ^ { 2 } \mathrm { \sf C }$ contents possess lower ECSAs and reduced areas available for catalysis. The introduction of additional N, O, and defects can enhance the ECSAs in Co-(N)Ci, leading to increased catalytic activity, as evidenced by Co-NC1. As for the beneficial impact of Co content in Co-NCi, previous results indicate that Co-C interaction facilitates electron transfer from Co to surrounding C atoms.[16b] This electron mobility may facilitate electron donation from C to PMS, potentially promoting $\mathrm { S O _ { 4 } } ^ { \bullet - } / \mathrm { E T P }$ .

By contrast, in amorphous carbon like NCi, the random distribution of $\mathsf { s p } ^ { 2 }$ and $\mathsf { s p } ^ { 3 }$ hybridized carbon atoms[32] results in varying levels of electron delocalization and localization. Consequently, the overall contribution of $\mathsf { s p } ^ { 2 } \mathrm { ~ C ~ }$ content in NCi is less significant compared to that in graphitic Co-NCi, particularly since active sites such as pyridinic/pyrrolic/oxidized N species, and COOH groups play key roles in ETP. However, the high defect levels present in amorphous NCi can impede the delocalization of $\pi$ -electrons, negatively affecting conductivity and thus reducing the electron transfer capability.[33] The role of functional groups also depends on the catalyst's structure and surrounding chemical environment (e.g., composition, $\mathsf { s p } ^ { 2 } \mathrm { \ : C }$ content, metal introduction). For instance, COOH promotes the ETP pathway in NCi, whereas in Co-NCi, it contributes to both ETP and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ generation.

These results also highlight the significant impact of biomassnative structures on the engineering of both pristine and Ndoped carbon materials (Scheme 2). 2D white flower biomass excels over colored flower biomass, and the lightweight 1D pappus from plant seeds excels over 2D/1D plant flower biomass in producing Ci with higher SSAs, which are beneficial for PMS activation. The 2D/1D shape of the biomass also critically determines the carbon's morphology and O species content. Specifically, 1D acicular biomass leads to the production of tubular carbon featuring lower ETP-detrimental $\scriptstyle \mathrm { C = O }$ contents compared to the bulk carbon derived from 2D flaky plant biomass. 1D pappus in seeds of Sow thistles is most favorable for NCi preparation. The tubular carbon morphology in NCi also facilitates electron transfer to support ETP in NCi/PMS system. When preparing cobalt/graphitic carbon, 2D faky biomass benefits Co nanoparticle loading, especially the Ipomoea nil flower.

# 3. Conclusion

This work, based on the study of eight biomasses, highlights the critical impact of biomass selection, specifically native structure in terms of color, 2D, or 1D shape, on the engineering and performance of carbonaceous catalysts. 2D white rose outperforms 2D colored flowers, while 1D seed fluff shows advantages over 2D flaky or 1D acicular flowers in producing carbon materials with higher SSAs. Seed fuff from Sow thistles demonstrated the synthesis of C6 and NC6 with the highest performance among Ci and NCi. Compared to the four 2D biomasses, the four 1D plant biomasses produce lower surface $\scriptstyle \mathrm { C = O }$ contents and tubular structure in resultant Ci and NCi. Flaky flowers, especially Ipomoea nil, allow for higher Co nanoparticle loading in Co-NCi. In catalysis, we demonstrated that two types of efficient PMS activation mechanisms, i.e., selective ETP with tubular NC6/PMS and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ -dominated Co-NC1/PMS, achieving $9 0 . 5 \%$ and $6 6 . 7 \%$ TOC removal, respectively. Several factors were found to be beneficial for selective ETP by NCi/PMS, including high contents of COOH (1.652.45 at. $\%$ , N (5.087.91 at. $\%$ , tubular structure, PMS adsorption, high SSA, and high equilibrium potential, whereas high $\scriptstyle \mathrm { C = O }$ content $( 1 . 7 4 - 7 . 2 3 ~ \mathrm { a t . } \% )$ and defect level (1.281.42) are detrimentral to ETP. Pyrolysis of biomasses in $\mathrm { N H } _ { 3 }$ is a simple approach for producing surface N-doped carbon with selectie ETP for PMS activation, while 1D biomasses are advantageous to 2D counterparts for producing lower $\scriptstyle \mathrm { C = O }$ species and the tubular structure. The high defect level (0.861.00), in combination with higher N content, O content (2.41—5.28 at. $\%$ , $\mathrm { C - O / C O O H / C = O }$ groups, and high Co content $( 2 . 5 5 \mathrm { - } 7 . 6 3 ~ \mathrm { w t . } \% )$ , boosts the reactivity of graphitic Co-NCi, while a high $\mathsf { s p } ^ { 2 }$ C content $( > 7 5 - 8 0 \ \mathrm { a t . } \% )$ is not conducive. Moving forward, this work not only provides a framework for enhancing active sites and catalytic mechanisms in amorphous and graphitic carbons but also sets a precedent for future research exploring the pivotal role of native biomass structure in designing carbon catalyst functionality for environmental catalysis.

The working electrode was prepared as follows: $4 \ m g$ of catalyst was mixed with $2 0 0 ~ \mu \iota$ isopropanol and $5 ~ \mu \ L$ Nafion 117 solution by ultrasonic treatment. Then, $6 ~ \mu \iota$ of the catalyst ink was dropped onto a glassy carbon electrode. Then, chronopotentiometry analysis was carried out to monitor OCP changes. Later, $5 . 7 \mathrm { \ m w \ P M S }$ and $2 0 \mathrm { m g } \lfloor - 1$ phenol were involved to see OCP changes. The $\mathsf { p H }$ values were monitored after PMS or phenol addition. A saturated $\mathsf { A g } / \mathsf { A g C l }$ electrode and a Pt wire were used as the reference and the counter electrodes, respectively. $$
\mathsf { E } _ { \mathsf { R H E } } = \mathsf { E } _ { \mathsf { A g / A g C l } } + 0 . 0 5 9 \mathsf { p H } + 0 . 7 9 7
$$

The $\mathsf { C } _ { \mathrm { d } | }$ was evaluated according to the $\%$ slope values of the fitted lines, based on equation $\mathsf C _ { \mathrm { d } | } = ( \mathsf \Delta _ { \mathrm { a } } \mathsf { - } \mathsf { I } _ { \mathrm { c } } ) / 2 \mathsf { V } _ { \mathrm { s } } ,$ [34] where $\mathsf { V } _ { \mathsf { s } }$ was the scan rate, $\mathbf { \rho } ) _ { a }$ was the anodic current density, and $\mathsf { J } _ { \mathsf { c } }$ was the cathodic current density.

Electrochemical ORR tests were carried out on a CHI760E electrochemical workstation in a three-electrode system. An RRDE (PINE Research Instrumentation, USA) with catalysts, $\mathsf { A g } / \mathsf { A g C l }$ electrode (saturated KCI solution), and platinum foil were used as the working, reference, and counter electrodes, respectively. The catalyst ink was prepared as follows. First the catalyst $( 4 ~ \mathsf { m g } )$ was dispersed into the mixture of $2 0 0 \mu \iota$ isopropyl alcohol, and $5 \mu \ L$ Nafion solution $( 5 \mathrm { w t . \% } )$ . After at least 30 min of sonication, $5 \mu \ L$ of the ink was drop-cast onto the RRDE electrode and dried at room temperature. For ORR activity and ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ selectivity investigation, LSV curves were recorded with a scan rate of $\bar { 1 0 } \mathsf { m } \mathsf { V } \mathsf { s } ^ { - 1 }$ in $\mathrm { O } _ { 2 }$ -saturated $0 . 1 ~ \mathsf { M }$ KOH solution. The rotating speed was 1600 rpm, and a fixed potential of $1 . 2 \vee$ versus RHE was applied to the $\mathsf { P t }$ ring electrode. The ORR activity and ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ selectivity of the catalysts were also corrected by subtracting corresponding curves measured in $\mathsf { N } _ { 2 }$ -saturated $0 . 1 \mathrm { ~ w ~ } \mathsf { K O H }$ .

$$
H _ { 2 } O _ { 2 } \ ( \% ) = 2 0 0 * ( I _ { r } / N _ { C } ) / \left( \left| I _ { d } \right| + I _ { r } / N _ { C } \right)
