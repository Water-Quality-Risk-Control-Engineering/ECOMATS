# Multi-channel electron transfer induced by polyvanadate in metal-organic framework for boosted peroxymonosulfate activation

Received: 11 March 2024

Accepted: 9 August 2024

Published online: 22 August 2024

# Check for updates

Ming-Yan Lan1,5, Yu-Hang Li 2,5, Chong-Chen Wang 1 , Xin-Jie Li1 , Jiazhen Cao3 , Linghui Meng1 , Shuai Gao2 , Yuhui Ma4 , Haodong Ji 2 & Mingyang Xing 3

Catalytic peroxymonosulfate (PMS) activation processes don’t solely rely on electron transfer from dominant metal centers due to the complicated composition and interface environment of catalysts. Herein the synthesis of a cobalt based metal-organic framework containing polyvanadate $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ cluster, $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ $( \mathsf { b p y } = 4 { , } 4 ^ { \prime }$ -bipyridine), is presented. The catalyst demonstrates superior degradation activity toward various micropollutants, with higher highest occupied molecular orbital (HOMO), via nonradical attack. The X-ray absorption spectroscopy and density functional theory (DFT) calculations demonstrate that Co sites act as both PMS trapper and electron donor. In situ spectral characterizations and DFT calculations reveal that the terminal oxygen atoms in the $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ electron sponge could interact with the terminal hydrogen atoms in PMS to form hydrogen bonds, promoting the generation of ${ \bf S } { \bf O } _ { 5 } { \bf \Psi } ^ { * }$ intermediate via both dynamic pull and direct electron transfer process. Further, $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ exhibits long-term water purification ability, up to $4 0 \mathrm { h }$ , towards actual wastewater discharged from an ofloxacin production factory. This work not only presents an efficient catalyst with an electron sponge for water environmental remediation via nonradical pathway, but also provides fundamental insights into the Fenton-like reaction mechanism.

Fenton-like reactions triggered by peroxydisulfate (PDS) or peroxymonosulfate (PMS) activation were verified to be promising technology for water purification, profiting from the production of radicals and/or non-radicals via interacting between persulfates and active centers1–5 . Up to now, many efforts were devoted to directionally adjusting the oxidation mechanism or pursuing higher electron transfer efficiency during the Fenton-like reactions6–8 . However, beyond the reciprocating from the transition metal centers, the PDS/PMS activation processes might be induced by electron transfer by other components, which required fine regulation of catalysts from the molecule or even atom level.

Metal-organic frameworks (MOFs), as versatile inorganic-organic hybrid materials, could be finely tuned from molecule level9,10. Besides functional organic linkers, some polyoxometalate (POM) clusters could be used as inorganic linkers to construct special MOFs with unique properties11–14. Recently, a few MOFs containing POM were used in the fields of $\mathbf { C O } _ { 2 }$ reduction reaction15, hydrogen evolution reaction16 and solar cell17, benefiting from that POM as electron reservoir or sponge could presumably capture, reserve and transfer electrons to create various sorption sites and catalytic centers. However, PMS molecules owned more complicated chemical structure than those of $\mathbf { C O } _ { 2 }$ and $\mathsf { H } _ { 2 } \mathbf { O }$ . Therefore, it was expected that the catalytic environment near the interface of POM-based MOF was complicated due to the presence of unsaturated coordination oxygens, leading to that the PMS activation process might rely on other interactions like multielectron channel and inter-molecular forces rather than solely on electron transfer of transition metal centers. Therefore, it was interesting to explore the catalytic PMS activation mechanism for the subsequent direct regulation of catalyst structure and the investigation of structure-activity relationship.

In this work, a polyoxovanadate-based $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ was fabricated to achieve PMS activation for organic pollutants degradation, which could facilitate to investigate the relationship between the complex surface coordination environment of catalyst and Fenton-like reaction. This study affirmed that charge transfer between PMS and metal sites in metal-based catalysts was not the only activation pathway. The density functional theory (DFT) calculations exhibited that it was difficult to form the high-spin complexes between weak-field PMS and Co centers as the optimal sorption sites, implying that source of charge transfer was not just the metal center. In situ Raman and Fourier transform infrared (FTIR) illustrated the dynamic variation of O-H bond from PMS and metal-O/N bonds $( { \bf C o - O } / { \bf N }$ and V-O) as well as electron transfer between $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ and PMS during the Fenton-like reaction, which promoted the formation of $S O _ { 5 } \mathrm { ^ { \bullet - } }$ to further produce singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ and sulfate radicals $( { \mathsf { S O } } _ { 4 } ^ { \bullet - } )$ for ofloxacin (OFX) oxidation. Nonradical dominated oxidation mechanism helped $\mathrm { C o } _ { 2 } ( \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } )$ $( \mathsf { b p y } ) _ { 2 }$ to exhibit superior long-term treatment ability toward actual wastewater and satisfactory detoxification ability feedback from biological experiments. This work opened a door for designing and synthesizing catalysts with electron sponge like POM cluster to accomplish nonradical pathways for water purification.

# Characterizations of $\mathbf { C o } _ { 2 } ( \mathbf { V } _ { 4 } \mathbf { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 }$

The single crystal structure (CCDC 2323958) was analyzed to affirm the identical structure of as-prepared $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ to the previous ones18 , in which ${ \mathsf { C o } } ^ { 2 + }$ is five-coordinated by two nitrogen atoms from bpy and three oxygen atoms from three different $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ clusters. It was observed that six terminal oxygen atoms in $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ are coordinated to six different ${ \mathsf { C o } } ^ { 2 + }$ atoms via ${ \bf C o ^ { - } O }$ bonds, and the other two terminal oxygen atoms are uncoordinated (Supplementary Fig. 1 and Supplementary Table 1). The powder X-ray diffraction (PXRD) patterns (Fig. 1a) of as-prepared $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ matched well with the simulated ones from CCDC 2323958 and 152985, implying high purity of the catalyst used in the successive tests and determinations. The optical microscope image (Fig. 1b) showed that $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ displayed yellow clump crystal with the micron scale, which was affirmed by scanning electron microscopy (SEM) image (Supplementary Fig. 2). High-resolution transmission electron microscopy (HR-TEM) affirmed the exposed facet (3 3 2) of $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ (Fig. 1c and Supplementary Fig. 3). The corresponding elemental mapping (Fig. 1d) displayed uniform distribution of characteristic elements like Co, V, N, and O.

The chemical state and coordination environment of Co and V were investigated using X-ray adsorption near edge structure (XANES) and extended X-ray absorption fine structure (EXAFS) spectra. The Co (Fig. 1e) and V (Fig. 1f) element K-edge XANES combined with k-space and fitted data (Supplementary Fig. 4) illustrated that the valence states of Co and V were near $^ { + 2 }$ and $+ 5$ , respectively. The EXAFS spectra (Fig. 1g) indicated that Co atoms from $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 }$ were coordinated to O and N atoms with the bond length of $1 . 5 6 \mathring \mathrm { A }$ (Peak I). In addition, no Co clusters or crystalline particles was presented in $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ structure due to that no obvious peak of the ${ \mathsf { C o } } { \mathsf { - C o } }$ bond at 2.18 Å were observed19, which matched well with the results of crystal structure analyses. The EXAFS spectra of $\mathsf { V }$ element (Fig. 1h) demonstrated that V-O bond (Peak II) with the length of $1 . 2 8 \mathring { \mathbf { A } }$ was different from those of $\ V _ { 2 } 0 _ { 3 } \left( 1 . 5 4 \mathring { \mathbf { A } } \right)$ and $\ V _ { 2 } 0 _ { 5 } \left( 1 . 5 4 \mathring { \mathsf { A } } \right)$ , illustrating that the interactions between V and O atoms in $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ were stronger than those in $\mathsf { V } _ { 2 } \mathsf { O } _ { 3 }$ and ${ \bf V } _ { 2 } { \bf O } _ { 5 }$ . The wavelet transform (WT) of $\mathrm { C o } _ { 2 } ( \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } )$ $( \mathsf { b p y } ) _ { 2 }$ was performed to further clarify the above-mentioned peaks. As illustrated in Fig. 1i and Supplementary Fig. 5, the peaks at $3 . 6 7 \mathring { \mathbf { A } } ^ { - 1 }$ and $3 . 8 1 \mathring { \mathsf { A } } ^ { - 1 }$ of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ sample could be ascribed to $\mathbf { \left. C o - O / N \right. }$ and V-O bonds, respectively. The WT plots of Co foil, V foil and the single crystal structure determination results revealed that no Co-Co and V-V bond could be observed in $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ .

# Catalytic activity and involved oxidation mechanism

OFX was selected as target micropollutant to investigate the PMS activation performance of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ . The PMS activation abilities of different systems were investigated without adjusting pH $\mathrm { ( p H = 6 . 3 8 ) }$ (Fig. 2a and Supplementary Figs. 6, 7). The $\mathrm { C o } _ { 2 } ( \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } )$ $( \mathsf { b p y } ) _ { 2 }$ displayed the best PMS activation for OFX degradation with the biggest reaction apparent rate constant $( k _ { \mathrm { o b s } } )$ of $2 . 7 2 \mathrm { { m i n } ^ { - 1 } }$ (Supplementary Fig. 8a), which was further affirmed by PMS consumption experiments (Supplementary Fig. 8b). Additionally, ca. $4 8 . 5 \%$ of total organic carbon (TOC) removal could be achieved within $5 . 0 \mathrm { { m i n } }$ in $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 } / \mathrm { P M S }$ system (Supplementary Fig. 8c), verifying the better mineralizing capacity of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ than ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ and ${ \bf V } _ { 2 } { \bf O } _ { 5 }$ . The $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ could also accomplish ultra-high elimination efficiencies toward other organic micropollutants like tetracycline (TC), bisphenol A (BPA), 3,4-dichlorophenol (3,4-DCP), chloroquine phosphate (CQ), and sulfamethoxazole (SMX) (Fig. 2b and Supplementary Fig. 8d), in which the corresponding $k$ -value $( \mathsf { m i n } ^ { - 1 } \mathsf { M } ^ { - 1 } )$ surpassed almost all reported catalysts for PMS activation (Fig. 2c and Supplementary Table 3). It was affirmed that $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ displayed good reusability (Fig. 2d). Only slight decline of catalytic activity could be observed after five recycles’ operation, possibly due to that some active sites are occupied by the formed intermediates (Supplementary Fig. $9 ) ^ { 2 0 }$ . The leaching Co $( 0 . 0 6 5 \mathrm { m g L ^ { - 1 } } )$ and V $( 0 . 0 8 4 \mathrm { m g L ^ { - 1 } } )$ were far below the environmental quality standards for surface water (GB 3838-2002), indicating the great water stability of catalyst. Also, the observations of PXRD patterns, FTIR spectrum, SEM image and HR-TEM image affirmed the decent stability of $\mathrm { C o } _ { 2 } ( \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } )$ $( \mathsf { b p y } ) _ { 2 }$ (Supplementary Fig. 10a–d).

While negligible influence on catalytic OFX degradation efficiencies could be observed when TBA and BQ were added. Additionally, the immobilized $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ ensured the catalyst stability during the reaction process (Supplementary Fig. 30a, b), in which the leached Co $( < 0 . 3 \mathrm { m g L ^ { - 1 } } )$ and $\mathsf { V }$ $( < 0 . 3 5 \mathrm { m g L ^ { - 1 } } )$ concentrations were far below the maximum pollutant level target set by the Chinese National Standard (Co: GB 3838-2002; V: GB 26452-2011). The PXRD pattern (Supplementary Fig. 31) and SEM image (Supplementary Fig. 32) of the used $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ after the reaction matched well with the fresh sample, demonstrating the stable phase, composition and morphology of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ . Meanwhile, the TOC removal efficiency could reach about $50 \%$ within $4 8 \mathrm { h }$ in $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 } / \mathrm { P M S } /$ pure water system (Supplementary Fig. 30c), implying that OFX could be partly mineralized into $\mathbf { C O } _ { 2 }$ and $\mathsf { H } _ { 2 } \mathbf { O }$ . These results confirmed that the $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ catalyst possessed great potential for practical application.

# Catalytic sites identification and excitation mechanism

DFT calculations were utilized to construct $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 }$ bulk model with spin parallel, which was more stable than spin antiparallel (Supplementary Fig. 33). The $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ surface model (Supplementary Fig. 34a) was constructed along the (0 0 1) crystal facet, in which Co atoms adjacent the vacuum layer were unsaturated coordination sites. The EPR exhibited an obvious response at $g = 2 . 0 0 3$ (Supplementary Fig. 34b), affirming the existence of vacancies39. Generally, the electron accumulation area might be more likely to act as the catalytic center40. The results of density of states and partial density of states (PDOS) indicated that electron occupied orbital near Fermi level $( E _ { \mathsf { F } } )$ were mainly attributed to the contribution of Co 3d, V $3 d$ and O $2 p$ orbitals (Supplementary Fig. 35), in which electronic state of Co $_ { 3 d }$ displayed obvious split due to the Jahn-Teller effect (Supplementary Fig. 35b). Six possible PMS sorption models (Supplementary Figs. 36, 37) were built to calculate adsorption energy $( E _ { \mathrm { a d s } } )$ , considering that both Co and V could be seen as the potential sorption sites to interact with PMS. As shown in Fig. 3a, Co sites from $\mathrm { C o } _ { 2 } ( \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } )$ $( \mathsf { b p y } ) _ { 2 }$ surface bonded with O1 from PMS, and the hydrogen bond was formed between the terminal hydrogen of PMS and the terminal oxygen of $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ . The $E _ { \mathrm { a d s } }$ was calculated to be −1.57 eV, much more negative than those of other models, confirming that Co-O1 (Co-PMS\*) was the optimal sorption model.

Based on optimal model, the corresponding electron density difference was calculated. Figure 3b indicated that PMS could draw electron (0.35 e) from the surface of catalyst, in which the electron accumulation area mainly focused on hydrogen bond rather than peroxo O-O bond (Fig. 3c). To further investigate the source of electron for PMS activation, the $\complement 0 \ 4 d$ orbital electron distribution was calculated based on Hund’s rule and Pauli exclusion principle (Fig. 3d). Although Co sites were regarded as the optimal sorption sites toward PMS, weak increase of spin states after PMS adsorption indicated that high-spin complexes with strong oxidation potential were not facilely formed. Therefore, Co sites might not be considered as the only electron transport centers, which was also consistent with the analyses results of PDOS. As shown in Fig. 3e and Supplementary Fig. 38, all the Co 3d, O $2 p$ and $\textsf { V } 3 d$ orbitals presented distinct blue shift, indicating that PMS could draw electrons from Co, O, V atoms. Mulliken charge population results (Fig. 3f) indicated that H atom in PMS model after adsorption could obtain more electrons than those of other atoms in original PMS model. The bond length of O-H bond of PMS after adsorption was longer than that of pristine one (Supplementary Fig. 39), while the bond length of peroxo O-O bond nearly remain constant. The above-mentioned results indicated that O-H bond of PMS was easier to be broken than peroxo O-O bond during activation process, due to the pull of hydrogen bond and charge transfer, which was further confirmed by the Gibbs free energy diagrams (Supplementary Fig. 40). To investigate the significant role of hydrogen bond, PMS adsorption model without hydrogen bond was built and calculated. It was found from Supplementary Fig. 41 that the $E _ { \mathrm { a d s } }$ of PMS adsorption model with hydrogen bond was higher than that of PMS adsorption model without hydrogen bond $( - 1 . 1 5 \mathrm { e V } )$ , illustrating that PMS adsorption pattern with hydrogen bond was easier to be formed from thermodynamic perspective. To further affirm the role of hydrogen bond interaction, $\mathsf { F } ^ { - } \left( \mathsf { N a F } \right)$ with biggest electronegativity was introduced into the reaction system to compete with O from $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ for forming hydrogen bond. The introduction of $\mathsf { F } ^ { - }$ led to the noticeable inhibition of OFX degradation efficiency and rate (Supplementary Fig. 42), due to that $\mathsf { F } ^ { - }$ could prefer to interact with O-H from PMS to form strong hydrogen bond to decrease the formation of hydrogen bond between PMS and catalyst. It was deemed that Co cations as the PMS sorption sites also played the key role during the Fenton-like reaction. As shown in Supplementary Fig. 43, ethylene diamine tetraacetic acid and phosphate were selected to shield the Co sites to further inhibit the PMS sorption process. As expected, both the OFX elimination performances and PMS consumption decreased, confirming the significant contribution of Co sites. In addition, the PMS activation ability of V sites based on the $\mathbf { { V } } { \cdot } \mathbf { { O } } _ { 2 }$ model was also investigated (Supplementary Fig. 37e). As shown in Supplementary Fig. 44a, 0.13 e could be transferred from the surface of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ to PMS. Supplementary Fig. 44b indicated that the electron accumulation area mainly focused on hydrogen bond rather than peroxo O-O bond in PMS, which was similar to Co-O1 model. Moreover, the dual sites PMS adsorption model was also constructed (Supplementary Fig. 45). The antibonding orbital formed between the adsorption site and PMS was filled with more electrons due to the blue shift of the $d$ -band center41,42, which further led to the deterioration of the PMS adsorption ability (Supplementary Fig. 46a, b). As shown in Supplementary Fig. 47a, the $E _ { \mathrm { a d s } }$ of dual sites PMS adsorption model was lower than that of individual Co or V sites. It was interesting that PMS activation didn’t merely rely on electron transfer from Co metal sites in $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 } / \mathrm { P M S }$ system, due to that the electron transfer number (0.37 e) from catalyst to PMS was not altered (Supplementary Fig. 47b). The decrease of $E _ { \mathrm { a d s } }$ signified that the formed active species were more susceptible to desorption, which was more conducive to achieve PMS activation.

# Discussion

In all, $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ , a MOF containing polyvanadate was fabricated to be used as PMS activator for the first time to accomplish efficient elimination of micropollutants with high HOMO via nonradical pathway. The synergistic effect between Co sites and $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ led to enhanced catalytic rate of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ toward OFX, about 25.16 and 39.37 times higher than those of ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ and ${ \bf V } _ { 2 } { \bf O } _ { 5 }$ . The oxidation mechanism dominated by nonradical pathway endowed $\mathrm { C o } _ { 2 } ( \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } )$ $( \mathsf { b p y } ) _ { 2 }$ good environmental tolerance, in which different co-existing ions and pH (3.12−8.04) could not produce influence on PMS activation efficiencies. In addition, $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 } / \mathrm { P M S }$ system exhibited satisfactory long-time treatment of $4 0 . 0 \mathrm { h }$ toward actual wastewater. The diameters of inhibition zones experiment against E. coli indicated good detoxification ability of $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ as PMS activator. Significantly, various experiments, characterizations and DFT calculations were performed to verify the multiple host-guest interactions on complicated interface of catalyst. DFT calculations integrated with XAS affirmed that Co sites played key role for PMS trap. However, interfacial $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ with the properties of electron sponge and robustness led to the generation of strong interaction between terminal O from $[ \mathsf { V } _ { 4 } \mathsf { O } _ { 1 2 } ] ^ { 4 - }$ and terminal H from PMS, which was confirmed by DFT calculations, In situ FTIR and In situ Raman technologies. Formed hydrogen bond provided directional electron transfer channel for catalyst, and the dynamic pull process promoted the generation of key $S 0 _ { 5 } { ^ * }$ intermediate, which was beneficial to produce ${ } ^ { 1 } { \bf O } _ { 2 }$ for micropollutant degradation. Furthermore, this activation mechanism was also suitable to other POM-MOFs/PMS systems. This work provided a good case to fabricate efficient catalyst/activator containing polyoxometalate for the purpose of water purification. In future, more efforts will be made to clarify the catalytic performances and mechanisms of more MOFs with different POM clusters, and to tap the possibility of their application for large-scale water environment remediation.

# Synthesis of $\mathbf { C o } _ { 2 } ( \mathbf { V } _ { 4 } \mathbf { O } _ { 1 2 } ) ( \mathbf { b p y } ) _ { 2 }$

The matrix of 0.2 mmol $\mathrm { C o } ( \mathsf { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathsf { H } _ { 2 } \mathrm { O }$ $( 5 8 . 2 \mathsf { m g } )$ , $0 . 4 \ : \mathrm { m m o l }$ bpy $( 6 2 . 5 \mathrm { m g } )$ , 0.4 mmol $\mathsf { N H } _ { 4 } \mathsf { V O } _ { 3 }$ $4 6 . 8 \mathrm { m g } )$ and $1 3 . 0 \mathrm { m L }$ distilled water was transferred into a $2 5 . 0 \mathrm { m L }$ Teflon lined autoclave, which was heated at $1 7 0 . 0 ^ { \circ } \mathrm { C }$ for $7 2 . 0 \mathrm { h }$ . The purple-brown $\mathrm { C o } _ { 2 } ( \mathrm { V } _ { 4 } \mathrm { O } _ { 1 2 } ) ( \mathrm { b p y } ) _ { 2 }$ crystals were harvested after the autoclave was cooled to room temperature, which were dried in an oven at $6 0 . 0 ^ { \circ } \mathrm { C }$ for $1 2 . 0 \mathrm { h }$ after being washed by distilled water and ethanol18. The detail characterization technologies were listed in Supplementary Notes 3 and 11.

# Catalytic activity test

The performances of the various catalysts for PMS activation and pollutant degradation were evaluated by OFX as the model recalcitrant pollutant. All experiments were conducted in a $6 0 . 0 \mathrm { m L }$ reactor with a constant stirring of 200.0 rpm under room temperature, in which $0 . 2 \mathrm { g } \mathrm { L } ^ { - 1 }$ catalyst and $0 . 1 \mathsf { m M }$ PMS were added into $5 0 . 0 \mathrm { m L }$ of aqueous solution containing pollutant with initial concentration of $1 0 . 0 \mathrm { m g l ^ { - 1 } }$ . The residual concentrations methods were provided in Supplementary Note 4. The pH values ranging from 2.0 to 11.0 of the targeted solution were adjusted with ${ \sf H } _ { 2 } { \sf S } { \sf O } _ { 4 }$ or NaOH solutions with suitable concentrations. All the experiments were carried out at least three times.

# DFT calculation details

In this study, the first-principles calculations under frame of DFT were performed using Materials Studio 2020 (CASTEP module)54. The exchange-correlation energy was described by the Perdew–Burke–Ernzerhof (PBE) form of generalized-gradient approximation (GGA) exchange-correlation energy functional55. The energy cutoff was set as $5 0 0 \mathrm { e V }$ and the $k$ -point spacing was set to be smaller than $0 . 0 5 \mathring { \mathsf { A } } ^ { - 1 }$ $\boldsymbol { \mathbf { \mathit { k } } }$ -point was $\mathbf { 1 } \times 2 \times \mathbf { 1 }$ ). The spin state and $\mathsf { D F T } + \mathsf { U }$ were considered due to the existence of Co and V, in which the U value of Co and V was set as 3.2 and 2.5, respectively56. The convergence standards for optimizing crystal geometry like energy tolerance, maximum force tolerance, maximum stress tolerance and maximum displacement tolerance were less than $2 . 0 \times 1 0 ^ { - 5 } \mathrm { e V }$ atom−1 , $0 . 0 3 \mathrm { e V } \mathring { \mathbf { A } } ^ { - 1 }$ , 0.1 GPa and $0 . 0 0 2 \mathring { \mathbf { A } }$ . The specific calculation items were presented in Supplementary Note 10.
