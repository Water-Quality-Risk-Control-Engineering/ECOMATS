Iron-based heterogeneous Fenton systems have been widely proposed for recalcitrant contaminants degradation. However, low efficiency of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition and Fe(II)/Fe(III) recycling quite limited their applications. In this work, Co-doped iron sulfide (FeS) was successfully prepared through a modified hydrothermal method, and characterized by XRD, FESEM, HRTEM, XPS and BET. With $\operatorname { C o } ( \operatorname { I I } )$ substitution, FeS structure transformed from pyrrhotite to mackinawite. The $1 0 \%$ Co-FeS was highly effective in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation toward Rhodamine B (RhB) degradation. The pseudo first-order kinetic constant of $1 0 \%$ Co-FeS was $0 . 3 2 3 ~ \mathrm { m i n ^ { - 1 } }$ , which was 31.4 and 85 times higher than that of $\mathbf { C o S } _ { 2 }$ and FeS, respectively. Quenching experiments and EPR analysis illustrated that •OH was the dominant radicals for RhB degradation and the role of $\operatorname { C o } ( \operatorname { I I } )$ in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ direct decomposition was negligible. Batch experiment suggested that the excellent catalytic performance of $1 0 \%$ Co-FeS were ascribed to: (i) Co incorporation into FeS structure facilitated electron transfer between S species and $\mathrm { F e ^ { 3 + } }$ , thus accelerating Fe(II)/Fe(III) conversion on the surface, and (ii) more active sites were exposed. The Co-doped FeS exhibited high stability with low Fe/Co leaching and great recyclability. This novel strategy brought potential insights to develop highly efficient catalyst like metal sulfides for wastewater treatment.

# 1. Introduction

Advanced oxidation processes (AOPs) have obtained considerable attraction in the treatment of recalcitrant organic pollutants [1–3]. Hydroxyl radicals (•OH) with high redox potential $( \mathrm { E } ^ { 0 } = 1 . 9 – 2 . 7 \mathrm { ~ V } )$ and no-selective activity can effectively destroy organic pollutants through in situ chemical oxidation (ISCO) processes [4,5]. Fenton reaction is the most common strategy to produce •OH generated from the decomposition of hydrogen peroxide. In traditional homogeneous Fenton systems, ferrous ion $( \mathrm { F e ^ { 2 + } } )$ has been recognized as the efficient catalyst, but its recycling from $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e ^ { 2 + } }$ is the primary rate-limiting step, leading to low efficiency of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition [6–8]. In addition, other drawbacks, such as acid pH reaction condition $\mathrm { ( p H } = 3 . 0 $ ) and secondary sludge, also quite limited its application [9,10]. To eliminate these negative effects, iron-based heterogeneous Fenton process has occurred with plentiful advantages like a wide range of $\mathsf { p H }$ and no residual iron ions in water [4,11,12]. However, low activity of iron-based heterogeneous Fenton catalysts is still a great challenge in ISCO treatments due to insufficient active sites and low efficiency of Fe(II)/Fe(III) recycling on the surface [6,13]. According to aforementioned above, whether homogeneous Fenton process or heterogeneous Fenton process, how to mediate $\mathrm { F e } ^ { 3 + } { \cdot } \mathrm { t o } { \cdot } \mathrm { F e } ^ { 2 + }$ conversion for improving $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition efficiency is the core problem in practical applications.

Over the past decade, various methods to promote Fe(II)/Fe(III) recycling in iron-based AOPs have been widely investigated. Zhang’s group has systematically studied the effect of one category of reductive reagents in the degradation of refractory organic contaminants. They found that protocatechuic acid [14] and ascorbic acid [15–17] could simultaneously form stable complexes with dissolved iron to hamper their precipitation, as well as facilitate the reduction of $\mathrm { F e ^ { 3 + } }$ back to $\mathrm { F e ^ { 2 + } }$ in homogeneous Fenton systems, thus enhancing •OH generation. Besides, ascorbate and hydroxylamine could also promote iron cycle on the surface of goethite [18], hematite [15], magnetite [17] and nano zerovalent iron [16] in heterogeneous Fenton systems. Though these reductive reagents were highly effective to achieve the aim, they might cause secondary pollution risk due to residual solvents and were comparatively expensive. Consequently, some reductive metal sulfides (e.g., $\mathbf { M o S } _ { 2 }$ , ${ \sf W S } _ { 2 }$ and $\mathrm { C r } _ { 2 } S _ { 3 } .$ ) [6,19,20] and zerovalent metals (e.g., Mo and W) [21] as “co-catalysts” have gradually gained more and more attentions. Xing et al. [6] revealed that the exposed reductive metallic sites could reduce $\mathrm { F e } ^ { 3 + }$ by external electron transfer on the surface to accelerate the rate-limiting process of Fe(II)/Fe(III) recycling. Similarly,

Tang et al. reported that bimetallic composites like ${ \mathrm { C u F e O } } _ { 2 }$ [22,23] and ${ \mathrm { C u F e S } } _ { 2 }$ [24] exhibited strong synergistic effect between $\mathrm { F e ( I I I ) / F e ( I I ) }$ and $\mathsf { C u ( I I ) / C u ( I ) }$ cycles in PMS activation, inferring that $\mathrm { { C u ^ { + } } }$ or $\ S ^ { 2 - }$ species on the surface might act as an electron donor for $\mathrm { F e ^ { 3 + } }$ reduction. Thus, the introduction and development of reductive species in Fenton systems is of great significance to improve the efficiency of Fe(II)/Fe(III) recycling and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition.

Iron sulfide (FeS) is an ubiquitous mineral in natural environments [25]. Generally, its crystalline phase appears to be pyrrhotite structure when the proportion of sulfide species is larger than that of mackinawite structure [28]. Due to its abundant Fe(II) and S(-II) that can serve as electron donors, FeS has been considered as a crucial reductant for the attenuation of metals or metalloids (e.g., Cr, Hg, U and As) and halogenated organic compounds [26–28]. Moreover, FeS can also be an effective activator for some peroxide activation toward organic contaminants oxidation. It was reported that mackinawite could be applied as a heterogenous catalyst to activate persulfate for $p$ -chloroaniline and 2,4-dichlorophenoxyacetic acid degradation in a wide pH range (3.0- 11.0) [29,30]. Gao et al. delineated that Zn modified pyrrhotite named as $\mathrm { F e } _ { 0 . 7 } \mathrm { Z n } _ { 0 . 3 } S$ achieved rapid phenol degradation at room temperature [31]. However, mackinawite, a metastable phase of FeS, could not be a great heterogeneous catalyst and has low stability because it is easy to dissolute to ferrous ions and $\mathrm { H } _ { 2 } S$ in acid condition [32]. And pyrrhotite, a stable phase of FeS, is instead of a perfect catalyst due to its very low activity [31]. Hence, both of them are not ideal phase for practical application of FeS as a heterogeneous catalyst in AOPs. Therefore, the designation and preparation of FeS catalyst with high reactivity and great recyclability is highly desired in AOPs application.

In this work, a series of Co-doped FeS were successfully prepared through a modified hydrothermal method and were characterized by X-ray diffraction (XRD), field emission scanning electron microscopy (FESEM), high-resolution transmission electron microscopy (HRTEM), X-ray photoelectron spectroscopy (XPS) and Brunauer–Emmett–Teller (BET). We investigated the effect of Co doping on the activity of FeS in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation toward the degradation of model contaminant, Rhodamine B. Effects of different experimental parameters (initial pH, catalyst loading, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration, various contaminants and coexisting substances) in Co-doped FeS catalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ systems were systematically studied. The underlying mechanism was proposed by quenching experiments and EPR analysis. Recycle experiments were designed to testify the reusability of catalyst and the mineralization efficiency of RhB was also evaluated by analyzer of total organic carbon (TOC). This strategy brought potential insights to develop highly efficient iron sulfide catalyst for wastewater treatment.

# 2. Materials and methods

# 2.1. Materials

$\mathrm { C o S O } _ { 4 } { \bullet } 7 \mathrm { H } _ { 2 } 0$ , $\mathrm { F e S O } _ { 4 } { \bullet } 7 \mathrm { H } _ { 2 } 0$ , $\mathrm { C u S O } _ { 4 } { \bullet } \mathrm { S H } _ { 2 } 0$ , $\mathrm { Z n S O } _ { 4 }$ , HCl, NaOH, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $3 0 \ \mathrm { w t \% } )$ ), ethanediamine, thioacetamide (TAA), ethanol (EtOH) and tert-butanol (TBA) were obtained from Sinopharm Chemical Reagent Co. Ltd. Rhodamine B and 5,5-dimethyl-2-pyrolin-N-oxide (DMPO) were supplied by Sigma-Aldrich. All the reagents were of analytical grade without further purification. All the aqueous solutions were prepared by deionized (DI) water $( 1 8 . 2 5 \Omega \mathrm { c m } )$ ).

# 2.2. Sample preparation

The Co-doped FeS samples were prepared through a modified hydrothermal synthesis method [31]. In a typical preparation, $1 8 \ \mathrm { m m o l }$ $\mathrm { F e S O } _ { 4 } { \bullet } 7 \mathrm { H } _ { 2 } 0$ and 2 mmol $\mathrm { C o S O } _ { 4 } { \bullet } 7 \mathrm { H } _ { 2 } 0$ were blended with $5 0 ~ \mathrm { m L }$ DI water under magnetic stirring. Then, $1 0 \mathrm { m L }$ ethanediamine and $2 5 \mathrm { m m o l }$ TAA were added into the above aqueous solution. After a further stir for $3 0 \mathrm { m i n }$ , the suspension was kept into a $1 0 0 ~ \mathrm { { m L } }$ Teflon-lined autoclave, sealed and treated at $2 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 0 \mathrm { ~ h ~ } }$ . The solid sample obtained was washed with ethanol and DI water for 10 times, and dried at $6 0 ^ { \circ } \mathrm { C }$ for 12 h in vacuum oven. Ultimately, the samples with different ${ \bf C o } / ( { \bf C o } + { \bf F e } )$ molar ratios were named as $\mathbf { X } \%$ Co-FeS $\left( \mathbf { x } = 2 \right.$ , 5, 7, 10, 15, 20, respectively). For comparison, FeS and $\mathbf { C o S } _ { 2 }$ were prepared by the similar process.

# 2.3. Characterization

The details were provided in Supporting Information (Text S1). And the content of Co in the synthesized samples was determined through acid dissolution by 1:1 HCl (Table S3).

# 2.4. Degradation procedures

All experiments were conducted in $5 0 ~ \mathrm { m L }$ conical flasks on magnetic stirrers at room temperature. In brief, the reactions were started by adding $1 0 ~ \mathrm { m g }$ catalyst and $0 . 1 ~ \mathrm { m L }$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (0.5 M) solution into $5 0 ~ \mathrm { m L }$ of $5 0 ~ \mathrm { m g / L }$ RhB aqueous solution in sequence. 0.1 M HCl and NaOH was used to adjust the initial pH of RhB solution. At selected time intervals, $1 . 0 ~ \mathrm { m L }$ suspension was taken out, immediately filtered through $0 . 2 2 \ \mu \mathrm { m }$ membrane, and finally quenched with $2 . 5 ~ \mathrm { m L }$ ethanol. Then, the concentration of RhB was measured by UV-vis spectrophotometry at $5 5 4 \mathrm { n m }$ wavelength [33]. To evaluate the recyclability of Co-doped FeS, they were separated from the solution after each reaction, subsequently washed with ethanol and DI water, and ultimately dried in vacuum oven for next reuse. All experiments were conducted in dark by covering foil paper on vessels.

# 3.1. Characterization

As shown in Fig. 1a, the XRD patterns of all as-synthesized samples were indexed to FeS crystalline phase. Interestingly, with the doping of Co, the crystalline structure of FeS transformed from pyrrhotite to mackinawite. As shown in Fig. S1, the XRD pattern of cobalt sulfide in hydrothermal reaction was indexed to $\mathbf { C o S } _ { 2 }$ phase according to the standard card (PDF#41-1471) [35,36]. With increasing doping dosage of Co, the crystallinity of pyrrhotite phase was gradually decreasing and an apparent right shift in both of FeS phases (Fig. 1b) was observed, indicating that crystal size of Co-doped FeS became smaller and Co atom successfully substituted Fe atom in the structure of FeS.

# 3.2. $H _ { 2 } O _ { 2 }$ activation by Co-doped FeS for RhB degradation

The catalytic efficiency and adsorption performance of synthesized samples were evaluated by removal of the target contaminant Rhodamine B with or without $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ addition. As illustrated in Fig. 4b and d, with the increase of doping dosage of Co on FeS, RhB adsorption performance was relatively promoted from $1 . 4 \%$ to $2 4 . 8 \%$ . Such improvement suggested that Co doping may fragmentize the nanoparticles and lead to the exposure of substantial active sites, which can be demonstrated by FESEM images and BET analysis. As presented in Fig. 4a, drastic RhB degradation was detected with the addition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Almost $9 9 . 5 \%$ removal was observed by all samples with the incorporation of Co after 35-min reaction at $\mathsf { p H 3 . 0 }$ , which was much higher than by FeS $( 1 7 . 7 \% )$ and $\mathbf { C o S } _ { 2 }$ $( 3 4 . 5 \% )$ alone, respectively. Apparently, the doped Co was of great significance in affecting the catalytic reactivity of $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ toward RhB degradation. As revealed in Fig. 4c, the pseudo first-order kinetic constant for the reaction systems upon the Co doping percentage of $2 \%$ , $5 \%$ , $7 \%$ , $1 0 \%$ , $^ { 1 5 \% }$ and $2 0 \%$ on FeS were 32.7-, 41.9-, 40.1-,

85.2-, 56.8- and 39.2-fold than that of bare FeS, respectively. For bare $\mathbf { C o S } _ { 2 }$ , adsorption was the dominant way for RhB removal (Fig. 4d). It was obviously found that the Co doping brought about a volcano-type effect on the degradation rate and the optimal Co doping percentage was $1 0 \%$ . However, the effect cannot be simply elucidated by the BET analysis (Table S1) in which the specific surface area of synthesized samples increased proportionally with the increase of Co doping percentage. Consequently, an in-depth study below has been carried out to unravel the mechanism.

# 3.3. Identification of reactive oxygen species (ROS)

Quenching experiments were carried out to identify the main reactive oxygen species of $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system. Ethanol (EtOH) and tertbutyl alcohol (TBA) are regarded as two common scavengers of hydroxyl radicals. EtOH could react with •OH with a higher rate constant $( \mathbf { k _ { E } } = 1 . 2 – 2 . 8 \times 1 0 ^ { 9 } \ \mathbf { M } ^ { - 1 } \ s ^ { - 1 } )$ than that of TBA $( \mathbf { k } _ { \mathrm { T } } = 3 . 8 { - } 7 . 6 \times 1 0 ^ { 8 }$ $\mathbf { M } ^ { - 1 } \thinspace s ^ { - 1 } )$ [41-44]. As seen in Fig. 5a, RhB degradation was significantly suppressed with the addition of EtOH and TBA, suggesting that •OH was the dominant ROS in RhB oxidation. Utilizing spin-trapping agent DMPO to trap ROS in the aqueous solution, the EPR experiments were conducted to further confirm the presence of hydroxyl radicals and the catalytic performance of various catalysts. As presented in Fig. 5b, the EPR signals agreed well with the four characteristic peaks of DMPO•OH (the intensity ratio of 1:2:2:1) [18], indicating the production of hydroxyl radicals in different systems. It was worth noting that the signals strength of DMPO-•OH in $\mathrm { C o S _ { 2 } / H _ { 2 } O _ { 2 } }$ system was indistinct, implying that the transition metal of Co was not the dominant active species to decompose $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in this system. Furthermore, it was observed that the signals strength of DMPO-•OH in Co-FeS catalyzed heterogeneous Fenton system was much stronger than that in $\mathrm { F e S } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ system. Furthermore, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition was increasing with the increase of Co doping dosage (Fig. S8). These results demonstrated that hydroxyl radicals were the main ROS and the incorporation of Co into FeS structure significantly promoted the decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ toward RhB degradation.

# 3.4. Effects of reaction parameters

The influence of catalyst dosage on the degradation of RhB was examined in Fig. 6a. With increasing catalyst dosage from $0 . 0 5 ~ \mathrm { g / L }$ to 0.3 $_ { \textrm { g / L } }$ , the degradation degree of RhB increased from $9 3 . 5 \%$ to $9 9 . 9 \%$ and the degradation kinetic rate also increased quickly. This enhancement was on account of more active sites, which active $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to generate more amounts of reactive oxygen species for RhB degradation. Apparently, $0 . 2 ~ \ g / \mathrm { L }$ catalyst loading was enough for the complete removal of RhB. As illustrated in Fig. 6b, RhB degradation was remarkably promoted with increasing $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentrations (range from $0 . 2 ~ \mathrm { m M }$ to $1 . 0 ~ \mathrm { m M } )$ . However, further promotion was not conspicuous at the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration up to $2 . 0 \ \mathrm { m M }$ because of the quenching of radicals by excessive $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [53]. Therefore, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration was optimized as $1 . 0 \mathrm { m M }$ for next experiments.

The impacts of initial pH on RhB degradation were displayed in Fig. 6c. It was observed that the catalytic performance of $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system was pH-dependent with the $\mathtt { p H }$ range from 2.0 to 6.0. At pH 2.0, 3.0 and 4.0, RhB was completely removed after $3 5 \mathrm { { m i n } }$ . However, only $9 2 . 6 \%$ and $5 2 . 4 \%$ of RhB degraded at $\mathrm { p H } 5 . 0$ and $\mathrm { p H } 6 . 0$ in the same experimental condition, respectively. And the change of solution $\mathtt { p H }$ during reaction was negligible at initial $\mathrm { p H } 3 . 0$ (not shown). It has been reported that the generation of $\mathrm { F e O H ^ { 2 + } }$ , reactive species for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation, might be restrained at too low or too high pH values [27].

The generated radicals were scavenged very rapidly by massive $\mathrm { H ^ { + } }$ at pH below 3.0 and ferric hydroxide precipitate might be formed on the surface of catalyst at $\mathsf { p H }$ values over 4.0 [19]. Hence, a suitable initial pH was 3.0 for the following degradation experiments.

For the sake of examining widespread application of the catalyst, variety of contaminants with various functional groups were utilized to study their degradation efficiency in $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system. As depicted in Fig. 6d, several typical organic pollutants including RhB, Organic Acid II (AOII), Methylene Blue (MB) and Bisphenol S (BPS) were chosen to testify their degradation degree. Surprisingly, the degradation efficiencies of RhB, AOII, MB and BPS in $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system reached up to $9 9 . 9 \%$ , $9 2 . 1 \%$ , $1 0 0 \%$ and $1 0 0 \%$ , respectively. Besides, $1 0 \%$ CoFeS showed the greatest performance for RhB degradation than other modified FeS catalysts (such as $1 0 \%$ Cu-FeS and $1 0 \%$ Zn-FeS) synthesized through the same methods. These results demonstrated that Codoped FeS was assuredly an excellent catalyst, which could be applied for the non-selective oxidation of different recalcitrant organic pollutants in heterogeneous Fenton process.

# 3.5. Effects of the coexisting substances

The effects of these substances on RhB degradation were evaluated in Fig. 7. In general, effects of anions on RhB degradation in $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system followed the order: $\mathrm { P O } _ { 4 } { } ^ { 3 - } >$ $\mathrm { C l ^ { - } } > \mathrm { N O _ { 3 } } ^ { - } > \mathrm { S O _ { 4 } } ^ { 2 - }$ . In addition, phosphate existed in metal-based heterogeneous Fenton system usually resulted in strong inhibitory effect [47], and its effect was observed in Fig. 7d. The RhB degradation efficiency decreased to $4 7 . 5 \%$ when $1 \mathrm { m M P O } _ { 4 } { } ^ { 3 - }$ was added. And the degradation rate further declined to $1 9 . 3 \%$ with the addition of $1 0 0 \mathrm { m M P O } _ { 4 } { } ^ { 3 - }$ . This result could be clarified by two factors. One was that the reaction between $\mathrm { P O } _ { 4 } { } ^ { 3 - }$ and •OH could produce phosphate radicals, which were less reactive than •OH. The other was that $\mathrm { P O } _ { 4 } { } ^ { 3 - }$ could occupy the active sites on the catalyst surface, and restrained the adsorption of RhB and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , thus impeding the decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . It might be expected that HA would exhibit inhibitory effect like $\mathrm { P O } _ { 4 } { } ^ { 3 - }$ , since HA has abundant electrons and is easily attacked by •OH [48]. The reaction between HA and •OH possesses a high constant $( \mathrm { k _ { H A } } = 3 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ [5], which exactly illustrated its adverse influence on the degradation of RhB in $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system.

# 3.6. Effects of FeS crystal phase transformation and specific surface area change on catalytic activity

As is well-known, the crystal phase and specific surface area (SSA) of materials are crucial roles in determining the catalytic activity for peroxide decomposition. Zhao et al. has synthesized $\mathsf { A g F e O _ { 2 } }$ nanoparticles with two crystal phases mixture to catalyze peroxymonosulfate (PMS) for Orange I removal [49]. They found that the reactivity of catalysts for PMS decomposition was closely related with 2H-phase ratio in $\mathsf { A g F e O _ { 2 } }$ nanoparticles. Similarly, Gao et al. has reported that a new phase, $\mathrm { F e S } _ { 2 }$ -pyrite, was formed when a spot of $\mathrm { Z n }$ was added into synthesis procedure of FeS-pyrrhotite. And the $\mathrm { F e S } _ { 2 }$ -pyrite were responsible for the enhanced phenol degradation [31]. Moreover, a higher SSA of catalyst usually means greater catalytic performance [50,51]. However, can these theories be applicable to this system?

# 3.7. Interaction between Fe, Co and $s$ species

To further explore the mechanism of RhB degradation in Co$\mathrm { F e S } / \mathrm { H } _ { 2 } 0 _ { 2 }$ system, it is imperative to identify the main active sites for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation and the underlying acceleration process of $\mathrm { F e ( I I ) / F e ( I I I ) }$ recycling on the catalyst surface. Though many studies have reported that cobalt-based materials (e.g., ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ and CoO) [52] and iron-based catalysts (e.g., reduced nontronite, $\mathrm { F e } _ { 3 } 0 _ { 4 } .$ ) [53–55] could effectively activate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ for several organic contaminants oxidation, the role of cobalt and iron in this system is still unclear. As illustrated in Fig. 9a, RhB removal efficiency was below $1 9 . 5 \%$ in 35 min in the presence of $0 . 5 \mathrm { m M }$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ with either individual $\operatorname { C o } ( \operatorname { I I } )$ , $\mathbf { C o S } _ { 2 }$ and FeS or $\operatorname { C o } ( \operatorname { I I } )$ with FeS. Notably, adsorption was the main removal way for RhB in $\mathrm { C o S _ { 2 } / H _ { 2 } O _ { 2 } }$ system according to the results presented in Fig. 4b. These results indicated that the contribution of Co species (either Co cations or structure Co) induced catalytic reaction to RhB degradation was little, thus Co species were not the main active species for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation in $\mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system. From studies mentioned above, the synergistic effect of $\operatorname { C o } ( \operatorname { I I } )$ doping on $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation cannot be entirely elucidated by FeS crystal phase transformation and the increase of specific surface area of synthesized samples. Consequently, we speculated that the acceleration of $\mathrm { F e ( I I ) / F e ( I I I ) }$ conversion could be the main reason for dramatically promotion of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation. Hence, further experiments were conducted to explore the role of Co and S species in the acceleration process of $\mathrm { F e ( I I ) / F e ( I I I ) }$ recycling. As displayed in Fig. 9b, physical mixture of FeSpyrrhotite with $\mathbf { C o S } _ { 2 }$ indeed exhibited remarkable synergistic effect on RhB degradation, whereas the performance of single FeS-pyrrhotite or $\mathbf { C o S } _ { 2 }$ was very poor. Previous studies reported that metal sulfides (e.g., $\mathbf { M o S } _ { 2 }$ , $\mathrm { W S } _ { 2 } )$ [6,19] could be superior co-catalysts for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation in AOPs, insisting that the exposure of $\mathrm { M o ^ { 4 + } }$ or $\mathsf { W } ^ { 4 + }$ species on the catalyst surface could immensely accelerate the Fe(II)/Fe(III) conversion. However, in this system, we thought that ${ \mathsf { C o } } ^ { 2 + }$ could not reduce $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e ^ { 2 + } }$ because it was thermodynamically unfavorable $( \mathrm { E } _ { \mathrm { F e ( I I I ) / F e ( I I ) } } = 0 . 7 7 \mathrm { \ V } ;$ $\mathrm { E } _ { \mathrm { C o ( I I I ) / C o ( I I ) } } = 1 . 9 2 \ \mathrm { V } )$ [5,24]. This result suggested that S species could be the main electron donors, while behave differently in various metal sulfides. As depicted in Fig. $9 \mathbf { c }$ , nearly all dissolved Fe(III) was rapidly reduced to $\mathrm { F e ( I I ) }$ by ${ \mathrm { C o } } S _ { 2 }$ , but the Fe(III) reduction percentage by FeS was just $1 0 \%$ suggesting S species in $\mathbf { C o S } _ { 2 }$ were more reductive than those in FeS. In addition, the Fe(III) reduction percentage was increased to $4 4 . 3 \%$ with only $1 0 \%$ Co doping. This result also supported that the reactivity of S species could be greatly promoted by the small amount of doped Co in FeS structure.

As mentioned above, the role of Fe, Co and S species and the synergistic effect of Co doping on FeS in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation could be confirmed. Fe(II) was the main active sites in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation to generate hydroxyl radicals for RhB degradation. The role of $\operatorname { C o } ( \operatorname { I I } )$ in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ direct decomposition was negligible. The doping of Co modified the structure of FeS and led to S species in FeS structure more active, which dramatically improved the Fe(II)/Fe(III) recycling.

# 3.8. Reusability and stability of catalysts

For practical use, it is critical to evaluate the reusability and stability of catalysts. As shown in Fig. 10a, almost $1 0 0 \%$ RhB removal was achieved within $3 5 \mathrm { { m i n } }$ in four repeated runs. This result demonstrated that the Co doped FeS catalyst has excellent catalytic ability to activate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Besides, the leaching of metal ions should be concerned for their secondary pollution risks. As is well known, iron ion is not toxic and easy to precipitate but cobalt ion is poisonous in aquatic environment. In the stability assessment, the Co leaching concentration only reached at 0.79 $\mathrm { m g / L }$ after 1st run and $0 . 1 8 \mathrm { m g / L }$ after 3rd run (Fig. 10b), both of which were no more than $1 \ \mathrm { m g } / \mathrm { L }$ (the emission limit, GB 25467-2010), indicating that the catalysts have great stability. XRD patterns in Fig. 10c confirmed that the structure of Co-FeS did not obviously changed after several runs, also indicating that Co doped FeS catalyst has superb stability in water treatment application. As seen in Fig. 10d, $2 5 . 1 \%$ TOC removal for RhB was achieved in $1 0 \% \mathrm { C o - F e S / H _ { 2 } O _ { 2 } }$ system.

# 4. Conclusions

In summary, a series of Co-doped FeS samples were successfully prepared via a modified hydrothermal method. Co-doped FeS with Co percentage of $1 0 \%$ exhibited high activity, reusability and stability in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation toward the degradation of RhB and was superior to FeS without Co doping and $\mathrm { C o } S _ { 2 }$ . Radical quenching experiments and EPR analysis revealed that the dominant reactive oxygen species in RhB oxidation were hydroxyl radicals. It was Fe(II) not Co(II) that behaved as the main active sites for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation. Meanwhile, the synergistic effect of Co doping on FeS was observed, and could be mainly attributed to the structure modification by Co doping. The facilitated electron transfer between Fe and more active S species on catalyst surface ultimately resulted in acceleration of Fe(II)/Fe(III) conversion. Moreover, the Co doped-FeS kept high stability with low Fe and Co leaching, and great recyclability even after four runs. These results could provide a new idea for FeS structure modification and reconsideration of the interaction between transition metals and sulfur species, which could bring potential insights to develop highly efficient catalyst for wastewater treatment.
