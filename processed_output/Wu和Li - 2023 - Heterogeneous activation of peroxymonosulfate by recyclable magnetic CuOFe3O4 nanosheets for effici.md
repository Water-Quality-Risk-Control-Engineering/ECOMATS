In this work, recyclable magnetic $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ nanosheetswere successfully synthesized via a simple continuous precipitation method, which can effectively activate peroxymonosulfate (PMS) to decompose organic pollutants. The properties of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ nanosheets were measured by a series of characterization techniques. $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites showed highly effectiveness for PMS activation to degrade methyl blue (MB), and several influencing factors were investigated, such as initial $\mathsf { p H }$ , catalyst dosage, PMS concentration and reaction temperature. Although $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } / \mathsf { P M S }$ system exhibited effectiveness for MB degradation in a wide pH range, the natural $\mathsf { p H }$ value was the best. The increase in reaction temperature is favorable for MB degradation, and the activation energy was calculated as $4 0 . 3 4 ~ \mathrm { k J / m o l }$ . Quenching experiments and electron spin resonance (ESR) analysis proved that  OH, $S O _ { 4 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ were generated in the $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } / \mathsf { P M S }$ system, and $S O _ { 4 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ played the dominant role. Moreover, $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ remained good activity and stability after being recycled five times. In addition, the complete degradation of methylene orange (MO) and tetracycline hydrochloride (TC), and MB degradation in tap water and lake water further confirmed the wide applicability of the $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } / \mathsf { P M S }$ system. These results exhibited that $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system has great advantages of high removal efficiency, reusability and wide applicability, demonstrating its potential environmental application in the treatment of organic wastewater. $^ { © }$ 2023 The Author(s). # 1. Introduction

Usually, biological processes may be the first choice in the wastewater treatment, because of the effectiveness and costeffectiveness (Liu et al., 2022). However, conventional biological processes cannot effectively remove nonbiodegradable organic pollutants. So some new advanced oxidation processes (AOPs) have been developed to decompose the nonbiodegradable pollutants (Nguyen et al., 2020; Liu et al., 2023). Among them, sulfate radical $( \mathrm { S O } _ { 4 } ^ { - } )$ based advanced oxidation processes (SR-AOPs) have received increased attention (Li et al., 2022; Zhu et al., 2023; Zhang et al., 2020). $S 0 _ { 4 } ^ { - }$ has the higher oxidation potential and longer half-life than that of hydroxyl radical ( OH). Compared with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , persulfate, including peroxymonosulfate (PMS) and peroxodisulfate (PDS), has lots of advantages, suach as lower cost, higher security, easier storage and transportation.

PMS is an asymmetric structure peroxide, which can be activated by carbon-based materials (Wang et al., 2023) transition metals (Wang et al., 2023), UV radiation (Guerra-Rodriguez et al., 2021); heat (Yin et al., 2022), ultrasound (Gujar et al., 2023); microwaves (Qi et al., 2017). Transition metal ions were used to activate PMS for the degradation of organic pollutants (Wang et al., 2023; Song et al., 2022; Mohammed Al-Balawi et al., 2023). But there are some insurmountable drawbacks for the homogeneous phase of transition metal ions; such as the high pH dependence, unrecyclable flaw. Metal oxides as heterogeneous catalysts can overcome the above drawbacks (Nguyen et al., 2023; Liu et al., 2023). Therefore, metal oxides have been intensively developed for PMS activation. For example, magnetic $\mathsf { C o F e } _ { 2 } .$ - ${ { 0 } _ { 4 } }$ nanocrystals were prepared to activate PMS for the degradation of chloramphenicol (Yang et al., 2021) and for disinfection in different wastewater matrices (Rodriguez-Chueca et al., 2020). Nano$\mathsf { M o O } _ { 2 }$ exhibited excellent performance in activating PMS and the $\mathsf { M o O } _ { 2 } / \mathsf { P M S }$ system can effectively remove naphthalene derivatives in aqueous systems (Chen et al., 2021). $\mathtt { C u M n _ { 2 } O _ { 4 } }$ nanoparticles were utilized to activate PMS for the degradation of crystal violet (Farajollahi et al., 2023). Recently, CuO as PMS activator has attracted much attention due to its abundant reserves, low price, simple preparation and high catalytic ability (Wei et al., 2022; Yan et al., 2021; Wang et al., 2021; Qin et al., 2020; Wang et al., 2019). Spongelike porous CuO exhibited good performance in activating PMS for the degradation of Acid Orange 7 (Qin et al., 2020). A series of metal oxides (ZnO, NiO, $\mathsf { A l } _ { 2 } \mathsf { O } _ { 3 }$ , $\mathsf { F e } _ { 2 } \mathsf { O } _ { 3 }$ , $\mathsf { M n O } _ { 2 }$ , CuO, $\mathsf { C e O } _ { 2 }$ ${ \bf L } { \bf a } _ { 2 } { \bf O } _ { 3 }$ ) were synthesized by calcination method for PMS activation, and CuO showed a relatively higher performance in the degradation of 2, 6-dichlorophenol (Yan et al., 2021).

However, difficult recovery of $\mathtt { C u O }$ limited its application for PMS activation in aqueous systems. Therefore, the development of recyclable CuO-based heterogeneous catalysts is a meaningful thing. Due to the magnetic property, $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ was used as a support to obtain stable and magnetically recyclable heterogeneous catalysts (Li et al., 2023; Guo et al., 2023). Herein, $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ catalyst was prepared via a simple continuous precipitation method and used to activate PMS, which might simultaneously utilize the high catalytic property of CuO and the magnetic property of $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ . The morphologies and properties of the $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ catalyst were systematically characterized by scanning electron microscopy (SEM), transmission electron microscopy (TEM), X-ray diffraction (XRD) and X-ray photoelectron spectroscopy (XPS). The catalytic performance of the $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ catalyst as PMS activator was evaluated through decomposing methyl blue (MB). Several influencing factors were investigated, such as initial pH, catalyst dosage, PMS concentration and reaction temperature. Furthermore, the applicability and stability of the $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ were also evaluated. In addition, the reactive oxygen species (ROS) generated in the $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ were verified by the quenching experiment and EPR analysis.

# 2. Experimental section

# 2.1. Materials

Potassium peroxymonosulfate (PMS), Methylene blue (MB), Methyl Orange (MO), Tetracycline Hydrochloride (TC), isopropanol (IPA), tert-Butanol (TBA), L-Histidine (L-HIS), $\mathrm { F e S O } _ { 4 } { \cdot } 7 \mathrm { H } _ { 2 } 0$ , $\mathrm { C u S O _ { 4 } }$ - ${ \cdot } 5 \mathrm { H } _ { 2 } 0$ , NaOH and HCl were obtained from Sinopharm Chemical Reagent Co., Ltd. All of the reagents and solvents used in the experiment were commercially obtained without any purification. Deionized water (DI water, $1 8 . 2 \ \mathrm { \ M \Omega 2 c m } .$ ) applied for preparing aqueous solutions.

# 2.2. Preparation of the catalysts

The $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ catalyst was fabricated using a simple method. Typically, $5 . 0 \textrm { g F e S O } _ { 4 } { \cdot } 7 \mathrm { H } _ { 2 } 0$ was dissolved into $1 0 0 ~ \mathrm { { m L } }$ DI water under stirring. And pH value was adjusted to 12 using 1 mol/L NaOH solution. Then, the mixture was heated in a water bath at $7 0 \ \%$ for $^ { 2 \mathrm { ~ h ~ } }$ to obtain black precipitates of $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ . The $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ precipitates were collected and cleaned with DI water and ethanol for four times each, followed by drying under vacuum at $7 0 \ \%$ .

The $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ catalysts were prepared as follows: $2 0 0 ~ \mathrm { m g }$ asprepared $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ was uniformly mixed with $1 0 0 ~ \mathrm { { m L } }$ DI water with the aid of ultrasound, a certain amount of $\mathrm { C u S O } _ { 4 } { \cdot } 5 \mathrm { H } _ { 2 } 0$ was added into the solution under stirring. After $^ { 1 \mathrm { ~ h ~ } }$ , pH value of the mixture was adjusted to 12 using $1 \mathrm { m o l / L N a O H }$ solution. Then, the mixture was heated in a water bath at $7 0 \ \%$ for $^ { 2 \mathrm { ~ h ~ } }$ to obtain $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ catalysts. The $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ precipitates were collected and cleaned with DI water and ethanol for four times each, followed by drying under vacuum at $7 0 \ \%$ . The molar ration of CuO to $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ were set to 2:1, 1:1, 1:2, respectively. And as-prepared catalyst were named as $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 } – 2$ , $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 } \mathrm { - }$ 1, $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } – \mathsf { O } . 5$ , respectively. If there is no special instruction, $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ appeared in the following section was $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ -1.The CuO catalyst was prepared by the same process without adding $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ .

# 2.3. Material characterization

X-ray powder diffraction (XRD) pattern of samples were recorded on a powder $\mathsf X$ -ray diffractometer $\mathrm { ( D / m a x - } 2 2 0 0 / \mathrm { P C } ,$ Rigaku Corporation, Japan) with Cu Ka radiation, operating at $4 0 ~ \mathrm { k V }$ and $3 0 ~ \mathrm { { m A } }$ , where $\lambda = 0 . 1 5 4 1 8 \ \mathrm { n m }$ for the $\mathtt { C u } \mathtt { K } \mathtt { Q }$ line. XPS experiments were carried out on a RBD upgraded PHI-5000C ESCA system (Perkin-Elmer, USA), the shift of the binding energy due to relative surface charging was corrected using the C 1s level at $2 8 4 . 6 \ \mathrm { e V }$ as an internal standard. The structure and morphology of the coatings were investigated by the field emission scanning electron microscopy (FESEM, FEI SIRION 200, FEI, USA). The structure and the morphology of the catalyst powders were observed by Transmission Electron Microscope (TEM, JEM-100CX, JEOL, Japan).

# 2.4. Experimental procedure

The catalytic activity of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ was evaluated by degrading MB in the presence of PMS. Typically, $0 . 0 1 \mathrm { \ g } \mathrm { C u O } / \mathrm { F e } _ { 3 } 0 _ { 4 }$ was added into $1 0 0 ~ \mathrm { { m L } }$ MB solution $( 2 0 \mathrm { m g } / \mathrm { L } )$ under stirring. After adsorption equilibrium for $3 0 \mathrm { { m i n } }$ , PMS solution was added to trigger the oxidation process. Under continuous stirring, samples were taken at interval time, and immediately filtrated by a $0 . 2 2 ~ { \mu \mathrm { m } }$ syringe. The filtered fluid was instantly analyzed by a UV–vis spectrometer at $6 6 4 ~ \mathrm { { n m } }$ to measure the MB concentration. Each experiment was replicated three times.

# 3. Results and discussion

# 3.1. Characterization of catalysts

The morphologies of CuO, $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ and $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ were characterized by SEM (Figs. S1-S3). CuO owned sheet shape with a smooth surface (Fig. S1), and most $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ particles were agglomerated together due to the magnetic force (Fig. S2). $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ also exhibited sheet shape, but the surface is obvious rough, and the shape is irregular compared to CuO (Fig. S3). In addition, $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ also showed the sheet shape observed from the TEM images of $\mathtt { C u O } /$ $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ (Fig. 1a), and the lattice lines of $\mathtt { C u O }$ and $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ can be observed clearly in HR-TEM image (Fig. 1b). The lattice lines of $0 . 2 3 5 ~ \mathrm { n m }$ and $0 . 2 9 2 ~ \mathrm { { n m } }$ should be attributed to the (1 1 1) crystal plane of $\mathtt { C u O }$ and the (22 0) crystal plane of $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ , respectively. Furthermore, the elemental mapping test was carried out to further determine the composition of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ . According to the results (Fig. S4), Cu, Fe and O elements coexisted in the catalyst, and dispersed uniformly on the composite surface.

The catalytic performance of $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ was explored by the degradation of MB. As shown in Fig. 4, the MB removal though the adsorption of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ was negligible. The MB degradation by PMS without catalyst is no obvious. However, the $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } /$ PMS system can realize the complete the MB degradation in $3 0 ~ \mathrm { { m i n } }$ . The results demonstrated that $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ can effectively activate PMS to decompose MB. Meanwhile, $\mathrm { F e } _ { 3 } { 0 _ { 4 } } / { \mathrm { P M S } }$ showed equally poor oxidation performance with a removal efficiency of only about $1 2 \%$ (Fig. S5). And the proportion of $\mathtt { C u O }$ in $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites is higher, the catalytic performance of $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } /$ PMS is better for the degradation of MB. And all MB can be removed in 5 min by the CuO/PMS system (Fig. S5). Other studies also have verified that $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ has a weak catalytic activity to active PS or PMS, which often needs external energy, such as ultrasonic sound, ultraviolet light (Yang et al., 2021). These results certified that the outstanding performance of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ for PMS activation should be attributed to $\mathtt { C u O }$ . And the main role of $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ is to provide the magnetic property for $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites in our work, which is very convenient to recover the catalyst.

The effects of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ dosage and PMS concentration on the MB removal were studied, as shown in Fig. 5. MB degradation efficiency drastically enhanced with the increased $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ dosage (Fig. 5a). When $0 . 1 \ \mathrm { g } / \mathrm { L }$ of catalyst is added into the solution, it needs $3 0 ~ \mathrm { { m i n } }$ to completely remove MB. As the catalyst amount is increased to $0 . 2 0 \mathrm { \textrm { g } } / \mathrm { L }$ , MB can be completely removed in $1 0 \ \mathrm { m i n }$ . Subsequently, the degradation rate can be continuously improved by adding more $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ dosage $( 0 . 3 0 ~ \mathrm { g / L } )$ . The result is mainly because the increased catalyst may provide more reactive sites for PMS activation (Yang et al., 2021; Zhao et al., 2021). As a result, more reactive species can be produced for the rapid decomposition of MB. The effect of PMS concentration was showed in Fig. 5b. Firstly, the degradation rate of MB increased with the increase of PMS concentration form $1 \ \mathrm { m m o l / L }$ to $2 \ \mathrm { m m o l / L }$ . The reactive sites on the surface of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ will be more fully utilized with the increase of PMS dosage. Consequentially, more ROS can be produced to improve the removal efficiency of MB (Yang et al., 2021). In most cases, the highest degradation rate of pollutants via PMS/catalyst system is obtained under near-neutral conditions (Liu et al., 2023; Li and Wu, 2022; Zhen et al., 2021). Under acidic conditions, strong hydrogen bonds will be formed between excess $\mathrm { H } ^ { + }$ with O-O in PMS, which inhibit the reaction between catalysts and PMS. Thus it depresses the formation of ROS, and further reduce the degradation of pollutant. Besides, metal ions from metal oxides are easy to dissolve into the reaction solution under acidic conditions. But the leaching ions always have a weaker ability for PMS activation. In our work, the extreme acidic condition $( \mathsf { p H } = 2 . 2 1 $ ) is bad for PMS activation by $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites. And the MB removal efficiency was very tiny $( 1 4 . 1 \% )$ . Similar phenomenon was displayed in our previous work, the MB degradation in the $\mathtt { C u O } _ { \scriptscriptstyle \perp }$ /PMS system was negligible under extreme acidic condition $\left( \mathsf { p H } \approx 2 \right) ,$ ) (Li and Wu, 2022). On the other hand, although the increasing of OHions may accelerate PMS decomposition, the MB removal deceased from $1 0 0 \%$ at $\mathsf { p H } \ = \ 7 . 5 5$ to $8 5 . 2 \%$ a t $\mathsf { p H } = 1 2 . 1 0$ . The several reasons may lead to this result. Firstly, the $\mathsf { p K } _ { \mathsf { a } 2 }$ of PMS is 9.4, so PMS mainly exists in the form of $S 0 _ { 5 } ^ { 2 - }$ under strongly alkaline conditions $\mathrm { \langle p H } = 1 2 . 1 0 \mathrm { \rangle }$ . The isoelectric point (pHpzc) of the $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composite was about $\mathrm { p H } ~ 8 . 8$ (Zhen et al., 2021; Ding et al., 2020). Therefore, the surface of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ catalyst was negative under strongly alkaline conditions $\mathrm { ( p H } = 1 2 . 1 0 \mathrm { ) }$ . Consequentially, electrostatic repulsive forces are generated between PMS components and catalysts under strongly alkaline conditions $\mathrm { ( p H } = 1 2 . 1 0 $ ), preventing the generation of ROS. Secondly, inactive materials such as $S O _ { 4 } ^ { 2 - }$ will be formed through the hydrolysis of PMS under basic conditions (Eq. (5)) (Rastogi et al., 2009). In addition $S 0 _ { 4 } ^ { - }$ was easily converted to  OH under alkaline conditions (Eq. (6)), which had lower oxidation capacity and selectivity (Liu et al., 2023).

The operating temperature also affect the chemical reaction. Here the PMS activation at varying temperatures with/without $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites toward MB oxidation were comprehensively investigated. As presented in Fig. 7a, MB molecules can be degraded through thermally activated PMS without catalyst. The MB degradation rate was improved with the increase of reaction temperature. It was improved from $1 2 . 1 \%$ to $3 3 . 9 \%$ with increasing reaction temperature from 20 to $4 0 ~ \mathrm { ^ { \circ } C }$ . PMS can be activated by energy, and a higher reaction temperature can supply more energy to promote the decomposition of PMS into more ROS (Duan et al., 2018), resulting in the higher degradation of MB. Compared with the thermally activated PMS, the MB decomposition by PMS activation in the presence of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites was greatly improved (Fig. 7a). Similarly, the catalytic activity was also enhanced with the increasing reaction temperature. It took $2 5 ~ \mathrm { { m i n } }$ to completely degrade MB at $2 0 ^ { \circ } \mathrm { C } ,$ , while $1 0 ~ \mathrm { { m i n } }$ at $4 0 ~ \mathrm { ^ { \circ } C }$ . According to the first order kinetic model (Fig. S7), the rate constants were obtained. The rate constant is increased form $0 . 1 2 2 3 \mathrm { m i n } ^ { - 1 }$ at $2 0 ^ { \circ } \mathsf C$ to $0 . 3 5 0 1 \ \mathrm { m i n } ^ { - 1 }$ at $4 0 ^ { \circ } \mathsf C$ (Fig. S8). The molecular movement would be accelerated with the increase of temperature, the higher temperature may facilitate the mass transfer process of heterogeneous systems (Duan et al., 2018; Yu et al., 2022; Asif et al., 2021). In a word, the upper temperature is good for the MB degradation based on the above-mentioned reasons. In addition, the activation energy of this reaction measured by employing the Arrhenius equation (Eq. (7)) (Qin et al., 2020; Ma et al., 2018), where R is the molar gas constant (8.314472 J/(mol K)), T is the temperature (K), $\mathbf { k _ { o b s } }$ was the rate constant. The curve between $1 / \mathrm { T }$ and ln $\mathbf { k _ { o b s } }$ was plotted (Fig. 7b), and calculated Ea value is about $4 0 . 3 4 ~ \mathrm { k J / m o l }$ . The Ea value is lower than those of reported PMS-based systems, such as $\mathrm { C o _ { 3 } O _ { 4 } { - } B i _ { 2 } O _ { 3 } / P M S }$ $( 5 0 . 5 \ \mathrm { k J } / $ - mol), CoMnAl-metal oxides/PMS $( 7 6 . 8 ~ \mathrm { ~ k J / m o l } )$ and N-rGO/PMS $( 4 6 . 9 ~ \mathrm { { k J / m o l } ) }$ , indicating that the catalytic oxidation process in the $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system could be easily achieved (Qin et al., 2020).

To examine the wide applicability of this technology, the removal efficiencies of various organic pollutants and MB degradation efficiencies in different water bodies were explored respectively. Water bodies include tap water from our lab and lake water from the artificial lake on campus. MB, MO and TC were used as various organic pollutants. Details about the related process were described in the Supporting Information (Text S1 and Text S2). Fig. 8a presented the removal efficiencies of various organic pollutants in the $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system. Different pollutants have different molecular constructions and physicochemical characteristics, some differences in degradation efficiencies between pollutants are observed in the $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system. But all pollutants can be degraded effectively in $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system (Fig. S9). Surprisingly, it only took $1 0 \ \mathrm { m i n }$ to degrade most of MO. Fig. 8b exhibited MB degradation efficiencies in different water matrices. Clearly, the removal efficiencies of MB in different water matrices all are nearly $1 0 0 \%$ (Fig. S10). The apparent rate constants for MB degradation were calculated by the pseudo first order kinetic model (Fig. S11). The $\mathbf { k _ { o b s } }$ values for MB degradation were 0.2266, 0.1468 and $0 . 1 1 0 1 \ \mathrm { m i n } ^ { - 1 }$ in TW, DW and LW, respectively (Fig. S12). What‘s more, the existence of positive ions in the MB solution, such as $\mathrm { K } ^ { + }$ , ${ \mathsf { C a } } ^ { 2 + }$ , ${ { \ N } _ { { \bf { d } } } } ^ { + }$ , $\mathsf { M g } ^ { 2 + }$ , had no inhibition for the removal of pollutants by the $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system (Fig. S13), other researches had got the similar phenomenons (Zhang et al., 2023; Zhong et al., 2022).

The stability and reusability of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites were evaluated via cyclic experiment, which are very important for practical application. After each cycle, the used catalyst was collected by an external magnet (Fig. S14), and reused after drying. Details about the related process were described in the Supporting Information (Text S3). Observed from Fig. 9, the MB degradation efficiency was depressed along with the increase of number of cycle. The main reason should be that the pollutants adsorbed on the surface of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites gradually accumulated each cycle, thereby hindering the interaction between $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ composites and PMS molecules to produce ROS (Yang et al., 2021). Satisfactorily, the MB degradation efficiency still remained $7 7 . 4 8 \%$ after five runs. Meanwhile, the XRD pattern of $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites has no remarkable change (Fig. S15). The results demonstrated that $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ composites have good stability and reusability, highlighting the practicability in water remediation.

# 4. Conclusion

In summary, magnetic $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ nanosheets were facilely synthesized for PMS activation to achieve high-efficient degradation of organic pollutants. $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ showed the good catalytic performance in a wide pH range (4–12). Higher dosages of $\mathsf { C u O } / \mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } ,$ appropriate PMS concentration, higher reaction temperature and the neutral solution $\mathsf { p H }$ value were beneficial for MB removal. The radical quenching test and ESR showed that  OH, $S O _ { 4 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ were generated in the $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system, and $S O _ { 4 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ played the main role. In addition, $\mathsf { C u O } / \mathsf { F e } _ { 3 } 0 _ { 4 }$ could be collected by magnetic separation and reused with good performance. Moreover, other organic pollutants can be degraded completely in $\mathtt { C u O } /$ $\mathrm { F e } _ { 3 } { \cal O } _ { 4 } / \mathrm { P M S }$ system, and $\mathrm { C u O } / \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { P M S }$ system exhibited satisfactory removal of MB in real water matrix. In a word, high removal efficiency, the stability, reusability and wide applicability of $\mathtt { C u O } /$ $\mathrm { F e } _ { 3 } { \cal O } _ { 4 } / \mathrm { P M S }$ were good for its utilization in the environmental remediation.
