In the present study, comparison of activation efficiencies of hydrogen peroxide $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 } )$ and persulfate (PS, $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 } )$ induced by Fe(III)-Ethylenediamine- $\mathbf { \nabla } \cdot N , N ^ { \prime }$ -disuccinic acid (EDDS) under polychromatic irradiation UVA and visible region at same conditions was studied for the first time. The effects of $\mathsf { p H }$ , Fe(III)-EDDS concentration, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PS concentrations were investigated. $p$ -hydroxyphenylacetic acid $\scriptstyle ( p \mathrm { - H P A } )$ was taken as a model pharmaceutical intermediate pollutant to estimate the oxidative process efficiency. In these two systems, the degradation rate of $p$ -HPA increased (not linearly) using higher concentrated solution of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ . However, when $\mathrm { F e ( I I I ) }$ -EDDS concentration exceeding $2 5 0 ~ \mu \mathrm { M }$ , the degradation efficiency of $p$ -HPA began to decrease. Surprisingly, results of $\mathsf { p H }$ effects showed that Fe(III) $\mathrm { - E D D S / H _ { 2 } O _ { 2 } / U V }$ system presents much higher degradation efficiency than Fe(III)-EDDS/PS/UV whatever the solution pH’s, especially in neutral and alkaline solutions. In the $\mathrm { F e ( I I I ) { \cdot } E D D S / H _ { 2 } O _ { 2 } / U V }$ reaction, $p { \mathrm { - } } \mathrm { H P A }$ degradation rate $( \mathrm { R } _ { p - \mathrm { H P A } } )$ increased fast from $\mathrm { p H } 2 . 5$ to 7.5, then it began to decrease when pH increased to 9.0. While $\mathrm { R } _ { p - \mathrm { H P A } }$ started to decrease with pH increase to 3.9 in Fe(III)-EDDS/PS/UV system. To explain this phenomenon, the second order constant of $p { \mathrm { - } } { \mathrm { H P A } }$ (for both molecular and mono-anionic forms) with HO% and $s 0 _ { 4 } ^ { ~ \cdot ~ - }$ radicals were determined by laser flash photolysis (LFP) experiments for the first time. Results showed that $k _ { p - H P A , H O } \cdot$ was higher than $k _ { p - H P A , S O _ { 4 } ^ { * - } }$ for both anionic and molecular forms of pollutant. These results demonstrated that iron-complex induced photo-Fenton process is more efficient than activation of persulfate process, particularly at environmentally closed $\mathsf { p H }$ values and sunsimulated wavelengths $( \lambda > 3 0 0 \mathrm { n m } )$ .

# 1. Introduction

Wastewater treatments based on advanced oxidation processes (AOPs), which mainly depend on the generation of free radical species, have been extensively studied in the last two decades [1,2]. The reaction between $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { F e ( I I ) / F e ( I I I ) }$ is a well-known method for the generation of hydroxyl radicals $\mathrm { ( H O ^ { \cdot } ) }$ , including Fenton $\mathrm { ( F e ( I I ) / H _ { 2 } O _ { 2 } ) }$ [3,4], Fenton-like $\mathrm { ( F e ( I I I ) / H _ { 2 } O _ { 2 } ) }$ [5] and photo-Fenton (UV/Fe(III)/ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ processes [6–10]. With high oxidation abilities, HO% $( \mathbf { E } ^ { \circ } = 2 . 8 \mathbf { V } )$ has a wide application for removing environmental contaminants like endocrine disruptors, chlorophenols, dyes, pharmaceuticals and pesticides [4,11–13]. However, in recent years, studies on sulfate radical $\mathrm { ( } S 0 _ { 4 } \mathrm { ' ~ } ^ { - } \mathrm { ) }$ have proved that this radical is outstanding in degrading recalcitrant organic pollutants ascribing to its similar oxidation-reduction potential $( \mathrm { E } ^ { \circ } \ : = \ : 2 . 6 \mathrm { - } 3 . 2 \ : \mathrm { V } )$ ) [14], much longer half-life time and more selective reactivity compared with HO% . From previously reported literature data, the generation of $S O _ { 4 } ^ { \cdot - }$ usually derives from the activation of persulfate (PS) by heat [15], UV or transition metals [16–18]. Among these activation processes, methods involved $\boldsymbol { \mathrm { F e } ^ { \circ } }$ , $\mathrm { F e } ^ { 2 + }$ or $\mathrm { F e } ^ { 3 + }$ with or without UV are efficient, energy-saving and relatively nontoxic [18]. The main formations of HO% and $\mathrm { { \le { O } _ { 4 } } ^ { \cdot - } }$ , from iron activation routes, are shown below [19–21]:

$$
\begin{array} { r l } & { \mathrm { F e } ^ { 2 + } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }  \mathrm { F e } ^ { 3 + } + \mathrm { H O } ^ { * } + \mathrm { H O } ^ { - } k _ { 1 } = 7 6 \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 } } \\ & { \mathrm { F e } ^ { 3 + } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }  \mathrm { F e } ^ { 2 + } + \mathrm { H O } _ { 2 } ^ { * } + \mathrm { H } ^ { + } k _ { 2 } = 0 . 0 2 \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 } } \\ & { \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - } + \mathrm { F e } ^ { 2 + }  \mathrm { S O } _ { 4 } ^ { * - } + \mathrm { S O } _ { 4 } ^ { 2 - } + \mathrm { F e } ^ { 3 + } k _ { 3 } = 2 0 - 2 7 \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - } } \end{array}
$$

The generation of HO% and $S O _ { 4 } ^ { \cdot - }$ based on iron mediated activation, mainly combined with UV irradiation, has played predominant roles in advanced oxidation processes. However, there are several defects in these activation methods. The most predominant drawback is the $\mathrm { F e } ^ { 2 + }$ natural oxidation into $\mathrm { F e } ^ { 3 + }$ in water due to the oxygen presence and $\mathrm { F e } ^ { 3 + }$ ions precipitation at $\mathtt { p H }$ higher than 4.0. Therefore, most of the iron species present in natural and slightly basic solutions, exist in the form of insoluble ferric oxides and (hydr)oxides. Due to these physicochemical properties of iron in water, the activation of persulfate by $\mathsf { F e } ^ { 2 + } / \mathsf { F e } ^ { 0 }$ is more favorable in acidic solution than in neutral and alkaline pH [18].

For these reasons, the development of Fe(III)/Fe(II) organic complexes is essential to improve the removal efficiencies under environmentally relevant $\mathsf { p H }$ values. Polycarboxylate acids like citric, oxalic and aminopolycarboxylic acids like ethylenediaminetetraacetic acid (EDTA) can form stable water soluble complexes with iron in neutral and slightly basic pH solutions, enhancing the dissolution of iron in natural water. Moreover, these complexes are photochemicaly active and efficient leading, by photoredox process, to the production of oxidative species like hydroxyl radicals [13,22,23]. However, EDTA is toxic and hard to be removed from aqueous solution by traditional chemical and biological water treatments and so it is always found in considerable concentration in rivers [24]. Compared to EDTA, ethylenediamine- $\mathbf { \nabla } \cdot N _ { \mathbf { \mu } } ^ { \prime }$ -disuccinic acid (EDDS), which is a structural isomer of EDTA, has been recognized to be more easily biodegraded and more environmental friendly [25]. Photo-induced production of HO% and $\mathrm { { } ~ } ^ { S O _ { 4 } ^ { ~ \cdot ~ - } }$ based on Fe(II)/Fe(III)-EDDS complexes has been widely studied in recent years, showing excellent efficiency in removing organic pollutants in water and soil near neutral pH [5,7,9,26–33]. Huang et al. demonstrated that in homogeneous Fenton-like process (Fe(III)-EDDS/ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ , Fe(III)-EDDS (molar ration 1:1) shows better removal efficiency of bispenol A (BPA) in alkaline solution than in acidic one [34]. At the same time, Wu and coworkers reported that under UV radiation, photoFenton process $\mathrm { ( F e ( I I I ) { \cdot } E D D S / H _ { 2 } O _ { 2 } / U V ) }$ has much higher efficiency in removing 4-tert-Butylphenol (4tBP) than Fenton process. This result can be ascribed to the rapid generation of $\mathrm { F e ( I I ) }$ under irradiation [9]. In the presence of PS with Fe(III)-EDDS/UV, rapid oxidation of 4-terbutylphenol (4tBP) is observed due to the formation of $\mathrm { { S O } _ { 4 } \mathrm { { \dot { \Omega } } ^ { - } } }$ . In neutral and basic pH conditions, the efficiency of 4tBP degradation is much higher with Fe(III)-EDDS than with Fe(III) aquacomplexes [14]. So, the use of Fe(III)-EDDS complexes leads to efficient oxidation processes whatever the sources of radical species (HO% or $S O _ { 4 } ^ { \cdot } - )$ . However, the comparison between $\mathrm { F e ( I I I ) { \cdot } E D D S / H _ { 2 } O _ { 2 } / U V }$ and Fe(III)- EDDS/PS/UV systems under same conditions including the effects of pH, Fe(III)-EDDS concentration, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PS concentrations has never been investigated before. The main goal of this paper is to compare these two processes using $p$ -hydroxyphenylacetic acid $\scriptstyle ( p - \mathrm { H P A } )$ as a model pollutant. $p { \mathrm { - } } { \mathrm { H P A } }$ is one of the pharmaceutical intermediates and also widely used in the synthesis of pesticides and commonly detected in olive oil wastewaters [35,36]. The aim of this study is to quantify the different activation efficiency of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PS by Fe(III)-EDDS under irradiation in the same experimental conditions and to correlate the efficiency with the production of HO% and $\mathrm { { } } S 0 _ { 4 } { } ^ { \cdot \mathrm { { - } } }$ radicals. Especially, to reach this goal and understand the different mechanisms, the second order rate constants of $p$ -HPA with HO% and $\mathrm { { S O } _ { 4 } \mathrm { { \dot { \Omega } } ^ { - } } }$ are determined by laser flash photolysis (LFP) for the first time.

# 2. Materials and methods

# 2.1. Irradiation setup and experimental procedure

List of chemicals used in this work is reported in the Supporting Information. For the control experiment in the dark, reactions are performed in a brown bottle with continuous magnetic stirring at room temperature. The reactions start from the addition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ to the solution. For the degradation of $p$ -HPA under irradiation, the experiments are performed in a home-made photoreactor placed in a cylindrical stainless steel container. Four fluorescent light bulb lamps (Philips TL D 15 W/05) were separately placed in four different axes. Meanwhile, the photoreactor, which is a water-jacketed Pyrex tube with $2 . 8 \mathrm { c m }$ internal diameter, was placed at the center of the setup. The emission spectrum (Fig.S1) was determined using an optical fiber coupled with a CCD spectrophotometer (Ocean Optics USD $2 0 0 0 + { \mathrm { U V } } .$ –vis) and energy has been normalized to the actinometry results using paranitroanisole (PNA)/pyridine method [37]. A total flux of 1451 W $\mathbf { m } ^ { - 2 }$ reaching the solution was determined between $3 0 0 { - } 5 0 0 \mathrm { n m }$ . Solutions are magnetically stirred with a magnetic bar during the reaction and total volume was $1 0 0 \mathrm { m L }$ . All the experiments are carried out at room temperature $( 2 9 3 ~ \pm ~ 2 \mathrm { K } )$ , controlled by a circulating cooling water system. The initial concentration of $p { \mathrm { - H P A } }$ is $5 0 \mu \mathrm { M }$ in all experiments, and samples are taken from the reaction tube at fixed interval times. In order to stop the Fenton reaction after the samples taken from the photoreactor, $2 0 \mu \mathrm { L }$ IPA were added immediately after withdrawn.

# 2.2. $p$ -HPA quantification and degradation rate

The concentration of the $p$ -HPA remaining in the aqueous solution is determined with an Alliance high performance liquid chromatography (HPLC) equipped with a photodiode array detector (Waters 2998, USA) and Waters 2695 separations module. The experiments are performed by UV detection at $2 7 4 \mathrm { n m }$ . The flow rate is $0 . 1 5 \mathrm { m L } \mathrm { ~ m i n } ^ { - 1 }$ , the injection volume is $5 0 \mu \mathrm { L }$ and the mobile phase is a mixture of water (with $0 . 1 \%$ $\mathrm { H } _ { 3 } \mathrm { P O } _ { 4 } )$ and methanol $( 6 5 / 3 5 , \mathrm { v / v } )$ . The column is a Nucleodur 100-3 C18 of $1 5 0 \times 2 . 0 \mathrm { m m }$ , particle size $3 \mu \mathrm { m }$ . In these conditions, the retention time of $p$ -HPA is 6.7 min.The initial degradation rate of $p$ -HPA is $\mathrm { R } _ { p - \mathrm { H P A } }$ $( \mathrm { M ~ } s ^ { - 1 } ) \ = \ \mathrm { k _ { a p p } \times \ [ \mathit { p } \mathrm { - } H P A ] _ { 0 } }$ with $[ p \mathrm { - } \mathrm { H P A } ] _ { 0 }$ the initial concentration of $p$ -HPA, $\bf k _ { a p p }$ the pseudo-first-order apparent rate constant $( s ^ { - 1 } )$ . The error is $\pm ~ 3 \sigma$ , obtained from the scattering of the experimental data.

# 2.3. Laser flash photolysis

Experiments are carried out using the fourth harmonic $( \lambda _ { \mathrm { e x c } }$ $= 2 6 6 \mathrm { n m } )$ of a Quanta Ray GCR 130-01 Nd: YAG laser system instrument and the energy is set at $4 5 \mathrm { m J }$ /pulse. Other conditions are kept the same to those described in previous articles [14,38]. Conditions and chemicals used for the determination of reactivity constants are reported in the Supplementary Information.

# 3.2. Effect of UV and Fe(III)-EDDS complex

In the dark, $p { \mathrm { - } } { \mathrm { H P A } }$ is stable in aqueous solution even in the presence of Fe(III)-EDDS and no direct photolysis was observed under adopted irradiation conditions. As a contrary, under adopted UVA polychromatic irradiation, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } }$ can produce HO% (R4) and $S O _ { 4 } ^ { \cdot - }$ (R8).

$$
\begin{array} { l } { { S _ { 2 } O _ { 8 } ^ { 2 - } { \stackrel { h \nu } { \longrightarrow } } 2 S O _ { 4 } ^ { * - } } } \\ { { \ } } \\ { { F e ( I I I ) - E D D S + H _ { 2 } O _ { 2 }  F e ( I I ) - E D D S + H O _ { 2 } ^ { * } / O _ { 2 } ^ { * - } + H ^ { + } } } \\ { { \ } } \\ { { F e ( I I I ) - E D D S { \stackrel { h \nu } { \longrightarrow } } F e ( I I ) + E D D S ^ { . } } } \end{array}
$$

However, $p$ -HPA has a relatively low degradation rate in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (1 mM) or $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ (1 mM) alone under UV, achieving $1 0 \%$ and $3 0 \%$ removal respectively, after $1 2 0 \mathrm { m i n }$ of irradiation (Fig. S3 and S4). In fact, the quantum yield of HO% generation is very low at wavelengths longer than $3 0 0 \mathrm { n m }$ . In terms of $\mathsf { p H }$ effect, faster $p { \mathrm { - } } { \mathrm { H P A } }$ degradation is observed at $\mathrm { p H } 3 . 0$ or 4.5 than at $\mathrm { p H } 9 . 4$ in agreement with the evaluated second order rate constants as a function of $\mathsf { p H }$ (Table 1).

Fig.1A shows the degradation of $p$ -HPA with Fe(III)-EDDS $( 1 0 0 \mu \mathrm { M } )$ at two different $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentrations (100 and $5 0 0 ~ { \mu \mathrm { M } } )$ in the dark or under irradiation. The disappearance of $p { \mathrm { - } } { \mathrm { H P A } }$ is much faster in the photo-Fenton system $\mathrm { ( F e ( I I I ) { \cdot } E D D S / H _ { 2 } O _ { 2 } / U V ) }$ than in Fenton-like process $\left( \mathrm { F e ( I I I ) { \cdot } E D D S / H _ { 2 } O _ { 2 } } \right)$ [34]. According to the summarized mechanism (see before), the production of HO% was correlated with the formation of Fe(II) (R9, R10) [9,34] and then with the oxidation of target compound. Under irradiation, UVA light significantly enhances the generation of Fe(II), improving the degradation of $p$ -HPA in the first $1 0 \mathrm { { m i n } }$ through the Fenton process (R1) [7,9]. At higher $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration $( 5 0 0 ~ \mu \mathrm { M } )$ added into the solution, $p$ -HPA can be removed completely in $6 0 \mathrm { { m i n } }$ in Fenton-like process and in $1 0 \mathrm { { m i n } }$ in photoFenton system. At lower concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $1 0 0 \mu \mathbf { M } ) _ { I }$ $p$ -HPA is not completely removed with or without UV irradiation. These results corroborate that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration is a crucial and a limiting parameter in the oxidation process.

With $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ , the $\mathsf { p H }$ and the different concentrations are kept the same of the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ system. The different degradation kinetics are shown in Fig. 1B. Although some previous papers reported that Fe(III) can activate persulfate to produce $\mathrm { { } ~ } ^ { S O _ { 4 } ^ { ~ \cdot ~ - } }$ in the dark, it was not the case in our system. In fact, much higher concentration of $\mathrm { F e ( I I I ) }$ species and persulfate seem needed to do this activation [39]. Under irradiation, Fe (III)-EDDS ${ \mathrm { N a } } _ { 2 } S _ { 2 } { \mathrm { O } } _ { 8 }$ system shows a good efficiency for $p { \mathrm { - } } { \mathrm { H P A } }$ degradation but much lower compared to the system with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Different reasons can explain the lower efficiency of this system. First of all, it is important to mention that the formation of $\mathrm { F e ( I I ) }$ via reaction R10 is one of the crucial step to active $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ or $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to produce oxidative species through reactions R1 and R3, which are identified and evaluated in terms of relative importance in the following part of this paper. The lower efficiency can be due to the fact that the second order rate constant of the activation of $5 _ { 2 } { \ O _ { 8 } } ^ { 2 - } ( k _ { S _ { 2 } O _ { 8 } ^ { 2 - } , F e ^ { 2 + } } = 2 0 { - } 2 7 { \ } { \mathrm { M } } ^ { - 1 } \ s ^ { - 1 } )$ is more than three times smaller than the one with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \left( k _ { H _ { 2 } O _ { 2 } , F e ^ { 2 + } } = 7 6 \right.$ $\mathbf { M } ^ { - 1 } \thinspace s ^ { - 1 } )$ ). In addition, the lower efficiency of $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ can be also due to the second order rate constants between $p { \mathrm { - } } { \mathrm { H P A } }$ with HO% or $S O _ { 4 } ^ { \cdot - }$ , $k _ { p - H P A , H O } \cdot$ is 4.6 times higher than $k _ { p - H P A , S O _ { 4 } ^ { * } }$ in acidic solutions (Table 1). As a contrary, the photolysis of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } }$ are not responsible for this effect at the concentration and light irradiation wavelengths used in this process.

# 3.3. Effects of $H _ { 2 } O _ { 2 }$ and $N a _ { 2 } S _ { 2 } O _ { 8 }$ concentrations

Initial degradation rate of $p$ -HPA $( \mathrm { R } _ { p - \mathrm { H P A } } )$ is used to evaluate the degradation efficiency of the reaction process. $\mathrm { R } _ { p - \mathrm { H P A } }$ is evaluated from the first $5 \mathrm { { m i n } }$ of irradiation, because during this period $\mathtt { p H }$ of the solution kept stable, and the degradation can be well fitted by pseudo first order kinetics. Fig. 2 shows the initial degradation rate of $p$ -HPA with different $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentrations in photo-Fenton process. $\mathrm { R } _ { p - \mathrm { H P A } }$ increases from $1 . 5 0 \times 1 0 ^ { - 7 }$ to $3 . 8 0 \times 1 0 ^ { - 7 } \mathrm { ~ M ~ } s ^ { - 1 }$ when $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentrations increases from $5 0 ~ \mu \mathrm { M }$ to $^ { 1 \mathrm { m M } }$ . The observed increase of $p$ -HPA degradation when the concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ increased is obvious considering that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is one of the two compounds generating HO% in the Fenton process. In fact, as described in Fig. 1A, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration was the limiting parameter. However, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is also a scavenger of HO% $( k _ { H _ { 2 } O _ { 2 } , H O } \cdot = 2 . 7 \times 1 0 ^ { 7 } \mathrm { ~ M } ^ { - 1 } \mathrm { ~ s } ^ { - 1 } )$ and so too high concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ will lead to a decrease of the organic compound degradation rate [7]. Due to the much higher rate constant of $_ \mathrm { H O } \cdot$ reaction on $p { \mathrm { - } } { \mathrm { H P A } }$ $( k _ { p - H P A , H O } \bullet = 2 . 2 \times 1 0 ^ { 1 0 } \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 } )$ the decrease of the $p$ -HPA degradation is not observed in our experimental conditions. In fact at highest $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration used (1 mM) $9 0 \%$ of HO% are still consumed by $p$ -HPA. For this reason, it was only observed that the increase rate slowed down when $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ increased from $2 5 0 ~ \mu \mathrm { M }$ to $^ { 1 \mathrm { m M } }$ . Moreover, at this concentration the contribution to the degradation of $p$ -HPA from the direct photolysis of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is still negligible (Fig. S3).

The effect of $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } }$ concentration is shown in Fig. 2. Similar to $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , the degradation rate is always increasing when $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ concentration increases. # 3.5. Effects of pH

In the Fe(III) (photo)-induced activation reactions, pH always plays a significant role during the whole process. Firstly, in the $p$ -HPA/Fe(III)- EDDS/UV system, pH effects are investigated, as shown in the insert of Fig. 4. Under polychromatic irradiation, Fe(III)-EDDS can produce HO% through a complex photoinduced mechanism as described in different studies [17,44]. However, if we compare with the photo-Fenton process, the photo-production of HO% was very limited without $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . (Fig. 1). When the pH increases from 3.0 to 4.7, the removal efficiency increases very fast, while with pH further increase up to 9.4, degradation percentage continues to increase but much more slowly. The constant increase of the $p$ -HPA removal with the increase of $\mathtt { p H }$ is due to the higher HO% formation quantum yield when the pH increases [17]. However, according to our previous results by Wu et al. [14,30], Fe(III)- EDDS showed different predominant species with respect to pH and the complex Fe(OH)EDDS formed at $\mathsf { p H }$ higher than 6.0 can also explain the higher efficiency at higher $\mathsf { p H }$ in terms of HO% formation. However, the slower increase observed at pH higher than 4.7, can be attributed to the lower reactivity (three times lower) of HO% on the mono-anionic form of $p$ -HPA. The rate constants have been evaluated for the first time during this study and are presented in Table 1.

The $\mathsf { p H }$ effect on the $\mathrm { F e ( I I I ) { \cdot } E D D S } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { U V }$ and Fe(III)-EDDS/ $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / U V }$ processes during the initial stage (first $5 \mathrm { { m i n } }$ of irradiation) are shown in Fig. 4. The trend of $\mathtt { p H }$ effects is different from Fe (III)-EDDS/UV system and is also quite different although the experimental conditions are similar but the oxidation species used $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } ) }$ are different. So, the activation mechanisms of these two different processes are not exactly the same.

In the $\mathrm { F e ( I I I ) { \cdot } E D D S / H _ { 2 } O _ { 2 } / U V }$ reaction, $p { \mathrm { - } } { \mathrm { H P A } }$ degradation efficiency increases fast from $\mathrm { p H } 2 . 5$ to 7.5, then it begins to decrease when $\mathsf { p H }$ increases to 9.0. As explained with the system Fe(III)-EDDS/UV (insert Fig. 4), in general, the increase of efficiency with the increase of $\mathsf { p H }$ is mainly due to the increased HO% formation quantum yield and chemical speciation of Fe(III)-EDDS complexes vs pH possessing different photoactive abilities. However, in the photo-Fenton process HO% generation is mainly due to the Fenton process and so to the photogeneration of $\mathrm { F e ( I I ) }$ which is correlated with the first photochemical step, the photoredox process from the complex Fe(III)-EDDS leading to the formation EDDS% and Fe(II). To compare and understand well this mechanism, $\mathrm { F e } ^ { 3 + }$ is introduced instead of Fe(III)-EDDS, see Fig.S5. In order to keep $\mathrm { F e } ^ { 3 + }$ soluble in the solution, a very acidic pH is selected $\mathrm { ( p H } = 2 . 0 \mathrm { ) }$ although the optimal $\mathsf { p H }$ is 2.8 to better generate the most light absorbing iron complex with water molecules. Fe(III)-EDDS shows faster degradation efficiency than $\mathrm { F e } ^ { 3 + }$ in the initial stage, ascribing to the higher photochemical activity of the complex Fe(III)-EDDS than the ion $\mathrm { F e } ^ { 3 + }$ . As for Fe(III)-EDDS, the degradation is also very fast in the first $1 0 \mathrm { { m i n } }$ and after slows down. In $\mathrm { F e ^ { 3 + } / H _ { 2 } O _ { 2 } / U V }$ system, the degradation is nearly stopped after about $3 0 \mathrm { { m i n } }$ of irradiation. This important slow down and then complete stop of the reaction is due to the almost total consumption of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . The higher final removal percentage observed with $\mathrm { F e } ^ { 3 + }$ than with Fe(III)-EDDS is due to the presence of EDDS which can consume also HO% and so decrease the reactivity efficiency on $p$ -HPA.

As a contrary of this rapid initial degradation observed with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ in the $\mathrm { F e ( I I I ) { \cdot } E D D S } / \mathrm { N a _ { 2 } } S _ { 2 } \mathrm { O _ { 8 } } / \mathrm { U V }$ system, a gradual degradation during the irradiation process is observed (Fig. 1). Indeed, $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ can react with the first radical generated by the photoredox process on EDDS (R10) and then avoid the reaction with ${ \bf O } _ { 2 }$ leading to the formation of $\mathrm { H O } _ { 2 } { ' } / \mathrm { O } _ { 2 } { ' } ^ { - }$ [44]. This hypothesis was deduced from the literature (Miralles-Cuevas et al. 2014) [12], EDDS% can react with hydroxide anions or persulfate in aqueous solution to form related radicals (i.e. hydroxyl and sulfate radicals). Furthermore, $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ can consume electrons and $\mathrm { O } _ { 2 } \cdot \mathrm { ^ - }$ to form sulfate radicals [45,46]. While it’s well known that $\mathrm { H O } _ { 2 } { ' } / \mathrm { O } _ { 2 } { ' } ^ { - }$ are particularly important because they can modify the Fe(III)/Fe(II) cycle and so the reactivity [34]. Moreover, the degradation efficiency is mainly affected by the photochemical activation abilities of different formed of Fe(III)-EDDS complex and the soluble $\mathrm { F e ( I I I ) }$ concentrations in solution [30]. With pH increase, the precipitation of Fe(III) in aqueous solution is became a main limiting step. For another non-negligible reason, it’s well known that Fe(II) can be easily oxidized to Fe(III) by the dissolved oxygen in water, and this effect is accelerated when solution $\mathtt { p H }$ is higher than 4 [47]. So, the soluble Fe(II) undergoes competitive reaction with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ or dissolved oxygen. From R1 and R3, $k _ { S _ { 2 } O _ { 8 } ^ { 2 } } – _ { , F e ^ { 2 + } }$ is smaller than $k _ { H _ { 2 } O _ { 2 } , F e ^ { 2 + } }$ , and we argue that in the competing reactions, high amount of Fe(II) can be consumed by oxygen in $\mathrm { F e ( I I I ) { \cdot } E D D S } / \mathrm { N a _ { 2 } } S _ { 2 } \mathrm { O _ { 8 } } / \mathrm { U V }$ systems at higher pH’s solutions. This reactivity can explain the decreased degradation rate when the pH increases. Comparison between $\mathrm { F e } ^ { 3 + }$ and Fe(III)-EDDS also was conducted, as shown in Fig.S5. At $\tt { p H } 2 . 0$ , $\mathrm { F e ^ { 3 + } / N a _ { 2 } S _ { 2 } O _ { 8 } }$ $( 5 0 0 ~ \mu \mathrm { M } ) / \mathrm { U V }$ system shows a fast and gradual degradation of $p$ -HPA, and $p$ -HPA can be removed completely in $4 5 \mathrm { { m i n } }$ .

# 4. Conclusion: comparison of $\mathbf { H _ { 2 } O _ { 2 } }$ and $\pmb { S _ { 2 } 0 _ { 8 } } ^ { 2 - }$ efficiency

In general, the $p$ -HPA degradation efficiency is much higher with Fe (III)- $\mathrm { \cdot \mathrm { E D D S / H _ { 2 } O _ { 2 } / U V } }$ system than with $\mathrm { F e ( I I I ) { \cdot } E D D S } / \mathrm { N a _ { 2 } } S _ { 2 } \mathrm { O _ { 8 } } / \mathrm { U V }$ system whatever the solution pH’s. Firstly, this difference can be explained considering the second order rate constants $k _ { p - H P A , H O } .$ and $k _ { p - H P A , S O _ { 4 } ^ { * } }$ (Table 1). The value of $k _ { p - H P A , H O } .$ is higher than $k _ { p - H P A , S O _ { 4 } ^ { * } }$ both at $\mathrm { p H } ~ 2 . 5$ (4.6 times) and 8.5 (2.1 times). Secondly, the rate constants of the key reactions generating the radical species is more than 3 times higher for the Fenton process (R1) than for the activation of persulfate with Fe(II) (R3). However, at $\mathrm { p H } 2 . 5$ , the ratio of the rate constants between radical species and $p { \mathrm { - } } \mathrm { H P A } \ k _ { p - H P A , H O ^ { * } } / \ k _ { p - H P A , S O _ { 4 } ^ { * - } }$ equal to 4.6 and the ratio of $p { \mathrm { - H P A } }$ disappearance rate in the two systems $\mathrm { R } _ { p \mathrm { - } \mathrm { H P A } } ~ ( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ) / ~ \mathrm { R } _ { p \mathrm { - } \mathrm { H P A } } ~ ( \mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } )$ equal to 5.2 are similar. It is slightly higher for the $p$ -HPA disappearance rate which is coherent with the two reasons mentioned at the beginning of this paragraph. As a contrary the difference between these two ratios is much higher at pH 8.5, $\mathrm { R } _ { p \mathrm { - } \mathrm { H P A } } \left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right) / \mathrm { R } _ { p \mathrm { - } \mathrm { H P A } } \left( \mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } \right)$ equal to 16.7 is eight times higher than $k _ { p - H P A , H O ^ { * } } / \ k _ { p - H P A , S O _ { 4 } ^ { * - } }$ equal to 2.1. So, as previously demonstrated, the Fenton process, involving Fe(III)-EDDS complex, is higher at near neutral $\mathtt { p H }$ than in acidic pH [34]. This significant result in terms of environmental aquatic compartments seems not present for the activation of persulfate to generate $S O _ { 4 } ^ { \cdot - }$ radical. Indeed, in this case a dramatic decrease of the efficiency is observed. So, in this particular study, with $p { \mathrm { - } } { \mathrm { H P A } }$ used as organic pollutant and UV/Fe(III)EDDS as source of Fe(II), we clearly demonstrated that the Fenton process is more efficient than activation of persulfate process and more particularly at environmentally closed $\mathsf { p H }$ values.

In the future, the application of such AOP’s using Fe(III)EDDS complexes could be also studied in real water matrix such as sewage treatment plant (STP) waters. However, it is very well known that the presence of naturally occurring inorganic ions and organic matter can play very often an inhibition role on the pollutant degradation. In fact, as recently demonstrated in STP waters, the formation of secondary radicals such as carbonate ${ ( \mathrm { C O } _ { 3 } } ^ { \cdot - } )$ and chloride derivative (Cl% , $\mathrm { C l } _ { 2 } \mathrm { \dot { \Omega } } ^ { - }$ , …) can strongly modify the oxidative process and as consequence the pollutant degradation [39,50].
