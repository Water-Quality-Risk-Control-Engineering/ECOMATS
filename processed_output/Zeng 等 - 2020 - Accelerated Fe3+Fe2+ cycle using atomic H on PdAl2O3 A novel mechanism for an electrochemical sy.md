# Abstract

The high cost associated with the disposal of iron sludge in $\mathrm { F e } ^ { 2 + }$ activated oxidation systems significantly limits their widespread use. In this study, we constructed a trace iron-based peroxydisulfate (PDS) oxidation system (Pd-EFP) using $\mathrm { P d } / { \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 } }$ as the particle electrode and externally added PDS as an oxidant. At an initial solution $\mathsf { p H }$ of 3.0 and a current density of 3.33 $\mathrm { m A } / \mathrm { c m } ^ { 2 }$ , with the addition of $1 0 ~ \mathrm { m M }$ PDS, $5 0 \mathrm { m g } \mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ , and $2 \mathrm { m g / L }$ Fe ions, $8 0 . 1 2 \%$ of 180 $\mu \mathrm { M }$ benzoic acid (BA) was degraded within $1 2 0 \mathrm { m i n }$ . The Pd/Al2O3 catalyst provided sufficiently large surface area for atomic $\mathrm { H ^ { * } }$ production from the adsorption of electrogenerated $\mathrm { H } _ { 2 }$ or $\mathrm { H } ^ { + }$ conversion via electro-induction on the Pd/Al2O3 surface, which subsequently accelerated the transformation from $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e } ^ { 2 + }$ . Using this method, organics could be degraded by both $\mathrm { S O } _ { 4 } ^ { \cdots }$ and ·OH via the $\mathrm { F e } ^ { 2 + }$ -activated PDS process. In the Pd-EFP process, the optimal dosage of Fe ions was determined to be $3 6 ~ \mu \mathrm { M }$ $( 2 ~ \mathrm { m g / L } )$ . Correspondently, the optimal current density and PDS concentration in the Pd-EFP system were $3 . 3 3 \mathrm { \ m A } / \mathrm { c m } ^ { 2 }$ and $2 0 ~ \mathrm { m M }$ , respectively. Furthermore, degradation of BA was efficiently promoted by the ${ \Nu } _ { 2 }$ atmosphere, which could steer the reaction on the surface of Pd/Al2O3 in the right direction toward $\mathrm { F e } ^ { 3 + }$ reduction by atomic $\mathrm { H ^ { * } }$ , by dispelling accumulated $\mathrm { H } _ { 2 }$ above the reaction liquid and suppressing oxygen reduction. Finally, the Pd/Al2O3 catalyst was found to be durable in the Pd-EFP system according to reusability experiments and X-ray diffraction patterns of the fresh and used $\mathrm { P d } / { \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 } }$ catalyst. This research provides an environmentally benign system for recycling $\mathrm { F e } ^ { 3 + }$ in $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ processes and for suppressing iron sludge production.

Keywords: $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ process, Pd/Al2O3, atomic $\mathrm { H ^ { * } }$ , iron cycle, iron sludge reduction

# 1. Introduction

By producing strongly oxidising ·OH, advanced oxidation processes (AOPs) are appealing treatment options for removing non-biodegradable, recalcitrant and toxic organic contaminants from water [1-4]. Among AOPs, the Fenton reaction (reaction 1) has been widely applied in wastewater treatments for its high oxidation ability, low operating cost, and controllability [5]. In parallel to the Fenton reaction, the reaction between $\mathrm { F e } ^ { 2 + }$ and peroxydisulfate (PDS, $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ ) ( $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ reaction, reaction 2) shares similar advantages with the Fenton reaction while sulfate radical $\mathrm { ( S O _ { 4 } ^ { \cdot - } ) }$ demonstrate a longer lifetime than hydroxyl radical (·OH) in water [6-8].

The activation of PDS with dissolved Fe ions as a catalyst has some intrinsic drawbacks [15]. As shown in reaction 2, one mole of added $\mathrm { F e } ^ { 2 + }$ only produce one mole of radicals. Although $\mathrm { F e } ^ { 2 + }$ can be regenerated via reactions 4 and 7, the regeneration rate of $\mathrm { F e } ^ { 2 + }$ remains far lower than their consumption rate via reaction 2 [12, 13]. For efficient production of $\mathrm { S O } _ { 4 } ^ { \cdots }$ , engineers normally choose to add more $\mathrm { F e } ^ { 2 + }$ . The separation of Fe ions as ferric oxyhydroxides is required before discharging treated wastewater into natural waters, resulting in the production of iron sludge. Correspondently, the high cost of the disposal of iron sludge significantly limits the widespread use of the $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ reaction. Although PDS oxidation processes initiated by heterogeneous catalysts have the potential to avoid iron sludge formation, the application of some of these catalysts leads to problems, such as leaching of metal ions into the acidic solution [16]. Furthermore, other efforts to accelerate the transformation of $\mathrm { F e } ^ { 3 + }$ into $\mathrm { F e } ^ { 2 + }$ have been undertaken. Hydroxylamine in the Fenton process and the $\mathrm { F e } ^ { 2 + } / \mathrm { P M S }$ process is reported to enhance the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ redox cycles, which leads to steady $\mathrm { F e } ^ { 2 + }$ recovery and significantly activated H2O2/PMS with a small addition of Fe ions $( 1 ~ \mathrm { m g / L } )$ [17, 18]. Hydroxylamine is degraded in oxidation processes, but it also introduces $\mathrm { N O } _ { 2 } \mathrm { ^ { - } / N O } _ { 3 }$ into the wastewater. Anett et. al explored $\mathrm { H } _ { 2 } / \mathrm { P d }$ pairs as a reductant/catalyst to achieve the fast regeneration of $\mathrm { F e } ^ { 3 + }$ back to $\mathrm { F e } ^ { 2 + }$ and an accelerated catalytic Fenton reaction with traces of iron [9]. It can be concluded from these studies that the continuous regeneration of $\mathrm { F e } ^ { 2 + }$ occurs in the presence of a reductive substance. Based on its excellent performance in the reductive dechlorination of various by-products, electrochemical systems with Pd-modified particle electrodes, namely three-dimensional (3D) electrochemical systems, are also promising systems for the acceleration of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ recycling [21, 22]. Pd catalysts have the unique ability to activate $\mathrm { H } _ { 2 }$ to form continuously adsorbed atomic $\mathrm { H ^ { * } }$ , which has been confirmed to be a strong reducing agent in catalytic reduction process [23]. Furthermore, compared to an electro-reduction system with a traditional two-dimensional (2D) cathode, a 3D electrochemical system provides a larger surface area and more active sites, significantly improving the electro-reduction capacity [24, 25]. In the work by Qin et. al, it was deduced that $\mathrm { F e } ^ { 2 + }$ continuously came from the reduction of $\mathrm { F e } ^ { 3 + }$ by chemisorbed atomic $\mathrm { H ^ { * } }$ on Au/Pd particle electrodes [26]. However, no direct evidence was provided in their study and, to our knowledge, no study has quantified the accelerating effect of a 3D electrochemical system on $\mathrm { F e } ^ { 2 + }$ regeneration and sludge reduction.

In this work, benzoic acid (BA) was used as a probe for $\mathrm { S O } _ { 4 } ^ { \cdots }$ and ·OH because BA is highly reactive with these two radicals [27, 28]. First, a trace iron-based electro ${ \mathrm { / F e } } ^ { 3 + } ,$ /PDS system was constructed using Pd/Al2O3 as the particle electrode and by externally added PDS as the oxidant. The oxidation performance of this new system was assessed by comparing it with other systems and the radicals in this process were confirmed via electron spin resonance (ESR) analysis and quenching experiments. Thereafter, the influencing factors such as PDS concentration, current density, iron concentration and gas atmosphere were investigated to evaluate the radical utilisation efficiency. Finally, the stability of Pd/Al2O3 was studied and the application potential of this system was discussed.

# 2. Experimental Section

# 2.1 Chemicals and Materials

Benzoic acid (BA), sodium peroxydisulfate (PDS), ferric sulfate $( \mathrm { F e } _ { 2 } ( \mathrm { S O } _ { 4 } ) _ { 3 } )$ , sodium sulfate (NaSO4), methanol, tert-butyl alcohol (TBA), and 5,5-dimethyl-1-pyrroline N-oxide (DMPO) were purchased from Sigma Aldrich (Finland).

The Pd/Al2O3 catalyst was purchased from Sigma Aldrich (Finland), which had $10 \%$ Pd loading on Al2O3.

# 2.2 Experimental Procedures

The solutions in this study were prepared using deionised (DI) water (resistivity of $1 8 . 2 ~ \mathrm { M } \Omega$ , Arium $\textsuperscript { \textregistered }$ Pro System). The solution pH was adjusted using either 100 mM NaOH or $5 0 \mathrm { m M H } _ { 2 } \mathrm { S O } _ { 4 }$ . Experiments were conducted in a two-cell electrochemical reactor, a schematic diagram of which is presented in Figure SM-2 (Supplementary Material). Before the reactor was used, ${ \Nu } _ { 2 }$ was used to flush out the air in the cathode cell. The hydrogen produced from the cathode was sealed in the cathode cell during the experiment. To prevent further oxidation of BA in the sample, an ethanol solution was added once the sample was removed from the reactor.

# 2.3 Analytical Methods

The concentration of BA was measured by high-performance liquid chromatography (HPLC, Shimadzu LC-20AD, Tokyo, Japan) using a C18 column and ultraviolet detector. The mobile phase was maintained at a flow rate of $1 . 0 ~ \mathrm { m L / m i n }$ with a constant ratio (50:50) of $2 5 ~ \mathrm { m M }$ acetic acid and methanol; the temperature of the column was kept at $3 5 ~ ^ { \circ } \mathrm { C }$ , and the maximum absorption wavelength at 228 nm was selected. The PDS concentration was determined colorimetrically using potassium titanium oxalate solution at a wavelength of $3 5 2 ~ \mathrm { \ n m }$ using an ultraviolet spectrophotometer (Lambda 45, PerkinElmer). This detection method was described in detail by Zeng et al [29]. The Pd leaching concentration was analysed by inductively coupled plasma-optical emission spectroscopy (ICP Agilent 5110).

The formation of reactive oxygen radicals was identified using an electron spin resonance (ESR) spectrometer (CMS 8400, Adani). For the OH∙ and $\mathrm { S O } _ { 4 } ^ { \cdots }$ measurements, the sample was immediately mixed with DMPO to form adducts. The phase composition of the synthesised catalyst was studied using an X-ray diffractometer (XRD, PANalytical) using Co-Kα radiation $( \lambda { = } 0 . 1 7 8 9 \mathrm { n m }$ , at $4 0 \mathrm { k V }$ and $4 0 \mathrm { m A }$ ) over a 2θ range of $1 0 – 1 2 0 ^ { \circ }$ with a step size of $0 . 0 2 ^ { \circ }$ and scan speed of $2 ^ { \circ } / \mathrm { m i n }$ .

# 3. Results and Discussion

# 3.1 Enhancement of the Electro/Fe2+ /PDS process using Pd/Al2O3

Initially, we conducted an experiment to degrade BA $( \mathrm { C } _ { 0 } { = } 1 8 0 ~ \mu \mathrm { M } )$ in a $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ -enhanced electro/Fe3+/PDS system (Pd-EFP system), i. e. in addition to PDS $\mathrm { 1 0 ~ m M ) }$ and $\mathrm { F e } ^ { 3 + }$ (2 mg or 36 $\mu \mathrm { M } )$ , the reaction suspension contained Pd/Al2O3 as the particle electrode catalyst and cathode $( 3 . 3 3 \mathrm { \ m A } / \mathrm { c m } ^ { 2 }$ , $\mathsf { p H }$ of 3.0, and ${ \Nu } _ { 2 }$ atmosphere). As shown in Figure 1a, $8 0 . 1 2 \%$ of BA was degraded within $1 2 0 \mathrm { m i n }$ . The $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst in this experiment showed almost no adsorption towards BA or Fe ions.

To clarify the role of PDS, the cathode, $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst, and $\mathrm { F e } ^ { 3 + }$ in the oxidation process, control experiments were conducted by excluding each component. Zero degradation of BA occurred in the absence of PDS (electro/Pd/Fe3+  system), which obviously played the role of oxidant in the Pd-EFP system. The addition of the $\mathrm { P d } / { \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 } }$ catalyst in the $\mathrm { F e } ^ { 3 + } / \mathrm { P D S }$ system also had a negligible effect on the degradation of BA $( \mathrm { P d } / \mathrm { F e } ^ { 3 + } / \mathrm { P D S }$ system). To our surprise, $2 . 8 7 \%$ of BA was degraded in the electro $/ \mathrm { F e } ^ { 3 + } / \mathrm { P D S }$ system. According to the aforementioned discussion, $\mathrm { F e } ^ { 3 + }$ could be reduced on the cathode directly and then led to the subsequent activation of PDS [19]. The low reduction efficiency of $\mathrm { F e } ^ { 3 + }$ could be ascribed to the occupation of active sites by $\mathrm { H } ^ { + }$ and subsequent $\mathrm { H } _ { 2 }$ evolution on the cathode (Figure SM-3a). This was verified by the large amount of bubbles near the cathode. According to the research reported by Anett, generated $\mathrm { H } _ { 2 }$ can be chemically adsorbed by the $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst and converted into a strongly reducing agent (Pd$\mathrm { H } ^ { * }$ ) (reaction 8), which can reduce $\mathrm { F e } ^ { 3 + }$ [9]. To verify our hypothesis for our system, we investigated the variation of the $\mathrm { F e } ^ { 2 + }$ concentration in the Pd-EFP system in the absence of BA and PDS (Figure 1b). Because the recycling of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ was too fast to detect the variation of the $\mathrm { F e } ^ { 2 + }$ concentration, we increased the initial concentration of Fe ions ten-fold. In the absence of the $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst, no variation in the iron species was observed. With the addition of $5 0 ~ \mathrm { m g }$ of Pd/Al2O3 in the electrochemical cell, $3 6 0 ~ \mu \mathrm { M }$ of $\mathrm { F e } ^ { 3 + }$ could be totally reduced, and $\mathrm { F e } ^ { 2 + }$ were formed in only 1 min. The results strongly supported our hypothesis that the cathode played the role of electron donor by electro-generating $\mathrm { H } _ { 2 }$ . $\equiv \mathrm { P d } \mathrm { - } \mathrm { H } _ { 2 } \to 2 \equiv \mathrm { P d } \mathrm { - } \mathrm { H } ^ { \ast }$ (8)

165  In summary, this new system exhibited continuously strong oxidation ability when we applied PDS as the oxidant, a cathode as an electron donor, $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ particles for the catalytic reduction of $\mathrm { F e } ^ { 3 + }$ , and Fe ions as the one-electron transferring medium. Based on this, it is reasonable to divide the Pd-EFP system into a two-stage process: an accelerated $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle on the $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ particle electrode and a subsequent $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ oxidation process in the bulk solution.

# 3.2 Active radical analysis

ESR spectroscopy with the spin-trapping reagent of DMPO was applied to directly confirm the generation of radicals. The hyperfine splitting constants for the DMPO radical adducts of DMPO·- OH and DMPO·-SO4 were representative of ·OH and $S O _ { 4 } ^ { " }$ , respectively [13, 30-32]. In this study, as shown in Figure 2a, we observed no signal for the $\mathrm { F e } ^ { 3 + } / \mathrm { P D S }$ system. For the Pd-EFP system, as we predicted, slight signals for DMPO·-SO4 adducts suggested the generation of $\mathrm { S O } _ { 4 } ^ { \cdots }$ . Moreover, a typical four-line ESR spectrum with an intensity of 1:2:2:1 was detected, which indicated the emergence of ·OH.

It is obvious that $\mathrm { S O } _ { 4 } ^ { \cdots }$ came from the PDS activation via in situ-generated $\mathrm { F e } ^ { 2 + }$ (reaction 2) in the Pd-EFP system. The redox potential of $\mathrm { S O } _ { 4 } ^ { \cdots }$ was confirmed to be $2 . 5 { \sim } 3 . 1 \ \mathrm { V } ,$ while the $2 . 7 \mathrm { ~ V ~ }$ potential of ·OH was detected in acidic solution [33, 34]. Due to the narrow gap of potentials between the two radicals, ·OH could be generated via fast transformation from $S O _ { 4 } ^ { \cdots }$ (reaction 9).

$$
\mathrm { S O 4 ^ { - } } + \mathrm { H } _ { 2 } \mathrm { O } \longrightarrow \mathrm { S O 4 ^ { 2 - } } + \cdot \mathrm { O H } + \mathrm { H ^ { + } }

Quenching experiments were further conducted to check the importance of $\mathrm { S O } _ { 4 } ^ { \cdots }$ and ·OH in the oxidation process. Ethanol is well known to be an efficient scavenger for ·OH and $\mathrm { S O } _ { 4 } ^ { \cdots }$ due to its high reaction constant with these two radicals [34]. As shown in Figure 2b, the degradation of BA was significantly inhibited in the presence of ethanol. More specifically, $8 0 . 1 2 \%$ BA was degraded without ethanol within $1 2 0 \mathrm { m i n }$ . With the addition of $0 . 1 8 { \mathrm { M } }$ ethanol, only $3 0 . 8 0 \%$ BA degradation was observed; with a further increase in the ethanol concentration to $1 . 8 \mathbf { M } _ { : }$ , the degradation of BA was reduced to $2 2 . 8 2 \%$ . The inhibitory effect of ethanol on the BA degradation indicated that $S O _ { 4 } ^ { \cdots }$ and its symbiotic radical (·OH) were the main oxidation species in the Pd-EFP system. The reductive effect of Pd-based catalysts in the electrochemistry system has been extensively investigated [21, 22, 35, 36]. Direct electron transfer and atomic $\mathrm { H ^ { * } }$ may be both involved in the accelerated recycling process of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ . For a better understanding of the accelerated iron recycling process, we further clarified the importance of the two reductive mechanisms in the reduction process of $\mathrm { F e } ^ { 3 + }$ . Tert-butyl alcohol (TBA) is reported to be an efficient scavenging agent of atomic $\mathrm { H ^ { * } }$ [21]. To minimise the systematic error, the initial $\mathrm { F e } ^ { 3 + }$ concentration was increased to $3 6 0 ~ \mu \mathrm { M }$ , while the Pd/Al2O3 catalyst was set to only $5 . 0 ~ \mathrm { m g } / 1 2 0 ~ \mathrm { m L }$ . As shown in Figure 3, strong inhibition of $\mathrm { F e } ^ { 3 + }$ reduction occurred with TBA addition ( $3 6 \mathrm { m M }$ and $3 6 0 \mathrm { m M }$ ). We further fitted the process with pseudo-first-order kinetics. As shown in Figure 3 (insert), with TBA additions of $3 6 \mathrm { m M }$ and $3 6 0 \mathrm { m M }$ , the reduction kinetics constant decreased by $7 7 . 8 1 \%$ and $8 3 . 9 7 \%$ , respectively. The sharp decrease in the $\mathrm { F e } ^ { 3 + }$ reduction rate suggested the main role of atomic $\mathrm { H ^ { * } }$ rather than direct electron transfer on the Pd/Al2O3 particle electrode (reaction 10, Figure SM3b), which is identical to the catalytic property of Pd as an atomic $\mathrm { H ^ { * } }$ keeper.

$$
\equiv \mathrm { P d } \mathrm { - } \mathrm { H ^ { * } + F e ^ { 3 + } } \longrightarrow \equiv \mathrm { P d } + \mathrm { H ^ { + } + F e ^ { 2 + } }
$$

TBA is also an effective screening agent for ·OH because it exhibits a low reactivity towards $\mathrm { S O } _ { 4 } ^ { \cdots }$ [34]. Consequently, the inhibitory effect of TBA on organic degradation is normally not stronger than that of ethanol for normal oxidation processes. Interestingly, the screening effect of TBA on BA degradation in our system was stronger than the influence of ethanol (Figure 2b) [18]. This contradiction can be ascribed to the simultaneous inhibition of both ·OH and atomic $\mathrm { H ^ { * } }$ . The results further confirmed the importance of atomic $\mathrm { H ^ { * } }$ for the reduction of $\mathrm { F e } ^ { 3 + }$ .

Atomic $\mathrm { H ^ { * } }$ may originate from the adsorption of electrogenerated $\mathrm { H } _ { 2 }$ or $\mathrm { H } ^ { + }$ conversion via electroinduction on the Pd surface [9]. Plenty of atomic $\mathrm { H ^ { * } }$ in the bulk solution accelerated the transformation of $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e } ^ { 2 + }$ considerably. The Pd-EFP system provided continuous $\mathrm { F e } ^ { 2 + }$ for the $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ oxidation process. Thus, organics could be degraded by both $\mathrm { S O } _ { 4 } ^ { \cdots }$ and ·OH from the $\mathrm { F e } ^ { 2 + }$ -activated PDS process.

# 3.3 Sludge production

Fe ions bridged as a single electron-transferring medium between the electron-donor and PDSoxidation process. Additionally, Fe ions are significant for this system because they are removed from water as a sludge, which is the focus of our research. We then investigated the effect of varying the initial iron concentration on the efficiency of BA. As shown in Figure 4, with the addition of $1 8 0 \mu \mathrm { M F e } ^ { 3 + } ( 1 0 \mathrm { m g / L } )$ , the degradation efficiency of BA was determined to be $8 6 . 8 9 \%$ within $1 2 0 \mathrm { m i n }$ . When we further decreased the initial $\mathrm { F e } ^ { 3 + }$ concentration to $3 6 \mu \mathrm { M } \left( 2 \mathrm { m g / L } \right)$ , the removal efficiency was kept at $8 0 . 1 2 \%$ .

To quantitatively compare the iron sludge production in various systems, we standardized the iron sludge production by dividing the iron dosage $\mathrm { ( C o ( F e ) ) }$ by the organic removal (ΔC(pollutant)) in the $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ process. Depending on the organic contaminants, the ratio varied from 5.1 to 238 for the $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ process (Table 1) [37-43]. As shown in reactions 2-7, one mole of $\mathrm { F e } ^ { 2 + }$ can produce one mole of ·OH, which can subsequently oxidize up to one mole of organics. Thus, a ratio of C(Fe)/ΔC(pollutant) in the $\mathrm { F e } ^ { 2 + }$ -activated PDS process below 1.0 indicates the recycling of Fe ions in the system. We checked the $\mathrm { C ( F e ) } / \Delta \mathrm { C } ( \mathrm { B A } )$ in the $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ oxidation process of BA (Table 1), and the ratio was 87.2 when the ratio was decreased to 0.2 in the Pd-EFP system, suggesting trace production of iron sludge in the post-treatment process.

For conventional Fenton processes or $\mathrm { F e } ^ { 2 + } /$ /PDS processes, excess $\mathrm { F e } ^ { 2 + }$ has been reported to have a detrimental effect on the oxidation of contaminants owing to their quenching effect toward ·OH and SO4 ·- (reactions 11-12). According to studies on $\mathrm { F e } ^ { 2 + }$ /PDS processes (Table 1), an optimal ratio of C(Fe)/C(PDS) for organic degradation has generally been determined to be in the range of 0.16-1.0 [37-43]. With higher $\mathrm { F e } ^ { 2 + }$ addition than the optimal dosage, excess Fe2+  will result in decreasing the degradation efficiency of organics. We checked the BA degradation in the Fe2+ /PDS system, and the optimal ratio was obtained when the iron concentration was 1.5 times the PDS concentration (Figure SM-4). In the Pd-EFP process, the $\mathrm { F e } ^ { 2 + } ,$ /PDS ratio was no more than 0.0036, indicating that $\mathrm { F e } ^ { 2 + }$ was mainly used for PDS activation instead of radical quenching. The addition of trace iron not only benefited the post treatment of the dissolved iron, but also improved the contaminant oxidation efficiency of the Fe2+ /PDS process.

# 3.4 Radical consumption analysis

The effects of the applied current density and PDS concentration were investigated to optimize the parameters and explore side reactions. As shown in Figure 5a, under a current density of 0.66 $\mathrm { m A } / \mathrm { c m } ^ { 2 }$ , the degradation efficiency of BA was only $2 0 . 6 3 \%$ within $1 2 0 \mathrm { m i n }$ . With an increase in the current density to $3 . 3 3 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ , the degradation efficiency was improved to $8 0 . 1 2 \%$ . Interestingly, a further increase in the current density to $6 . 6 6 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ led to a counterproductive effect on BA degradation.

With the increase in the current density, the applied voltage increased and hydrogen bubbles were produced faster, both of which were beneficial to the production of atomic $\mathrm { H ^ { * } }$ on the $\mathrm { P d } / { \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 } }$ . Thus, as a reductant, atomic $\mathrm { H ^ { * } }$ on the catalyst can act not only as an accelerator of iron recycling but also as a possible quenching agent for ·OH and $S O _ { 4 } ^ { \cdots }$ (reactions 14-15). The adverse effect of current density beyond $3 . 3 3 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ verified the hypothesis, i. e. in our system, the optimal current density was $3 . 3 3 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ .

# 3.5 Effect of the gas atmosphere

The gas atmosphere above the cathodic cell is another parameter that affects the reaction on the

Pd/Al2O3. We concluded that atomic $\mathrm { H ^ { * } }$ is the main species responsible for $\mathrm { F e } ^ { 3 + }$ reduction. It has been found that dissolved oxygen can compete with $\mathrm { F e } ^ { 3 + }$ for the reaction with atomic $\mathrm { H ^ { * } }$ (reaction 16) [45, 46]. Given the inhibition of dissolved oxygen on atomic $\mathrm { H ^ { * } }$ , oxygen should be prevented in the cathodic cell.

$$
4 \equiv \mathrm { P d } \mathrm { - } \mathrm { H } ^ { * } + \mathrm { O } _ { 2 } \to 4 \equiv \mathrm { P d } + 2 \mathrm { ~ H } _ { 2 } \mathrm { O }
$$

In the study by Anett et.al, increasing concentration of $\mathrm { H } _ { 2 }$ above the cathode cell was found to be beneficial to accelerate $\mathrm { F e } ^ { 3 + }$ recycling owing to the reductive effect of activated $\mathrm { H } _ { 2 }$ on the Pd/Al2O3 catalyst [9]. By slowly feeding ${ \Nu } _ { 2 }$ and $\mathrm { H } _ { 2 }$ , we checked the performance of the Pd-EFP process on BA degradation in ${ \Nu } _ { 2 }$ and $\mathrm { H } _ { 2 }$ atmospheres (Figure 6a). Compared with the in situ electrogenerated $\mathrm { H } _ { 2 }$ atmosphere, pure ${ \Nu } _ { 2 }$ provided a better atmosphere for the performance of the PdEFP system on BA degradation. Interestingly, PDS in the $\mathrm { H } _ { 2 }$ atmosphere initially displayed a higher degradation rate than in the ${ \Nu } _ { 2 }$ atmosphere, but almost no degradation of BA occurred after a retention time of $4 0 ~ \mathrm { { m i n } }$ . This variation can be ascribed to the quick degradation of PDS in the pure $\mathrm { H } _ { 2 }$ atmosphere. As shown in Figure 6b, the PDS was degraded quickly in the pure $\mathrm { H } _ { 2 }$ atmosphere, while ${ \Nu } _ { 2 }$ and electro-generated $\mathrm { H } _ { 2 }$ atmospheres showed a relatively slow degradation rate towards PDS. The results indicated a two-electron transfer from $\mathrm { H } _ { 2 }$ to PDS via reaction 17 rather than one-electron transfer from atomic $\mathrm { H ^ { * } }$ to $\mathrm { F e } ^ { 3 + }$ , which suppresses the oxidation process via a $\mathrm { P d \mathrm { - } H ^ { \mathrm { * } } { \longrightarrow } F e ^ { 3 + } / F e ^ { 2 + } { \longrightarrow } P D S / S O _ { 4 } ^ { \mathrm { - } } { \longrightarrow } B A }$ mechanism. To confirm this hypothesis, we checked BA degradation in the ${ \mathrm { H } } _ { 2 } / { \mathrm { P d } } / { \mathrm { P D S } }$ system, and PDS was completely consumed with zero degradation of BA. $\mathrm { \equiv } \mathrm { P d } \mathrm { - } \mathrm { H } _ { 2 } + \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - } \mathrm {  } \mathrm { \equiv } \mathrm { P d } + 2 \mathrm { \ H } ^ { + } + 2 \mathrm { \ S O } _ { 4 } { } ^ { 2 - }$ (17)

By dispelling accumulated $\mathrm { H } _ { 2 }$ above the reaction liquid and suppressing the oxygen reduction, ${ \Nu } _ { 2 }$ atmosphere could steer the reaction on the surface of Pd/Al2O3 in the right direction toward $\mathrm { F e } ^ { 3 + }$ reduction by atomic $\mathrm { H ^ { * } }$ , further leading to efficient organic degradation.

3.6 Application potential analysis   
The aforementioned results indicated that $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ particles, as a famous $\mathrm { H } ^ { * }$ keeper, showed high performance for iron recycling and reduction of iron sludge production in the $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ process. According to our catalyst dosage study, even with the addition of only $1 0 \mathrm { m g } \mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst per $1 2 0 \mathrm { m L }$ of reaction liquid in the Pd-EFP system, BA degradation could reach the level of $60 \%$ (Figure SM-5). However, the stability of the particle electrode is a crucial issue owing to the high cost of noble metals. The Pd/Al2O3 catalyst has been extensively used in chemical industries owing to its high stability and outstanding catalytic efficiency [23]. We also monitored the catalyst stability by recycling the $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst in the Pd-EFP system five times. As shown in Figure 7a, the degradation efficiencies were kept relatively stable between $8 0 . 5 6 \%$ and $8 3 . 1 9 \%$ , indicating relatively high stability. Simultaneously, the Pd concentration in the effluent was lower than the detection limit of ICP-OES $( 0 . 0 1 ~ \mathrm { m g / L } )$ . The variation in the catalytic activity on the Pd/Al2O3 catalyst in the Pd-EFP process was evaluated using XRD analysis. XRD patterns of the fresh and used $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst were recorded, as shown in Figure 7b, where diffraction peaks assigned to (111), (200), and (311) of metallic Pd were observed. The obtained results demonstrated that Pd/Al2O3 is stable and could be effectively used for a long period of time, which can produce a considerable economic benefit.   
For practical application, the initial solution $\mathsf { p H }$ and the variation of the solution $\mathsf { p H }$ with the reaction progress are also important [48, 49]. Owing to the acidification effect of the PDS decomposition process (reaction 17), the Pd-EFP process was confirmed to be an efficient system even with an initial solution pH of 10.0. (Text SM-2).   
The Pd-EFP process successfully produced a continuous $\mathrm { F e } ^ { 2 + } / \mathrm { P D S }$ process with trace amounts of

Fe ions. However, this also resulted in some drawbacks, such as a low oxidation rate, high cost for catalyst preparation, and subsequent recovery of the Pd/Al2O3 catalyst. The catalyst dosage analysis revealed that the Pd-EFP process exhibited oxidation capacity even when we used a Pd catalyst dosage of $1 0 ~ \mathrm { \ m g / 1 } 2 0 ~ \mathrm { \ m L }$ (Figure SM-5). Furthermore, in the research field of electrocatalytic dechlorination, various functional materials have been developed that possess new characteristics while maintaining their capacity as an atomic $\mathrm { H ^ { * } }$ keeper, and they are good alternatives as particle electrodes in this system. To further decrease the Pd dosage in the Pd-EFP system, the catalytic activity of atomic $\mathrm { H ^ { * } }$ formation can be enhanced by changing the morphology so that the Pd(111) facet and defect sites on the Pd crystal are highly active [50, 51]. It has been found that Pd-supported multi-walled nanotubes can act as an excellent $\mathrm { H ^ { * } }$ producer in a 3D electrocatalytic process with only $0 . 5 \%$ loading of Pd [22]. A bimetal catalyst (Pd/In) has also showed strong reductive capacity in a 3D electrochemical process [21]. This research points out the novel approach of reducing the iron sludge in the $\mathrm { F e } ^ { 2 + }$ -activated peroxide process by accelerating the transformation from $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e } ^ { 2 + }$ using surface-bound atomic $\mathrm { H ^ { * } }$ on Pd/Al2O3. Other atomic $\mathrm { H ^ { * } }$ keeper materials should be tested to evaluate the application value of this technology in the future.

# 4. Conclusion

In this study, a trace-iron based electro $\mathrm { F e } ^ { 3 + } / \mathrm { P D S }$ system was constructed using $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ as the particle electrode and by externally added PDS as the oxidant. At an initial solution pH of 3.0, with the addition of $1 0 ~ \mathrm { m M }$ PDS, 50 mg Pd/Al2O3, and $2 ~ \mathrm { m g / L }$ Fe ions, $8 0 . 1 2 \%$ of $1 8 0 ~ \mu \mathrm { M }$ BA was degraded within $1 2 0 \mathrm { m i n }$ . Mechanistic studies showed that the ·OH and $\mathrm { S O } _ { 4 } ^ { \cdots }$ from $\mathrm { F e } ^ { 2 + } .$ -activated PDS were responsible for the BA degradation, whereas atomic $\mathrm { H ^ { * } }$ was mainly responsible for $\mathrm { F e } ^ { 3 + }$ reduction to $\mathrm { F e } ^ { 2 + }$ . In the Pd-EFP process, the optimal dosage of Fe ions was determined to be 36 $\mu \mathrm { M } \left( 2 \mathrm { m g / L } \right)$ because the extra addition of more than $2 \mathrm { m g / L }$ Fe ions had a positive but negligible influence on BA degradation. Correspondently, the optimal current density and PDS concentration in the Pd-EFP system were found to be $3 . 3 3 \mathrm { \ m A } / \mathrm { c m } ^ { 2 }$ and $2 0 ~ \mathrm { m M }$ , respectively. A higher current density or higher PDS concentration had a quenching effect on $\mathrm { S O } _ { 4 } ^ { \cdots }$ . The Pd-EFP process is efficient for BA degradation at various initial solution pH levels. Furthermore, the degradation of BA was also efficiently promoted by the ${ \Nu } _ { 2 }$ atmosphere, which could steer the reaction on the surface of Pd/Al2O3 in the right direction toward $\mathrm { F e } ^ { 3 + }$ reduction by atomic $\mathrm { H ^ { * } }$ by dispelling accumulated $\mathrm { H } _ { 2 }$ above the reaction liquid and suppressing oxygen reduction. Finally, catalyst reusability experiments and the XRD pattern of fresh and used $\mathrm { P d } / \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ catalyst indicated that the Pd/Al2O3 catalyst maintained its high durability in the Pd-EFP system.
