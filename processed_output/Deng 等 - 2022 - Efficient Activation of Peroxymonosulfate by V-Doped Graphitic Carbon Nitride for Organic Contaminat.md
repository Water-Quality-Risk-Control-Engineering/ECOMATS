Abstract: Advanced oxidation processes (AOPs) based on peroxymonosulfate (PMS) activation have been developed as an ideal pathway for completely eradication of recalcitrant organic pollutants from water environment. Herein, the V-doped graphitic carbon nitride $( \mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } )$ is rationally fabricated by one-step thermal polymerization method to activate PMS for contamination decontamination. The results demonstrate the V atoms are successfully integrated into the framework of $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ,$ , which can effectively improve light absorption intensity and enhance charge separation. The V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ displays superior catalytic performance for PMS activation. Moreover, the doping content has a great influence on the activation performances. The radical quenching experiments confirm $\bullet \mathrm { O } _ { 2 } -$ , $\mathrm { S O _ { 4 } ^ { \bullet - } }$ , and $h ^ { + }$ are the significant species in the catalytic reaction. This work would provide a feasible strategy to exploit efficient $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ -based material for PMS activation.

Keywords: $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ;$ advanced oxidation processes; photocatalysis; peroxymonosulfate; organic contamination

# 1. Introduction

The organic contamination in groundwater and wastewater has become a challenging issue in the development of a sustainable society [1–3]. A number of toxic and persistent organic pollutants such as endocrine disrupting chemicals, antibiotics, and petroleum hydrocarbon, are frequently found in groundwater [4–6]. These pollutants are difficult to be biodegraded because of their chemical stability and environmental risk [7,8]. To date, various treatment techniques have been developed for organic contamination remediation, such as membrane separation, anaerobic technologies, and adsorption [3,5]. Unfortunately, their application are dramatically impeded by the low removal efficiency [3,9,10]. It is imperative but still remains challenges to develop cost-effective treatment methods for addressing organic contamination issues.

In recent years, advanced oxidation processes (AOPs) have been developed as an ideal pathway for completely eradication of recalcitrant organic pollutants from water environment [3,9,11]. In this process, the structure of organic contaminants can be destroyed by the highly reactive oxygen species [3,12,13]. Among various active radicals, sulfate radicals $\left( \mathrm { S O _ { 4 } } ^ { \bullet - } \right)$ generated from peroxymonosulfate (PMS) activation have been widely exploited due to their stronger oxidative capacity and longer lifetime [14–16]. More importantly, $\mathrm { S O _ { 4 } ^ { \bullet - } }$ is generally reacted with target compounds via an electron transfer pathway due to its high selectivity [12,17]. Therefore, many approaches have been extensively applied to activate PMS into $\mathrm { S O _ { 4 } ^ { \bullet - } }$ , such as electrochemistry, transition metal ions, UV, and photocatalysis [18,19]. It is recognized that the photocatalysis is a promising tool for PMS activation owing to its low cost and environmentally compatible [20–22]. Nevertheless, it is still a big challenge to explore advanced materials with high quantum efficiency and abundant active sites to meet the practical requirement for PMS activation.

Recently, a large variety of novel materials have been widely used in PMS activation, including semiconductor composites, perovskite, and carbon-based materials [3,11,13,23]. Among them, graphitic carbon nitride $( \mathrm { g } { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } )$ has been demonstrated as an effective heterogeneous catalyst due to its good stability and facile synthesis [24,25]. Especially, $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ possesses unique optical and electronic properties (ca. $2 . 7 \mathrm { e V }$ ), indicating that it can be excited by visible light with a wavelength of less than $4 6 0 \mathrm { n m }$ [26,27]. Nevertheless, the major drawbacks of pure $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ are the poor visible light response, sluggish charge separation efficiency and low surface area [25,28]. Various strategies have been employed to overcome these drawbacks, including morphological control, vacancies, heteroatom doping, and the construction of heterojunctions [24]. Among these methods, heteroatom doping into the frameworks carbon has become a pivotal strategy to develop $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ -based photocatalysts with pronounced catalytic performance [29–32]. In principle, element V may be a promising dopants to boost catalytic performance of $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ due to its comparable atom size. Wang et al., reported that $\mathrm { V }$ doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ catalysts shows an enhanced performance in the catalytic dehydrogenation of propane [33]. Neelakanta Reddy et al., reported that the incorporation of V into the host $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ material can enhance the catalytic activities in water splitting [32]. Yet, the utility of V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ for PMS activation has never been investigated.

Herein, the V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ are rationally fabricated by the thermal polymerization method. The structure, morphology, and optical properties were characterized using various analysis technologies, such as $\mathsf { X }$ -ray diffraction (XRD), Fourier transform infrared (FT-IR), $\mathsf { X } .$ -ray photoelectron spectroscopy (XPS), scanning electron microscopy (SEM), and UV-vis diffuse reflectance spectroscopy spectra (DRS). The bisphenol A (BPA), as an emerging recalcitrant contaminant, was selected to systematically probe the performance of the V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ . The doping V atoms could effectively increase light absorption intensity and enhance charge separation. As expected, the V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ displays superior catalytic performance for PMS activation. Finally, a possible activation mechanism was discussed and proposed based on the capture experiment and photoelectrochemical measurement.

# 2. Materials and Methods

# 2.1. Chemicals

Melamine, ammonium vanadate $\left( \mathrm { N H } _ { 4 } \mathrm { V O } _ { 3 } \right)$ , p-benzoquinone (BQ) and ethylenediaminetetraacetic acid dihydrate (EDTA) were purchased from Aladdin Industrial Co., Shanghai, China. Nafion solution $( 5 . 0 \mathrm { w t \% } )$ , peroxymonosulfate (PMS, $\mathrm { K H S O _ { 5 } { \cdot } 0 . 5 K H S O _ { 4 } { \cdot } 0 . 5 K _ { 2 } S O _ { 4 } ) }$ , and bisphenol A (BPA) were purchased from Sigma-Aldrich Co., LTD (St. Louis, MO, USA). Sodium sulfate $\left( \mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 } \right)$ , sodium hydroxide (NaOH), isopropanol (IPA), and methanol (MeOH) were obtained from Sinopharm Chemical Reagent Co., Ltd. (Shanghai, China). All chemical reagents are of analytical grade and used without further purification. Deionized (DI) water with a resistivity of $1 8 . 2 \mathrm { M } \Omega$ was used throughout the experiments.

# 2.2. Synthesis of Materials

The V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ was synthesized via the thermal polymerization method. In a typical procedure, $5 \mathrm { g }$ of melamine was thoroughly ground with an appropriate amount of $\mathrm { N H _ { 4 } V O _ { 3 } }$ . The collected mixture was placed into a crucible with a cover, and calcined at $5 5 0 ^ { \circ } C$ for $4 \mathrm { { h } }$ . The product was washed with NaOH solution (1 M), ethanol and water, and dried at $6 0 ^ { \circ } \mathrm { C }$ . A series of V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ were obtained by adjusting the weight ratio of $\mathrm { N H _ { 4 } V O _ { 3 } }$ and melamine (0.1, 0.2, 0.5, and $0 . 8 \%$ ) and denoted as $\mathrm { V - g - C _ { 3 } N _ { 4 } - 0 . 1 } ,$ , $\mathrm { V - g - C } _ { 3 } \mathrm { N } _ { 4 } – 0 . 2 ,$ $\mathrm { V } – g  – C _ { 3 } \mathrm { N } _ { 4 } – 0 . 5 ,$ and $\mathrm { V - g { - C _ { 3 } N _ { 4 } { - } O . 8 } }$ .

# 2.3. Materials Characterization

The TEM (Talos F200S microscope) and SEM (JSM-7800F microscope, Tokyo, Japan) were conducted to study the morphology. The XRD (PANalytical Powder X-ray diffractometer), FT-IR (Thermo Ni-colet iS 50, Waltham, MA, USA), and XPS spectroscopy (Thermo ESCA LAB 250, Waltham, MA, USA) were measured to analyze the surface elemental compositions. The DRS was recorded on a Shimadzu UV-3600 (Shimadzu, Kyoto, Japan). The $\Nu _ { 2 }$ adsorption−desorption measurements were performed on an $\Nu _ { 2 }$ adsorption apparatus (Micromeritics ASAP 2020, Norcross, GA, USA).

# 2.4. Activation Performance Tests

The photodegradation of BPA was selected as a model reaction to study the activation performance of the V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ . In a typical catalytic experiment, the sample $( 5 0 \mathrm { m g } )$ was put in $5 0 \mathrm { m L }$ BPA solution $( 1 0 \mathrm { m g / L } )$ , and stirred in the dark for $3 0 \mathrm { m i n }$ . The $3 0 0 W X e$ lamp with a $4 0 0 \mathrm { n m }$ cut-off filter (CEL-HXF300, Aulight, Beijing, China) was immediately turned on after a specific amount of PMS was added. The experiments were conducted at $2 5 ^ { \circ } \mathrm { C }$ . The $\mathrm { p H }$ was not controlled during the experiment. At specified time intervals, the sample was taken out from the solution and filtered with a PTFE filter. Then, $0 . 1 \mathrm { m L }$ of methanol was added immediately to quench radicals. The amount of BPA was analyzed by high performance liquid chromatography (HPLC, Agilent 1260, Santa Clara, CA, USA) with an Agilent C-18 column and UV detection wavelength of $2 7 6 \mathrm { n m }$ . The mixture solutions of $3 0 \%$ water and $7 0 \%$ methanol were used as the mobile phase, and the flow rate was $1 . 0 \mathrm { m L } { \cdot } \mathrm { m i n } ^ { - 1 }$ .

For the quenching experiment, BQ, EDTA, IPA, and MeOH were added as quenchers for different radicals.

# 2.5. Electrochemical Measurements

The Mott-Schottky plots and electrochemical impedance spectroscopy (EIS) were obtained on a CHI-660E electrochemical analyzer (CH Instruments, Shanghai, China) in a standard three electrode configuration. The $\mathrm { A g / A g C l }$ and $\mathrm { P t }$ sheet were used as the reference electrode and the counter electrode, respectively. The working electrode was prepared on indium doped tin oxide (ITO) substrates. The $1 \mathrm { m g }$ sample was dispersed in a mixture containing $0 . 9 8 \mathrm { m L }$ of anhydrous ethanol and $0 . 0 2 { \mathrm { m L } }$ of Nafion solution by ultrasonication for $3 0 \mathrm { m i n }$ . The obtained slurry was dropped onto the surface of the ITO glass with a size of $1 \times 1 \mathrm { c m } ^ { 2 }$ , and then dried at room temperature. 0.5 M ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ was employed as the electrolyte. The Mott-Schottky plot was obtained through measurement of the capacitance as a function of potentials at $1 \mathrm { k H z }$ . The EIS measurements were carried out in the frequency range of $1 0 ^ { - 2 }$ to $1 0 ^ { 5 } \mathrm { H z }$ with a $1 0 \mathrm { m V }$ amplitude.

# 4. Conclusions

In summary, the V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ was successfully designed and fabricated via onestep thermal polymerization method to activate PMS toward organic contamination degradation. The results reveal that the V atoms are successfully integrated into the structure of $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ,$ , which can effectively increase visible light absorption intensity and enhance charge separation. The obtained V-doped $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ shows superior catalytic performance for PMS activation, in which the BPA can be completely removed within $2 5 \mathrm { { m i n } }$ . Moreover, doping content has a great influence on the activation performances. The radical quenching experiments confirm the $\bullet \mathrm { O } _ { 2 } -$ , $\mathrm { S O _ { 4 } } ^ { \bullet - }$ , and $h ^ { + }$ are significant species in degradation reactions. Finally, a possible degradation mechanism is discussed and proposed. This work provides a feasible strategy to optimize the performance of novel materials for environmental remediation.
