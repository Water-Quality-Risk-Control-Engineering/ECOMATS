It is well known that pristine titanium dioxide $\mathrm { ( T i O _ { 2 } ) }$ is unable to absorb and utilize visible light to degrade organics and reduce hexavalent chromium $\mathrm { ( C r ( V I ) }$ . However, for the first time, this research found that when some organic compounds were mixed with hexavalent chromium, titanium dioxide could not only degrade organic compounds but also reduce hexavalent chromium synchronously under the drive of visible light. The pristine $\mathrm { T i O } _ { 2 }$ exhibited excellent simultaneity removal of bisphenol A (BPA) and $\mathrm { C r } ( \mathrm { V I } )$ under visible light irradiation, and almost $1 0 0 \%$ BPA $( 5 0 ~ \mathrm { m g / L } )$ and $1 0 0 \%$ $\mathrm { C r ( V I ) }$ $( 1 0 ~ \mathrm { m g / L } )$ were removed just within $6 0 \ \mathrm { m i n }$ . Photoluminescence (PL), electrochemical characterization and chemical quenching studies suggested that the reaction mechanism is similar to dye sensitization and electron transfer is responsible for the superior recation. Influences of different reaction conditions were systematically investigated, such as the initial concentration of BPA, the crystal structure of $\mathrm { T i O } _ { 2 }$ , the catalyst dosage, the initial $\mathsf { p H }$ value, and the common inorganic anions. Compared to the rutile, anatase exhibited the most remarkable performance for BPA degradation and $\mathrm { C r ( V I ) }$ reduction under visible light irradiation. In addition, many other typical refractory organics, such as acetaminophen and tetracycline, have been successfully applied in this photocatalytic system of $\mathrm { T i O } _ { 2 }$ under visible light irradiation $( \mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system) to synergistically remove self-contamination and $\mathrm { c r }$ (VI) pollution. The findings of the present study provide a valuable insight for sewage treatment, especially the composite wastewater containing organic pollutants and the hexavalent chromium.

# 1. Introduction

Over the decades, the presence of micropollutants and hexavalent chromium $\mathrm { ( C r ( V I ) ) }$ in aquatic environments has drawn increasing global attention, since these recalcitrant organic contaminants and highly toxic $\mathrm { c r ( V I ) }$ species may pose serious threats to ecosystems and human health [1,2]. Research in recent years has indicated that these organic micropollutants can merely be partially eliminated by traditional sewage treatment technologies [3]. Moreover, disadvantages of the conventional $\mathrm { { C r } ( V I ) }$ reduction methods have hugely inhibited their practical application, such as poor processing efficiency, secondary pollution, and high energy consumption, etc [4]. Therefore, developing a high-performance, cost effective, environmentally friendly technique to realize the synchronous treatment of organics and heavy-metal pollution is urgently required.

Numerous achievements have revealed that compared with other technologies, photocatalytic process enjoys many outstanding advantages, such as green, safety, and efficiency [5,6], especially the unique ability of simultaneously degrading organic contaminants and reducing heavy metals [7,8]. In photocatalytic reactions, the semiconductor photocatalyst absorbs photons matched with its band gap energy, and generates electrons $( \mathsf { e } ^ { - } )$ and holes $( \mathrm { h } ^ { + } )$ to participate in redox reactions, leading to organics degradation and hexavalent chromium reduction [8–11], which is in line with the current concept of green chemistry. These organics and hexavalent chromium, in turn, can act as scavengers for holes and photoelectrons, respectively, thereby promoting carrier separation and increasing the rate of catalytic reactions [8–13]. So far, a lot of photocatalysts have been employed to remove multiple substances simultaneously in wastewater, including titanium dioxide $\mathrm { ( T i O _ { 2 } ) }$ [14], zinc oxide $\left( \mathrm { Z n O } \right)$ [15], tin oxide $\left( \mathsf { S n O } _ { 2 } \right)$ [16], cadmium sulfide (CdS) [17] and other oxides and sulfide semiconductors, graphene-based heterojunction photocatalysts [18], carbon catalysts [19], and heptazine-based polymer melon (well known as $g _ { - }$ $\mathrm { C } _ { 3 } \mathrm { N } _ { 4 } )$ [20], etc.

Among the above catalysts, $\mathrm { T i O } _ { 2 }$ has attracted extensive research interest in practical application, since it not only owns an appropriate conduction band and valence band redox potential to guarantee the synchronous elimination of organic pollutants and hexavalent chromium, but also possesses great prominent environmental characteristics, such as high catalytic activity, various synthesis methods, nontoxicity, tasteless, and good stability [9,14,21]. However, the large band gap (3.0–3.2 ev) results in a narrow solar energy absorption range of $\mathrm { T i O } _ { 2 }$ $( \lambda ~ < ~ 3 8 7 ~ \mathrm { n m } )$ , which means it cannot absorb visible light [9,14]. Regrettably, visible light reaching the earth's surface accounts for $5 0 \%$ of solar energy, thus causing a severe restriction on the use of sunlight by $\mathrm { T i O } _ { 2 }$ [9,14,22]. In order to overcome the chief drawback, plentiful efforts have been dedicated to improve the absorption and utilization of $\mathrm { T i O } _ { 2 }$ for visible light [21]. As a consequence, various aspiring $\mathrm { T i O } _ { 2 }$ -based nanomaterials, e.g., $\mathbf { A u \mathrm { - T i O _ { 2 } } }$ [23], ${ \mathrm { C o } } { \cdot } { \mathrm { T i O } } _ { 2 }$ [24], $\mathrm { T i O } _ { 2 } / \mathrm { r G O }$ [15], $\mathrm { C Q D s  – T i O _ { 2 } }$ [25], ${ \mathrm { W O } } _ { 3 } – \mathrm { T i O } _ { 2 }$ [26], ${ \bf A g I } / { \bf T i O } _ { 2 }$ [27], have been synthesized to further improve the ability of the catalysts to absorb visible light. Although the photocatalytic properties of these reported materials have been greatly improved, their large-scale applications in the field of water treatment are still restricted owing to the complicated preparation routes, high costs, low yields and poor chemical stability.

Here in, during the process of developing new $\mathrm { T i O } _ { 2 }$ -based catalysts, we accidentally discovered that although pristine $\mathrm { T i O } _ { 2 }$ had no removal effect on bisphenol A (BPA) and $\mathrm { { C r } ( V I ) }$ under visible light irradiation, when BPA and $\mathrm { C r ( V I ) }$ were mixed, it could simultaneously eliminate both BPA and $\mathrm { { C r } ( V I ) }$ . Hence, we carried out a series of in-depth research and analysis on this amazing phenomenon to explore its reaction mechanism and factors affecting its processing effect. Sincerely hoping the present study can provide a novel pathway to cope with the organic substance and heavy-metal polluted environment.

# 2.2. Experimental procedures

The catalytic reactions were carried out in a dark chamber, which is mainly composed of a $1 5 0 ~ \mathrm { ~ m l ~ }$ double-wall beaker, a xenon lamp equipped with a $4 2 0 ~ \mathrm { { n m } }$ cut-off filter, a magnetic stirrer and a cooling water circulation system. In each treatment, $5 0 ~ \mathrm { m g }$ pristine $\mathrm { T i O } _ { 2 }$ was dispersed into $1 0 0 ~ \mathrm { m l }$ of a solution containing $5 0 ~ \mathrm { m g / L }$ BPA (or AAP, TC, CBZ, phenol) and $1 0 \mathrm { \ m g / L }$ Cr (VI), and stirred in the dark for $3 0 ~ \mathrm { \ m i n }$ to establish an adsorption–desorption equilibrium. Then, turning on the xenon lamp to trigger the process with continuous stirring. At given intervals, extracting $2 ~ \mathrm { m l }$ of the reaction solution from the reactor and immediately filtering through $0 . 4 5 \mu \mathrm { m }$ filters, $1 ~ \mathrm { m l }$ was used for HPLC analysis of residual organic content, and the remaining $1 ~ \mathrm { m l }$ was used for Cr (VI) content analysis. To avoid random errors and ensure the accuracy of experimental results, all experiments were repeated three times under the same experimental conditions.

# 3.1. Excellent performance of $T \mathrm { i } O _ { 2 }$ removing BPA and Cr (VI) under visible light

Firstly, the adsorption of BPA and $\mathrm { { C r } ( V I ) }$ by $\mathrm { T i O } _ { 2 }$ in the dark was studied, because adsorption is of great significance in photocatalytic removal reaction, which is the first step of the reaction. As shown in Fig. S1, after $3 0 \ \mathrm { m i n }$ of reaction, the equilibrium between adsorption and desorption has been established, and the maximum adsorption capacity of $\mathrm { T i O } _ { 2 }$ for BPA and $\mathrm { C r } ( \mathrm { V I } )$ was merely 2.33 and $1 . 3 5 \mathrm { m g } { \cdot } \mathbf { g } ^ { - 1 }$ , respectively, demonstrating that most of the BPA and $\mathrm { { C r } ( V I ) }$ were removed through the subsequent redox reaction of the system rather than the weak adsorption of the catalyst. At the same time, it can be seen that the adsorption kinetics of $\mathrm { T i O } _ { 2 }$ on BPA and $\mathrm { C r } ( \mathrm { V I } )$ conforms to the pseudo-second-order kinetic model $( \mathrm { R } ^ { 2 } = 0 . 9 9 0 4$ and 0.9905, respectively), which indicates that chemical adsorption is the rate-limiting step of adsorption [28–30]. That is, BPA and $\mathrm { c r ( V I ) }$ form chemical bonds with a large number of active adsorption sites on the surface of $\mathrm { T i O } _ { 2 } ,$ , thus the adsorption can be realized through the combination of chemical bonds.

Further, in order to facilitate the subsequent chapters to discuss the mechanism of $\mathrm { T i O } _ { 2 }$ simultaneously removing BPA and $\mathrm { { C r } ( V I ) }$ under visible light irradiation, the reaction kinetics in these four distinct processes was investigated. In most studies, the kinetics of the photocatalytic removal reaction is usually characterized by the pseudo-firstorder kinetic model (Eq.1) when the reactants are weakly adsorbed on the catalyst surfaces [31–33].

$$
\ln ( \mathbf { C _ { \mathrm { t } } } / \mathbf { C _ { 0 } } ) = - \mathbf { k } \mathbf { t }
$$

where $\mathrm { C _ { t } }$ and ${ \mathrm { C } } _ { 0 }$ are the concentration of residual reactants at time t and time zero, respectively, and $\mathbf { k }$ is the apparent reaction rate constant $( \mathrm { m i n } ^ { - 1 } )$ ).

It can be seen from Fig. 1C and D that the fitted kinetic curves were linear, and the linear regression coefficients $( \mathbb { R } ^ { 2 } )$ surpassed $9 8 \%$ , demonstrating that the degradation process of BPA and the reduction process of $\mathrm { c r ( V I ) }$ followed the pseudo-first-order kinetic model. Theoretically, the reaction conforms to the pseudo-first-order kinetic equation, which usually indicates that the reaction takes place on the surface of the catalyst or near the solution on the surface and that the catalyst provides a surface structure favorable to the reaction [32–34]. Moreover, as shown in Fig. S4, the reaction rate constants of organics (BPA, AAP, TC) and $\mathrm { { C r } ( V I ) }$ was directly proportional to the concentration of reactants effectively adsorbed on the catalyst (see SM, Text S6 for details), which is consistent with the relationship between the reaction rate constant and the adsorption amount described by the pseudo-firstorder kinetic model [30–34]. It's also worth noting that the corresponding BPA reaction rate constant in the BPA ${ \bf \mathcal { - } C r ( V I ) { \bf - } T i O _ { 2 } / V i }$ is process was up to $0 . 0 9 5 1 \mathrm { m i n } ^ { - 1 }$ , which is approximately 237.75-, 237.75-, and 475.5-fold faster than that in the $\mathrm { B P A  – T i O _ { 2 } / V } _ { 1 }$ is, ${ \mathrm { \bf { B P A cdot C r } ( V I ) { \mathrm { - } } T i O _ { 2 } } }$ and BPA-Cr(VI)/Vis processes, respectively. Similarly, as can be observed that the reaction rate constant of $\mathrm { { C r } ( V I ) }$ reduction in the BPA-Cr (VI)- $\mathrm { T i O } _ { 2 } ,$ /Vis process was as high as $0 . 1 1 4 9 \ \mathrm { m i n } ^ { - 1 }$ , much exceeding the other three processes. Obviously, the reaction rate constant of the system lacking one of the four conditions, namely $\mathrm { C r } ( \mathrm { V I } )$ , BPA, visible light, and $\mathrm { T i O } _ { 2 }$ , is too small to achieve the simultaneous removal effect.

Combined with a large number of literatures, these results may suggest that the mechanism of this reaction is photo excited adsorbed molecules (BPA), and then the excited adsorbed molecules (BPA) interacts with ground state catalysts to conduct electrons, and electron acceptors (Cr (VI)) can effectively interact with electrons to inhibit carrier recombination only after adsorption occurs [9,31–35]. A deeper analysis of this proposed mechanism will be explored in depth in the next chapter.

In addition, TOC of these four processes were also measured to verify the feasibility of visible light-driven pristine $\mathrm { T i O } _ { 2 }$ synergistic removal of organics. As shown in Fig. S2, the TOC removal rate of BPA by BPA-Cr(VI)- $\mathrm { \ T i O } _ { 2 } ,$ /Vis process was as high as $7 1 . 9 1 \%$ , indicating that most BPA molecules were completely oxidized to inorganic substances such as $_ \mathrm { H _ { 2 } O }$ and $\mathrm { C O } _ { 2 }$ instead of various intermediates. Additionally, the evaluation of degradation products of BPA and $\mathrm { C r } ( \mathrm { V I } )$ and their environmental toxicity were conducted as well by the acute toxicity test of luminescent bacteria. The specific method refers to “ISO13829-2000 Water Quality-Determination of Genotoxicity of Water and Wastewater by UMU Test Method”, and the quantitative concentration of positive control substance (Toxic Equivalent Quantity of phenol, $\mathrm { T E Q } _ { \mathrm { p h e n o l } } )$ is used to quantify the characteristics [36–38]. Therefore, this novel method that visible light energy driving the pristine $\mathrm { T i O } _ { 2 }$ to effectively remove BPA and $\mathrm { { C r } ( V I ) }$ in concert can be an alternative strategy for wastewater treatment.

# 3.2. Mechanism insights

The previous studies have demonstrated that the adsorption of dye and other color species on $\mathrm { T i O } _ { 2 }$ can extend its photo-response from the ultraviolet to the visible-light region, which is also defined as dye sensitization or surface sensitization [9,39]. In this process, the dye molecules first absorb visible-light to form the excited species. Then, the electrons transition from the excited dye to the conduction band of $\mathrm { T i O } _ { 2 }$ . Finally, the organic dyes themselves and the co-existing organics can be oxidized by the active oxygen species generated through the reduction of $\mathrm { O } _ { 2 }$ by the conduction band electrons [9,35,39–42]. Inspired by this, we speculate that the process of removing BPA and Cr (VI) with simultaneously by pristine $\mathrm { T i O } _ { 2 }$ under visible-light is similar to that of the dye-sensitized photocatalysis. In other words, the pollutants BPA and $\mathrm { c r }$ (VI) were first adsorbed on the surface of $\mathrm { T i O } _ { 2 }$ by chemical adsorption, forming a surface structure which is conducive to BPA absorbing visible light and a transmission channel conducive to electrons migration, thus expanding the visible light response range of the system [9,39,42]. As illustrated in Fig. 2A, when exposed to visiblelight, BPA adsorbed on the surface of $\mathrm { T i O } _ { 2 }$ was excited to produce electrons. Due to the existence of semiconductor titanium dioxide, sufficient unoccupied electron acceptor state is provided, which avoids useless electrons recombination and ensures the rapid and effective injection of electrons from the excited BPA into the $\mathrm { T i O } _ { 2 }$ conduction band [9,42]. Then, some of these electrons injected into the $\mathrm { T i O } _ { 2 }$ conduction band were captured by $\mathrm { { C r } ( V I ) }$ to reduce it to $\mathrm { { C r } ( I I I ) }$ , and some electrons were captured by dissolved oxygen in water to generate superoxide radicals ${ ( 0 _ { 2 } ) } ^ { - \cdot } )$ for the oxidization of BPA. However, due to the lack of medium $\mathrm { T i O } _ { 2 }$ in BPA-Cr(VI)/Vis system, it is impossible to realize the adsorption process and to transfer electrons from excited BPA to electron acceptors $\operatorname { \rho } ( \operatorname { C r } ( \operatorname { V I } ) )$ , which results in a failure to remove BPA and $\mathrm { { C r } ( V I ) }$ simultaneously.

In the dye-sensitized photocatalysis, organic species can be degraded, such as the self-degradation of methylene blue and rhodamine B under visible light irradiation [9,40,43,44]. However, as can be seen in Fig. 1A that pristine $\mathrm { T i O } _ { 2 }$ has no degradation of BPA under visiblelight. We speculate that this is primarily owing to the rapid recombination of photoinduced electrons and holes in BPA [9,10,45–47]. When there is only BPA in the $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system, due to the rapid recombination of charge carriers, the number of photoinduced electrons that can be injected into the conduction band of $\mathrm { T i O } _ { 2 }$ is very small, resulting in very few superoxide radicals [9,11,25,48]. Therefore, even though BPA has sensitizing properties, $\mathrm { T i O } _ { 2 }$ does not degrade it under visible-light. In contrast, when BPA and $\mathrm { C r } ( \mathrm { V I } )$ co-exist, $\mathrm { C r } ( \mathrm { V I } )$ will rapidly capture photoinduced electrons and greatly promote the separation of charge carriers [10,11,49]. To confirm this, the recombination of charge carriers in different reaction systems were investigated by photoluminescence (PL). Because the recombination of electrons and holes is often accompanied by the generation of fluorescence, the more severe the recombination, the stronger the fluorescence intensity generated [45,46,50]. As shown in Fig. 2B, no fluorescence signal peak was observed in the $\mathrm { T i O } _ { 2 } ,$ /Vis system, which is mainly because $\mathrm { T i O } _ { 2 }$ cannot be excited by visible light to produce electrons and holes. In contrast, a strong fluorescence signal peak was observed in the BPA-TiO $^ { \circ } _ { 2 }$ /Vis system, indicating that BPA can be excited by visiblelight and the generated electrons/holes will quickly recombine to generate fluorescence. When $\mathrm { { C r } ( V I ) }$ was added to the $\mathrm { B P A { \cdot } T i O _ { 2 } / V }$ is system, the intensity of the fluorescent signal was significantly reduced as previously analyzed, this is mainly due to the fact that $\mathrm { { C r } ( V I ) }$ can rapidly consume electrons, thereby inhibiting the recombination of electrons and holes, leading to a significant decrease in fluorescence intensity.

In order to further investigate the electron transfer between BPA, $\mathrm { T i O } _ { 2 }$ and $\mathrm { C r } ( \mathrm { V I } )$ , the changes in current density under different systems were detected [51–53]. As shown in Fig. 2C, no current was generated in the $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system due to the fact that $\mathrm { T i O } _ { 2 }$ cannot be excited under visible light irradiation. After the addition of BPA, the current density increased rapidly and then quickly decreased and maintained at a lower level, which proved that only a few photoinduced electrons can transition to the conduction band of $\mathrm { T i O } _ { 2 }$ after BPA was excited by visiblelight, and most of the electrons recombine with holes quickly. When Cr (VI) was added to the BPA-TiO2/Vis system, the current density increased rapidly in the opposite direction, and then decreased slightly but remained at a higher level. This is mainly because of the ability of $\mathrm { { C r } ( V I ) }$ to act as an electron capture agent to promote the electron migration from $\mathrm { T i O } _ { 2 }$ to $\mathrm { C r } ( \mathrm { V I } )$ .

In the process of photocatalytic reactions, the reduction of $\mathrm { { C r } ( V I ) }$ mainly relies on photoinduced electrons with reducibility, while the degradation of organics mainly depend on oxidative active species such as hydroxyl radicals and superoxide radicals. Hence, Chemical quenching experiments were conducted to identify the main reactive species that degraded BPA, in which p-benzoquinone (BQ) and tertiary butanol (TBA) were used as scavengers for superoxide radicals $( { \bf O } _ { 2 } ^ { - } \cdot { \bf \sigma } )$ and hydroxyl radicals (•OH), respectively [51,54]. As shown in Fig. 2D, $5 \ \mathrm { m M }$ TBA had a negligible influence on BPA degradation, indicating that no hydroxyl radicals were generated in the BPA-Cr(VI)- $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system. Interestingly, the addition of p-benzoquinone (2, 5 and $1 0 \mathrm { m M } )$ ) had a very considerable impact on the degradation of BPA, with the degradation efficiencies sharply reduced from $1 0 0 \%$ to $3 1 . 7 6 \%$ , $4 . 5 1 \%$ and $1 . 9 2 \%$ respectively, demonstrating that the generated ${ { 0 } _ { 2 } } ^ { - \cdot }$ contributed significantly to the degradation of BPA.

# 3.3.1. Effect of the initial concentration of BPA

Fig. 3 exhibited the effects of the initial concentration of BPA on the simultaneous degradation of BPA and reduction of $\mathrm { { C r } ( V I ) }$ by the $\mathrm { T i O } _ { 2 } /$ Vis system. Obviously, the removal rates of both BPA and $\mathrm { { C r } ( V I ) }$ were closely related to the initial concentration of BPA. As shown in Fig. 3A and B, as the initial BPA concentration increased from $1 0 \mathrm { \ m g / L }$ to $3 0 ~ \mathrm { m g / L }$ , $5 0 ~ \mathrm { m g / L }$ , the BPA degradation efficiency in $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system continued to decrease and the corresponding BPA degradation rate constant dramatically declined from $0 . 1 3 9 9 \ \mathrm { m i n } ^ { - 1 }$ to $0 . 1 1 7 5 \ \mathrm { m i n } ^ { - 1 }$ , $0 . 0 9 5 1 \ \mathrm { m i n } ^ { - 1 }$ , and $0 . 0 2 6 9 \mathrm { \ m i n } ^ { - 1 }$ , respectively. It is worth noting that approximately $9 2 . 9 3 \%$ of BPA was removed in $2 5 \mathrm { { m i n } }$ at the initial BPA concentration of $5 0 ~ \mathrm { m g / L }$ , and the reaction rate constant is still quite high. However, merely about $7 7 . 8 6 \%$ of BPA was removed after $6 0 \mathrm { { m i n } }$ of reaction when the initial BPA concentration reached $7 0 ~ \mathrm { m g / L }$ . This may be due to the fact that the limited electron trapping agent Cr (VI) decreased with the progress of the reaction, resulting in slower electron transference and less generation of superoxide radicals, thereby slowing down the degradation rate of BPA. In contrast, as presented in Fig. 3C and D, the reduction efficiency of $\mathrm { { C r } ( V I ) }$ at the same moment during the reaction process significantly improved with the increase of initial BPA concentration. In particular, when the initial BPA concentration further increased to 50 and $7 0 \mathrm { \ m g / L }$ , the $\mathrm { C r } ( \mathrm { V I } )$ was almost completely eliminated within $2 5 \ \mathrm { m i n }$ , and the corresponding reaction rate constants were as high as $0 . 1 1 4 9 \mathrm { \ m i n } ^ { - 1 }$ and $0 . 1 4 3 9 \ \mathrm { m i n } ^ { - 1 }$ , respectively. This phenomenon could be attributed to the higher initial BPA concentration producing more photoinduced electrons, which greatly facilitated the capture of electrons by Cr (VI) and ultimately promoted the reduction of Cr (VI) to $\mathrm { { C r } ( I I I ) }$ . Therefore, given both BPA degradation and $\mathrm { { C r } ( V I ) }$ reduction, the optimal BPA concentration of $5 0 ~ \mathrm { m g / L }$ was selected in the following study.

# 3.3.2. Effect of the crystal structure of pristine $T \mathrm { i } O _ { 2 }$

The simultaneous removal performance on BPA and $\mathrm { { C r } ( V I ) }$ by three commonly used titanium dioxides with different crystal structures, including rutile $\mathrm { T i O } _ { 2 } ,$ , OPV-P25 $\mathrm { T i O } _ { 2 } ,$ , anatase $\mathrm { T i O } _ { 2 }$ , was compared. 237.75- and 1.42-times faster than that of rutile $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system and OPV-P25 $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system, respectively. Similarly, as depicted in Fig. 4B, no reduction of $\mathrm { c r ( V I ) }$ was observed via rutile $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system, and the OPV-P25 $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system had a medium effect on $\mathrm { { C r } ( V I ) }$ reduction. The maximum photocatalytic reduction efficiency of $\mathrm { { C r } ( V I ) }$ was achieved by anatase $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system, and the corresponding reduction rate constant was 229.8- and 2.20-times faster than that of rutile $\mathrm { T i O } _ { 2 } ,$ /Vis system and OPV-P25 $\mathrm { T i O } _ { 2 } / \mathrm { V i s }$ system. The result could ascribe to the difference in the band alignment of rutile and anatase $\mathrm { T i O } _ { 2 }$ , as well as the complicated process of electrons transfer from the excited BPA to the catalyst conduction band. Recent research is suggesting that the conduction band of anatase is actually lower than that of rutile [19,55–57], thereby the electrons generated by the excitation of BPA can jump to the conduction band of anatase rather than to rutile. Moreover, anatase possesses the higher electron affinity due to rich defects [55–57], resulting in a significant enhancement in charge transfer from stimulated state BPA to titanium dioxide. Therefore, visible light can only drive anatase to synergistically remove BPA and $\mathrm { { C r } ( V I ) }$ .

The effect of initial solution $\mathsf { p H }$ on the removal rates of BPA and Cr (VI) was further investigated, since the $\mathsf { p H }$ of the solution has been recognized as a key parameter in chemical reactions. Similarly, Fig. 6C and D show that the reduction of $\mathrm { C r } ( \mathrm { V I } )$ was greatly influenced by different initial pH (2.28–11.39), and acidic conditions were more favorable for $\mathrm { c r }$ (VI) reduction. Compared with $\mathrm { p H } 5 . 3 6 $ , the Cr (VI) reduction efficiency and reaction rate constant of the system decreased slightly at $\mathrm { p H } 2 . 2 8 $ . # 3.3.5. Effect of the common inorganic anions

Considering that the presence of a large number of common inorganic anions in natural water will have a significant impact on the removal of pollutants, we investigated the effect of inorganic anions on the removal of BPA and $\mathrm { c r }$ (VI) in the BPA-Cr(VI)-TiO2/Vis system by using $1 0 \ \mathrm { m M \ C l ^ { - } }$ , $\mathsf { C O _ { 3 } } ^ { 2 - }$ , $\mathrm { H _ { 2 } P O _ { 4 } } ^ { - }$ , ${ \ S O _ { 4 } } ^ { 2 - }$ , and ${ \mathrm { N O } } _ { 3 } { } ^ { - }$ . # 3.5. Pristine $T \mathrm { i } O _ { 2 }$ recycling experiment

In order to evaluate the catalytic performance of the pristine $\mathrm { T i O } _ { 2 }$ more comprehensively, recycling experiments were conducted under the identical experimental conditions with the aim of measuring the stability of the catalyst. As presented in Fig. 9A, the degradation efficiency of BPA significantly declined to $3 1 . 4 5 \%$ and $1 3 . 1 7 \%$ in the second and third runs, respectively, while in the first round it was close to $1 0 0 \%$ within $6 0 ~ \mathrm { { m i n } }$ . Similarly, it can be observed from Fig. 9B that the removal efficiency of $\mathrm { C r } ( \mathrm { V I } )$ also showed the same downward trend, that is, from $1 0 0 \%$ in the first run to $3 1 . 5 1 \%$ and $1 3 . 2 1 \%$ in the second and third runs. Such notable decrease in the simultaneous removal performance of BPA and $\mathrm { { C r } ( V I ) }$ may be due to the adsorption of organics, chromium and other intermediates on the surface of titanium dioxide. As a result, the active sites on the surface of titanium dioxide were occupied, which hindered the electrons generated by the BPA excitation from being transferred to hexavalent chromium through the mediator titanium dioxide. Many researches have confirmed that the recalcination of anatase titanium dioxide at 400 degrees will not destroy its crystal structure, and can remove the organic intermediates adsorbed on the surface of titanium dioxide, so as to restore its catalytic activity [11,50,51]. Therefore, the third recovered pristine $\mathrm { T i O } _ { 2 }$ was recalcined at 400 degreesC for $^ { 2 \mathrm { ~ h ~ } }$ and then was put into reuse under the same reaction conditions. As shown in Fig. 9A and B, the removal efficiencies of BPA and $\mathrm { C r } ( \mathrm { V I } )$ in the recovery experiment could reach about $4 8 . 4 8 \%$ and $4 8 . 5 5 \%$ , respectively, which were higher than those in the second and third cycles. These results confirmed that it was the organics and chromium adsorbed on the surface of titanium dioxide that affected its catalytic activity, and part of its activity could be restored by removing the organic matter during calcination.

# 4. Conclusions

In this study, we found a synergistic removal effect on organics and hexavalent chromium by pristine $\mathrm { T i O } _ { 2 }$ under visible light irradiation. Based on the outstanding performance of BPA degradation and $\mathrm { { C r } ( V I ) }$ reduction, photoluminescence (PL), electrochemical characterization and chemical quenching experiments were utilized to explore the reaction mechanism. In this process, it was BPA excited by visible light irradiation to produce electrons that can be injected into the conduction bands of titanium dioxide. Then, the excellent electron receptor $\mathrm { { C r } ( V I ) }$ captured some of these transferred electrons to facilitate its reduction to $\mathrm { { C r } ( I I I ) }$ , and the dissolved oxygen scavenged others to produce superoxide radicals ${ ( 0 _ { 2 } ) } ^ { - } \dot { } \mathrm { ~ ) ~ }$ that degraded BPA. In addition, the crystal structure of titanium dioxide has an obvious effect on the photocatalytic reaction, that is, visible light was unable to drive rutile synergistic removal both BPA and $\mathrm { C r } ( \mathrm { V I } )$ , whereas anatase displayed the optimum ability for cooperatively removing BPA and $\mathrm { C r } ( \mathrm { V I } )$ . Overall, the results provide a novel strategy toward environmental remediation that is distinct from the traditional regulation and modification of catalyst structure, shining a light on the use of visible light to simultaneously remove refractory organics and high-priced heavy metal pollutants in wastewater.
