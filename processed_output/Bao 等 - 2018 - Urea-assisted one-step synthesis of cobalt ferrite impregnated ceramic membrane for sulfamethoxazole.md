In this study, a novel $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ nanocatalyst impregnated $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ ceramic membrane was prepared via a urea-assisted one-step combustion method. The catalytic membrane was characterized by field emission scanning electron microscopy (FESEM) with energy dispersive X-Ray analysis (EDX) and applied for the catalytic degradation of sulfamethoxazole (SMX) under a dead-end membrane filtration mode for the first time. Results indicate that ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ could be impregnated into the macropores throughout the whole $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ ceramic membrane via this method and the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ loading amount could be controlled by the multiple impregnation cycles. The membrane filtration operation mode significantly enhances the accessibility of the catalytic active sites to PMS and SMX in microreactor environment and thus the ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated membrane displays excellent catalytic activity for the SMX degradation. The pure water permeability flux can maintain at $\sim 3 0 0 0 \mathrm { ~ L ~ m } ^ { - 2 } \mathrm { ~ h } ^ { - 1 }$ bar-1 (LMHB) with the catalyst loading amount of $0 . 0 1 5 ~ \mathrm { g / g } ~ \mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ . In the membrane filtration system, the removal rate of SMX with the initial concentration of $1 0 ~ \mathrm { m g }$ $\mathrm { L } ^ { - 1 }$ can achieve to ${ \sim } 9 8 \%$ , $7 0 \%$ and $4 0 \%$ with the residence time of 90, 36 and $1 8 \mathrm { ~ s ~ }$ . The catalytic membrane shows a great tolerance at wide $\mathrm { p H }$ range (3-11), existence of humic acid and anions. Meanwhile, the membrane shows self-cleaning property by retaining $> 9 0 \%$ of initial flux after 3 treatment cycles. Electron paramagnetic resonance (EPR) and radical quenching experiments indicate that both sulfate radical and hydroxyl radical are generated and sulfate radical is the dominate active species in the process.

Key words: Cobalt ferrite; Combustion; Peroxymonosulfate; Sulfamethoxazole; Hybrid membrane; Sulfate radical

1. Introduction

As one of the most widely used antibiotics, sulfamethoxazole (4-amino-N-(5-methyl3-isoxazolyl)-benzene sulfonamide, SMX) is a broad-spectrum sulfonamide used against both Gram-positive and Gram-negative aerobic bacteria. The uncontrolled use of antibiotics can lead to water pollution resulting in undesired chronic effects on ecological system and induce the emergence of antibiotic resistance pathogenic microorganisms [1]. Up to date, SMX has been detected in various municipal sewage treatment plants, hospital effluents, surface water and even drinking water system [2–5]. Because of its extensive usage and resistance to natural biodegradation, it cannot be treated effectively by the conventional treatment methods [6,7]. A potential strategy to eliminate aqueous SMX could be via advance oxidation processes.

Among various advanced oxidation processes, sulfate radical-based advanced oxidation technology has recently emerged as a potential solution for removing recalcitrant organic pollutants in water [8]. The $\mathrm { S O } _ { 4 }$ - is a highly reactive radical with redox potential of 2.60 and it can react with the target organic pollutants via electron transfer reaction [9,10]. Meanwhile, compared to the HO, $\mathrm { S O } _ { 4 }$ - has a longer lifetime thus allowing it to react effectively with the target organic pollutants. The $\mathrm { S O } _ { 4 }$ - radicals can be generated from peroxymonosulfate (PMS) via thermal activation, ultraviolet irradiation, ultra-sonication, and catalytic activation with transition metals [11,12]. Among them, the activation via metal catalyst has been widely accepted as the more economical one because there is no need for the constant supply of external energy [13].

Comparing with other transition metal catalysts, cobalt ion and its composites were reported to be more efficient as PMS activators in degradation of most organic pollutants [14,15]. Meanwhile, iron has been widely applied in water treatment because of its low cost, abundant supply, low toxicity and environmental friendliness. The addition of iron into cobalt compound can not only enhance PMS activation through enriching hydroxyl groups on the catalyst surface, but also endow the catalyst with easier separation and recovery properties due to its magnetism and suppress cobalt leaching owing to the strong Co-Fe interactions [16].

However, the catalytic applications of metal catalysts still face challenges, including the undesirable agglomeration of metal catalysts and the limited utilization of active sites [17,18]. To address these limitations, metal catalysts could be designed to be wrapped into porous ceramic membranes, which show high stability as well as large surface area because of the numerous internal pores. Another advantage for membrane reactor is that fluids can bring the reactants to the active catalyst surface and constantly remove the products from the reaction zone [19], leading to enhanced mass transfer via faster conversion of reactants.

Herein, a simple urea-assisted one-step combustion method was used to prepare ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated $\mathbf { A l } _ { 2 } \mathbf { O } _ { 3 }$ ceramic membrane. To our knowledge, this is the first report on loading mixed metal oxides into ceramic membrane pores via this method. Also, the performance of catalytic ceramic membrane impregnated with $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ was evaluated in a membrane filtration system for the first time. Meanwhile, a comprehensive performance evaluation of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst as PMS activator for SMX degradation was investigated and the SMX degradation pathway was proposed via the determination of dominant radicals and the SMX degradation products in the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } / \mathrm { \Omega }$ membrane/PMS system.

# 2.1. Chemicals and materials

Sulfamethoxazole (SMX), cobalt(II) nitrate hexahydrate $( \mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O } )$ , humic acid (HA), nitric acid $\mathrm { ( H N O } _ { 3 } ,$ ), Sodium hydroxide (NaOH), glacial acetic acid $\mathrm { ( C _ { 2 } H _ { 4 } O _ { 2 } ) }$ , formic acid $\mathrm { C H } _ { 2 } \mathrm { O } _ { 2 }$ ), acetonitrile $\mathrm { ( C _ { 2 } H } _ { 3 } \mathrm { N ) }$ , tert-butanol $\mathrm { ( C _ { 4 } H _ { 1 0 } O ) }$ and methanol $\mathrm { C H } _ { 4 } \mathrm { O } _ { \it \Pi }$ were purchased from Sigma-Aldrich. Iron(III) nitrate nonahydrate $( \mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } \mathrm { O } ) $ was received from Acros organics. Urea ( $\mathrm { C H } _ { 4 } \mathrm { N } _ { 2 } \mathrm { O } ) ,$ was supplied by VWR. Oxone (PMS, $2 \mathrm { K H S O } _ { 5 }$  $\mathrm { K H S O _ { 4 } }$ ${ \bf K } _ { 2 } { \bf S O } _ { 4 }$ ) was supplied by Alfa Aesar. Sodium chloride (NaCl), sodium sulfate $\mathrm { ( N a _ { 2 } S O _ { 4 } ) }$ ), sodium nitrite $\left( \mathrm { N a N O } _ { 3 } \right)$ ) and sodium carbonate $\mathrm { ( N a _ { 2 } C O _ { 3 } ) }$ ) were from Merck. 5,5-dimethyl-1-pyrrolidine N-oxide (DMPO) was purchased from Aladdin and 5-tertButoxycarbonyl-5-methyl-1-pyrroline-N-oxide (BMPO) was from Cayman Chemical. All chemicals were of reagent grade or higher and were used without further purification. All solutions were prepared in deionized (DI) water (18.2 MΩ.cm at $2 5 ^ { \circ } \mathrm { C }$ ) from a Milli-Q purification system. Porous $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ -based filter substrates used in this work were disc shaped with a diameter of $2 2 ~ \mathrm { m m }$ and a thickness of $2 \mathrm { m m }$ . In the following part in this work, the porous $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ -based filter substrates were referred as membrane.

# 2.2. Preparation and characterization of $C o F e _ { 2 } O _ { 4 }$ impregnated membrane

Impregnation of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ in $\mathrm { { A l } } _ { 2 } \mathrm { { O } } _ { 3 }$ -based ceramic membrane pores via a urea-assisted one-step combustion method is shown in Fig S1. Briefly, the membranes were firstly washed with DI water and dried in oven at $1 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 4 \mathrm { ~ h ~ } }$ . Before the impregnation process, the disc was weighed as $\mathrm { W } _ { 0 }$ . Subsequently, 1-3 pieces of discs were immersed into $1 0 ~ \mathrm { m L }$ of the impregnation solution, which is a mixture of urea, $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ and $\mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } \mathrm { O }$ . After 30 min immersion, an additional force was applied on the solution to penetrate the pores, after the excess solution was drained off, the discs were put in a furnace with settled temperature. To get the ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated $\mathbf { A l } _ { 2 } \mathbf { O } _ { 3 }$ ceramic membrane, the discs were calcined for $3 0 \ \mathrm { m i n }$ in an air atmosphere. After the calcination, the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ ceramic membrane was weighed as $\mathrm { W } _ { 1 }$ . The final catalyst loading amount was calculated by the weight difference $\mathbf { W } = \mathbf { W } _ { 1 } – \mathbf { W } _ { 0 }$ . Meanwhile, the residual impregnation solution was put into the furnace at the same condition to get the ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ powders. For the multiple impregnation experiments, all previous steps (immersion and calcination) were repeated.

Brunauer-Emmett-Teller (BET) gas sorptometry measurements were conducted to examine the porous nature of the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ particle using Quantachrome Autosorb -1 Analyzer at liquid $\Nu _ { 2 }$ temperature of $7 7 ~ \mathrm { K }$ . The pulverized ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ powders were degassed at $1 5 0 \mathrm { { } ^ { \circ } C }$ for $^ { 5 \mathrm { ~ h ~ } }$ prior to the actual measurement. The Brunauer-Emmett-Teller surface area $( S _ { \mathrm { B E T } } )$ was calculated based on BET model [20].

The surface morphologies and particle sizes were obtained by field emission scanning electron microscope (FESEM, JSM-7600F, JEOL, Japan). The distribution of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ into the $\mathbf { A l } _ { 2 } \mathbf { O } _ { 3 }$ disc was examined by energy dispersive X-ray spectroscopy (EDX) techniques. Prior to the analysis, the samples were coated with platinum using Auto Fine Coater (JEC300FC, JEOL, Japan) to reduce the effect of surface charging. The mineralogy and crystal structures of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ particles were analyzed using X-rays diffractometer (XRD, Bruker D8 Advance) with a monochromated high intensity $\mathrm { { C u - K _ { a } } }$ $\lambda { = } 1 . 5 4 \mathrm { ~ \AA }$ radiation over a 2θ range of $1 5 – 7 5 ^ { \circ }$ at a step size of 0.02 combined with a rotation speed of $1 5 ~ \mathrm { r m p }$ . Zeta potential $( \zeta )$ of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ in water solution was measured by a zetasizer (Malvern, UK).

To further detect the chemical states of the elements in ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , X-ray photoelectron spectroscopy (XPS) analysis was conducted on a Kratos Axis Supra spectrophotometer (Shimadzu) equipped with a dual anode monochromatic Kα excitation source $h \nu = 1 4 8 6 . 7$ eV). All binding energies for elements of interest were corrected against an adventitious carbon C 1s core level at $2 8 4 . 8 \ \mathrm { e V }$ . All XPS peaks were fitted using Shirley background together with Gaussian-Lorentzian function.

For batch experiment, unless otherwise specified, all degradation experiments were carried out in $1 0 0 ~ \mathrm { m L }$ glass beakers at room temperature with magnetic stirring at $5 0 0 \ \mathrm { r p m }$ . Before the reaction, SMX with a certain concentration was prepared in the beakers followed by the addition of Oxone. Later, the catalysts or catalytic membranes were loaded into the solution to activate the reaction. Samples were withdrawn at specified time intervals followed by the addition of methanol to quench the reaction. The samples were then filtered with 0.45 $\mu \mathrm { m }$ polytetrafluoroethylene (PTFE) syringe filters and transferred into auto-sampler vials for further analysis.

2.4. Determination of chemicals and degradation products

The concentration of SMX was determined using a liquid chromatography system (Shimadzu, LC-2030C-3D) equipped with a C-18 column. The mobile phases were methanol and $0 . 1 \%$ acetic water (v/v, 60/40) at a flow rate of $0 . 8 ~ \mathrm { m L ~ m i n } ^ { - 1 }$ . The UV detector was operated at a wavelength of $2 6 4 ~ \mathrm { n m }$ and the injection volume is $1 0 ~ \mu \mathrm { L }$ . The intermediates were further analyzed using an Agilent 1290 Infinity HPLC coupled to an Agilent 6460 Triple quadruple mass spectrometry, which was equipped with an Electrospray ionization (ESI) source using Agilent Jet Stream Technology (Agilent, USA). The mobile phases consisted of water with $0 . 1 \%$ formic acid and acetonitrile with $0 . 1 \%$ formic acid. Separations were performed using a $7 5 \mathrm { m m } \times 2$ mm Luna $3 \mu \mathrm { C } 1 8$ column. The total organic carbon (TOC) before and immediately after the catalytic reaction without addition of methanol was measured using a TOC analyzer (Shimadzu ASI-V TOC analyzer) and the nitrate in solution was detected by ion chromatography (Dionex, ICS-1100) using the mixture of $\mathbf { N a } _ { 2 } \mathbf { C O } _ { 3 }$ and $\mathrm { N a H C O } _ { 3 }$ as the effluent. The mass of leached metal ions was measured by inductively coupled plasma optical emission spectrometry (ICP-OES, Optima 8000, Perkin Elmer).

Quenching experiments were conducted with the addition of methanol and tertbutanol for identifying the primary radical species. Electron paramagnetic resonance (EPR) experiments were performed using DMPO and BMPO as spinning agents via a Bruker Biospin ELEXSYS II E500 EPR spectrometer in continuous wave X-band mode. The modulation amplitude was $1 . 0 \ G$ and the EPR spectra were analyzed by the spin-fitting package of Bruker Xeon software.

3. Results and discussion   
3.1. Study of the urea-assisted one-step combustion method

The effect of calcination temperature on the morphology, crystal structure and catalytic performance of as-prepared $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ particle was investigated (Fig S2). The SEM images of all catalysts prepared under different calcination temperatures $\mathrm { 3 0 0 \mathrm { ~ - ~ } 8 0 0 ^ { \circ } C }$ ) show the similar surface morphology composing of closely packed particles with a particle size of $5 0 \textrm { - } 1 0 0 \ \mathrm { n m }$ . The intensity of the diffraction peaks increased with the increase of calcination temperature from 300 to $6 0 0 ~ ^ { \circ } C$ , indicating the higher crystallinity and larger particle size. Interestingly, when the calcination temperature increased to $8 0 0 ^ { \circ } \mathrm { C }$ , the characteristic peak of (311) for $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ deceased with the appearance of new peaks, meaning the crystal structure changed under high calcination temperature (Fig S2e). The catalytic performance of catalysts prepared with different calcination temperatures was investigated in a SMX/Oxone batch system. As shown in Fig S2f, the degradation efficiency of SMX decreased with increasing of calcination temperature. When the calcination temperature was increased from 300 to $8 0 0 \mathrm { { } ^ { \circ } C }$ , the SMX removal in $6 0 \ \mathrm { m i n }$ in this system decreased from $9 2 . 4 \%$ to $2 4 . 5 \%$ . That could be caused by the lower crystallinity of the catalyst prepared at $3 0 0 ^ { \circ } \mathrm { C }$ , indicating the presence of more defects which is in favor of electron transfer. Meanwhile, the leached metal ions due to the low crystallinity should be also considered (Table S1). Another reason is the particle aggregation increased with the increase of calcination temperature, resulting a larger particle size (Figs S2 a-d).

Fig 2 displays the $\Nu _ { 2 }$ adsorption-desorption isotherm and corresponding pore size distribution (inset) of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ particle. The sharp distribution of pore diameter around 1.8 nm suggests that the NPs have high monodispersity. The isotherm with hysteresis loop at relatively high pressure of $0 . 4 \textrm { - } 1 . 0$ indicates the existence of meso-pores to micro-pores generated due to the accumulation of nanoparticles. The BET specific surface area of the sample was calculated from $\Nu _ { 2 }$ isotherms at $7 7 ~ \mathrm { K }$ , and was found to be as much as about 57.5 $\mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 }$ . The single-point total volume of pores was calculated as $0 . 1 0 \mathrm { c m } ^ { 3 } \mathrm { g } ^ { - 1 }$ . The high BET surface area and low total pore volume strongly supported the fact that the NPs have a nonporous structure with small particles [21,22], which is in good accordance with the SEM results (Fig S2 a).

The crystalline structure of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ was determined by XRD (Fig 2b), the diffraction peaks at $3 5 . 5 ^ { \circ }$ , $5 3 . 5 ^ { \circ }$ and $6 2 . 6 ^ { \circ }$ of as-prepared catalyst can be attributed to ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ spinel ferrite (04-007-8945 in the database of PDF- $4 { + } 2 0 1 5$ RDB), corresponding to (311), (422) and (440).

# 3.3.1 Batch experiment

In a batch experiment, the catalytic performance of the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane was investigated. Typically, the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membranes with different coating cycles were fully submerged in $5 0 ~ \mathrm { m L }$ solution of $1 0 \mathrm { m g { L } ^ { - 1 } }$ SMX. Oxone was then added into the solution to activate the reaction. Solution samples were withdrawn at specified time intervals followed by the addition of methanol to quench the reaction before the further analysis.

Fig 6 shows the contribution of SMX removal by pristine membrane is much slighter compared with that of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated membranes. In this study, the catalyst loading amounts are 0.015, 0.035 and $0 . 0 8 ~ \mathrm { g } / \mathrm { g }$ $A 1 _ { 2 } O _ { 3 }$ for #1, #3 and #5, respectively, which could be ignored compared with the pristine $A 1 _ { 2 } O _ { 3 }$ substrate $\sim 2 \textrm { g }$ . Therefore, the surface area difference caused by the catalyst loading was not considered in the study. With increase of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ loading amount, a higher density of redox active catalytic sites for $\mathrm { S O } _ { 4 }$ -  generation from PMS activation could be achieved. However, the SMX degradation did not show significant difference with increasing ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ amount, meaning that compared with radical generation process, mass transfer is the rate-determining step in this system.

3.3.2 Hybrid membrane filtration experiment

In the hybrid membrane filtration system, #1 was chosen to investigate the effects of flow rate, PMS dosage and $\mathrm { p H }$ on SMX removal efficiency. As shown in Fig 7a, when the flow rate is set at $0 . 2 ~ \mathrm { m L ~ m i n } ^ { - 1 }$ with a calculated contact time of $9 0 ~ \mathrm { s }$ , nearly $1 0 0 \%$ removal of SMX could be achieved with the Oxone dosage of $0 . 1 \ \mathrm { g } \ \mathrm { L } ^ { - 1 }$ . While, when the flow rate is increased to $1 ~ \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ to shorten the catalytic reaction time to $1 8 ~ \mathrm { s }$ , the removal efficiency decreases to around $4 0 \%$ . Meanwhile, the removal of SMX by direct membrane filtration (no Oxone) is negligible. A higher PMS dosage increases the probability of PMS and $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ interaction, resulting in a higher SMX degradation rate.

Fig 7b shows the effect of initial pH on the SMX removal in the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } /$ membrane/PMS system. Under acidic condition $\mathrm { ( p H ~ } 3 \mathrm { - } 7$ ), the Oxone stabilization effect promotes the adherence of $\mathrm { H } ^ { + }$ to the electronegative peroxide bond (-O-O-) [26]. Similarly, the surface of the catalyst which consists of abundant hydroxyl groups (-OH) is also protonated ( $\cdot \mathrm { O H } _ { 2 } ^ { + \cdot }$ ) leading to the positive charged surface (Fig S5a) [27,28]. The -OH group has a critical role in Oxone activation process while - $\mathrm { \cdot O H } _ { 2 } ^ { + }$ has deleterious effect on the overall catalytic activity [29]. These factors could lead to the inherent negative effect on the catalytic activity in acidic condition.

Interestingly, when pH value was increased from 9 to 11, the catalytic degradation of SMX in $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system is inhibited (Fig 7b). The increase of $\mathrm { p H }$ can raise the amount of negative surface charge of the catalyst as well as SMX molecular (Fig. S5b), resulting in the electrostatic repulsion [30,31] . Meanwhile, since the $\mathrm { p K _ { a } }$ of $\mathrm { H S O } _ { 5 } \mathrm { ^ - } > 9 . 4$ [32], higher pH can also increase the proportion of less oxidative ${ \mathrm { S O } } _ { 5 } { } ^ { 2 - }$ by the deprotonation of PMS [33]. Another effect of $\mathrm { p H }$ is that it can affect the reactive species. When $\mathrm { S O } _ { 4 }$ - are generated, HO, which can also attack SMX, could be introduced into the system particularly under moderate alkaline condition. However, oxidation potential of HO decreases linearly with pH and the generated HO $( \mathsf { p K } _ { \mathrm { a } } = 1 1 . 9 )$ ) becomes unstable and tends to decompose under high pH value.

Durability of membrane could significantly lower the operation cost of water and wastewater treatment plants. A representative #1 membrane was used for 3 treatment cycles of $1 0 \mathrm { m g } \mathrm { L } ^ { - 1 }$ SMX solution with the flux of 236 LMH, and the results are shown in Fig 7c. A stable SMX removal efficiency could be maintained on $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane over multiple cycles of 60 min each. In this system, average cobalt ion leaching was recorded as $0 . 0 4 ~ \mathrm { m g ~ L } ^ { - 1 }$ in the effluent during each treatment cycle. The decrease of SMX removal in each cycle could be explained by the accumulative adsorption of SMX onto/into the membrane, reducing the density of active catalytic sites. However, upon each cleaning cycle with Oxone for $5 ~ \mathrm { { m i n } }$ , more than $9 5 \%$ of the SMX removal efficiency could be recovered, indicating the reusability potential of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated membrane via Oxone-assisted self-cleaning. During multiple-cycle experimental run, the permeability flux was maintained at $> 9 8 \%$ of the initial flux.

# 3.3.3 Effects of NOM and anions

Natural organic matter (NOM) is one type of substances existing in water and plays a number of important roles including controlling the pH balances, governing the mobility of contaminants through adsorption, aggregation and sedimentation, and chelating metals [30,34]. HA as one typical model was chosen to investigate the effect of NOM on the degradation of SMX in $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } /$ membrane/PMS system.

As shown in Fig 8a, at low concentration of HA $( 5 \mathrm { \ p p m } )$ , there is a slightly enhancement on the SMX degradation. This could be caused by the sensitizer function of HA to produce various reactive species [35]. While with the increasing of HA concentration, the inhibiting effect became more obvious. The inhibition is caused by the attachment of HA on the active sites of catalyst as well as the radical quenching effects to hinder the catalytic process. The results showed that the catalytic performance of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ might be suppressed in natural water which consists of NOM.

# 3.4. Proposed SMX degradation mechanism

Since the contributions of SMX degradation by direct Oxone oxidation and catalyst adsorption are negligible (Fig S6), the radical-based oxidation process was deduced as the mechanism of SMX degradation. Previous investigations have pointed out that in the $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system, $\mathrm { S O } _ { 4 }$  - and HO can always be identified as the main reactive species [43]. Therefore, an attempt with EPR experiments was made to verify the presence of $\mathrm { S O _ { 4 } }$ - and HO in $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system. As shown in Fig 9a, there were no obvious characteristic signals present in the EPR spectra of experiments conducted with DMPO $^ +$ Oxone $^ +$ SMX system. However, in the presence of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ , the characteristic signals of 5,5-dimethyl-2- pyrrolidone-N-oxyl (DMPOX) with heptet were detected, which was formed by the oxidation of DMPO via HO [44,45]. When BMPO was used as the spin trapping agent (Fig 9b), sevenline spectrum can be observed, which can be assigned to 5-tert-butoxycarbonyl-5-methyl-2- oxo-pyrroline-1-oxyl (BMPOX), a reaction product of BMPO with $\mathrm { S O } _ { 4 }$ -  [46].

Based on the metal ions leaching results (Table S1), it shows the surface active $\mathrm { C o } ^ { 2 + }$ should play a critical role in the decomposition of O-O bond in Oxone to generate sulfate radicals (Eq. 10). Meanwhile, the active $\mathrm { C o } ^ { 2 + }$ can react with hydroxyl group to form Co-OH complexes, which would further react with $_ \mathrm { H S O _ { 5 } }$ to generate sulfate radicals (Eq. 16) [49]. The transformation from $\mathrm { C o } ^ { 2 + }$ to $\mathrm { C o } ^ { 3 + }$ could be well demonstrated by the difference of XPS Co2p spectra before and after reaction. As shown in Fig 3b, the Co 2p3/2 peak (centered at 779.3 eV) of fresh $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ was attributed to the $\mathrm { C o } ^ { 2 + }$ . However, a new component (785.3 eV) occurred after the oxidation reaction, which was ascribed to the $\mathrm { C o } ^ { 3 + }$ in octahedral sites (Fig S8) [50,51].

This result indicated that SMX mineralization occurred during the catalytic degradation, whereas most of SMX molecules were probably transformed into other intermediates rather than being completely oxidized to $\mathrm { C O } _ { 2 }$ and $_ \mathrm { H _ { 2 } O }$ . Peaks at $\mathrm { m } / \mathrm { z }$ 99.1, 147.1, 158.1, 267.4 and 274.4 were detected. Subsequently, the electron transfer reaction between $\mathrm { S O } _ { 4 }$  - and the amine group can form nitro-SMX molecule $( \mathrm { m } / z 2 6 7 . 4 )$ ) [52]. The radicals can attack the $\mathrm { C } { = } \mathrm { C }$ to form C-C $( \mathrm { m / z ~ } 1 4 7 . 1 $ ) followed by the formation of inorganic ions $\left( \mathrm { N O } _ { 3 } \right)$ and mineral acid via ring opening reactions.

# 4. Conclusions

This study investigated the activation of PMS by $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ ceramic membrane to degrade SMX in a membrane filtration system. It is the first report on the one-step combustion synthesis of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane and the utilization of SMX degradation in an integrated continuous system. Based on the results presented, the following conclusions are drawn:

1) A robust and uniform $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane could be successfully prepared via a urea-assisted one-step combustion method.   
2) The pure water permeability flux can maintain at $\sim 3 0 0 0 \mathrm { L } \mathrm { m } ^ { - 2 } \mathrm { h } ^ { - 1 }$ bar-1 (LMHB) with the catalyst loading amount of $0 . 0 1 5 \ \mathrm { g / g } \ A l _ { 2 } \mathrm { O } _ { 3 }$ .   
3) The $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane could be applied in an integrated continuous filtration system and the SMX removal could achieve at nearly $1 0 0 \%$ at the contact time of $9 0 \mathrm { s }$ .   
4) The ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated membrane shows a great durability potential via Oxone-assisted self-cleaning as well as great tolerance at a wide pH range (3-11), existence of NOM and different anions.   
5) The degradation of SMX started from the cleavage of sulfonamide bond and the formation of mono-hydroxylated derivative, in which the major reactive radical is $\mathrm { S O } _ { 4 }$ - in natural pH condition.

Overall, the novel $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane exhibits a promising prospect for numerous catalytic application. Meanwhile, the urea-assisted one-step combustion is a promising method for impregnation of nanocatalysts into ceramic membrane pores.

1. Introduction

As one of the most widely used antibiotics, sulfamethoxazole (4-amino-N-(5-methyl3-isoxazolyl)-benzene sulfonamide, SMX) is a broad-spectrum sulfonamide used against both Gram-positive and Gram-negative aerobic bacteria. The uncontrolled use of antibiotics can lead to water pollution resulting in undesired chronic effects on ecological system and induce the emergence of antibiotic resistance pathogenic microorganisms [1]. Up to date, SMX has been detected in various municipal sewage treatment plants, hospital effluents, surface water and even drinking water system [2–5]. Because of its extensive usage and resistance to natural biodegradation, it cannot be treated effectively by the conventional treatment methods [6,7]. A potential strategy to eliminate aqueous SMX could be via advance oxidation processes.

Among various advanced oxidation processes, sulfate radical-based advanced oxidation technology has recently emerged as a potential solution for removing recalcitrant organic pollutants in water [8]. The $\mathrm { S O } _ { 4 }$ - is a highly reactive radical with redox potential of 2.60 and it can react with the target organic pollutants via electron transfer reaction [9,10]. Meanwhile, compared to the HO, $\mathrm { S O } _ { 4 }$ - has a longer lifetime thus allowing it to react effectively with the target organic pollutants. The $\mathrm { S O } _ { 4 }$ - radicals can be generated from peroxymonosulfate (PMS) via thermal activation, ultraviolet irradiation, ultra-sonication, and catalytic activation with transition metals [11,12]. Among them, the activation via metal catalyst has been widely accepted as the more economical one because there is no need for the constant supply of external energy [13].

Comparing with other transition metal catalysts, cobalt ion and its composites were reported to be more efficient as PMS activators in degradation of most organic pollutants [14,15]. Meanwhile, iron has been widely applied in water treatment because of its low cost, abundant supply, low toxicity and environmental friendliness. The addition of iron into cobalt compound can not only enhance PMS activation through enriching hydroxyl groups on the catalyst surface, but also endow the catalyst with easier separation and recovery properties due to its magnetism and suppress cobalt leaching owing to the strong Co-Fe interactions [16].

However, the catalytic applications of metal catalysts still face challenges, including the undesirable agglomeration of metal catalysts and the limited utilization of active sites [17,18]. To address these limitations, metal catalysts could be designed to be wrapped into porous ceramic membranes, which show high stability as well as large surface area because of the numerous internal pores. Another advantage for membrane reactor is that fluids can bring the reactants to the active catalyst surface and constantly remove the products from the reaction zone [19], leading to enhanced mass transfer via faster conversion of reactants.

Herein, a simple urea-assisted one-step combustion method was used to prepare ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated $\mathbf { A l } _ { 2 } \mathbf { O } _ { 3 }$ ceramic membrane. To our knowledge, this is the first report on loading mixed metal oxides into ceramic membrane pores via this method. Also, the performance of catalytic ceramic membrane impregnated with ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ was evaluated in a membrane filtration system for the first time. Meanwhile, a comprehensive performance evaluation of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst as PMS activator for SMX degradation was investigated and the SMX degradation pathway was proposed via the determination of dominant radicals and the SMX degradation products in the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } / \mathrm { \Omega }$ membrane/PMS system.

# 2.2. Preparation and characterization of $C o F e _ { 2 } O _ { 4 }$ impregnated membrane

Impregnation of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ in $\mathrm { { A l } } _ { 2 } \mathrm { { O } } _ { 3 }$ -based ceramic membrane pores via a urea-assisted one-step combustion method is shown in Fig S1. Briefly, the membranes were firstly washed with DI water and dried in oven at $1 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 4 \mathrm { ~ h ~ } }$ . Before the impregnation process, the disc was weighed as $\mathrm { W } _ { 0 }$ . Subsequently, 1-3 pieces of discs were immersed into $1 0 ~ \mathrm { m L }$ of the impregnation solution, which is a mixture of urea, $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ and $\mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } \mathrm { O }$ . To get the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ ceramic membrane, the discs were calcined for $3 0 \ \mathrm { m i n }$ in an air atmosphere. For the multiple impregnation experiments, all previous steps (immersion and calcination) were repeated.

3. Results and discussion   
3.1. Study of the urea-assisted one-step combustion method

The effect of calcination temperature on the morphology, crystal structure and catalytic performance of as-prepared $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ particle was investigated (Fig S2). The SEM images of all catalysts prepared under different calcination temperatures $\mathrm { 3 0 0 \mathrm { ~ - ~ } 8 0 0 ^ { \circ } C }$ ) show the similar surface morphology composing of closely packed particles with a particle size of $5 0 \textrm { - } 1 0 0 \mathrm { n m }$ . The intensity of the diffraction peaks increased with the increase of calcination temperature from 300 to $6 0 0 ~ ^ { \circ } \mathrm { C }$ , indicating the higher crystallinity and larger particle size. Interestingly, when the calcination temperature increased to $8 0 0 ^ { \circ } \mathrm { C }$ , the characteristic peak of (311) for ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ deceased with the appearance of new peaks, meaning the crystal structure changed under high calcination temperature (Fig S2e). The catalytic performance of catalysts prepared with different calcination temperatures was investigated in a SMX/Oxone batch system. As shown in Fig S2f, the degradation efficiency of SMX decreased with increasing of calcination temperature. When the calcination temperature was increased from 300 to $8 0 0 \mathrm { { } ^ { \circ } C }$ , the SMX removal in $6 0 \ \mathrm { m i n }$ in this system decreased from $9 2 . 4 \%$ to $2 4 . 5 \%$ . That could be caused by the lower crystallinity of the catalyst prepared at $3 0 0 ^ { \circ } \mathrm { C }$ , indicating the presence of more defects which is in favor of electron transfer. Meanwhile, the leached metal ions due to the low crystallinity should be also considered (Table S1). Another reason is the particle aggregation increased with the increase of calcination temperature, resulting a larger particle size (Figs S2 a-d).

Fig 2 displays the $\Nu _ { 2 }$ adsorption-desorption isotherm and corresponding pore size distribution (inset) of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ particle. The sharp distribution of pore diameter around 1.8 nm suggests that the NPs have high monodispersity. The isotherm with hysteresis loop at relatively high pressure of $0 . 4 \textrm { - } 1 . 0$ indicates the existence of meso-pores to micro-pores generated due to the accumulation of nanoparticles. The BET specific surface area of the sample was calculated from $\Nu _ { 2 }$ isotherms at $7 7 ~ \mathrm { K }$ , and was found to be as much as about 57.5 $\mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 }$ . Fig 7b shows the effect of initial pH on the SMX removal in the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } /$ membrane/PMS system. Under acidic condition $\mathrm { ( p H ~ } 3 \mathrm { - } 7$ ), the Oxone stabilization effect promotes the adherence of $\mathrm { H } ^ { + }$ to the electronegative peroxide bond (-O-O-) [26]. Similarly, the surface of the catalyst which consists of abundant hydroxyl groups (-OH) is also protonated ( $\cdot \mathrm { O H } _ { 2 } ^ { + \cdot }$ ) leading to the positive charged surface (Fig S5a) [27,28]. The -OH group has a critical role in Oxone activation process while - $\mathrm { \cdot O H } _ { 2 } ^ { + }$ has deleterious effect on the overall catalytic activity [29]. These factors could lead to the inherent negative effect on the catalytic activity in acidic condition.

Interestingly, when pH value was increased from 9 to 11, the catalytic degradation of SMX in $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system is inhibited (Fig 7b). The increase of $\mathrm { p H }$ can raise the amount of negative surface charge of the catalyst as well as SMX molecular (Fig. S5b), resulting in the electrostatic repulsion [30,31] . Meanwhile, since the $\mathrm { p K _ { a } }$ of $\mathrm { H S O } _ { 5 } \mathrm { ^ - } > 9 . 4$ [32], higher pH can also increase the proportion of less oxidative ${ \mathrm { S O } } _ { 5 } { } ^ { 2 - }$ by the deprotonation of PMS [33]. Another effect of $\mathrm { p H }$ is that it can affect the reactive species. When $\mathrm { S O } _ { 4 }$ - are generated, HO, which can also attack SMX, could be introduced into the system particularly under moderate alkaline condition. However, oxidation potential of HO decreases linearly with pH and the generated HO $( \mathsf { p K } _ { \mathrm { a } } = 1 1 . 9 )$ ) becomes unstable and tends to decompose under high pH value.

Durability of membrane could significantly lower the operation cost of water and wastewater treatment plants. A representative #1 membrane was used for 3 treatment cycles of $1 0 \mathrm { m g } \mathrm { L } ^ { - 1 }$ SMX solution with the flux of 236 LMH, and the results are shown in Fig 7c. A stable SMX removal efficiency could be maintained on $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane over multiple cycles of 60 min each. In this system, average cobalt ion leaching was recorded as $0 . 0 4 ~ \mathrm { m g ~ L } ^ { - 1 }$ in the effluent during each treatment cycle. The decrease of SMX removal in each cycle could be explained by the accumulative adsorption of SMX onto/into the membrane, reducing the density of active catalytic sites. However, upon each cleaning cycle with Oxone for $5 ~ \mathrm { { m i n } }$ , more than $9 5 \%$ of the SMX removal efficiency could be recovered, indicating the reusability potential of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated membrane via Oxone-assisted self-cleaning. During multiple-cycle experimental run, the permeability flux was maintained at $> 9 8 \%$ of the initial flux.

# 3.3.3 Effects of NOM and anions

Natural organic matter (NOM) is one type of substances existing in water and plays a number of important roles including controlling the pH balances, governing the mobility of contaminants through adsorption, aggregation and sedimentation, and chelating metals [30,34]. HA as one typical model was chosen to investigate the effect of NOM on the degradation of SMX in $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } /$ membrane/PMS system.

As shown in Fig 8a, at low concentration of HA $( 5 \mathrm { \ p p m } )$ , there is a slightly enhancement on the SMX degradation. This could be caused by the sensitizer function of HA to produce various reactive species [35]. While with the increasing of HA concentration, the inhibiting effect became more obvious. The inhibition is caused by the attachment of HA on the active sites of catalyst as well as the radical quenching effects to hinder the catalytic process. The results showed that the catalytic performance of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ might be suppressed in natural water which consists of NOM.

# 3.4. Proposed SMX degradation mechanism

Since the contributions of SMX degradation by direct Oxone oxidation and catalyst adsorption are negligible (Fig S6), the radical-based oxidation process was deduced as the mechanism of SMX degradation. Previous investigations have pointed out that in the $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system, $\mathrm { S O } _ { 4 }$  - and HO can always be identified as the main reactive species [43]. Therefore, an attempt with EPR experiments was made to verify the presence of $\mathrm { S O } _ { 4 }$ - and HO in $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system. As shown in Fig 9a, there were no obvious characteristic signals present in the EPR spectra of experiments conducted with DMPO $^ +$ Oxone $^ +$ SMX system. However, in the presence of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ , the characteristic signals of 5,5-dimethyl-2- pyrrolidone-N-oxyl (DMPOX) with heptet were detected, which was formed by the oxidation of DMPO via HO [44,45]. When BMPO was used as the spin trapping agent (Fig 9b), sevenline spectrum can be observed, which can be assigned to 5-tert-butoxycarbonyl-5-methyl-2- oxo-pyrroline-1-oxyl (BMPOX), a reaction product of BMPO with $\mathrm { S O } _ { 4 }$ -  [46].

However, a new component (785.3 eV) occurred after the oxidation reaction, which was ascribed to the $\mathrm { C o } ^ { 3 + }$ in octahedral sites (Fig S8) [50,51].

The TOC detection result showed that the TOC reduction was approximately $2 0 \%$ after 60 min reaction, which was much less than the SMX removal efficiency $( 9 2 . 4 \% )$ . This result indicated that SMX mineralization occurred during the catalytic degradation, whereas most of SMX molecules were probably transformed into other intermediates rather than being completely oxidized to $\mathrm { C O } _ { 2 }$ and $_ \mathrm { H _ { 2 } O }$ . Meanwhile, the concentration of $\mathrm { N O } _ { 3 } \mathrm { \overline { { \Omega } } }$ detected in the reaction solution after $6 0 ~ \mathrm { { m i n } }$ achieved to $1 . 3 ~ \mathrm { m g ~ L } ^ { - 1 }$ , around 4 times higher than the initial one of $0 . 3 \mathrm { m g L } ^ { - 1 }$ , evidencing the generation of $\mathrm { N O } _ { 3 } \mathrm { \overline { { \Omega } } }$ in the catalytic process.

To explore the intermediate products and degradation pathway of SMX, LC/MS/MS was utilized via the ES $( + )$ mode (Fig S9). Peaks at $\mathrm { m } / \mathrm { z }$ 99.1, 147.1, 158.1, 267.4 and 274.4 were detected. As shown in Fig 10c, the degradation happens with the cleavage of sulfonamide bond $( \mathrm { { m / z } ~ } 9 9 . 1 $ and 158.1) as well as the formation of mono-hydroxylated derivative $( \mathbf { m } / z \ 2 7 4 . 4 )$ . Subsequently, the electron transfer reaction between $\mathrm { S O } _ { 4 }$  - and the amine group can form nitro-SMX molecule $( \mathrm { m } / z 2 6 7 . 4 )$ ) [52]. The radicals can attack the $\mathrm { C } { = } \mathrm { C }$ to form C-C $( \mathrm { m / z ~ } 1 4 7 . 1 $ ) followed by the formation of inorganic ions $\left( \mathrm { N O } _ { 3 } \right)$ and mineral acid via ring opening reactions.

# 4. Conclusions

This study investigated the activation of PMS by $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ ceramic membrane to degrade SMX in a membrane filtration system. It is the first report on the one-step combustion synthesis of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane and the utilization of SMX degradation in an integrated continuous system. Based on the results presented, the following conclusions are drawn:

1) A robust and uniform $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane could be successfully prepared via a urea-assisted one-step combustion method.   
2) The pure water permeability flux can maintain at $\sim 3 0 0 0 \mathrm { L } \mathrm { m } ^ { - 2 } \mathrm { h } ^ { - 1 }$ bar-1 (LMHB) with the catalyst loading amount of $0 . 0 1 5 \ \mathrm { g / g } \ A l _ { 2 } \mathrm { O } _ { 3 }$ .   
3) The $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane could be applied in an integrated continuous filtration system and the SMX removal could achieve at nearly $1 0 0 \%$ at the contact time of $9 0 \mathrm { s }$ .   
4) The ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ impregnated membrane shows a great durability potential via Oxone-assisted self-cleaning as well as great tolerance at a wide pH range (3-11), existence of NOM and different anions.   
5) The degradation of SMX started from the cleavage of sulfonamide bond and the formation of mono-hydroxylated derivative, in which the major reactive radical is $\mathrm { S O } _ { 4 }$ - in natural pH condition.

Overall, the novel $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ impregnated membrane exhibits a promising prospect for numerous catalytic application. Meanwhile, the urea-assisted one-step combustion is a promising method for impregnation of nanocatalysts into ceramic membrane pores.
