# Synergistic Coordination in Cu Single-Atom Catalysts Enhances High-Valent Copper-Oxo Species for Efficient PMS Activation

Yi Shen,\*Yongliang Pan, Chao Zhu,\* Haizhong Zhang, Jun Wang, Renlan Liu, Qile Fang, Shuang Song, and Baoliang Chen

In the domain of heterogeneous catalytic activation of peroxymonosulfate (PMS), high-valent metal-oxo (HVMO) species are widely recognized as potent oxidants for the abatement of organic pollutants. However, the generation selectivity and efficiency of HVMO are often constrained by stringent requirements for catalyst adsorption sites and electron transfer efficiency. In this study, a single-atom catalyst, $\mathsf { C u } _ { \mathsf { S A } } / \mathsf { C N } / \mathsf { P } \& S$ , is synthesized featuring multiple types (planar/axial) of heteroatom coordination via an H-bond-assisted self-assembly strategy. It is confirmed that $\mathsf { C u N } _ { 3 }$ active centers with axial S coordination are uniformly distributed in a carbon matrix modified by planar P atoms. $\mathsf { C u } _ { \mathsf { S A } } / \mathsf { C N } / \mathsf { P } \& S$ activated PMS to selectively generate $\mathtt { C u } ^ { ( \mathsf { I I I } ) } = \mathtt { O H }$ species as the primary reactive oxygen species (ROS). The pseudo-first-order kinetic rate for bisphenol A degradation reached $\mathsf { 1 . 5 1 \min ^ { - 1 } }$ , a 17.57-fold increase compared to the unmodified $\mathsf { C u } _ { \mathsf { S A } } / \mathsf { C N }$ catalyst. Additionally, the $\mathsf { C u } _ { \mathsf { S A } } / \mathsf { C N } / \mathsf { P } \& S$ catalyst demonstrates high efficiency and durability in removing contaminants from various aqueous matrices. Theoretical calculations and experimental results indicate that the intrinsic electric field generated by distal planar P atoms enhances electron transfer efficiency within the carbon matrix. Meanwhile, axial S coordination elevates the d-band center and tunes the ${ \pmb e } _ { \pmb g } ^ { * }$ band broadening of $\mathtt { c u }$ , thereby enhancing the adsorption selectivity for the terminal oxygen of PMS. This multitype coordination synergistically mitigates the issues of low selectivity and yield of HVMO species.

# 1. Introduction

The activation of peroxymonosulfate (PMS) in advanced oxidation processes (AOP) has garnered significant attention for the degradation of various refractory organic pollutants via radical and non-radical pathways.[1] However, the predominance of traditional radical pathways (e.g., hydroxyl (•OH) and sulfate radicals $( \mathrm { S O } _ { 4 } \bullet ^ { - } ) )$ in PMS activation often results in suboptimal pollutant degradation due to their short lifetimes and poor resistance to interference.[2] Consequently, the exploration of non-radical pathways (e.g., singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , electron transfer, and high-valent metal-oxo (HVMO) species) has become the focal point of PMS activation research. HVMO species are particularly notable for their exceptionally long lifetimes $ { \left( 7 - 1 0 ^ { - 1 } \ \mathrm { ~ s } \right) }$ high steady-state concentrations $( { \approx } 1 0 ^ { - 8 } ~ \mathrm { \ m } )$ , and robust versatility.[3] Unlike other PMS activation pathways, HVMO species generation typically involves the heterolytic cleavage of the $\mathrm { O - O }$ bond at the PMS terminal, forming oxygen-containing metal species.[4,5] Investigations into the generation of HVMO species reveal that both the adsorption strength of PMS terminal oxygen and the effciency of electron transfer are needed to meet stringent requirements, leading to the exploration of various methods to satisfy these conditions.[6] For instance, the multi-metal FeCoCu alloy catalyst was synthesized, with the electron transfer regulated by adjusting the Cu content.[7] Moreover, oxygen vacancies in Cobased hollow microspheres modulated metal orbitals, facilitating $\mathrm { C o } ( \mathrm { I V } ) { = } \mathrm { O }$ species formation.[8] However, these approaches are limited by the presence form of metals such as alloys and nanoparticles, resulting in unclear active sites, further resulting in the electronic structure of the active sites not being directly and effectively affected, thereby failing to specifically enhance the selectivity and generation efficiency of HVMO species.

Single-atom catalysts (SACs) are considered ideal models for metal-support interactions due to their high atomic efficiency, well-defined active sites, and high dispersion.[9] These characteristics endow SACs with tremendous potential in catalysis, particularly in scenarios requiring high selectivity and efficiency. Particularly, carbon-based materials with nitrogen-coordinated transition metals (MN-C) offer a well-defined metal coordination environment and tunable electronic structures, making them highly suitable for generating HVMO species.[10,11] Zhou et al. demonstrated that single-atom Co sites on a carbon-nitrogen substrate show higher selectivity for PMS activation to generate Cooxo species compared to Co nanoparticles.[12] However, unmodified SACs often depend on a single electron transfer pathway and lack clear adsorption site selectivity, necessitating further modulation to enhance selectivity toward HVMO species. To address this, Jiang et al. introduced nitrogen vacancies in the substrate, optimizing the valence state of Co atoms and thus reducing the energy barrier for the formation of $\mathrm { C o } ( \mathrm { I V } ) { = } \mathrm { O }$ species.[13]Similarly, He et al. enhanced the adsorption of PMS terminal oxygen by constructing bimetallic organic frameworks, leading to high-valent $\mathrm { F e M n { = } O }$ species formation.[14] Meanwhile, current research predominantly focuses on adjusting the types and forms of metal sites without adequately leveraging the electronic potential of the matrix.

In this context, heteroatom doping emerges as a promising strategy, which retains the advantages of metal coordination while influencing catalytic activity by tuning electronic density and energy level structures.[15] For instance, selectivity for highvalent iron species was enhanced by altering the local environment of Fe single-atom through short-range S coordination.[16] Moreover, PMS was activated to produce $\mathrm { C u ( I I I ) { = } { O H } }$ species by doping different types of heteroatoms into the $\mathrm { M - N - C }$ matrix to modulate the electronic flow direction.[12] However, current heteroatom regulation methods are limited to selecting heteroatom types and planar coordination distances, resulting in relatively isolated effects on metal site regulation. Theoretical calculations and experimental findings reveal that modulating the axial coordination geometry of the metal center enhances the control over the ionic properties of metal site bonding.[17,18] This axial coordination offers substantial flexibility in modifying the energy level structure without being limited by the planar coordination number of the metal center.[19] However, relying solely on axial coordination is modulated by the strength of the absorption/donor moieties, failing to meet the high charge density requirements.[20] The adsorption selectivity and high electron transfer efficiency necessary for HVMO species formation are restricted by the tuning of the orbital energy level and the charge distribution of the metal. Although single heteroatom coordination strategies have successfully addressed certain prerequisites for HVMO species generation, they have not met all requirements simultaneously. Consequently, a strategy involving the synergistic modulation of multiple types of heteroatom doping types has been proposed to address these diverse requirements. Combining multiple (planar and axial) coordination forms is most effective in satisfying the stringent requirements for HVMO species generation. Nonetheless, accurately achieving axial coordination and implementing multiple types of coordinated modulation remain challenging, and the underlying mechanisms are still not well understood.

In this study, a precise H-bond-assisted self-assembly strategy was developed to tailor the coordination environment of ${ \mathrm { C u } }$ SACs with various heteroatom dopings: planar P coordinated ${ \mathrm { C u } }$ SACs $( \mathrm { C u _ { S A } / C N { - } P ) }$ , axial S coordinated Cu SACs $( \mathrm { C u } _ { \mathrm { S A } } / \mathrm { C N } { - } \mathrm { S } )$ , and planar/axial coordinated ${ \mathrm { C u } }$ SACs $( \mathrm { C u } _ { \mathrm { S A } } / \mathrm { C N } { - } \mathrm { P } \& \mathrm { S } )$ . Synchrotron X-ray absorption spectroscopy (XAS) and X-ray photoelectron spectroscopy (XPS) confirmed the successful synthesis of catalysts with planar P coordination and axial S coordination in the first shell of Cu within the $\mathrm { M - N - C }$ matrix. Under the synergistic synergistic regulation of planar P atoms and axial S atoms, $\mathrm { C u _ { S A } / C N { \mathrm { - P } } \& S }$ successfully generated ${ \mathrm { C u } } ^ { ( \mathrm { I I I } ) } { = } { \mathrm { O H } }$ species, achieving a pseudo-first-order rate constant for BPA degradation of $1 . 5 1 \mathrm { m i n ^ { - } }$ ,1 which is 17.57 times higher than that of $\mathrm { C u } _ { \mathrm { S A } } / \mathrm { C N }$ , leading the field of Cu-based catalysts. Density functional theory (DFT) analysis revealed that axial S coordination elevated the d-band center and broadened the $\boldsymbol { \mathrm { e _ { g } } } ^ { * }$ orbital of Cu, thereby improving the adsorption selectivity for the terminal oxygen of PMS. Meanwhile, planar $\mathrm { P }$ coordination significantly improved electron transfer efficiency by creating an intrinsic electric field in the carbon skeleton. Ultimately, theoretical calculations and experimental results elucidate the synergistic regulation of first shell axial S coordination on optimizing the adsorption sites of Cu and distal planar $\mathrm { P }$ coordinated intrinsic electric fields, thus enhancing the selectivity and efficiency of HVMO species generation. This research provides a novel strategy for multitype coordination modifying single-atom active centers to produce HVMO species, contributing to the advancement of SACs tuning methods and PMS activation pathways for HVMO species production.

To investigate the impact of heteroatom doping on the coordination environment and the electronic state of Cu under the selfassembled planar/axial coordination regulation, X-ray absorption spectroscopy (XAS) was employed to analyze the valence state and coordination environment of Cu atoms in $\mathrm { C u _ { S A } / C N { \mathrm { - P } } \& S }$ [26] Cu K-edge X-ray absorption near edge structure (XANES) analysis (Figure 2a) revealed that the oxidation state of Cu atoms in $\mathrm { C u _ { S A } / C N { - } P \& S }$ ranged between $+ 1$ and $+ 2$ , as indicated by the absorption edge resembling that of CuPc and $\mathrm { C u O }$ Fouriertransform (FT) analysis of the $\mathrm { k } ^ { 3 }$ -weighted extended X-ray absorption fine structure (EXAFS) data confirmed the presence of Cu atoms in single atomic form within $\mathrm { C u _ { S A } / C N { - P \& S } }$ compared to Cu-foil (Figure 2b). Simultaneously, the characteristic peaks of $\mathrm { C u _ { S A } / C N { \mathrm { - P } } \& S }$ overlapped significantly with those of $\mathrm { C u - N }$ bonds, suggesting the existence of $\mathrm { C u - N }$ coordination in the first shell. Utilizing wavelet transform (WT) with R and $\mathrm { k \Omega }$ spaces resolution for intuitive comparison (Figure 2c; Figure S12, Supporting Information), revealed the configuration of its Cu single-atom and demonstrated a rough consistency in WT distribution between $\mathrm { C u _ { \mathrm { s A } } / C N { \mathrm { - } } P \& S }$ and CuPc. This convincingly demonstrated the coordination structure of $\mathrm { C u _ { S A } / C N { \mathrm { - P } } \& S }$ , where each Cu atom was coordinated with three N atoms and one axial S atom within the first shell.

# 3. Conclusion

In summary, a single-atom catalyst with planar/axial coordination, $\mathrm { C u _ { S A } / C N { - } P \& S }$ , is synthesized using an H-bond-assisted self-assembly strategy. In the $\mathrm { C u } _ { \mathrm { S A } } / \mathrm { C N } { \mathrm { - } } \mathrm { P } \& \mathrm { S } / \mathrm { P M S }$ system, dominated by high-valent ${ \mathrm { C u } } ^ { ( \mathrm { I I I } ) } { = } { \mathrm { O H } }$ , a $k _ { \mathrm { o b s } }$ of $1 . 5 1 \ \mathrm { m i n ^ { - 1 } }$ for BPA degradation was achieved. XAS and other techniques confirm the planar $\mathrm { P }$ coordination modification of the $\mathrm { M - N - C }$ matrix and the axial S coordination structure in the first shell of Cu. DFT and electrochemical characterizations demonstrated the ability of planar P atoms to modulate the electronic properties of the distal carbon skeleton. Additionally, axial S atom doping elevated the valence state of Cu and the d-band center, optimizing the adsorption sites for PMS. Through the synergistic regulation of distal electronic modulation and axial adsorption selectivity optimization, $\mathrm { C u _ { S A } / C N { - } P \& S }$ significantly enhanced the selectivity and efficiency of HVMO species generation. This study reveals the impact of multiple coordination on the catalytic behavior of SACs, providing new possibilities for SAC modification strategies and catalytic mechanisms.
