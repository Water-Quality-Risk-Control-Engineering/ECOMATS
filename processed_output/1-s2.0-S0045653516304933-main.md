# ABSTRACT

To evaluate the heterogeneous degradation of sulfanilamide by external energyefree Fenton-like reactions, magnetic ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ spinel nanoparticles (NPs) were synthesized and used as catalysts for activation of hydrogen peroxide $\left( \mathrm { H } _ { 2 } 0 _ { 2 } \right)$ . The physicochemical properties of the $\mathtt { C u F e } _ { 2 } 0 _ { 4 }$ NPs were characterized with several techniques, including X-ray diffraction, X-ray photoelectron spectroscopy, transmission electron microscopy, and magnetometry. In the catalytic experiments, $\mathrm { C u F e _ { 2 } O _ { 4 } \ N P s / H _ { 2 } O _ { 2 } }$ oxidation showed the best degradation performance in the circumneutral conditions that resulted from the presence of $\mathtt { C u ( I I ) }$ on the surface of the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs. The surface area-normalized pseudo-first-order rate constants were calculated as $2 . 6 0 ~ \times ~ 1 0 ^ { - 2 } ~ \mathrm { ~ L ~ } ~ \mathrm { m } ^ { - 1 } ~ \mathrm { m i n } ^ { - 1 }$ , $2 . 5 8 \ \times 1 0 ^ { - 3 } \ \mathrm { ~ L ~ } \ \mathrm { m } ^ { - 1 } \ \mathrm { ~ m i n } ^ { - 1 } ,$ , $1 . 9 2 \times 1 0 ^ { - 3 } \mathrm { L } \mathrm { m } ^ { - 1 } \mathrm { m i n } ^ { - 1 }$ , and $7 . 3 0 \times 1 0 ^ { - 4 } \mathrm { L } \mathrm { m } ^ { - 1 } \mathrm { m i n } ^ { - 1 }$ for $\mathtt { C u O }$ , $\mathsf { C u F e } _ { 2 } 0 _ { 4 } \mathsf { N P s }$ , $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } ,$ and $a \mathrm { - F e } _ { 2 } 0 _ { 3 }$ catalysts, respectively. Thus, solid state $\mathtt { C u ( I I ) }$ a was more reactive and efficient than Fe(III) in the circumneutral activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ; this finding was further supported by the results regarding the stoichiometric efficiency of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . The effects of experimental parameters such as the oxidant dosage and catalyst loading were investigated. The mechanism for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation on the spinel surface was explored and could be explained by the solid redox cycles of $\mathrm { F e ( I I ) / F e ( I I I ) }$ and $\mathsf { C u } ( \mathrm { I I } ) / \mathsf { C u } ( \mathrm { I } )$ . Based on the products detected, a degradation pathway via the CeS bond cleavage is proposed for the degradation of sulfanilamide. The findings of this study suggest that copper can be used as a doping metal to improve the reactivity and expand the effective $\mathsf { p H }$ range of iron oxides.

# 1. Introduction

Heterogeneous Fenton-like reactions have been widely investigated as advanced oxidation processes for the degradation of refractory pollutants (Pignatello et al., 2006; Zhou et al., 2014). However, the reactivity of solid catalysts involving iron oxides usually decreases as the pH of their surroundings increases (Pham et al., 2009; Rodríguez et al., 2009; Xu and Wang, 2012). Thus, the development of solid catalysts that display great efficiency under neutral and even alkaline conditions is urgently needed.

As one kind of spinel, copper ferrite $\mathrm { ( C u F e _ { 2 } O _ { 4 } ) }$ , with $\mathtt { C u ( I I ) }$ and $\mathsf { F e } ( \mathrm { I I I } )$ at two different crystallographic sites, has high stability. This material has been investigated in energy storage (Zhu et al., 2013) and as a catalyst in hydrogen production (Faungnawakij et al., 2007), water gas shift reaction (Reddy et al., 2011; Subramanian et al., 2013), and peroxide activation (Feng et al., 2016). Ding et al. (2013) evaluated the activation of peroxymonosulfate with $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ as the catalyst and found that sulfate radicals could be produced. Zhang et al. (2013) examined the degradation of iopromide in $\mathrm { C u F e } _ { 2 } 0 _ { 4 } /$ peroxymonosulfate oxidation and showed that nearly complete degradation of iopromide could be achieved within 10 min. $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ also showed reactivity for the activation of hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ in Fenton-like reactions. Wang et al. (2014) compared four ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ catalysts with different forms under strongly acidic conditions $\left( \mathsf { p H } 3 . 0 \right)$ . They found that hydroxyl radicals (\$OH) could be produced in the presence of these catalysts. However, the effects of experimental parameters such as the solution pH on $\mathrm { C u F e _ { 2 } O _ { 4 } / H _ { 2 } O _ { 2 } }$ oxidation are still not known. Ma et al. (2015) investigated the degradation of methylene blue with $\mathrm { C u F e } _ { 2 } 0 _ { 4 } @$ polydopamine as the Fenton-like catalyst. The $\mathrm { C u F e } _ { 2 } 0 _ { 4 } @$ polydopamine catalyst showed greater reactivity in neutral and alkaline conditions. However, a thorough exploration of this behavior was not carried out. In addition, the use of iron for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation has been studied for several decades, but only in recent years has copper been used as a Fenton-like catalyst (Pham et al., 2013; Lee et al., 2014). Thus, the mechanism for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ activation by copper, especially by $\mathsf { \equiv C u ( I I ) }$ $\equiv$ was used to represent the element on the surface of solid catalysts), is still unclear.

Sulfanilamide (4-aminobenzenesulfonamide, SA; Fig. S1a), a persistent synthetic sulfonamide drug, is widely found in surface water and sludge due to the inefficiency of traditional biological treatment processes (Jia et al., 2011; El-Ghenymy et al., 2013). Given its potential toxicity, the significant presence of this compound poses a threat to the health of human beings and aquatic creatures (Munir et al., 2011). In addition, SA has been identified as one of the degradation intermediates of sulfonamides (Fig. S1b) (Boreen et al., 2004). In our previous study, we observed the accumulation of SA during sulfamethazine degradation (Feng et al., 2015). Thus, the degradation of SA might be the rate-determining step in mineralizing sulfonamides. Several ultraviolet-promoted approaches have been tested to degrade this compound (Wang et al., 2011; Batista and Nogueira, 2012). However, few investigations on its degradation by external energy-free Fenton-like reactions have been reported.

In this study, we report a new phenomenon in which the best catalytic efficiency can be achieved under near-neutral conditions with ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanoparticles (NPs) as Fenton-like catalysts. The mechanism for this circumneutral activation was studied with SA as the target contaminant. In addition, the degradation of SA was evaluated under various conditions, and its destructive pathway is proposed. To the best of our knowledge, this is the first study of the effects of a doping metal on the effective pH range of iron oxides.

# 2.3. Experimental procedures

Hydrogen peroxide $3 5 . 0 \mathrm { w t . \% }$ in $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ ) was standardized before use with potassium permanganate as the titration regent (Wang et al., 2004). First, $1 0 0 \mathrm { - m L }$ solutions of SA with a certain concentration were transferred into conical flasks with mechanical stirring, and a $\mathrm { N a C l O _ { 4 } }$ solution was added to the flasks to achieve a final concentration of $1 ~ \mathrm { \ m M }$ . Unless otherwise specified, all of the degradation experiments were carried out at $2 5 \pm 1 ^ { \circ } { \mathsf { C } }$ and were exposed to air.

To analyze the degradation products, SA degradation was also monitored with a Waters Acquity triple quadrupole mass (MS/MS) spectrometer (Milford, MA, USA). Chromatographic separation of the degradation products was realized with binary-gradient mobile phases of A (water with $0 . 0 1 \%$ formic acid) and B (methanol with $0 . 0 1 \%$ formic acid). The following gradient program was used: (1) Initially, $9 5 \%$ A was held steady for the first $1 . 5 \mathrm { { m i n } }$ ; (2) From 1.5 to $4 . 0 \mathrm { { m i n } }$ , A was linearly reduced to $0 \%$ and held steady until $4 . 5 \mathrm { { m i n } }$ ; (3) From 4.6 to $4 . 7 \ \mathrm { m i n }$ , A was rapidly increased to $9 5 \%$ and then held steady until $5 . 5 ~ \mathrm { { m i n } }$ . The MS was performed both in full-scan and selected ion recording modes with an electrospray ionization ion source. Possible degradation products were first identified by operating the mass spectrometer in full-scan mode. The selected ion recording methods for these products were then established with their corresponding standard reagents. Parameters such as the collision energy and cone voltage were optimized for each compound, with the most abundant daughter ion recorded in each case. Other parameters for MS included a source temperature of $1 2 0 ^ { \circ } \mathsf C _ { \mathsf { \Pi } }$ , a desolvation temperature of $3 5 0 ~ ^ { \circ } \mathrm { C } ,$ a desolvation gas flow rate of $6 0 0 \mathrm { L h } ^ { - 1 }$ , a cone gas flow rate of $5 0 \mathrm { L h } ^ { - 1 } ,$ , and capillary voltage of $0 . 5 0 \ \mathrm { k V } .$ . # 3. Results and discussion

# 3.1. Characterization of the $C u F e _ { 2 } O _ { 4 }$ NPs

Fig. 1a shows the X-ray powder diffraction pattern of the fresh and used $\mathsf { C u F e } _ { 2 } 0 _ { 4 } \mathsf { N P s }$ . In the pattern of the fresh samples, all of the diffraction peaks could be indexed exclusively to the known cubic $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ (PDF # 77-0010), which indicates that the prepared $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs had great purity. Compared with the fresh samples, the used $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs did not show an obvious change, which suggests that the $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs had stability in the catalytic reactions. The magnetic property analysis (Fig. 1b) showed that the saturation moment per unit mass of the fresh $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs was around 25.6 emu $\mathbf { g } ^ { - 1 }$ , whereas the value of the used ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs increased to 29.3 emu $\mathbf { g } ^ { - 1 }$ .

A transmission electron microscopic image of the $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs (Fig. 1c) shows that fine particles with diameters of around $1 5 ~ \mathrm { { n m } }$ dominated the prepared catalysts. However, large agglomerates in the range of $1 0 0 { - } 2 0 0 \ \mathrm { n m }$ appeared as the main form of the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs, probably due to the high surface energy of the NPs. The diffraction rings in Fig. 1d revealed concentric rings with bright spots. Based on the d-spacing of different rings, the $( \textrm { h k l } )$ planes were designated accordingly. A high-resolution transmission electron microscopic image of the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs with crystalline walls is displayed in Fig. 1e. The lattice repeat, a0, was determined to be around $0 . 2 5 2 5 \ \mathrm { n m }$ , corresponding to the crystal face of (3 1 1). The energy dispersive spectroscopic analysis confirmed the presence of Cu and Fe on the catalyst surface with an average atomic ratio that was very close to the theoretical value of 0.5 in the $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ structure (Fig. 1f).

# 3.2. $\equiv C u ( I I )$ -promoted circumneutral activation of $H _ { 2 } O _ { 2 }$

Fig. 2 shows the degradation of SA by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the presence of various catalysts under different initial pH values. In the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ $\mathrm { N P s } / \mathrm { H } _ { 2 } 0 _ { 2 }$ oxidation (Fig. 2a), of all $\mathsf { p H }$ values investigated, $\mathsf { p H } 1 0$ was revealed to be the worst condition, with less than $2 0 \%$ of SA degradation after $^ { 3 \mathrm { ~ h ~ } }$ . When the pH value was between 3.5 and 8, the best performance was achieved at $\mathsf { p H } 6 . 5$ . This observation seemed to differ from the results of some previous studies in which iron oxides were used as the catalysts (Barreiro et al., 2007; Melero et al., 2009); in these studies, the strongly acidic conditions (pH 3 to 4) showed the best degradation. In this study, the degradation of SA was also studied with iron oxides as the catalysts (Fig. S2). The results obtained here confirm that the best performance for these oxides is achieved under strongly acidic conditions $\left( \mathrm { p H } 3 . 5 \right)$ .

Because a transition metal other than iron was present in the spinel catalyst, the circumneutral activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ probably resulted from the interactions between $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathsf { \equiv C u ( I I ) }$ on the surface of the $\mathrm { C u F e } _ { 2 } 0 _ { 4 } \mathrm { N P s }$ . To verify this assumption, the effects of the solution pH on SA degradation in the presence of $\mathtt { C u O }$ were examined. As can be seen from Fig. 2b, $\mathrm { C u O } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ oxidation also was best at $\mathsf { p H } 6 . 5$ . This observation was consistent with the effects of pH values on $\mathrm { C u F e _ { 2 } O _ { 4 } N P s / H _ { 2 } O _ { 2 } }$ oxidation, which confirmed our assumption regarding the role of ${ \equiv } \mathrm { C u } ( \mathrm { I I } )$ . In contrast, $\mathsf { p H } 3 . 5$ was also an efficient condition for CuO. However, because CuO was highly unstable under strongly acidic conditions, this efficient degradation of SA under $\mathsf { p H 3 . 5 }$ was probably a combined effect of the interfacial reactions and the homogeneous interactions between $\mathtt { C u ( I I ) }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . # 3.3. Reactivity of $\equiv C u ( I I )$ and $\equiv F e ( I I I )$

To evaluate the reactivity of the $\mathsf { a F e ( I I I ) }$ in the circumneutral activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , the catalytic performances of common oxides were compared with that of the $\mathrm { C u F e } _ { 2 } 0 _ { 4 } \mathrm { N P s }$ (Fig. 3). The $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs had the highest reactivity of the three iron oxides investigated (Fig. 3a). At $1 5 ~ \mathrm { m M }$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $0 . 1 \ \mathrm { g } \ \mathrm { L } ^ { - 1 }$ catalyst loading, a degradation rate of $8 5 \%$ was achieved after $^ { 5 \mathrm { ~ h ~ } }$ , whereas degradation rates of less than $3 0 \%$ and $1 0 \%$ were realized with $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ and $\pmb { \mathscr { x } }$ - $\mathsf { F e } _ { 2 } \mathsf { O } _ { 3 }$ , respectively. The performance of $\mathtt { C u O }$ awas also investigated and compared with that of the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs. The final degradation of SA after $^ \textrm { \scriptsize 3 h }$ in the presence of CuO was slightly lower with catalyst loading of $0 . 1 \mathrm { ~ g ~ L ~ } ^ { - 1 }$ (Fig. 3b). However, this result was reversed when the loading was increased to $0 . 5 ~ \mathrm { g ~ L } ^ { - 1 }$ (Fig. 3c).

Pollutant degradation in Fenton-like reactions in general follows pseudoefirst-order kinetics (eq (1)) (Xue et al., 2009):

$$
\ln { \frac { \mathsf { C } } { \mathsf { C } _ { 0 } } } = - \mathbf { k } _ { \mathbf { a p p } } \cdot \mathbf { t }
$$

where $\boldsymbol { \mathrm { k _ { a p p } } }$ is the pseudoefirst-order rate constant of SA degradation, C is the concentration of SA at time t, and ${ \sf C } _ { 0 }$ is the initial SA concentration. Plotting ln $\mathsf { C } / \mathsf { C } _ { 0 }$ versus t produced a straight line for various doses of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , and a series of $\boldsymbol { \mathrm { k _ { a p p } } }$ values could be calculated by linear fitting (Table 1). The interfacial catalytic decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was controlled by the intrinsic reactions on the catalyst surface (Lin and Gurol, 1998; Kwan and Voelker, 2002). Meanwhile, these intrinsic reactions were mediated by the available reactive sites that were directly proportional to the specific surface area of the catalysts. Therefore, to minimize the influence of the specific surface area in the degradation of SA, the pseudoefirst-order rate constants were normalized by specific surface area per volume (Table 1). The results show that the reactivity of the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs $( 2 . 5 8 \times 1 0 ^ { - 3 } \mathrm { L } \mathrm { m } ^ { - 1 } \mathrm { m } \mathrm { i n } ^ { - 1 } .$ ) was higher than that of the iron oxides $( 1 . 9 2 \times 1 0 ^ { - 3 } \mathrm { L } \mathrm { m } ^ { - 1 } \mathrm { m i n } ^ { - 1 }$ for $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ and $7 . 3 0 \times 1 0 ^ { - 4 } \mathrm { L } \mathrm { m } ^ { - 1 } \mathrm { m i n } ^ { - 1 }$ for $a \mathrm { - F e } _ { 2 } 0 _ { 3 }$ ) but significantly lower than that of $\mathtt { C u O }$ $( 2 . 6 0 \times 1 0 ^ { - 2 } \mathrm { ~ L ~ m } ^ { - 1 } \mathrm { ~ m i n } ^ { - 1 } .$ ). Based on these results, it could be concluded that $\equiv \mathrm { C u ( I I ) }$ had much better reactivity than $\mathrm { { \equiv F e ( I I I ) } }$ in the circumneutral activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Probably due to its high reactivity toward $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , the leached copper ions from the $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs were much higher than iron ions (Fig. S4a), which is consistent with the increased magnetism of the used ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs (Fig. 1b).

# 3.5. Stoichiometric efficiency of $H _ { 2 } O _ { 2 }$

To evaluate the use of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in different conditions, the stoichiometric efficiency (SE) of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was calculated. A high SE value indicates efficient use of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . With SA as the target contaminant, the SE was defined by the following equation (eq (4)):

$$
\mathrm { ~ E ~ } \left( \frac { \mu { \mathrm { m o l } } } { \mathrm { m m o l } } \ \times 1 0 0 0 \right) = \ \frac { \Delta [ \mathsf { S } \mathsf { A } ] } { \Delta [ \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ] }
$$

where $\Delta [ S A ]$ and $\Delta [ \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ]$ represent the degradation and decomD Dposition amounts of SA and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in micromolar and millimolar, respectively. Fig. 5a to d shows the SE values in various experimental conditions. An increase in the SE value followed by a rapid decrease was noticed when the dose of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was gradually changed from 1 to $2 0 \mathrm { m M }$ (Fig. 5a). The oxidation system exhibited the highest SE performance with $5 \mathrm { m M H } _ { 2 } 0 _ { 2 }$ and $\boldsymbol { 0 . 5 \mathrm { g . L ^ { - 1 } C u F e _ { 2 } O _ { 4 } } }$ NPs, which suggests that this oxidant dose was the optimal condition for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to realize its best utilization efficiency.

The profile of SE under different loadings of $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs is shown in Fig. 5b. When the catalyst loading was increased from 0.1 to $1 . 5 \mathrm { g L } ^ { - 1 }$ , a decline in the SE value was observed, with the highest SE value achieved at $0 . 1 \ \mathrm { ~ g ~ L ^ { - 1 } ~ C u F e } _ { 2 } 0 _ { 4 }$ NPs. Xue et al. (2009) examined the relationship between the SE value and catalyst and even the reaction medium, its half-life in the aqueous solution was extremely short (around $1 0 ^ { - 3 } \mu \mathsf { s } )$ . At equilibrium in which \$OH mwas generated at a constant rate, high levels of SA captured more \$OH, which contributed to the promoted use of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ .

No obvious variation among the SE values was observed under acidic conditions $\mathrm { \ p H } 3 . 5$ to $\mathsf { p H } 6 . 5$ ) (Fig. 5d), which was consistent with the inert effect of these pH conditions on the degradation of SA (Fig. 2a). When the pH was increased to 8.0, the SE value declined, which was followed by a significant decrease at $\mathsf { p H } 1 0$ . Considering the instability of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in alkaline conditions, this steep decline in the SE value could be explained in terms of the invalid decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ into $0 _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ .

The SE values of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the presence of different catalysts were calculated and compared (Fig. 5e). The results show that $\mathtt { C u O }$ had the greatest efficiency, with an SE value of 1.05. The SE value (0.25) with $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs was significantly lower than that with $\mathtt { C u O }$ , but still much higher than the values (0.13 for $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ and 0.05 for $\pmb { \mathscr { L } }$ - $\mathsf { F e } _ { 2 } \mathsf { O } _ { 3 }$ ) obtained with iron oxides as the catalysts. These observations also suggested that $\mathsf { \equiv C u ( I I ) }$ was more efficient than $\mathsf { a F e ( I I I ) }$ in the circumneutral activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ .

# 3.7. Pathways for SA degradation

The SA degradation in the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ $\mathrm { N P s } / \mathrm { H } _ { 2 } 0 _ { 2 }$ system was monitored via a UPLC/MS/MS system, and 11 products from compound B to compound L were detected; their monitored transitions and retention times are listed in Table S1. Sulfanilic acid was proposed as a product of the oxidative degradation of sulfonamides via the $_ { S - N }$ bond cleavage (Boreen et al., 2004; Khankhasaeva et al., 2015). To verity this degradation pathway, the selected reaction monitoring mode was used to monitor the generation of sulfanilic acid. An external standard calibration method was established to determine this compound, and its detection limit was lower than $0 . 0 6 ~ \mu \mathrm { M }$ (Fig. S7). However, no generation of this compound was mobserved, which revealed that the cleavage of the $_ { S - N }$ bond (dashed arrow in Fig. 6) was probably not the main route for the degradation of SA. Based on the identified intermediates, a pathway via the CeS bond cleavage was proposed (Fig. 6). First, aniline $( \mathtt { B } , m /$ $z 9 4 > 6 6$ ) was produced through the cleavage of the CeS bond in the SA structure. This compound was readily degradable in advanced oxidation systems (Anotai et al., 2011; Xie et al., 2012). Under the attack of \$OH, phenol $( \mathsf C , \ m / z \ \ 9 5 \ > \ 7 7 )$ and 4- aminophenol (D, $m / z$ $1 1 0 > 9 3 $ ) were produced.

Hydroxylation of phenol has been widely reported, in which catechol, resorcinol, and hydroquinone were found to be the degradation products (Zazo et al., 2005). In this study, as identified via the UPLC/MS/MS system, these three compounds were also produced in $\mathrm { C u F e _ { 2 } O _ { 4 } N P s / H _ { 2 } O _ { 2 } }$ oxidation (Table S1). However, the MS/MS signals for catechol and hydroquinone were extremely low and quickly disappeared as the reactions continued. The rapid disappearance of the catechol and hydroquinone was probably due to the relative ease of their degradability in the presence of \$OH. To verify this assumption, the degradation of SA and these three aromatic compounds in a single $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ $\mathrm { N P s } / \mathrm { H } _ { 2 } 0 _ { 2 }$ system was investigated (Fig. S8). The $\boldsymbol { \mathrm { k _ { a p p } } }$ values for SA, catechol, hydroquinone, and resorcinol degradation were determined to be $0 . 0 2 6 \ \mathrm { m i n } ^ { - 1 }$ , $0 . 1 0 7 \ \mathrm { m i n } ^ { - 1 }$ , $0 . 1 1 2 \ \mathrm { m i n } ^ { - 1 }$ , and $0 . 0 0 6 \ \mathrm { m i n } ^ { - 1 }$ , respectively. These pseudo-constants confirmed that the degradation of catechol and hydroquinone in the $\mathrm { C u F e _ { 2 } O _ { 4 } \ N P s / H _ { 2 } O _ { 2 } }$ system was much more rapid than that of SA and resorcinol. As the ring-opened products of benzene, maleic acid $( \mathrm { H } , m / z 1 1 5 > 7 1 $ ) and fumaric acid $( \mathrm { I } , m / z 1 1 5 > 7 1$ ) were detected at $0 . 5 4 \mathrm { ~ m i n }$ and $0 . 4 9 \ \mathrm { m i n }$ , respectively. The maleic acid underwent further decomposition to produce malonic acid $( \mathrm { J } , m / z \ 1 0 3 > 5 9 )$ and ${ \mathrm { C O } } _ { 2 }$ . The malonic acid produced was highly unstable and further decomposed into oxalic acid $( \mathrm { K } , m / z 8 9 > 4 3 )$ ), acetic acid $( \mathrm { L } , m / z 6 1 > 4 4 )$ ), and formic acid (Li et al., 2005; Zazo et al., 2005).

# 4. Conclusions

Magnetic $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ NPs were successfully used as Fenton-like catalysts for the degradation of SA. Under the optimal conditions of $1 5 \mathrm { \ m M }$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , $0 . 5 \mathrm { ~ g ~ L ^ { - 1 } \ C u F e _ { 2 } O _ { 4 } }$ NPs, and $\mathsf { p H } 6 . 5$ , near-total degradation of SA was achieved. The $\mathrm { C u F e _ { 2 } O _ { 4 } \ N P s / H _ { 2 } O _ { 2 } }$ had the best degradation performance in circumneutral conditions, which was due to the presence of $\equiv \mathrm { C u ( I I ) }$ on the surface of the spinel catalyst. Under circumneutral conditions, the catalytic reactivity of $\mathsf { \equiv C u ( I I ) }$ was much greater than that of $\mathsf { \equiv F e ( I I I ) }$ . Experimental factors such as the oxidant dosage and catalyst loading influenced the degradation of SA and the SE values of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . The SE values obtained with different catalysts showed that the copper-containing catalysts were more efficient than the iron oxides. In the catalytic processes, $\mathsf { a F e ( I I I ) }$ was first reduced to $\mathsf { \equiv F e ( I I ) }$ , which then reacted with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ via a mechanism similar to the Haber-Weiss reaction. For the interactions between $\equiv \mathrm { C u ( I I ) }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , both $\equiv \mathrm { C u ( I ) }$ and $\equiv \mathsf { C u } ( \mathrm { I I I } )$ were likely produced. However, mechanisms on the reaction between $\equiv \mathrm { C u ( I ) }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ are still not quite clear and deserve further studies. Eleven degradation products were detected, but sulfanilic acid was not detected in the system. Based on the compounds identified, a pathway via the ${ \tt C } { - } { \tt S }$ bond cleavage instead of the $_ { S - N }$ bond cleavage is proposed for the mineralization of SA.
