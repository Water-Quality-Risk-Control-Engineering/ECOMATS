The catalytic efficacy of biochar is significantly influenced by the biomass feedstocks. To produce active, environmentally friendly and cost-effective biochar, in this study, cottonseed hull biomass was subjected to 80 days of fungal fermentation pretreatment. Enzymes secreted during fungal fermentation effectively deconstructed the plant structure, yielding a biochar precursor with enhanced porosity and optimal catalytic properties. The enzymes secreted by fungi-fermentation were used to break down the plant structure, resulting in a biochar precursor with well-developed porosity and optimal catalytic chemical characteristics. Under high annealing temperature, the resulting biochar derived from the fermentation residues ( $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 } \mathrm { \Omega }$ ) retained the overall structure of its precursor, but with favorable graphitization degree and optimized ${ \mathrm { C } } { = } 0 / { \mathrm { C } } { \mathrm { - } } 0$ ratio, favorable reactive sites and faster electron transfer rate. Radical quenching tests and electron spin resonance characterization revealed that SA degradation was predominantly driven by non-radical pathways, such as singlet oxygen oxidation and direct electron transfer. Kinetic studies revealed that the C $\mathrm { S H - B C } _ { 8 0 } { \mathrm { - } } 8 0 0 / \mathrm { P M S }$ system achieved an $8 4 . 8 ~ \%$ degradation efficiency in $1 2 0 \ \mathrm { m i n }$ , reflecting a $4 3 . 9 ~ \%$ increase over the removal of SA in the pristine biochar system. This research not only synthesized a highly functionalized catalyst through microbial regulation and pyrolysis but also established a pathway for developing functionalized biochar precursors.

# 1. Introduction

Wide occurrence and distribution of antibiotics discharged from medical and pharmaceutical sectors has raised much ecological and environmental health concern over the last decade [1]. Among these antibiotic chemicals, sulfonamides are a class of most commonly used antibiotics in medical treatment, animal husbandry and aquaculture [2]. Due to weak absorption and incomplete metabolism [3], sulfonamides and their residues are frequently detected in reclaimed wastewater and natural water around different regions [4]. Hirsch et al. reported that sulfamethazine was $0 . 4 8 ~ { \mu \mathrm { g } } { \cdot } \mathrm { L } ^ { - 1 }$ and $0 . 4 7 ~ { \mu \mathrm { g } } { \cdot } \mathrm { L } ^ { - 1 }$ in river and groundwater in Germany [5]. Sulfonamides in the environment are highly toxic to microorganisms, algae and certain plants [6]. Hence, the development of novel, efficient and sustainable technologies for removing sulfonamides and their derivatives from wastewater has received a lot of attention.

Advanced oxidation processes (AOPs) have been utilized with highpriority for degrading refractory organic pollutants due to the advantages of producing high oxidizing species, such as sulfate and hydroxyl radicals, providing a feasible approach for the complete mineralization of refractory pollutants [7]. Peroxymonosulfate (PMS) is a desirable oxidizer for AOPs because it is easy to obtain and transport and stable before reaction [8]. $S O _ { 4 } ^ { \bullet \cdot }$ or $\cdot _ { \mathrm { O H } }$ are then frequently reported as the generated reactive oxidizing species (ROS) responsible for the pollutant degradation. However, the implementation of $S O _ { 4 } ^ { \bullet \bullet }$ and $\cdot _ { \mathrm { O H } }$ radicals based AOPs can be limited by the presence of radical quenchers in real wastewater, such as inorganic anions and naturally-occurring organic compounds [9]. In comparison with $S O _ { 4 } ^ { \bullet \bullet }$ and $\cdot _ { \mathrm { O H } }$ , singlet oxygen $( ^ { 1 } 0 _ { 2 } ,$ $\boldsymbol { \mathrm { E } } ^ { 0 } = 1 . 5 2 \ \mathrm { e V } )$ ) shows stronger resilience in the presence of quenching organic and inorganic matters because of its fine selectivity for electronrich compounds [10].

$^ 1 0 _ { 2 }$ can be produced during PMS activation using metal-free carbon catalysts such as carbon nanotubes, nano-diamonds, activated carbon, graphene and biochar, etc. [11]. In comparison with other carbon counterparts, biochar is cheap, easy-available and function as a feasible route for biomass waste valorization. For PMS activation, structural defects and oxygen-containing groups $\scriptstyle { \mathrm { { C = } } }$ , etc.) are biochar’s typical catalysis moieties. But due to dense lignocellulose framework, limited number of carbonyl groups and low degree of structural defects can be obtained during biomass pyrolysis, only endowing biochar unsatisfactory catalytic capacity. To modulate the inherent properties of biochar, kinds of chemical modifications, such as $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ oxidation, acid activation and heteroatom doping, have been employed to introduce more active sites. However, these modification strategies often entail strict synthetic procedures, high associated costs and usage of toxic reagents, which may limit the scalable application of such catalysts [12]. Instead, biodegradation of biomass lignocellulose prior to pyrolysis may be an alternative green route to obtain the functional biochar with desired catalysis moieties. Our previous study found that fungal pretreatment of biomass (cottonseed husks) can beneficially destroy the rigid lignocellulosic matrix, create well-defined pores, enrich functional $\scriptstyle { \mathsf { C } } = 0$ moieties and form graphitic carbon domains during pyrolysis [13]. Even though this microbial-driven approach of biochar modification was proven effective for micropollutant adsorption, its critical role on facilitating catalytic PMS activation is still unknown.

To fill this knowledge gap, this study used fungal-fermented cottonseed husk as the precursor for biochar synthesis, enabling targeted regulation of active sites (e.g., oxygen-containing functional groups) and porous architecture through microbial metabolism. This strategy circumvents traditional chemical modifications, offering an eco-friendly and cost-effective route to engineer high-performance biochar catalysts. A well-functionalized biochar was then obtained by pyrolysis of the fungi-fermented biomass, and the correspondence between the functional structures and catalytic mechanism of the biochar was explored. Concurrently, the generation pathway of reactive oxygen species and potential degradation pathway of sulfanilamide in biochar/ PMS systems was revealed by this research. Unlike conventional biochar, this work provids a novel strategy for designing biochar with tailored reactivity toward recalcitrant organic contaminants.

# 2. Materials and methods

# 2.1. Materials and chemicals

The oyster mushroom culture mediums were prepared with cottonseed husks waste and treated with Pleurotus ostreatus strains for varied time intervals. The information of all chemicals used in this study can be found in Supplementary Materials. Stock solutions of sulfanilamide and PMS were prepared with deionized water $( > 1 8 . 0 \mathrm { M } \Omega \mathrm { c m } )$ ).

# 2.2. Preparation of biochar

After an 80-day cultivation at a constant temperature of $2 5 \pm 0 . 5 ^ { \circ } \mathrm { C } ,$ the Pleurotus ostreatus strains were inactivated by steam at $1 2 0 ~ ^ { \circ } \mathbf { C } .$ . Collected waste mushroom substrates are washed with deionized water to remove impurities and then dried to a constant weight. In this way, the $\mathrm { C S H \mathrm { - B M _ { 8 0 } } }$ feedstock which was used as precursor for the biochar catalysts was obtained. $_ { 3 } \mathbf { g }$ of dried $\mathbf { B M } _ { 8 0 }$ was pyrolyzed at $8 0 0 ^ { \circ } \mathrm { C }$ for $^ { 1 \mathrm { h } }$ using a furnace with Ar gas flow at $5 0 0 \ \mathrm { m L / m i n }$ . Afterwards, the resulting biochar labelled as $\mathrm { C S H \mathrm { - } B C } _ { 8 0 } \mathrm { - } 8 0 0$ was sieved to $< 7 5 ~ { \mu \mathrm { m } }$ and washed by 2 M HCl at room temperature for $2 4 \mathrm { h }$ with magnetic stirring. For comparison, biochar named CSH-BC0–800 was also prepared from the original cottonseed husks $\left( \mathrm { C S H - B M _ { 0 } } \right)$ at $8 0 0 ~ ^ { \circ } \mathrm { C }$ using the same procedures. Furthermore, the $\mathrm { C S H \mathrm { - } B M _ { 8 0 } }$ biomass also underwent pyrolysis at temperatures of 600 and $7 0 0 ~ ^ { \circ } \mathrm { C }$ for comparison, and the resulting biochar was named $\mathrm { C S H - B C } _ { 8 0 } { - 6 0 0 }$ and $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 7 0 0 }$ respectively.

# 2.3. Characterization of samples

The physicochemical properties of the biochar-based catalysts were characterized by scanning electron microscopy (SEM, HITACHI, SU810, Japan), Fourier transformed infrared spectroscopy (FTIR, Thermo Fisher, Nicolet IS 50, USA), Brunauer-Emmett-Teller (BET, ASAP 2460, Micromeritics, USA), laser Raman spectroscopy (Roman, Thermo Scientific, DXR, USA) with a laser wavelength of $5 3 2 \ \mathrm { n m }$ , and X-ray photoelectron spectroscopy (XPS, Thermo Scientific K- Alpha). The electrochemical impedance spectroscopy (EIS) of samples and I-t curve in the CSH-BC –800/PMS system were measured by an electrochemical workstation (Chenhua CHI660E, Shanghai).

# 2.4. Experimental procedures

Degradation experiments were performed in $2 5 0 ~ \mathrm { m L }$ glass flasks at ambient conditions $( 2 2 \pm 2 ^ { \circ } \mathbf { C } )$ under magnetic stirring. Briefly, $5 0 \mathrm { m } g$ of biochar powder was dispersed into $1 0 0 ~ \mathrm { { m L } }$ of solution containing desired amount of contaminant substrate. The degradation reaction was initiated when $1 . 0 \mathrm { m L }$ of PMS stock solution $\mathrm { { ( 0 . 1 \ m o l { \cdot } L ^ { - 1 } ) } }$ was injected. At selected time intervals, $1 \mathrm { m L }$ of sodium thiosulfate was added to $1 \mathrm { m L }$ of SA solution. Then filter with $0 . 2 2 ~ { \mu \mathrm { m } }$ microporous membrane. SA concentration was analyzed by high performance liquid chromatography. For comparison, the removal of SA by only biochar or PMS were also evaluated in this work. The influence of operating parameters (e.g. biochar dose, PMS concentration, pH value, and water conditions) on SA degradation were investigated by single factor experiments. Moreover, different quenching agents (MeOH, FFA, $\mathrm { N a N } _ { 3 }$ and KI) were employed to identify the ROS in the biochar/PMS oxidation system. After the degradation experiments, the used biochar was filtered, washed with deionized ethanol and water, and collected for stability tests and characterizations. All the tests were conducted in duplicates at least twice and the mean values of the experimental data were presented in figures with standard deviations $( < 5 ~ \% )$ .

# 2.5. Analytical methods

The residual sulfanilamide was determined using a RIGOL L-3000 HPLC equipped with a UV detector at $2 6 6 \ \mathrm { n m }$ , and a Compass C18 column $( 5 ~ { \mu \mathrm { m } } , \ 4 . 6 \ \times \ 2 5 0 ~ \mathrm { m m } )$ . The mobile phase was a mixture of methanol and water at a ratio of $5 5 { : } 4 5 \ ( \nu / \mathrm { v } )$ . The ROS generated in the $\mathsf { B C } _ { 8 0 } { - } 8 0 0 / \mathsf { P M S }$ system were detected by JES-FA200 EPR spectrometer using DMPO or TEMP as the radical catchers. The total organic carbon (TOC) was determined by an Elementary TOC II analyzer. The intermediate products of SA were detected using liquid chromatography coupled with a mass spectrometer (Agilent, 1260, LC-Q-TOF-MS). The MS was operated in the positive mode and the mobile phase was the mixture of methanol and water at a ratio of $9 5 { : } 5 \ ( \nu / \mathrm { v } )$ . The details of PMS concentration detection are shown in Text S2.

# 3.1. Characterization

Raman spectra were obtained to further evaluate the degree of graphitization and defect status of the carbon matrix. Typical D bands represented defect sites or disordered carbon layers, whereas G bands identified ordered and crystalline carbon structures (associated with $\mathsf { s p } ^ { 2 }$ carbon hybridization), and were respectively observed at ${ \sim } 1 3 0 0$ and $\sim$ $1 5 8 0 ~ \mathrm { c m } ^ { - 1 }$ in the Raman spectrum of samples (Fig. 2(a)) [15,18]. Lignocellulose was decomposed by fungal and converted into phenols, ethers, alcohols and esters. These small organic molecules can be utilized in the pyrolysis process to form conjugated aromatic rings through condensation reactions, the biomass material is then converted into biochar [20]. In this process, the surface edges of biochar formed massive defects, these defects are rich in hydrogen atoms and oxygen functional groups of active sites [21,22]. Noticeably, the values of $\mathrm { I _ { D } / I _ { G } }$ increased from 1.023 of CS $\mathrm { \bullet H \mathrm { - } B C _ { 8 0 } \mathrm { - } } 6 0 0$ to 1.189 of $\mathrm { C S H \mathrm { - } B C } _ { 8 0 } \mathrm { - } 8 0 0$ , indicating that high temperature promoted the generation of defective sites.

Furthermore, the total N and O content slightly decreased with temperature due to the deconstruction of unstable organic components. Similar evidence can be seen in Fig. 2(d). The N1s peak could be deconvoluted as pyridinic, pyrrolic and graphitic N. During the pyrolysis process, pyridine N and pyrrolic N were more easily decomposed at high temperature, resulting in a higher relative atomic proportion of graphitic N, while the proportion of pyrrolic N increased by dynamic regeneration at the graphitized edge [27].

# 3.3. Effects of influential factors on SA removal

As illustrated in Fig. 4(a), impressive SA removal efficiencies $( > 8 0$ $\%$ were achieved within a wide pH range. When the pH value is 3, the kinetic rate constant is the highest $( k _ { o b s } = 0 . 0 1 7 6 2 \ \mathrm { m i n } ^ { - 1 } )$ . This is because under acidic conditions, the strong interaction between the $\pi { - } \pi$ electron donor and acceptor promotes the adsorption of SA, thereby accelerating its degradation process [28]. On the other hand, PMS $\mathrm { ( p K _ { a 1 } }$ $< 0$ , $\mathsf { p K } _ { \mathsf { a } 2 } = 9 . 4 )$ mainly exists in anionic form $\mathrm { ( H S O } _ { 5 } ^ { - }$ and $S 0 _ { 5 } ^ { 2 - }$ ) within the pH range of 3 to 11. The surface charge of $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 }$ becomes more negative with increasing pH $\mathrm { ( p H _ { p z c } \approx 2 . 7 }$ , Fig. S5). Therefore, under higher pH conditions, the electrostatic repulsion between CSH$\mathrm { B C } _ { 8 0 } { - } 8 0 0$ and PMS is enhanced, thereby inhibiting the removal efficiency of SA [29]. Overall, the $\mathrm { C S H - B C } _ { 8 0 } { - } 8 0 0 / \mathrm { P M S }$ system is satisfactory for efficiently degrading SA over a wide pH range and has high practical application prospects.

# 3.4. Catalytic oxidation mechanism

According to previous research, the activation of PMS by carbon based catalysts involves both free radical and non-free radical processes [36]. A series of quenching experiments were conducted to identify the potential ROS for SA degradation in the $\mathrm { C S H - B C } _ { 8 0 } { - } 8 0 0 / \mathrm { P M S }$ system. Ethanol is a typical $S O _ { 4 } ^ { \bullet \cdot }$ and $\cdot _ { \mathrm { O H } }$ quencher, while $\mathrm { N a N } _ { 3 }$ and furfuryl alcohol (FFA) are $^ 1 0 _ { 2 }$ scavengers [4,29]. Fig. 5(a) shows that EtOH (0.1 $\mathrm { \ m o l { \cdot } L ^ { - 1 } }$ ) hardly affected, while equal concentrations of $\mathrm { N a N } _ { 3 }$ and FFA significantly impeded the SA degradation with the removal efficiency decreased to $1 8 . 1 ~ \%$ and $2 7 . 6 \%$ (from $8 4 . 8 ~ \%$ ), respectively. These results demonstrated that, instead of $S O _ { 4 } ^ { \bullet \bullet }$ or $\cdot _ { \mathrm { O H } }$ , $^ 1 0 _ { 2 }$ played an important role in SA degradation. Except for the above ROS, superoxide anion radicals (O•- ) were also reported to participate in the formation of $^ 1 0 _ { 2 }$ as an important intermediate in oxidation systems coupling biochar with PMS [37]. p-benzoquinone (p-BQ) was selected as effective scavenger of $0 \mathbf { \overline { { 2 } } } ^ { \bullet - }$ as shown in Fig. 5(a) [29]. A high removal efficiency of $8 4 . 9 \%$ was maintained with the introduction of p-BQ $\mathrm { { ( 0 . 1 \ m o l { \cdot } L ^ { - 1 } ) } }$ , ruling out the hypothesis that the source of $^ 1 0 _ { 2 }$ was $\boldsymbol { 0 } _ { 2 } ^ { \bullet - }$ .

ESR was performed to further identify the ROS in the systems, using TEMP and DMPO as spin trapping agents, respectively. As plotted in Fig. 5(b) and 5(c), neither DMPO-• OH nor DMPO- $. 0 _ { 2 } ^ { \bullet \bullet }$ was detected in the oxidation systems with hyperfine splitting of 1:2:2:1 and 1:1:1:1:1:1, respectively, which was consistent with the quenching experimental results. Instead, a typical 1:1:1 triplet EPR signal can be observed from Fig. 5(d). Since this signal is a paramagnetic reaction intermediate between TEMP and $^ 1 0 _ { 2 } ,$ it confirmed the existence of $^ 1 0 _ { 2 }$ in the system [38]. The stronger peak intensity of TEMPOL in the $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 / }$ PMS, compared to the PMS and CSH-BC0–800/PMS systems, aligned with the enhanced kinetics of SA degradation. Additionally, the characteristic signal with an intensity ratio of 1:2:1:2:1:2:1 was assigned to DMPOX adducts and observed in the sole PMS system [39]. The appearance of DMPOX adducts could be attributed to the direct oxidation of DMPO by $^ 1 0 _ { 2 }$ via single electron transfer [40]. The results thus confirmed that the non-radical pathway dominated by $^ 1 0 _ { 2 }$ lead to the degradation of SA.

Previous studies have shown that $^ 1 0 _ { 2 }$ can be generated through the self-decomposition of PMS, as described in Eqs. (1) and (2). In addition, carbon-based catalysts as electron acceptors can induce the production of $^ 1 0 _ { 2 }$ [12]. To unveil the underlying active sites for the PMS activation, an XPS atlas of $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 }$ after the reaction was obtained. As shown in Fig. 6(a), an increased $\mathrm { N } \%$ was interpreted as the successful adsorption of SA or its by-products. Fig. 6(b) and 6(c) showed the O1s and N1s XPS spectra of $\mathrm { C S H \mathrm { - } B C } _ { 8 0 } \mathrm { - } 8 0 0$ before and after use. A significant decrease in the content of $\scriptstyle { \mathsf { C } } = 0$ was observed in Fig. 6(b) after the catalytic reaction. The electrophilic $\scriptstyle \mathrm { C = } 0$ groups of the $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 }$ could accept the electrons released by PMS molecules to produce $s 0 _ { 5 } ^ { \bullet }$ , leading to the formation of $^ 1 0 _ { 2 }$ via the self-reaction of $S O _ { 5 } ^ { \bullet }$ (Eqs. There were two conceivable reasons: (1) Adsorbed SA molecules resided on the surface of the used catalyst. (2) The graphitic N took part in the catalytic oxidation reaction as active sites, as postulated by some authors [42,43]. However, the free radical assay results excluded the second theory.

# 3.5. Application prospects of CSH-BC80–800/PMS

The recycling potential of $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 }$ was investigated by plotting the ratio of residual sulfanilamide to starting concentration as a function of the reaction time (Fig. S6). Prior to each recycle, the used biochar was recovered and washed with deionized water. Overall, CSH$\mathrm { B C } _ { 8 0 } { - } 8 0 0$ exhibited favorable reuse performance. After five cycles, the SA removal rate declined from $8 4 . 8 \%$ to $5 5 . 3 \%$ , which was attributed to the irreversible depletion of the active sites.

Further to assess practicability of the CSH- $\mathrm { B C } _ { 8 0 }$ –800/PMS process, tap water, raw and tail wastewater (Tangxun Lake Wastewater Plant, Wuhan city, China) were separately used to prepare SA reaction solutions (Fig. 9(a)). High SA removal efficiencies $( 8 4 . 0 \% \sim 9 1 . 0 \% )$ were observed even in the raw wastewater containing high amounts of inorganic ions and other competitive pollutants, clearly demonstrating the promising potential of the system.

The environmental application of the $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 / F }$ MS system was explored by selecting four other organic pollutants as the target substrates, including BPA, SMX, SMZ and CIP. Fig. 9(b) shows that over $8 5 \%$ removal was also achieved for BPA, SMX, SMZ and CIP within 120 min, with TOC removal rates of $4 7 . 4 ~ \%$ , $2 8 . 1 ~ \%$ , $3 6 . 9 ~ \%$ and $4 5 . 6 \ \%$ , respectively. The above results demonstrated a satisfactory oxidizing performance of the CSH-BC80–800/PMS system.

Although the $\mathrm { C S H - B C } _ { 8 0 } { - } 8 0 0 / \mathrm { P M S }$ system demonstrates excellent broad-spectrum degradation capability and environmental adaptability, further efforts are needed to improve its recyclability. Future studies could explore regeneration strategies such as thermal treatment, chemical cleaning, or physical activation, combined with in situ characterization techniques to elucidate the evolution of surface chemistry and structural properties during regeneration. These efforts will advance the scalability and practical application of this catalytic system.

So far EE/O is supposed to be the universal approach to evaluate energy associated cost in AOPs [47]. With regard to the C $\mathrm { S H - B C } _ { 8 0 } { - } 8 0 0 /$ PMS process, the electrical energy of stirring, consumptions of catalyst and oxidant are the key parameters to determine the total EE/O for SA remova. The costs of CSH-BC80–800 manufacture and PMS reagent are estimated $\operatorname { U S } \$ 9$ 210 and 562 per ton, respectively. The cost of $\operatorname { U S } \$ 9$ 210/ ton primarily includes raw biomass acquisition, fungal culture media, pyrolysis energy (Ar gas, furnace operation), and post-synthesis treatments. Energy consumption for fungal fermentation (e.g., sterilization, incubation) was estimated based on laboratory-scale operations but requires further optimization for industrial scaling [48]. A detailed cost breakdown will be prioritized in future large-scale feasibility studies [49]. And the local price of electrical energy is approximately $\mathrm { U S } \$ 0.1$ per kilowatt hour. # 4. Conclusions

This study combines fungal biotechnology with carbon material engineering to create a low-cost, metal free biochar catalyst. The fungal fermentation procedure optimized the structure of the biomass precursor, which possesses excellent porosity and optimal catalytic chemical properties. The favorable graphitization degree and optimized ${ \bf C = } 0 / { \bf C - } 0$ ratio provided direct evidence for the increased catalytic ability of the optimized biochar. $\mathrm { C S H \mathrm { - } B C _ { 8 0 } \mathrm { - } 8 0 0 }$ can efficiently activate PMS to degrade organic pollutants. According to the radical quenching tests and ESR analysis, the non-radical pathways of direct electron transfer and $^ 1 0 _ { 2 }$ oxidation were identified as the key mechanism of pollutant degradation. Furthermore, the $\mathrm { C S H - B C } _ { 8 0 } { - } 8 0 0 / \mathrm { P M S }$ system exhibited a broad pH tolerance, achieving a removal efficiency of over $8 0 \%$ for SA within the pH range of 3.0 to 11.0. In addition, high SA removal efficiencies were observed even in synthetic wastewater (tap water, raw wastewater, and tail wastewater) containing high amounts of inorganic ions and other competitive pollutants. This study also elucidates the correspondence between functional structures and catalytic mechanisms, revealing the mineralization pathway of sulfanilamide contaminants and providing a promising platform for treating complex wastewater matrices.
