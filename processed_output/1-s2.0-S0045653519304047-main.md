# 1. Introduction

As one of the most serious environmental deterioration issues, water contamination has interrupted the balance between nature and human beings in recent decades. Volatile aromatic compounds such as ethylbenzene is a component of petroleum hydrocarbons, entering the water in the form of the industrial discharges from petroleum refining, plastics processing and pharmaceutical production (Liang et al., 2008). Ethylbenzene is toxic to human beings, and its chronic exposure can potentially damage the kidneys, liver and central nervous system (Parameswarappa et al., 2008). Due to its relative stable chemical structure, ethylbenzene was hardly degraded by the ecosystem through natural attenuation processes (Li et al., 2014). Thus, there is an urgency to develop cleanup technologies to eliminate ethylbenzene from the environment. Various approaches have been proposed for removing ethylbenzene such as adsorption, biofiltration, and photocatalytic oxidation (Sperfeld et al., 2018; Strini et al., 2005; Wang et al., 2007). Among them, advanced oxidation processes (AOPs) like Fenton reaction $\mathrm { ( F e ^ { 2 + } / H _ { 2 } O _ { 2 } ) }$ using hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathbf { O } _ { 2 } \right)$ have attracted much attention because of the advantages of costeffectiveness and non-toxicity (Cabrera Reina et al., 2017; Fenton, 1894; Yan et al., 2012).

$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ itself is a strong oxidant with a high redox potential $\mathrm { E } ^ { 0 } = 1 . 7 6 \mathrm { V }$ , Eq. (1)), and it requires high reaction activation energy to cleavage the $_ { 0 - 0 }$ bond (bond energy is $2 1 3 . 8 \mathrm { k J m o l } ^ { - 1 }$ to generate hydroxyl radicals (OH, $\mathsf { E } ^ { 0 } = 2 . 8 0 \mathsf { V } ,$ ) for the destruction of organic contaminants (Andreozzi et al., 1999). Chemical activation using ferrous ion was found subsequently to decompose $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (Yan et al., 2017b). However, it should be operated under acidic conditions to prevent the precipitation of ferrous ion. In addition, the iron sludge formed will also halt the activation process, thus limiting the ultimate oxidizing capability of Fenton reaction (Masomboon et al., 2009; Nie et al., 2015).

$$
\begin{array} { r l } & { \mathsf { H } _ { 2 } \mathsf { O } _ { 2 } + 2 \mathsf { H } ^ { + } \to 2 \mathsf { H } _ { 2 } \mathsf { O } } \\ & { \mathsf { F } \mathsf { e } ^ { 2 + } + \mathsf { H } _ { 2 } \mathsf { O } _ { 2 } \to \mathsf { F } \mathsf { e } ^ { 3 + } + \bullet \mathsf { O } \mathsf { H } + \mathsf { O } \mathsf { H } ^ { - } } \\ & { \bullet \mathsf { O } \mathsf { H } + \mathsf { H } ^ { + } + \mathsf { e } ^ { - } \to \mathsf { H } _ { 2 } \mathsf { O } } \end{array}
$$

Solid iron compounds such as ferroferric oxide, iron-carbon were used to proceed the heterogeneous Fenton-like process (Wang et al., 2010a; Yan et al., 2017b). However, the drawback of using solid iron compounds was the slow kinetics for the cycle of ferric iron to ferrous iron, which was mainly due to the less reactive sites and weak catalytic activity of iron to drive $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition (Guo et al., 2012). Thus, to develop efficient and durable catalysts for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition remained one of the most active research areas in AOPs.

Cu and Cu-based compounds are widely known as efficient catalysts, which has exhibited excellent catalytic activity toward $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Zhou et al. (2016) revealed that the released cuprous copper $( \mathsf { C u } ^ { + } )$ from the corrosion of zero valent copper in acidic solution could activate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to produce OH radicals through the cycle of ${ \mathsf { C u } } ^ { + } / { \mathsf { C u } } ^ { 2 + }$ . Zhang et al. (2014) also reported that the solid ${ \mathrm { C u F e O } } _ { 2 }$ microparticles could efficiently catalyze the activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , Cu on its surface made great contributions to the catalytic activity of ${ \mathrm { C u F e O } } _ { 2 }$ , and the catalyst of ${ \mathrm { C u F e O } } _ { 2 }$ was confirmed to have merits of easy recycling and good stability by successive degradation of bisphenol A in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . In this study, Cu layered double hydrotalcite of Cu(II)-Mg(II)-Fe(III)LDHs was prepared in the form of two-dimensional structure as $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ catalyst. The general formula of LDHs can be expressed to be $[ \mathsf { M } ^ { 2 + } \mathsf { \Pi } _ { 1 - \mathrm { X } } \mathsf { M } ^ { 3 + } \mathsf { \Pi } _ { \mathrm { X } } ( \mathsf { O H } ) _ { 2 } ] ( \mathsf { A } ^ { \mathrm { n } - } ) _ { \mathrm { X } } /$ $\mathrm { \ n e m H { 2 } O }$ , in which $\mathbf { M } ^ { 2 + }$ are divalent metals of $\mathrm { M g } ^ { 2 + }$ , $Z \mathrm { n } ^ { 2 + }$ , ${ \mathrm { C u } } ^ { 2 + }$ , $\mathsf { F e } ^ { 2 + }$ , $\mathsf { M } ^ { 3 + }$ are trivalent metals of $\mathsf { F e } ^ { 3 + }$ and $A | ^ { 3 + }$ , and ${ \mathsf { A } } ^ { \mathrm { n - } }$ is the interlayer anion (Li et al., 2014). With low toxicity and ubiquitous existence in minerals, co-divalent cation of $\mathbf { M g }$ was selected to relieve the Jahn-Teller effect in preparing LDHs (Cavani et al., 1991). $\mathsf { C O } _ { 3 } ^ { 2 - }$ have strong affinity with LDHs, and was chosen as interlayer anion (Ma et al., 2009). Due to its inherent advantages of good crystallinity, large surface area and great structural stability, $\operatorname { C u } ( \operatorname { I I } ) \cdot$ - Mg(II)-Fe(III)LDHs are anticipated as an excellent $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ catalyst with little amount of metal ions leaching in the system of $\operatorname { C u } ( \operatorname { I I } ) \cdot$ - $\mathrm { M g ( I I ) \mathrm { - } F e ( I I I ) L D H s / H _ { 2 } O _ { 2 } }$ . Therefore, the objective of the present work is focused on the synthesis of $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with highly-efficient catalytic activity for the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition, the mechanism of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ catalysis and oxidative degradation of ethylbenzene in the $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s / H _ { 2 } O _ { 2 } }$ system is also proposed.

# 2. Materials and methods

# 2.1. Chemicals

Copper sulfate $\mathrm { ( C u S O } _ { 4 } { \cdot } 5 \mathrm { H } _ { 2 } O \rangle$ , magnesium sulfate $( \mathrm { M g } \mathrm { S } 0 _ { 4 } { \cdot } 7 \mathrm { H } _ { 2 } 0 )$ and iron nitrate $( \mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } 0 )$ were purchased from Kemiou Chemical Reagent Co Ltd. (Tianjin, China). Ethylbenzene and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ were obtained from Sinopharm Chemical Reagent Co Ltd. (Shanghai, China). 5,5-Dimethyl-1-Pyrroline-N-Oxide (DMPO) was obtained from Aladdin Industrial Corporation (Shanghai, China). All chemicals are analytical-reagent grades as received, and all solutions used in the experiments were prepared with ultrapure water.

# 2.2. Preparation of catalysts

The $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with different $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratios were synthesized by the constant pH co-precipitation method (Li et al., 2015). Firstly, alkaline solution containing $3 . 0 \mathrm { m o l } \mathrm { L } ^ { - 1 } \mathrm { N a O H }$ and $1 . 0 \mathrm { m o l } \mathrm { L } ^ { - 1 } \dot { \mathrm { N a } } _ { 2 } \mathrm { C O } _ { 3 }$ with pH value of 10.5 was prepared. Secondly, metal salt solution with total volume of $2 5 0 \mathrm { m L }$ and $0 . 5 \mathrm { m o l } \mathrm { L } ^ { - 1 }$ $\mathrm { C u S O } _ { 4 } { \cdot } 5 \mathrm { H } _ { 2 } 0$ , $0 . 5 \mathrm { m o l } \mathrm { L } ^ { - 1 }$ $\mathrm { M g S O } _ { 4 } { \cdot } 7 \mathrm { H } _ { 2 } 0$ and $0 . 2 \mathrm { m o l } \mathrm { L } ^ { - 1 }$ $\mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } 0$ were simultaneously added into the alkaline solution at room temperature of $2 5 . 0 ^ { \circ } \mathsf C$ with vigorously stirring. The suspension was aged for $^ { 2 4 . 0 \mathrm { h } }$ after the addition, and the precipitate was filtered and washed with ultrapure water to neutral pH. Finally, the collected composite was dried at $6 0 ^ { \circ } \mathsf C$ and denoted as $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with $( \mathsf { C u } ^ { 2 + } \ + \ \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratio of 5.0. $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with different $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratios of 1.0, 2.0, 3.0 and 4.0 were also prepared in accordance with the above described processes.

# 2.3. Characterization of catalysts

The crystal patterns of $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ were characterized using X-ray powder diffraction on a diffractometer with Cu $\mathrm { K } \mathfrak { a }$ radiation (XRD, X'TRA, Swiss). The surface morphologies and selected area electron diffraction (SAED) features were analyzed by a scanning electron microscope (SEM, Hitachi S4800, Japan) coupled with energy dispersive X-ray spectroscopy (EDS) and transmission electron microscope (TEM, JEM 1400, JEOL, Japan). The surface functional groups were determined by a fourier transform infrared spectrophotometer within $1 . 0 \%$ KBr wafers (FTIR, Nicolet iS10, USA). Elemental compositions and the chemical oxidation states were observed through $\mathsf X$ -ray photoelectron spectra on a KRA70S AXIS Ultra DLD spectrometer (XPS, Kratos, UK).

# 2.4. Catalytic degradation experiments

Sacrificial batch experiments were carried out in a $2 0 \mathrm { m L }$ borosilicate glass with PTFE liner, and the glass was placed on a rotary shaker at 150 rpm at $2 5 . 0 ^ { \circ } \mathsf C$ . The reaction solution was prepared by $1 . 0 \mathrm { m m o l } \mathrm { L } ^ { - 1 }$ ethylbenzene and appropriate amount of $\operatorname { C u } ( \operatorname { I I } ) .$ - $\mathrm { M g ( I I ) \mathrm { - F e ( I I I ) L D H s } }$ . A required concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was added into the suspension to initiate the reaction. Initial pH was adjusted at 7.0 by addition of HCl or NaOH. Samples were taken at regular intervals and filtered through a $0 . 2 2 \mu \mathrm { m }$ membrane for analysis. For recycling tests, the solid composites of the used $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) }$ LDHs were collected from the solution by vacuum filtration and rinsed with ultrapure water thoroughly, dried at $6 0 ^ { \circ } \mathsf C$ for $8 . 0 \mathrm { h }$ . The conditions of ethylbenzene degradation with the used catalyst were consistent with the fresh one, and the recycled degradation experiments were repeated for 5 times. All the tests were conducted in triplicate to ensure reproducibility and estimate experimental errors.

# 2.5. Chemical analysis

The chemical composition of the prepared $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) }$ LDHs were measured by inductively coupled plasma atomic emission spectroscopy (ICP-AES, Thermo Jarrell Ash/Baird, USA) after the samples were completely dissolved in hydrochloric acid. The concentrations of ethylbenzene in aqueous phase were quantified by gas chromatograph (Agilent 7890A, USA) by using DB-624 chromatographic column $( 3 0 . 0 \mathrm { m } \times 0 . 2 5 \mathrm { \ m m } \times 1 . 4 \mathrm { \mu m } )$ equipped with flame ionization detector (FID), and nitrogen was utilized as carrier gas. An electron spin resonance (Bruker ESR 300E, Germany) was utilized to record the generated active radicals using 5,5- dimethylpyrroline-oxide (DMPO) as radical spin trapping reagent, and the conditions for instrument operation were receiver gain $1 0 ^ { 5 }$ modulation amplitude 2 Gauss, microwave power $1 0 \mathrm { m W } ,$ and modulation frequency $1 0 0 \mathrm { k H z }$ . The total organic carbon (TOC) was analyzed by a multi $\mathsf { N } / \mathsf { C }$ model TOC analyzer (Analytik Jena, multi $\mathsf { N } / \mathsf { C }$ 2100, Germany).

# 3. Results and discussion

# 3.1. Characterization of Cu(II)-Mg(II)-Fe(III)LDHs

The XRD patterns of the as-synthesized $\mathsf { C u } ( \mathrm { I I } ) { \mathsf { - M g } } ( \mathrm { I I } ) .$ -Fe(III) LDHs composites with $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratios of 1.0e5.0 were shown in Fig. 1(a). It was clearly illustrated that the XRD patterns of the prepared composites resembled the typical brucitelike LDHs materials reported in the literature (JCPDS 38-0487) (Cavani et al., 1991; Yan et al., 2017a), and only the crystalline phase of LDHs was observed in all the composites. The reflection peaks of the (003), (006), (009), (015) and (110) planes were indexed corresponding to the basal spacing and rhombohedral symmetry. The crystallite size of d was measured by Scherrer equation of $\mathsf { d } = 0 . 8 9 \lambda / \beta ( \theta ) \cos \Theta$ , where d is the crystallite size, $\gimel$ is the wavelength of the radiation used $( 0 . 1 5 4 2 \mathrm { n m }$ ), q is the Bragg diffraction angle, and $\beta ( \theta )$ is the full width at half-maximum (fwhm). The lattice parameter of c $( \mathsf { c } = d _ { O O 3 } + 2 d _ { O O 6 } + 3 d _ { O O 9 } )$ is characterized as the inter layer distance of the crystal cell (Millange et al., 2000). From Fig. 1(a), the average values obtained from the data for the (003), (006) and (009) diffraction peaks showed that the crystallite sizes were decreased following the rise in the $\mathbb { M } ^ { 2 + } / \mathbb { M } ^ { 3 + }$ ratios. By increasing the $\mathsf { M } ^ { 2 + } / \mathsf { M } ^ { 3 + }$ ratios, the positive charge densities in the layers were increased, making the $\bar { \mathsf { M } } ^ { 2 + } - \mathsf { M } ^ { 3 + } - 0$ octahedron smaller, leading to sharper diffraction peaks and greater c values (Zhang et al., 2010).

As illustrated in Fig. 1(b), the FT-IR spectrum of $\mathsf { C u } ( \mathrm { I I } ) { \mathrm { - } } \mathsf { M g } ( \mathrm { I I } ) .$ - $\mathrm { F e ( I I I ) L D H s }$ exhibited broad absorption band signals assigned to the vibration mode of the hydroxyl groups $\left( - \mathrm { O H } \right)$ at around $3 4 0 0 \mathrm { c m } ^ { - 1 }$ , and the overlapping stretching vibration of the hydroxyl groups was raised from metal-hydroxyl groups in the layers and hydrogen-bonded interlayer water molecules. The deformation mode of water molecules signals was observed at $1 6 2 9 \mathrm { c m } ^ { - 1 }$ . The band signal at $1 3 6 0 \mathrm { c m } ^ { - 1 }$ was corresponded to the stretching vibration of the interlayer $\mathsf { C O } _ { 3 } ^ { 2 - }$ anion, revealing that LDHs contained $\mathsf { C O } _ { 3 } ^ { 2 - }$ as the counter anions in the interlayer (Rigg et al., 1954). In addition, the peaks from 500 to $8 0 0 \mathrm { c m } ^ { - 1 }$ at low frequency were due to the vibration of metal O and metal OH groups in LDHs lattice. The plate-like morphology of the LDHs was characterized by SEM and TEM as shown in Fig. 1(c)e(e), corresponding well with the XRD data. EDS results demonstrated that a large portion of Cu, Fe and Mg were distributed in the layer of as-synthesized LDHs from Fig. 1(f).

# 3.2. Degradation of ethylbenzene in different systems

The effects of different systems on the degradation of ethylbenzene were evaluated as illustrated in Fig. 2(a). Low degradation efficiency of ethylbenzene at $5 . 5 \%$ was observed when only $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was added to the solution, which indicated that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ itself could not efficiently degrade ethylbenzene. When $\mathrm { F e } ( \mathrm { O H } ) _ { 3 }$ was applied to the solution, nearly similar degradation curve of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ for ethylbenzene was obtained, hinting the weak catalytic ability of $\mathrm { F e } ( \mathrm { O H } ) _ { 3 }$ for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ due to the small reaction rate constant of $1 0 ^ { - 3 } { \sim } 1 0 ^ { - 2 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ (Guo et al., 2012). The degradation efficiency of ethylbenzene was slightly increased to $3 8 . 5 \%$ as $\mathrm { C u } ( \mathrm { O H } ) _ { 2 }$ was selected to catalyze $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ as shown in the curve 3 of Fig. 2(a). In addition, in the presence of both $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratio of 1.0 and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , the degradation efficiency of ethylbenzene was accelerated to $6 1 . 1 \%$ , exhibiting higher catalytic activity of $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ composites than $\mathrm { C u } ( \mathrm { O H } ) _ { 2 }$ . Increasing the $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratios to 5.0, the degradation efficiency of ethylbenzene was further increased to $9 6 . 1 \%$ .

Based on the kinetic curves in Fig. 2(a), all the degradation of ethylbenzene was numerically fitted and approximately followed the pseudo-first-order reaction as expressed as $\ln ( c _ { \mathrm { t } } / c _ { 0 } ) = k \mathrm { t } + \mathrm { b } ,$ , where t is the reaction time (h), $c _ { \mathrm { t } }$ and $c _ { 0 }$ are the ethylbenzene concentrations at time of $\mathbf { t } = \mathbf { t }$ and $\mathbf { t } = \mathbf { 0 }$ respectively, $k$ is the apparent reaction rate constant $( \mathsf { h } ^ { - 1 } )$ , and b is a constant. In all the studied cases, the linear regression coefficients of R were higher than 0.98. The calculated $k$ values were 0.159, 0.185, 0.246, 0.313 and $0 . 5 6 3 \mathrm { h } ^ { - 1 }$ in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) \bar { / } \mathsf { F e } ^ { 3 + }$ molar ratios of 1.0, 2.0, 3.0, 4.0 and 5.0, respectively, much greater than that $k$ values of $0 . 0 7 7 \mathrm { h } ^ { - 1 }$ and 0.062 $\mathbf { h } ^ { - 1 }$ evaluated in the systems of $\mathrm { C u ( O H ) } _ { 2 } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and Cu, Mg and Fe hydroxide compounds $( ( \mathbf { C u } ^ { 2 + } + \mathbf { M g } ^ { 2 + } ) / \mathbf { F e } ^ { 3 + }$ molar ratio was 5.0)/ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } .$ . It should be stressed that the $k$ values were increased as the $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratios were raised from 1.0 to 5.0 in $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ systems. The data indicated that surface metal ion of Cu was the active center and played an important role in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ catalysis process for the degradation of ethylbenzene, which was in accordance with the previous research that Cu-based catalysts possess excellent catalytic activity toward catalytic wet oxidation (Guo et al., 2012).

As shown in Fig. 2(b), the decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and TOC removal were measured respectively. The decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the systems of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ alone and $\mathrm { F e ( O H ) } _ { 3 } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ proceeded slowly due to the relative stable structure of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and weak catalytic ability of $\mathrm { F e } ( \mathrm { O H } ) _ { 3 }$ , only a small quantity of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition was achieved, corresponding to little TOC removal. With the addition of $\mathrm { C u } ( \mathrm { O H } ) _ { 2 }$ , the decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was accelerated, with $2 9 . 8 \%$ of the added $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ being decomposed and accompanied by $1 2 . 8 \%$ TOC removal in $6 . 0 \mathrm { h }$ . In contrast, about $3 8 . 3 \%$ , $4 1 . 0 \% , 4 3 . 3 \%$ , $4 8 . 5 \%$ and $5 3 . 7 \%$ of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ were decomposed in the systems of $\mathsf { C u } ( \mathrm { I I } ) { \mathsf { - M g } } ( \mathrm { I I } ) .$ - $\mathrm { F e ( I I I ) L D H s }$ with $( \mathsf { C u } ^ { 2 + } + \mathsf { M g } ^ { 2 + } ) / \mathsf { F e } ^ { 3 + }$ molar ratios of 1.0, 2.0, 3.0, 4.0 and 5.0, corresponding to TOC removals of $2 1 . 0 \%$ , $2 5 . 6 \%$ . $2 9 . 2 \%$ , $3 3 . 1 \%$ and $3 9 . 7 \%$ in the above 5 systems. The decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and TOC removal were also calculated in the system of Cu, Mg and Fe hydroxide compounds $( ( \mathbf { C u } ^ { 2 + } + \mathbf { M g } ^ { 2 + } ) / \mathbf { F e } ^ { 3 + }$ molar ratio was 5.0)/ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , and the values were $2 3 . 7 \%$ and $1 0 . 2 \%$ respectively.

# 3.4. Identification of predominant radical species

Previous studies revealed that reactive oxygen species (ROSs) of OH and $0 _ { 2 } ^ { - } { \bullet } / \mathrm { H O } _ { 2 } { \bullet }$ were the main oxidants in the heterogeneous Fenton-like system using metal oxides as catalyst, and high-valent iron species $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ , $\bar { \mathsf { E } ^ { 0 } } = 1 . 6 5 \mathsf { V } ,$ might be formed, which was accounted for the degradation of organic pollutants under alkaline conditions (Deng et al., 2008; Keenan and Sedlak, 2008; Luo et al.,

2010). Due to the relative lower redox potential of $\mathsf { F e } ^ { \mathsf { I V } } { = } 0$ , benzoic acid could not be degraded and chosen as a probe reagent to test whether the existence of $\mathsf { F e } ^ { \mathrm { I V } } { = } 0$ in the heterogeneous Fenton-like system (Wang et al., 2010b). As indicated in Fig. 4(a), the degradation of benzoic acid with an initial concentration of $0 . 0 8 \mathrm { m m o l } \mathrm { L } ^ { - 1 }$ were $7 1 . 4 \%$ and $2 2 . 7 \%$ respectively for the $\mathtt { C u ( I I ) }$ - $\mathrm { M g ( I I ) \mathrm { - } F e ( I I I ) L D H s / H _ { 2 } O _ { 2 } }$ and $\mathrm { C u ( O H ) } _ { 2 } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ systems under the same conditions. It was suggested that $\mathsf { F e } ^ { \mathrm { I V } } { = } 0$ was not formed in such a system, and ROSs were the main oxidants responsible for the degradation of ethylbenzene. Quenching experiments using benzoquinone and $t$ -butyl alcohol were carried out to further verify the ROSs species in the above 2 systems.

With the addition of $0 . 8 \mathrm { m m o l } \mathrm { L } ^ { - 1 }$ benzoquinone (10 times of ethylbenzene addition), the degradation efficiencies of ethylbenzene were $9 2 . 3 \%$ and $3 4 . 3 \%$ in the $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s } /$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { C u ( O H ) } _ { 2 } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ systems after $6 . 0 \mathrm { h }$ reaction, only a slight decrease was observed than those without the addition of benzoquinone. Little quenching effect indicated that $0 _ { 2 } { \bullet } \mathrm { / H O } _ { 2 } { \bullet }$ radicals were not the main ROSs as benzoquinone was usually used as a scavenger for $0 _ { 2 } { \bullet } \mathrm { / H O } _ { 2 } { \bullet }$ radicals (Palominos et al., 2008). However, the presence of $0 . 8 \mathrm { m m o l } \mathrm { L } ^ { - 1 } t$ -butyl alcohol dramatically inhibited the degradation of ethylbenzene as indicated in curves 1 and 2 of Fig. 4(b). Because t-butyl alcohol was a scavenger for OH radicals, the inhibiting effect implied that OH radicals were the predominant ROSs, responsible for the degradation of ethylbenzene in both $\mathrm { C u ( I I ) { - } M g ( I I ) { - } F e ( I I I ) L D H s / H _ { 2 } O _ { 2 } }$ and $\mathrm { C u ( O H ) } _ { 2 } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ systems (Gültekin et al., 2009).

In the heterogeneous system of the $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s } /$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , the hydroxyl groups were bonded on the surface or the layer of the $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ , which would act as active sites for the decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . On an account of chemical and energetic heterogeneity of the layer structured $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) }$ LDHs, the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ molecules will be adsorbed on the active center of $\mathtt { C u ( I I ) }$ via the coordination bonds to form $\mathsf { \equiv C u ( I I ) H _ { 2 } O _ { 2 } }$ , where $\equiv \mathrm { C u ( I I ) }$ represents the surface lattice $\mathtt { C u ( I I ) }$ . Due to electron donating property of $\mathtt { C u ( I I ) }$ to $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , the reaction was initiated by the adsorbed $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ on the catalyst surface through electron transfer process. By receiving one electron, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was decomposed with the formation of OH radicals and $\mathrm { O H ^ { - } }$ . In the meantime, the surface lattice $\mathsf { \equiv C u ( I I ) }$ was simultaneously converted to higher transient valence of $\equiv \mathsf { C u } ( \mathrm { I I I } )$ . The $\equiv \mathrm { { C u } ( I I I ) }$ in the $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ is unstable and will react with $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ subsequently giving rise to the regeneration of $\equiv \mathrm { C u ( I I ) }$ and the formation of OH (Eq. (16)) (Pham et al., 2013). The OH radicals generated from both the $\mathtt { C u ( I I ) }$ oxidation process with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and the $\mathtt { C u ( I I I ) }$ reduction process with $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ were responsible for the degradation of ethylbenzene (Fig. 7). In the heterogeneous Fenton-like system using composite oxides of iron (Zhang et al., 2010), a surface complex of $\equiv \mathrm { F e } ( \mathrm { I I I } ) \mathrm { H } _ { 2 } { \mathrm O } _ { 2 }$ would be formed and successively converted to $\mathrm { F e ( I I ) }$ and $\bullet \mathrm { H O } _ { 2 }$ , which favoured the activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and the recycle of $\mathsf { \equiv F e ( I I I ) }$ . Because the rate constant for the reduction of $\mathsf { \equiv F e ( I I I ) }$ to $\equiv$ Fe(II) was very slow (Guo et al., 2012), and only OH radicals but no $\bullet \mathrm { H O } _ { 2 }$ signals were detected in the ESR measurement, the effect $\equiv \mathrm { F e ( I I I ) }$ in $\operatorname { C u } ( \operatorname { I I } ) .$ - Mg(II)-Fe(III)LDHs on the whole $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ catalysis process was negligible.

# 4. Conclusions

In the present study, a series of layer structured $\mathsf { C u } ( \mathrm { I I } ) { \mathsf { - M g } } ( \mathrm { I I } ) .$ - Fe(III)LDHs were fabricated and characterized as an excellent heterogeneous Fenton-like catalyst of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ for the degradation of ethylbenzene. The $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ with $( \mathsf { C u } ^ { \bar { 2 } + } + \mathsf { M g } ^ { 2 + } ) /$ $\mathsf { F e } ^ { 3 + }$ molar ratio of 5.0 caused the ethylbenzene degradation efficiency and TOC removal of $9 6 . 1 \%$ and $3 9 . 7 \%$ in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ with the reaction time of $6 . 0 \mathrm { h }$ . The experimental results indicated that the $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ was of high level of catalytic activity and stability, and OH radicals were the predominant ROSs for the degradation of ethylbenzene. Catalytic mechanism revealed that the redox of $\mathsf { C u } ( \mathrm { I I } ) / \mathsf { C u } ( \mathrm { I I I } )$ on the active sites of layered $\mathtt { C u ( I I ) }$ - Mg(II)-Fe(III)LDHs surface was accounted for the formation of free radicals and the cycle of $\mathtt { C u ( I I ) }$ . The decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ catalyzed by $\mathrm { C u ( I I ) \mathrm { - } M g ( I I ) \mathrm { - } F e ( I I I ) L D H s }$ would provide a potential alternative for the degradation of organic pollutants.
