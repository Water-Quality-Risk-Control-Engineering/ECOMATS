# Electron Delocalization Realizes Speedy Fenton-Like Catalysis over a High-Loading and Low-Valence Zinc Single-Atom Catalyst

Shaosong Xin, Luning Ni, Peng Zhang, Haobin Tan, Mingyang Song, Tong Li, Yaowen Gao,\* and Chun Hu\*

A zinc (Zn)-based single-atom catalyst (SAC) is recently reported as an active Fenton-like catalyst; however, the low Zn loading greatly restricts its catalytic activity. Herein, a molecule-confined pyrolysis method is demonstrated to evidently increase the Zn loading to 11.54 wt. $\%$ for a Zn SAC $( Z \mathsf { n } _ { \mathsf { S A } } { \mathsf { - N - C } } )$ containing a mixture of $Z n - N _ { 4 }$ and ${ Z _ { \mathsf { n } - \mathsf { N } _ { 3 } } }$ coordination structures. The latter unsaturated ${ Z _ { \mathsf { n } - \mathsf { N } _ { 3 } } }$ sites promote electron delocalization to lower the average valence state of Zn in the mix-coordinated ${ \mathsf { Z } } { \mathsf { n } } { - } { \mathsf { N } } _ { \mathsf { x } }$ moiety conducive to interaction of $z _ { \mathsf { n } _ { \mathsf { S A } } }$ -N-C with peroxydisulfate (PDS). A speedy Fenton-like catalysis is thus realized by the high-loading and low-valence $Z n _ { S A } - N - C$ for PDS activation with a specific activity up to $0 . 1 1 \mathrm { \ m i n } \mathsf { L } ^ { - 1 } \mathsf { m } ^ { - 2 }$ , outstripping most Fenton-like SACs. Experimental results reveal that the formation of $Z \mathsf { n } _ { \mathsf { S A } } { \cdot } \mathsf { N } { \cdot } \mathsf { C } { \mathrm { - } } \mathsf { P } \mathsf { D } \mathsf { S } ^ { \ast }$ complex owing to the strong affinity of $Z n _ { S A } - N - C$ to PDS empowers intense direct electron transfer from the electron-rich pollutant toward this complex, dominating the rapid bisphenol A (BPA) elimination. The electron transfer pathway benefits the desirable environmental robustness of the $Z _ { \mathsf { n } _ { \mathsf { S A } } }$ -N-C/PDS system for actual water decontamination. This work represents a new class of efficient and durable Fenton-like SACs fol potential practical environmental applications.

# 1. Introduction

The worldwide water scarcity and increasing need for clean water has provoked the mushroom development of water decontamination technologies over the past decades.[1] The Fenton-like reaction using persulfate, including peroxymonosulfate (PMS) and peroxydisulfate (PDS), as a main oxidant represents a promising strategy for the elimination of refractory organic contaminants, generally thanks to the yield of highly reactive hydroxyl $( \bullet _ { \mathrm { { O H } } } )$ and/or sulfate $( \mathrm { S O } _ { 4 } ^ { \bullet - } )$ radicals upon the dissociation of the O-O bond in the persulfate molecule.[25] Amongst multifarious heterogeneous persulfate activators, carbonbased single-atom catalysts (SACs) with utmost atom efficiency, tunable metal coordination, and the confinement effect of electrons have attracted tremendous interest in the Fenton-like catalysis, particularly in the activation of the asymmetric PMS $( \mathrm { H } { - } \mathrm { O } { - } \mathrm { O } { - } \mathrm { S } \mathrm { O } _ { 3 } { - } )$ ,[6,7] which is considered to be activated more easily compared to PDS with a symmetric structure $( \mathrm { S O } _ { 3 } { - } \mathrm { O } { - } \mathrm { O } { - } \mathrm { S O } _ { 3 } { { ^ { 2 - } } ) }$ .[8]

With reference to the reported Fentonlike SACs, the central metal sources are dominantly concentrated on partially occupied 3d transition-metals, including cobalt $( \mathrm { C o } )$ [1) ro Fe,0e (Mn),[21] and copper $\mathrm { ( C u ) }$ [22,23] which are intrinsically active for the Fenton-like chemistry. Aside from those unfilled 3d transition metal atoms, our recent work demonstrated that construction of atomically dispersed zinc-nitrogen $( \mathrm { Z n - N _ { 4 } } )$ sites could tune the electron density of the $_ { \mathrm { Z n } }$ atom and hence convert the inert element $_ \mathrm { Z n }$ with a full-filled 3d orbital into an active Fenton-like single-atom catalyst (SA-Zn-NC) for PMS activation, which expanded the variety of Fenton-like SACs.[24] In spite of this, the SAZn-NC catalyst suffered from a relatively poor Fenton-like activity due to its low $\mathrm { Z n }$ loading $( 0 . 8 2 \mathrm { w t } . \% )$ . This leaves plenty of room for increase of active site density to enhance the Fenton-like performance of the $\mathrm { Z n }$ -based SACs. On the other hand, compared to PMS, PDS possesses a higher stability and solubility at room temperature, and meanwhile, causes a lower solution $\mathrm { p H }$ decrease at a same concentration.[4,25,26] In this context, the SACs-related PDS activation processes should deserve more attention and investigation. Despite the achievement of a certain progress of PDS activation by SACs, to the best of our knowledge, the activation of PDS over Zn single-atom catalysts has been rarely reported so far. Moreover, the relevant PDS-mediated Fenton-like catalytic mechanism includes radical and/or non-radical (high-valent metaloxo species, singlet oxygenation, electron transfer) pathways. In particular, the electron transfer route involves the intense interaction of persulfate with catalysts and the subsequent formation of surface-activated complexes, which triggers the direct electron transport from organic pollutants toward such complexes and thus results in the oxidation of contaminants. This process endows the catalytic systems with high selectivity to electron-rich organics and remarkable anti-interference capability to background substances in the complicated water matrix.[27] It therefore necessitates an exploration of the electron transfer pathway in the course of PDS activation over $_ { \mathrm { Z n } }$ SACs.

Herein, we have observably increased the loading of $\mathrm { Z n }$ single atom to $1 1 . 5 4 \mathrm { w t . } \%$ for a low-valence $\mathrm { Z n }$ -based SAC (marked as $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C ) } } }$ via a surface molecule-confined pyrolysis approach. Different from the common SACs with a single and well-defined $\mathrm { { M - N _ { x } } }$ coordination configuration, the resultant $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C contains a mixture of atomic ${ \mathrm { Z n - N _ { 4 } } }$ and ${ \mathrm { Z n - N } } _ { 3 }$ structures. The formation of low-coordinated ${ \mathrm { Z n - N } } _ { 3 }$ sites facilitates electron delocalization and thus affords enough delocalized electrons to lower the oxidation state of the $_ \mathrm { Z n }$ atom conducive to electron transport between the mix-coordinated ${ \mathrm { Z n - N _ { x } } }$ moiety and PDS. As a result, the high-loading and low-valence $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C catalyst exhibits a remarkable Fenton-like performance for the activation of PDS toward bisphenol A (BPA) degradation, with a specific activity up to $0 . 1 1 \mathrm { L } \operatorname* { m i n } ^ { - 1 } \mathrm { m } ^ { - 2 }$ , surpassing most Fenton-like SACs for PDS and even PMS activation. Detailed experimental results revealed that the strong interaction of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ with PDS favors the formation of $\mathrm { { Z n } _ { \mathrm { { S A } } } \mathrm { { - N \mathrm { { - C - P D S } ^ { \ast } } } } }$ complex, which triggers direct electron transfer from the electron-rich organic pollutant toward this adduct, dominating the speedy contaminant oxidation in the course of Fenton-like catalysis. The electron transfer pathway endows the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { \cdot C / P D S } } }$ system with high antiinterference property for the complicated water matrix. Notably, $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C achieves an efficient pollutant remediation over $2 1 6 \mathrm { h }$ when used in a continuous-flow column reactor, presenting a broad prospect for sustainable environmental applications.

# 2. Results and Discussion

# 2.1. Characterizations of Samples

The $_ \mathrm { Z n }$ single-atom catalyst $( \mathrm { Z n } _ { \mathrm { { S A } } } – \mathrm { { N } } – \mathrm { { C } ) }$ was prepared through a surface molecule-confined calcination method. As shown in Figure 1a, certain amounts of melamine, phenanthroline and $\mathrm { Z n } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ are ground uniformly in an agate mortar, where the melamine was utilized as both carbon and nitrogen precursors, and phenanthroline was used as a chelating agent to anchor the $_ { \mathrm { Z n } }$ species so as to promote the space isolation of $\mathrm { Z n }$ ions. The as-prepared sample was then calcined at $6 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ under nitrogen gas atmosphere to yield the $\mathrm { Z n }$ -decorated carbon nitride $( \mathrm { Z n } { \cdot } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } )$ . Upon further pyrolysis at a higher temperature $( 8 0 0 ~ ^ { \circ } \mathrm { C } )$ , the ${ \mathrm { Z n } } { \cdot } { \mathrm { C } } _ { 3 } { \mathrm { N } } _ { 4 }$ is converted to $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ after acid etching. The importance of phenanthroline in the synthesis of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ can be detailed after Figures S1 and S2 (Supporting Information). The scanning electron microscope (SEM) image (Figure S3, Supporting Information) shows the loose layered and porous structure of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ , which is also visualized by the transmission electron microscopy (TEM) analysis (Figure 1b), without any identifiable metallic particles on the surface. The high-resolution TEM (HRTEM) image (Figure 1c) with the randomly selected region illustrates the typical nature of carbonbased material for $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ , and no crystalline $_ { \mathrm { Z n } }$ species is observed. The Raman spectrum (Figure S4, Supporting Information) further validates the carbonaceous character of $\mathrm { Z n } _ { \mathrm { S A } } – \mathrm { N } .$ C. Elemental mapping by energy-dispersive X-ray (EDX) spectroscopy (Figure 1d) manifests the uniform distribution of $\mathrm { Z n }$ over the entire N-doped carbon matrix. The high-angle annular dark-field scanning TEM (HAADF-STEM) image (Figure 1e) clearly reveals the atomic dispersion of $_ \mathrm { Z n }$ atoms in $\mathrm { Z n _ { S A } \mathrm { ^ { - N } } }$ C at a high density, as visualized by numerous bright spots on the surface.[28] The Zn content was measured to be $3 . 0 4 ~ \mathrm { a t \% }$ and $1 1 . 5 4 ~ \mathrm { w t . } \%$ by XPS and inductively coupled plasma-optical emission spectroscopy (ICP-OES) (Table S1, Supporting Information), respectively, suggesting a high loading of $_ \mathrm { Z n }$ for $\mathrm { Z n } _ { \mathrm { S A } } .$ N-C. The atomically dispersed $_ { \mathrm { Z n } }$ species can be also evidenced by the X-ray diffraction (XRD) pattern of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ (Figure 1f) which shows only diffraction from graphitic carbon but no Znrelated crystalline phase. The $\Nu _ { 2 }$ adsorption/desorption isotherm (Figure 1g) exhibits a representative type IV curve for $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C, with its specific surface area of $2 2 2 . 3 \ \mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 }$ . The relevant pore size distribution curve (inset of Figure 1g) indicates the mesoporous structure of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ .

The X-ray absorption spectroscopy (XAS) analysis was performed to probe the coordination structure and valence state of the $_ { \mathrm { Z n } }$ atom in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. The Zn K-edge X-ray absorption nearedge structure (XANES) spectra (Figure 2a) demonstrate that the absorption edge position of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ locates away from that of $_ { \mathrm { Z n } }$ foil but approaches that of zinc phthalocyanine $( \mathrm { Z n P c } )$ , and meanwhile, is lower than that of ${ \mathrm { Z n O } }$ This implies that the $\mathrm { Z n }$ atom is in an oxidation state between $\mathrm { Z n ^ { 0 } }$ and ${ \mathrm { Z n } } ^ { 2 + }$ .Similarly, the white line peak intensity of $\mathrm { Z n _ { S A } \mathrm { \overline { { + } N \mathrm { - } C } } }$ is higher than that of Zn foil, while is inferior to that of $\mathrm { Z n P c }$ and ${ \mathrm { Z n O } }$ .The $\mathrm { Z n P c }$ molecule possesses a typical ${ \mathrm { Z n - N _ { 4 } } }$ configuration, more specially, the $\mathrm { Z n }$ pyrrolic $\mathrm { N } _ { 4 }$ structure (Figure S5, Supporting Information). In the XANES spectrum of $\mathrm { Z n P c }$ , the $D _ { 4 \mathrm { h } }$ symmetry fingerprint peak of Zn—pyrrolic $\mathrm { N } _ { 4 }$ appears at $\approx 9 6 6 2 . 4 \ : \mathrm { e V } .$ However, this symmetry peak disappears in the spectrum of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ which suggests that $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C contains no $\mathrm { Z n }$ pyrrolic $\mathrm { N } _ { 4 }$ moiety, and that a non-centrosymmetric $\mathrm { Z n - N }$ structure may form in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C.[29,30] From the Fourier transformed extended $\mathrm { X } \cdot$ sorption fine tructure (EXAFS) spectra (Figure ), $\mathrm { Z n } _ { \mathrm { S A } }$ N-C shows only one primary peak at $\bar { 1 } . 5 0 \mathrm { ~ \AA ~ }$ assignable to the $\mathrm { Z n - N }$ scatting path, without the detection of $Z \mathrm { n - Z n }$ (at $2 . 2 8 \mathring { \mathrm { A } } ]$ and second-shell $Z { \mathrm { n - O - Z n } }$ (at 2.91 Å) bonds.[24,31] Besides, the wavelet transform (WT) analysis of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C and reference samples was further conducted. As shown in Figure S6 (Supporting Information), the WT contour plots of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ exhibits one intensity maximum at ${ \approx } 5 . 6 5 \ \mathring { \mathrm { A } } ^ { - 1 }$ , which is close to that in $\mathrm { Z n P c }$ $( 6 . 1 5 \mathrm { ~ \AA ~ } ^ { - 1 } )$ attributable to the $\mathrm { Z n - N }$ coordination. Moreover, the signals derived from the $Z \mathrm { n - Z n }$ contribution in the $\mathrm { Z n }$ foil $( 7 . 3 5 \mathring { \mathrm { A } } ^ { - 1 } )$ and ${ \mathrm { Z n O } }$ $( 7 . 2 5 \mathring { \mathrm { A } } ^ { - 1 } )$ are unobservable in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. These results reveal that the $_ { \mathrm { Z n } }$ element exists in the nitrogencoordinated atomically dispersed form in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. In the spectrum of $\mathrm { Z n P c }$ containing a well-defined ${ \mathrm { Z n - N } } _ { 4 }$ configuration, the $\mathrm { Z n - N }$ bond length is $1 . 5 7 \mathrm { ~ \AA ~ }$ By contrast, $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C delivers a slightly shorter $\mathrm { Z n - N }$ interatomic distance of $1 . 5 0 \mathrm { ~ \AA ~ }$ ,implying a contractive $\mathrm { Z n - N }$ local coordination center in $\mathtt { Z n } _ { \mathtt { S A } }$ -NC.[30] In the meantime, the ${ \mathrm { Z n - N } }$ peak intensity of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ is also weaker relative to that of $\mathrm { Z n P c }$ , which indicates the coordination number of $\mathrm { Z n }$ around $_ \mathrm { N }$ in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C is ${ < } 4$ [12,32]Considering the $\mathrm { Z n P c }$ molecule possesses a representative ${ \mathrm { Z n - N _ { 4 } } }$ configuration, $\mathrm { Z n P c }$ was used as a ${ \mathrm { Z n - N _ { 4 } } }$ core structure for the EXAFS fitting to ascertain the local coordination of $\mathtt { Z n } _ { \mathtt { S A } }$ -NC. According to the first-shell EXAFS fitting results (Figure 2c; Figure S7 and Table S2, Supporting Information), the average coordination number of $_ { \mathrm { Z n } }$ with $_ \mathrm { N }$ in $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ is found to be 3.6, which is lower than that in $\mathrm { Z n P c }$ (3.9). The lower $\mathrm { Z n - N }$ coordination number means that, besides the normal ${ \mathrm { Z n - N _ { 4 } } }$ moiety, an unsaturated ${ \mathrm { Z n - N _ { x } } }$ $\left( \mathbf { X } < 4 \right)$ structure may also form in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. In this context, a lower-coordinated ${ \mathrm { Z n - N } } _ { 3 }$ model was constructed via density functional theory (DFT) calculations (Figure S8a, Supporting Information) and utilized as a core structure to conduct the EXAFS fitting for $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ However, the relevant fitting results turn out to be less satisfactory due to the larger R-factor (percentage misfit) and the unmatched coordination number (Figure S8b and Table S3, Supporting Information), indicating $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C is not just composed of the ${ \mathrm { Z n - N } } _ { 3 }$ configuration. The above results demonstrate that $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C consists of a mixture of ${ \mathrm { Z n - N _ { 4 } } }$ and ${ \mathrm { Z n - N } } _ { 3 }$ coordination structures.[30]

In addition, the XPS analysis was further performed to investigate the chemical structure of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ As displayed in Figure 2d, the XPS N 1s spectrum of ZnPc can be deconvoluted into two $\mathrm { N } _ { \alpha }$ and $\mathrm { N } _ { \beta }$ sub-peaks, the former of which refers to the Zn—pyrrolic $_ \mathrm { N }$ bond in the $\mathrm { Z n }$ -pyrrolic $\mathrm { N } _ { 4 }$ structure.[33] The $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ contains five peaks corresponding to pyridinic N, pyrrolic N, ${ \mathrm { Z n - N } }$ ,graphitic N, and oxidized N. Notably, the position of $\mathrm { Z n - N }$ peak in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C is close to that in $\mathrm { Z n P c }$ but with a negative shift of $0 . 1 6 \ \mathrm { e V } .$ This result suggests the existence of ${ \mathrm { Z n - N _ { 4 } } }$ configuration in $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ , while the $_ { \mathrm { Z n } }$ atom may coordinate with other N species rather than pyrrolic N. The absence of $\mathrm { Z n } { - } \mathrm { C }$ peak in the XPS C 1s spectrum (Figure S9, Supporting Information) excludes the bonding of $_ { \mathrm { Z n } }$ and C atoms in $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ . As the organic precursors would decompose completely at elevated pyrolysis temperature, the calcination of the mixture of melamine and phenanthroline (without the $_ { \mathrm { Z n } }$ source) with the same method to the preparation of $\mathtt { Z n } _ { \mathtt { S A } }$ -NC cannot produce the pure nitrogen-doped carbon (N-C) material. Similarly, the formation energy of the $_ { \mathrm { Z n } }$ pyridinic $\Nu _ { 3 }$ model is inferior to that of the $_ { \mathrm { Z n } }$ pyrrolic $\Nu _ { 3 }$ one. The lower $E _ { \mathrm { f } }$ values of $\mathrm { Z n }$ pyridinic $\mathrm { N _ { x } }$ structures relative to those of Zn-pyrrolic $\mathrm { N _ { x } }$ ones suggest that the isolated $_ \mathrm { Z n }$ atoms are more likely to bond with pyridinic N to constitute $\mathrm { Z n }$ pyridinic $\mathrm { N } _ { 4 }$ and $_ { \mathrm { Z n } }$ pyridinic $\Nu _ { 3 }$ configurations in $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ . Thus, the atomic structure of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ containing a mixture of $\mathrm { Z n }$ pyridinic $\mathrm { N } _ { 4 }$ and $\mathrm { Z n - }$ pyridinic $\mathrm { N } _ { 3 }$ moieties can be visualized in Figure 1a above. In the XPS Zn 2p spectra (Figure 2e), the $\mathrm { Z n ~ } 2 \mathrm { p } _ { 3 / 2 }$ and $\mathrm { Z n ~ } 2 \mathrm { p } _ { 1 / 2 }$ peaks in $\mathrm { Z n _ { \mathrm { { S A } } } \mathrm { \overline { { { - N } } } \mathrm { { - C } } } }$ are situated at lower binding energies compared with those in the ${ \mathrm { Z n O } }$ reference, reflecting a low oxidation state $( < + 2 )$ of $_ { \mathrm { Z n } }$ for $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. To quantify the oxidation state of $_ \mathrm { Z n }$ species, the correlation between $_ { \mathrm { Z n } }$ valence state and the absorption threshold energy $( E _ { 0 } )$ obtained from the first differentiation in the main absorption edge region of XANES was explored. As depicted in Figure 2f, the average oxidation state of $_ { \mathrm { Z n } }$ in $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ is determined to be $\approx + 1 . 5 0$ . The decrease of average valence state of $_ \mathrm { Z n }$ can be attributable to the formation of low-coordinated ${ \mathrm { Z n - N } } _ { 3 }$ configuration. The electron density distribution analysis (Figure $^ { 2 \mathrm { g } , \mathrm { h } }$ illuminates electron accumulation around the $\mathrm { Z n }$ atom in both $\mathrm { Z n - N _ { 4 } }$ and ${ \mathrm { Z n - N } } _ { 3 }$ models. A lower Hirshfeld charge signifies an electron-richer environment of the $_ \mathrm { Z n }$ atom in the unsaturated ${ \mathrm { Z n - N } } _ { 3 }$ configuration, suggesting that the formed ${ \mathrm { Z n - N } } _ { 3 }$ structure holds abundant delocalized electrons to reduce the average valence state of $_ \mathrm { Z n }$ in $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C. The electron delocalization of the mix-coordinated ${ \mathrm { Z n - N _ { x } } }$ (particularly $\mathrm { Z n - N } _ { 3 } ,$ sites can be evidenced by a strong signal with a $\boldsymbol { \mathrm { g } } .$ factor of 2.003 referring to free electrons in the solid-state electron paramagnetic resonance (EPR) spectrum of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C (Figure 2i). All the above characterization results manifest that $\mathrm { Z n _ { S A } \mathrm { \overline { { + } N \mathrm { - } C } } }$ contains a non-centrosymmetric mix-coordination of single-atomic and high-density $\mathrm { Z n - N _ { 4 } }$ and ${ \mathrm { Z n - N } } _ { 3 }$ structures, which results in the decrease of the average valence of the $_ \mathrm { Z n }$ atom. Benefiting from the high $_ { \mathrm { Z n } }$ loading to provide abundant ${ \mathrm { Z n - N _ { x } } }$ sites and the electron delocalization of ${ \mathrm { Z n - N _ { x } } }$ centers to facilitate interfacial electron transfer, the $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C catalysts is expected to deliver an admirable Fenton-like activity.

# 2.2. Fenton-Like Performance of ${ \bf \delta Z } _ { \bf n _ { S A } }$ -N-C

The Fenton-like performance of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ was assessed by catalytic oxidation of bisphenol A (BPA, a typical emerging contaminant in water) in the presence of PDS. As displayed in Figure 3a, a 30-min pre-interaction of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ with BPA causes ${ \approx } 2 4 \%$ of BPA removal. The PDS alone affords an insignificant removal of BPA, indicating the incapability of PDS in oxidizing BPA directly. However, the addition of PDS into the suspension brings about the complete BPA elimination within $3 \mathrm { { m i n } }$ , suggesting a superb Fenton-like reactivity of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. According to pseudofirst-order kinetics $( \ln ( C / C _ { 0 } ) = - k t$ ,inset of Figure 3a), the reaction rate constant of $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C for PDS activation toward BPA oxidation was found to be $2 . 4 4 ~ \mathrm { { m i n ^ { - 1 } } }$ . By normalizing the rate constant to specific surface area and dosage of the catalyst, the specific activity of $\mathrm { Z n _ { \mathrm { { S A } } } \mathrm { - N \mathrm { { - C } } } }$ was calculated to be $0 . 1 1 \mathrm { ~ L ~ m i n ^ { - 1 } }$ $\mathrm { m } ^ { - 2 }$ (Table S4, Supporting Information), which is much greater than that of most Fenton-like SACs for PDS and even PMS activation (Figure 3b), reflecting that $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ is among the rank of excellent Fenton-like SACs. The increase of total organic carbon (TOC) removal efficiency as a function of reaction time (Figure 3c) attests to the degradation of BPA by $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ via PDS activation. It is worth noting that the pre-interaction between $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C and BPA for $3 0 \ \mathrm { m i n }$ produces ${ \approx } 2 0 \%$ of TOC removal, which is slightly lower than the BPA removal efficiency $( \approx 2 4 \% )$ , suggesting that besides BPA adsorption, the oxidation of BPA occurs over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C simultaneously (see more discussions in the next section). The initial pH exerts an insignificant impact on the abatement of BPA (Figure 3d), illustrating the effectiveness of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { \cdot C / P D S } } }$ over a broad $\mathsf { p H }$ range. The inappreciable influence of common environmental-relevant substances including inorganic anions and natural organic matter such as humic acid (HA) on BPA decay (Figure 3e) reveals the sound tolerance of the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { \cdot C / P D S } } }$ system to the complicated water matrix. Moreover, the efficient elimination of BPA can be fulfilled in tap and river waters (Figure 3f) (their water quality parameters could be available from our previous work),24] which manifests the potential practicability of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C for actual environmental remediation with PDS.

# 2.3. Mechanistic Insights into Fenton-Like Catalysis

The PDS-mediated Fenton-like catalysis generally involves the formation of reactive oxygen species (ROS). In the course of PDS activation by $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ , the yield of ROS was detected via the EPR- measurements. As shown in Figure 4a, neither ${ \bullet } _ { \mathrm { O H } }$ nor $\mathrm { S O } _ { 4 } ^ { \bullet - }$ signals are visible for $\mathrm { Z n _ { S A } \mathrm { \overline { { + } N \mathrm { - } C } } }$ irrespective of the addition of BPA or PDS by using 5,5-dimethyl-1-pyrroline N-oxide (DMPO) as a spin-trapping reagent, excluding the generation of ${ \bullet } _ { \mathrm { O H } }$ and $\mathrm { S O } _ { 4 } ^ { \bullet - }$ during the interaction between $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ and BPA or PDS. In contrast, the characteristic signal of superoxide radical $( \mathsf { O } _ { 2 } ^ { \bullet - } )$ can be clearly noted for the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ alone using DMPO as a trapping agent (Figure 4b). After the addition of benzoquinone (BQ, a typical scavenger for $\mathsf { O } _ { 2 } ^ { \bullet - }$ , the $\mathrm { O } _ { 2 } ^ { \bullet - }$ peak intensity experiences a dramatic decrease for bare $\mathrm { Z n } _ { \mathrm { S A } } .$ . N-C (Figure S11, Supporting Information). Upon $\Nu _ { 2 }$ aeration, the $\mathrm { O } _ { 2 } ^ { \bullet - }$ signal vanishes completely for the individual $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -NC. These phenomena illustrate the capability of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C in dissolved oxygen (DO) activation for $\mathrm { O } _ { 2 } ^ { \bullet - }$ production. Intriguingly, the intensity of $\mathrm { O } _ { 2 } ^ { \bullet - }$ signal increases after the introduction of BPA into the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ suspension (Figure 4b), which implies that the presence of BPA boosts DO reduction over $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ to produce more amount of $\mathrm { O } _ { 2 } ^ { \bullet - }$ . Nonetheless, the replacement of BPA with PDS decreases the $\mathrm { O } _ { 2 } ^ { \bullet - }$ peak intensity, indicating that PDS weakens the reduction of DO by $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. Meanwhile, the infusion of BPA into the $\mathrm { Z n _ { S A } { \cdot } N { \cdot } C / P D S }$ system further attenuates the intensity of $\mathrm { O } _ { 2 } ^ { \bullet - }$ peak, which can be ascribed to the BPA oxidation by a small amount of $\mathrm { O } _ { 2 } ^ { \bullet - }$ . Similarly with ${ \bullet } _ { \mathrm { O H } }$ and $\mathrm { S O } _ { 4 } ^ { \bullet - }$ , the non-radical species, namely singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , is undetectable for $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ in the absence and presence of BPA or PDS, as evidenced by the inexistence of any ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ signal in different suspensions with 2,2,6,6-tetramethyl-4-piperidinol (TMP) (Figure 4c). The quenching tests (Figure S12a, Supporting Information) suggest that the injection of isopropanol (IPA, a scavenger for ${ \bullet } _ { \mathrm { O H } }$ or ethanol (a quencher for $\mathrm { S O } _ { 4 } ^ { \bullet - } ]$ exerts an insignificant suppression on BPA oxidation over $\mathrm { Z n _ { \mathrm { { S A } } } \mathrm { { \cdot N \mathrm { { - C } } } } }$ with PDS, while the presence of BQ shows a slight inhibition on BPA degradation in $\mathrm { Z n _ { S A } { \cdot } N { \cdot } C / P D S }$ As for ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , the addition of TMP (a typical ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ quencher) with different concentrations hardly alters the degradation of BPA (Figure S12b, Supporting Information). Nonetheless, when furfuryl alcohol (FFA) was used as another ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ quenching agent, the BPA abatement is slightly inhibited at a FFA concentration of $\mathsf { 5 } \mathrm { m M }$ (Figure S12c, Supporting Information), which is contradictory to above EPR and quenching test results in terms of no ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ formation. Guan et al.[34] reported the analogous inhibitory effect of FFA on organic pollutant degradation during PDS activation by carbon nanotube (CNT). They demonstrated that the high-concentration FFA could competitively consume the reactive nonradical PDS-CNT species leading to the inhibition of bromophenol oxidation. Moreover, Ren et al.[35] also observed that FFA profoundly inhibited the oxidation of phenolic compounds via suppressing the electron transfer between the radical-free $\mathsf { C N T - P D S } ^ { \ast }$ complex and phenolic pollutants, without the production of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ . According to these literatures, the FFA concentration was increased to probe its impact on BPA degradation by the present $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { \cdot C / P D S } } }$ system. As expected, FFA at a higher concentration of $1 0 ~ \mathrm { m M }$ evidently restrains the degradation of BPA (Figure S12c, Supporting Information). This result rules out the formation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ during PDS activation by $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ , and furthermore, implies the existence of electron transfer pathway behind the Fenton-like oxidation of BPA by $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C.

Without the involvement of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , the substitution of deuteroxide $( \mathrm { D } _ { 2 } \mathrm { O } )$ for $\mathrm { H } _ { 2 } \mathrm { O }$ exhibits an insignificant influence on the overall BPA oxidation in $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C/PDS (Figure S13, Supporting Information). However, the BPA oxidation performance in $\mathsf { D } _ { 2 } \mathsf { O }$ is slightly slower compared to that in $\mathrm { H } _ { 2 } \mathrm { O }$ within the reaction time from 1 to $3 \mathrm { { m i n } }$ . This phenomenon is similar with a recent work reporting that the replacement of $\mathrm { H } _ { 2 } \mathrm { O }$ with $\mathrm { D } _ { 2 } \mathrm { O }$ decreased PMS decomposition and hence retarded PMS activation, giving rise to the $\mathsf { D } _ { 2 } \mathsf { O }$ exchange-induced attenuation of 4-chlorophenol (4-CP) degradation in the annealed diamonds (AND)/PMS system.[36] In view of the similarity of PMS and PDS, it can be assumed that the substitution of $\mathrm { H } _ { 2 } \mathrm { O }$ with $\mathrm { D } _ { 2 } \mathrm { O }$ could also weaken the decomposition of PDS by $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. Following this literature, the PDS decay over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C in $\mathsf { D } _ { 2 } \mathsf { O }$ was explored. As depicted in Figure S14a (Supporting Information), the decay of PDS is indeed slower in $\mathsf { D } _ { 2 } \mathsf { O }$ as compared with that in $\mathrm { H } _ { 2 } \mathrm { O }$ Considering the existence of BPA can boost PDS decomposition by $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ . N-C apparently (see Figure 4j below), the consumption of PDS in $\mathsf { D } _ { 2 } \mathsf { O }$ with the presence of BPA was also investigated. From Figure S14b (Supporting Information), the PDS consumption in $\mathrm { D } _ { 2 } \mathrm { O }$ is also inferior to that in $\mathrm { H } _ { 2 } \mathrm { O }$ Therefore, the lower BPA degradation in $\mathrm { D } _ { 2 } \mathrm { O }$ than that in $\mathrm { H } _ { 2 } \mathrm { O }$ can be attributable to the retardation of PDS activation by $\mathsf { D } _ { 2 } \mathsf { O }$ . The above EPR measurement, quenching test, and solvent exchange experiment results illuminate no generation of $\bullet _ { \mathrm { O H / S O _ { 4 } } } \bullet -$ and ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , but the production of a handful of $\mathrm { O } _ { 2 } ^ { \bullet - }$ during PDS activation over $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ .

To validate the yield of $\mathsf { O } _ { 2 } ^ { \bullet - }$ over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C, the nitroblue tetrazolium (NBT) method was adopted since $\mathrm { O } _ { 2 } ^ { \bullet - }$ can interact with NBT to weaken the maximum absorbance of NBT at $2 5 9 \mathrm { n m }$ [37,38] As depicted in Figure 4d, the maximum absorption intensity of

NBT undergoes a decrease after interacting with $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ for $3 0 \mathrm { m i n }$ , confirming the $\mathrm { O } _ { 2 } ^ { \bullet - }$ generation over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C via DO reduction. The attenuation of NBT absorbance continues to proceed upon the addition of BPA into the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ suspension, while the infusion of PDS reduces the NBT absorption intensity, which symbolizes the promotion and demotion of DO reduction over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C by BPA and PDS, respectively. The further introduction of PDS into the suspension of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C and BPA decreases the NBT maximum absorbance slightly (Figure 4e), which suggests the limited production of $\mathrm { O } _ { 2 } ^ { \bullet - }$ in the system of $\mathrm { Z n _ { S A } { \cdot } N { \cdot } C / P D S } + \mathrm { B P A }$ , consistent with the relevant EPR analysis in Figure 4b above. Considering the capacity of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ in molecular oxygen activation for $\mathrm { O } _ { 2 } ^ { \bullet - }$ formation, the BPA removal by the single $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ was investigated. As displayed in Figure S15a (Supporting Information), the augment of the catalyst dosage from 0.05 to $\stackrel { \cdot } { 0 . 2 } \mathtt { g L } ^ { - 1 }$ produces a finite enhancement for BPA elimination by the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ alone after a 30-min reaction, implying that the $\mathrm { O } _ { 2 } ^ { \bullet - }$ generated from DO reduction over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C seems to be insufficient to oxidize BPA efficiently. In this regard, the desirable BPA degradation necessitates the introduction of PDS. As anticipated, the addition of PDS apparently $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ . N-C affords the higher BPA degradation kinetics (Figure S15a, Supporting Information) and the larger reaction rate constant (Figure S15b, Supporting Information). Nevertheless, these reinforcements become less significant by increasing the catalyst dose from 0.1 to $0 . 2 \mathrm { g } \mathrm { L } ^ { - 1 }$ . Unlike the apparent rate constant, the specific activity first increases from the catalyst loading of 0.05 to $0 . 1 \ \mathrm { g } \ \mathrm { L } ^ { - 1 }$ , but decreases with the further augment to $0 . 2 \ \mathrm { g } \ \mathrm { L } ^ { - 1 }$ (Figure S15c, Supporting Information). This phenomenon may be explained by the following reasons. On one hand, the augment of catalyst dosage can assuredly provide more active sites to strengthen the interaction between $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ and reactants, so as to enhance the apparent activity of $\mathtt { Z n } _ { \mathtt { S A } }$ N-C. On the other hand, the higher dose of the catalyst is likely to impede its complete uniform suspension in the reaction solution, which cannot guarantee the full accessibility of active sites per surface area to reactants, giving rise to the decrease of specific activity of $\mathrm { \Delta } \mathrm { z n } _ { \mathrm { s A } }$ -NC at the greater catalyst loading. In addition, the larger dosage of $\mathtt { Z n } _ { \mathtt { S A } }$ N-C causes more serious leaching of $\mathrm { Z n }$ ions (Figure S16, Supporting Information), and meanwhile, increases the resource consumption, particularly for the large-scale application. Taking above aspects together, the optimum catalyst dosage is selected to be $0 . 1 \mathrm { g } \mathrm { L } ^ { - 1 }$ to fulfill the upmost specific activity with resource consumption and $_ { \mathrm { Z n } }$ leaching as low as possible.

Given the only generation of a small quantity of $\mathrm { O } _ { 2 } ^ { \bullet - }$ (without other ROS) during PDS activation by $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C, the rapid BPA degradation in the $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { \cdot C / P D S } } }$ system may be mainly originated from the non-radical pathway including high-valence metal species formation and electron transfer process. The influence of dimethyl sulfoxide (DMSO) on BPA oxidation was explored to probe the formation of high-valent $_ { \mathrm { Z n } }$ species. As shown in Figure 4f, the presence of DMSO with different concentrations shows an inappreciable impact on catalytic degradation of BPA, suggesting no formation of high-valence $\mathrm { Z n }$ species in the course of PDS activation by $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ In this case, the electron transfer pathway is likely to be responsible for the speedy BPA oxidation during the Fenton-like catalysis. In cyclic voltammetry (CV) curves (Figure $^ { 4 } \mathrm { g } )$ , the $\mathrm { Z n _ { \mathrm { { S A } } } \mathrm { { \cdot N \mathrm { { - C } } } } }$ electrode delivers two main peaks at ${ \approx } - 0 . 6 5$ and $1 . 2 4 \mathrm { ~ V ~ }$ corresponding to the reduction of DO and the oxidation of $\mathrm { Z n }$ species, respectively. After adding BPA into the electrolyte, both DO reduction and $\mathrm { Z n }$ species oxidation are enhanced for $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ ,suggesting that the electron transfer between $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C and BPA facilitates DO reduction over $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ By contrast, the presence of PDS exhibits an insignificant influence on DO reduction but a slight enhancement for $_ \mathrm { Z n }$ species oxidation compared to the $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C alone, which implies a mild electron transport from $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C toward PDS. Upon the co-existence of PDS and BPA, the redox currents are intensified, signifying that BPA boosts the interfacial electron transfer between $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ and reactants. From the solid-state EPR spectra (Figure 4h), the increased signal associated with free electrons for $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ after reacting with BPA illuminates the electron delivery from BPA to $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. On the contrary, such peak intensity decreases after the interaction between $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ and PDS, which may be attributable to the binding of PDS onto single-atomic ${ \mathrm { Z n - N _ { x } } }$ sites, as affirmed by a pronounced inhibition of BPA oxidation upon the addition of phenanthrolin, a strong chelating agent for the metal species,[24] into the suspension of $\mathrm { \Delta } Z \mathrm { n } _ { \mathrm { s A } }$ -N-C and PDS (Figure S17, Supporting Information). In the meantime, a slight electron transport from $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ toward PDS also takes place. After further interaction of BPA with $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C and PDS, the paramagnetic signal in turn increases to some extent, indicating that the organic compound transfers the electron toward the PDS-attached $\mathrm { Z n _ { S A } \mathrm { \overline { { + } N \mathrm { - } C } } }$ .

In contrast, an obvious current is recorded by substituting the $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C-coated graphite electrode for the primitive graphite electrode in the PDS solution. The direction of current substantiates that electrons are transferred from BPA toward PDS through the $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C catalyst.[43] The above results demonstrate that, besides a minor radical $( \mathsf { O } _ { 2 } ^ { \bullet - } )$ oxidation route, the electron transfer pathway via the formation of $Z \mathrm { n _ { S A } - N } .$ ${ \mathrm { C } } { \mathrm { - P D S } } ^ { * }$ to abstract electrons from BPA is dominantly responsible for the speedy BPA degradation during the Fenton-like catalysis over $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ The detection of several intermediates via gas chromatography-mass spectrometer (GC-MS) (Figure 5d; Figure S21, Supporting Information) verifies the occurrence of partial BPA degradation during the interaction between BPA and $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. The succedent introduction of PDS leads to an evident decrease of BPA peak intensity, and meanwhile, an obvious peak associated with 4-tert-butylphenol (retention time at $\approx 3 6 . 5 \ \mathrm { m i n }$ ) appears. This signifies that the addition of PDS expedites the oxidation of BPA over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C mainly via an electron transfer route. On such basis, the possible BPA degradation pathway is proposed in Figure S22 (Supporting Information). To be specific, the BPA molecule first loses electrons to break up into 4-tert-butylphenol and phenol, which are further oxidized and decomposed into other aromatic compounds and small molecular alcohols and acids. The in situ diffuse reflectance infrared Fourier transform spectroscopy (DRIFTS) analysis (Figure S23, Supporting Information) further supports the degradation of BPA into the phenolic compounds and carboxylic acids as well as alcohols during the PDS activation over $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ (see more details after Figure S23, Supporting Information). However, the detailed decomposition of intermediate phenolic compounds to alcohols and acids still seems to be ambiguous, which needs further investigation in the future. Besides the electron-rich BPA, 2-chlorophenol (2-CP) and methylene blue (MB) with electrondonating phenolic hydroxyl and/or halogen groups (for their molecular structures, see Figure S24, Supporting Information) can be also removed efficiently by $\mathrm { Z n _ { S A } ^ { \mathrm { } } { \cdot } N { \cdot } C / P D S }$ (Figure 5e). In contrast, the oxidation of ibuprofen (IBU), ciprofloxacin (CIP), and diphenhydramine (DP) containing electron-withdrawing carboxyl groups or no electron-donating groups seems to be less effective, confirming the electron transfer mechanism behind the Fenton-like catalysis over $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C.

# 2.4. Potential Practicability of ${ \bf \delta Z _ { n _ { \mathsf { S A } } } }$ -N-C

Benefiting from the dominant electron transfer pathway, the couple of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ and PDS possess a favorable anti-interference capability to the complicated water matrix, which accounts for the efficacious BPA elimination in the presence of prevalent environmental-related substances and under different water systems in the above section of Fenton-like performance evaluation. The potential practicability of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ was evaluated by the treatment of actual kitchen wastewater (collected from the effluent of a shopping mall in Guangzhou city after biological treatment) and the long-term remediation of BPA with PDS. In the three-dimensional excitation-emission matrix (3D-EEM) fluorescence spectra (Figure S25, Supporting Information), the primitive actual kitchen wastewater sample exhibits two main peaks with strong fluorescence intensities assignable to aromatic fulvic-like substances.[44] After Fenton-like reaction, the fluorescence peak intensities decreases distinctly, indicative of successful destruction of aromatic compounds in the realistic kitchen wastewater by $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ with PDS. By means of a homemade continuous-flow column reactor comprising $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C and silica sand (Figure S26, Supporting Information), the effective BPA remediation can be attained over $2 1 6 \mathrm { ~ h ~ }$ (Figure 5f), which attests to the admirable Fenton-like reactivity and robust durability of $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C. Moreover, the diffraction pattern of the used $\mathtt { Z n } _ { \mathtt { S A } }$ -NC after reaction alters hardly (Figure $\mathtt { S 2 7 a }$ , Supporting Information), and meanwhile, the Zn atoms are still atomically dispersed on the surface of the spent catalyst (Figure $\mathtt { S 2 7 b }$ , Supporting Information), further verifying the sound stability of $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C in the Fenton-like catalysis.

# 3. Conclusion

We have successfully prepared a high-loading and low-valence $_ { \mathrm { Z n } }$ single-atom catalyst $( \mathrm { Z n } _ { \mathrm { S A } } – \mathrm { N } – \mathrm { C } )$ with a mix-coordination of ${ \mathrm { Z n - N _ { 4 } } }$ and ${ \mathrm { Z n - N } } _ { 3 }$ configurations for speedy Fenton-like catalysis. Comprehensive characterizations and theoretical calculations revealed that the formation of unsaturated atomic ${ \mathrm { Z n - N } } _ { 3 }$ structure facilitates electron delocalization to reduce the average valence of $\mathrm { Z n }$ in the mix-coordinated ${ \mathrm { Z n - N _ { x } } }$ sites so as to enhance the interaction between $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C } } }$ and PDS. As a result, the $\mathtt { Z n } _ { \mathtt { S A } }$ -N-C catalyst exhibits an admirable Fenton-like performance in PDS activation with a superb specific activity of $0 . 1 1 \mathrm { ~ L ~ }$ $\mathrm { m i n } ^ { - 1 } \mathrm { m } ^ { - 2 }$ , exceeding most majority of Fenton-like SACs for PDS and even PMS activation. Experimental results unveiled that the formation of $\mathrm { Z n _ { S A } \mathrm { \cdot N \mathrm { - C \mathrm { - P D S ^ { \ast } } } } }$ complex enables strong electron transfer from the electron-rich pollutant toward the catalyst and thus dominantly realizes the rapid BPA degradation. From an application prospect, the $\mathrm { { Z n } _ { \mathrm { { S A } } } }$ -N-C material achieves a remarkable long-term remediation of BPA over $2 1 6 \mathrm { ~ h ~ }$ using a continuousflow column reactor. This work offers a feasible approach to significantly increase active site density and unravels the correlation between valence state of metal species and Fenton-like activity of SACs, which may serve as a guideline for the development of efficient and stable Fenton-like SACs for widespread sustainable environmental applications.

# 4. Experimental Section

Material Syntheis: The zinc single-atom catalyst was synthesized via a surface molecule-confined pyrolysis approach. Typically, $\rceil 5 \mathrm { g }$ of melamine was placed in an agate mortar, followed by the sequential addition of $2 . 5 ~ \mathsf { m L }$ ethanol solution of phenanthroline $( 1 . 6 2 ~ \mathrm { g } )$ and $7 0 \ m L$ ethanol solution of $Z n ( N O _ { 3 } ) _ { 2 } { \cdot } 6 { \mathsf { H } } _ { 2 } { \mathsf { O } }$ $( 1 . 1 3 \ \& )$ . Then, the mixture was ground uniformly for $3 0 \mathsf { m i n }$ The harvested white complex was subjected to calcination in a tube furnace at $6 0 0 ~ ^ { \circ } \mathsf C$ under $\mathsf { N } _ { 2 }$ atmosphere for $^ { 2 \mathrm { ~ h ~ } }$ with a heating rate of $5 ~ ^ { \circ } C \min ^ { - 1 }$ to obtain the $Z { \mathsf { n } }$ -decorated carbon nitride (Zn${ \mathsf C } _ { 3 } { \mathsf N } _ { 4 } )$ For comparison, the $Z _ { \mathsf { n } }$ -supported carbon nitride (marked as Zn $N p s { \scriptscriptstyle - } C _ { 3 } N _ { 4 }$ was prepared by the same process as $Z _ { \mathsf { n - C } _ { 3 } } \mathsf { N } _ { 4 }$ but without the addition of phenanthroline. Subsequently, the $Z _ { \mathsf { n - C } _ { 3 } } \mathsf { N } _ { 4 }$ material was further calcined at ${ 8 0 0 ^ { \circ } } \mathsf C$ in a tube furnace under $\mathsf { N } _ { 2 }$ atmosphere for $^ { 2 \mathrm { ~ h ~ } }$ at a ramping rate of $5 ~ ^ { \circ } C \min ^ { - 1 }$ . After cooling naturally to room temperature, the black powder solid was immersed and stirred in 1 M ${ \sf H } _ { 2 } { \sf S } { \sf O } _ { 4 }$ at $6 0 ~ ^ { \circ } \mathsf { C }$ for $^ \textrm { \scriptsize 8 h }$ , which was collected by centrifugation and rinsed with ultrapure water for several times until neutral. The final product was dried at $6 0 ~ ^ { \circ } \mathsf { C }$ and denoted as $Z \mathsf { n } _ { \mathsf { S A } }$ -N-C.

Catalytic Tests and Analyses: The catalytic performance was assessed through the oxidation of bisphenol A (BPA, a representative emerging contaminant) by $Z \mathsf { n } _ { \mathsf { S A } }$ -N-C with PDS. The batch experiments were conducted in at least two duplicates. The initial solution $\mathsf { p H }$ (before PDS addition) was adjusted by dilute sodium hydroxide and sulfuric acid solutions. Electrochemical measurements were performed in a standard three-electrode cell system on a CHI 700E electrochemical workstation. The identification of degradation intermediates was performed by a gas chromatographymass spectrometer (GC-MS, Shimadzu GC/MS-QP2020 NX). The longterm stability of $Z \mathsf { n } _ { \mathsf { S A } }$ -N-C was assessed via a continuous-flow column reactor.
