# ABSTRACT

This study investigated the degradation of eight aliphatic halogenated contaminants (one brominated flame retardant and seven disinfection by-products) in synthetic drinking water by the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ and $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ processes. The degradation rate constants of 2,2-bis(bromomethyl)-1,3-propanediol and trichloromethane in the $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process were 10.1 and 1.29 times, respectively, higher than those in the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process. In contrast, the degradation rate constants of dichloroacetaldehyde, monochloroacetonitrile, monobromoacetonitrile and dibromonitromethane in the $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process were 8.15, 2.33, 2.84 and 1.80 times, respectively, lower than those in the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process. The degradation rate constants of monobromonitromethane and dichloronitromethane were comparable in the two processes. The relationships between the degradation rate constants and the structural characteristics of the selected contaminants were examined to explain the different degradation efficacies of the contaminants in the two processes. As suggested by a quantitative structure-activity relationship (QSAR) model, the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process favored the degradation of contaminants with more polar electronwithdrawing moieties and higher degrees of chlorination. While the U $\mathsf { V A } / \mathsf { C u - T i O } _ { 2 }$ process favored the degradation of hydrophilic unsaturated contaminants with multiple bonds. The concentrations of the reactive species (e.g., HO and $e ^ { - }$ ) generated in the two photocatalytic processes were quantified using competition kinetics. The $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process generated ${ > } 1 0$ times higher concentrations of HO than the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process, suggesting that the former process was more suitable for the degradation of contaminants that are reactive towards HO , while $e ^ { - }$ and $e ^ { - }$ -derived superoxide radicals were nonnegligible contributors to contaminant degradation in the UVA $\mathrm { \Pi } / \mathrm { \Pi } \mathrm { T i O } _ { 2 }$ process. $^ ©$ 2020 Elsevier Ltd. # 1. Introduction

Halogenated organic contaminants have been found in surface water, groundwater and wastewater at concentrations of $\mathrm { n g / L }$ to $\mathrm { m g / L }$ (Zhou et al., 2015). Some halogenated contaminants are causing worldwide concern, such as flame retardants (e.g., brominated flame retardants) and surfactants (e.g., perfluorooctanoic acid), due to their persistence in water and potentially adverse effects (e.g., toxicity, mobility and bioaccumulation) on the ecoenvironment and human health (Matzek and Carter, 2016; Zeng et al., 2016; Zhou et al., 2015). Another group of halogenated contaminates of concern are disinfection by-products (DBPs), which are typically formed from chlorination/chloramination of drinking water or reused water containing dissolved organic matter (Li et al., 2020; Linge et al., 2013; Zeng et al., 2016). Toxicological and epidemiological studies have shown that some DBPs pose genotoxicity and mutagenicity to human, and the exposure to DBPs is associated with an increased risk of cancers (e.g., bladder and colorectal cancers) (Fiessinger et al., 1981; Krasner et al., 2006; Zhu and Zhang, 2016). Therefore, effective removal of these halogenated contaminants is becoming a high priority in securing safe potable water.

Halogenated organic contaminants are usually classified into two groups, aliphatic and aromatic, depending on their structures. Aliphatic contaminants are generally more persistent than the aromatic counterparts (Kanzari et al., 2014; Li et al., 2019). The chemical stability of the Cehalogen bonds make these aliphatic contaminants recalcitrant to conventional drinking water treatment processes, including coagulation/flocculation, sand filtration and disinfection (Douvris et al., 2010). Advanced treatment technologies are thus required to eliminate the health risks posed by these aliphatic halogenated contaminants in water (Chao et al., 2017). Advanced oxidation/reduction processes, which generate highly reactive species (e.g., hydroxyl radicals, hydrated electrons and superoxide radicals) via the activation of oxidant/reductant precursors or catalysts, are good alternatives for the abatement of the aliphatic halogenated contaminants in water (Alnaizy and Akgerman, 2000; Venkatadri and Peters, 1993). Photocatalytic processes, especially titanium dioxide $\left( \mathrm { T i O } _ { 2 } \right)$ -based ones, are relatively cost-effective and promising to real-world applications (Loeb et al., 2019; Nakata and Fujishima, 2012). To further improve the efficiency in reactive species generation and to inhibit the recombination of electrons and holes, numerous efforts have been made on modifying $\mathrm { T i O } _ { 2 }$ (Loeb et al., 2019). Incorporating $\mathrm { T i O } _ { 2 }$ with metal-based materials is a facile and effective approach (Rauf et al., 2011; Rivera-Utrilla et al., 2013). For example, copper doped $\mathrm { T i O } _ { 2 }$ $\left( \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 } \right)$ has been reported to degrade azo dye orange II and methylene blue in water $^ { > 2 }$ times faster than pristine $\mathrm { T i O } _ { 2 }$ (P25), due to the decelerated recombination of holes and electrons by the metallic copper (Rauf et al., 2011). Our previous work has also reported that the ${ \mathrm { C u } } { - } \mathrm { T i O } _ { 2 }$ showed 3.3 times higher efficiency than pristine $\mathrm { T i O } _ { 2 }$ in chromium reduction under UVA irradiation (Yin et al., 2018b), and the $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process is anticipated to show a different efficacy from the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process in degrading aliphatic halogenated contaminants in water. More experimental evidence needs to be collected to verify this hypothesis.

There have been very limited studies that evaluate the degradation of aliphatic halogenated contaminants, especially aliphatic DBPs, by the photocatalytic processes. Given the paucity of data on this topic in the literature, it is necessary to evaluate the kinetics and mechanisms of the degradation of aliphatic halogenated contaminants by the photocatalytic processes under environmental relevant conditions (Cagnetta et al., 2017). Among the limited literature, Chen et al. (2009) investigated the degradation of aliphatic carboxylic acid by the $\mathrm { U V } / \mathrm { T i O } _ { 2 }$ suspension system and found that the degradation rate constants of dicarboxylic acids were higher than those of monocarboxylic acids with the same carbon atoms. The findings indicate that the photocatalytic efficiency of contaminant degradation is structure dependent. The diversity in the degradation efficacies inspired us to examine the structural reactivity relationship between the photocatalytic processes and the target contaminants. Quantitative structure-activity analysis (QSAR) is an approach that correlates experimental observations (e.g., photocatalytic degradation rate constants) and physicochemical properties of the target contaminants (Dearden et al., 2009). It helps better understand the reaction mechanisms (e.g., sites/moieties that are more easily attacked by oxidants/ reactive species) and predict the behavior of untested contaminants with similar structural characteristics in the same treatment process (Mamy et al., 2015). Previous studies have examined the structural properties and photocatalytic reactivity relationships of some aromatic contaminants, such as aniline and phenolic compounds (Ahmed et al., 2010; Pelaez et al., 2012), but there is no such information relevant to the aliphatic halogenated contaminants. Moreover, degradation of the aliphatic halogenated contaminants has been reported to be attributed to both oxidative (e.g., by hydroxyl radicals) and reductive power (e.g., by electrons and/or superoxide radicals) (Loeb et al., 2019). The roles of different reactive species need to be elucidated more clearly to better understand the degradation mechanisms of aliphatic halogenated contaminants in the photocatalytic processes.

Therefore, this study was designed to fill the knowledge gaps as discussed above. A facial-synthesized $\mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ photocatalyst was used for photocatalytic degradation of eight selected aliphatic halogenated organic contaminants, including one brominated flame retardant and seven chloro- and bromo-DBPs. Pristine P25 $\mathrm { T i O } _ { 2 }$ was used for comparison with $\mathrm { C u } { - } \mathrm { T i O } _ { 2 }$ . The structural activity relationships were examined to better understand the mechanisms of the degradation of the aliphatic contaminants. The roles of different reactive radical species in the degradation of the selected contaminants were also investigated and discussed.

# 2. Materials and methods

# 2.1. Chemicals and photocatalyst

Monochloroacetonitrile (MCAN), monobromoacetonitrile (MBAN), trichloromethane (TCM), dichloronitromethane (DCNM), dibromonitromethane (DBNM), monobromonitromethane (MBNM), dichloroacetaldehyde (DCACH), 2,2-bis(bromomethyl)- 1,3-propanediol (BBMP), nitrobenzene (NB) and $\mathrm { T i O } _ { 2 }$ P25 were purchased from Sigma-Aldrich. Copper chloride $( \mathsf { C u C l } _ { 2 } )$ was purchased from Tianjin Fuchen Chemical. Stock solutions of these contaminants were prepared by dissolving or diluting the powders or liquids into deionized water ( $1 8 . 2 ~ \mathrm { M } \Omega ~ \mathrm { c m }$ , Barnstead, US). ${ \mathrm { C u } } { - } \mathrm { T i O } _ { 2 }$ was synthesized following a method described in a previous manuscript (Yin et al., 2018a). Briefly, the $\mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ photocatalyst was synthesized using a solvation/calcination method by mixing $\mathrm { T i O } _ { 2 }$ suspension with $\mathrm { C u C l } _ { 2 }$ solution at a Cu to $\mathrm { T i O } _ { 2 }$ mass ratio of $1 . 5 \%$ and drying at $1 0 0 ^ { \circ } \mathsf C$ for $2 4 \mathrm { h }$ and $5 0 0 ^ { \circ } C$ for another 1 h (Yin et al., 2018a). The Cu on the ${ \mathrm { C u } } { - } \mathrm { T i O } _ { 2 }$ photocatalyst has a valence of two (Yin et al., 2018a). The detailed characterizations of the $\mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ photocatalyst were shown in the previous manuscript (Yin et al., 2018a).

# 2.2. Experimental setup and procedures

The experimental setup of the photocatalytic reactor is shown in Fig. S1. A UVA light irradiator consisting of three 6-W UV lamps $1 8 0 ~ \mathrm { m m }$ in length, placed in parallel, Philips Co.) was placed horizontally as the light source. A Petri dish $9 0 \mathrm { m m } \times 1 5 \mathrm { m m }$ , Thermo Scientific) was used as the reactor and placed $2 5 \mathrm { m m }$ below the UV lamps. A magnetic stir plate with a magnetic stirrer were used to provide moderate mixing. The UV lamps emitted UV light from 320 to $4 2 0 \mathrm { n m }$ with a peak emission at a wavelength of $3 6 5 \mathrm { n m }$ (Fig. S2), which was measured by a photo-spectrometer (RPS900-R, International Light Technology). The integrated light intensity from wavelengths of $3 0 0 { - } 4 2 0 \ \mathrm { n m }$ was $5 . 0 { \bar { 5 } } \ \mathrm { m W } / \mathrm { c m } ^ { 2 }$ . The UV lamps were turned on at least $3 0 ~ \mathrm { { m i n } }$ before each test for warm-up. The $2 . 5 \mathrm { - m g }$ photocatalysts (e.g., $\mathrm { T i O } _ { 2 }$ or $\mathrm { C u } { - } \mathrm { T i O } _ { 2 }$ ) were dispersed in 25- mL deionized water by sonicating for $1 5 ~ \mathrm { m i n }$ to make the catalyst suspension. The BBMP/DBP stock solutions, phosphate buffers and water were then added to the suspension to adjust the volume of the solution to $5 0 ~ \mathrm { ~ m L }$ and the initial concentration of each contaminant, buffer and photocatalyst at $1 0 \mu \mathrm { M } ,$ , $5 \mathrm { m M }$ and $0 . 0 5 { \mathrm { g / L } }$ , respectively. Samples were taken at different time intervals (e.g., 0, 30, 60, 120, 180, 300 and 600 s), filtered through a $0 . 2 2 \mathrm { - } \mu \mathrm { m }$ PTFE membrane filter, extracted if necessary, and subjected to analysis of the concentrations of BBMP/DBPs. All tests were conducted at ambient temperature $\left( 2 2 \pm 2 ^ { \circ } \mathsf { C } \right)$ . The experiments designed to quantify the reactive species generated in the two photocatalytic processes were conducted in a similar manner, except that NB, phenol and BBMP were spiked into the solution as probe compounds and the initial concentration of each probe compound was $1 0 ~ { \mu \mathrm { M } } .$ Tests, under anaerobic conditions, were carried out in an anaerobic glove box (855, Plas Labs Inc., USA) using $\Nu _ { 2 }$ gas purged deionized water in which the dissolved oxygen concentration was lower than $0 . 1 \ \mathrm { m g / L }$ .

# 2.3. Analytical methods

BBMP, NB and phenol concentrations were analyzed by using a high-performance liquid chromatography (HPLC) system (VP series, Shimadzu) with a symmetry C18 column $( 4 . 6 \ : \mathrm { m m } \times 1 5 0 \ : \mathrm { m m }$ , $5 \mu \mathrm { m }$ in particle size; Waters) and a UVeVis detector. The reference wavelengths were set at 210, 262 and $2 7 5 ~ \mathrm { { n m } }$ for BBMP, NB and phenol respectively. The mobile phases were water/acetonitrile $( 7 0 { : } 3 0 , \nu / \nu \% )$ , water/acetonitrile $( 5 0 { : } 5 0 , \mathrm { v / v } \% )$ and water/methanol $( 5 5 { : } 4 5 , \mathrm { v / v \% } )$ , respectively, at a flow rate of $1 . 0 \ \mathrm { m L / m i n }$ . The DBP concentrations were measured according to the USEPA Method 551.1. The DBPs in the samples were extracted using the following procedure: $3 ~ \mathrm { m L }$ of methyl-tert-butyl-ether and $_ { 8 \mathrm { ~ g ~ } }$ of muffled sodium sulfate were added sequentially into the quenched solution and then the vial was sealed with a Teflon-lined cap. After 4-min mixing by vortex shaking followed by $2 0 { \mathrm { - m i n } }$ stabilization, the separated upper methyl-tert-butyl-ether layer was transferred to a vial for subsequent analysis by gas chromatography. The detailed procedures for the gas chromatography setup are described in a previous report (Yin et al., 2018b). The concentration of the released ${ \mathrm { C u } } ^ { 2 + }$ in solutions was determined using inductively coupled plasma optical emission spectrometry (ICP-OES). The $\mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ photocatalyst was stable during use, and the concentration of the released ${ \mathrm { C u } } ^ { 2 + }$ in the solution was lower than $1 0 ~ \mu \mathrm { g / L }$ under the experimental conditions, which is far below the USEPA Maximum Contaminant Level Goal (MCLG) in drinking water (i.e., $1 . 3 ~ \mathrm { m g / L } )$ (Pontius, 1998), and hardly affected the performance of the photocatalytic processes.

# 2.4. QSAR model construction and statistical analysis

The QSAR model was constructed using a software (i.e., Toxicity Estimation Software Tool) from USEPA (Tool, 2008), which elucidates the relationships between the molecular characteristics (e.g., constitutional descriptors, topological descriptors, molecular distance edge, and molecular fragment counts, etc.) and the corresponding experimental data (e.g., degradation rate constant). The software calculates the molecular descriptors, based on the Chemistry Development Kit, which is an open-source Java library for computational chemistry (Nicolas et al., 2018). The calculated descriptor values were validated using MDL® QSAR, Dragon, and Molconn-z (Nicolas et al., 2018). The calculated values of different descriptors were correlated with the degradation rate constants of each contaminant in the two photocatalytic processes, with their relationships examined using the Pearson correlation (Nicolas et al., 2018; Suh et al., 2002). A Pearson coefficient between $^ { - 1 }$ and 1 indicates the extent to which two variables are linearly related, where $+ 1$ means perfectly positive linear correlation, 0 means a non-linear correlation, and 1 means a perfectly negative linear correlation. The closer the value is to 1 or $^ { - 1 }$ , the stronger is the linear correlation. Significance testing was also conducted, and the correlation coefficient is statistically significant if the $p$ -value is lower than the conventional accepted $5 \% ( p < 0 . 0 5 )$ .

# 3.1. Degradation of contaminants by the UVA/ $T i O _ { 2 }$ and UVA/ $C u { - } T i O _ { 2 }$ processes

Fig. 1 shows that the degradation of the eight selected aliphatic halogenated contaminants in the two photocatalytic processes followed the pseudo first order kinetics (Fig. 1). The adsorption of these contaminants by $\mathrm { T i O } _ { 2 }$ or ${ \mathrm { C u } } { - } \mathrm { T i O } _ { 2 }$ was found to be insignificant under the experimental conditions, and these contaminants were resistant to direct UV photolysis (Ling et al., 2016). Their degradation was thus mainly attributed to reactive species generated in the photocatalytic processes. The apparent degradation rate constants $( \bar { \mathsf { s } } ^ { - 1 } )$ of the eight contaminants in the two photocatalytic processes were obtained from Fig. 1 and are listed in Table 1. The degradation rate constants of DCACH, MCAN, MBAN, and DBNM were 8.13, 2.33, 2.90 and 1.80 times higher in the UVA $\Gamma \mathrm { i } 0 _ { 2 }$ process than those in the $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process, respectively. The degradation rate constants of DCNM and MBNM were comparable in the two photocatalytic processes. The variation of the degradation rate constants of the eight contaminants suggested that their degradation was dependent on the contaminant structures in the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ or UVA/ ${ \mathrm { C u } } { - } \mathrm { T i O } _ { 2 }$ process, which was discussed in detail in Section 3.2. # 3.3. Roles of reactive species in the UVA $\mathrm { \Delta } T i O _ { 2 }$ and $U V A / C u { - } T i O _ { 2 }$ processes

The concentrations of different reactive species generated in the two photocatalytic processes were anticipated to be different, which resulted in the different degradation efficiencies of the tested halogenated aliphatic contaminants. In the photocatalytic processes, hydrated electrons $( e ^ { - } )$ and hydroxyl radicals (HO ) are the two major reactive species responsible for degrading halogenated contaminants in water (Muuronen et al., 2017). NB exhibits high reactivity towards $e ^ { - }$ $( k = 3 . 7 \times 1 0 ^ { 1 0 } \mathrm { ~ M } ^ { - 1 } \ s ^ { - 1 } ) $ and HO $( k = 3 . 9 \times 1 0 ^ { 9 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ (Buxton and Elliot, 1986), and phenol reacts with HO and $e ^ { - }$ at second order rate constants of $8 . 4 \times 1 0 ^ { 9 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ and $3 \times 1 0 ^ { 7 } \mathrm { M } ^ { - 1 } \ : s ^ { - 1 } ,$ , respectively (Buxton et al., 2000). To further verify this hypothesis, supplementary tests were conducted in oxygen-free solutions to examine the effects of dissolved oxygen on the generation of reactive species, since oxygen is considered as a strong scavenger to $e ^ { - }$ $( k = 1 . { \overset { \cdot } { 9 } } \times 1 0 ^ { 1 0 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ (Tay et al., 2008). The apparent degradation rate constants of NB and phenol in the two processes both decreased in the oxygen-free solutions (Fig. S3). In the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process, the calculated steadystate concentrations of $\mathrm { H O ^ { \bullet } }$ and $e ^ { - }$ in the oxygen-free solutions decreased by $1 4 . 3 \%$ and $1 . 9 5 \%$ , respectively (Table 3). Superoxide radicals $( 0 2 ^ { \bullet ^ { - } } )$ that are known to be formed from the reduction of dissolved oxygen by $e ^ { - }$ $( k = 1 . 9 \times 1 0 ^ { 1 0 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ were anticipated to contribute to BBMP degradation (Furman et al., 2010). The decrease of degradation rate constant was much more significant in the UVA/ $\mathrm { T i O } _ { 2 }$ process (i.e., by $5 2 . 7 \%$ ) than that in the $\mathrm { U V A / C u - T i O _ { 2 } }$ process (i.e., by $2 4 . 8 \%$ ), indicating that other reactive species (e.g., $0 2 ^ { \bullet ^ { - } }$ ) contributed more in the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process than that in the $\mathrm { U V } \mathsf { A } /$ ${ \mathrm { C u } } { - } \mathrm { T i O } _ { 2 }$ process to the overall degradation of BBMP. This was also consistent with the findings that nCl and nHBD were positively correlated with $k$ in the UVA $\mathrm { T i O } _ { 2 }$ process (Section 3.2), considering that contaminants with higher extents of chlorine substitution and more hydrogen bond donors were relatively more reactive towards $0 2 ^ { \bullet ^ { - } }$ (Tay et al., 2008). Further investigations are recommended to identify and quantify $0 2 ^ { \bullet ^ { - } }$ in the two photocatalytic processes.

# 4. Conclusion

In this paper, the degradation kinetics of eight selected aliphatic halogenated contaminants in the $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ and $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ photocatalytic processes are compared. BBMP and DCM were degraded faster in the $\mathrm { U V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process, while DCACH, MCAN, MBAN, DBNM were degraded faster in the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process. The findings provide new insights into the degradation of aliphatic halogenated contaminants by the photocatalytic processes, which is both contaminant- and process-dependent. A QSAR model was established to differentiate the reactivity of the tested contaminants towards the two photocatalytic processes from the contaminant structure perspective. The $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process favored the degradation of polar electron-withdrawing molecules with higher degree of chlorination. While the $\mathrm { J V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process favored the degradation of hydrophilic unsaturated contaminants with multiple bonds. It is recommended that the appropriate photocatalytic process for remediation shall be selected according to the characteristics of the target contaminants. Concentrations of the reactive species (e.g., $e ^ { - }$ and HO) in the two photocatalytic processes were elucidated and compared to explain the differences in the efficiencies of the two processes from the reactive species perspective. The $\mathrm { J V A } / \mathrm { C u } { - } \mathrm { T i } 0 _ { 2 }$ process was generally more suitable for the degradation of contaminants that are more reactive towards HO than other reactive species, while $0 z ^ { \bullet ^ { - } }$ might be a non-negligible contributor to contaminant degradation in the $\mathrm { U V A } / \mathrm { T i O } _ { 2 }$ process. In addition to the difference on generating reactive species in bulk solutions, other physical-chemical properties of catalysts (e.g., the affinity of a certain contaminant to surfaces of different catalysts) might also affect the degradation efficacy and deserves further investigation. The water matrix components (e.g., natural organic matter, carbonate/bicarbonate and chloride) in drinking water may affect the photocatalytic processes via radical scavenging and transformation, inner filter effects and surface adsorption/ complexation (Ribeiro et al., 2019). The effects are complicated and interesting and deserve further investigation. The effect of pH (e.g., $\mathsf { p H } 5 { - } 8 )$ is also recommended for future investigation. Apart from $e ^ { - }$ and HO, other reactive species (e.g., $0 _ { 2 } { \cdot }$ , $^ 1 0 _ { 2 }$ , and $h ^ { + }$ ) may also contribute to the degradation of organic contaminants, and their roles in the two photocatalytic processes are recommended for future investigations. The degradation of these contaminants is anticipated to be a de-halogenation process (Gao et al., 2013; Ling et al., 2016). Their degradation products and the corresponding degradation pathways are recommended for future investigation using mass spectrometry (Yang et al., 2019).
