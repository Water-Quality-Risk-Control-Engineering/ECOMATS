Water contamination with synthetic dyes and metal ions is an escalating problem, despite the huge research efforts put in the field of water treatment. The paper reports on one-step synthesis of reduced graphene oxide-cobalt oxide nanoparticles $\left( \mathrm { r } \mathsf { G } 0 \mathrm { - } \mathsf { C o } _ { 3 } \mathsf { O } _ { 4 } \right)$ ) nanocomposite under mild conditions. The nanocomposite material has been characterized using various analytical techniques, including scanning electron microscopy (SEM), transmission electron microscopy (TEM), energy dispersive X-ray (EDX) spectroscopy, UV–visible spectrophotometry and Fourier-transform infrared (FTIR) spectroscopy. The catalytic properties of the nanocomposite were demonstrated for the sodium borohydride-induced 4- nitrophenol reduction to 4-aminophenol. A full reduction has been achieved within less than 1 min at room temperature. Further, the nanocomposite was successfully applied for $\mathrm { C r } ( \mathrm { V I } )$ adsorption with a maximum adsorption capacity of $2 0 8 . 8 \ \mathrm { m g . g ^ { - 1 } }$ , which is much higher than that obtained using many other magnetic adsorbents. Finally, the nanocomposite was found to be very efficient for anionic and cationic dye adsorption with complete removal within less than $2 \mathrm { { m i n } }$ . The performance of the rGO$\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ nanocomposite is quite high as compared to other graphene-based adsorbents. The ferromagnetic properties of the composite allowed effective separation and recyclability of the material by simple application of an external magnet.

# 1. Introduction

With the rapid industrialization, the discharge and release of heavy metal ions and synthetic organic dyes from the textile, paper, and leather industries into the environment represent a serious issue to be addressed since these substances are potentially carcinogenic and mutagenic. To meet environmental regulations and limit the amount of these substances, effluents or water contaminated with these organic and inorganic species must be treated before discharge [1].

Chromium is widely used in industries as for instance, mining, and pigment manufacturing. In aqueous media, Cr exists in two different oxidation states i.e. trivalent $\mathrm { { C r } ( I I I ) }$ and hexavalent Cr (VI) forms. While $\mathrm { C r } ( \mathrm { I I I } )$ is less toxic, $\mathrm { C r } ( \mathsf { V I } )$ is extremely mobile in the environment and carcinogen to living organisms [2]. Due to its bioaccumulation through the food chain, $\mathrm { C r } ( \mathsf { V I } )$ can cause harm to the human body even at low concentrations. Therefore, it is necessary to reduce the $\mathrm { C r } ( \mathsf { V I } )$ concentration to a level as low as possible before discharging the industrial waste matter into the environment.

Synthetic dyes represent also an important class of water pollutants. They originate from various sources such as textile, dyeing, printing, paper and pulp, tannery and paint industries. Dyes discharged in water can cause problems to aquatic life and some dyes are even toxic to human life [1]. Most of synthetic dyes are easily dissolved in water in cationic or anionic forms. The cationic dyes include rhodamine B (RhB), methylene blue (MB), methyl violet (MV), malachite green (MG), and the anionic dyes consist of methyl orange (MO) and rose Bengal.

For example, wastewater from textile industries is highly colored by dissolved organic dyes. Color removal from these wastewaters is one of the most difficult tasks, because synthetic dyes and pigments are resistant to biodegradation, and thus remain for a long period of time in the environment. Therefore, from an environmental point of view, the disposal and treatment of organic dyes are of great concern as well as the development of cost-effective methods to remove colored substances from wastewater [1].

To provide solutions for the above-mentioned environmental problems, various approaches and technologies to remove $\mathrm { C r } ( \mathsf { V I } )$ and synthetic dyes have been described in the literature. These strategies include adsorption, photocatalysis, electro-chemical precipitation, reverse osmosis, and ion exchange [1,3–6]. Among these methods, only adsorption is a fast, highly efficient, inexpensive, and a widely applicable technique with no discharge of harmful substances.

Even though, adsorption represents an appealing method for environmental remediation, the lack of full recovery of the adsorbent from wastewater may cause a secondary pollution. For that, a magnetic adsorbent is highly desirable, because it allows removal of toxic pollutants (metal ions, dyes) and the adsorbent itself can be recovered easily from water through application of an external magnet.

Despite its short development history, graphene-metal oxide nanocomposites have attracted increasing attention for their applications in environmental and energy-related areas, and GO/rGO-based composites have been successfully applied to treat different types of organic dyes and heavy metal ions [3]. As discussed above, organic dyes exist in ionic (anionic or cationic) forms in water, while $G 0 / \mathrm { r } G 0$ are negatively charged, so dye adsorption on $G 0 / \mathrm { r } G 0$ is believed to be dominated by electrostatic interactions (anionic-cationic). However, other interactions such as H-bonding and $\pi { - } \pi$ stacking are not excluded during adsorption processes of organic dyes on GO/rGO-based composites [3]. On the one hand, negatively charged graphene oxide (GO) possesses various oxygen containing groups such as OH and COOH groups.

As a consequence, it exhibits high adsorption capacity for basic compounds and metal cations. Reduced graphene oxide (rGO), on the other hand, displays a hydrophobic surface and this presents high adsorption capacity for dyes through strong $\pi { - } \pi$ stacking and hydrophobic interactions [3].

An enhanced adsorption ability can be obtained by a modification of GO or rGO with metal oxides or organics. Recent reports have shown that $G 0 / \mathrm { r } G 0$ -based composites have an excellent adsorption ability for $\mathrm { C r } ( \mathsf { V I } )$ [7,8] and dyes (methyl orange, methylene blue, rhodamine B) and as such they represent promising adsorbents for water purification [3,9].

For instance, cobalt oxide $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ is a magnetic $p$ -type semiconductor with a cubic spinel crystal structure in which ${ \mathsf { C o } } ^ { \mathrm { I I } }$ and ${ \cal C } 0 ^ { \mathrm { I I I } }$ atoms occupy the tetrahedral sites and octahedral sites, respectively [10]. It is a transition metal oxide with interesting optical, electronic, electrochemical, catalytic and electrocatalytic properties [11]. However, the $C o _ { 3 } 0 _ { 4 }$ outstanding properties are decreased or even lost, because severe particle aggregation takes place during their processing. To limit $C o _ { 3 } 0 _ { 4 }$ aggregation, their hybridization with carbon-based supports seems to be a very effective approach. For instance, the integration of $C _ { 0 _ { 3 } } 0 _ { 4 }$ onto graphene matrices endows the resulting materials with enhanced performance [12]. This has also been demonstrated in a few examples for environmental remediation. $C o _ { 3 } 0 _ { 4 } /$ /graphene have been successfully applied for heterogeneous activation of peroxymonosulfate (oxone) for the degradation of Orange II [13–16], phenol [17] by advanced oxidation technology.

To the best of our knowledge, the utilization of $\Gamma { \cal G } 0  – { \cal C } 0 _ { 3 } 0 _ { 4 }$ nanocomposite for synthetic dyes and metal ions adsorption has been investigated only in a few reports [18]. Indeed, Yavuz et al. successfully applied $C o _ { 3 } 0 _ { 4 } /$ graphene as an effective adsorbent for the retention/separation of $\mathrm { P b } ( \mathrm { I I } )$ , $\mathtt { C u ( I I ) }$ and $\mathsf { F e } ( \mathrm { I I I } )$ ions from environmental water [18]. In this paper, we took benefit of the high surface area and of the magnetic properties of rGO- ${ \bf \cdot } { \bf C } { \bf 0 } _ { 3 } { \bf O } _ { 4 }$ nanocomposite to improve the catalytic and environmental efficiencies of the process. rGO- ${ C o } _ { 3 } { 0 } _ { 4 }$ nanocomposite was used for two environmental applications: $\mathrm { C r } ( \mathsf { V I } )$ and organic dyes removal from aqueous solution. The description of these applications is preceded with the catalytic reduction of 4-nitrophenol to 4-aminophenol by $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposite using sodium borohydride $\mathrm { ( N a B H _ { 4 } ) }$ ; this model reaction is commonly used to evaluate the catalytic performance of metal or metal oxide nanoparticles.

# 2. Experimental

# 2.1. Preparation of graphene oxide (GO)

GO was synthesized from natural graphite powder according to [19]. A homogeneous GO suspension $( 0 . 5 \mathrm { m g / m L } )$ in water was achieved by ultrasonication for $^ { 3 \mathrm { h } }$ .

# 2.2. Preparation of reduced graphene oxide/ $\scriptstyle { \bf \mathit { C o } } _ { 3 } 0 _ { 4 }$ nanocomposite

Different routes have been developed for the synthesis of $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposites. Generally, they all require a twostep synthesis with the use of hazard agents and high temperatures $( 8 0 - 6 0 0 ^ { \circ } { \mathsf { C } } )$ to reduce graphene oxide and anchor cobalt oxide NPs. In the present study, the $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposite was synthesized using a one-step, low-cost and simple preparation method based on simultaneous reduction of GO and $\mathsf { C o C l } _ { 2 }$ using borohydride $\mathrm { N a B H _ { 4 } }$ as reducing agent at room temperature [20]. $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposite was prepared by simultaneous chemical reduction of GO and $\mathsf { C o C l } _ { 2 }$ with sodium borohydride $\mathrm { ( N a B H _ { 4 } ) }$ . Typically, to $5 \mathrm { m L }$ of $1 ~ \mathrm { m g / m L }$ GO suspension in Milli-Q water, was added $5 0 \mathrm { m g }$ of $\mathsf { C o C l } _ { 2 }$ . The resulting mixture was sonicated for $1 0 \mathrm { { m i n } }$ . Then $5 \mathrm { m L }$ of $0 . 1 \mathrm { ~ M ~ }$ sodium borohydride aqueous solution was added to the mixture at room temperature. A black precipitate was formed spontaneously, which was separated by centrifugation and washed repeatedly with water [20].

# 2.3. Reduction of 4-nitrophenol to 4-aminophenol catalyzed by $r G O { - } C o _ { 3 } O _ { 4 }$

The reduction of 4-nitrophenol (4-NP) to 4-aminophenol was carried out at room temperature under stirring. To $3 \mathrm { m L }$ of freshly prepared $0 . 1 ~ \mathrm { m M }$ 4-nitrophenol aqueous solution was added $3 0 0 \mu \mathrm { L }$ of 0.1 M $\mathsf { N a B H } _ { 4 }$ and $2 0 0 \mu \mathrm { L }$ of $0 . 1 ~ \mathrm { m g / m L }$ $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ in water. Following $\mathrm { N a B H _ { 4 } }$ addition, the solution turned yellow green due to the formation of 4-nitrophenolate. This is accompanied by a change of the maximum absorption from $3 1 7 \mathrm { n m }$ (4-nitrophenol) to $4 0 0 \mathrm { n m }$ (4-nitrophenolate). The progress of 4-nitrophenolate reduction to 4-aminophenol catalyzed by $\Gamma { \cal G } 0  – { \cal C } 0 _ { 3 } 0 _ { 4 }$ was monitored by the decrease of the absorption band at $4 0 0 \mathrm { n m }$ using UV–vis spectrophotometry.

# 2.4. Adsorption studies

The batch adsorption mode was used to study $\mathrm { C r } _ { 2 } 0 _ { 7 } ^ { 2 - }$ and dyes adsorption. A stock potassium dichromate $( \mathsf { K } _ { 2 } \mathsf { C r } _ { 2 } 0 _ { 7 } )$ aqueous solution $( 5 0 0 \mathrm { m g / m L } )$ was prepared. Aqueous solutions of different Cr concentrations (25, 50, 100, 200, 300 and $4 0 0 \mathrm { m g / L } )$ were prepared by dilution of the stock solution with Milli-Q water. The pH of the Cr solutions was adjusted to 3 with $0 . 1 \mathrm { ~ M ~ H C l }$ aqueous solution.

The removal ability of $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposite of organic dyes in aqueous solutions was investigated for three different dyes (rhodamine B, methyl orange and rose Bengal) at three different concentrations for each dye. For the adsorption experiments, $2 \mathrm { m g }$ of rGO- $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ nanocomposite was added to $2 \mathrm { m L }$ of an aqueous solution of rhodamine B (RhB), methyl orange (MO) or rose Bengal (RB) (5, 10 or $1 5 \mu \mathrm { M }$ ) at room temperature at $\mathsf { p H } 7$ .

The $\%$ of removal of $\mathrm { C r } ( \mathsf { V I } )$ and dyes is calculated using:

Removal $( \% ) = ( { \mathsf { C } } _ { 0 } - { \mathsf { C } } _ { \mathrm { f } } ) / { \mathsf { C } } _ { 0 } \times 1 0 0$ where ${ \sf C } _ { 0 }$ is the initial concentration and $C _ { \mathrm { f } }$ the final concentration of $\mathrm { C r } ( \mathsf { V I } )$ ions or dyes.

# 3. Results and discussion

# 3.1. Characterization of $r G O { - } C o _ { 3 } O _ { 4 }$ nanocomposite

The morphology and microstructures of the as-synthesized samples were investigated by FE-SEM (Fig. 1). Fig. 1a displays the SEM image of the initial GO, consisting of crumpled sheets. Similarly, the SEM image of the as-synthesized $\scriptstyle \Gamma \mathbf { G } 0 - \mathbf { C } 0 _ { 3 } 0 _ { 4 }$ nanocomposite comprises aggregated and crumpled sheets of many graphene sheets along with $C o _ { 3 } 0 _ { 4 }$ nanoparticles (Fig. 1b).

The TEM image of the prepared $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposite displays $\mathrm { C o } _ { 3 } 0 _ { 4 } \mathrm { N P s }$ of $2 { - } 1 0 \mathrm { n m }$ in size distributed on the rGO sheets (Fig. 1c). Additionally, the HIgh Resolution-TEM ( HR-TEM) image of a single $C o _ { 3 } 0 _ { 4 }$ NP exhibits an interplanar distance between adjacent planes of $0 . 4 7 \mathrm { n m }$ , corresponding to the interplanar spacing of (111) plane of $C o _ { 3 } 0 _ { 4 }$ (Inset Fig. 1c) [20]. The diffraction rings of the selected-area electron diffraction (SAED) pattern consists of five diffraction rings corresponding to the (2 2 0), (3 1 1), (4 0 0), (4 4 0), and (511) planes of $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ (Fig. 1d).

The as-synthesized $\scriptstyle \Gamma \mathbf { G } 0 - \mathbf { C } 0 _ { 3 } 0 _ { 4 }$ nanocomposite contains only cobalt, carbon, and oxygen, as revealed by TEM-EDX analysis (Fig. S1), consistent with the chemical composition of the material. Some of the carbon signal may originate from the carbon grid onto which the sample was deposited for TEM and EDX analysis.

The cobalt content in the synthesized $\scriptstyle \Gamma \mathbf { G } 0 - \mathbf { C } 0 _ { 3 } 0 _ { 4 }$ nanocomposite was estimated by ICP-AES analysis, and the results showed a Co loading of $5 0 . 4 \ : \mathrm { g }$ in $_ { 1 0 0 \mathrm { g } }$ of composite.

Fig. 2 depicts the UV–vis absorption spectra of GO, rGO and $\Gamma { \cal G } { \cal O } { - } { \cal C } _ { 0 _ { 3 } } { \cal O } _ { 4 }$ nanocomposite. The UV–vis absorption spectrum of GO displays characteristic absorption peaks at $2 2 5 \mathrm { n m }$ and a shoulder at around $3 0 0 \mathrm { n m }$ due to $\pi { - } \pi ^ { * }$ of aromatic carbon bonds and n$\pi ^ { * }$ transition of $\mathtt { C = } 0$ bonds, respectively (Fig. 2, red trace). Upon GO reduction with $\mathrm { N a B H _ { 4 } }$ at room temperature, a red shift of the GO absorption band to $2 6 0 \mathrm { n m }$ is observed, suggesting partial restoration of the aromatic network (Fig. 2, blue trace).

$\mathrm { N a B H _ { 4 } }$ reduction of a mixture of GO and $\mathsf { C o C l } _ { 2 }$ aqueous solution induces also a red-shift of the absorption band of GO from 225 to $2 6 0 \mathrm { n m }$ as well as the appearance of a new strong band at $4 3 3 { \mathrm { n m } }$ due to $C o _ { 3 } 0 _ { 4 }$ NPs (Fig. 2, black trace) [21,22]. The results suggest that GO nanosheets have been reduced to rGO and the $\mathsf { s p } ^ { 2 }$ network within the GO nanosheets was partially restored upon reaction with cobalt chloride and $\mathrm { N a B H } _ { 4 }$ . The presence of a new band at $4 3 3 { \mathrm { n m } }$ evidences that the cobalt oxide nanoparticles have been anchored onto the rGO sheets, suggesting a strong interaction between rGO and ${ \cal C } _ { } 0 _ { 3 } 0 _ { 4 }$ NPs. $C _ { 0 _ { 3 } } 0 _ { 4 }$ NPs are $2 { - } 1 0 \mathrm { n m }$ in size as evaluated by X-ray diffraction (XRD) and transmission electron microscopy (TEM) analysis [20].

The FTIR spectra show remarkable differences between GO and $\Gamma { \cal G } { \cal O } { - } { \cal C } _ { 0 _ { 3 } } { \cal O } _ { 4 }$ (Fig. 3). For GO, a strong and broad absorption ascribed to $\mathrm { O - H }$ vibration mode, and the $\mathtt { C = } 0$ stretching mode of COOH groups situated at the edges of GO sheets are observed at 3404 and $1 7 4 0 \mathrm { c m } ^ { - 1 }$ , respectively.

The vibration mode at $1 4 2 2 \mathrm { c m } ^ { - 1 }$ may be due to bending vibrations of tertiary ${ \mathsf { C } } { \mathsf { - O H } }$ groups or to bending vibration of $\mathrm { C - H }$ bonds. But, due to the presence of OH groups on $\scriptstyle \Gamma \mathbf { G } 0 - \mathbf { C } 0 _ { 3 } 0 _ { 4 }$ composites (Fig. 3) and to the usual existence of hydroxyl and carboxyl group on rGO, we suggest that the $1 4 2 2 \mathrm { c m } ^ { - 1 }$ vibration modes are more likely due to ${ \mathsf { C } } { \mathsf { - O H } }$ groups. The band at $1 0 2 3 \mathrm { c m } ^ { - 1 }$ is attributed to stretching vibrations of ${ \tt C } { - } 0$ groups, while the band at $1 6 2 3 \mathrm { c m } ^ { - 1 }$ is attributed to ${ \mathsf { C } } { = } { \mathsf { C } }$ stretching vibration as part of the ring breathing mode in the GO skeleton [23]. By contrast, for the $\Gamma { \cal G } { \cal O } { - } { \cal C } _ { 0 _ { 3 } } { \cal O } _ { 4 }$ nanocomposite, the $\mathrm { O - H }$ absorption band is shifted to $3 4 2 4 \mathrm { c m } ^ { - 1 }$ , while the skeletal vibration band ${ \mathsf { C } } { = } { \mathsf { C } }$ at $1 6 2 3 \mathrm { c m } ^ { - 1 }$ is shifted to $1 6 2 7 \mathrm { c m } ^ { - 1 }$ . Moreover, the stretching band of $\mathtt { C = } 0$ at $1 7 4 0 \mathrm { c m } ^ { - 1 }$ disappears, suggesting that GO was reduced to rGO during the chemical process [24].

The rGO- $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ NPs hybrid exhibits typical ferromagnetic behavior with a saturation magnetization (Ms) of $0 . 1 \mathrm { \ e m u . g ^ { - 1 } }$ and a hysteresis of $1 1 5 0 \mathrm { e }$ at 300 K $( 2 7 ^ { \circ } \mathsf C )$ , as shown by the magnetic hysteresis loop in Fig. 4a.

The coercive force increases as the temperature is decreasing, to 495 Oe at $2 \mathrm { K }$ ; similarly, the saturation magnetization (Ms) increased to $4 0 \mathrm { \ e m u . g ^ { - 1 } }$ (Fig. 4b). This value can facilitate the recycling of the nanocomposite catalyst by a low energy-saving magnetic separation process.

# 3.2. Applications

# 3.2.1. Catalytic reduction of 4-nitrophenol

The catalytic activity of the $\Gamma { \cal G } { \cal O } { - } { \cal C } _ { 0 _ { 3 } } { \cal O } _ { 4 }$ nanocomposite was evaluated for 4-nitrophenol (4-NP) reduction to 4-aminophenol (4-AP) in the presence of excess $\mathrm { N a B H } _ { 4 }$ . This model reaction is commonly used in catalytic processes to examine the catalytic performance of metal or metal oxide nanoparticles (Fig. 5).

Typically, two aqueous solutions of $0 . 1 ~ \mathrm { m M }$ of 4-NP and $0 . 1 \mathrm { ~ M ~ }$ $\mathrm { N a B H _ { 4 } }$ were prepared. Then a mixture of $3 \mathrm { m L }$ of 4-NP and $0 . 5 ~ \mathrm { m L }$ of $\mathrm { N a B H _ { 4 } }$ was prepared from these solutions. During this process, the color changed from transparent to yellow, because 4-nitrophenol was converted to 4-nitrophenolate anion by $\mathrm { N a B H } _ { 4 }$ (Figs. 5 and 6). To this mixture, $1 0 0 \mu \mathrm { L }$ of $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ nanocomposite $( 0 . 5 \mathrm { m g } \mathrm { m L } ^ { - 1 }$ ) catalyst was added at room temperature; the yellow-green color disappeared (Fig. 6).

# 3.2.2. $C r ( W )$ removal from aqueous solution by $r G O { - } C o _ { 3 } O _ { 4 }$ nanocomposite

3.2.2.1. Adsorption experiments. $\mathrm { C r } ( \mathsf { V I } )$ aqueous solutions of different Cr concentrations $( 0 . 5 { - } 3 0 0 \mathrm { m g / L } )$ were prepared through successive dilutions of a stock $\mathrm { K } _ { 2 } \mathrm { C r } _ { 2 } \mathrm { O } _ { 7 }$ solution $( 5 0 0 \mathrm { m g / m L } )$ with Milli-Q water. $$

$$

$$

In acidic medium, high concentration of $\mathrm { H } ^ { + }$ ions is present which are able to neutralize the negatively charged adsorbent surface, thereby enhancing dichromate ions diffusion at low pH [37]. In alkaline media, surface protonation decreases gradually and only chromate $( \mathrm { C r O } _ { 4 } ^ { 2 - } )$ ions remain as stable species. # 3.2.4. Removal by rGO: Adsorption mechanism

To gain a better understanding on the important parameters that govern the adsorption process, we have applied rGO as adsorbent of RhB, MO and RB from aqueous solution (Fig. 13). Although rGO was efficient for dye removal, the adsorption process was quite longer than with $\Gamma { \cal G } 0  – { \cal C } 0 _ { 3 } 0 _ { 4 }$ nanocomposite; it took $2 0 \mathrm { { m i n } }$ to remove $9 2 \%$ of RhB and 6 min to remove $7 5 \%$ of MO. Surprisingly, rGO was not efficient for RB adsorption with only $8 \%$ removal after $5 0 \mathrm { { m i n } }$ . Interestingly, under otherwise identical experimental conditions, rGO- ${ \bf \cdot } { \bf C o } _ { 3 } { \bf O } _ { 4 }$ nanocomposite removed $9 6 \%$ , $9 1 \%$ and $9 2 \%$ of RhB, MO and RB after 2, 1 and $2 \mathrm { { m i n } }$ , respectively. From these results, we can conclude that hybridization of rGO with $C o _ { 3 } 0 _ { 4 }$ NPs has improved significantly its adsorption capacity for the three investigated dyes with the big advantage that they can be easily separated by an external magnet.

The mechanism of dye adsorption is controlled by various parameters such as the physical and/or chemical properties of the adsorbent. rGO nanosheets are capable of interacting with a dye molecule through $\pi { - } \pi$ conjugation, H-bonding, electrostatic and hydrophobic interactions [38,39]. Moreover, dye adsorption is strongly influenced by the surface area and surface functionality of adsorbents [3]. The surface structure of graphene has a strong influence on its adsorption capability. The surface of $\scriptstyle \Gamma \mathbf { G } 0 - \mathbf { C } 0 _ { 3 } 0 _ { 4 }$ is positively charged under our experimental conditions (zeta potential of $1 7 \pm 1 . 5 \mathrm { m V }$ in water, Fig. S6). This implies that, for anionic dyes, electrostatic interactions play a major role even though aromatic interactions $\scriptstyle { \pi - \pi }$ stacking) are well recognized in adsorption processes of aromatic molecules on graphene surface. Moreover, the homogeneous dispersion of ${ \cal C } _ { } 0 _ { 3 } 0 _ { 4 }$ NPs over the rGO support results in enhanced surface area and improved adsorption ability. For cationic dyes, the interaction between the nanocomposite and the dyes is believed to be governed by $\pi { - } \pi$ interactions rather than binding at the oxygen groups of the nanocomposite [40].

Our results prove that $\Gamma { \cal G } { \cal O } { - } { \cal C } _ { 0 _ { 3 } } { \cal O } _ { 4 }$ nanocomposite is an excellent, very efficient and fast dye adsorbent which works at neutral pH. Moreover, the rGO- $\mathrm { \cdot } \mathsf { C o } _ { 3 } \mathrm { O } _ { 4 }$ hybrid is superparamagnetic at room temperature. Therefore, it can be easily and rapidly recovered from the solution through magnetic separation.

# 4. Conclusion

We have demonstrated that superparamagnetic $\scriptstyle \Gamma \mathbf { G } 0 - \mathbf { C } 0 _ { 3 } 0 _ { 4 }$ nanocomposite exhibited good catalytic properties for

4-nitrophenol reduction to 4-aminophenol by $\mathrm { N a B H _ { 4 } }$ with a full reduction in less than 1 min. The nanocomposite can be reused for 10 consecutive catalytic cycles without any apparent loss of its activity, indicating a good stability. Furthermore, the nanocomposite displayed high adsorption capacity for $\mathrm { C r } ( \mathsf { V I } )$ at room temperature. The adsorption process can be well described by the Langmuir model, suggesting monolayer coverage sorption of Cr (VI) on the surface of $\scriptstyle \mathrm { r G O - C o } _ { 3 } 0 _ { 4 }$ . The adsorption process of rGO$\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ for $\mathrm { C r } ( \mathsf { V I } )$ ions is pH dependent, reaching a higher adsorption capacity at low pH values. Finally, the nanocomposite was successfully applied for rhodamine B, methyl orange and rose Bengal (5– $1 5 \mu \mathrm { M } )$ removal in less than 1 min at neutral pH. More importantly, the magnetic properties of the nanocomposite permit its simple separation from the liquid phase by application of an external magnet (1 T). These results evidence that rGO- ${ \bf \cdot } { \bf C o } _ { 3 } { \bf O } _ { 4 }$ holds promise for potential applications for the removal of heavy metal ions and organic dyes from wastewater, but also for other catalytic transformations in the field of environmental remediation.
