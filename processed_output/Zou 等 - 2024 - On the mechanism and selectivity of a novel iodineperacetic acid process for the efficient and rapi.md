# . Introduction

The availability of fresh water is decreasing in many parts of the world because of unsustainable withdrawals and contaminant emissions [1]. Therefore, technologies for producing clean water have gained worldwide attention. Today, the majority of wastewater is treated with biological processes (e.g. activated sludge), physical processes (e.g. adsorption or membranes) or through advanced oxidation (e.g. ozonation) [2,3]. Despite these efforts, removing micropollutants from municipal wastewater remains a challenge, particularly for certain classes of contaminants. For example, many recalcitrant micropollutants, such as phthalates, phenols and pharmaceuticals, enter the environment in the effluent from wastewater treatment plants (WWTPs), thus leading to negative impacts on the environment and human health[4,5].

Bisphenol A (BPA) is a commonly used compound in the production of synthetic polymers, but its continuous emission into the environment poses a threat to aquatic organisms [6]. Despite being prohibited for use in infant feeding bottles by the EU, it is still permitted for use in food contact materials. BPA has a short half-life but is pseudo-persistent in the environment, and typical removal efficiencies in wastewater treatment plants are around $7 0 \ \%$ [7]. More advanced wastewater treatment methods need to be developed to ensure better removal of BPA. Advanced oxidation processes (AOPs) are a collection of oxidation methods utilizing highly reactive radicals, such as hydroxyl radicals $( \bullet \mathrm { O H } )$ , sulfate radicals $( \bullet S O _ { 4 } ^ { - } )$ or superoxides $\left( \bullet 0 _ { 2 } ^ { - } \right)$ [8,9]. AOPs are good procedures for degrading biologically toxic and persistent pollutants [9]. In most AOPs, the primary process is the in-situ production of radicals, which is often done by oxidizing agents such as hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ or peroxymonosulfate (PMS) [8,10]. Peracetic acid (PAA) is a novel oxidant that has gained attention recently [8]. The compound is manufactured by reacting $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ with acetic acid using a catalyst such as sulfuric acid [11]. Compared to $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PMS, PAA is safer, more effective, environmentally friendly, highly water-soluble, and minimizes the formation of harmful byproducts, with its selfdecomposition yielding acetic acid and oxygen at pH ranged from 5.5 to 8.2, thus reducing environmental impact [8]. Besides, compared with the more commonly used $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $2 1 3 \mathrm { k J } \mathrm { m o l } ^ { - 1 }$ and PMS $( 3 1 7 \mathrm { k J } \mathrm { m o l } ^ { - 1 } )$ , PAA $( 1 5 9 \mathrm { k J } \mathrm { m o l } ^ { - 1 } \cdot$ ) has a lower bond energy of the O-O bond and can be more easily activated [10,12,13]. Typically, PAA can itself be activated to form reactive radical species such as organic radicals (R-O•, including $\mathrm { C H _ { 3 } C ( O ) O \bullet }$ , $\mathrm { C H _ { 3 } C ( O ) O O \bullet }$ , and $\mathrm { C H _ { 3 } } \bullet \mathrm { _ { \it { i } } }$ and •OH through ultraviolet (UV) irradiation or metal-based catalysts (e.g., $\mathrm { F e ^ { 2 + } }$ or ${ \mathsf { C o } } ^ { 2 + }$ [8]. In addition, it has been revealed that PAA can also be activated by heat, ultrasound, microwave, and activated carbon to produce the above listed reactive radical species and non-radicals (singlet oxygen, $^ 1 0 _ { 2 } )$ for the effective elimination of micropollutants[8,14].

Though promising, the existing methods for PAA activation rely primarily on external energy input (e.g., UV, ultrasonic and heating) and/or transition metals (e.g., $\mathrm { F e } ^ { 2 + }$ and $\mathsf { C o } ^ { 2 + } )$ , which suffer from high energy consumption, metal leaching, and poor catalytic stability. Furthermore, the low selectivity of R-O• and •OH is also a disadvantage of the traditional PAA-based AOPs, because it results in R-O• and •OH easily being scavenged by various compounds (e.g. natural organic matter (NOM)) present in complex water matrices [10,15]. This inevitably consumes a large fraction of the radicals increasing the required chemical amounts and costs of the treatment. Given the deficiencies of existing PAA activation techniques, we are inspired to offer a novel activation approach for PAA that may be carried out under more environmentally friendly settings and reduced treatment costs.

Iodine ion $\left( \mathrm { I } ^ { - } \right)$ is an indispensable micronutrient that plays a crucial role in the development of plants, animals, and even humans, and is omnipresent in nature, particularly in the various water bodies. Recently, Feng et al. developed an innovative AOP by combining PMS and $\Gamma ^ { - }$ to generate reactive iodine species (RIS, e.g., I• and ${ \mathbf { I } } _ { 2 } { \bullet } ^ { - } .$ )for the selective and efficient removal of phenolic contaminants from wastewater [15]. Notably, RIS has gained interest for AOPs since they are more selective radicals with relatively strong oxidation capacity compared to broad-spectrum •OH [15,16]. For example, I• could rapidly react with compounds containing electron-donating groups such as phenolic hydroxyl [15]. In particular, in contrast to $\mathrm { C l ^ { - } }$ and $\mathrm { B r } ^ { - }$ , which can form toxic chlorates and bromates during oxidation, the generation of $\mathrm { I O } _ { 3 } ^ { - }$ by oxidation of $\Gamma ^ { - }$ is considered a green route since $\mathrm { I O } _ { 3 } ^ { - }$ is non-toxic and $\Gamma ^ { - }$ can be regenerated endogenously through this way [15]. RIS based AOPs are, therefore, a promising alternative to traditional methods. Considering that PAA and PMS are both novel oxidants with similar molecular structures containing O-O bond, it is reasonable to assume that the selective and efficient removal of pollutants with phenolic structures (e.g., BPA) can be achieved by generating RIS through the interaction of $\Gamma ^ { - }$ and PAA.

In this work, we propose an innovative approach to combine PAA and $\Gamma ^ { - }$ as green and sustainable alternative RIS-based AOPs for selective and efficient degradation of micropollutants with phenolic structures (e. g., BPA). In addition, we performed batch tests to identify the reactive species generated throughout the $\Gamma ^ { - } / \mathrm { P A A }$ process and combined the analysis with density functional theory (DFT) thermodynamic calculations to reveal the reaction mechanism of PAA with $\Gamma ^ { - }$ in depth. Thereafter, the feasibility of reacting PAA with other halogens $\mathrm { \Omega C l ^ { - } }$ and $\mathsf { B r } ^ { - } )$ to generate reactive halogen species (RHS, e.g., Cl•, Br•, $\mathrm { C l } _ { 2 } { \bullet } ^ { - } { \mathrm { a n d } }$ $\mathbf { B r _ { 2 } bullet } ^ { - } .$ was also systematically evaluated. Lastly, the $\Gamma ^ { - }$ /PAA process was further evaluated for the removal capacity and selectivity of 21 typical micropollutants in the wastewater containing phenolic and nonphenolic compounds. This is the first research to our knowledge that employs PAA and $\mathrm { I } ^ { - }$ to form RIS to facilitate the selective removal of refractory micropollutants. This study innovatively proposes a novel PAA-mediated RIS-based AOP and can provide a new strategy for the treatment of toxic industrial wastewater containing phenolics.

# 2. Materials and methods

# 2.1. Chemicals

Peracetic acid $( 3 8 - 4 0 ~ \% )$ , bisphenol A $( \geq 9 9 ~ \% )$ , potassium iodine $( 9 9 . 9 \% )$ , sodium chloride $( \geq 9 9 . 9 ~ \% )$ , sodium bromide $( \geq 9 9 . 9 ~ \% )$ , and 3,5-Dimethyl-1H-pyrazole $( 9 9 . 9 \% )$ were purchased from Sigma-Aldrich (Denmark). Text S1 in the Supplementary information (SI) contains comprehensive information on the chemicals utilized.

# 2.2. Experimental procedure

Batch experiments were conducted in triplicate at room temperature $( 2 5 \pm 2 ^ { \circ } \mathbf { C } )$ in $2 5 0 \mathrm { m L }$ beakers. The volume of the reaction solution was $2 0 0 ~ \mathrm { m L }$ containing $4 3 . 8 \mu \mathrm { M }$ BPA and $1 0 0 \mu \mathrm { M }$ PAA and the reaction was started after the addition of $1 0 0 ~ \mu \mathrm { M } ~ \mathrm { I } ^ { - }$ (KI stock solution, $2 0 0 ~ \mathrm { m M } )$ , unless otherwise stated. The initial pH of the reaction is adjusted by using NaOH $\mathbf { \hat { \Pi } } ^ { 1 0 0 \mathbf { m } \mathbf { M } ) }$ or $\mathrm { H _ { 2 } S O _ { 4 } }$ $\bf { \Omega } ^ { \mathrm { ~ \tiny ~ 1 0 0 ~ m M } }$ . At the set sampling interval, $9 5 0 \mu \mathrm { L }$ of the sample was drawn, quenched with $5 0 \mu \mathrm { L }$ of $\mathrm { N a _ { 2 } S O _ { 3 } }$ (2 M), and kept at $4 ^ { \circ } \mathrm { C }$ in the dark before testing. Additionally, the experiment was carried out by adding $4 3 . 8 \mu \mathrm { M }$ BPA to three different types of water, including tap water, sea water (Skovshoved, Copenhagen, Denmark), and WWTP secondary effluent (Lyngby WWTP, Copenhagen, Denmark), to study the effect of water matrices on the $\Gamma ^ { - } / \mathrm { P A A }$ process. The characteristics of the three different types of water are listed in Table S1-S3. Lastly, the selective removal of typical pollutants by $\Gamma ^ { - } / \mathrm { P A A }$ was investigated by spiking 21 micropollutants with concentrations ranging from 20 to $1 3 0 ~ \mu \mathrm { g } / \mathrm { L }$ (detailed concentration of each compound can be seen in Text S1) to the WWTP secondary effluent (Lyngby WWTP, Copenhagen, Denmark).

# 2.3. Computational and analytical method

The specific DFT calculations were described in Text S2. A highperformance liquid chromatography (Agilent 1290 Infinity, USA, HPLC) system coupled with a tandem mass spectrometer (Agilent 6470 series, USA, MS/MS) was used to quantify the concentration of the selected model micropollutants. The detailed operational parameters of HPLC-MS/MS system are shown in Text S3. In addition, the total organic carbon (TOC) and pH were determined using the methodology outlined in our previously published paper [17]. Furthermore, the concentrations of the byproducts $\mathrm { I } _ { 2 }$ and $\bar { \mathrm { I } _ { 3 } }$ generated in the $\Gamma ^ { - } / \mathrm { P A A }$ process were monitored using spectrophotometric methods as described in Text S4. For the potential formation of HOBr in the $\mathrm { B r ^ { - } / P A A }$ process, the pH of the solution was adjusted to 11.0 before spectrophotometrically measuring its formation at $3 2 9 \ \mathrm { n m }$ [18]. The determination of the concentration of PAA was conducted in the same manner as described in a previous study [19]. A microplate reader (Synergy H1, Agilent Technologies, USA) was employed for detecting HOCl.

# 3. Results and discussion

# 3.1. Proof-of-concept: Abatement of BPA by $\boldsymbol { \ulcorner }$ /PAA process

Fig. 1 depicts the degradation of BPA in various systems. Neither PAA nor $\Gamma ^ { - }$ showed any capability of removing BPA alone, which might be attributed to the insignificant production of reactive species when they were present individually. It has been reported that most molecules, except for a few nucleophilic reagents containing electrondonating groups, may not readily react with PAA [20,21]. Comparatively, BPA removal was high when both PAA and $\Gamma ^ { - }$ were added. In fact, after $6 0 \ \mathrm { m i n }$ , the removal efficiency was almost $1 0 0 ~ \%$ .In the continuation of the reaction, the BPA degradation became much slower, presumably due to the quick consumption of PAA, leading to a remarkable decrease in the production of reactive species [20]. These results indicate that the PAA and $\Gamma ^ { - }$ reaction was possible and necessary to achieve efficient BPA degradation. Besides, the removal of BPA followed a pseudo-first-order kinetic model, and the corresponding $\bf k _ { a p p }$ value was $0 . 2 1 \ \mathrm { m i n } ^ { - 1 }$ . Generally, PAA is produced by reacting $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ with acetic acid, and thus, both compounds would be in excess in the final PAA solution. It was found in a previous study that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ can be activated by $\Gamma ^ { - }$ to form RIS, including $\mathrm { I } _ { 2 } , \ \mathrm { I } _ { 3 } ^ { - }$ and HIO for arsenite oxidation [22]. Moreover, reactive oxygen species (ROS), including •OOH and •OH, were identified in the $\Gamma ^ { - } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ process in acidic pH [23]. Thus, it is essential to investigate the role of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the degradation of BPA during the $\Gamma ^ { - } / \mathrm { P A A }$ process. Therefore, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentrations of $5 \mu \mathrm { M }$ similar to those identified in the $1 0 0 ~ \mu \mathrm { M }$ PAA solution were used to examine the effect of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ on BPA removal. The results showed that only around 20 $\%$ of the BPA was degraded during $\Gamma ^ { - } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ process within $6 0 \ \mathrm { m i n }$ , while $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ alone had no effect. The degradation $\mathrm { I ^ { - } / H _ { 2 } O _ { 2 } }$ process occurred in the first $1 5 \ \mathrm { m i n }$ , which might be due to the rapid consumption of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [24,25]. As the BPA elimination rate by the $\mathrm { I ^ { - } / H _ { 2 } O _ { 2 } }$ process was quite low, it can be concluded that the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the PAA solution did not significantly contribute to the overall $\Gamma ^ { - } / \mathrm { P A A }$ process for BPA removal and that PAA was the main reactant. In addition, compared to the commonly utilized metal-based catalytically activated PAA processes such as $\mathrm { C o } ^ { 2 + } / \mathrm { P A A }$ ( $1 0 0 \%$ removal $1 0 \mu \mathrm { M }$ BPA within $3 0 \mathrm { \ m i n s } \mathrm { \cdot }$ and $\mathrm { F e } ^ { 2 + } / \mathrm { P A A }$ processes $( 8 7 . 7 ~ \%$ removal $1 5 ~ { \mu \mathrm { M } }$ BPA within $1 2 0 ~ \mathrm { { m i n s } ) }$ [20,2628], the overall performance of the $\Gamma ^ { - } / \mathrm { P A A }$ process $9 3 \%$ removal $4 3 . 8 \mu \mathrm { M }$ BPA within 30 mins) was advantageous as a metal-free process in the removal of micropollutants represented by BPA. Furthermore, $\Gamma ^ { - }$ are abundant in a variety of aqueous matrices, particularly in oil and gas wastewaters, where extraordinarily high levels of $\Gamma ^ { - }$ (up to $2 8 0 \mu \mathrm { M } )$ coexist with phenolic pollutants [15]. Thus, the quick elimination of phenolic pollutants by adding PAA to iodideion-containing wastewater renders this method a viable, eco-friendly, cost-effective water treatment technique.

# 3.2. Validation of primary reactive species and abatement mechanism in the $\boldsymbol { \ulcorner }$ /PAA process

PAA, like $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ persulfate (PS), and periodate (PI), is a singleelectron oxidant. When combined with reducing agents like $\mathrm { F e ^ { 2 + } }$ or ${ \mathrm { C o } } ^ { 2 + }$ , it could produce R-O• and $\bullet \mathrm { O H }$ ,allowing efficient removal of pollutants [8,12,27]. Because of the reducing property of $\Gamma ^ { - }$ and the asymmetric structure of PAA, the electron transfer between $\Gamma ^ { - }$ and PAA may lead to the generation of reactive species such as R-O• and •OH. To further identify the primary active species for BPA abatement, quenching experiments were conducted using MeOH and TBA as scavenging probes for R-O• and •OH $( \mathbf { k } = 6 . 0 \times 1 0 ^ { 8 } \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ , respectively [12,29]. As illustrated in Fig. 2a, the addition of 100 to $5 0 0 \mathrm { m M }$ TBA showed no suppressive activities on the removal of BPA, suggesting •OH was not the main reactive species generated in the $\Gamma ^ { - } / \mathrm { P A A }$ process. In addition, •OH was not identified by coumarin fluorimetry analysis (Fig. S1), confirming that it was not the main reactive species [30]. As shown in Fig. 2b, adding MeOH (as much as $5 0 0 \mathrm { m M }$ had no appreciable effect on the rate of BPA breakdown. These findings indicate that R-O• and •OH were not the reactive species primarily responsible for the abatement of BPA.

Besides, it has been reported that quinones which can occur as possible byproducts from BPA degradation, can activate PAA and produce $^ 1 0 _ { 2 }$ [31]. Furfuryl alcohol (FFA) is an effective $^ 1 0 _ { 2 }$ quencher, and its rate constant for the reaction with $^ 1 0 _ { 2 } ( \mathrm { k } = 1 . 2 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } \mathrm { \Omega } s ^ { - 1 } )$ is slightly lower than the value between $^ 1 0 _ { 2 }$ and BPA $( \mathbf { k } = 2 . 1 \times 1 0 ^ { 8 } \mathbf { M } ^ { - 1 }$ $\mathsf { s } ^ { - \bar { 1 } \cdot }$ [32]. The exploration of the influence of FFA on BPA elimination revealed that a dose of $2 \ \mathrm { m M }$ FFA $( \mathrm { [ F F A ] / [ B P A ] } ~ = ~ 5 0 { : } 1 )$ did not significantly limit the abatement of BPA during the $\Gamma ^ { - } / \mathrm { P A A }$ process (Fig. 2a). In addition, the rate constant for the reaction of $^ 1 0 _ { 2 }$ with $\Gamma ^ { - }$ (k $= \bar { 5 } \times 1 0 ^ { 6 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ , second-order reaction rate constants $\left( \mathbf { k } \right) )$ was significantly lower than its value with BPA [15]. As shown by the apparent suppression of BPA degradation by a modest excess of $\Gamma ^ { - }$ (Fig. 3b), $^ 1 0 _ { 2 }$ should not be the primary reactive species involved in the degradation of BPA in the $\Gamma ^ { - } / \mathrm { P A A }$ process.

In prior research, various oxidants, including $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ,have been proven to oxidize $\Gamma ^ { - }$ to hypoiodous acid (HOI) [22]. Due to the high oxidizing potential of PAA and the low concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the administered PAA solution, HOI could be produced during the $\Gamma ^ { - } / \mathrm { P } \mathrm { A } \mathrm { A }$ process (Eq. (1)). Crotonic acid, an effective HOI scavenger [33], was employed to determine the role of HOI in the $\Gamma ^ { - } / \mathrm { P A A }$ process. The results showed that crotonic acid (maximum $2 0 \ \mathrm { m M }$ , [crotonic acid]/ $[ \mathrm { B P A } ] = 5 0 0 $ did not affect BPA elimination. HOI may undergo electrophilic aromatic substitution reactions with BPA to generate iodinated aromatic products [34]. Still, it should not account for the observed rapid elimination of TOC (Fig. S2). Moreover, no significant amounts of iodinated products were detected in the degradation products, but rather non-iodinated degradation products were dominant (Fig. S6) [35]. In particular, we also observed the presence of $\Gamma ^ { - }$ , unlike the previous reaction of HOI with BPA where $\Gamma ^ { - }$ were barely detectable, which again proves that HOI is not the main active species in the $\Gamma ^ { - }$ /PAA process (Fig. S6) [34]. Thus, the above results demonstrate that HOI was also not the primary active species for the degradation of BPA during the $\Gamma ^ { - }$ /PAA process.

In conclusion, the primary active species that were responsible for the abatement of BPA were found to be $\mathbf { I } \bullet$ rather than R-O•, •OH, HOI and $^ 1 0 _ { 2 }$ .

# 4. Conclusions

As PAA is an alternate environmentally friendly oxidant with an increasing field of applications, this research is the first to demonstrate that the $\Gamma ^ { - } / \mathrm { P } \mathrm { A } \mathrm { A }$ process can be a viable AOPs for the selective and efficient abatement of micropollutants containing electron-donating groups. The influence of crucial factors (initial PAA and $\Gamma ^ { - }$ dosage, and pH) on BPA elimination in the $\Gamma ^ { - } / \mathrm { P } \mathrm { A } \mathrm { A }$ process was investigated. This process demonstrated a high BPA elimination efficacy over a wide pH range (28). Under optimal conditions (PAA of $5 0 0 \mu \mathrm { M } ,$ $\Gamma ^ { - }$ of $1 0 0 \mu \mathrm { M } ,$ and pH of 3), $4 3 . 8 \mu \mathrm { M }$ of BPA was completely eradicated within $1 0 \mathrm { m i n }$ . Apart from the previously reported PAA-based AOPs, which rely on free radicals (e.g., •OH and R-O•) or non-radical species (e.g., $^ 1 0 _ { 2 } )$ engagement, DFT calculations indicated that the interaction between PAA and $\Gamma ^ { - }$ follows a novel radical pathway in which I• produced via single electron transfer is the predominant reactive species. In contrast, two other halide ions including $\mathrm { C l ^ { - } }$ and $\mathtt { B r } ^ { - }$ can only generate HOCl and HOBr, respectively, via the oxygen atom transfer pathway, leading to poor removal of BPA and no demineralization. Furthermore, the $\Gamma ^ { - } / \mathrm { P A A }$ process displayed superior removal efficiency in a variety of water matrices and highly resistant to co-exisiting anions (e.g., $\mathrm { H C O } _ { 3 } ^ { - } .$ , indicating a high applicability. The $\Gamma ^ { - } / \mathrm { P A A }$ process was further tested for the removal of other 21 micropollutants. The variation in the removal effectiveness also thoroughly validated the existence and contribution of •I. This research will shed light on developing costefficient, ecologically friendly, effective, and catalyst-free PAA-based AOPs for water treatment.
