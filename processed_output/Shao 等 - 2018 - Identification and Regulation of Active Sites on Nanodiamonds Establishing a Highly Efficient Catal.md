# Identification and Regulation of Active Sites on Nanodiamonds: Establishing a Highly Efficient Catalytic System for Oxidation of Organic Contaminants

Penghui Shao, Jiayu Tian,\* Feng Yang, Xiaoguang Duan, Shanshan Gao, Wenxin Shi, Xubiao Luo,\* Fuyi Cui, Shenglian Luo, and Shaobin Wang

Nanodiamonds exhibit great potential as green catalysts for remediation of organic contaminants. However, the specific active site and corresponding oxidative mechanism are unclear, which retard further developments of high-performance catalysts. Here, an annealing strategy is developed to accurately regulate the content of ketonic carbonyl groups on nanodiamonds; meanwhile other structural characteristics of nanodiamonds remain almost unchanged. The well-defined nanodiamonds with well-controlled ketonic carbonyl groups exhibit excellent catalytic activity in activation of peroxymonosulfate for oxidation of organic pollutants. Based on the semi-quantitative and quantitative correlations of ketonic carbonyl groups and the reaction rate constants, it is conclusively determined that ketonic carbonyl groups are the catalytically active sites. Different from conventional oxidative systems, reactive oxygen species in nanodiamonds@peroxymonosulfate system are revealed to be singlet oxygen with high selectivity, which can effectively oxidize and mineralize the target contaminants. Impressively, the singlet-oxygen-mediated oxidation system significantly outperforms the classical radicals-based oxidation system in remediation of actual wastewater. This work not only provides a valuable insight for the design of new nanocarbon catalysts with abundant active sites but also establishes a very promising catalytic oxidation system for the green remediation of actual contaminated water.

# 1. Introduction

In recent decades, organic pollutants in the aquatic environment have become a ubiquitous and serious problem faced on a global scale,2] Tremendous efforts were devoted to developing advanced technology for the remediation of organic contaminants. Among these technologies, advanced oxidation processes based on persulfates have been suggested as an effective approach to decompose the organic compounds.[3,4] Various strategies have been developed for activating persulfates to generate reactive oxygen species (ROSs) such as UV irradiation, heating, and electrochemical method.[57] However, these activating techniques require high energy inputs, which are not cost-effective. Metalbased materials (e.g., ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ , $\mathrm { M n O } _ { 2 }$ , CuO$\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } )$ are efficient catalysts for persulfates activation.[810] Unfortunately, toxic metal leaching from metal-based catalysts inevitably occurs, leading to the secondary contamination of water body.

To overcome this disadvantage, metalfree carbon nanomaterials have emerged as promising alternatives to conventional metal-based catalysts in activating persulfates.[1114] Among these nanocarbons, nanodiamonds (NDs) formed by $\mathsf { s p } ^ { 3 }$ hybridized carbon atoms exhibit great potentials as green catalysts for remediation of organic contaminants owing to its excellent biocompatibility and relatively inexpensive costs [15,16] Recently, Duan et al. reported that the nitrogen-modified annealed NDs exhibited excellent activity in catalytic dissociation of peroxymonosulfate (PMS) to produce sulfate $\left( \mathrm { S O } _ { 4 } ^ { - \bullet } \right)$ and hydroxyl radicals (·OH) for phenol oxidation.[17] Additionally, they also found that the persulfates can be effectively dissociated into reactive species by the annealed NDs with graphitic shell structure.[18] Later, Lee et al. reported that the graphitic NDs possessed an outstanding performance in the catalytic activation of persulfate for oxidative degradation of phenol.[19]

Although the exciting advances have been achieved, there still exist two problems retarding the further developments of high-activity NDs. First, the specific active site on NDs is unclear. Previous researches indicated that the activity of NDs can be effectively improved by the surface modification.[1719] However, upon these modification methods, complex changes occurred on the surface structures of NDs; thus, it is very difficult to determine exactly which type of structural change leads to the enhancement in the catalytic performance. Second, the oxidation mechanism is under debate. Duan et al. considered that the radical-mediated oxidation process played a vital role in the degradation of organic pollutants.[17,18,20,21] On the contrary, Lee et al. proposed that the charge transfer process without the involvement of ROSs resulted in the degradation of organic pollutants.[19,22] Therefore, it is highly desirable to gain a mechanistic insight into the heterogeneous catalysis of PMS activation on nanodiamonds to guide the design of new catalytic materials with sufficient active sites.

In this study, we deliberately designed an annealing strategy that can accurately regulate the content of ketonic carbonyl $( \mathrm { C = O } )$ groups on NDs surface; meanwhile, the other structural characteristics of NDs (e.g., micromorphology, hybridization of carbon atoms, oxygen content) remain almost unchanged. The well-defined NDs with well-controlled ketonic $\mathrm { C } { = } \mathrm { O }$ groups exhibited excellent catalytic activity in activation of PMS for oxidation of organic pollutants. Based on the semiquantitative and quantitative correlations of ketonic $\mathrm { C } { = } \mathrm { O }$ groups and the reaction rate constants, we conclude that the ketonic $\mathrm { C } { = } \mathrm { O }$ groups are the catalytically active sites. Different from the free radicals involved in the conventional PMSbased oxidation systems, the ROSs generated in the $\mathrm { N D s } /$ PMS system were revealed to be the singlet oxygen $( { } ^ { 1 } \mathrm { O } _ { 2 } )$ with high selectivity, which can suffer less interference from background organic and inorganic matters and effectively oxidize and mineralize the target contaminants. More importantly, as compared with the classical radical-based oxidation system, the ${ } ^ { 1 } \mathrm { O } _ { 2 }$ -mediated oxidation system exhibited an outstanding performance for the remediation of organic contaminants in actual water body.

# Results and Discussion

The raw NDs consist of a crystalline diamond core and an amorphous carbon shell decorated with abundant oxygencontaining groups.[23] Due to the difference of thermal stability of the oxygenic groups,2427] annealing treatment may be an effective approach to control the type and content of oxygenic functional groups. Besides, to minimize the change of other surface properties, the selected annealing temperature should be as low as possible. This is because that the excessive high temperature may give rise to the unnecessary alterations of the surface properties such as the hybridization of surface carbon atom and the micromorphology. Inspired by the abovementioned considerations, we speculate that the regulating surface oxygenic functional groups of NDs along with the maintaining other structural properties may be realized by the facile and discreet thermal treatment.

Catalytic activities of the NDs were evaluated in catalytic decomposition of PMS for oxidative degradation of 4-chlorophenol (4-CP, a ubiquitous organic contaminant in water). Figure 2a shows that a very limited degradation of 4-CP $( < 5 \% )$ is obtained by PMS itself, demonstrating that PMS alone cannot produce ROSs for 4-CP removal. Physical adsorption of 4-CP on the NDs is also negligible (Figure S5a, Supporting Information). However, obvious degradation of 4-CP can be observed in the raw $\mathrm { N D s @ P M S }$ system, indicating that raw NDs are able to activate PMS to generate ROSs for 4-CP degradation. More importantly, a remarkable enhancement in the catalytic activity of NDs can be easily achieved with the increase of annealing temperatures in the range of $5 5 0 – 8 0 0 ^ { \circ } \mathrm { C }$ For the AND/800, as high as $8 1 \%$ of 4-CP can be completely mineralized within $3 0 \mathrm { m i n }$ (Figure S5b, Supporting Information), highlighting its outstanding catalytic performance. Catalytic activities of the NDs in degradation of 4-CP were also evaluated by using the pseudo-first-order model.

It further demonstrates that the catalytic activity of NDs can be significantly improved by a facile thermal treatment.

By comparing the physicochemical properties of the NDs annealed at different temperatures, it is deduced that the observed distinctions in catalytic performance may be attributed to the significant differences in the type and level of surface oxygen-containing groups of NDs. Hence, we correlated the values of degradation rate constants of 4-CP $( k _ { 4 \cdot \mathrm { C P } } )$ to the values of $A _ { \mathrm { C = O } } / A _ { \mathrm { C - O } }$ Figure 2c shows that the $A _ { \mathrm { C = O } } / A _ { \mathrm { C - O } }$ presents a positive linear relationship with the $k _ { 4 \mathrm { - } \mathrm { C P } }$ and the obtained correlation coefficient $\scriptstyle ( R ^ { 2 } )$ is as high as 0.99. This result suggests that the ketonic $\mathrm { C } { = } \mathrm { O }$ groups make substantial contributions to the performance of NDs for catalytic 4-CP oxidation. To versify this hypothesis, catalytic decomposition of PMS by the NDs was further investigated. Similar to the above observations, the decomposition efficiencies (Figure 2b) and corresponding rate constants $( k _ { \mathrm { P M S } }$ , Figure S7, Supporting Information, and Table 1) increased with the raise of $A _ { \mathrm { C = O } } / A _ { \mathrm { C - O } }$ .And the $R ^ { 2 }$ calculated from the values of $k _ { \mathrm { P M S } }$ versus $A _ { \mathrm { C = O } } / A _ { \mathrm { C - O } }$ reaches to 0.97 (Figure 2c), confirming that the ketonic $\mathrm { C } { = } \mathrm { O }$ groups could be the active centers for ND-catalyzed PMS activation.

However, when the temperature increased to $8 0 0 ~ ^ { \circ } \mathrm { C }$ ,the surface concentration of ketonic $\mathrm { C } { = } \mathrm { O }$ groups rapidly soared to $4 3 . 4 5 \pm 2 . 7 4 \times 1 0 ^ { - 3 } \times \mathrm { g r o u p s ~ n m ^ { - 2 } }$ By the correlation analysis, the $R ^ { 2 }$ values of the surface ketonic $\mathrm { C } { = } \mathrm { O }$ concentration with $k _ { 4 \mathrm { - } \mathrm { C P } }$ and $k _ { \mathrm { P M S } }$ were 0.98 and 0.96, respectively (Figure 2d). To the best of our knowledge, this is first time to conclusively determine the active site of NDs for heterogeneous catalysis in the liquid phase, which may provide a valuable insight for the design of high-performance nanocarbon catalysts.

To elucidate the oxidation mechanism, the ROSs were first identified by in situ electron paramagnetic resonance (EPR) technology. When the spin trapping reagent, 5,5-dimethylpyrroline-oxide (DMPO),[39,40] was added into the reaction system, the specific signals of $\mathrm { D M P O { \cdot } S O _ { 4 } } ^ { \cdot - }$ and DMPO..OH did not appear (Figure 3a), suggesting that no detectable $\mathrm { S O } _ { 4 } \mathrm { \mathrm { ^ { - } } }$ and · OH radicals are generated, which is different from the previously reported radical-based processes. To verify this observation, the photoluminescence (PL) technology was also used for detection of the free radicals and no signal of ·OH radicals was discerned in the PL spectra (Figure S8a, Supporting Information), further confirming the absence of free radicals. However, when 2,2,6,6-tetramethyl-4-piperidinol (TMP, the spin trapping reagent for singlet oxygen $( ^ { 1 } \mathrm { O } _ { 2 } ) \}$ was added, a triplet EPR spectrum corresponding to the oxidized TMP by $^ 1 0 _ { 2 } ^ { [ 4 1 ] }$ can be clearly observed (Figure 3b). Moreover, the intensities of the characteristic signals of ${ } ^ { 1 } \mathrm { O } _ { 2 }$ manifested an increasing trend with the reaction proceeded (Figure S8b, Supporting Information), which implies that ${ } ^ { 1 } \mathrm { O } _ { 2 }$ may be the reactive species responsible for 4-CP degradation. To verify this hypotheses, classical quenching tests were carried out employing tert-butyl alcohol (TBA) as the scavenger of ·OH radicals, methanol as the scavenger of $\mathrm { S O _ { 4 } } ^ { \bullet - } / { \cdot } \mathrm { O H }$ radicals, and sodium azide $\left( { \mathrm { N a N } } _ { 3 } \right)$ as the scavenger of $^ 1 0 _ { 2 } . ^ { [ 3 9 , 4 0 , 4 2 ] }$ Figure S9a,b (Supporting Information) shows that the excess TBA or methanol generates very limited effect on the 4-CP degradation. Contrarily, the degradation efficiency of 4-CP remarkably declined from 100 to $8 \%$ when only $1 2 . 5 \times 1 0 ^ { - 3 } \mathrm { ~ m ~ }$ of $\mathrm { N a N } _ { 3 }$ was added (Figure S9c, Supporting Information), further indicating that ${ } ^ { 1 } \bar { \mathrm { O } } _ { 2 }$ is the dominating reactive species involved in the degradation of 4-CP in the AND/800@PMS system.

In addition, atrazine (ATZ) and benzoic acid (BA), the popular probe compounds for · OH and $\mathrm { S O } _ { 4 } \mathrm { \mathrm { \Sigma } } ^ { \bullet - }$ [43] respectively, were found to be hardly degraded $( < 6 \% )$ by the AND/800 (Figure S10, Supporting Information). Interesting, there is a strong positive correlation between the removal efficiency of FFA and the annealing temperature of NDs (Figure 4a). As exhibited above, increase of the annealing temperature leads to the increasing in the amounts of ketonic $\mathrm { C } { = } \mathrm { O }$ groups on NDs (Table 1). These results are just like a bridge which connects active sites $[ \mathrm { C = O }$ groups) and ROSs $( { } ^ { 1 } \mathrm { O } _ { 2 } )$ ; hereby, a novel and integrated heterogeneous catalysis oxidation reaction is proposed as follows: the ketonic $\mathrm { C } { = } \mathrm { O }$ groups on NDs serve as active sites which can catalyze PMS dissolution into the ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ rather than free radicals for organic oxidation.

Recently, Lee et al. reported the graphitic NDs exhibited excellent performance in activation of persulfate for phenol oxidation.[9] They suggested that the electron transfer from phenol to persulfate through the graphitic NDs resulted in the phenol degradation and persulfate decomposition. According to their hypothesis, the phenol derivatives substituted with one or two electron-withdrawing groups, such as 4-chlorophenol and 2,4-dichlorophenol, would be more resistant to degradation by the NDs/persulfate system, as compared with phenol. However, the degradation efficiencies of the organic pollutants achieved by the AND/800@PMS system were followed as this order: 2,4-dichlorophenol $>$ 4-chlorophenol $>$ phenol (Figure S11, Supporting Information), which is inconsistent with the results predicated by the charge-transfer mechanism. Moreover, Zhou et al. reported that 1,4-benzoquinones (BQ) with two ketonic $\mathrm { C } { = } \mathrm { O }$ groups served as a homogeneous catalyst that can catalyze the dissolution of PMS into the ${ } ^ { 1 } \mathrm { O } _ { 2 }$ for oxidation of sulfamethoxazole.43] They proposed a catalytic mechanism involving the formation of a dioxirane intermediate between PMS and BQ and the subsequent decomposition of this intermediate into ${ } ^ { 1 } { \mathrm { O } } _ { 2 }$ . To verify whether this mechanism is applicable to the AND $/ 8 0 0 @ \mathrm { P M S }$ system, additional experiments have been done. First, the AND/800 have been replaced by the BQ in activation of PMS for the 4-CP oxidation. It can be seen that with the increase of BQ dosage from 30 to $1 0 0 \mu \mathrm { m o l }$ the degradation efficiencies of 4-CP remain unchanged at a very low level $( \approx 5 \% )$ (Figure S12, Supporting Information). This result demonstrates that the BQ cannot activate the PMS to production of ${ } ^ { 1 } \mathrm { O } _ { 2 }$ for the 4-CP oxidation in the present reaction system. Second, the characteristic EPR signals of ${ } ^ { 1 } { \mathrm { O } } _ { 2 }$ cannot be observed in the ${ \mathrm { B Q } } @ { \mathrm { P M S } }$ system with reaction proceeded (Figure S13, Supporting Information), which is in line with the above-mentioned degradation tests but contrast to the observation exhibited by Zhou et al. All the observed discrepancies may be attributed to the different pH values of reaction system. Therefore, it can be deduced that the heterogeneous catalysis mechanism of the NDs/PMS system could be different from the homogeneous catalysis mechanism of the BQ/PMS system. To explore the oxidative feature of the AND/800@PMS system, the effects of operating parameters on the 4-CP degradation were evaluated systematically. As shown in Figure $\mathtt { S 1 4 a }$ (Supporting Information), the variation of pH in the range of 5.0-9.0 (the pH values detected frequently in aquatic environment) exhibits a negligible influence on the degradation of 4-CP. This result contrasts with the pH-dependent degradation performances observed in the BQ/PMS system, further demonstrating that the catalytic mechanism proposed by Zhou et al.[43] does not match the NDs/PMS oxidative system present in this work. Besides, a very minor inhibition of 4-CP oxidation can be observed in the presence of humic acid with the concentrations in the range of $0 { - } 1 0 \ \mathrm { m g \ L ^ { - 1 } }$ (the concentrations detected frequently in aquatic environment, Figure S14b, Supporting Information). Likewise, the common inorganic species (e.g., ${ \mathrm { N a ^ { + } } }$ $\mathrm { C l ^ { - } }$ , ${ \mathrm { H C O } } _ { 3 } { } ^ { - }$ ,and $\mathrm { S O _ { 4 } } ^ { 2 - }$ ions) with different concentrations also exhibit a very limited effect on the 4-CP degradation (Figure S14c—e, Supporting Information). All the results indicate that the ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ -mediated oxidative system possess a high selectivity, which can suffer less interference from common background organic and inorganic substances in water. Even in the actual water body (detailed water quality parameters shown in Table S1, Supporting Information), as high as $8 7 \%$ of 4-CP can be degraded by the ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ produced in AND $8 0 0 @$ PMS system (Figure 5). In comparison, only a very limited degradation of 4-CP was obtained by the free radicals produced in the classical $\mathrm { F e } ^ { 2 + } @ \mathrm { P M S }$ system $( \approx 4 \% )$ and ${ \mathrm { C o } } ^ { 2 + } @ { \mathrm { P M S } }$ system $( \approx 1 0 \% )$ . These exciting experimental results highlight the great efficiency of the NDs/ $@$ PMS oxidative system for remediation of toxic organic contaminants in actual wastewater.

# 3. Conclusion

In summary, a facile annealing approach was developed to precisely regulate the ketonic $\mathrm { C } { = } \mathrm { O }$ groups on NDs surface. The well-defined NDs with well-controlled ketonic $\mathrm { C } { = } \mathrm { O }$ groups exhibited excellent catalytic activity in activation of PMS for oxidation of organic pollutants. Based on the correlation analysis between the ketonic $\mathrm { C } { = } \mathrm { O }$ groups and the reaction rate constants, it was conclusively determined that the ketonic $\mathrm { C } { = } \mathrm { O }$ groups were the catalytically active sites. Integrated with the EPR study, PL study, quenching experiment, and molecule probe experiment, the ROSs in the NDs/PMS system were revealed to be ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ with high selectivity, which can effectively oxidize and mineralize the target contaminants. Importantly, the ${ } ^ { 1 } \mathrm { O } _ { 2 }$ -mediated oxidation system significantly outperformed the classical radical-based oxidation system in the remediation of organic contaminants in actual water body. This work not only provides a valuable insight for the rational design and directed synthesis of high-performance nanocarbon catalysts but also develops a very promising catalytic oxidation system for the green remediation of actual wastewater.
