Layered Li-rich cathode materials with high reversible energy densities are becoming prevalent. However, owing to the activation of low-potential redox couples and the progressively irreversible structural transformation caused by the local adjustmenttransition-metalonsntheintra/interlayedriven by anionic redox, continuous capacity degradation, and voltage decay emerge, thus greatly reducing the energy density and increasing the diffculty f battry system management. Herein, layered Li-rich cathode materials with higher intralayer configuration entropy have more local structural diversity and higher distortion energy, resulting in superior local structural adaptability with no drastic redox couple evolution, major local structural adjustment, or obvious layered-to-spinel phase transition. Consequently, the energy retention of the entropy-stabilization-strategy-enhanced Li-rich cathode materials is almost twice that of a typical Li-rich cathode material $( \mathsf { L i } _ { 1 . 2 0 } \mathsf { M n } _ { 0 . 5 4 } \mathsf { N i } _ { 0 . 1 3 } \mathsf { C o } _ { 0 . 1 3 } \mathsf { O } _ { 2 } ,$ T-LRM) after 3 months of cyclic testing. This study paves the way for the development of Li-rich cathode materials with stabilized intralayer atomic arrangements and high local structural adaptability.

# 1. Introduction

Lithium-ion batteries (LIBs) have emerged as a primary energy storage option.[14] The demand for more advanced LIBs is increasing rapidly because of the ongoing development of electric vehicles and largescale energy storage grids. To realize a long-endurance and/or lightweight in new-energy automobiles, high-energydensity and low-cost LIBs are urgently needed; however, their limiting factor has been proven to be cathode materials.[57] State-of-the-art cathode materials include traditional layered $\mathrm { L i M O } _ { 2 }$ $( \mathrm { M } { = } \mathrm { N i }$ , Co, Mn, etc.), spinel $\mathrm { L i M n } _ { 2 } \mathrm { O } _ { 4 } ,$ olivine $\mathrm { L i F e P O } _ { 4 } ,$ and rechargeable lithium oxides; however, ${ \mathrm { L i F e P O } } _ { 4 } ,$ $\mathrm { L i M n } _ { 2 } \mathrm { O } _ { 4 } ,$ and some traditional layered $\mathrm { L i M O } _ { 2 }$ cathode material provide a relatively low specific capacity,[810] which is not conducive to the realization of high-energy-density LIB systems. Lithium oxides can provide ultrahigh reversible capacities of over

1000 mwah $\mathsf { g } ^ { - 1 }$ , but they suffer from low energy efficiency and poor cycle performance.[1113] Although high-Ni cathode materials are now being gradually utilized in new-energy vehicles, they still face the problems of structural collapse and oxygen evolution in the deep delithiated state, and their synthesis cost is uneconomical [1418]

Layered Li-rich Mn-based cathode materials $( \mathrm { x L i } _ { 2 } \mathrm { M n O } _ { 3 }$ (1-x) $_ { \mathrm { L i M O } _ { 2 } ) }$ could be one of the most attractive cathode choices for future-generation LIBs owing to their low cost and high specific capacity of more than $2 5 0 \mathrm { \ m A h \ g ^ { - 1 } , ^ { [ 1 9 , 2 0 } }$ which originates from the co-participation of anionic and cationic redox couples in charge compensation.[2124] However, additional anionic redox reactions have advantages and disadvantages; although they contribute to a high capacity, they also introduce new issues.[2528] When charged to a high voltage, the $\mathrm { L i } _ { 2 } \mathrm { M n O } _ { 3 }$ or $\mathrm { L i } _ { 2 } \mathrm { M n O } _ { 3 }$ -like component is activated, and a considerable amount of $O ^ { 2 \cdot }$ participates in the charge compensation, resulting in oxygen loss, which causes the activation of low-potential redox couples.[26,27,29] Furthermore, the local structural adjustment of transition-metal (TM) ions within and/or between layers, which is driven by the anionic redox process, results in progressive and irreversible structural transformation.[26,2831] These result in continuous capacity degradation and voltage decay, thus lowering the energy density of the LIBs and increasing the difficulty of battery system management, which significantly hinders the commercial penetration of Lirich cathode materials.

# 2. Results and Discussion

X-ray diffraction (XRD) patterns of the as-prepared E-LRM are presented in Figure 1a. The diffraction peaks can be assigned to the $\mathrm { C } 2 / \mathrm { m }$ space group, and a few diffraction peaks between $2 0 ^ { \circ }$ and $2 5 ^ { \circ }$ of $2 \theta$ are ascribed to the $\mathrm { L i } / \mathrm { T M }$ ordering in the TM layer-generally called the superlattice and can be easily observed; however, the peak intensity is relatively low, which indicates the existence of stacking faults and intralayer disordering. Therefore, ${ \mathrm { C } } 2 / { \mathrm { m } } { \mathrm { \ L i } _ { 2 } } { \mathrm { M n O } } _ { 3 }$ $\mathrm { ( L i [ L i _ { 1 / 3 } M n _ { 2 / 3 } ] O _ { 2 } ) }$ was considered as the initial model for starting the Rietveld refinement process (Using Topas 4.2).[50] Given the existence of superlattice peaks, additional Li ions have priority in the Wyckoff position of the 2b site, and other elements occupy the remaining Li and Mn sites in a proportionate manner. As shown in Figure 1a, the calculated patterns are in good agreement with the observed patterns, and the refinement results are listed in Table S1 (Supporting Information). The morphology was characterized by HAADF-STEM-EDS (high-angle annular dark-field-scanning transmission electron microscopy-energy dispersive X-ray spectroscopy) mappings, which clearly reveal that all the elements are uniformly distributed as shown in Figure 1b, respectively.

STEM was carefully performed to better visualize the configuration of Li/M-ions in the E-LRM. The HAADF-STEM images in Figure 1c,d are projected along the (100) and (11_0) directions, respectively, and each row corresponds to one (001) plane projection. This is because the image intensity is related to the atomic number, wherein the brighter dots represent heavier atoms, whereas light Li and O atoms are nearly undetectable. Figure 1c,d presents the pattern features of "two bright and one dark," which are attributed to the ordering of $\mathrm { L i } / \mathrm { M }$ in the TM layers. However, the low-intensity dots commonly regarded as Li-ion columns here are not that "dark," and some (001) plane projections exhibit almost the same brightness; all of these indicate the partial intralayer disordering in the TM layer. Furthermore, the (001) plane projections are not arranged in a regular manner as expected (the simulated crystal pattern observed in a typical axe is presented in the inset). Moreover, the (001) plane projections display varying degrees of misalignment in Figure 1c,d (the domains with different orientations are labeled using different colors), which are referred to as stack faults. These results are consistent with the XRD patterns. Overall, the E-LRM exhibited more local structural diversity.

X-ray absorption near-edge structure (XANES) was used to characterize the electronic structural evolution of the E-LRM at different states of charge, as shown in Figure 3. During the entire charge/discharge process, the Mn K-edges do not undergo noticeable rigid shifts, thus indicating their inertness; however, their shapes change continuously, implying that local structural evolution occurs around Mn, as shown in Figure 3a. This is confirmed by the radial distribution function of Mn ions (Figure 3d), which is consistent with the evolution of Mn ions in common Li-rich cathode materials.[51,52] In the case of Co and Ni, when charged from the open-circuit voltage to $4 . 4 5 \ \mathrm { V } ,$ the absorption edges of both spectra shift to higher energy, as shown in the insets of Figure 3b,c, thus indicating that both Ni and Co are oxidized in this voltage region. When subsequently charged to a higher voltage, the XANES spectra of Co and Ni do not shift to a higher energy; instead, the XANES spectra of Co exhibit a slight shift to a lower energy, and the XANES spectra of Ni exhibit a significant shift to a lower energy, which is similar to the XANES spectra of Fe (Figure S4, Supporting Information). This redox behavior could be attributed to a reductive coupling mechanism,[5355] which can prevent the release of $\mathrm { O } _ { 2 }$ gas or drastic structural reorganization, thus resulting in better structural stability. Furthermore, after charging to $4 . 4 5 \mathrm { ~ V } ,$ beyond the cationic redox, the evolution behavior of the Fourier transform magnitudes of the TM K-edge EXAFS (FT-EXAFS) spectra become smoother, as shown in Figure 3df. When discharged to $2 . 1 \mathrm { V } ,$ the absorption edges of the Mn K-edge XANES spectra exhibit an almost reversible evolution as compared to the initial charge process (Figure 3a,g). In the case of Co, Ni, Cu, and Fe, when entering the discharge state, their XANES spectra shift to lower energy and return to a position close to the pristine state, which means that the cathode material experiences a good electronic structural evolution (Figure 3h,i, and S4, Supporting Information). Interestingly, when discharged to a relatively high voltage $\mathrm { \hbar } ( > 3 . 6 0 \mathrm { \Delta V } )$ , the Fourier transform magnitudes of the TM K-edge EXAFS spectra maintain a smooth evolution behavior, as shown in Figure 3jl; this is ascribed to the TM-O redox evolution or reductive coupling mechanism.

To understand the significant difference in cycle stability between the E-LRM and T-LRM, we compared the evolution of their electronic, local, and crystal structures after the first cycle and after dozens of cycles. Figure 4a-f presents the XANES spectra of the common elements and corresponding FT-EXAFS spectra in the initial state and after one cycle for the E-LRM and T-LRM, respectively. For the initial state of the E-LRM and T-LRM, the common elements, Mn, Co, and Ni, have almost the same absorption edge energy (as shown in Figure 4a-c, inset). However, after one cycle, with the exception of a similar shift in the Ni K-edge XANES, the absorption edge of Mn and Co in the T-LRM shifts to the lower energy side, and their shapes change dramatically; in contrast, these changes in the E-LRM are more moderate, as shown in Figure 4a-c. Furthermore, the change in the FT-EXAFS spectra for the T-LRM in Figure 4df is particularly striking and more dramatic than that in the case of the E-LRM, thus indicating that the T-LRM experiences more severe local structural evolution and greater activation of lowpotential redox couples during the first cycle.

The deviations for the E-LRM system are greater, demonstrating a more obvious splitting of the energy levels of the three $\mathrm { t } _ { 2 \mathrm { g } }$ orbits, further confirming the stronger distortion in the E-LRM system.

The higher CFSE that results from the larger splitting of the $\mathrm { t } _ { 2 \mathrm { g } }$ energy level increases the stability of Mn ions. Therefore, it can be expected that substantially higher energy barriers for Mn-ion migration from the octahedron site within the TM layer through the tetrahedral site within the Li layer to the octahedron site within the Li layer will be presented in the E-LRM. Figure 7e displays the migration diagram. The energy difference between the initial state of the Mn ion at the octahedral site and the intermediate state of the Mn ion at the tetrahedral site within the Li layer was calculated (Figure 7f). The T-LRM exhibits more negative migration barriers than the E-LRM. Furthermore, the average migration barriers in T-LRM are lower than those in E-LRM, which indicates that the Mn ions easily migrate in the T-LRM, which is consistent with the prediction based on the CFSE.

The stability of O was also further explored because the Mn-ion migration in layered Li-rich cathode materials is usually coupled with O evolution. In general, the shorter the O-O distance within the $\mathrm { M n O _ { 6 } }$ octahedra in the fully delithiated state, the easier it is to confront the risk of $\mathrm { O } _ { 2 }$ release. As shown in Figure $7 \mathrm { g }$ ,some ultra-short O-0 distances (2.252.40 Å) are found in the fully delithiated state of T-LRM. However, such ultra-short O-O distances are avoided in the E-LRM, which is beneficial for O stability.

These results confirm that the layered Li-rich cathode material with higher intralayer configuration entropy has more local structural diversity and higher distortion energy, leading to superior local structural adaptability. Consequently, Mn migration and O evolution are greatly mitigated, resulting in enhanced structural stability.

# 3. Conclusion

In conclusion, an entropy stabilization strategy is successfully applied to layered Li-rich cathode materials. The introduction of multiple elements increased the local structural diversity and distortion energy of $\mathrm { M n ^ { 4 + } }$ , which is verified by the DFT calculation results, leading to superior local structural adaptability and enhanced structural stability. Therefore, the activation of the low-potential redox couples is critically suppressed, and the local structural evolution, as well as the crystal structural evolution from layered to spinel structure, is effectively mitigated in the E-LRM, which is distinguished from that in the T-LRM. Consequently, the E-LRM exhibits high stability of capacity and voltage, leading to impressive energy retention. The possible mechanism suggests that the entropy strategy for stabilizing the TM intralayer structure is encouraging and will have a significant impact on the development of cathode materials.
