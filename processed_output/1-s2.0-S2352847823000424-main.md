# a b s t r a c t

Catalysts that can rapidly degrade tetracycline (TC) in water without introducing secondary ion pollution have always been challenging. Herein, a cobalt-based catalyst $( \mathsf { C o O } _ { x } @ \mathsf { P } { - } \mathsf { C } )$ is prepared so that ${ \mathsf { C o O } } _ { x }$ quantum particles $( 5 { - } 1 0 ~ \mathrm { n m } )$ are uniformly distributed on a linear substrate, and the outer layer is covered with a shell (P-C). The quantum particles of ${ \mathsf { C o O } } _ { x }$ provide many active sites for the reaction, which ensures the efficient degradation effect of the catalyst, and $3 0 \mathrm { \ m g / L }$ TC can be completely degraded in only $5 \ \mathrm { m i n }$ . The shell of the quantum particles' outer layer can effectively reduce ions' extravasation. The combination of the shell-like structure and the linear substrate greatly enhances the catalysis's stability and ensures that the catalyst is prepared into a film for practical application. The high catalytic activity of ${ \mathsf { C o O } } _ { X } @ { \mathsf { P } } { \cdot } { \mathsf { C } }$ is mainly due to the following factors: (1) Uniformly distributed ultra-small nanoparticles can provide many active sites. (2) The microenvironment formed by the core-shell structure enhances not only catalytic stability but also provides the driving force to improve the reaction rate. (3) The composite of ${ \mathsf { C o O } } _ { x }$ and P-C core-shell structure can accelerate electron transfer and generate many reactive oxygen species in a short time, which makes TC degrade extremely rapidly.

# 1. Introduction

Water pollution has attracted more and more attention in recent years, especially many organic pollutants in water [1,2]. How to efficiently degrade contaminants in flow systems has always been a challenge. Among them, the relative chemical stability of tetracycline (TC) antibiotics makes it difficult to degrade and cannot be completely absorbed by organisms, resulting in a large enrichment of soil and water sources, which in turn poses a great threat to the integrity of agricultural soil ecology and human health [3,4]. Therefore, efficient and rapid degradation of TC and the ability to achieve practical applications are of great significance, and many organic pollutants, including TC, can be well degraded by advanced oxidation processes (AOPs) [5e7].

AOPs that use peroxymonosulfate (PMS) as an oxidant to generate highly active species have received more and more attention in the field of water purification with the deepening of catalysis research [8e11]. Most AOPs systems require the supply of external energy, such as light, heat, ultrasonic waves, and microwaves [12e18]. However, catalysts prepared from metal oxides, especially cobalt-based oxides, due to their excellent electron transfer ability, can directly activate PMS without external energy input, which makes cobalt-based catalysts have better practicability and application range [19e23]. Although the ${ \mathsf { C o } } ^ { 2 + } / { \bar { \mathsf { P } } } { \mathsf { M } } { \mathsf { S } }$ system has high catalytic efficiency, Co-based catalysts tend to agglomerate during the degradation process, resulting in a significant drop in the degradation efficiency [24e28]. More importantly, the direct exposure of catalyst active sites to the reaction solution easily leads to the loss of active sites and the leaching of $C 0 ^ { 2 + }$ , resulting in secondary pollution [29,30]. Therefore, making the catalyst into a core-shell structure is an effective method to avoid the loss of active sites and the leaching of $C 0 ^ { 2 + }$ [31e34].

Core-shell catalysts have multiple advantages; on the one hand, the permeable shell could prevent core accumulation and protect the embedded catalyst from the harsh external environment without affecting the transportation of reactants and products [35e37]. On the other hand, the internal cavity could retain all exposed catalytic sites for reactants and provide a microenvironment for the oxidation reaction [32,33,38e41]. Ma et al. prepared a graphitized carbon shell co-doped with Co and N atoms to achieve efficient activation of PMS [42]. However, most of the shell of the core-shell structure is an inert component, which cannot effectively trigger PMS due to the lack of sufficient catalytic active sites. Therefore, the key is to construct an active shell to induce PMS activation and protect the active sites of the inner core catalyst. Zhang et al. synthesized a graded egg yolk-shell $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } \mathrm { - } \mathrm { C @ \mathrm { C o S i O } } _ { x }$ nanoreactor with multiple active components [43]. In our work, C was used as the shell and substrate, and to enhance its activity of inducing activation of PMS, it was modified with phosphorus to make the P-C. The shell prepared with P-C can not only protect the abundant active sites inside but also accelerate the electron transport from PMS to the catalyst to further accelerate the catalytic rate [43].

The effect of pH on the AOPs system is obvious [44]. Therefore, preparing catalysts suitable for a wide pH range is an important factor in achieving efficient degradation [45,46]. Li et al. prepared a novel ${ \tt A g } _ { 3 } { \sf P } { \sf O } _ { 4 }$ -modified tubular porous carbon nitride $( \mathsf { A g } _ { 3 } \mathsf { P O } _ { 4 } @ \mathsf { T P C N } _ { 1 2 } .$ ) photocatalyst with a broad pH range [47]. Recently, there has been increasing interest in using nitrilotriacetic acid (NTA) as a chelating agent to keep catalysts at neutral pH in a solution, avoiding the effect of various ions on catalyst pH [48,49]. For example, Wang et al. prepared Fe-NTA to degrade crotamiton [50]. Chi et al. used NTA as a complexing agent to degrade naproxen [51]. The use of NTA as a chelating agent is a promising option due to its low biodegradability, toxicity, and price. Therefore, we use the combination of Co with NTA as a precursor to prepare ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ , which can well stabilize the pH value at neutral to adapt to various water environments and accelerate the degradation of TC.

Herein, in order to solve the efficient and rapid degradation of TC and achieve practical applications, Co-NTA was prepared as a precursor, and then Co-NTA was calcined in one step to prepare a catalyst $( \mathsf { C o O } _ { x } @ \mathsf { P } { - } \mathsf { C } )$ with core-shell structured ${ \mathsf { C o O } } _ { x }$ quantum particles (Scheme 1). Since the ${ \mathsf { C o O } } _ { x }$ quantum particles are uniformly dispersed on the linear substrate, coupled with their coreshell structure, the CoO quantum particles will not agglomerate into a block, thus improving the active site of the reaction. Due to its linear substrate, ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } }$ can be filtered to form a film, which can be well adapted to the flow system. ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } }$ exhibits extremely fast TC degradation performance and strong stability thanks to its large specific surface area, abundant active sites, and core-shell structure. In the flow system, the membrane made of Co can rapidly degrade $5 0 0 ~ \mathrm { m L }$ of methyl blue and maintain stability. Furthermore, LC-MS revealed the degradation pathway of TC, EPR revealed the main active species $( 0 \bar { 2 } ^ { - } )$ , and 3D-EEM demonstrated the degradation process of TC. Meanwhile, ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } }$ has also carried out rapid degradation experiments of various pigment dyes and a large number of degradation experiments of methyl blue in a fluid system, all of which show excellent catalytic activity and stability. This study provides new ideas for efficient, rapid degradation and practical application of pollutants in water and practical applications.

# 2. Experimental

# 2.1. Preparation method

# 2.1.1. Synthesis of Co-NTA

In a typical experiment, $4 . 2 \ \mathrm { g } \ C o C l _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } 0 , 3 0 \ \mathrm { m L }$ of isopropanol and $1 . 8 \ : \mathrm { g }$ of hyponitrotriacetic acid (NTA) are added sequentially to $9 0 ~ \mathrm { m L }$ of water and stirred for $2 0 \mathrm { { m i n } }$ to dissolve completely. After that, the precursor (labeled as Co-NTA) was prepared by hydrothermal method, the above stirred solution was poured into the reactor and heated at a constant temperature of $1 8 0 ^ { \circ } \mathrm { C }$ for $^ { 6 \mathrm { h } }$ . After heating, pour the sample out of the kettle, centrifuge at $8 0 0 0 \mathrm { r / m i n }$ for 3 min to collect the lower pink pellet, and wash 3 times with water and ethanol, respectively. The resulting sample is frozen in liquid nitrogen, dried with a freeze dryer, and Co-NTA is obtained after drying.

# 2.1.2. Synthesis of $C o O _ { x } @ P _ { - } C$

1 g of sodium hypophosphite and $_ { 0 . 2 \mathrm { g } }$ of Co-NTA were placed in an Ar atmosphere, sodium hypophosphite was placed in the upper air outlet, and Co-NTA was placed in the lower air outlet, and was then heated at $3 5 0 ~ ^ { \circ } C$ for $^ { 2 \mathrm { ~ h ~ } }$ at a heating rate of $2 ~ { ^ { \circ } C } / \mathrm { m i n }$ , the obtained black powder is ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ (Scheme 1).

# 2.1.3. Synthesis of C

Nitrotriacetic acid (NTA) was heated to $6 0 0 ^ { \circ } \mathsf C$ at a rate of $2 ^ { \circ } C /$ min under Ar atmosphere and maintained for $^ { 2 \mathrm { ~ h ~ } }$ to get C.

# 2.1.4. Synthesis of $C o _ { 3 } O _ { 4 }$

The Co-NTA was heated to $5 0 0 ~ ^ { \circ } C$ in air at $2 ~ { ^ { \circ } C } / { \operatorname* { m i n } }$ and maintained for $^ { 2 \mathrm { ~ h ~ } }$ to get ${ C o } _ { 3 } { 0 } _ { 4 }$ .

# 2.2. Experimental conditions

The catalytic activity of samples for PMS activation was assessed by monitoring the degradation of TC. In a typical experiment, $1 2 \mathrm { m g }$ of catalyst is dispersed in $2 0 0 ~ \mathrm { m L }$ of TC solution $\left( 3 0 ~ \mathrm { m g / L } \right)$ and stirred for $3 0 \ \mathrm { m i n }$ to establish TC adsorption-desorption equilibrium, then $1 . 5 ~ \mathrm { m L }$ of solution is extracted as the initial concentration, and then the reaction is triggered by adding 3 mg PMS, and $1 . 5 ~ \mathrm { m L }$ of solution is immediately extracted after PMS and filtered through a syringe filter, and injected into $2 \mathrm { m L }$ of $\mathsf { N a } _ { 2 } \mathsf { S O } _ { 3 }$ $\mathrm { \Omega } ^ { \mathrm { \prime } } 1 \mathrm { \ m o l / L } )$ solution. After that, samples were drawn and filtered at intervals of 1 min each time, and then injected into $2 \ \mathrm { m L }$ of ${ \bf N } { \bf a } _ { 2 } { \bf S } { \bf O } _ { 3 }$ $( 1 ~ \mathrm { m o l / L } )$ solution. A total of ten samples were taken, the concentration of TC was determined at $3 7 7 ~ \mathrm { { n m } }$ with Shimadzu UV-2600 spectrophotometer. The degradation curve of TC was plotted with the ratio of the degraded concentration to the total concentration.

# 2.3. Characterizations

Powder X-ray diffraction (XRD) data were collected on an X-ray diffractometer (Hitani D/Ma-2500, Tokyo, Japan) using Cu $\mathrm { K } _ { \mathfrak { a } }$ radiation in the scanning range from $1 0 ^ { \circ }$ to $8 0 ^ { \circ }$ and the scanning speed of $1 0 ^ { \circ }$ per minute. X-ray photoelectron spectroscopy (XPS) spectra were obtained from an electron spectrometer (Thermo Fisher ESCALAB $\mathrm { X i + }$ ). Scanning electron microscopy (SEM) and transmission electron microscopy (TEM) were performed with JSM7500 and JEM-F200, respectively. UVeVis diffuse reflectance spectroscopy (DRS) was performed using a Shimadzu UV-2600. The specific surface area was calculated using the Brunauer-EmmettTeller (BET) method. The $\Nu _ { 2 }$ adsorption-desorption isotherms at $7 7 ~ \mathrm { ~ K ~ }$ were measured using an adsorption instrument (TriStarII, Micromeritics Company, USA) to evaluate the pore structures. Radicals’ signals were recorded on an EPR spectrometer (Bruker EMXnano, Germany). The degradation process of TC was monitored by 3D fluorescence spectroscopy (3D-EEM), and the products in the degradation process were detected by LC-MS system.

# 3. Results and discussion

# 3.1. Characterizations

TEM observations are used to further investigate the internal structure of ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ . From Fig. 1a, it can be clearly seen that there are obvious particles attached to the wire structure. From the enlarged Fig. 1b, it can be clearly seen that the particle structure is a shell-like structure, the inner core is surrounded by the outer shell, the particle diameter t is $3 0 { - } 4 0 ~ \mathrm { n m }$ , and the size of the core part is $5 { - } 1 0 ~ \mathrm { n m }$ . The lattice fringe of the inner material is $0 . 2 4 ~ \mathrm { n m }$ , corresponding to the (311) crystal plane of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } ,$ , and the lattice fringe of $0 . 2 0 \ \mathrm { n m }$ is consistent with the (200) crystal plane of CoO. From the mapping image (Fig. 1d-f), the core structure inside the shell is $\mathrm { C o _ { 3 } O _ { 4 } / C o O }$ , and P is uniformly attached to the entire particle and wire structure. The polycrystalline diffraction rings (Fig. 1c) can clearly be ascribed to $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ (311) and CoO (200).

XRD patterns in Fig. 2a show the diffraction peaks located at $3 1 . 2 ^ { \circ }$ , $3 6 . 8 ^ { \circ }$ , $4 4 . 8 ^ { \circ }$ , $5 9 . 3 ^ { \circ }$ and $6 5 . 2 ^ { \circ }$ , corresponding to (220), (311), (400) and (511) planes of cubic spinel $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ , respectively [43,52,53]. Simultaneously, the diffraction peaks located at $3 6 . 5 ^ { \circ }$ , $4 2 . 4 ^ { \circ }$ and $6 1 . 5 ^ { \circ }$ can well correspond to (111), (200) and (220) planes of cubic spinel CoO [54]. These results are in good agreement with TEM observations.

$\Nu _ { 2 }$ absorption-desorption isotherms for the three samples (CoO, $C o _ { 3 } 0 _ { 4 } ,$ and ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } } )$ in Fig. 2b exhibit typical type IV isotherms with $\mathrm { H } _ { 3 }$ -type hysteresis loops, which are characteristic of slit-type mesopores. ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ , $C o _ { 3 } 0 _ { 4 } ,$ , and CoO display a narrow hysteresis loop in the relative pressure range of 0.8e1.0, which indicates the presence of mesopores in the ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } }$ , ${ \cal C } _ { { \bf 0 } _ { 3 } { \bf O } _ { 4 } } ^ { \phantom { 0 } } ,$ and CoO nanoparticles. Moreover, the specific surface area of ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } }$ is $7 8 . 9 8 ~ \mathrm { m } ^ { 2 } / \mathrm { g } ,$ , the specific surface area of $\mathrm { { C o } _ { 3 } \mathrm { { O } _ { 4 } } }$ is $2 . 7 5 \ : \mathrm { m } ^ { 2 } / \mathrm { g }$ and the specific surface area of CoO is $1 5 . 3 9 \mathrm { m } ^ { 2 } / \mathrm { g }$ calculated by BET based on the $\Nu _ { 2 }$ adsorption and desorption curve. A large specific surface area will inevitably bring rich active sites, which can greatly promote the occurrence of degradation reactions.The results indicate that ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ has a strong adsorption capacity, which is beneficial to rapidly adsorb pollutants in water, thereby performing rapid degradation [38].

# 3.3. Transformation products and TC degradation pathway

The degradation intermediates of TC in the ${ \mathsf { C o O } } _ { x } @ { \mathsf { P } } { \cdot } { \mathsf { C } } / { \mathsf { P M S } }$ system is identified by LC-MS technique (Fig. S15). The possible degradation pathways are displayed in Fig. 5. There are three possible degradation pathways. In these three pathways, the following reactions mainly occur: deamination, hydroxylation, dehydroxylation, demethylation, ring-opening reaction, and central carbon cleavage [28,58,59]. These three paths will eventually generate p3 $( m / z = 3 1 6$ , $m / z$ is mass-to-charge ratio), p6 $( m /$ $z = 2 8 5$ ) and p9 $( m / z = 2 6 4 )$ , and further generate small molecular organics, which are finally converted to ${ \bf C } { \bf O } _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ [60].

3D Fluorescence Spectroscopy (3D-EEM) to analyze the degradation process of TC, and the results are presented in Fig. 6. After adding the ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } } _ { \mathsf { 1 } }$ the fluorescence peak of TC can be seen at Excitation wavelength/Emission wavelength $1 { = }$ $( 3 2 5 - 3 5 5 \ \mathrm { ~ n m } ) /$ $( 4 1 0 - 4 8 0 \mathrm { n m }$ ) after ultrasonication and stirring, which indicates that the physical adsorption of the catalyst does not convert TC into other substances. When the PMS is added, one fluorescence peak located at Excitation wavelength/Emission wavelength $= ( 4 0 0 - 4 5 0 ~ \mathrm { ~ n m } ) /$ $( 5 1 0 - 5 8 0 \mathrm { n m } )$ ) appears, which is ascribed to the generation of humic acid-like organic matters [61]. With the increase of time, the intensities of the peaks weaken. When the time reaches $1 0 \ \mathrm { m i n }$ , the fluorescence peak almost disappears, indicating that the intermediate is further degraded to ${ \mathrm { C O } } _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ , consistent with the degradation pathway of TC [60].

# 4. Conclusions

In conclusion, ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ is a catalyst with a uniformly dispersed core-shell structure prepared by one-step quenching of the precursor Co-NTA and has the performance of efficiently activating PMS, which can completely degrade TC $3 0 \mathrm { m g / L } ,$ within 5 min. The recombination of metal-based and non-metallic bases can greatly increase the electron transfer rate, which leads to the generation of large amounts of $0 \bar { 2 } ^ { - }$ , while $0 \bar { 2 } ^ { - }$ and $\mathrm { h ^ { + } }$ are observed to be the main active species that deeply decompose TC into organic intermediates and inorganics. ${ \mathsf { C o O } } _ { X } @ { \mathsf { P - C } }$ has ultra-fast degradation performance and stability, $2 0 \ \mathrm { \ m g }$ of ${ \mathsf { C o O } } _ { x } @ { \mathsf { P - C } }$ was immobilized on a filter membrane, which could rapidly degrade nearly $5 0 0 ~ \mathrm { m L }$ of MB while still maintaining catalytic activity. This study not only designs and prepares a catalyst that can achieve rapid degradation, but also provides a potential strategy for powder catalysts to be applied in large-scale sewage treatment plants.
