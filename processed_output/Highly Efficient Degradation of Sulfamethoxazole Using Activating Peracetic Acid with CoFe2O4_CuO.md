# Highly Efficient Degradation of Sulfamethoxazole Using Activating Peracetic Acid with CoFe2O4/CuO

Zhenzhong Liu 1,\*, Siwen Wan 2, Yang Wu 2, Boyan Wang 2, Hongliang Ji 1

1 School of Resources and Environment, Nanchang University, Nanchang 330031, China.   
2 School of Infrastructure Engineering, Nanchang University, Nanchang 330031, China.

Abstract: Advanced oxidation processes (AOPs), especially AOPs that use transition metals as catalyst activated oxidants, are extremely effective in removing organic pollutants; they can completely degrade pollutants into $\mathtt { C O } _ { 2 }$ and ${ \sf H } _ { 2 } \sf { O }$ . Thus, they have been widely studied in the field of water treatment. However, owing to the low catalytic efficiency and metal leakage, their applicability is currently limited. In this paper, the composite catalyst $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ containing spinel cobalt ferrite and copper oxide was successfully prepared by the chemical precipitation and sol-gel methods with two steps. The prepared $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ was characterized using scanning electron microscopy (SEM), X-ray photoelectron spectroscopy (XPS), and $\mathsf { X }$ -ray diffraction (XRD), and its ability to remove sulfamethoxazole (SMX) with different AOPs was evaluated. Characterization results show that ${ \mathsf { C o F e } } _ { 2 } { \mathsf { O } } _ { 4 }$ and CuO are well-complexed together, and the catalyst has good crystallinity. The effects of peracetic acid (PAA) concentration, catalyst dosage, common interfering substances $\subset 1 ^ { - }$ , HCO−3, ${ \tt S O } _ { 4 } ^ { 2 - }$ , and HA) in water, and different radical scavengers on SMX removal were also investigated. The results show that $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ has the characteristics of both ${ \mathsf { C o F e } } _ { 2 } { \mathsf { O } } _ { 4 }$ and CuO. Compared with ${ \mathsf { C o F e } } _ { 2 } { \mathsf { O } } _ { 4 }$ or CuO alone, $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ exhibits an excellent activation performance for PAA. Under the optimal reaction conditions (catalyst dosage $= 2 0 \mathsf { m g } { \cdot } \mathsf { L } ^ { - 1 }$ , $c ( \mathsf { P A A } ) = 2 0 0 \mu \mathsf { m o l } { \cdot } \mathsf { L } ^ { - 1 }$ , $c ( \mathsf { S } \mathsf { M } \mathsf { X } ) =$ $1 0 \mu \mathrm { m o l } { \cdot } \mathsf { L } ^ { - 1 } ,$ ), the degradation rate of SMX reaches $92 \%$ within $\mathfrak { g } 0 \mathfrak { s }$ . The existence of $\mathsf { C u ^ { + } / C u ^ { 2 + } }$ electron pairs can convert Co from the high valence to low valence state and accelerate the conversion of $\mathsf { C o } ^ { 2 + } / \mathsf { C o } ^ { 3 + }$ , thereby improving the catalytic performance. An increase in the PAA concentration increases the removal efficiency of SMX; however, too high a concentration lowers removal efficiency. Compared to acidic or alkaline conditions, the $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ reaction system exhibits a better removal rate of SMX under neutral conditions. The common interfering substances in the environment have different effects on the $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ reaction system. $\mathtt { C l ^ { - } }$ promotes the degradation of SMX by producing Cl•, HCO3− and HA inhibit the removal of SMX because of their quenching effect on free radicals, and ${ \tt S O } _ { 4 } ^ { 2 - }$ has no significant effect on the progress of the reaction. The XPS characterization results before and after the reaction show that the valence state of Co changes, indicating that Co is the main element involved in the activation of PAA. Radical quenching experiments demonstrate that the organic radical $( \mathsf { R } - \mathsf { O } \bullet )$ plays a dominant role in the removal of SMX. Further, the removal rate of SMX decreases after the catalyst is subjected to 3 recycle; nevertheless, it achieves a relatively rapid degradation of SMX $8 5 \%$ within $1 0 \mathrm { \ m i n }$ ).

# 1 Introduction

Sulfamethoxazole (SMX), a typical sulfonamide antibiotic, is one of humans’ most commonly used sulfonamides. It is used to treat infections and diseases caused by Gram-negative and Gram-positive aerobic bacteria and is a feed additive for animal growth 1. Since SMX cannot be completely metabolized in the body, the residual SMX is eventually discharged into the water environment 2 . A survey of the most common pollutants in wastewater by the USGS showed that SMX was in the top 30 in terms of frequency of detection 3. The constant enrichment of antibiotics will bring many adverse effects on the ecological environment, such as the generation of resistance genes and drug-resistant microorganisms 1 .

Traditional treatment technologies cannot effectively degrade SMX 4, and advanced oxidation processes (AOPs), as a deep treatment technology that completely degrades organic pollutants into $\mathrm { C O } _ { 2 }$ and $\mathrm { H } _ { 2 } \mathrm { O }$ by generating strong oxidizing free radicals without secondary pollution, which is difficult to achieve by other treatment methods. At the same time, because the AOPs has the advantages of short reaction time, fast reaction speed, and controllable process, it has great development potential in the removal of refractory organic pollutants, and has attracted the attention of many scholars 5. In recent years, peracetic acid (PAA), dominated by the generation of organic radicals $( \mathrm { R - O } \bullet )$ , has been successively reported as a new advanced oxidation process 6. PAA first appeared in the field of water treatment as a disinfectant 7. Compared with traditional chlorine disinfection technology, PAA has higher disinfection efficiency and fewer disinfection by-products 8 . PAA has a high reduction potential $( 1 . 8 1 ~ \mathrm { V } )$ , and its peroxygen $_ { ( \mathrm { O - O } ) }$ bond energy $( 1 5 9 \mathrm { k J \cdot m o l ^ { - 1 } } )$ is lower than that of $\mathrm { [ 2 O _ { 2 } ( 2 1 3 k J \cdot m o l ^ { - 1 } ) }$ , which makes PAA not only have higher oxidation performance, but also it is easier to break $\mathrm { O } { - } \mathrm { O }$ to generate a variety of free radicals $\mathrm { R - O ^ { \bullet } }$ and •OH) 9. In different PAA activation systems, the major reactive species responsible for the degradation of organic pollutants are different. For example, in the UV/PAA system, $\mathrm { R } ^ { - } \mathrm { O } ^ { \bullet }$ and •OH are generated simultaneously, but •OH plays a dominant role in degrading pollutants 10, while when some transition metals are introduced into the PAA solution, $\mathrm { R } - \mathrm { O } \bullet$ (including $\mathrm { C H } _ { 3 } \mathrm { C O } _ { 2 } \bullet$ and $\mathrm { C H } _ { 3 } \mathrm { C O } _ { 3 } { \bullet }$ ) are considered as major free radicals 11. Since transition metals are easy to decompose $\mathrm { O } { - } \mathrm { O }$ bonds, the combined process of transition metals and PAA is meaningful for the development of AOPs on the degradation of organic pollutants.

Metal oxides, as heterogeneous catalysts, have attracted wide attention due to their simple preparation and convenient operation. Bimetallic oxides can synergistically couple active sites, thereby improving catalytic activity, and have higher catalytic performance than single metal oxides 12. Spinel is a kind of bimetallic oxide with the general formula $\mathrm { { A B } } _ { 2 } \mathrm { { O } } _ { 4 }$ . The transition metals in various valence states in spinel can allow electrons to circulate, thereby promoting the generation of free radicals 13, and spinel metal oxides containing different transition metals have been reported in heterogeneous advanced oxidation processes such as persulfates 14, Fenton-like 15, and photocatalysis 16. Spinel ferrite stands out among catalytic materials due to its abundant iron reserves, low cost and easy separation from water 15–17. Because cobalt has more efficient catalytic performance, cobalt-based ferrite ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ has higher catalytic activity than other ferrites. Ren et al. 18 compared the performance of cobalt, copper, manganese, and zinc ferrites for the catalytic degradation of organic matter, and the experimental results showed that within $3 0 \ \mathrm { \ m i n }$ , the degradation rate of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ reached $8 1 . 0 \%$ , which is much higher than other spinel ferrites. Guan et al. 19 indicated that among ${ \bf M F e } _ { 2 } { \bf O } _ { 4 }$ $\mathbf { M } = \mathbf { C } \mathbf { o } _ { \mathrm { i } }$ , Cu, Zn, Ni, Mn) activated persulfate, ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ had the highest activation efficiency. Although cobalt has efficient catalytic properties, the leakage of $\mathrm { C o } ^ { 2 + }$ from cobalt-based materials in water will adversely affect human health and the ecological environment 20. Therefore, reducing the use of cobalt while maintaining high catalytic activity has become one of the challenges in the search for more efficient and green-friendly catalysts. As a transition metal, copper has much research in advanced oxidation processes 21. Copper-based catalysts have excellent development potential in the field of environmentally friendly catalysts due to the low toxicity of copper, and CuO has received attention from many scholars for its weak toxicity, low cost and easy availability compared with other metal oxides 22, and CuO has also shown good catalytic performance in persulfate advanced oxidation processes 23.

Based on the above, the combination of CuO and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ can expand its related properties, improve the catalytic activity, and reduce the use of cobalt. Meanwhile, there are few studies on the combination of $\mathrm { C u O }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ for activation, and there is no relevant research on the activation of PAA to degrade antibiotics. In this study, $\mathrm { C u O }$ was prepared by the chemical precipitation method, and then the $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ composite catalyst was prepared by the sol-gel method. The effect of $\mathrm { C u O }$ addition amount and calcination temperature on the degradation of SMX by $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ activated PAA in material preparation was explored, and the optimal CuO addition amount and calcination temperature were determined by comparing the removal rate of SMX. The SMX degradation performance of $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ and $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ and $\mathrm { C u O }$ alone activated by PAA were compared, and the effects of different influencing factors on the degradation of SMX by the $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O + P A A }$ system were investigated, and the regeneration stability of the composite $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ was explored. In general, our research will enrich the understanding of the activation mechanism between PAA and composite metal materials, and provide more ideas for new PAA activation methods to degrade organic pollutants and explore green, friendly and efficient catalysts.

# 2.2 Preparation of catalyst

# 2.2.1 Preparation of CuO

Weigh $1 0 \mathrm { ~ g ~ }$ of $\mathrm { C u S O _ { 4 } }$ and dissolve it into $4 0 0 ~ \mathrm { m L }$ of pure water, stirred magnetically for $1 5 \ \mathrm { m i n }$ , adjust the $\mathsf { p H }$ of the solution to 10.5–11.0 with $1 \ \mathrm { \ m o l { \cdot } L ^ { - 1 } }$ NaOH, stirred continuously for $0 . 5 \mathrm { h }$ and then left for $^ { 1 \mathrm { h } }$ . and separate the blue precipitate by filtration, washed the precipitate three times with pure water, dried at $8 0 ^ { \circ } \mathrm { C }$ , transferred to a muffle furnace, heated at $1 0 \ ^ { \circ } \mathrm { C } { \cdot } \mathrm { m i n } ^ { - 1 }$ to $6 0 0 ~ ^ { \circ } \mathrm { C }$ , calcined for $^ { 2 \mathrm { ~ h ~ } }$ , and ground into powder after cooling to obtain $\mathrm { C u O }$ .

# 2.2.2 Preparation of ${ \mathsf { C o F e } } _ { 2 } { \mathsf { O } } _ { 4 }$

Dissolved $_ { \mathrm { ~ 0 . 2 9 1 ~ g ~ } }$ (1 mmol) $\mathrm { C o ( N O _ { 3 } ) _ { 2 } { \cdot } 6 H _ { 2 } O }$ , $0 . 8 0 8 \mathrm { ~ g ~ }$ (2 mmol) $\mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } \mathrm { O }$ and $0 . 6 3 0 \ \mathrm { g }$ (3 mmol) citric acid in 15 mL of pure water with magnetic stirring for $1 5 \mathrm { { m i n } }$ to form a sol, added ammonia water $( 2 5 \% )$ to adjust the $\mathsf { p H }$ to neutral, transferred to a water bath at $8 0 ^ { \circ } \mathrm { C }$ with continuous stirring until a gel with low fluidity is formed. The gel was dried at $8 0 ~ ^ { \circ } \mathrm { C }$ to a dry gel, and the dry gel was transferred to a muffle furnace and heated to $6 0 0 ~ ^ { \circ } \mathrm { C }$ at $5 ~ \mathrm { { ^ circ C } { \cdot m i n ^ { - 1 } } }$ for $^ \textrm { \scriptsize 3 h }$ . After cooling and grinding, CoFe2O4 was obtained.

# 2.2.3 Preparation of $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$

Similar to the preparation of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , after adding ammonia water to adjust the $\mathsf { p H }$ to neutral, weigh $0 . 6 \ \mathrm { g }$ of $\mathrm { C u O }$ into the neutralized solution, transfer it to a water bath at $8 0 ~ ^ { \circ } \mathrm { C }$ and continue stirring until a gel with low fluidity was formed, the gel was dried at $8 0 ~ ^ { \circ } \mathrm { C }$ to a dry gel, and the dry gel was transferred to a muffle furnace and calcined at $5 ^ { \circ } \mathrm { C } { \cdot } \mathrm { m i n } ^ { - 1 }$ to $6 0 0 ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ . After cooling and grinding, the product obtained was $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ .

# 3.2 Comparison of different systems on the degradation of SMX

In this section, the SMX removal capabilities of different oxidation processes, including PAA alone, $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ , $\mathrm { C u O + }$ PAA, $\mathrm { C o F e _ { 2 } O _ { 4 } ~ + ~ \mathrm { P A A } }$ , and $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O _ { 3 } \ + \Delta P }$ AA, were investigated. As shown in Fig. 4, $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ alone has little ability to remove SMX, and the removal rate of SMX by PAA alone is $6 2 \%$ at $2 5 ~ \mathrm { { m i n } }$ , which indicates that the system of PAA and $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ alone cannot produce highly oxidizing radicals. The removal rate of SMX reached $9 4 \%$ after adding $\mathrm { C o F e _ { 2 } O _ { 4 } C u O }$ to PAA, which significantly improved the catalytic efficiency. The catalytic performance of the $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O \ + }$ PAA system showed a significant improvement compared with that of $\mathrm { C o F e _ { 2 } O _ { 4 } } + \mathrm { P M S } \ ^ { 2 7 }$ , indicating that the combination of $\mathrm { C u O }$ played the expected role. As shown in Eqs. (1) & (2), $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ can effectively activate PAA to generate free radicals to attack target pollutants, thereby achieving more efficient removal of SMX 28. Due to the high reaction rate of $\mathrm { C o } ^ { 2 + } / \mathrm { C o } ^ { 3 + }$ with PAA 29, the reaction reached degradation equilibrium at $1 0 \mathrm { { m i n } }$ after the addition of CoFe2O4 to PAA, and the removal rate of SMX reached $8 6 \%$ . The removal rate of SMX in the $\mathrm { C u O \ + \ P A A }$ system achieved $94 \%$ . Compared with $\mathrm { C o F e _ { 2 } O _ { 4 } + P A A }$ , $\mathrm { C u O } + \mathrm { P A A }$ was able to remove SMX more thoroughly, but the removal rate of SMX was lower than the former. It is worth noting that the $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O + P A }$ A system has both a higher removal capacity for SMX compared to the $\mathrm { C o F e _ { 2 } O _ { 4 } \ + \ P A A }$ system and a faster removal rate for SMX compared to the $\mathrm { C u O } + \mathrm { P A A }$ system because the presence of $\mathrm { C u ^ { + } / C u ^ { 2 + } }$ electron pairs enables the conversion of Co from high to low valence 30, accelerating the $\mathrm { C o } ^ { 2 + } / \mathrm { C o } ^ { 3 + }$ conversion and enhance the catalytic performance of the catalyst. Compared with other AOPs that activate PAA to degrade SMX, the $\mathrm { { C o F e _ { 2 } O _ { 4 } / C u O } ^ { \mathrm { ~ + ~ } } }$ PAA system showed a tremendous improvement in the degradation of SMX compared to the other catalysts, both homogeneous 31 and non-homogeneous 32, which fully illustrated the superiority of this catalyst.

A suitable oxidant concentration can ensure the best removal of the target pollutant while avoiding unnecessary selfconsumption of excess oxidant in the reaction system. It is noteworthy that when the PAA concentration is lower than $2 0 0 \mu \mathrm { m o l } { \cdot } \mathrm { L } ^ { - 1 }$ , the removal rate of SMX rises significantly with the increase of PAA concentration, and the PAA concentration increases from 200 to $2 5 0 \ \mu \mathrm { m o l } { \cdot } \mathrm { L } ^ { - 1 }$ , the removal rate of SMX only increased from $9 3 \%$ to $9 4 \%$ , which indicates that not higher concentrations of PAA are better for SMX removal. Exploring the appropriate catalyst dosage can achieve the best pollutant removal rate while reducing the risk of metal ion leakage from the catalyst. Fig. 5b shows the removal of SMX with different $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ dosages. The removal rates under the dosage of 30, 50, 70, 100 and $1 5 0 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ were $9 0 \%$ , $91 \%$ , $9 2 \%$ , $9 2 \%$ , and $91 \%$ , respectively. It can be seen that the effect on SMX removal was small at different dosing levels, but at dosing levels below $7 0 \ \mathrm { \ m g { \cdot } L ^ { - 1 } }$ , the removal rate of SMX increased in the first 60 s with increasing dosing level, which was because the increase of the dosage could provide more active sites, and when the dosage was increased to $1 5 0 \mathrm { m g { \cdot } L ^ { - 1 } }$ , the removal effect of SMX was the same as that at $7 0 ~ \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ . This may be because the fact that the reaction time is too fast, the catalyst is sufficient to activate and decompose PAA, and the active sites provided by the excess catalyst were no longer able to enhance the generation rate of free radicals.

The environmental $\mathsf { p H }$ greatly affects the removal of target pollutants by the advanced oxidation process, and the optimal $\mathsf { p H }$ plays an important role in guiding the application range of the reaction. Fig. 5c shows the removal effect of SMX at different pH. It can be seen that the removal rate of SMX is only $8 \%$ under acidic conditions $\mathrm { \mathfrak { p H } } = 3 \mathrm { \AA }$ ), and the removal rate of SMX increases sharply with the increase of $\mathsf { p H }$ , when $\mathrm { p H } = 5$ , the removal rate of SMX reached $9 3 \%$ , slightly higher than $\mathrm { p H } =$ 7 $( 9 2 \% )$ , when the $\mathsf { p H }$ increased to 9, the removal rate of SMX decreased slightly to $8 7 \%$ , and when the $\mathsf { p H }$ increased to 11, almost no removal effect on SMX. This is because the two $\mathsf { p } K _ { \mathrm { a } }$ values (1.8 and 5.6) of SMX make SMX exist in different forms at different $\mathsf { p H }$ values. When the $\mathsf { p H }$ is lower than 1.8, SMX mainly exists as $\mathrm { S M X ^ { + } }$ , and when the $\mathsf { p H }$ is between 1.8 and 5.6, SMX exists as a neutral molecule, while SMX exists as SMX− when the $\mathsf { p H }$ higher than 5.6, SMX− exhibited higher activity towards free radicals. The $\mathsf { p } K _ { \mathsf { a } }$ value of PAA is 8.2. Under acidic or neutral conditions, PAA exists in the form of conjugated acid (PAA0), and when $\mathrm { p H } > 8 . 2$ , more PAA will exist in the form of conjugated base (PAA−) 34, in addition the catalyst surface will be positively charged under acidic conditions and negatively charged under alkaline conditions. When $\mathrm { p H } < 5$ or $\mathrm { p H } > 9$ , the contact between the catalyst surface and PAA is reduced by the repulsive force of the same charge, leading to a decrease in the production of free radicals and consequently a decrease in the removal rate of SMX 35. In addition, •OH will snatch free radicals 36, resulting in a rapid decrease in the removal rate of SMX in a strongly alkaline environment.

Fig. 7 shows the effect of different free radical quenchers on the removal of SMX. Existing research results have shown that due to the strong interaction between $\mathrm { C o - F e }$ , cobalt ferrite composites can significantly inhibit the leaching of cobalt, thereby reducing the toxicity of leached cobalt ions 40. At the same time, due to the leakage of metal ions, the activation mechanism of most metal-based heterogeneous systems also includes a homogeneous process, and metal ions participate in the activation of peroxides 15,41. In order to further explore the degradation effect of metal ions leaked in the solution on SMX, Wang et al. 27 used the same concentration of $\mathrm { C o } ^ { 2 + }$ and $\mathrm { F e } ^ { 2 + }$ as in the $\mathrm { C o F e _ { 2 } O _ { 4 } / P A A }$ heterogeneous system to conduct homogeneous system experiments, and the results showed that $\mathrm { C o } ^ { 2 + }$ has a certain degradation effect but it is lower than $\mathrm { C o F e _ { 2 } O _ { 4 } / P A A }$ system, and the activation effect of $\mathrm { F e } ^ { 2 + }$ on PAA is not obvious. # 3.6 Reusability and stability of $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 } / \mathsf { C u O }$ catalyst

Fig. 8 shows the effect of the catalyst $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ activated PAA to remove SMX after multiple uses. It can be seen that after the second recovery, the removal rate of SMX by $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ activated PAA decreased but still had $89 \%$ removal rate at 10 min. After the third recovery, the removal rate of SMX decreased again compared with the second time, and the removal rate of SMX was also $8 5 \%$ at $1 0 \mathrm { { m i n } }$ . This indicates that the rate of free radical generation by $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ activation of PAA decreases slightly after multiple recoveries because some of the reaction sites are occupied by contaminants, but it still maintains a good activation performance and shows a certain stability performance.

# 4 Conclusions

(1) The composite catalyst $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ with high activation performance was successfully prepared by the chemical precipitation method and sol-gel method. Compared with the oxidation processes of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } \ +$ PAA and $\mathrm { C u O } + \mathrm { P A A }$ , the removal rate of SMX by $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O + P A A }$ reached $9 2 \%$ at $9 0 \textrm { s }$ and reached the degradation balance, showing a faster degradation rate and higher removal rate than other oxidation processes, and $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ showed specific stability after multiple uses.

(2) The increase of catalyst dosage and PAA concentration improved the removal rate of SMX, but with the continuous increase of the two, their enhancement effect on the removal rate of SMX was weakened. The $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O \ + \ P A A }$ process showed a higher removal rate of SMX under neutral conditions. $\mathrm { C l ^ { - } }$ in this process would generate $\mathrm { C l } \bullet$ that promote the removal of SMX, and $\mathrm { H C O } _ { 3 } ^ { - }$ and HA would inhibit the removal of SMX by robbing free radicals.

(3) $\mathrm { C H } _ { 3 } \mathrm { C } ( = \mathrm { O } ) 0 \mathrm { O } ^ { \cdot }$ is the free radical that plays a dominant role in the degradation of SMX in the $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O _ { 3 } + \Delta P A A }$ process, and $\mathrm { C o }$ element is the dominant element in the process of $\mathrm { C o F e _ { 2 } O _ { 4 } / C u O }$ activating PAA to generate free radicals.
