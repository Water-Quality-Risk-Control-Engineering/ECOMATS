# INTRODUCTION

Environmental water pollution is a significant global problem, especially in the urbanized industrial centers. Accordingly, there has been growing interest in finding effective methods for wastewater purification in recent years.1 Among a wide range of catalytic methods, advanced oxidation processes $\left( \mathrm { A O P s } \right)$ have been gradually recognized as appealing techniques due to their high performance, low cost, and environmental friendliness. Candidate AOPs can be classified based on the catalysis and/or oxidation approaches that are employed, such as photocatalysis,68 ozone oxidation, Fenton/Fenton-ke oxidation. 12 Recently, the persulfate (PS)-based AOP has emerged as an appealing candidate for fast degradation and mineralizationoxiorganic pollutants.he eff this approach derives from the fast generation of sulfate $\left( \mathrm { S O _ { 4 } } ^ { \cdot - } \right)$ and hydroxyl radicals (·OH) with a high redox potential in the wastewater. However, a research challenge remains to develop low-cost environmental catalysts that promote highly efficient PS activation with little performance degradation over multiple reuses.

Metallic glasses (MGs), also known as amorphous alloys, have recently attracted significant research interest as excellent catalyst candidates for AOPs.2030 The outstanding performance of novel MG catalysts is attributed to their unique disordered atomic structures and their associated electronic structures.3133 For example, it was reported that FeSiBNb34 and MgZnCa351 MG catalysts present 200 and 1000 times higher catalytic activity than their annealed crystalline counterparts, respectively. Furthermore, Fe-based MG catalysts have been modified to exhibit phenomenal catalytic stability over 60-100 reuse cycles by introducing porous architecwork, we found that an FeSiBPC MG catalyst presents a strong electronic delocalization on the free surface through microalloying with P that facilitates excellent catalytic activity and blity    ol changes have the ability to alter the atomic and electronic structures of MG catalysts and their corresponding catalytic activity. Therefore, attention should be paid to understanding the mechanistic role of each active metal/metalloid element in MG catalysts to provide a pathway for the design of optimized compositions that will give novel and low-cost environmental catalysts with enhanced performance.

Boron (B) is a metalloid element that is proven to be highly beneficial for the design of MG catalysts. In addition to the large improvement $\mathrm { B }$ gives for glass-forming ability,3 41 the electronic states of B possess a well-distributed configuration in $1 s ^ { 2 } , \ 2 s ^ { 2 }$ and $2  { \mathrm { p } } ^ { 1 }$ The unique single electron around its $\mathtt { p }$ orbital has a very close radius with the 2s electrons and provides opportunities to form electronic orbital hybridization and multiple bonding chemistry in designed alloys. While the significance of B in enhancing the catalytic performance of Febased MGs has recently been identified,24,42 the detailed mechanism of how it alters the electronic structure to control the catalytic performance of Fe-based MG catalysts is not yet understood. To develop this mechanistic understanding, in this work, we produced two MG catalysts with the nominal atomic compositions of $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 } ,$ which were then employed in the PS-based AOP to degrade seven different organic pollutants. The primary purpose of this work is to determine how the B content regulates the electronic structure of these two MG catalysts. To achieve this goal, density functional theory (DFT) was employed to simulate the local atomic environment during PS activation in various organic pollutants. Additionally, quenching experiments were employed to help discern the mechanism of PS activation. Finally, an understanding of how sample reuse affects catalytic efficiency and stability, kinetic reaction rates $( k _ { \mathrm { o b s } } )$ and microstructural evolution has been developed.

# MATERIALS AND METHODS

Materials. High-purity $( 9 9 . 9 \% )$ elemental granules of iron (Fe), silicon (Si), and boron (B) were obtained from China Rare Metal Material Co., Ltd. and mechanically mixed to obtain the theoretical atomic compositions of $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ for the metallic glasses. The organic dyes used in this work were purchased from Xilong Chemical Co., Ltd. (China) and included rhodamine B (RhB), malachite green, methyl blue, methyl orange, brilliant yellow, brilliant red, eosin Y, and a mixture of the above seven dyes mixture in equal concentration. Analytical-grade chemicals, such as potassium persulfate (PS), ethyl alcohol (EtOH), tertiary butanol (TBA), and nitric acid $\left( \mathrm { H N O } _ { 3 } , 7 0 \mathrm { w t } \ \% \right)$ were supplied by Sigma-Aldrich. Milli- $\mathbf { \delta Q }$ water $\left( 1 8 . 2 \ : \mathrm { M } \Omega \cdot \mathrm { c m } \right)$ was employed throughout this work to dilute all of the concentrated chemicals and dyes.

Material Preparation. The two Fe-based MGs were manufactured using our previously reported physical metallurgical technique.43 -45 Specifically, two master alloy ingots $\left( \mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 } \right.$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 } )$ were prepared from the elemental mixtures by arc-melting under a Ti-gettered high-purity argon atmosphere. The arc-melting process was repeated at least four times to ensure a homogeneous distribution of the elements. Then, the ingots were mechanically cut into several small pieces and further remelted in the quartz crucible of a melt-spinning furnace under an argon atmosphere in the temperature range of $1 2 0 0 { - } 1 5 0 0 ~ ^ { \circ } \mathrm { C }$ The liquid alloy was then ejected onto a single rotating Cu wheel surface by a pressure difference. The rotational speed of the Cu wheel was $3 0 \mathrm { ~ m } / s$ to achieve rapid cooling of the ribbons down to room temperature.

Prior to the TEM characterization, the specimens were prepared by a standard lift-out technique using a focused ion beam/scanning electron microscope (FIB/SEM, FEI Scios, FEI). Surface morphology was examined using a scanning electron microscope (SEM, JSM-820, JEOL). Catalytic Measurements. Catalytic activity for the Fenton-like process was measured at temperatures ranging from $2 9 8 - 3 2 3 \mathrm { ~ K ~ }$ by employing the two as-spun Fe-based MGs as catalysts to activate PS for degradation of various dyes. The two MG ribbons were cut into 5 $\times 2 0 ~ \mathrm { m m }$ pieces with approximate thickness of $3 0 { - } 4 0 ~ \mu \mathrm { m }$ for use in the following catalytic investigations (Figure la). For each experiment, a $0 . 5 ~ \mathrm { g / L }$ dose of the as-spun Fe-based MGs was dispersed in $1 0 0 ~ \mathrm { m L }$ of dye solution with a $2 0 \ \mathrm { p p m }$ concentration. Afterward, PS with a concentration of $2 \mathrm { m M }$ was added to the dye solution to record the starting point of the catalytic experiment. Then, $4 ~ \mathrm { m L }$ of the target dye solution was taken out after different time intervals of 1, 2, 5, 10, 20, and $3 0 \ \mathrm { m i n }$ from the start of the experiment and immediately measured for absorbance using a UV—vis spectrometer. Equations 1 and 2 were employed for the calculation of the dye degradation efficiency $( X )$ and kinetic rate $( k _ { \mathrm { o b s } } ) _ { \mathrm { . } }$ ,respectively, for each of the various dyes. Dye degradation efficiency was calculated according to:

$$
X = \frac { C _ { 0 } - C } { C _ { 0 } } \times 1 0 0 \%
$$

where $C _ { 0 }$ and $C$ are the initial concentration and the concentration at time $t _ { r }$ respectively. The kinetic rate was calculated according to:

$$
\ln ( C _ { 0 } / C ) = k _ { \mathrm { o b s } } t
$$

where $k _ { \mathrm { o b s } }$ is the kinetic rate constant, $C _ { 0 }$ is the original concentration of the dye, and $C$ is the dye concentration at time t. Prior to each reuse experiment, the used Fe-based MGs were carefully washed by Milli $\mathrm { \bf Q }$ water and ethanol three times to remove any adsorbed substances on their surfaces. Finally, for the quenching experiments, TBA and EtOH were added at a concentration of $0 . 5 \ \mathrm { ~ M ~ }$ at the beginning of the degradation experiments for investigating the roles of hydroxyl (·OH) and sulfate radical $( \mathrm { S O } _ { 4 } ^ { \cdot - } )$ production, respectively.

Density Functional Theory Simulations. Density functional theory (DFT) simulations were employed to acquire a mechanistic understanding of the catalytic performance of the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs. The calculations were conducted using the Cambridge Sequential Total Energy Package (CASTEP) module in Materials Studio. The exchange and correlation interactions between atoms were described by the generalized gradient approximation with the Perdew—Burke—Ernzerhof functional.46 The ultrasoft pseudopotential method implemented in CASTEP was adopted to describe the interactions between valence eectrons and ionic cores.The cf energy of the plane wave basis set was $3 0 0 ~ \mathrm { e V } .$ A $\Gamma$ point was used to sample the Brillouin zone for the amorphous system. The tolerances for acceptable convergence of the total energy and displacement were $1 0 ^ { - 5 }$ eV/atom and $0 . 0 0 2 \mathrm { ~ \AA ~ } ,$ respectively. The self-consistence field was specified as $1 0 ^ { - 6 } \mathrm { e V } /$ aom. The intial confgurations of $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ contained 200 atoms in a cubic supercell with periodic boundary conditions along three directions. The initial positions of the atoms were randomly assigned to construct amorphous atomic configurations. Next, ab initio molecular dynamics was employed to achieve accurate atomic configurations for the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs. All calculations were conducted under isothermalisobaric (NPT) or canonical (NVT) conditions, as described below. Temperature was controlled by a Nose-Hoover thermostat. Specifically, the models were first kept at $2 0 0 0 ~ \mathrm { K } ,$ i.e., far above the melting point, for 6 ps with a time step of 3 fs under the NVT ensemble to ensure that the atomic structure was well relaxed and any artifacts were removed. After relaxation, the models were quenched in two steps under NPT conditions: first to $1 0 0 0 \mathrm { ~ K ~ }$ at $2 . 5 \dot { \times } 1 0 ^ { 1 3 } \mathrm { ~ K } / s$ and then to $3 0 0 ~ \mathrm { K }$ at $2 . 0 \times 1 0 ^ { 1 3 } \mathrm { K } / s$ Finally, the models were kept at $3 0 0 \mathrm { ~ K ~ }$ for 3 ps under NVT conditions, followed by a structure optimization. In order to obtain the surface property of the models, a 20 Å-thick vacuum layer was introduced along the surface. After optimizing the atomic configurations once again, the adsorption energies of the ion $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 + } \left( \Delta E _ { \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 + } } \right)$ onto the surfaces of each MG were simulated to evaluate the difference in the adsorption capability between $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ The $\Delta E _ { \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 + } }$ at the surface of the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs was calculated by eq 3:

$$
{ \Delta E _ { \mathrm { S _ { 2 } O _ { 8 } } ^ { 2 + } } = E _ { \mathrm { s u r f + 5 _ { 2 } O _ { 8 } } ^ { 2 + } } - E _ { \mathrm { s u r f } } - E _ { \mathrm { S _ { 2 } O _ { 8 } } ^ { 2 + } } }
$$

where $E _ { \mathrm { s u r f } }$ and $E _ { \mathrm { s u r f } +  { \mathrm { S } } _ { 2 }  { \mathrm { O } } _ { 8 } ^ { 2 + } }$ are the total energies of the system before and after the adsorption of $S _ { 2 } { \mathrm O } _ { 8 } ^ { 2 + }$ at the surface of the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs, respectively, while $E _ { \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 + } }$ is the energy of a free ${ \mathsf { S } } _ { 2 } { \mathsf { O } } _ { 8 } { } ^ { 2 + }$ ion.

Microstructures and Chemical States. Figure 1a shows optical images of the as-spun MG ribbons. The prepared MG ribbons are flexible and could be bent to any shape or direction for device applications. The amorphous nature of the two as-spun Fe-based MGs is confirmed by XRD (Figure 1b) in which only broad diffuse diffraction peaks are observed and no crystalline peaks are detected. Since XRD cannot detect fine nanocrystals, the amorphous nature at the nanoscale is further confirmed by HRTEM and corresponding SAED images. Catalytic Mechanisms (DFT Simulation). To better understand the difference in catalytic performance of the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs, DFT calculations were employed to reveal the fundamental mechanism at the atomic scale. Figure S4 shows DFT results on the partial density of states (PDOS) for Fe, Si, and B in each MG, and it is noted that an enhancement of electron delocalization is observed for the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MG. Thus, one role of slightly higher B content is to better promote electron transfer to enhance the persulfate activation during the degradation of organic pollutants.38 In addition, the work function was analyzed to directly uncover the relative capability of electron transfer from the surfaces of the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs. As shown in Figure S5, the average electrostatic potentials demonstrate a lower work function value of $3 . 5 1 \mathrm { e V }$ for the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MG relative to 3.55 $\mathtt { e V }$ for the $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MG, indicating that the activation of electrons from the surface of $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ is easier than that of $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ This result is also in perfect agreement with the EIS measurement in Figure 3b. Furthermore, the difference of electronic property closely relates to the variation of atomic configurations. The radial distribution function (RDF) clearly shows that more B content results in the elongation of the $\mathrm { F e - }$ B and Fe-Fe bonds (Figure S6). Bond elongation implies a reduction of electronic interactions and thus benefits the electron transfer during catalysis. 54

The adsorption characteristics were also analyzed to unravel the interaction between the ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 + }$ ions and the MG catalysts. To determine the most energetically favorable adsorption site of the ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 + }$ ion onto the surface of $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs, a series of adsorption sites were compared by setting different initial orientations and positions of the $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 + }$ ion. It was found that the Fe atom is the active adsorption site based on the local adsorption configurations shown in Figure 8 in which the O atoms in ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 + }$ are preferentially bound with Fe atoms. The adsorption energy $( \Delta E _ { \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 + } } )$ for the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MG is $4 . 2 3 3 \ : \mathrm { e V }$ , which is higher than the value of $3 . 9 8 1 ~ \mathrm { e V }$ for the $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MG, demonstrating that the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MG has a better adsorption capability for $\mathrm { { \bar { S } } } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 + }$ ions. In addition, the local electron density difference between the $\mathrm { F e - O }$ adsorption pair indicates that the electron transfer for the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MG is more significant, leading to a shorter atomic distance between the Fe and $\mathrm { o }$ atoms (Figure 9). Moreover, the corresponding PDOS of Fe and O atoms is further calculated in Figure 10. It was found that the d electronic orbital of Fe atoms hybridizes with the $\boldsymbol { \mathrm { p } }$ electronic orbital of $\mathrm { o }$ atoms for $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ after $S _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 + }$ adsorption. In particular, the interaction between Fe and O atoms in $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MGs is much stronger than that in $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ MGs, further evidencing the significant function of electronic regulation through the slightly higher B content. Consequently, as depicted in Figures $^ { 8 - 1 0 }$ and Figures S4-S6, our collective DFT results indicate that the relative catalytic performance of Fe-based MG catalysts can be predicted by understanding their corresponding electronic structures and key factors include the length of bonds, the coordination environment of metallic/metalloid atoms, the work functions, the electron orbital hybridization and distribution, the density of electronic states, etc. Thus, future research studies can focus on the screening of underlying atomic compositions in the catalysts via computational methods that examine their electronic structures, a method that we expect will facilitate the design of new novel catalysts with improved performance for practical water treatment applications.

# CONCLUSIONS

In this work, we have demonstrated how a slight increase in boron content in iron-based MGs regulates the electronic structure to enhance the catalytic performance. Compared to the composition $\mathrm { F e } _ { 8 0 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 1 }$ a 2.0 atom $\%$ increase in boron to create a metallic glass with composition $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ gives rise to improved catalytic efficiency and stability for the degradation of various organic pollutants. The improved catalytic performance is attributed to the increased percentage of $\mathrm { F e - B }$ atomic coordination that results in enhanced surface electronic delocalization, stronger persulfate adsorption energy, and a narrower work function with higher B content. In addition, the higher proportion of $\mathrm { F e - B }$ atomic coordination in the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MGs enables faster electron transfer ability on the reactive interface that further promotes the persulfate being activated to hydroxyl radicals (·OH) and sulfate radicals $( \mathrm { S O } _ { 4 } ^ { \cdot - } )$ for rapid degradation of organic molecules. The catalytic efficiency and stability of the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MG are excellent; indeed, complete degradation can be achieved within $3 0 ~ \mathrm { m i n }$ for seven different organic pollutants and the MG can be reused up to 23 times without significant deterioration. It is noteworthy that our employed melt-spinning technique can produce the MG ribbons at an industrial scale in tons with very low cost. Thus, the present results provide a new roadmap for compositionally designing a new-generation of environmental catalysts that are low-cost and scalable while providing high performance and great potential for practical wastewater treatment applications.
