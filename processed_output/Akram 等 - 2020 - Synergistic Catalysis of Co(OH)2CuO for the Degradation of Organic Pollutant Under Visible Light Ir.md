# Synergistic Catalysis of Co(OH)2/CuO for the Degradation of Organic Pollutant Under Visible Light Irradiation

Naeem Akram , Jia Guo, Wenlan Ma, Yuan Guo, Afaq Hassan & Jide Wang\*

The exploration of advanced water treatment technologies e.g. heterogeneous photocatalysis is the most promising way to address organic pollution issues. Semiconductors based bimetallic photocatalysis with wide bandgap, have displayed splendid degradation performance in the UV light region, but their extension to the visible light/near infra-red region is still a matter of great concern. CuO, $\mathsf { C o ( O H ) } _ { 2 } , \mathsf { C o o }$ and $\mathsf { C o ( O H ) } _ { 2 } / \mathsf { C u o }$ nanocomposites were synthesized via simple co-precipitation method and further practiced for Rhodamine B (RhB) decomposition by introducing per-sulfate (PS) as a sacrifcial agent. Results revealed that $\mathsf { C o ( O H ) } _ { 2 } / \mathsf { C u o }$ catalyst had shown robust catalytic activity for RhB photodegradation (degradation time 8min, $\mathbf { k } = 0 . 8 6 4 \mathop { \operatorname* { m i n } } ^ { - 1 } ,$ ) under light illumination, signifcantly less (12–60 times) than the other reported bimetallic catalysts. Catalyst also have verifed excellent performance for a broader pH range (5–9) with excellent stability. Main reactive species responsible for the photocatalytic reaction were sulfate $( \mathsf { S O } _ { 4 } ^ { \bullet - } )$ and superoxide $( \mathsf { O } _ { 2 } ^ { \bullet } )$ radicals, duly verifed by ESR and by using radical scavengers. With outstanding recycling abilities, this is probably the fewer successful attempt for RhB decolorization and can be highly favorable for efuent treatment by using the synergic efect of absorption and photodegradation.

Globally increased population resulting in escalating environmental pollution, particularly, water contamination is consistently grabbing attention of researchers to overcome the needs of clean and safe water sources, for many decades1 . Ever-increasing garbage and efuents of many industries especially the usage of synthetic dyes in textile, tannery, paint, and paper industries are continuous sources of contaminated water2 . Releasing these dyes into the water sources, afecting aquatic life, ecosystems and human beings, adversely3 . Tus, the exploration of new and efective ways to overwhelmed organic water pollution issues is always considered as challenging. Many biological, physical, chemical, electrical and electrochemical methodologies have been developed, so far, for the removal of organic matter4 . From these methodologies, advanced oxidation processes (AOPs) have been extensively employed because of their simple, efcient and feasible approach. Amongst AOPs, heterogeneous photocatalysis has remarkable potential for organic pollutant removal, also has eco-friendly behavior, good stability, efcient photocatalytic activity for various dyes and most advantageously their economical and simple synthesis5 . Many techniques including sol-gel6 , co-precipitation7 , soluble sacrifcial salt template8 , solvothermal9 and microwave-assisted approach10 have been extensively attempted for the synthesis of facile and economical metallic catalysts.

Rhodamine B is a widely used colorant in dyeing, textiles and food sectors, although it’s banned, but still practiced in food factories, and also a good water tracer fuorescent11. Te carcinogenicity of RhB causes serious irritation of the skin, eyes and respiratory tract toward living beings12, so the development of a degradation system is always in demand to overcome water pollution issues by degrading organic pollutants. Many chemical, electrochemical, and photochemical ways, for example heterogeneous Fenton like photodegradation13,14, adsorption, microwave-assisted degradation, LED assisted catalysis and photodegradation with/without oxidants under diferent light sources, were practiced15–21. All afore-mentioned methodologies have some limitations such as usage of expensive materials, higher operational cost, longer degradation time and incomplete degradation.

Te wide bandgap metallic oxides (CuO, $\mathrm { T i O } _ { 2 }$ ) have presented splendid decolorization abilities in the UV light region (only $4 \%$ of the solar energy)22,23, but their extension to the visible light or near infra-red (IR) region is still a matter of great concern. Te performance of a photocatalyst for photodegradation reaction is strongly depended on the number of active sites developed on the surface of the catalyst, light absorption ability (band gap), and the electron-holes $( \mathrm { e ^ { - } h ^ { + } } )$ generation/transfer efciency of the catalyst24. Transition metals have great potential with their higher bandgap energy, $( \mathrm { e ^ { - } h ^ { + } } )$ generation and larger surface area for the degradation of organic matter.

Nanoparticles have some salient features such as simple and economical synthesis procedure, high surface area, good stability and easy recovery. Tese properties make them more favorable than other synthesis strategies of catalysts. Bimetallic nanoparticles have accomplished much attention because of their enhanced solid-state properties as well as they have better photocatalytic efciency than their monometallic precursors25. Metals alloying over other semiconductor materials are consistently reported, in lieu of more active hetero-catalyst. Copper doped $\mathrm { T i O } _ { 2 } /$ polythiophene $\mathrm { ( P T h ) ^ { \mathrm { 1 1 } } }$ , $\operatorname { C u } @ \operatorname { A g }$ , $\mathrm { C u } _ { 2 } \mathrm { O } { \cdot } \mathrm { A g } ^ { 2 \dot { 6 } }$ , Cu-doped $Z _ { \mathrm { { n O } / Z _ { \mathrm { { n O } } } } }$ heterostructures27, $\mathrm { Z n O / C u O }$ heterojunction28, $\mathrm { C u C o } _ { 2 } \mathrm { O } _ { 4 } ^ { 2 9 }$ , $\mathrm { C u O }$ nanowires and nanorods23, and $\mathrm { { \bar { C } o _ { 3 } O _ { 4 } / F e _ { 2 } O _ { 3 } } ^ { 3 0 } }$ were the diferent hybrid catalysts employed for the photodegradation reactions.

Copper and cobalt are two abundantly available semiconductor materials. Copper-based catalysts have excellent absorption properties in UV-region but cannot be practiced under visible light spectrum just because of their wide bandgap23,31. On the contrary, cobalt metallic centers have verifed tremendous optical absorbance abilities in the visible light region, so, cobalt doping can be considered as a good tuner of the electro-optical properties of a bimetallic catalyst32. For instance, 3D continuous $\mathrm { P P y } @ \mathrm { M n C o } _ { 2 } \mathrm { O } _ { 4 } / \mathrm { G N F }$ nanoarchitectures and $\mathrm { C o - N i } _ { 3 } \mathrm { S } _ { 2 } @ \mathrm { C N T s } /$ GNF hybrid are Co doped composites, resulting in high specifc capacitance alongwith excellent cycling stability for efcient HER electrocatalytic activity33,34.

UV-Vis/PS/heterogeneous photocatalysis is a relatively new, promising and the most efective technique for the removal of recalcitrant organic pollutants35,36, comparatively lower in operational cost and better photolysis abilities than the other oxidants such as PMS, PDS, per-iodate and $\mathrm { C e } ( \mathrm { N O } _ { 3 } ) _ { 4 } { } ^ { 3 7 - 4 0 }$ . UV-Vis/PS oxidation process is successfully practiced in water oxidation reactions (WORs), degradation of p-chloroaniline and aniline, degradation of, phenol, propachlor atrazine41–44. Te aforementioned catalysts had some limitations, such as unpractical pollutant degradation time (usually $> = 1 0 0$ minutes), narrow or precised $\mathrm { p H }$ , and higher catalyst cost upon noble metals coupling, to their commercial applications.

Te prime objective of this work was the development of an optimum, simple, relatively cheaper and efective technique for the degradation of RhB dye. To achieve this goal, shuttle-like $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ nanoparticles were successfully synthesized by the simple co-precipitation method. $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ nanocomposite/PS system under visible light was successfully practiced for the removal of RhB dye within a short time interval for a broader $\mathrm { p H }$ range $\mathrm { ( p H 5 - 9 ) }$ with excellent stability. Crucial parameters and recycling ability of $\mathrm { C o ( O H ) _ { 2 } / C u O }$ hybrid was also investigated. Te reaction mechanism of $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ catalyst for the elimination of reluctant organic pollutant was also systematically explored.

Catalytic performance of $\mathsf { C o ( O H ) } _ { 2 } / \mathsf { C u O }$ catalyst. Te adsorption of organic molecules on the surface of photocatalysts had been verifed to infuence greatly the photocatalytic degradation of the organics45. To investigate adsorption and degradation mode, the catalytic performance of $\mathrm { V i s / P s / C o ( O H ) _ { 2 } / C u O }$ catalyst based system was practiced by selecting (RhB) dye as a model pollutant. To ensure visible light only for degradation system, a cut flter of ${ > } 4 0 0 \mathrm { n m }$ was used. Initially, the catalyst was adsorbed in RhB solution for 20 minutes under dark conditions to investigate the efect of adsorption, afer that, this system was subjected under Vis-light with the addition of PS for photo-decolorization. No obvious adsorption was observed, while for the case of photodegradation, $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ catalyst was found best amongst all other compositions so, for the rest of the study it will be described.

UV-Vis absorption spectrum in Fig. 2 revealed that decolorization for $\mathrm { V i s / P s / C o ( O H ) _ { 2 } / C u O }$ based photocatalytic system was approached to $3 3 . 5 \%$ in 2 minutes under visible light illumination and afer 8 minutes, dye concentration was approached to $0 . 0 1 0 5 \mathrm { m g / L }$ from $\mathrm { 1 0 0 m g / L }$ . In order to regenerate catalyst, the degraded solution was allowed to settle all the catalyst for two hours, afer that, it was seperated and was named as $\mathrm { R - C o ( O H ) _ { 2 } / C u O }$ catalyst. Further, similar reaction systems for without $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst, without persulfate, and without light were also practiced.

Performance optimization of $\mathsf { C o ( O H ) } _ { 2 } / \mathsf { C u o }$ catalyst for photolysis reaction. Te normalized concentration of degraded dye was studied by varying diferent parameters e.g. concentration of dye, the dosage of bimetallic catalyst, per-sulfate dosage, and the initial $\mathrm { p H }$ of the solution. Under optimized conditions binary metal oxide $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst has proved itself better than the single metal oxides (CuO, CoO and ${ \mathrm { C o } } ( { \mathrm { O H } } ) _ { 2 } )$ for photodegradation. Tis bimetallic oxide is also superior in its actions because of the crucial role played by Cu having extraordinary abilities to degrade many azo dyes. While on the other hand Co absorbs light and resulting in the generation of electron and hole pairs1 , so, the combined efect of $\mathrm { C u }$ and Co oxides posed better photo-decomposition activity.

Figure 3(a–d) illustrates the behavior of four key parameters, that are the initial $\mathrm { p H }$ of the system, PS dosage, initial dye concentration (D.C) and catalyst dosage (C.D), playing a vital role in photodegradation reaction. Four diferent initial concentrations (25, 50, 75 and $\mathrm { 1 0 0 m g / L }$ ) were practiced during this study and $1 0 0 \mathrm { m g / L }$ was selected for further studies. From $5 \mathrm { m g }$ to $2 0 \mathrm { m g }$ , four diferent catalyst dosages were studied and $2 0 \mathrm { m g }$ was preferred for further studies as it had better degradation results in lesser time.

PS plays an important role in the photodegradation of organic pollutants by providing active sites and a platform for the exchange of electrons during reacting with catalyst, so, alike the absence of the catalyst, the absence of PS also did not permit photodegradation reaction. For optimum PS dosage, diferent persulfate quantities $( 1 0 \mathrm { m g } , 1 5 \mathrm { m g }$ and $2 0 \mathrm { m g }$ ) were studied and $2 0 \mathrm { m g } \mathrm { P S }$ dosage was observed as most suitable for further studies. Further increase in PS dosage may cause a reduction in organic matter degradation probably because of a faster and instantaneous generation of sulfate radicals $\mathrm { ( S O _ { 4 } ^ { \bullet - \cdot } ) }$ ) and they can react with each other to form per-sulfate as per following reactions46.

Usually, basic $\mathrm { p H }$ solutions or acidic $\mathrm { p H }$ solutions were reported for RhB degradation, as their catalysts had evidenced that their best performance was either in acidic or in basic media47,48. Terefore, diferent $\mathrm { p H }$ solutions were monitored to observe the efect of initial $\mathrm { p H }$ and fortunately $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ has performed well for a variety of pH (3–13) solutions. More specifcally for neutral $\mathrm { p H }$ or the nearly neutral $\mathrm { p H }$ either slightly acidic $\mathrm { ( p H } = 5$ ) or slightly basic $\displaystyle \left( \mathrm { p H } = 9 \right)$ ), bimetallic oxide had exhibited excellent photo-decolorization performance. But neutral $\mathrm { p H }$ was selected for further studies as it posed the best photo decolorization.

For photolysis, the bandgap energy of a catalyst allows the generation of the electron-hole pair at conduction and valence band respectively. Excitation of electron takes place from the valence band to conduction band when absorption of light takes place. In this work PLS-SXE300D, a high power xenon light source, with a cut flter of ${ > } 4 0 0 \mathrm { n m }$ , was used for the excitation of electrons, responsible for the generation of diferent radicals taking part in the photodegradation of RhB.

Under optimum conditions, CoO and ${ \mathrm { C o } } ( \mathrm { O H } ) _ { 2 }$ had $1 3 \%$ and $9 . 1 3 \%$ catalytic activities for RhB degradation respectively, while both $\mathrm { { c u O } }$ and $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst displayed excellent activity with diferent degradation time. Almost $9 9 . 9 \%$ RhB was degraded with $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst by lowering RhB concentration from $1 0 0 \mathrm { m g / L }$ to $0 . 0 1 0 5 \mathrm { m g / L }$ in presence of light, that is, obviously because of synergistic efect between $\mathrm { { c u O } }$ and ${ \mathrm { C o } } ( \mathrm { O H } ) _ { 2 }$ . Radical identification. The activation of sodium persulfate (PS) in the heterogeneous catalysis could produce $\mathrm { S O _ { 4 } ^ { \bullet - } }$ , HO• and/or $_ { \mathrm { ~ \normalfont ~ O ~ } _ { 2 } ^ { \bullet } }$ radicals. In order to identify the radicals generated during the photocatalytic reaction and their role in photocatalysis, electron spin resonance (ESR) technique was adopted, 5,5-Dimethyl1-Pyrroline-N-Oxide (DMPO) was used as the radical capture agent. ESR results evidenced that sulfate $( \mathrm { S O } _ { 4 } ^ { \bullet - } )$ ), Superoxide $( \mathrm { O } _ { 2 } ^ { \bullet } )$ and hydroxyl (HO• ) radicals were generated during $\mathrm { V i s / P s / C o ( O H ) _ { 2 } / C u O }$ based photocatalysis system and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and $_ { \mathrm { ~ \normalfont ~ O ~ } _ { 2 } ^ { \bullet } }$ radicals were mainly responsible for the photocatalytic dye degradation. Figure $\mathbf { 4 } ( \mathrm { a , b } )$ clearly demonstrated that the most dominant radical was $\mathrm { S O _ { 4 } ^ { \bullet - } }$ radical while $_ { \mathrm { ~ \normalfont ~ O ~ } _ { 2 } ^ { \bullet } }$ has an intermediate role in the photocatalysis process. Te role of hydroxyl (HO• ) in the photocatalytic reaction is almost negligible. Te efect of light for activation of radicals generated from PS based heterogeneous catalysis was also highlighted by ESR spectra. Initially, under dark conditions, there were few radicals but when the catalytic system was exposed to light the radical’s generation was more and more with an increase in time.

Te results claimed by ESR were also verifed by introducing three diferent radical quenching reagents. Methanol (MA), Chloroform $\mathrm { ( C H C l _ { 3 } ) }$ ) and tert-butyl alcohol (TBA) were studied as quenching agents for $\mathrm { S O _ { 4 } ^ { \bullet - } }$ , $\mathrm { O } _ { 2 } ^ { \bullet }$ and $\mathrm { H O ^ { \bullet } }$ radicals respectively. Methanol (MA) with $\alpha$ -hydrogen was selected as probe agent for capturing both hydroxyl and sulfate radicals at signifcant rates $( \mathrm { k } \mathrm { S O _ { 4 } } ^ { \bullet - } / _ { \mathrm { M A } } = 1 . 6 \mathrm { - } 7 . 7 \times 1 0 7 \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 }$ , $\mathrm { k } \mathrm { H O ^ { \bullet } } / _ { \mathrm { M A } } = 1 . 2 -$ $2 . { \overset { \cdot } { 8 } } \times 1 0 9 { \overset { \cdot } { \mathrm { M } } } ^ { - 1 } { \overset { \cdot } { \mathbf { s } } } ^ { \cdot } { \overset { \cdot } { \mathrm { 1 } } } )$ ), while, TBA without $\alpha$ -hydrogen was chosen as a probe agent for studying the reaction of hydroxyl radicals $( \mathrm { k _ { \mathrm { ~ H O ^ { \bullet } / T B A } } } = 3 . 8 – 7 . 6 \times 1 0 8 \mathrm { M ^ { - 1 } } \mathrm { s ^ { - 1 } } )$ . On the other hand, $\mathrm { C H C l } _ { 3 }$ was used as a scavenger for superoxide $( \mathrm { O } _ { 2 } ^ { \bullet } )$ radicals50. Te role of these three radicals played during $\mathrm { V i s / P s / C o ( O H ) _ { 2 } / C u O }$ based photocatalysis was also explored by these quenching reagents.

In the reaction system, all the radical scavengers were 10 times more concentrated than the PS concentration. Figure 4(c), clearly demonstrated that a signifcant diference was observed in the photolysis results of tert-butanol alcohol, chloroform, and methanol. RhB degradation was signifcantly reduced at the addition of methanol because it had breached photocatalytic reaction immediately on its addition to the reaction system by eliminating sulfate and hydroxyl radicals. At 10 equivalent addition of TBA, the photodegradation was slightly decreased $( 9 6 \% )$ , the absence of $\alpha$ -hydrogen in TBA has a fewer efect on the generation of sulfate radicals, that’s why the photodegradation rate was not signifcantly infuenced. At the addition of $\mathrm { C H C l } _ { 3 , }$ the generation of superoxide radicals was inhibited, an ultimate reason to slow down the photodegradation process and as a result efciency of the photocatalytic system was decreased to $6 4 \%$ . Tis claim was also evidenced by Fig. 4(d), as it was clearly demonstrated that, under controlled reaction conditions when there wasn’t any radical scavenger, the rate constant (k) was much higher than in the presence of any scavenger. Hence, as a result, it was verifed that $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and $_ { \mathrm { ~ \normalfont ~ O ~ } _ { 2 } ^ { \bullet } }$ radicals had a lead role in this photolysis system.

From Fig. 5(a) it is clear that the main difraction peaks of $\mathrm { { c u O } }$ and ${ \mathrm { C o } } ( { \mathrm { O H } } ) _ { 2 }$ for recycled catalyst have no obvious shif comparative to XRD patterns of fresh bimetallic oxide, indicating that $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ catalyst is highly efcient and stable during photolysis of RhB dye. For recycled ${ \mathrm { C o } } ( \mathrm { O H } ) _ { 2 } /$ CuO, even afer the 6th run, the main and satellite peaks of Cu and Co were consistent with the main and satellite peaks of fresh $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst. Te bimetallic catalyst synthesized in this work has high selectivity and reproduction abilities. Form Fig. 5(b), the stability and reusability of the $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst was verifed for the photocatalytic reaction. Te recycling of as-synthesized catalyst was observed in six successive runs to patterned its regeneration and sustainability.

Mechanism and reaction pathway. Heterogeneous semiconductor photocatalysis allows both reduction and oxidation state to take place at the same time on its surface. Te PS based mechanism for activating heterogeneous catalysts have been broadly studied in water treatment51. Te mechanism of heterogeneous photocatalysis can be explained by the Langmuir–Hinshelwood kinetic technique i.e. basically the simultaneous generation of electrons $( { \mathsf { e } } - )$ and holes $( \mathrm { h } + )$ under light irradiation. Tese holes are then trapped by the catalyst surface absorbed organic pollutants for the production of a radically reactive state which was recombined with a photogenerated electron to decompose the pollutant. Subsequently, the regeneration of catalyst takes place that can be further used52. A schematic illustration of a possible mechanism for photodegradation of rhodamine B by activating $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ catalyst bimetallic catalyst with PS under visible light was proposed as shown in Fig. 6. A similar illustration was already reported with $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and HO• as dominant species in their Fenton like reaction system47.

At frst, the ${ \mathrm { C o } } ( \mathrm { O H } ) _ { 2 }$ was excited under visible light irradiation and generated photoexcited electrons $\left( \mathrm { e } ^ { - } \right)$ and holes $\left( \mathrm { h ^ { + } } \right)$ . Tese photoexcited electrons contributed to decomposition reaction by reacting with PS to generate $\mathrm { S O _ { 4 } ^ { \bullet - } }$ radicals having a major contribution to degradation reaction. While holes reacted with $_ \mathrm { H } _ { 2 } \mathrm { O }$ to produce superoxide $( \mathrm { O } _ { 2 } ^ { \bullet } )$ radicals. In photocatalytic reaction superoxide $( \mathrm { O } _ { 2 } ^ { \bullet } )$ radicals although posed less role than sulfate $\mathrm { S O _ { 4 } ^ { \bullet - } }$ radicals but still playing a vital role in the photodegradation of RhB. Such cyclic production of these radicals progressively increases the photocatalytic degradation activity of bimetallic catalysts towards organic pollutants.

Te reaction pathway was also systematically explored by using HPLC-MS. Mainly six intermediates (A-F) were found to be involved by HPLC-MS chromatograms, at diferent retention times during RhB decolorization with v $\mathrm { i s / P s / C o ( O H ) _ { 2 } / C u O }$ based photocatalyst. From the results as tabulated in Table S4, it’s clear that frst peak i.e. A at retention time $\left( \mathrm { { t _ { R } } } \right)$ 9.8 min purely belongs to RhB, while peak B $\left( \mathrm { t _ { R } } 1 1 . 6 \mathrm { m i n } \right)$ , C $\left( \mathrm { t _ { R } } 1 3 \mathrm { m i n } \right)$ , and D $\mathrm { \Delta t _ { R } }$ $1 3 . 3 \mathrm { m i n }$ ) were species identifed as N-de-ethylated intermediates in positive $\mathrm { ( + i v e ) }$ ion mode, while derivative of RhB at peak E $\left( \mathrm { t _ { R } } 1 9 . 2 \mathrm { m i n } \right)$ and $_ \mathrm { H }$ $\mathrm { ' t _ { R } } 2 2 \mathrm { m i n } )$ were identifed as benzoic acid, phthalic acid were in negative (−ive) ion mode. Te structural formulae of N-de-ethylated intermediates with their accurate mass and $\mathbf { M } ^ { + }$ peaks were also discussed in Table S4. Te rapid decrease in the intensity of peak A (RhB) can be observed afer a reaction time of $2 \mathrm { { m i n } }$ , on contrary, there was an increase in the peak of intermediates (B–E) initially but decreased shortly due to their conversion into F intermediate.

A-F intermediates underwent ring-opening and mineralization, as a result, the production of biodegradable small molecular acids took place. N-de-ethyl group on the dye molecule was immediately approached by the $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and $_ { \mathrm { ~ \normalfont ~ O ~ } _ { 2 } ^ { \bullet } }$ radicals, as a result, ring-opening and mineralization occur and subsequently, it led to the formation of (A-F) intermediates. Ring-opening step further resulting in the formation of some small molecular weighted biodegradable acids under continuous reaction. Te ring-opening and partial mineralization pattern can be verifed by many reported works such as recently reported work of Wenxing Chen and co-workers53. # Conclusion

$\mathrm { C o ( O H ) _ { 2 } / C u O }$ nanocomposite was prepared by a simple co-precipitated process and was examined by diferent analytical techniques. $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ catalyst was optically active, having the synergic efect of cobalt hydroxide modifcation on copper oxide, and posed excellent potential application towards organic pollutants degradation in the visible light region. Tis work mainly emphasizes the performance of newly synthesized $\mathrm { C o ( O H ) } _ { 2 } / \mathrm { C u O }$ catalyst and efect of initial $\mathrm { p H }$ of the solution on the photocatalysis reaction and it’s an achievement to degrade RhB not just in under neutral pH but also for basic or acidic $\mathrm { p H }$ (5–9) in such a shorter time with $\mathrm { C o ( O H ) _ { 2 } / C u O / }$ PS/Vis-Light based system. Mechanistic studies had explored that sulfate radicals and superoxide radicals were the key radicals responsible for the photolysis of RhB. HPLC and GC results suggested that partial degradation of pollutant into $\mathrm { C O } _ { 2 }$ and water tookplace. Most importantly, the regeneration of bimetallic catalyst is quite facile and have excellent $( 8 2 . 8 7 \% )$ recyclability even afer six consecutive runs. Te XRD and XPS measurements of $\mathrm { R - C o ( O H ) _ { 2 } / C u O }$ catalyst strongly recommend that the catalyst posed good stability. Also, $\mathrm { C o ( O H ) _ { 2 } / C u O }$ catalyst has verifed its tendency for the degradation of many organic pollutants.

Tus, conclusively this bimetallic nanocomposite photocatalyst can be highly recommended for accomplishing photocatalysis in favor of health observations and polluted water resources, by keeping in view its simple synthesis procedure and less degradation time for the decomposition of toxic organic matters.

Ground the dried product and calcinate it in an inert $( \Nu _ { 2 } )$ environment, at $4 0 0 ^ { \circ } \mathrm { C }$ for 2 hours with a heating rate of $1 0 ^ { \circ } \mathrm { C } . \mathrm { m i n } ^ { - 1 }$ .
