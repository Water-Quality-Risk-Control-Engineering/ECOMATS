# . Introduction

Long-term mining activities have caused serious pollution in the environment, which is the inevitable result of the economic development and social demand for mineral products. Mining pollution not only contains various metal(loid)s, but it also contains a large number of mineral organic flotation reagents [1,2]. BTA, an emerging contaminant, is widely applied to extraction of minerals [35]. However, this compound is a proven endocrine disruptor which is also resistant to biodegradation [6]. Due to its high toxicity, carcinogenicity and teratogenicity $\mathrm { { C r } ( V I ) }$ is one of the most toxic pollutants in the mine environment [7]. Cr(III) is thermodynamically the most stable oxidation state of this element, kinetically inert, and significantly less toxic [8]. Therefore, development of a highly efficient system that is able to degrade organic flotation reagents and simultaneously reduce $\mathrm { C r } ( \mathrm { V I } )$ to Cr(III) is imperative.

Peroxydisulfate (PDS; $S _ { 2 } 0 _ { 8 } ^ { 2 - \cdot }$ based advanced oxidation processes (AOPs) have been widely employed for elimination of organic pollutants from wastewater [9,10]. However, homogeneous AOPs usually suffer from some drawbacks that lower their efficiency and limit their application [11,12]. In order to overcome the difficulties encountered in the application of homogeneous AOPs, various heterogeneous catalysts have been developed so far [13,14]. However, most of them are limited to laboratory studies or small trials. Furthermore, most of them are unacceptable for large-scale pollution remediation due to the high cost and hidden danger of secondary pollution. In that respect, a more sensible option would be to use iron-bearing solid waste as a heterogeneous Fenton catalyst. One of the potential candidates to be used for this purpose is CS, a by-product of the copper flotation and refining [15,16].

Despite the widespread utilization of heterogeneous catalysts, the decomposition rate of PDS is still very low due to the inefficiency of Fe (III)/Fe(II) cycle. Many efforts have been made to improve the inefficient transformation of Fe(III) to Fe(II). Some of them involved addition of various organic ligands [17,18], organic carboxylic acids [1921] or polyphenols [22,23]. In comparison with organic co-catalysts, inorganic co-catalysts are more stable, eco-friendly and sustainable. Recently, researchers have found that metal sulfides such as ${ \sf W S } _ { 2 } .$ . $\mathbf { M o S } _ { 2 }$ and ${ \tt Z n S }$ can be used as co-catalysts to promote the Fenton process by accelerating the rate-limiting step of $\mathrm { F e ( I I I ) / F e ( I I ) }$ transformation [2426]. Among these metal sulfides, ${ \sf W S } _ { 2 }$ has attracted much attention due to its stronger redox capacity, stable physicochemical property and abundant resources [25,27]. However, these studies were more focused on the homogeneous Fenton system [24,25,28]. In addition, these studies lack in-depth critical discussion on the generated ROS. Almost all of them revealed that free radicals were the primary ROS only by quenching experiment or electron paramagnetic resonance (EPR) analysis. Recent studies revealed that non-radical ROS such as singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ or ferryl iron (Fe(IV) generated from iron activated Fenton reactions at neutral $\mathsf { p H }$ were primary working ROS, responsible for the degradation of organic compounds [2933]. However, the generation of non-radical ROS has never been evaluated in the ${ \sf W S } _ { 2 }$ co-catalyzed systems. It has remained unclear so far whether Fe(IV) or singlet oxygen can be produced in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system.

The objectives of this study are to: (1) investigate the possibilities for application of copper slag in degradation of BTA and reduction of $\mathrm { C r } ( \mathrm { V I } )$ , (2) evaluate the co-catalytic behavior of ${ \sf W S } _ { 2 }$ on the CS/PDS heterogeneous Fenton process, and (3) elucidate the main ROS in the ${ \mathrm { C S } } / { \mathrm { W } } { \mathrm { S } } _ { 2 } /$ PDS system by diverse methods such as quenching experiments, in situ Raman spectrum, EPR analysis and product identification by gas chromatography-mass spectrometry (GCMS).

# 2. Materials and methods

# 2.1. Materials

All details about the chemicals used in this study are presented in the Supporting Information Text S1. CS was obtained from Sichuan Pengcheng Mining Co., Itd. The CS was air-dried, then milled with an agate mortar and screened through a 100-mesh sieve.

# 2.2. Simultaneous oxidation of BTA and reduction of $C r ( W I )$

The simultaneous removal experiments of BTA and $\mathrm { C r } ( \mathrm { V I } )$ were performed in $5 0 ~ \mathrm { m L }$ centrifuge tubes with $2 0 ~ \mathrm { m g / L }$ of BTA, $2 0 ~ \mathrm { m g / L }$ of $\mathrm { C r } ( \mathrm { V I } )$ and $\mathbf { 3 } \mathrm { m M }$ of PDS. The initial pH was adjusted to $3 . 0 \pm 0 . 1$ Then $1 0 \ g / \mathrm { L }$ of CS and ${ } _ { 4 } \ g / \mathrm { L }$ of ${ \sf W S } _ { 2 }$ were rapidly added into the mixed solution. At predetermined time intervals, $0 . 5 ~ \mathrm { m L }$ of the reaction solution was withdrawn and $0 . 5 \mathrm { m L }$ of the saturated sodium thiosulfate solution was added to quench the reaction. Finally, the reaction solution was filtered through a polyethersulfone membrane $( 0 . 2 2 ~ \mu \mathrm { m } )$ for a further analysis.

For the cycle experiments, every $^ { 2 \mathrm { ~ h ~ } }$ additional portions of BTA and $\mathrm { C r } ( \mathrm { V I } )$ were added to the system [34]. Then PDS was added to initiate the next cycle.

# 2.3. Analytical methods

The residual concentration of BTA was quantified using a HPLC (Alliance) with a UV detector. The mobile phase consisted of $4 0 \ \%$ MeOH and $6 0 ~ \%$ water at the flow rate of $1 \ \mathrm { m L / m i n }$ .The detection wavelength was set at $2 8 0 \ \mathrm { n m }$ . Cr(VI) residual concentration was quantified using a UV-vis spectrophotometer (UV-DR6000, HACH, USA) with 1,5-diphenylcarbazide colorimetric method [35]. Methyl phenyl sulfoxide (PMsO) and methyl phenyl sulfone $\mathrm { ( P M S O _ { 2 } ) }$ were analyzed using HPLC. All details about this analytical method are provided in Supporting Information Table S6. After addition of 1,10-phenanthroline, the dissolved $\mathrm { F e } ^ { 2 + }$ concentration was determined with UVvis spectrophotometer at $5 1 0 ~ \mathrm { n m }$ . The total iron was determined after addition of hydroxylamine hydrochloride followed by addition of 1,10-phenanthroline. The dissolved $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ was measured after filtration, while the total $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ , including dissolved and surfacebound species, was measured before filtration [29]. PDS concentration was measured by the KI method [36]. Free radicals were measured using an electron paramagnetic resonance spectroscopy instrument (EPR, Bruker E 500, Germany). TOC analyzer (TOC-V, Shimadzu, Japan) was used to determine the total organic carbon. Method for the detection and identification of BTA degradation products is described in Supporting Information Text S2.

# 3.3.3. EPR analysis

Electron paramagnetic resonance (EPR) spectroscopy was coupled with 5,5-dimethyl-1-pyrolin-N-oxide (DMPO) as a spin-trapping agent to detect free radicals generated in the ${ \mathrm { C S / W S } } _ { 2 } / { \mathrm { P D S } }$ system (Fig. 4A). The signal of DMPOOH adducts can be clearly observed with typical 1:2:2:1 type characteristic peaks in the CS/PDS system and in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system, suggesting the existence of hydroxyl radicals in both of these systems. Nevertheless, the characteristic absorption peaks in the CS/ ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system are much higher than in the CS/PDS system. This result indicates that the yield of hydroxyl radicals in the ${ \mathrm { C S / W S } } _ { 2 } / { \mathrm { P D S } }$ system is much higher than in CS/PDS system. Furthermore, the adsorption peaks of hydroxyl radical adducts in the ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system are very weak. Because of that, the significant enhancement of PDS decomposition and hydroxyl radical production should not be ascribed to the activation of PDS by ${ \sf W S } _ { 2 }$ . Therefore, the accelerated generation of \*OH in ${ \mathrm { C S } } / { \mathrm { W } } { \mathrm { S } } _ { 2 } /$ PDS system should be attributed to the accelerated generation of $\mathrm { F e } ^ { 2 + }$ after the addition of ${ \sf W S } _ { 2 }$ . The signal of $\mathrm { D M P O } { - } S 0 _ { 4 } ^ { - }$ adduct was barely found due to its rapid transformation to DMPOOH adduct. Furthermore, the DMPOOH adducts could also be produced by the direct oxidation of DMPO by Fe(IV) or singlet oxygen [54,55].

A very weak signal of TEMP. $^ 1 0 _ { 2 }$ adduct in the EPR spectrum also confirmed that a singlet oxygen was not the primary ROS in the CS/ ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system (Fig. 4B). # 3.3.4. Probing Fe(IV)-oxo (ferryl) species

Some studies have found that Fe(IV)-oxo (ferryl) species are the main non-radical ROS in iron-based materials mediated AOPs [5759]. PMSO was usually chosen as a probe compound to verify the existence of Fe (IV), because it could be oxidized by Fe(IV) to generate $\mathrm { P M S O _ { 2 } }$ through the oxygen atom transfer mode [60]. This is a reaction that clearly distinguishes free radicals and Fe(IV). # 3.5Mechanisms of BTA degradation promoted by $W S _ { 2 }$

To further confirm the acceleration of the Fenton reaction by ${ \sf W S } _ { 2 }$ , the decomposition of PDS was monitored. In the CS/PDS system, less than $5 \ \%$ of the PDS was consumed within $1 2 0 \ \mathrm { m i n }$ , whereas the introduction of ${ \sf W S } _ { 2 }$ greatly increased the decomposition efficiency of PDS to $6 6 ~ \%$ within $1 2 0 \ \mathrm { m i n }$ (Fig. S19a). The decomposition of PDS fitted well with pseudo-first order kinetic model (Fig. S19b), and the apparent rate constant $( k )$ of PDS decomposition increased by 161 times from $5 . 1 8 \times { 1 0 ^ { - 5 } } \operatorname* { m i n } ^ { - 1 }$ in the CS/PDS system to $8 . 3 3 \times 1 0 ^ { - 3 } \operatorname* { m i n } ^ { - 1 }$ in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system. In addition, the significantly enhanced characteristic adsorption peaks of EPR spectra trapped by DMPO also indicated that the introduction of ${ \sf W S } _ { 2 }$ accelerated the Fenton reaction and ROS production (Fig. 4a).

Although all previous results showed that ${ \sf W S } _ { 2 }$ could indeed accelerate the Fenton reaction process in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system, it remained unclear how actually ${ \sf W S } _ { 2 }$ affected this process. It could be presumed that the introduction of ${ \sf W S } _ { 2 }$ accelerated the Fenton reaction in two ways: (1) WS2 catalyzed the decomposition of PDS; (2) ${ \sf W S } _ { 2 }$ acted as a reducing agent to accelerate the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle in the system, thus promoting the decomposition of PDS. To test this hypothesis, 1,10-phenanthroline and $\mathrm { F ^ { \ast } }$ were used as masking agents for $\mathrm { F e } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + }$ in the system, respectively. The aim was to investigate whether the iron ions released from the copper slag and iron cycling play a key role in the degradation of BTA. As Fig. 6A shows, upon the addition of 1,10-phenanthroline, BTA degradation was almost completely inhibited. These results indicated that the direct depletion of PDS by 1,10-phenanthroline can be excluded (Fig. S20). Therefore, these results suggested that $\mathrm { F e } ^ { 2 + }$ did play a key role in the BTA degradation in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system. The results also negated the hypothesis that the accelerated Fenton reaction after the introduction of ${ \sf W S } _ { 2 }$ might be due to the direct activation of PDS by ${ \sf W S } _ { 2 }$ .

# 3.6. BTA degradation products

Possible degradation products of BTA in ${ \mathrm { C S / W S } } _ { 2 } / { \mathrm { P D S } }$ system were detected using a GCMS. The products of BTA degradation can be divided into two categories: compounds produced by electron transfer and compounds produced by oxygen atom transfer. The main compounds formed are: 1-hydroxybenzotriazole, phenylhydrazine, aniline, nitrosobenzene, nitrobenzene, azobenzene and azoxybenzene. The possible degradation pathways of BTA in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ Fenton system are proposed in Fig. 7. The first step was mainly hydroxylation of the pyridine ring in BTA to generate 1-hydroxybenzotriazole. This product could be further oxidized by the rupture of the pyridine ring, resulting in the generation of phenylhydrazine and aniline. On the one hand, aniline could be oxidized to nitrosobenzene by oxygen atom transfer. On the other hand, two molecules of aniline could be linked to form azobenzene, which could be further oxidized to azoxybenzene through the oxygen atom transfer. The specific MS spectra of the BTA degradation products in the ${ \mathrm { C S / W S } } _ { 2 } / { \mathrm { P D S } }$ system are shown in Fig. S25. Interestingly, there are some degradation intermediates generated via transfer of oxygen atom, which seem to be different from those that were expected to be formed from $S O _ { 4 } ^ { \bullet - }$ and/or 'OH mediated oxidation. This result further suggests that Fe(IV) should be the primary ROS that was responsible for the degradation of BTA.

# 3.7. $W S _ { 2 }$ accelerated reduction of $C r ( W )$

$\mathrm { C r ( V I ) }$ is a toxic metal that is widespread in aqueous environments. Treatment of $\mathrm { C r ( V I ) }$ in waste water and drinking water has been a great challenge. Coexistence of $\mathrm { c r ( V I ) }$ and organic pollutants in the environment is a common phenomenon. Because of that, there is a great need for the development of a system that will be able to simultaneously eliminate $\mathrm { C r } ( \mathrm { V I } )$ and organic pollutants. In this study, ${ \sf W S } _ { 2 }$ was used as a cocatalyst for simultaneous removal of $\mathrm { C r } ( \mathrm { V I } )$ and BTA in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system.

As it was explained earlier, preliminary investigations were conducted in the CS/PDS system, and, separately, in the ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system. As Fig. 8 shows, ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system showed a remarkable promotion of $\mathrm { { C r } ( V I ) }$ reduction, in comparison with the CS/PDS system. Despite the major iron species of CS is ferrous iron $\mathrm { ( F e _ { 2 } S i O _ { 4 } , }$ fayalite), CS/PDS system had a very low reduction rate of $\mathrm { { C r } ( V I ) }$ . This result can be explained with a very stable spinel structure of fayalite in which iron ions are surrounded by a silicon-oxygen tetrahedral or octahedral lattice. Because of that, iron ions in CS are difficult to be released and used. Moreover, the slow $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle also inhibited the reduction of $\mathrm { c r }$ (VI). A moderate reduction efficiency of $\mathrm { C r ( V I ) }$ was obtained in the ${ \sf W S } _ { 2 } /$ PDS system. $\mathrm { { C r } ( V I ) }$ could not be completely reduced by ${ \sf W S } _ { 2 }$ even in a high dosage $( 4  g / \mathrm { L } )$ . As it is well known, $\mathrm { { C r } ( V I ) }$ usually exists in the form of oxyanions in aqueous solution $( \mathrm { C r _ { 2 } O _ { 7 } ^ { 2 - } }$ or $\mathrm { C r O } _ { 4 } ^ { 2 - }$ (Fig. S26). The surface of ${ \sf W S } _ { 2 }$ in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system is negative charged due to the deprotonation which causes electrostatic repulsion between ${ \sf W S } _ { 2 }$ and Cr (VI) and hinders reduction of $\mathrm { C r ( V I ) }$ Because of that, in this system Cr (VI) preferably reacts with $\mathrm { F e } ^ { 2 + }$ due to the electrostatic attraction. Furthermore, ${ \sf W S } _ { 2 }$ preferably reacts with $\mathrm { F e } ^ { 3 + }$ to generate $\mathrm { F e } ^ { 2 + }$ which is confirmed by a constantly elevated $\mathrm { F e } ^ { 2 + }$ concentration in the system (Fig. 6C and D).

In order to further understand the mechanisms of $\mathrm { { C r } ( V I ) }$ reduction, $\mathrm { { C r } ( V I ) }$ reduction experiments were conducted without BTA (Fig. 8B). The results showed that $\mathrm { C r ( V I ) }$ cannot be reduced by PDS, which reacts differently than $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ As it is well known, $\mathrm { { C r } ( V I ) }$ can be quickly reduced by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in acidic conditions. Moreover, previous studies reported that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ could be activated by both $\mathrm { { C r } ( V I ) }$ and $[ \mathrm { C r } ^ { \mathrm { I I I } } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { \mathrm { y } } ] ( \mathrm { O H } ) _ { \mathrm { x } }$ to generate $\cdot _ { \mathrm { O H } }$ , which was used in degradation of 4-chlorophenol [8,66]. However, $\mathrm { { C r } ( V I ) }$ can hardly activate PDS due to the more stable $\mathrm { S O _ { 3 } } \mathrm { - } 0 \mathrm { - } 0 \mathrm { - } \mathrm { S O _ { 3 } }$ structure. Even PDS is unable to reduce $\mathrm { C r } ( \mathrm { V I } )$ due to the high redox potential $[ \mathrm { E } ^ { 0 } ~ ( \mathrm { S _ { 2 } O _ { 8 } ^ { 2 - } / S O _ { 4 } ^ { 2 - } } ) ~ = ~ 2 . 0 1$ eV] (Fig. 8B). Approximately $2 0 ~ \%$ of $\mathrm { C r } ( \mathrm { V I } )$ was reduced by CS alone. However, the addition of CS and ${ \sf W S } _ { 2 }$ to the reaction system made the reduction efficiency of $\mathrm { { C r } ( V I ) }$ higher than $7 0 \%$ in $1 0 \ \mathrm { m i n }$ . As discussed above, the addition of ${ \sf W S } _ { 2 }$ not only accelerated the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle, but also the dissolution of $\mathrm { F e } ^ { 2 + }$ due to the decreased solution pH. $\mathrm { F e } ^ { 2 + }$ preferably reacts with $\mathrm { C r ( V I ) }$ than with ${ \sf W S } _ { 2 }$ due to the electrostatic attraction. Furthermore, a significant positive correlation between production of $\mathrm { F e } ^ { 2 + }$ and reduction of $\mathrm { c r ( V I ) }$ further confirms that $\mathrm { F e } ^ { 2 + }$ in the system has a key role for the reduction of $\mathrm { C r ( V I ) }$ (Fig. 8C). In order to confirm whether the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle accelerated by ${ \sf W S } _ { 2 }$ had a main role in the $\mathrm { { C r } ( V I ) }$ reduction process, $\mathrm { F ^ { \ast } }$ (KF) was used as a masking agent for $\mathrm { F e } ^ { 3 + }$ , to disrupt the Fe cycle in this system. $\mathrm { F ^ { \ast } }$ is able to form $\mathrm { F e F } _ { 3 }$ precipitate with $\mathrm { F e } ^ { 3 + }$ , while $\mathrm { F ^ { \ast } }$ cannot be oxidized by PDS due its chemical stability. The effect of $\mathrm { F ^ { \ast } }$ on the reduction of $\mathrm { { C r } ( V I ) }$ in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system is shown in Fig. 8D. The addition of $\mathrm { F ^ { \ast } }$ significantly inhibited the reduction efficiency of $\mathrm { C r } ( \mathrm { V I } )$ in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system (reduced by $5 0 . 2 ~ \% )$ , which should be ascribed to the destruction of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle through the formation of $\mathrm { F e F } _ { 3 }$ precipitate. Moreover, the reduction efficiency of $\mathrm { { C r } ( V I ) }$ in the $\mathrm { C S / W S _ { 2 } / P D S  – F }$ system was even lower than that in the ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system. The reduction of $\mathrm { C r } ( \mathrm { V I } )$ in the $\mathrm { C S / W S _ { 2 } / P D S  – F }$ system almost stopped after $1 0 \ \mathrm { m i n }$ . This result can be explained with the formation of a dense $\mathrm { F e F } _ { 3 }$ passivation layer on the surfaces of ${ \sf W S } _ { 2 }$ and CS, which interrupts the electron transfer between ${ \mathsf { W S _ { 2 } } } / { \mathsf { F e } } ^ { 2 + }$ and $\mathrm { { C r } ( V I ) }$ . As it is shown earlier, the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle does play a crucial role in the reduction of $\mathrm { C r } ( \mathrm { V I } )$ , in which ${ \sf W S } _ { 2 }$ acts as an electron donor to facilitate the efficient conversion of $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e } ^ { 2 + }$ .

Finally, the XPS spectrum was employed to the detect the reduction products of $\mathrm { { C r } ( V I ) }$ . As it is shown in Fig. S27, $\mathrm { C r ( I I I ) }$ was identified as the main reduction product of $\mathrm { C r } ( \mathrm { V I } )$ in the reaction system used. Since the solution $\mathtt { p H }$ less than 3.0, soluble $\mathrm { C r ^ { 3 + } }$ was the main species of $\mathrm { { C r } ( I I I ) }$ rather than ${ \mathrm { F e C r } } _ { 2 } { \mathrm { O } } _ { 4 }$ or $\mathrm { { C r } _ { 2 } \mathrm { { O } _ { 3 } } }$ precipitates (Fig. S28).

We have demonstrated that iron ions played the main roles during the reduction of $\mathrm { c r ( V I ) }$ in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system. To further investigate whether the $\mathrm { c r ( V I ) }$ reduction was dominated by homogeneous or heterogeneous reactions, the Zeta potential of the copper slag was measured. As it is shown in Fig. S29, the zero charge point of copper slag is at $\mathrm { p H } = 2 . 2$ . Because of that, the copper slag surface is negatively charged throughout the reaction due to the deprotonation in the CS/ ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system. Obviously, this is unfavorable for the contact reduction of $\mathrm { C r } ( \mathrm { V I } )$ due to electrostatic repulsion. Furthermore, ${ \sf W S } _ { 2 }$ surface is also negatively charged due to its low zero potential point $( \mathrm { p H } _ { \mathrm { p z c } } = 2 . 2 )$ and deprotonation. This also negates the contact reduction of $\mathrm { C r ( V I ) }$ on the surface of ${ \sf W S } _ { 2 }$ . According to all these facts it can be presumed that the reduction of $\mathrm { c r ( V I ) }$ in the ${ \mathrm { C S / W S } } _ { 2 } / { \mathrm { P D S } }$ system is dominated by the homogeneous $\mathrm { F e } ^ { 2 + }$ .To confirm this presumption, $\mathrm { { C r } ( V I ) }$ reduction in the $\mathrm { F e ^ { 2 + } / W S _ { 2 } / P D S }$ and $\mathrm { F e ^ { 3 + } / W S _ { 2 } / P D S }$ systems was performed (Fig. S30). The concentrations of $\mathrm { F e ^ { 2 + } }$ and $\mathrm { F e } ^ { 3 + }$ were set as $1 . 6 5 ~ \mathrm { m g / L }$ and $4 . 0 \mathrm { m g / L }$ respectively, which are consistent with the dissolved $\mathrm { F e ^ { 2 + } }$ and $\mathrm { F e } ^ { 3 + }$ concentrations in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system at $6 0 \ \mathrm { m i n }$ The results showed that both $\mathrm { F e ^ { 2 + } / W S _ { 2 } / P D S }$ and $\mathrm { F e ^ { 3 + } / W S _ { 2 } / P D S }$ systems achieved efficient $\mathrm { C r ( V I ) }$ reduction within $1 2 0 \mathrm { m i n }$ , which is generally in agreement with the results in the ${ \mathrm { C S / W S _ { 2 } / P D S } }$ system. In other words, the homogeneous iron is able to achieve efficient $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ conversion and $\mathrm { C r ( V I ) }$ reduction with the assistance of ${ \sf W S } _ { 2 }$ , even at a very low dissolved iron content.

According to the previous discussion, it can be claimed that the reduction of $\mathrm { C r } ( \mathrm { V I } )$ in the ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system mainly occurred in the solution through homogeneous reactions, while the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ transformation primarily occurred on the surface of ${ \sf W S } _ { 2 }$ , as it is shown in Scheme 2. Firstly, $\mathrm { F e } ^ { 3 + }$ generated from the oxidation of $\mathrm { F e } ^ { 2 + }$ by $\mathrm { { C r } ( V I ) }$ absorbs on the surface of ${ \sf W S } _ { 2 }$ Then ${ \sf W S } _ { 2 }$ surface produces $\mathrm { H } _ { 2 } S$ to expose $\mathrm { W } ^ { 4 + }$ . $\mathrm { W } ^ { 4 + }$ preferentially provides electrons to $\mathrm { F e } ^ { 3 + }$ , rather than to $\mathrm { c r }$ (VI), due to the electrostatic repulsion between ${ \sf W S } _ { 2 }$ and $\mathrm { C r } ( \mathrm { V I } )$ . Subsequently, the $\mathrm { F e } ^ { 2 + }$ produced on the surface of ${ \sf W S } _ { 2 }$ dissolves back into solution to reduce $\mathrm { C r ( V I ) }$ .Additionally, surface $\mathsf { W } ^ { 4 + }$ can also directly donate electrons to $\mathrm { { C r } ( V I ) }$ around the ${ \sf W S } _ { 2 }$ surface.

# 3.8. Influencing factors affecting the removal of BTA and Cr(VI)

The impacts of pH, PDS concentration and water matrix on the BTA degradation and $\mathrm { { C r } ( V I ) }$ reduction were evaluated. As it is shown in Fig. 9A and B, both, the BTA degradation and $\mathrm { C r } ( \mathrm { V I } )$ reduction were sensitive to the solution pH. BTA degradation gradually decreased as the initial solution pH raised from 3 to 10. Obviously, acidic solution pH was more favorable to BTA degradation than neutral or alkaline conditions. Lower pH accelerates the release of iron ions from CS, which is favorable for both, the PDS decomposition and BTA removal. On the contrary, one part of iron ions will precipitate at neutral or alkaline pH, which has an adverse effect on the PDS decomposition. In case of $\mathrm { C r ( V I ) }$ reduction, acidic solution pH is also more favorable than neutral or alkaline conditions. On the one hand, acidic conditions would bring out more dissolved iron ions from the CS. On the other hand, when the solution pH is lower than the zero charge point of the CS, the surface of the CS will have a positive charge due to the protonation. This situation is more conducive to the removal of $\mathrm { c r ( V I ) }$ by electrostatic attraction between the CS and $\mathrm { C r ( V I ) }$ oxygen-containing anions $( \mathrm { C r _ { 2 } O _ { 7 } ^ { 2 - } }$ or $\mathrm { C r O } _ { 4 } ^ { 2 - } )$ . PDS concentration can also influence the degradation efficiency of BTA. BTA degradation efficiency increased with the PDS concentration in the CS/ ${ \mathsf { W S } } _ { 2 } / { \mathsf { P D S } }$ system (Fig. 9C). Furthermore, the kinetic parameters were well fitted with the pseudo-first-order model, while the apparent rate constant $( k _ { \mathrm { o b s } } )$ was linearly correlated with PDS concentration (Fig. S31A and B). Hence, the BTA degradation is of the first-order with regard to PDS concentration. Interestingly, increased initial PDS concentration also resulted in an improved $\mathrm { c r ( V I ) }$ removal (Fig. 9D). This result could be ascribed to the increased $\mathrm { H } ^ { + }$ concentration that derived from PDS decomposition, which could facilitate the dissolution of iron ions from the CS. Meanwhile, the enhanced surface protonation of the CS also increased electrostatic attraction between $\mathrm { { C r } ( V I ) }$ and the CS. As a consequence, the removal efficiency of $\mathrm { { C r } ( V I ) }$ was increased.

The simultaneous removal of BTA and $\mathrm { C r } ( \mathrm { V I } )$ in a real water (mine water, river water and tap water) was also investigated (Fig. 9E and F). The degradation rate of BTA was obviously inhibited in the real water. The decreased Fenton reaction rate in a real water of ${ \mathrm { C S } } / { \mathrm { W S } } _ { 2 } / { \mathrm { P D S } }$ system could be attributed to the competitive consumption of ROS by complex ingredients in real water (Table S5), such as dissolved organic matter and interfering ions. Tap water had the most significant effect on the BTA degradation. This observation might be ascribed to the consumption of ROS by the high concentration of chloride ions (Table S5). In case of $\mathrm { { C r } ( V I ) }$ removal, a similar trend was found in the real water. This result could be attributed to consumption of $\mathrm { F e } ^ { 2 + }$ and $\mathrm { W } ^ { 4 + }$ by oxidizing species in a real water (e.g., nitrite or nitrate). Fortunately, good removal efficiency can still be achieved in $1 2 0 ~ \mathrm { m i n }$ except for the tap water. These results suggested that the ${ \mathrm { C S / W S } } _ { 2 } / { \mathrm { P D S } }$ is a promising system for wastewater treatment.

# .9Stability and reusability

As a final part of this study, the stability and reusability of the CS and ${ \sf W S } _ { 2 }$ were evaluated. The characteristic peaks and mineral speciation in XRD patterns of the CS and ${ \sf W S } _ { 2 }$ before and after reaction show no visible changes in any of these components after the reaction (Fig. 1A). These results are not surprising because CS has a high chemical stability due to the spinel structure of fayalite. SEM images of used CS and ${ \sf W S } _ { 2 }$ also show that their microstructures are consistent with those of fresh CS and ${ \sf W S } _ { 2 }$ (Fig. 1B). Obviously, both the CS and ${ \sf W S } _ { 2 }$ have high stability in the treatment of sewage. The recycling behavior of a ${ \mathrm { C S } } / { \mathsf { W } } { \mathsf { S } } _ { 2 }$ mixture was evaluated in a semi-continuous batch cycle experiment [34]. Five continuous cycles were conducted, and each time fresh micro volumes of concentrated BTA and $\mathrm { { C r } ( V I ) }$ solutions were added to the system. The results in Fig. S32 show that both, the removal efficiency of BTA and Cr (VI) remained $1 0 0 \%$ throughout all five cycles. These results indicated a high remediation capacity of the ${ \mathrm { C S } } / { \mathsf { W } } { \mathsf { S } } _ { 2 }$ mixture in the treatment of the combined pollution in wastewater.

# 4. Conclusions

In this study, a copper slag mediated persulfate Fenton system was constructed, in which ${ \sf W S } _ { 2 }$ served as a co-catalyst. The applicability of this system in simultaneous elimination of BTA and $\mathrm { C r ( V I ) }$ was investigated. Fayalite was identified as the main mineral component of the CS. The CS was able to release iron ions continuously for AOPs, while ${ \sf W S } _ { 2 }$ served as a co-catalyst in acceleration of the rate-limiting step of the $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ conversion and in prevention of $\mathrm { F e } ^ { 3 + }$ precipitation. In this process, $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ conversion primarily occurred on the surfac of ${ \mathrm { W } } S _ { 2 } ,$ whereas decomposition of PDS and degradation of BTA mainly occurred through homogeneous Fenton reactions. The reactive oxygen species detection experiments showed that Fe(IV) was the main ROS, followed by hydroxyl radicals and sulfate radicals. The detailed kinetics calculation indicated that Fe(IV) was responsible for $6 3 . 4 \%$ of the degradation of BTA, while hydroxyl radicals and sulfate radicals accounted for 27.7 $\%$ and $8 . 9 ~ \%$ of BTA degradation, respectively. The $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ cycle accelerated by ${ \sf W S } _ { 2 }$ had a crucial role in the reduction of $\mathrm { C r } ( \mathrm { V I } )$ .Similarly to the degradation of BTA, the reduction of $\mathrm { C r } ( \mathrm { V I } )$ occurred mainly through the homogeneous reactions. Dissolved $\mathrm { F e ^ { 2 + } }$ had the main role in the reduction of $\mathrm { C r } ( \mathrm { V I } )$ . Considering its low cost and good performance in a removal of the organic pollutant and the heavy metal, the ${ \mathrm { C S } } / { \mathrm { W } } { \mathrm { S } } _ { 2 } /$ PDS system is considered to have a good potential for the treatment of mine pollution.
