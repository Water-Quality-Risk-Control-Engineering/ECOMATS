Herein, a series of monolithic $\bf { M n / C e }$ -based catalyst of ceramic membranes (CMs) were prepared through impregnation method for volatile organic compounds (VOCs) removal. The porous fibrous CMs with a sinter-locked network structure were fabricated by molding method in a feasible sintering process. Then, the catalytic CMs were systematically analyzed by using specific analytical techniques. The results showed that the fibrous CMs possessed a unique interconnected and uniform pore structure, and $\mathbf { M n O _ { x } { \mathrm { - C e O _ { 2 } } } }$ active phases were homogenously dispersed into the porous CMs support. The catalytic activity of samples was measured by using benzene as target VOCs. The results revealed that all catalytic CMs were active for oxidation of benzene. Significantly, the catalytic performance was promoted by introducing Ce species into $\mathbf { M n O _ { x } } .$ Among all, $\mathrm { { M n O } _ { x } . }$ - $\mathrm { C e O } _ { 2 } { \cdot } 3 { : } 1$ catalyst exhibited the lowest $9 0 \%$ benzene conversion temperature $\left( \mathrm { T } _ { 9 0 } \right)$ at $2 4 4 ^ { \circ } \mathrm { C }$ and high stability with continuous benzene stream in the presence of $9 0 \mathrm { v o l . } \%$ $( 2 0 ^ { \circ } \mathrm { C } )$ water vapor under a gaseous hourly space velocity (GHSV) of $5 0 0 0 \mathrm { h } ^ { - 1 }$ , owing to the lower-temperature reducibility and the abundant active oxygen $( \mathrm { O } _ { \mathrm { A d s } } . \mathrm { \textrm { } }$ ) with synergetic effect of $\mathtt { M n O _ { x } }$ and $\mathrm { C e O } _ { 2 }$ . The results indicated a promising way to design a high efficiency dual functional CMs for the industrial application of removal VOCs while controlling particulate matters (PMs) from hot gases.

# 1. Introduction

Monolithic catalysts have good performances on mass and heat transfer, high thermal stability, low pressure drop associated with the high flow rate and good mechanical strength over conventional pellets or powders catalyst [1–3]. Commonly, the monolith support can be divided into metallic or ceramic structure according to the fabrication materials. Metallic monoliths offer advantages such as better heat transfer, good ductility and mechanical stability [4], but limited by its higher cost, lower chemical stability and difficulty in immobilizing catalysts in industrial application [1,5]. Ceramic monoliths have the advantages of a higher porosity, good thermal and chemical stability, strong coating adherence and easier dispersion of used catalysts [6–9], which make it suitable for an excellent monolithic catalyst support to satisfy industrial requirements.

In addition, various industrial processes produce kinds of VOCs containing fine PMs which directly or indirectly threaten the environment and human health [10–15]. Therefore, it must be very desirable to remove VOCs meanwhile dedust does. In fact, porous CMs have been widely used for cleaning dust due to their specific physical and chemical properties which can tolerate the severe conditions with high temperature, high flows, high corrosive atmospheres, thermal shocks and vibrations [13]. In this work, we functionalized the porous CMs with catalytic active components as a monolithic catalyst and studied the effect of monolithic catalyst in removal of VOCs.

Currently, catalytic oxidation is a high-efficiency method in the removal of VOCs by complete oxidizing them into $\mathrm { C O } _ { 2 }$ and $_ \mathrm { H _ { 2 } O }$ over specific catalysts at a relatively lower temperature. Mn and Ce-based catalysts exhibited superior catalytic activity for complete oxidation of VOCs [16–19]. Mn oxides have good performance due to their multiple metal oxidation states, high poison resistance, good reducibility and low cost etc. [20,21]. Ce oxides, as a rare earth oxide, has been investigated as an oxygen storage material and perceived an effective component in the VOCs oxidation [22]. $\mathbf { M n O _ { x } { \mathrm { - C e O _ { 2 } } } }$ mixed oxides showed much higher catalytic activity than those of pure $\mathrm { { { M n O } _ { x } } }$ and $\mathrm { C e O } _ { 2 }$ in VOCs oxidation, resulting from the synergistic effect existed in the mixed oxides [17,23,24]. However, the catalytic oxidation of industrial VOCs over the conventional powder or pellet catalysts are often limited in practical application. Hence, it is significant to load traditional powder catalysts on to a monolithic support for using in the industrial VOCs removal.

Herein, we successfully prepared a porous CMs by using mullite fiber as raw material and earth-abundant raw chemicals kaolin and feldspar powder as high temperature binder in a relatively low thermal process. Then, the monolithic Mn/Ce-based catalytic CMs were prepared by a simple impregnation method. The Mn/Ce-based catalytic CMs improved gas and heat transfer by acting as a microreactor which is related to the contact of reactant gases with the catalytically active sites on the catalyst surfaces, which is a promising high efficiency dual functional material for treatment the industrial PMs and VOCs pollutions.

# 2. Experimental

# 2.1. Preparation of the catalytic ceramic membrane

Porous fibrous ceramic membranes (CMs) were fabricated by molding method in a feasible sintering process. Specifically, a suspension was prepared by dissolving Carboxymethylcellulose $_ { ( 5 ~ g ) }$ into deionized water $\mathrm { ( 1 0 0 m L ) }$ and stirring vigorously for $3 0 \mathrm { m i n }$ . Short-cut polycrystalline mullite fibers $( \mathsf { d } = 1 0 { - } 2 0 \mu \mathrm { m }$ , $1 = 1 0 0 { - } 2 0 0 \mu \mathrm { m }$ , $3 0 \mathrm { g }$ ) were added to the stirring suspension. Then, Economic accessible ultrafine kaolin $( \mathrm { d } _ { 5 0 } = 1 . 3 3 9 \mu \mathrm { m } ,$ , $7 . 5  \ g \}$ and high-purity feldspar powders $( \mathrm { d } _ { 5 0 } = 1 . 4 3 2 \mu \mathrm { m }$ , $7 . 5 g \rangle$ ) were added as high temperature binder, followed by adding of a corn starch $( \mathsf { d } _ { 5 0 } = 1 3 . 1 5 \mu \mathrm { m } ,$ $1 0 \ : \mathrm { g }$ as binder and pore-forming additive. The mixture was then stirred for $1 0 \mathrm { { m i n } }$ in a mixing equipment to get a stable and condensed slurry. The CMs green body was manufactured by pressing the slurry into a metal mold $( \varphi 2 0 \mathrm { m m } ^ { * } 8 \mathrm { m m } )$ and drying at $8 0 ~ ^ { \circ } \mathrm { C }$ for $2 4 \mathrm { h }$ in an oven, and then the green bodies were removed from the mold and sintered at $1 2 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ with the heating rate of $3 ^ { \circ } \mathrm { C } \mathrm { m i n } ^ { - 1 }$ to obtain the special sinterlocked three-dimensional structure porous CMs.

The catalytic CMs of different atomic ratio of $\mathbf { M n O _ { x } / C e O _ { 2 } }$ on the asprepared CMs were prepared by using an impregnation method and carried out in the following sequences. Firstly, the resulting CMs were cut into cylindrical pieces (diameter $2 0 \mathrm { m m }$ ; height $1 0 \mathrm { m m }$ ), then the as-prepared CMs were immersed in an aqueous solution of $\bf { M n } ( N O _ { 3 } ) _ { 2 }$ $( 5 0 \%$ aqueous solution, $\mathbf { M } = 1 7 8 . 9 5 )$ and $\mathrm { C e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ $( \mathrm { M } = 4 3 4 . 1 2 )$ . To ensure completely loading of given $\mathrm { M n / C e }$ molar ratio to the CMs support, a rotary evaporator was used for evaporating solvents and impregnating catalytic active components. After the solvents evaporated completely, the impregnated catalytic samples were dried at ${ 1 2 0 ~ ^ { \circ } \mathrm { C } }$ for $^ { 2 \mathrm { h } }$ and calcined at $5 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ (with $2 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 } .$ ). Monolithic $\mathrm { M n / C e }$ -based catalysts of CMs with $1 0 \%$ $\mathbf { M n O _ { x } / C e O _ { 2 } }$ were thus prepared by this procedure.

# 3.4. X-ray photoelectron spectra

The oxidation states and percentage of chemical species on catalysts were investigated by XPS analysis, which is deeply related to the catalytic oxidation reaction. Fig. 6 showed the XPS results of O 1s, Mn 2p and Ce 3d in all catalysts. All the spectra were referenced to the residue carbon at binding energy (BE) of $2 8 4 . 6 \mathrm { e V }$ . As shown in Fig. 6(a), The XPS spectrum of Ce 3d can be decomposed into eight peaks corresponding to four pairs of spin-orbit doublets. The peaks located at 882.7, 884.9, 888.9 and $9 9 8 . 5 \mathrm { e V }$ are corresponding to v, v1, v2 and v3 represent the Ce $3 \mathrm { d } _ { 2 / 5 }$ , and the peaks at 901.0, 903.2, 907.3 and $9 1 6 . 8 \mathrm { e V }$ are corresponding to u1, u, u2, u3 are the features of Ce $3 \mathrm { d } _ { 3 / 2 }$ , respectively. The v, v2, $\nu 3$ , u, u2 and u3 peaks are assigned to ${ \mathsf { C e } } ^ { 4 + }$ species, while the ν1 and u1 belong to the characteristic peaks of Ce3+ species [29]. Evidently, ${ \mathsf { C e } } ^ { 4 + }$ and ${ \mathsf { C e } } ^ { 3 + }$ coexisted on the surface of the catalysts, and ${ \mathsf { C e } } ^ { 4 + }$ is the primary oxidation state of Ce [30], while $\mathsf { C e } ^ { 3 + }$ exists only a small percentage according to the results quantitatively calculated from the XPS spectra area summarized in Table 2, the ratio of the area assigned to $\mathsf { C e } ^ { 3 + }$ to total area. # 3.6. Mechanism discussion

According to the analysis above, the PM control and benzene catalytic oxidation mechanism for $\mathbf { M n O _ { x } / C e O _ { 2 } }$ on CMs is discussed.

Mullite fibers were well welded together to build a relative stable skeleton structure after high temperature calcination. More specifically, at the heat treatment process, the corn starch was decomposed and formed abundant interconnected pores, and the high temperature binder of ultra-fine kaolin and feldspar powders were formed as fiber bonding points and the fibers were well connected together to cause a sinter-locked three-dimensional net structure. The prepared fibrous CMs possess properties with high porosity, lightweight, interconnected pores and high mechanical strength. When the dust-laden air passed through the CMs, the PM with different particle sizes were captured on the CMs surface by the special structure, and accumulated into a duskcake which could act as the filter layer.

Catalyst particles were uniformly embedded on the CMs by a simple impregnation method. Micro-meter scale porous structure of catalytic CMs promotes diffusion of reactant gases and keep a low pressure drop, which defined as a micro-reactor. Benzene is oxidized by the oxygen species released from Mn-Ce oxides and gas oxygen molecules. $\mathbf { M n O _ { x } }$ serves as main active phase which provides the most active oxygen species, and $\mathrm { C e O } _ { 2 }$ acts as an oxygen storage material improving the mobility of oxygen species due to $\mathsf { C e } ^ { 4 + } / \mathsf { C e } ^ { 3 + }$ redox. As shown in Fig. 8, the oxidation of benzene is associated with adsorbed oxygen and oxygen vacancy which promote the catalytic reaction at lower temperature. From the XPS data summarized in Table 2, the amount of adsorbed oxygen increased with the existence of Ce ions, and served as active oxygen species. Active oxygen can be promoted by increasing the content of higher manganese oxidation state $\left( \mathrm { M n } ^ { 4 + } \right)$ ) and the small quantity of $\mathsf { C e } ^ { 3 + }$ which can be beneficial for the redox transport process and then enhance the catalytic properties. The synergistic effect between $\mathrm { { { M n O } _ { x } } }$ and $\mathrm { C e O } _ { 2 }$ can improve the concentration of active oxygen species to improve the catalytic activity. From XPS and $\mathrm { H } _ { 2 ^ { - } } \mathrm { T P R }$ results, the $\mathbf { M n O _ { x } / C e O _ { 2 } }$ -3:1catalyst showed more adsorbed oxygen species and better reducibility which were crucial to the benzene oxidation.

# 4. Conclusions

In summary, we have successfully prepared porous fibrous CMs and developed a series of Mn-Ce based monolith catalysts by the facile impregnation method. The evaluation for catalytic activity shows that all of the catalytic CMs were active for catalytic oxidation of benzene and the $\mathbf { M n } / \mathbf { C e } { - 3 : 1 }$ catalyst showed the best performance, giving the $\mathrm { T } _ { 9 0 }$ about $2 4 4 ^ { \circ } \mathrm { C }$ at a gaseous hourly space velocity (GHSV) of $5 0 0 0 \mathrm { h } ^ { - 1 }$ because of the high reducibility, active oxygen species, and enhanced interaction among different elements. The specific structure of CMs facilitates the well dispersion of Mn and Ce oxides particles and enhance the contact of reactant gases to the catalytically active sites on the catalyst surfaces. This work demonstrated a promising concept for dual functional of monolith catalyst which can simultaneously serve as PMs filter and high efficient catalyst for benzene oxidation in a practical application.
