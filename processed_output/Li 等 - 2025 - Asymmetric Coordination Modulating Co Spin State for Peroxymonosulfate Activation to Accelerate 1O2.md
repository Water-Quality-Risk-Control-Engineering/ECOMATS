# Asymmetric Coordination Modulating Co Spin State for Peroxymonosulfate Activation to Accelerate $\boldsymbol { \mathsf { I } } _ { \mathbf { O } _ { 2 } }$ Generation

Xiuze Li, Yixuan Gao, Juanjuan Qi,\* Yibo Liu, Qiangwei Li, Jianui Wang and Lidong Wang\*

Singlet oxygen $( ^ { 1 } \mathsf { O } _ { 2 } )$ has received extensive attention for the selective degradation of emerging contaminants. However, how to efficiently generate $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } } ^ { \phantom { \dagger } }$ by modulating the asymmetric structure and electron spin state of catalyst remains a challenge. Herein, an asymmetric Fe—S—Co structured catalyst $( \mathsf { C o - F e } _ { 3 } \mathsf { S } _ { 4 } )$ is designed by in situ substitution o $\mathsf { F e } ^ { \mathsf { I I I } } \tau \mathsf { d }$ strategy. The strong interaction in the asymmetric structure induces a low-spin state (e: ↑, $\uparrow \downarrow , t _ { 2 } \colon \underline { { \uparrow \downarrow } } , \ldots \rfloor$ at d-orbital of Co sites, shifting the d-band center closer to the Fermi level and elevating the antibonding states, which is beneficial for the adsorption of peroxymonosulfate (PMS). The catalyst accelerates $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } }$ generation by PMS activation, achieving $100 \%$ removal of acetaminophen in pharmaceutical wastewater in 8 min with a high K-value of 1 $\lvert 1 2 \mathrm { m i n } ^ { - 1 } \mathrm { ~ } \mathsf { M } ^ { - 1 }$ . Experiments and DFT calculations reveal that the spin state of the generated $\ " { \boldsymbol { \mathbf { \rho } } } _ { 2 }$ (from the $\multimap$ bond cleavage in ${ \mathsf { H } } { \mathsf { S } } { \mathsf { O } } _ { 5 } { } ^ { - } )$ is reduced by electron reversal $\{ \downarrow$ to ) or pairing (1,  to↑↓, −) in the 2p $( 2 \mathsf { p } _ { x }$ and $z _ { P _ { Y } }$ orbitals of the $\multimap$ anti- $\pmb { \pi }$ bond $( \pi ^ { * } )$ , resulting in the $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } }$ generation. This work presents an approach for regulating the spin state using an asymmetric structure and offers a broader perspective on the generation mechanism of $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } } ^ { \mathsf { 1 } }$

# 1. Introduction

Compared to the traditional Fenton process, the peroxymonosulfate (PMS)-based advanced oxidation process (AOP) offers several advantages, including wider pH applicability, high efficiency, and easy transportation and storage.[1] As a result, this process has obtained significant attention for treating complex water contamination. The generation of reactive oxygen species (ROS) by activating PMS is a key step in AOP. The ROS include free radicals such as $\bullet _ { \mathrm { O H } }$ and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and non-free radicals of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ . The PMS-based AOP typically involves the generation of free radical species. The previous studies have thoroughly analyzed the mode of free radical production, in which PMS is adsorbed on the surface of the metal sites of the catalyst, and the metal sites transfer electrons to the PMS, which results in the reduction of the PMS to $\bullet _ { \mathrm { O H } }$ and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ [2] The ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ of the non-radical pathway has been widely noticed for its strong resistance to background ion interference and high selectivity.[3] However, the mechanism behind its production remains unclear. For instance, Bu et al. suggested that ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ may be produced by dissolved oxygen in water.[4] In contrast, Yang et al.

found that ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ can be further converted by free radicals produced in the system.[5] Moreover, Zhang et al. found that PMS was synergistically activated by Fe(II) and pyridine N to produce ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ [6] They discovered that ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ originated from the superoxide radicals generated in the system. Wang et al. proposed that nonmetal systems, such as carbon/PMS systems, can generate ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ through carbonyl groups $( { \mathrm { C } } { = } 0 )$ acting as active sites.[7] Additionally, the studies by Mi et al. and Zhang et al. found that electron transfer from PMS to the catalyst active sites can enhance the production of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ [8] The results are inconsistent, and the production mechanism of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ is still unclear, so further exploration of the production mechanism of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ is necessary.

In recent years, acetaminophen (APAP) has been one of the typical active pharmaceutical ingredients, which has been widely detected in water bodies, posing a threat to both the ecological environment and human health.[9] Therefore, developing functional catalysts capable of effectively activating PMS to generate ROS for the degradation of pharmaceutical pollutants is imminent. Asymmetric site catalysts, owing to their unique structure, have been widely studied in various fields and are known to effectively improve adsorption and catalytic activity. For example, Xu et al. utilized the tuning effect of the $\mathrm { P }$ atom to break the local charge symmetry of the Fe single atom, promoting the enrichment of nitrate ions in the ${ \mathrm { N O } } _ { 3 } { } ^ { - } { \mathrm { R R } }$ process.[10] Mu et al.

introduced Ru to form asymmetric Ru—O—TM and achieved excellent OER catalytic activity.[11] Therefore, by designing a catalyst with an asymmetric structure and applying it to a Fenton-like system, it is expected that the degradation performance of pharmaceutical pollutants will be greatly improved.

Herein, a catalyst $\mathrm { ( C o - F e } _ { 3 } \mathrm { S } _ { 4 } )$ with an asymmetric Fe—S—Co structure was designed by introducing Co to replace the four—coordinated $\mathrm { F e ^ { I I I } }$ site in $\mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ . This asymmetric structure induced a low-spin state (e: ↑, 1↓ $t _ { 2 } \colon \underline { { \uparrow \downarrow } } , . . . - )$ at d-orbitals of Co sites, shifting the d-band center closer to the Fermi level and elevating the antibonding states. This configuration facilitated the adsorption of PMS onto ${ \mathrm { C o - F e } } _ { 3 } { \mathrm { S } } _ { 4 }$ . The designed ${ \mathrm { C o - F e } } _ { 3 } { \mathrm { S } } _ { 4 }$ (asymmetric structure, low-spin Co) degraded $100 \%$ of the target pollutant APAP within 8 min with the modified kinetic rate constant (K-value) of $1 1 2 \mathrm { m i n ^ { - 1 } M ^ { - 1 } }$ . Further, DFT calculations indicated that the electron reversal $( \downarrow$ to $\uparrows$ or pairing (1,  to $\uparrow \downarrow , \downarrow$ of the 2p orbitals of the $\mathrm { O - } \mathrm { O }$ anti $\pi$ bond $( \pi ^ { * } )$ decreased the spin state, leading to the generation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ . The asymmetric structure catalyst was developed to promote the production of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , which efficiently degraded organic pollutants, and the mechanism of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ production was analyzed in detail.

ESR technology was implemented to identify the reactive oxygen species (ROS) generated within the system. To investigate the ROS, which played a major role in the APAP degradation, typical quenching experiments were performed. P-benzoquinone (BQ), tert-butyl alcohol (TBA), ethanol (EtOH), and furfuryl alcohol (FFA) were used as quenching agents for ${ \mathrm { O } _ { 2 } } ^ { \bullet - }$ , $\bullet _ { \mathrm { O H } }$ , $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , respectively.[30] The effects of quenching various active species on the APAP degradation were revealed. Because the lifetime of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ in $\mathsf { D } _ { 2 } \mathsf { O }$ is 1015 orders of magnitude longer than that in $\mathrm { H } _ { 2 } \mathrm { O }$ , through degradation experiments conducted in $\mathsf { D } _ { 2 } \mathsf { O }$ , the lifetime of $^ 1 { \bf O } _ { 2 }$ was prolonged, and the degradation efficiency was improved, confirming the existence of $^ 1 \mathrm { O } _ { 2 }$ (Figure S19a, Supporting Information). Recent studies have shown that when the catalyst reaction sites transferred electrons to the PMS, the PMS was reduced to free radicals.[32] Conversely, when the PMS transferred electrons to the catalyst reaction sites, the PMS was oxidized to ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ [8b,32]Electrochemical tests were performed to determine the direction of electron transfer between the catalyst and the PMS. # 3. Conclusion

In summary, the ${ \mathrm { C o - F e } } _ { 3 } { \mathrm { S } } _ { 4 }$ was synthesized with MIL101(Fe) as a template. Characterization revealed the introduction of Co resulted in the formation of an asymmetric Fe—S—Co structure. Strong interaction induced a low-spin state at the Co sites, promoting PMS adsorption and catalytic reaction. The ${ \mathrm { C o - F e } } _ { 3 } { \mathrm { S } } _ { 4 }$ showed outstanding degradation performance, degrading $100 \%$ of APAP in 8 min with a K-value of $1 1 2 \mathrm { m i n ^ { - 1 } M ^ { - 1 } }$ . It had numerous advantages, including a wide $\mathrm { p H }$ range, resistance to different anions in water, and good stability. According to experiments and DFT calculations, we have proposed a mechanism for ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ production. In this mechanism, ${ \mathrm { H S O } } _ { 5 } { } ^ { - }$ forms an $\mathrm { { } ^ { * } O } _ { 2 }$ intermediate after breaking the S—O bond. Subsequently, ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ is generated through the reversal (↓ to ) and pairing (, to ,  f $\mathrm { 2 p }$ orbital electrons in the $\mathrm { O - } \mathrm { O }$ anti $\pi$ bond. This work provided insights into the degradation of active drugs in water and the mechanism of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation.
