# Beyond Catalysts: Pioneering a New Era in Aluminum-Based Electrochemical Energy Systems

Vijayakumar Elumalai, Arunprasath Sathyaseelan, Swapnil Shital Nardekar, Muthukumar Perumalsamy, Arul Saravanan Raaju Sundhar, Agilan Perumal, Ji Hyun Jeong, and Sang-Jae Kim\*

Aqueous Aluminum-air batteries (AABs) hold promise for advancing high-energy density storage systems in future technologies. However, their widespread practical deployment is limited by the inherent hydrogen side reactions in Aluminum (Al) and incomplete cathodic reactions. To address these challenges, the Al-sodium persulfate $( \mathsf { N a } _ { 2 } \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } )$ system is introduced as an alternative to traditional AABs. Utilizing $N a _ { 2 } S _ { 2 } O _ { 8 }$ allows to simultaneously achieve three critical objectives, namely, eliminating the need for a cathode catalyst, increasing the system voltage from 1.4 to 2 V, and reducing the hydrogen evolution reaction (HER). Three distinct configurations of the Aluminum electrochemical energy system (Al-EES) using $N a _ { 2 } S _ { 2 } O _ { 8 }$ : static, flow, and gel are developed. The static configuration demonstrates a performance 1.7 times superior to that of traditional AABs. The flow configuration of Al-EES achieves a discharge duration of $7 7 \ h$ , which is three to four times longer than that of AABs and exhibits an energy density of 2,650 Wh ${ \mathsf { k g } _ { \mathsf { A l } } } ^ { - 1 }$ . This emerging technology has the potential to significantly enhance electric vehicles by providing powerful, efficient, cost-effective, and durable power-generation devices.

# 1. Introduction

Aluminum-air batteries (AABs) have garnered significant interest as potential next-generation energy storage solutions owing to their cost-effectiveness and high energy capacity.[1,2] Typically, primary AABs are composed of an Al anode, air cathode, and aqueous electrolyte. With a high energy density of

8131 Wh $\mathrm { k g _ { A l } } ^ { - 1 }$ , lightweight nature, and safety, AABs are promising for use in electric vehicles, telecommunications, and medical devices.[3] Despite these advantages, several challenges hinder their practical applications,[4] including the high corrosion rate of Al anodes, rapid self-discharge, and issues related to the cost and performance of cathode catalysts. To achieve satisfactory power density, AABs commonly use alkaline electrolytes such as potassium hydroxide (KOH) or sodium hydroxide (NaOH), rather than neutral electrolytes such as sodium chloride (NaCl).[5] However, the use of strongly alkaline electrolytes leads to hydrogen evolution reactions (HERs) at the anode, significantly reducing the actual specific capacities of conventional AABs to less than $60 \%$ of their theoretical values.[6] Consequently, enhancing the specific capacity of AABs requires the inhibition of HER at the Al anodes.

To date, researchers have proposed two primary strategies to mitigate the corrosion of Al anodes. The first strategy involves alloying Al with metals such as magnesium $( \mathrm { M g } )$ , tin $( \mathsf { S } \mathrm { n } )$ , indium (In), and gallium (Ga) to increase the overpotential for HER. The second strategy involves adding corrosion inhibitors, either inorganic or organic, to the alkaline electrolytes.[7] These inhibitors restrict the migration rate of water molecules, thereby preventing direct contact between water and the anode. Although these approaches effectively reduce anode corrosion to a certain extent, they also introduce drawbacks. Alloying Al with other metals or adding corrosion inhibitors increases the overall cost of the system. Furthermore, these modifications demand additional steps in the recycling process of Aluminum oxides, reducing the efficiency of the recycling process.

Oxygen is widely employed as a cathodic electron acceptor in AABs due to its high standard redox potential, abundant availability, and its reduction process produces harmless water as a byproduct. Despite their ability to directly utilize atmospheric oxygen, air cathodes in AABs often exhibit limited efficacy as electron acceptors due to the low solubility of oxygen $( 7 -$ $9 \mathrm { m g \ L ^ { - 1 } }$ at operational temperatures and suboptimal interactions at the electrode/electrolyte interface near the air surface.[8] Consequently, precious metals such as platinum $( \mathrm { P t } )$ are utilized to facilitate the cleavage of double bond in oxygen $( \mathrm { O = O } )$ .[9] Additionally, hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ serves as an alternative electron acceptor in metal batteries, especially in environments where air is inaccessible, such as in submarines and underwater unmanned aerial vehicles.[10,11] Nonetheless, because of their inadequate electron transfer kinetics and mass transport efficiency, these systems also rely on noble metal catalysts to enhance performance.

Recently, chemical electron acceptors (CEAs) have attracted attention owing to their high solubility in water, elevated reduction potentials, and rapid reduction kinetics, which aid in overcoming activation energy barriers and minimizing cathodic activation losses. CEAs such as ferricyanide $( \mathrm { [ F e ( C N ) _ { 6 } ] ^ { 3 - } } )$ , iron chloride $\left( \mathrm { F e C l } _ { 3 } \right)$ , dichromate $\scriptstyle { \left( \mathrm { C r } _ { 2 } \mathrm { O } _ { 7 } { } ^ { 2 - } \right) }$ ,hypochlorite $\left( \mathrm { C l O ^ { - } } \right)$ , vanadium oxide $( \mathrm { V } _ { 2 } \mathrm { O } _ { 5 } )$ , permanganate $\left( \mathrm { M n O _ { 4 } } ^ { - } \right)$ , and persulfate $\phantom { - } ( \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } )$ have demonstrated superior performance as electron acceptors in microbial and microfluidic fuel cells compared to oxygen[1218] Although $\mathrm { C l O ^ { - } }$ and $\mathrm { C r } _ { 2 } \mathrm { O } _ { 7 } { } ^ { 2 - }$ require catalysts for optimal performance, $\mathrm { M n O _ { 4 } } ^ { - }$ and ${ \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 5 }$ can be used without catalysts, despite the drawback of $\mathrm { M n O } _ { 2 }$ production, which can adhere to electrode surfaces, and the toxicity of ${ \mathrm { V O } _ { 2 } } ^ { + }$ that poses risks to water and soil. Among these CEAs, persulfate is recognized for its environmental friendliness, rapid reaction kinetics without requiring a catalyst, and easily soluble reduction products. Notably, the theoretical potential of persulfate (2.1 V) exceeds that of other CEAs and also Soraya et al. demonstrated that persulfate could inhibit the corrosion of Al.[1921]

Inspired by the advantages of Al and $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ , we propose a novel, cost-effective Aluminum electrochemical energy system (Al-EES) that eliminates the need for expensive platinum and membranes in the electrochemical system. The Al-EES is a unique type of electrochemical cell classified as a primary power system that generates electrical power through the redox reaction between the chemical energy of Al and persulfate. This proposed hybrid cell integrates an Al battery/fuel cell at the anode with a redox flow battery at the cathode. The impact of various operational parameters including electrolyte-oxidant concentrations, compositions, and different cathodes was thoroughly investigated. Furthermore, the discharge performance of the Al-EES system was evaluated to assess the stability of the cell.

The first capacitive loop in the high-frequency region is associated with the charge transfer resistance of the redox reaction $\mathrm { A l }  \mathrm { A l } ^ { + }$ , which is the rate-determining step in the charge transfer process of Al dissolution.[27] A larger arc radius in this loop suggests increased difficulty in charge transfer. The small inductive loop at intermediate frequencies is indicative of the adsorbed intermediate $\mathrm { \sf A l ( O H ) _ { 1 - 4 } }$ species on the Al surface. The second capacitive loop in the low-frequency region is attributed to the dissolution of corrosion products on the Al surface through a rapid complementary redox reaction $\mathrm { A l ^ { + } }  \mathrm { A l ^ { 3 + } }$ .

After adding $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ to the electrolyte, the Nyquist patterns remained largely unchanged, indicating that the corrosion mechanism was not significantly altered.[28] However, the diameter of the semicircles, which represent the charge-transfer resistance, increased considerably. This increase is attributed to the enhanced inhibition of Al corrosion due to the formation of a passivation layer on the Al surface. Additionally, changes in the inductive loop may result from the deposition of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ molecules on $\mathsf { A l } ^ { 3 + }$ , potentially altering the surface adsorption of the intermediates. The increase in the second capacitive loop suggests that the combination of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and NaOH forms a more robust passive layer compared to NaOH alone. Consequently, $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ serves as an exceptionally effective corrosion inhibitor for Al in alkaline solutions.

In the absence of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ in the electrolyte, significant corrosion and damage were observed on the Al surface, as evidenced by the FE-SEM images in Figure 3F(i) and S15-S17. These findings are supported by electrochemical and physicochemical studies, demonstrating optimal performance of our Al-EES approach in $3 \textrm { \textmu N N a O H } + 1 . 5 \textrm  \textmu$ $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ with minimal corrosion.

# 2.4. Performance Evaluation of Flow and Gel Type Al-EES System

To adapt the Al-EES technology for scalable real-time applications, a flow-type Al-EES was developed, consisting of an Al metal anode and a carbon cloth cathode separated by a flowfield plate (Figure 4A; Figure S1, Supporting Information). The system was designed to allow a mixture of NaOH and $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ to flow through the flow-field plate without accumulating byproducts, thereby mitigating self-discharge issues and extending the lifespan of the Al-EES. The performances of various flow batteries are comparatively visualized in Figure 4B, highlighting that the flow-type Al-EES surpasses established technologies such as vanadium and zinc bromide batteries in terms of power density and voltage. The Al-EES offers several advantages over traditional redox flow batteries; it separates the electrodes through a constant flow of electrolytes rather than using a typical ion-permeable selective membrane, and it replaces the two pumps and valves typically required in conventional flow batteries with a single flow system. These features enhance the mechanical simplicity and reliability of the Al-EES, rendering it particularly suitable for large-scale applications.

Figure 4C presents the polarization curve for the Al-EES flow system with dimensions of $2 \ \mathrm { c m } \times 2 \ \mathrm { c m }$ . Using an optimized electrolyte composition of $3 \mathrm { \textbf { M } N a O H + 1 . 5 \textbf { M } N a _ { 2 } S _ { 2 } O _ { 8 } }$ , the system achieves a maximum power output of $5 6 0 \mathrm { m W } ,$ corresponding to a power density of $1 4 0 \mathrm { ~ m W ~ c m ^ { - 2 } }$ , and exhibits the lowest resistance as depicted in Figure 4D. When the flow-type Al

EES system is discharged at various currents (Figure 4E), the discharge voltage decreases with increasing discharge current. At high current discharge conditions, a greater amount of Al must oxidize to maintain charge balance, which consequently leads to a thicker passivation layer than the one formed in the lower current discharge. This increase in layer thickness exacerbates the voltage downtrend, as the current density increases. Similar to fuel cells, the Al-EES system can operate continuously when supplied with $\mathrm { N a O H + N a _ { 2 } S _ { 2 } O _ { 8 } }$ At a discharge current of $1 0 0 ~ \mathrm { { m A } }$ , the cell operates for ${ \approx } 7 7$ h with a nominal voltage of ${ \approx } 1 . 4 \mathrm { ~ V ~ }$ and an energy density of 2,650 Wh $\mathrm { k g _ { A l } } ^ { - 1 }$ , which represents the longest runtime for an Al metal flow system without replacing the Al plate, as documented in Table S3 (Supporting Information). The continuous operation of Al-EES was facilitated by the constant flow of electrolyte and catholyte to the cell. This constant flow is crucial not only for efficient ion transport but also for stabilizing the redox reactions and ensuring favorable mass transfer at the anode surface. Furthermore, this constant flow helps maintain the passivation layer on the Al surface, thereby contributing to the stability and efficiency of the system.

To enhance the voltage, a stack of three cells connected in series using a graphite bipolar plate was constructed. This configuration achieved a cell voltage of $6 \mathrm { V }$ without any loss in voltage or power, delivering ${ \approx } 1 . 6 2$ W at a discharge current of $7 5 0 ~ \mathrm { m A }$ , as depicted in Figure 4F. The cell maintained a power output of $1 \ \mathrm { W }$ for $^ { 4 \mathrm { ~ h ~ } }$ , as illustrated in Figure 4G. In AAB cells, stacking the cathode and anode on the same surface poses challenges due to the use of oxygen at the cathode, which requires separation and an external serial connection.[42] In contrast, the Al-EES uses graphite plates to internally separate the cells, effectively reducing intercell resistance.

Furthermore, an Al-EES system with a total active area of $2 5 6 ~ \mathrm { c m } ^ { 2 }$ was fabricated, consisting of single cells each with an area of $6 4 ~ \mathrm { c m } ^ { 2 }$ connected in a series of four, as displayed in Figure 4H. This configuration allows the cell to deliver a maximum power of $3 2 \mathbb { W }$ at a discharge current of 6 A and ${ \approx } 6 \mathrm { V } .$ Based on these flow-type stack studies, we can conclude that the AlEES system can be effectively scaled up for practical applications at low cost, as it does not require expensive catalysts or membranes. Furthermore, the system does not use external inhibitors to control the HER; instead, persulfate acts as an inhibitor of Al self-corrosion.

We developed a gel-based Al-EES system using poly (sodium acrylate) gel (PSA), and the preparation details are provided in the Supporting Information. The PSA gel was immersed in a solution of $3 \mathrm { ~ M ~ N a O H }$ and 1.5 M $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ for $^ { 4 \mathrm { ~ h ~ } }$ .Subsequently, the device was assembled by placing the Al foil and CC between the soaked PSA gels, as illustrated in Figure 4I. This flexible gelbased Al-EES system exhibited a power density of $2 4 \mathrm { m W } \mathrm { c m } ^ { - 2 }$ , which exceeded the $2 1 \mathrm { m W } \mathrm { c m } ^ { - 2 }$ power density of the Al-air system using a $\mathrm { P t / C }$ cathode, as depicted in Figure 4J. At a constant discharge of $1 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ , the Al-EES system maintained a longer discharge time and higher voltage compared to the Al-air system, as displayed in Figure 4K. The voltage at $1 . 2 \mathrm { V }$ increased to $1 . 8 \mathrm { V }$ upon the addition of few drops of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ . The performance of this gel-based Al-EES surpassed that of previously reported airbased systems and other flexible devices, as detailed in Table S4 (Supporting Information).

# 2.5. Investigation of Anode and Cathode Reactions of Al-EES

To investigate the chemical composition and distribution of the anode and cathode, we conducted time-of-flight secondary ion mass spectrometry (TOF-SIMS) analysis $3 0 \mathrm { m i n }$ after discharge.

The TOF-SIMS analysis confirmed the presence of sulfate ions $( \mathrm { S O _ { 4 } } ^ { - } )$ as a by-product in the Al-EES system, as indicated in Figure S25 (Supporting Information). This finding is critical as it supports our proposed mechanism wherein persulfate ions serve as chemical electron acceptors at the cathode, leading to the formation of sulfate ions. Additionally, the analysis verified the presence of sulfate ions as well as provided detailed insights into their spatial distribution within the electrodes. Crucially, the analysis revealed the presence of persulfate ions $( \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { - } )$ and sulfate ions $( \mathrm { S O _ { 4 } } ^ { - } )$ on the surface of the Al anode, as displayed in Figures S25A,E, Supporting Information for $S _ { 2 } { O _ { 8 } } ^ { - }$ and Figure S23C,G (Supporting Information) for $\mathrm { S O } _ { 4 } ^ { - }$ . This layer acted as a corrosion inhibitor, preventing parasitic HER and enhancing anode utilization. Furthermore, the depth profiles indicated a greater concentration of these species at the cathode than at the anode, suggesting that the reduction reactions predominantly occurred at the cathode. Further to verify the movement of $\mathrm { N a ^ { + } }$ ion from the anode to the cathode, we utilized a sodium ion conducting membrane placed between the anode and cathode. This configuration also demonstrated an OCV of $2 . 2 \mathrm { V }$ (Figure S26A, Supporting Information). And delivering a constant current of $1 0 0 \mathrm { m A c m } ^ { - 2 }$ until the Al was fully depleted (as shown in Figure S26B, Supporting Information). These results further confirm the oxidation of Al at the anode and the reduction of sodium persulfate at the cathode, with $\mathrm { N a ^ { + } }$ ions moving across the membrane from anode to cathode to facilitate reduction reactions.

# 2.6. Applications of Al-EES from Miniaturized Devices to EVs

The Al-EES can generate power ranging from milliwatts to several watts (Figure 5D). Initially, we focused on the potential applications of Al-EES for small button cells and $1 . 5 ~ \mathrm { V }$ primary battery replacements. Using a 3D printer, a cell case was fabricated with two compartments, each having inner dimensions of $0 . 5 \mathrm { c m } \times 0 . 5 \mathrm { c m } \times 0 . 5 \mathrm { c m }$ , resulting in a total volume of $0 . 1 2 5 \mathrm { m L }$ (Figure 5A). In the first compartment, $0 . 0 5 \mathrm { m L }$ of a solution containing $3 \ \mathrm { ~ M ~ } \ \mathrm { N a O H }$ and $1 . 5 \mathrm { ~ M ~ N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ was added. The Al foil serving as the anode was encapsulated around the negative terminal of the wire, and a $0 . 1 \mathrm { m m }$ thick graphite rod serving as the cathode was attached to the positive terminal. The opposite ends of the wires were connected to the terminals of a digital clock. Upon immersing the anode and cathode in the solution, the digital clock was successfully powered.

The second compartment was filled with the same solution of $3 \ \mathrm { M } \ \mathrm { N a O H }$ and $1 . 5 \mathrm { ~ M ~ N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and a piece of CC measuring 0.25 $\mathrm { c m } ^ { 2 }$ was placed in the first compartment, whereas an Al sheet of identical dimensions was placed in the second compartment (Figure 5B). The CC and Al sheets were electrically connected using conducting silver paste. In this setup, the positive terminal of a green light-emitting diode (LED) was attached to the graphite rod, and the negative terminal was covered with Al foil. The LED was powered for at least $1 0 \mathrm { { h } }$ when the terminals were immersed in the respective compartments. A coin-sized container with two cells, each with an active area of $1 \mathrm { c m } \times 1 \mathrm { c m }$ , continuously powered 50 LEDs for $1 . 5 \mathrm { h }$ (Figure 5C). Additionally, a hydrogel-based flexible Al-EES was demonstrated for powering an emergency lamp using three cells connected in series (Figure 5E and Video S2, Supporting Information). Owing to the lightweight nature and high energy density of Al, Al-EES is particularly suitable for applications in electric vehicles (Figures 5FI).

Initially, a miniature car powered by an Al-EES measuring $0 . 5 \ \mathrm { {  c m } \times 0 . 5 \ \mathrm { { c m } } }$ was operated successfully for up to $6 0 \mathrm { m i n }$ (Figure 5F). Subsequently, we designed an electric vehicle equipped with two $1 2 \mathrm { ~ V ~ }$ motors measuring $4 0 \mathrm { c m }$ in length and $2 5 \mathrm { c m }$ in width. An Al-EES stack, consisting of six $4 \mathrm { c m } \times 4$ cm cells connected in series, was created (Figure 5H). A similar stack was constructed, and the two were connected in parallel to produce $1 2 \mathrm { V } .$ Both the positive and negative terminals of the Al-EES stack were connected to each $1 2 \mathrm { ~ V ~ }$ motor, powering the electric vehicle for a total operational time of $4 0 \mathrm { m i n }$ . The supplementary document includes a video (Video S3, Supporting Information) demonstrating the vehicle in action.

# 2.7. Recovery and Cost Analysis of Al-EES

After the vehicle operation, the consumed Al was converted into Aluminum hydroxide $\left( \mathrm { A l } ( \mathrm { O H } ) _ { 3 } \right)$ , and $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ was reduced to sodium sulfate $( \mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 } )$ . The byproduct, $\mathrm { A l ( O H ) } _ { 3 }$ , is completely insoluble and settled out of the solution, whereas ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ is highly soluble and remains in the solution. Simple separation was achieved by filtering and utilizing the differing solubility properties of $\mathsf { A l } ( \mathrm { O H } ) _ { 3 }$ and ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ . The solution containing the ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ and NaOH mixture was further processed by adding twofold methanol, which precipitated the $\mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 }$ , enabling its removal through filtration. We propose that electrolyzing the mixture to regenerate sodium persulfate may be more efficient than separating $\mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 }$ . Previous studies have reported the electrochemical conversion of ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ back to $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ [41,42]

In our future research, we aim to regenerate $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and reuse it in subsequent cycles. We conducted X-ray diffraction (XRD) and energy-dispersive X-ray spectroscopy (EDAX) analyses on the recovered $\mathrm { A l ( O H ) } _ { 3 }$ and ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ , as detailed in Figures S27S29 (Supporting Information). The XRD patterns of $\mathsf { A l } ( \mathrm { O H } ) _ { 3 }$ displayed a strong correlation with the Joint Committee on Powder Diffraction Standards (JCPDS) card 536399, indicating an orthorhombic phase and a purity of ${ \approx } 9 9 . 9 \%$ according to the EDAX analysis. Similarly, the ${ \mathrm { N a } } _ { 2 } { \mathrm { S O } } _ { 4 }$ correlated well with JCPDS card no. 371465. The recovery results strongly suggest that replacing air with persulfates (catholytes) did not compromise the energy cycle of Al, as illustrated in Figure 6A.

Financial analysis is crucial for evaluating the feasibility of sustainable technologies. In a cost comparison, AABs use ${ \approx } 6$ M KOH as the electrolyte, whereas Al-EES systems use a mixture of $3 \textbf { M }$ $\mathrm { \Delta N a O H }$ and $1 . 5 \mathrm { ~ M ~ } \mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ Given that the costs of $\mathrm { \Delta N a O H }$ and $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ are equal at $2 \mathrm { U S D } / \mathrm { k g }$ , Al-EES maintains the same electrolyte cost despite using an external oxidant. Furthermore, persulfates can operate without a catalyst and help control the selfcorrosion reaction of Al. Economic analysis was conducted for a $1 \mathrm { m } ^ { 2 }$ cathode based on bench-scale results (Table S5, Supporting Information).[43] As estimated, the total capital investment for catalyst-free cathode (CC) and $\mathrm { P t / C }$ catalysts for an area of 1 $\mathrm { m } ^ { 2 }$ will be 350 USD and 3020 USD, respectively. Consequently, removing the catalyst from the cathode reduces the cathode price by $8 7 . 3 2 \%$ , including the catholyte cost, as displayed in Figure 6B.

Moreover, this approach decreases the capital investment required for fabricating air cathodes, which involve high-cost techniques such as spray coating, drop casting, screen printing, electrodeposition, inkjet printing, dip coating, physical vapor deposition, and chemical vapor deposition. We believe that further optimization of flow, temperature, and Al composition, and activation through a physical method, such as ultrasound or ultraviolet, enable the Al-EES system for real-world applications. Further, the developed configuration emphasizes the shift from catalyst-dependent systems to more versatile, easily enhanced alternatives, marking a substantial advancement in the field of electrochemical energy systems.
