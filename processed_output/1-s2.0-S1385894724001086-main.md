# . Introduction

Phenolic compounds are well known as persistent and harmful pollutants which are present in wastewater of various industries, thus presenting a serious threat to ecosystems and human health [1]. Among these pollutants, bisphenol A (BPA) is an endocrine disrupting contaminant that can be found in different concentrations in many consumer products such as personal care products, tableware and medical supplies [2]. Due to its widespread industrial use, BPA has been detected in environmental matrices (such as soil, sediments, groundwater, surface water, air) and food [3]. Other phenolic compounds including phenol and p-nitrophenol which are used in a wide range of chemical syntheses and as pesticides, respectively, can be also bioaccumulated, thus being considered highly toxic [4,5]. Advanced oxidation processes (AOPs) have attracted a lot of interest for their high efficiency in the treatment of water pollution [6]. Furthermore, compared to the other existing technologies such as adsorption [7], flocculation [8], biodegradation [9] and membrane filtration [10], AOPs are very promising because they induce rapid degradation of organic pollutants into less harmful substances or completely convert them to carbon dioxide $\left( \mathrm { C O } _ { 2 } \right)$ , water, and inorganic ions [11]. Usually, hydroxyl radicals (HO•, $\mathbf { E } ^ { 0 } = 1 . 9 – 2 . 7 \mathrm { ~ V ~ }$ vs. NHE) are the most common reactive oxygen species (ROS) in AOPs and are non-selective for the degradation of almost all organic pollutants. In addition, sulfate radicals $( S 0 _ { 4 } ^ { \bullet - \cdot }$ based AOPs (SR-AOPs) have become a more promising research direction since $S O _ { 4 } ^ { \bullet - }$ has a longer half-life, greater oxidation capacity $( \mathrm { E } ^ { 0 } = 2 . 5  – 3 . 1$ and a wider $\mathsf { p H }$ range stability compared to HO• [1215]. Moreover, $S O _ { 4 } ^ { \bullet - }$ is more selective for the degradation of organic compounds containing aromatic group constituents than the hydroxyl radicals [16,17].

Sulfate radicals can be produced by homolytic cleavage of peroxydisulfate (PDS) and unsymmetric cleavage of peroxymonosulfate (PMS), which can be activated by either light, heating, or alkaline earth and transition metals [1821]. However, these activation processes limit their application at larger scales than laboratory conditions. For example, some transition metal ions can be either harmful to organisms or unstable at natural pH, thus leading to pH limitation and sludge formation [22]. Heterogeneous catalysts are a potential response to these problems since they are stable at natural pH and can efficiently trigger SR-AOPs [23]. Therefore, the development of transition metalcontaining heterogeneous catalysts for the activation of PDS and PMS for the degradation of organic pollutants has been a popular research topic [2430].

Many ferrites, including spinel ferrites, have been already reported to be efficient catalysts for the degradation of organic pollutants [27,31]. $M _ { \mathrm { F e _ { 2 } O _ { 4 } } }$ is the typical formula of spinel ferrites, where $M = \mathbf { M } \mathbf { n }$ Ni, Cu, Zn [3235]. Copper ferrite $\mathrm { ( C u F e _ { 2 } O _ { 4 } ) }$ , has received considerable attention in water treatments due to its high magnetic permeability, excellent chemical and mechanical stability, and widespread application in PDS and PMS activation [3638]. Moreover, $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ is a semiconductor with a band gap energy of $1 . 7 { - } 1 . 9 \ \mathrm { e V }$ [39,40]. So it can be also used as photocatalyst under either visible or UVA light, since such energies are sufficient to excite electron from the valence band (VB) to the conduction band (CB), thus enabling the production of ROS like HO• [39,40]. Although the excellent efficiency of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ has been explained by its ability to activate PDS and PMS into HO•, $S O _ { 4 } ^ { \bullet }$ , singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ , there are still some discrepancies in the current published works that do not use a comprehensive approach, thus leading to a lack of detailed explanation between the differences of activation mechanisms in $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S }$ and $\mathrm { C u F e _ { 2 } O _ { 4 } / P D S }$ systems. For example, Jun Li et al. [41] highlighted a combination of $S O _ { 4 } ^ { \bullet - }$ , OH and non-radical pathways in the $\mathrm { C u F e _ { 2 } O _ { 4 } / P D S }$ system, whereas the $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S }$ system reported by Yaobin Ding et al. [18] led to a mechanism dominated by $S O _ { 4 } ^ { \bullet - }$ . Furthermore, the differences in the activation mechanisms in the dark and under UVA light have not been yet thoroughly compared.

In this study, the ability of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ synthesized in the form of nanopowder was evaluated through the degradation of BPA as model pollutant at concentration of $2 5 \mu \mathrm { M }$ as in other similar works [4244]. Indeed, the detected BPA in the natural aquatic environment often exceeds the limit set by the European Union i.e., $1 5 0 0 ~ \mathrm { n g / L }$ , thus reaching much higher concentrations by accumulation effect [4244]. The effects of UVA light, nanopowder and oxidant dosage on the BPA degradation efficiency were investigated. The different activation mechanisms and involvement of reactive species generated from PMS and PDS containing systems were elucidated. Finally, the simultaneous degradation of different phenolic compounds (BPA, phenol and $\mathbf { p }$ nitrophenol) using $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ were investigated in real water matrices to highlight potential applications. Besides, this work aims to highlight ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ -PMS/PDS as a prominent SR-AOPs that offers a cost-effective and sustainable treatment that could be integrated into a municipal wastewater treatment plant as post-treatment. This approach could also offer an ecological benefit by discharging purified treated wastewaters that can either contribute to the environmental protection or be reused in the circular economy.

# 2.2. Preparation and characterization of $C u F e _ { 2 } O _ { 4 }$

${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanopowder was synthesized using a hydrothermal method with polyethylene glycol (PEG) as a structure directing agent and metal nitrate as precursors [27,45]. Briefly, $4 0 ~ \mathrm { m L }$ solutions of $5 0 ~ \mathrm { m M }$ Cu $( \mathrm { N O _ { 3 } } ) _ { 2 } { \cdot } 3 \mathrm { H _ { 2 } O }$ and $1 0 0 \mathrm { \ m M \ F e ( N O _ { 3 } ) _ { 3 } . 9 H _ { 2 } O }$ were mixed in the presence of $_ { 1 g }$ of PEG under magnetic stirring for $3 0 \mathrm { { m i n } }$ . After adjustment of pH to 12 (using NaOH solution), the solution was transferred in an autoclave and subsequently heated for $2 4 \ \mathrm { h }$ at $1 6 0 ~ ^ { \circ } \mathrm { C }$ After cooling down, the nanopowder was collected by centrifugation ( $8 0 0 0 ~ \mathrm { r p m }$ for $5 \mathrm { { m i n } }$ and was washed with distilled water and ethanol (three washing stages). ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanopowder was obtained by drying at $8 0 . 0 \ ^ { \circ } \mathrm { C }$ overnight and annealing at $5 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ $( 2 . 5 \ ^ { \circ } \mathbf { C } \ \operatorname* { m i n } ^ { - 1 \cdot }$ ).

The crystalline phase composition of the nanopowder was investigated by X-ray diffraction (XRD) using PANalytical X-ray diffractometer (Cu Kα, $\lambda = \overset { \cdot } { 1 . 5 } 4 1 8 \overset { \circ } { \mathrm { A } }$ . The surface morphology was analyzed by scanning electronic microscope coupled to energy dispersive X-ray spectroscopy (SEM/EDX) using Tescan Lyra III instrument. Transmission electron microscopy (TEM) was performed on JEOL JEM ARM $2 0 0 ~ \mathrm { c F }$ instrument. The chemical state of the elements at the surface of the nanopowder was investigated by $\mathbf { X }$ ray photoelectron spectroscopy (XPS) equipped with monochromatic Al Kα X-rays (1486.6 eV) and spectra was measured at ambient temperature with photoemission of $4 5 ^ { \circ }$ from the surface. A low energy electron gun (below 1 eV) had been used for charge neutralization to reduce the effects of charging. The XPS analyses was performed before and after the use of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ to characterize its surface composition but also to clarify the mechanism of PDS and PMS activation. Also, the valence band maximum (VBM) was also determined using ultraviolet photoelectron spectroscopy (UPS) by a He discharge lamp with a photon energy of 21.22 eV. To investigate the stability of the nanopowder, the concentration of leaching metals including Cu and Fe was determined during the pollutant degradation by atomic absorption spectrophotometry (AAS, PerkinElmer). The samples were first filtered using a PTFE $0 . 2 2 \mu \mathrm { m }$ filter prior for analyses while $1 0 ~ \mu \mathrm { M }$ of $\mathrm { F e } ( \mathrm { S O } _ { 4 } )$ and $\mathrm { C u } ( \mathbf { S O } _ { 4 } )$ solutions were prepared and used for the calibration curves. For the calibration curves, dissolved Fe and Cu standard solutions were used in the range $0 - 2 5 ~ \mu \mathrm { M }$ The detection wavelength was set at $2 4 8 . 3 \ \mathrm { n m }$ and $3 2 4 . 8 \ \mathrm { n m }$ for iron and copper, respectively.

# 3.3. Oxidant activation mechanism and involvement of reactive specie:

To gain in-depth mechanistic insights into the oxidant activation in $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S }$ and $\mathrm { C u F e _ { 2 } O _ { 4 } / P D S }$ systems, scavenging experiments had been conducted to identify the generated reactive oxygen species (ROS) both in the dark and under UVA light (Fig. 4 and S6).

In the presence of TBA, Isop, or a combination of Isop $^ +$ FFA in the $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S }$ system, noticeable reductions in the degradation constants of BPA were observed, with values decreasing from 0.112 to 0.059, 0.045, and $0 . 0 1 8 \mathrm { m i n } ^ { - 1 }$ , respectively (Fig. 4a). In the presence of UVA light, the BPA degradation constants also decreased from 0.211 to 0.159, 0.047, and $0 . 0 2 7 \mathrm { m i n } ^ { - 1 }$ following the introduction of TBA, Isop, Isop $^ +$ FFA (Fig. 4a). Regarding the contribution of these ROS in the degradation of BPA (Text S2), HO' played a predominant role in the dark $( 4 7 \% )$ while $S O _ { 4 } ^ { \bullet - }$ was identified as the main reactive specie under UVA light $( 5 3 ~ \% )$ . In addition, the PMS containing systems had been also purged using $\Nu _ { 2 }$ to eliminate dissolved $\mathrm { O } _ { 2 }$ , At such conditions, a decrease of BPA degradation rate of $7 3 \ \%$ in the dark and $6 6 ~ \%$ under UVA light was observed, thus indicating that a part of ROS was derived not only from dissolved $\mathrm { O } _ { 2 }$ but also by the activation of PMS. On the other hand, in the $\mathrm { C u F e _ { 2 } O _ { 4 } / P D S }$ systems (Fig. 4b), the addition of the different scavengers led to a small decrease of the BPA degradation constant, thus highlighting a limited contribution of HO•, $S O _ { 4 } ^ { \bullet - }$ and $^ 1 0 _ { 2 }$ . These results are not consistent with previous studies (Table S3), as most of $\mathrm { C u F e _ { 2 } O _ { 4 } / P D S }$ and $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S }$ systems were dominated by the radical pathway. Indeed, our study puts emphasis on the mechanistic elucidation in such systems that are not comprehensively approached in the literature, thus leading to discrepancies. In addition, the $\mathrm { N } _ { 2 }$ purging experiments demonstrated a slight impact of oxygen concentration on the degradation of BPA, suggesting the presence of non-radical degradation pathway.

To further clarify the mechanism of oxidant activation, the generation of high valent iron was first checked since surface Fe(III) might be oxidized into Fe(IV) [20]. Fe (IV) can react with PMSO to produce $\mathrm { P M S O } _ { 2 } \left( \mathrm { F e } ( \mathrm { I V } ) { : } \mathrm { P M S O } _ { 2 } { = } 1 { : } 1 \right)$ , but in all the investigated systems, no $\mathrm { P M S O _ { 2 } }$ was detected (Fig. S8) which excludes the role of Fe(IV) in the activation of PMS and PDS.

It might be plausible that the leached metal from ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ i.e., $\mathrm { C u ^ { 2 + } }$ and $\mathrm { F e } ^ { 3 + }$ can be involved in the activation of PMS and PDS via homogeneous reactions. # 3.4. Reusability of $C u F e _ { 2 } O _ { 4 }$ and its application in different water matrices

In order to assess the reusability of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 } ,$ the degradation of BPA was tested during recycling experiments. As shown in Fig. 7, the $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S / }$ UVA system demonstrated a higher degradation efficiency than the PDS containing system at the first use.

However, the BPA degradation in the PMS containing system significantly decreased from $1 0 0 \%$ to $3 2 \%$ in the second cycle with the reuse of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ (Fig. 7). On the contrary, ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ was much more stable for activating PDS (Fig. 7), since a slower decrease was observed with BPA degradation efficiency degrading from $7 2 \ \%$ , to $2 9 \ \%$ after three cycles. The observed decrease can be due to the leaching of copper which was more significant in the PMS containing system, thus explaining the differences between PMS and PDS containing systems. Also, the XPS analyses showed significant changes at the surface of the $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ after its use for PMS and PDS activation, and that might also a reason to explain its low reusability.

The degradation efficiency of ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ in pure water, TW and STPW was investigated for three phenolic organic pollutants (BPA, phenol and p-nitrophenol) (Fig. 8). In pure water system (Fig. 8a), all target pollutants can be completely degraded within $2 0 \ \mathrm { m i n }$ in $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S / }$ UVA. As expected, the degradation rate of all three pollutants decreased significantly in both the tap water (Fig. 8c) and STPW (Fig. 8e). This effect was due to presence of inorganic anions and natural organic matter, which can partially quench the generated ROS. However, in STPW (Fig. 8e), phenol and p-nitrophenol were degraded up to $9 0 \%$ and $6 1 \ \%$ ,which were good degradation extents after only $3 0 \ \mathrm { \ m i n }$ in $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S / }$ UVA system. The degradation efficiencies for the three pollutants in this system followed the order $\mathbf { B P A } >$ phenol $>$ p-nitrophenol, which was the same observed trend as in the case of the PDS system. In this latter system, although the degradation of BPA remained relatively efficient in pure water $( 1 0 0 \% )$ , TW $( 7 5 \% )$ and STPW $( 6 4 \% )$ , the degradation rate of phenol and p-nitrophenol significantly decreases in TW and STPW (Fig. 8b, d and f).

The degradation efficiencies observed for the three phenolic compounds can be correlated with their $\mathrm { O - H }$ bond dissociation energies (BDE) where the values have been already reported by H. Su et al. [73] (Table S1). In addition, for phenolic organic contaminants, the BDE of CH bond is higher than that of O-H bond, thus the compounds with electron donating groups (such as OH) are more reactive. Therefore, BPA which had a smaller BDE and more electron-donating groups compared to phenol and p-nitrophenol was easier to degrade.

# 4. Conclusion

In this study, the mechanism of PMS and PDS activation using $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ both in the dark and under UVA light was clarified while the effect of different experimental parameters on the BPA degradation was also investigated to determine optimal conditions. In brief, the selected conditions were $0 . 5 g / \mathrm { L }$ ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ and $2 \mathrm { m M }$ PMS/PDS at $\mathrm { p H } _ { 0 } = 6 . 2$ For the degradation of BPA, $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ coupling with PMS demonstrated better degradation than PDS-containing systems. The reaction rate constants of BPA degradation followed the order: $\mathrm { C u F e _ { 2 } O _ { 4 } / P M S / U V A }$ $( 0 . 2 1 1 \ \mathrm { m i n ^ { - 1 } } ) > \mathrm { C u F e _ { 2 } O _ { 4 } / P M S }$ $( 0 . 1 1 2 \ \mathrm { m i n ^ { - 1 } } ) > \mathrm { C u F e _ { 2 } O _ { 4 } / P D S / U V A }$ $( 0 . 0 1 8 \ \mathrm { m i n } ^ { - 1 } ) > \mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 } / \mathrm { P D S }$ $( 0 . 0 1 1 \ \mathrm { m i n } ^ { - 1 } )$ Radical quenching experiments suggested that the BPA degradation followed a radical pathway in PMS-containing systems with $S O _ { 4 } ^ { \bullet - }$ as the main reactive species while a non-radical pathway was predominant in PDScontaining systems. Indeed, xPS analyses exhibited that surface copper played an important role and electron transfer from the pollutant to the nanopowder and then to PDS was suggested. The stability of $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ exhibited leaching of $\mathrm { C u } ^ { 2 + } ( 2 6 . 1 \ : \mathrm { m g / L }$ under PMS system and $1 . 7 ~ \mathrm { m g / L }$ under PDS system), thus highlighting that this nanopowder cannot be reused, especially for PMS activation. However, regarding the complexity of tap and sewage treatment plant waters, the activation of PMS by $\mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 }$ nanopowder exhibited excellent performance. In conclusion, the obtained results, especially for the ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ -PMS system, have shown a relatively high treatment efficiency along with a limiting impact of competitive reactions in real water matrices. Furthermore, the efficiency of the systems under circumneutral pH has a direct economic impact, thus being promising for a potential integration to a municipal wastewater treatment plant as post-treatment since pH adjustment to acidic conditions is usually required and expensive. Therefore, the treated wastewaters by this technology might be reused in the circular economy of water.
