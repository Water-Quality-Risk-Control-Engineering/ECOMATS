# Hexagon AgNCs/PVP Crystallization Induced Cathode Electrochemiluminescence Enhancement for miRNA221 Biosensing

Bin Wang, Guangjie Wang, Jing Li, Xinling Liu, Nan Ni, Huilan Su, Mei Chen, and Li Mao\*

Aggredation-induced electrochemiluminescence (AIECL) promises an efficient strategy for synthesize highly luminescent emitter and co-reactant for ECL analysis, however, rational control of electrogenerated emission intensity is still challenging. The low electroconductivity and amorphous molecular configuration are intrinsic bottleneck. This work reveals the impact of polyvinyl pyrrolidone backbone regulated silver nanocrystallines (AgNCs/PVP) on the cathode AlECL properties in near infrared region, by employing the Box-Behnken designed response surface computation model to modulate crystal aggregates. Electron paramagnetic resonance spectroscopy discovered hydrogen radical (HO%) dominant reductive-oxidative (R-O) ECL mechanism with AgNCs acting as the co-reaction accelerator in graphene oxide/persulfate system $( \mathsf { G O } / \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } )$ . Both theoretical calculation and experimental measurement testified that the ECL of AgNCs in $\mathsf { C O } / \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - }$ dependent on the concentration of in situ electrochemical oxidized ${ \pmb { \mathsf { A } } } { \pmb { \mathsf { g } } } ^ { + }$ . The high efficiency of crystallization-induced enhanced ECL (CIECL) originates from 1) the effective electron transfer of ${ \pmb { A } } { \pmb { g } } ^ { + }$ accelerated HO' produce to notable promote radioactive transition, and 2) twisted intramolecular charge transfer from the electron-rich donor of PVP to electron-deficient receptor of $\mathsf { A } \mathsf { g } ^ { 0 }$ to restrict nonradioactive transition. The $\mathsf { A g N C s } / \mathsf { P V P }$ with CIECL effect are applied to construct an ultrasensitive platform for miR-221 assay with a lower detection limit of $7 . 4 7 \times 1 0 ^ { 3 }$ copies $\mathsf { m L } ^ { - 1 }$ than typical qPCR method.

# 1. Introduction

Aggredation-induced electrochemiluminescence (AIECL) is an intriguing phenomena that was classified as the fact that the aggregation-induced emission (AIE) property and enhanced electrochemiluminescence (ECL) intensity exhibits aggregates rather than in dispersion phase.[13] Since Bardl4] found the slight AIECL of donor—acceptor- $\pi$ bond-acceptordonor type conjugated polymer spiro-2,1,3-benzothiadiazole nanoparticles in water over that in THF until Colal1] put forward the concept of AIECL in 2017, much effort has been payed to develop species of AIECL materials, involving Pt/Ir complex,[4,5] polymer dots,[6,7] and organic dots.[8,9] Along with the blossom of AIECL materials over the past five years, majority projects focused on molecular designs, aggregate morphology and mechanistic study due to the connection between structure and high-efficient ECL mechanism.

ECL mechanism are grouped into annihilation and co-reactant ECL, among that co-reactant mechanism ushered in major research direction.[912] Due to the excited intermediates mostly produced in anode or cathode electrode, co-reactant behavior was sorted into oxidative-reductive (O-R) and reductive-oxidative (R-O) types.[4] Most reported aggregates of inorganic complex and polymer dots belong to O-R ECL, for instance $\mathrm { P t } \mathrm { - P E G } _ { 2 }$ {4] $\mathrm { I r ( d f p p y ) } _ { 2 } ( \mathrm { P V P / S } ) _ { 2 }$ {[5] 9-(diphenylmethylene)-9H-fluorene conjugated 9,9-dioctyl9H-fluorene polymer dots (DPF-DOF PDots),[6] 6-[4-(N,N-diphenylamino)phenyl]-3 -ethoxycarbonyl coumarin nanoparticles (DPA-CM NPs)7] and tetraphenylethylene microcrystals (TPE MCs),8] whereas only a few of semiconductor dots and organic dots show R-O ECL (such as $\mathrm { C _ { 3 } N _ { 4 } Q D s , ^ { [ 9 ] } }$ BN QDs,[10] caboranyl carbazoles[11] and tetraphenylsiloes[12]). The finite R-O AIECL generally focused on $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ co-reactant systems, whose capability dependent on two features of aggregation-induced emission and cathode electrochemical redox-induced luminescence.

The high-efficient cathode ECL tend to appear in this kind of co-reactant with high stable organic archetypes of AIE backbone that either restricted intra-/intermolecular rotation (RIM)(8] via substituent to reduce energy loss, or promote twisted intramolecular charge transfer(TICT)3,14)vi donor—acceptor (DA) molecular designs to minimize non-radioactive decay, or form band-gap transition via hole-electron injection.[15] Although kinds of organic backbone have been applied to guarantee AIE property, the low elector-conductivity of organic molecules or amorphous molecular configuration is still the intrinsic bottleneck to confine AIECL efficient. Liu et al. designed micro-crystalline of tetraphenyl alkene to solve this pesky problem, whilst proposing the concept of crystallization-induced enhanced ECL (CIECL).[16] Adsetts and his co-author synthesized AIE-types carbon quantum dots emitter in $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ coreactant systems to promise in optoelectronics.[17]

Notably, metal materials generally possess both electorconductivity and AIE feature. Five implications advise for AIE of metal nanoclusters are summarized over the past few years:[1820] 1) building polymers that sequence metal (I) species with oligopolies to protect metal shall; 2) increasing the load of metal (I) species to induce significant metallophilic interactions; 3) intensifying metal-ligand bonds for possible ligandmetal charge transfer or ligandmetalmetal charge transfer; 4) improves the rigidity of the shell by surface engineering; and 5) increasing the load of inter-cluster packing by self-assembly, crystallization, or using some kind of spatially confined scaffold to warp metal nanoclusters. Moreover, as subtle changes might cause completely differentiated results, the procedures of forming aggregates have been modulated via reprecipitation, ultrasonication, microemulsion.[3,20]

Enlightened by these molecular designs experience, the polyvinyl pyrrolidone backbone regulated nano-silver crystallization aggregates $( \mathrm { A g N C s } / \mathrm { P V P } )$ was designed to develop new AIECL material as the co-reaction accelerator for cathode ECL of graphene oxide/persulfate $\mathrm { ( G O / S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - } \mathrm { ) }$ system. Here, with the help of Box-Behnken analog computation model, the subtle size change was elaborately modulated to yield hexagon silver nanocrystalline with certain size and explore their CIECL property in near infrared region. Electron paramagnetic resonance spectroscopy (EPRs) revealed an AgNCs co-reaction accelerated R-O ECL mechanism via measuring resonant absorption of the unpaired electron spins in this R-O system exposed to the static magnetic field. The CIECL of co-reaction accelerator of AgNCs/PVP can be exploited into gain ultrasensitive miRNA biomarker assay in early stages of cancer disease.

The crystallization induced cathode ECL enhancement behavior was explored in Figure 3D-I. An elliptical contour plot from

# 3. Conclusion

The crystallization-induced enhanced cathode electrochemiluminescence of H-AgNCs was revealed in $\mathrm { { G O } / { S _ { 2 } \mathrm { { O } _ { 8 } } } ^ { 2 - } }$ coreaction system. Both BBD theoretical calculations and EPR experiments suggested that the CIECL emissions are closely associated with $\mathrm { A g ^ { + } }$ concentrations and nanocrystal morphology. Interestingly, large size AgNCs possess an intense acceleration for hydroxyl radical chain reaction via a coreactant pathway, due to the unique crystallization aggregates that significantly promotes radiation transitions while suppressing non-radiative transitions. Hence, the CIECL of AgNCs with strong cathode ECL signal not only initiate new ECL strategy but also are highly efficient ECL labels for superior biosensing.
