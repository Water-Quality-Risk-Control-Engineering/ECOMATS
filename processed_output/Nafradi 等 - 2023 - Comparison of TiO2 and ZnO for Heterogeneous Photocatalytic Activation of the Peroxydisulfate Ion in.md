Abstract: The persulfate-based advanced oxidation process is a promising method for degrading organic pollutants. Herein, $\mathrm { T i O } _ { 2 }$ and $Z _ { \mathrm { { n C } } }$ photocatalysts were combined with the peroxydisulfate ion (PDS) to enhance the efficiency. $Z _ { \mathrm { { n C } } }$ was significantly more efficient in PDS conversion and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ generation than $\mathrm { T i O } _ { 2 }$ . For $Z _ { \mathrm { { n O } _ { \it { i } } } }$ , the PDS increased the transformation rate of the trimethoprim antibiotic from $1 . 5 8 \times 1 0 ^ { - 7 } \mathrm { M } \mathrm { s } ^ { - 1 }$ to $6 . 8 3 \times 1 0 ^ { - 7 } \mathrm { M } \mathrm { s } ^ { - 1 }$ . However, in the case of $\mathrm { T i O } _ { 2 }$ , the moderated positive effect was manifested mainly in $\mathrm { O } _ { 2 }$ -free suspensions. The impact of dissolved $\mathrm { O } _ { 2 }$ and trimethoprim on PDS transformation was also studied. The results reflected that the interaction of $\mathrm { O } _ { 2 }$ , PDS, and TRIM with the surface of the photocatalyst and their competition for photogenerated charges must be considered. The effect of radical scavengers confirmed that in addition to $\mathrm { S O _ { 4 } ^ { \bullet - } }$ , •OH plays an essential role even in $\mathrm { O } _ { 2 }$ -free suspensions, and the contribution of $\mathrm { S O _ { 4 } ^ { \bullet - } }$ to the transformation is much more significant for $Z _ { \mathrm { { n O } } }$ than for $\mathrm { T i O } _ { 2 }$ . The negative impact of biologically treated domestic wastewater as a matrix was manifested, most probably because of the radical scavenging capacity of $\mathrm { C l ^ { - } }$ and $\mathrm { H C O } _ { 3 } ^ { - }$ . Nevertheless, in the case of $Z _ { \mathrm { { n O } } }$ , the positive effect of PDS successfully overcompensates that, due to the efficient $\mathrm { S O _ { 4 } ^ { \bullet - } }$ generation. Reusability tests were performed in Milli-Q water and biologically treated domestic wastewater, and only a slight decrease in the reactivity of $Z _ { \mathrm { { n O } } }$ photocatalysts was observed.

# 1. Introduction

Nowadays, environmental pollution, including water pollution, has received particular attention, and treating water pollutants has become an urgent task due to the biologically active and non-biodegradable organic contaminants, such as pharmaceuticals, which cannot be removed entirely using conventional water treatment methods. The global use of antibiotics and the increase of their concentration in wastewater is still growing [1–3]. During wastewater treatment, a significant part of the antibiotics and some of their metabolites can often remain in the effluent and reach surface waters, leading to the emergence of antibiotic-resistant bacterial strains, resulting in more than 70,000 deaths yearly worldwide [4]. Their emergence in wastewater and release to wastewater treatment plants can have significant effects, as they might act as reservoirs of antibiotic-resistant genes [5,6]. Therefore, effective elimination of these contaminants requires additive, tertiary water treatment methods and improvements in the existing technologies.

Advanced oxidation processes (AOPs) based on the in situ generation of strong oxidants have been developed to remove non-biodegradable organic pollutants. Most

AOPs are based on the hydroxyl radical $( { } ^ { \bullet } \mathrm { O H } )$ generation, but in recent years methods based on the sulfate radical ion $( \mathrm { S O _ { 4 } } ^ { \bullet - } )$ have been gaining popularity [7,8]. The $\mathrm { S O _ { 4 } ^ { \bullet - } }$ has a similar redox potential but a longer lifetime than •OH [9,10]. Moreover, the easy activation of peroxymonosulfate (PMS) and peroxydisulfate (PDS) to produce $\mathrm { S O _ { 4 } ^ { \bullet - } }$ makes this method favorable. The application of PDS is more advantageous due to its higher oxidation potential, stability, and lower production costs than PMS [11]. From PDS, the $\mathrm { S O _ { 4 } ^ { \bullet - } }$ can be generated in situ by cleaving the O–O bond, which can be achieved by electron transfer [12,13] or by energy transfer through introducing energy in the form of photons [14,15] or heat [16]. In the case of different AOPs, the application of PDS is often mentioned as an alternative to the application of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ —the effectiveness of PDScombined methods can usually exceed the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -combined processes, partly due to the higher steady-state concentration of reactive species.

The excitation of the photocatalyst results in charge separation. The photogenerated electrons $\left( \mathrm { e } _ { \mathrm { C B } } { } ^ { - } \right)$ and holes $\mathrm { ( h _ { V B } + ) }$ can reduce and oxidize substrates adsorbed on the photocatalyst surface, respectively, or they can recombine with each other and disappear without leading to any chemical reaction. Consequently, an efficient $\operatorname { e } _ { \mathrm { C B } } { } ^ { - }$ scavenger is required to prevent charge recombination and allow oxidation via ${ \mathrm { h } } { \mathrm { v } } { \mathrm { B } } ^ { + }$ . Most often, dissolved $\mathrm { O } _ { 2 }$ reacts with $\mathrm { e } _ { \mathrm { C B } } { } ^ { - }$ . The formed $\mathrm { O } _ { 2 } { } ^ { \bullet - }$ has a dual role: it can react with organic substances [17,18] or produce $\textstyle \cdot _ { \mathrm { O H } }$ via a multistep reaction, especially in the case of $\mathrm { T i O } _ { 2 }$ and $_ { Z \mathrm { n O } }$ photocatalysts [19].

In the case of heterogeneous photocatalysis, PDS can act as an $\operatorname { e } _ { \mathrm { C B } } { } ^ { - }$ scavenger, like dissolved $\mathrm { O } _ { 2 }$ . The reaction with the $\mathrm { e } _ { \mathrm { C B } } { } ^ { - }$ results in the formation of $\mathrm { S O _ { 4 } ^ { \bullet - } }$ ; its oxidation potential and reactivity significantly exceed that of $\mathrm { O } _ { 2 } { } ^ { \bullet - }$ . Consequently, the combination of PDS with heterogeneous photocatalysis is expected to enhance the efficiency of the transformation and mineralization of organic substances, as has been confirmed by numerous publications [8,10,12]. PDS has been combined with various photocatalysts, including $\mathrm { T i O } _ { 2 }$ -based composites [20] and metal-oxide-based photocatalysts [21–23]. Its combination with metal-free graphitic carbon nitride $( \mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } )$ [11] and visible light-active photocatalysts [23] is particularly beneficial.

Nevertheless, the combination of PDS and heterogeneous photocatalysis still raises many questions. The complexity of the process, such as the competition between PDS and $\mathrm { O } _ { 2 }$ , the simultaneous occurrence of radical and non-radical processes, and the interaction of various reactive species with each other, is challenging and needs further investigation [13,20,24–27].

The current research aims to compare the efficiency of commercial $\mathrm { T i O } _ { 2 }$ and $Z _ { \mathrm { { n O } } }$ for removing an antibiotic, trimethoprim (TRIM), and to investigate the efficiency of combined $\mathrm { T i O } _ { 2 }$ /PDS and $\mathrm { Z n O / P D S }$ systems. The effects of reaction parameters, the formation of degradation products, the mineralization, and the reaction mechanisms were investigated and compared. Regarding practical applicability, it is essential to examine the matrix effect—for this, biologically purified domestic wastewater was used as a matrix.

# 3. Results

# 3.1. Effect of PDS and Dissolved $O _ { 2 }$ on the TRIM Transformation

Using $1 . 0 \times 1 0 ^ { - 4 } \mathrm { ~ M ~ }$ TRIM and $1 . 0 \ \mathrm { g \ d m } ^ { - 3 }$ photocatalyst dosage less than $5 \%$ of TRIM was adsorbed. The photolysis of TRIM was negligible, and no transformation was observed in the presence of a photocatalyst without irradiation. Using the highest PDS concentration $( \hat { 5 . 0 } \times 1 0 ^ { - 3 } \mathrm { M } )$ , the slow TRIM transformation took place in the solution without photocatalyst under $3 6 5 \mathrm { n m }$ radiation, most probably due to the photolysis of PDS (Figure S2), although its molar absorbance is negligible at this wavelength [7]. The competition with photocatalysts for photons in $\mathrm { T i O } _ { 2 }$ and $Z _ { \mathrm { { n O } } }$ suspensions strongly reduces the possibility of direct PDS photolysis.

The effect of photocatalyst dosage was investigated in the $0 { - } 1 . 5 \mathrm { g } \mathrm { d } \mathrm { m } ^ { - 3 }$ range. The transformation rate of TRIM did not change significantly above $0 . 5 \ \mathrm { g } \ \mathrm { d } \mathrm { m } ^ { - 3 }$ (Figure S2) in the case of both photocatalysts. For further experiments, $1 . 0 \mathrm { ~ g ~ d } \bar { \mathrm { m } } ^ { - 3 } \mathrm { ~ T i O } _ { 2 }$ and $_ { Z \mathrm { n O } }$ concentration was used to ensure the complete absorption of the incoming photons by the photocatalyst and to minimize the possibility of direct photolysis of PDS. The $\mathrm { T i O } _ { 2 }$ was slightly more efficient than $_ { Z \mathrm { n O } }$ in TRIM transformation (Figure S3), opposite to its less favorable optical properties. The better light absorption property of $Z _ { \mathrm { { n C } } }$ can be observed in the wavelength range emitted by $\mathrm { L E D } _ { 3 6 5 \mathrm { n m } }$ $( 3 5 5 - 3 8 0 \mathrm { n m } )$ ) (Figure 2b); at $3 6 5 \mathrm { n m }$ , $\mathrm { T i O } _ { 2 }$ reflects approximately $4 0 \%$ , while $_ { Z \mathrm { n O } }$ practically fully absorbs the photons. The better efficiency of $\mathrm { T i O } _ { 2 }$ in terms of TRIM transformation can be explained by the more efficient formation of $\cdot _ { \mathrm { O H } }$ which was verified by Náfrádi [33], comparing $\mathrm { T i O } _ { 2 }$ and $_ { Z \mathrm { n O } }$ in the case of coumarin transformation.

The effect of PDS concentration $( 0 { - } 5 . 0 \times 1 0 ^ { - 3 } \mathrm { M } )$ was investigated in aerated suspensions containing $1 . 0 \ \mathrm { g } \ \mathrm { d } \mathbf { m } ^ { - 3 }$ photocatalyst (Figure 3a). The effect varied according to a saturation curve; above $2 . 0 \times 1 0 ^ { - 3 } \mathrm { M } ,$ the efficiency cannot be significantly improved with further increase in PDS concentration. The difference in the surface properties of $Z _ { \mathrm { { n O } } }$ and $\mathrm { T i O } _ { 2 }$ partially explains their different behavior. Under the conditions applied $\mathrm { \Phi _ { p H } } 6 . 8$ and 7.3 for $\mathrm { T i O } _ { 2 }$ and $Z _ { \mathrm { { n O } } }$ suspension, respectively), the surface charge of $\mathrm { P } 2 5 \mathrm { T i O } _ { 2 }$ $\mathrm { ( p H _ { P Z C } } = 5 . 2$ and $\mathrm { p H } _ { \mathrm { I E P } } = 6 . 2$ [36,37] is negative, while the surface charge of $\mathrm { Z n O ( p H _ { P Z C } = 8 \mathrm { - } 9 . 4 \ : [ 3 8 \mathrm { - } 4 1 ] \ : p H _ { I E P } = 6 . 4 \mathrm { - } 7 . 5 }$ [42] is positive. For $Z _ { \mathrm { { n O } _ { \it { i } } } }$ , a surface interaction was observed for several negative ions (carbonate, sulfate, and phosphate [43–45]), suggesting the possibility of a particular interaction with PDS, which can enhance the electron transfer from the surface of excited $_ { Z \mathrm { n O } }$ to PDS. However, for $\mathrm { T i O } _ { 2 }$ , no significant interaction was observed between the surface and inorganic anions [38].
