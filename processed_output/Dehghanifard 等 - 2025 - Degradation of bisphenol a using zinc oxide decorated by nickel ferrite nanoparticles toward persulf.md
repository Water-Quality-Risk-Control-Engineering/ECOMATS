# Degradation of bisphenol a using zinc oxide decorated by nickel ferrite nanoparticles toward persulfate activation in the presence of ultraviolet radiation

Emad Dehghanifard1,2, Ahmad Jonidi Jafari1,2, Babak Kakavandi3 & Roshanak Rezaei Kalantary1,2

Bisphenol-A (BPA), a commonly used chemical in the production of thermal paper and kinetic polymers, acts as an endocrine disruptor, leading to biological accumulation in the environment and posing long-term risks to human health. This study aimed to assess the degradation of BPA using persulfate (PS) activated by nickel ferrite-anchored zinc oxide $( \boldsymbol { \mathrm { Z n O } @ \mathsf { N i F e } _ { 2 } \mathrm { O } _ { 4 } } )$ nanoparticles in the presence of ultraviolet (UV) radiation. The $Z n { \mathsf { O } } ( { \mathsf { a } } { \mathsf { N i F e } } _ { 2 } { \mathsf { O } } _ { 4 }$ catalyst was synthesized using a coprecipitation method. Its structure was characterized through FESEM, EDS, XRD, VSM, DRS, TEM, and PL analyses. Several parameters including solution $\mathsf { p H } _ { i }$ , initial BPA concentration, and catalyst and PS dosages were examined. Additionally, the influence of interfering ions such as nitrate, chloride, sulfate, carbonate, and bicarbonate was evaluated. Total organic carbon (TOC) analysis was conducted to measure BPA mineralization throughout the process. Lastly, the reusability of the photocatalyst and the overall efficiency of the process were assessed. Under optimal conditions $( { \mathsf { p H } } = 9 _ { i }$ , BPA concentration $= 0 . 0 4 ~ \mathfrak { g } / \mathsf { L } ,$ catalyst dosage ${ \bf \varepsilon } = { \bf 0 . 3 \mathsf { g } } / { \mathsf { L } } ,$ and $\mathsf { P S } = \mathsf { m } \mathsf { M } ,$ ), the highest removal efficiency and mineralization of BPA after 15 min were found to be $> 9 9 . 9 \%$ and $5 9 . 2 1 \%$ , respectively. However, interfering ions reduced the BPA degradation efficiency in order of Cl− $( 5 1 . 7 5 \% ) < 5 0 _ { 4 } ^ { - 2 } ( 7 0 . 6 1 \% ) < 1 1 0 _ { 3 } ^ { - }$ $( 7 5 . 4 1 \% ) < 9 0 _ { 3 } ^ { - 2 }$ (82.41%). After four recovery cycles, the catalyst’s effectiveness decreased to $1 5 . 7 \%$ . The photocatalytic oxidation of BPA adhered to pseudo-first-order kinetics $( \mathsf { k } = 0 . 2 3 \mathsf { m i n } ^ { - 1 } )$ ). In conclusion, the PS activated by $\mathsf { Z n O @ N i F e   _ { 2 } O _ { 4 } / U V }$ proved to be effective for BPA degradation due to its strong performance and high recovery capability.

In recent decades, there has been growing concern about the availability of clean water, driven by population growth, inadequate sanitation, and the emergence of resistant pollutants in the environment1 . Many emerging pollutants are classified as endocrine disruptors due to their capacity to interfere with the endocrine systems of living organisms2 . Global regulatory bodies define endocrine-disrupting compounds (EDCs) as external substances or mixtures that alter endocrine functions, potentially leading to harmful health effects in organisms or specific subpopulations. EDCs encompass a range of substances, including phthalates, bisphenol A (BPA), alkylphenols (surfactants), pesticides, organotin compounds, dioxins and furans, polychlorinated biphenyls, aromatic hydrocarbons, natural hormones, and heavy metals. Research indicates that these EDCs are commonly detected in surface water, groundwater, sewage, sediments, and drinking water. Furthermore, it is well established that prolonged exposure to EDCs, even at low concentrations measured in $\mathrm { n g / L }$ , can result in adverse health outcomes3,4 . BPA, chemically known as 2,2-(4,4-dihydroxydiphenyl) propane, is widely used in the production of polycarbonate and epoxy resins, finding applications in medical devices and water containers.

Global production of this endocrine-disrupting chemical reaches several tons annually, leading to its persistent presence in water, soil, and air3,4 . Zhang et al. (2018) revealed varying concentrations of BPA in urban and industrial wastewater, surface water, and landfill sites4 . Experimental studies have shown that environmental exposure to BPA and its transfer into the human body can disrupt the synthesis and metabolism of estrogen and thyroid hormones, highlighting the need for effective methods to remove this compound. Hence, developing a proper method to remove BPA is very necessary and important5 .

Various physicochemical methods such as ozonation, chlorination, absorption, reverse osmosis, and ion exchange have been used to remove $\mathrm { B P A } ^ { 6 }$ , many of these methods have drawbacks, including low efficiency, membrane clogging, high energy consumption, the transfer of contaminants between phases, and the generation of secondary waste7 . In recent years, the advanced oxidation process (AOP) has been considered due to the characteristics of fast reaction, complete mineralization, and no production of secondary waste and byproducts8,9 . In this process, the hydroxyl radical $\mathrm { ( H O ^ { o } ) }$ , which has an oxidation potential ranging from 1.95 to $2 . 8 \mathrm { V } ,$ can be utilized across a broad $\mathrm { p H }$ spectrum. Its non-selective oxidation of various pollutants leads to the breakdown of structural bonds and their conversion into $\mathrm { C O } _ { 2 }$ and $\mathrm { H } _ { 2 } \mathrm { O }$ through mechanisms such as radical addition, radical combination, hydrogen accumulation, and electron transfer. AOPs such as $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { U V } ,$ Fenton, Photo-Fenton, electrolysis, and photocatalysis have gained prominence for the oxidation of organic pollutants through the generation of HO· by a variety of reactions10. In recent years, AOPs utilizing sulfate radicals $( \mathrm { S O } _ { 4 } ^ { \cdot - } )$ have gained significant attention for the oxidation of organic pollutants. Unlike $\mathrm { H O ^ { o } }$ , $\mathrm { S O } _ { 4 } ^ { \cdot - }$ possess several advantageous properties, including a high standard reduction potential (ranging from 2.5 to $3 . 1 \mathrm { ~ V ~ }$ ), a longer lifespan (approximately 30 to $4 0 ~ \mu s \mathrm { { \vert } }$ ), and selectivity, making them effective across a broad pH range11. These reactive species are produced by activating persulfate (PS) and peroxymonosulfate (PMS) through various methods, including ultrasound (US), heat, ultraviolet (UV) radiation, and the use of transition metals.

Transition metals, particularly nickel (Ni), are often favored due to their ease of use, low energy consumption, and ability to quickly activate oxidants. However, the Ni/PS process has its drawbacks, such as the toxicity of nickel and challenges related to its separation during purification12. Addressing the need for efficient pollutant removal, researchers have increasingly focused on composite materials incorporating multiple metal oxides. Among these materials, ferrites with the general formula ${ \mathrm { M F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ (where M represents a divalent metal like Co, Ni, Cu, or Mn) have gained prominence. Their recyclability, desirable electronic and magnetic properties, and cost-effectiveness make them attractive for various applications13. Wei et al. (2021) applied a novel magnetic $\mathrm { A g _ { 3 } P O _ { 4 } / N r G O / C u F e _ { 2 } O _ { 4 } }$ photocatalyst for notable degradation of 2,4-dichlorophenol (2,4-DCP) which achieved to $> 9 5 \%$ of its removal14. In another study, Wei et al. (2023) developed a novel $\mathrm { A g V O _ { 3 } / r G O / C u F e _ { 2 } O _ { 4 } }$ heterojunction catalyst to achieve 8.937 mmol $\mathbf { g } ^ { - 1 } \dot { \mathbf { h } } ^ { - 1 }$ hydrogen generation $\left( \operatorname { H } _ { 2 } \right)$ and also $9 4 . 7 \%$ 4-nitrophenol (4-NP) degradation, simultaneously15. ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 } ,$ a heterogeneous catalyst, exhibits high catalytic activity towards persulfate (PS) activation and the degradation of various pollutants. These attributes are attributed to its low solubility, stable crystal structure, and high specific surface area16. In general, catalysts based on Fe and $\mathrm { N i }$ are divided into two types based on their performance: (1) as a photocatalyst, and (2) as an activator for oxidants. Combining multiple activation agents within oxidation systems has proven highly effective in enhancing pollutant degradation and mineralization.

Recent research has explored various combinations of activators, including $\mathrm { F e } _ { 2 } ^ { + } / \mathrm { U V } ,$ $\mathrm { C o } _ { 2 } ^ { + } / \mathrm { U S }$ , $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } / \mathrm { U S }$ , CN $\mathrm { T s - T i O } _ { 2 } / \mathrm { U V } ,$ and $\mathrm { T i O } _ { 2 } @ \mathrm { C u F e } _ { 2 } \mathrm { O } _ { 4 } / \mathrm { U V } ,$ to generate reactive species17. The hybridization of Ni and ZnO significantly increases the photocatalytic efficiency of ${ \mathrm { Z n O } }$ . A comparison between several transition metals shows that 2-valent Ni has a higher catalytic efficiency for the activation of ${ \mathrm { Z n - F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ . Also, one of the other advantages of using Ni in the AOP is its efficiency in a wide range of $\mathrm { p H }$ 2 4, especially neutral $\mathrm { p H } ^ { 1 8 }$ . Considering the many capabilities of AOPs as well as catalytic processes in the removal of environmental pollution, it can be considered an effective technology to achieve sustainable development. This study aimed to investigate the efficiency of BPA mineralization and degradation generated by a $\mathrm { Z n O @ N i F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst combined with PS and UV radiation. The synthesis of the $\mathrm { Z n O @ N i F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst was modified in terms of multistage heating in order to better maturation and therefore increase the resistance and stability of the catalyst over multiple uses. The study examined the influence of various parameters, including $\mathrm { p H }$ , reaction time, initial BPA concentration, PS dosage, catalyst amount, and the presence of anions, on the degradation process.

# Synthesis of composite

Synthesis of $\mathrm { N } i F e _ { _ 2 } O _ { _ 4 }$ catalyst

At first, a solution containing $0 . 5 ~ \mathrm { m M }$ of $\mathrm { N i } ( \mathrm { N O } _ { 3 } ) _ { 2 } – 6 \mathrm { H } _ { 2 } \mathrm { O }$ and $1 \ \mathrm { m M }$ of $\mathrm { F e ( N O } _ { 3 } ) _ { 3 } – 9 \mathrm { H } _ { 2 } \mathrm { O }$ mixed in $1 0 ~ \mathrm { m L }$ of ethanol was prepared. The solution $\mathrm { p H }$ was adjusted to 13 using a 6 M NaOH solution, to precipitate ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanoparticles. The solution volume was then brought to ${ 8 0 } \mathrm { m L }$ with distilled water. This mixture was vigorously stirred for $3 0 \ \mathrm { m i n }$ , resulting in a stable, homogeneous emulsion. The emulsion was then transferred to a 100 mL stainless steel autoclave equipped with a Teflon liner. The autoclave was heated to $1 8 0 ^ { \circ } \mathrm { C }$ for $2 0 \mathrm { h }$ . After the reaction, the solution was allowed to cool to room temperature. The solid precipitate was magnetically separated, washed with water, and dried in an oven at $6 0 ~ ^ { \circ } \mathrm { C }$ for $\bar { 1 2 } \bar { \mathrm { h } } ^ { 1 9 }$ .

Synthesis of ZnO Separately, we dissolve $2 . 1 9 5 \ \mathrm { g }$ of $\mathrm { Z n } ( \mathrm { A c } ) _ { 2 } { \cdot } 2 \mathrm { H } _ { 2 } \mathrm { O }$ in $3 0 ~ \mathrm { m L }$ of distilled water and $_ { 0 . 8 \ \mathrm { g } }$ of $\mathrm { \Delta N a O H }$ in $3 0 ~ \mathrm { m l }$ of distilled water. The container containing zinc acetate $\left( \mathrm { Z n } ( \mathrm { A c } ) _ { 2 } . 2 \mathrm { H } _ { 2 } \mathrm { O } \right)$ was placed on the heater and stirred by a magnet. NaOH solution was added dropwise to the solution, causing it to turn milky and form a gel-like consistency. The resulting material was placed in a Teflon container and heated in an oven at $1 7 0 ~ ^ { \circ } \mathrm { C }$ for $1 0 \mathrm { ~ h ~ }$ . After cooling, the container was removed from the oven, revealing ${ \mathrm { Z n O } }$ particles deposited at the bottom. These particles were separated by filtration using a paper filter. The collected sediment on the filter was then dried in an oven at $6 0 ~ ^ { \circ } \mathrm { C }$ for $1 0 \mathrm { { h } }$ , resulting in a white powder of $Z _ { \mathrm { { n O } ^ { 1 9 } } }$ .

# Composite characterization

To characterize the composite material, several analytical techniques were employed. Field emission scanning electron microscopy (FESEM) equipped with energy dispersive spectroscopy (EDS) was employed to investigate morphology and elemental composition (Mira 3-XMU instrument). Structural properties and crystal phases were determined using X-ray diffraction (XRD) analysis conducted on a Quantachrome NOVA 2000 system (USA). Ni-filtered Cu Kα radiation was used in the scan range of $1 0 ^ { \circ }$ to $8 0 ^ { \circ }$ with a step width of $0 . 0 5 ^ { \circ }$ . Transmission electron microscopy (TEM) analysis, performed on a PHILIPS EM instrument (Netherlands) at an accelerating voltage of $1 0 0 \mathrm { k V } ,$ provided insights into the morphology of the synthesized nanoparticles. Raman spectroscopy was utilized to obtain detailed information about the chemical structure, crystallinity, molecular interactions, phase, and polymorphy of the $\mathrm { Z n O @ { N i F e } } _ { 2 } \mathrm { O } _ { 4 }$ catalyst. This analysis was conducted using a Teksan Takram P50C0R10 spectrometer (Iran) with a laser wavelength of $5 3 2 ~ \mathrm { n m }$ . The catalyst’s surface area was determined using the Brunauer-Emmett-Teller (BET) method through $\Nu _ { 2 }$ sorption-desorption at $7 7 ~ \mathrm { K }$ and a pressure of $8 6 . 9 0 7 ~ \mathrm { k P a }$ , using a Quantachrome NOVA 2000 analyzer. The Barrett-Joyner-Halenda (BJH) method was applied to analyze the catalyst’s pore size distribution. The optical properties of the sample were characterized using UV-Vis diffuse reflectance spectroscopy (DRS) on a U-3900 Spectrophotometer (Hitachi Ltd., Japan) and photoluminescence (PL) analysis on a Perkin Elmer-LS 55 instrument. The excitation wavelength for PL analysis was set to $3 3 0 \mathrm { n m }$ . Finally, the magnetic saturation of the samples was measured using vibrating sample magnetometry (VSM) analysis on a Lakeshore 7400 instrument (USA).

# BPA photocatalytic oxidation experiments

A $3 0 0 ~ \mathrm { m L }$ quartz reactor, equipped with an 8  W UV-C lamp $\lambda { = } 2 5 4 ~ \mathrm { n m }$ , Philips, $3 \mathrm { \ m W . c m } ^ { - 2 }$ ) positioned vertically beside the reactor, was prepared to conduct BPA oxidation experiments.

To initiate the photocatalytic oxidation experiments, the solution $\mathrm { p H }$ was first adjusted to the desired level using $1 \mathrm { M N a O H }$ and $\mathrm { 1 ~ M ~ H N O } _ { 3 }$ solutions. All variable optimization experiments were performed at $ { 0 - 6 0 }  { \mathrm { m i n } }$ reaction times and laboratory temperature $( 2 0 ^ { \circ } \mathrm { C } )$ . A specific amount of the synthesized $\mathsf { \bar { Z } n O @ N i F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst was then introduced to the BPA solution. The mixture was stirred for $3 0 \ \mathrm { m i n }$ using a mechanical mixer to reach adsorption equilibrium, a condition determined in previous studies. Once equilibrium was established, the desired dose of PS was added to the mixture, and the UV lamp was switched on to begin the photocatalytic oxidation process. To monitor the reaction progress, $5 ~ \mathrm { m L }$ samples of the suspension were collected at specific time intervals. The catalyst was separated from the solution using a magnetic field, and the remaining solution was analyzed using a high-performance liquid chromatography (HPLC) system. All samples were filtered through a $0 . 2 2 \mu \mathrm { m }$ polytetrafluoroethylene (PTFE) filter before injection into the HPLC. The influence of key operating parameters, including solution pH, PS loading, catalyst dosage, and initial BPA concentration, on the performance of the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ process was evaluated over a $1 2 0 \ \mathrm { m i n }$ reaction period. After optimizing the process conditions, the degradation efficiency of BPA using the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ system was further investigated in the presence of various scavenging agents, including benzoquinone (BQ), tert-butyl alcohol $\left( { \bf t } { - } \mathrm { B u O H } \right)$ , sodium azide $( \mathrm { N a N } _ { 3 } )$ , potassium iodide (KI), and methanol (MeOH), as well as inorganic ions such as chloride $\left( \mathrm { C l ^ { - } } \right)$ , nitrate $( \mathrm { N O } _ { 3 } ^ { - } )$ , carbonate $\mathbf { ( C O _ { 3 } } ^ { - 2 } )$ , and sulfate ${ ( \mathrm { S O _ { 4 } } ^ { - 2 } } .$ ). # Comparative tests on the degradation of BPA

Effect of initial solution $p H$

The initial solution $\mathrm { p H }$ plays a crucial role in AOPs by influencing ionization, solubility, and oxidizing efficiency. This factor also impacts the molecular forms of pollutants and the surface properties of photocatalysts. Within advanced oxidation processes, the solution $\mathrm { p H }$ stands out as a vital parameter affecting multiple aspects of the process. $\mathrm { p H }$ influences the ionization degree, activity, and solubility of oxidants and pollutants, as well as the surface features of catalysts, radical production, and reaction kinetics. Due to its profound impact on chemical and oxidation processes, the influence of $\mathrm { p H }$ on pollutant removal has been extensively studied.

Experimental results (Fig. 4a) revealed that as $\mathrm { p H }$ increased from 3 to 11, pollutant degradation efficiency escalated from 35.17 to $8 2 . 1 5 \%$ during $6 0 \ \mathrm { m i n }$ of photodegradation reaction. The highest pollutant removal efficiency was observed at $\mathrm { p H 1 1 }$ . Moreover, the impact of $\mathrm { p H }$ on BPA degradation in the presence of $\mathrm { P S } { = } 2 \ \mathrm { m M }$ during photocatalysis was assessed, and the results are illustrated in Fig. 4b. This investigation demonstrated that BPA degradation occurred most effectively in the $\mathrm { p H }$ range of 7–9 after $3 0 \mathrm { \ m i n }$ of oxidation, achieving an efficiency of $9 9 \%$ . Notably, the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ process performance exhibited $\mathrm { p H }$ sensitivity, showing excellent activity in a broad neutral to alkaline range, with $\mathrm { p H } = 9$ selected as the optimal $\mathrm { p H }$ for subsequent experiments.

The reduction in degradation efficiency at higher $\mathrm { p H }$ values $( > 9 . 6 )$ was attributed to the anionic nature of BPA and the synthesized $\mathrm { p H } _ { \mathrm { p } _ { \mathrm { Z C } } }$ catalyst. Effective adsorption of BPA molecules on the catalyst was expected at $\mathrm { p H }$ levels between 7.7 and 9.6, where the catalyst surface carried a negative charge while BPA molecules held a positive charge, facilitating pollutant adsorption22. Consequently, the maximum efficiency of the $Z { \mathrm { n O } } @$ $\mathrm { N i F e _ { 2 } O _ { 4 } / P S / U V }$ process was observed at $\mathrm { p H } = 9$ . Previous studies have also highlighted the enhanced efficiency 2 4in alkaline environments due to the generation of various reactive species $( \mathrm { S O } _ { 4 } ^ { - \cdot - } , \mathrm { S } _ { 2 } \mathrm { \bar { O } } _ { 8 } ^ { - 2 } , \mathrm { O } _ { 2 } ^ { - \cdot - } , \mathrm { H O } ^ { \cdot } )$ via substance interactions. Furthermore, at relatively alkaline $\mathrm { p H }$ levels, the conversion of $\mathrm { S O } _ { 4 } ^ { \cdot - }$ to HO· helped compensate for the low concentration of HO· during pollutant degradation23–25.

Effect of catalyst dosage

The quantity of catalyst dosage plays a significant role in AOPs, impacting the reaction process by creating essential absorption surfaces and generating electron-hole pairs. An investigation depicted in Fig. 5a showcased the impact of varying catalyst doses in the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ process for BPA removal across the range of 0.1 to $0 . 5 \mathrm { g } / \mathrm { L }$ . It was evident that all catalyst doses facilitated BPA degradation at varying rates. Specifically, the $0 . 1 ~ \mathrm { g / L }$ dose achieved $9 0 \%$ efficiency in $6 0 \ \mathrm { m i n }$ , while other doses achieved similar efficiency in $3 0 \ \mathrm { m i n }$ for a $0 . 0 2 { \mathrm { ~ g / L } }$ BPA concentration. Results indicated an increase in BPA degradation efficiency from 78.35 to $9 4 . 8 2 \%$ by elevating the catalyst dose from 0.1 to $0 . 3 \mathrm { g / L }$ within a $1 5 \mathrm { { m i n } }$ reaction time. However, beyond a certain point, the efficiency began to decline, with a rise in catalyst dose from 0.4 to $0 . 5 \mathrm { g } / \mathrm { L }$ resulting in a drop from 87.46 to $9 1 . 5 6 \%$ within the same timeframe. Consequently, the optimal catalyst dosage was determined as $0 . 3 ~ \mathrm { g / L }$ for subsequent experiments to sustain BPA degradation.

Enhancing the efficiency of photocatalytic degradation relies on factors like active sites and photon absorption capabilities on the catalyst surface. Increasing the catalyst dose amplifies active sites, light absorption, and subsequently, the generation of charge carriers (electron-hole pairs) for pollutant absorption and degradation. Moreover, a rise in active sites boosts the degradation of oxidizing agents like persulfate, fostering the production of active radicals (e.g., $\mathrm { S O } _ { 4 } \mathrm { \Omega } ^ { \cdots } ) ^ { 2 8 }$ .

Contrastingly, the efficiency of the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ process exhibited a decline in BPA removal efficiency upon increasing the catalyst concentration from 0.4 to $0 . 5 ~ \mathrm { g / L }$ which may be attributed to light scattering, reduced charge carrier production, and hindered catalyst activation due to excessive catalyst concentration causing turbidity. Additionally, catalyst accumulation could diminish light penetration depth, hampering oxidant activation and active radical generation. In essence, higher catalyst doses could lead to catalyst condensation and reduced surface area for pollutant and oxidant interaction29.

Li et al. (2018) investigated the impact of catalyst dosage $( 0 . 6 { - } 6 . 0 \ \mathbf { g } / \mathrm { L } )$ on atrazine oxidation using the $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ process was investigated. The addition of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ nanoparticles at a dosage of $0 . 1 \mathrm { g / L }$ significantly enhanced atrazine degradation, achieving an $8 1 \%$ removal efficiency after a $3 0 \mathrm { { m i n } }$ reaction period. The results underscored the poor performance of PMS alone in pollutant removal and validated the activation of PMS by ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O 4 } }$ . The degradation efficiency of atrazine surpassed $9 9 \%$ upon increasing the catalyst dosage to $0 . 3 \ \mathrm { g / L }$ . Moreover, efficiency levels exceeding $9 9 \%$ were observed at dosages of 0.4, 0.5, and $0 . 6 ~ \mathrm { g / L } ,$ indicating that higher catalyst dosages enhance the surface area available for pollutant and PMS absorption. This increase also boosts the number of active sites on the catalyst surface, leading to enhanced PMS activation and active radical production for efficient pollutant removal30.

# Effect of PS concentration

An essential factor in improving the efficiency of photocatalytic oxidation systems involves introducing electron acceptors like HO· and $\mathrm { S O } _ { 4 } ^ { \cdot - }$ . These oxidants within the reaction environment can fulfill two critical roles: (1) engaging with the photogenerated electrons, thereby preventing their interaction with valence band $\mathrm { h ^ { + } }$ species; and (2) enhancing the generation of additional oxidative species, particularly $\mathrm { S O } _ { 4 } ^ { \cdot - }$ in the case of PS anions31. As illustrated in Fig. 5b, explored the influence of PS concentration ranging between 1 and $5 \mathrm { m M }$ on pollutant degradation within the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ process, all considered concentrations of PS could effectively facilitate BPA removal. Specifically, PS concentrations of $1 { - } 5 ~ \mathrm { m M }$ achieved $a > 9 9 \%$ efficiency in degrading a $0 . 0 2 { \mathrm { g } } / { \mathrm { L } }$ BPA within 60, 30, 15, 10, and $1 0 \mathrm { { m i n } }$ , respectively.

Analysis over a $1 0 \ \mathrm { m i n }$ contact time revealed a notable enhancement in BPA degradation efficiency with increasing PS concentration; elevating the PS concentration from 1 to $3 \mathrm { m M }$ led to a degradation efficiency of $< 9 9 \%$ for BPA. Notably, further increasing the PS concentration from 4 to $5 \mathrm { m M }$ did not significantly impact the process, maintaining an efficiency of $< 9 9 \%$ . Consequently, based on the findings and aiming to optimize PS consumption (compared to $3 { - } 5 \mathrm { m M }$ concentrations) and reaction time (compared to $1 \mathrm { m M }$ concentration), the optimal PS concentration selected to continue experiments was determined to be $3 \mathrm { m M }$ .

The efficacy improvement observed at higher PS concentrations may be linked to the augmented generation of $\mathrm { S O } _ { 4 } ^ { \cdot - }$ through PS degradation catalyzed by the photocatalyst32. Moreover, elevated levels of PS in the photolysis reactor and photocatalyst environment foster direct PS degradation into $\mathrm { S O } _ { 4 } ^ { \cdot - }$ . Previous studies by Barbhuiya et al. (2024), Davarazar et al. (2023), Smaali et al. (2021), and Liu et al. (2020) delved into the effect of PS concentration on various photocatalytic processes, highlighting the positive impact of increased PS dosage on degradation efficiency through enhanced PS degradation by electrons, UV light, and activated catalysts, leading to the production of sulfate and hydroxyl radicals33–36.

Effect of initial concentration of BPA

High pollutant concentrations within the reactor could impede UV light penetration, hampering UV-PS interaction and active radical species production. Additionally, consistent generation of reactive radicals under constant laboratory conditions may prove inadequate for large pollutant volumes37. The efficacy of photocatalytic degradation is notably swayed by the initial concentration of the contaminant under treatment. As depicted in Fig. 5c, the impact of varying initial pollutant concentrations (ranging from 0.01 to $\mathbf { 0 . 0 8 \mathrm { g / L } }$ ) on the performance of the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ process in BPA degradation was scrutinized. The results indicated a reduction in BPA removal efficiency with escalating pollutant concentrations. Specifically, BPA concentrations of $0 . 0 1 ~ \mathrm { g } / \mathrm { L }$ in $1 0 \mathrm { { m i n } }$ , $0 . 0 2 { \mathrm { g } } / { \mathrm { L } }$ in $1 5 \mathrm { { m i n } }$ , $0 . 0 4 \ : \mathrm { g / L }$ in $3 0 \mathrm { { m i n } }$ , and $0 . 0 6 { - } 0 . 0 8 \mathrm { g / L }$ in $6 0 \mathrm { { m i n } }$ achieved an efficiency of $< 9 9 \%$ . Analysis over a $1 0 \ \mathrm { m i n }$ period unveiled a decrease in BPA degradation efficiency from 99.9 to $6 0 . 7 \%$ with an increment in pollutant concentration from 0.01 to $0 . 0 8 ~ \mathrm { g / L }$ . This decline in the degradation rate may be attributable to the competition between BPA and PS for adsorption on the catalyst’s active sites, leading to a diminished catalytic reaction rate and subsequent decrease in reactive species production.

Wu et al. (2024) observed analogous photocatalytic behavior in organic pollutant degradation via PS activation. They elucidated the efficiency reduction at high pollutant concentrations as arising from catalyst surface occupation and diminished $\mathrm { { e ^ { - } / h ^ { + } } }$ pair generation due to byproducts38. Similar findings were reported by Yan et al. (2023), which highlighted the impact of resistant intermediate byproducts at higher pollutant concentrations that diminish removal efficiency by impeding free radical-pollutant reactions and reducing collision chances between amoxicillin molecules and free radicals, necessitating more active radicals or extended time for higher pollutant concentrations39.

Efficiency evaluation of different conditions in BPA degradation (control tests)

To assess the effectiveness of the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / \bar { U } V }$ process for degrading BPA, the oxidation efficiencies of separate and integrated systems under identical laboratory conditions were compared. As demonstrated in Fig. 6, BPA degradation efficiencies were $2 6 . 3 1 \%$ for the UV process and $6 6 . 5 9 \%$ for the PS/UV process. In contrast, the presence of the $\mathrm { Z n O @ N i F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst led to degradation efficiencies of 38.54 and $5 7 . 2 1 \%$ when PS and UV were applied separately. The $Z _ { \mathrm { { n } \bar { O } / \bar { U } V } }$ process, a well-known photocatalytic method, achieved a removal efficiency of $4 6 . 9 5 \%$ . The results indicated that the lowest removal efficiency was $1 9 . 5 3 \%$ for the $\mathrm { Z n O @ { N i F e _ { 2 } O _ { 4 } } }$ process, while the highest was $< 9 9 \%$ for the original process. Enhancing the efficiency of this method may depend on factors such as the presence of UV light, ZnO, $\mathrm { F e } _ { 2 } \mathrm { O } _ { 4 } ,$ and $\mathrm { N i }$ to activate persulfate and generate sulfate radicals, as well as the simultaneous operation of photocatalytic absorption and oxidation processes and the variety of radicals present in the system (including hydroxyl, sulfate, and superoxide radicals). Jorfi et al. (2017) studied the removal of benzotriazole (BTA) using a heterogeneous photocatalyst made from magnetic active carbon- $\mathrm { \cdot T i O } _ { 2 }$ $\left( \mathrm { T } @ \mathrm { M P A C } \right)$ in conjunction with peroxymonosulfate (PMS). They compared the photocatalytic efficiency of $\mathrm { T } @$ MPAC for pollutant removal against control experiments conducted over $6 0 \ \mathrm { m i n }$ under consistent laboratory conditions. The removal efficiencies of BTA for the UV, PMS, and UV/PMS methods were found to be 6.2, 8.1, and $1 2 \%$ , respectively, indicating that these approaches were ineffective for benzotriazole degradation. In contrast, the MPAC/PMS and MPAC/PMS/UV processes achieved pollutant removal efficiencies of 54.6 and $5 9 . 3 \%$ , respectively, within the same time frame. This increase in efficiency can be attributed to the combined effects of absorption and degradation processes. Additionally, the synergistic interaction between UV light and MPAC enhanced the activation of PMS and the generation of sulfate radicals, further improving removal efficiency. The highest removal efficiency of $7 1 . 2 \%$ was achieved using the T@MPAC/PMS/UV method in under $6 0 \mathrm { { m i n } }$ , highlighting its excellent photocatalytic performance and significant potential for PMS activation40.

BPA mineralization rate in ZnO@NiFe2O4/PS/UV process

The investigation into the degree of mineralization during AOPs aimed to assess the effectiveness of these methods in eliminating organic compounds. The TOC analysis was employed to quantify the mineralization of organic substances in photocatalytic processes. The results (Fig. 9a) indicated that the mineralization efficiency of BPA exhibited minimal variation across four stages. Specifically, the mineralization efficiency was $5 9 . 2 1 \%$ in the initial stage of photocatalyst application, while it decreased to $3 5 . 4 7 \%$ by the 4th stage. This reduction in mineralization over five consecutive reaction stages may be attributed to several factors, including a decline in the catalyst’s adsorption capacity due to saturation of active sites with degradation byproducts, wear on the catalyst surface during drying and washing, and a reduction in the catalyst amount during collection and reuse53.

Numerous studies have explored the mineralization processes involved in the removal of organic materials. For instance, Chen et al. (2021) examined the mineralization efficiency of the $\mathrm { A g / P b O _ { 3 } / P S / U V }$ system for nitrobenzene removal and found a slight decrease in mineralization from the first to the fifth stages. (2019) investigated the mineralization of rhodamine B dye using a $\mathrm { C u F e _ { 2 } O _ { 4 } / P S / U V }$ system, achieving a TOC removal efficiency of $3 8 . 7 9 \%$ after $6 0 \ \mathrm { m i n }$ of reaction time. # Conclusion

The current study aimed to evaluate the effectiveness of the $\mathrm { Z n O @ N i F e _ { 2 } O _ { 4 } / P S / U V }$ system in degrading and 2 4removing BPA from aqueous solutions. Initially, nanoparticles and catalysts were synthesized, followed by their application in the presence of PS oxidant and UV light to eliminate BPA. The findings demonstrated the successful synthesis of nanoparticles, specifically ${ \mathrm { Z n O } }$ and ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 } ,$ which exhibited a well-defined crystal structure, high purity, and strong magnetic properties. The synthesized catalyst displayed significant catalytic activity in promoting PS degradation and generating sulfate free radicals. Furthermore, it demonstrated good stability and reusability during successive recovery experiments. The combination of the $\mathrm { Z n O @ N i F e } _ { 2 } \mathrm { O } _ { 4 }$ catalyst with PS oxidant and UV radiation proved to be highly efficient in degrading BPA $( > 9 9 \% - \mathrm { k } = \bar { 0 . 2 3 } ^ { \cdot } \operatorname* { m i n } ^ { - 1 } )$ , effectively breaking it down into simpler molecular structures. This study not only provided a recyclable catalyst (4th cycle with an acceptable resistance) with high catalytic activity for PS degradation but also introduced an effective system for the degradation of toxic pollutants, by $5 9 . 2 1 \%$ TOC removal. This approach represents a cost-effective and economical method for wastewater treatment, helping to meet environmental standards.
