# SUMMARY

Advanced oxidation processes (AOPs) based on sulfate radicals $( \pmb { 5 0 } _ { 4 } ^ { \cdot - } )$ suffer from low conversion rate of Fe(III) to Fe(II) and produce a large amount of iron sludge as waste. Herein, we show that by using $\ M \circ \mathsf { O } _ { 2 }$ as a cocatalyst, the rate of Fe(III)/Fe(II) cycling in PMS system accelerated significantly, with a reaction rate constant 50 times that of PMS/Fe(II) system. Our results showed outstanding removal efficiency $( 9 6 \% )$ of L-RhB in $1 0 \mathrm { ~ m i n }$ with extremely low concentration of Fe(II) $( 0 . 0 3 6 ~ \mathsf { m M } )$ , outperforming most reported $\$ 0_ { 4} \dot { }$ -based AOPs systems. Surface chemical analysis combined with density functional theory (DFT) calculation demonstrated that both Fe(III)/Fe(II) cycling and PMS activation occurred on the (110) crystal plane of ${ \mathsf { M o o } } _ { 2 } ,$ whereas the exposed active sites of Mo(IV) on $\ M \circ \mathsf { o } _ { 2 }$ surface were responsible for accelerating PMS activation. Considering its performance, and non-toxicity, using $\scriptstyle { \mathsf { M o o } } _ { 2 }$ as a cocatalyst is a promising technique for large-scale practical environmental remediation.

# INTRODUCTION

The presence of organic pollutants such as aromatic organic compounds in the environment is among the most significant issue for humans that requires immediate remediation (Muthuraman and Teng, 2009; Crini, 2006; Al-Ghouti et al., 2003). These pollutants are toxic, carcinogenic, and recalcitrant to degrade with time, demonstrating the great need for their removal (Ito et al., 2016; Du et al., 2018b; Yi et al., 2015; Dong et al., 2018). Although several processing methods have been proposed for effectively removing organic compounds from places such as drinking water, advanced oxidation processes (AOPs) based on the generation of hydroxyl radicals (, OH) are among the most promising techniques because they are inexpensive, environmentally safe (Buck et al., 2018; Yang et al., 2019, Tao et al., 2001), and efficient in oxidizing almost all organic pollutants to harmless products (Clarizia et al., 2017).

Recently, sulfate radical $\left( \mathsf { S } \mathsf { O } _ { 4 } ^ { \bullet - } \right)$ -based AOPs have drawn much interests (Zhang et al., 2016; Yun et al., 2018; Chen et al., 2018) due to their higher oxidation potentials $\left( \mathsf { S O } _ { 4 } ^ { \bullet - } \right.$ , 2.5–3.1 eV) compared with hydroxyl radical ( , OH, $2 . 8 \mathsf { e } \mathsf { V }$ , longer half-life, higher selectivity (Li et al., 2018; Huang et al., 2017; Hu et al., 2017), and tolerance to wider pH range (2–8) (Ghanbari and Moradi, 2017). Peroxymonosulfate (PMS) molecules are widely used as a source for sulfate radicals in AOPs, which can be activated during the treatment process through various methods such as heating (Chen et al., 2016), UV light (Guan et al., 2011), transition metal ions, and ultrasound (Liu et al., 2017; Du et al., $2 0 1 8 \mathsf { a } )$ . Dionysiou et al. found that PMS can be activated by various transition metals, among which $C \mathsf { o } ( | | )$ and $\mathsf { R u } ( \mathsf { I I I } )$ demonstrated the best performances as catalysts for generating sulfate radicals (Anipsitakis and Dionysiou, 2003, 2004). However, their high toxicity and scarcity significantly limited their implementation in PMS activation system. A more environmental and economical alternative to Co and Ru has been found to be Fe(II), which can decompose PMS and generate $\mathsf { S O } _ { 4 } ^ { \bullet - }$ in a similar manner (Dan et al., 2014). Generally, the stoichiometric ratio of PMS to $\mathsf { F e } ( \mathsf { I I } )$ is maintained at approximately 1:1 according to Equation 1. Transformation from Fe(III) to Fe(II) was found to be the limiting step for the reaction (Anipsitakis and Dionysiou, 2003). Besides, the activation of PMS by Fe(III) will also produce $\mathsf { S } \mathsf { O } _ { 5 } ^ { \bullet - } ( 1 . 1 \mathtt { e } \mathsf { V } )$ under acidic conditions (Equation 2), greatly decreasing its oxidation capacity (Anipsitakis and Dionysiou, 2004).

other combination methods have been proposed to further enhance the performance of $\mathsf { F e } ( \mathsf { I I } )$ in PMS activation system. For example, iron tetracarboxyphthalocyanine molecules were synthesized as a homogeneous catalyst to activate PMS, which outperformed the performance of $C o ( | | )$ (Dai et al., 2017). Also, a ${ \mathsf { p } } { - } { \mathsf { M n } } / { \mathsf { F e } } _ { 3 } { \mathsf { O } } _ { 4 }$ catalyst with high porosity showed excellent regeneration ability just by simply washing with deionized water (Du et al., 2018a). Assisted UV irradiation has shown also to greatly improve the regeneration of $\mathsf { F e } ( \mathsf { I I } )$ (Khan et al., 2016). However, the following factors need to be considered when using the assisted-Fe(II)/PMS activation: (1) the elimination of competitive reaction between organic complexes and pollutants; (2) the reduction of energy consumption during the process; and (3) the simplicity of preparation and availability of the assisted materials or methods. Recently, AOPs with ${ \mathsf { M o S } } _ { 2 }$ as a cocatalyst have achieved surprising results (Xing et al., 2018; Wang et al., 2020; Sheng et al., 2019). However, there are still some critical problems with ${ \mathsf { M o S } } _ { 2 }$ as a cocatalyst to decompose PMS: the inevitable secondary pollution caused by the generation of ${ \sf H } _ { 2 } { \sf S }$ during reaction and the fact that ${ \mathsf { M o S } } _ { 2 }$ itself can activate PMS, leading to itself to be consumed.

Therefore, there is an urgent need to develop a greener and more efficient cocatalyst that can replace ${ \mathsf { M o S } } _ { 2 }$ for rapid, stable, and efficient cocatalytic decomposition of PMS for environmental remediation. Here, we present a facile strategy to significantly enhance the performance of $\mathsf { S O } _ { 4 } \mathrm { \Sigma } ^ { \bullet - }$ -based AOPs by using molybdenum dioxide $( \mathsf { M o O } _ { 2 } )$ as a cocatalyst in PMS/Fe(II) system. The oxidation efficiencies of PMS/Fe(II)/ $M \circ O _ { 2 }$ system were examined with different aromatic organic pollutants, including lissaminerhodamine B (L-RhB), phenol, methylene blue (MB), sulfadiazine, and norfloxacin. Among them, the degradation rate of L-RhB in the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system was significantly improved, 50 times higher than that in the PMS/Fe(II) system, with removal efficiency of $9 6 \%$ in $1 0 \mathsf { m i n }$ while very low concentration of Fe(II) was used $( 0 . 0 3 6 \mathsf { m M } )$ , exceeding most reported PMS/Fe(II) systems. We further employed surface chemical analysis and DFT calculation to understand the cocatalytic enhancement of ${ \mathsf { M o O } } _ { 2 }$ . The results revealed that the (110) crystal plane of ${ \mathsf { M o O } } _ { 2 }$ worked as active site for PMS activation, where the exposed Mo(IV) on the ${ \mathsf { M o O } } _ { 2 }$ cocatalyzed the conversion of Fe(III) to $\mathsf { F e } ( | | )$ . To the best of our knowledge, this is the first report of utilization ${ \mathsf { M o O } } _ { 2 }$ as a cocatalyst in $\mathsf { S O } _ { 4 } \cdot -$ -based AOPs. Compared with ${ \mathsf { M o S } } _ { 2 }$ cocatalytic AOPs system, ${ \mathsf { M o O } } _ { 2 }$ cocatalytic system has higher valence band free electron density, less toxicity, better stability, and no release of secondary pollutants ${ \sf H } _ { 2 } { \sf S }$ (Hu et al., 2009). Therefore, it is reasonable to believe that ${ \mathsf { M o O } } _ { 2 }$ cocatalytic activation of PMS will have greater potential for large-scale practical environmental remediation.

# RESULTS

# $\ M \circ \mathsf { O } _ { 2 }$ Cocatalytic PMS/Fe(II) System for the Oxidation Reaction

As shown in Figure 1A, no oxidation of L-RhB was observed in the absence of PMS. Besides, in the absence of Fe(II) ions, the oxidation efficiency was extremely low that only $4 . 1 \%$ of L-RhB was removed. This is attributed mainly to almost no production of reactive radical species in the absence of PMS or Fe(II). When the concentration of $\mathsf { F e } ( | | )$ was fairly low $\left( 0 . 0 3 6 \mathsf { m } \mathsf { M } \right)$ and no ${ \mathsf { M o O } } _ { 2 }$ was added, the degradation performance of the PMS/Fe(II) system remained poor because of the slow conversion rate of Fe(III) to Fe(II) (Anipsitakis and Dionysiou, 2004), with only $2 9 \%$ of L-RhB degraded within $3 0 ~ \mathsf { m i n }$ . However, when all components were involved, L-RhB degraded near completely in 10 min $( 9 6 \% ) ,$ , indicating that ${ \mathsf { M o O } } _ { 2 }$ accelerated the conversion from Fe(III) to Fe(II), leading to continuous activation of PMS.

We also found that the degradation rate slowed as the concentration of L-RhB increased (Figure 1B), because there is always a constant number of radical species generated when the amount of PMS is fixed. In addition to L-RhB, the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system also showed a rapid and effective degradation of other organic pollutants. Figure 1C shows that phenol, MB, sulfadiazine, and norfloxacin were degraded by $6 9 \%$ , $8 4 \%$ , $80 \%$ , and $5 9 \%$ in $3 0 ~ \mathsf { m i n }$ , respectively, demonstrating the potentials of this system for remediating various organic pollutants.

To explore the influence of ${ \mathsf { M o O } } _ { 2 }$ , Fe(II), and PMS concentrations on the reaction rate, a series of experiments were conducted to determine the best reaction conditions (Figures S1A–S1C). The oxidation rate of L-RhB becomes faster with the increase of $\mathsf { F e } ( | | )$ and ${ \mathsf { M o O } } _ { 2 }$ at $\mathsf { p H 3 . 0 }$ (Figures S1A and S1B). It is worth noting that the concentration of $\mathsf { F e } ( \mathsf { I I } )$ in the solution was extremely low $( 0 { - } 0 . 0 3 6 ~ \mathsf { m M } )$ , far less than the molar amount of PMS, so the increase of $\mathsf { F e } ( \mathsf { I I } )$ concentration had a significant effect on the PMS activation (Anipsitakis and Dionysiou, 2003). The more addition of $M _ { 0 } O _ { 2 }$ provided more redox active sites for the transformation from Fe(III) to ${ \mathsf { F e } } ( { \mathsf { I I } } ) .$ , resulting in the rapid oxidation of L-RhB. However, with the increase of PMS (Figure S1C), the degradation rate first increased and then decreased a little, reaching the maximum when the adding amount of PMS was $0 . 6 5 0 \mathsf { m M }$ , which could be attributed to the scavenging of $\mathsf { S O } _ { 4 } \mathrm { \Sigma } ^ { \bullet - }$ by excess PMS to produce $\mathsf { S O } _ { 5 } ^ { \bullet - } \left( 1 . 1 ~ \mathsf { e V } \right)$ via Equation 3 (Ling et al., 2010).

The kinetics were investigated by using a first-order kinetic model, as in the following equation: $- | { \mathsf { n } } ( C / C _ { O } ) =$ $k \bullet t ,$ where $C _ { O }$ and $C$ represent organic matter concentrations at time $t = 0$ and $\mathrm { t } ,$ respectively, and $k ( \mathsf { m i n } ^ { - 1 } )$ ) is the reaction rate constant (Figures S1D–S1F). Figures S1D–S1F show that the experiment results were fitting the first-order kinetics well. Not surprisingly, the reaction rate constant (k) was upgraded with the increase of $\mathsf { F e } ( | | )$ and ${ \mathsf { M o O } } _ { 2 }$ . Specifically, the $k$ value with the condition of $0 . 0 3 6 \mathsf { m M F e } ( 1 1 ) ( 0 . 3 1 1 \mathsf { m i n } ^ { - 1 } )$ was 222 times faster than that without $\mathsf { F e } ( | | )$ $( 0 . 0 0 1 4 0 \mathsf { m i n } ^ { - 1 } )$ . Meanwhile, the addition of $M _ { 0 } O _ { 2 }$ made $" k "$ 4–50 times faster than that with no ${ \mathsf { M o O } } _ { 2 }$ added $( 0 . 0 0 9 3 8 \operatorname* { m i n } ^ { - 1 } )$ , and there was no striking difference between $3 0 0 \mathrm { m g / L }$ and $6 0 0 \mathrm { m g / L } \mathrm { M o O } _ { 2 }$ added. When the PMS concentration was $0 . 6 5 0 \mathsf { m M }$ , the $k$ value was the largest, about 2.3 times higher than that with $0 . 3 2 5 \mathsf { m M }$ and a little higher than that with $1 . 3 0 0 \mathsf { m } \mathsf { M }$ . As a result, we concluded that $\mathsf { F e } ( | | )$ had the greatest influence on the reaction rate in the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system, whereas the addition of ${ \mathsf { M o O } } _ { 2 }$ significantly reduced the required amount of $\mathsf { F e } ( \mathsf { I I } ) .$ , and the amount of PMS greatly determined the amount of radical species generated.

In the exploration of the influence of the initial pH in the mixture, we found that L-RhB could be removed efficiently in 30 min with a wide initial pH range of 2.0–9.0, as shown in Figure 1D. An increase in the degradation efficiency of L-RhB was obtained by increasing the initial pH from 2.0 to 3.0, in which $F e ( O H ) _ { 2 }$ might form and activate PMS more efficiently as reported previously (Pignatello et al., 2006). However, L-RhB could be still completely oxidized within 20 min when the initial pH was neutral. There was a slight decrease in the degradation rate when the initial pH increased from 4.0 to 7.0. It has been reported that $\mathsf { F e } ( | | )$ coprecipitates with Fe(III) oxyhydroxides when both Fe(II) and Fe(III) coexist under a pH value over 3.0. The degradation rate of L-RhB continued to decrease as the initial pH was increased to 9.0 because of more iron coprecipitation. Thus, the fastest degradation rate was obtained at $\mathsf { p H 3 . 0 }$ . According to Equation 1, when $\mathsf { F e } ( | | )$ activates PMS, $\mathsf { O H } ^ { - }$ is generated. Under acidic conditions, the generated $\mathsf { O H } ^ { - }$ can be quickly neutralized so that the reaction can proceed in the positive reaction direction. Moreover, under acidic conditions, $\mathsf { F e } ( | | )$ is not easily complexed with $\mathsf { O H } ^ { - }$ , which leads its precipitation. Thus, PMS can be activated more easily by Fe(II) under acidic conditions. Nevertheless, with the increase in initial pH, the removal efficiency of L-RhB in the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system varied slightly but remained superior compared with the PMS/ Fe(II) system. The variation of pH values in the system was also measured during the reaction process as shown in Figure 1E. Considering the possibility of radical consumption or complexation with Fe(II) or Fe(III), there were no buffering reagents included in the solution so far. Regardless of the initial pH of the system, the reaction solution would quickly become acidic when PMS was added, because $K H S O _ { 4 }$ molecules are essential part of the PMS mixtures (Wacławek et al., 2015). Also, the pH values slowly declined until PMS was completely consumed (Figure 1E). This explains why the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system maintained a high level of activity in the treatment of neutral dye solution because this dropping of pH value would suppress the precipitation of Fe(II), keeping Fe(II) at high catalytic activity in the acidic solution. Moreover, the influence of solution pH was also investigated with potassium hydrogen phthalate (C8H5KO4, $\mathsf { p H 4 . 0 0 }$ ), mixed phosphate $\left( \mathsf { p H } 6 . 8 6 \right)$ ), and borax $( \mathsf { N a } _ { 2 } \mathsf { B } _ { 4 } \mathsf { O } _ { 7 } { \cdot } 1 0 \mathsf { H } _ { 2 } \mathsf { O } _ { \prime }$ , pH 9.18) buffer solutions, respectively. As shown in Figure S2, the degradation efficiency of L-RhB became extremely poor at all three different pH conditions, which may be attributed to the consumption of most of the free radicals by the ions in the buffer solution, leading to few free radicals attacking L-RhB molecular (Zou et al., 2013).

We concluded that the optimal conditions for the degradation of L-RhB were as follows: an initial pH value of 3.0, PMS concentration of around $0 . 6 5 0 \mathsf { m M }$ , and the more ${ \mathsf { M o O } } _ { 2 }$ and Fe(II) are added to the system, the faster the reaction rate will be. Given that moderate dosages of $3 0 0 \mathrm { m g } / \mathrm { L } \mathrm { M o O } _ { 2 }$ and $0 . 0 3 6 \mathsf { m M F e } ( | | )$ were enough to completely degrade L-RhB, they were chosen for most further experiments in the subsequent investigations. Ultimately, the performance of PMS/Fe(II)/MoO2system was also compared with other reported heterogeneous catalysis $\ S { \ O _ { 4 } } ^ { \cdot - }$ -based AOPs, where its removal efficiency performed most reported values as shown in Table S1.

# xploration of PMS Activation Mechanism in PMS/Fe(II)/MoO2 System

The slow conversion of Fe(III) to Fe(II) is the rate-determining step in effective PMS activation (Rastogi et al., 2009a, 2009b). Based on our results, the acceleration of L-RhB oxidation rate was attributed to ${ \mathsf { M o O } } _ { 2 }$ promoting the transformation of Fe(III) to Fe(II), consequently leading to faster activation of PMS. To further explore this hypothesis, the valence levels of Fe(II) and Fe(III) during the reaction were investigated. According to Equation 4, the ratio of Fe(II) to Fe(III) is believed to be positively correlated with the activation rate of PMS. 1,10-phenanthroline molecule can complex with Fe(II) to produce the jacinth complex in a pH range of 2–9 (Harvey et al., 1955, Herrera et al., 1989), whereas potassium thiocyanate (KSCN) is usually used to coordinate with Fe(III) to produce a blood-red complex (Kusic et al., 2011). As shown in Figures 2C and 2D, before the addition of PMS, the concentrations of Fe(II) (blue bar) were the same, whereas no Fe(III) was detected in the solutions (orange bar) in both the PMS/Fe(II) system and the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system. When PMS was added, the concentrations of $\mathsf { F e } ( | | )$ in the solutions rapidly decreased, and the concentrations of Fe(III) reached their maximum values within $5 \mathsf { m i n } _ { \iota }$ illustrating that most Fe(II) was immediately oxidized to Fe(III) by PMS (Equation 1), and the reduction of Fe(III) was slow in the system (Equation 2). Fe(II) was extremely low during L-RhB oxidation in both systems. After almost complete consumption of PMS, Fe(III) was gradually reduced to $\mathsf { F e } ( | | )$ by ${ \mathsf { M o O } } _ { 2 }$ until it maintained a relative dynamic equilibrium with the residual PMS, further indicating that $M _ { 0 } O _ { 2 }$ continuously accelerate the conversion of Fe(III) to Fe(II) because the presence of PMS made Fe(II) difficult to exist stably. After the PMS was almost consumed, the stable existence of Fe(II) could be detected. Notably, the equilibrium concentration of Fe(III) in the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system was much lower than that in the PMS/Fe(II) system. Therefore, zeta potential tests were conducted to determine the isoelectric point (IEP) of ${ \mathsf { M o O } } _ { 2 }$ . The results showed that its IEP was between ${ \mathsf { p H 4 } }$ and 5 (Figure 2E). Because the $\mathsf { p H }$ was lower than 4 during the reaction, the surface of ${ \mathsf { M o O } } _ { 2 }$ would be positively charged, leading PMS to be easily adsorbed, and then Fe(II) could be absorbed as well. Then, ${ \mathsf { M o O } } _ { 2 }$ was recovered, dried, and redispersed in an acidic aqueous solution $\langle \mathsf { p H } = 3 \rangle$ after completing the oxidation reaction. Through ICP measurements of the supernatant, we found that the iron ions adsorbed on the surface of $M \circ { \cal O } _ { 2 }$ accounted for $8 7 . 7 \%$ of the initial amount, which could explain the low equilibrium concentration of Fe(III) and the incomplete recovery of $\mathsf { F e } ( | | )$ in the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system.

# DFT Calculation

DFT calculation was employed to investigate the reaction mechanism in the $\mathsf { P M S / F e ( l l ) / M o O } _ { 2 }$ system. $M \circ \mathsf { O } _ { 2 }$ has a monoclinic crystal structure, with P21c space group, and unit cell dimensions of $\mathtt { a } =$ $5 . 6 1 1 \mathring { \mathsf { A } } , \mathsf { b } = 4 . 8 5 6 \mathring { \mathsf { A } } , \mathsf { c } = 5 . \dot { 6 } 2 9 \mathring { \mathsf { A } } ,$ and $\beta = 1 2 0 . 9 5 ^ { \circ }$ (Brandt, 1971). Figure S5A shows its crystal structure, which consists of distorted octahedral $[ \mathsf { M o O } _ { 6 } ]$ units. Structural optimizations of bulk $M \circ { \cal O } _ { 2 }$ were performed at a series of volumes to obtain the equilibrium unit cell parameters. The calculated lattice parameters $( \mathsf { a } = 5 . 5 9 4 \hat { \mathsf { A } } , \mathsf { b } = 4 . 9 1 0 \hat { \mathsf { A } } , \mathsf { c } = 5 . 6 8 2 \hat { \mathsf { A } } )$ and bond angle $\mathrm { \Delta } ( \mathrm { \ B } = 1 2 0 . 4 7 ^ { \circ } )$ were generally consistent with experimental data. To better understand the activation mechanism of PMS molecules (labeled as ${ \mathsf { H S O } } _ { 5 } -$ in Figure S5B) on the ${ \mathsf { M o O } } _ { 2 }$ surfaces, DFT calculations were performed to determine which species are stable. The most commonly studied surface in rutile-type $M _ { 0 } O _ { 2 }$ systems is the (110) plane, where the atomic layers along the [110] direction are ordered as MoO-O- ${ \cal O } ^ { \prime }$ -MoO (Tokarz-Sobieraj et al., 2011). The $M _ { 0 } O _ { 2 }$ (110) surface possesses three distinct surface terminations: (1) both Mo and $\bigcirc$ atoms exposed, (2) with O atoms exposed, and (3) $\bigcirc ^ { \prime }$ atoms exposed, as shown in Figures S5C–S5E. The comparison of surface formation energy—1.25 $\mathsf { J } / \mathsf { m } ^ { 2 } .$ , $1 . 1 2 \mathrm { \ J } / \mathsf { m } ^ { 2 } ,$ and $0 . 7 9 \mathrm { \ J } / \mathsf { m } ^ { 2 } .$ —indicated that a surface with the ‘‘bridging oxygen’’ termination $\bigcirc ^ { \prime }$ termination) was most likely to form, hence, it was selected for the further analysis.

As shown in Figure 4A, during the activation on the ${ \mathsf { M o O } } _ { 2 }$ (110) surface, the PMS molecule was likely to locate at the $M \circ { \cal O } _ { 2 }$ (110) surface with the two $\bigcirc$ atoms on the ${ } _ { - } \mathsf { S O } _ { 4 }$ side bonding with two Mo atoms of the surface. The two bond lengths were calculated as $2 . 0 9 \mathring { \mathsf { A } }$ and $2 . 0 7 \mathring { \mathsf { A } } ,$ respectively. In addition, the H atom on the -OH side would form a hydrogen bond with the $\bigcirc ^ { \prime }$ termination (approximately $1 . 8 0 \mathring { \mathsf { A } }$ in length), where the O-O bond length $( I _ { \mathrm { O - O } } )$ rarely changed after its adsorption. All these inhibited the generation of hydroxyl radicals, which could explain the poor performance of ${ \mathsf { M o O } } _ { 2 }$ alone in activating PMS. For the adsorption of PMS on the Fe(II)-decorated $\bigcirc ^ { \prime }$ surface, the PMS attached to the surface with three $\bigcirc$ atoms from - ${ \mathfrak { - } } \mathsf { S } { \mathsf { O } } _ { 4 }$ group binding the Fe(II) and two Mo atoms, as shown in Figure 4B. The bond lengths were calculated as 2.08 A˚ , $2 . 2 4 \mathring { \mathsf { A } } ,$ , and $2 . 2 7 \mathring { \mathsf { A } } ,$ respectively. The adsorption between PMS and surface was enhanced by these three bonds, the occurrence of more electron transfer, and that -OH side would be maintained far from the surface, leading to an elongation of $I _ { \mathrm { O - O } }$ . To better understand the interaction between the surfaces and PMS activation, we calculated the adsorption energy of PMS $\ [ E _ { \mathrm { a d s } } )$ on the different surfaces, charge transfer $( \Delta \mathsf { q } )$ between PMS and (110) surfaces, and the bond length $( I _ { \mathrm { O - O } } )$ between the -OH group and ${ } _ { - } \mathsf { S O } _ { 4 }$ group. All results are summarized in Table S3. The adsorption on both surfaces was found to be strong, with $E _ { \mathsf { a d s } }$ being $- 2 . 0 6$ and $- 3 . 1 7 \mathrm { e V }$ for ${ \mathsf { M o O } } _ { 2 }$ (110) surface without and with $\mathsf { F e } ( | | )$ respectively. This was also consistent with the formation of chemical bonds between PMS and the two surfaces, illustrating the strong interaction between PMS and Fe(II) and electrons transferred from the surface atoms to the PMS molecules. The adsorption of PMS on Fe(II)-(110) was stronger, with lower $E _ { \mathsf { a d s } } ,$ longer $I _ { \mathrm { O - O } } ,$ and more electrons received from the metal atoms on the surface. Therefore, we concluded that the PMS on the modified $M \circ O _ { 2 }$ (110) surface was the most active site.

Based on the above comprehensive characterization and DFT calculations (Figure 4), the mechanism of the L-RhB degradation can be inferred as follows: first, ${ \mathsf { H S O } } _ { 5 } -$ adsorbed on ${ \mathsf { M o O } } _ { 2 }$ surface under acidic conditions, followed by $\mathsf { F e } ( | | )$ approaching the surface owing to its positive charge. Subsequently, $\mathsf { F e } ( | | )$ donates one electron to ${ \mathsf { H S O } } _ { 5 } -$ transforming into $\mathsf { F e } ( \mathsf { I I I } )$ . Therefore, ${ \mathsf { H S O } } _ { 5 } -$ is dissociated into the radical species ( , OH and $\ S O _ { 4 } ^ { \bullet - } )$ ) to attack the organic molecules. These results are supported by the rapid decline of $\mathsf { F e } ( | | )$ in the first minute (Figure 2D) and the EPR signals of DMPO, -OH and $\mathsf { D M P O } ^ { \bullet } { \cdot } \mathsf { S O } _ { 4 } ^ { - }$ adducts (Figure 2B). Afterward, the organic compounds are mineralized by those radical species, and Fe(III) is reduced to $\mathsf { F e } ( | | )$ by Mo(IV) on the surface of the $M _ { 0 } O _ { 2 }$ to continue activating PMS at the same time. Moreover, PMS is also decomposed to produce $\mathsf { S O } _ { 5 } \mathsf { ^ { * - } }$ as a by-product. This cocatalytic mechanism of ${ \mathsf { M o O } } _ { 2 }$ in the PMS/ $\mathsf { F e } ( \mathsf { I I } ) / \mathsf { M o O } _ { 2 }$ system is schematically summarized in Figure 5A.

High-performance liquid chromatography (HPLC) was employed to analyze the primary products after the L-RhB degradation in the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system. As shown in Figure 5B, the strongest peak at $1 4 . 0 2 \mathrm { m i n } _ { . }$ , which corresponds to complete disappearance of L-RhB molecules after the oxidation reaction, confirms its complete degradation. Moreover, the PMS/Fe(II)/MoO2 system achieved relatively a high total organic carbon (TOC) removal rate $( 5 0 \% )$ with the addition of $0 . 6 5 0 \mathsf { m M }$ PMS per 30 min, as illustrated in Figure 5C. This method may be an appropriate way for further mineralization of intermediates to $\mathsf { H } _ { 2 } \mathsf { O }$ and $C O _ { 2 }$ (Zou et al., 2013).

Due to the complex structure of L-RhB, we explored the degradation intermediates and mechanisms of phenol, another organic pollutant that can be degraded in the $\mathsf { P M S / F e ( l l ) / M o O } _ { 2 }$ system. Based on the fragment peaks obtained from gas chromatography-mass spectrometry (GC-MS) measurements (Figure S6), we speculated that mainly $\mathsf { S O } _ { 4 } \mathsf { \Omega } ^ { \bullet - }$ and ,OH would attack the benzene ring first to form phenoxy radicals, thereby producing a series of ring-opening reactions, as speculative in the oxidation reaction pathway depicted in Scheme S1. However, the fragment $( \mathsf { m } / z = 7 3 )$ ) with the strongest molecular ion peak could be attributed to glyoxylic acid intermediate, which is known to resist mineralization (Pimentel et al., 2008).

The reusability of ${ \mathsf { M o O } } _ { 2 }$ is a very important aspect for commercial pollutants treatment. The cocatalytic activity of ${ \mathsf { M o O } } _ { 2 }$ was greatly reduced in the second cycle as shown in Figure 5D. Vacuum calcination was employed to restore the activity of ${ \mathsf { M o O } } _ { 2 }$ . As shown in Figure S7, the activity of ${ \mathsf { M o O } } _ { 2 }$ after vacuum calcination was still much worse than the original. Therefore, we suspect that the active sites on the surface of ${ \mathsf { M o O } } _ { 2 }$ were covered by carbon deposits, which were difficult to remove, but after UV irradiation of ${ \mathsf { M o O } } _ { 2 } ,$ its cocatalytic activity was restored, which could be attributed to the decomposition of some unmineralized carbon-based residues on $M \circ { \cal O } _ { 2 }$ surface. Hence, its cocatalytic activity remained stable for the next three recycles.

Subsequently, the amount of the dissolved Mo ions under acidic conditions was determined. Figure S8 shows that the dissolution balance of Mo ions $( 1 . 6 0 \mathrm { m g / L } , 0 . 7 1 \%$ of the total Mo addition) was achieved in $1 2 0 ~ \mathrm { m i n }$ . Because each experiment ended in $3 0 ~ \mathsf { m i n }$ , and the dissolved Mo ions might be the primary cocatalyst in reducing Fe(III) rather than ${ \mathsf { M o O } } _ { 2 }$ itself, the degradation of L-RhB and the variation of Fe(II) and Fe(III) concentrations were measured in the PMS/Fe(II)/dissolved Mo ion system. As shown in Figure 5E, the degradation rate of L-RhB dropped sharply, with only $5 1 . 9 \%$ degraded in 30 min, which is far slower than that in the PMS/Fe(II)/MoO2 system. This demonstrates that the main cocatalytic effect in the PMS/Fe(II)/ $M \circ O _ { 2 }$ system comes from Mo(IV) on the surface of $M _ { 0 } O _ { 2 }$ rather than the dissolved Mo ions. Also, the variations of Fe(II) and Fe(III) concentrations can explain the poor performance of the PMS/Fe(II)/dissolved Mo ion system. As shown in Figure 5F, almost no Fe(II) was recovered after 30 min, whereas Fe(III) concentration remained almost constant similar to the PMS/Fe(II) system, which could be correlated to the low conversion rate of Fe(III)/Fe(II), confirming that the few dissolved Mo ions were not sufficient to promote rapid Fe(III)/ $\mathsf { F e } ( | | )$ conversion.

Ultimately, a large scale-up test with 1 L system was employed to examine the practicality in scaling-up the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system for practical environmental remediations. As shown in Figure S9, PMS/Fe(II)/ $M \circ O _ { 2 }$ system maintained its excellent catalytic performance compared with the PMS/Fe(II) system even in this large volume, consistent with results in Figure 1A. Moreover, we found that 12 times the amount of Fe(II) $( 4 0 \mathrm { \ m g / L }$ per 10 min added) was required to make the degradation effect of PMS/Fe(II) system almost same as that of $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system. Therefore, the addition of ${ \mathsf { M o O } } _ { 2 }$ reduced the amount of $\mathsf { F e } ( | | )$ needed by more than $9 2 \%$ and subsequently reduced the generation of iron sludge and the cost of secondary pollution treatment. Taking one ton of this wastewater as an example, the consumption of PMS and $\mathsf { F e } ( | | )$ in MS/Fe(II) system was $0 . 8 2 \$ 5$ and $0 . 1 7 \$ 8$ , respectively. And the consumption of PMS and $\mathsf { F e } ( \mathsf { I I } )$ in $\mathsf { P M S / F e ( l l ) / M o O } _ { 2 }$ system was $0 . 8 2 \$ 5$ and $0 . 0 1 \$ 5$ . Considering that the amount of PMS added to the two systems is the same, the cost difference between the two systems is mainly due to the amount of iron added. Therefore, the addition of cocatalyst can save $9 4 \%$ of the cost. This shows the great potentials of the PMS/Fe(II)/MoO2 system for industrial applications.

# Expanded Application of ${ \mathsf { M o o } } _ { 2 }$ in PMS/Fe(III) System

In general, Fe(III) does not readily activate PMS according to Equation 2. However, because the addition of ${ \mathsf { M o O } } _ { 2 }$ significantly promotes the conversion of Fe(III) to $\mathsf { F e } ( | | )$ , it should enhance the decomposition of PMS in PMS/Fe(III) system. To examine this hypothesis, we carried a series of testing for the degradation of L-RhB in $\mathsf { P M S } / \mathsf { F e } ( | | | ) / \mathsf { M o O } _ { 2 }$ system as shown in Figure 5G. The obtained results were far better than the PMS/Fe(III) system $( 4 . 1 \% )$ and the $\mathsf { P M S } / \mathsf { M o O } _ { 2 }$ system $( 3 . 3 \% )$ , where no degradation was observed in the $\mathsf { F e } ( | | \mathsf { I } | ) / \mathsf { M o O } _ { 2 }$ system. This might be because Fe(III) was reduced to Fe(II) immediately after the addition of ${ \mathsf { M o O } } _ { 2 } ,$ leading to its spontaneously precipitation. Therefore, the performance of the degradation of L-RhB is substantially the same as that in the $\mathsf { P M S } / \mathsf { M o O } _ { 2 } / \mathsf { F e } ( \mathsf { I I } )$ ) system. Figures S10 and S11 show the great degradation performance of L-RhB and other organics, and Figure S12 shows the almost same kinetic results as $\mathsf { P M S } / \mathsf { M o O } _ { 2 } / \mathsf { F e } ( | | )$ system. The degradation of L-RhB in different pH was also investigated as shown in Figure S13. Radical quenching tests proved that $\mathsf { S O } _ { 4 } \mathrm { \Sigma } ^ { \bullet - }$ was the main reactive species (Figure S14), which was further supported by EPR spectra (Figure S16). Typically, as shown in Figure S15, as the reaction progressed, Fe(III) rapidly decreased and $\mathsf { F e } ( | | )$ gradually increased, but the total amount of iron ions detected after starting the reaction was lower than initially added. This may be because in the presence of PMS and ${ \mathsf { M o O } } _ { 2 } ,$ Fe(II) was rapidly oxidized by PMS, and Fe(III) was also rapidly reduced by ${ \mathsf { M o O } } _ { 2 } ,$ so that 1,10-phenanthroline and KSCN were difficult to capture $\mathsf { F e } ( | | )$ or Fe(III) quickly. The result proves the circulation of iron ions during the reaction in $\mathsf { P M S / F e ( l l l ) / M o O } _ { 2 }$ system. The oxidation mechanism of L-RhB in the $\mathsf { P M S } / \mathsf { F e } ( | | | ) / \mathsf { M o O } _ { 2 }$ system is also basically the same as that of PMS/Fe(II)/ ${ \mathsf { M o O } } _ { 2 }$ system, which was supported by SEM images (Figure S17), XRD patterns (Figure S18), Raman spectra (Figure S19), and XPS spectra (Figures S20–S22). The only difference that might exist is that in the PMS/Fe(III)/MoO2 system, ${ \mathsf { M o O } } _ { 2 }$ reduces the surface-adsorbed Fe(III) to $\mathsf { F e } ( | | )$ first and then activates PMS.

# DISCUSSION

The slow transformation from Fe(III) to $\mathsf { F e } ( \mathsf { I I } )$ has persistently limited the practical application of PMS/Fe(II) systems, for which a great amount of iron ions are needed to activate PMS, causing massive formation of iron sludge. In the $\mathsf { P M S / F e ( l l ) / M o O _ { 2 } }$ system, this problem is solved by the addition of ${ \mathsf { M o O } } _ { 2 } ,$ which is earthabundant, quite stable, and has enough reductive power to reduce Fe(III). Therefore, an extremely low concentration of Fe(II) $( 0 . 0 3 6 ~ \mathrm { m M } )$ is adequate to activate PMS and degrade organic pollutants rapidly in the wide pH range of 2.0–9.0. The iron sludge is limited so that no more secondary pollution is caused. $\mathsf { S O } _ { 4 } \mathsf { \Omega } ^ { \bullet - }$ and , OH are the primary reactive species produced in the PMS/Fe(II)/MoO2 system. The TOC removal rate of L-RhB reached $50 \%$ with the addition of PMS, which will be an appropriate approach to completely mineralize refractory organic contaminants. Moreover, $M _ { 0 } O _ { 2 }$ could be recycled and exhibited excellent recover activity after its treatment with UV light irradiation. The involvement of $M \circ { \cal O } _ { 2 }$ in the PMS/Fe(II) system could allow for the low-cost remediation of organic pollutants, thus contributing to sustainable development for the environment.

# Limitations of the Study

Although this study greatly accelerates the activation of PMS and reduces secondary pollution compared with some other systems, the amount of catalyst needed for the reaction is relatively high. Fe(II) is inevitably needed to activate PMS because ${ \mathsf { M o O } } _ { 2 }$ itself cannot activate PMS.

Experimental Procedures. All experiments were performed in plastic cups with magnetic stirring to keep the solution homogeneous during the reaction. The predesigned initial $\mathrm { p H }$ of the L-RhB solution was adjusted first with NaOH, $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ or buffer solutions. Then, fixed amounts of $\mathbf { M o O } _ { 2 }$ and $\mathrm { F e S O } _ { 4 } { \bullet } 7 \mathrm { H } _ { 2 } \mathrm { O }$ were added to $1 0 0 ~ \mathrm { m L }$ reaction solutions with the desired concentration of organic pollutants. Finally, quantitative PMS was added to initiate the oxidation. Samples were taken out at regular intervals, centrifuged and analyzed immediately. The stability of $\mathbf { M o O } _ { 2 }$ was also investigated. After being centrifuged, washed, dried and vacuum calcination/UV $3 6 5 ~ \mathrm { n m }$ )-activated, $\mathbf { M o O } _ { 2 }$ continued to participate in the next degradation reaction.

Radical quenching tests. Radical quenching tests were conducted to identify the dominant radicals in $\mathrm { P M S / F e ( I I ) / M o O } _ { 2 }$ system with methanol and TBA, which were added before the addition of PMS. The other procedures were the same as the experiments above. The radical species were further detected by electron paramagnetic resonance (EPR) technology, where 5,5-dimethyl-1-pyrroline (DMPO) was used as a spin-trapping reagent. The detailed parameters were as follows: a center field of $3 5 2 . 0 ~ \mathrm { m T }$ , a sweep width of $2 0 . 0 ~ \mathrm { m T }$ , a microwave frequency of $9 . 8 8 2 ~ \mathrm { G H z }$ , a microwave power of $6 . 4 0 2 ~ \mathrm { m W }$ , a temperature of 300.0 K, a receiver gain of $7 . 9 6 \times 1 0 ^ { 4 }$ , a modulation amplitude of $0 . 1 ~ \mathrm { m T }$ , and a sweep time of 41.94 s.

The variety of iron ions concentrations. The variety of Fe(II) or Fe(III) concentration was tracked during the reaction by complexing the samples with 1, 10-phenanthroline or potassium thiocyanate (KSCN), respectively. Fe(II) and Fe(III) can be complexed with 1,10-philoxene and KSCN for color development, respectively. Since the concentration of the complex is proportional to the absorbance, the corresponding absorbance of Fe(II)/Fe(III)-complex with the initial known concentration was measured. Thus, the content of Fe(II)/Fe(III) can be calculated from the ratio of the absorbance of the complex to the absorbance of the initial complex at different time periods: The L-RhB solution was replaced by deionized water while the other conditions and procedures remained unchanged; excessive 1,10-phenanthroline or potassium thiocyanate reagent was immediately added after sampling and centrifuging, and then analyzed.

The effect of dissolved Mo ions. Moreover, in order to investigate the effect of dissolved Mo ions for (i) the conversion of $\mathrm { F e ( I I I ) / F e ( I I ) }$ and (ii) the degradation of L-RhB, the following experiments were also explored: $\mathbf { M o O } _ { 2 }$ was added first in (i) deionized water or (ii) L-RhB solution at fixed initial pH. Then, the solution was stirred for $3 0 \mathrm { { m i n } }$ to dissolute Mo ions and centrifuged to remove solid $\mathbf { M o O } _ { 2 }$ . Finally, $\mathrm { F e S O } _ { 4 } { \cdot } 7 \mathrm { H } _ { 2 } \mathrm { O }$ and PMS was added to initiate the reaction. (i) Excessive 1,10-phenanthroline reagent was immediately added after sampling and centrifuging, and then analyzed; (ii) samples were taken out at regular intervals, centrifuged and analyzed immediately.

All the experiments in PMS/Fe(III)/MoO2 system were the same as those in PMS/Fe(II)/MoO2 system, just using $\mathrm { F e ( I I I ) }$ to replace $\mathrm { F e ( I I ) }$ .

DFT calculation. Computational details. Density functional theory (DFT) calculations were carried out using the all-electron code Fritz-Haber Institute ab initio molecules simulations package (FHI-aims).(Blum et al., 2009) Interactions between atomic core shells and the valence electrons were described using the projector-augmented wave (PAW) method, the Perdew-Burke-Ernzerh (PBE) of gradient-corrected functional was used to treat the exchange and correlation. (Perdew, 1996, Kresse, 1999) The default “tight” species were chosen in this work. Considering the weak non-covalent van der Waals attraction, all calculations were performed by the scheme of Tkatchenko and Scheffler. (Tkatchenko and Scheffler, 2009) Gaussian smearing was used with a width of $0 . 1 \ \mathrm { e V }$ to determine the partial occupancies. The convergence threshold was set to be $1 0 ^ { - 5 } ~ \mathrm { e V }$ in energy and $1 0 ^ { - 3 } \mathrm { e V } { \cdot } \mathring { \mathrm { A } } ^ { - 1 }$ in force. A periodic (110) slab model of $\mathbf { M o O } _ { 2 }$ was built up to simulate the activation process of peroxymonosulfate (PMS) molecules, which preferred to adsorb on the (110) surfaces, contributed to the electron transfer and the generation of hydroxyl radicals. Besides, the catalytic effect of $\mathrm { F e ( I I ) }$ ions was also taken into account for low surface coverages of PMS molecules. To minimize the interaction of (110) surfaces in different supercells along c direction, a $2 0 \textrm { \AA }$ vacuum layer between them was taken. All atoms were allowed to relax expected the bottom three-layer atoms to fix at the bulk parameters. Brillouin zone was sampled using a $3 { \times } 3 { \times } 1$ Monkhorst Pack k-point mesh during geometry optimization and properties calculation for the (110) surface of $\mathbf { M o O } _ { 2 }$ . (Monkhorst, 1976)

Adsorption energy and charge transfer. To reveal the activation process of PMS molecule on the (110) surface of $\mathbf { M o O } _ { 2 }$ , the interaction between them could be evaluated by the adsorption energies, which was defined as $\Delta E _ { \mathrm { a d s } } { = } E _ { \mathrm { M o O } _ { 2 } + \mathrm { P M S } ^ { - } }$ $E _ { \mathrm { M o O } _ { 2 } } – E _ { \mathrm { P M S } }$ , where $E _ { \mathrm { M o O } _ { 2 } + \mathrm { P M S } }$ was the total energy for the PMS adsorbed on the surface, $E _ { \mathrm { M o O } _ { 2 } }$ was the total energy for the $\mathbf { M o O } _ { 2 }$ substrate without adsorption, and $E _ { \mathrm { P M S } }$ was the total energy of a separated molecule as determined from DFT calculations. The Mulliken charge analysis was used to quantitatively estimate the amount of charge transfer between the adsorbed molecule and $\mathbf { M o O } _ { 2 }$ substrate, which contributed to reveal the activation mechanism. (Tang et al., 2009)
