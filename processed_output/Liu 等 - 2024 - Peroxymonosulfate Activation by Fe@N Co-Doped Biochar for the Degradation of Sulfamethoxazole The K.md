Abstract: In this study, Fe, N co-doped biochar ( $\mathrm { F e @ N }$ co-doped BC) was synthesized by the carbonization–pyrolysis method and used as a carbocatalyst to activate peroxymonosulfate (PMS) for sulfamethoxazole (SMX) removal. In the $\mathrm { F e @ N }$ co-doped BC/PMS system, the degradation efficiency of SMX $( 1 0 . 0 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 } )$ ) was $9 0 . 2 \%$ within $4 0 \mathrm { m i n }$ under optimal conditions. Radical quenching experiments and electron spin resonance (ESR) analysis suggested that sulfate radicals $( \mathrm { S O _ { 4 } } ^ { \bullet - } )$ ), hydroxyl radicals $( { } ^ { \bullet } \mathrm { O H } )$ , and singlet oxygen $( ^ { 1 } \mathrm { O } _ { 2 } )$ participated in the degradation process. After the reaction, the proportion of pyrrolic $_ \mathrm { N }$ decreased from $5 7 . 9 \%$ to $2 7 . 1 \%$ . Pyrrolic $_ \mathrm { N }$ served as an active site to break the inert carbon network structure and promote the generation of reactive oxygen species (ROS). In addition, pyrrolic N showed a stronger interaction with PMS and significantly reduced the activation energy required for the reaction $( \Delta \mathrm { G } = 2 3 . 5 4 \mathrm { k c a l / m o l } )$ . The utilization potentiality of $\mathrm { F e @ N }$ co-doped BC was systematically evaluated in terms of its reusability and selectivity to organics. Finally, the intermediates of SMX were also detected.

Keywords: biochar; sulfate radicals; peroxymonosulfate; pyrrolic N

# 1. Introduction

Sulfamethoxazole (SMX), as a common sulfonamide drug, can efficiently treat gastroenteritis, coccidiosis, diarrhea, and other infections and diseases [1]. Due to the high water solubility and potential carcinogenicity of SMX, it has a negative impact on the ecosystem [2,3]. Since SMX is not easy to degrade through conventional treatment processes, it is urgent that we explore an efficient, low-cost, and simple technology for eliminating residual SMX in the aquatic environment.

Advanced oxidation processes (AOPs) have received a huge amount of attention due to their high efficiency and extensive adaptability [4]. Among AOPs, persulfate-based advanced oxidation processes (PS-AOPs) have gradually emerged due to their unique advantages such as a higher oxidation potential and a wider applicability in aquatic environments [5,6]. Due to having a higher oxidation potential $( 2 . 5 \mathrm { - } 3 . 1 \mathrm { ~ V ~ }$ vs. 1.9–2.7 V) and longer half-life $( 3 0 - 4 0 ~ \mu \mathrm { s }$ vs. $2 0 ~ \mathrm { n s }$ ) than hydroxyl radicals $( ^ { \bullet } \mathrm { O H } ) .$ , sulfate radicals $( \mathrm { S O _ { 4 } } ^ { \bullet - } )$ can rapidly travel long distances to attack pollutant molecules and oxidize them thoroughly [7]. As a result, there are several approaches to peroxydisulfate (PDS) and peroxymonosulfate (PMS) activation to produce reactive oxygen species (ROS), such as electrolysis, ultrasound, ultraviolet irradiation, heat, and transition metals [8]. Biochar (BC) is produced via the thermochemical treatment of biomass under an oxygen-limited atmosphere [9]. Biomass feedstock, such as citrus peels, maize stalks, sawdust, corncobs, wood chips, and shrimp shells, is rich and low-cost [7]. Furthermore, BC contains abundant oxygen-containing functional groups (e.g., C-OH, -COOH,3 $\mathrm { C } { = } \mathrm { O } )$ and micropore or mesopore structures [10]. The redox cycle of metal ions (e.g.,2+ + $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ , $\mathrm { C u } ^ { 2 + } / \mathrm { C u } ^ { + } )$ can contribute to the generation of ROS in catalytic oxidation processes due to the consecutive cleavage of the peroxide bond (O-O) [11]. Nitrogen doping adjusts the chemical properties of the graphitic structure and increases the electron cloud density of the surrounding carbon atoms, and, thus, regulates the chemical properties of biochar-based catalysts [12].

Herein, Fe, N co-doped biochar ( $\mathrm { F e @ N }$ co-doped BC) was prepared through the carbonization–pyrolysis method and was used as a PMS activator for the elimination of SMX. Characterizations and batch experiments were employed to assess the degradation ability of $\mathrm { F e @ N }$ co-doped BC. Then, the active species in the $\mathrm { F e @ N }$ co-doped BC/PMS system were identified by quenching tests and electron spin resonance (ESR) tests. The range of $\mathrm { F e @ N }$ co-doped BC dosing was $0 . 2 \mathrm { - } 0 . 8 \mathrm { g / L } ,$ , the concentration of PMS was $0 . 2 \mathrm { - } 0 . 8 \mathrm { m M }$ , the $\mathrm { p H }$ was 3.0–11.0, the SMX concentration was $0 . 5 { - } 1 0 . 0 \mathrm { m g / L } ,$ and the reaction temperature was set to $2 5 ^ { \circ } \mathrm { C }$ All experiments were carried out at $1 5 0 \ \mathrm { r p m } ,$ and $1 . 0 ~ \mathrm { m L }$ reaction solution was taken periodically at intervals and filtered through a $0 . 2 2 ~ { \mu \mathrm { m } }$ filter. The excess reaction was terminated by adding 1 mL ${ \mathrm { N a } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 3 }$ $( 0 . 2 { } \mathrm { M } )$ . Before the reaction, $0 . 1 \mathrm { M N a O H }$ or ${ \mathrm { H } } _ { 2 } { \mathrm { S O } } _ { 4 }$ was added into the reaction solution to adjust the initial $\mathrm { p H }$ values. All experiments were performed in triplicate.

# 4. Conclusions

In summary, $\mathrm { F e @ N }$ co-doped BC was prepared by the carbonization–pyrolysis method, and the catalyst obtained abundant catalytic centers $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } ,$ pyrrolic $\mathrm { N }$ ) and defect sites $\mathrm { ( I _ { D } / I _ { G } = 0 . 9 7 ) }$ . Under optimal conditions, the degradation efficiency of SMX in the $\mathrm { F e @ N }$ codoped BC/PMS system is $9 0 . 2 \%$ . The degradation process conforms to pseudo-first-order kinetics with a $k _ { \mathrm { o b s } }$ of $0 . 0 4 1 \mathrm { m i n } ^ { - 1 }$ . In addition, various typical PPCPs could be efficiently degraded in the $\mathrm { F e @ N }$ co-doped BC/PMS system within $4 0 \mathrm { m i n }$ . The quenching experiment and ESR test results show that $\mathbf { \nabla } ^ { \bullet } \mathrm { O H }$ , $\mathrm { S O _ { 4 } ^ { \bullet - } }$ , and $^ 1 \mathrm { O } _ { 2 }$ were produced in the $\mathrm { F e @ N }$ co-doped BC/PMS system, in which $\mathrm { S O _ { 4 } ^ { \bullet - } }$ was the main active species. $\mathrm { S O _ { 4 } ^ { \bullet - } }$ can be produced in the redox cycle between $\mathrm { F e ( I I I ) }$ and $\mathrm { F e ( I I ) }$ , and $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ acts as an important catalytic center to break the inert carbon network structure and promote the formation of ROS in the reaction system. Before and after the reaction, the content of pyrrolic N decreased from $5 7 . 9 \%$ t o $2 7 . 1 \%$ . As the main active site, pyrrolic N showed stronger interaction with PMS and significantly reduced the activation energy required for the reaction $( \Delta \mathrm { G } = 2 3 . 5 4 \mathrm { k c a l / m o l } )$ ). Therefore, this work first solves the problem of low catalytic activity caused by the lack of catalytic center in carbon materials. Moreover, the excellent reusability, oxidation ability, stability, good mineralization ability, and low cost confirm that $\mathrm { F e @ N }$ co-doped biochar is a promising catalyst in industrial wastewater advanced treatment.
