# A B S T R A C T

Pure Magn´eli-phase $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ were prepared by means of a Plasma Torch (PT) coating method and integrated into an advanced electro-catalytic oxidation (AEO) process in order to degrade perfluorooctanoic acid (PFOA) and perfluorooctanesulfonic acid (PFOS) persistent pollutants present in waters. The X-ray diffraction analysis confirmed the polycrystalline nature of the pure Magn´eli phase $\mathrm { P T } \mathrm { - T i } _ { 4 } \mathrm { O } _ { 7 }$ coatings $( \sim 1 0 0 ~ \mu \mathrm { m }$ thick)). The Raman spectra of the $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ coatings also exhibited the two characteristic peaks (at 138 and $1 8 3 ~ \mathrm { c m } ^ { - 1 }$ ) of the PT$\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ Magn´eli phase. Scanning electron microscopy revealed the nanostructured hierarchical morphology of the $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ thus conferring them high surface area. The PT- $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ anodes are shown to achieve higher degradation efficiencies towards PFOA and PFOS in comparison with the conventional boron-doped diamond anodes. By investigating several AEO parameters (including current density, treatment time, nature of the anode material), we were able to optimise the AEO process. Thus, for both PFOA and PFOS (at an initial concentration of $5 0 0 { \mathrm { p p b } }$ in synthetic wastewaters), degradation efficiencies as high as $9 6 . 6 \%$ and $9 9 . 7 \%$ were achieved, respectively, with a current density of $2 0 ~ \mathrm { m A } / \mathrm { c m } ^ { 2 }$ , a treatment time of $1 2 0 ~ \mathrm { m i n }$ and PT- $\mathrm { \cdot \mathrm { T i } } _ { 4 } \mathrm { O } _ { 7 }$ mesh-type anodes. PFOA and PFOS can be degraded by both direct anodic electrochemical oxidation ( • OH radicals) and indirect electrochemical oxidation via mediators, such as persulphate acid $\mathrm { ( H _ { 2 } S _ { 2 } O _ { 8 } ) }$ generated by sulphate anodic oxidation. The degradation of both compounds followed pseudo-first-order kinetics. The reaction rate constant (k) for PFOS removal was $4 . 6 3 \times 1 0 ^ { - 2 } \mathrm { m i n } ^ { - 1 }$ , whereas $2 . 7 6 \times 1 0 ^ { - 2 } \mathrm { m i n } ^ { - 1 }$ was recorded for PFOA removal. Subsequently, we have used the above optimal AEO operating conditions to treat real wastewater effluents (containing 17 types of PFAS molecules with a total content of $8 5 0 0 ~ \mathrm { p p b }$ ) and achieved a degradation rate of $3 9 . 1 \% - 8 7 . 4 \%$ for eight of the 17 PFAS compounds. The degradation rate was found to be dependent on the chemical structure and chain length of each PFOA/PFOS component.

# 1. Introduction

Per and polyfluoroalkyl substances (PFAS, $\mathrm { C } _ { \mathrm { n } } \mathrm { F } _ { 2 \mathrm { n } + 1 } { - \mathrm { R } } )$ are a manmade chemicals that have been introduced to the world since 1930 (ITRC, 2020). Because of their high thermal and chemical stability, the PFAS have been widely used in a variety of application such as food packaging, non-stick cookware, waterproof makeup, aqueous firefighting foam, surface coatings, water-resistant fabrics, semiconductor industry, etc. (Buck et al., 2011; Rekik et al., 2024; Tsang et al., 1998). PFAS compounds are known by their highly stable C-F bonds that replace of the typical C-H bonds in organic molecules (Fujii et al., 2007). Additionally, highly fluorinated aliphatic substances are a subset of fluorinated compounds that contain one or more carbon atoms on which all hydrogen substituents have been replaced by fluorine atoms resulting in the presence of the perfluoroalkyl moiety $\mathrm { { C _ { n } F _ { 2 n - 1 } } }$ (Buck et al., 2011). Thus, PFAS are extremely persistent in the environment and human body and can be introduced in the environment through waste streams in different ways of making their removal very difficult. Due to their strong chemical stability, special procedures are generally required to handle this persistent class of contaminants (Tsang et al., 1998). A large portion of the PFAS persistent pollutants ends up in waste waters or can be a potential source of contamination of drinking waters. Unfortunately, the PFAS molecules are hardly removable by using traditional wastewater treatments and/or remediation methods. It is thus urgent to develop advanced and highly efficient technologies for the effective PFAS degradation and cleanup, in order to protect both human health and our environment.

While the PFAS related regulations are getting tighter, it is equally important to use affordable and scalable techniques for their massive treatment. Although there are many techniques and approaches for PFAS remediation, the advanced electrochemical oxidation (AEO) remains, to the best of our knowledge, the most appropriate and effective yet affordable and scalable approach. The choice of the AEO technique is justified by its robustness, ability to operate under severe conditions, and capacity to remove recalcitrant organic contaminants (Wang et al., 2020c). In general, the AEO process is based on the synergy between the anode oxidation reactions and the cathode reduction reactions. The goal of the AEO technique is the achievement of a degradation and ultimately a complete mineralization of the pollutants by exploiting and optimizing the redox reactions that produce a maximum of oxidant species (Coman et al., 2013; Nancharaiah et al., 2015). The oxidation of the PFAS occurs via the synergetic action of both direct anodic oxidation and indirect oxidation in the electrolytic reactor. First, the direct anodic oxidation takes place on the anode and drives a direct charge transfer reaction between the anode surface and the PFAS compound. To clearly understand the mechanism, a intermediation of the electrons endures the oxidation of the PFAS present in the effluent at a defined current density (Dombrowski et al., 2018). Secondly, the indirect oxidation is maintained by the in-situ produced oxidant species at the electrode surface such as hydrogen peroxide, hydroxyl radicals and persulphate (Dombrowski et al., 2018). Beside the redox reaction, the material used for the anodes is of paramount importance in the AEO pollutant removal rate (Brillas and Martínez-Huitle, 2015; Panizza and Cerisola, 2009). The elimination of PFAS by AEO has shown great promises, but finding the right anode is crucial to the process’s effectiveness. The effective breakdown of PFAS is ensured by choosing the appropriate anode material that can perform efficiently while retaining scalability and economic viability.

The nature and properties of the anodes used in electro-oxidation processing are key for the successful degradation of pollutants in water. They must be chemically stable, highly-electrically conductive, non-polluting, and cost-effective (Sarkk ¨ ¨a et al., 2015). Boron-doped diamond (BDD) is well known to be a reliable anode, but it is also a highly expensive one. Their high manufacturing costs and difficulty in obtaining large surface areas are significant barriers to their scale-up (ELECTROCHEMICAL OXIDATION OF SULFIDE IONS IN SYNTHETIC SOUR, 2010; Kumar and Pan, 2020). Sub-stoichiometric titanium dioxide $\left( \mathrm { T i O } _ { 2 - \mathrm { x } } \right)$ anodes have emerged as a highly attractive alternative to BDD, as they were already used in many applications (Lan et al., 2013; Park et al., 2013). More precisely, the Magn´eli phase $( \mathrm { T i } _ { \mathrm { n } } \mathrm { O } _ { 2 \mathrm { n } - 1 } ;$ with $3 \leq$ $\mathbf { n } \le 1 0 \mathbf { \dot { \Omega } }$ ) materials, exhibit a pseudo-metallic electrical conductivity, in addition to their high chemical stability and strong corrosion resistance (Andersson et al., 1957; Liborio and Harrison, 2008; Walsh and Wills, 2010). Among the $\mathrm { T i } _ { \mathrm { n } } \mathrm { O } _ { 2 \mathrm { n } - 1 }$ Magn´eli phase compounds, $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ ${ \mathtt { ( n = 4 ) } }$ ) is the most interesting one because of its highest electrical conductivity (Gusev et al., 2007; Smith et al., 1998; Xu et al., 2016). Moreover, the Magn´eli phase anodes can be generally produced at a much lesser cost than the BDD ones, making them highly cost-effective (Delegan et al. (2014). Different forms of Magn´eli phase anodes, including $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ , have been reported to be effective for the degradation of various water pollutants including amoxicillin (Ganiyu et al., 2016), tetracycline (Liang et al., 2018), oxalic and terephthalic acids (Nayak and Chaplin, 2018), p-methoxyphenol (Zaky and Chaplin, 2013), methyl orange (Wang et al., 2020a) and PFAS (Le et al., 2019; Li et al., 2021; Lin et al., 2018). So far, $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ electrodes have been mostly prepared in powder form and pressed into pellets (Arif et al., 2017; Li et al., 2010; Lin et al., 2020; Nayak and Chaplin, 2018; Zhu et al., 2013). Due to the rather poor latitude of the pelletizing process, the pellets cannot be scaled up into large size electrodes, and their nanostructure is barely controllable.

In the present work, we report on the use of a plasma torch (PT) based coating process to deposit $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ layers onto Ti substrates (both plate and mesh). Thus, by plasma spraying the $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ powder onto Ti substrates of desirable sizes and shapes, we were able to fabricate $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ anodes with controllable thickness, microstructure, and electrode size. The structure, morphology, and electrical conductivity of the PTdeposited $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ electrodes were systematically characterized. In a second step, the $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ anodes were used into an electro-oxidative reactor to assess their capacity to produce hydroxyl radicals $( ^ { \bullet } \mathrm { O H } )$ and persulphate $( S _ { 2 } 0 _ { 8 } ^ { 2 - } )$ . Finally, the degradation performance of our PT$\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ anodes was investigated against PFOA and PFOS pollutants in both synthetic and real wastewaters.

# 2. Materials and methods

# 2.1. $T \dot { \iota } _ { 4 } O _ { 7 }$ electrode preparation

The $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ anodes were produced via the coating of Ti substrates by $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ films using a plasma torch system where $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ powder was used as a feedstock. Prior to their coating with $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ , the Ti substrates $( 4 \times 9 \mathrm { c m } ^ { 2 } )$ were first sand blasted to increase artificially their surface area, then cleaned with isopropanol and deionized water, and finally dried with nitrogen gas jet. The plasma torch system was operated at a DC current of ${ 5 0 0 } \mathrm { A }$ and a DC voltage of ${ \sim } 7 0 \mathrm { V }$ , with an $\mathbf { A r / H } _ { 2 }$ (90/10) carrier gas, resulting in a discharge that ionizes the gas and generates the plasma plume through which the powder is melted and projected towards the substrates. The PT system was fed by $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ powder at a feeding rate of ${ \sim } 4 0 ~ \mathrm { g / m i n }$ . To achieve uniform coating of the Ti substrates, the PT nozzle was swept over the samples placed at a distance of ${ \sim } 1 2 ~ \mathrm { c m }$ . The deposition time (or the number of PT-nozzle passes) was set to obtain $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ films with a thickness of ${ \sim } 1 0 0 ~ \mu \mathrm { m }$ . The crystalline structure of the feedstock powder and the PT-deposited films was determined by using a PANalytical X-Pert Pro X-ray diffractometer (XRD) operating with a $\mathrm { c u } \mathrm { K }$ source of 1.5418 A). Raman spectrometer (Renishaw inVia Reflex) with a $5 2 3 ~ \mathrm { n m }$ laser excitation line (and $1 0 \%$ energy filter) was also used to characterize the Magn´eli phase structures. The morphology and thickness of the PT-deposited films were determined by using a Jeol JSM-6300F scanning electron microscope (SEM). Finally, the electrical resistivity of the overall $\mathrm { ( T i _ { 4 } O _ { 7 } / T i ) }$ electrodes was measured by means of the four-point probe method.

# 2.2. Preparation of synthetic solutions

Different synthetic solutions were prepared by adding $1 \ \mathrm { m g } / \mathrm { L }$ of either PFOS or PFOA and a matrix of both PFOA and PFOS (each $0 . 5 \mathrm { m g } /$ L) to a volume of $_ { 1 . 0 \mathrm { ~ L ~ } }$ of distilled water. The solution was kept under magnetic agitation until complete dissolution of the PFOS and PFOA. Sodium sulphate $( \mathrm { N a _ { 2 } S O _ { 4 } } , 2 . 8 6 \mathrm { g / L } )$ was added as supporting electrolyte in order to increase the conductivity of the synthetic solution. PFOA/ PFOS and sodium sulphate were purchased from Sigma-Aldrich $( > 9 8 \%$ purity, a mixture of branched and linear isomers). The electrolyte concentration was selected based on the following considerations: the electrolyte concentration of $2 . 8 6 ~ \ g / \mathrm { L }$ was selected in order to be able to impose a current density varying from 5 to $5 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ . This electrolyte concentration aims to provide sufficient conductivity for efficient electrooxidation of PFAS while minimizing the potential difference existing between the electrodes connected to the power supply.

# 2.3. Real wastewater sampling and characterization

The real wastewater (RWW) used throughout this study was an effluent provided from a sampling campaign carried out by ALTRA SANEXEN company. Samples were collected and stored in polypropylene bottles and kept at $4 ~ { } ^ { \circ } \mathrm { C }$ until use. The raw effluent had an initial content of COD of $5 8 8 ~ \mathrm { m g / L }$ , pH of 6.66 and conductivity of 451 $\pm 9 \mu \mathrm { S } / \mathrm { c m }$ . # 2.4. Electrochemical devices

The advanced electro-oxidation reactor was consisted of five rectangular electrodes placed vertically as a distance of $1 . 0 \ \mathrm { c m }$ . Two different configurations of $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ (three graphite $( \mathrm { G r } )$ with similar size $4 \ \mathrm { c m }$ width $_ { \textrm { \tiny X 9 c m h i g h } }$ ) serving as the anode and cathode, respectively. The electro-oxidation reactor was made of high-density polyethylene material (capacity $1 . 0 \ \mathrm { L } )$ to minimize cross contamination of per-and poly-fluoroalkyl substances (PFAS) coming from the reactor walls. Using two peristaltic pumps, the electrolyte was recirculated through a $1 5 0 0 ~ \mathrm { m l }$ beaker so then the process was performed in a dynamic-batch mode operation. The anodes were in two geometrical forms mesh and plate. A power supply (Sorensen DCS40-75E, MagnaPower Electronics Inc., Flemington, New Jersey, USA) was utilized to provide electrical power to perform electro oxidation at varying constant current density ranging of 5, 10, 15, 20, 30, $5 0 \ \mathrm { m A } / \mathrm { c m } ^ { 2 }$ for a treatment time of $1 8 0 \mathrm { m i n }$ . After identifying the optimal parameters for PFOA and PFOS electrochemical degradation, a transition to real wastewater samples had place, which were collected and characterized for their composition.

# 2.6. Analytical techniques

# 2.6.1. Hydroxyl radical and total oxidant concentration measurements

Reactive oxygen species (such as hydroxyl radicals (• OH)) have been show to bleach RNO (N, N- Dimethyl-4-nirtoso-aniline) by chemical oxidation (García-Gomez ´ et al., 2014). The hydroxyl radical production is equal to RNO disappearance rate. The bleachate rate was monitored by absorbance measurements of RNO at $4 4 0 \ \mathrm { n m }$ using an UV–visible absorption spectrophotometer (UV M136, Varian, Australia) (Simonsen et al., 2010).

The indirect method of measuring oxidants by iodides is a chemical method able to determine the concentrations of oxidants produced during the EO reaction. The use of sodium sulphate during electrolysis generates $S _ { 2 } O _ { 8 } ^ { 2 - }$ persulphate ions at the anode, while at the cathode and the use of graphite facilitates the oxygen reduction reaction (ORR), leading to the production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (hydrogen peroxide). In the presence of oxidants, the iodide ions are oxidized into diode, giving the solution a yellow color. The entire solution is then dosed by a solution of thiosulphate up to the equivalence which will allow to quantify the oxidants produced during the ECO (Davis et al., 2014; Koda et al., 2003; Rao et al., 2014).

$$
\begin{array} { r l } & { 2 \mathrm { I } ^ { - } + \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - \dot { o } }  \mathrm { I } _ { 2 } + 2 \mathrm { S O } _ { 4 } \mathrm { \Omega } ^ { 2 - } } \\ & { } \\ & { \mathrm { I } _ { 2 } + 2 \mathrm { S } _ { 2 } \mathrm { O } _ { 3 } ^ { 2 - }  2 \mathrm { I } ^ { - } + \mathrm { S } _ { 4 } \mathrm { O } _ { 6 } \mathrm { \Omega } ^ { 2 - } } \end{array}
$$

To further understand the effect of $S _ { 2 } O _ { 8 } ^ { 2 - }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ a UV spectrophotometer was employed $( \lambda = 3 5 3 \mathrm { n m } )$ ) (Simonsen et al., 2010). These resulting oxidants (persulphate) were quantified by titration during the EO reaction (Davis et al., 2014; Rao et al., 2014).

# 2.6.2. PFOA, PFOS and PFAS measurements

PFAS analysis was carried out using an ultra-high-performance liquid chromatography coupled with high-resolution Q Exactive Orbitrap mass spectrometry (UHPLC-HRMS). Analysis was performed at a mass range of $1 5 0 { - } 1 0 0 0 ~ \mathrm { m / z }$ , and both negative and positive electrospray ionization full scan acquisition modes. Thermo Hypersil Gold C18 columns were used for the chromatographic separation process. HPLCwater with $0 . 1 \%$ formic acid and acetonitrile with $0 . 1 \%$ formic acid served as mobile phases A and B, respectively. Before being injected into the LC-MS, all samples were diluted by 25 because of the high concentration of PFAS in the samples. The calculation of the removal efficiency was performed according to the following equation:

Degradation efficiency $\left( \% \right) = \frac { \mathbf { C } _ { 0 } - \mathbf { C } _ { \mathrm { t } } } { \mathbf { C } _ { 0 } } \times 1 0 0 $

In the sample, the initial and final concentrations of PFAS are represented by ${ \mathrm { C } } _ { 0 }$ and $\mathrm { C } _ { \mathrm { t } } ,$ respectively.

# 3. Results and discussion

# 3.1. Characterization of Magn´eli phase PT-Ti4O7 material

Fig. 1 (a) shows the X-ray diffraction (XRD) spectra of both the $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ powder feedstock (bottom) and the $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ electrode made out of it (top). The XRD peaks exhibited by the feedstock powder correspond to the $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ pattern (JCPDS 050 0787), confirming the purity and high polycrystallinity of the used powder. For the obtained PT- $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ coatings (top spectrum of Fig. 1(a)), the majority of the diffraction peaks appear at the same positions as for the $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ feedstock powder, confirming the effective transfer of stoichiometry and polycrystalline structure to the films. The XRD peaks located at $2 \theta = 2 0 . 8 ^ { \circ }$ , $2 6 . 4 ^ { \circ }$ , $2 9 . 6 ^ { \circ }$ , $3 6 . 3 ^ { \circ }$ , $4 0 . 5 ^ { \circ }$ , $5 3 . 3 ^ { \circ }$ and $5 5 . 1 ^ { \circ }$ ,corresponding to the (102), (120), (122), (120) (015), (322) and (142) crystallographic plans of $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ , respectively, are the most prominent ones. In comparison with the isotropically dispersed powder, the coatings are seen be more crystallographically orientated. Such a preferential orientation is believed to result from the directional nature of the PT deposition process, which is expected to favor more mechanical stress relaxation in the in-plane direction of the coating than in its out-of-plane one. In the XRD spectrum of the PT- $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ films, few other peaks (identified by light-blue triangles) corresponding to Magn´eli phases $( \mathrm { T i } _ { \mathrm { n } } \mathrm { O } _ { 2 \mathrm { n } - 1 } )$ with higher n values $\mathbf { \rho } ( \mathbf { n } > 5 )$ ) were also observed. Finally, one can also note the presence of two XRD peaks (appearing at $2 6 = 2 5 . 2 \textrm { ^ { \circ } }$ and $2 7 . 5 ^ { \mathrm { ~ \circ ~ } } .$ ) that can be associated with some anatase and rutile $\mathrm { T i O } _ { 2 }$ respective phases. The latter along with the high-order Magn´eli phases possibly result from some surface oxidation of the coatings during their deposition under ambient atmosphere or postexposure to air. Fig. 1a shows the Raman spectra of both $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ feedstock powder and PT-deposited $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ films. Our pure $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ phase powder is shown to exhibit two distinct and intense characteristic peaks located at $1 3 8 ~ \mathrm { c m } ^ { - 1 }$ and $1 8 3 ~ \mathrm { c m } ^ { - 1 }$ . There are multiple pathways involved in the degradation of PFOS and PFOA by persulfate and hydroxyl radicals. These oxidants have the potential to cause PFOS to defluorinate and break down into shorter-chain PFAS molecules. $S _ { 2 } O _ { 8 } ^ { 2 - }$ has the ability to initiate a decarboxylation reaction, which in fact begins with a fluoride elimination process that eventually results in the degradation of PFOA (Bruton and Sedlak, 2017). Persulfate’s complicated process of degrading PFOA involves multiple reaction stages. A perfluorooctanoic carboxyl radical is first produced by $S _ { 2 } 0 _ { 8 } ^ { 2 - }$ attacking the ionic PFOA. This radical subsequently goes through decarboxylation to yield a perfluoroheptyl radical. The perfluoroheptyl radical is then hydrated to produce a perfluorinated alcohol, which is then eliminated from HF to produce its acid fluoride. After that, the acid fluoride is hydrolyzed to produce a PFCA that has one fewer $\mathrm { C F } _ { 2 }$ unit. The resultant PFCA then reacts with $S _ { 2 } 0 _ { 8 } ^ { 2 - }$ in a way comparable to that of PFOA. This reaction then repeats itself until all of the PFCAs are fully mineralized (Zhang et al., 2019). According to the previous persulfate production, it can be seen that the rate of PFOA decomposition increased as $S _ { 2 } O _ { 8 } ^ { 2 - }$ dosages increased (Lee et al., 2009). In order to understand way more the mechanism in experiments utilizing $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ electrodes, the electrochemical breakdown of PFOS begins with a single electron transfer from the PFOS from the head group of $\mathrm { C _ { 8 } F _ { 1 7 } S O _ { 3 } }$ to an anode (Zhang et al., 2019), producing $\mathrm { C _ { 8 } F _ { 1 7 } }$ radicals that will react with •OH to generate $\mathrm { C _ { 8 } F _ { 1 7 } O H }$ . It’s worth noting that the exact pathway and distribution of intermediate products can vary depending on specific electrooxidation conditions, such as electrode material, applied potential, and electrolyte composition.

Since PFOA and PFOS are frequently discovered together at contaminated sites, it is important to understand how they degrade when present in a mixture solution. It’s interesting to note that when PFOA and PFOS were present in the same solution and treated with AEO, the rate of PFOS degradation was greatly slowed down. During the first hour of degradation with EO PFOS attend ${ > } 9 0 \%$ of degradation at the highest current density $5 0 ~ \mathrm { m A } / \mathrm { c m } ^ { 2 }$ (Fig. 9A). However, after $^ { 1 \mathrm { ~ h ~ } }$ of EO PFOA degradation was $8 0 \%$ . Overall, when both are present in the same solution, PFOS breaks down more quickly than PFOA (Yang et al., 2013). This occurrence happens as a result of PFOS having the potential to defluorinate, which causes PFOA to develop during the breakdown process. This causes some of the PFOS to change into PFOA, which may explain why PFOA degrades more slowly overall and why the combined PFOS and PFOA remain in the solution throughout the breakdown process (Fig. 9B) (Kim et al., 2019; Yang et al., 2020).

To further investigate the electrochemical degradation efficiency of

PFOA and PFOS in a separated solution, we calculated the Faradaic efficiency for each compound. The Faradaic efficiency represents the ratio of the actual amount of substance degraded to the theoretical amount that could be degraded based on the charge passed through the system (Panizza and Cerisola, 2009). The following equation was used to determine the Faradaic efficiency (η) of the degradation:

$$
\mathfrak { \eta } = \frac { \bar { \mathbf { n } } \times \bar { \mathbf { F } } \times \mathbf { z } } { \mathbf { I } \times \mathbf { t } }
$$

Where $\mathbf { n }$ is the number of moles of the species degraded, F is Faraday’s constant $( 9 6 , 5 0 0 ~ \mathrm { C / m o l } )$ , and $\mathbf { z }$ is the number of exchanged electrons during electrolysis, I is the current intensity in ampere and t is the time in seconds.

The electrochemical degradation of PFOS and PFOA reveals intriguing insights into their removal efficiencies and faradaic efficiencies. The faradaic efficiency for PFOS is $0 . 0 0 2 2 \%$ , while for PFOA, it is slightly higher at $0 . 0 0 2 5 \%$ , indicating that only a small fraction of the electrical current is utilized for direct degradation in both cases. Despite these low faradaic efficiencies, the degradation rates are remarkably high, with PFOS achieving a $9 7 \%$ removal rate compared to $9 1 \%$ for PFOA. It is worth noting that, PFOA and PFOS degradation are mainly attributed to anodic oxidation (owing to the formation of hydroxyl radicals on the surface of $\mathrm { P T } \mathrm { - T i } _ { 4 } \mathrm { O } _ { 7 }$ -anode). First, PFOA/PFOS must be transported toward the anode electrode surface, and then be oxidized there. The PFAS degradation may be subjected either to current control or mass transfer control. In fact, at the start of the electrolysis, the PFOA/ PFOS concentration was relatively high and accordingly the PFOA/ PFOS reduction rate was subjected to current control. As the PFOA/ PFOS concentration was lowered to a certain level, the PFAS reduction rate was subjected to the mass transfer control (Panizza et al., 2001). In that case, only a fraction of current intensity (or charge loading) supplied was used to oxidize PFOA/PFOS, while the remaining charge loading was wasted for parasitic reactions (such as of oxygen generation). It was the reason for which the faradaic yields were very low in spite of relatively high percentages of PFOA and PFOS abatements recorded during electrolysis. Overall, these findings highlight the need for further optimization of the electrochemical process to enhance energy efficiency while maintaining high removal rates for these persistent contaminants, as emphasized by (Wang et al., 2020b) in their work on enhanced PFOA degradation.

# 3.5. Application to real wastewater treatment

The effectiveness of the electro-catalytic oxidation (AEO) process in treating real wastewater effluent contaminated by PFAS (around 8502 $\mu \mathrm { g } \mathrm { L } ^ { - 1 }$ of total PFAS) was evaluated at a current intensity of $2 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ using PT- $\mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ -Mesh anode electrodes and a retention time of $1 2 0 ~ \mathrm { m i n }$ (best conditions determined above in synthetic effluent). The application of these parameters to real wastewater requires careful consideration. The objective was to test the effectiveness of the electrolytic reactor for a mixture of PFAS compounds in real wastewater, along with other co-occurring contaminants. In addition to PFOS and PFOA, the raw wastewater contained different PFAS (PFHx, PFHpS, FHxSA, PFPrA, PFBA, PFPeA, PFHpA, FBSA, etc.).

Fig. 10 indicate the percentages of PFAS removal in real wastewater sample after electrochemical treatment. In order to better illustrate and compare the different abatements, two groups of PFAS were defined according to their percentage of degradation. The first group includes PFAS compounds for which more than $2 0 \%$ of degradation was recorded. The second group of PFAS pollutants includes the most difficult degradable compounds with final abatement inferior to $2 0 \%$ (Fig. 11). PFOS and PFOA are included in the first group of PFAS pollutants having more than $2 0 \%$ of degradation (Fig. 10). After an electrolysis time of $1 2 0 \mathrm { m i n }$ , the residual PFOS concentrations decreased from 406 to 28.14 $\mu \mathrm { g } / \mathrm { L }$ $8 6 \%$ of PFOS removal), whereas PFOA decreased from 64 to 39 $\mu \mathrm { g } / \mathrm { L }$ $3 9 \%$ of PFOA removal). In spite of a mixture of PFAS in real wastewater, the percentage of PFOS degradation was quite the same percentage recorded $( 8 6 \% )$ in synthetic effluent. By comparison, the percentage of PFOA degradation in real wastewater was 1.6 times lower that obtained $( 6 4 \% )$ in synthetic effluent. The competitive reactions did not affect PFOS degradation (compared to PFOA) owing to its molecular structure easier to oxidize.

The high rate of PFOS degradation $( 8 6 . 4 \% )$ was consistent with earlier research using comparable electrooxidation process. These works reported that PFOS degradation rates ranging between $8 8 \%$ and $9 0 \%$ (Houtz and Sedlak, 2012; Zhuo et al., 2011). The first group of PFAS pollutants was comprised of PFHpS and 6:2 FTAB for which at least $8 0 \%$ of degradation was recorded. Final abatements ranging between $3 5 \%$ and $6 0 \%$ were also recorded for the following compounds: PFHxS, 5:3 acid, 6:2 FTSA, 5:3 FTB, 5:1:2 FTB. Finally, it is worth noting that the best rates of PFAS degradation in this fist group were obtained with perfluoroalkyl sulfonic acid compounds, PFHxS $( 5 3 . 0 \% )$ ), PFHpS $( 8 0 . 2 \% )$ , and PFOS $( 8 6 . 4 \% )$ . The observed differences in degradation rates among various PFAS compounds can be attributed to several key factors. The search results indicate that the molecular structure and functional groups of the PFAS play a crucial role. Perfluoroalkyl sulfonic acids, such as PFOS, PFHxS, and PFHpS, which contain a sulfonate group $\left( { { \cal S } 0 _ { 3 } ^ { - } } \right)$ are generally more susceptible to be oxidized compared to carboxylate-based PFAS like PFOA. This is because the sulfonate group can undergo desulfonation reactions during the degradation process, facilitating the further breakdown of the molecule (Hori et al., 2006; Ochoa-Herrera et al., 2008). Additionally, the carbon-sulfur bond in these sulfonic acid compounds requires less energy to degrade than the carbon-carboxylate bond found in PFOA (Ochoa-Herrera et al., 2008).

Fig. 11 presents the second group of PFAS pollutants for which less than $2 0 \%$ of abatement was recorded. The percentages of PFAS degradation varying between $4 \%$ and $1 2 \%$ for the following compounds: PFPrA, PFBA, PFPeA, PFHxA and FBSA. However, negative abatements were recorded for PFHpA $( - 1 . 8 9 \% )$ and 6:2FTCA $( - 0 . 8 2 \% )$ , indicating that these compounds were formed as by-product during the application of electro-catalytic oxidation (AEO) process (Gomez-Ruiz et al., 2017). The production of byproducts such as 6:2 FTCA and PFHpA emphasises the need for additional research into the processes of degradation and the possible environmental effects of these by-products (Gomez-Ruiz et al., 2017; Kim et al., 2021).

The electrooxidation process demonstrated effectiveness in reducing organic contaminants in wastewater contaminated with PFAS, with COD reduced from $5 8 8 ~ \mathrm { m g / L }$ to $4 6 8 ~ \mathrm { m g / L }$ $2 0 . 4 \%$ reduction) and TOC decreased from $1 8 0 ~ \mathrm { m g / L }$ to $1 4 6 ~ \mathrm { m g / L }$ $. 1 8 . 7 \%$ reduction). The similarity in reduction percentages suggests consistent degradation of organic compounds. The Faradaic efficiency for PFOA degradation was exceptionally low, primarily due to the small fraction of the electrical current used for direct PFOA degradation. This low efficiency can be attributed to the complex nature of the wastewater matrix, where multiple competing reactions occur simultaneously (Ma et al., 2015). Analysis revealed the presence of shorter chain perfluorinated carboxylic acids as final transformation products, indicating partial PFOA degradation without complete mineralization. Specifically, the production of by-products such as 6:2 fluorotelomer carboxylic acid (6:2 FTCA) and perfluoroheptanoic acid (PFHpA) was observed. The presence of these compounds provides valuable insights into the degradation pathway of PFOA. For instance, the formation of PFHpA suggests the stepwise removal of $\mathrm { C F } _ { 2 }$ units from the PFOA molecule, while the presence of 6:2 FTCA indicates potential defluorination processes occurring during electrooxidation (Godoi et al., 2021). These by-products align with the proposed degradation pathway for PFOA, which involves successive oxidation steps (Zhuo et al., 2012). The fluoride concentration increased from an initial value of $1 . 0 3 \mathrm { m g / L }$ to a final value of $2 . 8 \mathrm { m g / L }$ (2.7 times higher than initially measured in the raw effluent). This increase in fluoride concentration is an indicator of PFAS degradation during the electrooxidation process. The observed rise in fluoride levels can be attributed to the breaking of carbon-fluorine bonds in PFAS molecules, releasing fluoride ions into the solution. This defluorination process is a crucial step in PFAS degradation and is often used as a measure of treatment efficiency. The increase to $2 . 8 \mathrm { m g / L }$ suggests that a substantial portion of the PFAS compounds were degraded. However, it’s important to note that the extent of fluoride release may not directly correlate with complete mineralization of PFAS, as some fluorine-containing intermediates or shorter-chain PFAS may still be present in the treated water. The incomplete mineralization and presence of transformation products highlight the challenges in achieving complete PFAS destruction through electrochemical oxidation. This is particularly evident in complex wastewater matrices, where competing reactions and the presence of other organic compounds can interfere with the degradation process. The low COD and TOC reduction levels observed in our study $( 2 0 . 4 \%$ and $1 8 . 7 5 \%$ , respectively) further emphasize these challenges, as they indicate that a significant portion of organic compounds, including PFAS and their transformation products, remain in the treated water. It is worth underlying that, in addition to PFAS present in the raw effluent, other pollutants such as surfactants could be found in this type of effluent and they constitute the majority of the COD (Aboulhassan et al., 2006). During electrolysis, COD pollutants can be subjected to two different paths in anodic oxidation: electrochemical conversion or electrochemical combustion (Drogui et al., 2001; Grimm et al., 1998). Electrochemical conversion only transforms the non-biodegradable organic pollutants into biodegradable compounds, whereas electrochemical combustion yields water and carbon dioxide, and no further treatment is then required. To improve the treatment efficiency, future research could focus on optimizing reaction conditions, exploring enhanced catalytic activity, and developing strategies to minimize energy consumption while maximizing PFAS degradation. Additionally, coupling electrochemical oxidation with other treatment methods, such as foam fractionation, may provide a more comprehensive approach to PFAS remediation in contaminated water (Radjenovic and Sedlak, 2015).

# 4. Conclusion

The electrooxidation (EO) process using a plasma torch Magn´eli phase $\mathrm { P T } { \cdot } \mathrm { T i } _ { 4 } \mathrm { O } _ { 7 }$ anode has demonstrated feasibility as a technology for the treatment of water contaminated by PFAS. Using sodium sulphate $\mathrm { ( N a _ { 2 } S O _ { 4 } ) }$ at a concentration of $2 . 8 6 \ g / \mathrm { L }$ as the supporting electrolyte and applying a current density of $2 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ during a 2-h electrolysis time ensures a high degradation efficiency of PFAS compounds, reaching up to $8 6 \%$ for PFOS and $6 4 \%$ for PFOA in synthetic water. However, the degradation of PFAS compounds in real wastewater was lower, with a $4 0 \%$ removal rate observed for PFOA. Further research is needed to fully understand the performance and limitations of this EO process using Magn´eli phase $\mathrm { P T } \mathrm { - T i } _ { 4 } \mathrm { O } _ { 7 }$ anodes for the remediation of PFAScontaminated waters, particularly in addressing the differences in degradation efficiency between synthetic and real-world wastewater matrix. Likewise, the identification of by-products needs to be rigorously verified and a mechanism of PFOA/PFOS degradation should be proposed. The total organic (TOC) should be measured to evaluate the degradation level and see if PFAS other organic pollutants are completely or partially transformed into water and carbon dioxide.
