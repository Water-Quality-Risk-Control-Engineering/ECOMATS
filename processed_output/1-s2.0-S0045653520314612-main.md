# ABSTRACT

In this work, UVA radiation that is part of solar light is taken as the irradiation source and radicals (HO , $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ and $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - } )$ are generated through activation of hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ , sodium persulfate $\left( \mathsf { N a } _ { 2 } \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } \right)$ and Bismuth catalyst (BiOCl), respectively. The distinguished performance in removing acetaminophen (ACTP), a model pharmaceutical pollutant, by these three radicals was compared for the first time. Effect of pH, halide ions concentration and interfacial mechanism have been investigated in detail. Interestingly, results show that heterogeneous UVA/BiOCl process has higher degradation efficiency than homogeneous $\mathrm { U V A } / \mathrm { H } _ { 2 } 0 _ { 2 }$ and UVA $I N a _ { 2 } S _ { 2 } O _ { 8 }$ systems whatever the solution’s pH. To explain these results, second order reaction rate constant $( k _ { \mathrm { r a d i c a l , A C T P } } )$ have been determined with laser flash photolysis (LFP) or radical scavenging experiments. The strongly interfacial-depended $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - }$ radicals have the lowest second order rate constant with ACTP but highest steady state concentration. BiOCl is much easier activated by UVA, and outstanding ACTP mineralization can be achieved. Combination of BiOCl and ${ \Nu a } _ { 2 } { \ S _ { 2 } } { 0 } _ { 8 }$ exhibits synergistic effects rather than antagonism effects with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . This study highlights the relative effective utilization of solar light through interfacial directed BiOCl photocatalysis and its synergistic effects with traditional oxidants.

# 1. Introduction

In recent years, advanced oxidation processes (AOPs) have been proposed as alternative methods to effectively remove persistent organic pollutants (POPs) in environment. Normally, AOPs have always proved to achieve the best yields in pollutant destruction when biological treatments are unfeasible, like for endocrine disrupting chemicals (EDCs) (Pera-Titus et al., 2004; Rosenfeldt and Linden, 2004), pharmaceuticals or personal care products (PPCPs) (Huber et al., 2003; Abdelmelek et al., 2011). The predominant oxidation processes are usually based on $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or persulfate activation by in situ production of hydroxyl radical (HO) or sulfate radical $( \mathrm { S O } _ { 4 } { \cdot } ^ { - } )$ , followed by reaction on the targets pollutants in aqueous solutions (Andreozzi et al., 1999; Esplugas et al., 2002). Especially, traditional Fenton reaction $\mathrm { ( F e ( I I ) / H } _ { 2 } 0 _ { 2 } )$ (Neyens and Baeyens, 2003; Huang et al., 2013) and $\mathrm { U V } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ are predominant strategies to generate HO. Similarly, $S O _ { 4 } { ^ { \bullet } } ^ { - }$ are always produced through activation of persulfate by heat (Nie et al., 2014), UV, alkalinity (Nie et al., 2019) and transition metals (Wu et al., 2015a). However, Fenton reactions always suffer from several limitations like strict acidic solution $\left( \mathrm { p H } < 4 . 0 \right)$ and iron sludge disposal.

At the same time, interfacial based heterogeneous photocatalysis is also one of the most promising oxidation processes through producing electron $( \mathsf { e } ^ { - } )$ and hole $( \mathsf { h } ^ { + } )$ pairs under illumination. HO or hydroperoxyl radicals/superoxide radical anion $\mathrm { ( H O } _ { 2 } { \bullet } / \mathrm { O } _ { 2 } { \bullet } ^ { - }$ , pKa 4.88) will be subsequently produced by reaction of photogenerated charge carriers with ${ { 0 } _ { 2 } }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ (Shaban et al., 2013). Among these photocatalysts, $\mathrm { T i O } _ { 2 }$ and its doped products have received a great deal of attention due to its efficient and abundant production of HO (Yang et al., 2008a). Different to $\mathrm { T i O } _ { 2 }$ , in bismuth-related photocatalytic process, especially layered BiOX $\mathbf { \nabla } [ \mathbf { X } \mathrm { ~ = ~ } \mathbf { C l } ]$ , Br, I) (Zhang et al., 2008), quenching experiments and theoretical calculation have proved that they are featured with $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - }$ generation for organic compound degradation (Tian et al., 2019). Taking BiOCl as catalyst, the photocatalytic process can supply a simple route to produce $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - }$ effectively. In our last studies, a series of BiOCl related catalysts have been synthesized by precipitation method successfully followed with detailed characterization (Wang et al., 2014, 2016a; 2016b). BiOCl possesses great surface area and suitable valence/conduction band structures to produce $\mathrm { H O } _ { 2 } { \bullet } / \mathrm { O } _ { 2 } { \bullet } ^ { - }$ active species, showing excellent performance in removing acetaminophen (ACTP) from water under irradiation $( \lambda > 2 9 0 ~ \mathrm { n m } )$ ), although the band gap value of BiOCl $( { \sim } 3 . 2 \mathrm { e V } )$ shows that it only can be activated by the ultraviolet light with the wavelength shorter than $3 8 7 . 5 \mathrm { n m }$ . Similar to the previous literatures, $\mathrm { H O } _ { 2 ^ { \bullet } } / \mathrm { O } _ { 2 ^ { \bullet ^ { - } } }$ species are the main radical determined by indirect scavenging experiments.

If UVA radiation $( 3 1 5 - 4 0 0 \ \mathrm { n m } )$ is chosen as the irradiation source, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and persulfate as the oxidation sources, the quantum yield comparison between HO and $S O _ { 4 } { ^ { \bullet } } ^ { - }$ still stay unknown. Furthermore, nobody has compared these two radicals with $\mathrm { H O } _ { 2 } { \cdot } /$ $0 z ^ { \bullet ^ { - } }$ under the same experimental conditions. The degradation rate of organic pollutant depends on the radical concentration, selectivity and oxidizing power. For these reasons, the distinguished and cumulated effects of these parameters need to be explored. ACTP is chosen as the model pollutant in this study, because of its heavy use all over the world. Most of the research on ACTP degradation are mainly based on HO and $S O _ { 4 } { ^ { \bullet } } ^ { - }$ like $\mathrm { U V } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (Andreozzi et al., 2003), Fenton (de Luna et al., 2013), $\mathrm { T i O } _ { 2 }$ photocatalyst (Yang et al., 2008b) and persulfate activation (Noorisepehr et al., 2019; Yun et al., 2019). Its degradation pathway by HO and $S O _ { 4 } { ^ { \bullet } } ^ { - }$ are almost clear, while its degradation and mineralization abilities by $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - }$ still stays largely unknown. Furthermore, the combination of $\mathrm { T i O } _ { 2 }$ with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (Li et al., 2001) or persulfate activation (Xu et al., 2019) has been widely investigated. However, rare studies focus on the synergistic effects between BiOCl with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or persulfate (Zhang et al., 2017).

In brief, the main goal of this paper is to compare, for the first time, three different active species HO, $S O _ { 4 } { ^ { \bullet } } ^ { - }$ and $\mathrm { H O } _ { 2 } { \bullet } / \mathrm { O } _ { 2 } { \bullet } ^ { - }$ produced by $\mathrm { U V A } / \mathrm { H } _ { 2 } 0 _ { 2 }$ , UVA $\mathsf { I } / \mathsf { N a } _ { 2 } \mathsf { S } _ { 2 } \mathsf { O } _ { 8 }$ and UVA/BiOCl respectively on the degradation of ACTP. pH and halide ions $[ \mathbf { C } ] ^ { - }$ and $\mathrm { I } ^ { - }$ ) concentration effects on ACTP’s degradation have been investigated in this work. The combination of oxidants in the systems UVA $\mathrm { | B i O C l / H _ { 2 } O _ { 2 } }$ and UVA/BiOCl $/ \mathsf { N a } _ { 2 } \mathsf { S } _ { 2 } \mathsf { O } _ { 8 }$ are also studied to explore the potential synergistic effects. Interfacial mechanism, mineralization and efficiency of this process will be explained in detail. Furthermore, second order reaction rate constants between ACTP and HO, $S O _ { 4 } { ^ { \bullet } } ^ { - }$ or $\mathrm { H O } _ { 2 } { \bullet } / \mathrm { O } _ { 2 } { \bullet } ^ { - }$ radicals will be determined by laser flash photolysis (LFP) or competition experiments. The critical affecting parameters on ACTP’s degradation rate will be determined.

# 2. Materials and methods

# 2.1. Chemicals

BiOCl catalyst was synthesized as in our previous papers (Wang et al., 2016a). ACTP was purchased from Sinopharm Chemical Reagent Co., Ltd. (China). Bisphenol A (BPA), $\mathrm { N a H _ { 2 } P O _ { 4 } { \cdot } H _ { 2 } O }$ , $\mathrm { N H } _ { 4 } S C N$ , ethanol (EtOH), tert-butanol (TBA), isopropanol (IPA), sodium persulfate $\left( \mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } \right)$ , benzoquinone (BQ) and potassium iodine (KI) were obtained from Sigma, France. Hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ solution $30 \%$ in water) and sodium chloride (NaCl) were purchased from Fluka, France. 5,5-Dimethyl-1-pyrroline N-Oxide (DMPO, $9 8 \%$ ) was obtained from Adamas Reagent Co., Ltd. Perchloric acid $\mathrm { ( H C l O _ { 4 } ) }$ and sodium hydroxide (NaOH) were used to adjust the pH of the solutions. All chemicals were used without further purification, and Milli-Q water was used throughout all the experiments.

# 2.2. Irradiation setup and experimental procedure

The photocatalytic degradation experiments were performed in a homemade photoreactor placed in a cylindrical stainless steel container. Four fluorescent lightbulb lamps (Philips TL D15 W/05) were separately placed in the four different axes while the photoreactor, a water-jacketed Pyrex tube of $2 . 8 ~ \mathrm { c m }$ internal diameter, was placed in the center of the setup. The lamp emitting from 300 to $5 0 0 ~ \mathrm { { n m } }$ was used to simulate UVA solar light; their emission spectrum is shown in Fig. S1. 100 mL of solutions were magnetically stirred with a magnetic bar during irradiation and experiments were carried out at room temperature $( 2 9 3 \pm 2 \mathrm { ~ K ~ }$ ) set by a circulating cooling water system. Samples were taken from the reaction tube at fixed interval times and the catalyst solid was removed by $0 . 2 2 ~ { \mu \mathrm { m } }$ PTFE filters before analysis. In the experiments, the initial concentrations used were: ACTP $5 0 ~ \mu \mathrm { M }$ , $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\Nu { \bf a } _ { 2 } \tt S _ { 2 } { 0 } _ { 8 } \uparrow \ m \tt M$ and BiOCl catalyst $0 . 3 \mathrm { ~ g ~ L ~ } ^ { - 1 }$ (approximately $1 . 1 \ \mathrm { m M } $ ). All experiments were performed in duplicates, experimental points represent the averages of two values, and the error bars indicate the standard deviation.

# 2.3. Analytical method

The remaining ACTP concentration in the aqueous solution was determined by high performance liquid chromatography (HPLC) (Alliance, Waters, 2695, USA) equipped with a photodiode array detector (Waters 2998). A Nucleodur 100-3 C18 reverse column $1 5 0 \times 2 . 0 \mathrm { m m }$ , $3 . 0 \mu \mathrm { m } \ ' ,$ was used to separate the compound in the solution. The flow rate was $0 . 1 5 \mathrm { \ m L \ m i n } ^ { - 1 }$ with a mobile phase mixture of methanol and water with $0 . 1 \% \mathrm { H } _ { 3 } \mathrm { P O } _ { 4 } ( 3 0 / 7 0 , \mathrm { v / v } )$ . The UV detection of ACTP was set at $2 4 4 ~ \mathrm { n m }$ wavelength, and the retention time was $4 . 9 \ \mathrm { m i n }$ . Mineralization of ACTP solution was followed by total organic carbon (TOC) analysis (5050A, Shimadzu, Japan). UVevis spectra were recorded with a Cary 300 UVevisible spectrophotometer. pH values of the solutions were measured using a Cyberscan $5 1 0 ~ \mathrm { p H }$ meter. The zeta potential of BiOCl was determined by the potentiometric titration method under $\Nu _ { 2 }$ atmosphere at $2 9 8 \ \mathrm { K }$ in $1 \ \mathrm { m M } \ \mathrm { N a C l }$ solutions. X-ray photoelectron spectroscopy (XPS) spectra were collected by using a VG Scientific ESCALAB 250Xi spectrometer (Thermo Fisher Scientific) with C 1s as the calibration standard line. The optical properties of BiOCl samples were analyzed through the UVevis diffuse reflectance (DRS) by Shimadzu UV-3600. The electron spin resonance (ESR) experiments were carried out on a JES-X320 spectrometer to detect the reactive radicals generated over the photocatalytic degradation process. As radical probe, DMPO ( $1 0 0 ~ \mathrm { { m M } ) }$ was used for $S O _ { 4 } { ^ { \bullet } } ^ { - }$ , HO and $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - }$ . ESR spectrum was recorded at room temperature under the following operating conditions: a modulation frequency of $1 0 0 \mathrm { k H z }$ , a sweep width of $0 . 5 \mathrm { m T } ,$ a microwave power of 1 mW, a microwave frequency of 9.15 GHz and a centerfield of $3 2 6 . 0 \pm 5 \mathrm { m T }$ .

# 3.1. ACTP degradation in $U V A / H _ { 2 } O _ { 2 }$ and UVA $\prime N a _ { 2 } S _ { 2 } O _ { 8 }$ systems under different $p H$

To explore ACTP’s degradation with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and ${ \Nu } _ { { \bf { d } } _ { 2 } } { \cal S } _ { 2 } { \cal O } _ { 8 }$ under UVA irradiation, blank experiments were firstly conducted in the dark to check its stability. ACTP alone in aqueous solution was stable between $\mathsf { p H } 3 { - } 9 . 5$ within $4 0 \ \mathrm { h }$ (Fig. S2A). In addition, when ACTP was mixed with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and ${ \Nu a } _ { 2 } { \cal S } _ { 2 } { \cal O } _ { 8 }$ (Figs. S2B and C), no detectable degradation can be observed until $\mathsf { p H } ~ 9 . 0$ , while at higher pH a degradation was measured particularly with persulfate.

# 3.2. Halide ions (chloride and iodide) effects on ACTP degradation in $U V A / H _ { 2 } O _ { 2 }$ and UVA $N a _ { 2 } S _ { 2 } O _ { 8 }$ systems

Effects of halide ions were widely studied in previous research works, especially chloride and bromide (Tamtam and Chiron, 2012; Li et al., 2015). In our study for the first time the comparison of $\mathtt { C l } ^ { - }$ and $\mathrm { I } ^ { - }$ , which is also commonly detected in costal seawater, saline water or industrial wastewater discharges, were investigated in $\mathrm { U V A } / \mathrm { H } _ { 2 } 0 _ { 2 }$ and UVA $/ \mathsf { N a } _ { 2 } \mathsf { S } _ { 2 } \mathsf { O } _ { 8 }$ systems. In the dark and whatever the systems, the addition of $\mathrm { C l ^ { - } }$ has no impact on ACTP’s concentration change (see Fig. S3). Under irradiation, the impact of $\mathrm { C l ^ { - } }$ is also very weak. The only effect is observed in the $\mathrm { U V A } / \mathrm { H } _ { 2 } 0 _ { 2 }$ system, when NaCl is set as $1 0 ~ \mathrm { m M }$ , the pseudo first order reaction rate constant increase around $3 0 \%$ (see Fig. S4). In the presence of chloride ions, generated reactive species such as chlorine radical (Cl) and dichlorine radical anion $( \mathsf { C l } _ { 2 } \bullet ^ { - } )$ could react more selectively with electron-rich organic compounds (Grebel et al., 2010).

On the contrary, when iodide ions at same concentrations were added to the solution, ACTP degradation rates are strongly affected as shown in Fig. 2. In the dark, the addition of KI from $2 6 0 ~ \mu \mathrm { M }$ to $5 \ \mathrm { m M }$ leads to an increase of the ACTP degradation with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , which is much less the case with ${ \Nu a } _ { 2 } { \cal S } _ { 2 } { \cal O } _ { 8 }$ at $\mathsf { p H } 5 . 4$ . In the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or ${ \Nu a } _ { 2 } { \cal S } _ { 2 } { \cal O } _ { 8 }$ , iodide ions could be oxidized to iodine $\mathrm { I } _ { 2 }$ (Eq. 6). Under UVA irradiation, KI alone in solution has no effect on ACTP (Fig. S5), indicating that iodide ions under UVA cannot transform or generate any active species. However, in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or ${ \Nu } _ { { \bf { d } } _ { 2 } } { \cal S } _ { 2 } { \cal O } _ { 8 }$ in the KI solution, the photo-degradation rate is highly enhanced (Fig. 2). In addition, ${ \mathrm { H O I } } ^ { \bullet ^ { - } } / \mathrm { I } ^ { \bullet }$ reactive halogenated species can be generated from $\mathrm { H O ^ { \bullet } }$ or $S O _ { 4 } { ^ { \bullet } } ^ { - }$ as shown in Eqs. 7-8 (Elliot, 1992), indicating that iodide radicals (I, $\mathrm { H O I ^ { \bullet ^ { - } } }$ and $\mathrm { I } _ { 2 } { \cdot } ^ { - }$ ) have higher reactivity with organic pollutants than chloride radicals (Yang et al., 2018a). Tamtam and Chiron (2012) and Li et al. (2015) have demonstrated that reactive halogenated species reacted more selectively than hydroxyl radicals with electron-rich organic pollutants. As ACTP contains hydroxyl and acetamido groups, which are electron donors to the aromatic rings, so it is hypothesized that these electron-rich moieties may selectively react with these iodide related radical reactive species. These selectivity properties of iodide based radicals are more emphasized than chloride ions. However, too much higher concentrated iodide ions $( 5 ~ \mathrm { m M } )$ will decrease the efficiency of ACTP degradation by self-quenching effects (Eq. 9). (Elliot, 1992)

Heterogeneous photocatalytic degradation of ACTP has attracted numerous attentions recently, and various degradation pathways have been proposed for $S O _ { 4 } { ^ { \bullet } } ^ { - }$ and HO reactivity on ACTP. On the contrary, seldom studies have investigated the degradation of ACTP predominantly by superoxide radicals. In our previous studies (Wang et al., 2016a), BiOCl catalyst has been synthesized following with detailed characterization properties, as shown in Table 1. The

With a relatively wide band-gap $( 3 . 2 { \mathrm { ~ e V } } )$ , BiOCl could hardly absorb the light wavelengths longer than $4 0 0 \ \mathrm { n m }$ (Figs. S7A and B). # 3.4. Heterogeneous interfacial mechanism in UVA/BiOCl

For heterogeneous photocatalytic degradation, interfacial mechanism is essential to be investigated to confirm if the reaction is occurring in the solution or on the surface of catalyst. To clarify this question, ${ \sf N a H } _ { 2 } { \sf P O } _ { 4 }$ has been proved to be a perfect desorbent in our experiment. Because ${ \tt N a H } _ { 2 } { \tt P O } _ { 4 }$ could occupy almost all the adsorption sites on the surface of catalyst, and the surface was tightly surrounded by ${ \tt N a H } _ { 2 } { \tt P O } _ { 4 }$ molecules instead of ACTP (Wang et al., 2018). With the addition of ${ \sf N a H } _ { 2 } { \sf P O } _ { 4 }$ , the degradation rate and removal percentage are both strongly suppressed (Fig. 4A). As we discussed above, the main active species $\mathrm { H O } _ { 2 ^ { \bullet } } / \mathrm { O } _ { 2 ^ { \bullet ^ { - } } }$ comes from the combination of dissolved oxygen in water and conduction band electrons. With a very short half-life time, $\mathrm { H O } _ { 2 } { \cdot } / \mathrm { O } _ { 2 } { \cdot } ^ { - }$ would easily undergo disproportionation (Liang et al., 2015). Consequently, the fast and direct contact of pollutant and catalyst surface is crucial for the reaction. Furthermore, BiOCl nanosheets prepared in alkaline conditions in this research were usually dominated with high [010] facets exposure. The [010] facets possessed open channels and abundant unsaturated Lewis/base sites, which was helpful for intimate contact between the interfacial surface and organic molecules (Jiang et al., 2012). So in this photocatalytic degradation system, degradation reactions must be occurred on the surface or very close to the surface of the catalyst.

# 4. Conclusion

In summary, heterogeneous photocatalytic process UVA/BiOCl was always more efficient than the homogeneous $\mathrm { U V A } / \mathrm { H } _ { 2 } 0 _ { 2 }$ and $\mathrm { U V A } / \mathrm { N a _ { 2 } } \mathrm { S _ { 2 } } 0 _ { 8 }$ processes to degrade ACTP whatever the solution’s pH. Halide ions such as $\mathrm { C l ^ { - } }$ plays a negligible role in $\mathrm { U V A } / \mathrm { H } _ { 2 } 0 _ { 2 }$ and $\mathrm { U V A } / \mathrm { N a _ { 2 } } \mathrm { S _ { 2 } } 0 _ { 8 }$ systems, while $\mathrm { I } ^ { - }$ could significantly improve the degradation performance due to the reactive species formation. BiOCl catalyst can be efficiently activated by solar light than traditional oxidant like $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and ${ \Nu } _ { { \bf { d } } _ { 2 } } { \cal S } _ { 2 } { \cal O } _ { 8 }$ . With the same amount of oxidant or catalyst loading, UVA/BiOCl system could produce higher concentration of $\mathrm { H O } _ { 2 ^ { \bullet } } / \mathrm { O } _ { 2 ^ { \bullet ^ { - } } }$ radicals, compared to HO and $S O _ { 4 } { ^ { \bullet } } ^ { - }$ . This surface-depended $\mathrm { H O } _ { 2 } { \bullet } / \mathrm { O } _ { 2 } { \bullet } ^ { - }$ oxidation process could induce significant mineralization abilities. Addition of ${ \Nu } _ { { \bf { d } } _ { 2 } } { \cal S } _ { 2 } { \cal O } _ { 8 }$ shows synergistic effects in UVA/BiOCl compared to the addition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . This research could provide implications in heterogeneous photocatalyst utilization, and shed light on capable combinations between photocatalyst and oxidants in future wastewater treatment under solar light irradiation.
