# Confining Asymmetrically Coordinated Cobalt Single-Atoms/Clusters on Holey MXene for Ultrafast Fenton-Like Catalysis

Xin Guo, Hao Zhang, Yunlong Wang, Yiyuan Yao, Chengming Xiao, Kechen Gu, Junwen Qi, Yujun Zhou, Yue Yang, Zhigao Zhu, and Jiansheng Li\*

Abstract: Developing single-atom catalysts (SACs) with asymmetric coordination configurations is essential for enhancing peroxymonosulfate (PMS) activation in Fenton-like reactions. However, precisely regulating the electronic structure and coordination environment of metal centers to further improve activation kinetics remains a key challenge. Herein, we designed asymmetric $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ single atoms (SAs) sites and $\mathrm { C o }$ nanoclusters (NCs) that were spatially confined in highly graphitized carbon layers and supported on holey MXene nanosheet $( \mathrm { C o } _ { \mathrm { S A - N C } } / \mathrm { H } _ { 2 0 } \mathrm { M X } )$ via a dual-coordination microenvironment strategy. The $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst demonstrated exceptional performance on bisphenol A (BPA) removal, achieving a corrected rate constant $( k _ { \mathrm { v a l u e } } )$ of $2 7 5 0 \ \mathrm { m i n ^ { - 1 } \ M ^ { - 1 } }$ and a total organic carbon removal efficiency of $7 8 . 2 \%$ . Mechanistic studies revealed that BPA removal was dominated by a nonradical electron transfer process (ETP, ${ \sim } 1 0 0 \%$ ), which facilitated rapid polymerization of BPA. Density functional theory calculations demonstrated that Co NCs synergistically enhanced the ability of asymmetric $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites to adsorb and activate PMS, significantly accelerating interfacial charge transfer. Furthermore, a catalytic membrane fabricated by crosslinking of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ and graphene achieved $1 0 0 \%$ BPA removal in single-pass mode with a hydraulic retention time of just $4 0 \ \mathrm { m s }$ over $^ { 2 4 \mathrm { ~ h ~ } }$ of continuous operation. This work provides new insights into designing high-performance catalysts for pollutant removal via ETP-driven polymerization pathways.

Single-atom catalysts (SACs), featuring $1 0 0 \%$ atomic utilization efficiency, high catalytic activity, and tunable electronic structures, have emerged as promising candidates for PMS activation.[6] Among various configurations, the symmetric metal- ${ \bf \cdot N } _ { 4 }$ $\left( \mathbf { M } - \mathbf { N } _ { 4 } \right)$ structure has been widely explored due to its excellent catalytic performance and high selectivity toward reactive oxygen species (ROS) generation.[79] However, the inherent nonpolar nature of ${ \bf M } { - } { \bf N } _ { 4 }$ configurations restricts efficient charge transfer between metal center and oxygen atoms in PMS, leading to sluggish reaction kinetics.[10] To address this limitation, engineering strategies that modulate the electronic structure of the metal center and its coordination microenvironment have been developed to break the symmetry of the single atoms (SAs) sites.[11] These strategies include introducing heteroatoms (e.g., Cl, O, B, P, and S) to construct asymmetric coordination environments[12-14] or design synergistic systems by integrating SAs sites with nanoparticles/nanoclusters (NCs).[15,16] Despite these advances, current studies predominantly focus on individual regulatory strategies, while the electronic structure evolution and dual-regulation mechanisms arising from the synergetic interplay between asymmetrically coordinated SAs sites and NCs remain largely unexplored.

# Introduction

Peroxymonosulfate (PMS) based advanced oxidation processes (AOPs) have attracted significant attention in water

Metal-organic frameworks (MOFs), with their precisely tunable pore structures, present unique advantages for the synthesis of SACs.[17] Among various MOFs, zeolitic imidazolate framework (ZIF) are particularly promising due to their microporous structures and high nitrogen content, which facilitate the anchoring of metal active sites.[18] However, many metal active sites were buried within the support or micropores, significantly diminishing the atomic utilization effciency[19] MXene, a family of 2D transition metal carbides/nitrides, has emerged as a promising platform for maximizing exposure of active sites, attributed to their excellent electrical conductivity, tunable layered structure, and abundant surface functional groups.[20] Notably, the 2D MXene nanosheets feature terminal groups $( - \mathrm { O } , - \mathrm { O H }$ ,and —F) along with high-density transition metal vacancy defects, providing dual assurance for both stable anchoring and full exposure of metal active centers.[21]

In this work, we developed an innovative dualcoordination microenvironment strategy for the uniform anchoring of ${ \cal Z } \mathrm { n C o - } { \cal Z } \mathrm { I F }$ on both sides of holey $\mathrm { T i } _ { 3 } \mathrm { C } _ { 2 } \mathrm { T } _ { \mathrm { x } }$ MXene $\mathbf { ( H _ { x } M X ) }$ nanosheets (denoted as $\mathrm { Z I F / H _ { x } M X }$ . After pyrolysis, asymmetric $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and Co NCs were spatially confined within highly graphitized carbon layers and supported on holey MXene nanosheets $( \mathrm { C o _ { S A - N C } / H _ { x } M X } )$ . A hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ -assisted etching method simultaneously engineered planar nanopores and Ti vacancy defects in the surface of MXene. The abundant surface functional groups and high-density Ti vacancy defects of MXene, as well as nitrogen-enriched ZIF precursors, synergistically facilitate the generation of $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and Co NCs confined in multilayer graphitic carbon layers. The integration of $\mathbf { H } _ { \mathrm { x } } \mathbf { M } \mathbf { X }$ with multilayer graphitic carbon created an interconnected conductive network that collectively enhanced charge transfer efficiency. Density functional theory (DFT) calculations revealed the atomiclevel synergistic mechanism between SAs sites and NCs during PMS activation. Systematic characterization confirmed the dominance of a nonradical electron transfer process (ETP) that mediated bisphenol A (BPA) removal through a polymerization pathway in the $\mathrm { C o _ { S A - N C } / H _ { x } M X / P M S }$ systems. This work provides a viable strategy for engineering high-performance catalysts that achieve ultrafast pollutants removal via polymerization pathways.

# Results and Discussion

The $\mathrm { C o _ { S A - N C } / H _ { x } M X }$ catalyst was fabricated via an innovative dual-coordination microenvironment strategy (Figure 1a). MXene nanosheets were first prepared by selectively etching the Al layer from $\mathrm { T i } _ { 3 } \mathrm { A l C } _ { 2 }$ MAX phase using a HCl/LiF solution, followed by ultrasonic exfoliation. Then, a $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching method was employed to create abundant in-plane mesopores while preserving the structural integrity of MXene. Subsequently, $Z _ { \mathbf { n } } { } ^ { 2 + }$ and $\mathrm { C o } ^ { 2 + }$ were adsorbed onto the surface and edge sites of the negatively charged $\mathbf { H } _ { \mathrm { x } } \mathbf { M } \mathbf { X }$ nanosheets through electrostatic interactions. 2-methylimidazole was coordinated with these ions to form ZnCo-ZIF crystals, which were uniformly anchored on both sides of the $\mathbf { H } _ { \mathrm { x } } \mathbf { M } \mathbf { X }$ nanosheets. Eventually, the resulting catalyst featured welldispersed asymmetrically coordinated $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and Co NCs firmly immobilized on the $\mathbf { H } _ { \mathrm { x } } \mathbf { M } \mathbf { X }$ substrate following pyrolysis and acid-washing.

As shown in the $\mathbf { X }$ -ray diffraction (XRD) pattern of Figure S1a, the disappearance of the diffraction peak at $2 \theta$ $= 3 9 ^ { \circ }$ corresponding to the (104) crystal plane in the $\mathrm { T i } _ { 3 } \mathrm { C } _ { 2 } \mathrm { T } _ { \mathrm { x } }$ pattern confirmed the successful etching of the Al layer.[22] In addition, the (002) diffraction peak of $\mathrm { T i } _ { 3 } \mathrm { C } _ { 2 } \mathrm { T } _ { \mathrm { x } }$ shifted from $9 . 5 ^ { \circ }$ to $6 . 8 ^ { \circ }$ relative to $\mathrm { T i } _ { 3 } \mathrm { A l C } _ { 2 }$ , indicating the synthesis of the $\mathrm { T i } _ { 3 } \mathrm { C } _ { 2 } \mathrm { T } _ { \mathrm { x } }$ MXene with an increased interlayer spacing.[23] The transmission electron microscopy (TEM) image of the $\mathrm { T i } _ { 3 } \mathrm { C } _ { 2 } \mathrm { T } _ { \mathrm { x } }$ MXene nanosheets in Figure S2a revealed a smooth and flat surface. After $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching, the interlayer spacing of $\mathrm { H } _ { 2 0 } \mathrm { M X }$ $( d ~ = ~ 1 . 1 9 ~ \mathrm { { \ n m } }$ )was slightly reduced compared to that of MXene $\dot { \boldsymbol { d } } = 1 . 2 9 \mathrm { n m }$ ), as determined by the Bragg equation $( 2 \mathrm { d } \mathrm { s i n } \theta ~ = ~ \mathrm { n } \lambda$ ). This may be attributed to the decrease in $- \mathrm { O H }$ surface groups, which enhances the interlayer bonding force.[24] During the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching process, the $\mathrm { T i } { - } \mathrm { C }$ bonds on the MXene surface were disrupted and partially oxidized to $\mathrm { T i O } _ { 2 }$ nanoparticles. The subsequent treatment with $\operatorname { L } ( + )$ -tartaric acid removed the $\mathrm { T i O } _ { 2 }$ while introducing a certain amount of vacancy defects.[25,26] As shown in Figure S2c, the surface of $\mathrm { H } _ { 2 0 } \mathrm { M X }$ nanosheets exhibited numerous planar mesopores after the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching. The inset of the hole size distribution statistics in Figure S2c confirmed that the average pore size within the plane was about $1 1 ~ \mathrm { { n m } }$ Atomic force microscopy (AFM) image (Figure 1b) further revealed the holey $\mathrm { H } _ { 2 0 } \mathrm { M X }$ nanosheets with a thickness of about $1 . 6 \ \mathrm { n m }$ As shown in Figure S2b-d, prolonged etching with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ resulted in an increased density of in-plane pores within the $\mathbf { H } _ { \mathrm { x } } \mathbf { M } \mathbf { X }$ nanosheets. However, excessive etching time will destroy the structure of MXene.

After the self-assembly of holey MXene nanosheets and ZIF crystals, the XRD pattern confirmed the successful synthesis of $\mathrm { Z I F / H _ { 2 0 } M X }$ (Figure S1b). Scanning electron microscope (SEM) images of $\mathrm { Z I F / H _ { 1 0 } M X }$ and $\mathrm { Z I F / H _ { 2 0 } M X }$ revealed that ultrasmall ZIF nanoparticles were uniformly anchored on both sides of holey MXene nanosheets (Figures 1c and S3a). However, due to partial framework collapse in $\mathrm { H } _ { 3 0 } \mathrm { M X }$ (Figure S3b), the $\mathrm { Z I F / H _ { 3 0 } M X }$ hybrid displayed a fragmented nanosheet morphology with compromised structural coherence. Furthermore, the TEM image and particle size distribution histogram of $\mathrm { Z I F / H _ { 2 0 } M X }$ (Figure S2e) revealed that the planar mesopores of $\mathrm { H } _ { 2 0 } \mathrm { M X }$ were densely surrounded by ZIF nanoparticles with an average size of $3 2 \mathrm { n m }$ The holey sandwich structure is conducive to the generation of high-density active sites. After pyrolysis and acid washing, the SEM image of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ in Figure 1d showed that $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ maintained the 2D layered structure, with some mesopores still preserved on the surface. The TEM images of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ showed no obvious metal nanoparticles on the surface of the catalyst (Figure 1e). The high-resolution TEM image in Figure 1f indicated that the surface of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst exhibited distinct graphitic features, with an average interlayer spacing of $0 . 3 6 \ \mathrm { n m }$ (Figure S4).[27] Meanwhile, highly curved multilayer graphitic carbon layers were also observed surrounding planar pores. This phenomenon can be attributed to the high-temperature catalytic graphitization effect induced by $\mathrm { C o }$ within the ZIF anchored on the MXene substrate.[28]

High-angle annular dark-field scanning transmission electron microscopy (HAADF-STEM) in Figure 1g clearly revealed numerous bright spots corresponding to atomically dispersed Co SAs sites (highlighted with red circles) and Co NCs (highlighted with yellow circles) distributed within the graphitic carbon layers. Energy-dispersive spectroscopy (EDS) in Figure 1h demonstrated the uniform distribution of C, O, N, Ti, and Co, further confirming the coexistence of Co in both SAs sites and NCs.

XRD, X-ray photoelectron spectroscopy (XPS) and X-ray absorption fine structure (XAFS) characterizations further investigated the chemical composition and atomic coordination environment of the catalysts. As shown in Figure 2a, no distinct peaks were observed in the XRD patterns of $\mathrm { C o _ { S A - N C } / H _ { 1 0 } M X }$ $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ ,and $\mathrm { C o _ { S A - N C } / H _ { 3 0 } M X }$ .In contrast, CoO/MX synthesized without $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching exhibited prominent peaks at $3 6 . 5 ^ { \circ }$ , $4 2 . 4 ^ { \circ }$ , and $6 1 . 5 ^ { \circ }$ , indexed to the (111), (200), and (220) planes of crystalline $_ \mathrm { C o O }$ (PDF#43-1004)[29] The results indicate that $\mathrm { C o O / M X }$ lacks sufficient anchoring sites for $\mathrm { C o }$ atoms, leading to the aggregation of Co nanoparticles (Figure S2f), which indicates that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching of MXene is beneficial for enhancing the dispersion of $\mathrm { C o }$ atoms.

XPS analysis studied distinct nitrogen species and their atomic content. As depicted in Figure 2b, the high-resolution N 1 s XPS spectrum of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ exhibited six distinct peaks at 397.2, 398.5, 399.2, 400.3, 401.1, and $4 0 4 . 0 \ \mathrm { \ e V } .$ These peaks were assigned to $ \mathrm { T i - N } .$ pyridinic N, metalcoordinated N (Co—N), pyrrolic N, graphitic N, and oxidized N, respectively[2,3032] As the etching time increased, the MXene surface generated more in-plane pores, exposing numerous pore edge sites. These edge sites provided additional anchoring sites for ZnCo-ZIF nanoparticles, which facilitated the formation of $\mathrm { C o - N }$ and graphitic N species following subsequent pyrolysis. Therefore, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst exhibited a significant increase in the atomic percentages of $\mathrm { C o - N }$ $( 2 0 \% )$ and graphitic N $( 3 8 \% )$ compared to $\mathrm { C o O / M X }$ (Figure 2c). The $\mathrm { C o - N }$ and graphitic N sites can facilitate the adsorption and activation of PMS. Additionally, $\mathrm { N - C }$ bonds formed between graphitic N and adjacent carbon atoms can accumulate substantial organic pollutants through $\pi - \pi$ interactions.[33] Thus, $\mathrm { C o - N }$ and graphitic N may be the main active sites in catalytic reactions.[34]

X-ray absorption fine structure (XAFS) spectroscopy was employed to investigate the coordination environment and chemical state of $\mathrm { C o }$ atoms. The Co K-edge X-ray absorption near-edge structure (XANES) spectrum revealed the absorption edge energy of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ sample (Figure 2d). The absorption edge of $\mathrm { C o }$ lies between Co foil and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , indicating that the chemical state of cobalt atoms is between 0 and $+ 3$ ,close to $+ 2$ Extended $\mathbf { X }$ -ray absorption fine structure (EXAFS) analysis further explored the coordination environment of $\mathrm { C o }$ sites. In the R-space of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst (Figure 2e), the peak at $1 . 3 4 \mathrm { ~ \AA ~ }$ corresponds to $\mathrm { C o { - } N / C o { - } O }$ bond, while the broad peak at $2 . 1 \mathrm { ~ \AA ~ }$ corresponds to $C \mathrm { o } { - } \mathrm { C o }$ bond, indicating the coexistence of Co SAs sites and NCs in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst.[16] The fitting results of EXAFS (Figure 2f and Table S1) suggested that the coordination environment of Co SAs sites in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ sample was likely to be $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ . Additionally, the wavelet transform (WT) analysis in $\mathbf { k }$ -space further elucidated the atomic structure of $\mathrm { C o }$ (Figures $2 \mathrm { g }$ and S5). The intensity peaks observed in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ sample can be attributed to $_ { \mathrm { C o - O / N } }$ and Co-Co coordination, respectively [35]

Raman spectroscopy was employed to evaluate the structural defect density and graphitization degree of the materials. As shown in Figure S6a, all samples exhibited characteristic peaks at the D-band $( 1 3 4 0 ~ \mathrm { c m } ^ { - 1 } $ and G-band $( 1 5 7 0 ~ \mathrm { c m } ^ { - 1 } ) $ ). The intensity ratio of the D-band to the G-band $\mathrm { ( I _ { D } / I _ { G } ) }$ increased with prolonged chemical etching time, indicating that longer etching times result in higher defect densities. This defect-rich environment promotes uniform dispersion and stabilization of $\mathrm { C o }$ species.[36] Additionally, the Raman spectrum of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ featured a distinct 2D peak at $2 6 9 0 ~ \mathrm { c m } ^ { - 1 }$ , suggesting the presence of highly ordered graphitic carbon layers in the material. This structural feature is conducive to enhancing the electronic conductivity of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ [37] ${ \bf N } _ { 2 }$ adsorption-desorption isotherms were employed to study the specific surface area $( S _ { \mathrm { B E T } } )$ and pore structure of different samples (Figure S6b and Table S2). $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ exhibited a Type IV isotherm with a hysteresis loop in the relative pressure $\left( \mathrm { P } / \mathrm { P } _ { 0 } \right)$ range of 0.451.0, indicating the presence of significant mesopores. Compared to CoO/MXene $( 2 2 9 . 3 ~ \mathrm { ~ m } ^ { 2 } ~ \mathrm { ~ g } ^ { - 1 } )$ , the $S _ { \mathrm { B E T } }$ of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ increased to $4 3 4 . 5 \ : \mathrm { m } ^ { 2 } \ : \mathrm { g } ^ { - 1 }$ , which is attributed to the generation of abundant in-plane pores within MXene during the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching. The pore size distribution diagram in Figure S6c revealed the coexistence of mesopores and macropores in $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ , which facilitate the exposure of active sites and ensure efficient interface mass transfer and electron transfer processes.[38]

BPA was selected as the target pollutant to evaluate the catalytic performance of various catalysts. As shown in Figure S7, the adsorption capacities of $\mathrm { C o O / M X }$ , $\mathrm { C o _ { S A - N C } / H _ { 1 0 } M X }$ $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ , and $\mathrm { C o _ { S A - N C } / H _ { 3 0 } M X }$ for BPA was below $2 0 \%$ . MXene alone exhibited limited efficiency in activating PMS for BPA degradation (Figure 3a). In contrast, the CoO/MX/PMS system achieved $6 7 \%$ BPA removal within $1 0 \ \mathrm { m i n }$ The $\mathrm { C o _ { S A - N C } / H _ { x } M X }$ catalysts synthesized via $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching demonstrated significantly enhanced BPA removal efficiency $( > 9 5 \% )$ . Notably, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system exhibited superior catalytic performance, achieving $9 6 \%$ BPA removal within $4 \ \mathrm { m i n }$ . The apparent rate constant $( k _ { \mathrm { o b s } } )$ in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system was $1 . 3 2 \ \mathrm { \ m i n } ^ { - 1 }$ , which was 3.4, 1.4, and 2.0 folds higher than those observed in the CoO/MX, $\mathrm { C o _ { S A - N C } / H _ { 1 0 } M X }$ , and $\mathrm { C o _ { S A - N C } / H _ { 3 0 } M X }$ systems, respectively (Figure S8). This indicates that appropriate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted etching treatment of MXene can improve the dispersion of $\mathrm { C o }$ atoms, thereby significantly enhancing catalytic efficiency. Figure 3b and Table S3 compared the catalytic performance in this work through multiple metrics: $k _ { \mathrm { o b s } }$ , total organic carbon (TOC) removal efficiency, and normalized parameters including $k _ { \mathrm { o b s } }$ normalized by $\mathrm { C o }$ content $\left( k _ { \mathrm { p e r } } _ { \mathrm { C o } } \right)$ , the specific surface area $( k _ { \mathrm { S B E T } } )$ , and the corrected rate constants $( k _ { \mathrm { v a l u e } } )$ . $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ displayed superior comprehensive performance across all parameters. Furthermore, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system exhibited a remarkably high corrected reaction rate constant $( k _ { \mathrm { v a l u e } } = 2 7 5 0 \ \mathrm { m i n ^ { - 1 } \ { M } ^ { - 1 } } )$ , surpassing most state-of-the-art catalyst/PMS systems (Figure 3c). These findings confirm the exceptional catalytic activity of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ in PMSbased Fenton-like reactions.

To further investigate the practical applicability of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system in wastewater treatment, its catalytic degradation performance for diverse pollutants was evaluated. As shown in Figure 3d, $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ demonstrated superior removal rate for electron-rich pollutants, including BPA, 4-chlorophenol (4-CP), and phenol (PE), while its removal efficiency for electrondeficient pollutants such as 4-nitrophenol (4-NP) and benzoic acid (BA) was significantly reduced. These results indicate that the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system shows high selectivity for electron-rich contaminants. Moreover, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system demonstrated wide $\mathrm { p H }$ compatibility (3.611) and strong resistance to interference from coexisting anions $\mathrm { ( C l ^ { - } }$ , ${ \mathrm { N O } } _ { 3 } { } ^ { - }$ , $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } { } ^ { - }$ , and $\mathrm { H C O } _ { 3 } { } ^ { - }$ and humic acid (HA) (Figures 3e and S9a,b). Additionally, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system exhibited excellent BPA removal efficiency across diverse aqueous matrices, including tap water and lake water, highlighting its compatibility with complex aqueous environments (Figure 3f). Collectively, these findings underscore the significant potential of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system for practical wastewater treatment. Inductively coupled plasma-optical emission spectrometry (ICP-OES) was employed to analyze the Co loading of different catalysts and the leaching of $\mathrm { C o }$ ions in different systems. As shown in Figure S10, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst had the lowest loading of $\mathrm { C o }$ (approximately $1 . 0 ~ \mathrm { w t \% }$ )but exhibited the highest catalytic activity, demonstrating its superior atomic utilization efficiency. In addition, the leaching of $\mathrm { C o }$ ions in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system was approximately $0 . 0 7 \mathrm { m g L ^ { - 1 } }$ , which could remove $1 6 \%$ BPA within $1 0 \ \mathrm { m i n }$ (Figure S11). Thus, the primary reason for the excellent catalytic activity is attributed to the synergistic effect of $\mathrm { C o N _ { 1 } O _ { 2 } }$ SAs sites and Co NCs, rather than the leaching of $\mathrm { C o }$ ions.

The ROS generated in PMS-based Fenton-like reactions play a crucial role during the removal of pollutants. The catalytic mechanism of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ was investigated by quenching experiments. Potassium thiocyanate (KSCN) was introduced as a chemical probe to shield metal atoms, which significantly suppressed BPA degradation (Figure S12a). This confirmed that $\mathrm { C o }$ atoms, rather than carbon species, serve as the key active centers.[39] Methanol (MeOH), tert-butanol (TBA), nitrotetrazolium blue chloride (NBT), $\mathbf { L }$ -histidine (Lhis), and dimethyl sulfoxide (DMsO) were used to identify the contributions of ROS.[40,41] As shown in Figure 4a, the addition of MeOH or TBA caused negligible changes in BPA removal rate, indicating minimal contribution of sulfate radicals $( \mathrm { S O } _ { 4 } ^ { \bullet - } )$ and hydroxyl radical $\left( { } ^ { \bullet } \mathrm { O H } \right)$ [42] BA, used as a chemical probe, further validated this conclusion. As shown in Figure S12b, the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system exhibited negligible BA degradation, confirming the absence of $\mathrm { S O _ { 4 } ^ { \bullet - } }$ and $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ in the system.[43] Besides, NBT was employed as a chemical probe to assess the generation of superoxide radical $( \mathrm O _ { 2 } ^ { \bullet - } )$ [44] NBT can react with $\mathrm { O } _ { 2 } { } ^ { \bullet - }$ to form monoformazan, which can be monitored by ultravioletvisible (UV-vis) spectroscopy. As shown in Figure S13, negligible reduction of NBT was detected, confirming the minimal contribution of $\mathrm { O } _ { 2 } { } ^ { \bullet - }$ in the system. Therefore, the removal of BPA was primarily dominated by a nonradical pathway.

As shown in Figure S14, the 2,2,6,6-tetramethylproline ${ } ^ { 1 } \mathbf { O } _ { 2 }$ $\mathrm { ( T E M P \ – ^ { 1 } O _ { 2 } ) }$ triplet signal was not detected in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system, further proving the minimal role of ${ } ^ { 1 } { \bf O } _ { 2 }$ [46] When DMPO was used as a trapping agent and water as the solvent, distinct characteristic peaks attributed to 5,5-dimethyl-1-pyrrolidone2-oxyl (DMPOX) were observed in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system (Figure 4b). These peaks may originate from the electron-mediated oxidation of DMPO to DMPOX.[47,48] The introduction of MeOH, furfuryl alcohol (FFA), or DMSO had minimal impact on the signal intensity of DMPOX in the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system, further supporting the negligible contributions of $\mathrm { S O } _ { 4 } \mathrm { ^ { \bullet - } }$ , OH, ${ } ^ { 1 } { \bf O } _ { 2 }$ , and high-valent metal oxides.[49,50] Collectively, these results indicate that the nonradical electron transfer mechanism plays a dominant role during the removal of BPA.

In-situ Raman spectroscopy, electrochemical experiments, and galvanic oxidation processes (GOP) were employed to elucidate the electron transfer mechanisms within the system. As depicted in Figure $_ \mathrm { 4 c }$ , the introduction of PMS to the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst resulted in the emergence of a new peak at $8 3 4 \mathrm { c m } ^ { - 1 }$ , which subsequently vanished upon the addition of BPA. This phenomenon corresponds to the formation and consumption of the metastable $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X { - } P M S ^ { \ast } }$ complexes.[51] Additionally, the open-circuit potential (OCP) test was used to further reveal the surface active species formed on the catalyst surface during activation of PMS. The potential of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst increased significantly to $0 . 8 9 5 \mathrm { ~ V ~ }$ upon the addition of $0 . 3 2 ~ \mathrm { m M }$ PMS (Figure 4d). This increase was attributed to the formation of the high-potential metastable complexes $\mathbf { \mathrm { ( C o _ { S A - N C } / H _ { 2 0 } M X . } }$ . $\mathrm { P M S ^ { * } }$ . After the addition of BPA, the potential decreased to $0 . 8 3 7 \mathrm { ~ V } ,$ indicating the transfer of electrons between $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X { - } P M S ^ { \ast } }$ and BPA.[52] As shown in Figure S15, the electrochemical properties of various catalysts were also investigated using electrochemical impedance spectroscopy (EIS). $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ exhibited a low charge transfer resistance in the high-frequency region, signifying superior conductivity and enhanced electron transfer efficiency.[53] GOP were conducted to explore the interactions between the catalyst, BPA, and PMS. As shown in Figure 4f, the current increased to $8 . 6 3 ~ \mu \mathrm { A }$ upon PMS addition and subsequently stabilized at $4 . 5 2 ~ \mu \mathrm { A }$ after $2 4 \mathrm { ~ h ~ }$ . In contrast, no significant current change occurred in the absence of PMS. These results robustly confirm that the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X { - } P M S }$ \*complexes act as an electronic bridge that mediates the transfer of electrons from BPA to PMS.

Density functional theory (DFT) calculations were performed to investigate the influence of cobalt coordination environments on PMS activation. Both $\mathrm { C o _ { S A } / H _ { 2 0 } M X }$ and $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ exhibited metallic properties as shown by the projected density of states (PDOS) in Figure 5a. To elucidate the synergistic effects between SAs sites and NCs in the catalysts, we systematically analyzed PMS adsorption energies $\left( E _ { \mathrm { a d s } } \right)$ , $\mathrm { O } { - } \mathrm { O }$ bond lengths of PMS $\left( \mathrm { L } _ { \mathrm { O - O } } \right)$ , and electron transfer tendency (Q). The $\mathrm { { { E } _ { a d s } } }$ of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ $\left( - 0 . 8 3 \ \mathrm { e V } \right)$ and $\mathrm { C o _ { S A } / H _ { 2 0 } M X }$ $( - 2 . 6 9 \mathrm { e V } )$ were negative, indicating that the adsorption process was exothermic and readily occurred. The more negative $E _ { \mathrm { a d s } }$ of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ indicated stronger adsorption of PMS, which was more favorable for forming the $\mathrm { C o } _ { \mathrm { S A - N C } } / \mathrm { H } _ { 2 0 } \mathrm { M X } .$ $\mathrm { P M S ^ { \ast } }$ complexes. Besides, the shorter Lo-o in $\mathrm { C o } _ { \mathrm { S A } - \mathrm { N C } } /$ $\mathrm { H } _ { 2 0 } \mathrm { M X } / \mathrm { P M S }$ system might be attributed to the synergistic stretching effect of the $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and Co NCs.

The number of electrons transferred from the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ to PMS was 0.86, significantly higher than that in $\mathrm { C o _ { S A } / H _ { 2 0 } M X }$ This indicated that the synergistic effect of the $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and $\mathrm { C o } ~ \mathrm { N C s }$ accelerated the transfer of electrons. Given that the formation of catalyst-PMS\* complexes was a crucial step in ETP-based systems, the crystal orbital Hamilton population (COHP) was employed to study the bond strength between the Co atoms in the catalysts and the $\mathrm { o }$ atoms of PMS (Figure 5f). Based on the above analysis, a polymerization mechanism initiated by nonradical ETP is proposed (Figure 5g). The synergistic effects between $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and Co NCs can efficiently activate PMS and form $\mathbf { C o } _ { \mathrm { S A - N C } } / \mathrm { H } _ { 2 0 } \mathbf { M } \mathbf { X } \mathbf { - } \mathbf { P } \mathbf { M } \mathbf { S } ^ { \ast }$ complexes. Concurrently, $\mathrm { N - C }$ bonds formed by graphitic $\mathbf { N }$ and surrounding carbon atoms enrich BPA through $\pi$ - $\pi$ interactions. The holey MXene substrate, coupled with highly conductive graphitic carbon layers, accelerated internal charge transfer. Subsequently, BPA undergoes oxidation to generate phenoxy radicals, thereby initiating $\mathrm { C - O / C - C }$ polymerization reactions. The resulting polymeric products are adsorbed on the catalyst surface, enabling rapid removal from aqueous solutions.

To evaluate the practical application potential of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst in wastewater treatment, a composite catalytic membrane $\mathrm { ( C o _ { S A - N C } / H _ { 2 0 } M X / G O / P V D F ) }$ was fabricated through crosslinking with graphene oxide (GO). The membrane was subsequently deposited onto a polyvinylidene fluoride (PVDF) substrate via vacuum filtration, forming a simplified water treatment device (Figure 6a). As shown in Figures 6b and S18, the digital photographs of $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / G O / P V D F }$ membrane revealed a smooth surface morphology with excellent flexibility. The SEM images demonstrated successful crosslinking between GO and the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst (Figure 6b). The crosssectional SEM images showed a typical layered structure similar to that of other 2D material membranes, with a thickness of approximately $1 . 4 ~ { \mu \mathrm { m } }$ (Figure 6c). The catalyst loading was $0 . 9 6 ~ \mathrm { m g ~ c m } ^ { - 2 }$ . The catalytic membrane achieved $1 0 0 \%$ BPA removal over $2 4 \mathrm { ~ h ~ }$ with the hydraulic retention time of just $4 0 ~ \mathrm { { m s } }$ (Figure 6d). Notably, the leaching of $\mathrm { C o }$ ions was well below the reclaimed water limit set by the U.S. Environmental Protection Agency $( 5 0 ~ \mu \mathrm { g } ~ \mathrm { L } ^ { - 1 } )$ , which confirmed the significant potential of the catalytic membrane for water purification applications.

# Conclusion

In summary, asymmetric $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs sites and Co NCs were spatially confined within highly graphitized carbon layers and supported on holey MXene nanosheets via a dual-coordination microenvironment strategy. The synthesized $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst achieved nearly $1 0 0 \%$ nonradical ETP during the activation of PMS. The $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X / P M S }$ system demonstrated ultrafast BPA removal through polymerization pathway and achieved $7 8 . 2 \%$ TOC removal efficiency. The system also showed excellent selectivity toward electron-rich organic pollutants and strong resistance to interference from anions and HA. Furthermore, integration of the $\mathrm { C o _ { S A - N C } / H _ { 2 0 } M X }$ catalyst with membrane separation technology achieved $1 0 0 \%$ BPA removal in single-pass mode with a hydraulic retention time of just $4 0 ~ \mathrm { { m s } }$ over $^ { 2 4 \mathrm { ~ h ~ } }$ . DFT calculations revealed a dualsite synergistic activation mechanism, where $\mathrm { C o N } _ { 1 } \mathrm { O } _ { 2 }$ SAs and Co NCs sites collaboratively facilitated the adsorption and activation of PMS. This finding provides new insights into the regulation of coordination microenvironments for metal active centers. However, current limitations in directional synthesis techniques prevented the preparation of control catalysts containing exclusively single active sites (either SAs or NCs). Future research should focus on developing precise synthetic methodologies to systematically investigate structure-activity relationships between metal center coordination configurations and ROs, along with conducting large-scale practical water treatment trials to assess engineering applicability.
