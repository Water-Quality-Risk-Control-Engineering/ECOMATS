# Abstract

This study develops and evaluates a novel wet method for NO removal using a $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ solution. The effects of these two components both and alone in solution, $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ concentration, $\mathrm { C a O } _ { 2 }$ concentration, initial $\mathrm { p H }$ , reaction temperature, and the concentrations of NO and $\mathrm { O } _ { 2 }$ on NO removal efficiency were evaluated using a bubbling reactor. The combination of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and $\mathrm { C a O } _ { 2 }$ had a synergistic effect on NO removal efficiency. NO removal was effected by $\mathrm { C a O } _ { 2 }$ concentration, reaction temperature and the initial solution $\mathrm { p H }$ , while $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ concentration and $\mathrm { O } _ { 2 }$ concentration had little effect. The NO removal efficiency decreased linearly from $9 4 . 5 ~ \%$ to $7 5 . 1 \ \%$ when the NO concentration increased from 139 to $5 5 9 ~ \mathrm { p p m }$ . The products were characterized using XRD、XPS and IC, and $\mathrm { C a S O } _ { 4 } { \cdot } 2 \mathrm { H } _ { 2 } \mathrm { O }$ , ${ \bf N a N O } _ { 3 }$ and $\mathrm { C a N O } _ { 3 }$ were found to be the main products. The EPR analysis showed that free radicals of ${ \mathrm { O } } _ { 2 } ^ { \bullet - }$ , $\mathrm { S O _ { 4 } } ^ { \bullet - }$ and •OH were the key species involved in the NO removal process. Finally, the corresponding reaction mechanisms were proposed.

Keywords: NO removal; $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ ; $\mathrm { C a O } _ { 2 }$ ; Free radical; EPR analysis

# 1. Introduction

Nitric oxide (NO) accounts for more than $9 0 ~ \%$ of $\mathrm { N O } _ { \mathrm { x } }$ emitted from coal-fired boilers and plays a key role in the formation of photochemical smog and acid rain [1]. Several denitration techniques have been developed to control emissions of $\mathrm { N O } _ { \mathrm { x } }$ . Recently, selective catalytic reduction (SCR) or selective non-catalytic reduction (SNCR) have been widely used in industrialization [2]. In order to meet the required standards of emission concentrations for $\mathrm { { \bf S } O } _ { 2 }$ and $\mathrm { N O } _ { \mathrm { x } }$ (lower than 35 and $5 0 ~ \mathrm { m g / m } ^ { 3 }$ , respectively), SCR or SNCR have been used before wet desulfurization in coal-fired $+ 1 ^ { \circ }$ many disadvantages, including its complex system, large footprint and high operating cost [3, 4]. These disadvantages can be addressed by simultaneous removal of $\mathrm { N O } _ { \mathrm { x } }$ and $\mathrm { S O } _ { 2 }$ in the same wet scrubber.

Unlike $\mathrm { { S O } } _ { 2 }$ , NO is an insoluble gas. Therefore, it is much more difficult to remove with conventional wet scrubbing [5]. To convert NO into more easily removable soluble nitrogen oxides, reagents are added that include ozone $( \mathbf { O } _ { 3 } )$ [6 ] , hydrogen peroxide $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 } )$ ) [7], chlorine dioxide $\mathrm { ( C l O } _ { 2 } )$ [8], potassium permanganate $\left( \mathrm { K M n O _ { 4 } } \right)$ ) [9], sodium chlorite $\mathrm { ( N a C l O } _ { 2 } ,$ ) [10], sodium hypochlorite (NaClO) [11], sodium persulfate $\left( \mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } \right)$ [12], $\mathrm { F e ( I I ) E D T A }$ and $\mathrm { C o ( N H _ { 3 } ) } _ { 6 } \mathrm { ^ { 2 + } ) }$ [13-14]. There is much interest in hydrogen peroxide $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ in particular because it is relatively low cost and does not produce secondary pollution. Cooper et al. [15] studied the injection of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ into hot flue gases for NO emission control. At the optimum temperature of $5 0 0 ~ ^ { \circ } \mathrm { C } ,$ hydrogen peroxide can be thermally activated to generate active radicals including hydroxyl radical (•OH) and hydroperoxy radical $\mathrm { ( H O } _ { 2 } { \bullet } )$ . More than $90 \%$ of NO can be effectively converted into soluble nitrogen oxides by these radicals of •OH and $\mathrm { H O } _ { 2 } \cdot$ . However, this gas-phase oxidation method has so far only been studied in the laboratory due to the limitations imposed by the high temperatures required.

Persulfate can be stimulated by heat [16], UV light [17], ultrasonic [18] or transition metals $( \mathrm { F e } ^ { 2 + } , \mathrm { C o } ^ { 2 + } , \mathrm { C u } ^ { 2 + } )$ [19, 20] to generate sulfate radical $\mathrm { ( S O _ { 4 } ) ^ { \bullet \ - } } ,$ ) (Eqs. 1-2), which is an oxidant with a similar function to • OH. Adewuyi et al. [5, 12] studied the absorption-oxidation of NO and $\mathrm { { \bf S } O } _ { 2 }$ by $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ aqueous solution in a bubbling reactor. Their results indicated that $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ can be activated to generate active $\mathrm { S O _ { 4 } } ^ { \bullet - }$ radical at $5 0 ~ ^ { \circ } \mathrm { C }$ , which then reacts with $\mathrm { H } _ { 2 } \mathrm { O }$ to produce •OH radical. The reaction rate was very slow $( k [ \mathrm { H } _ { 2 } \mathrm { O } ] < 2 \times 1 0 ^ { - 3 } \mathrm { s } ^ { - 1 } )$ ), and so NO and $\mathrm { S O } _ { 2 }$ were mainly removed by $\mathrm { S O } _ { 4 } ^ { \bullet - }$ radical in the thermal excitation system of ${ \mathrm { N a } } _ { 2 } { \bf S } _ { 2 } { \bf O } _ { 8 }$ aqueous solution. Block et al. [21] found that $\mathrm { S O _ { 4 } } ^ { \bullet - }$ and •OH radicals coexisted in the dual oxidation $\mathrm { ( S _ { 2 } O _ { 8 } } ^ { 2 - } / \mathrm { H } _ { 2 } O _ { 2 } )$ system owing to the significant synergistic relationship between ${ \mathrm { S } } _ { 2 } { { \mathrm { O } } _ { 8 } } ^ { 2 - }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . In our previous studies [22, 23], we also showed that the combination of ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 - }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ had a significant synergistic effect on NO removal. In addition, the NO removal efficiency under alkaline conditions was much higher than that under acidic or neutral conditions, reaching $8 0 ~ \%$ or higher for a long period of time under strongly alkaline conditions adjusted by the addition of sodium hydroxide (NaOH). All these indicated that ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 - }$ can be activated by strong alkalinity, heat and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . This finding was consistent with the conclusions of Zhao et al [24].

\begin{array} { l } { { \ S _ { 2 } { 0 _ { 8 } } ^ { 2 - } + \mathrm { h e a t / U V / u l t r a s o n i c } \right. 2 \mathrm { S } { 0 _ { 4 } } ^ { \left. \right.} } } \\ { { \ S _ { 2 } { 0 _ { 8 } } ^ { 2 - } + \mathrm { M e } ^ { \mathrm { n } + }  \mathrm { S } { 0 _ { 4 } } ^ { \left. - } + \mathrm { S } { 0 _ { 4 } } ^ { 2 - } + \mathrm { M e } ^ { \mathrm { ( n } + \mathrm { 1 } ) + } } } \end{array}

The problems of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ instability and extra consumption of NaOH in the dual oxidation $( \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ system can be solved by dissolving the solid oxidant $\mathrm { C a O } _ { 2 }$ in water for producing $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathrm { C a ( O H ) } _ { 2 }$ as described in $\operatorname { E q } . 3 ^ { [ 2 5 ] }$ [25]. As well as a source of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (liberating a maximum of $0 . 4 7 \textrm { g H } _ { 2 } \mathbf { O } _ { 2 } / \mathbf { g } \textrm { C a O } _ { 2 } ^ { [ 2 5 ] } )$ , $\mathrm { C a O } _ { 2 }$ is also a strong alkali oxidant. This means it can activate ${ \bf S } _ { 2 } { \bf O } _ { 8 } { } ^ { 2 - }$ and can therefore be used as an absorbent for the alkaline absorption of NO and $\mathrm { { S O } } _ { 2 }$ 。 To the best of our knowledge, no study on wet desulfurization and denitration using the dual component of $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - } / \mathrm { C a O } _ { 2 }$ has yet been reported.

$$
\mathrm { C a O } _ { 2 } + \mathrm { H } _ { 2 } \mathrm { O }  \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { C a } ( \mathrm { O H } ) _ { 2 }
$$

This study was aimed to understand the feasibility of simultaneous absorption of NO using $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - } / \mathrm { C a O } _ { 2 }$ . Specifically, the effects on NO removal of single and dual component methods, ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 - }$ concentration, $\mathrm { C a O } _ { 2 }$ concentration, the initial $\mathrm { p H }$ , the reaction temperature, NO concentration, and $\mathrm { O } _ { 2 }$ concentration were investigated in a bubbling reactor. In addition, the related mechanisms of NO removal by ${ \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } { } ^ { 2 - }$ and $\mathrm { C a O } _ { 2 }$ were revealed by free radical detection. The results would contribute to the knowledge of simultaneous removal of $\mathrm { N O } _ { \mathrm { x } }$ and $\mathbf { S } \mathbf { O } _ { 2 }$ in the same wet scrubber.

# 2. Experimental

# 2.1. Materials

Flue gases were simulated by mixing $\mathrm { N } _ { 2 } ( 9 9 . 9 9 9 \ \% )$ ), $\mathrm { O } _ { 2 }$ $( 9 9 . 9 9 9 ~ \%$ ), and NO mixed gas $( 1 \ \% )$ ). All gases were purchased from Air Liquide Tianjin Co., Ltd. Sodium persulfate $\mathrm { ( N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ , powder, $9 9 \ \%$ ), sulfuric acid $\mathrm { \bf { H } } _ { 2 } \mathrm { \bf { S } } \mathrm { \bf { O } } _ { 4 }$ , liquid, $9 8 \ \%$ ), sodium hydroxide (NaOH, pellets, $9 6 ~ \%$ ) and anhydrous calcium chloride (CaCl2, pellets, $9 6 ~ \%$ ) were supplied by Sinopharm Chemical Reagent Beijing Co., Ltd. All reagents used in this experiment were analytically pure. The calcium peroxide $( \mathbf { C a O } _ { 2 } )$ powder $( 7 0 ~ \% )$ ) used was chemically pure and obtained from Shandong Western Chemical Industry Co., Ltd.

# 2.2. Experimental Procedure

Fig. 1 shows the experimental setup used in this study. It consisted of four parts, a simulated flue gas generation system, a bubble column reactor with an inner diameter of $7 5 ~ \mathrm { m m }$ and a height of $3 0 0 ~ \mathrm { { m m } }$ , a flue gas analysis system and a tail gas absorption system. The NO, $\mathrm { O } _ { 2 }$ and $\Nu _ { 2 }$ (Fig. 1, 1-3) had their flow rates measured by mass flowmeters (Fig. 1, 4) before being mixed in a surge flask (Fig. 1, 5). Concentrations of NO and $\mathrm { O } _ { 2 }$ were adjusted by diluting with $\Nu _ { 2 }$ . The flow rate of the simulated flue gas was kept at $2 \mathrm { L } / \mathrm { m i n }$ .

All experiments were conducted at temperatures between $1 5 . 7 0 ~ ^ { \circ } \mathrm { C }$ . The temperature was controlled by the digital thermostat water bath (Fig. 1, 9) (HWSH, $\pm 0 . 1 \ ^ { \circ } \mathrm { C }$ , Shanghai Tian Heng Instrument co., Ltd). For a typical test, the bubble column reactor was first filled with $6 0 0 \ \mathrm { m L }$ of water and heated to the required temperature. Sodium persulfate and calcium peroxide solutions were added into the reactor until the total liquid volume reached $8 0 0 ~ \mathrm { m L }$ . The pH of the solution was adjusted by adding $3 \ \mathrm { m o l / L }$ $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ or 2 mol/L NaOH solution into the reactor. When the liquid phase was ready, the simulated flue gas was passed through the bubbling reactor, the surge flask (Fig. 1, 10), the drying tube (Fig. 1, 11) containing anhydrous $\mathrm { C a C l } _ { 2 }$ used for the removal of moisture in the simulated flue gas, and finally through another surge flask (Fig. 1, 14) before entering the flue gas analyzer.

The direction of simulated flue gas flow was controlled by a 3-way valve (Fig. 1, 6). The inlet and outlet concentrations of $\mathrm { N O } _ { \mathrm { x } }$ and $\mathrm { O } _ { 2 }$ were measured by the ecom-J2KN flue gas analyzer (German RBR Measurement Technology Co., LTD). The pH of the reaction solution was measured before and after each test with a digital pH meter (PHS-3C, E-201F of electrode assembly type, $\pm 0 . 0 1$ , Shanghai Leici Co., LTD). The tail gas was further cleaned by the exhaust gas absorption unit (Fig. 1, 17) before entering the fume hood (Fig. 1, 18).

# 2.3. Data Analysis

The ions in the spent scrubbing solution were analyzed with a Dionex ICS 1000 ion chromatography system under the following chromatographic conditions: ion pac AS11-HC capillary column $( 4 ~ \times ~ 2 5 0 ~ \mathrm { \ m m } )$ , eluent (2 mmol/L NaOH), injection volume $( 2 5 ~ \mu \mathrm { L } )$ ), column temperature $( 3 0 3 ~ \mathrm { K } )$ , flow rate (1.0 mL/min) and automatic regeneration suppression system (60 mmol $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { \mathrm { \ell } }$ ). The crystalline structure of fresh and spent solid absorbents was analyzed by X-ray diffraction (XRD, D8 ADVANCE type, BRUKER-AXS in Germany) ( $6 0 \mathrm { k V }$ and $5 0 ~ \mathrm { m A }$ ) with a Ni-Filtered Cu Kα, with a scanning 2θ range of $5 ^ { 0 }$ to $9 0 ^ { 0 }$ and a step size of 0.02. The fresh and spent solids were analyzed by X-ray photoelectron spectroscopy (XPS, PHI Quantera SXM Scanning ESCA Microprobe (Physical Electronics), Ulvac-Phi Inc in Japan) with a hemispherical detector operated at a constant pass energy $\mathrm { ( P E { = } } 5 5 \ \mathrm { e V }$ ) using Al Kα radiation (1486.6 eV). All binding energies were referenced to C 1s line at 284.8 eV. Active free radical species were detected with an electron spinresonance (EPR) spectrometer (JES-FA200) using 5,5-dimethyl-1-pyrrolidine N-oxide (DMPO) ( $9 9 \%$ , Sigma) as a spin trap agent.

The inlet concentrations of $\mathrm { N O } _ { \mathrm { x } }$ and $\mathrm { O } _ { 2 }$ were measured immediately upstream of the gas inlet. The outlet concentrations of $\mathrm { N O } _ { \mathrm { x } }$ and $\mathrm { O } _ { 2 }$ from the bubble column reactor were continuously monitored and recorded. Each measurement lasted for 90 minutes, and the mean concentration within the 90 minutes was used for the calculation of removal efficiency. When the mixed gas was bubbled through the reactor, NO reacted with the $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - } / \mathrm { C a O } _ { 2 }$ solution. The corresponding NO removal efficiency was calculated by:

$$
\eta _ { \mathrm { N O } } ( \% ) = \frac { \mathrm { N O _ { i n l e t } } - \mathrm { N O _ { o u t l e t } } } { \mathrm { N O _ { i n l e t } } } \times 1 0 0 
$$

where ηNO is the removal efficiency of NO, $\mathrm { { N O } _ { \mathrm { { i n l e t } } } }$ and NOoutlet are the NO concentrations in the inlet and outlet gas.

# 3.1. Stability of the dual component of $\bf N a _ { 2 } S _ { 2 } O _ { 8 / } C a O _ { 2 }$

Experiments were conducted with the pH changes of different $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ solutions over time at room temperature and atmosphere pressure to determine the stability of $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ solution. The corresponding results are shown in Fig. 2. 0.1 mol/L $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ solution was acidic due to the hydrolysis of ${ \mathrm { N a } } _ { 2 } { \bf S } _ { 2 } { \bf O } _ { 8 }$ via Eq. 5 [5], and exhibited negligible change in pH over time, likely because of the very slow hydrolysis of ${ \mathrm { N a } } _ { 2 } { \bf S } _ { 2 } { \bf O } _ { 8 }$ at room temperature and atmosphere pressure [26]. $0 . 2 2 ~ \mathrm { m o l / L }$ CaO2 solution was strongly alkaline and exhibited a slow increase in pH over time because of the slow release of $\mathrm { C a ( O H ) } _ { 2 }$ caused by the dissolution of $\mathrm { C a O } _ { 2 }$ in water via Eq. 3 [25, 27]. # 3.2. Effects of single and dual component on NO removal

# 3.2.1 Effect of $\mathrm { C a O } _ { 2 }$

In order to verify the synergistic effects of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and $\mathrm { C a O } _ { 2 }$ , the effects of each, both alone (single component) and together (dual component) on NO removal performance were analyzed at $5 5 . 5 ~ ^ { \circ } \mathrm { C } .$ Fig. 3 shows that NO removal efficiency was about $1 0 \ \%$ when using $\mathrm { C a O } _ { 2 }$ alone. This confirmed our expectations that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ released from $\mathrm { { C a O } } _ { 2 }$ has weak oxidation capacity due to its low oxidation reduction potential $( \mathrm { E } ^ { \ominus } \left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right) = 1 . 7 7 ~ \mathrm { V } )$ ). As shown in Fig. 3, NO removal efficiency decreased $\mathrm { f r o m } 2 1 \ \%$ to $6 \%$ for the reaction time of 4000 s. One reason for the decrease of NO removal efficiency with time might be that as the reaction proceeded, the main oxidant $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ released from $\mathrm { C a O } _ { 2 }$ was gradually consumed to remove NO. In addition, the $\mathrm { p H }$ of the single $\mathrm { C a O } _ { 2 }$ solution increased from 10.98 to 11.54 for the reaction time of 4000 s. Zhang et al. [27] found that the generation rate of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ from $\mathrm { C a O } _ { 2 }$ slowed down with the increase of $\mathrm { p H }$ , which may also explain the observed decline in removal efficiency. $\mathrm { O } _ { 2 }$ was not detected in the NO removal process when $\mathrm { C a O } _ { 2 }$ was the only component. # 3.4. Effects of temperature and pH on NO removal

Temperature affects the mass transfer rate of the chemicals of concern [30], while pH has obvious effects on the forms and oxidation-absorption potentials of the active species in the solution [31]. The effects of temperature on NO removal efficiency are shown in Fig. 6. NO removal efficiency increased from $1 5 . 9 ~ \%$ to $8 2 . 6 ~ \%$ when the temperature increased from $1 8 . 0 ~ ^ { \circ } \mathrm { C }$ to $5 5 . 5 ~ ^ { \circ } \mathrm { C }$ . The increase leveled off when the temperature changed from $5 5 . 5 ~ ^ { \circ } \mathrm { C }$ to $6 5 . 5 ~ ^ { \circ } \mathrm { C }$ . These results were similar to those for dual oxidant $\mathrm { ( N a _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } ) }$ system in our previous studies [23]. [32] also showed that the yields of $\mathrm { S O _ { 4 } } ^ { \bullet - }$ increased as the activation temperature increased from 25 to $7 5 ~ ^ { \circ } \mathrm { C }$ . # 4. Conclusions

We studied a wet $\mathrm { N O } _ { \mathrm { x } }$ removal technology using a $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ solution. The performance of the dual component $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ was stable at room temperature and atmosphere pressure. Comparative performance studies showed that the combination of $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and $\mathrm { C a O } _ { 2 }$ had significant synergistic effects on NO removal. With an increase of $\mathrm { C a O } _ { 2 }$ concentration and reaction temperature, NO removal efficiency first rapidly increased and then slowed down. With the increase of initial pH, NO removal efficiency first increased and then decreased. NO removal efficiency did not show a significant relationship with $\mathrm { N a } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ concentration or $\mathrm { O } _ { 2 }$ concentration. NO removal efficiency decreased almost linearly from $9 4 . 5 ~ \%$ to $7 5 . 1 \ \%$ with the increase in NO concentration from 139 to $5 5 9 ~ \mathrm { p p m }$ . According to the EPR $\mathrm { O } _ { 2 } ^ {  } , \mathrm { S O } _ { 4 } ^ {  }$ and •OH played a key role in the NO removal in $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ understanding of the reaction mechanisms of NO removal with $\mathrm { N a _ { 2 } S _ { 2 } O _ { 8 } / C a O _ { 2 } }$ .
