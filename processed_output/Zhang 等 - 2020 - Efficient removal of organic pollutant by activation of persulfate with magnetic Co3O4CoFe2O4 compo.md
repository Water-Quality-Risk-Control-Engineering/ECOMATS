# KEYWORDS

$\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite;   
Persulfate;   
Rhodamine B;   
Sulfate radicals;   
Hydroxyl radicals

Abstract In this study, magnetic spinel $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite were synthesized by the mechanical mixing of both powdered pristine samples. Then the catalyst was characterized by TEM, SEM, XRD, BET, XPS and VSM measurement. Next, $\mathrm { C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 } }$ composite was applied to degrade rhodamine B (RhB) in water by activating persulfate. Results showed that $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite exhibited high efficiency for removal of RhB, and $9 5 . 5 9 \%$ of it could be degraded in $4 5 ~ \mathrm { { m i n } }$ . Besides, the effects of parameters, such as initial $\mathrm { p H }$ , PS dosage, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } /$ ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ composite dosage, initial concentration of RhB and temperture were studied. Also, the effects of coexisting anions on RhB degradation were observed and explained. Furthermore, we conducted the quenching experiment and found that sulfate radical and hydroxyl radicals were the main active radicals in the degradation process. Finally, recycle experiments proved that $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ had a good stability for RhB degradation. In short, $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite is a promising catalyst for wastewater treatment.

# 1. Introduction

Today, water environment pollution is one of the major environmental problems in the world. Among various types of polluted water, printing and dyeing wastewater, as one of the hard-degradable wastewater, is gradually receiving more and more attention (Hou et al., 2016; He et al., 2018). Due to the processing of chemical fiber and other spinning products, the printing and dyeing wastewater contains a large amount of dyes, oils, starch alkalis, resins and inorganic salts, etc. It is very difficult to deal with. Most of the dyes are easily dissolved in water in form of cationic (rhodamine B, malachite green, methylene blue, and methyl violet) and anionic (Congo red, methyl orange, and rose Bengal) (Nafiey et al., 2017).

Advanced oxidation technology is a new technology which can efficiently remove difficult-to-degrade pollutants from water. In this method, highly active radicals (HO , $\mathrm { S O } _ { 4 } ^ { \bullet - }$ , etc.) can be generated through various routes to degradate pollutants, including Fenton method (Wang et al., 2009), photocatalytic oxidation method (Cheng et al., 2015), electrochemical oxidation method (Li et al., 2013), etc. Among these approaches, $\mathrm { S O } _ { 4 } ^ { \bullet - }$ -based technology has received increasing attention due to its higher redox potential $( 2 . 5 { - } 3 . 1 \ \mathrm { ~ V } )$ based on the activation methods compared with HO (Lutze et al., 2015; Ghauch and Tuqan, 2012). Apart from these, $\mathrm { S O } _ { 4 } ^ { \bullet - }$ has higher selectivity and longer half-life over HO in some cases (Ahmed et al., 2012). It can be generated by persulfate (PS) and peroxymonosulfate (PMS) activation through heat (Antoniou et al., 2010; Huang et al., 2002), ultraviolet (Chu et al., 2016; Sharma et al., 2016; Sharma et al., 2015), ultrasound (Gayathri et al., 2010; Chakma et al. 2017; Babu et al. 2017; Neppolian et al., 2010), electron beam (Criquet and Leitner, 2011; Furman et al., 2010); electrochemical (Ahmadi and Ghanbari, 2016; Ghanbari and Martinez-Huitle, 2019; Popat et al., 2019); zero valent metal (Khatri et al., 2018; Devi et al., 2016) and transition metal ions (Xie et al., 2016; Rastogi et al., 2009; Ayoub and Ghauch, 2014; Senthilnathan and Nachiappana, 2015; Sarath et al., 2014; Nidheesh and Rajan, 2016; Asha et al., 2017). Particularly, potassium persulfate $\left( \mathrm { K } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } \right)$ , as one of the common source of $\mathrm { S O } _ { 4 } ^ { \bullet - }$ , attached much attention due to its moderate cost, high stability, high solubility in aqueous solution, and it exists in the form of solid at room temperature (Zacharias et al., 2016; Lin et al., 2011). In view of economy and operation, choosing transition metal to activate PS is a good choice because it doesn’t require energy. Furthermore, the ${ \mathrm { C o } } ^ { 2 + }$ was proven to be most effective transition metal ions (Anipsitakis and Dionysiou, 2003). However, $\mathrm { C o } ^ { 2 + }$ is highly soluble in water environments, which could induce health problems (Huang and Huang, 2009; Yang et al., 2009; Ji et al., 2016). In order to overcome this shortcoming, heterogeneous Co catalysts such as CoO, $\mathrm { C o O } _ { 2 }$ , $\mathrm { C o } _ { 2 } \mathrm { O } _ { 3 }$ , and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , have been used to activate PS. Among them, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , as one of the P-type metal oxide semiconductors, attracted wide attention due to its magnetic (Wang et al., 2015). Besides, owing to its low valence band maximum (VBM), $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ has a superior oxidation capacity (Bautista et al., 2008). What’s more, spinel ferrites $\mathrm { ( M F e } _ { 2 } \mathrm { O } _ { 4 }$ $( \mathbf { M } \ = \ \mathrm { F e }$ , Cu, Co, Ni, etc.)) have high catalytic activity, stable crystalline structure, extremely low solubility and good magnetic in terms of activating PS in water environment. So they have been taken as very promising candidates (Yang et al., 2009; Zhang et al., 2013; Deng et al., 2013). In particular, spinel cobalt ferrite $\mathrm { ( C o F e _ { 2 } } \cdot$ $\mathrm { O } _ { 4 }$ ) has been confirmed to be one of the efficient catalyst which can activate PMS to degrade organic compounds due to its excellent magnetic property and surface active $\mathrm { C o } 2 +$ (Ren et al., 2015; Liu et al., 2015). Sun et al. (2016) fabricated an octahedral $\mathrm { C o F e / C o F e _ { 2 } O _ { 4 } }$ submicron composite by a flexible one-pot hydrothermal, which can efficient activate PMS to decompose methyl orange. Li et al. (2017) successfully prepared polypyrrole/CNTs- ${ \mathrm { . C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ magnetic nanohybrid (CNTs- $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } @ \mathrm { P P y } )$ , which was used as a superior adsorbent and catalyst to remove anionic and cationic dyes according activating PMS. However, at present, there is less research on activating PS with ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ to produce sulfate radicals for degradation of pollutants. If combine $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ with ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ the cobalt leaching will reduce and magnetic will strengthen, thus catalysts can be better recycled.

In this study, we first prepared $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ by calcination, then syntheized ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ by a simple one-step hydrothermal method. Subsequently, we combined the two of catalysts by mechanical stirring. Next, the physicochemical properties of $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite were analyzed. After this, we evaluated the catalytic activity of $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ by degradation of RhB via the formation of sulfate radicals and hydroxyl radicals by activating PS. Finally, we proposed the possible reaction mechanism towards the degradation of RhB.

# 2. Materials and methods

# 2.1. Materials

Ferric nitrate $( \mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O } )$ , cobalt nitrate $( \mathrm { C o } ( { \mathrm { N O } } _ { 3 } ) _ { 2 } .$ $6 \mathrm { H } _ { 2 } \mathrm { O } )$ , and potassium persulfate $( \mathrm { K } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } )$ were purchased from Tianjin Kemiou Chemical Reagent Co. LTD. Cobalt chloride $( \mathrm { C o C l } _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O } )$ , urea $\mathrm { ( C O ( N H _ { 2 } ) _ { 2 } ) }$ ) and ascorbic acid $\mathrm { ( C _ { 6 } H _ { 8 } O _ { 6 } ) }$ were provided by Sinopharm Chemical Reagent Co. Ltd. Ultra-pure water was used throughout the whole experiment.

# 2.2. Synthesis of $C o _ { 3 } O _ { 4 }$ powder

In a typical experiment, $5 \mathrm { g }$ of $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ was placed in a closed ceramic crucible and heated in a muffle furnace at around $4 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 4 \mathrm { h } }$ . After the furnace cooling to room temperature, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ powder was obtained. All chemicals were of analytical reagent grade and used without any further purification. Ultra-pure water was used throughout this experiment.

# 2.3. Synthesis of $C o _ { 2 } F e _ { 2 } O _ { 4 }$ powder

${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ were synthesized by a simple one-step hydrothermal method. 3.9975 mmol $\mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathrm { H } _ { 2 } \mathrm { O }$ , 1.995 mmol $\mathrm { C o C l } _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ , $4 . 2 6 ~ \mathrm { \ m m o l }$ $\mathrm { C _ { 6 } H _ { 8 } O _ { 6 } }$ and 15 mmol $\mathrm { C O } ( \mathrm { N H } _ { 2 } ) _ { 2 }$ were slowly added to the $1 0 0 ~ \mathrm { m L }$ breaker which contained $6 0 ~ \mathrm { m L }$ distilled water. Afterwards, it was stirred under magnetic for $3 0 \ \mathrm { \ m i n }$ until dissolved. Subsequently, the mixture was transferred into an autoclave and treated at $1 6 0 ~ ^ { \circ } \mathrm { C }$ for $^ \textrm { \scriptsize 6 b }$ . After centrifuging and washing with water and ethanol for several times, the black precipitate was dried at $8 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ . Finally, it was calcined in static air at $5 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 4 \mathrm { ~ h ~ } }$ .

# 2.4. Synthesis of $C o _ { 3 } O _ { 4 } / C o _ { 2 } F e _ { 2 } O _ { 4 }$ composite

The $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite was fabricated by the mechanical mixing method. In detail, a certain amount of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ powders were dispersed in absolute ethanol and stirred for $^ { 2 \mathrm { ~ h ~ } }$ under magnetic. After, the powders were dried at $7 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 4 \mathrm { ~ h ~ } }$ .

# 2.5. Characterization

In this paper, the surface morphology of $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite catalyst was observed by scanning electron microscopy (SEM) at $2 0  { \mathrm { ~ \textrm ~ { ~ ~ } ~ } }  { \mathrm { \mathrm { k V } } }$ . Transmission electron microscopy (TEM) was conducted on a FEI Tecnai F20 transmission electron microscope at an acceleration voltage of $2 0 0 \ \mathrm { k V }$ . The crystal structure, composition and lattice constant of catalysts were measured on a Rigaku D/MAX III-3B X-ray diffractometer (XRD) with Cu ka $\lambda ~ = ~ 0 . 1 5 4 1 8 \ \mathrm { \ n m } )$ radiation. And the accelerating voltage and applied current were held at $4 0 \ \mathrm { k V }$ and $2 0 0 ~ \mathrm { { m A } }$ , respectively. The specific surface area and pore size distribution of samples were measured on an AUTOSORB-1 (Quantachrome Instruments) at $7 7 ~ \mathrm { K }$ . X-ray photoelectron spectroscopy (XPS) analysis of the catalysts obtained were conducted on PHI-5700 ESCA apparatus with an Al $\mathrm { K } \alpha$ X-ray source to explore the elements of the surface, and the binding energies were referenced to adventitious carbon for $2 8 4 . 6 2 \ \mathrm { e V }$ . Lakershore Model 7304 instrument was used to measure the magnetic properties of catalysts. Magnetic measurement was performed at room temperature by using a physical property measurement system (PPMS, $7 3 0 \mathrm { T }$ , LAKESHORE, USA)

# 2.6. Pollutants degradation experiment

As for the organic pollutant degradation tests, RhB was selected to be a typical model contaminant. In each run, a certain amount of catalysts above was added into $5 0 ~ \mathrm { m L }$ of RhB solution $( 1 0 \ \mathrm { m g { \cdot } L ^ { - 1 } } )$ under stirring. The initial $\mathrm { p H }$ value of RhB solution solution was about 5.49 without adjustment. Before to reaction, the suspension was kept in dark for $2 0 \ \mathrm { m i n }$ to ensure the establishment of adsorption/desorption equilibrium between catalysts and rhodamine B. Next, a fixed amount of PS was added to initiate the catalytic reaction. At given time intervals, the collected samples after centrifugation and filtration (through a $0 . 2 2 \mu \mathrm { m }$ membrane) were measured at the characteristic peak of $5 5 0 \ \mathrm { n m }$ by using a T6 ultravioletvisible spectrophotometer.

# 3.6. Degradation performance

# 3.6.1. Activation of PS by $C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 }$ composite for RhB degradation

Fig. 6 exhibited the degradation of RhB under different conditions. As seen from Fig. 6, the catalyst alone did not substantially remove RhB, only $6 . 6 1 \%$ , $2 . 0 9 \%$ and $8 . 0 8 \%$ of RhB was removed by ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite, respectively. The low removal efficiencies might be due to the weak adsorption capacity of these materials. The degradation of RhB in $\mathrm { C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 } / P S }$ system with different PS doses was investigated and exhibitied in Fig. 7a. # 3.6.3. Effect of co-existing ions

In practice, a large amount of salts were usually added in various dyeing processes and might affect the active radical chain reaction in $\mathrm { S O } _ { 4 } ^ { \bullet - }$ based AOP (Li et al., 2015). As shown in Fig. 8, different inorganic anions exhibited different inhibiting effects on the RhB degradation. As seen from Fig. 8a, chloride ion inhibited the degradation of RhB, and the degradation efficiency of RhB decreased with increasing chloride ion concentration. Compared to the case where $\mathrm { C l ^ { - } }$ was not added, only $8 8 . 1 8 \%$ of RhB was degraded in the existence of $4 0 \ \mathrm { m M \ C l ^ { - } }$ . # 3.7. Mechanism analysis

Fig. 10a and b presented the XPS of $\mathrm { C o } \ 2 \mathrm { p }$ and O 1s of the catalysts before and after oxidation process. After PS reacted with $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite, the position of the $\mathrm { C o } \ 2 \mathrm { p }$ peak had a little shift and the area of peaks decreased, indicating that the fraction of $\mathrm { C o } ^ { 2 + } / \mathrm { C o } ^ { 3 + }$ changed after used. From the deconvolution of $\mathrm { C o } ~ 2 \mathrm { p }$ envelop (Fig. 10a), the proportion of ${ \mathrm { C o } } ^ { 2 + }$ dropped from $4 7 . 9 6 \%$ to $4 5 . 2 7 \%$ of Co specie, which implied that the valence state of cobalt increased from $\mathrm { C o } ^ { 2 + }$ to $\bar { \mathrm { C o } ^ { 3 + } }$ due to transferring electrons to PS to generate $\mathrm { S O } _ { 4 } . ^ { - }$ . Fortunately, the binding energy of the two main peaks was basically unchanged, which indicated that the catalyst was well regenerated. In the case of O 1s spectra (Fig. 10b), the $\mathrm { O } _ { \mathrm { a d s } } /$ $\mathrm { O } _ { \mathrm { l a t t } }$ ratio had changed and the proportion of $\mathrm { O } _ { \mathrm { a d s } }$ had increased from $3 1 . 1 7 \%$ to $3 5 . 0 9 \%$ and the proportion of $\mathrm { O } _ { \mathrm { l a t t } }$ reduced from $6 8 . 8 3 \%$ to $6 4 . 9 1 \%$ , indicating that both of them are involved during the degradation process. The increase of $\mathrm { O } _ { \mathrm { a d s } }$ concentration might be ascribed to the formation of Co-OH and Fe-OH groups adsorbed on the $\mathrm { C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 } }$ surface, which might contribute to the enhancement of the PS activation process.

Based on XPS analysis and other findings, the catalytic mechanism of PS activation by $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite was proposed. As shown from Fig. 10c, ${ \mathrm { C o } } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + }$ were main active centers in $\mathrm { C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 } / P S }$ system. Generally speaking, PS could react with ${ \mathrm { C o } } ^ { 2 + }$ and $\mathrm { F e } ^ { 2 + }$ to produce $\mathrm { S O } _ { 4 } \mathrm { . } ^ { - }$ , and simultaneously generate ${ \mathrm { C o } } ^ { 3 + }$ and $\mathrm { F e } ^ { 3 + }$ (reaction (13) and (14)). In addition, the conduction band of $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ was more negative than the $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ . When $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ combined with ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , the heterojunction was rapidly formed and electrons were more easily transferred from ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ to $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ which promoted the regeneration of ${ \mathrm { C o } } ^ { 2 + }$ (reaction (15)), which was consistent with the XPS analysis. However, due to the transfer of electron from ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ to $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , only a few portion of $\mathrm { F e } ^ { 3 + }$ could be converted to $\mathrm { F e } ^ { 2 + }$ to activate PS (reaction (16)). Fortunately, $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - }$ could produce ${ \mathrm { H S O } } _ { 5 } ^ { - }$ by hydrolysis under acidic condition, therefore ${ \mathrm { C o } } ^ { 3 + }$ and $\mathrm { F e } ^ { 3 + }$ could react with $\mathrm { H S O } _ { 5 } ^ { - }$ to achieve the regeneration of ${ \mathrm { C o } } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + }$ (reactions (17), (18) and (19)). In addition, $\mathrm { { S O } _ { 4 } . \mathrm { { ^ - } } }$ could also react with $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ to produce HO (reaction (20)). # 3.8. Stability of the catalyst

The repeatability and stability of catalysts are key factors in actual application of persulfate activation. In this study, the recycling experiment was conducted by the sample recovery method of centrifugation and drying. Fig. 11a exhibited the RhB removal in successive four cycles with recycled $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } /$ $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ composite. It was clearly that the $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite maintained its performance among the four cycles. $\mathrm { C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 } }$ composite catalyst could still degrade $8 5 . 4 9 \%$ RhB after 4 cycles. In addition, we tested the XRD pattern of the fresh and used $\mathrm { C o _ { 3 } O _ { 4 } } / \mathrm { C o F e _ { 2 } O _ { 4 } }$ composite, which were exhibited in Fig. 11b. Obviously, the used $\mathrm { C o _ { 3 } O _ { 4 } / C o F e _ { 2 } O _ { 4 } }$ composite maintained the stable crystal structure without phase transition. These indicated that the $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } /$ $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 }$ composite catalyst as-prepared had a good practical potential, which could provide the possibility of practical application in future.

# 4. Conclusion

In the present study, a novel magnetic catalyst was synthesized, which was applied for PMS activation to achieve effective RhB degradation. It was found that the degradation of RhB was highly pH-dependent with a higher degradation efficiency near the weakly acidic $\mathrm { p H }$ . The maximum degradation efficiency was obtained at $\mathrm { p H }$ of 5, where $9 6 . 0 5 \%$ of RhB was removed (the persulfate concentration of $0 . 5 \ \mathrm { g } { \bullet } \mathrm { L } ^ { - 1 }$ , catalyst dosage of $0 . 5 \ \mathrm { g } { \cdot } \mathrm { L } ^ { - 1 }$ and reaction temperature of $2 5 ~ ^ { \circ } \mathrm { C } )$ .

What’s more, naturally occurring species $( \mathbf { C l } ^ { - }$ , $\mathrm { N O } _ { 3 } ^ { - }$ and $\mathrm { H C O } _ { 3 } ^ { - }$ ) exhibited inhibitory effects on RhB degradation, especially at higher concentrations.
