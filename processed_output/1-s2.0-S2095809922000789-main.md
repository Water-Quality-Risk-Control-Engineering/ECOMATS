# a b s t r a c t

$I n$ -situ photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production has been receiving increasing attention in recent years for sustainable $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ synthesis. Graphitic carbon nitride $\left( \bf { g } { - } \bf { C } _ { 3 } \mathbf { N } _ { 4 } \right)$ is regarded as one of the most promising semiconductor photocatalysts for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution. Introducing N defects in ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ has been proved to be an effective strategy to enhance photocatalytic activity. However, the photocatalytic mechanism of the N vacancies is ambiguous and different types of N vacancies in ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ may exhibit different effects on photocatalytic activity. Herein, we develop a facile sodium persulfate eutectic polymerization method to prepare the ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ with abundant three coordinate nitrogen $( \mathsf { N } 3 _ { \mathsf { C } } )$ vacancies. This type of nitrogen vacancy has not been studied in ${ \bf g } – { \bf C } _ { 3 } { \bf N } _ { 4 }$ for photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production. Our results show that the introduction of $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies in the ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ successfully broadens the light absorption range, and inhibits the photoexcited charge recombination with enhanced $0 _ { 2 }$ adsorption to promote oxygen activation. The photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution from the $\mathsf { N } 3 _ { \mathsf { C } }$ -rich ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ is 4.5 times higher than that of the pristine ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ . This study demonstrates a novel strategy to introduce $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies in ${ \bf g } { - } { \bf C } _ { 3 } { \bf N } _ { 4 } ,$ , which offers a new method to develop active catalysts for photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution.

# 1. Introduction

Hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ is one of the most valuable chemicals in pharmaceutical, chemical, food, and environmental industries [1–3]. It is a potential oxidant for carbonaceous fuels in electricity generation [4]. The traditional large-scale production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ relies on the energy-intensive anthraquinone method [5]. The sustainable in-situ production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ can significantly reduce the production, storage, and transportation costs with minimized safety risks [6]. Recently, sunlight-driven $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation using suitable photocatalysts has become a research hotspot [7,8]. Various photocatalysts including metal oxides $\mathrm { T i O } _ { 2 }$ and ${ \tt B i V O } _ { 4 }$ ) [9,10], metal–organic materials (MOMs) [11], metal-free polymers [12], and graphitic carbon nitride $\left( { \bf g - C } _ { 3 } \mathbf { N } _ { 4 } \right)$ have been studied for the photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production [13,14]. Among those semiconductors, $\mathrm { g - C _ { 3 } N _ { 4 } }$ is considered a promising photocatalyst owing to the merits of suitable bandgap structure, good thermal and chemical stability, low cost with facile production process [15–18].

However, pristine $\mathrm { g - C _ { 3 } N _ { 4 } }$ only offers a limited visible-light absorption range. It suffers from rapid charge recombination and low charge carrier mobility with a poor selectivity towards the twoelectron $( 2 \mathsf { e } ^ { - } )$ reaction pathway. Therefore, further enhancement of the photocatalytic activity of $\mathrm { g - C _ { 3 } N _ { 4 } }$ in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production becomes a hot research topic in recent years.

Introducing defects (nitrogen and carbon vacancies) in $\mathrm { g - C _ { 3 } N _ { 4 } }$ was reported to be effective in enhancing photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production [19,20]. Specifically, N vacancies engineering in $\mathrm { g - C _ { 3 } N _ { 4 } }$ can not only adjust the bandgap structures for harnessing more visible light but also increase the surface energy to promote active sites for oxygen reduction [21]. For instance, with KOH-assisted polymerization of the nitrogen-rich precursors, nitrogen defects and the cyano group were introduced into the $\mathrm { g - C _ { 3 } N _ { 4 } }$ to control the band structure. As the electron-withdrawing groups, nitrogen defects, and cyano groups could improve the charge transportation to delivery charges to the surface terminal sites [22,23]. In addition to KOH, other K or Na salts have also been used to modify ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ to enhance the production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ via two specific mechanisms, that is, modifying the pre-synthesized $\mathrm { g - C _ { 3 } N _ { 4 } }$ or participating in the molten polymerization synthesis of $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ [24–28]. The advantages of the alkali-assisted modification method can be summarized as follows: $\textcircled{1}$ The generated N vacancies inhibit the charge recombination; $\textcircled{2}$ the coexistence of cyano groups and N vacancies affects the bandgap of $\mathrm { g - C _ { 3 } N _ { 4 } }$ ; $\textcircled{3}$ introduction of alkali metal dopants broadens the light absorption range; and $\textcircled{4}$ the incorporation of multiple hetero-elements (O, S, P) into the polymeric CN matrix enhances the charge transfer properties. Although this method can introduce N vacancies in $\mathrm { g - C _ { 3 } N _ { 4 } }$ , the formation and identification of nitrogen defects have not received enough attention. Moreover, different types of N vacancies produced in this method may exhibit different photocatalytic performances. Recently, $\mathrm { g - C _ { 3 } N _ { 4 } }$ containing two types of $_ \mathrm { N }$ vacancies $\mathrm { N H } _ { x }$ and $\mathsf { N } 2 _ { \mathsf { C } } )$ has been reported, where $\mathrm { N H } _ { x }$ promotes the photoexcited charge separation and ${ \mathsf { N } } 2 _ { \mathsf { C } }$ is responsible for the oxygen activation [29]. ${ \mathsf { N } } 3 _ { \mathsf { C } }$ vacancy is another type of N vacancy that has been reported in photocatalytic $\mathsf { N O } _ { x }$ reduction and $\mathrm { H } _ { 2 }$ production [30,31], which has yet been studied in photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production.

Herein, we designed a one-step sodium persulfate (PDS)- assisted molten polymerization method to produce $\mathrm { g - C _ { 3 } N _ { 4 } }$ with $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies. The effects of N vacancies and defects in ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ in photocatalysis were characterized by investigating the light absorption performance, charge transfer properties, and the selective two-electron pathway. Importantly, the process and mechanism of PDS-induced formation of $\mathsf { N 3 } _ { \mathsf { C } }$ vacancy during the polymerization process were also elucidated. The $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution study showed that $\mathrm { g - C _ { 3 } N _ { 4 } }$ with the highest amount of $\mathsf { N } 3 _ { \mathsf { C } }$ offered the best $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution activity, which is 4.5 times higher than that of the pristine $\mathrm { g - C _ { 3 } N _ { 4 } }$ . To the best of our knowledge, this is the first time to identify the role of the $\mathsf { N } 3 _ { \mathsf { C } }$ vacancy in ${ \tt g } { - } { \sf C } _ { 3 } { \sf N } _ { 4 }$ for promoting the photocatalytic production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . The reported sodium persulfate-assisted synthetic method provides a novel strategy to customize $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies in $\mathrm { g - C _ { 3 } N _ { 4 } }$ and has significant implications for developing photocatalysts for other applications.

# 2. Experimental

# 2.1. Chemicals

Sodium persulfate $\mathrm { \Delta } ^ { \prime } \mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ , $9 9 . 0 \%$ and $p$ -Benzoquinone $p$ -BQ, $9 9 . 0 \% )$ were purchased from Aladdin Chemistry Co., China. Melamine, ethanol (analytical reagent (AR), $9 5 . 0 \%$ , and sodium sulfate $\left( \mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 } \right)$ were supplied by Macklin Biochemical Co., Ltd. (China). Ethanol $( 9 9 . 5 \% )$ and potassium iodide (KI) were obtained from Sinopharm Chemical Reagent Co., Ltd. (China). Methanol (MeOH, high performance liquid chromatography (HPLC)) and isopropanol (IPA, HPLC) were bought from Anpel Laboratory Technologies Inc., China. Ultrapure water $( 1 8 . 2 ~ \mathrm { M } \Omega { \cdot } \mathrm { c m } ^ { - 1 }$ ) produced from Milli- $\mathbf { \nabla } \cdot \mathbf { Q }$ System was used in all experiments.

# 2.2. Preparation of the catalysts

Before the synthesis, $_ { 1 0 \mathrm { ~ g ~ } }$ melamine was mixed with $0 . 3 3 \mathrm { ~ m o l }$ ${ \Nu } _ { { \bf { d } } _ { 2 } } { \cal S } _ { 2 } { \cal O } _ { 8 }$ followed by grounding for $3 0 ~ \mathrm { { m i n } }$ to form a uniform precursor. This mixture was heated to $5 5 0 ~ ^ { \circ } C$ in an Ar atmosphere at a heating rate of $5 \mathrm { ~ } ^ { \circ } \mathsf { C } { \cdot } \mathsf { m i n } ^ { - 1 }$ and kept for $^ { 2 \mathrm { ~ h ~ } }$ . The obtained solid was ground and washed with ultrapure water before being dried at $6 0 ~ ^ { \circ } \mathrm { C } .$ . The obtained sample was named sodium persulfate doped ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ (SPCN). The sodium sulfate doped $\mathrm { g - C _ { 3 } N _ { 4 } }$ (SSCN) was prepared by the same method with $_ { 1 0 \mathrm { ~ g ~ } }$ melamine mixed with $0 . 3 3 \mathrm { ~ m o l }$ of sodium sulfate $( \mathsf { N a } _ { 2 } \mathsf { S O } _ { 4 } )$ . The pristine ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ (CN) was prepared by the same method with only melamine as the precursor.

# 2.3. Characterizations

X-ray diffraction (XRD) patterns were collected on a Bruker D8- Advanced X diffractometer (Germany) with $_ \mathrm { C u - K @ ~ }$ radiation. Fourier transform infrared spectroscopy (FTIR) spectra were acquired on a Nicolet 380 spectrometer (USA). The microstructure of the samples was characterized using a scanning electron microscope (SEM; Hitachi S-4800, Japan). X-ray photoelectron spectroscopy (XPS) study was conducted by a Thermo Scientific K-Alpha spectroscope (USA). Thermogravimetry analysis (TGA) was measured on an FEI Themis Z (USA), and the sample was heated at a rate of $1 0 \ ^ { \circ } \mathsf { C } { \cdot } \mathsf { m i n } ^ { - 1 }$ up to $5 5 0 ~ ^ { \circ } C$ under Ar atmosphere $( 3 0 \mathrm { \ m L } { \cdot } \mathrm { m i n } ^ { - 1 }$ ). Ultraviolet–visible diffuse reflectance spectra (UV–vis DRS) were collected on a UV-2450 spectrophotometer (Shimadzu, Japan) equipped with an integrating sphere with $\mathtt { B a S O _ { 4 } }$ as the reference. The ${ { 0 } _ { 2 } }$ temperature-programmed desorption (TPD) measurement was performed on a Thermo Scientific ESCALAB $\mathrm { X I ^ { + } }$ . Electron paramagnetic resonance (EPR; Bruker $_ { A 3 0 0 - 1 0 / 1 2 } )$ was performed to detect the nitrogen vacancy. The photoluminescence (PL) emission spectra were obtained on a Hitachi F-7000 fluorescence spectrophotometer at an excitation wavelength of $3 5 5 ~ \mathrm { { n m } }$ . The zeta potentials of the prepared samples were measured by a Zetasizer Nano ZS90 analyzer (China). The setup of a photoelectrochemical reactor is shown in Text S1 in Appendix A.

# 2.4. Photocatalytic $H _ { 2 } O _ { 2 }$ evolution

$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution tests were conducted in a photocatalytic reactor. Typically, $2 5 \mathrm { m g }$ photocatalyst was dispersed into $5 0 ~ \mathrm { m L }$ of isopropanol $J \mathrm { H } _ { 2 } 0$ mixture $( 1 0 / 9 0 , \mathrm { v / v ) }$ . The suspension was stirred and ultrasonicated for $5 \mathrm { \ m i n }$ . A 300 W white-light light emitting diode (LED; CEL-PE300-4A; AuLight, China) with a $4 2 0 ~ \mathrm { { n m } }$ cutoff filter was used as the light source with a light intensity of $1 0 0 \mathrm { m W } { \cdot } \mathrm { c m } ^ { - 2 }$ (at the upper surface of the solution). During the reaction, the solution was stirred continuously without pumping in $0 _ { 2 }$ . The solution was sampled every $1 0 \ \mathrm { m i n }$ , which was filtered using a $0 . 2 2 ~ { \mu \mathrm { m } }$ Millipore filter. The concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was determined by iodometric titration with a UV–vis spectrophotometer (see details in Fig. S1 in Appendix A) [32].

The improved thermal stability may be due to the synergistic effect of electrostatic and hydrogen bonding interaction between the O–O $( \Nu { \bf a } _ { 2 } S 0 _ { 3 } – 0 – 0 – 5 0 _ { 3 } )$ ) bond and $\mathrm { - N H } _ { 2 }$ groups of melamine [36,37]. The rapid weight loss peak appeared at the temperature between 210 and $3 1 8 ^ { \circ } \mathrm { C } ,$ associated with the deamination, sublimation, and thermal condensation of melamine [38]. Among them, melamine doped by persulfate showed the least weight loss due to the aforementioned synergistic stabilization effect inhibiting the release of $\mathrm { N H } _ { 3 }$ and the degree of condensation. Meanwhile, melamine doped by sodium sulfate showed less weight loss than pure melamine. Additionally, eutectic Na salts could improve the mass transport of the reactants and achieve a more uniformly distributed dopant in carbon nitride [24]. Notably, there is another weight loss peak at a higher temperature of $4 1 2 ^ { \circ } \mathrm { C }$ only in the persulfate doped melamine sample, implying a further polymerization to generate small molecule fragments containing oxygen and nitrogen. Compared with the typical phase formation from melamine to ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ this process forms more cyano and nitrogen vacancies.

Solid-state $^ { 1 3 } \mathsf { C }$ nuclear magnetic resonance (NMR) spectroscopy of SPCN showed two dominant peaks at 156.4 and 164.5 parts per million (ppm), which corresponds to the chemical shifts of C2N– $\mathrm { N H } _ { x }$ (peak 2) and C3N (peak 1) in the heptazine units, respectively (Fig. 2(b)). This phenomenon indicates that the PDS-assisted eutectic polymerization process does not alter the main heptazine core structure [26]. Notably, a broad peak at 115.8 ppm assigned to the aromatic pyridine carbon species (peak 3) in the CN framework was observed, implying the formation of $\mathsf { N } 3 _ { \mathsf { C } }$ vacancies [39]. Solidstate EPR spectra were collected to investigate the electronic band structure of nitrogen vacancies. As shown in Fig. 2(c), the Lorentz signal with $g = 2 . 0 0 3$ was recorded for all three samples, which is assigned to the unpaired electrons of the $\mathsf { s p } ^ { 2 }$ hybridized carbon atoms on the $\pi$ -conjugated planes of $\mathrm { g - C _ { 3 } N _ { 4 } }$ . The higher intensity in the EPR signal represents more unpaired electrons, associated with the higher population of nitrogen vacancies introduced by the thermal eutectic persulfate treatment [40]. Combining the EPR the XPS results, $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies were mainly introduced in SPCN. In this regard, a higher number of unpaired electrons can facilitate the photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution reaction [41].

The zeta-potential analysis was used to further understand the surface properties of the catalysts. As shown in Fig. S4 in Appendix A, CN exhibits the zero-point charge $\mathrm { ( p H _ { Z P C } ) }$ at $\mathsf { p H } 3$ . In contrast, the SSCN and the SPCN surfaces were negatively charged over the entire pH range from 2 to 9. This result indicates the electron-withdrawing ability of SPCN was enhanced due to the strong electronegativity of the N atoms in the $\mathsf { C } \equiv \mathsf { N }$ and/or unsaturated C atoms surrounding the $\mathsf { N 3 } _ { \mathsf { C } }$ defects [35,42]. SPCN showed a slightly positive zeta potential than SSCN at the same pH. Based on the element component analysis (Table S1), it can be inferred that the presence of positively charged ${ \ N } { \bf { a } } ^ { + }$ ions partially counteracted the negative charges on SPCN [43]. The more negatively charged surface of the photocatalyst can enhance the adsorption of $0 _ { 2 }$ , which could subsequently react with $\mathrm { H } ^ { + }$ to produce $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [44].

The schematic illustration of the persulfate-induced surface modification during the synthesis of SPCN is shown in Fig. 2(d). At the first step of polymerization, the released N component was oxidized by the low eutectic salt sodium sulfite salt. In the second step, the oxygen species in the $\mathrm { g - C _ { 3 } N _ { 4 } }$ framework were released to form sodium sulfate. As a consequence, this process generates more defects in SPCN compared to that in SSCN. As shown in Figs. 1(e) and (f), the potential reaction sites (green parts) on the pure CN can be converted into N defects (red parts) following the molten salt eutectic reaction. By summarizing the above observations, the presence of persulfate during the synthesis of ${ \bf g } { - } \mathsf { C } _ { 3 } \mathsf { N } _ { 4 }$ produced more active sites in the form of $\mathsf { N } 3 _ { \mathsf { C } }$ vacancies and cyano groups for photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution.

# 3.3. Band structure and optical properties

The light absorption properties are critical to photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production performance. The UV–vis DRS absorption spectra in Fig. 3(a) show that the catalysts had good absorption in the visible region. Compared with CN, the adsorption edges of both the SPCN and the SSCN are redshifted, indicating improved visible light absorption. The broad increase of the absorption in the long wavelength by SSCN and SPCN indicates the more homogeneous distribution of N defects [22]. SPCN shows the highest absorption in the visible region, which is associated with its highest density of defects. Bandgap energy $\left( E _ { \mathrm { g } } \right)$ of the samples was calculated using the Kubelka–Munk function (see details in Text S2 in Appendix A) based on the UV–vis DRS data [45]. The results show that the light-harvesting abilities were enhanced from the SSCN and the SPCN in comparison with the pristine CN due to the high population of N defects and cyano groups introduced during the thermal polymerization of melamine with the presence of eutectic sodium salt.

To identify the band edges of the catalysts, the work function and the valence band (VB) of the catalyst were determined by ultraviolet photoelectron spectroscopy (UPS) (Fig. 3(b) and Fig. S5 in Appendix A). The cut-off binding energy $\left( E _ { \mathsf { C } } \right)$ of all samples was determined as $1 6 . 4 0 \ \mathrm { e V } .$ . Then, the work function $( \phi )$ of the catalysts was calculated as $4 . 8 2 \ \mathrm { e V }$ by $E _ { \mathrm { H e - I } } \ - \ E _ { \mathrm { C } } ,$ where $E _ { \mathrm { H e - l } }$ (He–I photoelectron energy) is the photon energy $( 2 1 . 2 2 \ \mathrm { ~ e V } )$ [46]. The energy of VB $\left( E _ { \mathsf { V B } } \right)$ of SPCN was determined to be $6 . 3 3 \mathrm { e V }$ (vs vacuum) by $\phi + E _ { \mathrm { V B / H O M O } }$ (HOMO: the highest occupied molecular orbital). With the $E _ { \mathrm { g } }$ from the DRS results, the position of the conduction band (CB) of SPCN was calculated to be $3 . 6 8 \ \mathrm { e V }$ by $E _ { \mathrm { V B } } - E _ { \mathrm { g } }$ . Finally, the $E _ { \mathsf { V B } }$ and $E _ { \mathrm { C B } }$ of CN, SSCN, and SPCN were converted to the electrochemical potentials with respect to reversible hydrogen electrode (RHE) $( - 4 . 4 4 ~ \mathrm { e V }$ vs vacuum) [47]. The band alignments of the catalysts are shown in Fig. 3(c).

As shown in the photoluminescence (PL) spectra (Fig. 3(d)), the major peak around $4 6 5 ~ \mathrm { { n m } }$ is ascribed to the band–band recombination of photogenerated carriers. The fluorescence intensity of this peak is in the order of $\mathrm { C N } > \mathrm { S S C N } > \mathrm { S P C N }$ , which implies that the charge separation ability was improved with the sodium salts modification. It is also found that this peak was redshifted for the SPCN sample, associated with the reduction of the bandgap energy, which is consistent with the DRS results [44,48]. Moreover, as shown in Fig. 3(e), the decreased electrochemical impedance spectroscopy (EIS) slop of SPCN also reflects the improved charge migration rate and the reduced electric transferring resistance, which benefits the photoelectric activity [49]. Considering the above facts, this enhancement is attributed to the improved charge-trapping offered by the defect sites of cyano groups and N vacancies.

To further investigate the influence of N vacancies on photocatalytic performance, the transient photocurrent responses were obtained, which represented the efficiency of using the photogenerated electrons and holes in the redox reactions. Considering the aforementioned results of light-harvesting capability and charge separation efficiency, the order of photoelectric activity is as follows: $\mathrm { S P C N } > \mathrm { S S C N } > \mathrm { C N } .$ . The stable photocurrent density of SPCN (plateau: $0 . 3 1 5 \ \mu \mathrm { A } { \cdot } \mathrm { c m } ^ { - 2 } ,$ ) under visible light irradiation is 1.56- and 3.12-fold higher than that of SSCN and CN, respectively (Fig. 3(f)). Therefore, the introduction of $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies is beneficial to the charge separation of $\mathrm { g - C _ { 3 } N _ { 4 } }$ . Due to the presence of extra electrons in the nitrogen-deficient sites on the catalyst, it is easier to trap the photoinduced holes, which leads to the reduced spatial separation of the photoinduced carriers [50] (details of electrochemical and photoelectrochemical tests are shown in Text S3 in Appendix A).

# 3.4. Photocatalytic activity for $H _ { 2 } O _ { 2 }$ generation

Fig. 4(a) shows that the production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ increased linearly with time by different catalysts under visible light irradiation $( \lambda \ge 4 2 0 ~ \mathrm { n m } .$ ). SPCN exhibits the highest photocatalytic activity $( 3 2 3 . 6 ~ \mathrm { \textmu m o l { } { \cdot } L ^ { - 1 } { \cdot } h ^ { - 1 } { \cdot } g ^ { - 1 } } )$ among the three catalysts. Comparatively, the production rate of SPCN was calculated to be $1 6 1 . 8 \ \mu \mathrm { m o l } . \mathrm { L } ^ { - 1 } { \cdot } \mathrm { h } ^ { - 1 }$ which is about 4.5-fold higher than that of CN. Compared with the performance of other CN-based photocatalysts in the literature (Table S2 in Appendix A), SPCN shows an outstanding photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation rate. The produced $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ can also be effectively activated by carbon nitride under visible light irradiation to generate hydroxyl radicals ( OH) [21]. Hence, the overall $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production rate represents the dynamic competition between the rates of formation $( k _ { \mathrm { f } } , \ \mu \mathrm { m o l . L ^ { - 1 } { \cdot } m i n ^ { - 1 } } )$ ) and decomposition $( k _ { \mathrm { d } } , \ \operatorname* { m i n } ^ { - 1 } )$ . The rate constants of $k _ { \mathrm { f } }$ (zero-order kinetics) and $k _ { \mathrm { d } }$ (first-order kinetics) were calculated by fitting the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution data shown in Fig. S6(a) in Appendix A into the formula ${ { t } }$ represents the irradiation accumulation time) :

$$
[ \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ] = ( k _ { \mathrm { f } } / k _ { \mathrm { d } } ) / [ 1 - \mathrm { e x p } ( k _ { \mathrm { d } } t ) ]
$$

As shown in Fig. S6(b) in Appendix A, the $k _ { \mathrm { f } }$ and $k _ { \mathrm { d } }$ of SPCN were $3 . 0 5 \mu \mathrm { m o l } { \cdot } \mathrm { L } ^ { - 1 } { \cdot } \mathrm { m i n } ^ { - 1 }$ and $0 . 0 0 4 3 \ \mathrm { m i n } ^ { - 1 }$ , respectively. Interestingly, SPCN exhibited the lowest $k _ { \mathrm { d } }$ value, implying that the decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was hindered. This is possibly due to the improvement in the band edge positions of SPCN. The photoexcited electrons in the conduction band were not negative enough to cause the fast decomposition of the generated $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , described in Eq. (2).

$$
\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { e } ^ { - } {  } ^ { \cdot } \mathrm { O H } + \mathrm { O H } ^ { - }
$$

From Fig. 4(b), the effects of oxygen on $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production were studied. The $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ yield was suppressed from $1 6 1 . 8 ~ { \mu \mathrm { m o l . L } } ^ { - 1 } { \cdot } \mathrm { h } ^ { - 1 }$ in the air to $5 2 . 7 ~ \mu \mathrm { m o l } . \mathrm { L } ^ { - 1 } { \cdot } \mathrm { h } ^ { - 1 }$ in the argon environment. In contrast, the production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ increases to $1 9 4 . 7 \ \mu \mathrm { m o l . L } ^ { - 1 } \cdot \mathrm { h } ^ { - 1 }$ with pure ${ \bf O } _ { 2 }$ gas purging. Therefore, the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production rate was significantly enhanced under the saturated ${ { 0 } _ { 2 } }$ condition, suggesting that $0 _ { 2 }$ plays a critical positive role in the reaction.

The impact of electron donors on photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production was also investigated. As shown in Fig. S7(a) in Appendix A, the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production performance in the presence of electron donors was in the order of IPA $( 1 6 1 . 8 \ \mathrm { \textmu m o l { } { \cdot } L ^ { - 1 } { \cdot } h ^ { - 1 } ) \ > \ \mathrm { \text M e O H } }$ $( 1 2 2 . 0 ~ \mu \mathrm { m o l . L ^ { - 1 } { \cdot } h ^ { - 1 } } )$ $>$ EtOH ( $1 0 3 . 1 \ \mathrm { \ \ \mu \ m o l . L ^ { - 1 } { \cdot } h ^ { - 1 } } ) \ >$ > deionized (DI) water $\mathrm { ^ { \prime } } 1 0 . 0 \ \mu \mathrm { m o l } { \cdot } \mathrm { L } ^ { - 1 } { \cdot } \mathrm { h } ^ { - 1 } \mathrm { ^ { \prime } }$ . The MeOH and EtOH are typical sacrificial agents, which show similar negative effects on $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production. In contrast, IPA is more conducive to selective $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production than the two aliphatic alcohols. The electron donor can boost $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production, which is in agreement with the results in previous studies [35,51]. In the case of DI water, the water oxidation reaction by photogenerated holes is slow, which leads to the recombination of photogenerated charges. Herein, IPA, as the electron donor, can promote photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production by consuming the photogenerated holes. Besides, the yield of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decreases as the pH value increases from 5 to 7 (Fig. S7(b) in Appendix A). This is because the reduced proton concentration in the solution slows down the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production while increasing the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition rate [52]. The stability and cycle performance of photocatalyst is essential for practical application. As shown in Fig. S8 in Appendix A, SPCN maintains $8 9 . 4 \%$ of the initial $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production performance after four cycles of reaction, confirming the good stability of SPCN for continuous photoproduction of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . We further studied the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production under continuous irradiation for $^ { 7 \mathrm { h } }$ (Fig. $4 ( \mathsfit { c } )$ ), and the SPCN showed a high accumulation of produced $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . The generated $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is stable and its concentration has remained under dark conditions for more than 30 hours, which makes it a promising method of in-situ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation for practical applications.

# 3.5. Reaction pathway of $H _ { 2 } O _ { 2 }$ generation

To study the reaction pathway of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution, the catalytic activities of CN, SSCN, and SPCN for oxygen reduction reaction (ORR) were studied using electrochemical voltammetry. Fig. S9 in Appendix A shows the linear sweep voltammetry (LSV) curves of the catalysts on a rotating disk electrode (RDE). The higher current densities were achieved from the SSCN and SPCN compared with that of CN at the same rotating speed, which suggests a higher cathodic ORR performance [4]. Based on the voltammetry results, the corresponding Koutecky–Levich (K–L) plots are obtained (Fig. 5(a)). The electron transfer numbers $( n )$ of CN, SSCN, and SPCN, extracted from the slopes via the $_ { \mathrm { K - L } }$ analysis, are 1.41, 1.54, and 1.58, respectively. These values indicated that the oxygen reduction reactions on the catalysts have a mixed one- and twoelectron pathways [53]. Among them, SPCN shows the highest n value, indicating the highest selectivity toward two-electron transfer for the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution. The one- and two-electron reactions can be specifically expressed as:

One-electron reaction:

The $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ evolution reaction involves oxygen, proton, and photoexcited electron, as described in Reaction (4) [2]. For the oneelectron oxygen reduction, ${ \bf O } _ { 2 }$ took an electron to produce $\cdot { \bf O } _ { 2 } ^ { - }$ Then, the $\cdot { \bf O } _ { 2 } ^ { - }$ combines another electron and two protons to convert to $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . To identify this photocatalytic ${ \bf O } _ { 2 }$ reduction process, $p { \mathrm { - } } \mathtt { B Q }$ and ${ \sf A g N O } _ { 3 }$ were used as the chemical quenching agents to scavenge ${ \mathrm { O } } _ { 2 } ^ { - }$ and $\mathtt { e } ^ { - }$ , respectively [12]. Fig. S10 in Appendix A shows that when $p$ -BQ or ${ \sf A g N O } _ { 3 }$ were added into the photocatalytic reaction, the generation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was completely suppressed.

The characteristic EPR signals of 5,5-dimethyl-1-pyrroline $N \cdot$ - oxide $( \mathsf { D M P O } )  – \cdot 0 _ { 2 } ^ { - }$ were collected from SPCN as photocatalyst under visible light irradiation, shown in Fig. 5(b). The results suggest that ${ { 0 } _ { 2 } }$ was reduced to $\cdot { 0 } _ { 2 } ^ { - }$ via photoexcited electrons and $\cdot 0 _ { 2 } ^ { - }$ is the indispensable intermediate for photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation [54]. On the other hand, SPCN and SSCN have higher negative zeta potentials compared with CN, suggesting the higher adsorption capacity of $\mathrm { H } ^ { + }$ which also promotes the generation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Although SPCN exhibited a slightly positive zeta potential than SSCN at the same $\mathsf { p H }$ , the electron transfer number $( n )$ of SPCN was higher than that of SSCN, indicating that $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies in SPCN dominated the contribution to the higher activity for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation. Moreover, the oxygen adsorption capacity of the catalysts was evaluated by $0 _ { 2 }$ -TPD experiments (Fig. S11 in Appendix A). The physisorption of $0 _ { 2 }$ is important in the initial stage of ORR. The TPD results show that SPCN has the highest physical $0 _ { 2 }$ adsorption capacity $( < 2 0 0 ^ { \circ } \mathrm { C } )$ [55], which is because ${ \bf O } _ { 2 }$ is more likely to be adsorbed on the C sites near the $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies [31].

Based on the above analysis, we propose a reaction pathway for the production of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ by SPCN in Fig. 5(c). At first, ${ \bf O } _ { 2 }$ molecules were adsorbed onto the C sites around N3c vacancies. With the illumination of visible light, SPCN generates electron-hole pairs. Due to the synergistic effect between the N3c vacancies and cyano group, SPCN offered excellent charge separation ability, which enables the efficient reduction of $0 _ { 2 }$ to $\cdot { 0 } _ { 2 } ^ { - }$ . Finally, the $\cdot { \bf O } _ { 2 } ^ { - }$ took another electron and reacted with the adsorbed $\mathrm { H } ^ { + }$ to form $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ .

# 4. Conclusions

In this study, we design a modified polymeric carbon nitride with rich $\mathsf { N } 3 _ { \mathsf { C } }$ vacancies by sodium persulfate eutectic polymerization with melamine. The formation mechanism of nitrogen vacancies and other defects during the co-polymerization process is investigated, in which the $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies are formed by the persulfate-assisted molten polymerization process. The results show that SPCN with a high amount of ${ \mathsf { N } } 3 _ { \mathsf { C } }$ vacancies exhibits enhanced visible light absorption with accelerated photoexcited charge carrier separation compared with the unmodified CN. The SPCN shows excellent photocatalytic kinetic performance with high $k _ { \mathrm { f } }$ $( 3 . 0 5 \ \mu \mathrm { m o l . L ^ { - 1 } { \cdot } m i n ^ { - 1 } } )$ and low $k _ { \mathrm { d } }$ $( 0 . 0 0 4 3 \ \mathrm { \ m i n } ^ { - 1 }$ ) and delivers a 4.5-fold enhancement in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production $( 3 2 3 . 6 ~ \mu \mathrm { m o l . L ^ { - 1 } { \cdot } h ^ { - 1 } { \cdot } g ^ { - 1 } } )$ compared to that of pristine CN. This work reveals insights into the high photocatalytic activity of $\mathsf { N 3 } _ { \mathsf { C } }$ vacancies in photocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation and offers a new perspective for the development of defect engineering in carbon nitride towards various photocatalytic applications.
