Methyl paraben (MP), a widely used preservative, exhibits endocrine-disrupting properties with estrogenic activities. The aqueous phase degradation of MP, using UV-activated persulfate method, was investigated in the present study. The combination of UV irradiation and persulfate anion successfully degraded MP showing $9 8 . 9 \%$ removal within $9 0 \mathrm { { m i n } }$ . A quenching experiment using ethanol (EtOH) and tert-butyl alcohol (TBA) showed the presence of both radicals (OH and $S O _ { 4 } ^ { - }$ ) in the system; near neutral pH $S O _ { 4 } ^ { - }$ radical was the major species. The influence of various factors such as persulfate dose, initial MP concentration, solution pH, and water matrix components on the degradation kinetics was examined in view of the practical applications of the developed process. The degradation rate of MP was considerably increased as the amount of persulfate increased. The degradation of MP in the UV/persulfate system was pH dependent and more promising near neutral pH (6.5) conditions. The presence of anions such as $\mathtt { C l } ^ { - }$ , $\mathrm { H P O } _ { 4 } ^ { 2 - }$ and $\mathrm { H C O } _ { 3 } ^ { - }$ showed inhibitory effect towards MP degradation. The presence of humic acid also suppressed the degradation efficiency of MP. The reaction rate followed pseudo-first-order kinetics for all of the degradations. The degradation of MP by UV/persulfate treatment led to the production of seven transformation byproducts, which were identified using ultra-high-performance liquid chromatography-mass spectrometry (UPLC-MS). A degradation pathway for MP degradation was also proposed. The results of the present study reveal that the UV/persulfate process could be an effective approach to remove MP from aqueous solutions.

# 1. Introduction

Pharmaceuticals and personal care products (PPCPs) pose a potential global threat to drinking water and aquatic ecosystems [1]. Alkyl and aryl esters of para-hydroxybenzoic acid, known as parabens, are a group of PPCPs with activities against yeasts, molds, and bacteria over a wide pH range. These antimicrobial properties of parabens encourage their use in pharmaceuticals, foodstuffs, and cosmetics as preservatives [2], which has led to their presence in approximately $8 0 \%$ of personal care products [3]. Parabens are known as endocrine-disrupting compounds (EDCs) and possess estrogenic activities [2,4]. The U.S. Environmental Protection Agency (USEPA) has classified parabens as emerging environmental contaminants [5]. Despite the restricted threshold limit of these chemicals in cosmetics by the European Union, parabens and their residues have frequently been detected in rivers [6,7], discharges of wastewater treatment plants and even in drinking water [8].

Among parabens, the amounts of methyl paraben (MP) in various cosmetic products are reported to be higher compared to others [4] and have the potential to cause breast cancer [9]. Biodegradation of parabens is likely in natural environments; however, they are characterized by slow reaction rates, which tend to be reduced as the alkyl chain length or degree of chlorination increase [2]. The presence of parabens in the discharge of wastewater treatments plants (WWTPs) indicates their incomplete removal through conventional treatment processes [2,10]. Thus, the development of an effective treatment methodology to eliminate such contaminants is the need of the hour. Advanced oxidation processes (AOPs), which are simple and cost effective, have gained much attention for the decontamination of wastewater containing a variety of refractory organic contaminants [11,12]. AOPs rely on the formation of reactive species, namely hydroxyl (HO ) and sulfate $( S 0 _ { 4 } ^ { - } )$ radicals, which can be used to degrade and mineralize recalcitrant pollutants [13–15]. Photo-assisted AOP processes, such as $\mathrm { U V } / \mathrm { O } _ { 3 }$ , $\mathrm { U V } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , $\mathrm { U V } / \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } ^ { 2 - }$ , and $\mathrm { U V } / \mathrm { T i O } _ { 2 }$ have successfully been used for aqueous phase degradation of organic contaminants [16]. Sulfate radical $( \mathrm { S O } _ { 4 } ^ { - } )$ assisted AOPs are efficient to remove organic contaminants in wastewater treatment and in situ chemical oxidation (ISCO). The $S 0 _ { 4 } ^ { \cdot - }$ radical is considered to be an effective substitute for the HO radical due to its high redox potential $( 2 . 5 { - } 3 . 1 \ V )$ and longer lifetime $\left( 3 - \right.$ $4 \times 1 0 ^ { - 5 } s ^ { , }$ ) [17]. The persulfate anion $( S _ { 2 } 0 _ { 8 } ^ { 2 - } )$ is a strong, aqueous-stable, selective, and cost effective oxidant that operates at a wide pH range (1.2–12) [18,19]. Moreover, the persulfate anion is stable at ambient temperatures and generates $S O _ { 4 } ^ { - }$ radicals by breaking peroxide bonds upon exposure to heat, UV light, bases, transition metals and ultrasound. (Eq. (1)) [20,21]. The sulfate ion is the final product of the $S 0 _ { 4 } ^ { - }$ radical and is considered to be ecofriendly.

$$
\Sigma _ { 2 } \mathsf { O } _ { 8 } ^ { 2 - } + a c t i \nu a t o r \to \mathsf { S O } _ { 4 } ^ { - } + ( \mathsf { S O } _ { 4 } ^ { - } \mathrm { ~ o r ~ } \mathsf { S O } _ { 4 } ^ { 2 - } )
$$

In the recent years, several AOPs have been tested to degrade parabens [22–24]. The degradation of MP has been investigated through several AOPs, such as photo catalysis [25], ozone oxidation [26], electrochemical [27], sonochemical [28], photodegradation processes [29,30] and heat activated persulfate method [31] using hydroxyl ( OH) and sulfate $( \mathrm { S O } _ { 4 } ^ { - } )$ radicals as the main oxidants. However, to the best of the authors’ knowledge, UV/persulfateassisted degradation of methyl paraben has yet to be studied. The objective of this study was to investigate the degradation efficiency of methyl paraben using a UV-activated persulfate method. The effects of different parameters, such as the initial concentration of substrate (MP), persulfate dosage, solution pH, and water matrix components (humic acid and inorganic anions), were studied to explore their potential influence on the degradation kinetics of MP. In addition, the predominant radicals and reaction byproducts obtained after the treatment were identified using LC-MS. A degradation pathway was also proposed.

# 2. Materials and methods

# 2.1. Chemicals

Methyl paraben (purity $9 9 \%$ ), sodium persulfate, sodium thiosulfate, sodium bicarbonate, and humic acid were procured from Sigma-Aldrich (USA). Sodium chloride (NaCl), sodium sulfate $( \mathsf { N a } _ { 2 ^ { - } }$ $S 0 _ { 4 } \mathrm { \cdot }$ ), and tert-butanol were supplied by Junsei Chemicals (Japan), Merck (Germany) and Wako Pure Chemicals (Japan), respectively. Acetonitrile (HPLC grade) was purchased from Thermo Fisher Scientific (USA). All of the chemicals were of analytical reagent grade and were used as received without further purification (or unless otherwise mentioned). Milli-Q-Water was used for preparation of aqueous solutions and the HPLC mobile phase.

# 2.2. Photochemical experiments

Photodegradation experiments were conducted in a benchscale photochemical apparatus (Fig. 1). The apparatus was equipped with a borosilicate glass vessel, a magnetic stirrer, and two low-pressure mercury UV lamps emitting monochromatic light $( 2 5 4 \mathrm { n m } )$ as the irradiation source. Using potassium ferrioxalate actinometry, the photon flux $\left( \mathrm { I } _ { 0 } \right)$ was estimated to be $0 . 4 4 \mu \mathrm { E } s ^ { - 1 }$ [32]. A $1 0 0 \mathrm { m L }$ aqueous solution of MP, in a $2 5 0 – \mathrm { m L }$ - capacity photoreactor, was irradiated at $\mathsf { p H } 6 . 5$ and room temperature. It was then stirred thoroughly to homogenize the reaction solution. After the adjustment of initial $\mathsf { p H }$ of solution (except in the case of anions effect on MP degradation), the desired amount of persulfate was added to the reactor. The reaction was started by holding the reaction vessel under the irradiation region. The persulfate solutions were freshly prepared for each experiment. At specified time intervals, $1 ~ \mathrm { m L }$ aliquots were withdrawn and quenched immediately with a sodium thiosulfate solution (1 M), followed by filtration $0 . 2 0 \mu \mathrm { m }$ syringe filter, Pall Life Sciences, USA). The filtrate was used for HPLC analysis to determine the residual concentrations of MP. The same procedure was followed to study the effects of various parameters on the degradation of MP. The effect of the components of the water matrix was assessed by adding known amounts of anions and humic acid to the solution before the addition of an oxidant. All of the experiments were conducted in duplicate, and the data reported in this paper are the average of duplicate measurements.

# 2.3. Analytical procedures

The residual concentration of MP was determined using highperformance liquid chromatography (HPLC) (Alliance 2695 system, Waters, USA) equipped with a UV–Vis detector (Waters 2487) at $ \lambda = 2 5 6 \ \mathrm { n m }$ using a C18 column $2 5 0 \mathrm { m m } \times 4 . 6 \mathrm { m m }$ , $5 \mu \mathrm { m }$ , Agilent, USA). The injection volume was $2 0 \mu \mathrm { L }$ , and the column temperature was adjusted to $3 0 ^ { \circ } \mathsf C$ An isocratic flow $( 1 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ ) of the mixed solvent (acetonitrile) and Milli-Q water $( 4 0 / 6 0 ; \mathrm { ~ v / v ) }$ was introduced as the mobile phase. The chromatographic data were processed by the Empower2 Program (Waters, USA). The pH of the reaction solutions was measured using a pH meter (Thermo scientific, Orion Star A series, USA). The use of buffer was avoided in all the experiments because common buffer anionic species $( \mathrm { H P O } _ { 4 } ^ { 2 - }$ or $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } ^ { - } ,$ interfere with the degradation rate of compound [33,34]. Solution pH was adjusted using $0 . 1 \mathrm { ~ M ~ }$ HCl and 0.1 M NaOH. The mineralization of MP was determined by analyzing the reduction in total organic carbon (TOC) of the sample over time. The TOC analysis was carried out using a TOC analyzer (TOC-LCPH, Shimadzu, Japan) equipped with an auto sampler.

The degradation byproducts of MP during UV/persulfate treatment were identified using ultra-high-performance liquid chromatography-tandem mass spectrometry (UPLC-MS, Waters Acquity TM UPLC, USA). Chromatographic separation was performed using an Acquity UPLC BEH C18 column (dimensions of $2 . 1 \ \mathrm { m m } \times 5 0 \ \mathrm { m m } \times 1 . 7 \ \mu \mathrm { m } )$ at $3 0 ^ { \circ } \mathrm { C }$ using a mobile phase consisting of acetonitrile (HPLC grade) and Milli- $\mathbf { \nabla } \cdot \mathbf { Q }$ water containing $1 \%$ formic acid and a gradient elution profile with a flow rate at $0 . 2 ~ \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ . Analyses were conducted in negative (ESI-Q1) electro-spray ionization in the mass scanning range of 50–200. The capillary needle voltage and sampling cone voltage were $3 \mathrm { k V }$ and $2 0 \mathrm { V } ,$ respectively. The source temperature was maintained at $1 2 0 ^ { \circ } \mathrm { C }$ (ESI-Q1), and the desolvation gas (nitrogen) flow rate was $6 0 0 \mathrm { L h } ^ { - 1 }$ at $3 0 0 ^ { \circ } \mathsf C$ .

# 3. Results and discussion

# 3.1. Degradation of methyl paraben

To better evaluate the decomposition of MP under UV-activated persulfate system, a pseudo-first-order kinetics model (Eq. (2)) was used to calculate the results of MP degradation.

$$
\ln \left( \frac { [ M P ] } { [ M P ] _ { o } } \right) = - k _ { o b s } t
$$

Here, $[ \mathrm { M P } ] _ { \mathrm { o } }$ is the initial concentration $( \mu \ M )$ of MP, and [MP] is the concentration at any time t (min). $\mathbf { k _ { o b s } }$ is the pseudo-first-order reaction rate constant $( \operatorname* { m i n } ^ { - 1 } )$ ).

The degradation performance of MP under different conditions in aqueous solution is shown in (Fig. 2(a)). The initial experiments were conducted under different conditions to determine the efficiency of different processes for the degradation of MP. The preliminary experiment, carried out in the presence of sole persulfate, showed insignificant removal of MP. It exhibited $1 0 \%$ removal over $9 0 \mathrm { { m i n } }$ with the degradation rate constant of $0 . 0 0 1 \ \mathrm { m i n } ^ { - 1 }$ . Similar outcomes have been reported for the degradation of sulfamethazine using only persulfate [35]. In a separate experimental set up, slow degradation of MP $34 \%$ removal, rate constant$0 . 0 0 5 \mathrm { ~ m i n } ^ { - 1 }$ , within $9 0 \mathrm { { m i n } }$ ) was observed under UV irradiation (without an oxidant); this may be due to the fact that the maximum absorption band of MP occurs at $2 5 6 \mathrm { n m }$ , which is very close to the light emitted by UV-C low-pressure mercury lamps [36]. Alternatively, the combination of UV irradiation and persulfate (UV/persulfate) significantly enhanced the decomposition of MP, indicating the synergistic effect of UV/persulfate on MP degradation; $9 8 . 9 \%$ of MP was removed within $9 0 \mathrm { { m i n } }$ using the UV/persulfate method. The degradation rate constant was found to be $0 . 0 3 9 6 \mathrm { m i n } ^ { - 1 }$ for the UV/persulfate system (optimum condition: $\mathsf { M P } = 3 2 . 8 ~ \mu \mathrm { M } ,$ , persulfate $= 1 ~ \mathrm { m M }$ , $\mathrm { p H } = 6 . 5 $ . The energy consumption for UV/persulfate process was $5 4 . 2 \mathrm { k W h m } ^ { - 3 }$ ; as calculated using a formula given elsewhere [29]. As compared to heat activated persulfate oxidation of methyl paraben, present system was found to be time effcient process [31].

In addition, the UV irradiation and UV/persulfate processes achieved $4 . 8 \%$ and $3 0 . 7 \%$ removal of TOC within $9 0 \mathrm { { m i n } }$ , respectively. When the reaction time was increased to $2 4 0 \mathrm { { m i n } }$ , a proportional increase in TOC removal to $1 1 \%$ and $5 3 \%$ with UV irradiation and UV/persulfate processes, respectively, was observed. Interestingly, insignificant mineralization of MP was observed when only the persulfate oxidation treatment was used. As depicted in Fig. 2(a), the degradation of MP under UV irradiation or UV/persulfate oxidation shows that both direct and indirect photolysis contributed to the removal of MP.

Additional experiments were carried out in the presence of radical scavengers, such as ethanol (EtOH) and tert-butyl alcohol (TBA), to explore the degradation mechanism and identify the predominant reactive species at different pH responsible for the oxidation of MP. Fig. 2(b) shows the effect of quenchers on MP degradation using the UV/persulfate system. As shown, $9 8 . 9 \%$ of MP was removed in the absence of any quenchers. When $1 0 0 \mathrm { m M }$ TBA and EtOH were added into the reaction solution at different pH, the decomposition of MP was suppressed significantly. The removals of MP with EtOH at pH 3, 6.5 and 9 were $5 4 . 3 \%$ , $5 2 . 7 \%$ and $2 8 . 6 \%$ , respectively; whereas TBA removed $8 0 . 2 \% $ . $7 7 . 1 \%$ and $5 9 . 7 \%$ of MP at pH 3, 6.5 and 9, respectively.

The results can be described on the basis of the scavenging properties of ethanol and TBA toward HO and $S 0 _ { 4 } ^ { - }$ radicals. Ethanol, which contains $\pmb { \alpha }$ -hydrogen, scavenges both hydroxyl and sulfate radicals, and the degradation follows second-orderkinetics (rate constants: $1 . 2 – 2 . 8 \times 1 0 ^ { 9 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ for HO and $1 . 6 { - } 7 . 7 \times 1 0 ^ { 7 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ for $S O _ { 4 } ^ { - }$ ) [37,38]. The inhibition caused by EtOH found to be low and similar at $\mathsf { p H } 3$ and 6.5 as compared to that at high pH. In second case, alcohol without $\pmb { \alpha }$ -hydrogen (TBA) scavenges hydroxyl radicals but not sulfate radicals because its rate of scavenging for HO radicals $( 3 . 8 - 7 . 6 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ is about three orders of magnitude higher than that for $S O _ { 4 } ^ { - }$ radicals $( 4 { - } 9 . 1 \times 1 0 ^ { 5 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ [37,39]. TBA slightly suppressed degradation of MP at $\mathsf { p H } 3$ and 6.5; whereas, the inhibitory effect was more pronounced at $\mathsf { p H 9 }$ . These findings suggested that sulfate radical was the predominant species in acidic and neutral conditions and hydroxyl radical as the principal active species at high pH. The presence of hydroxyl radical was due to the reaction of sulfate radical with hydroxyl anion (Eq. (3)). These outcomes are consistent with previous investigations [18,40].

$$
\mathrm { S O _ { 4 } ^ { - } } + \mathrm { O H ^ { - } }  \mathrm { S O _ { 4 } ^ { 2 - } } + \mathrm { O H ^ { - } }
$$

Thus, sulfate radical was the major reactive species in present UV/Persulfate system to degrade MP, particularly at acidic and neutral pH.

# 3.2. Effect of initial persulfate dosage

The amount of oxidant, which serve as a source of reactive radicals, is an important factor in evaluating the efficiency of the oxidation process. The effect of initial persulfate amount $( 0 . 5 \mathrm { m M } - 4 \mathrm { m M }$ ) on the degradation of MP at $\mathsf { p H } 6 . 5$ was investigated. Fig. 3(a) illustrates the pattern of $[ \mathrm { M P } ] / [ \mathrm { M P } ] _ { \mathrm { o } }$ at different persulfate concentrations as a function of reaction time. The degradation of MP followed pseudo-first-order kinetics at all persulfate doses. The degradation efficiency of MP was dependent on persulfate amount; an increase in persulfate significantly enhanced the MP degradation rate, and the observed rate constant $( \mathbf { k _ { o b s } } )$ increased $( 0 . 0 1 5 2 { - } 0 . 1 1 0 \operatorname* { m i n } ^ { - 1 } )$ ) with increasing persulfate dose $( 0 . 5 { - } 4 \mathrm { m M } )$ ). Moreover, Fig. 3(b) also demonstrates a linear relationship between $\mathbf { k _ { 0 } } \mathbf { _ { \mathrm { { o b s } } } }$ and persulfate dosage $( \mathrm { k _ { o b s } } = 0 . 0 2 5 8 \times \mathrm { P S } +$ 0.0075, $\mathrm { R } ^ { 2 } = 0 . 9 8 6 \mathrm { \Omega }$ , which indicates that the degradation rate is closely related with the total amount of oxidants in the solution. A similar trend was reported for carbamazepine (CBZ) and sulfamethazine (SMT) degradation at various persulfate dosages in the UV/persulfate system [35,41]. The improved degradation rate with greater persulfate dosages can be attributed to the formation of more free radicals in the presence of higher concentrations of the oxidant source [42]. Therefore, an excessive amount of persulfate can hinder MP oxidation, because of self-scavenging of $S O _ { 4 } ^ { - }$ radicals (Eq. (4)) [40,43]. # 3.3. Effect of initial MP concentration

The effect of initial concentration of MP $1 9 . 9 \substack { - 6 5 . 7 \mu \mathrm { M } } ,$ on its degradation kinetics was evaluated (Fig. 4(a)). The degradation rates of MP followed pseudo-first-order kinetics at all of the tested initial concentrations. An increase in the initial concentration of MP (from 19.9 to $6 5 . 7 \mu \mathrm { M } \dot { }$ ) induced a decrease in the degradation rate; the degradation rate constant decreased from 0.0781 to $0 . 0 1 0 4 \mathrm { m i n } ^ { - 1 }$ .

The cause of this phenomenon is that a certain amount of sulfate radicals is produced at fixed persulfate dosage and UV irradiation intensity. As the amount of MP increased, most of the UV radiation was absorbed by MP and its transformation products, thereby inhibiting the absorption of UV radiation by persulfate molecules and subsequently forming $S 0 _ { 4 } ^ { - }$ radicals via photoreaction [44]. In contrast to the effect of initial persulfate dosage, the degradation rate constant displays an exponential trend as a function of MP concentration $( \mathrm { k _ { o b s } = 0 . 1 5 2 \ [ M P ] _ { o } ^ { - 0 . 2 7 6 } }$ , $\mathsf { R } ^ { 2 } = 0 . 9 9 0 \mathrm { \Omega } ,$ as depicted in Fig. 4(b). Similar observations for the degradation of carbamazepine and mineralization of sucralose under UV/persulfate treatment have been reported [41,45].

# 3.4. Effect of $p H$ variation

The acidity and alkalinity often influence the photoreaction rate of a molecule due to electronic distribution differences in the molecule. To evaluate these effects, the photo-degradation experiment of MP was carried out at different pH ranging from 3 to 11. Fig. 5(a) shows the effect of initial solution pH on the decomposition of MP. The initial $\mathsf { p H }$ of solution was adjusted by $0 . 1 \mathrm { ~ M ~ }$ NaOH and $0 . 1 \mathrm { ~ M ~ H C l }$ to avoid the use of buffer. It is well reported that phosphate buffer inhibits the reactivity of sulfate and hydroxyl radicals [34]. A significant decrease in solution pH was observed after the completion of reaction. The degradation rate of MP in the UV/persulfate system was pH dependent and found to be highest near neutral conditions $\mathrm { \ D H } = 6 . 5$ , $9 8 . 9 \%$ degradation, and $\mathrm { k _ { \mathrm { o b s } } = 0 . 0 3 9 6 \ m i n ^ { - 1 } } ;$ ). A decrease in pH did not show any noticeable change in degradation; MP removal rate of $9 7 . 7 \%$ and a rate constant value of $0 . 0 3 4 9 \mathrm { m i n } ^ { - 1 }$ were observed at $\mathsf { p H } 3$ , which were very close to the values observed at $\mathsf { p H } 6 . 5$ . Moreover, as the pH increased from 6.5 to 9 and 11, the MP degradation rate constant decreased from 0.0396 to 0.0222 and $0 . 0 1 4 7 \mathrm { m i n } ^ { - 1 }$ , respectively. These results are in agreement with previous studies that investigated the degradation of, trichloroethylene and anatoxin-a in heat activated persulfate and UV/PMS systems, respectively [18,46].

The concentration of generated radicals and speciation of the oxidizing moiety depend on the pH in the UV/persulfate oxidation system. Due to the lower activation energy of sulfate radicals at neutral pH [18], their concentration would be at the maximum level. The higher degradation rate of MP at $\mathsf { p H } 6 . 5$ observed in this study might be attributed to the presence of sulfate radicals as the main reactive species in the system at $\mathrm { p H } < 7 .$ . Liang and coworker investigated that acid-catalyzed decomposition of persulfate anion under acidic pH gives higher amount of $S 0 _ { 4 } ^ { \cdot - }$ radicals (Eqs. (5) and (6). They also proposed that the high concentration of radicals might facilitate the radical to radical quenching, resulting into lower oxidation efficiency [18]. Therefore, a slight decrease in reaction rate at pH 3 may be ascribed to the acid catalyzed decomposition of persulfate.

$$
\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 } + \mathrm { H } ^ { + }  \mathrm { H S } _ { 2 } \mathrm { O } _ { 8 } ^ { - }
$$

$$
\mathrm { H S } _ { 2 } \mathrm { O } _ { 8 } ^ { - } \to \mathrm { S O } _ { 4 } ^ { - } + \mathrm { S O } _ { 4 } ^ { 2 - } + \mathrm { H } ^ { + }
$$

At pH between 7 and 10.5, hydroxyl radicals also exist in the UV/persulfate system with sulfate radicals, and the reaction between these radicals causes a decrease in MP degradation (Eq. (7)).

$$
\mathrm { S O _ { 4 } ^ { - } } + { \mathrm { O H } } ^ { \cdot }  \mathrm { H S O _ { 5 } ^ { - } }
$$

In addition, hydroxyl radicals are a predominant species at $\mathrm { p H } > 1 0 . 5$ and are produced by the reaction between sulfate radicals and hydroxide ions in the oxidation system (Eq. (3)) [39]. The minimal degradation rate of MP is expected to be caused by the lower redox potential of hydroxyl radicals at $\mathsf { p H } 1 1$ . Furthermore, the observed decrease in reaction rate with increasing pH for MP can also be described in terms of the formation of ionized and negatively charged methyl paraben $\mathrm { \Delta } \cdot \mathrm { P K } _ { \mathrm { a } } = 8 . 4 0 )$ , which hinders the reaction of these molecules with negatively charged sulfate radicals due to the repulsion. Similar findings were also reported by Błe˛dzka et al. [47] for butyl paraben degradation under a UV/ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ system. Although the degradation efficiency of present system is pH dependent, the UV/persulfate method is still expected to be applicable for the remediation of contaminated real waste waters.

# 3.5. Influence of background water matrix

Inorganic anions (e.g., $\mathrm { C l ^ { - } }$ , $S O _ { 4 } ^ { 2 - }$ , ${ \mathsf { N O } } _ { 3 } ^ { - }$ , $C 0 _ { 3 } ^ { 2 - }$ , ${ \mathrm { H C O } } _ { 3 } ^ { - }$ , and $\mathrm { H P O } _ { 4 } ^ { 2 - }$ ) and natural organic matter (NOM) commonly exist in natural waters and significantly influence the efficiency of oxidation processes [48,49]. It is equally necessary to understand the effect of the background matrix on the destruction of MP to take the advantage of practical applications of the UV/persulfate oxidation process in the treatment of MP in natural water or wastewater.

# 3.5.1. Effect of anions

Anions are a major part of water matrix components. To investigate their impact on MP degradation, experiments were carried out in the presence of selected anions, such as chloride, sulfate, bicarbonate, and hydrogen phosphate, at different concentrations $( 5 { - } 2 0 \mathrm { m M } )$ . Fig. 5(b) plots the graph of percent removal of MP versus different concentrations of anions. The results revealed that different anions showed unusual inhibiting effects on the degradation of MP. Sulfate anion exhibited less inhibition on the removal rates of MP whereas chloride, bicarbonate and hydrogen phosphate anions significantly suppressed the reaction. The degradation rates of MP decomposition in the presence of chloride, sulfate, bicarbonate and hydrogen phosphate at different conditions are summarized in a table (Table S1).

The presence of sulfate anion exhibited only a slight impact on MP degradation at all concentrations because sulfate ions are the expected final product of persulfate oxidation and they also do not react with $S 0 _ { 4 } ^ { - }$ . If a high amount of persulfate is used in the reaction, more sulfate anions will be produced. The similar effects of sulfate ions on the degradation of MP using a sonochemical method were observed by Sasi et al. [28]. Chloride ions also illustrated less inhibitory effect on MP degradation rate at low concentrations (0.0372 and $0 . 0 3 5 2 \mathrm { m i n } ^ { - 1 }$ for 5 and $1 0 \mathrm { m M }$ , respectively); however, the oxidation was remarkably retarded at higher amount $( 0 . 0 2 9 0 \mathrm { m i n } ^ { - 1 }$ at $2 0 \mathrm { m M }$ ). In contrast to sulfate anions, chloride ions react with sulfate radicals and produce relatively weak moieties such as Cl , $\mathsf { C l } _ { 2 } ^ { \bullet - }$ , and ClHO [50]. The redox potentials of chloride-active species are lower than those of sulfate radicals [51], suppressing the degradation rate of MP in UV/persulfate oxidation system. Hence, MP decomposition will not be influenced at lower dosage of chloride ions. Deng et al. [41] also investigated similar findings of chloride ions on the degradation of carbamazepine.

In the present case, ${ \mathrm { H C O } } _ { 3 } ^ { - }$ and $\mathrm { H P O } _ { 4 } ^ { 2 - }$ anions significantly retarded the MP removal efficiency at different concentrations. As the amount of ${ \mathrm { H C O } } _ { 3 } ^ { - }$ and $\mathrm { H P O } _ { 4 } ^ { 2 - }$ anions increased degradation rate decreased accordingly (Table S1). ${ \mathrm { H C O } } _ { 3 } ^ { - }$ ions which are an established scavenger for hydroxyl radicals, produced carbonate radicals during the reaction (rate: $8 . 5 \times 1 0 ^ { 6 } \mathrm { M } ^ { - 1 } \mathsf { s } ^ { - 1 } )$ [52]. ${ \mathrm { H C O } } _ { 3 } ^ { - }$ anions can react with sulfate radicals at a rate constant of $2 . 8 \times 1 0 ^ { 6 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ to produce bicarbonate radicals and act as sulfate radical scavengers in the reaction solution [53]. Similarly, $\mathrm { H P O } _ { 4 } ^ { 2 - }$ ions can also react with sulfate radicals with a second-order rate constant of $1 . 2 \times 1 0 ^ { 6 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ to propagate a chain reaction and generate various phosphate radicals. Bicarbonate and phosphate radicals possess lower redox potentials than sulfate radicals, causing a reduction in the degradation rate of MP. Similar findings have also been demonstrated for the degradation of 1,1,1- trichloroethane and acid orange 7 under the persulfate oxidation system [53,54].

# 3.5.2. Effect of humic acid

Natural organic matter (NOM), present in surface water and ground water, is a complex mixture of naturally-occurring organic compounds. Humic acid (HA), generally used as a representative of NOM, was added to investigate the effects of NOM on the UV/persulfate oxidation process. HA is revealed to perform as a photosensitizer, light filter, and quencher for free radicals. HA can boost the reaction by reacting with contaminants to form photo-oxidant species [55]. HA might inhibit the reaction due to competition with the target pollutant and persulfate for incident UV light [56]. Various concentrations of HA (5 ppm to $2 0 \mathrm { p p m } ,$ were added to the reaction solutions in order to examine the effect of HA on the degradation of MP. As depicted in inset of Fig. 5(b), the degradation of MP was suppressed significantly in the presence of different amounts of humic acid, suggesting that HA increased the demand of UV dose to degrade MP. The percent removal of MP in the presence of 5 ppm, $1 0 \mathrm { p p m }$ , and 20 ppm HA was found to be $8 9 . 7 \%$ , $6 8 . 7 \%$ , and $5 3 \%$ , respectively compared to $9 8 . 9 \%$ in the absence of HA. These results are in agreement with previously reported observations [57]. The degradation rates for MP corresponding to 5, 10, and 20 ppm HA were 0.0211, 0.0122 and $0 . 0 0 9 4 \mathrm { m i n } ^ { - 1 }$ , respectively (Table S1).

# 3.6. Identification of the transformation byproducts (TBPs) and pathways

An experiment was carried out at a high MP concentration $( 1 5 \mathrm { m g L } ^ { - 1 } ) _ { \textrm { + } }$ to identify the TBPs formed during the UV/persulfate oxidation of MP. The oxidant amount was considered to be the same ratio as was used in the degradation kinetic experiments (Section 3.2). The UPLC/MS and HPLC analyses showed the formation of seven TBPs: monohydroxy-methyl paraben $( m / z ~ 1 6 7 )$ , dihydroxy-methyl paraben $( m / z ~ 1 8 3 )$ , trihydroxy-methyl paraben $( m / z$ 199), 4-hydroxybenzoic acid $( m / z \ 1 3 7 )$ , dihydroxy benzoic acid $( m / z \ 1 5 3 )$ , benzoic acid $( m / z \ 1 2 1 )$ , and phenol $( m / z$ 94) (Table S2, Fig. S1). On the basis of product analysis, the proposed steps involved in the degradation mechanism are 1) hydroxylation of the aromatic ring and 2) hydrolysis of the ester group.

Three hydroxylated TBPs, namely monohydroxy-methyl paraben $( m / z \quad 1 6 7 )$ , dihydroxy-methyl paraben $( m / z$ 183), and trihydroxy-methyl paraben $( m / z 1 9 9 )$ , were identified in the mass spectrum. The hydroxylated TBPs were 16, 32 and 48 mass units greater than methyl paraben $( m / z \ 1 5 1 )$ , respectively. The TBPs were formed as a result of hydroxylation of the aromatic ring of MP. Similar products were also proposed during ozonation and sonochemical degradation of methyl paraben by Tay et al. [58], and Sasi et al. [28], respectively. The hydroxyl and sulfate radicals can generate similar TBPs via different mechanistic routes. Hydroxylation of the aromatic ring can occur via two different mechanisms: (i) electrophilic attack by hydroxyl radicals and (ii) direct electron transfer from aromatic compounds to the sulfate radicals to produce radical cations, which give hydroxyl radical adducts upon hydrolysis [59–62]. The $S O _ { 4 } ^ { - }$ radicals are more selective and can react easily with the aromatic ring through electron transfer reactions. In comparison with the sulfate radical, nonselective HO radicals can react with the aromatic ring or the aliphatic chain via either hydrogen abstraction or addition reactions [63]. Radical quenching experiment clearly suggested that both oxidizing moieties (i.e. hydroxyl and sulfate radicals) are present in the UV/persulfate system for MP degradation. Both of these radical species might be responsible for hydroxylation; however, sulfate radical was observed to be a major species at $\mathsf { p H } 6 . 5$ . Sulfate radicals attack aromatic ring to yield MP radical cation which further react with $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ to generate hydroxycyclohexadienyl radical via addition or elimination reaction to give hydroxylated TBPs. Thus, the electron transfer reaction may be the predominant mechanism for MP degradation.

The formation of 4-hydroxy benzoic acid (4-HBA) as a degradation byproduct confirms the hydrolysis of the ester chain as another mechanistic route [28]. Furthermore, the oxidation of 4- HBA leads to the formation of its monohydroxylated isomer (dihydroxy benzoic acid) which has been reported to be the more stable intermediate of hydroxy benzoic acid [64]. The generation of phenol and benzoic acid was also observed in the degradation process of MP. Similar findings were also observed by researchers during the photodegradation of paraben using Fe(III)-citrate complexes and ${ \tt A g } _ { 3 } { \sf P } { \sf O } _ { 4 }$ as photocatalysts [30,65]. On the basis of the obtained TBPs, a degradation pathway of MP, including hydroxylation of the aromatic ring and hydrolysis of the ester chain, is proposed (Fig. 6). The observed intermediates can be further oxidized into lower molecular weight molecules through the continuous attack of HO and $S O _ { 4 } ^ { - }$ radicals [60].

# 4. Conclusion

This study explored the degradation, mechanism, and a novel advanced oxidation route for methyl paraben (a phenolic preservative) in aqueous phase using the UV-assisted persulfate (UV/persulfate) method. The results showed that direct photolysis could degrade MP, but the persulfate-assisted photolysis system possessed a superior degradation rate. The resultant activated sulfate radicals successfully removed MP and produced TBPs. MP degradation followed pseudo-first-order kinetics. The increased initial persulfate dosage improved the degradation rate $( \mathbf { k _ { o b s } } )$ , while the $\mathbf { k _ { o b s } }$ decreased as the initial MP concentration increased. The decomposition of MP was favorable at neutral pH. The presence of $S O _ { 4 } ^ { 2 - }$ anion did not considerably affect the rate constant, while $\mathrm { { C l } ^ { - } }$ , $\mathrm { H P O } _ { 4 } ^ { 2 - }$ and ${ \mathrm { H C O } } _ { 3 } ^ { - }$ inhibited the reaction rate. Similarly, HA significantly retarded the removal of MP. Seven TBPs were detected during the degradation process. Based on the observed TBPs, a degradation pathway was proposed. The present study suggests that the UV/persulfate method can be used as an efficient method for MP removal from aqueous systems.
