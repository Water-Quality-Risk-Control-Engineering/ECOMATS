# Multi-function PtCo nanozymes/CdS nanocrystals $@$ graphene oxide luminophores and ${ \sf K } _ { 2 } { \sf S } _ { 2 } { \sf O } _ { 8 } / { \sf H } _ { 2 } { \sf O } _ { 2 }$ coreactants-based dual amplifed electrochemiluminescence immunosensor for ultrasensitive detection of anti-myeloperoxidase antibody

Wei Yang1,3†, Zheng Zhou2,3†, Haiping Wu3 , Changjin Liu3 , Bo Shen3 , Shijia Ding3\* and Yonglie Zhou1\*

# Abstract

Background: Anti-myeloperoxidase antibody (anti-MPO) is an important biomarker for anti-neutrophil cytoplasm antibody (ANCA)-associated vasculitides (AAVs). However, the complicated operation procedures and insufcient sensitivity of conventional anti-MPO detection methods limit their application in monitoring efcacy of AAVs in clinical diagnosis. Herein, a dual amplifed electrochemiluminescence (ECL) immunosensor based on multi-function PtCo nanozymes/CdS nanocrystals@graphene oxide $( { \mathsf { P t C o } } / { \mathsf { C d S @ G O } } )$ luminophores and $K _ { 2 } S _ { 2 } O _ { 8 } / \mathsf { H } _ { 2 } O _ { 2 }$ coreactants has been fabricated for ultrasensitive detection of anti-MPO.

Results: PtCo/CdS@GO luminophores as novel signal amplifcation labels and nanocarriers to load rabbit anti-mouse IgG were synthesized by co-doping with Pt and Co nanozymes simultaneously with several considerable advantages, including astonishing peroxidase-like catalytic activity, high-efciency luminescence performance and superior stability in aqueous solutions. Meanwhile, upon the $K _ { 2 } S _ { 2 } O _ { 8 } / \mathsf { H } _ { 2 } O _ { 2 }$ coreactants system, benefting from the efcient peroxidase-like activity of the PtCo/CdS@GO toward $\mathsf { H } _ { 2 } \mathsf { O } _ { 2 } ,$ massive of transient reactive intermediates could react with $\mathsf { K } _ { 2 } \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } ,$ thus obtaining higher ECL emission. Therefore, the developed ECL immunosensor for anti-MPO detection displayed good analytical performance with good concentration linearity in the range of 0.02 to $1 0 0 0 \ : \mathrm { p g / m L }$ and low detection limit down to 7.39 fg/mL.

Conclusions: The introduction of multi-function $\mathsf { P t C o / C d S @ G O }$ luminophores into the established ECL immunoassay not only was successfully applied for specifc detection of anti-MPO in clinical serum samples, but also provided a completely new concept to design other high-performance luminophores. Meaningfully, the ECL immunoassay strategy held wide potential for biomarkers detection in clinical diagnosis.

Keywords: PtCo/CdS@GO luminophores, Nanozyme, $K _ { 2 } S _ { 2 } O _ { 8 } / \mathsf { H } _ { 2 } O _ { 2 }$ coreactants, Electrochemiluminescence immunosensor, Anti-myeloperoxidase antibody

# Background

Anti-myeloperoxidase antibody (anti-MPO) is one of the most important circulating biomarker for clinical diagnosis and efcacy monitoring of anti-neutrophil cytoplasm antibody (ANCA)-associated vasculitides (AAVs) [1, 2]. According to the International Consensus on ANCA Testing in Eosinophilic Granulomatosis with Polyangiitis and the Revised 2017 international consensus on testing of ANCAs in granulomatosis with polyangiitis and microscopic polyangiitis, indirect immunofuorescence (IIF) and enzyme-linked immunosorbent assays (ELISA) have been used to initially screen and verify anti-MPO [3, 4]. However, these conventional anti-MPO detection methods usually sufer from complicated operation procedures, insufcient sensitivity and specifcity [5, 6]. Recently, electrochemiluminescence (ECL) immunoassay with the unique advantages of chemiluminescence and electrochemistry, such as low background signal, simplifed optical setup, excellent spatial and temporal controllability, has been widely used in the felds of clinical diagnosis, which possesses great promise as a powerful analytical tool to replace IIF and ELISA [7, 8].

In ECL immunoassay system, traditional molecular luminophores $\left( \mathrm { R u ( b p y ) } _ { 3 } \right) ^ { 2 + }$ , luminol, acridinium ester) usually have some drawbacks including reagent waste and poor stability, restricting their analytical applications [9, 10]. Tus, with the development of multidisciplinary studies, especially nanomaterial technologies, the emergence of various new types of luminophores have been developed to overcome the aforementioned shortcomings [11–13]. As the potential ECL luminophore candidates, cadmium sulfde nanocrystals (CdS NCs) possess impressively splendid features including narrow and direct band-gap $( 2 . 3 ~ \mathrm { e V } )$ , excellent electronic/optical properties, size/surface-trap controlled luminescence and good photostability [14, 15]. Nevertheless, despite the great progress made by CdS NCs, their application in ECL immunoassay still face some challenges such as limited luminescence efectiveness and poor stability. Terefore, to address these challenges simultaneously, the exploration of novel CdS NCs is highly desirable in the feld of ECL luminophores.

Currently, a variety of excellent designs of CdS NCs have been sequentially developed to enhance the luminescence efciency, including metal deposition or doping [16, 17], band-gap engineering by forming core/shell structure [18] and coupling with carbon materials [19]. Among various metals dopants, noble metals-based dopants, especially doping platinum $\left( \mathrm { P t } \right)$ with CdS NCs not only evidently enhance the ECL emission through perturbing the host energy level or ofering a new electron energy level [20], but also act as peroxidase-like nanozymes to generate transient reactive intermediates like free radicals, and react with another substrate quickly, thus further improving the luminescence performance of CdS NCs [21–23]. Furthermore, the peroxidase-like activities can be reconstructed by charge, coating, doping, loading and external felds [24]. For instance, Fang’s group constructed $\mathrm { P t { - } C d S / g { - } C _ { 3 } N _ { 4 } { - } M n O _ { x } }$ composite photocatalyst for efcient visible-light-driven overall water splitting [25]. However, insufcient stability, low economy and specifcity of $\mathrm { P t }$ -based nanozyme still obstacle its broader application in ECL immunoassay system [26]. In response to above-mentioned drawbacks, the combination of Pt-based CdS NCs with another transition metals (Co, Pd, Mo, Ni, etc.) can possess better stability, higher luminescence efciency and catalytic activity [27, 28], which hold great promise as efcient ECL luminophores to replace conventional luminescent reagents.

Additionally, maintaining high-efciency luminescence performance of luminophores while having good stability in the most desirable environment, i.e., aqueous solutions is also an extremely important concerns, which is closely related to the dispersion of CdS NCs, and few technologies can meet all the requirements. Recently, two-dimensional (2D) graphene oxide (GO) has been generally utilized as preeminent support matrixes for nanoparticles anchoring and ensuring dispersion [29]. Moreover, the presence of efective electron-hole and abundant functional groups (–OH, –COOH, etc.) on the surface of GO sheets possess enhanced charge transfer, good biocompatibility and stability [30]. In our previous work, PtCo@rGO hybrids with almost no agglomeration has been successfully synthesized, contributing to the higher dispersion and catalytic activity [6]. Inspired by the above research, simultaneously co-doping with PtCo nanozymes, GO-supported PtCo/CdS $\left( \mathrm { P t C o } / \mathrm { C d S } \varpi \right)$ GO) luminophores have been in  situ synthesized successfully, loading number of PtCo/CdS NCs and ensuring the dispersion to enhance the luminescence efciency and stability in aqueous solutions. Furthermore, the prepared multi-function PtCo/CdS@GO luminophores could also be employed as efcient peroxidase-like nanozymes to accelerate electrochemical redox processes of coreactants, thus further improving the luminescence performance.

Herein, a dual amplifed ECL immunosensor based on multi-function PtCo/CdS@GO luminophores is fabricated for ultrasensitive detection of anti-MPO. As shown in Scheme 1 A, PtCo/CdS NCs are stepwise in situ synthesized by co-doping with Pt and Co dual nanozymes simultaneously and further immobilized on the surface of GO, forming the multi-function PtCo/CdS@GO luminophores. Ten, rabbit anti-mouse IgG (anti-Ab) is assembled onto the surface of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores to fabricate anti- $\mathrm { . A b / P t C o / C d S } @ \mathrm { G O }$ bioconjugates. After that the ECL immunosensor has been constructed by immobilizing MPO (antigen) on the glassy carbon electrodes (GCE) modifed with the pre-synthesized Au@ $\mathrm { M o S } _ { 2 }$ nanosheets, which can greatly improve the electroconductivity and modifability of the GCE. In the presence of anti-MPO (target), the anti-Ab/PtCo/CdS@GO bioconjugates are assembled on the surface of modifed GCE based on sandwich-like immunoreaction. Upon the $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } }$ coreactants system, benefting from the strong peroxidase-like activity of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores toward $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ massive of transient reactive intermediates could react with $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } }$ to obtain higher ECL emission of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores, thus further improving the analytical performance of the developed ECL immunosensor. More importantly, the introduction of multi-function $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores into the ECL immunosensor ofer an efcient approach for the ultrasensitive detection of anti-MPO and held potential applications in clinical analysis, drug delivery systems and treatment of diseases.

# Instrument

Te electrochemiluminescence (ECL) measurements were executed using a MPI-E ECL workstation (Xi’an, China) with a conventional three-electrode system composed of $\mathrm { A g / A g C l }$ electrode as reference, Pt wire as auxiliary and $\operatorname { A u } @ \operatorname { M o S } _ { 2 }$ nanosheets modifed glassy carbon electrode (GCE, $3 \ \mathrm { m m }$ in diameter) as working electrode. Cyclic voltammetry (CV) and electrochemical impedance spectroscopy (EIS) were performed with a PC-controlled CHI 660E electrochemical workstation (Shanghai, China). Transmission electron microscope (TEM, Hitachi, Tokyo, Japan), high-resolution transmission electron microscopy (HRTEM, Talos F200X, USA), scanning electron microscope (SEM, Hitachi SU8000, Japan), energy dispersive spectrometer (EDS, Oxford X-MaxN, Britain) and UV-2550 spectrophotometer (Shimadzu, Kyoto, Japan) were employed to characterize the features and morphologies of nanomaterials.

# Synthesis of $\mathsf { P t C o \it / C d S @ G O }$ luminophores

Firstly, $2 \mathrm { m L }$ $\mathrm { H _ { 2 } P t C l _ { 6 } }$ solution $( 2 0 ~ \mathrm { m M } )$ , 7 mL $\mathrm { C o C l } _ { 2 }$ solution $( 1 . 6 6 ~ \mathrm { m M } )$ and $7 6 ~ \mathrm { m g }$ glycine were mixed together and stirred for $1 \mathrm { { h } }$ , and sonicated into an ultrasonic bath at room temperature (RT) for $0 . 5 \mathrm { ~ h ~ }$ . After that, the welldistributed solution was transferred to a $5 0 ~ \mathrm { m L }$ Tefonlined stainless-steel autoclave and heated at $2 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 9 \mathrm { h } }$ . After being cooled to RT and ultrasonically dispersed for $1 5 \ \mathrm { m i n }$ , $3 1 . 0 \ \mathrm { m g \ C d ( N O _ { 3 } ) _ { 2 } . 4 H _ { 2 } O }$ was dissolved into the above mixtures $\mathrm { P t C o ~ N C s } )$ and preheated to $8 0 ~ ^ { \circ } \mathrm { C }$ under stirring. Ten, $9 9 . 4 \mathrm { \ m g \ N a _ { 2 } S { \cdot } 9 H _ { 2 } O }$ was dissolved into $5 ~ \mathrm { m L }$ DI water and slowly injected into the above solution. After that, the mixture was heated to $8 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ with continuous refuxing. Finally, the obtained products were washed with a mixture bufer (ethanol/ acetone, volume ratio $= 2 / 1$ ) for three times $( 8 0 0 0 ~ \mathrm { r p m } _ { \cdot }$ $1 5 \ \mathrm { m i n } )$ to fully eliminate the excess reactants, and then vacuum-dried at RT for further use. # Amplifcation mechanism of the multi‑function $\mathsf { P t C o / C d S @ }$ GO luminophores

Te multi-function $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores have been in  situ synthesized by co-doping with $\mathrm { P t }$ and $C \mathbf { o }$ nanozymes simultaneously, in which PtCo was employed as an efcient peroxidase-like nanozymes toward $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ CdS was used as a new type of ECL luminophore, while GO was utilized as nanocarrier to load a large amount of $\mathrm { P t C o / C d S }$ and ensure their dispersion. Specifcally, in $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } }$ coreactants system, $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } }$ played a leading role (OH• acceptor) in the process of promoting luminescence, while $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ played an auxiliary role (OH• donor). Te multi-function $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores $\left( \mathrm { P t C o } \right)$ could accelerate electrochemical redox processes of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to generate massive of transient reactive intermediates (OH• ), and then OH• rapidly reduced $\mathrm { S _ { 2 } O _ { 8 } } ^ { 2 - }$ to produce more strong oxidant $\mathrm { ( S O _ { 4 } ^ { \bullet - } ) }$ with suffciently negative electrode potential, thus enhancing the ECL emission of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores (CdS). Based on the synergistic efect of $\mathrm { K } _ { 2 } \mathrm { S } _ { 2 } \mathrm { O } _ { 8 }$ and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ the ECL intensity of the $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores was greatly increased. Furthermore, GO as a novel signal amplifcation label and nanocarrier could further amplify the ECL emission of the PtCo/CdS@GO luminophores. A typical catalytic oxidation reaction of the peroxidase substrate 3, $3 ^ { \prime }$ , 5, $5 ^ { \prime }$ -tetramethylbenzidine (TMB) by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was performed to investigate the peroxidaselike activity of $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ (classic nanozyme, Additional fle  1: Figure S3A), $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ (this work), PtCo/ rGO nanozyme (our previous work, Additional fle  1: Figure S3B) [6] and horseradish peroxidase (HRP). As shown in Fig. 3B, when HRP was added to $\mathrm { T M B / H _ { 2 } O _ { 2 } }$ system, a highest absorbance slope was obtained, which was signifcantly higher than that of $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ and slightly higher than that of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ and $\mathrm { P t C o / r G O }$ . Tese results showed that the $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ possessed a comparable catalytic activity with HRP.

Moreover, in order to explore the superiority of $\mathrm { P t C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ luminophores towards $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } }$ coreactants ECL system, we incubated diferent nanomaterials including CdS NCs [36], PtCo/CdS NCs, $\mathrm { P t C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ (molar ratio: ${ \mathrm { C d } } / { \mathrm { S } } = 1 / 4 { \mathrm { , } }$ ) and $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores (molar ratio: $\mathrm { C d } / \mathrm { S } = 1 / 1$ , this work) on the electrodes and compared their ECL performance. As shown in Fig.  3C, the highest ECL intensity about 17,343 a.u. was observed from the developed $\mathrm { P t C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ luminophores (curve d), which was higher than that of above-mentioned nanomaterials such as CdS NCs (curve a, 3799 a.u), PtCo/CdS NCs (curve b, 10,333 a.u) and $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ (curve c, 11,257 a.u). Tese results indicated that the multi-function PtCo/CdS@GO luminophores possessed high peroxidase-like activity and enhanced electron transfer, which could evidently enhance luminescence efciency [27, 28]. Furthermore, GO had large specifc surface area to support massive PtCo/CdS NCs and provided superior stability to ensure the dispersion of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores in the ECL system.

# Optimization of the reaction conditions

To explore the optimal analytical performance of the ECL immunosensor, several vital experimental parameters were systematically optimized in the whole ECL immunoassay system, including the concentration proportion of PtCo/CdS NCs and GO, the dilution ratio of $\mathrm { P t C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ luminophores and the concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } }$ coreactants. As shown in Fig.  5A, with the concentration proportion of GO from 500:1 to 100:1, the ECL intensity gradually increased. Tis was because the introduction of GO enhanced the charge transfer efciently and repressed the recombination of electron-holes pairs. However, the ECL intensity gradually decreased along with the increase of GO concentration proportion from 100:1 to 20:1, which was because the excess GO might shield the active sites of $\mathrm { P t C o / C d S }$ NCs surface and reduce the ECL intensity of the $\mathrm { P t C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ luminophores. Tus, 100:1 of PtCo/CdS NCs and GO was chosen as the optimum proportion in this experiment. Moreover, in order to obtain better dispersion and higher ECL signal, the dilution ratio of $\mathrm { P t C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ luminophores was further investigated. As displayed in Fig. 5B, a gradually increased ECL intensity with the dilution ratio of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores, and the maximum ECL intensity was achieved at 3 times dilution $( 3 . 3 3 ~ \mathrm { m g ~ m L ^ { - 1 } } ) _ { \mathrm { \ell } } .$ ). Tis was because the high concentration of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores would form some granular precipitations after mixing with the antiAb, which could reduce the ECL signal. Tus, three times dilution of $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores was selected as the optimum reaction condition while presenting better stability and higher luminescence efciency in the ECL immunoassay system. # Application in clinical serum samples

To further estimate the practicability of the proposed ECL immunosensor in a complex biological matrix, recovery experiments were executed by successively adding anti-MPO in clinical serum samples with a known gradient concentration. As shown in Table 1, the concentrations of anti-MPO were accurately quantifed by the ftted linear equation in Fig. 6B $( I { = } 6 5 3 9 . 7 5 { + } 3 0 6 8 . 5 9 \log$ $\mathrm { C _ { a n t i - M P O } ) }$ , and the recoveries were obtained from 95.54 to $1 0 6 . 3 7 \%$ with the RSD of 0.84 to $3 . 2 0 \%$ $( \mathtt { n } = 3 )$ ). Tese results demonstrated that the proposed ECL immunosensor could serve as an alternative method for ultrasensitive detection of anti-MPO held a great potential in clinical application.

# Conclusions

In this work, an ultrasensitive ECL immunosensor based on the dual amplifcation strategies of multi-function $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores and $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } }$ coreactants has been developed for anti-MPO detection. Benefting from several considerable advantages of $\operatorname { P t } \mathbf { C o } /$ $\mathrm { C d S } @ \mathrm { G O }$ luminophores, including extraordinary peroxidase-like activity toward $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } / H _ { 2 } O _ { 2 } } ,$ high-efciency luminescence performance and superior stability in aqueous solutions, the ECL immunosensor for anti-MPO detection displayed excellent analytical performance with linear concentration range from 0.02 to $1 0 0 0 \ \mathrm { p g \ m L ^ { - 1 } }$ and LOD down to 7.39 fg $\mathrm { m L } ^ { - 1 }$ . More importantly, the introduction of multi-function $\mathrm { P t C o } / \mathrm { C d S } @ \mathrm { G O }$ luminophores not only ofers a successful application for anti-MPO detection in clinical serum samples, but also provides a new concept to design other semiconductor nanomaterials in biomarker detection systems (e.g., ECL immunoassay, photoelectrochemical immunoassay), drug delivery systems and disease treatment systems. However, there are still some challenges in the future, including simplifying the synthesis steps of $\mathrm { P t C o / C d S } @$ GO luminophores and the infuence of diferent molar ratio of $\mathrm { P t } / \mathrm { C o }$ on peroxidase-like activity and ECL emission. In conclusion, the ECL immunosensor hold great potential for biomarkers detection in clinical application.
