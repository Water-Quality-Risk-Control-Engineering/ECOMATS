# . Introduction

The use of peroxymonosulfate (PMs) based advanced oxidation processes (AOPs) has gained popularity due to their high efficiency, across a wide pH range, in removing persistent organic pollutants from wastewater [1]. These AOPs generate a range of reactive oxygen species (ROS) by breaking the peroxide bond in the persulfate molecule through various methods such as heat, ultraviolet (UV) radiation, and transition metals [2,3].

A diverse array of heterogeneous catalysts has been shown to be effective activators of PMS, favored for their high efficiency, obviation of additional energy input, and prevention of metal ion leaching [46]. Beyond the generation of reactive radicals (such as SO4, 'OH, $\boldsymbol { 0 _ { 2 } ^ { \bullet \cdot } } )$ , non-radical mechanisms have also been identified as significant contributors to PMS activation [711]. Recent studies have revealed that the production of ROS can be linked to specific active sites on materials like graphitized nanodiamonds [12] and the $\mathrm { C o } / \mathrm { g } { \cdot } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ composite [13]. While the influence of ROS in metal oxide-mediated PMS activation can be modulated by combining it with an inert phase [14,15], the relationship between the particular active sites and the catalytic mechanisms involved to be elucidated.

Perovskite oxides with a general formula of $\mathbf { A B O _ { 3 } }$ (where A represents an alkaline or rare earth metal and B denotes a transition metal) have garnered significant attention as promising candidates for PMS activation. This interest is attributed to their exceptional chemicaldesign versatility, the ability to engineer defects, the tunable surface properties, and their robust stability [16]. Traditionally, the A-site cation was presumed to play a passive role in the degradation process; however, strategic substitution of the A-site cation has been shown to enhance PMS activation. This enhancement is achieved by influencing the electronic structure of the B-site cation, for instance, altering its oxidation state, spin state, and coordination environment, as well as by affecting the oxygen vacancy concentration. Such modifications have been successfully demonstrated in Fe-based [17,18], Mn-based [19] and Co-based [20] perovskite oxides. Nonetheless, the typical oxidation states of general A-site cations, which include $+ 1$ , $+ 2$ ,and $^ { + 3 }$ , coupled with the chemical solubility constraints imposed by the Goldschmidt tolerance factor, restrict the extent to which the electronic properties of the B-site cation can be modulated. For instance, in the case of the Sr-doped $\mathrm { S r _ { x } L a _ { 1 - x } C o O _ { 3 - \delta } }$ perovskite series, the oxidation state of cobalt will increase from $+ 3$ to a more oxidized state, as a result of the A-site doping with $\mathsf { S r } ^ { 2 + }$ to maintain the electrical neutrality of the compound. The progressive oxidation of the Co-sites within Sr-doping precludes the existence of ${ \mathsf { C o } } ^ { 2 + }$ , which is considered the most reactive site for PMS activation in cobaltites, illustrating a challenge in achieving precise control over the reactive sites within perovskite materials [21].

In recent studies, the spin state of transition metals has emerged as a crucial factor in determining the catalytic activity of transition metalbased PMS activators. Previous research has shed light on the spinstate-dependent mechanisms underlying PMS activation, revealing that high spin-state species enhance the overlap between the transition metal d orbitals and the oxygen 2p orbitals of O-containing species. This interaction promotes the adsorption of PMS and ultimately improves the catalytic performance of the system [22,23].

Nevertheless, the previous research has predominantly concentrated on the kinetic correlations between the spin state of individual transition metal sites and PMS catalytic activity within specific catalytic systems. This narrow focus has limited the understanding of the underlying mechanism behind the tuning of PMS activation by different spin states of transition metal (TM) species. Thus, it is crucial to unravel the PMS activation mechanism of different cobalt species crystallizing within identical coordination environments in order to gain deeper insights into the structure-activity relationship. Ruddlesden-Popper (RP) perovskite oxides, with a general formula $\mathbf { A _ { n + 1 } B _ { n } O _ { 3 n + 1 } }$ , are characterized by alternating rock-salt layers (AO) and perovskite-like layers $\left( \mathsf { A B O } _ { 3 } \right)$ along the crystallographic c-axis direction. Compared to traditional perovskite $\mathbf { A B O _ { 3 } }$ materials, $\mathbf { A _ { n + 1 } B _ { n } O _ { 3 n + 1 } }$ perovskites exhibit greater tunability in their composition and possess unique physicochemical properties [24]. In this context, the $\mathbf { n } = 1$ R-P series, noted as $\mathrm { S r _ { x } L a _ { 2 - x } C o O _ { 4 \pm \delta } }$ presents an exemplary model system for exploring the diverse electronic states of cobalt and their correlation with PMS activation, potentially leading to a better understanding of the catalytic phenomena.

In this study, a series of strontium-substituted lanthanum cobaltates $\mathrm { S r _ { x } L a _ { 2 - x } C o O } _ { 4 \pm \delta }$ ${ \bf \zeta } \cdot { \bf { x } } { = } 0 . 6$ , 0.8, 1.0, 1.2 and 1.5), referred to as SLCO, were synthesized employing the citric acid sol-gel method. The efficiency of these materials in activating PMS for the degradation of paracetamol was assessed. All synthesized SLCO catalysts significantly surpassed the performance of pristine $\mathrm { L a C o O _ { 3 } }$ (LCO) when used at low concentrations $( 0 . 1 g / \mathrm { L }$ for the catalyst and $0 . 5 \mathrm { m M }$ ,equivalent to $0 . 1 5 3 \mathrm { g / L }$ for PMS). To understand the underlying origin of this catalytic activity enhancement, the electronic structure of SLCO was investigated, particularly focusing on the spin configuration, using X-ray absorption fine structure (XAFS) spectra. Notably, our study revealed distinct PMS oxidation pathways correlating with the varying Sr/La ratios in SLCO. The spin state of cobalt emerged as a critical determinant in directing the PMS oxidation pathway. This finding provides new insights into the role of spin state in PMS activation using SLCO catalysts, paving the way for tailored design of superior catalysts, potentially revolutionizing environmental remediation strategies.

Perovskite $\mathrm { B O } _ { 6 }$ octahedra in a corner-sharing framework are offset from each other producing a cut apart of the perovskite lattice intervals such that corners that normally share an oxygen are now separated. # 3.2. Catalytic performance of catalysts for PMS activation

The PMS activation performance of the catalysts was evaluated through paracetamol degradation as a function of time. Previous studies indicate that PMS alone cannot remove paracetamol effectively (up to $2 \mathrm { m M }$ PMS concentrations) [34]. As shown in Fig. 3a, less than $5 \%$ of paracetamol was removed in the absence of PMS for the first $3 0 \mathrm { m i n }$ suggesting that the adsorption of the pollutant on the surface of the catalysts can be neglected. This observation is in good agreement with the low specific surface areas of all the catalysts. However, in the presence of PMS, the LaSrCoO4 (SLCO100) catalyst (at $0 . 1 \ g / \mathrm { L }$ achieved complete paracetamol removal in approximately $5 \mathrm { { m i n } }$ with a first order rate constant $( k _ { \mathrm { o b s } } )$ of $0 . 4 2 9 \mathrm { m i n } ^ { - 1 }$ .Surprisingly, all the SLCOs outperformed $\mathrm { L a C o O } _ { 3 - \delta }$ $( k _ { \mathrm { o b s } } = 0 . 1 3 \mathrm { m i n } ^ { - 1 }$ under the same reaction conditions [21]) and $\mathsf { S r C o O } _ { 3 - \delta }$ $( k _ { \mathrm { o b s } } = 0 . 0 6 7 \ \mathrm { m i n } ^ { - 1 }$ under the same reaction conditions, Fig. S5), despite the latter having more cobalt content, suggesting that the presence of a rock-salt layer has a positive effect on the performance. Increasing or decreasing the $\mathbf { s r }$ content by $2 0 \%$ significantly improved paracetamol removal, whereas further variations in Sr content have a negative effect on the performance. The higher efficiency of SLCO080 and SLCO120 can be attributed to different Co spin states affecting PMS activation. Additionally, the efficiency of PMS decomposition did not align with paracetamol degradation (Fig. 3b), as an increase in Sr content inhibited PMS decomposition, suggesting distinct the PMS activation pathways in the $S \mathbf { r } _ { \mathrm { x } } \mathrm { L a } _ { 2 \cdot \mathrm { x } } \mathrm { C o O } _ { 4 \pm \delta }$ series [14, 35].

Apart from free radicals and singlet oxygen, electron transfer from organics to PMS mediated by catalysts can initiate the effective degradation of pollutants [53,54]. An electrochemical test involving open-circuit potential (OCP vs time chronoamperometry) was conducted to monitor the electron transfer process upon adding PMS and paracetamol. As shown in Fig. 5a, the OCP is much lower for SLCO080 pointing out that this compound is the most oxidative active, followed by SLCO120, SLCO150 and SLCO060, and finally, SLCO100 compound. The potential increased immediately upon adding PMS in all the tests, due to electron density redistribution in the working electrode caused by PMS physiosorption [35]. Subsequently, upon adding paracetamol, the OCP significantly decreased, which implied that the complexed PMS was disrupted, owing to the rapid electron transfer from the target paracetamol compound to the adsorbed PMS [55]. Interestingly, the OCP changes upon adding PMS correlate quite well with paracetamol removal performance since SLCO080 and SLCO120 presented the highest oxidative power. However, the depletion of the potential after adding paracetamol correlates quite well with Sr content in the catalyst series. Thus, adding paracetamol caused a small decline of OCP from $0 . 8 6 \mathrm { V }$ to $0 . 8 1 \mathrm { ~ V ~ }$ at the steady state for SLCO060 indicative of a small electron transfer contribution. Since the differences between the addition of paracetamol and the corresponding steady state of SLCO catalysts increase with Sr content, the electron transfer mechanism is suggested to be the main mechanism in the paracetamol degradation. Chronoamperometric measurements, Fig. 5b, were conducted at an applied potential of $_ { 0 \mathrm { ~ V ~ } }$ vs Ag/AgCl with the sequential addition of PMS and paracetamol. When adding PMS a significant current depletion is observed in all the samples. Under the applied potential, PMS is reduced thus decreasing the current as lower as higher is the oxidative power of the catalysts. Therefore, PMS activation is higher for SLCO080, decreasing monotonically for SLCO120, SLCO100, SLCO060 and ending in SLCO150 which possesses the lowest activation performance. Previous studies have presented contradictory scenarios of ${ \mathsf { C o } } ^ { 3 + }$ ions in $S \mathrm { r _ { x } L a _ { 2 - x } C o O } _ { 4 \pm \delta }$ as a function of Sr doping, with both low-spin state and high-spin state ${ \mathsf { C o } } ^ { 3 + }$ observed across the $\mathrm { S r _ { x } L a _ { 2 - x } C o O _ { 4 \pm \delta } }$ range (0.6 $\leq \mathbf { x } \leq 1 . 5 )$ , and a transition to a high-spin state ${ \mathsf { C o } } ^ { 3 + }$ with increasing Sr doping [67,68]. The spin state of $\mathrm { S r _ { x } L a _ { 2 - x } C o O _ { 4 \pm \delta } }$ $\scriptstyle \left( \mathbf { x } = 0 . 6 \right.$ ,0.8, 1.0, 1.2, and 1.5) was checked by fitting the pre-edge peaks in the Co K-edges XANES spectra (see Fig. 6c and Table S6) [69] and high resolution XPS spectra of the Co L-lines (Fig. 6d). These pre-edge features, ranging from 7709 to $7 7 1 2 \mathrm { e V }$ in Fig. 6c, correspond to quadrupole ${ 1 } \thinspace s { - } 3 \mathrm { d }$ transitions into unoccupied $\mathbf { t } _ { 2 \textrm { g } }$ and $\mathrm { e _ { g } }$ orbitals [70,71]. The presence of both, 1 s$\mathrm { t } _ { 2 \mathrm { ~ g ~ } }$ and $\mathrm { e _ { g } }$ contributions support the coexistence of HS and LS states in all the compositional range, which is in good agreement with previous publications and our structural Jahn-Teller distortion analysis and electrochemical tests [67,68,70,71]. Furthermore, the broadening of the spectral high resolution XPS feature $\mathrm { L } _ { 2 }$ , depicted in Fig. 6d which is centered around $7 9 5 \mathrm { e V }$ rebles h shape tha presents ${ \mathsf { C o } } ^ { 3 + }$ containing compounds with spin crossover characteristics. The intensity of the $1 \ s \mathrm { - \ e _ { g } }$ transition feature systematically increased with Sr doping, indicating a spin transition from low-spin (LS) to high-spin (HS). Recent research has shown that spin state influences the decomposition behavior of oxygen-containing substances in catalytic processes such as oxygen reduction reaction and water splitting [72,73]. The $\mathrm { e _ { g } }$ orbitals of transition metals participate in $\sigma$ bonding with oxygen-containing species by overlapping with O 2p orbitals, influencing bonding strength, electron-transfer rates, and catalytic activity for PMs activation [7476]. The literature also indicates that the specific electronic configuration of transition metal d orbitals can induce exclusive PMS oxidation pathways [23,77]. High-spin state Co sites, characterized by a large magnetic moment, facilitate the coupling of oxygen-containing compounds, enhance the transfer of spin-oriented electrons, promote PMS adsorption, strengthen the oxidation potential of intermediates, and accelerate electron transfer [23,30,72]. Therefore, the HS ${ \mathsf { C o } } ^ { 3 + }$ favors the electron transfer process while the LS ${ \mathsf { C o } } ^ { 3 + }$ favors the radical generation. This may explain the radical-dominated PMS activation observed in the presence of low-spin state ${ \mathsf { C o } } ^ { 3 + }$ mainly stabilized in $\mathbf { L a C o O _ { 3 } }$ [78].

Scheme S1 shows all the possible spin states of cobalt oxidation states present in SLCO compounds and the strength of the corresponding JahnTeller effect. When $\bar { \mathsf { C o } } ^ { 2 + }$ and ${ \mathsf { C o } } ^ { 4 + }$ ions sit in octahedral coordination, they are always in HS configuration but ${ \mathsf { C o } } ^ { 3 + }$ , present in all SLCO compounds, can be found in both HS and LS configurations. According to the broad set of experimental techniques (Rietveld refinement of XRD, XPS, XANES, OCP and Chronoamperometry measurements) used to determine strain, Jahn-Teller distortion, cobalt oxidation states, $\mathrm { e _ { g } }$ and $\mathrm { t } _ { 2 \mathrm { ~ g ~ } }$ orbital contribution and oxidative power of SLCO species, we are in the position to establish a solid relationship between Co-spin state and PMS activation process. From the structural point of view, both SLCO080 and SLCO120 display the most regular $\left[ { \bf C o - O 6 } \right]$ octahedra and therefore, optimum overlapping of the $\mathtt { d z } ^ { 2 }$ and $\mathrm { { d x ^ { 2 } - y ^ { 2 } } }$ non-bonding $\mathrm { e _ { g } }$ orbitals with $\mathsf { 2 p }$ oxygen ones, resulting in the best PMS activation, better oxidative ability (supported by OCP measurements) and therefore the best catalyst performance. The main differences between these two compounds in paracetamol degradation can be explained in terms of the cobalt oxidation state. The redox ${ \mathrm { C o } } ^ { 2 + } / { \mathrm { C o } } ^ { 3 + }$ couple operates in the SLCO080 compound, whereas ${ \mathrm { C o } } ^ { 3 + } / { \mathrm { C o } } ^ { 4 + }$ operates in SLCO120.

According to the trend observed in OCP measurements when the paracetamol pollutant is added, the SLCO080 activation properties are due to a dominant radical process and, otherwise electron transfer rules the degradation of paracetamol for SLCO120 compound. Finally, as indicated by our XANES, XPS results and a previous report [67], both HS and LS ${ \mathsf { C o } } ^ { 3 + }$ states are present in all SLCOs, however with increasing the Sr content $\mathrm { e _ { g } }$ contribution and HS ${ \mathsf { C o } } ^ { 3 + }$ also enhances and therefore decreases LS ${ \mathsf { C o } } ^ { 3 + }$ sites. In light of these observations, a radical to electron transfer process and a LS to HS ${ \mathsf { C o } } ^ { 3 + }$ transition are demonstrated to occur with increasing Sr content along the R-P series.

SLCOs with higher Sr content provides highly active HS ${ \mathsf { C o } } ^ { 3 + }$ with abundant ${ \mathrm { C o } } ^ { 3 + } / { \mathrm { C o } } ^ { 4 + }$ species to directly extract electrons from the surface-confined paracetamol. The increasing ${ \mathsf { C o } } ^ { 4 + }$ ratio has been reported to favor the electron transport, which may also contribute to strengthen electron transfer process [41]. The extracted electrons thus full filling the redox cycling of the Co species, thereby avoiding the speed-limiting step in the radical generation pathway (Eq. 4). The superior conductivity of SLCO facilitates these processes, enabling the simulating reduction of Co cations [24]. Moreover, the concerted mixed pathways can synergistically address the surface passivation and low activity/ selectivity issue of the heterogeneous catalyst, where the highly oxidative radicals can efficiently degrade the surface-bound pollutants/intermediates to prevent their accumulation and the electron transfer process enhance the surface enrichment of pollutants to favor efficient degradation by radicals. Furthermore, the performance of SLCO080 were compared with the state-of-the-art Co-based perovskite PMS activator and Co-based PMS activators towards paracetamol degradation in Table S7, suggesting its excellent catalytic activity.

Based on the above analysis, the composition dependent PMS activation mechanism in $S \mathbf { r } _ { \mathrm { x } } \mathrm { L a } _ { 2 - \mathrm { x } } \mathrm { C o O } _ { 4 \pm \delta }$ can be summarized. Both sulfate radicals and direct electron transfer contribute the paracetamol removal. With increasing Sr content, the radical pathway gradually weakens while electron transfer gradually enhances. The reduced oxidation state of Co in low Sr content $\mathrm { S r _ { x } L a _ { 2 - x } C o O _ { 4 \pm \delta } }$ favors PMS activation through sulfate radical generation. The modulated Co spin state enables mediated electron transfer, which can be further enhanced by increased charge transfer properties. SLCO080 and SLCO120 catalyzed PMS activation through a synergistic effect of radical generation and mediated electron transfer pathways, resulting in the best paracetamol removal performance.

# 3.4. Reusability and stability test

Recycling experiments were conducted to evaluate the reusability of $\mathbf { S r } _ { 0 . 8 } \mathbf { L a } _ { 1 . 2 } \mathbf { C o O } _ { 4 }$ (SLCO080) as selected catalyst. As it is shown in Fig. 7b, the paracetamol removal efficiency slightly decreased over the cycles, yet it remained high enough to completely remove paracetamol within $1 5 \mathrm { { m i n } }$ by the fourth cycle. This suggests that the catalyst retains its activity over multiple uses, which is an important factor for practical applications. XRD was used to analyze the crystalline structure of the $\mathbf { S r } _ { 0 . 8 } \mathbf { L a } _ { 1 . 2 } \mathbf { C o O } _ { 4 }$ catalyst after it had been used in the reaction cycles. Fig. 7a showed no significant changes in the crystalline structure, indicating that the catalyst is stable and maintains its structure after repeated use. XAS measurements was also conducted at Co K-edge after the catalytic degradation experiment. As shown in Fig. S20a, an shift to higher energy in absorption edge is observed after the catalytic reaction, suggesting the oxidation of Co. Moreover, The FT modulus of the $\mathbf { k } ^ { 3 } \chi ( \mathbf { k } )$ spectra at Co K-edge (Fig. S20b) indicated that no obvious structural change happened after reaction, agreeing with the XRD results. The stabilizing effect of the rock-salt layer on the perovskite layer was reported to contribute to the enhanced chemical stability [24]. The leaching of Co from the catalyst was tested at different initial pH values. Fig. 7c indicates that Co leaching increases with the Sr content in the catalyst. However, even with $3 \mathrm { \ m g / L } \mathrm { C o } ^ { 2 + }$ , less than $2 0 \%$ paracetamol was removed after $2 0 \mathrm { { m i n } }$ , indicating the Co leaching may not dominate the paracetamol removal with LSCOs as catalysts (Fig. S21). The stability and minimal structural change after repeated use are positive indicators for potential practical applications in wastewater treatment or similar processes where paracetamol contamination is an issue.

# 4. Conclusion

# Data Availability

In this work, a series $\mathrm { S r _ { x } L a _ { 2 - x } C o O _ { 4 \pm \delta } }$ $\scriptstyle \left( \mathbf { x } = 0 . 6 \right.$ , 0.8, 1.0, 1.2 and 1.5) was demonstrated to be efficient PMS activator. Using $0 . 1 ~ \ g / \mathrm { L }$ $\mathrm { S r } _ { 0 . 8 } \mathrm { L a } _ { 1 . 2 } \mathrm { C o O } _ { 4 }$ and $0 . 5 \mathrm { m M }$ PMS led to the complete removal of paracetamol (initial concentration of $1 0 \mathrm { m g / L }$ in $5 \mathrm { { m i n } }$ . The reaction constant for the degradation process was found to be $0 . 7 0 \mathrm { m i n } ^ { - 1 }$ , which is five times higher than that of the benchmark material $\mathrm { L a C o O _ { 3 } }$ .This suggests a substantially faster reaction rate when using the Sro.8La1.2- $\mathrm { C o O } _ { 4 }$ catalyst. The catalytic performance and the reaction pathway are significantly influenced by the valence and spin state of Co within the perovskite sub-structure. All tested $\mathrm { S r _ { x } L a _ { 2 - x } C o O _ { 4 \pm \delta } }$ materials exhibit both radical and electron transfer pathways for PMS activation. An increase in Sr content in the catalysts correlates with an increased prevalence of the non-radical pathway and higher PMS utilization, suggesting that the Sr content plays a role in modulating the activation pathway of PMS. The intercalation of rock-salt layer sub-structures in the perovskite material appears to tune the electronic structure of Co, which in turn influences the activation pathway of PMS. This study provides insights into how different Co species can induce distinct PMS activation pathways and opens new strategies for modulating these pathways to enhance the efficiency and selectivity of pollutant degradation processes.
