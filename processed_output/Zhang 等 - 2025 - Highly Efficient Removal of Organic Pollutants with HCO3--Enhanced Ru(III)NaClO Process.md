Abstract: The design of efficient advanced oxidation processes (AOPs) in the presence of bicarbonate has long attracted considerable attention in the field of environmental catalysis. In this study, sodium bicarbonate $\left( \mathrm { N a H C O } _ { 3 } \right)$ ) as one of the most abundant substances in actual water, was introduced to a $\mathrm { { N a C l O / R u ( I I } }$ I) system to enhance the removal of acid orange 7(AO7). ${ \mathrm { N a H C O } } _ { 3 }$ could significantly improve the removal efficiency of the $\mathrm { R u ( I I I ) / N a C l O }$ process in $\mathrm { H C O } _ { 3 } ^ { - }$ at a $\mathrm { p H }$ range of 6.9–10.0. $\scriptstyle \mathrm { R u ( V ) = O }$ was identified as a dominant reactive species involved in the degradation of pollutants in the $\Nu \mathrm { a H C O _ { 3 } / N a C l O / R u ( I I I ) }$ system. $\mathrm { H C O } _ { 3 } ^ { - }$ interacts with $\mathrm { R u ( I I I ) }$ to generate $\mathrm { R u ( I I I ) { – } H C O _ { 3 } } ^ { - }$ , which enhances the activation performance of $\mathrm { R u ( I I I ) }$ under neutral or alkaline conditions. The removal of AO7 was significantly enhanced with increasing ${ \mathrm { N a H C O } } _ { 3 }$ concentration, and the rate constant increased more than 2-fold to 4-fold as ${ \mathrm { N a H C O } } _ { 3 }$ concentrations increased from 0 to $1 0 0 \mathrm { m M }$ at $\mathrm { p H }$ 6.9 and 8.5. This study proposed a novel strategy to enhance the $\mathrm { R u ( I I I ) / N a C l O }$ process with environmentally friendly inorganic ligands and highlights its potential applications in the removal of pollutants.

Keywords: advanced oxidation processes; sodium bicarbonate; NaClO; Ru(III); $\scriptstyle \mathrm { R u ( V ) = O }$

# 1. Introduction

Advanced oxidation processes (AOPs) are based on the generation of highly reactive species, including radicals (e.g., hydroxyl radicals, superoxide anion radicals, sulfate radicals) [1,2] and non-radicals (e.g., singlet oxygen and high-valent metal–oxo species (HMOS)) [3,4] that show great potential in removing contaminants. Among those, HMOS exerts higher selectivity towards electron-rich substances, which in turn reduces the toxicity of such compounds [5,6]. In general, compared to radicals, HMOS have the advantages of a longer lifespan, higher steady-state concentration [7], and less susceptibility to being scavenged by non-target substrates such as natural organic matter and inorganic ions [8]. In addition, several studies have shown that HMOS, such as Fe(IV) and $\mathrm { C o ( I V ) }$ , are typically formed in acid environments [6,9,10], while few studies have explored the formation of HMOS over a wide pH range, especially under neutral or alkaline conditions.

Up to now, various oxidants, such as ozone $\left( \mathrm { O } _ { 3 } \right)$ [11], hydrogen peroxide $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ [12], persulfates [13,14], peracetic acid (PAA) [6], and periodate $\left( \mathrm { I O } _ { 4 } ^ { - } \right) .$ ) [15] have received considerable attention. Compared to the aforementioned oxidants, reports in the literature on the use of sodium hypochlorite (NaClO) oxidation technology for pollutant degradation are still limited. However, NaClO as an oxidant has unique advantages: it exhibits strong oxidizing properties over a wide pH range and is inexpensive and easy to produce [16]. Nevertheless, NaClO is not a strong oxidizing agent compared to Fenton oxidation [17], and generally requires a relatively long reaction time to achieve the high-efficiency removal of refractory compounds by ultraviolet (UV) activation [18]. In 2020, Liang et al. provided multiple evidence demonstrating that high-valent iron–oxo species (i.e., Fe(IV)) can be generated in the Fe(II)/HClO system under acidic conditions (at $\mathrm { p H } 2 . 0 $ ) via Equation (1) [19].

$\mathrm { R u ( I I I ) }$ is a rare transition metal ion, which was employed to activate PAA for the removal of sulfamethoxazole (SMX) in a phosphate solution at $\mathrm { p H } 7 . 0 ,$ , and the results suggested that the Ru(III)/PAA oxidation process was not affected by chloride and carbonate ions in the reaction solution [20]. Later, Zong et al. used $\mathrm { { R u } ( I I I ) }$ as an activator to activate peroxymonosulfate $( \mathrm { H S O } _ { 5 } ^ { - }$ , PMS) and found that the high-valent ruthenium–oxo species (i.e., $\mathrm { R u ( V ) = O ) }$ were the predominant reactive species in the $\mathrm { R u ( I I I ) / P M S }$ system at $\mathrm { p H } 3 . 0$ [21]. In this process, the inhibitory effects of inorganic ions and dissolved organic matters (DOMs) on SMX degradation were negligible. Bicarbonate ion $\left( \mathrm { H C O } _ { 3 } ^ { - } \right)$ ) is one of the most abundant ions in actual water because of the high solubility of $\mathrm { C O } _ { 2 }$ from the air. In the vast majority of AOPs, $\mathrm { H C O } _ { 3 } { } ^ { - }$ plays a significant inhibition role in the degradation of pollutants because it can quench free radicals to form weak reactive species [22–24]. However, there are a few reports on the enhanced removal of pollutants in the presence of $\mathrm { H C O } _ { 3 } ^ { - }$ [25]. Therefore, it is of great significance to investigate the effect of $\mathrm { H C O } _ { 3 } ^ { - }$ on catalytic activity in view of its practical applications.

Inspired by the above studies, we proposed a $\Nu a H C O _ { 3 } / \mathrm { N a C l O } / \mathrm { R u ( I I I ) }$ system with the expectation of achieving highly efficient contaminant removal under near-neutral $\mathrm { p H }$ and alkaline conditions, and until now little is known about the degradation of organic pollutants by this system. Previous studies have reported that $\mathrm { H C O } _ { 3 } ^ { - }$ can interact with metal ions, leading to significant changes in their reactivity [26,27]. We suspect that $\mathrm { H C O } _ { 3 } ^ { - }$ can significantly enhance the removal efficiency of contaminants in the activation of NaClO by $\mathrm { { R u } ( I I I ) }$ . Herein, the aim of the this study was to investigate the catalytic activity of $\Nu { \mathrm { a H C O } _ { 3 } } / \Nu { \mathrm { a C l O } } / \mathrm { R u ( I I I ) }$ for organic pollutants.

Acid orange 7 (AO7) is a representative substance among azo dyes, which is “carcinogenic, teratogenic and mutagenic” [28–30] and difficult to degrade, and was selected as the main test compound. Parameters influencing degradation using the present system were systematically examined, including NaClO and $\mathrm { R u ( I I I ) }$ dosage, the concentration of AO7, and the concentration of $\mathrm { H C O } _ { 3 } ^ { - }$ under different $\mathrm { p H }$ values. Furthermore, the dominant reactive species in the $\Nu a H C O _ { 3 } / \mathrm { N a C l O } / \mathrm { R u ( I I I ) }$ system were identified, and the possible activation mechanisms were also elucidated.

# 2.4. Effect of Concentration of $H C O _ { 3 } ^ { - }$ Under Different pH Values

As is well known, carbonic acid is a diprotic acid with two $\mathrm { p K } _ { \mathrm { a } }$ values $( \mathrm { p K } _ { \mathrm { a 1 } } = 6 . 4 ,$ $\mathsf { p K } _ { \mathsf { a } 2 } = 1 0 . 3 )$ [34], so carbonate has three species in water, namely $\mathrm { H } _ { 2 } \mathrm { C O } _ { 3 } .$ , $\mathrm { H C O } _ { 3 } ^ { - }$ , and $\mathrm { C O } _ { 3 } { } ^ { 2 - } .$ , and their distribution fractions are highly pH-dependent. # 2.5. Impact of Common Anions

In the present study, $\mathrm { S O } _ { 4 } { } ^ { 2 - }$ , $\mathrm { C l ^ { - } }$ , and $\mathrm { P O } _ { 4 } { } ^ { 3 - }$ were selected to investigate their effects on the removal of AO7 in the $\Nu a H C O _ { 3 } / \mathrm { N a C l O } / \mathrm { R u ( I I I ) }$ system, as they are ubiquitous in various natural waters and wastewaters, and their presence may promote, inhibit, or have no obvious effect on the removal of contaminants from water, depending on the situation [22,36–38]. As depicted in Figure 5a,b, the removal of AO7 was not significantly affected in the presence of $\mathrm { S O } _ { 4 } { } ^ { 2 - }$ and $\mathrm { C l ^ { - } }$ at concentrations ranging from 1 to $1 0 0 ~ \mathrm { m M }$ These results showed that $\mathrm { S O } _ { 4 } { } ^ { 2 - }$ and $\mathrm { C l ^ { - } }$ had little effect on the removal of AO7, implying that the dominant reactive species $\scriptstyle \mathrm { R u ( V ) = O }$ was not insensitive to $\mathrm { S O } _ { 4 } { } ^ { 2 - }$ and $\mathrm { C l ^ { - } }$ . These phenomena can also be attributed to their low oxidation/reduction reactivity with the primary oxidant $\mathrm { R u ( V ) { = } O }$ [21]. In contrast, the removal of AO7 was significantly inhibited in the presence of the same concentration of $\mathrm { P O } _ { 4 } { } ^ { 3 - }$ (Figure 5c). It was also reported that $\mathrm { P O } _ { 4 } { } ^ { 3 - }$ can act as a chelating agent to form complexes with ${ \mathrm { R u } } ( { \mathrm { I I I } } )$ , and cause a strong inhibitory effect in the activation of periodate by $\mathrm { { R u ( I I I ) } }$ [33].

Moreover, organic compounds are widely present in waters and wastewaters in the form of natural organic matter (NOM) and may interact with the target contaminant and/or reactive species in AOPs, due to the presence of carboxyl groups and phenolic hydroxyls [39,40]. In this study, humic acid sodium was used as a representative of large molecular weight NOM. As shown in Figure 5d, the removal of AO7 was inhibited with the addition of NOM from 1 to $2 0 \mathrm { m g / L }$ . When the NOM concentration increased from 0 to $2 0 \mathrm { m g / L } ,$ the removal efficiency of AO7 decreased from $1 0 0 \%$ to $7 4 \%$ , indicating that NOM plays a detrimental role in the reaction process.

# 4. Conclusions

In the present study, the removal of AO7 by the $\mathrm { R u ( I I I ) } / \mathrm { N a C l O }$ system provided a novel oxidation system to efficiently degrade pollutants in water containing $\mathrm { H C O _ { 3 } } ^ { - } / \mathrm { C O _ { 3 } } ^ { 2 - }$ buffers. The results demonstrated that $1 0 0 \%$ of AO7 could be removed in the $\Nu \mathrm { a H C O _ { 3 } / N a C l O / R u ( I I I ) }$ system within $1 0 \ \mathrm { m i n }$ with a high rate constant of $0 . 4 5 8 5 \mathrm { m i n } ^ { - 1 }$ . Significantly, when $\mathrm { H C O } _ { 3 } ^ { - }$ was introduced into this system, it was found that the removal of AO7 was remarkably enhanced, and the rate constant increased by more than 2- to 4-fold at $\mathrm { p H } 6 . 9$ and 8.5. Interestingly, the key factor responsible for improved catalytic oxidation was the novel reactive species, ${ \mathrm { R u } } ( { \mathrm { V } } ) { = } \mathrm { O } ,$ which was confirmed by using PMSO as a probe compound. This oxidation system was further investigated by removing $5 0 ~ \mu \mathrm { M }$ of various pollutants at $\mathrm { p H } 8 . 5$ using $0 . 1 \mathrm { m M N a C l O }$ and $1 0 ~ \mu \mathrm { M }$ Ru(III). Satisfactory removal efficiencies for electron-rich groups compounds such as phenol, SMX, ACT, and BPA were obtained; however, no obvious removal of electron-rich organic electronwithdrawing group compounds such as BA and $p$ -CBA was determined, indicating the dominant role of high-valent Ru–oxo (e.g., $\mathrm { R u ( V ) = O ) }$ species in the reaction system. Using novel oxidation technology to create a complex of the $\mathrm { { N a C l O / R u ( I I I ) } }$ process and $\mathrm { H C O } _ { 3 } ^ { - }$ showed a wide application prospect in pollutant degradation, and has the potential for further designing effective oxidation processes of the treatment of actual wastewater under neutral or alkaline conditions.
