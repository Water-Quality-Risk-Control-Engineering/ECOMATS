# Aeration-Free Photo-Fenton-Like Reaction Mediated by Heterojunction Photocatalyst toward Efficient Degradation of Organic Pollutants

Yan Wang\*, Lianxin $L i ^ { + }$ , Puyang Zhou, Yu Gan, Weipeng Liu, Yiwen Wang, Yilin Deng, Hongping Li, Meng Xie,\* and Yuanguo Xu\*

Abstract: The regulation of peroxymonosulfate (PMS) activation by photo-assisted heterogeneous catalysis is under in-depth investigation with potential as a replaceable advanced oxidation process in water purification, yet it remains a significant challenge. Herein, we demonstrate a strategy to construct polyethylene glycol (PEG) well-coupled dual-defect $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ Sscheme heterojunction to degrade organic pollutants without aeration, which dramatically provides abundant active sites, excellent photo-thermal property, and distinct charge transport pathway for PMS activation. The degradation rate of $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ in anaerobic conditions shows a higher efficient rate $( 4 . 5 8 \mathrm { m i n } ^ { - 1 } \mathbf { g } ^ { - 2 } )$ than in aerobic conditions $( 1 . 6 7 \mathrm { m i n } ^ { - 1 }$ g-²2). Experimental evidence reveals that $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ promotes more rapid redox conversion of photoexcited electrons induced by defects with PMS under anaerobic conditions compared to aerobic conditions. Additionally, in situ experiments and DFT provide mechanistic insights into the regulation pathway of PMS activation via synergistic defectinduced electron, revealing the competitive effect between $\mathrm { O } _ { 2 }$ and PMS over $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ during the reaction process. The continuous flow reactor and flow cytometry results demonstrated that the $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } / P M S / V i s }$ system has remarkably enhanced stability and purification capability for removing organic pollutants. This work provides valuable insights into regulating the heterologous catalysis oxidation process without aeration through the photoexcitation synergistic PMS activation.

# Introduction

The existence of refractory organic pollutants in trace from aqueous environments poses significant risk to human health and ecosystems safety.["] The effective treatment of pollution using Fenton technology has been deeply investigated by Xing et al.,2] achieving an eco-friendly way for Fenton reactions by designing high-performance Fenton catalyst. Peroxymonosulfate (PMS)-based Fenton-like process by catalytic activation of PMS to produce highly reactive oxygen species (ROs), has been evidenced as a clean and effective technology to abatement persistent organic pollutant.[3] An asymmetric structure $\left( \mathrm { H O - O S O _ { 3 } } ^ { - } \right)$ and longer $\mathrm { O } { - } \mathrm { O }$ bonds of PMS can be activated by multiple approaches.4] Photocatalyst that continuously generate abundant photo-generated carriers under light irradiation are considered a more effective and cost-efficient strategy to activate PS.[5] Zheng et al. developed oxygen-vacancyinduced composite catalysts with synergetic effects, regulating photocatalysis through directional charge transfer to generate active radicals.[6] Reportedly, the removal efficiency of pollutant has no distinct difference under aerobic and anaerobic conditions in some Fenton-like degradation system due to the O in ROS not stemming from dissolved oxygen (DO) but PMS.[7] It is well recognized that the ROS in the conventional photocatalytic degradation system is usually over-reliant on oxygen $( \mathbf { O } _ { 2 } )$ and forced air convection, which limits its large-scale application in industry.[8] Statistics show that aeration constitutes 3551 percent of the total energy consumption in wasted water treatment, leading to the energy consumption of 57.5 billion kWh annually.[9] Hence, designing and developing a photo-Fenton-like system without aeration that effectively promotes PMS activation becomes crucial. But even more primary, constructing an ideal photocatalyst without aeration to synergistically promote PMS activation for water remediation remains a challenge.

Graphitic carbon nitride (CN) consists of earth-abundant elements, which attracted the wide attention of researchers due to its suitable band gap, visible-light response, and PMS activation capacity.[10] The fabrication of CN typically involves varying degrees of defects due to the inevitable loss of nitrogen atoms during the thermal polymerization of nitrogen-rich precursors.[11] As unique interior defects in CN, nitrogen vacancies $( \mathrm { V _ { N } } )$ facilitate photo-assisted PMS activation by attracting or interacting with negatively charged PMS.[12] However, the poor light absorption, rapid charge recombination, and slow PMS activation kinetics of single-component photocatalysts result in low degradation activity. Currently, the developed step-scheme (S-scheme) heterojunction possesses a unique charge migration pathway and strong photo-redox ability (Figure S1),[13] which have received widespread attention over pollutant removal system.

The typical cobalt (Co) based Fenton-like process has been demonstrated to be an effective for PMS activator.[14] Zhang et al. effectively activated PMS by introducing Co active center into the structure of CN to generated ROSs.[15] Metalorganic framework (MOF) subclass, zeolite imidazolate framework (ZIF-67) as precursor derived cobaltosic oxide $\left( \mathrm { M - C o } _ { 3 } \mathrm { O } _ { 4 } \right)$ photocatalyst,[16] has been proven to enhance the stability and electrical conductivity for PMS activation.[1] Besides, $\mathbf { V } _ { \mathrm { O } } { - } \mathbf { M - } \mathbf { C } \mathbf { o } _ { 3 } \mathbf { O } _ { 4 }$ with oxygen vacancies $\mathrm { ( V _ { O } ) }$ could provide plentiful active sites, increasing electron generation and enhancing ROS production.[18] Therefore, the abundant active site ( $\mathrm { \Delta V _ { O } } .$ $, \mathrm { C o } ^ { 2 + } {  } \mathrm { C o } ^ { 3 + } )$ and suitable band gap of $\mathbf { V } _ { \mathrm { O } } { - } \mathbf { M - } \mathbf { C } \mathbf { o } _ { 3 } \mathbf { O } _ { 4 }$ theoretically is an ideal catalyst for activating PMS and establishing S-scheme heterojunction CN with natural nitrogen defects $\mathbf { \left( \mathbf { C N } _ { x } \right) }$ . Although CN has been used to support compositing $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ in pollutant degradation,[19] the profoundly investigated interaction between $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ with CN as support still deserves discussion. To our knowledge, the research in the S-scheme $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ with dual-defect photocatalyst system without aeration enhancing PMS activation to degrade organic pollutant is still in virgin territory.

Hence, we introduce a polyethylene glycol (PEG)- assisted construction of an S-scheme heterojunction $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ with dual defects for heterogeneous catalysis, synergistically accelerating PMS activation under photoexcitation without aeration. As a result, $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ with excellent stability, appropriate photo-thermal properties, and unique PMS activation manner are prepared, and high efficiency mineralization pollutant is achieved. The degradation mechanism over $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ under aerobic and anaerobic conditions, utilizing the pathway of synergistic PMS activation and photoexcitation, has been thoroughly investigated, revealing a novel avenue for developing PMS-activated functional materials with efficient photoelectron transfer.

# Conclusion

In summary, dual-vacancy S-scheme heterostructure was successfully constructed by incorporating $\mathbf { V } _ { \mathrm { O } ^ { - } } \mathbf { M } \mathbf { - } \mathbf { C } \mathbf { o } _ { 3 } \mathbf { O } _ { 4 }$ nanocages with natural $\mathbf { N }$ defect modified $\mathrm { C N _ { x } }$ using PEG, displaying excellent PMS activation ability synergized with photoexcitation. The degradation rate of $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ in anaerobic conditions shows a higher efficient rate $( 4 . 5 8 \mathrm { m i n } ^ { - 1 } \mathbf { g } ^ { - 2 } )$ than in aerobic conditions $( 1 . 6 7 \mathrm { m i n } ^ { - 1 } \mathrm { g } ^ { - 2 } )$ , outperforming typical heterogeneous heterojunction catalyst degradation systems. In situ experimental and DFT studies reveal that defect-induced electron transfer regulates PMS activation synergistic photoexcitation, elucidating the competitive interaction between $\mathrm { O } _ { 2 }$ and PMS on $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ Furthermore, the continuous flow reactor and ecotoxicity experiments demonstrated that photoexcitation $\mathrm { V _ { o } { - } M { - } C o _ { 3 } O _ { 4 } @ C N _ { x } }$ synergistic activated PMS novel oxidation system had excellent stability and was suitable for advanced oxidation in sustainable water treatment applications. This work offers a novel strategy for regulating the PMS activation process synergistic photoexcitation S-scheme heterojunction, developing a promising catalytic oxidation system toward actual environmental cleanup without aeration.
