# . Introduction

Bisphenol A is extensively used as a plasticizer to produce epoxide resin for polycarbonate, paints, plastics and other polymer products with 4.6 million tons of annual production in the world [1-3]. The extensive consumption of BPA results in its collection in the environment [4]. As stated by earlier research, 55 countries have reported BPA levels ranging from 0 to $6 3 . 6 4 \mathrm { m g L } ^ { - 1 }$ [5]. As a typical endocrine-disrupting compound (EDC), it has various dangerous effects on the both genital and endocrine systems of aquatic animals, terrestrial animals and human beings [6,7].

The European Food Safety Authority (EFSA) and the United States Environmental Protection Agency (USEPA) have established a $5 0 ~ \mu \ g$ $\mathbf { k } \mathbf { g } ^ { - 1 }$ tolerable daily intake and $1 0 0 \mu \mathrm { g } \mathrm { L } ^ { - 1 }$ total allowable concentration of BPA for drinking water [6,7,8]. Because of its hydrophobicity and structural stability, BPA degrades slowly in the environment [9,10]. As a result, it is critical to develop an effective method for consistently degrading the BPA in order to maintain ecological health and environmental sustainability. Various treatment technologies such as adsorption, biodegradation, membrane/nanofiltration, ozonation/advanced oxidation processes (AOPs), photodegradation, and photo-Fenton methods have been applied for the last few years and were observed to be very efficient in BPA removal [11-13].

But, the widespread literature review illustrates that each treatment technology has its own particular limitations and advantages. For example, adsorption illustrated unique sorbent properties, surface modification enhanced the adsorption properties more than pure adsorbent. Similarly, modified photocatalysts showed complete mineralization of BPA during the photocatalytic degradation, while ozonation required additional information to optimize the process for real-time application [5,11]. The $\cdot _ { \mathrm { O H } }$ radicals formation from hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ is a source of BPA reduction during the Fenton process, whereas the photo-Fenton process illustrated the higher removal of BPA than only the Fenton process [12-14] Moreover, electrochemical treatment technologies required higher energy consumption and high capital cost of treatment Similarly, high power consumption for pressure generation and membrane fouling are some of the main disadvantages of membrane nanofiltration [2,10,11,14]. BPA elimination by the biodegradation method requires a long incubation time and a specific procedure according to the microorganisms used.

Recently, sulfate $( S O _ { 4 } ^ { \bullet \cdot } )$ radical (SR) based SRAOPs have been effectively used to degrade the BPA via the electrostatic interaction, hydrogen bonding and $\pi \mathfrak { - } \pi$ interactions mechanism [15-17] because $S O _ { 4 } ^ { \bullet \bullet }$ is a strong oxidant $( \mathrm { E } ^ { \circ } = 2 . 5 \mathrm { - } 3 . 1 5 \mathrm { V }$ vs SHE) with a longer half-life $\left( \mathrm { { t } _ { 1 / 2 } } \right)$ of $3 1 \mathrm { - } 4 0 \times 1 0 ^ { - 6 } s$ and reactivity over a wide solution $\mathtt { p H }$ range (28) than others reactive oxidation species (ROS) such as $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ $( \mathrm { E } ^ { \circ } = 1 . 8 – 2 . 7$ $\mathrm { V } , \mathrm { t } _ { 1 / 2 } < 1 \mu s ; \mathrm { p H }$ dependent), $0 \mathbf { \overline { { 2 } } } ^ { \bullet \bullet }$ $( \mathrm { E } ^ { \circ } = 1 . 2 3 \ : \mathrm { V } )$ , HO $\operatorname { E } ^ { \circ } = 1 . 7 8 \operatorname { V }$ and $s 0 _ { 5 } ^ { - \bullet }$ $\mathbf { \tilde { E } } ^ { \circ } = 0 . 8 1 \pm 0 . 0 2 \ : \mathrm { V } )$ [18-20]. Generally, various ROS are produced by the heterogeneous and homogeneous activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $\begin{array} { r l } { ( \mathbb { E } ^ { \circ } } & { { } = } \end{array}$ $1 . 8 2 { - } 2 . 8 5 \ \mathrm { V } )$ , peroxydisulfate (PDS) and PMS $( \mathrm { E } ^ { \circ } = 1 . 8 2 \ : \mathrm { V } _ { \cdot }$ . Various activation approaches have been reported in the literature such as transition metals (TMs) ions or TM oxides [21-24], carbon materials, and energy-based methods i.e., heat [25], ultrasound [23,26], and UV [27], etc.

Among these approaches, TMs and TM oxides like as Mn-, Co-, Ni-, and Cu- have been effectively used for the PMS activation to produce the $S O _ { 4 } ^ { \bullet - }$ [28-30]. Only a few studies are reported on PMS activation with nano $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ . For example, [18] proposed the homogeneous reactions of ${ \mathsf { C o } } ^ { 2 + }$ with PMS activation but cobalt ions leaching poses a serious environmental problem, whereas, a limited literature reported heterogeneous activation of PMS with cobalt oxide catalysts including ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 } ,$ . $\mathrm { C o _ { 2 } O _ { 3 } }$ $\mathrm { C o O _ { 2 } }$ and CoO [13]. It was found that $\mathrm { C o _ { 3 } O _ { 4 } }$ spinel consisting of ${ \mathsf { C o } } ^ { 2 + }$ and ${ \mathsf { C o } } ^ { 3 + }$ ions exhibits excellent catalytic activity toward SRAOPs owing to its low ${ \mathsf { C o } } ^ { 2 + }$ leaching, effective activation rate, and high stability [31]. Anipsitakis et al. [32] first investigated that PMS activation with CoO and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ exhibited strong oxidation capacity for the mineralization of 2, 4-dichlorophenol (2, 4-DCP) with low cobalt leaching; Bandala et al. However, very few studies are available on the mechanism of spinel $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ during PMS activation, which could determine the catalyst's nature. Furthermore, no systematic study about the effects of water matrices on pollutant degradation in nano-- $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ systems has been done.

The present study proposed the heterogeneous mineralization of BPA via the $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ system. $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ spinel in nano-size and spherical form was prepared by solvent-free hydrothermal method. The effect of different treatment parameters such as initial solution pH $\mathrm { ( p H _ { o } ) }$ , PMS concentration, catalyst dose and water matrix components (HA, $\mathrm { C l ^ { - } }$ ,and $\mathrm { H C O } _ { 3 } ^ { - }$ ) on BPA degradation with nano $\mathrm { \cdot { C o _ { 3 } O _ { 4 } } / P M S }$ system were investigated. # The experimental procedure and t-up

The BPA degradation study was performed in batch experiments using $2 5 0 \ \mathrm { m L }$ glass bottles. Generally, $1 0 0 \ \mathrm { m L }$ of the solution was selected to perform the experiments at different concentrations of BPA and PMS by mixing the solution at different temperatures on a magnetic stirrer. During the experiments, the initial pH of the solution was adjusted by adding NaOH and $\mathrm { H _ { 2 } S O _ { 4 } }$ . At this point, the catalyst was mixed to start the reaction. The sample aliquots $\mathrm { ( 1 . 0 ~ m L ) }$ were taken after a certain interval and then treated with excess methanol to quench reactions. Then, the quenched samples were filtered via a $0 . 2 2 ~ \mu \mathrm { m }$ polyethersulfone (PES) membrane and analyzed within $\mathbf { 2 4 } \mathrm { h }$ In contrast, the samples were collected and measured without a quencher for peroxide analysis.

In order to know the role of major oxidants, p-benzoquinone (BQ), Lhistidine, and tert-butyl alcohol (TBA) were selected as scavenging agents for $\mathrm { O } _ { 2 } ^ { \bullet - }$ , $^ 1 0 _ { 2 } ,$ and $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ , respectively, whereas ethanol (EtOH) scavenger was used for the identification of both $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ and $S O _ { 4 } ^ { \bullet - }$ [21,25, 36]. The molar ratio of $1 / 1 / 2 0 0$ were used for BPA, oxidant, and scavenger, respectively during the radical detection experiments and the experiments were performed at the optimum treatment conditions.

# 2.4. Analytical measurements

During the treatment, BPA samples were collected at different time intervals. The collected samples were filtered before analysis. Highperformance liquid chromatography (HPLC, Waters, India) with a column configuration of $3 . 9 \mathrm { m m } \times 1 5 0 \mathrm { m m }$ coupled with a UV detector at $2 7 6 \ \mathrm { n m }$ was used to know the change in concentration during the treatment at different time intervals. A mixed HPLC-grade solvent system of acetonitrile and water $( 6 0 { : } 4 0 \mathrm { v / v } )$ at a flow rate of $1 \mu \mathrm { L } \operatorname* { m i n } ^ { - 1 }$ was selected as a mobile phase for this system. Gas chromatography-mass spectroscopy (GC-MS, Perkin Elmer, USA) analysis of the samples were performed using the MS model of Clarus SQ8C coupled with GC model of Clarus-680 with Elite 5-MS consisting of $3 0 \mathrm { ~ m ~ } \times \mathrm { ~ 0 . 2 5 ~ m m }$ capillary column. Helium at a flow rate of $1 . 5 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ was used as the carrier gas. At $2 2 0 ~ ^ { \circ } \mathrm { C }$ split-less mode, $1 ~ \mu \mathrm { L }$ aliquots of samples were injected and the GC temperature program was set in the following order: $4 0 ~ ^ { \circ } \mathrm { C }$ was selected as the starting temperature, after a $5 \mathrm { { m i n } }$ hold, the column temperature was increased from 40 to $2 0 0 ~ ^ { \circ } \mathrm { C }$ at $1 0 \ \mathrm { ^ { \circ } C } \ \mathrm { m i n ^ { - 1 } }$ then it was held again for $5 \mathrm { { m i n } }$ and finally, the temperature increased from 200 to $2 3 0 ^ { \circ } \mathrm { C }$ at the rate of $5 \mathrm { ^ { \circ } C } \operatorname* { m i n } ^ { - 1 }$ . For the qualitative analysis of the samples, two temperatures i.e., $1 7 0 ~ ^ { \circ } \mathrm { C }$ and $2 0 0 ~ ^ { \circ } \mathrm { C }$ were selected for the ion source temperature and transfer line, respectively at $7 0 ~ \mathrm { e V }$ electron impact (EI) mode using the $m / z$ range of 40500 amu in a full scan mode. NIST and Wiley Library were used to identify the unknown peaks of the samples.

Before and after the treatment, the sample's chemical oxygen demand (COD) were measured by using the double-beam UV—visible spectrophotometer (HACH, DR-5000) coupled with a digestion unit (HACH, DRB-200). An atomic absorption spectrometer (AAS) was used to measure the concentrations of dissolved Co ions. To detect the effects of the water matrices, the known concentration of different salts i.e., NaCl, $\mathrm { N a H C O _ { 3 } }$ ${ \mathrm { N a H P O } } _ { 4 }$ and humic acid (HA) were mixed in BPA solution before the addition of an oxidant. Scavenger test analysis was performed to know the effect of reactive oxidation species. All the experimental runs were done in triplicate.

# 3.2. PMS activation performance with $C o _ { 3 } O _ { 4 }$

The catalytic activity of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ during PMS activation was tested for BPA reduction. Fig. 3a showed that BPA was practically totally degraded by the $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ system within $1 2 0 \mathrm { m i n }$ , while $< 1 0 \%$ and about $3 4 \%$ BPA were degraded by PMS and nano- ${ \bf \cdot C o _ { 3 } O _ { 4 } }$ alone, respectively in the identical treatment conditions. A comparative study on the catalytic performance of commercial $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ showed that only $1 2 \%$ and $3 0 \%$ BPA were degraded with $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ alone and $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ system, respectively, while a rapid degradation $( > 9 0 \%$ BPA was occurred with nano- $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ in $1 2 0 \mathrm { m i n }$ at $\mathrm { p H } 7 . 0$ (Fig. 3a). These results confirmed that the nano- $\mathrm { C o _ { 3 } O _ { 4 } }$ and PMS system have a synergistic effect on the efficient reduction of BPA. As shown in Fig. 3b, BPA reduction with $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ system followed pseudo-first-order kinetics with an observed rate constant $( \mathbf { k _ { \mathrm { o b s } } } )$ of $0 . 0 1 2 3 \mathrm { m i n } ^ { - 1 }$ .

The rate constant of BPA degradation with $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ alone decreased comparatively during the course of the reaction, possibly because the reactive sites on the $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ surface were occupied by ${ \mathsf { C o } } ^ { 2 + }$ and ${ \mathsf { C o } } ^ { 3 + }$ and/or the oxidative by-products of BPA [38]. # 3.3.2. Effect of solution pH

Solution pH is an extremely crucial factor during the BPA degradation with $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ system due to its effect on the catalyst surface, radicals' transformation, and organic contaminant species [35]. The removal of BPA was reported within the range $5 \mathrm { - } 2 8 \%$ or $3 { - } 1 8 \%$ at different pH range with $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and PMA alone, respectively (Fig. S8). These results showed that the removal of BPA by PMS and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ alone could be ignored at different pH values.

Fig. 4c showed that the BPA degradation progressively increased when the solution pH was raised from 3 to 7, after that it decreased when the initial $\mathsf { p H }$ continued to increase from 7 to 11. It is observed that $1 0 \%$ BPA was degraded at a $\mathsf { p H }$ of 3.0 with a rate constant (kobserved) of $0 . 0 2 0 8 \mathrm { m i n } ^ { - 1 }$ , while maximum removal was achieved at a $\mathsf { p H }$ of 7.0 with a kobserved of $0 . 2 9 4 1 \mathrm { \ m i n } ^ { - 1 }$ , which is 14 times higher than the $\mathbf { k _ { 0 } b s e r v e d }$ at $\tt p H 3$ . BPA degradation consistently increased when the pH was increased to $\mathtt { p H } = 7$ , while the removal rate decreased when the solution $\mathsf { p H }$ increased from 7 to 11. This work confirmed that the decomposition or hydrolysis of PMS could be ignored in the selected pH range (Fig. S8). It was found that the solution pH could be affected by both PMS speciation and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ surface charge, while the changes in solution pH did not disturb the self-decomposition of PMS (Fig. S8), so, the interaction between PMS species and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ surface charge was the main attention. The different $\mathtt { p H }$ range affects the functional group of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ surface and PMS speciation.

Subsequently, the zero-point charge $\mathrm { ( p H _ { p z c } ) }$ of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ was determined at a $\mathrm { p H } { \sim } 6 . 8 $ , which means that the surface charge of $\mathrm { C o _ { 3 } O _ { 4 } }$ changes from a positive to a negative charge at this value (Fig. S9). The nano $\mathrm { \bf { C o _ { 3 } O _ { 4 } } }$ surface shows protonation (Eqs. (17) and (18)) and deprotonation (Eq. (19)) because the surface charge of nano ${ \bf \cdot C o _ { 3 } O _ { 4 } }$ changed between negative and positive at acidic and basic pH, respectively. To examine the effect of $\mathsf { p H }$ on BPA reduction, the $\mathsf { p H }$ changes were determined throughout the treatment and the results are illustrated in Fig. S10. It was detected that the final pH change $\mathrm { ( p H _ { f } ) }$ increased slightly at $\mathrm { p H } _ { \mathrm { o } }$ 3 and 5 due to the buffer effect of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ However, the solution $\mathrm { \ p H _ { f } }$ decreased noticeably at $\mathrm { p H } _ { 0 } 7 \mathrm { - } 1 1$ due to the release of $\mathrm { H } ^ { + }$ in ${ \mathrm { H S O } } _ { 5 } ^ { - }$ activation (Eqs. (20)(22)).

To detect reusability and catalytic stability of the nano- $\mathrm { \cdot { C o _ { 3 } O _ { 4 } } / P M S }$ system, five repeated cycles were performed. It was observed that the catalyst showed excellent catalytic stability even in five consecutive catalytic cycles of BPA reduction.

# 4. Conclusions

The present study proposed that $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ consisting of $\mathrm { C o } ^ { 2 + } /$ $( \mathrm { C o } ^ { 3 + } ) _ { 2 } \mathrm { O } _ { 4 } ,$ activates PMS via radical and non-radical mechanisms to generate various reactive species that effectively degraded the organic compounds. In the $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ system, low cobalt leaching with rapid BPA degradation was detected at neutral pH. The formation of radicals is favored by the interconversion of cobalt sites i.e., $( \mathsf { C o } ^ { 2 + } / ( \mathsf { C o } ^ { 3 + } ) _ { 2 }$ ,while a single cobalt atom catalyzed the non-radical PMS activation. The nonradical reactions favored the propagation reaction, while the radical reaction contributes to the ring cleavage and degradation of the byproduct. It was observed that about $9 2 \%$ of BPA was degraded in $8 0 \mathrm { { m i n } }$ with pseudo-first-order kinetics and gave the best fit for $\boldsymbol { \mathrm { n } } ^ { \mathrm { t h } }$ order kinetics models at neutral pH. The PMS and catalyst dosages showed a positive relationship with oxidative performance. The presence of anion and HA confirmed the small effects on BPA degradation. In addition, probable pathways of BPA alteration were planned based on the finding of the products. This approach was initiated to highlight specific contaminants with electron donor functional groups (EWG))/moieties. Considering the kinetics of the removal, long half-life and organic radicals' selectivity, this study provides a promising method for pollutant degradation in an aqueous solution.
