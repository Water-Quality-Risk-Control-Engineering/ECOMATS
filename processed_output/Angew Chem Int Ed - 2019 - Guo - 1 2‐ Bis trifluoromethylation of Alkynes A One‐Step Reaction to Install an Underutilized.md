# 1,2-(Bis)trifluoromethylation of Alkynes: A One-Step Reaction to Install an Underutilized Functional Group

Shuo Guo, Deyaa I. AbuSalim, and Silas P. Cook\*

Abstract: Modifying the electronic properties of olefins is the quintessential approach to tuning alkene reactivity. In this context, the exploration of trifluoromethyl groups as divergent electronic modifiers has not been considered. In this work, we describe a copper-mediated 1,2-(bis)trifluoromethylation of acetylenes to create $E$ -hexafluorobutenes $E$ -HFBs) under blue light in a single step. The reaction proceeds with high yield and $E / Z$ selectivity. Since the alkyne captures two trifluoromethyl groups from each molecule of bp $y C u ( C F _ { 3 } ) _ { 3 } ,$ mechanistic studies were conducted to illuminate the role of the reactants. Interestingly, $E$ -HFBs exhibit remarkable stability to standard olefin functionalization reactions in spite of the pendant trifluoromethyl groups. This finding has significant implications for medicine, agroscience, and materials.

T hydrophobicity, metabolic stability, and bioavailability, is widely found in organic structures in the context of medicines, agrochemicals, and organic materials.[1] While frequently connected to aromatic systems, the trifluoromethyl group can also be found appended to alkenes in many biologically active molecules and organic functional materials.[2] Interestingly, olefins bearing two trifluoromethyl groups remain rare but should possess unique properties. The ability to introduce trifluoromethyl groups into complex molecular architectures, however, presents a difficult proposition, even with modern organic chemistry. Installation of stereochemically defined $E$ . hexafluorobutenes $E$ HFBs) requires multistep synthesis, wherein the difficult-to-append trifluoromethyl groups are added separately or through the difunctionalization of hexafluoro-2-butyne, which is a gas at $2 5 ^ { \circ } \mathrm { C }$ [3] For example, the treatment of trans-1,2-diiodoalkenes with copper and $\mathrm { F S O } _ { 2 } \mathrm { C F } _ { 2 } \mathrm { C O } _ { 2 } \mathrm { M e }$ leads to the formation of $E$ HFBs,[4] and the treatment of arynes with a trifluoromethyl-ligated copper produces ortho-bis(trifluoromethyl)benzenes. [5c] Obviously, the direct difunctionalization of alkynes would offer advantages for both step- and atom-economy. [5]

Trifluoromethyl-adorned copper systems have proven robust, and numerous applications for aryl trifluoromethylation have been developed.[6] As early as the 1980s, stable copper complexes containing trifluoromethyl groups were synthesized and studied.[7] In 2015, Grushin et al. reported $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 3 }$ and related complexes that are bench-stable and easy to prepare.[8] While some reports described similar copper systems as high-valent $\mathrm { { C u } ^ { \mathrm { { I I I } } } }$ complexes, theoretical work as early 1995 showed that these structures possess filled 3d orbitals (i.e., ${ \mathrm { d } } ^ { 1 0 } )$ , in part due to the inversion of the ligand field caused by the $\mathrm { C F } _ { 3 }$ ligands.[9] Consequently, such copper complexes are more accurately described, and spectroscopically observed,[10] as $\mathrm { C u } ^ { \mathrm { I } }$ ,which has significant implications for reactivity.

Several groups have demonstrated that the unique reactivity of $\mathsf { b p y C u } ( \mathbf { C F } _ { 3 } ) _ { 3 }$ can be used for mono-trifluoromethylation. For example, Li and co-workers developed alkyl trifluoromethylation from halides or carboxylic acids (Scheme 1a),[1] and later formed trifluoromethyl ketones from aldehydes with $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 3 }$ (Scheme 1 b).[2] Liu et al. and our group disclosed benzylic $\mathrm { C } ( \mathrm { s p } ^ { 3 } ) { \mathrm { - H } }$ trifluoromethylation that can be employed for late-stage functionalization (Scheme 1 c).[13] Here, we describe the simultaneous introduction of two trifluoromethyl groups across alkynes using b $\mathsf { p y C u } ( \mathbf { C F } _ { 3 } ) _ { 3 }$ , persulfate and blue light to access $E$ -HFBs (Scheme 1 d). Under irradiation, $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 3 }$ liberates one trifluoromethyl radical. We found that the newly formed $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 2 } .$ . $\mathrm { ( O S O _ { 3 } H ) }$ also liberates a trifluoromethyl radical (Scheme 1e). The conditions provide a tandem radical and innersphere trifluoromethylation that we harness for the synthesis of $E$ HFBs.

With general access to a wide range of $E$ -HFBs, we sought to explore the reactivity of this unusual olefin and expand the currently very limited known reactions of $E$ HFBs. With two antiparallel trifluoromethyl groups, $E$ -HFBs are expected to be rather electron-deficient. Conversely, near cancellation of their dipoles might confer added stability. Remarkably, various attempts to leverage the electronic deficiency of the $E$ -HFB in 3c failed. For example, $E$ -HFBs fail to engage with Danishefsky diene[14] or furan[15] but are also inert to $\alpha$ -diazo esters,[16] catalytic Rh carbenes,[17] mCPBA,[18] and bromine, thus demonstrating that E-HFBs are much more stable than the parent styrene. Counterintuitively, the Os-catalyzed dihydroxylation of the $E$ HFB proceeded in $7 8 \%$ yield to produce the vicinal diol (see the Supporting Information). This stability has significant implications for fields ranging from medicinal chemistry to materials.

Based on the remarkable scope developed in Table 2, we thought this reaction might serve in the late-stage functionalization of bioactive molecules. To that end, a variety of alkyne-containing molecules were used to test whether this chemistry can offer direct access to $E$ -HFBs as a potentially new functional group. We found that the $E$ -HFB functional group could be easily installed in natural product scaffolds such as unnatural amino acids (4), steroid structures (6), and tocopherol (7). An alkyne-containing medicine with sensitive functionalities (5) could also be converted into novel $E$ HFB structures (Scheme 2).

To explore the role of oxidant and copper, a series of simple mechanistic reactions were conducted. First, deuterated solvent led to the detection of deuterated fluoroform $1 8 \%$ yield) under the standard reaction conditions when using 4-bromophenylacetylene (1a) as substrate (Sche$\mathrm { m e } 3 \mathrm { A }$ ), thus implying that quenching of trifluoromethyl radical by solvent competes with our desired reaction.[19] To further investigate the presence of trifluoromethyl radicals, complex 2 was irradiated with blue light in the presence of TEMPO (Scheme 3 B). Interestingly, the trifluoromethyl ether of TEMPO could be obtained in $3 0 0 \%$ yield relative to compound 2 with ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ , but only $6 0 \%$ yield without, thus suggesting that ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ interacts directly with copper to facilitate homolysis and generate trifluoromethyl radicals. This was further investigated under the standard reaction conditions by varying the ratio of substrate 1a to Grushin's reagent 2 with and without the oxidant (Scheme 3C). While a ratio of 1:1 without ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ provided low yield $( 3 2 \% )$ , the yield could be rescued (to $8 2 \%$ ) by increasing the ratio to 1:3 (Scheme 3 C). These reactions suggest that the ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ could facilitate the copper complex 2 to provide more trifluoromethyl radicals. Since these reactions revealed the critical role of ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ for the efficient release of trifluoromethyl groups from 2, we turned to DFT to better clarify these observations.

We chose phenylacetylene and employed DFT to calculate the relative Gibbs free energies for all intermediates and transition states (see the Supporting Information for computational details). The absorption of light by 2 results in the formation of the triplet complex 32, which elongates the axial $\mathrm { C u } { - } \mathrm { C F } _ { 3 }$ bond (Figure 1). This system decomposes into a trifluoromethyl radical and $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 2 }$ (I), which we used as our starting point for relative energies (Figure 1). The addition of the trifluoromethyl radical into the alkyne proceeds with an activation energy of 11.3 kcalmol-1 via transition state I-TS to produce an allenyl radical II, which is $- 2 8 . 7 \mathrm { k c a l m o l ^ { - 1 } }$ more stable than the trifluoromethyl radical (Figure 2). The conjugated allenyl radical explains the lack of reactivity for aliphatic alkynes. Allenyl radical $\mathbf { I I }$ recombines with the copper(II) species to form intermediate $\mathbf { I I I }$ via an energy barrier (to II-TS) of $1 2 . 8 \mathrm { k c a l m o l ^ { - 1 } }$ , with III being lower in energy $( - 4 3 . 6 \mathrm { k c a l m o l } ^ { - 1 } )$ than I. Intermediate III then undergoes reductive elimination to form the 1,2- (bis)trifluoromethylated product IV and $\mathrm { C u ^ { I } }$ This step (via III-TS) has an energetic barrier of $1 5 . 9 \mathrm { k c a l m o l } ^ { - 1 }$ , and was deemed rate-determining (Figure 2). Under these reaction conditions, the homolysis of persulfate into two hydrogen sulfate (or potassium sulfate) radicals was assumed. Consistent with the reactions in Scheme 3, the binding of sulfate to copper results in a $9 . 8 \mathrm { k c a l m o l ^ { - 1 } }$ reduction in the $\mathrm { C u } { - } \mathrm { C F } _ { 3 }$ bond-dissociation energy (see the Supporting Information for details). Moreover, the reductive elimination now proceeds with a lower barrier $( 4 . 3 \mathrm { k c a l m o l ^ { - 1 } }$ ), thereby changing the rate-determining step (RDS) to the radical addition via I-TS $( 1 1 . 3 \mathrm { k c a l m o l } ^ { - 1 } )$ . The change in RDS and lower overall transition-state energy explains the higher yield observed with persulfate since it allows radical addition to vastly outcompete the quenching of the trifluoromethyl radical by the solvent (see the Supporting Information for more details).

Finally, we employed $\mathrm { T D D F T } ^ { [ 2 0 ] }$ to examine the requisite wavelength of light for the excitation of this system (see the Supporting Information for computational details). Interestingly, there exist several transitions to the first excited state during the singlet-singlet excitation (see the Supporting Information), but the major transition promotes an electron from the HOMO-1 to the $\mathrm { L U M O } + 1$ (Figure 3). This transition had a calculated wavelength of $3 6 2 \mathrm { n m }$ and results in the formation of $\mathbf { \tau } ^ { 3 } \mathbf { I }$ after intersystem crossing. We found that the first excited state for the singlettriplet excitation, however, results from promoting an electron from the HOMO to the $\mathrm { L U M O } + 1$ with a calculated wavelength of $4 8 6 \mathrm { n m }$ . While this transition is spin-forbidden, there exist several examples of populating a triplet system from a singlet ground state.[21] Calculations suggest that UV irradiation induces a singlet-to-singlet excitation, followed by intersystem crossing to a triplet prior to $\mathrm { C u } { - } \mathrm { C F } _ { 3 }$ bond scission, whereas blue-light irradiation leads directly to a singlet-totriplet excitation. Further experiments will be needed to better understand these properties.

In conclusion, we have developed a method for the difunctionalization of alkynes with two trifluoromethyl groups to produce $E$ -hexafluorobutenes $E$ HFBs). Both trifluoromethyl groups come from a single equivalent of $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 3 }$ through a combination of persulfate and blue light $( 4 4 7 \mathrm { n m }$ ). Our mechanistic studies explore the photochemical properties and subtle changes in the reaction coordinates. We propose, for the first time, a role for persulfate in b $\mathrm { p y C u } ( \mathrm { C F } _ { 3 } ) _ { 3 }$ -based reactions wherein persulfate serves as an oxidant and offers a critical replacement ligand in the form of sulfate. The sulfate ligand changes the RDS of these transformations. Such insights should aid in the future design of reaction manifolds that employ $\mathrm { b p y C u } ( \mathrm { C F } _ { 3 } ) _ { 3 }$ .The reaction has excellent substrate scope and functional-group compatibility, providing the desired products in high yields. The chemistry functions well for the late-stage functionalization of alkynes in the presence of various functional groups and heterocycles. Moreover, the $E$ -HFBs demonstrate remarkable chemical stability toward a range of olefin functionalization reactions. This simple access to aromatic $E$ . HFBs provides exciting opportunities in medicinal chemistry, agroscience, and materials.
