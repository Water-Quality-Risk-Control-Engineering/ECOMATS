# . Introduction

Trace organic contaminants (TrOCs) such as pharmaceuticals, personal care products, pesticides and endocrine disrupting chemicals are found in the aquatic environment at low concentrations, i.e. ranging from ng/L to $\mu \mathrm { g } / \mathrm { L }$ [13]. Wastewater treatment plants (WWTPs) have been identified as a major pathway through the discharge of secondary effluent in the environment [1]. To remove these TrOCs from the secondary effluent, a change in the design and operation of WWTPs is needed [4]. More specifically, an extra polishing step should be introduced that focuses on the removal of biorecalcitrant TrOCs. Advanced oxidation processes (AOPs) are extensively investigated [2] and ozonation $\left( \mathbf { O } _ { 3 } \right)$ has recently been implemented in WWTPs in Switzerland and other countries for this purpose [5,6].

The mechanisms of the ozonation process are well-known, and control strategies for optimal ozone dosage have been investigated in recent years [5,710]. Ozonation depends on both direct ozone and indirect hydroxyl radical $( ^ { \bullet } \mathrm { O H } )$ reactions for the removal of TrOCs [11]. In a first phase, ozone quickly reacts with the effluent organic matter (EfOM), which initiates the production of $\bullet _ { \mathrm { O H } }$ Some TrOCs are also ozone-reactive, but their impact on the radical production is minimal in comparison to that of EfOM, given the lower concentrations at which TrOCs are present in the effluent $( \mu \ g / \mathrm { L }$ versus $\mathrm { { m g / L } }$ . This first phase is characterized by the instantaneous ozone demand (IOD), which represents the ozone that is consumed by the highly ozone-reactive EfOM components and inorganic ozone scavengers such as nitrite [12]. Although the radicals produced during this phase can contribute to the degradation of ozone-recalcitrant TrOCs [13], this is reduced at high IOD values because of lower or delayed $\bullet _ { \mathrm { O H } }$ exposures [14,15]. Therefore, in these effluents, it is crucial that higher ozone concentrations are added to exceed the IOD value and to achieve higher TrOCs removal [5]. It is critical that the TrOCs concentration or their removal can be monitored during ozone applications. However, TrOCs analyses are cost- and time consuming, and cannot be used as a real-time measurement in order to make changes in ozone dosage. Therefore, the use of surrogate measurements is suggested within a monitoring strategy to observe TrOCs removal. Spectral parameters such as UV absorbance at 254 nm $\mathrm { ( U V A _ { 2 5 4 } ) }$ and fluorescence are often investigated as surrogate parameters [5,7,9]. These parameters are easily measured on-site and are related to the water quality of the effluent. Hence, a reduction in the surrogate parameter intensity is observed as EfOM is oxidized by ozone and radicals during the process. This reduction can be correlated with the TrOCs removal. Typically, a (two-stage) linear relationship exists between the reduction in the intensity of the surrogate parameter and the TrOCs removal [5,7,9]. Correlation models are used to control the TrOCs removal in full-scale ozonation plants [1619].

As $\bullet _ { \mathrm { O H } }$ are easily scavenged by bulk organic components in the wastewater matrix, the ozonation process has proven to be less efficient for TrOCs removal in highly loaded wastewaters compared to e.g. spiked clean water which is often used as a model matrix. For example, Souza et al. [20] observed a decrease in reaction rate for atrazine (ATZ) removal by approximately a factor of 15 in secondary effluent compared to spiked clean water. Deniere et al. [21] observed a reduction in ATZ and chloramphenicol removal of respectively $6 0 ~ \%$ and $4 0 \ \%$ when changing the matrix from spiked clean water to secondary effluent. Therefore, there is an increased interest in AOPs that produce sulfate radicals $( S 0 _ { 4 } ^ { \bullet } )$ , as these are less scavenged by organic components due to their lower reactivity. For example, the reaction rate constant between $\bullet _ { \mathrm { O H } }$ and natural organic matter (NOM) varies between (1.4 $4 . 6 ) \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 }$ , while the reaction rate constant between $\mathsf { s o } \frac { \bullet } { 4 }$ and NOM is $( 0 . 4 6 - 8 . 2 ) \times 1 0 ^ { 7 } \ : \mathrm { M } ^ { - 1 } s ^ { - 1 }$ [2225]. The ozonation process can be upgraded to the ozone-activated peroxymonosulfate process $( \mathrm { O } _ { 3 } /$ PMS) which simultaneously generates both $\bullet _ { \mathrm { O H } }$ and $\operatorname { s o } \frac { \bullet } { 4 }$ from the reaction between ozone and PMS $( \mathrm { k } = 2 . 1 2 \times 1 0 ^ { 4 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ [26]. The pathway of radical formation is described below (Eq. 18) [26]:

$$

Most $\mathrm { O _ { 3 } / P M S }$ research has been performed on the removal of ozonerecalcitrant TrOCs in spiked clean water, while only a few studies are available about its application in real water matrices. Sbardella et al. [27] assumed that if both radicals are in solution at the same time, organic matter will react faster with $\bullet _ { \mathrm { O H } }$ than with $\mathsf { s o } \frac { \bullet } { 4 }$ , making the latter less scavenged and thus more available for TrOCs removal [27]. However, it has recently been observed that ${ \bullet } _ { \mathrm { O H } }$ are the dominant species during $\mathrm { O _ { 3 } / P M S }$ in natural waters and wastewater [21], while mainly $\mathsf { s o } \pmb { \varphi } ^ { . }$ are contributing to TrOCs removal in synthetic clean water [26,2830]. The $\mathsf { p H }$ of both water matrices was similar $\mathrm { ( p H = 7 . 5 - 8 . 2 ) }$ , hence, this shift in radical contribution could not be ascribed to $\mathsf { p H }$ changes. It was suggested that $\mathsf { s o } \frac { \bullet } { 4 }$ are transformed into $\bullet _ { \mathrm { O H } }$ via reactions with chloride in real waters [21]. Furthermore, competition has been noticed between PMS and organic matter for the consumption of ozone which reduced the removal efficiency of TrOCs during the $\mathrm { O } _ { 3 } /$ PMS process [21,31]. The results discussed above were obtained at high TrOCs concentrations (approximately $1 \ \mathrm { m g / L }$ and the studies mostly focussed on the removal of one TrOC. Hence, knowledge is missing about the performance of $\mathrm { O _ { 3 } / P M S }$ at low TrOCs concentrations and for mixtures of TrOCs. Furthermore, the applicability of spectral surrogate parameters to monitor TrOCs removal during the $\mathrm { O _ { 3 } / P M S }$ process has not been investigated yet. Hence, it is unknown how the existing correlation models developed for the ozonation process will change (or not) when PMS is added and if a correct ozone dosing would be possible while using these existing correlation models.

To fill these knowledge gaps about $\mathrm { { O _ { 3 } / P M S } }$ , the research goal of this study is threefold: (1) to evaluate the performance of $\mathrm { { O _ { 3 } / P M S } }$ for the removal of a mixture of TrOCs at environmentally relevant concentrations in a real water matrix, (2) to investigate the intensity reduction in spectral surrogate parameters during $\mathrm { O _ { 3 } / P M S }$ , and (3) to develop and evaluate the applicability of surrogate models as an ozone dose control tool in $\mathrm { O _ { 3 } / P M S }$ applications. This work is the first to investigate these research topics, in view of the practical application of the $\mathrm { O _ { 3 } / P M S }$ process for TrOCs removal from secondary effluent. To address the research objectives, the removal efficiency of $1 1 \ \mathrm { T r O C s }$ with a broad range in ozone reactivity $( 0 . 1 \leq \mathrm { k } _ { 0 3 } ( \mathrm { M } ^ { - 1 } s ^ { - 1 } ) \leq 1 0 ^ { 6 } ;$ ,see Table S1) was investigated with both ${ \mathrm { O } } _ { 3 } / { \mathrm { P M S } }$ and the conventional ozonation process (considered as a benchmark). The experiments were performed in secondary effluent spiked at realistic low $\mu \mathrm { g } / \mathrm { L }$ levels, and a range of ozone concentrations $\left( 0 . 8 { - } 1 2 . 3 \mathrm { m g } \mathrm { O } _ { 3 } { / } \mathrm { L } \right)$ was added. At the same conditions, radical exposure experiments were performed to get a more in-depth view of the mechanisms of the $\mathrm { O _ { 3 } / P M S }$ process.

# 2.3. Analytical methods

# 2.3.1. General

The ozone concentration in the stock solutions was measured by the indigo method [35]. PMS concentrations were measured by a spectrophotometric method using potassium iodide [36].

COD and nitrite concentrations were determined spectrophotometrically using Hach cuvettes (Hach LCK 1414 and LCK 341) and a DR6000 spectrophotometer (Hach, Belgium). The alkalinity was determined according to standard methods, i.e. by titration using a pH meter (HQ40d multimeter) [37]. Chloride and sulfate concentrations were also determined according to standard methods by using a Dionex ion chromatograph, equipped with an AS14A column $( 1 5 0 \times 3 . 0 \mathrm { m m }$ , $5 \mu \mathrm { m } \dot { }$ [37]. The composition of the mobile phase and regenerant is specified in Deniere et al. [21]. Turbidity was measured with a portable Hi 98703 (Hanna Instruments).

The instantaneous ozone demand (IOD) represents the rapid ozone consumption by highly ozone-reactive compounds in the matrix. $\mathrm { I O D } _ { \mathrm { P M S } }$ also includes the additional ozone consumption when PMS is added to the matrix. IOD and $\mathrm { { I O D } _ { P M S } }$ were determined according to the method of Bader and Hoigné (1981), which involves the quenching of the reaction after 5 s by adding an indigo solution [21].

# 2.4.2. Radical exposure and contribution

Radical probes were used to determine the radical exposure and contribution to TrOCs removal during the $\mathrm { O _ { 3 } / P M S }$ process. pNBA was used as an ${ \bullet } _ { \mathrm { O H } }$ probe, as the reaction rate constants express a high reactivity with $\mathbf { 0 } \mathrm { H } ( \mathrm { k } _ { \mathrm { O H } } = 2 . 6 \times 1 0 ^ { 9 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ and a low reactivity with ozone and $\mathsf { s o } \frac { \bullet } { 4 }$ $\mathbf { k } _ { 0 3 } < 0 . 1 5 \mathbf { M } ^ { - 1 } s ^ { - 1 }$ , $\mathrm { k } _ { \mathrm { S O 4 } } < 1 0 ^ { 6 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ [40]. ATZ was used as the $\operatorname { s o } \frac { \bullet } { 4 }$ probe, as it is reactive with both $\bullet _ { \mathrm { O H } }$ and $\operatorname { s o } \frac { \bullet } { 4 }$ $\mathbf { \boldsymbol { k } } _ { \mathrm { O H } } =$ $\mathbf { k } _ { \mathrm { S O 4 } } = 2 . 6 \times 1 0 ^ { 9 } \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ . Both probes are also not reactive with PMS: (1) pNBA is unlikely to react with PMS as electron withdrawing groups $\left( - \mathbf { N O } _ { 2 } \right)$ are not favourable for a non-radical reaction [41,42], and (2) ATZ reacts slowly with PMS $( \mathbf { k } = 0 . 0 4 \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ [43]. This has also been confirmed in additional experiments discussed in SI-Text 1. The kinetic equations that describe the degradation of ATZ and pNBA can be found in SI-Text 2. The reactions with ozone (pNBA, ATZ) and $\mathsf { s o } \pmb { \varphi } ^ { . }$ (pNBA) can be neglected, hence the equations can be simplified to:

$$

$$

$$
\ln \left( \frac { [ A T Z ] } { [ A T Z ] _ { 0 } } \right) = - k _ { O H , A T Z } \ \times \int [ O H ] d t - \ k _ { S O _ { 4 } , A T Z } \ \times \int [ S O _ { 4 } ] d t

Small differences were noticed between the removal patterns of the different TrOCs in both processes, depending on their ozone reactivity. At $0 . 5 \mathrm { { m i n } }$ (Fig. 2), the removal efficiencies of CHLOR, ATZ, FLU, AMA and METR were up to $1 9 ~ \%$ higher during ozonation than during $\mathrm { O } _ { 3 } /$ PMS. Especially for ATZ and CHLOR, ozone concentrations of at least $3 . 8 ~ \mathrm { m g / L }$ were needed to observe any removal with $\mathrm { O _ { 3 } / P M S }$ , whereas already higher removal was noticed during ozonation at lower ozone concentrations. However, at the same reaction time and at $0 . 8 \mathrm { m g } \mathrm { O _ { 3 } } / \mathrm { L }$ , $\mathrm { O _ { 3 } / P M S }$ shows to be more efficient (up to $2 7 \ \%$ higher removal than with ozonation) for the ozone-reactive TrOCs (AMI, VEN, CIP, LEVO, TRIM and DFC). At ozone concentrations equal to IOD and $\mathrm { I O D } _ { \mathrm { P M S } }$ , the TrOCs removal is approximately the same (i.e. less than $8 \%$ difference) for both processes, or slightly higher with ozonation for the ozonereactive compounds. From these observations, two important points of attention can be addressed.

First, ozone-recalcitrant TrOCs depend on radical reactions for their removal. Hence, the lower removal efficiencies during $\mathrm { O _ { 3 } / P M S }$ suggest that less radicals were available during ${ \mathrm { O } } _ { 3 } / { \mathrm { P M S } }$ at $0 . 5 \ \mathrm { m i n }$ , in comparison with ozonation. However, higher total radical exposures during $\mathrm { O _ { 3 } / P M S }$ were noticed when applying ozone concentrations equal to or higher than $2 . 6 \mathrm { m g } \mathrm { O _ { 3 } } / \mathrm { L }$ (Fig. 1A). This suggests that the main pathway of radical formation is via PMS (and not via bulk organic matter as in ozonation) which explains the higher observed total radical exposure. However, it appears that the (in)organic matrix highly scavenges these radicals, resulting in lower TrOCs removal efficiencies in comparison to ozonation. This might be caused by the fact that the (in)organic matrix encounters less direct ozone reactions during ${ \mathrm { O } } _ { 3 } / { \mathrm { P M S } }$ than in ozonation, which results in more residual ozone-reactive organic bulk compounds. These organic compounds are also highly reactive towards $\mathsf { s o } \pmb { \varphi } ^ { . }$ and ${ \bullet } _ { \mathrm { O H } }$ , which leads to a higher scavenging capacity for radicals [27]. Wert et al. [51] made a similar observation for the $\mathrm { O _ { 3 } / H _ { 2 } O _ { 2 } }$ process, i.e. ozonation showed $1 0 { - } 4 0 ~ \%$ higher $\bullet _ { \mathrm { O H } }$ exposure than $\mathrm { O _ { 3 } / H _ { 2 } O _ { 2 } }$ in waters with high ${ \bullet } _ { \mathrm { O H } }$ scavenging rate, leading to a reduced pCBA removal during $\mathrm { O _ { 3 } / H _ { 2 } O _ { 2 } }$ in comparison to ozonation.

Second, in $\mathrm { O _ { 3 } / P M S }$ , the ozone exposure of TrOCs is reduced at all ozone concentrations due to the extra ozone consumption by PMS. Nonetheless, highly ozone-reactive TrOCs were more efficiently removed during $\mathrm { O _ { 3 } / P M S }$ , compared to ozonation, at low ozone concentrations. This indicates that these compounds were also removed by radical pathways, as the reaction time $( 0 . 5 \ \mathrm { m i n } )$ was too short for removal through direct PMS oxidation [54]. Sbardella et al. [27] noticed that competition for $\operatorname { s o } \frac { \bullet } { 4 }$ occurs between pharmaceuticals and the electron-rich moieties of EfOM at low oxidant doses. Produced $\operatorname { s o } \frac { \bullet } { 4 }$ during this phase can thus be consumed by the highly ozone-reactive TrOCs and EfOM.

Similar removal patterns are observed for the low ozone-reactive TrOCs after $3 0 \ \mathrm { m i n }$ of reaction (Fig. 3), compared to $0 . 5 \ \mathrm { m i n }$ For some ozone-reactive TrOCs, more pronounced differences between both processes are noticed at $3 0 \mathrm { { m i n } }$ . Consequently, the absence of residual ozone and radicals is expected which makes it hard to understand the higher removal efficiencies at $3 0 ~ \mathrm { { m i n } }$ than at $0 . 5 \mathrm { { m i n } }$ of reaction time during $\mathrm { { O _ { 3 } / P M S } }$ .Therefore, the impact of direct PMS reactions with the 11 selected TrOCs was investigated (Fig. S4). LEVO and CIP show to be the most susceptible to PMS reactions, as at least $6 0 ~ \%$ removal is observed after $3 0 \ \mathrm { m i n }$ .Recent literature confirms that fluoroquinolones, except flumequine, are susceptible for (unactivated) PMS oxidation [55,56]. Hence, their removal does not solely depend on reactions with ${ \bullet } _ { \mathrm { O H } }$ $\mathsf { s o } \pmb { \varphi } ^ { . }$ or singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ , but for example LEVO is primarily oxidized by PMS through Oaddition and dealkylation pathways [56]. However, at full-scale applications of $\mathrm { { O _ { 3 } / P M S } }$ , higher ozone doses $( >$ IOD) and short reaction times $\mathrm { 7 } 0 . 5 \mathrm { m i n } $ will be most likely used, which means that PMS oxidation will only be relevant for residual oxidation, for example in pipes.

The relationship between ΔTrOC and the surrogate intensity reduction was the best described by two linear curves. For the components with a low ozone reactivity $( \mathbf { k } _ { 0 3 } < 1 0 0 0 ~ \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ , this results in a moderate slope in the first phase and a steep slope in the second phase (up to 31 times higher). On the other hand, for highly and moderate ozone-reactive TrOCs $( \mathbf { k } _ { 0 3 } \geq 1 0 0 0 ~ \mathbf { M } ^ { - 1 } . s ^ { - 1 } )$ , a steep slope in the first phase and a moderate slope in the second phase (up to 9 times smaller) was noticed. This profile has been earlier reported for ozonation [5,17] and is confirmed in this work for the $\mathrm { O _ { 3 } / P M S }$ process. The inflection point was determined by minimizing the mean squared error between the predicted and experimental data, while also minimizing the (prediction) difference (∆y) between the two curves at the inflection point [17]. The location of the inflection point for the different surrogates is summarized in Table 3.

Two observations suggest that the first phase in the correlatior model between surrogate and TrOCs removal is dominated by the fast reactions occurring within the IOD phase of ozonation and $\mathrm { { O _ { 3 } / P M S } }$ . First, the TrOCs with high and moderate ozone reactivity $( \mathbf { k } _ { 0 3 } \geq 1 0 0 0$ $\mathbf { M } ^ { - 1 } . s ^ { - 1 } )$ obtain a removal efficiency of at least $9 0 ~ \%$ in both processes during this first phase. Second, results shown in Fig. 4 reveal that up to $4 0 ~ \% ~ \mathrm { U V A } _ { 2 5 4 }$ and $6 5 ~ \% ~ \mathrm { F m a x _ { 1 } }$ is removed during the IOD phase of the processes, which means that the inflection points observed in Figs. 5 and 6 are located before the IOD is reached.

The inflection points of the $\mathrm { U V A } _ { 2 5 4 }$ correlation models at both sampling times are located at a higher value in $\mathrm { O _ { 3 } / P M S }$ than in ozonation, while the opposite is observed in the fluorescence models. According to Chys et al. [17] the region before the inflection point is a representation of the fast direct ozone reactions that takes place during the ozonation process, while the second phase is more related to $\bullet _ { \mathrm { O H } }$ reactions. As direct ozone reactions are reduced in $\mathrm { O _ { 3 } / P M S }$ due to ozone consumption of PMS, other (radical) reaction pathways become more dominant during that first phase. At $0 . 5 ~ \mathrm { m i n }$ , more radicals were produced during the IOD phase in $\mathrm { O _ { 3 } / P M S }$ compared to ozonation (Fig. 1A). Thus, the higher inflection point in $\mathrm { O _ { 3 } / P M S }$ indicates that the $\mathrm { U V A } _ { 2 5 4 }$ surrogate intensity decreased to a larger extent by radicals than by ozone to obtain an equal removal of $> 9 0 ~ \%$ of the highly and moderate ozone-reactive TrOCs $( \mathbf { k } _ { 0 3 } > 1 0 0 0 \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ . The fluorescence surrogates have lower removal efficiencies, which suggests that the fluorophores are less susceptible for radical reactions.

At $3 0 \mathrm { { m i n } }$ , also direct reactions with PMS might become important. However, direct PMS oxidation appeared to have more impact on the TrOCs removal (as was seen for some TrOCs like CIP and LEVO, Fig. S4) than on the surrogate removal (Fig. 4). If the comparison is made between the models of $\mathrm { { O _ { 3 } / P M S } }$ at $0 . 5 \mathrm { { m i n } }$ and $3 0 \mathrm { { m i n } }$ , it is noticed that the inflection point has a lower value in the fluorescence models and a similar value in the $\mathrm { U V A } _ { 2 5 4 }$ models. This means that the control range of the first phase can be reduced in the fluorescence models using PMS. As this phase takes place at ozone concentrations below the IOD, the second phase will be of higher importance due to the higher radical production at ozone concentrations exceeding the IOD. Large control ranges within the reduction of a surrogate parameter are more favourable, as it provides a higher sensitivity for the prediction of TrOCs removal.

Hence, the second phase is the most useful to predict the removal of ozone-recalcitrant TrOCs as almost complete removal was already obtained for TrOCs with a $\mathbf { k _ { 0 3 } }$ of at least $8 \mathrm { M } ^ { - 1 } s ^ { - 1 }$ . At $0 . 5 \mathrm { { m i n } }$ , the slopes of the linear relationships are more similar among the different TrOCs during $\mathrm { O _ { 3 } / P M S }$ than during ozonation. For example, the relative standard deviation (RSD, $\%$ ), calculated for the slopes in the second phase of the 5 ozone-recalcitrant TrOCs, are $4 6 ~ \%$ and $4 8 ~ \%$ in respectively the $\mathrm { U V A } _ { 2 5 4 } .$ and $\operatorname { F m a x } _ { 1 }$ -based correlation model during the ozonation process, while these values were only $1 3 ~ \%$ and $1 7 ~ \%$ during $\mathrm { { O _ { 3 } / P M S } }$ . This smaller variation is advantageous for the prediction of the $\mathrm { T r O C s }$ removal, as the value of the slope can be seen as a constant which simplifies the data processing. The surrogate models of the ozonation process also show this advantage, but at longer reaction times $\mathrm { 3 0 } \mathrm { m i n } \dot { }$ . For example, the RSD value of the slopes is $2 2 ~ \%$ for both $\mathrm { U V A } _ { 2 5 4 }$ and $\operatorname { F m a x } _ { 1 }$ -based correlation models during ozonation at $3 0 ~ \mathrm { \ m i n }$ . An explanation for these differences in reaction time can be found in the radical production. As seen in Fig. 1, similar radical exposures were obtained between $\mathrm { { O _ { 3 } / P M S } }$ at $0 . 5 \ \mathrm { m i n }$ and ozonation at $3 0 \ \mathrm { m i n }$ The ozonation process needs longer reaction times to produce radicals, while $\mathrm { O _ { 3 } / P M S }$ has a fast radical production due to the reaction between ozone and PMS. Hence, the surrogate-based prediction models can be applied with high accuracy at short reaction times $\left[ 0 . 5 \mathrm { { m i n } } \right]$ during $\mathrm { O _ { 3 } / P M S }$ , but not during ozonation.

All these observations show the need for specific surrogate-based prediction models for the $\mathrm { O _ { 3 } / P M S }$ process. If not, using the prediction models of the ozonation process will result in under- or overpredicting the required ozone concentration. For example, if $5 0 \%$ ATZ and CHLOR removal is targeted by $\mathrm { { O _ { 3 } / P M S } }$ , and we assume a reaction time of 0.5 min, the model of ozonation will predict 1.7 (ATZ) and 1.3 (CHLOR) times higher $\Delta \mathrm { U V A } _ { 2 5 4 }$ values (and thus higher ozone concentrations) than that are needed during $\mathrm { { O _ { 3 } / P M S } }$ However, if for ozonation the correlation model is used at $3 0 \mathrm { { m i n } }$ reaction time, it will underestimate the needed ozone concentration and thus a lower TrOCs removal will be obtained.

# 4. Conclusions

This work has investigated for the first time the performance of the $\mathrm { O _ { 3 } / P M S }$ process for the removal of a broad range of selected TrOCs at environmentally relevant conditions. The reaction between ozone and PMS already takes place within the IOD phase, which indicates a high level of competition between PMS and bulk organic matter for the consumption of ozone. After $0 . 5 ~ \mathrm { \ m i n }$ of reaction and at ozone concentrations exceeding the IOD, the total radical exposure in $\mathrm { O _ { 3 } / P M S }$ was already at the same level as after $3 0 \mathrm { m i n }$ of conventional ozonation. Hence, the $\mathrm { O _ { 3 } / P M S }$ process shows better removal efficiencies for ozonerecalcitrant TrOCs at short reaction times $( 0 . 5 \mathrm { m i n } )$ and at ozone concentrations exceeding the IOD of the effluent. This is advantageous in terms of reactor design, as shorter contact times and smaller reactors can be applied. The fast ozone-reactive TrOCs have a similar removal efficiency in ozonation and $\mathrm { O _ { 3 } / P M S }$ at $0 . 5 \ \mathrm { m i n }$ . Overall, the increase in TrOCs removal efficiency during $\mathrm { { O _ { 3 } / P M S } }$ is limited (up to $2 4 \%$ at 12.3 $\mathrm { m g } \ O _ { 3 } / \mathrm { L }$ in comparison to ozonation. The process should still be optimized to achieve higher TrOCs removal during $\mathrm { { O _ { 3 } / P M S } }$ in order to increase its added value for implementation in practice. For example, recent research has shown that the TrOCs removal can be enhanced by adapting the ozone dosing strategy from one-time dosing to sequential dosing [61]. Further research could also focus on the type of scavenging reactions in effluent, and on appropriate techniques to reduce scavenging (e.g. by use of pre-filtration techniques).

Next to that, this work demonstrates that  also for the $\mathrm { O _ { 3 } / P M S }$ process  spectral surrogates, i.e. $\Delta \mathrm { U V A } _ { 2 5 4 }$ and ΔFmax (fluorescence), have the potential to be used in ozone dosage control strategies to maintain a certain TrOCs removal. The established correlation models are most efficiently used in differential ozone dosage control strategies, taking into account the load, scavenging capacity and reactivity of the water matrix, which can highly influence the efficiency of TrOCs removal [5]. In future research, the correlation models could even be extended to predict the radical scavenging capacity using surrogate measurements [58], and should be validated with different secondary effluents. The intensity of both surrogates decreased in a similar way in both the ozonation and ${ \mathrm { O } } _ { 3 } / { \mathrm { P M S } }$ process, which indicates that the extra radicals that were produced in $\mathrm { O _ { 3 } / P M S }$ do not result in additional removal of chromophores and fluorophores. However, some differences were noticed in the surrogate models developed to predict TrOCs removal, which makes the correlations not interchangeable between ozonation and $\mathrm { { O _ { 3 } / P M S } }$ .
