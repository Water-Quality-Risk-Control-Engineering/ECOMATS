# Interface and Defect Engineering in 3D $\mathsf { C o } _ { 3 } \mathsf { O } _ { 4 - \mathsf { O v } } / \mathsf { T i O } _ { 2 }$ to Boost Simultaneous Removal of BPA and $\mathbb { C } r ( \mathbb { V } | )$ upon Photoelectrocatalytic/Peroxymonosulfate (PEC/PMS) System

Yu Hu, Yuzhou Jin, Yuqing Gao, Mingfang Li, Xuejiang Wang, Haiying Ma, and Ya-nan Zhang\*

The combination of photoelectrocatalytic (PEC) and peroxymonosulfate (PMS) is an innovative strategy for environmental treatment. And fabricating a highly efficient photoelectrode is the most pivotal factor in PEC reactions. This study designs an advanced $\mathsf { C o } _ { 3 } \mathsf { O } _ { 4 \cdot \mathsf { O v } } / \mathsf { T i O } _ { 2 }$ photoelectrode by a dual-modification strategy encompassing interface engineering and defect engineering. The photoelectric characterization validates the synergy of oxygen vacancies and dual heterojunctions. Simulated electron density distribution and Kelvin probe force microscopy (KPFM) elucidate the charge transfer pathway between ${ \mathsf { C o } } _ { 3 } { \mathsf { O } } _ { 4 \cdot { \mathsf { O v } } }$ and $\mathrm { T i O } _ { 2 }$ • $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } }$ and ${ \pmb S } { \pmb O } _ { 4 }$ · are confirmed to be primarily responsible for the BPA oxidation in PEC/PMS system by radical scavenger experiments and the EPR technique. And the attack sites of BPA are precisely identified based on the Fukui index. Furthermore, density functional theory (DFT) calculations testify that ${ \mathsf { C o } } _ { 3 } { \mathsf { O } } _ { 4 \cdot { \mathsf { O v } } }$ can improve the adsorption capacity of PMS and reduce the energy barrier of the reaction process, while XPS analysis showed ${ \mathsf { C o } } ^ { 3 + } / { \mathsf { C o } } ^ { 2 + }$ redox couple can accelerate PMS activation. Enhanced anode oxidation can effectively promote cathode reduction and consequently $\mathsf { C o } _ { 3 } \mathsf { O } _ { 4 \cdot \mathsf { O v } } / \mathsf { T i O } _ { 2 }$ -PMS/PEC system presents a superior removal of both pollutants within only 15 min with fast kinetics $( 0 . 1 5 \mathrm { \ m i n ^ { - 1 } }$ for BPA, $\pmb { 0 . 2 9 \mathrm { \ m i n ^ { - 1 } } }$ for $\mathsf { c r } ( \mathsf { v } \mathsf { I } )$ ). This work provides unique insight into designing a highly efficient PMS/PEC system for simultaneous pollutant treatment.

# 1. Introduction

With the rapid advancement of society and urbanization, water pollution has emerged as a global concern.[1] The primary source of pollutants in water is mainly untreated industrial wastewater that consists of inorganic and organic pollutants,[2] resulting in combined pollution with altered physical and chemical properties and biological toxicity.[3] Bisphenol A (BPA), a prevalent emerging pollutant, is ubiquitous in aquatic ecosystems through discharge from the petrochemical industry and polycarbonate plastic processing.[4] $\mathrm { C r } ( \mathrm { V I } )$ is a known human carcinogen that is widely present in wastewater from various industrial processes.[5] BPA and $\mathrm { C r ( V I ) }$ frequently co-exist in industrial water at concentrations exceeding specified thresholds, which is difficult to simultaneously remove due to their complex interactions.[6] Therefore, it was urgent to develop an effective and sustainable method to achieve the simultaneous treatment of co-existed BPA and $\mathrm { C r } ( \mathrm { V I } )$ in wastewater.

Currently, the existing work on the simultaneous removal efficiency of BPA and $\mathrm { C r } ( \mathrm { V I } )$ is based on photocatalytic methods.[7] This method is timeconsuming, and most require more than

4 h for complete removal of pollutants.[8] Photoelectrocatalytic (PEC) technology utilizes the photoelectric effect and external bias to facilitate the transfer of photogenerated electrons to the cathode,[9] thereby enhancing the efficiency of carrier utilization.[10] And the electrode material is easily recyclable with promising practical applications.[11] At present, PEC methods have rarely been reported for the simultaneous removal of BPA and $\mathrm { C r } ( \mathrm { V I } )$ . In our previous work, BPA oxidation and $\mathrm { C r ( V I ) }$ reduction were carried out at the anode and cathode, respectively, enabling simultaneous removal of both pollutants.[12] Notably, it was demonstrated that the oxidation rate has a significant impact on the cathodic reduction efficiency. Here, we proposed 2 strategies for improving anodic oxidation efficiency to achieve efficient synergistic removal. One is to construct an efficient photoanode. $\mathrm { T i O } _ { 2 }$ has been extensively researched as a semiconductor material due to its exceptional chemical stability and non-toxic nature.[13] However, the practical application of $\mathrm { T i O } _ { 2 }$ is limited by its low utilization of visible light and the high recombination rate of photogenerated carriers.] In general, both interface engineering[15] and defect engineering[16] are common methods for enhancing the performance of photoelectrocatalytic materials. The other one is coupling PEC with other technologies[17] to facilitate the oxidation process. Peroxymonosulfate (PMS)based advanced oxidation processes (AOPs) could generate $\mathrm { S O } _ { 4 } \mathrm { ^ { \cdot - } }$ , which is advantageous in strong oxidation capability, long lifespan, wide $\mathsf { p H }$ range, and effectively degrading organic pollutants.[18] In recent years, PEC combined with PMS in a deep oxidation treatment system (PEC/PMS) has attracted some attention, in which the anodic oxidation produces reactive oxygen species $\left( \cdot \mathrm { O H } , ^ { 1 } \mathrm { O } _ { 2 } \right)$ , etc) and the $e ^ { - }$ in cathode reacts with PMS to produce $\mathrm { S O } _ { 4 } \mathrm { ^ { \cdot - } }$ for pollutant removal. [19] Meanwhile, the activation of PMS by transition metals such as Cobaltbased catalysts has been extensively reported due to their favorable attributes such as mild reaction conditions and the absence of additional energy requirements. [20] However, the majority of the current research has been centered on eliminating a solitary contaminant.[21]

Therefore, a high-efficiency 3D $\mathrm { C o _ { 3 } O _ { 4 . 0 v } / T i O _ { 2 } }$ photoelectrode in-situ growth on Ti mesh was fabricated through a two-step method. In terms of photoelectrode design, the oxygen vacancies (Ov)-enriched ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ $( \mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \mathrm { O v } } )$ was loaded on $\mathrm { T i O } _ { 2 }$ with multi-exposed {111}, {101} and $\{ 1 1 0 \}$ facets (developed by our previous work[22]). There are dual heterojunctions formed one is the "p-n heterojunction" between ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ and 3D $\mathrm { T i O } _ { 2 }$ , and the other is the "facet heterojunction" of $\{ 1 1 1 \} / \{ 1 0 1 \} / \{ 1 1 0 \}$ facets, resulting in an efficient photogenerated charges separation. Besides, the Ov constructed in ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ could play a significant role as an electron-donor dopant that boosts the carrier's transfer and separation[23] and improves the inherent defects of $\mathrm { T i O } _ { 2 }$ , which achieves an excellent PEC performance. And the synergistic effect of double heterojunction with Ov was confirmed by a series of PEC tests. The charge transfer pathway between ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 - { \mathrm { O v } } }$ and $\mathrm { T i O } _ { 2 }$ was elucidated by simulated electron density distribution and KPFM. Second, in the case of the reaction system, PMS was introduced into the PEC system to establish the PEC/PMS coupling system, accompanied by the exploration of the reactive oxygen species (ROSs) and intermediates. The ${ \mathrm { C o } } ^ { 3 + } / { \mathrm { C o } } ^ { 2 + }$ cycle promoted the activation of PMS, leading to the generation of $\mathrm { S O } _ { 4 } \mathrm { \mathrm { ^ { - } } }$ . Meanwhile, the existence of $\mathrm { O } _ { \mathrm { v } }$ further improved the adsorption capacity of PMS and reduced the energy barrier of the reaction process. XPS analysis and DFT calculations were conducted to illuminate the corresponding activation mechanism of PMS. Finally, the practical application potential of the system was evaluated by examining the removal efficiency in actual wastewater, the effect of $\mathsf { p H }$ , coexisting inorganic ions, and natural organic matter (NOM). Therefore, the $\mathrm { C o _ { 3 } O _ { 4 . 0 v } / T i O _ { 2 } }$ -based PEC/PMS system would achieve efficient and simultaneous removal of BPA and $\mathrm { C r } ( \mathrm { V I } )$ through the synergistic effect of efficient photoelectrode and advanced reaction system.

Based on the above experimental results, the charge transfer mechanism of $\mathrm { C o _ { 3 } O _ { 4 . 0 v } / T i O _ { 2 } }$ was proposed (Figure S7d, Supporting Information). After the contact between ${ \mathrm { p } } { \cdot } { \mathrm { C } } { 0 } _ { 3 } { \mathrm { O } } _ { 4 }$ and n$\mathrm { T i O } _ { 2 }$ in the dark, the $e ^ { - }$ would transfer from $\mathrm { T i O } _ { 2 }$ to ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ due to the lower Fermi level and work function of $\mathrm { T i O } _ { 2 }$ [36] until their Fermi level reached equilibrium. Since the charge redistribution at the interface, an electric field from $\mathrm { T i O } _ { 2 }$ to ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ was built, preventing the electrons of the $\mathrm { T i O } _ { 2 }$ from continuously transferring. Meanwhile, $\mathrm { T i O } _ { 2 }$ showed upward-curved band edges, while ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ showed downward-curved band edges. Under light irradiation, photogenerated $e ^ { - }$ jumped to $\mathrm { T i O } _ { 2 }$ and $h ^ { + }$ shifted to ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ through p-n heterojunction, thereby forming an efficient charge separation. The $h ^ { + }$ accumulated on ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ further fully participated in the oxidation of BPA, while the charge injection efficiency $( \eta _ { i n j } )$ was calculated to be $8 0 . 0 \%$ (Figure S10, Supporting Information). The role of ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ in the activation of PMS was clarified through analysis of $\mathrm { C o } \ 2 \mathrm { p }$ spectra of fresh and used $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \cdot \mathrm { O v } } / \mathrm { T i O } _ { 2 }$ (Figure 7a). After the reaction, the proportion of $\mathsf { C o } ^ { 3 + }$ increased from $2 7 . 2 \%$ to $4 3 . 7 \%$ , while the proportion of $\mathrm { C o } ^ { 2 + }$ decreased from $7 3 . 8 \%$ to $5 6 . 3 \%$ (Figure 7b), indicating the involvement of both ${ \mathrm { C o } } ^ { 2 + }$ and ${ \mathsf { C o } } ^ { 3 + }$ in the activation of PMS (Equations (17)- (18)).[52]

$$
\begin{array} { r l } & { \mathrm { C o } ^ { 2 + } + \mathrm { H S O } _ { 5 } ^ { - }  \mathrm { C o } ^ { 3 + } + \mathrm { S O } _ { 4 } \cdot \mathrm { \Lambda } ^ { - } + \mathrm { O H } ^ { - } } \\ & { \mathrm { ~ } } \\ & { \mathrm { C o } ^ { 3 + } + \mathrm { H S O } _ { 5 } ^ { - }  \mathrm { C o } ^ { 2 + } + \mathrm { S O } _ { 5 } \cdot \mathrm { \Lambda } ^ { - } + \mathrm { H } ^ { + } } \end{array}
$$

Furthermore, the DFT calculations explained in detail the interaction mechanism between the photoelectrode and PMS molecules. The projected density of states (PDOS) of ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ and $\mathrm { C o _ { 3 } O _ { 4 . 0 v } / T i O _ { 2 } }$ are displayed in Figure 7c. It could be seen that d-band centers $\mathrm { ( E _ { d } ) }$ of ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \cdot \mathrm { O v } } / \mathrm { T i O } _ { 2 }$ were located at $- 0 . 7 9 \ \mathrm { e V }$ and $- 0 . 7 2 \ \mathrm { e V } _ { \mathrm { i } }$ respectively, confirming the upward shift of the d-band center after forming heterojunction. The interaction between PMS and the metal d state could cause a split into bonding and antibonding states. Compared with ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ , the d-band center of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \cdot \mathrm { O v } } / \mathrm { T i O } _ { 2 }$ rose, making the occupation of antibonding states by electrons more difficult.[53] This demonstrated that the bond between PMS and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \cdot \mathrm { O v } } / \mathrm { T i O } _ { 2 }$ was more stable, so $\mathrm { C o _ { 3 } O _ { 4 . 0 v } / T i O _ { 2 } }$ would possess stronger chemisorption activity during the activation process. In addition, the overall activation steps of PMS were thermodynamically analyzed by the calculation of Gibbs free energy $( \Delta \mathsf { G } )$ . As depicted in Figure 7d, the activation process of PMS involved the adsorption (pathway(I)), dissociation (pathway(II), generate ${ \mathrm { S O } } _ { 4 } \cdots ^ { \cdots } 1$ of ${ \mathrm { H S O } } _ { 5 } { } ^ { - }$ , and desorption of $\mathrm { \vec { S } O _ { 4 } } ^ { . - ^ { * } }$ (rate-determining step:pathway(III).[53] The ∆G of the pathway (III) for $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \cdot \mathrm { O v } } / \mathrm { T i O } _ { 2 }$ was calculated as $3 . 3 \ \mathrm { e V } ,$ which was significantly lower than that of $\mathrm { T i O } _ { 2 }$ $( 6 . 2 \ \mathrm { e V } )$ , nearly half as much. Thus, the introduction of ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 }$ enhanced the activation efficiency of PMS, which was consistent with the results of Figure 6c.

The above results collectively verified that the photogenerated electrons and cycling of ${ \mathrm { C o } } ^ { 3 + } / { \mathrm { C o } } ^ { 2 + }$ facilitated the effective activation of PMS to generate various active species.

# 3. Conclusion

In this work, an advanced photoelectrode $( \mathrm { C o } _ { 3 } \mathrm { O } _ { 4 . \mathrm { O v } } / \mathrm { T i O } _ { 2 } )$ with $\mathrm { O } _ { \mathrm { v } }$ and dual heterojunctions was successfully constructed and exhibited superior PEC performance. The charge transfer pathway between ${ \mathrm { C o } } _ { 3 } { \mathrm { O } } _ { 4 - \mathrm { O v } }$ and $\mathrm { T i O } _ { 2 }$ was elucidated by simulated electron density distribution and in-situ KPFM technique and DFT calculations. In $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 \cdot \mathrm { O v } } / \mathrm { T i O } _ { 2 }$ -PEC/PMS system, the photoelectrode could degrade nearly $100 \%$ of both BPA $( 0 . 1 5 \mathrm { m i n ^ { - 1 } } )$ and $\mathrm { C r } ( \mathrm { V I } )$ $( 0 . 2 9 \mathrm { m i n ^ { - 1 } } )$ within $1 5 \mathrm { m i n }$ , and both maintained over $90 \%$ after 5 runs. Based on the investigation of ROSs and intermediates, a possible BPA degradation pathway was proposed. In addition, the activation mechanism of PMS was further clarified by XPS spectrum and DFT calculations. This system demonstrated excellent performance when applied to actual wastewater matrices, indicating promising potential for practical application. In conclusion, this work offers a novel approach for the efficient and simultaneous removal of organic pollutants and heavy metal ions in wastewater.

# 4. Experimental Section

Preparation of $C o _ { 3 } O _ { 4 . O \nu } / T i O _ { 2 }$ :The ${ \mathrm { T i O } } _ { 2 }$ photoelectrode was first synthesized, and the preparation method was described in Supporting Information. Subsequently, a $3 0 \mathsf { m L }$ $( \mathsf { C H } _ { 3 } \mathsf { C O O } ) _ { 2 } \mathsf { C o }$ ethanol solution of specific concentrations (0.05, 0.5, and $1 . 0 \mathsf { m } \mathsf { M } )$ was added to a $1 0 0 ~ \mathsf { m L }$ PTFE reactor. The $\mathrm { T i O } _ { 2 }$ electrode was then immersed in the solution and removed after reacting at $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $4 \mathrm { ~ h ~ }$ Finally, the electrode surface was rinsed with deionized water to obtain $\times { \mathsf { C o } } _ { 3 } { \mathsf { O } } _ { 4 \cdot { \mathsf { O v } } } / { \mathsf { T i O } } _ { 2 }$ $( x = 0 . 0 5$ , 0.5, 1.0).

Characterization and Photoelectrochemical Measurements: The microstructure and lattice fringes of photoelectrodes were characterized by Field emission scanning electron microscopy (SEM, Hitachi S4800) and high-resolution transmission electron microscopy (TEM, JEM-2100). The crystal phase and structure of the photoelectrodes were determined using X-ray diffraction spectroscopy (XRD, D8 Advance Bruker) and Raman spectroscopy (Renishaw Crop). The elemental composition of the photoelectrode was examined by X-ray photoelectron spectroscopy (XPS, AXIS Ultra DLD, Shimazu Kratos).

The photoelectrochemical properties of the photoelectrode were evaluated through CHI 660c electrochemical workstation. Light absorption and electron-hole separation were investigated through UV-Vis diffuse reflectance spectroscopy (Agilent Carry 5000), photoluminescence spectrophotometer (PL, F-7000), and time-resolved photoluminescence spectroscopy (TRPL, Fluorolog-3).

Experiments for Simultaneous Removal of BPA and $C r ( V I )$ in $C o _ { 3 } O _ { 4 \cdot O \nu } / T i O _ { 2 }$ -PEC/PMS System: The degradation of BPA and $\mathsf { C r } ( \mathsf { V } \mathsf { I } )$

in PEC/PMS system was conducted in a $5 0 ~ \mathsf { m L }$ quartz reactor using a conventional three-electrode cell system, containing $4 5 \ m L$ simulated wastewater solution with 0.1 M ${ \mathsf { N a } } _ { 2 } { \mathsf { S O } } _ { 4 }$ serving as the electrolyte. Prior to the reaction, adsorption-desorption equilibrium was achieved by stirring in dark conditions for $1 0 \mathsf { m i n }$ , followed by the addition of PMS and continuous stirring during the reaction process. The light source was provided by a 300 W xenon lamp (PLS-SXE 300, Perfect Light Technology Co. Ltd., Beijing, China) equipped with an AM 1.5 filter, and the output light intensity was $5 2 0 m \times 1 c m ^ { - 2 }$ .

Activity Assessment and Mechanism Exploration of $C o _ { 3 } O _ { 4 \cdot O \nu } / T i O _ { 2 } .$ PEC/PMS System: The concentration of organics was detected by Highperformance liquid chromatography (HPLC, Agilent 1260). Corresponding detection parameters are shown in Table S3 (Supporting Information). The concentration of $\mathsf { C r } ( \mathsf { V } \mathsf { I } )$ was detected by the 1,5-Diphenylcarbazide method. Total organic carbon (TOC) was measured by a total organic carbon analyzer (Analytikjena, Germany). The intermediates of BPA were detected by gas chromatography-mass spectrometry (GC-MS). Electron paramagnetic resonance (EPR) signals of the reactive oxygen species were detected by Bruker EMX X plus-10/12 ESR spectrometer.

Theoretical Calculation: All calculations were carried out based on density functional theory (DFT) as implemented in Vienna ab initio simulation package (VASP) with exchange-correlation functional of generalized gradient approximation (GGA) of Perdew, Burke, and Ernzerhof (PBE) method. A grid of $1 \times 1 \times 1$ Monkhorst—Pack $\boldsymbol { \mathrm { k } }$ points was used for the structural relaxation.
