# Vacancies and sea urchin structure protect cobalt manganese spinel from anion poisoning in peroxymonosulfate activation

Hui Jia1 , Rumeng Liu1 , Tenglong Huang1 , Fulin Wang1 , Shanshan Dong1 $\boxtimes ,$ Huihui Dai1 , Zhenxing Zeng2 , Dingding Tang3 , Xiaodong Wang3 & Suhua Chen1

Peroxymonosulfate (PMS) activation by cobalt manganese spinel (Co-Mn) is always unsatisfactory due to the interference of co-existing anions in water. In this study, we used a sulfate-modification strategy to prepare a sea urchin-like Co-Mn catalyst $( \mathsf { C o M n } _ { 2 } \mathsf { O } _ { 4 } { - } \mathsf { S } )$ with abundant oxygen vacancies for counteracting the interference of anions in pollutant degradation. Compared with the conventional Co-Mn catalyst $( \mathsf { C o M n } _ { 2 } \mathsf { O } _ { 4 } )$ , ${ \mathsf { C o M n } } _ { 2 } { \mathsf { O } } _ { 4 }$ -S exhibited higher resistance to poisoning of ${ \mathsf { N O } } _ { 3 } { } ^ { - }$ , $\mathtt { C l } ^ { - }$ , and ${ \mathsf { S } } { \mathsf { O } } _ { 4 } { } ^ { 2 - }$ in PMS activation involved phenol degradation. Additionally, ${ \sf H } _ { 2 } { \sf P } { \sf O } _ { 4 } ^ { - }$ could even enhance phenol degradation by $1 5 0 . 2 \%$ for ${ \mathsf { C o M n } } _ { 2 } { \mathsf { O } } _ { 4 }$ -S/PMS system, in contrast to its induced $1 8 . 5 \%$ inhibition to $\mathsf { C o M n _ { 2 } O _ { 4 } / P M S }$ system. It was demonstrated that vacancies and sea urchin structure alleviated catalyst agglomeration for preserving catalytic sites and promoted catalyst surface modulation for radical diffusion, contributing to the enhanced stability in saline water. This work provides a facile strategy for overcoming the negative effects of co-existing anions on heterogeneous PMS-activation based water treatment.

Over the past years, the increasing demand for clean water has been challenged by the inevitable discharging of refractory organic pollutants from multiple industries into various aquatic waters1–4 . To handle this problem, a number of water treatment technologies have been developed, among which heterogeneous peroxymonosulfate (PMS)-activation-based advanced oxidation process (PMS-AOP) appeared as a promising strategy for removal of refractory organic pollutants owing to its outstanding oxidation capability5 . As well known, PMS-AOP has some obvious advantages: (i) its main reactive species sulfate radical $\mathrm { ( S O _ { 4 } ^ { \bullet - } ) }$ possesses a higher potential $( 2 . 5 \mathrm { - } 3 . 1 \mathrm { e V } )$ and a longer lifetime $( \mathrm { t } _ { 1 / 2 } = 3 0 { - } 4 0 \mu s )$ than hydroxyl radical $( ^ { \bullet } \mathrm { O H } )$ $( 1 . 8 \mathrm { - } 2 . 7 \mathrm { e V }$ , $\mathfrak { t } _ { 1 / 2 } = 1 0 ^ { - 3 } \mu \mathrm { s } ) ^ { 6 , 7 }$ ; (ii) PMS of solid can be easily stored and transported8 ; (iii) it can be operated across a wide pH range9 . Further, compared with homogeneous catalytic reaction, the heterogeneous catalytic PMS-activation systems can be operated under mild conditions and easily recycled by catalyst separation10. Therefore, heterogeneous catalytic PMS-activation systems obtained much attention and many effective catalysts were developed.

To date, spinel catalysts have been widely studied for their superior catalytic properties in PMS activation due to their special $\mathrm { A B } _ { 2 } \mathrm { O } _ { 4 }$ configuration which not only guarantee high-efficiency PMS activation but also allow quick high-valency metal ion transforming to low-valency metal ion for continuously activating $\mathrm { P M S } ^ { 1 1 , 1 2 }$ . For example, Feng et al. prepared a series of $\mathrm { M } _ { \mathrm { x } } \mathrm { M n } _ { 3 - \mathrm { x } } \mathrm { O } _ { 4 }$ ( $\mathbf { M } = \mathbf { C o }$ , Zn, Cu, Fe; $\mathbf { X } = 1 , 2$ ) nanoparticles which showed excellent catalytic PMS activation performance for deep dechlorination $( 9 5 . 0 \% )$ and mineralization $( 6 5 . 0 \% )$ of trichloroethylene13. Xu et al. developed a series of ordered mesoporous silica SBA-15 supported bimetallic Co-Mn spinel oxides, and these materials exhibited higher PMS activation performance than monometallic catalysts14. However, the performance of most spinel catalysts in PMS-activation-based pollutant removal is unsatisfactory due to the severe interference of co-existing anions in water. According to literature, the reasons for the interference of coexisting anions include: (i) anions may react with ${ \bullet } _ { \mathrm { O H / S O _ { 4 } } } { \bullet } -$ free radicals to produce less reactive radicals, such as ${ \mathrm { N O } } _ { 3 } ^ { - }$ , $\mathrm { C l ^ { - } }$ , $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } { } ^ { - }$ , and $\mathrm { C O } _ { 3 } ^ { 2 - 1 5 , 1 6 }$ (ii) anions may compete adsorption sites with PMS or pollutants, preventing PMS activation or pollutant degradation17; (iii) anions may cause catalyst agglomeration, reducing exposure of active catalytic sites on the surface of catalysts18. For example, Guo et al. prepared a series of $\mathrm { C o } _ { 3 - \mathrm { x } } \mathrm { M n } _ { \mathrm { x } } \mathrm { O } _ { 4 }$ with increased Mn-O covalency, which presented efficient pollutant degradation using PMS in deionized water, but exhibited much lower pollutant degradation performance with addition of $5 \mathrm { m M }$ anions19. Therefore, it is highly necessary to design a novel spinel catalyst with efficient anti-interference to anions in water when it is used to PMS-activation based pollutant degradation.

In this study, we synthesized a sea urchin-like Co-Mn spinel catalyst $\mathrm { ( C o M n _ { 2 } O _ { 4 } { - } S ) }$ with enriched oxygen vacancies by a facile sulfate modification strategy, which exhibited stronger resistance to anionic interference, comparing with its counterpart material, the spinel Co-Mn spinel catalyst $\mathrm { ( C o M n _ { 2 } O _ { 4 } ) }$ ) without sulfate modification. The sea urchin-like spinel $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ was systematically characterized by scanning electronic microscopy (SEM), transmission electronic microscopy (TEM), X-ray diffraction (XRD) pattern, Brunauer-Emmett-Teller (BET), Fourier transform infrared spectroscopy (FT-IR), Raman scattering spectroscopy, electronic paramagnetic resonance (EPR) spectroscopy, and X-ray photoelectron spectroscopy (XPS). Then, we studied the main active species involved in the $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system and the mechanism for its enhanced antiinterference to anions. Finally, the applicability and reusability of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ for PMS activation in tap and river waters were studied. This work provides a new strategy to advance the negative effects of co-existing anions on heterogeneous PMS-activation-based pollutant degradation using spinel catalysts.

# Results

# Characterization

We first used XRD to characterize the crystal structure of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – \mathrm { S }$ and ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 } .$ . As shown in Fig. 1a, both the synthesized $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ and $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 }$ materials exhibited the XRD patterns of spinel crystalline structure (JCPDS 18-0410), since the diffraction peaks of the (111), (113), (311), and (004) planes matched well with spinel $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 }$ oxides. It should be noted that, the XRD peaks of ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S presented much weaker than that of ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 } ,$ suggesting that the possible formation of crystal defects by the sulfate-modification strategy. EPR spectra (Fig. 1b) further showed that $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ possessed a much higher symmetrical EPR peak $\left( \mathbf { g } = 2 . 0 0 3 \right)$ ) than ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 } ,$ indicating that $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } { \cdot } \mathrm { S }$ contained more oxygen vacancies. In comparison, ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ was then calcined at $4 5 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ under $\Nu _ { 2 }$ protection to obtain the ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -control which showed no EPR peak indicating no presence of vacancies. This further confirmed the measured EPR peaks for ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S and $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 }$ were from oxygen vacancies.

We then characterized the morphological structure of the asprepared $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } { \cdot } \mathrm { S }$ and ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ by SEM. As shown in Fig. 2a, b, the ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S had a sea urchin-like structure with a radial distribution of nanorods, while the ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ was composed of a bunch of stacking nanorods. It can be found that intense Co, Mn, and O signals were uniformly distributed in the energy dispersive X-ray spectroscopy (EDS)

mappings of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – \mathrm { S }$ (Supplementary Fig. 1), while a slight S signal was also observed and should be from the remanent sulfate, suggesting sulfate addition induced the formation of the sea urchin-like structure. Magnified SEM images (Fig. 2c, d) show that the average diameter sizes of the nanorods in the sea urchin-like ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ and the $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ were about $8 5 . 3 \mathrm { n m }$ and $1 8 6 . 0 \mathrm { n m }$ , respectively, suggesting sulfate modification would stimulate the growth of spinel nanorod. Additionally, obvious lattice spacings of 0.224 and $0 . 2 6 5 \mathrm { n m }$ were found in the HR-TEM images of ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S (Supplementary Fig. 2), which could be attributed to spinel (004) and (113) lattices19, respectively. This is consistent with the result of XRD pattern of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } { \cdot } \ s$ S. Moreover, the $\Nu _ { 2 }$ adsorption–desorption isotherms of the synthesized ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ and $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ (Fig. 3a, b)) exhibited the type IV isotherm curves with an H3 hysteresis loop. The specific surface areas and the pore sizes (Supplementary Table 1) of the two catalysts are very close to each other, but the sulfate modification process slightly reduced the pore volume of the catalyst, which was probably caused by the modification process and the formation of sea urchin-like nanospheres without the mesoporous structure 20 .

# Peroxymonosulfate activation for pollutant degradation

Next, we evaluated the catalytic PMS activation performance of ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S and ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ using phenol (PE) as a target pollutant first. Figure 5a shows that $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – \mathrm { S }$ possessed slightly better PMS activation performance than ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ since the $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system achieved faster PE removal kinetics with achieved a higher apparent kinetic rate constant $( \mathrm { k _ { a p p } } )$ $( 0 . 2 0 6 4 \mathrm { m i n } ^ { - 1 } )$ than the $0 . { \dot { 1 } } 5 3 5 \operatorname* { m i n } ^ { - 1 }$ of $\mathrm { C o M n _ { 2 } O _ { 4 } / P M S }$ system in $1 8 \mathrm { m i n }$ , although the final PE removals were both $1 0 0 \%$ . In addition, the catalytic performance of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – \mathrm { S }$ is compared with other catalysts reported in recent literature shown in Supplementary Table 2. It should be noted that the $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } { \cdot } \mathrm { S }$ spinel showed the fastest and highest removal efficiencies of PE degradation $1 0 0 \%$ PE removal within $1 8 \mathrm { m i n }$ ). Without either catalyst or PMS, there were nearly no PE degradation $( < 2 \% )$ in $1 8 \mathrm { m i n }$ , confirming the effectiveness of PMS activation by ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ and ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 } .$ -S. To rule out the possible effects of leached metals on PMS activation, we tested the cobalt leaching and analyzed its direct effect on PMS activation. After ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S/PMS reaction for 10 and $2 0 \mathrm { { m i n } }$ , the detected concentrations of cobalt ions were 2.46 and $3 . 9 6 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ , and no Mn leaching was detected. We then conducted phenol degradation experiments by ${ \mathrm { C o } } ^ { 2 + } / { \mathrm { P M S } }$ system with using 2 and $4 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ of $\mathrm { C o } ^ { 2 + }$ at the same reaction conditions as $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system except for the addition of ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S. As can be seen from Supplementary Fig. 3, only $1 7 . 9 \%$ and $2 8 . 6 \%$ of phenol were degraded in $1 8 \mathrm { m i n }$ by the usage of 2 and $4 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ of $\mathrm { C o } ^ { 2 + }$ , respectively, which are much lower than $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system achieved $( 1 0 0 \% )$ . Therefore, the phenol degradation in $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system should be originated from the $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ catalytic PMS activation, instead of the leached cobalt-based homogeneous catalysis. And the catalysis of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ in PMS activation could be further supported by the dose dependent PE removal efficiency of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ and PMS (Supplementary Fig. 4).

# Discussion

In summary, a sea urchin-like $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ spinel catalyst with abundant oxygen vacancies was developed to present an excellent catalytic performance for PMS activation, especially in the presence of co-existing anions. First, the enhanced anti-interference to anion poisoning originated from the unique sea urchin-like structure of $\mathrm { C o M n _ { 2 } O _ { 4 } { - } S . C o }$ -existing $\mathrm { N O } _ { 3 } { } ^ { - }$ , $\mathrm { C l ^ { - } }$ , and ${ \mathrm { S O } _ { 4 } } ^ { 2 - }$ were found to decrease the zeta potential of $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – \mathrm { S } ,$ and could trigger catalyst agglomeration and abatement of active catalytic sites. However, the unique sea urchin-like structure of ${ \mathrm { C o M n } } _ { 2 } { \mathrm { O } } _ { 4 }$ -S could weaken the catalyst agglomeration-induced abatement of reactive sites, thereby reducing the inhibitory effect of $\mathrm { N O } _ { 3 } { } ^ { - }$ , $\mathrm { C l ^ { - } }$ , and ${ \mathrm { S O } _ { 4 } } ^ { 2 - }$ to PE degradation in $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system. Second, the enriched oxygen vacancies in $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ synergistically coupled with $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } { } ^ { - }$ for promoting mainl $\ L _ { T } \mathrm { S O _ { 4 } } ^ { \bullet - }$ diffusing from catalyst surface to bulk liquid, consequently enhancing PE degradation in $\mathrm { C o M n _ { 2 } O _ { 4 } { \cdot } S / P M S }$ system. Additionally, $\mathrm { C o M n } _ { 2 } \mathrm { O } _ { 4 } – S$ presented excellent PMS-activation performance in tap and river waters for five cycles of running. This study provides a feasible strategy for enhancing the PMS-activation based pollutant degradation in the presence of co-existing anions.
