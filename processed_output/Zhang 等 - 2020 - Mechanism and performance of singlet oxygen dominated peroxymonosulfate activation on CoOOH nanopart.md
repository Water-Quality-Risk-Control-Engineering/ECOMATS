# Abstract

Peroxymonosulfate (PMS) has gained attention as oxidant for SR-AOPs. It is essential to develop a stable heterogeneous catalyst with strong hydrophilicity and high electron transfer capability for PMS activating. In this study, cobalt oxyhydroxide (CoOOH) was synthesized and activated PMS for degradation of 2,4- dichlorophenol (2,4-DCP) aiming to assess the feasibility of CoOOH/PMS system. $5 0 \mathrm { m g / L }$ of 2,4-DCP could be $1 0 0 \%$ degraded within 120 min with $0 . 2 0 \mathrm { g / L }$ CoOOH and 6 mM PMS. CoOOH/PMS system possessed a high degradation efficiency $( 0 . 0 4 6 2 \mathrm { m i n } ^ { - 1 } )$ ), which was about 10 and 4 times higher than $\mathrm { C o _ { 3 } O _ { 4 } / P M S }$ and $\mathrm { C o F e _ { 2 } O _ { 4 } / P M S }$ system, respectively. Furthermore, it was found that

CoOOH/PMS system displayed effective catalytic performance over broad pH range (e.g. 3-9). Importantly, the quenching tests revealed that $^ 1 { \bf O } _ { 2 }$ was identified as dominant reactive oxygen species (ROS). Co (Ⅲ) was rapidly reduced to Co (Ⅱ) owing to the efficient electron transfer rate performance of CoOOH in the catalytic reaction. Then, the regeneration of Co (Ⅱ) facilitated $\mathrm { C o O H ^ { + } }$ owing to the surface of CoOOH with sufficient hydroxyl group, which is crucial for PMS activation and reactive oxygen species-ROS generation. This study proposed an alternative technology based on peroxymonosulfate catalyzed by cobalt-based hydroxide for waste water treatment.

Keywords: CoOOH, sulfate radical, singlet oxygen, surface hydroxyl density, electron transfer

# 1. Introduction

2,4-dichlorophenol (2,4-DCP) has attracted a lot of attention due to its wide application in fungicides and pharmaceuticals[1]. Its high toxicity and biorefractory resulting in harm for human and living creatures [2, 3] , discharge of water containing 2,4-DCP poses a great threaten to the environment and human beings. However, conventional treatment methods have some drawbacks such as slow reaction rate and requirement of proper pH/temperature, etc.[4]. Therefore, developing an efficiency chemical oxidation technology is desired.

As reported, advanced oxidation processes (AOPs) is an alternative and effective technology for toxic and recalcitrant organic pollutants removal [5-9]. Recently,

compared with hydroxyl radical-based AOPs (•OH, $\mathrm { E } _ { 0 } = 1 . 8 – 2 . 7 \mathrm { V } \rangle$ , sulfate radicalbased AOPs (SR-AOPs) $\mathrm { 5 O } _ { 4 } \bullet ^ { - }$ , $\mathrm { E } _ { 0 } = 2 . 5 { - } 3 . 1 \mathrm { V } \mathrm { ~ , ~ }$ ) attracted more attention owing to its higher oxidized ability, independence for $\mathrm { p H }$ , and superior selective oxidation [10-12]. $\mathrm { S O } _ { 4 } { \bullet } ^ { - }$ is formatted via persulfate (PS, $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ ) activation or peroxymonosulfate (PMS, $\mathrm { H S O } _ { 5 } \mathrm { ~ , ~ }$ ). The activated approaches included heat, transition metals or UV irradiation, etc. Among them, transition metal activation cost less energy and less complex in reactor/system configuration [5].

As reported, $\mathrm { C o } ^ { 2 + }$ exhibited highest catalytic activity as PMS activator. Besides, $\mathrm { C o } ^ { 2 + } / \mathrm { P M S }$ system displayed superior performance and lower regent dosages than Fenton reaction at neutral pH [8, 11, 13]. In the $\mathrm { C o } ^ { 2 + } / \mathrm { P M S }$ system, the generation of $\mathrm { C o O H ^ { + } }$ , which is considered as the active species for sulfate radical generation as well as the rate-limiting step [14, 15]. Besides, $\mathrm { C o } ^ { 2 + }$ as PMS activator has also disadvantages of low recycle utilization, potential environmental risks of $\mathrm { C o } ^ { 2 + }$ discharge and dependence of pH [8]. According to the reports, cobalt containing materials as heterogeneous catalysts attracts attentions. Up to date, cobalt-based oxides as heterogeneous catalysts, such as $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , spinel cobalt-ferrite $\mathrm { ( C o F e _ { 2 } O _ { 4 } ) }$ ) have been investigated. Though promising, the electronic transmission rate, catalytic activity, the hydrophilic capability and pH flexibility of the above catalysts are required to be enhanced. Hence, developing a new cobalt-based heterogeneous catalyst for PMS activation is essential.

CoOOH nanoparticles gains our attention as an alternative catalyst attributed to its following properties [16]: it is a hydrophilic compound with sufficient active sites and hydroxyl groups. Moreover, CoOOH has been used as CO sensor [17], supercapacitor [18-20] and precursor for electrode materials [21, 22] in industry. It turns out that CoOOH has good electronic transmission rate. To date, there is little report on the catalysis oxidation system of peroxymonosulfate activated via CoOOH nanoparticles for 2,4-dichlorophenol degradation in water. Herein, the objectives of this study are: (i) to employ CoOOH/PMS system for pollutant degradation in water; (ii) to evaluate degradation efficiency for organic pollutant via system of peroxymonosulfate activation on CoOOH nanoparticles; (iii) to investigate mechanism of singlet oxygen dominated peroxymonosulfate activation on CoOOH nanoparticles via quenching experiments, ESR, FT-IR and XPS analysis.

# 2. Materials and Methods

# 2.1 Chemicals

The chemicals and reagents in this study are all commercially available and analytical grade. 2,4-dichlorophenol, methanol, $\mathrm { C o ( N O _ { 3 } ) _ { 2 } } { \cdot } 6 \mathrm { H _ { 2 } }$ $\mathrm { 6 H } _ { 2 } \mathrm { O }$ , $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $( 3 0 \% )$ and oxone (KHSO5·0.5KHSO4·0.5K2SO4) were provided by Aladdin Chemistry Co., Ltd (Shanghai, China). Quencher agents included furfuryl alcohol (FFA), sodium azide (NaN3), tert-butyl alcohol (TBA), ethanol (EtOH) and $p$ -benzoquinone ( $\dot { p }$ -BQ) were provided by Tianjin Kermel Chemical Reagents Company, China. Spin-trapping regent for ESR experiments including 5,5-dimethyl-1-pyrrolidine N-oxide (DMPO) and 2,2,6,6-tetramethylpiperidin-1-oxyl (TEMP) were purchased from Sigma. Solutions in this study were deionized water.

# 2.2 Synthesis of CoOOH

The CoOOH was prepared by the modified method of chemical precipitation [22]. $1 0 0 \mathrm { m L }$ of NaOH solution $( 2 . 5 \mathrm { m o l } / \mathrm { L } )$ was added dropwise into $1 0 0 ~ \mathrm { m L }$ of cobalt nitrate $( \mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ , $0 . 5 \mathrm { m o l / L }$ ) solution to get $\mathrm { C o ( O H ) } _ { 2 }$ precursor. After holding in $6 0 ~ ^ { \circ } \mathrm { C }$ water lasting 2 hours, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was added to the beaker. Then, the formation $\mathrm { C o ( O H ) } _ { 3 }$ ⋅CoOOH was obtained from $\mathrm { C o ( O H ) } _ { 3 }$ by holding in $6 0 ~ ^ { \circ } \mathrm { C }$ water bath. Afterwards, the final precipitate was filtered and washed many times, then dried at $6 0 ~ ^ { \circ } \mathrm { C }$ , and collected as CoOOH.

# 2.3 Experimental operation

To evaluate the catalytic activity of CoOOH, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and CoFe2O4 which have been well reported as most popular and efficient PMS activator was selected as a reference. A series of batch experiments under different conditions were implemented to assess the stability and catalytic performance activity of CoOOH nanoparticles for PMS activation. Each sample contained 50 mg/L 2,4-DCP with an amount of PMS and catalyst. Except for investigating effect of the initial pH on 2.4-DCP degradation, the other experiments were under the initial condition of neutral pH $\mathrm { ( p H } = 7$ ). And the initial condition of acidic pH and alkaline pH were achieved by adding 0.1 M $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ and 0.1 M NaOH solution into the reaction system, respectively. Moreover, each sample was at a rotation speed of $1 8 0 \mathrm { r p m }$ , $2 3 \pm 2 { } ^ { \mathrm { ~ o } } \mathrm { C }$ . Then, samples were collected at different time intervals and quenched by methanol. Afterwards, the samples were filtered through a $0 . 2 2 \mu \mathrm { m }$ membrane for further analysis by liquid chromatography instrument. Besides, all experiments were in duplicated.

# 2.4 Characterization and analysis

X-Ray Diffraction Analysis (XRD) was measured for probing the structure of catalyst (XD-3, Shimadzu Corporation, Japan). Energy dispersive spectrometer (EDS) was the method for detecting component elements (X-Max 50, Oxford Instrument, U.K.). Fourier transform infrared spectrometer (FTIR) was the method for further determining functional groups (8400S, Shimadzu Corporation, Japan). Additionally, scanning electron microscope (SEM) (JSM-6700 F, JEOL Ltd., Japan) was used for investigating the morphology of synthesized material. The X-ray photoelectron spectroscopy (XPS) (ESCALAB 250, Thermo Corporation, USA) was used for valance variation on different elements during the reaction. Electrochemical characteristics (CV and EIS) of CoOOH was tested by electrochemical workstation (CHI630E, Shanghai chenghua instrument co. LTD.).

The concentration of target pollutant, 2,4-DCP, was analyzed by a highperformance liquid chromatograph (HPLC, Agilent 1260 Infinity, Germany) with an Atlantis C18 column $( 4 . 6 \ : \mathrm { m m } \times 1 5 0 \ : \mathrm { m m } )$ ). Electron spin resonance (ESR) experiments were conducted on a JES FA200 spectrometer with DMPO and TEMP as a spintrapping agent. Free metal ions in solution were determined via atomic absorption spectrophotometer (Shimadzu AA-6000CF, Japan). The chloride ion was conducted by an ion chromatograph (Diane ICS-2100, USA). Jena TOC analyzer was used to determine total organic carbon (TOC) of pollutant.

# 3. Results and discussion

# 3.1 Phrase and morphology

The synthesized material was consistent with the JCPDS Card No. 73-1213 according to the XRD spectrum in Fig.1a, which was CoOOH. On the basis of the result from EDS spectrum (Fig.1b), the ratio between atomic percent of cobalt and oxygen was about 0.5. According to the characteristic peak at $3 4 2 9 \mathrm { c m } ^ { - 1 }$ , $1 6 3 9 \mathrm { c m } ^ { - 1 }$ and $5 8 1 . 5 \mathrm { c m } ^ { - 1 } ( < 1 0 0 0 \mathrm { c m } ^ { - 1 } )$ in Fig.1c, it turned out that groups of H-bonded hydroxyl $( - \mathrm { O H } )$ , $\mathrm { C o - O }$ and Co–OH were existed in the synthesized material [23, 24]. Thus, integrated with the SEM image in Fig.1d, the synthesized material can be confirmed as CoOOH nanoparticles with ring structure.

# 3.2 Catalytic performance evaluation

The catalytic performance evaluation of CoOOH on peroxymonosulfate activation for 2,4-DCP degradation was evaluated. The results were compared with that obtained from $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ which as a reference have been well reported as most popular and efficient PMS activator. And the structure properties of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ were displayed in Fig.S1. As illustrated in Fig.2a, in 120 min reaction, 2,4-DCP was completely degraded in CoOOH/PMS system, whereas only $3 3 \%$ and $7 3 \%$ degradation was achieved in PMS/Co3O4 and PMS/CoFe2O4 system, respectively. Moreover, based on the first-order dynamics, the reaction rate constant of processes including PMS activation by CoOOH nanoparticle $( 0 . 0 4 6 2 \mathrm { m i n } ^ { - 1 } )$ ) was about 10 and 4 times higher than that by $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and CoFe2O4, respectively. Besides, the contribution of physical adsorption by $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ and CoOOH to the organic degradation was negligible according to the results (Fig.2b). It may be explained by the structure properties of these three cobalt-based catalyst and the discussion was displayed in Text.S1. These findings clearly demonstrated that CoOOH displayed the higher catalytic performance for PMS activation than other reported cobalt-based oxides.

3.2.1 Effect of CoOOH, PMS and 2,4-DCP dosage on system performance

It was found that with increasing of CoOOH dosage, 2,4-DCP degradation rate increased significantly (Fig.S2a). Interestingly, the activation efficiency will be strongly inhibited when the dosage of CoOOH over $0 . 2 0 \ \mathrm { g / L }$ . As Wahiba Najjar reported, it can be explained by the diffusion limitation in heterogeneous reactions. When the catalyst dosage over the optimum value, the invalid oxidant on the surface will be dominantly consumed before ROS attacking pollutant, resulting in low degradation efficiency [25, 26]. Thus, $0 . 2 0 \mathrm { g / L }$ was the selected proper dosage for catalyst.

Fig. S2b showed the relationship between target pollutant efficiency of degradation and ratio between PMS and target pollutant. Apparently, the more PMS concentration resulting in the higher efficiency for pollutant degradation, however, when ratio of PMS and pollutant over 20:1, the degradation efficiency enhanced slightly. The ineffective PMS consumption can be explained as the limitation of the quantity of active sites for PMS activation [27]. Generally, 20:1 was selected as the optimal ratio of PMS and 2,4-DCP.

# 3.2.2 Effect of pH

The SR-AOPs can be performed over a wider range of pH by contrast with Fenton reaction [8, 28]. As Fig.S2c showed, when the initial pH range of 3.0-9.0, the 2,4-DCP degradation efficiency varied little, but significantly decreased at pH of 11.

Moreover, it turned out that the degradation of target pollutant followed the dynamics of first-order reaction. And it suggested that $k$ decreased with 2,4-DCP concentration increasing. The relationship between the $k$ and the initial pollutant concentration was dependent on the fitting equation.

$$
k = 7 9 0 . 9 5 \mathrm { C } ^ { - 1 . 4 6 2 }
$$

Where C is the initial concentration of target pollutant, 2,4-DCP, and $k$ is the firstorder reaction rate constant.

3.2.3 Effect of $\mathrm { H C O } _ { 3 } ^ { - }$ and natural organic matter (NOM) addition

Fig.S3a and Fig.S3b showed the effect of $\mathrm { H C O } _ { 3 } ^ { - }$ and NOM on the 2,4-DCP degradation efficiency, respectively. It turned out that the 2,4-DCP degradation efficiency was significantly inhibited with increasing $\mathrm { H C O } _ { 3 } ^ { - }$ concentration adding in the reaction solution. It can be explained that $\mathrm { H C O } _ { 3 } ^ { - }$ can react with both $S O _ { 4 } { \bullet } ^ { - }$ and OH• (Eq. (2)–(3))[29].

$$
\mathrm { S O _ { 4 } \mathrm { ^ { - } + H C O _ { 3 } \mathrm { ^ { - }  H C O _ { 3 } \bullet + S O _ { 4 } \mathrm { ^ { 2 - } } } } }
$$

$$
\mathrm { O H ^ { \bullet } + H C O _ { 3 } ^ { - }  C O _ { 3 } ^ { 2 - } + H _ { 2 } O }
$$

NOM is a compound in natural waters and soils and would either enhance or inhibit the pollutant degradation with increasing NOM concentration [30]. In this study, NOM displayed inhibition effect on target pollutant degradation (Fig.S3b). According to Yao’s study [31], NOM usually acts as a quencher of $\mathrm { S O } _ { 4 } { \bullet } ^ { - }$ and OH•. Moreover, the phenolic hydroxyl and carboxyl groups of NOM could be adsorbed onto the surface of catalysts leading to prohibiting the contact of active sites and PM [32]. Thus, NOM would be one of the inevitable factors when the heterogeneous CoOOH/PMS system put into application for waste water treatment.

# 3.2.4 TOC removal and chloride ion detectable rate

To explore the potential mineralization of 2,4-DCP in CoOOH/PMS system, the TOC and degradation product-chloride ion was determined in this study, shown in Fig.S4. Compared with Yang’s study [33], TOC removal efficiency in this study was much higher than that in Yang’s study. The TOC removal rate increased up to $50 \%$ after $1 . 5 \mathrm { h }$ reaction. Moreover, the results of dechlorination further confirmed that the catalysis oxidation system of PMS activated by CoOOH had contributions to 2,4-DCP mineralization. After $^ { 2 4 \mathrm { ~ h ~ } }$ reaction, TOC removal and Cl– detected rate were both increased up to $5 5 . 3 7 \%$ and $5 6 . 3 8 \%$ , respectively, indicating that more intermediate products of 2,4-DCP was further completely degraded.

# 3.3 Stability of CoOOH

The leaching of cobalt ion in CoOOH/PMS system under acid conditions (initial pH of 3) was investigated (Fig.3a). It was can be seen that the leaching of cobalt ion was about $0 . 3 \mathrm { m g / L }$ . Meanwhile, the recycle experiments and ion leaching concentrations at different cycles were carried out for catalyst stability evaluation (Fig.3b). It was found that little decline of pollutant degradation efficiency after 4 times cycles. Besides, cobalt ion leaching concentrations at different runs remained the same as the first run. Firstly, it is inevitable for cobalt leaching under the condition of acid, leading to relatively less reaction active sites on the surface of catalyst. Secondly, the active sites may be decreased owing to the intermediates of 2,4-DCP

covering the surface of catalyst. Thirdly, the surface properties on the catalyst may be varied under the condition of highly oxidative [34]. Integrated with XRD spectrums shown in Fig.S6, it turned out that CoOOH possessed a good stability after the PMS activation reaction.

# 3.4 CV and EIS analysis

Aiming to further investigate the superior properties of CoOOH than other cobalt oxides $( \mathrm { C o } _ { 3 } \mathrm { O } _ { 4 } , \mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } )$ , the characterization of CV and EIS were implemented (Fig.S7). And the multi-cycle cyclic voltammograms (CVs) of the CoOOH in 0.1 M $\mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 }$ solution were conducted in Fig. 4a and the EIS spectrum of CoOOH displayed in Fig.4b. Apparently, the CV spectra showed obvious REDOX peak shape, demonstrating that CoOOH underwent rapid faradic redox reactions (Co (Ⅲ) to Co (Ⅱ)). Thus, CoOOH displayed a good stability and recyclability owning to the little variant of measured CV curves during 3 cycles. Additionally, the EIS spectrum of CoOOH displayed as a semi-circle, demonstrating CoOOH possessed good conductivity.

Integrated with the CV and EIS characterization of $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , the results were shown as follows. Firstly, it has been reported that the electric potential for redox peaks (ΔEp) calculated by CV curves could suggest the electron transmission capability of catalysts [35]. Besides, the diameter of semi-circle represented the polarization resistance $( \mathbb { R } \mathbb { p } )$ and the smaller of diameter implying lower pure charge-transfer resistance and higher electrode potential [36]. Notably, compared with the calculated electric potential for redox peaks (ΔEp) of CoOOH $( 0 . 5 0 \mathrm { e V } )$ , it turned out that $\mathrm { C o _ { 3 } O _ { 4 } } ( 0 . 8 2 \mathrm { e V } )$ displayed higher ΔEp while CoFe2O4 $( 0 . 3 2 \mathrm { e V } )$ showed lower ΔEp. It indicated that CoOOH possessed higher electronic transmission rate than ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ . Moreover, compared with the diameter of semi-circle of CoOOH, apparently, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ possessed much larger diameter while ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ showed slightly smaller diameter. It indicated that CoOOH displayed much lower higher polarization resistance than $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ . Thus, neither $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ nor ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ exhibited higher electrochemical properties than CoOOH as PMS activator. It was concluded that $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ possessed lower catalysis activity than CoOOH in the PMS activation system for pollutant degradation.

3.5 Mechanisms of CoOOH activated PMS system.

# 3.5.1 XPS analysis

In the survey spectra of CoOOH (Fig.S8), the characteristic spectrum of Co and O was clearly observed, further confirming the composition of CoOOH [37]. Fig.5a showed the varied valence of cobalt element before and after the reaction. The Co 2p peak at $7 8 0 . 0 \mathrm { e V }$ presented Co (Ⅲ). The generated peak after the reaction presented the generated Co (Ⅱ). About $2 1 . 8 \%$ Co (Ⅲ) transferred into Co (Ⅱ) indicating the cycle of Co (Ⅲ)/Co (Ⅱ) generated in the system, which may be occurred as following equations (4-5) [6].

$$
\equiv \mathrm { C o } ( \mathrm { I I I } ) + \mathrm { H S O } _ { 5 } ^ { - }  \equiv \mathrm { C o } ( \mathrm { I I } ) + \mathrm { S O } _ { 5 } \bullet ^ { - } + \mathrm { H } ^ { + }
$$

$$
\equiv \mathrm { C o } ( \mathrm { I I } ) + \mathrm { H S O } _ { 5 } ^ { - }  \equiv \mathrm { C o } ( \mathrm { I I I } ) + \mathrm { S O } _ { 4 } \bullet ^ { - } + \mathrm { O H } ^ { - }
$$

Fig. 5b illustrates the O 1s spectra of CoOOH before the reaction, which was assigned to three peaks at 532.9, 531.3 and $5 2 9 . 9 \mathrm { e V } .$ The three peaks following the order from high to low binding energy were represented as surface adsorbed oxygen $\left( \mathrm { O _ { a b s } } \right)$ , metal hydroxide (Co-OH) and metal oxide (Co-O), respectively. The peak at $5 3 2 . 9 \mathrm { e V }$ representing $\mathrm { O _ { a b s } }$ disappeared after the reaction, indicating that $\mathrm { O _ { a b s } }$ was involved in the reaction. Integrated with the content of species before and after the reaction, it turned out that the increased content of Co-OH after $( 2 3 . 8 \%$ ) about as twice as that of Co-O $( 1 1 . 3 \% )$ ). And the ratio of Co-OH/Co-O was raised from 1.56 to 1.70 by contrast with the fresh and used catalyst (Tab.S2). Thus, the content of $\mathrm { C o O H ^ { + } }$ generated most, which played key role for PMS activation.

# 3.5.2 FTIR analysis

The vibration band of catalyst at $3 4 2 9 \mathrm { c m } ^ { - 1 }$ , $1 6 3 9 \mathrm { c m } ^ { - 1 }$ and $5 8 1 . 5 \mathrm { c m } ^ { - 1 }$ (Fig.5c) indicated the existence of the H-bonded hydroxyl group (-OH), Co-O and Co-OH, respectively [23, 24]. It can be seen that the responses of peak at $3 4 2 9 \mathrm { c m } ^ { - 1 }$ and 581.5 $\mathrm { c m ^ { - 1 } }$ after oxidation reaction were stronger than that before oxidation reaction. The result indicated that more -OH and Co-OH groups were formed on the surface of CoOOH during the catalytic oxidation process. As $\mathrm { C o O H ^ { + } }$ species is acknowledged as the key step for PMS activation, which limited the reaction rate [38, 39], the formation of -OH and Co-OH groups on the surface of CoOOH would play a significant role in facilitating PMS activation. Integrated with the result from XPS, the regeneration Co (Ⅱ) on the surface of CoOOH with sufficient hydroxyl groups accelerated generation of $\mathrm { C o O H ^ { + } }$ , leading to higher catalytic oxidation rate.

Subsequently, CoOOH displayed good catalytic activity of PMS activation for target pollutant degradation. All these above findings had a good explanation for why CoOOH exhibited high efficient catalytic for PMS activation.

3.5.3 Identification of reactive oxidizing species by specific quenchers

A series of selective radical quenching tests were implemented in order to determine the predominant reactive species in the CoOOH/PMS system and the quenching agents included EtOH, TBA, $p$ -BQ, FFA and ${ \mathrm { N a N } } _ { 3 }$ (Fig. 6a) [40]. As reported [41], $p$ -BQ can selectively react with $\mathrm { O } _ { 2 } \bullet ^ { - }$ . EtOH can easily react with $\mathrm { S O } _ { 4 } { \bullet } ^ { - }$ $( k = 1 0 ^ { 7 } \mathrm { M ^ { - 1 } s ^ { - 1 } } )$ and OH• $\mathit { \Omega } ^ { \prime } k = 1 0 ^ { 9 } \mathbf { M } ^ { - 1 } \mathbf { s } ^ { - 1 } ,$ ) while TBA has much higher reaction rate with OH• $( 4 { - } 9 . 1 \times 1 0 ^ { 8 } \mathrm { M ^ { - 1 } s ^ { - 1 } } )$ than that with $\mathrm { S O } _ { 4 } { \bullet } ^ { - } ( 3 . 8 { - } 7 . 6 \times 1 0 ^ { 5 } \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 } )$ , thus, the TBA can be considered as the mainly OH• quencher. # 4. Conclusions

This work outlined the performance and mechanism of CoOOH/PMS system for degradation of target pollutant, 2,4-DCP. The CoOOH/PMS system integrated the strengths of heterogeneous catalysts and technology of AOP. $5 0 \mathrm { m g / L }$ 2,4-DCP could be $1 0 0 \%$ degraded within 120 min by adding $0 . 2 0 \mathrm { g / L }$ CoOOH and 6 mM PMS. Moreover, CoOOH exhibited much higher heterogeneous catalytic activity than

$\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ over a broader pH value (e.g. 3-9). Interestingly, the results suggested that $^ 1 { \bf O } _ { 2 }$ was the dominated ROS in the CoOOH/PMS system for 2,4-DCP degradation. Due to the efficient electron transfer rate performance of CoOOH, Co (Ⅲ) was rapidly turned to Co (Ⅱ) due to redox oxidation, then, the regeneration of Co (Ⅱ) on the surface of catalyst with high hydroxyl groups greatly facilitated the generation of $\mathrm { C o O H ^ { + } }$ , which plays key role for PMS activation and reactive oxygen species generation. Generally, this study provides a promising alternative to cobaltbased heterogeneous catalysts for activating PMS, suggesting a potential technology in waste water treatment.
