# . Introduction

Persistent organic pollutants (POPs) such as antibiotics (acyclovir (ACV) and naproxen (NPx)) and phenolic contaminants (bisphenol A (BPA), p-hydroxybenzoic acid (HBA), and phenol) are difficult to remove in wastewater and can produce great harm to human health and ecosystem [1,2]. Advanced oxidation processes (AOPs) based on peroxymonosulfate (PMs) activation have emerged as a promising approach to eliminate POPs by generated reactive oxygen species (ROS), such as sulfate radical $( S O _ { 4 } ^ { \bullet - } )$ , hydroxyl radical (OH), superoxide ion $( 0 \mathbf { \dot { 2 } } ^ { - } )$ and singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ , or by electron transfer pathway [36]. Typically, PMS requires activation by mediators like UV lights, thermal radiation, electricity, metal ions, metallic compounds, or carbon-based materials [2,5,7,8]. Carbon-based materials have arisen an universal interest because of their abundance, nontoxicity, biocompatibility, and chemical stability [9,10]. Carbon-based catalysts prepared from abundant and low-cost biomass sources are especially promising for PMS activation [11]. Pristine carbons usually present low or modest catalytic activity, while the modification by transition metals is often considered an effective way to introduce more favorable active sites [12,13].

In homogeneous reactions, PMS can be activated via transition metal ions like ${ \mathsf { C o } } ^ { 2 + }$ , $\mathrm { F e } ^ { 2 + }$ , $\mathrm { M n ^ { 2 + } }$ ,and $\mathrm { N i ^ { 2 + } }$ , among which ${ \mathsf { C o } } ^ { 2 + }$ /PMS shows the best activity [14]. However, excessive cobalt ions in water may be toxic and present various challenges, raising significant concerns to public health and the environment [8]. Loading cobalt on suitable supports like $\mathrm { { A l } _ { 2 } \mathrm { { O } _ { 3 } } }$ $\mathrm { T i O } _ { 2 }$ , MgO, and carbon can effectively decrease the leaching of cobalt ions [8,15]. Especially, carbon materials serve as excellent supports for Co and the introduction of Co as the active sites for carbon provides a feasible strategy for efficient, economical, and environmentally friendly activation of PMS to degrade pollutants in water.

Heterogeneous Co-carbon based materials have been widely developed as efficient AOP catalysts, like $\mathrm { C o _ { 2 } O _ { 3 } } ,$ activated carbon [16], cobalt n anoparticles decorated biomass derived carbon [5], Co-encapsulated nitrogen-doped carbon nanotube [17], cobalt-doped carbon aerogel [12], $\mathrm { C o } @ \mathrm { C }$ nanoarchitecture in porous carbons [18], $\mathrm { C o } _ { 9 } { S } _ { 8 }$ anchored in heteroatom doped carbon [19], $\mathrm { C o } _ { 9 } \mathrm { S } _ { 8 } @ \mathrm { N } - \mathrm { C }$ [20], and $\mathrm { C o } _ { 9 } \mathrm { S } _ { 8 } @ S$ and N co-doped biochar [21].

To the best of our knowledge, despite of the extensive study of Cocarbon based materials, the effects of different cobalt salts on biomassderived carbon material synthesis and catalytic performance have not been thoroughly and systematically investigated yet. In this context, we aim to elucidate the impact of cobalt salt precursors on biomass conversion, including the structure of the resulting products and their catalytic behavior in AOPs.

Using white rose flower as an example of plant biomass resource, we prepared Co-modified carbon catalysts under pyrolysis with different cobalt salts, i.e., cobalt acetate $( \mathsf { C o } ( \mathsf { O A c } ) _ { 2 } )$ , cobalt acetylacetonate (Co $( \mathsf { a c a c } ) _ { 2 } )$ , cobalt nitrate $\mathrm { ( C o ( N O _ { 3 } ) _ { 2 } ) }$ and cobalt sulfate $\mathrm { ( C o S O _ { 4 } ) }$ . Our findings indicate that the carbon product structures were closely related to the melting points and anion species of cobalt precursors. Specifically, cobalt salts $( \mathsf { C o } ( \mathsf { O A c } ) _ { 2 }$ ${ \mathrm { C o } } ( \mathsf { a c a c } ) _ { 2 }$ b $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } )$ with melting points $( \leq 1 6 5 ^ { \circ } \mathrm { C } )$ that are lower than the carbonization temperature of biomass can be trapped into the carbon precursor, catalyze its graphitization, and generate different volumes of mesopores during pyrolysis, producing $\operatorname { C o } ( \omega$ graphitic C nanoparticles and trace isolated Co atoms on graphitic carbon (denoted as $\mathbf { C o } @ \mathbf { C } { \cdot } \mathbf { A } \mathbf { c }$ ,Co@C-acac, and $\mathrm { C o } @ \mathrm { C } { \cdot } \mathrm { N O } _ { 3 }$ ,respectively). Cobalt salt $\mathrm { ( C o S O _ { 4 } ) }$ with a high melting point $( 7 3 5 ^ { \circ } \mathrm { C } )$ cannot catalyze carbon graphitization but can be decomposed with biomass to form cobalt sulfide nanoparticles on amorphous carbon $( \mathrm { C o g } S _ { 8 } @ \mathrm { C } { \cdot } S _ { } 0 _ { 4 } )$ . Among the as-synthesized samples, $\mathrm { C o } @ \mathbb { C } \mathrm { - N O } _ { 3 }$ and $\mathrm { C o } 9 { \cal S } _ { 8 } @ { \cal C } { \cdot } { \cal S } 0 _ { 4 }$ show the most excellent performance in PMS activation to degrade BPA, so we further comprehensively investigated their different reaction mechanisms, activity, and adaptability for different POP degradation. Cyclic experiments were performed to assess the reusability of the materials, while X-ray absorption near-edge structure (XANEs) analysis was adopted to analyze structural changes and recovery. $\mathrm { C o } @ \mathrm { C } { \cdot } \mathrm { N O } _ { 3 }$ and $\mathrm { C o } 9 { \cal S } _ { 8 } @ \mathrm { C } { \cdot } { \cal S } 0 _ { 4 }$ were also applied in real river water to degrade different and mixed POPs. Overall, $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 }$ and $\mathrm { C o S O _ { 4 } }$ are prospective cobalt precursors that can be employed to modify the structure of biomassderived carbon catalysts for robust water remediation.

# 2.4. Adsorption and AOP experiments

As a target pollutant, the initial concentration of the BPA solution was $1 0 ~ \mathrm { m g / L }$ , with a $\mathtt { p H }$ value of 7. At least two parallel experiments were conducted to show error bars for the adsorption and degradation plots. In adsorption tests, $0 . 1 \mathrm { m g / L }$ carbon-based catalysts were added to BPA solutions. In fixed time intervals, $^ \mathrm { ~ 1 ~ m L }$ sample was filtered into a screw thread bottle. An ultra-high-performance liquid chromatograph (UHPLC, Ultimate 3000) was used to detect the pollutant concentration in solution.

In AOP experiments, $0 . 1 \mathrm { \ m g / L }$ carbon-based catalysts were first added into $1 0 ~ \mathrm { m g / L }$ BPA solutions for pre-adsorption. After $1 0 \ \mathrm { m i n }$ ,3 mM PMS was added. In constant time intervals, $^ { 1 \ m L }$ resulting solution was taken and filtered. It was then quenched with $0 . 5 ~ \mathrm { m L }$ methanol for testing residual BPA concentration by UHPLC.

In cyclic experiments, the catalyst samples after the 1st run of the degradation test were filtered and washed. The collected catalyst materials were dispersed in ethanol under ultrasonic treatment for $^ \textrm { \scriptsize 1 h }$ . After that, the samples were filtered and washed alternately with water and ethanol, and then dried in an oven at $6 0 ^ { \circ } \mathrm { C }$ The samples were then applied for the 2nd run of the degradation test. Procedures were the same for the regeneration after the 2nd run. In addition, the reclaimed $\mathrm { C o } @ \mathrm { C } { \cdot } \mathrm { N O } _ { 3 }$ after the 1st run and $\mathrm { C o } 9 { \cal S } _ { 8 } @ \mathrm { C } { \cdot } { \cal S } 0 _ { 4 }$ after the 2nd run were cleaned and heat-treated at $3 0 0 ~ ^ { \circ } \mathrm { C }$ or $4 0 0 ~ ^ { \circ } \mathrm { C }$ with a ramp rate of $5 ~ ^ { \circ } \mathrm { C }$ $\operatorname* { m i n } ^ { - 1 }$ for $^ { 2 \mathrm { ~ h ~ } }$ under an $\Nu _ { 2 }$ flow for performance recovery.

In AOPs for ACV, NPX, HBA, and phenol, the steps were similar to those for BPA. In mixed-system degradation, the initial concentration of each pollutant was $2 \mathrm { m g } / \mathrm { L }$ with $0 . 1 \mathrm { m g } / \mathrm { L }$ catalysts and $3 \mathrm { m M }$ PMS. The first-order kinetics was applied to calculate the reaction rate constant (k) [3]:

$$
\mathrm { l n } ( \mathbf { C } _ { \mathrm { t } } / \mathbf { C } _ { 0 } ) = - \mathrm { k t }
$$

# 2.5. Mechanism analysis

# 2.5.1. Quenching tests

In a quenching test, $^ { 3 \mathrm { ~ M ~ } }$ or $^ { 5 \mathrm { ~ M ~ } }$ ethanol was added into a BPA solution to scavenge ·OH OH and $S O _ { 4 } ^ { \bullet - }$ , $3 0 0 \mathrm { m M }$ or $5 0 0 \mathrm { m M }$ TBA was used to clear ·OH [3,18,22], and $3 \mathrm { m M }$ TEMP was used to capture $^ 1 0 _ { 2 }$ [23]. # 2.5.2. Electrochemical tests

Open circuit potential (OCP) and cyclic voltammetry (CV) were carried out on a Zennium electrochemistry workstation (Zahner, Germany) with a three-electrode configuration. In the CV test, a graphite plate ${ \mathrm { 1 ~ c m } } ^ { * } 1 { \mathrm { c m } } )$ was applied as a working electrode. A saturated $\mathbf { A } \mathbf { g } { \big / }$ AgCl electrode and a Pt wire were applied as the reference and the counter electrodes, respectively. The potential gap between the reversible hydrogen electrode (RHE) and saturated $\mathbf { A g / A g C l }$ electrode was converted by the following equation:

$$
\mathrm { E _ { R H E } = E _ { A g / A g C l } + 0 . 0 5 9 ~ p H + 0 . 1 9 7 }
$$

For an OCP test, the working electrode was prepared by the following steps. A sample $( 4 ~ \mathrm { m g } )$ was mixed with $2 0 0 ~ \mu \mathrm { L }$ isopropanol and $5 ~ { \mu \mathrm { L } }$ Nafion $^ \mathrm { \textregistered }$ 117 solution by ultrasonic treatment. Afterward, $5 . 5 \mu \mathrm { L }$ of the mixture was dipped into the center of the glassy carbon electrode. The process was repeated 23 times until the electrode center was all covered by the mixture. Then, chronopotentiometry analysis was carried out to monitor OCP changes. Later, $3 \mathrm { m M }$ PMS and $1 0 \mathrm { m g / L }$ BPA were added to detect OCP changes. At the same time, the change in pH value was recorded after PMS or BPA addition.

# 4. Conclusion

In summary, this work probed the structural engineering of biomassderived carbon catalysts by different cobalt precursors for PMS-based pollutant degradation. The melting point of cobalt salts was ascertained to be a vital factor that shaped the structures and properties of the as-prepared products. The cobalt precursors with low melting points $( \leq 1 6 5 ^ { \circ } \mathrm { C } )$ contributed to the graphitization of biomass during pyrolysis, and $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 }$ shows the best modification effect to generate the highest SSA, mesopore volume, and best catalytic activity. With graphitic C, $\operatorname { C o } ( \varnothing \mathrm { C }$ nanostructure, $\mathrm { { C } = 0 }$ groups, and trace isolated Co atoms as the potential active sites, $\mathrm { C o } @ \mathrm { C } { \cdot } \mathrm { N O } _ { 3 } / \mathrm { P M S }$ generates ·OH, $S O _ { 4 } ^ { \bullet - }$ , $^ 1 0 _ { 2 }$ and electron transfer in radical/nonradical pathways for BPA degradation with $4 0 . 9 \%$ mineralization. By contrast, pyrolysis of biomass flower with $\mathrm { C o S O _ { 4 } }$ that has a high melting point $( 7 3 5 ^ { \circ } \mathrm { C } )$ produces amorphous carbon/ $\mathrm { ' C o o } S _ { 8 }$ nanoparticle with $\mathrm { C o } _ { 9 } S _ { 8 }$ as the highly active site for PMS activation and selectively generate $S O _ { 4 } ^ { \bullet - }$ for high mineralization $( 9 9 . 8 \% )$ of BPA. The structure changes of $\mathrm { C o } @ \mathrm { C } { \cdot } \mathrm { N O } _ { 3 }$ and $\mathrm { C o } _ { 9 } \mathrm { S } _ { 8 } @ \mathrm { C } \cdot \mathrm { S O } _ { 4 }$ during cyclic tests and regeneration by low-temperature treatment were investigated, with both catalysts exhibiting recovery of excellent catalytic ability after $4 0 0 ~ ^ { \circ } \mathrm { C }$ treatment. The two catalytic systems also demonstrate excellent applicability in a wide pH range with the existence of different anions for removing multiple pollutants in complex real water.
