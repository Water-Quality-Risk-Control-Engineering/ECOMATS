# . Introduction

Fluoroquinolones (FQs) are the fourth most applied antibiotics for treating various microbial infections in humans and other organisms [1, 2]. Among the antibiotics belonging to FQs family, moxifloxacin (MFX) is an antibiotic used popularly to treat skin infection and against both Gram-positive and Gram-negative bacteria through activity inhibition of DNA [3]. However, upon applied to the human, the FQs are incompletely metabolized. Thus, about $2 0 { - } 8 0 \%$ of antibiotics are excreted through fecal and urine, finally discharged into receiving water bodies, and cause antibiotic resistance in bacteria [4]. The FQs concentration in the aquatic medium is detected up to mg/L [2]. Specifically, the FQs concentration ranged from $3 \ \mathrm { n g / L }$ to $2 4 0 ~ \mu \mathrm { g / L }$ in hospital wastewater and from $0 . 5 ~ \mathrm { { n g / L } }$ to $6 . 5 ~ \mathrm { m g / L }$ in surface water [5]. Especially, the exceptionally high concentration of FQs was detected in the pharmaceutical wastewater in the range from $6 ~ \mathrm { { n g / L } }$ to $3 1 ~ \mathrm { m g / L }$ [5]. Due to the persistent aromatic ring structure, conventional treatment technologies can not effectively remove these antibiotics because of the relatively low degradation rates of microbial [4]. Therefore, it is essential to develop advanced treatment technology to effectively remove of FQs from wastewater.

Recently, the advanced oxidation processes (AOPs) based on reactive oxygen species (ROs) such as hydroxyl $\mathrm { ( ^ { * } O H ) }$ , sulfate $( { } ^ { * } { \bf S O } _ { 4 } ^ { - } )$ , superoxide $( { \ " } 0 _ { 2 } )$ , and singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ have been emerging as costeffective technologies in degradation of persistent organic pollutants (POPs) [68]. Among the AOPs, persulfate-based processes have been attracting more attention in environmental pollution treatment. Peroxydisulfate $( S _ { 2 } O _ { 8 } ^ { 2 - }$ -PDS) is one of persulfate oxidants with a high standard oxidation potential of $2 . 0 1 \mathrm { V }$ [9], which can effectively produce sulfate radicals $( { } ^ { * } S 0 _ { 4 } ^ { - } )$ when is activated by physical or chemical agents. The formed $^ { * } S O _ { 4 } ^ { - }$ radicals then participate in the degradation of POPs from wastewater [10]. Among heterogeneous catalysts used to activate PDS, the ferrite spinel nanoparticles $\mathrm { ( M F e _ { 2 } O _ { 4 } ) }$ have been to be effective in activating PDS through the release of $\mathrm { F e } ^ { 2 + }$ in ${ \mathrm { M F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs constituent [10]. Among ferrite spinel nanoparticles, the ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs were among the popularly used catalysts to initiate persulfate activation because the couple of Ni and Fe has exhibited high catalytic activity and excellent magnetic property, which is beneficial for the treatment process with its easy recovery. For example, Wang et al., 2026 reported effective activation of peroxymonosulfate (PMS) by $\mathrm { N i F e _ { 2 } O _ { 4 } }$ for degradation of benzoic acid (BA) [11]; $\mathrm { N i _ { x } C o _ { 3 - x } O _ { 4 } }$ activated PDS for removal of tetracycline and bisphenol A [12]; degradation of sulfamethoxazole (SMX) by activating PMS using $\mathrm { C o F e _ { 2 } O _ { 4 } }$ [13]. However, using only ferrite spinel based-heterogeneous catalysts to activate persulfate exhibited some limitations, such as high cost, low stability, difficulty in recovery after reaction, and strong aggregation tendency of catalysts [6,7]. Therefore, to manipulate these drawbacks, it is necessary to develop low-cost, high-stability supporters for $\mathrm { N i F e _ { 2 } O _ { 4 } }$ NPs ferrite spinel to activate PDS for degradation of MFX from wastewater effectively.

Biochar (BC) derived from agricultural by-products possesses a good porous structure and is rich in surface functional groups with low production cost and is to be proven the most suitable supporter for good dispersion of NPs catalysts [7,1416]. Besides, the DP-BC also had the ability for activation of PDS thanks to the abundant surface functional groups [3]. These biochar-based composite catalysts exhibited high effectiveness in activating persulfate to enhance the generation of ROS such as $^ { \ast } { \bf S } 0 _ { 4 } ^ { - }$ . For instance, Li et al. (2020) reported the effectively activation of PMS by biochar loaded with ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs $\mathrm { C o F e _ { 2 } O _ { 4 } / H P C ) }$ for degradation of bisphenol A [15]; removal of PAEs in marine sediments using rice husk-based magnetic biochar for activation of PDS [17]; Fe-biochar composites for activation of PDS to degrade organic pollutants [6].

The simultaneous presences of redox couple of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ and $\mathrm { N i } ^ { 3 + } /$ $\mathrm { N i ^ { 2 + } }$ give richer redox reactions which enhance electron and energy transfer to activate PDS to generate ROS, leading to a noticeable increase in catalytic activity of nanocomposite. However, there has been little available information on the development of biochar-supported $\mathrm { N i F e _ { 2 } O _ { 4 } }$ composite for peroxydisulfate (PDS) activation to remove moxifloxacin from wastewater up to now. Therefore, the aim of this study was to develop a durian peels-derived biochar (DP-BC) as a supporter for the dispersion of $\mathrm { N i F e _ { 2 } O _ { 4 } }$ NPs to form $\mathrm { D P } { \cdot } \mathrm { B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 }$ nanocomposite catalyst for the activation of PDS to degrade MFX from wastewater. When composited with DP-BC, the $\mathrm { D P - B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 }$ composite exhibited supermagnetic properties, thus accessible in separation from solution after catalytic reaction using a magnet and reduced the agglomeration of ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanoparticles. To achieve this aim, the primary tests were conducted to find the most suitable pyrolysis temperature to fabricate biochar from durian peels via the degradation performance of MFX. The catalytic activity of $\mathrm { D P } { \cdot } \mathrm { B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 }$ nanocomposite at various modification ratios between DP-BC and ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs was evaluated through the removal efficiency of MFX. The physicalchemical properties of biochar, ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 } ~ { \mathrm { N P s } } ,$ and $\mathrm { D P } { \cdot } \mathrm { B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 }$ at various composite ratios were systematically studied. The primary degradation kinetic and mechanisms of MFX in the I $\mathrm { ) P { - } B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } /$ PDS system were elucidated in this study.

# 2. Materials and methods

The waste durian peels were collected from fruit shops in Ho Chi Minh City, Vietnam. Moxifloxacin (MFX, $\mathrm { C } _ { 2 1 } \mathrm { H } _ { 2 4 } \mathrm { F N } _ { 3 } \mathrm { O } _ { 4 } )$ was purchased from Sigma Aldrich (Germany). # 2.2. Preparation of catalyst materials

This work used the waste durian peels (DP) to prepare pristine biochar by slow pyrolysis method in the temperature range from 300500 $^ \circ \mathrm { C }$ with a heating rate of $5 { - } 7 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ In the first step of the process, the DP was repeatedly washed using double distilled water (DDW) to remove impurities. Then, the DP was cut into small pieces of $_ { 1 - 2 \thinspace \mathrm { c m } }$ size and dried at $1 2 0 ^ { \circ } \mathrm { C }$ for $2 4 \mathrm { h }$ The dried DP was continuously blended and sieved via sievier with a pore size diameter of $6 \mathrm { m m }$ . The DP power was then activated by KOH 1 M using an agitator at $1 2 0 ~ \mathrm { r p m }$ for $^ { 2 \mathrm { ~ h ~ } }$ The KOH-activated DP was dried at $1 0 5 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { ~ h ~ } }$ Afterwards, the dried KOH-activated DP power was pyrolyzed at 300, 350, 400, 450, and 500 $^ \circ \mathrm { C }$ in a furnace under limited oxygen conditions for $^ { 2 \mathrm { ~ h ~ } }$ with a heating rate of $5 { - } 7 ~ ^ { \circ } \mathrm { C }$ ,Finally, the mixture in the furnace was gradually and naturally cooled to room temperature to obtain pristine biochar at various pyrolysis temperatures. The obtained biochar was labeled as DPBC-300, DP-BC-350, DP-BC-400, DP-BC-450, and DP-BC-500. The schematic diagram of the preparation of DP-BC is illustrated in Fig. A1a.

In the following procedure, the ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs were synthesized the coprecipitate method. # 2.3. Catalytic activity measurement

The experiments to assess the catalytic activity of as-prepared DP${ \tt B C @ N i F e _ { 2 } O _ { 4 } }$ nanocomposite were carried out in batch-mode, through degradation efficiency of moxifloxacin (MFX). All tests were conducted using a $1 0 0 0 ~ \mathrm { { m L } }$ glass beaker containing $3 0 0 ~ \mathrm { m L }$ of MFX-contaminated solution of $3 0 ~ \mathrm { m g / L }$ at room temperature $( 2 5 { \pm } 2 \ ^ { \circ } \mathrm { C } )$ under constant agitation over $9 0 \mathrm { { m i n } }$ of reaction time. After adding $0 . 2 { \ g } / \mathrm { L }$ of PDS into the MFX-containing reactor, the solution pH was immediately adjusted to 3.0 using HCl 0.1 M and $\mathrm { N a O H } 0 . 1 \mathrm { M }$ The reactor was then initiated by adding a catalyst dosage of $0 . 6 \ g / \mathrm { L }$ . At interval time, $1 0 ~ \mathrm { m L }$ of solution was taken out of the reactor and filtered via $0 . 2 2 ~ { \mu \mathrm { m } }$ cellulose acetate membrane to collect liquid to determine the left MFX concentration in solution. All experiments were repeated in triplicate. Conversely, at a low pyrolysis temperature of $3 0 0 ^ { \circ } \mathrm { C } ,$ , the MFX removal was the lowest. There was no significant difference in MFX removal efficiency when using biochar pyrolyzed under a temperature range from $4 0 0 { - } 5 0 0 ~ ^ { \circ } \mathrm { C }$ The result is because there was a good development in the specific surface area and porous structure of DP-BC at higher pyrolysis temperatures [19]. # 3.5. Proposed mechanism

In combination with analysis data about physical-chemical characteristics of $\mathrm { D P - B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } { - } 1 5$ nanocomposite, in order to elucidate contribution of free radicals $( { } ^ { * } S 0 _ { 4 } ^ { - }$ , $\scriptstyle { \mathrm { ~ } ^ { * } \mathrm { O H } }$ , $\bf { \ddot { \alpha } O _ { 2 } } )$ and non-free radicals $( ^ { 1 } 0 _ { 2 } )$ to MFX degradation by D $\mathrm { P { - } B C  @ N i F e _ { 2 } O _ { 4 } { - } 1 5 / P D S }$ ,various scavengers, including EtOH, TBA, p-BQ and $\mathrm { N a N } _ { 3 }$ were supplemented into quenching reactors. The experiments were conducted under reaction conditions of $3 0 \mathrm { m g / L }$ MFX, PDS dosage of $0 . 2 { \ g } / \mathrm { L }$ , DP- $3 \mathrm { C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } { - } 1 5$ dosage of $0 . 6 g / \mathrm { L }$ at pH of 3.0 with adding $0 . 5 { \mathrm { M } }$ TBA, 0.5 M EtOH, 1 mM p-BQ and $0 . 0 1 \mathrm { M N a N } _ { 3 }$ , in separately. The results as shown in Fig. 7.

As indicated in Fig. 7, the supplementation of both TBA and EtOH in to $\mathrm { D P - B C @ N i F e _ { 2 } O _ { 4 } } – 1 5 / \mathrm { P D S }$ system had the slight effect on degradation of MFX with a decrease of $\mathbf { k _ { d } }$ by $2 2 . 7 \%$ and $3 1 . 6 \%$ , respectively. This proved that there was a limitation amount of $\mathrm { { \stackrel { \cdot } { \sim } } O H }$ and $^ { * } S O _ { 4 } ^ { - }$ formed in I $\mathrm { ) P { \cdot } B C  @ N i F e _ { 2 } O _ { 4 } { - } 1 5 / P D S }$ system and both $\mathrm { { \stackrel { \cdot } { \tilde { \alpha } } } O H }$ and $^ { * } { \bf S } 0 _ { 4 } ^ { - }$ radicals were not the dominant ROS in this system. Conversely, in the reactions with adding of p-BQ and $\mathrm { N a N } _ { 3 }$ , negative effects on MFX removal by DP$\mathsf { B C @ N i F e _ { 2 } O _ { 4 } } – 1 5 / \mathsf { P D S }$ system strongly occurred with a significant drop in $\mathbf { k } _ { \mathbf { d } }$ values by $4 0 . 2 \%$ and $7 4 . 0 \%$ , suggesting both $\mathrm { { } ^ { \ast } O _ { 2 } }$ and $^ 1 0 _ { 2 }$ play a vital role in degradation of MFX. Moreover, the contribution of $^ 1 0 _ { 2 }$ to MFX catalytic degradation was higher than that of $\mathrm { ^ { * } O _ { 2 } }$ as confirmed by the stronger quenching effect of $\mathrm { N a N } _ { 3 }$ Besides, it was proving that when $_ \mathrm { H _ { 2 } O }$ was replaced by solvent $\mathrm { D } _ { 2 } \mathrm { O }$ , the lifetime of $^ 1 0 _ { 2 }$ was lengthened up to 10 times [7]. Thus, in this study, to confirm role of $^ 1 0 _ { 2 }$ in degradation of MFX by DP-BC $\ @ \operatorname { N i F e } _ { 2 } 0 _ { 4 }$ -15/PDS system, the $\mathrm { D } _ { 2 } \mathrm { O }$ solvent was added in the oxidation system, replacing solvent $_ \mathrm { H _ { 2 } O }$ . The similar results were reported in previous study [7]. As a result, the MFX catalytic degradation by $\mathrm { D P { - } B C @ N i F e _ { 2 } O _ { 4 } { - } 1 5 / P D S }$ system was mainly through non-radical pathways by $^ 1 0 _ { 2 }$ . The analogue results were also shown by previous studies [6,7,29]. # Reusability of catalyst

The reusability has vital role in the heterogeneous solid catalyst oxidation systems from the practical application point of view. In this study, the reusability of the $\mathrm { D P - B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } { - } 1 5$ was assessed via five successive degradation cycles of MFX by recycled DP ${ \bf \cdot B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } { - } 1 5 /$ PDS. The result is presented in Fig. 9. As can be seen from Fig. 9, the degradation rate saw a gradually drop during the five successive runs. To be specific, the removal efficiency of MFX decreased from 87.2 to $5 5 . 9 \%$ from the first run to fifth run. This drop can be because of leaching the active Ni and Fe species [16]. However, the decrease in

MFX removal in the third cycle was negligible, proving good reusability of $\mathrm { D P - B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } { - } 1 5$ .

# 4. Conclusions

In this work, the DP. $\mathrm { \cdot B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 }$ nanocomposite was prepared from loading ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ NPs onto biochar derived from waste durian peels supporter. The DP-E $\mathsf { i C @ N i F e _ { 2 } O _ { 4 } }$ exhibited an improved catalytic activity in DP ${ \bf \cdot B C } @ { \bf N i F e } _ { 2 } { \bf O } _ { 4 }$ -15/PDS system for effectively removal of MFX from wastewater. The results indicated that all ROS, including $^ \mathrm { * } \mathrm { O H }$ $^ { \ast } \mathbf { S } \mathbf { O } _ { 4 } ^ { - }$ , ${ \bf { \ddot { \alpha } } } _ { \bf { O } _ { 2 } }$ and $^ 1 { \bf O } _ { 2 } ,$ participated in MFX degradation with different degree. And the $^ 1 0 _ { 2 }$ was the dominated ROS in the $\mathrm { D P - B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } \mathrm { - } 1 5 / \mathrm { P D S }$ system. The combination between DP-BC and ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ greatly improved the generation of ROS due to redox reactions of couples $\mathrm { F e } ^ { 3 } / \mathrm { F e } ^ { 2 + }$ and $\mathrm { N i } ^ { 3 + } / \mathrm { N i } ^ { 2 + }$ and precun -cntai urtional groups on the biochar's surface. The findings suggested that the $\mathrm { D P - B C } @ \mathrm { N i F e } _ { 2 } \mathrm { O } _ { 4 } \mathrm { - } 1 5 / \mathrm { P D S }$ system had high potentials in the removal of persistent organic pollutants from wastewater.
