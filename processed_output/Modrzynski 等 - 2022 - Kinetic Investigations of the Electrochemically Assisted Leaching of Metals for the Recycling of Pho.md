# Kinetic Investigations of the Electrochemically Assisted Leaching of Metals for the Recycling of Photovoltaics

Christian Modrzynski, ${ \pmb z } _ { \oplus }$ Jonathan Z. Bloh, and Claudia Weidlich

DECHEMA-Forschungsinstitut, Frankfurt am Main, Germany

To describe and predict the leaching of Ag, Cu and Sn from waste photovoltaic modules with an electrochemical-assisted process kinetic investigations were performed. In this process, peroxydisulfate is generated from sulfuric acid to oxidize metals. It was found that under the reaction conditions peroxymonosulfate is formed as well and has a major contribution to the leaching process. Electrochemically assisted leaching has great potential as a green method for recycling metal containing materials, especially electronics. In such a process, a leaching reagent is generated or continuously regenerated at an electrode that is placed in a solution containing the metal-containing compounds that are to be dissolved. Several applications have been described recently, e.g., for batteries,1– electronic waste5 and photovoltaic (PV) systems6 as discussed here.

On one hand, PV producers are obliged to recycle their modules according to the Waste Electrical and Electronic Equipment (WEEE) directive of the European Union7 on the other hand these modules contain substantial amounts of Cu and Ag making their recovery economically relevant. Additionally, the silicon wafers are of significant value, if the material can be recovered in high purity. Ag is printed onto the silicon wafers to enhance their conductivity while $\mathrm { C u }$ is part of busbars soldered to the $\mathbf { A } \mathbf { g }$ contact. A common process to remove these metals is by leaching them with concentrated $\mathrm { H N O } _ { 3 }$ which is hazardous to handle in large quantities and generates substantial amounts of toxic nitrous oxides.8–13 In a different process, HCl was proposed to remove and recover several metals, excluding Ag.14 Therefore, different leaching processes are interesting to improve the safety and ecological impact of the recycling methods. As an alternative, peroxydisulfate with a standard potential of $2 . 0 \mathrm { V }$ can be used as strong oxidizer that is already employed in advanced oxidation processes15–20 as well as leaching/etching applications.21–24 Here, $\mathrm { \dot { S } } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ -salts are usually added batchwise to the solution which has the disadvantage that $S _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ has a limited stability in the strongly acidic solutions25–27 that are typically required for leaching unreactive metals. To mitigate this, $\mathrm { S } _ { 2 } \mathrm { \dot { O } } _ { 8 } { } ^ { 2 - }$ can be generated electrochemically in situ with high efficiency on boron-doped diamond electrodes,28–31 making them attractive for the desired application. These electrodes possess a high overpotential for $\mathrm { O } _ { 2 }$ -evolution and thus allow the generation of strongly oxidizing species.32,33 This method has been proven to be effective for leaching Ag, Cu and Sn from PV modules to recover pure silicon.6 In these studies it was found that the leaching process is complex due to the involvement of peroxymonosulfate formed as decomposition product of $S _ { 2 } { \mathrm { O } } _ { 8 } ^ { 2 - }$ . As electrogenerated persulfate, is an interesting reagent for leaching purposes in recycling, etching in general and leaching in mining applications, more details about the reactions taking place are required. Thus, further insight into the reaction kinetics is required to predict the course of the reaction and optimize the process.

To validate the simulation data, it was compared to real leaching experiments of which two selected examples are shown in Fig. 13 as well as Figs. S5 and S6. The data correlates well and thus, allows reliable predictions for the leaching process. The observed minor deviations can be a result of several factors of which temperature has probably the greatest influence in general and variations in the flow rate for the flow cell. Especially if high currents are used in the Hcell, a rise in temperature of the solution occurs, changing the reaction rates. Furthermore, the stir rate can influence the leaching rate of the heterogenous reactions. The largest deviation is found for the flow cell etching of $\mathbf { A } \mathbf { g }$ (Fig. 13b) with high current and flow rate, showing a root mean square error (RMSE) of $43 \%$ , since with these parameters the linear Eq. 31 becomes invalid as side reactions occur comparable to the H-cell, making these settings unfavorable. Thus, the derived equations and experimentally determined rate constants allow a reliable description of the etching process.

# Conclusions

The investigations show that the removal of metal coatings is not as straightforward as expected. While the etching of $\mathrm { C u }$ occurs without difficulties the limited solubility of $\mathrm { C u S O _ { 4 } }$ in $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ reduces the efficiency of the process, bearing in mind that Cu is the major component of PV busbars.6 Furthermore, the autocatalytic decomposition of the leaching reagents by ${ \mathrm { A g } } ^ { + }$ is especially problematic at prolonged reaction times and necessitates a renewal or stripping of the solution to minimize $[ \mathrm { A g } ^ { + } ]$ . Yet, the overall low $\mathbf { A } \mathbf { g }$ content of solar cells mitigates this issue. The etching of Sn was found to be strongly limited by the slow dissolution of $\mathrm { S n S O } _ { 4 }$ on the surface, nevertheless, it is leached effectively, aided by the high solubility of the formed ${ \mathrm { S n } } ^ { 4 + }$ . The comparison of simulated concentration profiles is in good accordance with experimental data allowing reliable process predictions. Overall, the use of electrochemically generated peroxydisulfate was found to be a viable process that can be a more sustainable method compared to conventional HNO₃
