# Enhanced removal of antibiotics in hospital wastewater by Fe–ZnO activated persulfate oxidation†

Gnougon Nina Coulibaly,ab Sungjun Bae,b Joohyun Kim,b Aymen Amin Assadia and Khalil Hanna $\textcircled{1}$ \*a

Removal of two widely used antibiotics, flumequine (FLU) and ciprofloxacin (CIP), in synthetic and real hospital wastewaters was investigated using Fe-doped zinc oxide (Fe–ZnO) and UV-A irradiation. Fe–ZnO was supported on a cellulose acetate membrane and integrated in a recirculation reactor system, designed for continuous oxidative treatment of contaminated wastewaters. Addition of a low concentration of persulfate ( $0 . 5 ~ \mathsf { m M }$ ) improved considerably the degradation extent, where sulfate radicals were found to be the most involved oxidizing species. Oxidation rate constants decreased in mixture systems with respect to those of individual compounds, because of competition effects with radical species. Wastewater constituents like those found in hospital effluents affected the removal of both CIP and FLU, but CIP degradation is less affected probably because of its higher reactivity with sulfate radicals. Inorganic anions altered slightly the oxidation rate, while the organic compounds commonly found in wastewaters considerably reduced the degradation efficiency. ZnO doped with Fe exhibited photoactivity higher than bare zinc oxide and commercial $\mathrm { T i O } _ { 2 }$ , especially in hospital wastewater. The Fe–ZnO supported membrane can also be re-used for several oxidation runs, making this system quite suitable for larger applications in wastewater treatment processes.

# Water impact

A recirculation reactor system was designed to remove fluoroquinolones (FQs) in hospital wastewaters. FQs containing cyclopropane/piperazine rings have shown greater reactivity with radical species, and are less affected in multi-component wastewater systems, though natural organic matter affects considerably the degradation efficiency. This new system exhibited higher photoactivity than classical $\mathrm { T i O } _ { 2 }$ in wastewater and can be re-used for several oxidation cycles.

# 1. Introduction

Antibiotics, disinfectants, cytostatics, contrast agents, metals and other medicinal residues are present at significant concentrations in hospital wastewater.1 Fluoroquinolones (FQs) represent the third largest group of antibiotics with an increased use in hospitals, households and veterinary medicine.2,3 Among FQs, flumequine (FLU) and ciprofloxacin (CIP) can be found at relatively high concentrations in environmental settings. For instance, FLU can be detected at $6 . 9 \ \mu \mathrm { g } \ \mathrm { g } ^ { - 1 }$ in soil and from 2.5 to $5 0 ~ \mathrm { ~ n g ~ L } ^ { - 1 }$ in aquatic environments.4,5 The CIP concentration in treated hospital wastewater was found to be higher $( \sim 1 6 ~ \mu \mathrm { g } \ L ^ { - 1 } )$ than that in environmental systems $( 0 . 6 \mathrm { ~ \bf ~ \mu g ~ \mathrm { ~ \bf ~ L ~ } ^ { - 1 } } )$ .6–8 Although these compounds often co-exist with other inorganic and organic compounds, most previous studies have mainly focused on removal processes in mono-component systems and in pure water or synthetic contaminated waters.9

In order to remove antibiotics from wastewaters, advanced oxidation processes have attracted great attention through generation of reactive oxygen species (ROS).9–11 Among these processes, photocatalysis has been widely used in order to remove organic compounds in contaminated waters. The photocatalysis process involves irradiation of semiconductors such as $\mathrm { T i O } _ { 2 }$ or $\mathrm { z n o }$ , and when the energy of photons is greater than the width of the semiconductor band gap, electronic gaps (commonly called holes and denoted as $\mathrm { { h ^ { + } } }$ and electron overload denoted as e− ) are created.11–18 These charges migrate to the surface, act as electron donors or electron acceptors and initiate redox reactions, generating radical species.12 ZnO is considered as an environmentally friendly catalyst due to its non-toxic nature coupled with low cost.19 For $\mathrm { T i O } _ { 2 }$ or ${ \bf { Z n O } }$ , the photocatalytic activity is, however, still suffering from lower quantum efficiency because of the very fast recombination of photogenerated electron/hole pairs. To address this issue, incorporation of metallic (e.g. Fe)20,21 and non-metallic species22 has been proposed in order to enhance the photocatalytic activity. Although some studies were dedicated to the use of $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ in decontamination reactions,20,21 much remains to be learned on the ability of this material to effectively remove contaminants in mixtures and in real wastewaters. Indeed, very few investigations have been conducted to develop cost-effective methods for the elimination of antibiotics in multi-component systems, and much less in real wastewaters where target contaminants are found with many other colloidal or dissolved substances. Furthermore, supporting these reactive phases on materials such as membrane filters may offer great advantages for high-scale applications, especially in continuous wastewater treatment.23–25

In this study, the ability of iron doped-zinc oxide $\mathbf { ( F e { - } Z n O ) }$ supported on a cellulose acetate (CA) membrane to effectively remove two FQs, FLU and CIP, separately and in mixture was investigated under UV-A irradiation. Different water matrices [i.e., ultra-pure water (UPW), synthetic wastewater (SWW) and real hospital wastewater (RHW)] were used in order to test the impact of wastewater constituents on the removal performance. The CA membrane filter was selected as a support material because it is flexible, cheap and chemically stable in water. Fe–ZnO catalysts were characterized using high resolution-field emission scanning electron microscopy with energy dispersive X-ray (HR-FESEM-EDX) and X-ray diffraction (XRD). The effect of the addition of oxidants such as hydrogen peroxide $\left( \mathbf { H } _ { 2 } \mathbf { O } _ { 2 } \right)$ and persulfate ions $\left( \mathbf { S } _ { 2 } \mathbf { O _ { 8 } } ^ { 2 - } \right)$ o n the removal kinetics of FLU and CIP was also investigated. Quenching experiments were conducted to identify the main reactive species in the investigated system. The reusability of iron doped-zinc oxide $\bf ( F e - Z n O )$ has been evaluated in successive oxidation cycles and compared with that of commercial $\mathrm { T i O } _ { 2 }$ under the same operational conditions.

# 2.1. Chemicals

# 2.2. Preparation and characterization of Fe–ZnO supported on the CA membrane

A solvothermal method was used to synthesize Fe–ZnO nanoparticles following a modified procedure of Jia et al. (2009).26 Briefly, $\mathbf { 0 . 8 6 \  g }$ of zinc acetate dihydrate and different amounts $( 0 { - } 1 . 4 \%$ wt) of ironĲIII) nitrate nonahydrate were added to ethanol $\left( 6 0 \ \mathrm { m L } \right)$ under vigorous stirring for $^ { 2 \mathrm { ~ h ~ } }$ at room temperature. At the same time, $2 . 4 \textrm { ‰}$ of NaOH was dissolved into $1 0 0 ~ \mathrm { { m L } }$ ethanol, and then the prepared $\mathbf { F e - Z n }$ solution was added into a NaOH–ethanol solution dropwise under constant stirring for $^ \mathrm { ~ 1 ~ h ~ }$ . The mixed solution was transferred to a Teflon-lined stainless autoclave and thermotreated for $^ { 2 0 \mathrm { ~ h ~ } }$ at $1 5 0 ~ ^ { \circ } \mathrm { C } .$ . The dried sample was collected by centrifugation and washed several times with water and ethanol. Finally, the washed particles were dried for $^ { 1 5 \mathrm { ~ h ~ } }$ at $6 0 ~ ^ { \circ } \mathrm { C }$ and only $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ nanoparticles were calcined for $^ { 2 \mathrm { ~ h ~ } }$ at $5 0 0 ~ ^ { \circ } \mathrm { C }$ .

In order to support Fe–ZnO nanoparticles on CA membrane filter, we followed the method previously reported in Zhao et al. (2016).27 Different amounts of $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ nanoparticles were dispersed in $1 0 0 ~ \mathrm { \ m L }$ ultra-pure water under ultra-sonication. Then, the suspension was filtered on a piece of CA membrane ( $6 4 ~ \mathrm { m m }$ in diameter and $0 . 4 5 ~ { \mu \mathrm { m } }$ in pore size). Lastly, the membrane was pressed under ${ \bf 0 . 3 \ M P a }$ of nitrogen gas for $^ \mathrm { ~ 1 ~ h ~ }$ and the $\mathbf { F e - Z n O / C A }$ membrane was dried for $^ { 2 4 \mathrm { ~ h ~ } }$ at room temperature.

The morphology and particle size of synthesized $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ were identified using a HR-FESEM (SU8010, Hitachi High Technologies Corporation) equipped with an EDX instrument. The mineral phases in $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ were analyzed with an XRD (JP/MAX-3C, Rigaku) in the 2-theta range of $^ { 1 0 - }$ $9 0 ^ { \circ }$ at a scan speed of $2 ^ { \circ } \operatorname* { m i n } ^ { - 1 }$ .

# 2.3. Recirculation reactor and degradation experiments

The degradation of FQs using ZnO and Fe–ZnO was investigated using a recirculation glass reactor described in Fig. S1.† A peristaltic pump (Easy-Load Masterflex Head XX80 ELO 05) was used to circulate the contaminated solutions or wastewaters into the photoreactor continuously at a constant flow rate $( 2 2 2 \ \mathrm { \ m L } \ \mathrm { \ m i n } ^ { - 1 } )$ ). A UV-A lamp (PL-S 9W/10/2P; Philips, 9 W) was used as a light source at an intensity of 3.4 mW $\mathrm { c m } ^ { - 2 }$ measured using a radiometer (VLX-3W equipped with a sensor CX 365, ALYS Technologies, Switzerland). All photocatalytic experiments were performed under similar conditions at ambient temperature and an initial $\mathrm { p H }$ of $7 . 0 \pm$ 0.2. The $\mathrm { p H }$ value determined at the end of the reactions was around ${ \bf 6 . 9 \pm 0 . 3 }$ . A total of $^ \mathrm { ~ 1 ~ L ~ }$ of $5 ~ \mu \mathbf { M }$ FLU and/or CIP solutions were reacted with the CA supported photocatalyst for $^ { 1 2 \mathrm { ~ h ~ } }$ under dark conditions to achieve the adsorption– desorption equilibrium prior to the photoreaction, and then they were later exposed to UV radiation for decontamination. At each time interval, $1 . 5 ~ \mathrm { \ m L }$ of the treated solution was collected to determine the concentration of each compound by high performance liquid chromatography (HPLC). In order to investigate the effect of water matrices on the photooxidation of FLU and CIP, we prepared a synthetic wastewater as previously described.28 A real hospital wastewater sample was provided by the University Hospital Center of Rennes (Rennes City, France).

The FLU and CIP concentrations were measured using an Alliance UV controller HPLC system equipped with an autosampler (Waters 717 Plus), a C18 column $( 2 5 0 ~ \mathrm { m m } \times 4 . 6 ~ \mathrm { m m }$ ; i.d., $5 ~ { \mu \mathrm { m } }$ ) and a UV detector ( $2 4 6 \ \mathrm { n m }$ for FLU or $2 7 5 \ \mathrm { n m }$ for CIP, Alliance UV 2489). The mobile phase was a mixture of water/acetonitrile $5 5 : 4 5 { \mathrm { ~ } } { \mathrm { v / v } }$ and $1 5 : 8 5 { \mathrm { ~ } } { \mathrm { v } } / { \mathrm { v } }$ for FLU and CIP, respectively) containing $\mathbf { 0 . 1 \% }$ formic acid. The flow rate of the mobile phase was set at $1 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ in an isocratic mode. Total organic carbon (TOC) was determined using a TOCmeter (Shimadzu TOC-VCSH). All experiments of kinetic reactions were conducted in triplicate and showed a good reproducibility within $5 \%$ relative standard deviation.

# 3. Results and discussion

# 3.1. Characterization of Fe–ZnO supported materials and UVassisted oxidation tests

The XRD patterns showed that the crystallographic structure of $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ $( \mathbf { 0 . 7 \ w t \% }$ Fe) corresponds to that of $\mathrm { z n O }$ with no apparent iron oxides detected, probably due to the low detection limit of the XRD measurement (needed $> 2 ~ \mathrm { w t \% }$ ) (Fig. 1). However, the SEM images showed the effect of Fe on the particle size and morphology of $\bf { Z n O }$ . Indeed, pure ZnO was nanowire-shaped with a $3 0 – 4 0 \ \mathrm { ~ n m }$ diameter (Fig. 2a), while the presence of Fe caused a decrease of particle length and also a modification of morphology, i.e. rectangular shaped nanoparticles (Fig. 2b). Incorporation of $\mathrm { F e } ^ { 3 + }$ ions into the $\bf { Z n O }$ lattice may suppress crystal growth leading to a decrease in particle size.29 We also observed the successful deposition of $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ nanoparticles on the CA membrane (Fig. 2b). Furthermore, the EDX analysis clearly showed the presence of Zn, Fe, and O and their homogeneous distribution on the CA membrane (Fig. S2 and Table S1†).

The ability of different samples of Fe–ZnO (0, 0.07, 0.14, 0.28 and $0 . 7 \ \mathrm { w t \% }$ Fe) to remove FLU was then tested under UV-A irradiation. Generally, the degradation kinetics of organic compounds by reactive species is typically described by a second-order reaction:

$$
\frac { \mathrm { d } [ \mathrm { F l u } ] } { \mathrm { d } t } = \mathbf { \Gamma } - k [ \mathrm { F L U } ] [ \mathbf { R O S } ]
$$

where [ROS] is the steady-state concentration of active species, [FLU] is the concentration of FLU in water, $k$ is the second-order rate constant, and $t$ is the reaction time. By assuming that the concentration of active species was constant, the degradation kinetics of FLU can be described by the pseudo-first-order equation:

$$
[ \mathrm { F L U } ] ( t ) = [ \mathrm { F L U } ] _ { 0 } \mathrm { e x p } ^ { - k _ { \mathrm { a p p } } \cdot t }
$$

where $k _ { \mathrm { a p p } }$ is obtained by the linear regression of $\ln ( C _ { t } / C _ { \bf o } )$ versus time $t$ .

The kinetic rate constant as well as the degradation efficiency increased with increasing Fe content (Fig. 3a). It is worth noting that the initial rate constant calculated over the first stage of the reaction (i.e., 5 h) is very close to the rate constant calculated over the entire reaction time, thereby supporting that the ROS concentration can be assumed constant for the entire duration of the experiment (i.e. confirming the validity of eqn (2)).

$6 5 \%$ FLU removal $( k _ { \mathrm { a p p } } = 0 . 0 4 2 \ \mathrm { h } ^ { - 1 } )$ ) extent was observed in the absence of Fe (i.e., ZnO alone) indicating the activation of the semiconductor by UV-A light. Additional tests showed that removal of FLU by adsorption onto supported solids is negligible. The direct photolysis of FLU under UV-A was less than $8 \%$ in $^ { 2 4 \mathrm { ~ h ~ } }$ $( k _ { \mathrm { a p p } } = 0 . 0 0 4 ~ \mathrm { h } ^ { - 1 }$ , Fig. ${ \bf S } 3 \dagger { \bf \Sigma } $ ). Increasing the Fe content to $0 . 7 \mathrm { \ u t { \% } }$ enhanced the FLU removal up to $8 0 \%$ $( k _ { \mathrm { a p p } } ~ = ~ 0 . 0 6 3 ~ \mathrm { h } ^ { - 1 } )$ after $2 4 ~ \mathrm { \bf ~ h }$ of reaction time. However, increasing the catalyst density from 7.77 to $\mathbf { 1 5 . 5 4 \ g }$ per $\mathbf { m } ^ { 2 }$ CA membrane with a constant Fe content $\left( 0 . 7 ~ \mathrm { \ w t \% } \right)$ ) has no significant effect on the kinetic behavior (Fig. ${ \bf S } 4 \dagger$ ). Since the membrane is expected to be fully covered at $7 . 7 7 \mathrm { ~ g ~ m ~ } ^ { - 2 }$ further increasing the catalyst loading would form multilayerlike aggregates on the CA membrane, and therefore the amount of surface that is subject to irradiation remains unchanged in the recirculation reactor system. The increase in $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ activity under irradiation could be explained by the redox chemistry of iron and the high production of reactive oxygen species. Indeed, Fe acts as a trap for the photogenerated charges, thereby preventing the electron/hole recombination20,30 through one or a combination of two mechanisms: (i) $\mathrm { F e } ^ { 3 + }$ ions can react with the photogenerated electrons and be reduced to $\mathrm { F e } ^ { 2 + }$ which subsequently reacts with the oxygen adsorbed on the semiconductor surface to generate superoxide anion radicals $\bigl ( \mathbf { O } _ { 2 } ^ { \cdot - } \bigr )$ ; (ii) $\mathrm { F e } ^ { 3 + }$ ions could also react with holes, resulting in the formation of high valence iron (e.g. $\mathrm { F e } ^ { 4 + } )$ , which attacks directly the target compounds or combines with the surface hydroxyl groups to produce the ˙OH radicals. The involvement of holes and hydroxyl radicals in the FLU removal was confirmed here using quenching experiments as previously described.16,19,21

A higher Fe content (i.e. ${ > } 0 . 7 \quad \mathrm { w t \% } )$ inhibited the degradation process (data not shown), which can be attributed to an increase in the electron/hole recombination because of modification of the crystallinity and surface properties of the catalysts.20,31

# 3.2. Impact of oxidant addition on single and binary systems

The addition of an oxidant [hydrogen peroxide $\left( \mathbf { H } _ { 2 } \mathbf { O } _ { 2 } \right)$ or persulfate (PS)] to the reactor system allowed faster removal kinetics (Fig. 3b). Kinetic rate constants first increased with increasing $\mathbf { H } _ { 2 } \mathbf { O } _ { 2 }$ concentration and then decreased at a higher oxidant dose. This typical behavior can be explained by the scavenging effect of reactive species by an excess amount of $\mathbf { H } _ { 2 } \mathbf { O } _ { 2 }$ $\left( k _ { \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ; \mathrm { O H } } = 2 . 0 \times 1 0 ^ { 7 } \ \mathrm { M } ^ { - 1 } \ \mathrm { s } ^ { - 1 } \right.$ (ref. 32)). PS showed higher degradation rate constants, which continuously increased with increasing PS concentration $\left( k _ { \mathrm { a p p } } = 0 . 1 8 4 ~ \mathrm { h } ^ { - 1 } \right.$ at $\mathbf { 0 . 5 \ m M }$ PS). This great removal efficiency is probably due to the chemical activation of PS and the generation of sulfate radicals. Formation of the latter species $\left( \mathbf { S 0 } _ { 4 } ^ { \cdot - } \right)$ was confirmed here using iso-propanol $\left( k _ { \mathrm { i - P r O H , \dot { O } H } } \right. =$ $1 . 9 \times 1 0 ^ { 9 } \ \mathbf { M } ^ { - 1 } \ \mathbf { s } ^ { - 1 }$ and $k _ { \mathrm { i - P r O H } , \mathrm { S O } _ { 4 } \cdot \mathrm { ~ - ~ } } = 4 \mathrm { - } 7 . 4 2 \times 1 0 ^ { 7 } ~ \mathrm { M } ^ { - 1 } ~ \mathrm { s } ^ { - 1 } ) ^ { 3 2 , 3 3 }$ and $t$ -butanol $\left( k _ { t \mathrm { - B u O H } , \mathrm { \dot { O } H } } = 6 . 0 \times 1 0 ^ { 8 } \mathrm { \bf ~ M } ^ { - 1 } \ s ^ { - 1 } \right.$ , $k _ { t \mathrm { - B u O H } , \mathrm { S O } _ { 4 } \mathrm { - } } = 4 \mathrm { - }$ $8 . 4 \times 1 0 ^ { 5 } \times 1  &  \mathrm { \bf ~ S } ^ { - 1 } = \mathrm { \bf ~ \underline { { { \sigma } } } } ^ { 3 2 , 3 4 }$ as specific scavengers in the quenching experiments.35–37 Furthermore, the most involved radical species seem to form at the surface of the solid, since the addition of KI (known to react with surface bound radicals)38,39 completely inhibited the FLU removal in the Fe– $\mathbf { Z n O / P S / U V { - A } }$ system (data not shown). Photochemical activation of oxidants without $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ (i.e., $\mathbf { 0 . 5 \ m M }$ PS and $\mathbf { 0 . 2 \ m M \ H _ { 2 } O _ { 2 } }$ ) showed lower kinetic rate constants $( \mathbf { 0 . 0 7 4 \ h } ^ { - 1 }$ and $\mathbf { 0 . 0 0 5 \ h ^ { - 1 } }$ ) (Fig. S3†).

Higher kinetic rate constants were observed for CIP than for FLU (Fig. 4a), probably due to its strong reactivity with sulfate radicals $\left( k _ { \mathrm { C I P , S O _ { 4 } ^ { - } } } ~ = ~ 1 . 2 ~ \times ~ 1 0 ^ { 9 } ~ \mathrm { ~ \bf ~ M ~ } ^ { - 1 } ~ \mathrm { ~ \bf ~ s ~ } ^ { - 1 } \right.$ (ref. 40)). Compounds containing cyclopropane and piperazine rings (e.g. CIP) have shown greater reactivity with radical species because the cleavage of the cyclopropane moiety via the loss of one or two $\mathrm { C H } _ { 2 }$ units and the presence of the piperazine ring containing two amine-N in which the lone pair electrons are conducive to a strong reaction with $\mathrm { { \bf S O _ { 4 } } ^ { \bullet - } }$ .41,42 Compared to the single system, 1.5- and 1.8-fold decreases in the degradation rate constant were observed for CIP and FLU in the mixture system (Fig. 4b), respectively, probably due to the competition effects of compounds towards reactive species.

# 3.3. Effect of water matrices

The removal kinetics of FLU or CIP in different water matrices (UPW, SWW, and RHW) (see Table ${ \bf S } 2 \dagger$ for compositions) were investigated under the optimal experimental conditions (i.e., $\mathbf { 0 . 5 \ m M }$ of PS, $[ \mathrm { F e - Z n O } ] = 7 . 7 7$ g per $\mathbf { m } ^ { 2 }$ membrane). Significant inhibition of FLU degradation in SWW and RHW was observed, while degradation of CIP was reduced only in RHW (Fig. ${ \bf S } 5 \dagger { \bf \Sigma } .$ ). Indeed, less than a 7-fold decrease in the $k _ { \mathrm { a p p } }$ value was observed for FLU (0.184 $\mathbf { h } ^ { - 1 }$ (UPW) to $0 . 0 2 5 \ \mathrm { h } ^ { - 1 }$ and $0 . 0 2 7 ~ \mathrm { h } ^ { - 1 }$ in SWW and RHW, respectively), while less than a 2-fold decrease was observed for CIP (UPW $( 0 . 9 4 3 \ \mathrm { h } ^ { - 1 } )$ ), SWW $( 0 . 9 7 9 \mathrm { ~ h ~ } ^ { - 1 } )$ and RHW (0.456 $\mathbf { h } ^ { - 1 }$ ) (Fig. 5a). Similar degradation behavior was observed for FLU and CIP in the binary system (Fig. S6†) where the $k _ { \mathrm { a p p } }$ values decreased in RHW (Fig. 5b), probably due to competition and/or scavenging effects of wastewater components. To address this issue, the competitive effects of organic and inorganic compounds commonly found in wastewater were tested in the Fe–ZnO/PS/UV-A system. A significant inhibitive effect of organic compounds (i.e., sucrose, acetic acid, citric acid and LHA) was observed, while inorganic species showed a lesser impact on the FLU degradation (Fig. 6). # 3.4. Reusability tests in hospital wastewater

Reusability of the supported catalysts was investigated and compared with that of a conventional photocatalyst (i.e. $\mathrm { T i O } _ { 2 }$ ) under similar experimental conditions in hospital wastewater (Fig. 7). # 4. Conclusion

We have notably demonstrated that the PS/Fe–ZnO/UV-A system can be effectively used for the removal of fluoroquinolone antibiotics in hospital wastewater and in a new recirculation reactor system. Based on the probe and scavenging experiments, sulfate radicals were mainly involved in the heterogeneous oxidation reaction. The higher degradation rate constant of CIP relative to those of FLU could be explained by the high reactivity of $\mathrm { { \bf S O _ { 4 } } ^ { \bullet - } }$ radicals with the cyclopropane ring. Kinetic rate constants were found to be lower in binary systems with respect to those of individual compounds. The most common inorganic anions found in wastewaters can reduce the degradation efficiency, but they have a much less impact compared to the organic compounds. Natural organic matter exhibited strong inhibition effects on the $\mathrm { T i O } _ { 2 }$ activity compared to that on the $\mathbf { F e } { - } \mathbf { Z } \mathbf { n } \mathbf { O }$ activity. The $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ system exhibited better efficiency than $\mathrm { T i O } _ { 2 }$ , especially in hospital wastewater, and can be re-used for several oxidation cycles. In absence of organic matter, $\mathrm { T i O } _ { 2 }$ worked much better than $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ , but when these compounds were present, they exhibited strong inhibition effects on the $\mathrm { T i O } _ { 2 }$ activity compared to that on the $\mathbf { F e } { - } \mathbf { Z } \mathbf { n } \mathbf { O }$ activity. The $\mathbf { F e } { \mathrm { - } } \mathbf { Z } \mathbf { n } \mathbf { O }$ system exhibited better efficiency than $\mathrm { T i O } _ { 2 }$ in hospital wastewater and can be reused for several oxidation cycles. Therefore, we expect that the developed system could be efficiently applied to remove antibiotics from contaminated waters as a suitable alternative to $\mathrm { T i O } _ { 2 }$ in wastewater treatment technologies.
