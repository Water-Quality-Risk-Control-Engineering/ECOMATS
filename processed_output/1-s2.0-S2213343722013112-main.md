# . Introduction

Environmental pollution arising from antibiotics residues is receiving a great deal of attention in recent years. Many antibiotics, such as sulfamethoxazole, tetracycline, ciprofloxacin, and trimethoprim, among others, have been founded in surface and ground waters at variable concentrations [13]. Some of them are toxic, non- or low biodegradable and consequently, persistent. It is thus required to develop new materials and technologies for the degradation of antibiotic residues in the aquatic environment. Sulfamethoxazole (SMx) is a common sulfonamide antibiotic drug used for the treatment of various human and veterinary infections, and as food additive to endorse growth and gains. Due to its widespread use, it has been detected in the outlet stream of water treatment plants (WWTPs) with the subsequent potential danger to ecosystems and human health [1,4,5]. SMX is recalcitrant to conventional processes of the WWTPs [6]. For this reason, the implementation of highly efficient and stable methods for the removal and degradation of this and other antibiotics is mandatory. Among the different treatment options, solar photocatalysis can be considered a suitable, cost-effective, and eco-friendly approach to achieve the SMX degradation. However, this technology has still a large margin for development, especially regarding the degradation of recalcitrant antibiotic contaminants, due to the limited activity of the photocatalysts.

One of the alternatives to enhance the solar photodegradation of refractory pollutants is the combination of the photocatalyst with different oxidant agents, such as hydrogen peroxide, ozone, persulfate, and/or peroxymonosulfate (PMS) [7,8]. Peroxymonosulfate-based advanced oxidation processes (PMS-AOPs) have been considered as an efficient method based on the suitable characteristics of PMS, namely chemical stability, relatively low cost, and suitable transport and storage [9]. PMS possesses a long OO bond $( 1 . 3 2 6 \mathring { \mathrm { A } } )$ and asymmetric structure that demands less energy to be broken. This may facilitate its activation, as well as improve its oxidation efficiency to generate sulfate $( S O _ { 4 } ^ { \bullet - } )$ and hydroxyl (H0°) free radicals [10] through ultrasound, irradiation, heat, electrochemistry, or the action of semiconductors, transition metals, or carbon-based catalysts [1116]. These radicals possess high oxidation capacity $( S O _ { 4 } ^ { \bullet - }$ ; $\mathrm { E } ^ { 0 } = 2 . 5 - 3 . 1 \mathrm { V } _ { \mathrm { N H E } } / \mathrm { H O } ^ { \bullet }$ ; $\mathbf { E } ^ { 0 } = 1 . 8 - 2 . 8 \mathrm { V } _ { \mathrm { N H E } } )$ Sulfate radicals are characterized by a longer half-life $( 3 0 - 4 0 \mu s )$ than hydroxyl ones $( < 1 \ \mu s )$ and they have also probed good oxidation behavior of different antibiotics in a wide pH range of 2.0  8.0 [17].

Activation of PMS with transition metals (e.g., Co, Ni, Fe, Mn) have aroused great interest due to low energy demands, and economical and easy handling operation. Co(II) ions are considered a very effective homogeneous activator of PMS [18]. However, its application suffered from certain shortcomings due to the difficult recovery of the ions, which lead to the creation of secondary pollution. To overcome this problem, cobalt-based heterogeneous photocatalysts have been reported to be efficient and stable for PMS activation. In particular, Cu-Co bimetallic photocatalysts have been synthesized to enhance the water stability. Copper cobaltite $\mathrm { ( C u C o _ { 2 } O _ { 4 } ) }$ , as one of the bimetallic spinel o ousd  n teesin smnducor wit ano bnd $( 1 . 6 \mathrm { - } 1 . 8 \mathrm { e V } )$ and a promising potential for energy, photoelectrical, and catalytic applications. The simultaneous participations of both redox couuples $\mathrm { C o } ^ { \overline { { 3 } } + / } \mathrm { C o } ^ { 2 + }$ and $\mathrm { C u } ^ { 2 + / } \mathrm { C u } ^ { 3 + }$ enhanced the redox reactions in comparison with the single metallic oxide, which can improve the photocatalytic activity. Meanwhile, the high conductivity of $\mathrm { C u C o _ { 2 } O _ { 4 } } ;$ due to the relatively low activation energy of electron transfer between the cations, enhances the electron transfer rate and the charge separation efficiency [19,20]. After years of extensive research, various modification strategies have been developed to improve the photocatalytic activity of promising $\mathrm { C u C o _ { 2 } O _ { 4 } }$ , including doping or combination with other materials (e.g., $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 } / \mathrm { C u C o } _ { 2 } \mathrm { O } _ { 4 }$ [19], $\mathrm { X - C u C o _ { 2 } O _ { 4 } ( X = C r }$ Fe, Mo)/ $\mathrm { C u C o _ { 2 } O _ { 4 } }$ [21,22], $\mathrm { Z n O / C u C o _ { 2 } O _ { 4 } }$ [23], $\mathrm { C u C o _ { 2 } S _ { 4 } / C u C o _ { 2 } O _ { 4 } }$ [24], $g { - } \mathrm { C _ { 3 } N _ { 4 } / C u C o _ { 2 } O _ { 4 } }$ [25] etc.). To date, titanium dioxide $\mathrm { ( T i O _ { 2 } ) }$ still emerged as an attractive candidate for heterogeneous photocatalysis because of exceptional stability, non-toxicity, biologically inertness and high reactivity [2628]. However, the application of $\mathrm { T i O } _ { 2 }$ based photocatalysts is hampered due to its ineffectual use of solar energy and low charge separation [29]. Despite these inherent drawbacks, the semiconductor combination is the main factor to avoid the above limitation for practical application. Very few studies have analyzed the photoactivity of transition metal spinels combined with $\mathrm { T i O } _ { 2 }$ .Coromelci et al. [30] studied the photodegradation of a dye with $\mathrm { T i O _ { 2 } / Z n F e _ { 2 } O _ { 4 } }$ heterostructures prepared by ultrasound template-assisted sol-gel method. Ahmadpour et al. [31] concluded that $\mathrm { T i O _ { 2 } @ Z n F e _ { 2 } O _ { 4 } / P d }$ nanocomposite significantly improved the photodegradation of diclofenac under direct solar irradiation. Magdalane et al. [32] prepared $\mathrm { T i O } _ { 2 }$ doped ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ nanostructures to improve the photocatalytic degradation of Congo Red dye under visible light. Xu et al. [33] prepared $\mathrm { C u C o _ { 2 } O _ { 4 } / T i O _ { 2 } }$ for $\mathrm { H } _ { 2 }$ production and demonstrated that the efficient separation of charge carriers due to the p-n junction adopting the interfacial $\scriptstyle \mathrm { T i - O - C u / C o }$ bonds is crucial for the improved performance and photostability. These modifications may effectively decrease the band gap energy and expand light absorption range of $\mathrm { T i O } _ { 2 } ,$ as well as alter the band structure and improve the separation of charge carriers [33].

In this research, a simple hydrothermal-calcination method was used to synthesize $\mathrm { C u C o _ { 2 } O _ { 4 } }$ spinels with incorporated $\mathrm { T i O } _ { 2 }$ particles at different mass ratios. The purpose of this work is to demonstrate the outstanding effect of the coexistence of $\mathrm { C u C o _ { 2 } O _ { 4 } }$ and $\mathrm { T i O } _ { 2 }$ particles and explore the pathways for the activation of PMS to degrade SMx. The antibiotic degradation was found to increase with increasing $\mathrm { T i O } _ { 2 }$ loading in the composite, achieving a total degradation of SMX after $1 8 0 ~ \mathrm { m i n }$ under simulated solar light irradiation. This is the first study analyzing the photocatalytic behavior of $\mathrm { C u C o _ { 2 } O _ { 4 } / T i O _ { 2 } }$ heterostructures with peroxymonosulfate.

The photocatalytic activities of the different materials were tested in the degradation of SMX solutions (initial concentration, $5 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 } )$ under solar radiation in a Suntest ${ \bf X } { \bf L } { \bf S } + { \bf \Delta }$ simulator (ATLAS®) equipped with a Xenon lamp emitting $6 0 0 \mathrm { W } \mathrm { m } ^ { - 2 }$ and a light correction filter $\lambda \le 2 9 0 \mathrm { n m }$ . # 3.2. SMX degradation tests

The TO-X-CCO heterostructures were tested for the SMX degradation with PMS under simulated solar light, after observing that SMX adsorption before adding PMS was negligible in all cases. Fig. 5A represents the SMX evolution with irradiation time in the presence of PMS. $\mathrm { C u C o _ { 2 } O _ { 4 } }$ exhibited a very fast initial degradation of sMx that, regrettably, stops after the first reaction minutes. After $^ { 6 \mathrm { h } }$ of irradiation, about $8 0 \%$ of SMX degradation is observed. Photolysis/PMS system can degrade SMX, reaching $6 0 \%$ of pollutant removal after $^ { 6 \mathrm { h } }$ It seems that a high number of radicals $_ \mathrm { H O } \cdot$ and $S O _ { 4 } ^ { \bullet - } .$ ) are generated from PMS under light irradiation [50] at the beginning of the reaction, as indicates the very fast SMX removal in the first reaction minutes. However, it is most likely that this high number of radicals results also in a fast recombination into non-active species, which justifies the low activity observed for the rest of the reaction. The best results were obtained with the $\mathrm { T i O } _ { 2 } @ \mathrm { C u C o } _ { 2 } \mathrm { O } _ { 4 }$ heterostructures that accelerated the SMx degradation and achieved complete SMX degradation after $^ { 6 \mathrm { { h } } }$ . Considering the above results and the band edge positions of $\mathrm { T i O } _ { 2 }$ and $\mathrm { C u C o _ { 2 } O _ { 4 } }$ previously calculated, a schematic degradation diagram related to the formation of $\mathbf { n } { \cdot } \mathbf { n }$ heterojunction between $\mathrm { T i O } _ { 2 }$ and $\mathrm { C u C o _ { 2 } O _ { 4 } }$ is proposed in Fig. 1. It is shown the energy of the band gap, the edges of the valence and conduction bands of both $\mathrm { T i O } _ { 2 }$ and $\mathrm { C u C o _ { 2 } O _ { 4 } }$ before contact. Due to n-type characteristics of $\mathrm { T i O } _ { 2 }$ and $\mathrm { C u C o _ { 2 } O _ { 4 } }$ semiconductors, their Fermi levels $\left( \mathrm { E _ { F } } \right)$ are located close to the conduction band (CB) [67]. Furthermore, the Fermi level of $\mathrm { T i O } _ { 2 }$ is more negative than that of $\mathrm { C u C o _ { 2 } O _ { 4 } }$ .Consequently, after contact of these semiconductors and form an n—n heterojunction, electrons migrate from $\mathrm { T i O } _ { 2 }$ to $\mathrm { C u C o _ { 2 } O _ { 4 } }$ until their Fermi levels equalize. This results in a depletion layer (positive region) on $\mathrm { T i O } _ { 2 }$ side and an accumulation layer (negatively charged region) on $\mathrm { C u C o _ { 2 } O _ { 4 } }$ side. When the process reaches an equilibrium state (equalized Fermi level), a built-in electric field is established in the junction area with the field direction from $\mathrm { T i O } _ { 2 }$ to $\mathrm { C u C o _ { 2 } O _ { 4 } }$ (red arrow in Fig. 13) [68]. On the other hand, band gap of $\mathrm { C u C o _ { 2 } O _ { 4 } }$ is narrower than that of $\mathrm { T i O } _ { 2 }$ .Thus, under simulated solar light, electron-hole pairs are preferably produced in $\mathrm { C u C o _ { 2 } O _ { 4 } }$ rather than in $\mathrm { T i O } _ { 2 }$ .The built-in field promotes the separation of photogenerated carriers in $\mathrm { C u C o _ { 2 } O _ { 4 } }$ and facilitates the electrons flowing towards the CB of $\mathrm { T i O } _ { 2 }$ , meanwhile the photogenerated holes are effectively collected in the VB of $\mathrm { C u C o _ { 2 } O _ { 4 } }$ . In such a way, the photogenerated charge carriers are effectively separated, electronhole recombination is reduced, which can result in the observed enhanced photoactivity under solar irradiation. Based in the band alignment and taking into account the role of the different species suggested by the quenching tests, a reaction mechanism for the SMx degradation in $\mathrm { T i O _ { 2 } / C u C o _ { 2 } O _ { 4 } }$ PMS system is proposed (Fig. 13). PMS in the water solution can decompose homogeneously under irradiation into $S O _ { 4 } ^ { \bullet - }$ and $_ \mathrm { H O ^ { \bullet } }$ radicals (Eq. 4) [69,70]. PMS activation reaction also happens by a single electron transfer process in the presence of metal oxide couple, Cu (II) and Co(III) sites (Eq. 5) [71]. Simultaneously, solar light was absorbed by $\mathrm { C u C o _ { 2 } O _ { 4 } }$ which is able to generate charge pairs $( \mathrm { e } ^ { - } / \mathrm { h } ^ { + } )$ (Eq. 6). The excited electrons are transformed to the $\mathrm { T i O } _ { 2 }$ conduction band where they react with dissolved $\mathrm { O } _ { 2 }$ to generate $\mathrm { O } _ { 2 } ^ { \bullet - }$ radicals (Eq.

7), which according to the quenching tests are involved in the reaction [50,51]. Electron transfer between the metal pairs through redox reaction (Eq. 8) could regenerate the metal reaction sites of the spinel. Finally, the different generated radicals could oxidize SMX into the reaction byproducts (Eq. 9).

# 4. Conclusions

$\mathrm { T i O } _ { 2 ^ { - } } \mathrm { C u C o } _ { 2 } \mathrm { O } _ { 4 }$ heterostructures were synthesized through simple hydrothermal and calcination method with different ratios of $\mathrm { T i O } _ { 2 }$ The synthesized materials have been tested in the solar photocatalytic degradation of SMX enhanced by PMS activation. The method achieves excellent interface contact and strong interaction between $\mathrm { C u C o _ { 2 } O _ { 4 } }$ and $\mathrm { T i O } _ { 2 }$ , thus promoting absorption of visible light and enhancing separation and migration of photogenerated electron-hole pairs. Specifically, the heterostructures show the lowest charge transfer resistance, and consequently the best charge mobility. This results in more photoinduced carriers that can participate in redox reactions per unit time, thereby enhancing photocatalytic activity. We proposed the formation of a $\mathbf { n - n }$ heterojunction, being $_ \mathrm { H O } \cdot$ , $S O _ { 4 } ^ { \bullet - }$ and $0 \mathbf { \overline { { 2 } } } ^ { - }$ the main reactive species involved in the PMS assisted SMX degradation. The results of this study confirm the promising behavior of the $\mathrm { T i O _ { 2 } / C u C o _ { 2 } O _ { 4 } / P M \Omega }$ system in the SMX degradation.
