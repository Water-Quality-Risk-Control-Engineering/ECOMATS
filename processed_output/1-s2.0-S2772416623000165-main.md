Electro-reduction of $\mathrm { O } _ { 2 }$ to generate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ plays an important role in electro-Fenton (EF). In general, more catalytic active sites exposure and oxygen adsorption can shorten diffusion paths for the heterogeneous catalysis of $\mathbf { O } _ { 2 }$ . In this work, the ${ \mathrm { Z n O } }$ modified Boron $Z \mathbf { n O } .$ -Boron) was prepared through a high-temperature annealing method. This special combination promotes $\mathrm { F e ^ { 2 + } }$ recycling for the EF reaction and supplies rich active sites, which are beneficial to generate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Compared with pristine Boron, ZnO-Boron exhibited superior $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production performance and sulfamethazine (SM) degradation efficiency $1 0 0 \%$ within $3 0 \mathrm { { m i n } } \dot { }$ ). Moreover, ·OH and $^ 1 0 _ { 2 }$ act synergistically during the SM oxidation process in the EF system over ZnO-Boron. After five cycles, ZnO-Boron maintained the preeminent degradation efficiency of SM, indicating good structural stability and catalytic durability. This discovery provides new ideas for modifying a boron-based electrocatalyst practicable for outstanding pollutant degradation efficiency in the EF system.

# 1. Introduction

Sulfonamide antibiotics are used heavily and frequently, endangering the aquatic ecological balance because of their high genotoxicity, bioaccumulation ability, strong cytotoxicity, and carcinogenicity (Danner et al., 2019; Baran et al., 2006). As an emerging advanced oxidation technology, electro-Fenton (EF) is widely used for the selective treatment of organic pollutants due to its green and efficient features (Ye et al., 2019; Zhang et al., 2018). In the EF process, hydrogen peroxide $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 } )$ can be in-situ generated at the cathode via oxygen $\left( \mathbf { O } _ { 2 } \right)$ reduction reaction and can be further activated by externally added ferrous ions $( \mathrm { F e } ^ { 2 + } )$ to form highly strong oxidant hydroxyl radicals (·OH). The advantage of EF over conventional Fenton technology is that the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ produced by the cathode avoids the potential risks associated with its transport, storage and handling. In addition, the cathode enables a continuous conversion of $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e ^ { 2 + } }$ , which further ensures a continuous supply of active radicals. Hence, the efficiency of the EF system in degrading pollutants depends on the choice of electrode materials (Sopaj et al., 2016).

Many promising electrocatalysts were explored to improve the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production efficiency, such as noble metals, metal alloys and carbon materials (Pizzutilo et al., 2017; Young et al., 2019; Jung et al., 2020).

Although various precious metals and metal alloys exhibit excellent oxygen reduction reaction (ORR) properties, the earth’s abundance limits their large-scale application. Recently, carbon nanomaterials have received extensive attention due to their excellent thermal, mechanical and electronic properties (Tang et al., 2015; Kim et al., 2018). However, the catalytic activity of carbon materials decreases severely after several times of usage (Duan et al., 2019). Besides, sophisticated methods were frequently used to break the stable carbon framework to improve the electrocatalytic performance of pristine carbon electrodes (Zhou et al., 2014)[12]. Therefore, to promote the development of low energy-consuming EF technology, the exploration of non-metallic materials with simple preparation and high catalytic activity needs to be continuous. Boron owns a similar atomic cluster scale to carbon (Mannix et al., 2015). The unique electronic structure of boron enables it not only to be used as an electron donor but also to provide reduction sites for other substances through strong chemical coupling, facilitating the construction of catalysts with excellent performance (Yang et al., 2019; Yuan et al., 2017).

The prepared boron-doped carbon nanospheres can effectively activate the $\mathrm { N } { \equiv } \mathrm { N }$ triple bond and suppress the hydrogen evolution reaction, exhibiting excellent electrochemical performance (Li et al., 2021). In addition, boron also enhances the activity of photocatalysts by optimizing the band structure, light absorption range, and charge mobility (Patnaik et al., 2021). Therefore, the degradation efficiency of sulfamethazine by boron-modified graphitic carbon nitride is significantly improved under simulated sunlight (Xu et al., 2021). Boron can not only act as an electron donor to improve the catalytic activity of substrate materials but also exhibits unique catalytic properties due to the abundant active sites. In situ generation of $\mathrm { H } _ { 2 }$ as a proton source and electron donor for $\mathrm { C O } _ { 2 }$ reduction by inducing local hydrolysis of boron under light irradiation (Liu et al., 2013). In addition, the strong interaction between peroxymonosulfate and the boron surface is conducive to electron transfer, which benefits the efficient degradation of bisphenol S (Shao et al., 2017). The boron suboxide and B-B bonds of boron can also act as active sites for donating electrons, promoting the rapid reduction of $\mathrm { F e } ^ { 3 + }$ to $\mathrm { F e ^ { 2 + } }$ during the Fenton process (Zhou et al., 2020c). Therefore, it can be inferred that metal-free boron has catalytic properties for the construction of efficient and sustainable electrocatalytic systems.

Compared with single materials, composite materials can combine the advantages of each component, thus improving the catalytic performance (Hasanpoor et al., 2017). It has been confirmed that doping modification can further improve the electrocatalytic performance of cathode materials to generate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . Doping modification of the substrate materials can create more active sites and accelerate electron transport, thereby enhancing electrocatalytic activity (Liu et al., 2015; Jin et al., 2015). Transition metal oxides are widely used as dopants, ZnO has received extensive attention due to its good stability, high mechanical properties, and excellent electron transport properties (Cao et al., 2018; Khataee and Zarei, 2011). The synergistic effect between $\mathrm { z n O }$ and reduced graphene oxide nanosheets can enhance electron transport, improve electrical conductivity, and show high cathodic current density and positive onset potential in alkaline media (Yu et al., 2018). In addition, ZnO can also improve the surface adsorption properties of CuO films, thereby promoting the diffusion of ${ \bf O } _ { 2 }$ . Active sites can also be increased to further improve the electron transfer efficiency (Zhou et al., 2020a).

To further improve the electrocatalytic activity of bulk A-Boron, ZnO modified boron-based catalyst (ZnO-Boron) was prepared by a facile high-temperature annealing method. Firstly, a series of characterizations were conducted to reveal the modifying effect of $\mathrm { z n O }$ incorporation on the physical/chemical properties and electrochemical characteristics of the final presented ZnO-Boron. Secondly, the optimal conditions for electrocatalytic hydrogen peroxide production were searched by controlling the condition variables during the reaction. Finally, through several experimental explorations, an excellent electric Fenton system for SM was realized. The rough reaction mechanism was speculated to provide more theoretical ideas for the effective degradation of SM.

# 2. Experimental section

# 2.1. Chemicals and materials

Sodium sulfate $\mathrm { ( N a _ { 2 } S O _ { 4 } }$ , $9 9 \%$ ), Ferrous sulfate heptahydrate $\mathrm { ( F e S O _ { 4 } { \cdot } 7 H _ { 2 } O }$ , $9 9 \%$ ), Boron oxide $( \mathtt { B } _ { 2 } \mathsf { O } _ { 3 }$ , $9 9 \%$ ), Amorphous boron (Boron, $9 9 \%$ ), Zinc nitrate hexahydrate $( \mathrm { Z n } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ , $9 9 \%$ ), Potassium titanium oxide oxalate dihydrate $( \mathrm { C } _ { 4 } \mathrm { K } _ { 2 } 0 _ { 9 } \mathrm { T i } { \cdot } 2 \mathrm { H } _ { 2 } 0 _ { \perp }$ , $9 9 \%$ , and Sulfamethazine (SM, $2 9 9 \%$ ) were purchased from Sigma-Aldrich.

# 2.2. Preparation of ZnO and ZnO-Boron

The pristine ZnO was synthesized with a one-step thermal polymerization method. The crucible containing $_ { 4 } \mathrm { \Delta } _ { g }$ of $\mathrm { Z n ( N O _ { 3 } ) _ { 2 } { \cdot } 6 H _ { 2 } O }$ was put into a muffle furnace. Then, the muffle furnace was heated to $7 0 0 ~ ^ { \circ } \mathrm { C }$ with a heating rate of $5 \ ^ { \circ } \mathrm { C } \ \mathrm { m i n } ^ { - 1 }$ and maintained for $^ { 2 \mathrm { ~ h ~ } }$ . After cooling to room temperature, the powder was marked as $\mathrm { z n O }$ and collected for further use.

$_ { 0 . 5 ~ g }$ boron powder and $0 . 0 6 8 6 \ g$ zinc nitrate nonahydrate were added to $2 0 ~ \mathrm { m L }$ of ultrapure water, heated in a water bath and stirred continuously until the water evaporated to dryness. The temperature was controlled from $2 5 ~ ^ { \circ } \mathrm { C }$ to $7 0 0 ~ ^ { \circ } \mathrm { C }$ with a heating rate of $5 \ \mathrm { ^ { \circ } C \ m i n ^ { - 1 } }$ , and then maintained for $^ { 2 \mathrm { ~ h ~ } }$ , and the final drop to room temperature. The obtained catalyst was washed with ultrapure water and ethanol several times and then dried to obtain ZnO-Boron.

# 2.3. Electrochemical characterization

The crystal structure of boron-based materials was explored by the Xray powder diffraction (XRD) equipped with $\operatorname { C u K } \alpha$ radiation (Bruker D8 Advance, Germany) and $_ { 2 \theta }$ from ${ { 1 0 } ^ { \circ } }$ to $8 0 ^ { \circ }$ High-resolution transmission electron microscopy (HRTEM) experiments were performed on JEOL JEM-2100 equipment. Experimental X-ray photoelectron spectroscopy (XPS) patterns were collected by an ESCALAB 250Xi (Thermo Scientific, America) to explore the surface element compositions. The surface structure of the catalyst was analyzed by an IQ-AG-MP instrument (Quanta, America). The $\mathrm { O } _ { 2 }$ -temperature programmed desorption $( \mathbf { O } _ { 2 } \cdot$ - TPD) measurement was carried out on a Quanta chrome Autosorb-iQ-C analyzer (America) with temperatures ranging from $2 5 ~ ^ { \circ } \mathrm { C }$ to $8 0 0 ~ ^ { \circ } \mathrm { C } .$ The Electron paramagnetic resonance (EPR) was measured to detect the electronic states (Bruker A300, Germany).

# 2.4. Electrochemical characterization

# 2.4.1. Electrochemical oxygen reduction to generate $H _ { 2 } O _ { 2 }$

All the electrochemical experiments were carried out in a threeelectrode system with $\mathbf { A g / A g C l }$ and Platinum plate as a reference electrode and a counter electrode, respectively. The as-prepared sample was used to produce a working electrode. Briefly, the working cathode was prepared as following steps: $4 0 ~ \mathrm { m g }$ catalyst, $1 0 \ \mathrm { m g }$ acetylene black, $1 0 \ \mathrm { m g }$ Polyvinylidene Fluoride and $^ { 1 \ m L }$ DMA solution were mixed by sonification, and then the mixture was sonicated for $6 0 \ \mathrm { m i n }$ . Subsequently, the catalyst suspension $\left( 0 . 3 \mathrm { m L } \right)$ was spin-coated on a $4 \mathrm { c m } ^ { 2 }$ commercial carbon paper and then dried at $8 0 ~ ^ { \circ } \mathrm { C } .$ . The concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was tested by a titanium potassium oxalate method (KasprzykHordern et al., 2003). Electrochemical impedance spectroscopy (EIS) measurements were performed with a sinusoidal ac perturbation of $1 0 ~ \mathrm { m V }$ applied over the frequency range of $0 . 0 1 { - } 1 0 ^ { 5 } ~ \mathrm { H z }$ to determine the catalysts’ conductivity.

# 2.4.2. Organic pollutants degraded by EF

The $2 0 \mathrm { \ m g \ L ^ { - 1 } }$ organic pollutant containing 0.05 M $\mathrm { N a } _ { 2 } S { \mathrm { O } } _ { 4 }$ as the electrolyte was performed to conduct the EF experiments under $- 0 . 6 \mathrm { V }$ at $\mathrm { \tt p H } = 3$ , $\mathrm { F e } ^ { 2 + } = 1 \mathrm { m M }$ conditions, and $\mathrm { O } _ { 2 }$ was continuously introduced throughout the degradation process. The concentration of SM was detected by a high-performance liquid chrome (Waters e2695) equipped with an Athena C18-WP column $( 4 . 6 \times 2 5 0 \ : \mathrm { m m }$ , $5 \mu \mathrm { m } )$ and a PDA detector set at $2 7 0 \mathrm { n m }$ for SM. The mobile phase was a mixture of acetonitrile and ultrapure water (30:70).

# 3. Results and discussion

# 3.1. Chemical structure and properties

The $\mathrm { Z n ~ 2 p }$ XPS spectrum of pristine ZnO exhibited significant peaks in $1 0 2 1 . 3 \ \mathrm { e V }$ and $1 0 4 4 . 5 \ \mathrm { e V }$ , which correspond with $\mathtt { Z n 2 p } _ { 3 / 2 }$ and Zn $\mathsf { 2 p } _ { 1 / 2 }$ , respectively, with a spin-orbit split of $2 3 . 2 \ \mathrm { e V }$ (Fig. S1). The positions of characteristic peaks are consistent with that reported for $\mathrm { z n O }$ Alshammari et al., 2015; Park et al., 2010). Moreover, the $\mathtt { Z n 2 p }$ XPS spectrum of ZnO-Boron exhibited significant peaks in $1 0 2 2 . 6 \ \mathrm { e V }$ and $1 0 4 5 . 8 \ \mathrm { e V }$ , which corresponded with $\mathrm { Z n ~ 2 p _ { 3 / 2 } }$ and Zn $2 \mathsf { p } _ { 1 / 2 }$ , respectively, with a spin-orbit split of $2 3 . 2 \mathrm { e V }$ (Fig. 1a). The apparent chemical shift of the characteristic peak of the zinc ion toward the higher binding energies indicates a decrease in the surrounding electron density and loss of electrons, which may results from bonding with boron. The appearance of $\mathrm { Z n }$ characteristic pattern indicates the successful modification of Boron by $\mathrm { z n O }$ . Besides, as shown in Fig. 1b, the B 1 s XPS spectrum peaks of A-Boron and ZnO-Boron can be fitted to three peaks at 187.4, 188.7 and $1 9 2 . 5 \ \mathrm { e V }$ , which are assigned to B-B, boron suboxide and ${ \bf B } _ { 2 } { \bf O } _ { 3 }$ , respectively (Fan et al., 2019; Ong et al., 2004). The relative contents of $\mathtt { B _ { x } O }$ and $\mathbf { B } _ { 2 } \mathbf { O } _ { 3 }$ in ZnO-Boron were increased compared with that in Boron. Among these, the values of $\mathtt { B _ { x } O }$ and $\mathbf { B _ { 2 } O _ { 3 } }$ have elevated from $3 0 . 3 \%$ to $3 2 . 7 \%$ and $2 0 . 7 \%$ to $2 6 . 6 \%$ , respectively. The phenomenon can be presumed with two explanations: ((1) the partial oxidation of the A-Boron surface occurred during the high-temperature annealing process; (2) the oxygen atom in $\mathrm { z n O }$ interacted electronically with the B atom in Boron to form $\mathtt { B _ { x } O }$ . In addition, XRD characterization was used to further observe the crystal structure of the ZnO-Boron and Boron (Fig. 1c). The result revealed that the final ZnO-Boron obtained by $\mathrm { Z n O }$ modification exhibited similar XRD spectra as Boron, both displaying the characteristic broad bulge peak structure of amorphous Boron. The XRD pattern of $\mathrm { z n O }$ powder was shown in Fig. S2. The presence of different peaks such as (100), (002), (101), (102), (110), (103), and (112) confirm the hexagonal wurtzite structure of $\mathrm { z n O }$ powder (Kahouli et al., 2015). In the XRD spectra of ${ \mathrm { z n O } }$ -Boron, the characteristic peaks of ZnO didn’t appear. On the one hand, the dosage of the precursor of $Z n ^ { 2 + }$ was less, and on the other hand, the degree of uniformity of $\mathrm { Z n O }$ modification of Boron was high.

The morphology and lattice structure of the catalyst can be displayed by HRTEM. Compared to the regular disks appearance of pristine Boron (Fig. 2a), ZnO-Boron exhibited the morphological feature of smallersized fragments (Fig. 2b). By analyzing the crystal plane information of the small fragments, ZnO was successfully connected to Boron. According to the standard diffraction patterns of A-Boron (JCPDS-80-0324) and ZnO (JCPDS-77-0191) to identify the crystalline phase compositions. As shown in Fig. 2c, the lattice spacing of $0 . 4 5 0 ~ \mathrm { n m }$ corresponds to the (113) plane of A-Boron. Moreover, the lattice spacings of $0 . 3 6 9 \mathrm { n m }$ and $0 . 2 2 4 ~ \mathrm { { n m } }$ correspond to the (024) plane of A-Boron and (200) plane of $\mathrm { Z n O }$ -Boron, respectively (Fig. 2d). Based on these structural property results, we concluded that ZnO not only modified Boron uniformly but also the two components securely connected by B-O bonds. To explore the regulation of ZnO modification on the Boron surface and interface structure, a series of characterizations were carried out.

The surface pore structure information of the catalysts was analyzed by $\Nu _ { 2 }$ adsorption-desorption. As shown in Fig. 3a, the catalyst presented a type IV isotherm with a hysteresis loop between $\mathrm { P } / \mathrm { P } _ { 0 }$ of $0 . 4 \sim 1 . 0 $ , indicating the presence of mesopores in the catalyst (Sing, 1984). To further determine the composition of the pores, the pore size distribution of the catalysts was revealed (Fig. 3b). It can be found that the pore sizes of Boron and ZnO-Boron were widely distributed in $4 { \sim } 3 0 ~ \mathrm { n m }$ , which further proves the mesoporous structures of the catalyst. In addition, the dV/dD value of ${ \mathrm { z n O } }$ -Boron was larger than that of Boron, indicating the doping of $\mathrm { z n O }$ destroyed the layered Boron and increased the mesoporous structures. It can be calculated that the specific surface area of the Boron was $1 . 7 6 7 \ : \mathrm { m } ^ { 2 } \ : \mathrm { g } ^ { - 1 }$ . After doping with ZnO, its specific surface area increased to $3 . 4 3 0 ~ \mathrm { m } ^ { 2 } ~ \mathrm { g } ^ { - 1 }$ . The improvements of specific surface area and mesoporous structures are beneficial to the sufficient exposure of active sites and the capture of oxygen, respectively.

The exposure of the active sites is a key indicator to affect the electrocatalytic activity of electrocatalysts. By testing the cyclic voltammetry of Boron and ${ \mathrm { Z n O } } .$ -Boron, we determined the scan voltage to be 0.639 V (Fig. S3). As shown in Fig. 3c, the double-layer capacitance of Boron and ZnO-Boron were 1.09 and $1 . 8 3 \ \mu \mathrm { F } { \cdot } \mathrm { c m } ^ { - 2 }$ , respectively, indicating that ZnO-Boron exhibited more active sites during the electrocatalysis than ZnO, which mainly benefits from the relatively higher specific surface area and more mesoporous structures.

In addition to the active sites, conductivity also plays an important role in the electrocatalytic process. As shown in Fig. 4a, the smaller semicircle radiu evidenced the smaller internal resistance in ${ \mathrm { Z n O } }$ -Boron than that in Boron. It shows that the increase of active sites accelerates the charge transfer, thereby reducing the internal resistance and increasing the electrical conductivity. This is consistent with the observation from the LSV test of the catalysts (Fig. 4b). The onset potential of ZnO-Boron was shifted to a positive direction compared with that of Boron, indicating that the overpotential required for ZnO-Boron is smaller, which is favourable for the oxygen reduction reaction. In addition, the halfwave potential and limiting current density of ZnO-Boron are significantly increased, indicating that ${ \mathrm { Z n O } } .$ -Boron has faster reaction kinetics (Luo et al., 2019).

$\mathrm { O } _ { 2 } { \cdot } \mathrm { T P D }$ is used to determine the oxygen adsorption performance of the catalysts, and the enhanced $\mathrm { O } _ { 2 }$ adsorption capacity could facilitate the multi-electron reduction of $\mathrm { O } _ { 2 }$ (Sheng et al., 2013; Liu et al., 2014). The oxygen desorption states at low temperatures $( < 4 0 0 ~ ^ { \circ } \mathrm { C } )$ and high temperatures $\left( > 4 0 0 ~ ^ { \circ } \mathrm { C } \right)$ are attributed to physically and chemically adsorbed oxygen $( \mathrm { O } _ { \mathrm { a d s } } )$ capacity, respectively (Si et al., 2015). As shown in Fig. 4c, ZnO-Boron exhibited a wider peak range and higher peak intensity compared with Boron, indicating that the $\mathrm { O } _ { 2 }$ adsorption efficiency of ${ \mathrm { Z n O } } .$ -Boron was improved. This result benefits from the large specific surface area and abundant mesoporous structure produced by doped $\mathrm { Z n O }$ , which increases catalytically active sites and facilitates the diffusion of electrolytes (Zhao et al., 2019).

# 3.2. Catalytic generation performance of $H _ { 2 } O _ { 2 }$

The Boron and ZnO-Boron were arranged as the working electrodes for electrocatalytic hydrogen production experiments. The performance comparison of the catalysts was carried out under the conditions of $- 0 . 6 \mathrm { ~ V ~ }$ and $\mathtt { p H } = 3$ . The pristine ZnO does not equip the electrocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production performance (Fig. S4). The $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation over ZnO-Boron is $5 8 ~ \mathrm { m g ~ L ^ { - 1 } }$ , while that over Boron was $3 5 ~ \mathrm { m g ~ L ^ { - 1 } }$ within $6 0 \ \mathrm { m i n }$ (Fig. 5a). Furthermore, the formation rate follows oneorder kinetics, indicating that the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ decomposition process hardly occurred and had no effect on the formation reaction. The formation rate constant $( \mathbf { k } )$ of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation over ${ \mathrm { Z n O } } .$ -Boron is $0 . 9 3 3 \mathrm { m g } \mathrm { L } ^ { - 1 } \mathrm { m i n } ^ { - 1 }$ , which is 1.5 times that over $\mathrm { Z n O }$ $\left[ 0 . 6 3 9 \mathrm { \ m g \ L ^ { - 1 } \ m i n ^ { - 1 } } \right]$ ) (Fig. S5a and 1b). The result shows that ${ \mathrm { Z n O } } .$ -Boron exhibits excellent electrocatalytic performance as expected, which s benefited from the following points: the doping of $\mathrm { z n O }$ destroyed the original lamellar structure of Boron, raised the specific surface area and mesoporous structure, and then increased the number of catalytic activity centres; $\mathrm { z n O }$ as a co-catalyst was conducive to the efficient transfer of electrons and improved the conductivity.

Subsequently, a series of experiments were carried out to explore the effect of reaction conditions (voltage and pH) on the electrocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production process over ZnO-Boron. As shown in Fig. 5b, the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production efficiency exhibited a maximum value $( 5 8 \mathrm { m g L ^ { - 1 } } .$ ) at $\mathtt { p H } = 3$ , compared with other electrolyte conditions $\mathrm { \tt D H } = 5$ , 7). This is because the oxygen solubility and current efficiency decrease with the increase of electrolyte $\mathsf { p H }$ value, which leads to a decrease in the generation efficiency of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the electro-Fenton system (He and Zhou, 2017). On the side, we further investigated the effect of voltage on the formation efficiency of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ over the $\mathrm { z n O }$ -Boron. As shown in Fig. 5c, When the voltage was increased from $^ { - 0 . 4 }$ to $- 0 . 6 \mathrm { \ V }$ , the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generation concentration was increased from 35 to $5 8 \mathrm { m g L ^ { - 1 } }$ . However, when the voltage was increased to $- 0 . 8 \mathrm { V }$ , the amount of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ generated was only $5 9 ~ \mathrm { m g ~ L ^ { - 1 } }$ . The phenomenon was attributed to the reaction of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ with ·OH to generate hydroperoxyl radicals $\left( \mathrm { H O } _ { 2 } \right)$ (Zhou et al., 2020b). The excellent electrocatalytic $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production ability of the catalyst is closely related to the efficiency of the subsequent Fenton degradation of organic pollutants.

# 3.3. Degradation performance of SM by EF system

Taking SM as a representative of organic simulated pollutants, we study the performance of catalysts that electro-Fenton degradation of SM. As shown in Fig. 6a, before the reaction, the adsorption of SM on Boron and ZnO-Boron was carried out. The catalysts had achieved adsorption equilibrium for SM at $6 0 \ \mathrm { m i n }$ . In the absence of $\mathrm { F e ^ { 2 + } }$ dosing, the degradation efficiencies of SM over $\mathrm { Z n O }$ -Boron and A-Boron were $4 2 \%$ and $3 0 \%$ , respectively. After adding $1 \ \mathrm { m M \ F e { ^ { 2 + } } }$ , the degradation performance was improved, indicating that a large amount of ·OH was generated, which improved the degradation efficiency. The prepared ZnO-modified Boron can completely degrade $2 0 \ : \mathrm { p p m } \ : S \mathrm { M }$ within $3 0 \mathrm { { m i n } }$ , while bulk Boron required $6 0 \ \mathrm { m i n }$ . Compared with the published catalysts of the same type, ZnO-Boron exhibited superior performance in EF degradation of organic pollutants (Table S1).

Furthermore, the effect of the applied voltage on SM degradation kinetics with the electron-Fenton system over ZnO-Boron was examined (Fig. 6b). Enhanced SM degradation kinetics was observed as the voltage increased from $^ { - 0 . 4 }$ to $- 0 . 6 \mathrm { ~ V ~ }$ . As more $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was produced as the applied voltage increased, and in turn, more ·OH was generated for SM degradation reaction. However, a further increase in the voltage to $- 0 . 8 \mathrm { ~ V ~ }$ yielded less efficient SM degradation, which is the same as the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production process (Chen et al., 2019). The SM degradation performance was then investigated with solution pH as variate, for which the highest SM degradation efficiency was recorded at $\mathtt { p H } = 3$ (Fig. 6c). Under acidic conditions, it is beneficial to promote the two-electron reduction reaction of oxygen to generate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (Bokare and Choi, 2014). Moreover, the chloride $( \mathbf { C l } ^ { - } )$ and nitrate ions $\left( \mathrm { N O } _ { 3 } ^ { - } \right)$ act as representatives of common anions in wastewater, and humic acid (HA) act as a representative of large organic substances that are widely found in nature to conduct ion coexistence experiments. The results present that the presence of common anions does not have much influence on the EF degradation process of $\mathrm { z n O }$ -Boron (Fig. S6a and Fig. S6b). When HA was present, the degradation effect decreased significantly, probably because the process of competitive degradation between SM and HA occurred (Fig. S6c).

# 3.3. Reaction mechanism of EF system

As shown in Fig. 7, under the excitation of the electron, charge carriers were generated on the surface of $\mathrm { z n O }$ -Boron. In the electrochemical production of the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ process, oxygen was enriched on the surface of ZnO-Boron. The reduction of ${ \bf O } _ { 2 }$ to $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in acid conditions proceeds via the following steps:

$$
\mathrm { O } _ { 2 } + \mathrm { H } ^ { + } + \mathrm { e } ^ { - }  \cdot \mathrm { O O H }

In the subsequent EF process, $\mathrm { F e ^ { 2 + } }$ reacted with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to generate ·OH. Ultimately, the SM was degraded into harmless $\mathrm { C O } _ { 2 }$ and $\mathrm { H } _ { 2 } \mathrm { O }$ by ·OH with strong oxidizing property, and the related reaction formulas are as follows:

$$
\begin{array} { r l } & { \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + }  \cdot \mathrm { O H } + \mathrm { F e } ^ { 3 + } } \\ & { \mathrm { S M } + \cdot \mathrm { O H } + \mathrm { O } _ { 2 }  \mathrm { i n t e r m e d i a t e ~ p r o d u c t s } + \mathrm { C O } _ { 2 } + \mathrm { H } _ { 2 } \mathrm { O } } \end{array}
$$

It can be seen from Fig. 8a that within $6 0 \mathrm { { m i n } }$ of reaction time, the total Fe concentration in both A-Boron and ${ \mathrm { z n O } }$ -Boron decreased slightly, which is attributed to the adsorption of Fe on the prepared catalysts. The $\mathrm { F e ^ { 2 + } }$ concentration in the electro-Fenton system over Boron and ZnOBoron gradually decreased during the reaction process, because $\mathrm { F e ^ { 2 + } }$ reacted with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the solution to generate strong oxidizing ·OH, which further degraded the SM. Noteworthy, the $\mathrm { F e ^ { 2 + } }$ concentration in the ${ \mathrm { Z n O } } .$ -Boron EF system was always higher than that in the Boron EF system, the result benefits from the superior $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ production efficiency of ZnO-Boron. The continuously generated $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ will react with $\mathrm { F e } ^ { 3 + }$ to form $\mathrm { F e ^ { 2 + } }$ (Babuponnusami and Muthukumar, 2014). Therefore, ZnOBoron as a cathode material not only has high selectivity for the ORR process of in situ electrogenerated $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ but also has a rapid regeneration ability for $\mathrm { F e ^ { 2 + } }$ .

To confirm the role of ·OH in the electro-Fenton catalytic system, the trapping experiments used TBA as a trapping agent were performed (Fig. S7a). The results showed that the degradation efficiency of SM in the electro-Fenton systems over Boron and $\mathrm { Z n O }$ -Boron decreased significantly after adding TBA, indicating that ·OH were the main active species in the reaction process. After adjusting the dosage of TBA, the degradation efficiency of SM decreased with the increase of TBA concentration and reached a peak at $1 0 \%$ TBA, further indicating the important role of ·OH (Fig. S7b).

To demonstrate that the ·OH is generated in heterogeneous electroFenton systems, detections of ·OH using the EPR technique with the DMPO acting as a capture agent were performed (Oturan et al., 2010). As expected, both the electro-Fenton systems exhibited prominent characteristic peaks of ·OH, and the peak intensity in the ZnO-Boron system was higher than that in the bulk Boron system (Fig. 8b). It is worth noting that in the EPR spectrum of $\mathrm { Z n O }$ -Boron, the characteristic peak pattern of singlet oxygen radicals $( ^ { 1 } 0 _ { 2 } )$ was also revealed in addition to the characteristic peaks of ·OH. The signal of ·OH was stronger than that of $^ 1 0 _ { 2 }$ , which indicates the active oxidation species in the ZnOBoron EF system was mainly dominated by ·OH. As shown in Fig. 8c, SM can still be almost completely degraded in the electro-Fenton system over $\mathrm { Z n O }$ -Boron within $3 0 ~ \mathrm { { m i n } }$ after 5 reaction cycles. ZnO-Boron not only possesses excellent electrocatalytic activity but also possesses strong catalytic stability.

# 4. Conclusion

In summary, the ZnO-Boron synthesized by facile high-temperature calcination method not only has achieved ultrafast degradation kinetics but also promotes the rapid regeneration of $\mathrm { F e ^ { 2 + } }$ . SM degradation efficiency can reach $1 0 0 \%$ in the electron-Fenton system over ZnO-Boron within $3 0 \mathrm { { m i n } }$ . Moreover, the accumulation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration over ${ \mathrm { Z n O } }$ -Boron cathode reaches up to $5 8 ~ \mathrm { m g ~ L ^ { - 1 } }$ within $^ { 1 \mathrm { ~ h ~ } }$ at the condition of $\mathtt { p H } = 3$ and voltage $= - 0 . 6 \mathrm { V }$ , which is more outstanding than that over bulk Boron. The electrochemical activity of the ZnO-Boron electrode can retain at least 5 cycles of degradation experiments without obvious decay. After research, the factors for the exceptional performance of $\mathrm { z n O }$ -Boron can be summarized as the following points: (1) the mesoporous structure arose from chemical etching offers a larger specific surface area and exposes more active sites for reaction; (2) the introduction of $\mathrm { Z n O }$ as a co-catalyst can act as an electronic transfer center, promoting the electron transfer efficiency; (3) the optimized oxygen adsorption performance shortens electron transport paths; (4) ·OH and $^ 1 0 _ { 2 }$ synergistic effect on oxidation process. All these features indicate that ZnO-Boron is an attractive material to be used as an EF cathode, and thus exhibits excellent pollutant degradation performance.
