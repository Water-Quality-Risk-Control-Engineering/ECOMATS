# a b s t r a c t

Discovering functional applications of metallic glasses (MGs) as heterogeneous catalysts is a fundamental and essential topic. This work reports the rapid production of sulfate radicals $( \mathrm { S O } _ { 4 } { \bullet } ^ { - } )$ from peroxymonosulfate (PMS) using $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ glassy ribbons as catalysts for Eosin Y (EY) dye wastewater treatment. The reaction rates (k) from the experimental data reveal that the EY degradation is well fitted with the pseudo-first-order kinetic model. The strong electron transfer ability is characterized by electrochemical methods, presenting an advanced catalytic performance for EY degradation. Various experimental parameters, including dye concentration, catalyst dosage, PMS concentration, light intensity, pH and reaction temperature as well as the saline and natural inorganic effects, are fully investigated. The results show that the color removal of EY dye could achieve nearly $1 0 0 \%$ within $2 0 \mathrm { { m i n } }$ . The quenching experiments are performed to verify the production of reactive species, suggesting that both •OH and $S O _ { 4 } { \bullet } ^ { - }$ are produced from PMS and play significant roles in EY degradation. This critical study reveals that using $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs as catalysts exhibits a superior reactivity on PMS activation in wastewater treatment. The discoveries shed lights into the study of electron transfer ability for MGs, presenting extensive prospects in the application of dye wastewater treatment.

# 1. Introduction

Metallic glasses (MGs) have been extensively employed as either structural [1] or functional materials [2] in industries due to their superior physical and chemical properties such as high strength [3,4], excellent corrosion resistance [5,6], and soft magnetic properties [7,8]. However, the development of bulk metallic glasses (BMGs) still has many obstacles, such as the absence of plasticity [9]. Recent reports demonstrate that MG ribbons with enhanced mechanical properties present great potential application in the catalytic research field [10, 11]. To date, MGs in different alloy systems and with various chemical compositions have been widely studied as effective catalysts for industrial effluents treatment [12–15]. It has been reported that the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ and $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs demonstrate 5–10 times quicker production rate of reactive species than the currently employed Fe-based catalysts [16]. The $\mathrm { F e _ { 7 6 } B _ { 1 2 } S i _ { 9 } Y _ { 3 } }$ MG powder shows 1000 times higher reactivity than crystalline Fe powder in treating methyl orange [17]. In addition to their superior reusability, the $\mathrm { F e _ { 7 6 } B _ { 1 2 } S i _ { 9 } Y _ { 3 } }$ MG powder and ribbons could be reused up to 13 cycles in methyl orange degradation [17] and $> 3 0$ times in degrading methyl blue without significant reduction in efficiency [18], respectively. These catalytic performances show that using amorphous alloys as catalysts would provide better efficiency than the traditional crystalline catalysts. However, their catalytic mechanism is still not yet clear.

Conventional techniques, such as physical, biological, and chemical approaches, have been widely explored to remove various dye effluents. The physical treatments achieve removal of toxic organics by naturally occurring forces without altering the nature of organics. Biological methods are ineffective because the microorganisms are less resistant to the complex aromatic structure of dye effluents [19]. Most of traditional chemical methods cause seriously secondary pollution. Recently, advanced oxidation processes (AOPs), which combining chemical and advanced material technologies are rapidly developed, such as ozone $\left( 0 _ { 3 } \right)$ oxidation [20], Fenton/Fenton-like process [21–23], and photocatalysis [24–26]. The superiority of the AOPs is that the reactive species, such as hydroxyl radicals (•OH) and sulfate radicals $( 5 0 _ { 4 } { \bullet } ^ { - } )$ can be generated to effectively oxidize organic matters from effluents into $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ , ${ \mathrm { C O } } _ { 2 }$ , and other harmlessly inorganic molecules [24]. Very recently, largely due to the superior features of abundant natural source, low cost, and friendly environmental compatibility, Fe-based heterogeneous catalysts have been extensively investigated for their performance in AOPs, such as goethite $\alpha$ -FeOOH) [27], magnetite $\left( \mathrm { F e } _ { 3 } 0 _ { 4 } \right)$ [28], hematite $( \alpha \mathrm { - F e } _ { 2 } 0 _ { 3 }$ ) [29], maghemite $\left( \mathsf { g } \mathrm { - F e } _ { 2 } \mathsf { O } _ { 3 } \right)$ [30], and zerovalent iron (ZVI) [31]. However, these catalysts still have significant disadvantages, such as low efficiency, less reusable, fast decay, and secondary pollution [21]. Recent reports demonstrate that using MGs as catalysts could effectively overcome the aforementioned shortcomings and their catalytic activity could be much improved by tuning their particle size [32], surface morphology [33], surface to volume ratio [5], and chemical composition [14,15]. For example, the $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs can be used as an effective catalyst in activation of hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ to rapidly generate hydroxyl radicals (•OH) for completely degrading methyl blue and methyl orange within $2 0 ~ \mathrm { { m i n } }$ [16]. Compared to the •OH with the redox potential of $\mathsf { E } ^ { \circ } = 2 . 7 – 2 . 8 \ : \mathsf { V }$ [34] and the short half-life of $1 0 ^ { - 3 } \mu \mathrm { s }$ [35], the $S 0 _ { 4 } { \bullet } ^ { - }$ with a similar redox potential of $\mathrm { E } ^ { \circ } = 2 . 5 { - } 3 . 1 \mathrm { V }$ [36] has a much longer stability (half-life $3 0 { - } 4 0 \mu s )$ in the dye effluents [35,37]. In addition to the reactive environment, the $\mathrm { F e } ^ { 2 + } / \mathrm { H } _ { 2 } 0 _ { 2 }$ system is preferred at pH range from 2 to 6, which largely limits the actual industrialization. In comparison, the broad operative pH range of the $S 0 _ { 4 } { ^ \bullet } ^ { - }$ [37] is the second attractive property in water treatment. According to Nidheesh and Rajan [38], the AOPs involved $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ have a higher removal efficiency for pollutants and can be used in a wide pH range (i.e. 3, 6 and 9). Peroxymonosulfate (PMS) [39,40] and persulfate (PS) [41] are two important resources for producing the $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ . Traditionally, the $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ can be generated by the homogeneous energetic activation of UV [42] or thermal activation [43] and heterogeneous catalytic activation of metal-free catalysts [44] or metal-based catalysts [45]. Especially, the reaction rate of $S 0 _ { 4 } { \bullet } ^ { - }$ by homogeneously energetic activation (e.g. heat, $k = 1 . 0 \times 1 0 ^ { - 7 } \mathrm { M } ^ { - 1 } { \cdot } { s } ^ { - 1 }$ [46]) is much lower than heterogeneously catalytic activation by transition metals, such as using iron as the catalyst with the reaction rate of $k$ $= 2 . 0 \times 1 0 ^ { 1 } \mathrm { M } ^ { - 1 } { \cdot } { s } ^ { - 1 }$ [46]. However, the most important drawback to the transition metals $\mathrm { / S O _ { 4 } bullet ^ { - } }$ system is that the leached metallic ions would react with the PS/PMS to reduce the activation rate, and the salinity as well as natural inorganic ions in the water would consume the generated $S 0 _ { 4 } { ^ \bullet } ^ { - }$ . According to those aforementioned advantages and disadvantages, developing an advanced catalyst that has high efficiency in catalytic activation of $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ and low leaching rate of the transition metals as well as the effect of the salinity or natural inorganic ions for degrading contaminants in wastewater is always a challenging topic.

Eosin Y (EY), also named as Acid Red 87, is a xanthene red dye that defined as a conjugated π system [47]. The EY dye is broadly used in dyeing, printing, leather, and fluorescent pigment, and painting industries because of its low price and bright color. The carcinogenicity of EY has been experimentally confirmed, and the acute poisonousness of the dye can lead to a variety of chronic effects to the health of inhabitants and damages to the environment [48]. Therefore, to explore an effective, low cost, and environmental-friendly catalyst is increasingly concerned in the textile or paper industry. This work reports the sulfate radicals $( \mathrm { S O } _ { 4 } { \bullet } ^ { - } )$ and hydroxyl radicals (•OH) activation from PMS using $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ MGs under heterogeneous Fenton-like process. Initially, the amorphous nature of the manufactured $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ glassy ribbon is characterized by XRD and the surface morphology is analyzed by SEM. The electrochemical performance in simulated solution is also performed to examine electron transfer and corrosion resistance abilities of the glassy ribbons. The influencing factors on EY dye degradation efficiencies are systematically examined, and the corresponding pseudo-first-order reaction kinetic rates $( k )$ are thoroughly studied.

# 2.2. Characterizations

The structural characteristic and phase contents of the fabricated glassy ribbons were characterized by X-ray diffraction (XRD, PANalytical Empyrean, Netherlands) with $\mathrm { C o - K } \alpha$ radiation $( \lambda =$ $0 . 1 7 9 ~ \mathrm { n m }$ ). The surface morphologies of glassy ribbons before and after reactions were characterized by using a scanning electron microscope (SEM) outfitted with EDS detector (JEOL 6000, Japan). Electrochemical tests of the $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ glassy ribbons were conducted in a beaker containing sulfuric acid $\mathrm { ( H _ { 2 } S O _ { 4 } ) }$ solution at pH is equal to 3.4 (same as the experimental condition after adding PMS into dye solution). All electrochemical measurements were recorded by electrochemical workstation (PARSTAT 2273) in a conventional three-electrode cell, where the $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N } \mathrm { b } _ { 3 }$ ribbons were used as working electrode with an exposed surface area of approximately $1 . 0 \mathrm { c m } ^ { 2 }$ . A platinum sheet was applied as the counter electrode, and a saturated calomel electrode (SCE) served as the reference electrode which was connected to a Luggin capillary bridge. All the potentials recorded and mentioned in electrochemical measurements were versus SCE. The potentiodynamic polarization measurement was performed at a scan rate of $0 . 1 6 6 7 ~ \mathrm { m V } / s$ . The potential of cathodic polarization curve was scanned from $- 0 . 5 \mathrm { V }$ to $+ 2 . 0 \mathrm { V }$ at anodic polarization region. The electrochemical impedance spectroscopy (EIS) was probed at open circuit potential (OCP) potentiostatically, and performed with an AC amplitude of $5 \mathrm { m V }$ over the frequency range from $1 0 ^ { - 2 }$ to $1 0 ^ { 4 } \mathrm { H z }$ . The OCP of $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ ribbon was acquired by raising immersion time from 0 to $1 6 \mathrm { h }$ . The ZSimpWin software was used to fit the electrochemical impedance data, which were interpreted by a specific electrical equivalent circuit. For the measurements of total organic carbon (TOC), an excessive ${ \mathsf { N a N O } } _ { 2 }$ solution (0.1 M) was used to quench the reaction, following by a TOC analyzer $( \mathrm { T O C - V _ { C S H } , }$ Shimadzu, Japan) for the mineralization analysis. For Fe and Nb leaching experiments, $2 \% v / \mathrm { v }$ nitric acid $\mathrm { ( H N O _ { 3 } ) } .$ ) was used to dilute the samples. Then the samples were filtered by the $0 . 2 2 \mu \mathrm { m }$ filter before the trace element analysis (iCAP Q ICP-MS, Thermo Fisher Scientific, USA). The pH of dye solution was measured by a pH meter (Oakton PC 2700 Benchtop Meter, Oakton Instruments, USA).

# 2.3. Methods

Eosin Y dye was used to study the catalytic activity of the $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ glassy ribbons. A Vortex-Genie 2 mixer (Scientific Industries, USA) and a solar light (Perfectlight, China) were utilized for stirring and irradiating dye solutions, respectively. The catalytic activity was measured at the predetermined time intervals using Perkin Elmer Lambda 35 UV–vis spectrometer (Shelton, CT, USA), which can determine the variation of dye concentration as a function of absorbance peak value. For constant temperature experiments, the beaker was put into a thermostatic water bath with the predetermined temperature at $2 5 ^ { \circ } \mathrm { C } ,$ $3 0 ^ { \circ } \mathrm { C } ,$ $4 0 ^ { \circ } \mathrm { C } ,$ . $5 0 ^ { \circ } \mathrm { C } ,$ and $6 0 ~ ^ { \circ } \mathrm { C } .$ The initial pH of dye was measured as 5.8. # 3.2. Electrocatalytic performance

MGs have been attracting extensive attention in wastewater treatment due to their excellent corrosion resistance behavior [52–54]. As shown in Fig. 2, the potentiodynamic polarization curve and EIS measurements are recorded after observing a relatively stable OCP of the $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ glassy ribbon. Fig. 2(a) shows the potentiodynamic polarization curve that is characterized from cathodic and anodic polarization regions. Notably, no standard Tafel region can be observed, but it can be clearly seen that the corrosion potential of the glassy ribbon is approximately at $- 0 . 3 5 \mathrm { ~ V ~ }$ , which is much higher than the MgZnbased MGs $( - 1 . 0 \mathsf { V } )$ [12] and slightly greater than the $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ glassy ribbon $( - 0 . 6 \ : \mathrm { V } )$ [55]. This result proves that the $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ glassy ribbon has a strong corrosion resistance campared to the other two MGs. With respect to the anodic region of the polarization curve, unlike the 316L stainless steel [56] or other coated materials with superior corrosion resistance, the manufactured $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ glassy ribbon does not present passivation behavior. Furthermore, the anodic polarization curve shows a continuous dissolution and the curve extends to the potential of $2 . 0 \mathrm { V }$ even without any pitting behavior. This phenomenon indicates an excellent corrosion resistance of $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs withstanding the localized corrosion under the acid solution [52]. Fig. 2(a) inset presents the stabilization progress of open circuit potential (OCP) against the immersion time. The reduction of the OCP in the first $^ { 2 \mathrm { ~ h ~ } }$ reveals a dissolution stage of the active metal immersed in acidic solution, and the main dissolution element is Fe. The lowest OCP has been observed at the immersion time of $^ { 2 \mathrm { ~ h ~ } }$ , and the cationic metal ion at this stage has reached its critical point in the test solution. After passing this point, the OCP has a quickly positive move in the next $^ { 1 \mathrm { h } }$ This stage involves the swift development of passivation by fast electron transfer on the ribbon surface, which would lead to high chemical reactivity in dye degradation. After the immersion time of $^ { 3 \mathrm { h } }$ , the OCP curve moves along a flat line and trends to be stable while the time approaches to $1 6 \mathrm { { h } } .$ During this period, the electrons between the ribbon surface and the test solution have a relatively stable state, providing a protective film on the ribbon surface. The produced film would definitely improve the sustainability and reusability of the manufactured $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ glassy ribbons in the wastewater treatment. The stable and protective passive film on the ribbon surface is mainly formed by chemical reactions of the Fe, Si, and Nb [57] atoms, where the atoms are progressively hydrated or oxidized to $\gamma .$ - FeO(OH) [58], $\mathrm { S i O } _ { 2 }$ [33], and ${ \tt N b } _ { 2 } { \tt O } _ { 5 }$ [16], respectively. As shown in Figs. 2(b) and (c), the electrochemical impedance spectroscopy (EIS) measurements demonstrate the analysis in the shape of Nyquist and Bode plots for the $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ glassy ribbons. The EIS Nyquist plot is relevant to the electron transfer resistance. The radius of the semi-circular arc in the Nyquist curve indicates the interface layer resistance existing on the electrode surface and a smaller semi-cicular arc radius means a lower electron transfer resistance [59]. From the Nyquist plot (Fig. 2b), two capacitive arcs with small radius are observed. Comparing with semi-cicular arc radiuses of different partially crystallized $\mathrm { F e } _ { 7 8 } \mathrm { S i } _ { 9 } \mathrm { B } _ { 1 3 }$ MGs [55], the relatively small radius of $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs reveals a low polarization resistance of the passive film, presenting a considerably strong electron transfer ability on the ribbon surface [55]. Considering the Nyquist plot (Fig. 2b) and the Bode plot (Fig. 2c), two times constant equivalent circuit module (Fig. 2d) is used to fit the EIS results. The circuit model constitutes with a parallel combination of a constant phase element $( \mathrm { C P E } _ { 2 } )$ and a charge transfer resistance $\left( \operatorname { R } _ { \operatorname { c t } } \right)$ , in cascade with the passive film resistance $\left( \mathrm { R _ { f } } \right)$ , and then parallel with another constant phase element $\left( \mathrm { C P E } _ { 1 } \right)$ and next in series connected with solution resistance $( \mathbb { R } _ { s } )$ . The using of $\mathrm { C P E } _ { 1 }$ and $\mathrm { C P E } _ { 2 }$ is because the material surface is never ideal flat, and it is normally considered as a rough or defective layer on the surface of the electrode [60]. As can be seen from Figs. 2(b) and (c), the obtained results from potentiodynamic measurements and EIS data are in very good agreement.

# 3.3. Catalytic evaluation

# 3.3.1. Dye degradation and efficiency

To confirm the effects of various experimental parameters on EY degradation efficiency, the comparable results of color removals using as-spun $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs and the corresponding reaction rates $( k )$ are shown in Fig. 3 and Table 3, respectively. Fig. 3(a) shows the effect of EY concentration in the range of $2 0 { - } 1 2 0 ~ \mathrm { p p m }$ . It can be seen that the color removal rate slightly decreases when EY initial concentration increases. At 20 ppm of EY dye solution, the color removal rate reaches $9 5 \%$ within $1 0 \ \mathrm { m i n }$ and the reaction rate $( k )$ can be achieved at $k = 0 . 8 7 6 \ \mathrm { m i n } ^ { - 1 }$ . By comparison, the color removal rate only rises to $7 2 \%$ with $k = 0 . 1 7 0 \mathrm { m i n } ^ { - 1 }$ for the initial concentration of 120 ppm within the same time. The possible reasons are that: 1) increasing the concentration of EY dye, more organic dye molecules would adsorb on the ribbon surface thus blocking the reaction of Fe and PMS; 2) the produced reactive species from ribbon surface are not sufficient to consume extra organic molecules within the same time intervals; 3) the increased number of dye molecules could increase the optical density of solution, leading to less UV–vis light energy being transferred for producing $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ from PMS [25,41].

# 3.3.2. Effect of reaction temperatures

Fig. 5(a) shows the evaluation of the degradation efficiency in the temperature ranging from 25 to $6 0 ~ ^ { \circ } \mathrm { C } .$ Notably, the degradation rate rises along with the increase of temperature. # 3.3.3. Effect of salinity and natural inorganic ions

The natural inorganic ions are commonly existing in wastewater that would have impacts on the success of industrial effluents treatment. Humic acids (HA) are produced by biodegradation of dead organic matters and largely exist in aquatic environments. It has been reported that HA have the capability to activate PMS or PS to generate $S 0 _ { 4 } { ^ \bullet } ^ { - }$ and •OH [70,71]. Fig. 6(a) shows the influence of HA initial concentrations on EY dye degradation. Specifically, without the addition of PMS, decolorization rate of EY is only reached about $1 0 \%$ in the presence of HA and $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 } .$ . Increasing the HA concentration from 0 ppm to 40 ppm could slightly decrease the EY dye degradation efficiency. Fig. 6(b) depicts the pseudo first-order kinetic rate constants $k _ { \mathrm { o b s } }$ with the addition of HA. It can be clearly seen that the reaction rates $( k )$ moderately drop while increase HA initial concentration. The addition of 40 ppm HA in EY dye solution shows the lowest reaction rate of $0 . 0 7 1 \ \mathrm { m i n } ^ { - 1 }$ . Reducing the HA concentration to $2 0 \ \mathsf { p p m }$ , the kinetic rate increases to $0 . 1 2 0 \mathrm { m i n } ^ { - 1 }$ , whereas without adding HA shows the highest kinetic rate of $0 . 1 8 3 \mathrm { ~ m i n } ^ { - 1 }$ . In terms of high concentration of salinity, chloride ion $( \mathbf { C l } ^ { - } )$ is one of the major inorganic particles in the natural wastewater. The chloride ion $\left( \mathbf { C l } ^ { - } \right)$ could scavenge both $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ (Eq. 12) and •OH (Eq. (13)). The redox potential of the generated $\mathrm { C l } _ { 2 } { \bullet } ^ { - }$ (Eqs. (14) and (15)) is $2 . 1 \mathrm { V } ,$ which is much lower than the redox potentials of $S 0 _ { 4 } { ^ { \bullet } } ^ { - }$ (2.5–3.1 V) and •OH $( 2 . 7 \mathrm { - } 2 . 8 \mathrm { V } )$ . Meanwhile, the chloride ion $( \mathbf { C l } ^ { - } )$ could also break PMS down to inorganics (Eqs. (16) and (17)), resulting in the reduction of the dye degradation efficiency. Fig. 6(c) demonstrates that increasing the $\mathtt { C l } ^ { - }$ concentration from $0 \mathrm { m M }$ to $2 0 \mathrm { m M }$ has no obvious effect on EY degradation efficiency. Fig. 6(d) shows the pseudo first-order kinetic rate constants $k$ with the addition of chloride ions. The results indicate a slight decrease. Therefore, the $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs/PMS system is a very promising treatment method even with a certain amount of $\mathtt { C l } ^ { - }$ existing in EY dye water.

The mechanism of PMS activation by employing $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 } \mathrm { M G }$ is proposed in Fig. 8. The proposed mechanism is that the disordered atomic structure of $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ glassy ribbon has weak atomic bonding, where the electrons around the randomly disordered atoms can be easily activated on the surface of metal. The amorphous $\mathsf { F e } ^ { 0 }$ , acting both electron donator and acceptor, could significantly enhance the electron transfer ability, and the inclusion of Si and B elements would further strengthen the glass-forming ability (GFA) [16] and improve the surface stability [16,41,58]. Therefore, the effective electron transfer could enhance the activation efficiency of reactive species [77] from PMS by the $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ glassy ribbons. In addition, the thermostat water bath and UV–vis light are employed in this work could also improve activation efficiency of PMS, thereby increasing the production of •OH and $S 0 _ { 4 } { ^ \bullet } ^ { - }$ to degrade organic molecules.

From previous literatures, the $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MG has been demonstrated with high potential to activate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [16] and persulfate [41] to rapidly generate •OH and $S 0 _ { 4 } { ^ \bullet } ^ { - }$ , respectively. The $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 } \mathrm { M G }$ s show at least 5 times of reusability for the persulfate activation in malachite green dye degradation [41]. In this work, the $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MG also shows a high reusability and surface stability in the PMS activation.

# 3.5. Reusability and surface aging

According to Fig. 9, the $\mathrm { F e _ { 7 3 . 5 } S i _ { 1 3 . 5 } B _ { 9 } C u _ { 1 } N b _ { 3 } M G }$ s demonstrate an excellent reusability in the PMS activation for degrading Eosin Y dye even resued 10 times. The dye degradation efficiency slightly decreases after reused for 4 times but all the reactions can achieve $9 0 \%$ of color removal rate in $2 0 \ \mathrm { m i n }$ . The reaction rates for these 4 reused times are $0 . 2 2 7 \mathrm { m i n } ^ { - 1 }$ , $0 . 2 1 0 \mathrm { m i n } ^ { - 1 }$ , $0 . 1 6 2 \mathrm { m i n } ^ { - 1 }$ and $0 . 1 3 4 \mathrm { m i n } ^ { - 1 }$ , respectively. Then the decrease of reaction rate almost terminates after reused 7 times and 10 times, which have a same reaction rate of $0 . 1 2 0 \mathrm { m i n } ^ { - 1 }$ In order to assess the surface stability of MGs, Fig. 10(a) shows the surface aging of identical MGs after reused 10 times. Although the surface of ribbon has a slight decay with several corrosion areas, most of surface still present relative soomth as as-spun ribbons in the Fig. 1(b). In addition, it can be seen from Fig. 10(b) that there are some precipitations around the corrosion area, which can be comfirmed as Si/Nb oxides. Those precipitation are very similar as reported previously [41], as generated near the rougher areas. According to previous discussion of extreme low Nb leaching concentration in Fig. 4, it can be known that the inclusion of Nb can promote the formation of Nb oxides on the surface, which are very hard for shedding, and enhance the surface stability avoiding fast decay of surface as demonstration in Fig. 10 [16,41].

# 4. Conclusion

This work reports the PMS activation using $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs as catalysts in wastewater treatment. The result shows the low-cost glassy ribbons have excellent performance in catalytic degradation of EY dye effluents under heterogeneous photo Fenton-like process. The dye degradation processes are well fitted with the pseudo-first-order reaction kinetic model. Compared to the crystalline catalysts, a lower activation energy of $E _ { \mathrm { a } } = 2 2 . 2 \mathrm { k J } / \mathrm { m o l }$ is evaluated with Arrhenius equation for $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B } _ { 9 } \mathrm { C u } _ { 1 } \mathrm { N b } _ { 3 }$ MGs that are responsible for the high reactivity of dye treatment. Furthermore, the electrochemical behavior of $\mathrm { F e _ { 7 3 . 5 } S i _ { 1 3 . 5 } B _ { 9 } C u _ { 1 } N b _ { 3 } \ M G s }$ in simulated dye solution gives the evidence of high corrosion resistance ability and strong electron transfer ability. The disordered atomic packing structure gives weak atomic bonding in $\mathsf { F e } _ { 7 3 . 5 } \mathsf { S i } _ { 1 3 . 5 } \mathsf { B } _ { 9 } \mathsf { C u } _ { 1 } \mathsf { N b } _ { 3 }$ MGs, suggesting fast electron transfer ability during the dye treatment process. The fast generation of $S O _ { 4 } { ^ \bullet } ^ { - }$ and •OH from PMS by $\mathrm { F e _ { 7 3 . 5 } S i _ { 1 3 . 5 } B _ { 9 } C u _ { 1 } N b _ { 3 } M G s }$ are evidenced as the catalytic mechanism for dye degradation. This critical study provides a significant advance in the understanding of electron transfer ability of $\mathrm { F e } _ { 7 3 . 5 } \mathrm { S i } _ { 1 3 . 5 } \mathrm { B g C u } _ { 1 } \mathrm { N b } _ { 3 }$ MGs in the treatment of organic dye effluents and more importantly, gives a great idea to synthesize novel catalysts in dye wastewater treatment.
