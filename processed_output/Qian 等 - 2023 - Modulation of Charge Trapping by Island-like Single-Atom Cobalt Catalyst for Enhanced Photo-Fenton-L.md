# Modulation of Charge Trapping by Island-like Single-Atom Cobalt Catalyst for Enhanced Photo-Fenton-Like reaction

Mengying Qian, Xi-Lin Wu,\* Meichi Lu, Lizhou Huang, Wenxuan Li, Hongjun Lin, Jianrong Chen, Shaobin Wang, and Xiaoguang Duan\*

Composites-based photocatalysis relies on the interfacial electron transfer between the metallic cocatalyst and photosensitizer (the semiconductor) to realize spatial separation of charge carriers. Herein, an ingenious heterojunction between Co-CN single atom catalysts (SACs) and ${ \tt g } { \tt C } _ { 3 } \Nu _ { 4 }$ is constructed for heterogeneous photo-Fenton-like reactions. Driven by built-in electric field across the heterojunctions, the separation and migration of the photogenerated charge carriers is promoted, leading to the fast electron transfer from the ${ \tt g } { \tt C } _ { 3 } \Nu _ { 4 }$ to the Co-CN SACs. Theoretical calculations and transient absorption spectroscopy reveal the modulated charge transfer and trapping in the $\mathsf { S A - C o - C N } / \mathsf { g - C } _ { 3 } \mathsf { N } _ { 4 }$ heterostructure, resulting in the remarkably enhanced generation of reactive oxygen species via peroxymonosulfate activation under light irradiation. This ingenious $\mathsf { S A - C o - C N / g - C _ { 3 } N _ { 4 } / P M S } _ { i }$ /vis system is effcient for the oxidation of various antibiotics with high removal efficiency $( > 9 8 \% )$ , a wide operating pH range $\left( \mathsf { p H 3 - 7 7 } \right)$ and excellent stability in longterm operation. This study provides a new tactic for rational design of SACsbased heterojunctions to bridge photocatalysis and heterogeneous catalysis, attaining superior photoredox activity via interfacial coupling.

# 1. Introduction

The occurrence of antibiotic-resistant bacteria and antibiotic resistance genes induced by the antibiotic residues in aquatic environments are on the list of the most important public health concerns of this century (World Health Organization).[1] Effluents from wastewater treatment plants are the main source of antibiotics that are discharged into the aquatic environment,[1,2] owing to the inefficient elimination of antibiotics by conventional water purification techniques (e.g., biological treatment and chemical coagulation).[3,4] Recently, advanced oxidation processes (AOPs) are considered undoubtedly promising techniques for the treatment of antibiotic wastewater. Among the various AOPs, Fenton-like-reactions by catalytic activation of peroxymonosulfte (PMS) to generate highly reactive oxygen species (ROS), such as sulfate radical $( \mathrm { S O } _ { 4 } { } ^ { \bullet - } )$ , hydroxyl radical (·OH), superoxide radical $( \mathrm { O } _ { 2 } \mathrm { ^ { - } } )$ and singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , are emerging approaches for the abatement of antibiotics contaminants from wastewater.[3,5]

Semiconductor-based photocatalysis offers a clean and sustainable approach for the exploration of renewable energy and environmental remediation.[6] Numerous investigations on the development of efficient photocatalysts for the activation of PMS, such as metal oxides,7] metal sulfides,[8] and carbon nitrides,[9] have been conducted in the past few decades. However, for single-component photocatalysts, the rapid recombination of photoinduced electron-hole pairs and the poor light-adsorption property, resulting in low photocatalytic activity, greatly restrict their practical application. Construction of built-in electric field (EF) at interface of catalysts is a promising approach to improve the charge carriers' separation and migration.[10] Built-in EF can be created by fabricating of the semiconductor-based junctions, such as $p$ n homojunction, heterojunction or Schottky junction.[11] In this regard, fabrication of heterojunctions seems to be a feasible strategy to improve the performance of the semiconductorbased photocatalysis for PMS activation.

Single-atom catalysts (SACs) are defined as catalysts containing atomically dispersed metal sites anchored on the support.[12] SACs can minimize the consumption of transition and noble metals and maximize the exposure of active sites via robust coordination, thus delivering excellent catalytic activity, selectivity and durability [13,14] As emerging multifunctional materials, SACs have shown great promise for the treatment of organic pollutants via the heterogeneous activation of PMS. The single atom sites of Cu $\cdot \mathrm { N } _ { 4 } ,$ [5] ${ \mathrm { C o - N } } _ { 4 } ,$ [15] $\mathrm { C o N } _ { 2 + 2 } [ 1 6 ]$ and Fe $\mathrm { \cdot N _ { 4 } }$ anchored on various substrates empower SACs as efficient catalysts for PMS activation. Despite that a myriad of studies have reported the design and synthesis of SACs with wellidentified coordination and electronic structures, SACs-based heterojunctions are less explored. Fabricating SACs/semiconductor heterojunctions will combine the benefits of SACs and photocatalysts, enhancing the performance and triggering other functions.

In this study, heterojunctions of single-atom Co supported on N-rich carbons (SA-Co-CN) and graphitic carbon nitride $\mathrm { ( g - C } _ { 3 } \mathrm { N } _ { 4 } )$ were constructed and applied as heterogeneous catalysts for PMS activation. The heterojunctions facilitated the electron communication between the SACs and the photocatalysts within the nanocomposite, thereby boosting the catalytic performance of the $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ in photo-Fenton-like reactions. The degradation of various antibiotics via PMS activation using $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ was studied. Primary ROS generated in the $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } / P M S / v }$ is system were identified by quenching experiments and electron paramagnetic resonance (EPR) spectroscopy, and further quantified by a series of colorimetric analyses. Besides, the charge transfer process was revealed by femtosecond transient absorption (fs-TA) spectroscopy and density functional theory (DFT) calculations. We propose the concept of single-atom "islands"

in this work, which provides a new tactic for enhancing the performance of SACs.

# 2.1. Theoretical Calculations

In this proof-of-concept study, DFT calculations were first performed to reveal the electronic structure and electron-transfer behavior of the in-plane heterostructures. From the total density of states (TDOS) of $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ (Figure 1a), a large energy gap between the top of the valence band (VB) and the bottom of the conduction band (CB) is observed. TDOS of $\operatorname { S A - C o - C N } / \mathrm { g } .$ . $\mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ exhibits a much narrower band gap with the VB crossing the Fermi level (Figure 1b), which facilitates the electron transitions between the energy levels.[14] Strong hybridization of the electronic orbits between SA-Co-CN and $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ can be observed from TDOS of $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } , }$ implying the easy charge transfer across the heterostructure. Furthermore, charge distributions of $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ and $\mathrm { S A { \mathrm { - } C o \mathrm { - } C N / g \mathrm { - } C _ { 3 } N _ { 4 } } }$ upon one extra $\mathrm { e ^ { - } }$ or $\mathrm { h ^ { + } }$ injection were evaluated by Bader charge analysis (Figure S1, Supporting Information). For pristine $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 } ,$ the holes only accumulate on $N$ atoms $( 0 . 9 4 ~ \mathrm { h ^ { + } } )$ , while the electrons are mainly distributed on $C$ atoms $( 0 . 2 6 ~ \mathrm { e } ^ { - } )$ and $N$ atoms $( 0 . 5 7 \mathrm { e } ^ { - } )$ . For the $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } , }$ the electrons and holes are primarily distributed on $C$ atoms $0 . 6 6 ~ \mathrm { e } ^ { - }$ and $0 . 6 3 \mathrm { ~ h ^ { + \prime } }$ and $N$ atoms $0 . 3 3 ~ \mathrm { e } ^ { - }$ and $0 . 3 1 \mathrm { h } ^ { + } \vert$ , suggesting the more delocalization of the charge carriers in the $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ More interestingly, the electrons and holes are inclined to accumulate in the domains of SA-Co-CN $[ 0 . 5 2 \mathrm { e } ^ { - }$ and $0 . 4 3 \mathrm { ~ h ^ { + } } \backslash$ and $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ $0 . 4 7 \mathrm { e } ^ { - }$ and $0 . 5 1 \mathrm { ~ h ^ { + } } )$ , respectively, which is indicative of the efficient charge separation between the heterojunction of SA-Co-CN and $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ [17] Thus, the efficient charge delocalization and separation in the heterostructure will certainly boost the photocatalytic performance of $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } } .$ [18,19] As compared with the Bader charge of $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ before and after the injection of one extra $\mathrm { e ^ { - } }$ (Figure 1c), partial electron is also distributed over the $\mathrm { C o - N _ { 4 } }$ sites $( 0 . 1 1 \mathrm { e } ^ { - } )$ . # 2.2. Synthesis and Characterization

Inspired by the above theoretical predictions, a heterojunction between single-atom Co catalyst and $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ was fabricated using a facile co-calcination method. Prussian blue analog $( \mathrm { C o } _ { 3 } [ \mathrm { C o } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ ,PBA-Co),20] a common type of metal-organic framework, was applied as the precursor for the synthesis of island-like Co-CN SACs. The polymer precursor (PEI-MCA) made from melamine (M), cyanuric acid (CA) and polyethyleneimine (PEI) was applied for the fabrication of $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ [21] The heterojunction of $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ was prepared by calcinating the mixture of PBA-Co and PEI-MCA at $5 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { ~ h ~ } }$ under the $\Nu _ { 2 }$ atmosphere. Scanning electron microscopy (SEM) and transmission electron microscopy (TEM) observations show that the size of $\mathrm { C o } _ { 3 } [ \mathrm { C o } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ nanoparticles (NPs) are in the range of $1 0 0 { - } 2 0 0 \ \mathrm { n m }$ , with a polyhedral structure (Figure S2, Supporting Information). All the X-ray diffraction (XRD) peaks in Figure S3 (Supporting Information) are assigned to the face-centered cubic phase of $\mathrm { C o } _ { 3 } [ \mathrm { C o } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ (JCPDF No.77-1161).[20] From the SEM and TEM images, $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ possesses a sheet-like structure with abundant mesopores on its surface (Figure S4, Supporting Information). $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ has a similar morphology to polyhedral Co-CN NPs embedded in the $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ (Figure 2a; Figure S5, Supporting Information). The high-resolution TEM (HR-TEM) image (Figure 2b) of the $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } }$ reveals the formation of heterojunctions between amorphous Co-CN and $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ From the high-angle annular dark-field scanning TEM (HAADF-STEM) image (Figure 2c), densely distributed bright spots (marked with circles) are observed in the domain of Co-CN, corresponding to the atomically dispersed Co atoms. During the high-temperature calcination process, $\mathrm { C o } _ { 3 } [ \mathrm { C o } ( \mathrm { C N } ) _ { 6 } ] _ { 2 }$ NPs were carbonized and transformed into the single-atom Co sites anchored on the CN (SA-Co-CN). TEM image (Figure 2d) and the corresponding energy dispersive X-ray spectroscopy (EDX) mapping images (Figure 2e,f) show the homogeneous distribution of C and $N$ elements over $\mathrm { S A { - } C o { - } C N / g { - } C _ { 3 } N _ { 4 } , }$ while the Co element is almost solely distributed within Co-CN NPs (Figure 2g), indicating the formation of the island-like Co-CN catalyst supported on $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ Electron Energy Loss Spectroscopy (EELS) was applied to analyze the Co contents along the $\operatorname { S A - C o - C N } / \mathrm { g } -$ $\mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ heterojunction (Figure S6, Supporting Information). # 3. Conclusion

In summary, we have successfully designed and fabricated the heterojunctions of Co-CN SACs and $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ Photoelectrochemical and fs-TA analysis certified the efficient separation and fast transportation of charge carriers in the heterostructure. This proof-of-concept work provides a promising strategy for the rational design of SACs-based heterojunctions for photocatalysis and environmental remediation.

The control samples were fabricated by varying the mass ratio of PBA-Co to PEI-MCA from 0.05:1.25, 0.15:1.25, to 0.2:1.25, and the products were denoted as $0 . 0 5 { \cdot } C 0 { \cdot } C \mathsf { N } / \mathsf { g } { \cdot } C _ { 3 } \mathsf { N } _ { 4 } ,$ . $0 . 7 5 { \cdot } C 0 { \cdot } C { \mathsf { N } } / { \mathsf { g - } } C _ { 3 } { \mathsf { N } } _ { 4 }$ and $0 . 2 \mathrm { - } \mathsf { C o \mathrm { - } C N / g \mathrm { - } C _ { 3 } N _ { 4 } } ,$ respectively. The pure ${ \tt g } – { \mathsf { C } } _ { 3 } \mathsf { N } _ { 4 }$ was obtained following the same calcination procedure by using the polymer precursor as raw material. The $\mathsf { S A - C o - g - C _ { 3 } N _ { 4 } }$ was prepared with the same procedure by using the mixture of ${ \mathsf { C o C l } } _ { 2 }$ and PEI-MCA as the precursor.

PMS Activation: The catalytic performance of the as-prepared catalysts for PMS activation was systematically studied by using NOR as the target pollutant. A 300 W xenon lamp (PLS-FX300HU, Beijing Perfectlight) with a UV cutoff filter $( \lambda { < } 4 2 0 \ \mathsf { n m } )$ was used to simulate visible light. The solution pH was adjusted by using 0.1 M HCl or NaOH. Typically, $3 0 ~ \mathsf { m L }$ of reaction solution containing $2 0 ~ \mathsf { m g } ~ \mathsf { L } ^ { - 1 }$ of NOR and $0 . 2 \mathrm { ~ g ~ L ^ { - 1 } ~ }$ of the catalyst was first stirred in dark for 60 min to achieve the adsorption—desorption equilibrium. Catalytic degradation of NOR was triggered by adding a desired amount of PMS into the above suspension, and the reaction system was immediately subjected to light irradiation. The reaction solution was sampled at the required time intervals, immediately quenched with methanol, and then filtered with a $0 . 2 2 ~ \mu \mathrm { m }$ membrane to remove the solid catalyst. The concentration of NOR was determined by high-performance liquid chromatography (HPLC, Shimadzu 20AV) equipped with a C18 chromatographic column and a UV-vis detector at the detection wavelength of $2 7 8 { \mathsf { n m } }$ A mixture of HPLC grade methanol and water $( 4 5 / 5 5 , \ : \mathrm { v / v ) }$ with $0 . 1 \%$ formic acid was used as the mobile phase at a flow rate of $\mathsf { l } . 0 \mathsf { m L } \mathsf { m i n } ^ { - 1 }$ Degradation of other antibiotics (sulfamethoxazole (SMX), meropenem (MEM), amoxicillin (AML), tetracycline hydrochloride (TCH), metronidazole (MNZ)) was performed using the same procedures as mentioned above. The HPLC conditions for the detection of the various antibiotics are listed in Table S1 (Supporting Information). Details for the determination of PMS concentrations and the reusability of catalyst was evaluated by recycling the catalysts from the reaction system after each cycle. The recycled catalyst was washed with deionized water several times and then dried in a vacuum at $6 0 ~ ^ { \circ } \mathsf { C }$ overnight for the next cycle.
