# Bimetallic Phase Transition Induced Asymmetric Spin-State Modulation for Controllable Radical-Nonradical Pathways

Yanhua Peng, Yaxin Cheng, Jingdan Shi, Qiming Zhang, Fanxu Meng, Xiaojia Huang Xin Yu, Wei Ren, and Ting Wang\*

Rational spin-states modulation in bimetallic catalysts presents a promising strategy to enhance both the activity and selectivity of advanced oxidation processes. However, the underlying spin-electronic mechanisms, particularly in structurally complex, multiphase systems, remain insufficiently understood. Inthis study  sulfur-assistedphase engineeringstraty is employed to tune the structure of cobalt-iron catalysts between spinels $\mathsf { ( C o F e } _ { 2 } \mathsf { O } _ { 4 }$ and $\mathsf { C o F e } _ { 2 } \mathsf { S } _ { 4 } )$ and heterojunctions $( \mathsf { C o S } @ \mathsf { F e } _ { 3 } \mathsf { S } _ { 4 }$ and $\mathsf { C o } _ { 3 } \mathsf { S } _ { 4 } @ \mathsf { F e } _ { 3 } \mathsf { S } _ { 4 } )$ Integrated experimental and density functional theory (DFT) analysis reveal that sulfur incorporation triggers asymmetric spin-state modulation, characterized by enhanced electron localization in low-spin-state Co sites and significant spin polarization on S atoms. Such electronic configuration opens a directional Co—S—Fe electron spin channel in bimetallic sulfides, which promotes interfacial electron transfer and initiates the proton-coupled electron transfer (PCET) process, thereby enabling efficient activation of peroxymonosulfate (PMS) and selective generation of nonradical $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } } ^ { \phantom { \dagger } }$ species. The resulting $\mathsf { C o S @ F e _ { 3 } S _ { 4 } }$ catalytic system demonstrates ${ \approx } 1 4$ -fold increase in reaction kinetics compared to $\mathsf { C o F e } _ { 2 } \mathsf { O } _ { 4 }$ spinels, alongside high environmental applicability (Life Cycle Assessment) and minimal ecotoxicity of degradation intermediates. These findings highlight the critical role of asymmetric spin-state modulation in governing reactive oxygen species (ROS) pathways, providing a rational design strategy for tunable advanced oxidation processes.

# 1. Introduction

Advanced oxidation processes (AOPs) based on persulfate activation have gained prominence as an effective and economically viable approach for the refractory organic contaminants in wastewater, owing to their high oxidative efficiency, stability, and treatment versatility.[1,2] Upon catalytic activation, the peroxide bond in persulfate can be activated to generate highly reactive sulfate radicals $\mathrm { ( S O _ { 4 } ^ { \bullet 1 } ) }$ and hydroxyl radicals (·OH) with strong redox potentials and relatively long half-lifetime, which facilitate rapid degradation of a wide range of contaminants. However, the reactivity of these radical species is often compromised under realistic water matrices, where competitive side reactions may diminish the oxidation efficiency.[3,4] Alternatively, persulfates can be selectively activation to yield non-radical oxidizing species, such as singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , which demonstrate remarkable stability under complex aqueous conditions. This non-radical pathway not only mitigates the risk of secondary pollution (formation of toxic byproducts) but also allows for more selective pollutant removal, offering distinct advantages for water treatment applications.[5]Consequently, to development catalyst that can effectively steering the reactive oxygen species (ROS) pathway toward non-radical $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , in response to a specific reaction environment, is essential for maximizing the applicability and adaptability of persulfatebased advanced oxidation processes in practical wastewater treatment scenarios.

Transition metal (TM)-based bimetallic catalysts, particularly spinel-type oxides $( \mathrm { A B } _ { 2 } \mathrm { O } _ { 4 } )$ , are widely recognized for their redox flexibility, robust stability, low cost, and environmental adaptability.[611] Sulfur modification of these oxides has further improved their catalytic efficiency, commonly attributed to increased oxygen vacancies, improved electron/mass tanela  ciHover structural and electronic implications of sulfidation, especially in terms of phase evolution and local coordination, remain largely underestimated. Notably, excessive sulfur incorporation has been reported to impede catalyst performance, which is attributed to hindered electron transfer or surface blockage of active sites due to surface sulfur accumulation.[1214] Yet, the substantial structural transformations induced by varying sulfur content are often overlooked. Specifically, the transition from spine-type oxides ${ \tt A B } _ { 2 } { \tt O } _ { 4 }$ to sulfides $\mathrm { A B } _ { 2 } \mathrm { S } _ { 4 }$ demands precise stoichiometric control, otherwise phase segregation may occur, resulting in the formation of a multi-component heterojunction structure with distinct interfacial properties.[15] These structural evolutions substantially alter the coordination environment, interfacial electronic landscape, and ultimately the catalytic behavior. Despite growing interest in these complex materials, the influence of phase heterogeneity and interfacial anion chemistry (e.g., bridging ${ \mathsf { O } } ^ { 2 - }$ vS. $S ^ { 2 - }$ on catalytic activity and ROS pathway selection remains insufficiently understood.

Spin-state regulation has recently gained attention as a key descriptor for catalytic reactivity in transition metal-based systems. The spin-state is closely associated with reactant adsorption strength, interfacial electron transfer kinetics, and the corresponding thermodynamics of the reaction.[16] For instance, it has been reported that enhanced spin delocalization at high-spin centers disperses spin density, and promotes the release or exchange of electrons, thereby favoring the generation of reactive radicals upon peroxymonosulfate (PMS) activation.[1719] Despite its importance, most investigations to date have focused on spin-state modulation within crystalline spinel lattices, where symmetric metal-oxygen-metal (M-O-M) bridges enforce relatively uniform coordination geometries and limit spin asymmetry. In contrast, the introduction of sulfur, with its more diffuse $3 p$ orbitals and lower electronegativity of $S ^ { 2 - }$ $( \chi = 2 . 5 8 )$ relative to oxygen is expected to fundamentally reshape the local electronic and establish a markedly different spin landscape compared to conventional metal oxides. As such, sulfur incorporation in bimetallic sulfides is expected to drive distinct spin-state distributions that modulate electron transfer dynamics and influence the selection between radical and non-radical PMS activation pathways.

More importantly, in heterogeneous catalysis, spin-state modulation has typically been explored within single-phase or structurally uniform systems (e.g., spinels), leaving a substantial knowledge gap regarding how spin modulation manifests and governs reactivity in complex, multiphase bimetallic systems (e.g., heterojunctions). Typically, spinel structure features a more homogeneous distribution of metal cations within a rigid lattice, enforces relatively symmetric coordination environments, and limits variability in spin-state modulation. In comparison, the less constrained coordination in heterojunctions allows greater availability in adjusting spin-states due to its unique interfacial domains/phase boundaries, which offers a more accommodating platform for asymmetric spin-state modulation. Despite this potential, the implications of such asymmetric spin arrangements on ROS pathway selectivity and reaction dynamics remain poorly understood.

Herein, we employed a sulfur-assisted phase engineering strategy to construct cobalt-iron catalysts with tunable structural motifs, i.e., spinels $\mathrm { ( C o F e _ { 2 } O _ { 4 } }$ , ${ \mathrm { C o F e } } _ { 2 } { \mathrm { S } } _ { 4 } )$ and heterojunctions $( \mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ and $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } )$ . A combination of advanced characterization analysis and DFT calculations reveals that an asymmetric spin-state modulation is induced by sulfur incorporation, featuring electron-localized low-spin Co and spinpolarized S sites, forming a directional Co—S—Fe spin channel. This interfacial spin configuration promotes PCET, shifts the rate-determining step of PMS activation, and favors selective ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation. Accordingly, this study uncovers a previously underexplored mechanistic principle, i.e., in multiphase, structurally heterogeneous catalysts, spin-state modulation is not solely governed by metal identity or oxidation state, instead, it is deeply influenced by interfacial composition, bridging anions, and spin symmetry/asymmetry across adjacent domains. This work not only clarifies the intrinsic mechanism linking spin-state asymmetry with catalytic reactivity and pathway selectivity in complex bimetallic systems, but also provides a rational strategy for spintunable catalysts toward high-performance, selective advanced oxidation processes.

# 2. Results and Discussion

# 2.1. Sulfur-Assisted Phase Transition Regulation

A sulfur-assisted one-pot solvothermal synthesis strategy was developed to regulate the structural transformation of cobalt-iron sulfides from spine oxides to heterojunction sulfides (Figure 1a). Powder X-ray diffraction (XRD) revealed that, in the absence of thiourea, the product exhibits characteristic reflections of ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ (PDF# 221086), confirming the formation of a typical spinel structure (Figure 1b). At the high thiourea ratio (Co: thiourea $= 1 { : } 4$ , the diffraction pattern matches well with ${ \mathrm { C o F e } } _ { 2 } { \mathrm { S } } _ { 4 }$ spinel, indicating successful sulfurization into a spinel sulfide, which is consistent with the previous report.[20] Interestingly, Ferelated peaks consistently match $\mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ (PDF# 160713) across all sulfur conditions, suggesting that Fe preferentially forms thermodynamically stable mixed-valence sulfides even under Sdeficient environments. In contrast, Co-containing phases exhibit sulfur-dependent transformations. At moderate thiourea levels (Co: thiourea $= 1 { : } 2$ and 1:3), a mixed-phase structure is formed: CoS dominates at 1:2, generating a $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathbf { S } _ { 4 }$ heterojunction, while at 1:3, CoS progressively converts into $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 }$ , yielding a $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ heterojunction (Figure 1b). This transformation is evidenced by the gradual right-shift of the diffraction peak at ${ \approx } 3 1 ^ { \circ }$ (Figure 1b), indicating lattice transition driven by the redox flexibility of Co. Under S-deficient conditions, Co favors low-symmetry CoS, while higher sulfur availability promotes the formation of high-symmetry spinel-type phases $( \mathrm { C o } _ { 3 } \mathrm { S } _ { 4 } , \mathrm { C o F e } _ { 2 } \mathrm { S } _ { 4 } )$ .

To investigate the role of Fe in this transformation, ${ \mathrm { C o - S - F e } }$ sulfides with varied Fe content were synthesized under constant sulfur conditions. Increasing Fe content led to an enhancement of $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 }$ peaks and a corresponding decrease in CoS intensity (Figure S1a, Supporting Information), while in the absence of Fe, CoS was the dominant phase. The XRD patterns of the individual components ${ \mathrm { C o } } _ { 3 } { \mathrm { S } } _ { 4 }$ and $\mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ further verified this phase transition (Figure S1b, Supporting Information). These results suggest that $\mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ not only forms preferentially due to thermodynamic stability, but also serves as a structural scaffold and sulfur reservoir, promoting the stepwise transformation from CoS to $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 }$ , and enabling the construction of Co-based sulfide heterojunctions. High-resolution transmission electron microscopy (HRTEM) images and selected area electron diffraction (SAED) analyses further corroborate the phase evolution. ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ shows lattice fringes at 0.25 and $0 . 3 0 \ \mathrm { n m }$ (assigned to (311) and (220) planes, Figures S2a and S3a, Supporting Information), while $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathbf { S } _ { 4 }$ (Figures S2b and S3b, Supporting Information) and $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ (Figures S2c and S3c, Supporting Information) exhibit distinct dual-lattice structures, confirming heterojunction formation. The ${ \mathrm { C o F e } } _ { 2 } { \mathrm { S } } _ { 4 }$ shows lattice spacings consistent with spinel sulfide (Figures S2d and S3d, Supporting Information). Furthermore, energy dispersive spectroscopy (EDS) elemental mapping reveals the uniform distribution of Co, Fe, O, and S elements across all four samples, confirming the compositional homogeneity of the synthesized spinel and heterojunction phase (Figure S4, Supporting Information).

Importantly, those observations reveal an asymmetric spinstate modulation: low-spin, electron-localized Co centers are bridged by electron-delocalized sulfur atoms with a significant net spin moment. This spin asymmetry promotes the formation of a spin-polarized Co—S—Fe electron transport channel, enabling efficient interfacial charge transfer. Sulfur, with its partially filled $3 p$ orbitals, facilitates electron delocalization toward the Fermi level, unblocking spin channels connecting the cobalt cation and sulfur anion of the active site and enabling electron migration.[52,53] Meanwhile, the highly localized electrons in low-spin Co bring the $3 d$ -band center closer to the Fermi level (Figure 4b), enhancing antibonding orbital overlap with the $\pi ^ { * }$ orbitals (O—O bonds) of PMS (Figure 5d).[54] Furthermore, Electron Localization Function (ELF) calculations reveal that Co, O, and Fe in ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ tend to be electron localized, whereas in the bimetallic sulfides, Fe and S tend to be electron delocalized, while Co remains electron localized. This creates an ELF gradient at the Fe—S—Co interface, which is favorable for facilitating directional electron transfer (Figure 5e). Together, the resulting interfacial Co—S—Fe spin channel facilitates directional electron transfer from Fe and S to Co, and effective $\pi$ -back donation from the Co site to the $\mathrm { O - } \mathrm { O }$ bond in PMS, thereby promoting PMS activation and selective generate ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ .

To mechanistically rationalize the pathway selectivity between radical and nonradical oxidation, Gibbs free energy was calculated to compare the activation processes on the four catalysts. In the nonradical pathway, the adsorbed ${ \mathrm { H S O } } _ { 5 } { } ^ { - }$ undergoes simultaneous cleavage of the $\mathrm { O - } \mathrm { O }$ and polar $\mathrm { O - H }$ bond on the catalyst surface. The dissociated protons are easily captured by adjacent edge O atoms, leading to the formation of a high-valent Co $( \mathrm { I V } ) { = } 0$ intermediate and $\mathrm { H S O _ { 4 } } ^ { - }$ . The Co $( \mathrm { I V } ) { = } 0$ subsequently reacts with another PMS to form ${ } ^ { \ast } \mathrm { O O H }$ , which is immediately deprotonated to form $\mathrm { { } ^ { * } O O }$ , and finally desorption to form ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ (Figure 5f). Notably, in the $\mathrm { C o F e } _ { 2 } \mathrm { O } _ { 4 } \ @ \mathrm { P M S }$ system, the rate-determining step (RDS) is the formation of the high-valent Co $( \mathrm { I V } ) { = } 0$ intermediate $( ^ { * } { \mathrm { P M S } } \to { \mathrm { C o } }$ $( \mathrm { I V } ) { = } \mathrm { O } )$ . In contrast, for sulfur-containing catalysts such as $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathbf { S } _ { 4 }$ , the RDS shifts to a distinct pathway, where the desorption of the $\mathrm { { } ^ { * } O O }$ intermediate $( ^ { \ast } \mathrm { O O }  { ^ { 1 } \mathrm { O } _ { 2 } } )$ governs the reaction kinetics. This shift underscores the role of spin-polarized sulfur and high-spin Fe, specifically, electrons delocalized on sulfur and iron are transferred to low-spin cobalt through the Fe—S—Co electron spin channel, enhancing the local electric field and facilitating the proton-coupled electron transfer (PCET), which is thermodynamically favorable for $\mathrm { O - H }$ cleavage and stabilizes reactive intermediates.[55,56] The sulfur-mediated enhancement of the PCET process can be further explained by the retention of two electrons in the O 2p orbital upon $\mathrm { O - H }$ bond cleavage in PMS, which subsequently interacts with two additional electrons donated by the Co center to form $\scriptstyle \mathrm { C o = O }$ bond (Figure 5g). This electronic rearrangement is thermodynamically favorable for ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ formation and drives the nonradical pathway.

On the other hand, radical pathways were also evaluated. In this case, the adsorbed ${ \mathrm { H S O } } _ { 5 } ^ { - }$ accepts an electron directly from the Co atom to trigger the cleavage of the $\mathrm { O - } \mathrm { O }$ bond, generating $^ { * } \mathrm { O H }$ and $\mathrm { S O } _ { 4 } \mathrm { ^ { \cdot - } }$ rather than $\mathrm { H S O _ { 4 } } ^ { - }$ , and further desorption from $^ { * } \mathrm { O H }$ to form ·OH species (Figure ${ 5 } \mathrm { g } ;$ Figure S32, Supporting Information). The Gibbs free energy change of nonradical ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation from PMS is significantly reduced in $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ compared to ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , whereas the energy barrier for radical generation is the lowest in ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ , explaining its preference for radical-driven pathways. In summary, the sulfurmediated bimetallic phase transition enables site-specific spinstates tailoring, resulting in asymmetric spin distribution across the Co—S—Fe interface. The strong electron localization in lowspin cobalt, combined with the pronounced electron delocalization in spin-polarized sulfur, collaboratively establishes an efficient spin-selective transfer channel. This tailored spin configuration not only accelerates the formation and transformation of key intermediates like Co $( \mathrm { I V } ) { = } 0$ , but also selectively favors nonradical pathway via ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation, thereby offering a controllable route to optimize Fenton-like reactivity (Figure 5g).

# 2.5. Degradation Pathways and Environmental Applicability

To further understand how the tailored radical and nonradical pathways influence contaminant degradation, theoretical calculations based on DFT were used to identify potential reaction sites on SMX. The optimized SMX structure describes its electrostatic potential (ESP) distribution, where regions with negative ESP on the van der Waals surface correspond to electronrich sites prone to electrophilic attacks (Figure 6a,b).[57] According to frontier orbital theory, the spatial distribution of the highest occupied molecular orbital (HOMO) or the lowest unoccupied molecular orbital (LUMO) can be used to identify the site of electrophilic or nucleophilic attacks, respectively.[58] The HOMO orbital of SMX is primarily localized on the benzene ring and N. heterocyclic side, indicating their susceptibility to electrophilic attack. In contrast, the LOMO orbital is mainly concentrated on the sulfonyl group, suggesting its vulnerability to nucleophilic attack (Figure 6c). Given that SMX degradation in oxidation systems involves both non-free radical $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ and free radical $( { \bullet } \mathrm { O H } / { \mathrm { S O } _ { 4 } } ^ { { \bullet } - } )$ pathway, Fukui function $( f ^ { - } )$ analysis was performed to further evaluate the reactivity of individual atoms toward nucleophilic, electrophilic, and radical attacks.[59] Atoms with higher $f ^ { - }$ indices, specifically C1, C3, N11, N15, N16, S12, O13, O14, and 017, were identified as the most reactive centers likely to undergo attack by these oxidative species (Table S7, Supporting Information). These findings provide a molecular-level understanding of the degradation process and help pinpoint key transformation sites during catalytic oxidation.

To elucidate the degradation mechanism of SMX in the ${ \mathrm { C o S } } @ { \mathrm { F e } } _ { 3 } { \mathrm { S } } _ { 4 } @ { \mathrm { P M S } }$ system, intermediate products were identified by high-performance liquid chromatography-mass spectrometry (HPLC-MS), and the possible transformation pathway was proposed (Figure 6d; Figure S33-S38, and Table S8, Supporting Information). The oxidative degradation of SMX involves both electrophilic radicals ${ ( \mathrm { S O } _ { 4 } ) } ^ { \cdot - }$ and .OH) and nonradical species $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ , each initiating characteristic transformation pathways. Electrophilic radicals $\mathrm { ( S O _ { 4 } ) ^ { \cdot - } }$ , ·OH) typically attack electron-rich sites within the SMX molecule via three primary mechanisms: formation of free radical admixtures, extraction of hydrogen atoms, and single electron transfer. Fukui function analysis revealed that atoms including N11, N15, N16, O13, 014, and 017, with unsaturated states characterized by high $f ^ { - }$ values, are particularly susceptible to radical attack. Meanwhile, the non-radical oxidant ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ selectively reacts with electronrich unsaturated sites through electrophilic addition and electron extraction, due to its dual electron-donating and accepting capabilities. Specifically, N11, which exhibits the highest $f$ value (0.088), undergoes electrophilic substitution by hydroxyl groups to form TP1, followed by further oxidation to TP2. Alternatively, N11 can be oxidized to form the nitrification product (TP3), which then undergoes nucleophilic hydrolysis (C—S bond break) at the S12 position (with the highest $f ^ { + }$ value of 0.052), yielding classic SMX oxidation products TP4 and TP5. Subsequently, the sulfonyl group $( \mathrm { - S O } _ { 2 } \mathrm { N H - } )$ in TP5 is gradually hydroxylated to form TP6 and TP7. Alternatively, direct hydrolysis of the sulfonyl group $( \mathrm { - S O } _ { 2 } \mathrm { N H - } )$ in SMX can break $_ { \mathrm { N - S } }$ bond to form TP8, which subsequently undergoes hydroxylation to form TP9. In addition, the ${ \mathrm { C } } { \mathrm { - N } }$ bond cleavage near N15 with a $\operatorname { h i g h } f ^ { - }$ value (0.053), is vulnerable to electrophilic attack and yields TP10 and TP11. According to Fukui index analysis, the reactivity order within the benzene ring follows C3 $( 0 . 0 8 0 ) > \mathsf { C } 4$ (0.030), with C1 being saturated and less reactive toward nucleophilic addition. Therefore, C3 undergoes preferential hydroxylation to form TP14 by nucleophilic attack, which is to form TP15 and TP16 through sequential sulfonyl group transformation. The coupling process also plays a significant role in SMX removal. Hydrolysis-induced cleavage of the $_ { \mathrm { N - S } }$ bond, facilitated by electron-withdrawing effects from the para-sulfonamide group, leads to the formation of TP17 and TP18, which further self-coupling to produce TP19 and TP20, respectively. In addition, TP21 is likely formed via the coupling of two SMX molecules through their amino groups due to the N11 with a noticeable $f ^ { + }$ value (0.049), followed by hydroxylation to yield TP22.[60,61]

To evaluate the environmental impact of SMX and its intermediates, the Toxicity Estimation Software Tool (T.E.S.T.) was used to predict both acute (short-term) and chronic (long-term or delayed) toxicity toward aquatic organisms, including fish, daphnids, and green algae. Significantly lower than the parent SMX, most intermediates showed low risk to fish, daphnids, and green algae (Figure 6e). Additionally, assessments of persistence, mobility, and bioaccumulation revealed that the majority of intermediates were less persistent and less mobile than SMX, while bioaccumulation potentials remained largely unchanged (Figure S39, Supporting Information). More importantly, the biological toxicity of the treated solution was further evaluated by culturing Chlorella vulgaris in the SMX degradation solution. Measurements of photosynthetic maximum efficiency $( \mathrm { F _ { v } } / \mathrm { F _ { m } } )$ , optical density (OD), and chlorophyll content showed a marked increase following PMS treatment, indicating a significant reduction in biotoxicity (Figure 6f; Figure S40, Supporting Information). Thus, the overall toxicity, persistence, and mobility of SMX degradation in water usually decrease with the production of low ecotoxicity intermediates, which also indicates that the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ system effectively mitigates the ecotoxicity of antibiotics and is environmentally friendly. The environmental impacts and operating cost of the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ system were evaluated via life cycle assessment (LCA) and economic analysis, respectively, and benchmarked against the homogeneous $\mathrm { F e } ^ { 2 + } @ \mathrm { P M S }$ and $\mathbf { C o F e } _ { 2 } \mathbf { O } _ { 4 } @ \mathbf { P } \mathbf { M } \mathbf { S }$ systems. The results indicate that the ${ \mathrm { C o S } } @ { \mathrm { F e } } _ { 3 } { \mathrm { S } } _ { 4 } @ { \mathrm { P M S } }$ system exhibits superior environmental friendliness, as evidenced by lower impact scores for various descriptive indicators related to current wastewater treatment processes, such as global warming and freshwater/marine eutrophication (Figure S41 and Tables S9S12, Supporting Information). In addition, economic analysis shows that when treating the same amount of SMX-containing wastewater (1.0 ton), the operation cost required by the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ system is significantly lower than that of the $\mathrm { F e } ^ { 2 + } @ \mathrm { P M S }$ and $\mathbf { C o F e } _ { 2 } \mathbf { O } _ { 4 } @ \mathbf { P } \mathbf { M } \mathbf { S }$ systems, confirming the economic feasibility of the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathbf { S } _ { 4 }$ catalyst (Figure S42, Supporting Information). These characteristics highlight the ${ \mathrm { C o S } } @ { \mathrm { F e } } _ { 3 } { \mathrm { S } } _ { 4 } @ { \mathrm { P M S } }$ system as an environmentally sustainable and scalable strategy for advanced wastewater remediation.

To assess the universality, stability, and practical application of the ${ \mathrm { C o S } } @ { \mathrm { F e } } _ { 3 } { \mathrm { S } } _ { 4 } @ { \mathrm { P M S } }$ system, further tests were conducted under diverse conditions. The effects of reaction parameters (PMS concentration, catalyst dosage, and SMX concentration) and water matrix $\mathrm { ( p H }$ , inorganic anions, and NOM) on the removal rate of SMX were studied (Figure S43, Supporting Information), indicating that the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ systems have good stability in complex water quality environments. Beyond SMX, the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ systems effectively degraded a range of common micropollutants, including levofloxacin (LEVO), sulfonamide (SDZ), ciprofloxacin (CIP), 4-chlorophenol (4-CP), and bisphenol A (BPA), demonstrating its broad applicability (Figure 6g; Figure S44, Supporting Information). In addition, the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathbf { S } _ { 4 }$ catalyst also displayed excellent reusability, maintaining over $90 \%$ SMX removal efficiency across five consecutive (Figure 6h). Importantly, the system retained high catalytic performance under different water matrices, including tap water, secondary effluent, and surface water collected from Furong Lake at Xiamen University. In all cases, near-complete SMX removal was achieved within $3 0 ~ \mathrm { m i n }$ (Figure 6i; Table S13, Supporting Information). When applied to actual medical wastewater, the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ system led to dramatic reduction in 3D fluorescence signals, highlighting its exceptional efficiency in eliminate organic pollutants and demonstrating outstanding water purification performance (Figure 6j). Thus, these results demonstrate that the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { P M S }$ system not only facilitates effective SMX degradation via optimized mechanistic pathways, but also mitigate ecological risk through the formation of low-toxicity, low-persistence intermediates, underscoring its environmental compatibility and strong potential for practical and sustainable applications in water purification and antibiotic pollution control.

# 3. Conclusion

In summary, this work uncovers the intrinsic mechanism by which sulfur-mediated phase transition and asymmetric spinstate modulation synergistically regulate PMS activation and ROS pathway selectivity in Co—Fe-based catalysts. By employing a sulfur-assisted solvothermal strategy, a controllable structural evolution from spinel phase $\mathrm { ( C o F e _ { 2 } O _ { 4 } }$ and ${ \mathrm { C o F e } } _ { 2 } { \mathrm { S } } _ { 4 } )$ to heterojunction structures $( \mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 }$ and $\mathrm { C o } _ { 3 } \mathrm { S } _ { 4 } @ \mathrm { F e } _ { 3 } \mathrm { S } _ { 4 } )$ was achieved, which altered the coordination environment and spinelectronic properties of the catalytic interface. Comprehensive characterizations and DFT calculations revealed that sulfur incorporation induces low-spin Co and generates spin polarization on the bridging S atoms, collectively enabling the formation of a Co—S—Fe electron spin channel, which promotes an internal electric field to trigger the PCET processes, thereby enabling efficient and selective generation of $^ 1 { \mathsf { O } } _ { 2 }$ . Notably, the introduction of sulfur not only facilitates electron transfer but also modulates the reaction kinetics, i.e., altering the rate-determining steps from the radical $^ { * } \mathrm { P M S } {  } ^ { * } \mathrm { O H } { + } \mathrm { S O } _ { 4 } { ^ { - } }$ (in spinel oxides) to non-radical pathways $^ { * } { \mathrm { P M S } } {  } { \mathrm { C o } }$ $( \mathrm { I V } ) { = } 0$ (in sulfides), and effectively lowering the energy barrier for non-radical ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ pathway activation. Furthermore, the $\mathrm { C o S } @ \mathrm { F e } _ { 3 } \mathbf { S } _ { 4 }$ catalyst with a marked environmental friendliness (LCA) exhibited superior activity, reusability, and adaptability across various water matrices, outperforming most advanced heterogeneous Fenton-like catalyst systems in degrading refractory organic contaminants. Importantly, this study sheds light on a frequently underestimated mechanistic dimension: in multiphase, structurally heterogeneous catalysts, spinstate modulation is not solely governed by metal identity or oxidation state, but is fundamentally influenced by interfacial composition, the nature of bridging anion (e.g., S vs. O), and the asymmetry of spin distribution across phase domains. These findings emphasize the central role of asymmetry spin-state modulation in dictating ROS selectivity and open new avenues for designing spin-tunable, phase-engineered bimetallic catalysts for advanced environmental remediation.
