## 七、已知问题

### 轻微问题(不影响运行)
1. **工具类导入挂起** - 在测试脚本中导入某些工具类可能挂起
   - **原因**: 可能存在循环导入或Session对象问题
   - **影响**: 不影响CrewAI运行时调用
   - **解决方案**: 已优化PubChem工具,移除Session对象

2. **Materials Project API间歇性403** - 偶尔遇到Cloudflare阻止
   - **原因**: API Key过期或IP临时阻止

## 十、部署清单

### 环境要求
- ✅ Python 3.10+
- ✅ 网络连接(访问外部API)
- ✅ 足够的内存(建议4GB+)

### 必需配置
- ✅ `QWEN_API_KEY` - Qwen LLM API
- ✅ `MATERIALS_PROJECT_API_KEY` - Materials Project API
- ✅ `ENABLE_TOOLS=true` - 启用工具调用

### 可选配置
- ⚠️ `MOLPORT_API_KEY` - 商业可获得性查询
- ⚠️ `PUBCHEM_API_KEY` - 提高PubChem请求速率

### 依赖安装
```bash
pip install -r requirements.txt
```

### 启动命令
```bash
python scripts/main.py
```
