# . Introduction

In recent years, antibiotics have been developed and used extensively as pharmaceuticals and personal care products (PPCPs), posing a threat to aquatic life and human health [13]. Tetracycline (TC), the common antibiotic, is now found in surface and groundwater as well as drinking water due to its stable chemical structure and resistance to biodegradation [4]. Advanced oxidation processes (AOPs) based on the activation of peroxymonosulfate (PMS), due to their high degree of mineralization, produce reactive oxygen species (ROS) with high redox potential, such as hydroxyl radicals (•OH, 1.82.7 VNHE) and sulfate radicals $( \mathrm { S O } _ { 4 } ^ { \bullet - }$ , 2.63.1 VNHE), which are helpful in the removal of these organics [5,6]. Studies have shown that transition metal ions can activate PMS at room temperature to produce reactive oxygen species (ROS) for efficient removal of organic pollutants in water. Among these reported transition metal ions, cobalt ions has the highest activation efficiency [7]. However, the problematic recycling of homogeneous catalysts and the caused secondary pollution to the environment severely limit the application of cobalt ions in the PMS activation. Therefore, the design of efficient heterogeneous cobalt-based catalysts has become the research focus.

Recent research has been devoted to the preparation of novel MOFsbased materials with magnetic or core-shell structures, which have shown excellent performance in the catalytic degradation of organic pollutants [8,9]. MOFs are a new type of hybrid crystals with porous structures, which are formed by coupling inorganic metal ions/clusters with organic ligands [10]. Furthermore, MOFs have tunable chemical components, complex structures, and abundant derivatives (e. g. carbonaceous materials or metal oxides) that allow environmental remediation through a wide variety of versatile adsorption/catalytic sites [11,12]. ZIF-67 is one of the cobalt-based MOFs. The previous studies demonstrated that the nitrogen-rich ZIF-67 is a suitable precursor for the preparation of N-doped carbon and metal Co nanoparticles [13]. Although many outstanding achievements have been made in MOFs-derived cobalt-based heterogeneous nanocatalysts for AOPs, there are still some problems including the recovery of nanocatalysts and the leaching of metal ions [14], which will limit their large-scale use for AOPs in actual water treatment. To immobilize these heterogeneous nanocatalysts on carriers is one of the ways to solve these problems.

Various carriers, such as copper foam [15], ion exchange resins [16], and grapefruit peel [17], have recently been tried to immobilize ZIF-67 for the fabrication of recyclable heterogeneous cobalt-based catalysts in the activation of PMS to remove organic contaminants from water. However, these reported carriers are usually inactive, and part of the carriers will be destroyed in the heat-treatment process of ZIF-67. Therefore, developing high-quality carriers for the immobilization of heterogeneous cobalt-based nanocatalysts is still a significant challenge.

Considering the above conditions, the ideal substrate for the loaded MOFs-derived catalysts must also meet two criteria: 1) conductive to transfer the electrons generated in AOPs, and 2) resistant to pyrolysis for preparing cobalt-based catalysts [18]. Carbon cloth (CC) is ideal for ZIF-67 carrier as a flexible carbon-based carrier with good high conductivity, and excellent chemical and thermal stability [19]. Therefore, here $\mathrm { C o @ C }$ core-shell nanostructures were immobilized on the surface of CC by the pyrolysis of ZIF-67-modified CC. The catalytic degradation ability of the obtained $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ composite was evaluated by activating PMS to degrade TC. The effects of various experimental parameters on the degradation of TC were discussed. In addition, the degradation mechanism of TC was explored by scavenger quenching experiments and electron paramagnetic resonance (EPR) spectroscopy. The possible degradation pathway of TC was proposed by DFT. Finally, the cycle stability of $\mathrm { C o @ C / C C }$ catalyst and its potential in the actual water bodies were evaluated.

After $^ { 1 2 \mathrm { ~ h ~ } }$ of growth under room temperature, the CC was taken out from the solution and dried at $6 0 ^ { \circ } \mathrm { C }$ The uniform purple precipitation can be observed on the surface of CC.

The CC obtained above was placed in a tube furnace and heated to $4 5 0 ~ ^ { \circ } \mathrm { C }$ from room temperature with a heating rate of $2 \mathrm { ~ } ^ { \circ } \mathrm { C } / \mathrm { m i n }$ under an $\Nu _ { 2 }$ atmosphere. # 2.4. Catalytic degradation of TC

All degradation experiments were carried out at room temperature. Seven $\mathrm { C o @ C / C C }$ pieces (area of each piece is $1 \mathrm { c m } \times 1 \mathrm { c m } )$ were placed in a $2 5 0 ~ \mathrm { m L }$ brown beaker with $1 0 0 ~ \mathrm { { m L } }$ of TC solution $( \mathrm { C } _ { 0 } = 2 0 \mathrm { m g / L } )$ and stirred magnetically at $4 0 0 \mathrm { r p m }$ . Then, PMS was immediately added to the above solution to start the reaction. At the set time point, $3 \mathrm { m L }$ of the solution was drawn out using a tubular extraction unit equipped with a $0 . 2 2 \mu \mathrm { m }$ filter membrane, and the degradation reaction was immediately terminated using $0 . 5 ~ \mathrm { m L }$ methanol. The concentration of residual TC was determined using high performance liquid chromatography (HPLC, Agilent 1290 II-6460). The initial pH of the TC solution was adjusted using 0.1 M $\mathrm { H _ { 2 } S O _ { 4 } }$ or 0.1 M KOH solution. To explore the stability of the catalysts, the used catalysts were rinsed with $1 0 0 ~ \mathrm { { m L } }$ of ethanol and $5 0 0 ~ \mathrm { m L }$ of deionized water, and finally dried $6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ . The degradation efficiency (D.E) was calculated as follows (Eq. 1):

$$
\mathrm { D . E } ( \% ) = \frac { \left( \mathrm { C } _ { 0 } - \mathrm { C _ { t } } \right) } { \mathrm { C } _ { 0 } } \times 1 0 0 \%
$$

where ${ \bf C } _ { 0 }$ and $\mathbf { C _ { t } }$ (mg/L) are the initial concentration of TC and the concentration of TC after the degradation reaction, respectively.

# 3.3. Effect of vital reaction factors on TC degradation

# 3.3.1. Effects of experimental parameters

The effects of critical experimental parameters, including TC concentration, PMS dosage, reaction temperature, initial pH, and catalyst dosage are essential for the generated ROS and contaminant decomposition [28]. Fig. 3a shows that the degradation efficiency and rate decreased with the increase of TC concentration. When the TC concentration increases from 20 to $5 0 \mathrm { m g / L }$ , the degradation efficiency of TC decreases from $9 9 \%$ to $8 7 \%$ . Meanwhile, the reaction rate constant $( k )$ reduces gradually from $1 . 2 8 \times 1 0 ^ { - 2 }$ to $4 . 5 9 \times 1 0 ^ { - 3 } / s$ in Fig. S5a. It is mainly attributed to the generated ROS is not sufficient at the high concentration of TC. Fig. 3b exhibits that the TC degradation efficiency increases from $8 7 \%$ to $9 9 \%$ when the PMS dosage increases from 0.30 to $1 . 0 0 ~ \ g / \mathrm { L }$ . At the same time, the $k$ elevates from $5 . 1 9 \times 1 0 ^ { - 3 }$ to $1 . 2 8 \times 1 0 ^ { - 2 } / s$ (Fig. S5b). It is due to that high PMS dosage can provide more ROS, resulting in the improvement of TC degradation [29]. As the concentration of PMS further increases to $1 . 5 0 ~ \mathrm { g / L }$ , $k$ raises only to $1 . 3 3 \times 1 0 ^ { - 2 } / s ,$ which may be due to the saturation of the activation of PMS by the active sites on the catalyst surface, and the catalyst could not continue to activate the excess PMS even if the concentration of PMS continued to increase [30]. As presented in Fig. 3c, the degradation efficiency of TC increases significantly from $9 2 \%$ to $9 9 \%$ as the reaction temperature increases from $2 0 ^ { \circ }$ to $4 0 ^ { \circ } \mathrm { C }$ The $k$ also increases from $7 . 1 \bar { 5 } \times 1 0 ^ { - 3 }$ to $1 . 7 5 \times 1 0 ^ { - 2 } / s$ in Fig. S5c. It may be since higher temperature can promote the O-O breakage in PMS and facilitate the generation of ROS. In addition, higher temperature facilitates the reactants to overcome the reaction energy barrier and promote catalytic degradation [31]. According to the Arrhenius equation (Eq. 3) [5], the activation energy $\mathrm { ( E _ { a } ) }$ for TC degradation can be calculated.

Meanwhile, in solutions with higher alkalinity, catalysts generally have more negative charges and repel each other with PMS, resulting in less interaction between PMS and catalyst [38]. Therefore, when the solution pH increases, the degradation kinetics of TC decelerate significantly. In addition, the effect of $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ dosage on the degradation efficiency and the degradation rate of TC was also investigated in Fig. 3e and S5e. In the presence of one piece of $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalyst, $6 5 \%$ of TC is degraded and the degradation rate is $1 . 9 6 \times 1 0 ^ { - 3 } / s$ within $1 0 \mathrm { m i n }$ . # 3.4. Catalytic mechanism of TC degradation

ROS is the key in the catalytic degradation of organic pollutants. Generally, both free-radical $( \mathrm { S O } _ { 4 } ^ { \bullet - }$ , •OH and $\mathrm { O } _ { 2 } ^ { \bullet - }$ ) and non-radical paths can be observed in the Co-based catalyst activated PMS process. To distinguish between the radicals $\mathrm { S O } _ { 4 } ^ { \bullet - }$ and •OH, the dominant radical was determined by observing the difference in reaction rates with two types of alcohols. Methanol (MeOH) with three a-hydrogens can react rapidly with $\mathrm { S O } _ { 4 } ^ { \bullet - }$ and•OH $( k _ { \mathrm { { S O _ { 4 } ^ { * } } / M e O H } } = 2 . 5 \times 1 0 ^ { \dot { 7 } } / \mathrm { { M } } { \cdot } s$ $k _ { \bullet \mathrm { O H / M e O H } } =$ $9 . 7 \times 1 0 ^ { 8 } / \mathrm { M } { \cdot } s )$ and are usually used to scavenge both $\mathrm { S O } _ { 4 } ^ { \bullet - }$ and •OH [48]. In contrast, hydrogen-free tert-butyl alcohol (TBA) can react with •OH faster than $\mathrm { S O } _ { 4 } ^ { \bullet - }$ and selectively scavenge •OH. To further investigate the presence and contribution of different ROS in TC degradation, 5, 5-dimethyl-1-pyrrole N-oxide (DMPO) and 2, 2, 6, 6-tetramethyl-4-piperidinol (TEMP) were used as spin traps for EPR testing. # .Possible degradation pathway of TC

To reveal the possible degradation pathway of TC, it is necessary to determine the trend of electrophilic or nucleophilic attack of atoms in TC molecules. In theoretical speculation, the Fukui function is an essential concept in conceptual DFT. It is usually used to predict the regioselectivity of nucleophilic, electrophilic, and free radical attacks [59]. As shown in Fig. 7a-c, the Fukui exponent $( \mathbf { f } ^ { 0 } )$ and the electrostatic potential (ESP) contour plots were calculated using Materials Studio 2019. The higher the $\mathsf { f } ^ { 0 }$ value of the site indicates the greater the tendency for radical attack. The ESP distribution was also used to predict reaction sites, with negative regions (blue) and positive regions (red) predicting the reaction sites most likely to undergo reduction and oxidation reactions. Possible TC degradation sites were proposed based on the Fukui index and ESP calculations. As shown in Figs. 7b and 7c, the $\mathsf { f } ^ { 0 }$ values of C6 (0.026), C10 (0.034), C11 (0.026), C16 (0.025), N25 (0.032), and 020 (0.064), 022 (0.064), 026 (0.123) are higher than those of the same atoms, indicating that they are more easily attacked by free radicals [60].

Based on the results of DFT calculations, three pathways for TC degradation in the Co@C/CC/PMS system were proposed as shown in Fig. S7. In Path I, the $\mathrm { c } { = } \mathrm { c }$ bonds at the C(11) and C(16) are attacked to produce intermediate product A1, which continues through deamidation, decarbonisation, and ring-opening reactions before finally decomposing to A4 [10]. In Path II, N(25) is first attacked, which means that the amino group $\mathrm { ( N H _ { 3 } ) }$ in the formamide group is destroyed to produce product B1. Then the $\scriptstyle \mathrm { C = C }$ bond and carbonyl $\alpha$ -position of C (16) and C(17) are attacked to form B2 and B3, which eventually open the ring to form C3 [61]. In Path III, C(11) in TC and the hydroxyl group (-OH) are attacked to form C1 [62]. Then, C(16) is attacked to remove $\left( { \mathrm { - C O N H } } _ { 2 } \right)$ , followed by the destruction of the dimethylamine group (-N $\mathrm { ( C H _ { 3 } ) _ { 2 } ) }$ to give C2. Oxidation opens the ring and further decarbonizes to generate C3. C(10) is attacked by free radicals to obtain C4. Finally, all intermediates are entirely mineralized to $\mathrm { C O } _ { 2 }$ $_ \mathrm { H _ { 2 } O }$ , and small molecule products. As shown in Fig. S8, $4 7 \%$ of TOC was removed by the Co@C/CC/PMS system within $1 0 \mathrm { m i n }$ , further supporting the effective mineralization of TC.

# .Recoverabilityfcatalyst and applicability in theactual water body

The cycling stability of the catalyst is an important indicator to evaluate its potential in practical application. As shown in Fig. S9a, $9 9 \%$ of degradation efficiency for TC can be achieved in the initial cycle. However, only $5 4 \%$ , $4 4 \%$ and $4 3 \%$ of TC is degraded in the second, third and fourth cycle, respectively. This indicates that the catalyst' performance decreases significantly with the increase of process. According to previous studies, it is possible because the degradation products of TC cover the active sites on the surface of $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalyst, resulting in the decrease of its catalytic performance [63]. Subsequently, the used $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalysts after four cycles were heat-treated in $\mathrm { N } _ { 2 }$ atmosphere at $4 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } , }$ and the regenerated catalyst maintains high catalytic performance and the degradation efficiency of TC is $9 8 \%$ , which is close to the fresh catalyst. The fast and simple collection and regeneration processes are conductive to reducing the cost of $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalyst in practical application.

To verify the versatility of the prepared $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalysts, the degradation of other typical organic pollutants, such as AO7, MO, and CBZ, was also carried out in the $\mathrm { C o } @ \mathrm { C } / \mathrm { C C } / \mathrm { P M S }$ system. $9 4 \%$ of AO7, $9 7 \%$ of MO, and $8 1 \%$ of CBZ can be degraded within $1 0 \mathrm { m i n }$ , as shown in Fig. S9b. The above results reflect that the $\mathrm { C o @ C / C C }$ catalyst has good catalytic degradation performance for various organic pollutants, proving the universality of $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ in the removal of organic pollutant.

To further investigate the catalytic performance of $\mathrm { C o @ C / C C }$ catalysts in natural environments, a natural organic matter (NOM) of humic acid (HA) was selected to investigate the effect on the degradation of TC. Previous studies have shown that the inhibition of degradation by HA originates from the quenching effect on free radicals [64]. Fig. S9c demonstrates the obvious inhibition on the TC degradation in the presence of HA. When the concentration of HA increased from 0 to $1 0 0 ~ \mathrm { m g / L }$ , the degradation efficiency of TC decreased from $9 9 \%$ to $6 1 \%$ . In addition, to evaluate the practical application of the $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalyst, degradation experiments were conducted in river water and tap water. As shown in Fig. S9d, the removal efficiency of TC reached $9 6 \%$ in tap water and $8 8 \%$ in river water within $1 0 \mathrm { m i n }$ , indicating a good anti-interference capability of the $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ catalyst. Finally, the leaching of Co ion in the $\mathrm { C o } @ \mathrm { C }$ and $\mathrm { C o @ C / C C }$ systems was determined by ICP-MS. As presented in Fig. S10, the concentration of leached Co ions for $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ was $1 . 4 8 3 \mathrm { m g / L }$ within $1 0 \mathrm { m i n }$ , which is much lower than the bare $\mathrm { C o } @ \mathrm { C }$ of $3 . 1 9 6 ~ \mathrm { m g / L }$ . It suggests that the carrier of CC could enhance the stability of $\mathrm { C o @ C }$ core-shell structure, thus reducing Co ion leaching. In the $\mathrm { C o } @ \mathrm { C / C C / P M S }$ system, $9 8 \%$ of TC can be degraded within $5 \mathrm { { m i n } }$ , and the corresponding Co ion leaching is $0 . 9 4 3 \mathrm { m g / L }$ , which is lower than the emission standard of $1 \mathrm { m g } / \mathrm { L }$ (GB254672010, China). It further illustrates the potential of the Co@C/CC/PMS system in practical application for the rapid elimination of organic pollutants.

# 4. Conclusions

In this study, the immobilized $\mathrm { C o @ C / C C }$ catalyst was prepared from ZIF-67 modified carbon cloth (CC). Because of the carrier effect and excellent electrical conductivity of CC, the as-obtained immobilized catalyst of $\mathrm { C o } @ \mathbb { C } / \mathrm { C C }$ exhibits an improved catalytic activity and lower leaching of Co ions than the bare $\operatorname { C o } ( \varnothing \mathrm { C }$ nanocatalyst. The TC degradation efficiency in the $\mathrm { C o } @ \mathrm { C } / \mathrm { C C } / \mathrm { P M S }$ system reached $9 9 \%$ within $1 0 \mathrm { m i n }$ . The quenching experiment and EPR tests indicated the presence of the free radical oxidation pathway $( \mathrm { S O } _ { 4 } ^ { \bullet - }$ and •OH) and the nonradical oxidation pathway $( ^ { 1 } 0 _ { 2 } )$ in the degradation of TC, and the $^ 1 0 _ { 2 }$ is the dominate ROS. In addition, the $\mathrm { C o } @ \mathrm { C / C C / P M S }$ system exhibited good durability and interference resistance as well as wide pH range of 310. Importantly, the $\mathrm { C o @ C / C C }$ catalyst can be quickly collected and simply regenerated. This study provides a new idea for the preparation of efficient catalysts with easily recyclable for activating PMS in rapid elimination of organic pollutant from water.
