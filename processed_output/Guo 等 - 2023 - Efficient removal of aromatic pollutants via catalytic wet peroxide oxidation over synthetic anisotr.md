# ARTICLE OPEN Check fr updates Efficient removal of aromatic pollutants via catalytic wet peroxide oxidation over synthetic anisotropic ilmenite/carbon nanocomposites

Sheng Guo1 , Ran Huang2 , Jia Yuan1 , Rong Chen1,3 and Fengxi Chen 1✉

As one of the most common ferrous $( \mathsf { F e } ^ { 2 + } )$ -containing oxide minerals in the Earth’s crust, ilmenite $( \mathsf { F e T i O } _ { 3 } )$ is a potential low-cost heterogeneous Fenton-like catalyst for organic wastewater treatment via catalytic wet peroxide oxidation (CWPO). However, it suffers from low activity and long induction time. Herein anisotropic $\mathsf { F e T i O } _ { 3 } / \mathsf C$ nanocomposite with rich $\mathsf { F e } ^ { 2 + }$ ions on large surface area of $1 5 9 . 0 \ \mathsf { m } ^ { 2 } \ \mathsf { g } ^ { - 1 }$ (surface Fe/Ti and $\mathsf { F e } ^ { 2 + } / \mathsf { F e } ^ { 3 + }$ ratios were respectively 2.1 and 2.0) was prepared via cetyltrimethylammonium $( \mathsf { C T A } ^ { + } )$ -assisted sol-gel synthesis. $\mathsf { C T A } ^ { + }$ modulated the growth of $\mathsf { F e T i O } _ { 3 }$ nanoparticles with more exposed metallic sites by preferential adsorption on its (104) plane via electrostatic attraction, provided the carbon source and facilitated the generation of more $\mathsf { F e } ^ { 2 + }$ ions at the interface of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ via carbothermal reduction of $\mathsf { F e T i O } _ { 3 }$ . $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ efficiently catalyzed CWPO removal of six aromatic pollutants with different charges $( 2 5 \mathsf { m g L } ^ { - 1 }$ each) at $2 5 ^ { \circ } \mathsf { C }$ and $\mathsf { p H } 3 . 0$ without an induction period owing to rich $\mathsf { F e } ^ { 2 + }$ content on neutral surface $\{ \mathsf { p H } _ { \mathsf { p z c } } \sim 3 . 3 \}$ —three dye solutions completely decolorized in $^ { 1 \mathrm { { h } } }$ and three antibiotics degraded by ${ > } 9 0 \%$ in $^ { 3 \mathrm { h } }$ . Reusability of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ was demonstrated with cationic rhodamine B and anionic orange G dyes in five consecutive runs. Scavenging tests and spin-trapping EPR spectra confirmed the generation of dominant ·OH and minor ${ \sf O } _ { 2 } \dot { { \bf \mu } } ^ { - }$ species for organic degradation via catalytic decomposition of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ on $\mathsf { F e T i O } _ { 3 } / \mathsf C$ as a heterogeneous Fenton-like catalyst.

# INTRODUCTION

Recalcitrant aromatic compounds (e.g., ionic dyes and pharmaceuticals shown in Table 1) constitute a major type of organic pollutants in wastewater. Ionic dyes are extensively used in textile, paper, leather, personal care and food processing industries1 , whereas emerging pharmaceutical pollutants such as tetracycline and metronidazole are indispensable antibiotics in daily life. Their untreated effluents are not only aesthetically undesirable, but also harmful to water users due to potential CMR or other chronic biological effects (CMR for carcinogenicity, mutagenicity and toxicity for reproduction).

Various treatment technologies (physical, biological or chemical) have been explored to remove aromatic pollutants. Among these, physical adsorption only transfers toxic pollutants from solution to solid, which requires further treatment of contaminated adsorbents, and biological processes are not suitable for toxic or non-biodegradable pollutants. Therefore, catalytic wet peroxide oxidation (CWPO) has attracted wide attention for organic wastewater treatment2,3 . In this aspect, most organic pollutants can be effectively degraded via Fenton oxidation, wherein hydroxyl radicals (•OH) with high redox potential $( \sim 2 . 8 0 \lor )$ are in-situ generated by ferrous ions $( \mathsf { F e } ^ { 2 + } )$ - catalyzed decomposition of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ according to Eq. 1. However, the conventional Fenton process generates undesired iron sludge with high-color effluent since it uses soluble inorganic ferrous salts (e.g., $\mathsf { F e S O } _ { 4 } . 7 \mathsf { H } _ { 2 } \mathsf { O } )$ as homogeneous catalysts. Therefore, many efforts have been devoted to the development of efficient heterogeneous Fenton-like catalysts for sustainable remediation of organic wastewater2–4 .

$$
\mathsf { F e } ^ { 2 + } + \mathsf { H } _ { 2 } \mathsf { O } _ { 2 } \to \mathsf { F e } ^ { 3 + } + \bullet \mathsf { O H } + \mathsf { O H } ^ { - }
$$

Ilmenite $( \mathsf { F e T i O } _ { 3 } )$ is one of the most common $\mathsf { F e } ^ { 2 + }$ -containing 3 oxide minerals in the Earth’s crust5–10. Its catalytic applications have attracted much attention because of its good structural stability and low toxicity11–13. The $\mathsf { F e } ^ { 2 + }$ ions in $\mathsf { F e T i O } _ { 3 }$ are expected to act as Fenton-like active species for catalytic decomposition of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ to generate •OH via Eq. 1, which has been well demonstrated in other $\mathsf { F e } ^ { 2 + }$ -containing oxides such as $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } { } ^ { 1 4 - 1 9 }$ . Therefore, with ${ \sim } 3 6 . 8 ~ \mathsf { w t \% }$ of structural $\mathsf { F e } ^ { 2 + }$ ions, ilmenite would be a potential earth-abundant, low-cost, active and stable heterogeneous Fenton-like catalyst12,13. However, its two main drawbacks in relation to a long induction period (e.g., a $^ { 3 \mathrm { h } }$ induction time in CWPO of phenol at $\mathsf { p H } 3$ and $2 5 ^ { \circ } C ^ { 1 2 } )$ and low activity (e.g., slow decomposition rate of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ at $( 1 - 3 ) { \times } 1 0 ^ { - 3 } \operatorname* { m i n } ^ { - 1 }$ on natural ilmenite at $\mathsf { p H } 3$ or $7 ) ^ { 3 , 2 0 }$ seriously restrict its practical applications in CWPO. In addition, only limited model pollutants (usually phenol) have been used to assess the catalytic performance of $\mathsf { F e T i O } _ { 3 }$ while other pollutants remain largely unexplored so far.

Several methods have been developed to overcome the drawbacks of natural ilmenite. $\mathsf { F e I i O } _ { 3 }$ -based CWPO processes were strengthened by increasing the reaction temperature— complete conversion of $1 0 0 \mathrm { m g } \mathsf { L } ^ { - \overline { { 1 } } }$ phenol in $4 \mathsf { h }$ with $7 1 \%$ of TOC removal after reacting with $5 0 0 \mathrm { m g } \dot { \mathsf { L } } ^ { - 1 } \mathsf { H } _ { 2 } \mathsf { O } _ { 2 }$ over $1 \mathsf { g L } ^ { - 1 } \mathsf { F e T i O } _ { 3 }$ at $\mathsf { p H } 3$ and $7 5 ^ { \circ } C ^ { 3 }$ . However, high temperatures need more energy input and increase the process cost. Photo-assistance may improve the oxidation rates of CWPO processes based on $\mathsf { F e T i O } _ { 3 }$ or its composite (e.g., $\mathsf { F e T i O } _ { 3 } / \mathsf { T i O } _ { 2 } )$ via expediting redox cycling of $\mathsf { F e } ^ { 3 + } / \mathsf { F e } ^ { 2 + }$ or by facilitating the generation of more reactive species (e.g., •OH or superoxide radicals $( 0 _ { 2 } ^ { \cdot - } ) ) ^ { 3 , 1 2 , 1 3 , 2 1 , 2 2 } )$ ). However, external light sources are required in photo-assisted CWPO, which still hinders the applications of $\mathsf { F e T i O } _ { 3 }$ on large scale. It was also reported that the decrease in iron oxidation state on the ilmenite surface improved its catalytic activity13. The amount of low-valent iron (Fe(II) and $\mathsf { F e } ( 0 ) )$ on the surface increased upon reduction of raw ilmenite with ${ \sf H } _ { 2 }$ in the temperature range of $2 5 { - } 1 0 0 0 ^ { \circ } \mathsf C ,$ which in turn increased the decomposition rate of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ and generated more •OH radicals for higher oxidation rates of organic contaminants13. However, it is difficult to obtain $\mathsf { F e T i O } _ { 3 }$ with surface-enriched low-valent iron species without post-treatment due to their inherent instability under ambient conditions.

Synthetic $\mathsf { F e T i O } _ { 3 }$ particles can be prepared by solid-state reactions, hydrothermal syntheses and sol-gel methods. The products made via solid-state reactions (including mechanochemical milling) are usually impure or in homogeneous21,23. Hydrothermal syntheses of $\mathsf { F e I i O } _ { 3 }$ in closed autoclaves require high reaction temperature and high autogenous pressure with safety concern (e.g., $2 2 0 ^ { \circ } \mathsf { C }$ for $1 0 \bar { \mathsf { h } } ^ { 2 2 , 2 4 , 2 5 } )$ . In comparison, the sol-gel method is easier to perform21,26–28, in which a gel precursor is first prepared by a sol-gel process, followed by thermal annealing at suitable conditions (e.g., $70 0 ^ { \circ } \mathsf { C }$ for $\boldsymbol { 1 0 } \boldsymbol { \mathrm { h } }$ in ${ \mathsf N } _ { 2 } ^ { 2 1 }$ , or $6 0 0 ^ { \circ } \mathsf { C }$ for $^ { 2 \mathsf { h } }$ in air26). In addition, some functional organic additives (e.g., polymers and surfactants) can be included into the gel precursor to adjust the particle size, morphology and homogeneity of the obtained $\mathsf { F e T i O } _ { 3 }$ after pyrolysis.

In this work, a cationic surfactant cetyltrimethylammonium $( \mathsf { C T A } ^ { + } )$ bromide (denoted as CTAB) was added during the formation of the gel precursor. CTAB is a well-known template for the synthesis of siliceous M41S-type mesoporous materials via interfacial self-assembly between $\mathsf { C T A } ^ { + }$ and negatively charged siliceous species29. Herein CTAB was employed to modulate the growth of $\mathsf { F e T i O } _ { 3 }$ nanoparticles via preferential adsorption. To promote electrostatic interaction at the interface between inorganic species and $\mathsf { C T A } ^ { + }$ , it is critical to carry out the hydrolysis and condensation of iron and titanium sources under basic condition, which results in negatively charged inorganic species. The acidic condition used in the reference26 (pH adjusted by ${ \mathsf { H N O } } _ { 3 }$ to 1–2) led to positively charged inorganic species, which is not beneficial for its interaction with $\mathsf { C T A } ^ { + }$ due to electrostatic repulsion. Triethylamine (TEA) was found to be a suitable organic base without introducing other metal impurities for the preparation of $\mathsf { F e I i O } _ { 3 }$ nanoparticles upon pyrolysis of the gel precursor at $700 \text{‰}$ . TEA has been used as a template for the synthesis of microporous aluminophosphate molecular sieves (e.g., AlPO4- ${ \cdot } 5 ^ { 3 0 }$ , ${ \mathsf { S A P O } } { \cdot } 3 4 ^ { 3 1 { , } 3 2 }$ ) or nanocalix Ln(12) clusters of diacylhydrazone33), as an etching agent for post-synthesis of hierarchical ${ \mathsf { S A P O } } - 3 4 ^ { 3 4 }$ , or as a basic complexing agent for the formation of lanthanide (hydro)oxide nanorods35,36. In addition, CTAB serves as a carbon source upon pyrolysis to make $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ nanocomposites. More importantly, in-situ generated carbon partially reduced $\mathsf { F e } ^ { 3 + }$ to $\mathsf { F e } ^ { \dot { 2 } + }$ at the $\mathsf { F e T i O } _ { 3 } ,$ /carbon interface at high temperature in ${ \mathsf { N } } _ { 2 } { } ^ { 3 7 }$ , which results in $\mathsf { F e I i O } _ { 3 }$ nanoparticles with rich $\mathsf { F e } ^ { 2 + }$ ions on large surface area for enhanced activity in CWPO.

Some differences were discernable in Fig. 1(a–c). Firstly, a peak at $2 \Theta = 2 7 . 5 ^ { \circ }$ appeared in the XRD pattern of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } - 1 . 3 3$ (Fig. 1a inset), which was assigned to the (110) diffraction of rutile $\mathsf { T i O } _ { 2 }$ (PDF #84-1284). Due to higher CTAB concentration $( \sim 1 0 \mathrm { \ w t \% } )$ used in the synthesis of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } - 1 . 3 3$ , CTAB micelles were formed with some TBOT molecules solubilized in the hydrophobic micellar core, which led to the formation of separate $\mathrm { T i O } _ { 2 }$ phase as minor impurity in $\mathsf { F e T i O } _ { 3 } / \mathsf { C } - 1 . 3 3$ . Secondly, the (012) and (110) peaks of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - } 0 . 6 7$ synthesized with lower CTAB concentration ${ \cdot } ^ { \sim 5 }$ wt $\%$ ) were intensified with regard to the (104) peak $( \mathsf { I } _ { 0 1 2 } \mathsf { : } \mathsf { I } _ { 1 0 4 } \mathsf { : } \mathsf { I } _ { 1 1 0 } =$ 0.5:1.0:1.0 in Fig. 1b) while the relative XRD peak intensities in Fig. 1c for $\mathsf { F e T i O } _ { 3 } / \mathsf { C } { - } 0 ,$ which was $\mathsf { F e I i O } _ { 3 }$ synthesized without the addition of CTAB, were very close to the standard diffraction data of $\mathsf { F e T i O } _ { 3 }$ $( \mathsf { I } _ { 0 1 2 } ; \mathsf { I } _ { 1 0 4 } ; \mathsf { I } _ { 1 1 0 } = 0 . 3 ; 1 . 0 ; 0 . 7 )$ . This indicates larger growth rates of the (012) and (110) planes than that of the (104) plane in CTAB-assisted sol-gel synthesis of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - } 0 . 6 7 _ { i }$ , which was attributed to preferential adsorption of $\mathsf { C T A } ^ { + }$ cations on the (104) plane of $\mathsf { F e T i O } _ { 3 }$ .

To examine the adsorption of $\mathsf { C T A } ^ { + }$ on different crystal planes of $\mathsf { F e T i O } _ { 3 } ,$ the $\mathsf { F e T i O } _ { 3 }$ lattice was cleaved along (104), (012) and (110) planes, respectively, using Materials Studio 7.0 (Fig. 2). The crystal structure of $\mathsf { F e I i O } _ { 3 }$ was imported from the reference. 38. As displayed in Fig. 2a, the top layer of the cleaved (104) plane exclusively comprises lattice oxygen $( \mathsf { O } _ { \mathsf { L } } , \mathsf { O } ^ { 2 - } )$ with the density of $5 0 _ { \mathrm { l } }$ per $\mathsf { n m } ^ { 2 }$ , which favors the adsorption of $\mathsf { C T A } ^ { + }$ due to electrostatic attraction between $\mathsf { C T A } ^ { + }$ and surface ${ \mathsf { O } } ^ { 2 - }$ . Therefore, the growth of the (104) plane is restricted by the adsorbed $\mathsf { C T A } ^ { + }$ . In comparison, the top layer of the cleaved (012) plane has a lower $\mathsf { O } _ { \mathsf { L } }$ density $( 3 0 _ { \mathrm { L } }$ per $\mathsf { n m } ^ { 2 }$ , Fig. 2b). As such, the growth of the (012) plane is less inhibited by the adsorbed $\mathsf { C T A } ^ { + }$ . On the other hand, the top layer of the cleaved (110) plane mainly contains metal (Fe and Ti) cations with atomic ratios of 2Fe:2Ti:1 O (Fig. 2c). The positively charged (110) top surface is unbeneficial for the adsorption of $\mathsf { C T A } ^ { + }$ due to electrostatic repulsion. Therefore, the addition of $\mathsf { C T A } ^ { + }$ has little impact on the (110) growth. The unhindered growth of the (110) plane exposes more metallic ions on the particle surface, which serve as active sites for the activation of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ on $\mathsf { F e T i O } _ { 3 } / \mathsf C$ .

The $\mathtt { T G } /$ DSC analysis of the gel precursor in $\mathsf { N } _ { 2 }$ (Fig. 3) revealed that it underwent mass loss in three stages. The first stage up to $1 4 5 ^ { \circ } \mathsf C$ lost $7 . 6 \%$ of the initial mass accompanied by a small endothermic peak at $9 8 ^ { \circ } \mathsf { C }$ in the DSC curve, which was mainly attributed to the loss of residual ethanol and water in the precursor. The carbon content in $\mathsf { F e T i O } _ { 3 } / \mathsf C$ was determined by EDX to be $1 1 . 5 { \pm } 1 . 9 \mathsf { w t } \%$ (Fig. 4a). The characteristic D band at $1 3 5 0 \mathsf { c m } ^ { - 1 }$ (disordered carbon) and G band at $1 5 8 8 ( c m ^ { - 1 }$ (graphitic carbon) were observed in the Raman spectrum of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ (Fig. $4 \mathrm { b } ) ^ { 3 9 - 4 2 }$ The large area ratio of $\mathsf { D }$ to $\sf G$ band $( \mathsf { A } _ { \mathsf { D } } / \mathsf { A } _ { \mathsf { G } } ; ~ 3 . 5 )$ indicates the existence of abundant defect sites in $\mathsf { F e T i O } _ { 3 } / \mathsf C$ . $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ exhibited a type IV ${ \Nu } _ { 2 }$ adsorption-desorption isotherm with an H3-type hysteresis loop in the relative pressure $( \mathsf { P } / \mathsf { P } _ { 0 } )$ range from 0.6 to 1.0 due to capillary condensation inside the secondary inter-particle mesopores (Fig. 4c). $\mathsf { F e T i O } _ { 3 } / \mathsf C$ had a larger specific surface area $( \mathsf { S } _ { \mathsf { B E T } } ; 1 5 9 . 0 \mathsf { m } ^ { 2 } \mathsf { g } ^ { - 1 } )$ ) than natural ilmenite (1.7- $6 \ \mathsf { m } ^ { 2 } \ \mathsf { g } ^ { - 1 1 2 , 1 3 , 2 0 } )$ and other synthetic $\mathsf { F e T i O } _ { 3 }$ nanoparticles (e.g., $5 8 . 4 ~ \mathsf { m } ^ { 2 } ~ \mathsf { g } ^ { - 1 }$ for $\mathsf { F e T i O } _ { 3 }$ hollow spheres44, $1 3 9 . 5 ~ \mathsf { m } ^ { 2 } \mathsf { g } ^ { - 1 }$ for $\mathsf { F e T i O } _ { 3 }$ nanohexagons45). The average pore diameter $\mathsf { D } _ { \mathsf { p } }$ in $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ was estimated to be $8 . 8 \mathsf { n m }$ by $\mathsf { D } _ { \mathsf { p } } = 4 0 0 0 \mathsf { V } _ { \mathsf { P } } / \mathsf { S } _ { \mathsf { B E T } } ,$ where the pore volume ${ \mathsf { V } } _ { \mathsf { p } }$ is $0 . 3 5 ~ { \mathsf { c m } } ^ { 3 } ~ { \mathsf { g } } ^ { - 1 }$ . The larger $S _ { \mathsf { B E T } }$ and $\mathsf { D } _ { \mathsf { p } }$ values of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ are beneficial for rapid mass transport of reactants to access large amounts of surface active sites for enhanced adsorption and catalysis.

The ${ \mathsf { p H } } _ { \mathsf { p z c } }$ of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ was determined to be 3.30 (Fig. 4d). It renders the surface of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ particles nearly neutral or slightly positive charge at the typical pH value $( \sim 3 )$ used in Fenton oxidation, which is critical for wide applications of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ in the degradation of organic pollutants with different charges via CWPO.

The elemental composition and chemical states on the surface of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ were characterized by XPS. The XPS survey spectrum in Fig. 6a confirmed the presence of Fe, Ti, O, C and N elements on the surface with the atomic ratio of $2 . 1 \mathsf { F e } : 1 . 0 \mathsf { T i } : 3 . 3 \mathsf { O } : 8 . 5 \mathsf { C } :$ $0 . 5 0 \mathsf { N }$ . The asymmetrical C 1 s peak (Fig. 6b) were deconvoluted into three peaks at 284.5, 285.8 and $2 8 8 . 9 \mathsf { e V } ,$ which could be assigned to the C–C, C–N and C–O bonds, respectively46. Two weak peaks at 398.2 and $4 0 0 . 5 \ : \mathrm { e V }$ in the N 1 s spectrum (Fig. 6c) indicated that a small amount of nitrogen exists in two different chemical states, which may be respectively derived from the decomposition of CTAB and TEA. The O 1 s XPS spectrum (Fig. 6d) could be fitted into two peaks at 528.6 and $5 3 0 . 0 \mathsf { e V } ,$ respectively. The former was assigned to lattice oxygen $( 0 _ { \mathsf { L } } )$ in $\mathsf { F e T i O } _ { 3 } ,$ and the latter may be attributed to defect oxygen components such as chemisorbed hydroxyl groups or oxygen vacancies $( \mathsf { O } _ { \mathsf { V } } )$ in $\mathsf { F e T i O } _ { 3 } /$ $\mathsf { C } ^ { 4 5 , 4 7 }$ . The EPR technique is usually used to detect $0 _ { \mathsf { V } }$ with the appearance of a typical paramagnetic signal at $\mathfrak { g } = 2 . 0 0 1 ^ { 4 7 }$ However, the EPR spectrum of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ (Supplementary Fig. 2) cannot convincingly support the presence of $0 _ { \mathsf { V } }$ because of strong interference from a large amount of iron present in $\mathsf { F e T i O } _ { 3 } / \mathsf C ,$ which can mask the $0 _ { \mathsf { V } }$ signal by the generation of substantially overlapped EPR signals at similar positions48,49. The surface Fe/Ti ratio of 2.1 was obviously larger than the nominal Fe/Ti ratio of 1.0 or EDX-analyzed Fe/Ti ratio of 0.8 (Fig. 4a), indicating iron enrichment on the surface of $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ . # CWPO removal of aromatic pollutants on $\pmb { \mathrm { F e T i O } _ { 3 } } / \pmb { \mathrm { C } }$ nanocomposites

Widely used aromatic compounds have been considered as priority pollutants because of harmful effects on the ecosystem and human health due to their refractory and bio-accumulative nature. In this work, six model pollutants in Table 1 have been selected to represent aromatic compounds with different charges, including cationic RhB and MB dyes, anionic OG dye and three neutral pharmaceuticals, for evaluation of the catalytic performance of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ as a heterogeneous Fenton-like catalyst. TC was chosen as the initial compound to compare the catalytic activities of various $\mathsf { F e T i O } _ { 3 } / \mathsf C$ samples made under different conditions because of its slow degradation rate. As seen in Fig. 7a, $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - } 0 . 6 7$ performed the best for TC degradation, followed in order by $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \cdot 1 . 3 3$ , $\mathsf { F e T i O } _ { 3 } / \mathsf { C } { - } 0$ and $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - } \mathsf { N T }$ . In agreement with the XRD results in Fig. 1a, slightly lower activity of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } - 1 . 3 3$ could be due to the presence of minor rutile phase with low activity for ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ activation, and low activity of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - }$ NT may be related to its low crystallinity due to no addition of TEA during its preparation. The lowest activity of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } _ { - } 0$ which was prepared without the addition of CTAB, reflected the importance of CTAB-derived carbon component in $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - } 0 . 6 7$ for its improved activity.

# Mechanistic studies

The concentration of the total soluble iron leached into solution during the degradation of RhB over $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \mathrm { - } 0 . 6 7$ was $0 . 5 7 \bar { \mathsf { m } } 9 { \mathsf { L } } ^ { - 1 }$ . When 1.0 ppm of $\mathsf { F e } ^ { 2 + }$ or $\mathsf { F e } ^ { 3 + }$ $( \mathsf { F e S O } _ { 4 } . 7 \mathsf { H } _ { 2 } 0$ or hydrated $\mathsf { F e } _ { 2 } ( \mathsf { S O } _ { 4 } ) _ { 3 }$ used as soluble iron source, respectively) was added to replace $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ as homogeneous catalysts under otherwise identical conditions, the $^ { 2 \mathsf { h } }$ DR of RhB $( 2 5 \mathsf { m g l } ^ { - 1 } )$ was only $2 9 . 2 \%$ or $1 5 . 1 \%$ (Fig. 8a). These control experiments and the above-described recyclability tests supported that the RhB degradation with ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ was mainly a heterogeneous catalytic process occurring on the surface of $\mathsf { F e T i O } _ { 3 } / \mathsf { C } \cdot 0 . 6 7$ .

The reactive oxygen species (ROS) involved in the ${ \sf H } _ { 2 } { \sf O } _ { 2 ^ { - } } { \sf F e T i O } _ { 3 } /$ C system was investigated by scavenging experiments during the RhB degradation. Tert-butanol (TBA) and $\mathsf { p }$ -benzoquinone (BQ) were used to scavenge ·OH and $\hphantom { 0 } 0 _ { 2 } \cdot ^ { - }$ radicals, respectively59–61. As can be seen in Fig. 8b, the $^ { 2 \mathsf { h } }$ DR of RhB $( 2 5 \mathsf { m } \mathsf { g } \mathsf { L } ^ { - 1 } )$ decreased from $9 9 . 5 \%$ to $7 6 . 0 \%$ upon the addition of $5 0 \mathsf { m } \mathsf { M }$ of TBA, which is about 1000 times the RhB concentration $( 0 . 0 5 2 \mathsf { m M } )$ ). In contrast, it only slightly dropped to $9 6 . 5 \%$ in the presence of $5 \mathsf { m } \mathsf { M }$ of BQ. Higher concentration of BQ has not been tested because of its low solubility in water. It is important to note that the decolorization process of RhB solution with the co-addition of ${ \sf H } _ { 2 } { \sf O } _ { 2 } ,$ TBA and BQ was very similar to the adsorption of RhB on $\mathsf { F e T i O } _ { 3 } / \mathsf C$ . It implied that the addition of both TBA and BQ almost completely inhibited the degradation of RhB. The scavenging experiments indicated that ·OH radicals are the main ROS while ${ \sf O } _ { 2 } \ddot { \sf { ^ { . } } }$ make a minor contribution to the degradation of RhB with ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ over $\mathsf { F e T i O } _ { 3 } / \mathsf C$

The ·OH and $\hphantom { 0 } 0 _ { 2 } \cdot ^ { - }$ radicals as reactive intermediates then attack and degrade electron-rich $\pi$ -conjugated aromatic molecules (e.g., RhB) adsorbed on the surface of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ .

$$
\begin{array} { r l } & { \equiv \mathsf { M } ^ { \mathsf { n } + 1 + } + \mathsf { H } _ { 2 } \mathsf { O } _ { 2 } \to \equiv \mathsf { M } ^ { ( \mathsf { n } + 1 ) + } + \bullet \mathsf { O } \mathsf { H } + \mathsf { O } \mathsf { H } ^ { - } ( \mathsf { M } \mathrm { ~ f o r ~ } \mathsf { F e ~ o r ~ } \mathsf { T i } } \\ & { \equiv \mathsf { M } ^ { ( \mathsf { n } + 1 ) + } + \mathsf { H } _ { 2 } \mathsf { O } _ { 2 } \to \equiv \mathsf { M } ^ { \mathsf { n } + } + \mathsf { H } ^ { + } + \mathsf { H } \mathsf { O } \mathsf { O } \bullet } \end{array}
$$

As shown in Fig. 9a, during the RhB degradation over $\mathsf { F e T i O } _ { 3 } , C ,$ the peak intensity of its characteristic absorption $( \lambda _ { \mathrm { { m a x } } } )$ at $5 5 4 \mathsf { n m }$ gradually decreased and several small absorption bands before $4 0 0 \mathsf { n m }$ quickly diminished before 5 min. The degradation of RhB molecules (Fig. 9a inset) generally proceeds via two different pathways: N-de-ethylation or chromophore cleavage, followed by hydroxylation, ring opening or mineralization14,62,63. N-deethylation causes a hypsochromic shift in $\lambda _ { \operatorname* { m a x } }$ of the residual solution because of the auxochromic property of N-ethyl groups14,62,63, while chromophore cleavage only reduces the absorbance at $5 5 4 \mathsf { n m }$ . No shift in $\lambda _ { \operatorname* { m a x } }$ was observed during the entire course of the RhB degradation in the $_ { \mathsf { H } _ { 2 } \mathsf { O } _ { 2 } \mathsf { - F e T i O } _ { 3 } / \mathsf { C } }$ system (Fig. 9a), implying that the RhB degradation mainly proceeds via the chromophore cleavage under our experimental conditions. It was supported by the HPLC histograms of degradation solution at different times (Fig. 9b), in which very weak or negligible peaks due to N-de-ethylation intermediates were observed.

CTAB played critical roles in making highly active and stable $\mathsf { F e T i O } _ { 3 } , C$ catalyst. Firstly, it facilitated the growth of the (110) and (012) crystal planes with more metallic sites exposed on the surface upon selective adsorption on the (104) plane. Secondly, CTAB-derived carbon components restricted the growth of $\mathsf { F e I i O } _ { 3 }$ nanoparticles and partially reduced $\mathsf { F e } ^ { 3 + }$ to $\mathsf { F e } ^ { 2 + }$ during pyrolysis due to close contact between $\mathsf { F e T i O } _ { 3 }$ and C, thus generating $\mathsf { F e T i O } _ { 3 } \mathscr { C }$ composite with high surface area and rich ferrous content. Thirdly, the adsorption of aromatic pollutants via π-π interaction and electron transfer process during CWPO may be enhanced by graphitic and disordered carbons present in $\mathsf { F e T i O } _ { 3 } \mathscr { C }$ .

In conclusion, anisotropic ilmenite/carbon $( \mathsf { F e T i O } _ { 3 } , \mathsf { C } )$ nanocomposite with abundant interfacial ferrous ions was synthesized via CTAB-assisted sol-gel method in this work. $\mathsf { F e T i O } _ { 3 / } C$ exhibited high activity and good recyclability as a heterogeneous Fenton-like catalyst for CWPO removal of differently charged aromatic pollutants. Scavenging tests and spin-trapping EPR spectra confirmed that •OH and $\bullet { \mathrm { O } } _ { 2 } ^ { - }$ are the primary reactive species for pollutant degradation in ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ - $\mathsf { F e T i O } _ { 3 } / \mathsf C$ catalytic system.

# Chemicals and regents

$\mathsf { F e } ( \mathsf { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathsf { H } _ { 2 } \mathsf { O } ,$ tetrabutyl titanate (TBOT), triethylamine (TEA), CTAB, rhodamine B (RhB), methylene blue (MB), orange G (OG), tetracycline hydrochloride (TC), metronidazole (MNZ), acetaminophen (APAP), p-benzoquinone (BQ), tert-butanol, ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ $( 3 0 \% )$ NaCl, $\mathsf { K N O _ { 3 } } , \mathsf { N a _ { 2 } S O _ { 4 } } , \mathsf { N a H C O _ { 3 } }$ and $\mathsf { N a } _ { 2 } \mathsf { H P O } _ { 4 } . 1 2 \mathsf { H } _ { 2 } \mathsf { O }$ were purchased from Sinopharm Chemical Reagent (Shanghai, China). Humic acid was obtained from Yuanye Biotechnology (Shanghai, China). 5,5- Dimethyl-1-pyrrolidine N-oxide (DMPO) was supplied by SigmaAldrich (Shanghai, China). All chemicals were of analytic grade or above and used as received. All aqueous solutions were prepared with deionized (DI) water $( < 2 0 ~ \mu \mathsf { S } \mathsf { c m } ^ { - 1 } )$ ) produced from Heal Force NW 15VF.

# CTAB-assisted sol-gel synthesis of $\mathtt { F e T i O } _ { 3 } / \mathtt { C }$

In a typical synthesis, $1 . 4 5 4 0 9$ (3.6 mmol) of $\mathsf { F e } ( \mathsf { N O } _ { 3 } ) _ { 3 } { \cdot } 9 \mathsf { H } _ { 2 } \mathsf { O }$ was dissolved in $1 0 \mathsf { m L }$ of ethanol, followed by addition of $1 . 2 2 9 0 { \mathfrak { g } }$ $( 3 . 6 \ : \mathrm { m m o l } )$ of TBOT, $1 0 \mathsf { m L }$ of CTAB solution in ethanol and $2 \mathsf { m l }$ (14.4 mmol) of TEA to get a reaction mixture with molar composition of $1 . 0 \mathsf { F e } : 1 . 0 \mathsf { T i } : \mathsf { x C T A B } : 4 . 0 \mathsf { T E A }$ $( \mathsf { x } = 0$ , 0.67 or 1.33). Note that the $\mathsf { F e T i O } _ { 3 } / \mathsf C$ used in this work was generally synthesized with $\mathsf { x } = 0 . 6 7$ if not specified. The whole mixture was heated at $70 \textdegree$ to form a brown gel precursor, which was then converted to $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ by heating in $\mathsf { N } _ { 2 }$ at $70 0 ^ { \circ } \mathsf { C }$ for $^ { 2 \mathsf { h } }$ in a tube furnace with a heating rate of $5 ^ { \circ } C \mathsf { m i n } ^ { - 1 }$ from $2 5 ^ { \circ } \mathsf { C }$ to $70 0 ^ { \circ } \mathsf { C }$ .

# Characterization of $\mathtt { F e T i O } _ { 3 } / \mathtt { C }$ nanocomposites

Powder X-ray diffraction (XRD) patterns were collected on Bruker D8 Advance Diffractometer with Cu Kα radiation at $3 0 \kappa \up$ and ${ 2 0 } { \mathsf { m } } { \mathsf { A } }$ . Surface cleavage of the $\mathsf { F e I i O } _ { 3 }$ lattice was performed on Materials Studio 7.0. Thermogravimetric-differential scanning calorimetry (TG-DSC) analysis was carried out in ${ \Nu } _ { 2 }$ on Netzsch STA 449F3 from room temperature to $80 0 ^ { \circ } \mathsf { C }$ at a heating rate of

$1 0 ^ { \circ } \mathsf { C } \mathsf { m i n } ^ { - 1 }$ . Raman spectrum was recorded on Thermo Scientific DXR with a $5 3 2 \mathsf { n m }$ excitation laser source. ${ \Nu } _ { 2 }$ physisorption analysis was measured on Micromeritics ASAP 2020 at $7 7 \mathrm { \textK }$ The sample was degassed at $1 5 0 ^ { \circ } \mathsf C$ for $4 \mathsf { h }$ under vacuum before measurement. The BET specific surface area $S _ { \mathsf { B E T } }$ was calculated from the adsorbed amount of ${ \sf N } _ { 2 }$ in the relative pressure $( \mathsf { P } / \mathsf { P } _ { 0 } )$ range of $0 . 0 5 { - } 0 . 3 0$ . The pore volume ${ \mathsf { V } } _ { \mathsf { p } }$ was converted from the adsorbed quantity of ${ \sf N } _ { 2 }$ at $\mathsf { P } / \mathsf { P } _ { 0 } = 0 . 9 9$ . The point of zero charge $( p \mathsf { H } _ { \mathsf { p } z \mathsf { c } } )$ was determined by the conventional method64,65. In brief, $0 . 2 0 { \mathfrak { g } }$ of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ was dispersed into $2 0 \mathsf { m l }$ of 0.10 M NaCl after adjusting its initial pH (pHi) to 2–10 via HCl or NaOH solutions. After the suspensions were agitated in a shaker at 150 rpm and $3 0 \ ^ { \circ } \mathsf { C }$ for $^ { 8 \mathrm { h } , }$ the final pH values $\left( \mathsf { p H } _ { \mathsf { f } } \right)$ were recorded. The pHzpc was determined by the intersection point of the $\Delta { \mathsf { p } } { \mathsf { H } } - { \mathsf { p } } { \mathsf { H } } _ { \mathsf { i } }$ plot at $\Delta { \mathsf { p H } } = 0 .$ , where $\Delta p \mathsf { H } = \mathsf { p } \mathsf { H } _ { \mathsf { f } }$ -pHi. Zeta potentials were measured on Malvern Zetasizer Pro. Scanning electron microscope (SEM) images were taken on JEOL JSM-5510LV SEM at $2 0 \mathsf { k V } .$ Energydispersive X-ray spectroscopy (EDX, Oxford Instruments) attached to SEM was used for elemental analysis. Transmission electron microscope (TEM) and high-resolution TEM (HRTEM) images were taken on JEM-2100 TEM at $2 0 0 \mathsf { k V } .$ . The particle size and interlayer spacing were respectively measured by ImageJ and Digital Micrograph. X-ray photoelectron spectroscopy (XPS) analyses were conducted on X-ray Photoelectron Spectrometer (ESCALAB 250XI XPS Thermo Company, America) using a monochrome Al Kα radiation $( \mathsf { h } \mathsf { v } = 1 4 8 6 . 6 \mathsf { e V } )$ as the excitation source. The C 1 s peak of adventitious carbon at $2 8 4 . 8 \mathsf { e V }$ was used as charge reference.

# CWPO of aromatic pollutants over $\mathtt { F e T i O } _ { 3 } / \mathtt { C }$ nanocomposites

Six aromatic compounds in Table 1 were employed to evaluate the performance of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ in CWPO. Typically, $0 . 0 2 5 { \mathfrak { g } }$ of $\mathsf { F e T i O } _ { 3 } / \mathsf C$ was added into $5 0 \mathsf { m l }$ of aqueous solution of an organic pollutant $( 2 5 \mathsf { m g L } ^ { - 1 }$ , pH adjusted to ${ \sim } 3$ by 1 M $H _ { 2 } S O _ { 4 } )$ at $2 5 \pm 2 ^ { \circ } \mathsf C$ and 750 rpm. The degradation was initiated by adding $0 . 2 3 0 { \mathfrak { g } }$ of ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ $( 3 0 \% )$ into the solution. About $3 \mathsf { m L }$ of aliquots were sampled at given intervals by syringe and passed through a $0 . 2 2 \mu \mathrm { m }$ filter membrane before analyzing the concentration of residual pollutants. In recyclability tests, the used $\mathsf { F e T i O } _ { 3 } / \mathsf C$ was recovered by centrifugation after each run for $3 h$ , and directly reused according to the same degradation procedure.

The degradation or decolorization rate (in short DR) of organic pollutants was defined as $\mathsf { D } \mathsf { R } = ( 1 - \mathsf { C } _ { \mathsf { t } } / \mathsf { C } _ { 0 } ) \times 1 0 0 \% ,$ where ${ \sf C } _ { 0 }$ and $\mathsf { C } _ { \mathrm { t } }$ were the respective concentrations of organic pollutants at time zero and elapsed time (min). The concentrations of RhB, MB, OG, TC and MNZ in water were analyzed by measuring the absorbance at 554, 664, 478, 357 and $3 2 0 { \mathsf { n m } }$ , respectively, using a UV-Vis spectrophotometer (UV-1800PC, Shanghai Mapada Instrument) (Supplementary Fig. $9 ( \mathsf { a } \mathsf { - e } ) )$ . High concentrations of RhB and MB solutions were diluted by five times before measurement. The APAP concentration in water was measured by high-performance liquid chromatography (HPLC, Shimadzu LC-2050C 3D with a DAD detector or Thermo Fisher Ultimate 3000 with a UV-Vis detector) equipped with an Analytical C18 column ( $1 5 0 \mathrm { m m } \times 4 . 6 \mathrm { m m }$ packed with $5 \mu \mathrm { m }$ particles) at $3 5 ~ ^ { \circ } \mathsf { C }$ (Supplementary Fig. 9f). The mobile phase was the mixture of methanol and water (55:45 by volume) with a flow rate of $0 . 8 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ and UV-Vis detector was set at ${ 2 4 8 \mathsf { n m } }$ . The total soluble iron content leached into solution from $\mathsf { F e T i O } _ { 3 } / \mathsf C$ after the reaction was analyzed by 1,10-phenanthroline spectrophotometric method with hydroxylamine hydrochloride as a reducing agent. The chemical oxygen demand (COD) was determined according to China National Standard GB11892- 89 (ISO8467-1993).

# Determination of reactive oxygen species

Reactive oxygen species (ROS) were determined by scavenging experiments and electron paramagnetic resonance (EPR) measurements. In scavenging tests, a suitable quencher (tert-butanol for •OH and BQ for ${ \sf O } _ { 2 } \dot { { \bf \mu } } ^ { - }$ ) was added during the degradation of RhB with ${ \sf H } _ { 2 } { \sf O } _ { 2 }$ over $\mathsf { F e T i O } _ { 3 } / \mathsf { C }$ . During EPR measurements, DMPO was added as a spin-trapping agent for •OH in ${ \sf H } _ { 2 } { \sf O }$ or for ${ \sf O } _ { 2 } \cdot \mathrm { ^ - }$ in methanol. The EPR spectra were collected on Bruker EMX Plus with microwave frequency of $9 . 8 2 \mathsf { G H z } ,$ microwave power of $2 . 0 \mathsf { m W }$ , modulation frequency of $1 0 0 k H z ,$ , modulation amplitude of $\phantom { - } 0 . 8 \mathsf { G } ,$ sweep width of $\boldsymbol { 1 2 0 } \boldsymbol { \mathrm { \bar { G } } }$ and sweep time of $3 0 s$ .
