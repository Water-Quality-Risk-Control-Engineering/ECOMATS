# Sonicated Carbon Nanotube Catalysts for Efficient Point-of-use Water Treatment

Xin Yang, Justin Prabowo, Jiaxiang Chen, Fangxin She, Leo Lai, Fangzhou Liu, Zhechao Hua, Yangyang Wang, Jingyun Fang, Kunli Goh, Di Zhang,\* Hao Li,\* Li Wei,\* and Yuan Chen\*

The rising demand for freshwater and increasing contamination of distributed water sources, such as stormwater and surface water, necessitate innovative point-of-use treatment technologies. Advanced oxidation processes (AOPs) using solid oxidants offer a promising approach for decentralized freshwater production but are often limited by nonselective radical reactions that degrade both pollutants and background water constituents. Here, sonicated carbon nanotubes (CNTs) that efficiently activate peroxymonosulfate are demonstrated, enabling selective contaminant degradation via dual nonradical pathways—singlet oxygen oxidation and direct electron transfer. Optimized sonication introduces catalytically active carbonyl $\scriptstyle ( \mathbf { C } = \mathbf { O } )$ groups on CNT surfaces while preserving their graphitic structure, ensuring rapid electron transfer. This approach achieves 2,4-dichlorophenol removal, a common industrial and municipal pollutant, within 5 min at a record removal rate of $4 . 8 0 \mu \mathrm { m o l } \ \mathbf { g } ^ { - 1 } \ \mathbf { s } ^ { - 1 }$ • Furthermore, scalable CNT catalyst synthesis and integration into flat membrane and hollow fiber filtration devices, ensuring long-term stability and efficient pollutant removal in natural river water, are demonstrated. By advancing selective CNT catalysts for AOPs, this work offers a scalable, sustainable solution for point-of-use freshwater production in real-world applications.

# 1. Introduction

Global aquatic environments are continuously deteriorating due to human activities.[1] Using various distributed water, including stormwater, surface water, roof water, etc., offers the possibility of more sustainably addressing our increasing freshwater demands.[1b,2] Multiple contaminants in distributed water, such as refractory organics, trace toxic elements, and pathogens, must be treated adequately.[1b,2a,3] Centralized water treatment facilities, though common for municipal wastewater and drinking water treatments, face challenges in high construction and maintenance costs and poor deployment flexibility for treating distributed sources.[4] Advanced oxidation processes (AOPs) using solid oxidants are superior to gas or liquid oxidants for distributed water treatment because of their ease of storage and transport.[5]

Commonly used solid oxidants, such as persulfates, must be activated by photocatalysts[] or electrocatalysts[] to become efficient. Among various catalysts, metal-free carbon catalysts[5c,8] are attractive because they do not require additional energy inputs during persulfate activation, improving AOPs' feasibility and sustainability.[5c,9] Compared with other metal-free carbon catalysts, carbon nanotubes (CNTs) can be scalably synthesized with well-controlled structures at a relatively low cost. They also have superior chemical and structural stability. Further, most catalysts activate persulfate to yield hydroxyl $\left( \mathrm { H O ^ { \bullet } } \right)$ or sulfate radicals $( \mathrm { S O } _ { 4 } ^ { \bullet - } )$ radicals that nonselectively react with a wide range of water components.[1,5] These radicals can be rapidly quenched by chloride ions $[ \mathrm { C l ^ { - } }$ with a high secondorder reaction rate constant $( k )$ of $1 0 ^ { 8 } – 1 0 ^ { 9 } \mathrm { ~ M ~ } ^ { - 1 } \mathrm { ~ s ~ } ^ { - 1 } )$ and natural organic matters (NOMs with a high $k$ of $1 0 ^ { 7 } { - } 1 0 ^ { 8 } \ \mathrm { M ^ { - 1 } \ { \ s ^ { - 1 } } }$ in water,[5] compromising their capability in contaminant removal. In contrast, CNTs can enable the formation of singlet oxygenation $( ^ { 1 } 0 _ { 2 } ) ^ { [ 8 ] }$ or/and direct electron transfer (DET).8] They could preferentially target electron-rich moieties in contaminants (e.g., unsaturated organics and microorganisms),5,10] and have low reactivities with common environmental constituents (e.g., ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ reacts with $\mathrm { C l ^ { - } }$ and NOMs at low $k$ of $< 1 0 ^ { 2 } \ \mathrm { M ^ { - 1 } \ { \bf s } ^ { - 1 } }$ and ${ \bf \Gamma } \sim 1 0 ^ { 6 }    { \bf M } ^ { - 1 } { \bf s } ^ { - 1 }$ , respectively).[5,10] The selectivity via the nonradical oxidation pathways demonstrated by CNTs may enable efficient treatment of various distributed waters with varied pH, inorganic ions, and NOMs.[8,11]

Previous studies have correlated the nonradical oxidation pathways to different physicochemical characteristics of CNTs, with often conflicting opinions.[5,8] For example, CNTs' high electrical conductivity is proposed to facilitate electron transfer for DET.[8,12] Surface defects on CNTs that lower their electrical conductivity are credited as catalytically active sites.[5,8,1 Different surface oxygenous functional groups (e.g., carbonyl $( \mathrm { C = O } )$ , carboxylic (COOH), and hydroxyl (C—OH)) are proposed as catalytically active sites.[8,14] We hypothesize that $\scriptstyle \mathrm { C = O }$ groups on low surface-defect-density CNTs are the most active catalytic sites for persulfate activation via nonradical oxidation pathways, which would deliver superior AOP performances.

Herein, we demonstrate a sonication method tor obtaining CNT catalysts that enable efficient solid oxidant (i.e., potassium peroxymonosulfate $\mathrm { ( K H S O _ { 5 } }$ , PMS)) activation for point-of-use water treatment. By controlling the sonication energy inputs, a series of sonicated CNT catalysts are created with varied types and densities of oxygenous functional groups, which enable the identification of an AOP pathway shift from ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ oxidation to the DET process. 2,4-dichlorophenol (DCP) was selected as a representative contaminant in this study because it is widely found in industrial and municipal wastewater as well as natural waterbodies, with concentration levels ranging from $\mu \ g \mathrm { ~ L ~ } ^ { - 1 }$ to $\mathrm { m g L ^ { - 1 } }$ [15] and it is also formed as a halophenolic disinfection byproduct in chlorine-based disinfection processes.[8,16] Furthermore, DCP exhibits high reactivity via the nonradical oxidation pathways.[5,8] The optimized CNT catalyst delivers the highest reported removal rate $( 4 . 8 0 \ \mu \mathrm { m o l \ g ^ { - 1 } \ \mathrm { s ^ { - 1 } ) } }$ of DCP. A structure-activity relationship is established through correlation analysis, selective deactivation experiments, and theoretical calculation to pinpoint the catalytical active sites to $\mathrm { C } { = } \mathrm { O }$ groups on low surface-defectdensity CNTs. In contrast, CNTs with excessive defects are less efficient in ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation and divert reaction pathways. The optimal sonicated CNT catalyst is further integrated into continuousflow membrane and hollow fiber devices to demonstrate its high catalytic performance and stability in real water treatment. This research provides new insights into developing metal-free carbon catalysts for solid oxidant activation, applicable to AOP-based point-of-use water treatment to enable more sustainable freshwater production.

# 2.2. Catalytic Performance of Sonicated CNT Catalysts

The catalytic performance of the sonicated CNT catalysts in PMS activation (details in Experimental Section) was assessed by removing DCP. Figure 2a compares the performance of the pristine CNT catalyst (CNT-0) to several representative carbon materialbased catalysts, including carbon black (CB), graphite powder (GP), graphene oxide (GO), and reduced graphene oxide (rGO). CNT-0 removed ${ \approx } 7 0 . 5 \%$ of DCP after $3 0 \mathrm { { m i n } }$ , which is about $1 . 4 -$ 3.9 times higher than that of the other carbon catalysts (Figure S9, Supporting Information). We propose that the better performance of CNT-0 is related to its balanced electrical conductivity and defect density (Table S5, Supporting Information), which is discussed further later.

Next, the DCP removal performance by the sonicated CNT catalysts was compared. Control experiments show that PMS alone only oxidizes $7 . 5 4 \%$ of DCP (Figure 2b), and the adsorptive removal of DCP by CNTs is less than $9 . 1 7 \%$ after $3 0 ~ \mathrm { m i n }$ (Figure S10, Supporting Information). Nevertheless, an appreciably improved DCP removal is achieved by sonicated CNT catalysts, affording the pseudo-first-order rate constant $( k _ { \mathrm { o b s } } )$ about ${ \approx } 1 . 4 { - } 9 . 9 $ times higher than that of CNT-0 (Figure 2c; Figure S11, Supporting Information). This result suggests that the sonication could introduce catalytically active sites to CNTs and increase their catalytic performances.

CNT-1.0 exhibits the highest $k _ { \mathrm { o b s } }$ of $0 . 6 1 6 \ \mathrm { m i n ^ { - 1 } }$ and can remove $5 0 ~ \mu \mathrm { M }$ DCP in $5 ~ \mathrm { m i n }$ with $2 5 0 ~ \mu \mathrm { M }$ PMS at $\mathrm { p H } ~ 7 . 2$ . Its $k _ { \mathrm { o b s } }$ value is higher than most recently reported heterogeneous catalysts, electrocatalysts, and photocatalysts (Table S6 and Figure S12, Supporting Information). A modified kinetics model, $k \mathrm { . }$ value, has often been used to evaluate the pollutant removal potentials of catalysts (Text S1, Supporting Information).[13,22] Figure 2d shows that CNT-1.0's $k$ value at $4 . 8 0 \ \mu \mathrm { m o l } \ \mathrm { g } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ for DCP removal is the best among recently reported catalysts. # 2.3. DCP Removal Mechanisms on Sonicated CNT Catalysts

Due to the complex physicochemical properties of CNTs, the detailed mechanism of contaminant removal during PMS activation by CNT catalysts is not clearly elucidated. Some studies suggested that DCP was primarily oxidized through the DET process,[8] whereas others found that ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ oxidation was dominant.[8,14,21] To understand the DCP removal mechanisms by sonicated CNT catalysts, in situ electron paramagnetic resonance (EPR) spectroscopy is used to detect reactive species that CNT catalysts' activation of PMS could generate. Figure 3a depicts a septuple EPR signal (intensity ratio of 1:2:1:2:1:2:1) when 5,5-dimethyl-1-pyrroline-N-oxide (DMPO) is added into CNT1.0/PMS as a spin trapping agent, which can be attributed to 5,5- dimethyl-1-pyrroline-N-oxyl (DMPOX) generated from the direct oxidation of DMPO rather than free radicals.[23] The EPR signal remains unchanged with extended reaction time from 1 to $1 5 \mathrm { m i n }$ (Figure 3a). The absence of free radicals in CNT-1.0/PMS is further confirmed by adding two other radical scavengers, i.e., methanol and tert-butanol (TBA) (Figure S13 and Table S7, Supporting Information).[5,23] Figure 3b shows that both scavengers exhibit negligible impacts on the DCP removal, indicating that CNT-1.0/PMS does not follow the radical mechanism. When 2,2,6,6-tetramethylpiperidine (TEMP) is used as the trapping agent, EPR spectra in PMS alone and CNT-1.0/PMS exhibit a clear triplet signal, whose intensity gradually increases with the reaction time from 1 to $1 5 \ \mathrm { m i n }$ , suggesting that CNT-1.0 activates PMS to produce ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ (Figure 3c; Figure S14, Supporting Information).[5] This is further supported by using $\beta$ -carotene as the trapping agent, which is highly reactive to ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ but not PMS [10,23] to selectively quench ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ in CNT-1.0/PMS (Figure S13 and Table S7, Supporting Information). Figure 3b shows that the DCP removal ratio substantially decreases from 100 to $5 8 . 4 \%$ , and the corresponding $k _ { \mathrm { o b s } }$ reduces from 0.616 to $0 . 2 0 3 \ \mathrm { m i n ^ { - 1 } }$ , confirming that ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ plays a critical role in the DCP removal by CNT-1.0/PMS.

Next, whether CNTs serve as a charge-transfer mediator between the electron acceptor (PMS) and donor (DCP) is studied.[2,5,8] Electron migration during the DCP removal is monitored by linear sweep voltammetry (LSV) of CNT-1.0 loaded on a glassy carbon electrode $( \mathrm { C N T } { \cdot } 1 . 0 @ \mathrm { G C E } )$ . Figure 3d shows that a bare GCE has a negligible current in a $0 . 1 ~ \mathrm { ~ M ~ }$ phosphate buffered saline (PBS) electrolyte with $5 0 0 ~ \mu \mathrm { M }$ PMS and $1 0 0 ~ \mu \mathrm { M }$ DCP. The LSV curves of C $_ { \mathrm { N T } \cdot 1 . 0 @ \mathrm { G C E } }$ with $5 0 0 ~ \mu \mathrm { M }$ PMS or $1 0 0 ~ \mu \mathrm { M }$ DCP are similar but increase significantly when both compounds are added to the PBS electrolyte. This observation suggests that the DCP removal in CNT-1.0/PMS involves the DET mechanism. Further, the oxidation peak at ${ \approx } 0 . 6 2 \mathrm { ~ V ~ }$ (vs $\mathrm { { A g / A g C l } }$ indicates the electrochemical oxidation of DCP (Figure 3d; Figure S15, Supporting Information).

# 2.4. Catalytically Active Sites on CNT Catalysts

Sonication alters CNTs' surface chemistry and structures. Eight CNT properties may correlate with their catalytic performance, including ECSA, electrical conductivity, defect density, CNT length, surface O content, and abundances of different surface oxygenous functional groups (C—OH, COOH, and $\mathrm { C = O }$ (Tables S2 and S10, Supporting Information). Pearson, Spearman, and Kendall correlation analyses are conducted between their catalytic performance descriptor $( k _ { \mathrm { o b s } } )$ and these eight properties. Figure $\mathbf { 4 } \mathrm { { a } }$ shows a strong positive correlation between the abundance of $\mathrm { C } { = } \mathrm { O }$ and $k _ { \mathrm { o b s } }$ . Only the abundance change of $\scriptstyle \mathrm { C = O }$ on CNTs aligns well with the changing trend of $k _ { \mathrm { o b s } }$ (Figure S21, Supporting Information). This suggests that $\scriptstyle \mathrm { C = O }$ groups on CNTs are catalytically active sites for PMS activation.

Based on the correlation analysis result, specific roles of different O functional groups are compared via selectively deactivating $\mathrm { C } { = } \mathrm { O }$ using phenylhydrazine (PH), C—OH using benzoic anhydride (BA), and COOH using 2-bromo-1-phenylethanone (BrPE) on CNT catalysts, respectively (Figure 4b, see details in Experimental Section).[8,20,25] XPS analysis confirms that the relative abundance of $\scriptstyle \mathrm { C = O }$ reduces by $6 4 . 3 \%$ in CNT $\cdot 1 . 0 _ { \mathrm { P H } }$ , $\mathrm { C - O H }$ reduces by $2 8 . 7 \%$ in CNT $\cdot 1 . 0 _ { \mathrm { B A } }$ , COOH reduces by $3 4 . 3 \%$ in CNT $1 . 0 _ { \mathrm { B r P E } }$ , compared to CNT-1.0 (Figure S22 and Tables S2 and S11, Supporting Information), agreeing with FTIR results (Figure S23, Supporting Information). The quenched CNT-1.0 all exhibit lower efficiency in DCP degradation (Figure $_ { 4 \mathrm { c } }$ and Figure S24, Supporting Information). Specifically, $k _ { \mathrm { o b s } }$ of CNT$1 . 0 _ { \mathrm { P H } }$ dropped significantly to $0 . 0 3 5 \mathrm { { m i n ^ { - 1 } } }$ , even lower than CNT0 at $0 . 0 6 2 \mathrm { m i n ^ { - 1 } }$ . XPS results indicate that the abundance of $\scriptstyle \mathrm { C = O }$ in CNT $1 . 0 _ { \mathrm { P H } }$ $( 0 . 2 7 2 \mathrm { a t . } \% )$ is lower than CNT-1.0 (0.709 at $\%$ and CNT-0 $( 0 . 4 2 3 \mathrm { a t . } \% )$ (Tables S2 and S11, Supporting Information).

Thus, the $\scriptstyle \mathrm { C = O }$ group is most likely to determine the efficiency of PMS activation on sonicated CNT catalysts.

Next, to further validate this conclusion, sodium borohydride $\mathrm { ( N a B H _ { 4 } ) }$ and formaldehyde (HCHO) are used to partially remove and increase the abundance of $\mathrm { C } { = } \mathrm { O }$ on CNT catalysts, respectively (Figure 4b).21,26 Treatment with $\mathrm { N a B H _ { 4 } }$ generated the active hydrogen,[21] which reduces the $\scriptstyle \mathrm { C = O }$ abundance in CNT$1 . 0 _ { \mathrm { N a B H 4 } }$ to a low level $( 0 . 0 2 6 ~ \mathrm { a t . } \% )$ (Figures S22 and S23 and Table S11, Supporting Information). As a result, its performance in DCP removal performance is comparable to that of CNT-0 (Figure 4c). Conversely, by chemisorbing HCHO to edge carbon atoms of CNT-0,[14,27] the abundance of $\mathrm { C } { = } \mathrm { O }$ increases by 1.43 times $( 0 . 6 0 3 \mathrm { ~ a t . } \%$ , Figure S25 and Table S12, Supporting Information). The resulting $\mathrm { C N T } { \cdot } 0 _ { \mathrm { H C H O } }$ delivers $k _ { \mathrm { o b s } }$ of $0 . 5 3 8 \ \mathrm { m i n ^ { - 1 } }$ (Figure 4c), comparable to the optimal CNT-1.0.

Why do CNT-2.5 and CNT-4.0, despite their relatively high $\mathrm { C } { = } \mathrm { O }$ abundance, show lower DCP removal efficiency (Figure S21, Supporting Information)? On the one hand, due to the reduced $\mathrm { C } { = } \mathrm { O }$ abundance, CNT-4.0 exhibits a lower ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation capability (Figures S16 and S17, Supporting Information). Thus, the dominant DCP removal mechanism of CNT-4.0 shifts to DET $( 6 8 . 4 \%$ in Figure 3h). On the other hand, the excessive O functional groups ( $1 0 . 5 4 \mathrm { a t . } \%$ , especially COOH, Table S2, Supporting Information) on CNT-4.0 would limit the adsorption of PMS on CNTs due to the steric effect or/and electrostatic repulsion,[8,28] which lowers DCP removal via DET. Along this line, excessive O functional groups are introduced to CNT-1.0 during usage. The used CNT-1.0 shows lower catalytic performance than fresh CNT-1.0 (Figure S26, Supporting Information). Therefore, the lower DCP removal efficiency of CNT-2.5 and CNT-4.0 arises from both their reduced $\mathrm { C } { = } \mathrm { O }$ abundance and increased abundance of C—OH and COOH.

Density functional theory (DFT) calculations compare ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ formation on CNT catalysts with different O functional groups $\scriptstyle { \mathrm { C = O } }$ , C—OH, COOH). As illustrated in Figure 4d, previous studies and in situ Raman spectroscopy results[8,2] have proposed that ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation in PMS activation may involve three steps: PMS activation $\mathrm { \langle ^ { * } H S O _ { 5 }  ^ { * } S O _ { 4 } + ^ { * } O H \rangle }$ , O formation $( 2 ^ { \ast } \mathrm { O H }$ $ ^ { * } \mathrm { O } + \mathrm { H } _ { 2 } \mathrm { O } )$ , and the subsequent formation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ [5,29]When both PMS and DCP are added, the intensity of the peaks from the $\mathrm { O - } \mathrm { O }$ bond and $\mathrm { S O } _ { 3 } ^ { - }$ gradually declines, indicating that PMS is activated via $\mathrm { O - } \mathrm { O }$ bond cleaving, and subsequently decomposes into ${ } ^ { \ast } \mathrm { S O } _ { 4 }$ and $\ast \mathrm { O H }$ , confirming the three-step process (Raman spectra in Figure S27, Supporting Information). Thus, the reaction free energies of these steps on the different CNT models are calculated, and the corresponding free energy diagrams are shown in Figure 4e. The calculation results show that the efficiency of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation on $\scriptstyle \mathrm { C = O }$ is superior to that of other O functional groups. $\scriptstyle \mathrm { C = O }$ enhances ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation across CNTs due to the reduced adsorption strength of $\mathrm { H O ^ { \ast } }$ on edge carbon atoms. Also, the electron transfer from CNTs to adsorbed PMS molecules increases the net positive charge on CNTs (specifically incorporating $\mathrm { C } { = } \mathrm { O }$ functional groups), thereby elevating their surface potentials (Figure S28, Supporting Information). These calculation results support that the $\scriptstyle \mathrm { C = O }$ on CNTs are the most active sites for PMS activation.

Can the $\mathrm { C } { = } \mathrm { O }$ on other carbon materials also effectively activate PMS? CNTs have a long-range $s p ^ { 2 }$ -hybridized graphitic structure compared to other carbon materials. We hypothesize that this is also important in the superior catalytic performance of sonicated CNT catalysts. For comparison, sonicated carbon black (CB, Super P) is tested as a reference carbon catalyst. CB has a lower electrical conductivity $( 2 6 3 2 ~ \mathrm { S ~ m ^ { - 1 } }$ , Table S5, Supporting Information) with a lower $\mathrm { C } { = } \mathrm { O }$ abundance of $0 . 2 8 8 ~ { \mathrm { a t . } } \%$ (Table S12, Supporting Information). Pristine CB exhibits a much inferior $k _ { \mathrm { o b s } }$ of $0 . 0 2 5 \ \mathrm { m i n ^ { - 1 } }$ (Figure 4c). Sonicated CB-1.0 exhibits fewer $\mathrm { C } { = } \mathrm { O }$ but significantly increased COOH and $\mathrm { C - O H }$ (Figure S25 and Table S12, Supporting Information). Consequently, its DCP removal performance $( k _ { \mathrm { o b s } } = 0 . 0 0 9 \operatorname* { m i n } ^ { - 1 } )$ is worse than the pristine CB. HCHO chemisorption is applied to CB-0 to increase its $\scriptstyle \mathrm { C = O }$ abundance to $0 . 5 5 5 \ \mathrm { a t . \% }$ (Table S12, Supporting Information) comparable to CNT $\cdot 0 _ { \mathrm { H C H O } }$ $( 0 . 6 0 3 \mathrm { a t . } \% )$ . CB $0 _ { \mathrm { H C H O } }$ delivered improved $k _ { \mathrm { o b s } }$ of $0 . 0 5 8 \ \mathrm { m i n ^ { - 1 } }$ , doubled from CB-0 but still 9.3 times lower than CNT $\cdot 0 _ { \mathrm { H C H O } }$ $( 0 . 5 3 8 \mathrm { m i n ^ { - 1 } }$ , Figure 4c). These results indicate that the long-range graphitic structure and the proper type and concentration of O functional groups (i.e. $\mathrm { C } { = } \mathrm { O }$ are both critical for the observed superior catalytic performance of sonicated CNT catalysts.

# 2.5. Sonicated CNT Catalysts for Practical Point-of-Use Water Treatment

The practical application potentials of sonicated CNT catalysts/oxidants are comprehensively investigated. Except for PMS, sonicated CNT-1.0 can also effectively activate several other common oxidants, such as peroxydisulfate and hypochlorous acid, which can completely remove $5 0 \mu \mathrm { M }$ DCP within $5 \mathrm { { m i n } }$ (Figure S29, Supporting Information). Sonicated CNT-1.0/PMS shows more efficient and stable performance for DCP removal in DI water and real water than radical oxidation mechanism-based Fe powder/PMS under different pH conditions (Figure S30 and Table S13, Supporting Information), highlighting the superior nonradical oxidation for treating distributed water.

As the operation extends further, the removal efficiency slowly declines and retains ${ \approx } 9 0 \%$ after $2 0 5 \mathrm { h }$ (Figure 5e), indicating reasonable longterm stability under realistic water conditions.

# 3. Conclusion

Sonicated CNTs serve as a high-performance catalyst for activating the solid oxidant PMS to degrade contaminants. The optimal CNT-1.0 catalyst achieves complete DCP removal within $5 ~ \mathrm { m i n }$ exhibiting an exceptionally high degradation rate of $0 . 6 1 6 \mathrm { { m i n } ^ { - 1 } }$ With a remarkable potential (k-value) at $4 . 8 0 \mu \mathrm { m o l } \ \mathrm { g } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ , CNT1.0 outperforms recently reported catalysts. Detailed studies indicate that over $9 8 \%$ of DCP removal is attributed to nonradical oxidation pathways, with $67 \%$ resulting from singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ oxidation and $3 1 \%$ from direct electron transfer (DET). Through correlation analysis, deactivation experiments, and DFT calculations, we reveal that the $\scriptstyle \mathrm { C = O }$ groups formed on CNTs during sonication act as the primary catalytically active sites. Interestingly, CNTs with excessive defects exhibit reduced efficiency in generating ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , causing the dominant DCP removal pathway to shift from ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ oxidation to DET in more defective CNT catalysts. Sonicated CNT catalysts demonstrate strong potential for practical applications with various oxidants and under diverse environmental conditions, effectively reducing both the TOC and the potential toxicity of wastewater. The optimal CNT-1.0 catalyst is successfully integrated into flat CNT membrane and hollow fiber filtration modules. These devices demonstrate high pollutant removal efficiency and maintain stable performance over $1 1 5 \mathrm { ~ h ~ }$ when treating natural river water. Importantly, sonicated CNT catalysts can be produced at scale, paving the way for their application in point-of-use water treatment systems for more sustainable freshwater production and other environmental remediation technologies.

The electrolyte was saturated with Ar for 30 min before each test.

The CNT catalyst ink was prepared by dispersing $2 \mathsf { m g }$ of catalyst in a $\rceil \mathsf { m L }$ mixture of ${ 9 9 0 \mu \mathrm { L } }$ IPA $( 9 0 \% )$ and $1 0 \mu \iota$ Nafion117 solution $( 5 \mathrm { ~ w t . \% } )$ by $\rceil \textrm { h }$ bath sonication. About $2 0 . 0 ~ \mu \mathrm { L }$ suspension was drop cast on the glassy carbon electrode and dried at room temperature, affording a mass loading of ${ \approx } 0 . 2 ~ \mathsf { m g c m } ^ { - 2 }$ .

LSV and CV curves were collected between 0.1-1.5 V (vs $\sf A g / A g C l$ )at a scan rate of $2 0 \mathsf { m } \mathsf { V } \mathsf { s } ^ { - 1 }$ with and without $0 . 5 ~ \mathsf { m M }$ PMS and $0 . 1 ~ \mathsf { m M }$ DCP. The open circuit potential change after adding $0 . 5 ~ \mathsf { m M }$ PMS $( \Delta E _ { \mathsf { P M S } } )$ or $0 . 1 \mathsf { m M }$ DCP $( \Delta E _ { \mathsf { D C P } } )$ was obtained by a 20 min CP measurement. The potential difference between PMS and DCP on the ultrasonicated CNTs surface (∆E, V) was calculated by Equation (4):

$$
\Delta E = \Delta E _ { 1 } + \Delta E _ { 2 }
$$

where $\Delta E _ { \rceil }$ and $\Delta E _ { 2 }$ represent the potential variations after the addition of $0 . 5 ~ \mathsf { m M }$ PMS or $0 . 1 \mathsf { m M }$ DCP in 0.1 M PBS, respectively.

The amperometric it curves of CNT catalysts were conducted in the PBS electrolyte with and without $0 . 5 ~ \mathsf { m M }$ PMS or/and $0 . 1 ~ \mathsf { m M }$ DCP at 0.3 and $0 . 8 \mathsf { V }$ (vs $\mathsf { A g } / \mathsf { A g C l } )$ , respectively. ECSA $( \mathsf { m } ^ { 2 } \mathsf { g } ^ { - 1 } )$ of the CNTs were estimated from the DLC determined by CV measurements conducted in a non-Faradaic region $( 0 . 3 \mathrm { - } 0 . 4 \ V$ vs $\mathsf { A g } / \mathsf { A g C l } )$ in 0.5 M ${ \sf H } _ { 2 } { \sf S } { \sf O } _ { 4 }$ at difference scan rates (5, 10, 20, 30, 40, and $5 0 \ m \ V ^ { - 1 }$ , Figure S6, Supporting Information). The double layer capacitance $( \mathsf { C } _ { \mathsf { d } \mathsf { l } } , \mathsf { m } \mathsf { F } )$ was assessed from the slope of the linear regression between the current density differences and the scan rates (Figure S7, Supporting Information), and the ECSA was calculated by Equation (5):

$$
E C S A = \frac { C _ { \mathrm { d l } } } { C _ { s } }
$$

where $C _ { s }$ is the specific capacitance of carbon materials $( 0 . 0 2 ~ \mathsf { m F } ~ \mathsf { c m } ^ { - 2 } ,$ .[34]

DFT Calculations: DFT calculations were performed using the Vienna Ab initio Simulation Package (VASP). The generalized gradient approximation (GGA) with the RPBE functional was employed to describe the exchange-correlation effects.[5] The plane-wave basis6set energ cutoff (ENCUT) was set to $5 2 0 ~ { \mathsf { e V } }$ to ensure accurate results. Spin-polarized calculations were performed, allowing for the consideration of magnetic effects. The electronic convergence criterion was set to $1 \times 1 0 ^ { - 6 }$ eV, while the convergence criterion for ionic relaxation was set to $- 0 . 0 5$ eV $\mathring { \mathsf { A } } ^ { - 1 }$ . We utilized the DFT-D3[37] method with Becke-Johnson damping to account for van der Waals interactions, ensuring that dispersion forces were included.
