# A B S T R A C T

Keywords: High-valent iron-oxo species Single-atom catalysts Peroxymonosulfate Molybdenum disulfide Advanced oxidation processes

Efficient heterogeneous iron-based catalysts have demonstrated great potential for advanced oxidation processes (AOPs). In this study, enhancement of peroxymonosulfate (PMS)-based pollutant elimination was achieved through two approaches: maximizing exposed Fe sites and producing high-valent iron-oxo $( \mathrm { F e } ^ { \mathrm { I V } } { = } 0 )$ species. To this end, crumpled nanospheres of molybdenum disulfide $( c n \mathbf { M o S } _ { 2 } )$ were fabricated, followed by the coating of nitrogen/carbon species to accommodate single-atom Fe- ${ \bf \cdot N _ { 4 } }$ sites. The resulting catalysts of Fe-N-C- ${ \cdot } c n \mathbf { M o S } _ { 2 }$ were employed for degradation of 2,4,6-trichlorophenol (TCP) and other pollutants via PMS activation. The optimum 0.7Fe-N-C-cnMoS2/PMS system achieved $1 0 0 ~ \%$ TCP removal within only ${ 5 } \mathrm { { m i n } }$ , along with good resistance to environmental disturbances. The $\mathrm { F e - N } _ { 4 }$ single sites and $c n \mathbf { M o S } _ { 2 }$ substrate worked synergistically for efficient catalysis, with the former playing a predominant role. Classical quenching and EPR experiments demonstrated that reactive radicals of $\cdot _ { \mathrm { O H } }$ , $S O _ { 4 } ^ { \bullet - }$ and $\mathrm { O } _ { 2 } ^ { \bullet - }$ were generated in the $0 . 7 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 } / \mathrm { P M S }$ system. However, these were not the key driving forces in the decontamination processes. Further exploration demonstrated that the dominant reactive species for TCP degradation were $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ , rather than traditionally recognized radicals. DFT calculations revealed that Fe- $\cdot \mathrm { N } _ { 4 } .$ C and $\mathbf { M o S } _ { 2 }$ in the catalyst cooperatively expedited the PMS adsorption and binding, thus facilitated the $\mathrm { F e ^ { \mathrm { I V } } { = } } 0$ generation.

# 1. Introduction

In recent years, several techniques have been adopted for pollutant removal from waste water bodies, e.g., advanced oxidation processes (AOPs) [1], adsorption [2] and biodegradation [3]. Among these technologies, AOPs based on peroxymonosulfate (PMS) activation are considered a promising strategy, because of the advantages of simple operation, mild reaction conditions and high oxidation efficiencies [4,5]. However, the low capacity of direct oxidation using PMS leads to low or even no efficiency of AOPs. Under particular conditions, PMS can be activated to generate reactive oxygen species (ROSs), which possess strong oxidation capabilities and can oxidize refractory organic compounds to $\mathrm { C O _ { 2 } }$ and $_ \mathrm { H _ { 2 } O }$ [6,7]. Metal-based nanomaterials (such as Co [8], Fe [9] and Cu [10] etc.) are commonly known as the effective catalysts and have been widely developed for PMS activation. However, achieving outstanding performances with these metal-based nanomaterials remains challenging. Recent efforts have primarily focused on improving the density of accessible active metal atoms so as to enhance the degradation activity. Beyond that, the types of produced ROSs also exert critical roles, and have attracted increasing attention nowadays. During AOPs, typical radicals of $S O _ { 4 } ^ { \bullet - }$ and • OH are commonly produced and mainly contributed to decontamination, but these conventional radicals suffer from some issues like short lifetimes and environmental interferences. Alternatively, synergistic production of high-valent ironoxo $( \mathrm { F e } ^ { \mathrm { I V } } { = } 0 )$ species is more favorable, since the non-radical of $\mathsf { F e } ^ { \mathrm { I V } } { = } 0$ has several superior features to traditional radicals, for example, higher steady-state concentration, stronger redox potential, longer lifetime and unaffected oxidative properties by water backgrounds [11–13]. Nevertheless, the production of $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ species is not easy to achieve.

Single-atom catalysts (SACs) are a category of charming materials with atomic level precision, which shows the features of minimized size of the metal species, and thus maximizes the metal utilization [14,15]. In the AOPs, SACs have garnered extensive attention as well owing to their unique structural superiorities [16,17]. In particular, by regulating the coordination environment of the single-atom sites, generation of $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ species has been recently realized on the conformation of singleatom Fe- $\mathbf { \cdot N _ { 4 } }$ sites [18]. Thus, fabrication of SACs seems to be an efficient strategy to acquire $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ species. To date, numerous nanomaterials have been applied as the substrates of SACs, for example, mesoporous silica [19,20], reduced graphene oxide [21,22], carbon nitride [23,24] and carbon materials [25,26]. Among the alternatives, molybdenum disulfide $( \mathbf { M o S } _ { 2 } )$ stands out as a two-dimensional (2D) transition metal dichalcogenide material with significant anisotropy properties, structural flexibility and good stability [27,28]. $\mathbf { M o S } _ { 2 }$ has been explored in various applications, such as photocatalysis [29], electrocatalysis [30], lithium-ion batteries [31] and supercapacitors [32]. As the case stands, $\mathbf { M o S } _ { 2 }$ nanomaterials have been ever directly used as a PMS stimulator in AOPs, although they exhibit relatively low performances [33]. Additionally, $\mathbf { M o S } _ { 2 }$ has frequently been reported to enable accelerating the redox cycling of metal sites like $\mathbf { M } ^ { \mathrm { n + } } / ^ { ( \mathrm { n + 1 } ) }$ , which is conducive to improving the pollutant removal activity in PMS-based AOPs [34,35]. Therefore, $\mathbf { M o S } _ { 2 }$ is a promising candidate to serve as the support of SACs for PMS-based AOPs.

In this study, as depicted in Fig. 1, crumpled nanospheres of $\mathbf { M o S } _ { 2 }$ $( c n \mathbf { M o S } _ { 2 } )$ were fabricated, and a carbon shell was then coated around the whole $c n \mathbf { M o S } _ { 2 }$ core to facilitate nitrogen doping, which was prone to interface with metal atoms. Single-atom Fe sites were successfully anchored on the nitrogen/carbon coated $c n \mathbf { M o S } _ { 2 }$ to obtain Fe-N-C$c n \mathbf { M o S } _ { 2 }$ . The single Fe atoms were well observed on aberration corrected (AC) HAADF-STEM, and the configuration of $\mathrm { F e - N _ { 4 } }$ sites was precisely determined by EXAFS. In Fe-N-C- ${ \cdot } c n \mathbf { M o S } _ { 2 }$ catalysts, the single-atom Fe$\mathrm { N } _ { 4 }$ sites played a leading role, and $c n \mathbf { M o S } _ { 2 }$ activated PMS in a secondary role for 2,4,6-trichlorophenol (TCP) elimination. The optimum 0.7Fe-NC-cnMoS2/PMS system spent merely 5 min on complete degradation of TCP, and good resistance to environmental disturbances was also demonstrated. Mechanistic studies revealed that • OH, $S O _ { 4 } ^ { \bullet - }$ and $\mathrm { O } _ { 2 } ^ { \bullet - }$ radicals were produced during catalysis; however, they were not the primary contributors. $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ species were further identified as the dominant oxidants driving TCP elimination. Theoretical calculations suggested that under the cooperation between $\mathrm { F e - N } _ { 4 }$ -C and $\mathbf { M o S } _ { 2 }$ , the adsorption and activation of PMS was promoted, and $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ production was facilitated. This work is the first time to produce $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ species through combined effects of single Fe atoms and $\mathbf { M o S } _ { 2 }$ , then provides new insights into $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ acquisition.

# 3.2. TCP removal by Fe-N-C-cnMoS2/PMS systems

Chlorophenols in water resources are considered to be priority control pollutants due to their high toxicity, persistence, and potential biological accumulation [41]. TCP is the representative of the chlorophenols, and has been universally used in agriculture and chemical industry, which indirectly threatens human health [42]. Therefore, there is an urgent need to eliminate TCP from wastewater. The catalytic performances of prepared materials were then evaluated by degradation of TCP via PMS activation. As presented in Fig. 5a, PMS alone was unable to remove TCP, indicating the limited reactivity of PMS without activation. The catalysts were first subject to $3 0 \ \mathrm { m i n }$ of adsorption, and the removal of TCP was ${ \sim } 1 8 . 8 \%$ for $c n \mathbf { M o S } _ { 2 }$ , $\mathbf { N } { \cdot } \mathbf { C } { \cdot } c n \mathbf { M } \mathbf { o } S _ { 2 }$ , and ${ \sim } 3 6 . 6 \%$ for $0 . 3 { - } 1 . 0 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 }$ . After adsorption, $0 . 7 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 }$ was collected for further FT-IR analysis. As profiled in Fig. S7, the bands located at ${ \sim } 1 5 5 0$ and $1 0 3 5 ~ \mathrm { c m } ^ { - 1 }$ are assigned to ${ \mathrm { C } } { = } { \mathrm { C } } / { \mathrm { C } } { \mathrm { - C } }$ of benzene ring and C-O vibrations respectively [43], suggesting the TCP adsorption on the material. After addition of PMS, the activity of $c n \mathbf { M o S } _ { 2 }$ and N-CcnMoS2 on TCP removal was only slightly improved, getting $3 9 . 0 \%$ and $4 0 . 7 \%$ within $1 0 \mathrm { m i n }$ , respectively. The weak promotion was probably attributed to $c n \mathbf { M o S } _ { 2 }$ substrate, which stimulated PMS to generate some radicals. It was delightful that the catalytic degradation of TCP was significantly increased in the Fe-N-C-cnMoS2/PMS systems. The 0.3, 0.5, 0.7 and $1 . 0 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 }$ catalysts completely removed TCP within only 8, 7, 5 and $1 0 ~ \mathrm { { m i n } }$ , respectively. Since whether doping Fe was the only difference between $\mathrm { N - C - } c n \mathrm { M o S } _ { 2 }$ and $\mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 }$ , the significantly enhanced catalytic activity of Fe-N-C- $c n \mathbf { M o S } _ { 2 }$ was probably due to the Fe- $\mathbf { \cdot N _ { 4 } }$ single sites in the lattice. It was found that the addition of Fe was in a trace amount of no more than $1 . 0 ~ \mathrm { w t } \%$ , yet high catalytic activity was attainable. That was to say, the atomically dispersed Fe- $\mathbf { \cdot N _ { 4 } }$ sites in $\mathrm { F e { - } N { \mathrm { - } } C { \mathrm { - } } c n M o S _ { 2 } }$ demonstrated exceptionally high activity for the catalysis. Notably, the removal efficiencies of TCP improved with the growing of Fe content from 0.3 to $0 . 7 \mathrm { \textrm { w t } } \%$ in Fe-N-C-cnMoS2, and declined while further increasing Fe loading up to $1 . 0 \mathrm { w t } \%$ . The decline might be due to the distortion of the nanospherical structure, which restrained the catalytic activity. Therefore, we adopted 0.7Fe-N-CcnMoS2 as the optimum catalyst for the subsequent investigations.

# 3.3. Identification of ROSs in 0.7Fe-N-C-cnMoS2/PMS system

In order to investigate the ROSs produced in the 0.7Fe-N-C-cnMoS2/ PMS system, classical quenching experiments were performed. EtOH was known to be a quencher of $\cdot _ { \mathrm { O H } }$ and $S O _ { 4 } ^ { \bullet - }$ ; TBA was always effective for quenching $\cdot _ { \mathrm { O H } }$ , but less efficient for $S O _ { 4 } ^ { \bullet - }$ ; p-BQ and L-his were scavengers for $0 _ { 2 } ^ { \bullet - }$ and $^ 1 0 _ { 2 } ,$ respectively. $\mathrm { K _ { 2 } C r _ { 2 } O _ { 7 } }$ could readily interrupt the electron transfer process. It was reported that $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ species were also possibly generated in the Fe- $\mathrm { \cdot N } _ { x } / \mathrm { P M S }$ system [18]. Therefore, the occurrence of $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ during the TCP degradation in the 0.7Fe-N-CcnMoS2/PMS system was subsequently probed, and DMSO could be used to quench $\mathrm { F e ^ { I V } { = } } 0$ [53–55]. As presented in Fig. 6a-b, after adding L-his, only negligible change on the activity and $k$ value occurred in contrast to the original reaction, elucidating that $^ 1 0 _ { 2 }$ did not participate in the oxidation processes. When TBA and EtOH were added, the TCP removal efficiency declined from $1 0 0 \%$ in ${ \mathsf { 5 } } \operatorname* { m i n }$ to $9 7 . 8 \%$ and $9 7 . 1 \%$ in $1 0 \mathrm { m i n }$ , and the $k$ value declined from 1.022 to 0.692 and $0 . 6 6 7 \ \mathrm { \ m i n } ^ { - 1 }$ , respectively. This elucidated that $S O _ { 4 } ^ { \bullet - }$ and $\cdot _ { \mathrm { O H } }$ might not be the main ROSs. While p-BQ was added, TCP was completely degraded within 9 min with a $k$ value of $0 . 5 4 0 \ \mathrm { m i n } ^ { - 1 }$ , which manifested a slight decrease compared with the original activity, suggesting that $0 _ { 2 } ^ { \bullet - }$ was not the dominant ROSs as well. With regard to the possible role of electron transfer, ${ \bf K } _ { 2 } \mathrm { C r } _ { 2 } \mathrm { O } _ { 7 }$ was added. $1 0 0 \%$ TCP degradation was completed in $7 ~ \mathrm { { m i n } }$ with $k$ at $0 . 4 3 5 \ \mathrm { m i n } ^ { - 1 }$ , illustrating the minor role of electron transfer either. Another interesting finding was that after addition of DMSO, only $6 3 . 4 \%$ TCP was eliminated within $1 0 \mathrm { m i n }$ , and the $k$ value dramatically declined to just $0 . 2 0 6 \ \mathrm { \ m i n } ^ { - 1 }$ , which illuminated that $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ functioned as the predominant ROSs in the 0.7Fe-N-C-cnMoS2/ PMS system for TCP removal. Except for DMSO, EtOH and p-BQ also greatly quenched the degradation, which suggested the primary roles of not only $\mathsf { F e } ^ { \mathrm { I V } } { = } 0$ , but also $S O _ { 4 } ^ { \bullet - }$ , $\mathrm { O } _ { 2 } ^ { \bullet - }$ . This elucidated that single-atom $\mathrm { F e - N _ { 4 } }$ sites contributed to the high selectivity of $\mathrm { F e ^ { I V } = } 0$ production in the $0 . 7 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 } / \mathrm { P M S }$ system.

We also investigated the charge density differences of $\mathrm { F e - N } _ { 4 }$ -C and $\mathrm { F e { - } N _ { 4 } { - } C { - } M o S _ { 2 } }$ after adsorption of PMS to illustrate the charge gains and losses of PMS with the catalyst (Fig. S31). Remarkably, the charge density around $\mathrm { F e } { \cdot } \mathrm { N } _ { 4 } { \cdot } \mathrm { C } { \cdot } \mathrm { M o S } _ { 2 } { \cdot } ^ { \ast } \mathrm { P M S } { \cdot } 2$ increases significantly, resulting in more electrons being transferred from the catalyst to PMS, thus probably facilitating the formation of $\mathrm { F e } ^ { \mathrm { I I I } } \mathrm { O O S O } _ { 3 }$ intermediate and resulting $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ site along with deprotonation (losing H) and release of $S O _ { 4 } ^ { \bullet - }$ . This engenders an augmented potential per unit of PMS, thereby elevating the overarching conversion frequency of the entire reaction. In addition, further studies show that the interaction of $\mathbf { M o S } _ { 2 }$ with $\mathrm { F e - N _ { 4 } }$ -C could modulate the $\mathrm { e _ { g } }$ -orbital filling of Fe site along with inducing the rearrangement of the electronic structure after the adsorption of PMS on

$\mathrm { \bf { \dot { e } } - N _ { 4 } - C - M o S _ { 2 } } ,$ , which in turn promotes the adsorption and activation of PMS (Figs. S32–33). It suggests that the interaction of $\mathbf { M o S } _ { 2 }$ with Fe- $\mathrm { N } _ { 4 }$ -C leads to the increase in the adsorption energy at the Fe site, which is favorable for PMS adsorption. The initial step in the generation of $\mathrm { F e } ^ { \mathrm { I V } } { = } 0$ is just the adsorption of PMS on the surface of the catalyst rather than direct transformation of PMS. The higher adsorption strength between PMS and $\mathrm { F e - N _ { 4 } { \mathrm { - } } C { \mathrm { - } } M o S _ { 2 } }$ than that of PMS and $\mathrm { F e - N } _ { 4 } .$ -C is critical for the subsequent $\mathrm { F e ^ { \mathrm { I V } } = } 0$ production. That is to say, the composites of $\mathbf { M o S } _ { 2 }$ and $\mathrm { F e - N } _ { 4 } .$ -C improve the adsorption strength toward PMS, which significantly weakens the decomposition of PMS at the beginning. After PMS is adsorbed on $\mathrm { F e } { \cdot } \mathrm { N } _ { 4 } { \cdot } \mathrm { C } { \cdot } \mathrm { M o S } _ { 2 }$ , the single Fe site is bonded with O atom to form $\mathrm { F e } ^ { \mathrm { I I I } }$ -O-O- $S O _ { 3 } ,$ , and then $S O _ { 4 } ^ { \bullet - }$ is released to form $\mathsf { F e } ^ { \mathrm { I V } } { = } 0$ .

# 4. Conclusions

This work aims to promote the performance of AOPs from two aspects, i.e., the fabrication of single metal sites and production of ROSs of $\mathrm { F e ^ { I V } = } 0$ . The Fe-N-C-cnMoS2 nanospheres with crumpled surfaces were prepared and applied to activate PMS for degradation of TCP. Single Fe atoms were anchored on the unique $\mathrm { N - C - } c n \mathrm { M o S } _ { 2 }$ matrix in the configuration of $\mathrm { F e - N } _ { 4 }$ . During AOPs, $\mathrm { F e - N } _ { 4 }$ single sites acted as the main active species, and N-C-cnMoS2 cooperated to efficiently activate PMS and rapidly degrade TCP. The optimum 0.7Fe-N-C-cnMoS2 could eliminate $1 0 0 ~ \%$ of TCP within 5 min through PMS stimulation. Moreover, the $0 . 7 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 } / \mathrm { P M S }$ system for degradation of TCP demonstrated an excellent performance at a wide working pH range and in the presence of inorganic ions. The reason for these excellent performances was due to a new mechanism that the degradation was dominated by $\mathrm { F e } ^ { \mathrm { I V } } mathrm { = } 0$ and little by $\cdot _ { \mathrm { O H } }$ , $S O _ { 4 } ^ { \bullet - }$ , $0 _ { 2 } ^ { \bullet - }$ as for $0 . 7 \mathrm { F e - N - C - } c n \mathrm { M o S } _ { 2 } / \mathrm { P M S } ,$ which was different from the traditional PMS-based heterogeneous catalysts. DFT stimulation suggested that as compared to $\mathbf { M o S } _ { 2 }$ or $\mathrm { F e - N } _ { 4 } .$ - C, it was $\mathrm { F e - N } _ { 4 } { \mathrm { - C - M o S } } _ { 2 }$ more favored binding to the PMS and thus facilitated $\mathsf { F e } ^ { \mathrm { I V } } { = } 0$ generation. This study provides a new idea for designing heterogeneous catalysts for the preferable production of highvalent metal-oxo in water treatment.
