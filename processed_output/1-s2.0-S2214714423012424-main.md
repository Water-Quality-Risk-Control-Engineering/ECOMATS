# . Introduction

Agro-industrial needs increase with the global population, also increasing the amounts of generated agro-industrial wastewaters [1,2]. These waste waters contribute to the pollution of environmental compartments due to their complexity and frequent improper treatment and management. Different physicochemical and biological technologies [35] have been extensively investigated to treat olive mill waste water (OMW). However, most of these technologies still need to be improved to solve this problem [3,6].

Advanced oxidation processes (AOPs) and technologies (AOTs) generate reactive oxygen species (ROS), chlorine species (RCS) or sulphur species (RsS), which can degrade and mineralise organic contaminants, being recognised as efficient solutions to treat wastewater [7]. Several AOTs have been previously employed for the treatment of OMW, such as ozonation [8,9], heterogeneous photocatalysis [1036], electrochemical oxidation [3739], and Fenton-mediated processes [4046]. Heterogeneous photocatalysis has attracted increasing interest since it can be operated under mild conditions. It offers the possibility to employ artificial visible or solar light to properly excite a photocatalyst by generating ROS, RCS, and RSS [4749]. Among the many photocatalysts available, metal-based materials represent the vast share of published papers, and titanium dioxide $\mathrm { ( T i O _ { 2 } ) }$ is a benchmark photocatalyst reported in many studies for OMW treatment [1033]. More recently, other metal oxides have appeared as alternatives for the photocatalytic treatment of OMW, such as ZnO [34] and $\mathrm { C u C r _ { 2 } O _ { 4 } }$ [35,36]. In some of these studies, the photocatalytic process is assisted with persulfate (PS) activation [35,36].

Graphitic carbon nitride (GCN) is a material that can be obtained by simple synthesis routes and efficiently removes organic pollutants from water, the complexation of metals and bacterial inactivation [50,51]. The main advantages of employing GCN instead of $\mathrm { T i O } _ { 2 }$ in photocatalysis are its metal-free nature and activation under visible light. Moreover, GCN is stable under different $\mathsf { p H }$ media and requires only water and dissolved oxygen to generate ROS [52]. Allied with these advantages, GCN can photo-activate hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ , promoting an additional pathway for ROS formation [53,54]. Furthermore, this material has been shown to enhance photo-Fenton-like processes [55], photocatalysis [56], and photocatalytic chlorine activation [57]. In our previous work [52], we demonstrated that aromatic compounds could act as potential proton donors for the photocatalytic generation of ROS, viz. $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , with GCN. Thus, this material is expected to succeed in treating wastewater rich in aromatic compounds and with high organic loads.

In this work, we propose an innovative photocatalytic treatment of OMW, i.e., using GCN. These waste waters impact different compartments (water bodies pollution and soil deterioration) and organisms (e. g., plant growth inhibition) if improperly released into the environment. The eco- and phytotoxicity of the phenolic compounds present in OMW have been observed through various studies [5861]. The correct disposal of OMW is crucial since conventional wastewater treatment plants (centralised or not) cannot properly remove the compounds present in OMW. Hence, a photocatalytic treatment with a GCN material is explored in the current work, together with adding $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or other oxidising agents (i.e., persulfate salt and free chlorine) to assess their effectiveness for organic matter and phenolic content removal. To the best of our knowledge, no similar investigation concerns the role of a metal-free GCN photocatalyst in treating OMW.

# 2.3. Analytical techniques

Chemical oxygen demand (CoD) was determined by closed reflux and colourimetry method (Method 5220D). Briefly, for COD measurements, samples were mixed with a digestion solution (aqueous solution of $\mathrm { H _ { 2 } S O _ { 4 } }$ $\mathrm { K _ { 2 } C r _ { 2 } O _ { 7 } }$ and $\mathrm { H g } S 0 _ { 4 } .$ and with ${ \tt A g s S O 4 }$ to minimise chloride interference, heated up to $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { ~ h ~ } }$ and, after cooling, the absorbance was measured at $4 2 0 ~ \mathrm { { n m } }$ . Dissolved organic content (DOC) was analysed in a Shimadzu TOC-5000 A apparatus. Specific ultraviolet absorbance was determined by Method 415.3 of the U.S. Environmental Protection Agency.

Total phenolic (TPh) content was determined by a modified FolinCiocalteau method [12]. Briefly, $2 0 ~ \mu \mathrm { L }$ of the sample was diluted in $1 5 8 0 ~ \mu \mathrm { L }$ of ultrapure water and mixed with $1 0 0 ~ \mathrm { u L }$ Folin-Ciocalteu reagent. After resting for $5 \mathrm { \ m i n }$ $3 0 0 ~ \mu \mathrm { L }$ of $\mathrm { N a _ { 2 } C O _ { 3 } }$ was added to the solution. The samples were left in dark conditions for $^ { 2 \mathrm { ~ h ~ } }$ before reading the absorbance at $7 5 3 \ \mathrm { n m }$ to determine the equivalent gallic acid molarity. The absorbance of liquid aliquots was analysed in a JASCO V560 spectrometer.

The concentration of inorganic species was analysed by ion chromatography, in a Metrohm 881 Compact IC Pro equipment, with a Metrosep A Supp 7 anionic column $( 2 5 0 \mathrm { m m } \times 4 . 0 \mathrm { m m } )$ and a Metrosep C4 cationic column $( 2 5 0 \ \mathrm { m m } \times 4 . 0 \ \mathrm { m m } )$ .

Aromatic compounds present in the samples were identified by highperformance liquid chromatography (HPLC) in a Hitachi Elite LaChrom instrument (Japan) equipped with a diode array detector (L-2450), a Purospher Star RP-18 column $( 2 5 0 ~ \times ~ 4 . 6 ~ \mathrm { m m }$ , $5 ~ { \mu \mathrm { m } }$ particles), and solvent pump $\left( L - 2 1 3 0 \right)$ at a flow rate of $1 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ . The HPLC method started with an equilibrated A:B (20:80) mixture of $1 \ \%$ acetic acid and $0 . 5 ~ \%$ acetonitrile in methanol (A) and $1 \ \%$ acetic acid in water (B) for $2 0 \mathrm { { m i n } }$ , followed by a gradient to A:B (60:40) at $4 5 \mathrm { { m i n } }$ and another to A:B (10:90) at $6 0 \ \mathrm { m i n }$ and finally to A:B (20,80) in $5 \ \mathrm { m i n }$ . The absorbance values were read at $2 5 4 ~ \mathrm { n m }$ .

Aliphatic compounds in both original and treated waters were analysed by HPLC in a Hitachi Elite LaChrom equipment equipped with a UV detector and Grace Alltech OA-1000 column $( 3 0 0 ~ \mathrm { m m } \times 6 . 5 ~ \mathrm { m m } )$ . The eluent method consisted of an isocratic run with $5 \mathrm { m M }$ of $\mathrm { H } _ { 2 } S 0 _ { 4 }$ and a steady flow rate of $0 . 5 ~ \mathrm { m L } ~ \mathrm { m i n } ^ { - 1 }$ , the absorbance being read at a wavelength of $2 0 0 \ \mathrm { n m }$ .

# 2.4. OMW sampling and characterisation

The OMW samples were collected after coagulation and decanting treatments in an olive oil mill in the northern region of Portugal. These samples were filtered using $4 0 ~ { \mu \mathrm { m } }$ membrane filters and then stored in the dark at $4 ~ ^ { \circ } \mathrm { C }$ before use. The OMW used in the present work is $1 2 , 0 2 0 \mu \mathrm { S } \mathrm { c m } ^ { - 1 }$ a TPh content of $3 5 7 \pm 6 7 \mathrm { \ m g _ { G A } L ^ { - 1 } }$ and relatively high values of DOC $( 3 7 3 5 \pm 5 5 \mathrm { \ m g _ { C } \ L ^ { - 1 } ) }$ and COD $( 2 9 , 4 1 1 \pm 5 0 1 ~ \mathrm { { m g } _ { 0 2 } \ : L ^ { - 1 } } )$ , which are values commonly found in the literature for OMW [61,68,69]. It is noteworthy to mention that the amounts of chlorides $\left( 3 0 . 3 5 ~ \mathrm { m g ~ L } ^ { - 1 } \right)$ and aluminium $( 2 6 . 5 4 \ m g \ L ^ { - 1 } )$ are related to the Kemira PAX-18 coagulant (composed of aluminium polychloride) used for treating the olive oil mill wastewater before collecting the sample.

# 2.5. Experimental conditions for OMW treatment

The experiments were performed using a cylindrical borosilicate reactor with continuous stirring and air saturation. For photo-assisted runs, a four light-emitting diode (LED) system was used with the reactor placed at the centre and $4 . 0 \mathrm { c m }$ away from each LED (maximum emission at $4 1 7 \mathrm { n m }$ , average intensity of $2 5 0 \mathrm { W } \mathrm { m } ^ { - 2 }$ , measured with an OceanOptics USB ${ 2 0 0 0 + }$ spectrometer). For photocatalytic experiments, before turning on the LEDs $( t = 0 \mathrm { m i n } )$ ), the powdered material (GCN or $\mathrm { T i O } _ { 2 } )$ was dispersed in the aqueous matrix and stirred under air purging for $^ { 1 \mathrm { ~ h ~ } }$ in dark conditions to achieve the adsorption-desorption equilibrium. In selected experiments, an oxidising agent was added in the liquid phase while the LEDs were switched on. The selected oxidising agents were $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ NaOCl for the free chlorine (FC) species $\mathrm { ( H O C l / C l O ^ { - } ) }$ and $\mathrm { K _ { 2 } S _ { 2 } O _ { 8 } }$ for persulfate (PS) activation. For Fenton-based experiments, the pH was adjusted before the adsorption step, and the iron salt (to originate ferrous cations, $\mathrm { F e } ^ { 2 + }$ )was added. After the adsorption period, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ was added parallel to switching on the LEDs, with the $\bar { \mathrm { F e } } ^ { 2 + }$ : $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ratio being kept at 1:25, according to the literature [61,70].

Using a photolytic treatment without $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ slightly reduces the TPh $( < 7 \% )$ and DOC contents $( < 1 0 \% )$ in $^ { 6 \mathrm { h } }$ However, when $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is used (500 or $1 0 0 0 \ \mathrm { m M } )$ under visible light, the TPh content is reduced by ${ > } 5 0 ~ \%$ in the same period (Fig. 2a). This TPh reduction can be promoted by inorganic species naturally present in the OMW matrix (Table 1), such as $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ and $\mathrm { { C u } ^ { 2 + } ( T a b l e 1 ) }$ , which can activate the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ molecule [71]. Electrophilic activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ through hydrogen bonding with phenolic-related organic compounds can also occur [72,73]. It is also important to note that the photolysis of chloride anions $( \mathbf { C l } ^ { - } )$ , present in this OMW, can generate $\mathbf { \boldsymbol { C 1 } } ^ { \bullet }$ , $\mathrm { C l } _ { 2 } ^ { \bullet - }$ or ClO' (with weaker oxidation power than the Fenton-desired hydroxyl radicals) [74,75]. Some works have reported the effect of relatively low amounts of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in the removal of phenol in aqueous solutions [7981], diverse phenolic compounds in synthetic OMW [82], and even in the treatment of real OMW [61,83]. # 3.2. Photocatalytic treatment of OMW

Literature concerning the photocatalytic treatment of OMW was thoroughly examined and is listed in Table S1. The majority of studies were carried out using $\mathrm { T i O } _ { 2 }$ , and thus we employed this catalyst as a reference material. As abovementioned, the morphology and crystallinity of $\mathrm { T i O } _ { 2 }$ and GCN can be observed by SEM and XRD in Figs. S1 and S2, respectively. In particular, the optical properties of GCN and $\mathrm { T i O } _ { 2 }$ were characterised by DRUV-Vis spectroscopy. The LED emission peak was confirmed to fall within the absorption of either material, with a substantial overlap for GCN (Fig. 1). Only a fraction of the $\mathrm { T i O } _ { 2 }$ absorption overlaps with the LED emission, therefore the studies regarding OMW treatment with this catalyst employ radiation below $4 0 0 \ \mathrm { n m }$ as observed in Table S1. In contrast, GCN has a marked bathochromic absorbance shift (concerning $\mathrm { T i O } _ { 2 } )$ , thus being effectively activated by 417 nm-centred excitation.

The photocatalytic treatment of OMW was attempted using both GCN and $\mathrm { T i O } _ { 2 }$ materials individually and adding different $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ dosages (resulting in concentrations ranging between 0 and $1 0 0 0 \ \mathrm { m g \ L ^ { - 1 } } )$ , the results being shown in Fig. 2. As described in Table S1, some papers have also reported the combination of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted oxidation with photocatalysis with $\mathrm { T i O } _ { 2 }$ , but employing UV illumination [12,13,18,23,25].

Under visible light irradiation without $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (i.e., $0 \mathrm { m g L } ^ { - 1 }$ f $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ , GCN allowed for higher decreases of both TPh and DOC contents in $^ { 6 \mathrm { h } }$ $( 2 4 . 5 ~ \%$ and $1 8 . 6 ~ \%$ , respectively) than $\mathrm { T i O } _ { 2 }$ $1 6 . 2 ~ \%$ and $9 . 0 ~ \%$ respectively). In both cases, these photocatalytic removals were higher than those obtained with photolysis alone (Fig. 2a and b).

Adding $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ up to a concentration in the liquid phase of $5 0 0 ~ \mathrm { m M }$ , offered higher TPh and DOC removals (Fig. 2) since the photocatalysts can adequately activate the oxidising agent. However, a higher $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration $\mathbf { \Omega } ^ { \mathrm { ~ \tiny ~ 1 0 0 0 ~ m M } }$ is not recommended, probably due to scavenging effects since $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in excess can react with the generated hydroxyl radicals and promote its self-decomposition into water [84]. For instance, TPh removals of $7 5 . 1 \ \%$ and $5 1 . 1 \ \%$ were achieved with GCN and $\mathrm { T i O } _ { 2 }$ in $^ { 1 \mathrm { ~ h ~ } }$ of treatment using $5 0 0 ~ \mathrm { m M }$ of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ while $8 9 . 5 ~ \%$ and $8 3 . 0 ~ \%$ were obtained in $^ \textrm { \scriptsize 6 b }$ .These TPh removals were lower by employing $1 0 0 0 ~ \mathrm { { m M } }$ of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ,i.e., $8 4 . 1 ~ \%$ and $7 7 . 9 ~ \%$ with GCN and $\mathrm { T i O } _ { 2 }$ in $^ { 6 \mathrm { h } }$ . Both TPh and DOC contents generally decrease and reach a plateau, suggesting that removing intermediate compounds, or some parent ones, is difficult in these conditions.

The most prominent difference between GCN and $\mathrm { T i O } _ { 2 }$ was observed regarding the mineralisation (Fig. 2d and f). At the optimal $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration of $5 0 0 ~ \mathrm { m M }$ $\mathrm { T i O } _ { 2 }$ only reached $1 9 . 7 ~ \%$ DOC removal in $6 \mathrm { ~ h ~ }$ while GCN achieved $6 8 . 2 \%$ DOC reduction. The superior elimination of DOC with the GCN material in comparison with $\mathrm { T i O } _ { 2 }$ may be attributed to two hypotheses: (i) visible-light irradiation is not sufficient to activate the $\mathrm { T i O } _ { 2 }$ catalyst properly, even though there is a small overlap between the $\mathrm { T i O } _ { 2 }$ absorbance and the LED emission spectra, and (ii) the more adequate energy levels of GCN to catalyse $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ conversion into radicals. $\mathrm { T i O } _ { 2 }$ presents a band gap energy of $3 . 1 \ \mathrm { e V }$ , demonstrating the need for a wavelength smaller than $4 0 0 \mathrm { n m }$ to promote the photo-excitation of this optical semiconductor [85]. In comparison, GCN has a band gap of 2.8 eV and thus can be easily activated with the selected $4 1 7 \mathrm { n m }$ irradiation (Fig. 1). At the same time, the conduction band of GCN can promote the necessary reduction reactions of dissolved oxygen and spiked $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ into oxy-radical species [86].

Moreover, the inorganic matter in the OMW can heavily influence the photocatalytic process, such as the ionic species listed in Table 1. The OMW collected in this work shows a relatively high content of carbonates, chlorides, ammonium, sodium and calcium ions, and some can lead to the generation of reactive species under irradiation [87,88] or by contact with oxy-radical species [8991]. Besides iron, other dissolved metals, like copper (Table 1), may also induce the activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ as a Fenton-like catalyst, promoting the oxidation treatment [92]. However, these species can also hinder photoactivity by (i) inducing light attenuation, (ii) promoting the scavenging of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and photogenerated reactive species, or (ii) obstructing active sites by being adsorbed in the heterogeneous catalyst surface. It has been previously reported that these naturally-occurring species in different waters and wastewater can lead to complex interactions during oxidation reactions; therefore, it is difficult to predict the actual impact in photocatalysis [76].

# 3.3. Effect of adding GCN in Fenton and activation of free chlorine or persulfate

Considering the results of the previous sections, the next set of experiments was conducted in the presence of GCN and $5 0 0 \mathrm { m M }$ of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . The GCN photocatalytic treatment, with $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { G C N } + \mathrm { L E D } )$ and without $( \mathrm { G C N } + \mathrm { L E D } )$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , was compared to Fenton $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + } )$ in natural pH (4.8) and acidic pH (2.8) conditions, and when adding other oxidising agents: free chlorine (FC) and persulfate (PS), instead of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . These oxidation processes $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } , \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + }$ , $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + } ( \mathrm { p H } = 2 . 8 ) ,$ FC and PS) were tested alone and also under LED irradiation (LED), and in the presence of both GCN and LED irradiation $( \mathrm { G C N } + \mathrm { L E D } )$ . The resulting TPh, DOC and COD removals in $^ { 3 \mathrm { h } }$ of treatment are shown in Fig. 3a, b and c, respectively.

Photocatalysis alone $( \mathrm { G C N } + \mathrm { L E D } )$ lead to a negligible removal of TPh content (Fig. 3a). However, TPh reduction is notorious when an oxidising agent is present, i.e., 35.1, 78.9 and $4 8 . 7 ~ \%$ for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ FC and PS, respectively. Adding visible light to the system has little influence on FC activation (as the HOCl species has poor absorption at $4 1 7 ~ \mathrm { n m }$ . At the same time, the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { L E D }$ and $\mathrm { P S } + \mathrm { L E D }$ experiments resulted in high TPh removals $( 5 3 . 1 ~ \pm ~ 0 . 3 ~ \%$ and $7 4 . 4 \ : \pm \ : 0 . 3 \ : \%$ , respectively) compared to the results in dark conditions $( 3 5 . 1 \pm 0 . 3 \%$ and $4 8 . 7 \pm 0 . 3$ $\%$ , respectively). Visible-LED irradiation can form radicals from dissolved organic matter, a natural photosensitiser, that activates $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [93,94] and potentiates PS activation to some extent [9597].

Dark Fenton $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + } )$ leads to high TPh removals $( 8 8 . 7 \%$ and $9 4 . 7 ~ \%$ in natural and acidic $\mathrm { p H }$ ,respectively). Combined with the ferrous ion, visible-light illumination, as well as the GCN catalyst, integrated with Fenton oxidation, lead to a consistent enhancement in the abatement of the TPh content. Ferrous ions at natural pH, visible-light, and GCN $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + } { + } \mathrm { G C N } + \mathrm { L E D } )$ can enhance TPh removal up to $9 7 . 4 \%$ , Adjusting the pH to 2.8 (typically used for Fenton reactions), the TPh removal is also high $( 9 3 . 6 ~ \% )$ .

In terms of mineralisation (Fig. 3b), it is observed that the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . assisted photocatalytic system $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \ + \ \mathrm { G C N } \ + \ \mathrm { L E D } )$ is successful, reaching $6 3 . 9 ~ \%$ DOC removal, while the FC and PS processes, with visible-light and catalyst $( \mathrm { F C } \ + \ \mathrm { G C N } \ + \ \mathrm { L E D }$ and $\mathrm { P S } + \mathrm { G C N } + \mathrm { L E D } ,$ respectively), only allowed for 28.6 and $2 5 . 7 ~ \%$ DOC reductions. The Fenton-based processes also achieved high DOC removals, in particular with acidic conditions: $4 8 . 4 ~ \%$ , $5 4 . 3 ~ \%$ and $6 7 . 4 ~ \%$ ,respectively, for Fenton $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + } )$ , photo-Fenton $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 }  { \mathrm { ~ + ~ } } \mathrm { F e } ^ { 2  { + } }  { \mathrm { + L E D ) } }$ and photoFenton with GCN $\mathrm { ( H _ { 2 } O _ { 2 } + F e ^ { 2 + } + G C N + L E D ) }$ . Adding iron to the photocatalytic peroxidation system at natural $\mathtt { p H }$ also leads to a relatively high removal of DOC $( 6 7 . 3 \% )$ , showing that pH adjustment is not necessary when GCN is combined with the photo-Fenton process. As previously reported, iron complexation is possibly prevented owing to natural organic matter by using naturally-occurring iron chelating agents to optimise the Fenton process [98100]. It is thus noteworthy to mention that the DOC removals in the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + } { + } \mathrm { G C N } + \mathrm { L E D }$ system are only ca. $3 . 5 ~ \%$ higher than that obtained with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { G C N } + \mathrm { L E D }$ . This slight difference can be attributed to the complexity of the OMW sample since it is composed of several inorganic anions (Table 1) that could mimic photo-Fenton-like conditions to some extent in the presence of sufficient $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ GCN and visible light.

The elimination of CoD was significantly low in the experiments performed in dark conditions (Fig. 3c). The PS treatment was the least successful for the reduction of COD $( 2 8 . 4 \% )$ , improving by the presence of light $( 3 3 . 9 ~ \% )$ and catalyst $( 4 4 . 3 ~ \% )$ . For example, Oladipo [35,36] reported the use of PS-assisted photocatalytic treatment of OMW with efficient COD removals, but the authors also reports that in the absence of light or catalyst there is only residual reduction of COD. The use of FC proved somewhat more efficient $( 3 6 . 5 ~ \% )$ , with some improvements in the presence of light $( 3 8 . 5 ~ \% )$ and catalyst $( 4 6 . 3 \% )$ Then, using $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ alone was somewhat unsatisfactory, with a COD removal of only $1 5 . 5 \%$ while the photo-assisted peroxidation $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { L E D } )$ and combination with the photocatalyst $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { L E D } + \mathrm { G C N } )$ allowed for high reductions of COD up to 46.8 and $8 7 . 7 \%$ , respectively. These results were similar to the photo-Fenton treatments with GCN $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \mathrm { ~ + ~ } \mathrm { F e } ^ { 2 + } \mathrm { + L E D + G C N } )$ , which reached removals of 83.9 and $9 1 . 5 ~ \%$ , respectively, for natural and acidic pH.

The $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted photocatalytic system $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { L E D } \mathrm { + G C N } )$ was efficient for the removal of TPh $( 8 7 . 5 \pm 0 . 3 \% )$ , DOC $( 6 3 . 9 \pm 0 . 4 \% )$ and COD $( 8 7 . 7 \pm 0 . 6 \% )$ , without the need of adding iron or adjust the pH to promote Fenton or even without using a more aggressive oxidising agent, such as that needed in chlorination.

Overall, a synergistic effect was observed between adding oxidising agents with the presence of the photocatalyst, as demonstrated by the higher removal rates of the integrated processes. The presence of co-existing substances can induce parallel reactions to the reduction and oxidation of the pollutant organic molecules, being attacked by the reactive oxygen, chloride and sulphur species (respectively derived from $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ FC and PS).

Identifying aromatic compounds by HPLC in the original and treated wastewater samples can give some insights into the oxidation mechanism. The HPLC chromatograms (Fig. 4) suggest that the collected OMW contains a variety of aromatic molecules, identified by their specific retention time and absorbance spectra, such as protocatechuic, hydroxybenzoic, vanillic, coumaric, $p$ -coumaric, benzoic, syringic and caffeic acids, phenol, catechol and tyrosol, typical of OMw [35]. After GCN photocatalytic treatment, integrated with any of the studied options $\mathrm { ( H _ { 2 } O _ { 2 } }$ , Fenton, FC or PS), the vast majority of these compounds were degraded. Only small peaks could be found in the HPLC chromatograms, suggesting small amounts of protocatechuic, hydroxybenzoic, $p$ -coumaric, coumaric and benzoic acids, among others (Fig. 4a). Moreover, the collected OMW seems to contain low molecular weight carboxylic acids, namely malonic, succinic, propionic, butyric and isobutyric acids (Fig. 4b), also typical of these wastewaters [105]. The treated samples showed the persistence of the latter two compounds, in particular in the absence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ where the signals remain significantly high, as the HPLC peaks from the FC and PS treated samples have triple intensity than those of Fenton or peroxidation.

The ultraviolet absorbance (measured at $2 5 4 \mathrm { n m }$ can also be used to assess, in a broad sense, the quantity of aromatic compounds content in liquid samples. However, the specific ultraviolet absorbance (SUVA) can unbiasedly characterise the dissolved organic load. The values of $\mathtt { A b s } _ { 2 5 4 }$ and $\mathrm { S U V A } _ { 2 5 4 }$ , obtained for the collected OMW and the samples after $^ { 3 \mathrm { h } }$ of treatment, are shown in Fig. 5. It is noteworthy to mention the decreased absorbance of the treated OMW despite the treatment conditions, owing to the conversion of aromatic molecules capable of absorbing visible light. Adding GCN to the LED-assisted $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } +$ $\mathrm { F e } ^ { 2 + }$ , FC, and PS systems allowed to obtain lower absorbances, with the peroxidation $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { G C N } + \mathrm { L E D ) }$ and chlorination $( \mathrm { F C } + \mathrm { G C N } + \mathrm { L E D } )$ alternatives leading to some of the smaller absorbance values, i.e. 0.271 and 0.167, respectively.

The SUVA values allow us to infer the composition of the analysed samples in terms of the relative abundance of aromaticity and low molecular weight aliphatic compounds [106,107]. The Fenton-assisted treatments achieved good TPh removals (Fig. 3a); however, they still show high values of both $\mathtt { A b s } _ { 2 5 4 }$ and SUVA (Fig. 5), i.e., a vast range of aromatic compounds are present in the Fenton-treated samples. In the case of photocatalytic peroxidation, the values of SUVA are much lower, meaning that the aromatic fractions were significantly degraded. That was also observed, to some extent, in the PS and FC-assisted processes. Overall, the presence of the photocatalyst leads to a more significant reduction of SUVA for the several treatment alternatives, meaning that GCN aids in converting refractory aromatics into low molecular weight aliphatic compounds.

# 3.4. GCN reuse

The GCN reuse was studied for the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted photocatalytic system $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { G C N } + \mathrm { L E D } )$ , and consecutive cycles of $^ { 6 \mathrm { ~ h ~ } }$ each were performed using the same catalyst after recovering the powder catalyst by filtration and rinsing the material with $5 0 \mathrm { m L }$ of distilled water. It can be seen in Fig. 6a and b that the removal profiles of TPh and DOC remain very similar in 3 cycles. Therefore, after the $1 ^ { \mathsf { s t } }$ and $3 ^ { \mathrm { r d } }$ cycles, the used catalyst and the fresh material were analysed by photoluminescence emission (PL, Fig. 6c) and Fourier-transform infrared (FTIR, Fig. 6d) spectroscopy. The main difference between the PL spectra of fresh and used catalysts is the lower emission intensity for the used ones, probably owed to occupied charge transfer sites by adsorption of dissolved matter from the OMW. In the case of FTIR, we can observe an overall decrease of band intensity as some of the previously available surface groups can be occupied or blocked, owed to the adsorption of dissolved OMW matter on specific sites of GCN. Notably, the GCN catalyst after the $1 ^ { \mathrm { s t } }$ and $3 ^ { \mathrm { r d } }$ reuses show nearly the same PL emission and FTIR spectra, suggesting some modification in the first run that is reached and maintained in the subsequent cycles.

# 4. Conclusions

The photocatalytic and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted photocatalytic treatments of an olive mill wastewater were investigated with a metal-free GCN photocatalyst, which performed better than $\mathrm { T i O } _ { 2 }$ since visible-light LEDs $( \lambda _ { \mathrm { m a x } } = 4 1 7 \mathrm { n m } )$ were employed in this study. Moreover, GCN was tested for activating other oxidant agents besides $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , such as free chlorine and persulfate, and also tested with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { F e } ^ { 2 + }$ mimicking Fenton conditions (in acidic and natural $\mathsf { p H }$ . Employing visible-light-activated GCN was exceptionally favourable, as it vastly improved the performance of the added oxidants $\mathrm { ( H _ { 2 } O _ { 2 } }$ , free chlorine or persulfate) compared to their effect alone in dark conditions. The highest DOC and COD removals were observed for the photocatalytic system adding $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (63.9 and $8 7 . 7 \ \%$ or integrated with the Fenton system (67.4 and 91.5 $\% )$ . The high efficiency of the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -assisted photocatalytic system $\mathrm { ( H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { G C N } + \mathrm { L E D ) }$ suggests no need for adding iron salts, chemicals for pH adjustment or more complex oxidising agents. Moreover, the catalyst is stable and reusable when treating this wastewater with high organic contents, indicating that this photocatalytic process can be further investigated to develop sustainable technologies for efficiently treating olive mill wastewater.
