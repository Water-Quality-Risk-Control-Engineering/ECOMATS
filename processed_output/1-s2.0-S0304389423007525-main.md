# . Introduction

The peroxymonosulfate-based advanced oxidation process (PMSAOPs) is a promising approach which can efficiently transforming refractory organic pollutants into inorganic matter or stable organic matter via activating PMS [36,54]. The productions of reactive oxygen species (ROs) via activating PMS, play a significant role due to their higher redox potential than precursor (C. [4,16]; Q. [47]). In recent years, a variety of catalysts have been developed to promote PMS activation and accelerate the production of oxygen species [11,12,23]. The technology of using earth-abundant transition metals as single atom catalysts (SACs) has become one of the most active hotspots in the field of catalysis because of its highest atomic utilization, unique electron structure and adjustable coordination structure [9,21,25,46,49]. Synchronously, graphene materials play an important role in catalytic degradation as one of the most widely used SACs substrate materials.

One of the advantages of SACs is tunable electron structure, which can be regulated by the change of coordination environment (including coordination number and coordination atom) [56]. Therefore, manipulating the electron structure of SACs to promote the catalytic activity is crucial toward efficient degradation of recalcitrant organics. For example, Du et al. introduced S onto the $\mathrm { C o } @ \mathrm { N C }$ (designated as $\mathrm { C o - } S ( \mathscr { O } _ { \mathrm { N C } } )$ , which enhanced the excitation of the electron conductance of the original catalyst and boosted the generation of radicals as well as nonradicals [10]. With this strategy, introducing heteroatom S into the SACs, the coordination of metal and S is a potential method to expedite catalytic activity [44]. Notably, regulating the number of coordinated non-metallic heteroatoms can be an efficient way to regulate the electron structure of the metal center. Wang et al. found that the Co-N-C catalyst exhibited significant activity and selectivity [20,42,52], when the coordination number of N decreased from 4 to 2. The introduction of non-metallic coordination heteroatoms and the regulation of coordination heteroatoms have great potential to reconstruct the electron structure of SACs ( [43]). So comprehensive understanding of this mechanism is a prerequisite for rational design and construction of efficient SACs. However, it is difficult to advance this process owing to the experiments depend on a large number of material synthesis processes, which takes a long time and cannot accurately control the number of coordination heteroatoms. With the development of theoretical simulation, density functional theory (DFT) has become a powerful auxiliary tool in the field of environmental catalysis, which can design material structures on demand at the atomic-scale and reveal the intrinsic properties of materials [13,27,36,37,54]. More importantly, a series of descriptors have been developed to characterize the interaction between PMS and catalysts, and have shown advantages in determining PMS dissociation transition states and assessing the reaction pathways [18,26,37].

Fe is the cheapest and most abundant transition metal on earth. Previous research has shown that Fe-based SACs can maintain high catalytic activity and stability in a wide pH range. Doping of S-coordination atoms can change the highest occupying orbit of Fe and regulate the catalytic behavior of metal centers [32,41,43,49]. In this work, we investigated the coordination environment on the electron structure of Fe-based SACs by DFT calculations. Six SACs with different S coordination numbers were designed, namely $\mathrm { F e } { \cdot } S _ { \mathrm { X } ^ { - } } C _ { 4 - \mathrm { X } }$ (x represents the number of coordinated S atoms from 0 to 4; 4-x is the number of doped C atoms). The stability and electron structures of $\mathrm { F e } { \cdot } S _ { \mathrm { X } ^ { - } } \mathrm { C } _ { 4 - \mathrm { X } , }$ the adsorption energy and dissociation energy barrier of PMS upon interacting with Fe ${ \cal S } _ { \mathrm { X } ^ { - } } \mathrm { C } _ { 4 - \mathrm { X } }$ were explored. The findings can be used to revealing the dependence between PMS activation and the electron structure of the active site of SACs. This work reduces part of the experimental exploration and provides theoretical guidance for the preparation of SACs with high catalytic activity in the future.

# 2. Calculation method

The calculations were carried out using Vienna Ab-initio Simulation Package (VASP) [33]. The Perdew-Burke-Ernzerhof (PBE) within the generalized gradient approximation (GGA) was selected for the exchange-correlation potentials. The projector augmented-wave (PAW) method was employed to treat interactions between ion cores and valence electrons [33]. In addition, the cut-off energy of $5 0 0 \mathrm { e V }$ was set for the plane wave basis set. All atoms in the calculated model were fully allowed to relax until the force was less than $0 . 0 2 \ : \mathrm { e V } / \mathring { \mathrm { A } }$ , the maximum displacement was set to $0 . 0 5 \mathrm { ~ \AA ~ }$ and the change in energy was smaller than $1 0 ^ { - 5 } \mathrm { e V } / \mathring { \mathrm { A } }$ [14,52]. It is worth emphasizing that the PBE we used in this study suffers from the problem of underestimating the bandgap, mainly due to the spurious self-interaction error (SIE). Wong et al. propose the Fermi-Löwdin (WFL) self-interaction correction method, which provides a better bandgap prediction, and similarly, Janesko et al. summarize the partial self-interaction error elimination methods, such as $\mathrm { D F T + U }$ , self-interaction corrections, etc. This is necessary for future simulation work. [15,19,38] Despite the drawbacks of the PBE generalization, a reasonable qualitative analysis can be obtained for some properties that need to be predicted in this work, and we choose the PBE generalization in view of accuracy and low computational cost.

Applying periodic boundary conditions is helpful to minimize edge effects. We chose the lattice parameters $\mathbf { a } = \mathbf { b } = \mathbf { \bar { 1 6 . 8 } } \mathrm { \AA }$ to simulate the calculation [46]. We designed six catalyst models, namely, $\mathrm { F e - } S _ { 0 } \mathrm { - } C _ { 4 } ,$ . Fe $S _ { 1 } – C _ { 3 } .$ $\mathrm { F e { - } } S _ { 2 0 \mathrm { r t h o } ^ { - } } C _ { 2 }$ ,F $- S _ { \mathrm { 2 p a r a } } – \mathrm { C } _ { 2 } ,$ Fe $\cdot S _ { 3 } – \mathrm { C _ { 1 } }$ , $\mathrm { F e - } S _ { 4 } \mathrm { - } C _ { 0 }$ consisting of 127 C and 1 Fe atom, 126 C, 1 Fe and 1 S atom, 125 C, 1 Fe and $_ { 2 \mathrm { ~ S ~ } }$ atoms, 124 C, 1 Fe and 3 S atoms, 123 C, 1 Fe and 4 S atoms. The vacuum layer was $2 0 \mathring { \mathrm { A } }$ to avoid the interaction of two periodic structures in the dimension normal to the surface. A $2 \times 2 \times 1$ K-point gird was used in the Brillouin zone of all calculation models for structural optimization [33]. And a $4 \times 4 \times 1$ k-point grid was used for electron structure calculations. Finally, the energy for PMS dissociation reaction steps were assessed by climbing image nudged elastic band method (Cl-NEB) [17]. K-point and cut-off energy used in this study have been tested, refer to Table S2 and S3. The HOMO and the LUMO of aBPA were calculated by Gaussian 16 at the B3LYP/631 $\mathbf { G } ^ { * }$ level of theory. Grimme's DFT-D3 (BJ) empirical dispersion correction was adopted [3].

The adsorption energy of PMS $\mathrm { ( E _ { a d s } ) }$ was defined as follows:

$$
\mathrm { E _ { a d s } = E _ { t o t a l } - E _ { s u b s } - E _ { P M S } }
$$

The ${ \mathrm { E } } _ { \mathrm { t o t a l } } , { \mathrm { E } } _ { \mathrm { s u b s } } ,$ and $\mathrm { E } _ { \mathrm { P M S } }$ were defined as the energy of catalysts with PMS, catalysts, and free PMS, respectively.

The charge density was further investigated in this work. The fragment-based differential charge density is calculated as the total density of the system minus the charge density of adsorbed molecules and model catalysts, and the calculation formula is as follows : .

$$
\Delta \rho = \rho \mathrm { A } / \mathrm { B } \textrm { - } \rho \mathrm { A } \textrm { - } \rho \mathrm { B }
$$

$\boldsymbol { \rho } \mathbf { A } / \mathbf { B }$ is the total charge density between the adsorption molecule and the substrat. ρA and $\rho \mathbf { B }$ are the charge density between the adsorption molecule and the substrate (or model catalyst), respectively. The electron interaction between the adsorbed molecule and the model catalyst can be analyzed by the calculation and analysis of the fragmentbased differential charge density.

In order to identify the adsorption site of PMS and investigate the effect of coordination environments on the electron structure, the Bader charge and charge density differences were analyzed. The Fe and S atoms are both positively charged, but the Fe atom possesses a much higher positive charge than the S atoms $( \mathrm { F e } ^ { \delta + } > \mathsf { S } ^ { \delta + } )$ , indicating that the Fe atom facilitated the adsorption of negatively charged PMS. Moreover, the introduction of S makes the charge of the local environment of Fe-SxC4-x active center more and more positive [5,53]. The S atoms also have the potential to contribute electrons to PMS through the Fe atom.

# 3.4. Identification of ROS generation mechanism in the $F e { - } S _ { x ^ { - } } C _ { 4 - x } / P M S$ system

The kinetic process of PMS activation is also crucial and decisive to determine the catalytic reaction process. The maximum energy barrier to be overcome during the transition from reactants to products in a reaction path is defined as the reaction energy barrier for that path, which provides the kinetic information of the reaction. Therefore, the transition state search method (TS) was used to evaluate the reaction energy barrier of PMS. The Cl-NEB method modified by G. Henkelman was used in this study, which is considered to be one of the most efficient methods for searching transition states. The calculated reaction energy barrier is shown in Fig. 5b. This shows the three structure profiles for the TS reactions [17,40,50,54]: PMS molecule adsorption on the catalysts, transition intermediate structure and peroxide bond dissociation [55]. # 3.5. Degradation of BPA on the Fe. $S _ { X ^ { - } } C _ { 4 - X }$ catalysts

To further understand the feasibility of $\mathrm { F e - } S _ { \mathrm { X } ^ { - } } \mathrm { C } _ { 4 - \mathrm { X } }$ catalysts for the elimination of organic contaminants in water, bisphenol A (BPA) was chosen as a model molecule for further analysis. First of all, considering the adsorption configuration between BPA and $\mathrm { F e - } S _ { \mathrm { X } ^ { - } } \mathrm { C } _ { 4 - \mathrm { X } }$ catalysts, the DFT simulaitons for BPA at two possible adsorption sites of S and Fe were conducted. Compared with the positive adsorption energy at S site, the negative adsorption energy between BPA and $\mathrm { F e - } S _ { 4 } – C _ { 0 }$ catalyst at Fe site is more conducive to the activation of pollutant molecules, thus promoting the further electron transfer of organic molecules. At the same time, the dual index ∆f(r) was used to analyze the main active site of the bisphenol A molecule. The main difference between the double descriptor and the Fukui function is that the double descriptor can show both nucleophilic and electrophilic reaction sites without the need to examine $\mathbf { f } ^ { + }$ and f separately, and is therefore more convenient. The dual index Δf(r) concept was first introduced by Morell, who demonstrated the plausibility of this index through calculations combined with experiments. It is more likely to be a pro-potential site with increasing negativity of $\Delta \mathrm { f } ( \mathbf { r } )$ value, while, the increasing positivity of $\Delta \mathsf { f } ( \mathbf { r } )$ value will lead the greater vulnerability to nucleophilic attack. [31]. It is well known that •OH are electrophilic radicals, and for the reaction of •OH attacking bisphenol A, we should focus on the region where $\Delta \mathbf { f } ( \mathbf { r } ) < 0$ which is prone to electrophilic reactions. As shown in Table 3, C12, C5,

C2, and C15 with low $\Delta \mathrm { f } ( \mathbf { r } )$ values in the BPA molecule are the main active sites for the electrophilic radicals (•OH) attack. The HOMO of BPA (Fig. 6b) indicates that these benzene ring regions tend to lose electrons, wchich are the main sites of radical attack [10,2,37,39]. And the corresponding lowest unoccupied molecular orbital (LUMO) was described in Fig. 6d. Integrated analysis of double index and molecular orbital diagrams, C5 and C12 of BPA are the most vulnerable sites to attack, which may lead to the breakage of the C5-C21 bond (or C12-C21 bond) and the decomposition of the two compounds. It is consistent with the reported degradation path of BPA, first breaking the para-carbon atom of the hydroxyl group on the benzene ring [35,48,7]. This degradation pathway was also confirmed by the ESP mapping of BPA, C5 and C12 are red regions in BPA, with negative electrostatic potential values, indicating that this region is more likely to give electrons and be vulnerable to attack by electrophilic radicals.

According to theoretical calculation, the degradation of BPA is mainly through radical attack on C12 and C5 sites, C2 and C15 sites, to generate organic intermediates such as phenol and benzyl alcohol, and then these organic intermediates are further transformed into smaller intermediates through lysis and hydrolysis, and finally converted into carbon dioxide and water.
