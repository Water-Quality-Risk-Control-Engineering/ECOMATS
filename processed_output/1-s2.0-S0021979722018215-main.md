# ABSTRACT

Peroxymonosulfate (PMS) driven by halloysite nanotubes (HNTs) modified with nanomanganese cobaltate $( \mathrm { M n C o } _ { 2 } 0 _ { 4 } )$ ) generates reactive oxygen species (ROS) that offer high degradation efficiency and mineralization rates for many typical antibiotic pollutants, such as ornidazole (ONZ). The experimental results show that halloysite nanotubes (HNTs) modified with nanomanganese cobaltate $\mathrm { ( M n C o _ { 2 } O _ { 4 } @ H N T s }$ denoted as $\mathsf { M C O @ H N T s } ,$ ) can degrade ONZ completely over a wide pH range (6.08– 11.00) with little influence of the pH value. MCO@HNTs $^ +$ PMS exhibited higher catalytic activity and lower Co- and Mn-ion leaching rates. It also showed a strong anti-interference effect on natural lake water and anions. Additionally, PMS can be quickly activated and consumed in natural lakes to avoid secondary pollution. The roasting of MCO@HNTs showed good catalytic activity and stability after degrading ONZ. The combination of ion quenching and electron paramagnetic resonance (EPR) analysis illustrated that the MCO@HNTs $^ +$ PMS system had a strong oxidation capacity, and the produced singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ was the main ROS for ONZ degradation. The degradation pathway of ONZ via the MCO@HNTs $^ +$ PMS system was proposed based on the types of intermediates determined via liquid chromatography-mass spectrometry (LC-MS). This comprehensive study shows the preparation of a simple, environmentally friendly, and cheap PMS activation catalyst that has practical application value in the treatment of antibiotic wastewater and provides a focus on actual water testing with residual amount of PMS.

# 1. Introduction

In recent years, with the large-scale development of the pharmaceutical and laundry industries, the production and use of pharmaceuticals and personal care products (PPCPs) has grown rapidly, and the associated environmental problems have intensified [1,2]. PPCPs include many antibiotic drugs, among which ornidazole (ONZ) is a typical third-generation nitroimidazole antibiotic. ONZ is widely used in dental and gastrointestinal surgeries due to its excellent activity against anaerobic bacteria, longer elimination half-life, and greater ability to penetrate lipid tissues compared to other antibiotics [3,4]. The high water solubility $( 4 . 3 3 ~ \mathrm { g / L } )$ and low biodegradability of ONZ lead to its enrichment in aquatic environments, from where it is difficult to remove. ONZ reportedly has potential genotoxic, carcinogenic, and mutagenic properties. Even at low concentrations in the environment, ONZ can accumulate in the human body through the food chain, thereby harming ecosystems and human health [3,5,6]. Therefore, there is an urgent need to develop methods to efficiently degrade ONZ. The methods reported in the literature to degrade and remove antibiotics from aquatic environments (biodegradation, adsorption, photodegradation, etc.) have several shortcomings, such as complicated processes, difficulty in removing low-concentration residues, and high energy requirements [7–9].

With continuous improvements in removal processes and gradual development of the technology, advanced oxidation processes (AOPs) have become mainstream for antibiotic degradation because of their simple operation, high efficiency, mild reaction conditions, and the generation of non-selective reactive oxygen species (ROS). AOPs based on persulfate (PS) have proven to be powerful remediation technologies for polluted water bodies. Compared with traditional hydroxyl radicals ( $. 0 \mathrm { H } \ 1 . 8 \substack { - 2 . 7 \mathrm { ~ V } } ,$ ), sulfate radicals $\left( { \mathrm { S O } } _ { 4 } ^ { \cdot - } \right)$ have stronger oxidative powers (2.5–3.1 V), wider operative $\mathsf { p H }$ ranges (2.00–9.00), and longer half-lives ( ${ \cdot } 0 \mathrm { H } \leq 1 ~ \mu s$ and $\mathsf { S O } _ { 4 } ^ { - - } : 3 0 { - } 4 0 \mu s )$ ）[10–12]. $S 0 _ { 4 } ^ { \cdot - }$ is, in general, generated by the activation of peroxymonosulfate (PMS) or peroxodisulfate (PDS) by alkali, heat, radiation, or reaction with transition metals. The $_ { 0 - 0 }$ bond in its structure is broken, and $S O _ { 4 }$  and OH, as well as ROS, such as singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ and superoxide radicals $( 0 _ { 2 } ^ { \cdot - } )$ , are generated under the continuous action of external energy [13]. Among the various activation methods, efficient and easy-to-operate transition metal activation has been more widely studied than high-cost physical activation. PMS has an asymmetric structure and a shorter bond length compared to PDS, and is thus more easily activated by transition metals. In addition, PMS may also generate ${ } ^ { 1 } 0 _ { 2 }$ as the main ROS for pollutant degradation, which means that the degradation pathway would be dominated by nonradicals [14]. Cobalt-based bimetallic oxides have been widely studied in heterogeneous catalytic reactions for transition metal activation of PMS to generate ROS. The coupled transformation of ${ \mathsf { C o } } ^ { 2 + } / { \mathsf { C o } } ^ { 3 + }$ can accelerate electron transfer, thereby rapidly activating PMS and slowing the release of Co [15,16]. Among transition metals, manganese has attracted much attention because of its abundant content, low toxicity, and multiple valence states $( \mathrm { M n ^ { 2 + } / M n ^ { 3 + } / M n ^ { 4 + } } )$ , which are beneficial for promoting redox reactions [17,18]. The cobalt-manganese doublegold oxides that have been reported are not very active; moreover, there is a risk of cobalt ion leaching because of the possibility of agglomeration during crystallization [15,19,20].

In this study, our strategy was to precipitate cobalt-manganese bimetallic compounds on substrates with large specific surface areas. Among the many available substrates, natural clay minerals attracted our attention. As natural clays, halloysite nanotubes (HNTs) are abundant, inexpensive, and nontoxic. They have abundant hydroxyl groups on their surfaces and hollow structures, which result in high specific surface areas and strong anion/cation exchange capacities [21–23]. They are therefore excellent metal ion carriers. In this study, a new catalyst was prepared by the $\Nu _ { 4 _ { 2 } } .$ - ${ \mathrm { C O } } _ { 3 }$ co-precipitation method. Cobalt-manganese bimetallic oxides $\left( \mathrm { M n C o _ { 2 } O _ { 4 } } \right)$ ) were fixed on HNTs $( \mathrm { M n C o } _ { 2 } 0 _ { 4 } @ \mathrm { H N T s }$ , denoted as $\mathsf { M C O @ H N T S }$ ) to test their performance in the activation of PMS and the subsequent degradation of the target pollutant ONZ. To demonstrate the excellent performance of MCO@HNTs, nonanchored $\mathsf { M n C o } _ { 2 } \mathsf { O } _ { 4 } ( \mathsf { M C O } )$ , cobalt oxide $C 0 _ { \bf x } 0 _ { 1 - \bf x }$ anchored on HNTs $( \mathsf { C O @ H N T s } )$ , and manganese oxide $\mathsf { M n } _ { \mathbf { x } } \mathsf { O } _ { 1 - \mathbf { x } }$ anchored on HNTs $( \mathsf { M O @ H N T s } )$ were prepared for comparison. Comprehensive characterization and degradation experiments were carried out to study the practicability and stability of the catalyst as well as the reaction mechanism and degradation pathway of ONZ.

# 2.2. Synthesis of materials

$\mathrm { M n C o } _ { 2 } \mathrm { O } _ { 4 } @ \mathrm { H N T s }$ (denoted as x-MCO@HNTs, where $\times$ represents the mass proportion of $\mathrm { { M n C o } _ { 2 } O _ { 4 } } ,$ designated as $3 0 \%$ , $40 \%$ , $45 \%$ , $5 0 \%$ , and $5 5 \ \%$ according to the preliminary experimental results) were prepared using the $\Nu _ { 4 } \subset \mathrm { O } _ { 3 }$ co-precipitation method (Fig. 1). A solution of $\mathrm { C o } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ and $\mathsf { M n } ( \mathsf { N O } _ { 3 } ) _ { 2 } { \cdot } 4 \mathsf { H } _ { 2 } \mathsf { O }$ (each at $0 . 2 5 { \mathrm { ~ M ~ } }$ ) was prepared with $2 5 ~ \mathrm { m L }$ of ultra-pure water (solution A). HNTs in appropriate proportions were added to a solution of $\Nu _ { 4 } \subset \phantom { delimiterspace } O _ { 3 }$ $( 2 5 ~ \mathrm { m L } , 0 . 5 ~ \mathrm { M } )$ ) (solution B) and sonicated for $3 0 ~ \mathrm { { m i n } }$ . Solution A was added dropwise into solution B to form a carbonate precipitate, and the precipitated compound was then placed in a water bath at $7 0 ~ ^ { \circ } \mathrm { C }$ with stirring for $^ { 2 4 \mathrm { ~ h ~ } }$ . This caused the cobaltmanganese bimetallic salt to be fully loaded onto HNTs. After stirring, the product was washed repeatedly with ethanol and water until the solution collected after washings was pH neutral (to prevent agglomeration), and then dried in an oven at $8 0 ~ ^ { \circ } \mathrm { C } .$ . The dried precursors were calcined at $4 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 4 \mathrm { ~ h ~ } }$ under a $\Nu _ { 2 }$ atmosphere at a heating rate of $5 ~ { } ^ { \circ } { \mathsf { C } } \operatorname* { m i n } ^ { - 1 }$ . For the control experiments, samples of MCO, $5 0 ~ \% - \mathrm { C O @ H N T s }$ , and $5 0 \%$ -MO@HNTs were prepared using the aforementioned process but without the addition of HNTs, $\mathsf { M n } ( \mathsf { N O } _ { 3 } ) _ { 2 } { \cdot } 4 \mathsf { H } _ { 2 } 0$ , or ${ \mathrm { C o } } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ .

# 3. Results and discussion

# 3.1. Characterization of composite materials

The X-ray diffraction (XRD) patterns of the MCO@HNTs, MCO, ${ \mathsf { C O @ H N T s } }$ , $\mathsf { M O @ H N T s }$ , and HNTs are shown in Fig. 2a. Diffraction peak of HNTs at $2 6 . 9 9 ^ { \circ }$ (0 02) corresponds to $\mathsf { A l } _ { 2 } \mathsf { O } _ { 3 } { \cdot } 2 \mathsf { S i O } _ { 2 } { \cdot } 3 \mathsf { H } _ { 2 } \mathsf { O }$ (JCPDS:38-0449). The diffraction peak at $4 0 . 0 4 ^ { \circ }$ (0 4 0) is not distinct, which may be either because of the decrease in the crystallinity of HNTs after heat treatment at $4 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ \mathrm { ~ 3 ~ h ~ }$ , or destruction of the crystal structure of HNTs during hightemperature calcination. The peak (1 01) at $2 1 . 9 8 ^ { \circ }$ in the pattern of HNTs is attributed to $\mathrm { S i O } _ { 2 }$ (JCPDS:39-1425). It can also be seen from Fig. 2a that the crystallinity of MO@HNTs is significantly higher than that of ${ \mathsf { C O @ H N T s } }$ . The three diffraction peaks at $3 2 . 3 2 ^ { \circ }$ (1 0 3), $3 6 . 0 9 ^ { \circ }$ (211), and $5 9 . 8 4 ^ { \circ }$ (224) indicate that the crystal lattice in MO@HNTs is mainly from $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ (JCPDS: 24- 0734). The diffraction peaks exhibited by the CO@HNTs are mainly attributed to halloysite, and the cobalt oxides may have an amorphous structure or an extremely small lattice. The diffraction peaks for the formed MCO are observed at $3 0 . 5 4 ^ { \circ }$ (22 0) and $3 6 . 0 0 ^ { \circ }$ (3 1 1) when cobalt and manganese are combined, indicating the formation of $\mathsf { M n C o } _ { 2 } \mathsf { O } _ { 4 }$ (JCPDS: 23-1237). The $\mathrm { M n C o } _ { 2 } \mathrm { O } _ { 4 } @ \mathrm { H N T }$ s composite is then successfully formed by the combination of MCO and HNTs.

Fig. 2b shows the fourier-transform infrared (FTIR) spectra of the MCO@HNTs, MCO, CO@HNTs, $\mathsf { M O @ H N T s }$ , and HNTs samples. The peak at $7 5 5 ~ \mathrm { c m } ^ { - 1 }$ is related to the SiAOAAl bending vibration of the halloysite unit [24], and the absorption peaks at $4 6 7 ~ \mathrm { c m } ^ { - 1 }$ and $1 0 9 5 ~ \mathrm { c m } ^ { - 1 }$ are attributed to the stretching vibration of the SiAOASi tetrahedral layer in HNTs [24,25]. The absorption peaks at $1 6 4 5 \mathrm { c m } ^ { - 1 }$ and $3 4 6 6 \mathrm { c m } ^ { - 1 }$ are attributed to the stretching vibrations of physically adsorbed and chemically bonded water molecules, respectively [26,27].

In this study, the elemental valence distribution and chemical bonding state of the composite MCO@HNTs were analyzed by Xray photoelectron spectroscopy (XPS). As shown in Fig. 2c, Co, Mn, O, C, Si, and Al are the main components on the surface of the $\mathsf { M C O @ H N T s }$ . The O 1s spectrum shown in Fig. 2d contains three convolution peaks: the peak at $5 3 0 . 0 \mathrm { e V }$ corresponds to lattice oxygen (including Co–O and Mn–O), the peak at $5 3 1 . 7 \ \mathrm { e V }$ is due to surface-adsorbed oxygen species, and the peak at $5 3 2 . 6 ~ \mathrm { e V }$ corresponds to hydroxyl oxygen [28–30]. The ${ \tt C o } 2 \tt { p }$ and $\mathtt { M n 2 p }$ spectra of the MCO@HNTs are shown in Fig. 2e and f. The peaks at 780.9 and $7 9 6 . 0 \ \mathrm { e V }$ in the Co $2 \mathfrak { p }$ spectrum are related to Co $\mathsf { 2 p } _ { 3 / 2 }$ and Co $\mathsf { 2 p } _ { 1 / 2 }$ , respectively, and the satellite peaks at 786.0 and $8 0 3 . 0 \ \mathrm { e V }$ indicate the existence of ${ \mathsf { C o } } ^ { 3 + }$ and ${ \mathsf { C o } } ^ { 2 + }$ . For Mn 2p, the peaks at 642.2 and $6 5 3 . 8 \mathrm { ~ \ e V }$ correspond to Mn $2 { \tt p } _ { 3 / 2 }$ and Mn $\mathsf { 2 p } _ { 1 / 2 }$ , respectively [31]. The conversion between $\mathsf { M n } ^ { 2 + } / \mathsf { M n } ^ { 3 + }$ and ${ \mathsf { C o } } ^ { 2 ^ { + } } / { \mathsf { C o } } ^ { 3 + }$ as redox electron pairs provides the electron energy for the activation of PMS.

As shown in Fig. S2a and b, the pristine HNTs have a tubular structure with a diameter of approximately $1 0 0 \ \mathrm { n m }$ ; however, the distribution is not uniform, and some of the tubes are broken. After calcining pristine HNTs at $4 5 0 ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { h } }$ , the tubular structure did not change significantly (Fig. S2c and d). When the HNTs combined with MCO (Fig. S2e and f), a part of the nanotube structure was destroyed due to prolonged mechanical stirring and hightemperature calcination, but the overall structure remained tubular. To confirm that HNTs still provide a large number of active sites for bimetallic oxides, transmission electron microscopy (TEM) tests were first performed on the MCO@HNTs. As shown in Fig. 3a and 3b, nanoscopic black spots with diameters of approximately $1 0 { - } 2 0 \mathrm { n m }$ are observed on the surface and periphery of the tubular HNTs. Elemental composition of the MCO@HNTs (Fig. S3a and b) was further explored using high-angle annular dark field (HAADF) (Fig. 3c) and TEM mapping (Fig. 3d) to confirm that the black spots were MCO nanoparticles. The elements in the figure include Co, Mn, Si, Al, O, and C (Figs. 3d–f and S3c–h). Co and Mn are uniformly dispersed on the surface of tubular HNTs, which is beneficial for the electron exchange between metal ions, thereby allowing rapid PMS activation. HAADF combined with TEM-EDS (Fig. 3) showed that the MCO particles were relatively uniformly distributed on the tubular HNTs, which is consistent with the scanning electron microscopy (SEM) and XPS results. The lattice fringes of the MCO@HNTs were measured at 0.250, 0.160, and $0 . 2 9 3 ~ \mathrm { { n m } }$ , corresponding to (311), (511), and (22 0) planes, respectively (Fig. S4a), which are consistent with the XRD results. The selected-area electron diffraction (SAED) results further confirmed that the MCO@HNTs were crystalline (Fig. S4b), and the manganese cobaltate nanoparticles were successfully bound and supported on the HNTs.

# 3.2. ONZ degradation experiments

ONZ was used as the target pollutant to test the catalytic performance of the MCO@HNTs composites for organic pollutants. Fig. 4a shows the UV–vis spectra of the degradation of ONZ by the MCO@HNTs $^ +$ PMS system over $2 5 ~ \mathrm { { m i n } }$ . A significant absorption peak was observed at $3 1 9 ~ \mathrm { { n m } }$ , corresponding to the optimal ONZ absorption range $2 0 0 { - } 8 0 0 \ \mathrm { n m }$ ). With increasing reaction time, the absorption peak at $3 1 9 \mathrm { n m }$ gradually approached zero, whereas the peak at approximately $2 0 0 ~ \mathrm { { n m } }$ gradually became more significant, indicating that the MCO@HNTs $^ +$ PMS system can indeed rapidly act on ONZ. ONZ was degraded into intermediates and small molecules.

To explore the effect of different manganese-cobalt metal oxide loadings on the degradation of ONZ, we performed experiments with different MCO mass ratios. As shown in Fig. 4b, with the increase in MCO content $( 3 0 - 5 0 ~ \% )$ , the degradation rate of ONZ gradually increases, and at $5 0 \%$ loading, both the amount of degradation (approximately $100 \%$ ) and the reaction rate $( 0 . 1 5 7 0 \mathrm { m i n } ^ { - 1 } ,$ ) reach maximum values. When the MCO content was increased to $5 5 \ \% $ , although $1 0 0 \%$ degradation was still achieved, the reaction rate was significantly lower $( 0 . 1 4 5 6 \mathrm { m i n } ^ { - 1 }$ ). Excessive metal loading causes surface masking of the composites, and the binding of the metals on the surface of the HNTs becomes unstable; subsequent leaching of Co and Mn during the reaction reduces the ability of the composites to activate PMS. Therefore, considering the degradation performance and environmental concerns, we chose $5 0 \% \mathrm { M C O @ H N T s }$ for subsequent experiments. In order to illustrate the advantages of HNTs combined with bimetallic oxides, we compared the performance of $\mathsf { M C O @ H N T s }$ , MCO, $\mathsf { C O @ H N T s }$ , MO@HNTs, and HNTs for ONZ degradation by PMS activation and compared the leaching rate of ${ \mathsf { C o } } / { \mathsf { M n } }$ ions in each solution by ICP-OES. As shown in Fig. S5, after $2 5 \mathrm { \ m i n }$ , the degradation of ONZ in these systems reached $100 \%$ $( 0 . 1 3 5 6 ~ \mathrm { \ m i n } ^ { - 1 } . $ ), $100 \%$ $( 0 . 1 2 2 7 \ \mathrm { m i n } ^ { - 1 }$ ), $9 9 . 7 8 \ \% ( 0 . 1 2 0 0 \ \mathrm { m i n } ^ { - 1 } )$ , $1 0 . 0 9 \ \% \ ( 7 . 9 8 1 1 \times 1 0 ^ { - 4 }$ $\operatorname* { m i n } ^ { - 1 } .$ ), and $8 . 8 8 \% ( 2 . 2 6 4 5 \times 1 0 ^ { - 4 } \mathrm { m i n } ^ { - 1 } )$ , respectively.

ONZ degradation efficiency was evaluated using different amounts of MCO@HNTs catalysts (0.20, 0.30 and $0 . 4 0 \ \mathrm { g / L } $ and PMS (0.40 and $0 . 5 0 { \mathrm { g / L } }$ ). As shown in Fig. 4d, as the catalyst loading increases from $0 . 2 0 ~ \mathrm { g / L }$ to $0 . 4 0 ~ \mathrm { g / L }$ , the degradation of ONZ also increases from $8 6 . 3 9 \ \%$ $\mathrm { 0 . 0 5 9 1 \ m i n ^ { - 1 } }$ ) to $1 0 0 \ \% \ ( 0 . 1 4 2 2 \ \mathrm { m i n } ^ { - 1 } )$ . The increase in loading provides more active sites, thereby increasing the degradation efficiency of ONZ. Similarly, when the loading of MCO@HNTs was fixed at $0 . 4 0 ~ \mathrm { g / L }$ , the degradation efficiency of ONZ gradually increased with increasing PMS concentration (Fig. S7), and the reaction rates were $0 . 0 8 7 8 ~ \mathrm { \ m i n } ^ { - 1 }$ and $0 . 1 5 0 0 \ \mathrm { \ m i n } ^ { - 1 }$ , respectively. The system provides more ROS to attack the target pollutants, thereby promoting ONZ degradation. Therefore, in this study, we fixed the PMS amount at $0 . 5 0 ~ \mathrm { g / L } .$ .

The initial pH of the solution affects the degradation rate of ONZ. It has been reported that ONZ is stable in solutions with pH below 6.0, but rapidly hydrolyzes to form diols and epoxides in alkaline solutions [32]. In this study, the degradation rates of ONZ in the $\mathsf { M C O @ H N T S } + \mathsf { P M S }$ system at pH values of 2.00, 4.00, 6.08 (ONZ solution prepared with ultrapure water), 9.00, 11.00 and 12.00 were investigated. As can be seen in Fig. S8, the degradation efficiency of ONZ gradually increases with increasing pH value (2.00–11.00). The leaching rate of ${ \mathsf { C o } } / { \mathsf { M n } }$ ions was also investigated, and results are presented in Tab. 3 and Fig. S9. Table 3 reports the average concentrations of cobalt and manganese ions, and solutions with different initial pH values in the MCO@HNTs solid catalyst after the reaction. The leaching rates (i.e. ion concentration after solution reaction/ion content in MCO@HNTs solid catalyst) of cobalt and manganese ions are shown in Fig. S9. It can be observed that excess $\mathrm { H } ^ { + }$ leads to the leaching of metal ions (especially cobalt ions) [14,33]. Simultaneously, excess $\mathrm { H } ^ { + }$ can form hydrogen bonds with the $_ { 0 - 0 }$ group of PMS, thereby inhibiting the generation of ROS [34]. These factors together indicate that the stronger the acidity, the higher the cobalt ion leaching rate and the worse the degradation effect. When the initial pH value of the solution was higher than that of pure water (6.08–11.00), the degradation efficiency increased, indicating that the $\mathsf { M C O @ H N T s + P M S }$ system had better performance for ONZ degradation under alkaline conditions. However, as ONZ is easily hydrolyzed under alkaline conditions, the content of $S O _ { 5 } ^ { 2 - }$ in the heterogeneous catalytic system increases gradually with increasing pH value. The efficiency of $S 0 _ { 4 } ^ { - - }$ production is higher for $S 0 _ { 5 } ^ { 2 - }$ than for ${ \mathsf { H S O } } _ { 5 } ^ { - }$ [14]. However, when the $\mathsf { p H }$ of the initial solution was increased to 12.00, excessive alkalinity inhibited the hydrolysis of ONZ and the generation of $S 0 _ { 4 } ^ { \cdot - }$ , which greatly reduced the degradation rate. The zero-point charge (pHpzc) of the $\mathsf { M C O @ H N T s }$ was approximately 3.25, as determined by zeta potential analysis (Fig. S10), which indicates that the surface charge of the MCO@HNTs catalyst was negative when the pH value was greater than 3.25. It can be determined from the dissociation coefficient of PMS $\mathrm { ( p K _ { a } = 9 . 4 ) }$ that, in the pH range of 0–9.4, PMS mainly existed in the form of ${ \mathrm { H S O } } _ { 5 } ^ { - }$ [35], whereas the degradation rate of ONZ gradually increased in the pH range of 6.08–11.00. Therefore, we speculate that nonradicals are the main contributors to ONZ degradation in the MCO@HNTs $^ +$ PMS system.

# 3.3. Effects of different water matrices and inorganic anions

This study investigated the performance of the MCO@HNTs $^ +$ PMS system for the degradation of ONZ in natural water samples with different nitrogen and phosphorus contents. The natural water samples were collected from three typical plateau lakes in Yunnan, China. Fig. 5a and S11 show the degradation of ONZ by the catalysts in ultrapure water and natural water samples with low, medium, and high nitrogen and phosphorus contents. In natural water with low nitrogen and phosphorus content, the ONZ degradation efficiency is much higher than that in ultrapure water. Because natural water contains a variety of ions, the asymmetric structure of PMS is easily attacked by nucleophilic ions and transition-metal catalysts, causing the rapid generation of a large amount of ROS that can act on ONZ [36]. However, with an increase in the nitrogen and phosphorus content, the $\mathrm { M C O @ H N T S } \ + \ \mathrm { P M S }$ system inhibits the degradation of ONZ. Some inorganic ions and organic matter in natural water can inhibit or quench ROS, resulting in a decrease in the degradation rate. In addition, a large amount of PMS in the water body will also cause secondary pollution; therefore, we performed an experiment to explore the consumption rate of PMS in different water bodies. As shown in Fig. 5b, natural water bodies with medium and low nitrogen and phosphorus contents consume more PMS $8 0 . 8 8 \ \%$ and $7 3 . 3 2 \ \%$ , respectively) than ultrapure water $( 5 1 . 5 7 \ \% )$ . This may be because various ions contained in natural water can also consume PMS, but excessive ions and organic matter in water with high nitrogen and phosphorus contents will inhibit the decomposition of PMS. In conclusion, the $\mathsf { M C O @ H N T S } + \mathsf { P M S }$ system for ONZ degradation has good anti-interference and PMS decomposition abilities in natural water.

ONZ degradation experiments in natural water showed that some ions in the water significantly affected the degradation rate of ONZ by $\mathrm { M C O @ H N T s ~ + ~ P M S } .$ . For this experiment, we selected some common anions and humic substances $( \mathsf { N O } _ { 3 } ^ { - }$ , ${ \mathrm { H C O } } _ { 3 } ^ { - }$ , $\mathrm { { C l } ^ { - } }$ , $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } ^ { - }$ , and HA). In addition to testing in conventional ultrapure water, we selected a natural water sample with the highest consumption of PMS, medium nitrogen and phosphorus content, and ONZ concentration of $1 . 4 1 9 \mathrm { \ m g / L }$ for comparison. As shown in Fig. 5c, $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } ^ { - }$ does not inhibit the degradation of pollutants, instead promotes the degradation of ONZ in ultrapure water more strongly than in natural water. The obtained results are different from previous reports [37,38]. The catalytic strength of ${ } ^ { 1 } 0 _ { 2 }$ has been reported to increase when its catalyst-active sites are occupied by $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } ^ { - }$ . These results show that the presence of $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } ^ { - }$ in solution can accelerate the activation of PMS, which degrades pollutants by ROS generation [39]. The remaining ions and organic matter inhibited the degradation of ONZ, among which ${ \mathsf { N O } } _ { 3 } ^ { - }$ , $\mathbb { C } 1 ^ { - }$ , and HA showed weak inhibition in natural water (Fig. S12a–c). The complex ions in natural water may react with these ions such that they are consumed (Eqs. (1)–(7)) [39,40], leading to stronger anti-interference abilities and far-reaching significance for practical applications. However, ${ \mathrm { H C O } } _ { 3 } ^ { - }$ had a stronger inhibitory effect in natural water (Fig. S12d). This may be because it converts these ROS into weaker free radicals (Eqs. (8) and (9)) [41], which reduces the degradation performance.

# 3.4. Reusability of MCO@HNTs

To further investigate the practical applicability of the MCO@HNTs $^ +$ PMS system for ONZ degradation, we repeated the experiments. Particularly, the MCO@HNTs material after the previous ONZ degradation cycle was washed with ultrapure water and ethanol several times and dried at $7 0 ~ ^ { \circ } \mathrm { C }$ after filtration to use as the catalyst material for the next cycle. As shown in Fig. 5d, after three cycles, ONZ degradation decreases by approximately $3 0 \ \%$ Owing to the adsorption of ONZ and some reaction intermediates on the MCO@HNTs catalyst and the loss of ${ \mathsf { C o } } / { \mathsf { M n } }$ ions in the reaction process (as indicated by the ICP-OES results), the number of available active sites was reduced, which reduced the catalytic activity. In order to unblock the occupied active sites after three cycles of use, we regenerated the catalyst by calcination at $4 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ . After this treatment, $9 8 . 4 0 \%$ of the ONZ could again be degraded within $2 5 \mathrm { { m i n } }$ , which is of great significance for practical applications. After the cycle, we performed XRD analysis on the material, and the results are shown in Fig. S13. The typical characteristic peaks at $2 1 . 9 8 ^ { \circ }$ (1 0 1), $2 6 . 9 9 ^ { \circ }$ (0 02), and $3 6 . 0 0 ^ { \circ }$ (311) of the recycled material did not change significantly compared to those of the unreacted material, indicating that a small amount of metal leakage has little effect on the stability of the MCO@HNTs crystal structure. XPS test also performed on the MCO@HNTs before and after the cycle. As shown in Fig. S14, the total element content does not change after the catalyst regeneration (Fig. S14a), and the structure tends to be stable. The main metal ions, ${ \mathsf { C o } } ^ { 3 + } / { \mathsf { C o } } ^ { 2 + }$ and $\mathrm { M n } ^ { 3 + } / \mathrm { M n } ^ { 2 + }$ , were analyzed (Figs. S14b and c). The ratio of ${ \mathsf { C o } } ^ { 3 + } / { \mathsf { C o } } ^ { 2 + }$ increased from 0.45 to 1.31, and that of $\mathsf { M n } ^ { 3 + } / \mathsf { M n } ^ { 2 + }$ decreased from 4.44 to 2.80, indicating that redox reactions occurred between ${ \mathsf { C o } } ^ { 3 + } / { \mathsf { C o } } ^ { 2 + }$ and $\mathrm { M n } ^ { 3 + } / \mathrm { M n } ^ { 2 + }$ . To further detect the change in the MCO@HNTs redox capacity after the experiment, we performed cyclic voltammetry (CV) test on the MCO@HNTs catalyst before and after the reaction. As shown in Fig. S15, the redox peak of the MCO@HNTs catalyst does not change significantly after the reaction. In conclusion, the above tests show that the MCO $@$ HNTs possess good stability.

# 3.5. Reaction mechanism

To identify the main free radicals in the MCO@HNTs $^ +$ PMS degradation system, methanol (MA), tert-butyl alcohol (TBA), benzoquinone (BQ), and furfuryl alcohol (FFA) were selected as scavengers. MA contains three ${ \sf { \sf { q } } } \mathrm { - } { \sf { H } }$ that can rapidly react with OH $( \mathrm { K } = 9 . 7 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ and $S 0 _ { 4 } ^ { - - }$ $\mathrm { K } = 2 . 5 \times 1 0 ^ { 7 } \mathrm { M } ^ { - 1 } \mathrm { } s ^ { - 1 } )$ to quench them. TBA does not contain $\mathtt { \Omega } \mathtt { \backslash } \mathtt { \backslash } \mathtt { \backslash } \mathtt { \backslash } \mathtt { \backslash } \mathtt { \backslash }$ , and its reaction rate with OH $\mathrm { K } =$ $3 . 8 – 7 . 6 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ is much faster than that with $S 0 _ { 4 } ^ { \cdot - }$ ( $\mathrm { K } = 4 . 0 -$ $9 . 1 \times 1 0 ^ { 5 } \mathrm { ~ M } ^ { - 1 } \mathrm { ~ } s ^ { - 1 } ,$ [42]. Thus, MA acts as an OH and ${ \mathsf { S } } { \mathsf { O } } _ { 4 } ^ { - - }$ scavenger, while TBA scavenges OH. BQ acts as an $\mathrm { O } _ { 2 } ^ { \cdot - }$ scavenger $( \mathrm { K } = 1 . 0 \times 1 0 ^ { 9 } ~ \mathrm { M } ^ { - 1 } ~ s ^ { - 1 } )$ , and FFA scavenges ${ } ^ { 1 } 0 _ { 2 }$ $\mathrm { ~ K ~ } = \ 1 . 2 \ \times \ 1 0 ^ { 8 }$ $\mathsf { M } ^ { - 1 } \mathsf { s } ^ { - 1 } .$ ) [43,44].

The results are shown in Fig. 6a; the introduction of TBA into the MCO@HNTs $^ +$ PMS system affects the degradation of ONZ, which decreased to $8 7 . 1 2 \ \%$ However, when MA was introduced, the amount of degradation of ONZ reduced to $1 7 . 7 8 \ \%$ , which is $6 9 . 3 4 \ \%$ lower than that in the presence of TBA, indicating that the contribution of ${ \mathsf { S } } { \mathsf { O } } _ { 4 } ^ { \cdot - }$ to ONZ degradation is much greater than that of OH. The addition of BQ and FFA also inhibited the degradation of ONZ, but the inhibitory effect of FFA $( 1 0 . 7 7 \% )$ was stronger than that of BQ $( 4 8 . 3 3 \ \% )$ . Overall, ${ } ^ { 1 } 0 _ { 2 }$ and $S 0 _ { 4 } ^ { \cdot - }$ were found to be the main contributors to the degradation of ONZ in the $\mathsf { M C O @ H N T s + P M S }$ system; the contribution of ${ } ^ { 1 } 0 _ { 2 }$ was higher than that of ${ \mathsf { S } } { \mathsf { O } } _ { 4 } ^ { \cdot - }$ , and non-radical oxidation dominated.

ROS production was verified using EPR spectroscopy. The compounds were identified using 5,5-dimethyl-1-pyrroline-N-oxide (DMPO) and 2,2,6,6-tetramethylpiperidine (TEMP) as traps for $S 0 _ { 4 } ^ { - - }$ , OH, $\mathrm { O } _ { 2 } ^ { \cdot - }$ and ${ } ^ { 1 } 0 _ { 2 }$ . As shown in Fig. 6b, typical 1:2:1:2:1:2:1 seven peaks were observed in the MCO@HNTs $^ +$ PMS system, which represent the oxidation of the hyperfine splitting of the trapping agent DMPO to DMPO-X [45,46]. The production of DMPO-X indicates that PMS can produce radicals with strong oxidation abilities $\mathrm { \Omega } ( S 0 _ { 4 } ^ { - }$ and OH), causing the rapid oxidation of DMPO. The four typical strong peaks in Fig. 6c belong to DMPO$\overbrace { 0 _ { 2 } } ^ { \cdot - }$ , whereas the 1:1:1 triple signal peak in Fig. 6d represents TEMP- ${ } ^ { 1 } 0 _ { 2 }$ [47,48]. Based on these results, $S 0 _ { 4 } ^ { \cdot - }$ , OH, and $\overbrace { 0 _ { 2 } } ^ { \cdot - }$ were detected in DMPO-X, and the TEMPO- ${ } ^ { 1 } 0 _ { 2 }$ signal was strong, which is consistent with the quenching experiments. The reaction mechanism is therefore a combination of free radical and nonradical pathways and a nonradical-dominated degradation process. Notably, PMS itself can hydrolyze to $\mathrm { O } _ { 2 } ^ { \cdot - }$ through electron transfer, and then $\mathrm { O } _ { 2 } ^ { \cdot - }$ can activate PMS to generate $S 0 _ { 4 } ^ { - - }$ or recombine with ${ } ^ { 1 } 0 _ { 2 }$ (Eqs. (10)–(12)) [14,49]. Therefore, EPR spectroscopy was performed to detect $\mathrm { O } _ { 2 } ^ { \cdot - }$ and ${ } ^ { 1 } 0 _ { 2 }$ in PMS at $\mathbf { t } = \mathbf { 0 }$ and $2 \mathsf { m i n }$ , without catalyst addition. The results shown in the Fig. 6c indicate that $\mathrm { O } _ { 2 } ^ { \cdot - }$ has no signal peak and is combined with a weak $\mathrm { O } _ { 2 } ^ { \cdot - }$ signal at $3 \ \mathrm { m i n }$ (Fig. 6c). It can be concluded based on this study that $\mathrm { O } _ { 2 } ^ { \cdot - }$ does not activate PMS recombination to ${ } ^ { 1 } 0 _ { 2 }$ ; PMS itself can slowly hydrolyze to produce ${ } ^ { 1 } 0 _ { 2 }$ .

In general, the faster the charge separation, the stronger the ability of the catalyst to activate PMS and generate more ROS. In this regard, the current change between the catalyst and PMS can be explained by linear sweep voltammetry (LSV) and i-t curves [50]. As shown in the LSV plot (Fig. 6e), MCO@HNTs have higher current densities than the controls (MCO@HNTs $>$ MCO $>$ $\mathrm { C O @ H N T s > M O @ H N T s > H N T s } )$ . Therefore, we chose $\mathsf { M C O @ H N T s }$ , MCO, and ${ \mathsf { C O @ H N T s } }$ , which had stronger current densities, to explore the current change between the catalyst and PMS. In the i-t curve (Fig. 6f), the current densities of the three different catalysts are not significantly different at first, but when $0 . 5 { \mathrm { g } } / { \mathrm { L } }$ PMS is added for the first time in $6 0 ~ s$ , the current density changes, indicating that electron transfer occurs between PMS and the catalyst. After PMS is added again at $1 1 0 s$ , the current density again significantly changes. These results indicate that MCO@HNTs $^ +$ PMS can rapidly produce several electrons and provide more ROS for ONZ degradation, which is desirable for ONZ degradation.

# 3.6. Possible degradation path of ONZ

In this study, liquid chromatography–mass spectrometry (LCMS) was used to identify intermediate substances and possible degradation pathways produced by the MCO@HNTs $^ +$ PMS degradation of ONZ. As shown in Fig. 8, ONZ generates intermediate P2 under the action of OH, which is then dehydroxylated to generate P1. Demethylation and dehydrogenation of ONZ may generate P3, which further leads to the formation of P4 [51,52]. The studie have reported that the O on –OH and the C linked to -Cl are two typical active sites for ONZ [53]. Therefore, under the action of ROS, P6 and P5 are generated by dehydroxylation and methylation, respectively, and P5 can be demethylated to generate P7. P6 and P7 can then be broken down into P8 by the attack of oxides on the carbon chain, further oxidized and degraded to the small molecule P9, and finally mineralized into ${ \mathsf { C O } } _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ .

# 4. Conclusions

In this study, a co-precipitation method was used to immobilize cobalt-manganese bimetallic oxides on environmentally friendly and low-cost HNTs, and $\mathsf { M C O @ H N T s }$ bimetallic composites were successfully prepared. $\mathsf { M C O @ H N T s + P M S }$ showed excellent degradation performance for ONZ (the degradation rate was close to $1 0 0 \%$ in $2 5 ~ \mathrm { { m i n } }$ ) over a wide pH range, particularly under alkaline conditions. The nitrogen and phosphorus contents in natural water and the presence of anions have certain effects on the catalytic degradation of organic pollutants, such as antibiotics; however, such studies are rare. Here, three typical plateau lakes in Yunnan were selected as research objects. The results show that natural lake water has a certain effect on the degradation of ONZ by MCO@HNTs $^ +$ PMS, however it can promote the transformation of PMS and reduce the residue of PMS in water, thus effectively avoiding secondary pollution. The $\mathsf { M C O @ H N T S } + \mathsf { P M S }$ system has stronger anti-interference of negative ions in natural lake water; particularly, $\mathrm { H } _ { 2 } \mathrm { P O } _ { 4 } ^ { - }$ can quickly activate PMS to degrade ONZ in natural water. The $\mathrm { M C O @ H N T S } ~ + ~ \mathrm { P M S }$ system also has a strong ability to degrade several typical antibiotics with a high mineralization rate. The MCO@HNTs composite effectively inhibited the leaching of ${ \mathsf { C o } } / { \mathsf { M n } }$ ions. After three degradation cycles, the ONZ degradation rate reached $9 8 . 4 \ \%$ within $2 5 ~ \mathrm { { m i n } }$ using the catalyst regenerated by calcination. Free-radical quenching and EPR detection experiments showed that the degradation of ONZ by MCO@HNTs $^ +$ PMS was due to the combined action of free radicals $\mathrm { \Delta } [ \mathrm { S O _ { 4 } ^ { \cdot - } }$ , OH) and nonradicals $( ^ { 1 } 0 _ { 2 } , 0 _ { 2 } ^ { . - } )$ , wherein the nonradicals ${ } ^ { 1 } 0 _ { 2 }$ had a significant effect. Possible ONZ degradation pathways and intermediates were identified using LC-MS. Based on the experimental and characterization results of this study, it can be concluded that the MCO@HNTs bimetallic composites can act quickly and effectively on various antibiotics, exhibiting strong anti-interference and stability in natural water, thus being a promising and practical PMS activator.
