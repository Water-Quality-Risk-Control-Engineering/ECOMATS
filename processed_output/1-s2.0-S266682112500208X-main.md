In this work, metastable aluminum cluster ions $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ and hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ were used to degrade and mineralize atrazine (ATZ) in aqueous solution, where $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions can decompose $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ into hydroxyl radicals (HO• ). It was found that ATZ has a high degradation efficiency in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution both in acidic and alkaline condition, even ATZ concentration was up to $2 0 \mathrm { m g _ { \mathrm { ~ L ~ } } } ^ { - 1 }$ . ATZ can be completely degraded within $^ { 2 \mathrm { ~ h ~ } }$ and $1 0 \ \mathrm { m i n }$ in acidic solution at $\mathrm { p H } = 4 . 0$ and alkaline solution at $\boldsymbol { \mathrm { p H } } = 1 2$ , respectively. Even in neutral solution, AZT can be completely degraded if the time is long enough. However, total organic carbon (TOC) removal ratio reached the maximum $( 6 1 . 4 \% )$ at $\mathrm { p H } = 4 . 0$ . Furthermore, $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * } + \mathrm { \bar { H } } _ { 2 } \mathrm { O } _ { 2 }$ solution exhibited an excellent reusability for degradation of ATZ up to 10 cycles. Mechanism analyses revealed that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ spontaneously decomposes into $\mathrm { H O } _ { 2 } ^ { - }$ ions, which can transform ATZ into nontoxic hydroxyatrazine and contribute to the most of ATZ degradation in alkaline solution. HO• radicals generated by the catalysis of [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions contribute to the main part of ATZ degradation in acidic solution and almost all of mineralization in the full pH range. As the optimal condition to produce HO• radicals by $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ ions is at $\mathrm { p H } = 4 . 0$ , and its TOC removal ratio is the highest. The related influence factors and possible pathways for ATZ degradation were investigated in detail. The present study provides a new route to remove ATZ in aqueous solution.

# 1. Introduction

Atrazine (ATZ), a synthetic triazine herbicide, is extensively adopted for controlling grassy and broadleaf weeds in agricultural crops [1–3], ranking as the world’s second most widely used herbicide [4]. ATZ demonstrates dual ecotoxicity including phytotoxicity through suppressing photosynthesis [5]and zootoxicity manifesting as disruption of immune regulation [6,7] and endocrine systems [8,9]. ATZ persists widely in aquatic environments [10,11] due to its biodegradation resistance [12] and long half-life (30–100 days) [13]. The maximum allowed level for drinking water is $0 . 1 \mu \mathrm { g } \mathrm { l } ^ { - 1 }$ and $3 . 0 \mu \mathrm { g } \mathrm { l } ^ { - 1 }$ in Europe and USA, respectively [14]. Therefore, it is urgent to develop new robust approach for efficient degradation of ATZ.

Different methods have been developed for degradation of ATZ, including adsorption [15–18], biodegradation [19,20], and advanced oxidation processes (AOPs) [21–24]. Among them, AOPs are believed to be the efficient technologies for wastewater treatment, which generate high-activity oxidation radicals and efficiently degrade persistent organic pollutants in aqueous solution [25,26]. Hydroxyl radical $( \mathrm { H O ^ { \bullet } } )$ , main oxidation agents in most AOP systems, which have a high redox potential of $2 . 8 \mathrm { V }$ in acidic condition, just lower than that of fluorine gas [27], are non-selective for degradation of organic pollutants in aqueous solution [28]. Fenton reaction is an effective method for degradation of ATZ in aqueous solution, however its strict pH requirement $\mathrm { ( p H } < 4 . 0 \mathrm { ) }$ and the resultant iron sludge limit the practical application [29].

To address the limitation of Fenton reaction, new AOP technologies such as electro-Fenton, photo-Fenton, and Fenton-like reactions were used to degrade ATZ in aqueous solution [13,30,31]. Electro-Fenton and photo-Fenton technologies enhance the generation efficiency of HO• by ultraviolet light [32] or electrical current [21], respectively. However, electro-Fenton reaction generates HO• only at the electrode surface ${ \sim } 1$ $\mu \mathrm { m } )$ [33], and photo-Fenton reaction uses expensive catalysts [34]. Fenton-like reaction adopts multivalent metals such as Cu [35], Co [36] and $\mathrm { F e C o _ { 2 } O _ { 4 } }$ [37] as catalysts to generate HO• and degrade ATZ [38], but they raise the risks of secondary pollution. Until now, there is no effective method to remove ATZ in aqueous solution in full pH range.

Usually, aluminum ions have no catalytic activity due to the absence of aluminum intermediate valence states. Recently, Guo et al. [39] found that metastable aluminum cluster ions $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ , which are produced by Al-water reaction [40–44], can decompose $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ into HO• across a wide $\mathsf { p H }$ range. Metastable $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions have been successfully used to remove antibiotics (tetracycline, oxytetracycline) in aqueous solution, however their degradation efficiency in alkaline solution is not high and much lower than that in acidic solution [45,46]. In this work, new aluminum ion based Fenton-like solution, i.e. [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution was used to degrade ATZ in aqueous solution. It was found that there is a synergistic action of metastable [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ in $[ \mathrm { A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } } ] ^ { \ast } + \mathrm { H _ { 2 } O _ { 2 } }$ solution to degrade ATZ, leading to a high efficiency for removal of ATZ both in acidic and alkaline solution. The related influence factors on ATZ degradation, the reusability of $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ ions, and the reaction mechanisms were investigated systematically.

# 2.2. Preparation of metastable $I A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } J ^ { * }$ ion solution

Initially, $_ { 1 . 0 g }$ of 1 M $\mathrm { H _ { 2 } } S O _ { 4 }$ and $2 4 9 . 0  g$ deionized water were added into a $5 0 0 ~ \mathrm { m L }$ polytetrafluoroethylene (PTFE) beaker, followed by the addition of $5 . 0 \mu \mathrm { m }$ Al powder $( 2 . 0 \ g 1 ^ { - 1 } )$ , and stirred with a magnetic bar at $5 0 0 \mathrm { r p m }$ . After $2 4 \ \mathrm { h }$ of reaction, the above suspension was filtered through a $0 . 2 2 ~ { \mu \mathrm { m } }$ polyethersulfone (PES) filter [47,48], yielding a colorless solution with metastable [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions at pH value of $\sim 4 . 0$ [39]. In order to obtain metastable $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ion solution with different pH value, a suitable volume of 1 M $\mathrm { H } _ { 2 } S 0 _ { 4 }$ or $1 \mathrm { ~ M ~ N a O H }$ was added into the solution, followed by filtration through a $0 . 2 2 \mu \mathrm { m }$ PES filter to remove the possible hydroxide precipitates, because the solubility of aluminum ions in aqueous solution is highly dependent on its pH value [49].

# 2.3. Degradation tests in pure $H _ { 2 } O _ { 2 }$ solution

At first, aqueous solution with different pH value was prepared by adding a suitable amount of 1 M $\mathrm { H _ { 2 } S O _ { 4 } }$ or 1 M NaOH to deionized water. Then an appropriate amount of ATZ powder was added to above solution, and stirred with a magnetic bar at $5 0 0 ~ \mathrm { r p m }$ at $4 5 ~ ^ { \circ } \mathrm { C }$ for $^ { 8 \mathrm { ~ h ~ } }$ to completely dissolve ATZ with a concentration of $1 0 . 0 \mathrm { m g } \mathrm { l } ^ { - 1 }$ , which was subsequently filtered through a $0 . 2 2 \mu \mathrm { m }$ PES filter to remove insoluble impurities. Finally, $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ with a concentration of $8 0 ~ \mathrm { m M }$ was added to above solution to begin the test for ATZ degradation. $5 . 0 \mathrm { m L }$ of reaction solution was taken at predetermined time interval, following addition of $2 0 0 ~ \mu \mathrm { L }$ of methanol to quenching HO• radicals. The mobile phase consists of methanol and water $( 6 0 / 4 0 , \mathrm { v / v } )$ ) with a flow rate of $0 . 6 ~ \mathrm { m L }$ $\mathrm { m i n ^ { - 1 } }$ , and the analytical wavelength was set at $2 2 0 ~ \mathrm { { n m } }$ [50]. # 2.5. Recyclability

Before the recycling test, a stock solution of ATZ $( 2 0 . 0 \ \mathrm { m g \ l ^ { - 1 } } )$ was prepared using deionized water. In each recycling test, the reaction temperature is $6 5 ~ ^ { \circ } \mathrm { C } ,$ , the initial concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is $8 0 ~ \mathrm { m M }$ , and that of ATZ is $1 . 0 \mathrm { m g l } ^ { - 1 }$ . # 3.1. Degradation of ATZ in pure $H _ { 2 } O _ { 2 }$ solution

Fig. 1(a) shows variation of ATZ concentration with time in pure $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution at different pH value. The results indicate that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ can degrade ATZ in aqueous solution across a full pH range. However, the degradation efficiency of ATZ in aqueous solution with pH value $< 1 0 . 0$ is limited and ATZ can not be completely degraded within $^ { 4 \mathrm { h } }$ , especially in neutral solution. It is noted that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ exhibited a strong ability to degrade ATZ in a stronger alkaline solution $( \mathrm { p H } = 1 2 . 0 \ – 1 3 . 0 )$ , and ATZ was completely degraded in $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution at $\mathrm { p H } = 1 3 . 0$ within $1 0 \mathrm { m i n }$ .

(6)). # 3.2. Degradation of ATZ in metastable $I A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } J ^ { * }$ ion solution

Fig. 2 shows variation of ATZ concentration with time and its TOC removal ratio after $2 4 \mathrm { h }$ reaction in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution at pH $\mathit { \Theta } = \ 4 . 0$ , where the corresponding results using pure $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ion solution were added for comparison. The different catalytic efficiency of $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ ions in different pH solution can be attributed to the following causes. Firstly, the solubility of $\mathsf { A l } ^ { 3 + }$ ions in acidic solution is higher than that in neutral and alkaline solution [49,58], as shown in Fig. 7(c), where $\mathsf { A l } ^ { 3 + }$ ion concentration at $\mathrm { p H } = 2 . 0$ , 4.0, 7.5, 10.0 and 12.0 is 80.5, 81.2, 13.2, 61.9 and $5 4 . 9 \mathrm { m g }$ ${ \mathrm { l } } ^ { - 1 }$ , respectively. It should be mentioned that the weak ESR peaks at $\mathrm { p H } = 1 0 . 0$ and $\mathrm { p H } = 1 2 . 0$ do not imply the absence of HO• radicals, because the half-life of DMPO–OH adducts in alkaline solution is shorter than that in neutral and acidic solution [60], and the decreased stability of DMPO–OH adducts can lead to a week ESR response. The existence of $_ \mathrm { H O } \cdot$ radicals in $\mathrm { [ A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } ] ^ { * } + H _ { 2 } O _ { 2 } }$ solution across a wide pH range was also verified by TBA quenching tests shown in Fig. 8, where addition of $3 0 0 \ \mathrm { m M }$ TBA obviously decreases the degradation efficiency of ATZ in the solution at $\mathrm { p H } = 4 . 0$ and 12.0, because TBA is a quenching agent of HO• radicals [48]. However, in TBA quenching tests in Fig. 8, after quenching HO• radicals in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ $+ \ \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution, the degradation efficiency of ATZ in $\mathrm { [ A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } ] ^ { * } + }$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution is still higher than that in pure $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution. This implies that besides HO• radicals, there are other oxidants produced through the catalytic reaction by metastable $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ ions, which are responsible for the degradation difference in $[ \mathrm { A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } } ] ^ { * } + \mathrm { H _ { 2 } O _ { 2 } } + \mathrm { T B A }$ and pure $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution. The possible other oxidants are speculated to be $\mathrm { H O } _ { 2 } ^ { - }$ ions by the following reactions [54,61]

$$
\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \xrightarrow [ \mathrm { c a t a l y z e } ] { \left[ \mathrm { A l } ( H _ { 2 } O ) _ { 6 } ^ { 3 + } \right] { * } } \mathrm { H O } _ { 2 } ^ { - } + \mathrm { H } ^ { + }
$$

$$
\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } + \mathrm { H } \mathrm { O } _ { 2 } ^ { - } \xrightarrow [ \mathrm { c a t a l y z e } ] { \left[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } \right] * } \mathrm { H O } ^ { \bullet } + \mathrm { H O } _ { 2 } ^ { \bullet } + \mathrm { O H } ^ { - }
$$

These imply that $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ molecules decompose and generate $\mathrm { H O } _ { 2 } ^ { - }$ ions by the catalysis of metastable $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ ions at first, then $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ molecules react with $\mathrm { H O } _ { 2 } ^ { - }$ ions to produce HO• radicals. As the reaction (15) produces $\mathrm { H } ^ { + }$ ions, the higher $\mathrm { H } ^ { + }$ ion concentration in aqueous solution will suppress the reaction. This means that $\mathrm { H O } _ { 2 } ^ { - }$ ion concentration produced by the reaction (15) at $\mathrm { p H } = 2 . 0$ should be lower than that at $\mathrm { p H } = 4 . 0$ , leading to a lower HO• concentration produced by the reaction (16) at $\mathrm { p H } = 2 . 0$ than that at $\mathrm { p H } = 4 . 0$ (Fig. 7(b)). This is the reason why TOC removal ratio in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution at $\mathrm { p H } = 2 . 0$ is lower than that at $\mathrm { p H } = 4 . 0$ (Fig. 6(b)).

The above analyses indicate that there are two main oxidants, i.e. $\mathrm { H O } _ { 2 } ^ { - }$ ions and HO• radicals in $\mathrm { [ A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } ] ^ { * } + H _ { 2 } O _ { 2 } }$ solution, which contribute to ATZ degradation. Most of $\mathrm { H O } _ { 2 } ^ { - }$ ions come from the spontaneous decomposition by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ molecules (Eq. (4)), and their concentration increases rapidly at pH value $\geq 1 2 . 0$ , resulting in a high ATZ degradation rate in alkaline solution (Fig. 1 and S4). In contrast, the amount of left $\mathrm { H O } \bar { 2 }$ ions produced by the catalytic decomposition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ by $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions (Eq. (15)) is limited, which contribute to a small part of ATZ degradation (Fig. 8), because most of its $\mathrm { H O } _ { 2 } ^ { - }$ ions are reacted to produce HO• radicals (Eq. (16)). HO• radicals produced by [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions contribute to the most of ATZ degradation in acidic solution (Fig. 2(a), 8(a) and S4). On the other hand, TOC removal in aqueous solution mainly results from HO• radicals produced by [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions, especially in alkaline solution, because $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ can not spontaneously generate $_ \mathrm { H O } \cdot$ radicals at $\mathrm { p H } \geq 7 . 5$ . The above analyses indicate that the synergistic effect of $\mathrm { H O } _ { 2 } ^ { - }$ ions and HO• radicals in [Al $( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast } + \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution results in a high degradation efficiency of ATZ across a wide pH range, especially in acidic and alkaline solution.

# 3.6. Reaction byproducts

Fig. S5 gives LC-MS spectra of ATZ in deionized water and mass spectra of liquid phase separated from $\mathrm { A T Z } + \mathrm { [ A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } ] ^ { * } + H _ { 2 } O _ { 2 } }$ solution after $^ { 2 4 \mathrm { ~ h ~ } }$ reaction by LC at different time, where the intermediates were indentified by their mass to charge ratio $\left( m / z \right)$ with library data and published literatures [24,31]. It can be seen that there are five dealkylated intermediates (CDIT, CEPT, DIA, CAAT and CVAT) and five dechlorinated intermediates (OEIT, OAIT, OAAT, OVIT and its isomers). Based on the identified reaction byproducts, it was speculated that there are following three possible pathways for ATZ degradation in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ solution, as shown in Fig. 10. They include dealkylation, dechlorination, alkyl oxidation, decarboxylation, and ring opening reactions [64] by HO• radicals, and dechlorination reaction by $\mathrm { H O } _ { 2 } ^ { - }$ ions [54]. In the first pathway, ATZ undergoes continuous dealkylation reaction, initiated by $_ \mathrm { H O } \cdot$ radicals that preferentially attack on the electron-rich alkylamino side chains, and finally yields CAAT [65]. In the second pathway, ATZ undergoes alkyl oxidation reaction to form CDIT, which then undergoes decarboxylation, followed by successive dealkylation, and finally produces CAAT [64]. In the third pathway, ATZ undergoes dechlorination via $_ \mathrm { H O } \cdot$ radicals or $\mathrm { H O } _ { 2 } ^ { - }$ ions to generates OEIT [54], which subsequently undergoes dealkylation to yield OAAT [65]. At the end, both of CAAT and OAAT are finally mineralized through ring-opening reaction [66]. The main steps of ATZ degradation in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ solution are shown in Scheme 1. Moreover, removal of $\mathsf { A l } ^ { 3 + }$ ions from aqueous solution after degradation of ATZ remains a problem. This can be addressed by adjusting pH value of solution to neutral to precipitate $\mathsf { A l } ^ { 3 + }$ ions [67], or by adsorption using activated carbon [68] and bio-adsorbents [69] etc.

# 4. Conclusions

The present work investigated ATZ degradation in $\mathrm { [ A l ( H _ { 2 } O ) _ { 6 } ^ { 3 + } ] ^ { * } + }$ $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ solution. It was found that there is a high efficiency for degradation of ATZ in above solution across a wide pH range (2.0–12.0), especially in acidic and alkaline solution. At $\mathrm { p H } ~ = ~ 4 . 0$ , ATZ can be completely degraded within $^ { 2 \mathrm { h } }$ at $6 5 ^ { \circ } \mathrm { C }$ and its TOC removal ratio after $2 4 \ \mathrm { h }$ reaction was up to $6 1 . 4 ~ \%$ . At $\mathrm { p H } = 1 2 . 0$ , ATZ can be completely degraded within $1 0 ~ \mathrm { \ m i n }$ . Even in neutral solution, ATZ can be completely degraded if the reaction time is long enough. Meanwhile, metastable $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { * }$ ions have a good reusability and there is no large decline in ATZ degradation efficiency even up to 10 cycles. Mechanism analyses revealed that there are two main oxidants, i.e. $\mathrm { H O } _ { 2 } ^ { - }$ ions and HO• radicals, responsible for the degradation of ATZ. Metastable $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ ions can catalyze $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to produce HO• radicals, and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ can spontaneously decompose and generate $\mathrm { H O } _ { 2 } ^ { - }$ ions. $\mathrm { H O } _ { 2 } ^ { - }$ ions transform ATZ into non-toxic hydroxyatrazine, but they can not mineralize the organic intermediates. $\mathrm { H O } _ { 2 } ^ { - }$ ions contribute to the most part of ATZ degradation in alkaline solution, while HO• radicals contribute the most part of ATZ degradation in acidic solution. TOC removal in aqueous solution should be attribute to the action of HO• radicals. Furthermore, it was found that the degradation efficiency of ATZ in tap water is slightly lower than that in deionized water due to the existence of trace anions and organic species. There are three possible degradation pathways for ATZ degradation in $[ \mathrm { A l } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ^ { 3 + } ] ^ { \ast }$ solution, based on the analyses on reaction intermediates. This work offers a new homogeneous approach to degrade ATZ in aqueous solution.
