# . Introduction

Pharmaceutical and personal care products (PPCPs) are currently released into the aquatic environment through multiple pathways, including domestic wastewater, hospital discharge, improper manufacturing disposal, effluents from water treatment plants (WTPs) and sewage treatment plants (STPs) [1,2]. PPCPs could cause endocrine disruption and chronic toxicity to human health and aquatic microorganisms [3]. Because of their resistance to biodegradation during conventional activated sludge process in STPs, the occurrence of PPCPs in receiving waterbody becomes an emerging concern [4,5]. Thus, it is imperative to develop a more effective technique for degradation of PPCPs.

Advanced oxidation processes (AOPs) have been widely regarded as an efficient technique for degradation of recalcitrant organic contaminants in water environment. Especially, sulfate radical $( S O _ { 4 } ^ { \bullet \cdot } )$ based AOPs have attracted great interest in the abatement of micro-pollutants in water treatment [6,7]. $S O _ { 4 } ^ { \bullet \bullet }$ has become an alternative to hydroxyl radical $( ^ { \bullet } \mathrm { O H } )$ due to a relatively higher redox potential of 2.53.1 V. As a strong one-electron oxidant, $S O _ { 4 } ^ { \bullet \bullet }$ can readily react by addition to C-C double bonds and by H-abstraction [8]. Besides, $S O _ { 4 } ^ { \bullet \bullet }$ exhibits other obvious advantages over $\cdot _ { \mathrm { O H } }$ in terms of wider application pH range of 28 and longer lifespan of $3 0 { - } 4 0 ~ { \mu \mathrm { s } }$ [911]. In particular, PMS is a cost-effective and environmentally friendly oxidant with lower energy input and alkaline dosing [12]. Currently, cobalt (Co) is considered the most effective transition metal catalyst for PMS activation [13]. However, ${ \mathsf { C o } } ^ { 2 + }$ in aqueous solution leads to further environmental pollution and health issues. Recently, Mn oxide [1416] and supported Mn oxide catalysts [17,18] have demonstrated excellent catalytic activity as PMS activator for degradation of organic pollutants. Thus, it is of great interest to develop novel and efficient Mn oxide catalysts with less environmental toxicity to activate PMS for the decomposition of emerging PPCPs.

In the last decade, spinel ferrite nanoparticles with a general formula, $\mathrm { M C o _ { 2 } O _ { 4 } }$ ${ \bf { M } } = { \bf { M } } { \bf { n } }$ , Fe, Co, Ni or Cu), have been used in several applications such as catalysis, environmental remediation, and supercapacitor, due to their outstanding properties in terms of nanometer size, large surface area to volume ratio, and superparamagnetic behavior [11,19,20]. As PMS activator, $\mathrm { C o _ { x } M n _ { 3 - x } O _ { 4 } }$ [21] and $\mathrm { M n F e _ { 2 } O _ { 4 } }$ [22] were found to be active for oxidation of organic pollutants. Despite high catalytic activity of $\mathrm { M n C o _ { 2 } O _ { 4 } }$ nanoparticles (NPs), NPs materials could result in lower catalytic efficiency as a result of aggregation, lower electrical conductivity, poor electron transfer rate, and limited active sites. To solve these issues, carbonaceous materials with high electrical conductivity and buffer matrix can br employed as matrices for $\mathrm { M n F e _ { 2 } O _ { 4 } }$ -based materials to provide a larger surface area for the diffusion of reactants onto the active sites, thereby enhancing their catalytic performance.

As compared to other carbon materials (e.g., graphene, activated carbon, or graphite), carbon nanotubes (CNTs) possess unique properties, such as large surface area, high stability and mechanical strength, making CNTs suitable as support materials of various catalysts [2325]. The advantages of spontaneous redox reactions between CNTs and metal oxides have been recognized earlier [26]. The excellent electrical conductivity of CNTs could not only help to stabilize the active intermediates but also facilitate the catalytic processes involving electron transfer. Meanwhile, CNT. ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ $@ \mathrm { P P y }$ has been used as adsorbent and catalyst to remove anionic and cationic dyes [23]. Meanwhile, the stability of the PMS activator is also of critical importance in order to prepare eco-friendly nanoparticles or catalysts for practical application, thus the leaching of metal ions from the PMS activator should be substantially hindered. However, to the best of our knowledge, there is no literature on the exploration of robust and stable $\mathrm { M n C o _ { 2 } O _ { 4 } }$ supported on functionalized CNTs $( \mathrm { M n C o _ { 2 } O _ { 4 } }$ /FCNTs) for PMS activation in degradation of organic contaminants.

In the present work, we report a facile approach to prepare $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ and its catalytic activation in PMS oxidation of ibuprofen (IBU). The properties of $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ and its catalytic performance were investigated in terms of effects of various reaction parameters (e.g., pH, temperature, Cl, $\mathrm { H C O } _ { 3 } ^ { - }$ and natural organic matter (NOM)) on IBU removal. Furthermore, PMS activation mechanism and the dominant reactive oxygen species (ROS) were evaluated.

# 2.2. Preparation of catalysts

CNTs were employed as support materials for bimetallic catalysts preparation. Pristine CNTs were refluxed in concentrated nitric acid at $1 2 0 ^ { \circ } \mathrm { C }$ for $4 \mathrm { h }$ under stirring to remove metallic impurities and introduce oxygen-containing functional groups onto the surface of CNTs, thereby facilitating uniform precipitation of metal precursors [27]. The functionalized CNTs were washed and prepared following the procedure described by Nassr et al. [28], which were denoted as FCNTs thereafter. All monometallic and bimetallic nanomaterials were prepared using a hydrothermal method. Specifically, $0 . 2 1 8 \ g \ C 0 ( \mathrm { N O _ { 3 } } ) _ { 2 } . 6 \ \mathrm { H _ { 2 } O } , 0 . 0 1 3 4$ $\mathrm { { M n } ( N O _ { 3 } ) _ { 2 } . }$ 6 $_ \mathrm { H _ { 2 } O }$ and $2 5 ~ \mathrm { m g }$ FCNTs were added into a round bottomed flask with $3 7 . 5 \mathrm { m L }$ ethyl alcohol. The mixture was vigorously mixed in a rotary vibrator at $3 0 0 ~ \mathrm { r p m }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ under room temperature. The suspension was then dispersed by ultrasound for $^ { 1 \mathrm { ~ h ~ } }$ followed by filtration and washing with deionized water and acetone. This composite was subsequently transferred into a $1 0 0 ~ \mathrm { \ m L }$ Teflon-lined stainless-steel autoclave for hydrothermal reaction at $1 4 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ . The autoclave was naturally cooled down to room temperature afterwards. The formed composite was vacuum dried at $6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { h } }$ and was then calcined at $5 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ under vacuum. The as-synthesized catalyst was denoted as $\mathtt { M n C o 2 O 4 }$ /FCNTs.

# 2.4. Catalytic oxidation of IBU

Pharmaceutical wastewater containing high concentration of IBU has been simulated. Catalytic oxidation experiments were conducted in a $2 5 0 ~ \mathrm { m L }$ batch reactor at $2 5 . 0 \pm 0 . 2 ^ { \circ } \mathrm { C }$ and $3 0 0 ~ \mathrm { r p m }$ in a water bath shaker. The dosage of PMS and $\mathrm { M n C o _ { 2 } O _ { 4 } }$ /FCNTs was $1 . 0 g / \mathrm { L }$ and $0 . 0 1 \ g / \mathrm { L }$ , respectively. During the oxidation process, $_ { 1 \mathrm { m L } }$ of IBU solution was sampled at a pre-determined interval and quenched quickly with $0 . 1 \mathrm { \ m L }$ methanol followed by filtration using $0 . 2 2 ~ \mu \mathrm { m }$ cellulose acetate membrane for further analysis. Meanwhile, non-catalytic control experiments were carried out under identical conditions. Catalytic stability of $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ was examined through recycling test. Specifically, solid catalysts were filtered and recycled using $0 . 2 2 \mu \mathrm { m }$ Millipore filter and washed with deionized water followed by vacuum drying at $6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ before reuse.

# 3.3. Influences of various reaction parameters

# 3.3.1. Effect of pH

The IBU degradation at different pH values in the $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ . PMS system is shown in Fig. 4A. On the whole, the IBU degradation in the $\mathrm { M n C o _ { 2 } O _ { 4 } } .$ /FCNTs-PMS system under a wide pH range of 2.969.24 was generally lower than that within a relatively narrower pH range of 4.677.02. Considering the pKa value for IBU and PMS are 4.91 [35] and 9.4 [36], respectively, the point of zero charge of $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ is within the range of $4 . 9 \pm 1 . 8$ [37]. Thus, at $\mathsf { p H } 9 . 4$ , the electrostatic repulsion between the negatively charged PMS, IBU and $\mathrm { M n C o _ { 2 } O _ { 4 } }$ /FCNTs-PMS could be prominent, thereby inhibiting the overall IBU degradation rate. Similarly, at $\mathrm { p H } 2 . 9 6 $ , the IBU degradation rate was also inhibited, which could be ascribed to the scavenging effect of $\mathrm { H } ^ { + }$ $\mathsf { p H 3 - 9 }$ $k _ { a p p }$ ranged from 0.285 to $0 . 3 2 7 \mathrm { m i n } ^ { - 1 }$ This reveals that $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ may activate PMS at a satisfactory level within a wide pH range without distinctly losing its catalytic activity, which is in accordance with previous research results [32].

# 3.3.2. Effect of temperature

The degradation reaction of IBU was also significantly influenced by the reaction temperature. Generally, IBU removal would be promoted under increased reaction temperature. As shown in Fig. 4B, the degradation rate constant increased proportionally with increasing temperature from 25 to $4 5 ^ { \circ } \mathrm { C }$ The $k _ { a p p }$ values were fitted with the Arrhenius equation (i.e., $\ln { k _ { a p p } }$ versus 1/T) and the calculated activation energy was $2 . 6 \mathrm { k J } \mathrm { m o l } ^ { - 1 }$ . This activation energy was relatively lower than those in previous research using Mn-based catalysts [39,40], indicating that this as-synthesized catalyst could efficiently activate PMS. Previous research showed that elevating the reaction temperature may not only enhance the chemisorption of organic/PMs but also facilitate the electron-transfer process between pollutants and PMS via the carbon catalyst [41]. Therefore, the enhanced contribution of radicals in the $\mathrm { M n C o _ { 2 } O _ { 4 } }$ /FCNTs-PMS system could be attributed to generation of $S O _ { 4 } ^ { \bullet \bullet }$ and $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ via the activation of PMS [32,41,42].

# 3.3.3. Effect of Cl

The effect of the presence of typical ions (e.g., Cl, $\mathrm { H C O } \bar { 3 } .$ on IBU oxidation in the $\mathrm { M n C o _ { 2 } O _ { 4 } }$ /FCNTs-PMS system has also been investigated. Fig. 4C shows the IBU degradation efficiency at different Cl concentrations. # 3.3.5. Effect of NOM

Fig. 4E presents the effect of NOM on IBU removal in the $\mathrm { M n C o _ { 2 } O _ { 4 } / }$ FCNTs-PMS system. NOM can undergo competitive reaction with the generated ROS, leading to the decreasing decomposition efficiency towards IBU [9]. For instance, the values of $k _ { \mathrm { a p p } }$ for IBU was decreased from 0.285 to $0 . 0 9 2 \mathrm { m i n } ^ { - 1 }$ as the NOM concentration was increased from 1 to $5 \mathrm { m g } / \mathrm { L }$ . Previous studies have also reported that reactions of target compounds with $S O _ { 4 } ^ { \bullet \bullet }$ and $\cdot _ { \mathrm { O H } }$ were slowed down by NOM, which was primarily due to its competitive consumption for oxidants as well as the low reactivity of resulting organic radicals [4749]. Latest studies have revealed that NOM could undergo competitive reactions with $S O _ { 4 } ^ { \bullet \cdot }$ and $\cdot _ { \mathrm { O H } }$ and thus minimize the decomposition efficiency towards target components in AOPs, and its steric and electrostatic effects [32,50].

# 3.4. Stability and reusability of MnCo2O4/FCNTs

The stability and reusability of the catalyst is crucial for practical application. To evaluate the catalytic stability of $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ in the PMS oxidation system, the IBU removal study was conducted by using recycled catalyst over four cycles under identical reaction condition, and the results are shown in Fig. 4F. Apparently, it was found that IBU was still completely removed within $4 0 \mathrm { { m i n } }$ after four cycles despite a slight decrease of $k _ { a p p } \mathrm { f r o m } 0 . 2 8 5 \mathrm { m i n } ^ { - 1 }$ in the first cycle to $0 . 2 0 1 \ \mathrm { m i n } ^ { - 1 }$ in the fourth cycle due to the loss of catalyst during catalyst recovery process. Moreover, the leaching concentrations of metal ions (i.e., Mn and Co) were below the detection limit of ICP-OES $( 1 ~ \mu \mathbf { g } / \mathrm { L } )$ , which were far lower than those reported in previous studies (i.e., $0 . 0 7 { - } 0 . 1 2 \mathrm { m g / L }$ [51] up to $0 . 5 4 \mathrm { - } 0 . 6 1 \mathrm { m g / L }$ [52]). This indicates that the $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ was stable and its high activity could be maintained for at least four cycles.

The surface characteristics of $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ before and after catalytic reaction were measured by XPS. According to the highresolution XPS spectra of $\mathtt { M n } \ 2 \mathtt { p }$ depicted in Fig. 1, the $\mathtt { M n } \ 2 \mathtt { p }$ profile of spent $\mathtt { M n C o _ { 2 } O _ { 4 } }$ catalyst showed two main peaks at $6 4 2 . 2 \mathrm { e V }$ and $6 4 3 . 2 \mathrm { e V }$ which corresponded to $\mathtt { M n 2 p 3 / 2 }$ and Mn 2p1/2, respectively. This implies that the $\mathrm { M n ^ { 2 + } }$ chemical state on the sample surface [53,54] and the valence of Mn on the surface of spent catalyst had a noticeable change. Co $\mathsf { 2 p }$ spectra exhibited two main peaks at binding energy of 781.2 and $7 9 6 . 1 \ \mathrm { e V }$ which could be assigned to Co $\boldsymbol { 2 } \mathsf { p } _ { 3 / 2 }$ and Co $\boldsymbol { 2 } \mathsf { p } _ { 1 / 2 }$ respectively [55]. In addition, two satellite peaks confirmed the presence of $\mathsf { C o } ^ { 3 + }$ cation. These values were slightly shifted, and the area of peaks was decreased after the reaction with PMS and IBU, which suggested that Mn and Co species on the spent catalyst surface were in a mixed valence state. This suggests that $\mathrm { { M n } ( I I ) }$ and $\mathrm { C o ( I I I ) }$ on surface of the spent catalyst were partially transformed to $\mathrm { { M n } ( I I I ) }$ and $\operatorname { C o } ( \operatorname { I I } )$ , respectively, during catalysis. # 3.6. Reaction mechanism

Based on acquired data and aforementioned discussion, a rational heterogeneous PMS activation mechanism by $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ is proposed in Fig. 6. It is speculated that the $\mathrm { M n C o _ { 2 } O _ { 4 } }$ and FCNTs contributed to the production of $S O _ { 4 } ^ { \bullet \cdot }$ and $\cdot _ { \mathrm { O H } }$ (radical pathway), and $^ 1 0 _ { 2 }$ (nonradical pathway), respectively. In general, transition metal-based catalysts are prone to activate PMS via the radical pathway while carbonbased catalysts can activate PMS through both radical and nonradical pathways. In the radical pathway, ${ \bf { \Lambda } } = { \bf M } { \bf n }$ and ${ \equiv } \mathrm { C o }$ would react with surface hydroxyl groups (-OH) through dissociative adsorption of water molecules on $\mathrm { C o _ { x } M n _ { 3 - x } O _ { 4 } }$ surface to form $\equiv \mathbf { M n } ( \mathrm { I I } )$ - OH and ${ \equiv } \mathrm { C o } ( \mathrm { I I } )$ - 'OH, which could alter the oxidation state of the surface metal and offer active sites for further PMS activation [21]. Subsequently, the $\equiv \mathbf { M n } ( \mathrm { I I } )$ - OH species on $\mathrm { M n C o _ { 2 } O _ { 4 } }$ surface can activate PMS to produce highly diffusible $S O _ { 4 } ^ { \bullet \bullet }$ in Eq. (7) and some more $\equiv _ { \mathrm { M n ( I I ) } } - \mathrm { \cdot } \mathrm { O H }$ species can be generated from the reaction of formed $\equiv _ { \mathrm { M n ( I I I ) } } - \cdot \mathsf { O H }$ species with PMS in Eq. (8). Similarly, ${ \equiv } \mathrm { C o } ( \mathrm { I I } )$ - OH species on the catalyst surface can also react with PMS to produce $S O _ { 4 } ^ { \bullet \cdot }$ in Eq. (9) and then more species are generated by the reactions between the formed ${ \equiv } \mathrm { C o } ( \mathrm { I I I } )$ - OH species and PMS in Eq. (10). Since the reduction of ${ \equiv } \mathrm { C o } ( \mathrm { I I I } )$ by $\mathbf { \equiv } \mathbf { M } \mathbf { n } ( \mathbf { I I } )$ in Eq. # 4. Conclusions

This study has investigated the application of as-synthesized $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ as PMS activator for IBU degradation. Specifically, $\mathtt { M n C o 2 O 4 }$ was uniformly decorated on FCNTs via a facile hydrothermal method and $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ was characterized using multi-scale techniques. In PMS system, $\mathrm { M n C o _ { 2 } O _ { 4 } / F C N T s }$ demonstrated excellent catalytic activity with $k _ { a p p }$ ranging $0 . 2 8 5 { - } 0 . 3 2 7 \operatorname* { m i n } ^ { - 1 }$ under a wide pH range of 39 within $1 0 \mathrm { m i n }$ , achieving a complete removal of IBU and a mineralization rate higher than $9 0 \%$ Moreover, $\mathrm { M n C o _ { 2 } O _ { 4 } }$ /FCNTs can be recycled for stable PMS activation with slight decrease of $k _ { a p p }$ from 0.285 to $0 . 2 0 1 \mathrm { m i n } ^ { - 1 }$ after four cycles during the stability and reusability test. In addition, this catalyst was durable with negligible leaching of metal ions in the solution and could be promising ecofriendly PMS activator for highly efficient catalytic removal of organic pollutants. Furthermore, both radical and nonradical reactions are responsible for enhanced IBU degradation. $\mathrm { M n C o _ { 2 } O _ { 4 } }$ and FCNTs contributed to the production of $S O _ { 4 } ^ { \bullet \cdot }$ and $\cdot _ { \mathrm { O H } }$ (radical pathway), and $^ 1 0 _ { 2 }$ (nonradical pathway), respectively.
