# ARTICLE OPEN Degradation of bisphenol $\mathbf { A }$ in an oxidation system constructed from $\mathbf { M o } _ { 2 } \mathbf { C }$ MXene and peroxymonosulfate

Xuwen Chen $\textcircled { 1 0 } ^ { 1 }$ , Fredrick Owino Gudda1 , Xiaojie $\mathsf { H } \mathsf { u } ^ { 1 }$ , Michael Gatheru Waigi1 and Yanzheng Gao 1✉

The etched ${ \sf M o } _ { 2 } \mathsf { C }$ MXene with a layered structure was characterized as an environmentally friendly catalyst in the bisphenol A (BPA) removal by advanced oxidation. $9 9 . 7 5 \%$ of BPA was degraded in the oxidation system constructed using ${ \sf M o } _ { 2 } \mathsf { C }$ MXene and peroxymonosulfate (PMS). The ${ \sf M o } _ { 2 } \sf C$ MXene was recyclable, with a high removal percentage $( 8 9 . 2 9 \% )$ ) of BPA after even four cycles. The catalysis of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene on PMS was due to the Mo-deficit vacancy defects. The electron paramagnetic resonance technique and density functional theory (DFT)-based density of states calculations verified defect signals. In addition, the defective ${ \sf M o } _ { 2 } \sf C$ MXene and PMS have strong binding and electron transfer capabilities. The reactive oxygen species (ROS, including ${ \sf O } _ { 2 } \dot { { \bf \mu } } ^ { - }$ , $^ 1 \mathrm { O } _ { 2 } ,$ $\mathsf { S O } _ { 4 } \mathrm { ^ { - } }$ , and • OH) produced by ${ \sf M o } _ { 2 } \mathsf { C }$ MXene activates PMS, leading to BPA degradation. The condensed Fukui function predicted the active sites of the BPA molecule and found that the O1, O2, C3, C4, C6, C12, C15, and C16 sites have higher electrophilic reactivity. The C, C–C bonds, or $\mathsf { C 4 } / \mathsf { C 1 6 }$ sites in the isopropyl group connecting the two phenolic rings were attacked first, then further transformed BPA into non-toxic or low toxic small molecule degradation products through a series of reactions such as bondbreaking, addition, hydroxylation, and ring-opening. Moreover, the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene/PMS system has strong applicability in actual water bodies. The study provides valuable insights into PMS activation by two-dimensional MXenes to remove toxic organic pollutants in an aqueous matrix.

# INTRODUCTION

Bisphenol A (BPA) is an important organic chemical raw material used in the preparation of polymer materials such as epoxy resin and polycarbonate, which impact everyday life in that people are in close contact1,2 . The US Environmental Protection Agency stipulated that the BPA flowing into the environment through various channels exceeds one million pounds annually3 . BPA has a wide range of uses but is persistent in environmental matrices; hence it can contaminate food chains, groundwater, and oceans. The concentration of BPA in water, wastewater, food, biological liquids, consumer, and personal care products, and semi-solids were $2 5 1 . 0 0 \mu \mathrm { g } \mathsf { L } ^ { - 1 } .$ , $3 8 4 . \dot { 8 } 0 \mu { } 9 \mathsf { L } ^ { - 1 }$ , $9 3 7 . 4 9 \mu { 9 } \mathsf { k g } ^ { - 1 }$ , $2 0 8 . 5 5 \mu { \sf g } \mathrm { L } ^ { - 1 }$ $3 5 9 0 . 0 0 \mu \mathfrak { g } \mathfrak { g } ^ { - 1 } .$ , and $1 5 4 8 2 0 . 0 0 \mu { \sf g } \mu ^ { - 1 }$ , respectively4 . In surface water and groundwater of Europe and America, the concentrations range from 0.001 to $1 0 0 \mathrm { m g } \mathrm { m } ^ { - 3 } { \textrm { \textsf { 5 } } }$ In Ondo State, southwestern Nigeria, BPA concentrations were $0 . 4 1 - 5 . 1 9 \mu \mathfrak { g } \mathsf { L } ^ { - 1 }$ in river water, $0 . 6 4 - 1 0 . 6 0 \mu { } g \ k g ^ { - 1 }$ in river sediments, and $0 . 6 3 \substack { - 0 . 6 8 \mu { 9 } ^ { \updownarrow { - 1 } } }$ in well water6 . Also, BPA has endocrinedisrupting effects on aquatic wildlife and humans, with its acute toxicity in mammals valued at $6 . 5 0 \mathsf { g } \mathsf { k g } ^ { - 1 7 , 8 }$ . BPA was detected in the urine of approximately $9 5 \%$ of adults in the USA and Asia4 . And the maximum daily intake in adults was as high as $1 1 . 0 0 \mu \mathfrak { g } \ k \mathfrak { g } ^ { - 1 }$ , which was much higher than the average $( 3 0 . 7 6 \mathsf { n g } \mathsf { k g } ^ { - 1 } .$ ). The effects of BPA in humans include cardiovascular problems, reproductive effects, breast development problems, obesity, hormone-related cancers such as breast or prostate cancer, etc.9 . Attention has focused on removing BPA in water, with numerous proposed technologies, such as physical adsorption, chemical adsorption or/and degradation, and biotransformation10. Among them, the chemical oxidation method was widely used because of its fast effect and high rate, such as ${ \mathrm { T i O } } _ { 2 } ,$ $\mathsf { M n F e } _ { 2 } \mathsf { O } _ { 4 }$ modified ${ \mathsf { g } } { \mathsf { - } } { \mathsf { C } } _ { 3 } { \mathsf { N } } _ { 4 } /$ diatomite photocatalytic activation of peroxymonosulfate $( \mathsf { P } \mathsf { M } \mathsf { S } ) ^ { 1 1 - 1 3 }$ . However, the current oxidation methods also have some shortcomings, for example, requiring additional light sources; the cost of preparing composite catalysts is high and the process is complicated; the active components are easily changed and are not conducive to recycling. It is an urgent task to find a catalytic oxidation system that has a low cost of catalyst preparation and maintains a highefficiency catalytic effect.

The advanced oxidation process based on $\mathsf { S O } _ { 4 } \mathrm { ^ { - } }$ $( { \mathsf { S } } { \mathsf { O } } _ { 4 } ^ { \bullet - } { \cdot } { \mathsf { A } } { \mathsf { O } } { \mathsf { P } } { \mathsf { S } } )$ has always received extensive attention owing to its efficient reactivity, wide operating range, good stability, and relatively low cost in detoxifying dangerous pollutants14. It is used to mineralize many structurally stable organic compounds or/and convert them into low-toxic and low-hazard byproducts. The peroxides such as peroxydisulfate (PDS) or PMS are activated to generate $\mathsf { S O } _ { 4 } \mathrm { ^ { - } }$ , and other strong oxidizing agents (• OH) and weak oxidizing agents $( \mathsf { O } _ { 2 } ) ^ { \bullet - }$ and $^ 1 \bar { ( ) } _ { 2 } )$ . $\mathsf { S O } _ { 4 } \mathrm { ^ { - } }$ has a stronger oxidation ability $( 2 . 5 { - } 3 . 1 \lor )$ , a long half-life $( T _ { 1 / 2 } = 3 0 – 4 0 s )$ , a widely applicable pH range (3–9), and a higher selectivity than • OH ( $1 . 8 \mathrm { - } 2 . 7 \ : \forall ,$ $T _ { 1 / 2 } = 2 0 \mathsf { n s }$ , pH $2 - 4 ) ^ { 1 5 - 1 7 }$ . There are many ways to activate peroxides, including light10, heat18, bases19, and transition metals20–22. In recent years, the use of solid catalysts to activate peroxides has received particular interest because of their stability and reusability.

The MXene materials are shaped like a potato chip and have a two-dimensional (2D) nanostructure. Those can be produced by etching the A layer in MAX (M: transition metal, A: IIIA/IVA group element, $\langle : C / \mathsf { N } \rangle ^ { 2 3 , 2 4 }$ . ${ \sf M o } _ { 2 } \mathsf { C }$ MXene material is a transition metal carbide. MXene materials have a layered or sheet structure and unique advantages, such as a large specific surface area, surface functional group design, and considerably coordinated unsaturated external atoms25–27. Like the reported MOFs, MXene materials can also enhance their related application mechanisms through their own rational design, including the introduction of functional ligands, as well as structural and energy band regulation29. In addition, MXene materials generally have single-atom vacancy defects, which would provide a new mechanism for its application. It shows many unique characteristics and promising applications in the field of electronics. Some MXene-based materials can remove organic and inorganic contaminants to purify water and remediate polluted environments30. However, the research of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene in catalysis is mainly the hydrogen evolution reaction31,32. The study of ${ \sf M o } _ { 2 } \sf C$ MXene as a peroxides activator has not been reported yet. In this study, we utilized ${ M O } _ { 2 } C$ MXene and PMS to build an advanced catalytic oxidation system generating reactive oxygen species (ROS). BPA was used as a typical contaminant to examine the performance of the system. This work has the following objectives: (a) Morphology, phase, and mass transfer resistance were analyzed to characterize ${ M O } _ { 2 } C$ MXene; (b) the batch experiments were investigated to explore the activation efficiency of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene on PMS and the degradation effect of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene/PMS system on BPA and evaluate the stability and recyclability of ${ M O } _ { 2 } C$ MXene; (c) the ROS, the defect sites, and calculation of the binding capacity between defective ${ \cal M } \circ _ { 2 } { \cal C } / { \mathsf { n o n } } -$ defective ${ M O } _ { 2 } C$ and PMS were analyzed to elucidate the catalytic mechanism; (d) the transformation products were measured, combined with condensed Fukui function calculation, to clarify the transformation pathways of BPA.

# RESULTS AND DISCUSSION

# Characteristics of $M O _ { 2 } C$ MXene

The $M o _ { 2 } G a _ { 2 } C$ sample was first etched with $40 \%$ hydrofluoric acid solution for $3 6 { \mathfrak { h } }$ at $5 0 \ \textdegree$ to remove the Ga element as much as possible and form defects. As shown in Fig. 1a, the phase of ${ M o } _ { 2 } { \sf G a } _ { 2 } { \sf C }$ by XRD changed obviously after etching, and some diffraction peaks disappeared, especially the diffraction peak at $8 . 9 4 ^ { \circ }$ shifted to the left, and the peak intensity was noticeably enhanced. The peaks at $8 . 9 4 ^ { \circ } $ , $2 8 . 8 6 ^ { \circ }$ , $3 4 . 5 7 ^ { \circ }$ , $3 7 . 0 7 ^ { \circ }$ , $4 2 . 1 0 ^ { \circ } ,$ , $6 1 . 8 2 ^ { \circ } ,$ and $6 5 . 0 4 ^ { \circ }$ of 2θ are the diffraction peaks of the ${ M O } _ { 2 } C$ MXene, which indicated that the MXene material was successfully prepared. In Fig. 1b, c, SEM images showed that $M o _ { 2 } G a _ { 2 } C$ was a solid block, and it is an apparent layered ${ \sf M o } _ { 2 } \mathsf { C }$ MXene structure after etching. The elemental content and morphology of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene were further analyzed by SEM-EDS and TEM in Fig. 1d, e. Furthermore, single vacancy is the only point defect observed in MXene in experiments33. Also, according to previous studies, ${ \sf M o } _ { 2 } \mathsf { C }$ MXene is more prone to form Mo vacancy defects due to its relatively low single-vacancy formation energy $( 0 . 9 6 \mathsf { e V } ) ^ { 3 4 }$ . Regarding this characteristic, its mechanism shall be discussed in detail.

To verify the electrochemically active surface area of the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene, the CV of raw material $M \circ _ { 2 } \mathsf { G a } _ { 2 } \mathsf { C }$ and ${ \sf M o } _ { 2 } C$ MXene was measured in Fig. 1f. It was found that the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene has a larger surface area, which implies that there were more active centers on its surface35. About the Nyquist plots of EIS (Fig. 1g), the radius of the arc shows the interface resistance of the electrode surface, and the smaller the radius, the lower the charge transfer resistance36. Among them, the ${ \sf M o } _ { 2 } C$ MXene has a shorter radius than ${ \mathsf { M o } } _ { 2 } { \mathsf { G a } } _ { 2 } { \mathsf { C } } ,$ indicating that the ${ \sf M o } _ { 2 } C$ MXene obtained after $M o _ { 2 } G a _ { 2 } C$ etching has reduced charge transfer resistance, which not only accelerated the electron transfer in the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene but also promoted the catalytic activity37. Those characteristics suggest that ${ \sf M o } _ { 2 } \mathsf { C }$ MXene is a possible material for activating PMS.

# The performance of $M o _ { 2 } C$ MXene for PMS activation to degrade BPA

As exhibited in Fig. 2a, single-use of ${ \sf M o } _ { 2 } C$ MXene or PMS resulted in no BPA degradation, indicating that ${ \sf M o } _ { 2 } \mathsf { C }$ MXene and PMS have almost no BPA degradation effect. When the raw material $M \circ _ { 2 } \mathsf { G a } _ { 2 } \mathsf { C }$ and PMS coexist, the removal rate of BPA was minimal (only $1 6 . 3 0 \% )$ ), which may be caused by the adsorption of BPA by $M o _ { 2 } G a _ { 2 } C$ or the weak activation of PMS by the exposed transition metal atoms on $M o _ { 2 } G a _ { 2 } C$ surface. This phenomenon implies that $M o _ { 2 } G a _ { 2 } C$ has no effective activation effect on PMS. But when $0 . 5 { \sf g l } ^ { - 1 } { \sf M o } _ { 2 } { \sf C }$ MXene and $2 . 0 \mathsf { m m o l } \mathsf { L } ^ { - 1 }$ PMS exist simultaneously, the degradation percentage of BPA reached $9 9 . 7 5 \%$ within $2 4 0 \mathrm { m i n }$ . And this reaction fitted the pseudo-first-order kinetic equation, with the rate constant being $0 . 0 2 2 7 \mathrm { m i n } ^ { - 1 }$ . This result indicates that ${ \sf M o } _ { 2 } C$ MXene has excellent activation performance on PMS compared to other catalysts, and the production of stronger oxidizing substances led to the removal of BPA. For example, $0 . 5 { \sf g l } ^ { - 1 } 7 0 . 0 0 \%$ copper oxide/halloysite nanotubes activated PMS to degrade $5 0 . 0 \dot { \mathsf { m } } \mathfrak { g } \mathsf { L } ^ { - 1 }$ BPA, and the degradation percentage of BPA was less than $8 0 . 0 0 \%$ within $2 4 0 \mathsf { m i n } ^ { 3 8 }$ . Also, the Me(Ba, Ca, and Mg)SrCoO were used to catalytically generate • OH and $^ 1 { \sf O } _ { 2 }$ for the degradation of dye orange II; the reaction was slow and the degradation percentage was about $9 0 . 0 0 \%$ within $8 \mathsf { h } ^ { 3 9 }$ The ${ \sf M o } _ { 2 } C$ MXene used from two to four cycles resulted in BPA degradation percentages of $1 0 0 \%$ , $9 0 . 2 0 \%$ , and $8 9 . 2 9 \% ,$ respectively (Fig. 2b). This slight inactivation may be due to the active sites being occupied by partial decomposition of organic residues, as some defective sites on the ${ \sf M o } _ { 2 } C$ MXene were oxidized15,40. Overall, ${ \sf M o } _ { 2 } C$ MXenes have good recyclability compared to some catalysts in AOPs. It has been reported that the degradation activity of the traditional iron oxide Fenton catalyst decreased from $7 0 . 0 0 \%$ to $1 0 . 0 0 \%$ in only 4 cycles39.

Additionally, the reaction rate constants (Fig. 2d) were obtained by fitting the pseudo-firstorder degradation kinetic curves (Supplementary Fig. 1) to get. For the concentration of ${ \sf M o } _ { 2 } \sf C$ MXene and PMS at $0 . 1 { - } 1 . 0 9 \mathsf { L } ^ { - 1 }$ and $0 . 5 { - } 5 . 0 \mathsf { m m o l } \mathsf { L } ^ { - 1 }$ , as the dosage increased, the degradation rate of BPA increased first and then decreased. Still, the degradation percentage was close to $100 \%$ at high doses. When ${ M O } _ { 2 } C$ MXene and PMS were $0 . 5 { \mathfrak { g l } } ^ { - 1 }$ and $2 . 0 \ : \mathrm { m m o l } \ : \mathsf { L } ^ { - 1 }$ , respectively, there was a great increase in $k$ value, indicating that the two perfectly cooperate to continuously generate a large amount of ROS at this dose. ${ \sf M o } _ { 2 } \mathsf { C }$ MXene can provide more active sites and surface area, and higher PMS can offer greater contact with ${ \sf M o } _ { 2 } C$ MXene41. However, when ${ \sf M o } _ { 2 } \mathsf { C }$ MXene was excessive, its contact with PMS was limited. And when PMS was excessive, the large amount of ROS generated instantaneously would be self-quenched, resulting in a decrease of $k$ of BPA degradation42,43.

BPA degradation first decreased from $\mathsf { p H } ~ 3$ to $\mathsf { p H } ~ 7$ before increasing to $\mathsf { p H } 1 0$ . BPA can be entirely degraded under acidic conditions, $9 2 . 6 6 \%$ under basic conditions, and $7 3 . 6 1 \%$ under neutral conditions. This shows that ${ \sf M o } _ { 2 } \sf C$ MXene has a wider range of applications than some Fenton-like catalysts. The biochar/iron oxide composite degraded $1 0 \mathrm { m g L } ^ { - 1 }$ BPA at $\mathsf { p H } ~ 3$ through a Fenton-like reaction, and the degradation percentage was only $6 9 . 8 0 \%$ within $1 0 0 0 \mathrm { { m i n } }$ . And with the increase of solution pH, the degradation percentage of BPA tended to decrease44. The zero charge point $( p \mathsf { H } _ { \mathsf { p } z \mathsf { c } } )$ of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene is lower than 3 in Supplementary Fig. 2, indicating that its surface is negatively charged between pH 3–10, which is not conducive to binding with PMS molecules to produce ROS; therefore, the degradation rate of BPA gradually decreases at $\mathsf { p H 3 - 7 }$ . However, there may be a process of base activation at higher pH (pH 10), which led to BPA degradation, owing to the negatively charged $\mathsf { O H } ^ { - }$ being easier to donate electrons than ${ \sf H } _ { 2 } { \sf O }$ molecules43. This result implies that ${ M O } _ { 2 } C$ MXene/PMS system is effective for acidic and base conditions. Moreover, the initial unadjusted pH value of our experiment should be between 3 and 5.

Increasing the reaction temperature had a positive effect on the degradation of BPA (Supplementary Fig. 3a, b), which increased the degradation percentage and improved the reaction rate. The degradation percentage of BPA increased from $8 9 . 1 1 \%$ to $9 9 . 7 5 \%$ in $2 4 0 \mathrm { m i n }$ from $1 5 ^ { \circ } \mathsf { C }$ to $2 5 ^ { \circ } \mathsf C ,$ and further increased to $3 5 ^ { \circ } \mathsf C ,$ BPA was completely degraded within $1 0 0 \mathrm { { m i n } }$ . This was mainly because temperature accelerated the movement of molecules, which was favorable for ROS production and the interaction between ROS and pollutants, and high temperature may also contribute to the activation of ${ \mathsf { P M S } } ^ { 4 5 }$ . In addition, we calculated the activation energy using the Arrhenius equation (Supplementary Methods; Supplementary Fig. 3c), which was $5 2 4 . 1 \dot { 2 } \mathrm { J } \mathsf { m o l } ^ { - 1 }$ .

Other types of contamination were used to evaluate the ${ \sf M o } _ { 2 } \sf C$ MXene’s application potential, including the activation efficiency of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene for different kinds of oxidants and the degradation effects of oxidation systems for different types of pollutants (Supplementary Fig. 4). Both PMS and PS are peroxides, and the degradation percentage of BPA in the ${ M O } _ { 2 } C$ MXene/PMS system was $9 9 . 7 5 \%$ . However, when ${ \sf M o } _ { 2 } C$ MXene activated PS, BPA can be completely degraded within 80 min. This suggests that ${ \sf M o } _ { 2 } \mathsf { C }$ MXene has good applicability to persulfate-based peroxides. In addition, the degradation efficiency of ${ \sf M o } _ { 2 } C$ MXene-activated PMS to BPA, bisphenol S (BPS), benzyl butyl phthalate (BBP), and naphthalene (NAP) was also explored. In order to explore the environmental applicability of the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene/PMS system in real water, we applied it in five natural water bodies, namely Pond 1, Pond 2, Huai River, Guo River, and Qinhuai River. # Catalytic mechanism of $M O _ { 2 } C$ MXene

To further explore the electron transfer mechanism between ${ \sf M o } _ { 2 } \mathsf { C }$ MXene and PMS, the ${ \sf M o } _ { 2 } C$ MXene samples before and after the reaction were explored by XPS. As displayed in Fig. 4a, b and Supplementary Table 1, the ${ M O } _ { 2 } C$ MXene includes Mo, C, and O elements. The C 1s spectrum of ${ M O } _ { 2 } C$ MXene was fitted to three peaks: 284.07 eV belongs to the Mo–C bond, 284.81 eV was the C–C bond, and 288.55 eV may be contributed by oxidized $\mathtt { C = } 0$ bond on ${ \sf M o } _ { 2 } \sf C$ MXene surface26. The O 1s spectrum was deconvoluted into two peaks (530.09 and $5 3 1 . 2 3 \mathrm { e V } )$ ; they were contributed by the surface lattice oxygen in the metal–oxygen bond and adsorbed oxygen and the hydroxyl group, respectively7,57. The content of the adsorbed oxygen and the hydroxyl group increased from $5 4 . 9 6 \%$ to $6 4 . 2 0 \%$ after the reaction of ${ \sf M o } _ { 2 } \mathsf { C }$ MXene. The results indicate that the ${ \sf M o } _ { 2 } C$ MXene surface would adsorb some oxygen-containing groups during the reaction. # Condensed Fukui function and proposed transformation pathways of BPA

To deeply analyze the transformation mechanism of BPA in the ${ \sf M o } _ { 2 } \sf C$ MXene/PMS system, we calculated the condensed Fukui function of BPA (Fig. 6a). It can predict the reaction site. The reddest atom in the figure, the larger the condensed Fukui function value $f ^ { 0 } .$ , the easier it is for electrophilic reactions to occur. For BPA, O1, O2, C3, C4, C6, C12, C15, and C16 are all sites with very high reactivity with $\rho ^ { 0 } > 0 . 0 4$ . The mass spectra of the possible transformation products from BPA degradation in the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene/PMS system were shown in Supplementary Figs. 9–30. Figure 6b shows that BPA was first attacked by ${ \sf O } _ { 2 } \cdots$ and $\cdot _ { \mathrm { O H } , }$ which resulted in the C–C bond cleavage and hydroxylation, forming P1, then P2 generated by ring-opening72. Second, BPA can be oxidized by ROS to phenol (P3 and P4), then dehydrogenated and oxygenated to P6 before being hydroxylated and dehydroxylated to P7 and $\mathsf { P 9 } ^ { 7 2 , 7 3 }$ . After BPA decomposition, C3 or/ and C15 were attacked and dehydroxylated to form P5, and P6 was converted to P8 through ring-opening3,5 . Third, BPA was oxidatively demethylated by free radicals to become P10 and P12, and P10 can also be dehydrogenated to P11. P12 transforms the hydroxylated product P13 and P14 through the electrophilic addition of • OH to C4, C16, and C14, which was finally oxidized by $\mathsf { S O } _ { 4 } ^ { \bullet - }$ and • OH to cause ring-opening and form P15. This process has also been found in other $\dot { \mathsf { A O P S } } ^ { 6 6 }$ . Fourth, BPA can degrade to P19 by dehydroxylation and oxidation at the C16 site and then become small molecule acids P20, P21, and P22 through C–C cleavage, • OH addition, and elimination reactions3 . Also, similar to the above route, BPA can convert through dehydroxylation (P17) and oxidation (P18) at C4 and C16 sites7 . In addition, through ROS oxidation, the two methyl functional groups in the isopropyl group connecting the two phenolic rings can be transformed into alcohol and carboxyl groups $( \mathsf { P } 1 6 ) ^ { 6 6 }$ . Most of these intermediates were unstable and would soon be further mineralized into ${ \sf H } _ { 2 } { \sf O }$ and ${ \mathsf { C O } } _ { 2 }$ . Notably, the transformation products of BPA were found to be non-toxic or low-toxic (listed in Supplementary Table 2). The acute toxicity of BPA to Mouse (intraperitoneal) and Cavia porcellus (oral) was 150.0 and $4 . 0 \mathsf { m g } \mathsf { k g } ^ { - 1 }$ , respectively. And the median lethal dose $( \mathsf { L D } _ { 5 0 } )$ of Rat (inhalation) was $1 7 . 0 \mathsf { m g L } ^ { - 1 }$ . However, only the products P3, P4, P5, P6, P7, P9, P12, P20, and P22 have toxic records. Most of its toxicity values (expressed as $\mathsf { L D } _ { 5 0 } )$ in rats (oral, inhalation, dermal) and rabbit (dermal) were as high as several hundred, or even tens of thousands of $\mathsf { m } \mathsf { g } \mathsf { k } \mathsf { g } ^ { - 1 }$ . This implies that the transformation products of BPA after oxidation treatment by the ${ \sf M o } _ { 2 } \mathsf { C }$ MXene/PMS system were environmentally friendly.

# Computational chemical analysis

The binding energies are calculated based on density functional theory (DFT), which utilizes the $\mathsf { V A S P } ^ { 7 4 , 7 5 }$ with the frozen-core allelectron $\mathsf { P A W } ^ { 7 6 , 7 7 }$ . The Perdew–Burke–Ernzerhof78 of generalized gradient approximation was used to explain the exchange and correlation potential. A monolayer $4 \times 4$ defective ${ \sf M o } _ { 2 } { \sf C } /$ undefective ${ \sf M o } _ { 2 } \mathsf { C }$ (001) supercell was used. The ${ \mathsf { H S O } } _ { 5 } ^ { - }$ molecule was placed on the top-site of Mo in ${ M O } _ { 2 } C$ MXene, and a $2 0 \mathring { \mathsf { A } }$ vacuum area was added to decrease the interaction. Perform geometric optimization until the force on each ion drops below $\mathsf { \bar { 0 } } . 0 1 \mathsf { e V } / \mathring { \mathsf { A } } .$ The Monkhorst-Pack k-point sampling was set to $2 \times 2 \times 1 ^ { 7 9 }$ . The binding energy $( E _ { \mathrm { b i n d } } )$ is calculated using the Eq. 12.

$$
E _ { \mathrm { b i n d } } = E _ { \mathrm { m o l e c u l e + s u r f a c e } } - ( E _ { \mathrm { s u r f a c e } } + E _ { \mathrm { m o l e c u l e } } )
$$

where $\boldsymbol { E } _ { \mathsf { s u r f a c e } }$ is the energy of defective ${ \sf M o } _ { 2 } { \sf C } /$ undefective ${ \sf M o } _ { 2 } C$ (001) supercell, $\scriptstyle { E _ { \mathrm { m o l e c u l e } } }$ represents the energy of ${ \mathsf { H S O } } _ { 5 } ^ { - }$ , Emolecule $^ +$ surface represents the total energy.

The calculation method of the DOS is shown in Supplementary Methods. The condensed Fukui function was calculated through computational chemistry optimization. Firstly, Chemoffice 19 software was used to draw the molecular structure of BPA, and then Gaussian 09 W software was utilized to optimize the molecule by the DFT at the ωB97XD/6-31G basis set. Finally, Multiwfn 3.8 was used in the calculations before displaying using VMD80.
