# A BST RAC T

In this study, the catalytic ability and mechanisms involved in activating peroxymonosulfate (PMS) with $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ and the degradation pathways of bisphenol-AF (BPAF) removal was investigated. $S O _ { 4 } ^ { - \bullet }$ and ·OH which were explored by and scavenging tests were the major reactive radicals in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system. A simple simulation algorithm was also used to calculate the relative concentrations of $S O _ { 4 } ^ { - \bullet }$ $\mathrm { [ S O _ { 4 } ^ { - \bullet } ] ) }$ and ·OH ([·OH]) which were $8 . 3 9 \times 1 0 ^ { - 1 5 } \mathrm { ~ M ~ }$ and $6 . 9 6 \times 1 0 ^ { - 1 3 } \mathrm { ~ M } ,$ respectively. The mechanism for the electron transfer between the $\mathsf { M n }$ (II) and Mn (III) species was discussed. Three degradation pathways of BPAF were determined by the GC/MS and LC/MS technology, including chemical mechanism of oxidation, hydroxylation, electron transfer, polymerization, and ring-cleavage. In addition, the results suggested that the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system had an efficient total organic carbon (TOC) removal rate and excellent environmental adaptability, the removal rate of TOC being as high as $7 3 . 2 \%$ in the control condition. Furthermore, the reuse experiments and the comparison on the structural and componential changes of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ powder before and after reaction demonstrated that the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ catalyst possessed excellent stability and reusability. Finally, a maximum BPAF degradation of approximately $9 0 . 0 \%$ was achieved on the optimal conditions for $5 0 0 ~ \mathrm { m g / L }$ $\mathrm { { M n } _ { 3 } \mathrm { { O } _ { 4 } } }$ dosage, $4 \ \mathrm { m M }$ PMS concentration, $7 . 0 \pm 0 . 2$ initial $\mathsf { p H }$ , and $5 ~ \mathrm { \ m g / L }$ BPAF concentration respectively. And the effect of the coexisting anions and natural environmental water quality were also considered. This study demonstrated the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system can be considered as a green approach for the removal of environmental reluctant pollutants. $^ ©$ 2020 Elsevier Ltd. # 1. Introduction

As a commonly used BPA-substitute, BPAF has been extensively applied as a cross-linking reagent, curing agent, and food-contact polymer in many fields (Peng et al., 2015). With the consumption of BPAF increasing, BPAF has been detected at various levels in many areas, such as rivers (up to $1 5 . 3 \mu \mathrm { g } / \mathrm { L } \ '$ , sediments $( 0 . 2 \mu \mathrm { g } / \mathrm { g }$ dry weight), soils $( 3 3 1 ~ \mathrm { n g } / \mathrm { g }$ dry weight), indoor dust $\mathbf { ( 0 . 7 3 9 \ \mu g / g }$ dry weight), and well water ${ \mathrm { ~ \cos ~ } } [ \mathrm { L } )$ (Li et al., 2012; Choi and Lee, 2017; Moreman et al., 2017; Wang et al., 2019). In addition, previous literature have also reported that human urine contains BPAF, and public health is increasingly exposed to environmental BPAF (Yang et al., 2014). More importantly, due to the difficult biodegradability and photodegradability of BPAF, traditional biochemical treatments cannot effectively degrade it (Yang et al., 2019a). The advanced oxidation process (AOPs) is considered as an efficient and promising technology for removing refractory organic contaminants (Abdul Nasir Khan et al., 2019). Previous studies have presented a certain theoretical approach for effective mineralization of refractory organic pollutants, based on the in situ generation of highly reactive radicals, such as the hydroxyl radicals (·OH) and the sulfate radical $( \mathsf { S } 0 _ { 4 } ^ { - \bullet } )$ (Liu et al., 2017; Ren et al., 2015). Since $S O _ { 4 } ^ { - \bullet }$ has higher redox potential (2.5e3.1 V, versus NHE) (Qi et al., 2014), stronger selectivity, longer half-life, and a wider pH range compared to ·OH, it has been evaluated for pollutant destruction and has received increasing attention (Chen et al., 2012). Peroxymonosulfate (PMS), as the origin of $S O _ { 4 } ^ { - \bullet }$ , is relatively stable, easily stored and transported, and environmentally friendly, and can be activated using alkalines, nano carbons, UV irradiation, heat, microwaves, electro-sorption, and transition metal ions or oxides (Wang and Wang, 2018). Among these methods, transition metals or oxides provide a good and efficient way to generate $S O _ { 4 } ^ { - \bullet }$ owing to the low energy consumption and the ease of recycling these catalysts (Oh et al., 2015). Nevertheless, recent research for BPAF removal focus on the adsorption technology, ferrate oxidation or ferrite composites activation of PMS, and bisulfite activation of persulfate, and the previous literatures on BPAF removal were shown in Table S1. Peng et al. reported the adsorption capacity of chitosan-modified zeolite with $\mathsf { N a C }$ for BPAF, achieving a maximum degradation efficiency approximately $78 \%$ (Peng et al., 2015). Wang et al. synthesized porous ${ \tt B i F e O } _ { 3 }$ as a catalyst to activate PMS for BPAF degradation, and they detected an efficient degradation efficiency near neutral medium, in which the reusability of the catalyst was not explored (Wang et al., 2020a). In addition, previous literatures had reported the homogeneous system of ferrate and bisulfite for BPAF removal. Yang et al. explored the ferrate oxidation $( \mathrm { F e O } _ { 4 } ^ { 2 - } )$ of BPAF, and the dominant reaction mechanism of oxygen transfer and the improvement on their biodegradability were investigated (Yang et al., 2019b). Wang et al. used bisulfite to activating persulfate for BPAF removal, and both non-radical and radical were generated as the dominant reactive radical responsible for BPAF degradation (Wang et al., 2020b). However, little attention has been devoted to the transition metals or oxides, especially manganese oxide, to activate PMS for BPAF removal and the degradation pathway of BPAF remained unclear.

Recently, due to the advantages of being eco-friendly, costeffective, highly stable, variable valence, and abundant in soils, manganese-based materials have been identified as promising heterogeneous catalysts for AOPs, compared with some other transition metals such as cobalt and iron (Zhou et al., 2019; Huang et al., 2020; Shabanloo et al., 2020; Zeng et al., 2020; Zhu et al., 2020). $\beta \mathrm { - }  { \mathrm { M n O } _ { 2 } }$ nanorods was demonstrated to be the best catalyst by activating PDS for phenol degradation, compared with other chemical states and crystallographic structures of manganese oxide (Zhu et al., 2019). On the other hand, Khan et al. demonstrated that a nanorod $\scriptstyle \alpha - \mathbf { M } \mathbf { n } _ { 2 } \mathbf { O } _ { 3 } @ \alpha - \mathbf { M } \mathbf { n } \mathbf { O } _ { 2 } - 5 0 0$ nanocomposite exhibited the highest efficiency and remarkable stability in PMS activation compared with other manganese oxide based catalysts including $\pmb { \mathscr { L } }$ - $ { \mathrm { M n O } _ { 2 } }$ , ${ \beta } { \mathrm { - } } { \mathrm { M n O } } _ { 2 }$ , $\mathsf { \gamma } \mathsf { - M n O } _ { 2 }$ , ${ \delta } { \mathrm { - } } { \mathrm { } } { \mathrm { } } { \mathrm { M n O } } _ { 2 }$ , ${ \tt a } { \tt { - } } { \tt { M } } { \tt { n } } _ { 2 } { \tt { O } } _ { 3 }$ etc (Khan et al., 2018a). In addition, Wang et al. reported that the catalytic activity of the synthesized Mn oxides with different valence states to activate PMS for phenol degradation; the order of the catalytic activity was as follows: $\mathrm { M n } _ { 2 } \mathrm { O } _ { 3 } \mathrm { ~ > ~ } \mathrm { M n O } \mathrm { ~ > ~ } \mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } \mathrm { ~ > ~ } \mathrm { M n O } _ { 2 }$ , but the $\mathrm { M n _ { 3 } O _ { 4 } / P M S }$ system was not discussed in detail (Saputra et al., 2013, 2014). Mnoxide supported materials (CuO, ZnO, $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ , $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } ,$ , $\mathrm { T i O } _ { 2 }$ , $ { \mathrm { M n O } _ { 2 } }$ , and ZIF-8) have also been used as supports for hybridization with $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ , displaying the specific properties of catalysts, absorbents, or electrode materials, which require high energy consumption during preparation or complicated synthesis procedures (Chen et al., 2012; Khan et al., 2017; Qamar et al., 2017; Wan and Wang, 2017; Zhao et al., 2017a; Hu et al., 2017). Therefore, the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ has great potential to activate PMS for organic pollutants removal. However, the manganese-based catalysts were not comprehensive in the activation of PMS based AOPs, and no research has been conducted on the degradation of BPAF in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system. Hence, a systematic study of using $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ as a catalyst to activate PMS for BPAF degradation is needed. Moreover, it is of great significance to explore a catalyst with highly effective mineralization and to further analyze the catalytic mechanism by activating PMS with $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ and the degradation pathway of BPAF.

In this work, $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ was utilized for activating PMS to degrade BPAF in aqueous solutions. Fresh and used $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ were characterized by scanning electron microscopy (SEM), X-ray diffraction (XRD), X-ray photoelectron spectroscopy (XPS), and Fourier translation infrared spectroscopy (FT-IR). The effects of influential parameters, such as PMS dosage, catalyst dosage, and coexisting anions were investigated. Moreover, the stability and reusability of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ were observed. The excellent mineralization of the system was also confirmed by the TOC experiments and the comparison with other reaction systems. Finally, the main mechanism of different radicals for PMS activation and the degradation pathways of BPAF were explored in detail.

# 2.2. Experimental procedure

The BPAF degradation experiments were performed in a $2 5 0 \mathrm { m L }$ glass beaker containing $5 ~ { \mathrm { m g / L } }$ BPAF, which was placed in a water bath with a temperature controller $( 2 5 ^ { \circ } \mathsf C \pm 1 )$ . A predetermined concentration of PMS was added into the above-mentioned solution and then the desired amounts of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ catalysts were quickly added to initiate the BPAF degradation. The reaction was carried on for $9 0 \mathrm { { m i n } }$ and at a fixed time interval (0, 10, 20, 30, 45, 60, 90 min), $3 \mathrm { m L }$ of solution sample was taken from the mixture using a syringe with a $0 . 2 2 ~ { \mu \mathrm { m } }$ filter and then quenched with $0 . 0 5 { \mathrm { ~ m L } }$ furfuryl alcohol to determine the amount of BPAF. All the experiments were repeated three times to ensure accuracy. The results presented are the average values with error bars from the three experiments.

# 2.3. Samples analysis and characterization

The concentration of BPAF was analyzed using an Alliance Waters e 2695 high-performance liquid chromatography (HPLC) system, equipped with a 2489 UVevisible detector set at $\lambda = 2 7 0 \mathrm { n m }$ and a Waters C18 reversed-phase column $( 1 5 0 \times 4 . 6 ~ \mathrm { m m }$ , $5 ~ { \mu \mathrm { m } }$ particle). The flow liquid of the solvent (mobile phase) was taken by a combination of $7 0 \%$ methanol and $3 0 \%$ formic acid solution $( 0 . 1 \% )$ $( 7 0 { : } 3 0 ~ \mathrm { v / v } )$ and at a flow rate of $1 . 5 ~ \mathrm { m L / m i n }$ . The column temperature was maintained at $3 5 ^ { \circ } \mathsf C ,$ , and the injection volume was $6 0 \mu \mathrm { L }$ The intermediates of the BPAF degradation were qualitatively analyzed by gas chromatography-mass spectrometry (GC/MS, trace 1300, Thermo Fisher Scientific, USA) and high-performance liquid chromatography (HPLC, 1100, Agilent Technology, USA) equipped with a triple quadrupole mass spectrometer (TSQ Quantum Ultra, Thermo Fisher Scientific, USA).

Furthermore, the residual of the PMS concentration was measured using the iodometric method (Liu et al., 2019a). For some samples, the total organic carbon (TOC) was assayed by an Elementar liquid TOC II analyzer (CPH CN200, Shimadzu). For the measurement of TOC, a $1 0 ~ \mathrm { m L }$ sample was extracted at a fixed interval after using a syringe with a $0 . 2 2 ~ { \mu \mathrm { m } }$ filter, and mixed with $4 0 ~ \mu \mathrm { L }$ of $1 \textbf { M }$ sodium nitrite solution to quench the reaction and then analyzed on the TOC analyzer. The original and residual $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ particles were characterized by scanning electron microscopy (SEM, JSM-7500 F), X-ray diffraction (XRD, X’Pert Pro MPD diffractometer), and X-ray photoelectron spectroscopy (XPS, XSAM 800). The residual $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ particles which were examined were filtered through a glass fiber membrane $( 0 . 2 2 \mu \mathrm { m } )$ ), withdrawn at a pre-scheduled interval and dried in a vacuum dryer for $^ { 1 2 \mathrm { ~ h ~ } }$ . The air acetylene flow was set as $1 . 0 ~ \mathrm { L / m i n }$ , and combustion head height was $7 . 0 \ \mathrm { m m }$ .

# 3. Results and discussion

# 3.1. Effects of reaction parameters on the degradation of BPAF

# 3.1.1. Effect of catalyst dosage

Fig. 1a shows that the degradation of BPAF in aqueous solution was dramatically influenced by the catalyst dosage. The removal efficiency of BPAF increased from $4 3 . 6 \%$ to $9 6 . 1 \%$ when the catalyst dosage increased from $1 0 0 ~ \mathrm { { m g / L } }$ to $1 0 0 0 ~ \mathrm { { m g / L } }$ . This is because the increased catalyst dosage would provide more active sites on catalyst surface for PMS activation. In addition, almost no BPAF degraded in the PMS alone system.

As shown in Fig. 1b, the kinetic curves of BPAF degradation were close to a first-order kinetics model ln $( { \mathsf { C } } _ { \mathrm { t } } / { \mathsf { C } } _ { 0 } ) = - { \mathsf { k } } _ { 0 } { \mathsf { b } } s ^ { \mathrm { t } } ,$ where ${ \sf C } _ { 0 }$ and $\mathsf { C } _ { \mathrm { t } }$ represent the BPAF concentration at time (0) and $\mathbf { t } = \mathbf { t }$ respectively, and $\mathbf { k _ { 0 } } \mathbf { \hat { b } } \mathbf { s }$ is the apparent reaction rate constant. When the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ dosage increased from 100 to $1 0 0 0 ~ \mathrm { { m g / L } }$ , kobs increased almost linearly from 0.0059 to $0 . 0 3 6 7 \ \mathrm { m i n } ^ { - 1 }$ . This indicates that BPAF degradation can be enhanced under higher catalyst dosage.

# 3.1.2. Effect of PMS concentration

The effect of PMS concentration is shown in Fig. 2a. The BPAF degradation efficiency was significantly increased from $2 3 . 6 \%$ to $9 8 . 4 \%$ with increasing PMS concentration from $0 . 2 5 ~ \mathrm { m M }$ to $8 ~ \mathrm { m M }$ . However, when the concentration of PMS had been doubled from $4 \ m M$ to $8 \ \mathrm { m M }$ , the degradation of BPAF was not promoted but inhibited the excessive PMS, owing to the scavenging effect between ${ \mathrm { H S O } } _ { 5 } ^ { - }$ and the reactive oxygen species (ROS) (Eqns. (1-2)). Moreover, it was reported that the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ could react with ${ { 0 } _ { 2 } }$ to produce $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ , which in turn generated ·OH radicals to degrade organic pollution in the aqueous solution (Weng et al., 2017). However, owing to the low yield of ·OH with the addition of $5 0 0 \mathrm { m g / L M n _ { 3 } O _ { 4 } }$ during the reaction period, the removal efficiency of BPAF was only $7 . 6 \%$ .

# 3.2.1. Effect of water quality

To demonstrate the effects of these coexisting anions on the BPAF degradation in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system, ${ \mathrm { H C O } } _ { 3 } ^ { - }$ , ${ \mathsf { N O } } _ { 3 } ^ { - }$ , and ${ \bf C l ^ { - } }$ were added in the reaction solution, respectively. # 3.2.2. Reusability of ${ \cal M } n _ { 3 } { \cal O } _ { 4 }$

To evaluate the stability of the catalyst, four successive experiments were carried out in the same condition and the result is shown in Fig. 4a. The degradation efficiency of BPAF was more than $8 9 . 2 \%$ after the fourth run, a negligible drop compared to the control experiment of $9 0 . 0 \%$ , while the degradation efficiency increased to $9 4 . 2 \%$ and $9 7 . 1 \%$ for the fifth and sixth run, respectively. These results may be caused by the corrosion of the passivation layer on the oxide surface. Furthermore, Mn3O4 showed excellent stability in that the leached Mn was less than $5 . 6 9 ~ \mathrm { m g / L }$ after the reaction, only accounting for $1 . 1 \%$ of the total dosage. A metal ion leaching test using $\mathrm { M n } ^ { \bar { 2 } + }$ was also undertaken and the result indicated that the metal leaching had only a slight effect on PMS activation (shown in Fig. S1).

The original and residual $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ powders in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system characterized by SEM and XRD were investigated. Fig. S2 shows the SEM images of the original and residual $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ powders. The original $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ powders mainly consist of acicular crystals, which exhibit a relatively uniform size, with a diameter of around $5 0 0 \mathrm { n m }$ . However, there were obvious signs of corrosion on the crystal surface after $9 0 \mathrm { { m i n } }$ reaction, indicating the destruction of the acicular structure of the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ powders. These changes indicate that manganese ions are involved in the reaction process. To further identify the phase structure of the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ , X-ray diffraction (XRD) measurements were performed. As shown in Fig. S3, whether before the reaction or after the reaction to $3 0 0 \mathrm { { m i n } }$ , the diffraction peak is in perfect agreement with the acicular $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } ( \mathrm { P D F } \# 2 4 - 0 7 3 4$ , hausmannite, $\mathrm { { M n } _ { 3 } { O _ { 4 } } } .$ ), indicating the phase structure of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ powders is stable in the $\mathrm { M n _ { 3 } O _ { 4 } / P M S }$ system. The above experimental phenomena suggest that the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ catalyst possesses excellent stability and potential for repeated use, mainly attributed to the exchange of manganese ions on the surface of the material, which can enhance the stability of the catalyst.

# 3.2.3. Mineralization

TOC tests were conducted to evaluate the efficiency of BPAF mineralization for the $\mathsf { M n } _ { 3 } 0 _ { 4 } / \mathsf { P M S }$ system. As shown in Fig. 4b, the TOC removal rate increased with increasing reaction time, but remained stable after reaction for $9 0 \mathrm { { m i n } }$ . During the initial $6 0 \mathrm { { m i n } }$ reaction, TOC removal was achieved with a removal rate of $6 2 . 7 \%$ , which was consistent with the removal trend of BPAF. After 90min, the maximum removal rate for TOC reached $7 3 . 2 \%$ and the degraded BPAF, which was not mineralized, was only $1 8 . 3 \%$ . However, the TOC removal efficiency did not improve as the reaction time increased and tended to be stable. As shown in Table S1, the efficiency of BPAF mineralization was only $5 2 . 0 \%$ in the $_ { \mathrm { B i F e O _ { 3 } / P M S } }$ system. Although the efficiency of BPAF mineralization in the $\mathrm { T i O } _ { 2 } /$ UV was high at $7 0 . 0 \%$ , the mineralization time was much longer for the $\mathrm { M n _ { 3 } O _ { 4 } / P M S }$ system. These results indicate that BPAF can be efficiently mineralized in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system, compared with other reaction systems (Table S1).

# 3.3.3. XPS analysis of ${ \cal M } n _ { 3 } { \cal O } _ { 4 }$ powders

To further explain the activation mechanism of the $\mathrm { M n _ { 3 } O _ { 4 } / P M S }$ system, XPS was used to investigate the chemical composition of active species (i.e., Mn, and O) for $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ before and after the reaction. As presented in Fig. 6a, strong peaks of Mn 2p, O1s were observed. The survey scan revealed that the catalysts were manganese oxides. From Fig. 6b, whether before or after the reaction, two peaks can be observed at binding energies of 641.8 and $6 5 3 . 2 \mathrm { e V }$ , consistent with the characteristic values of XPS spectra on $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ , in which the splitting width between Mn $\mathsf { 2 p } _ { 3 / 2 }$ and Mn $\mathsf { 2 p } _ { 1 / }$ $^ 2$ is $1 1 . 4 \mathsf { e V }$ (Hu et al., 2017). The $\mathtt { M n 2 p 3 } / 2$ peaks can be divided into two components located at 641.4 and $6 4 3 . 4 ~ \mathrm { e V }$ (before reaction), 641.5 and $6 4 3 . 8 \ \mathrm { e V }$ (after the reaction), corresponding to Mn (III) and Mn (II) with the relative contributions of $6 6 . 3 \%$ , $3 3 . 7 \%$ before the reaction and $7 4 . 9 \%$ , $2 5 . 1 \%$ after the reaction, respectively (Zhou et al., 2019; Zhao et al., 2017b; Li et al., 2017). The relative contribution of Mn (III) increased from $6 6 . 3 \%$ to $7 4 . 9 \%$ after the reaction. Correspondingly, the relative contributions of Mn (II) reduced from $3 3 . 7 \%$ to $2 5 . 1 \%$ after the reaction. This suggests that the redox reaction among Mn (III)/Mn (II) and PMS occurred on the surface of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ , and the Mn (II) on the surface of the used catalyst could transform partially to Mn (III) during the process of PMS activation. The result is similar to that reported in the literature on the manganese oxides activating PMS (Zhao et al., 2017b; Tang et al., 2015; Yao et al., 2014).

Fig. 6c shows the O 1s profile for $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ before and after the reaction. The O 1s spectra of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ sample before reaction had three peaks at binding energies of 529.9, 531.0 and $5 3 3 . 7 \ \mathrm { e V }$ , corresponding to lattice oxygen of $_ { \tt M n - 0 }$ bonds (Olat), hydroxyl on the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ surface (Osurf) and the adsorbed molecular water (Oads) with the relative contributions of $3 9 . 7 \%$ , $5 7 . 6 \%$ and $2 . 7 \%$ respectively (Xu et al., 2019; Li et al., 2017; Duan et al., 2015). # 3.4. Proposed reaction pathways

To elucidate the degradation pathways of BPAF in the $\mathrm { { M n } _ { 3 } { O _ { 4 } } / }$ PMS system, the main intermediates were determined by LC/MS and GC/MS. Eleven intermediates were identified, including pyrocatechol, phthalic acid, phenol, 4-hydroxyisophthalic acid etc. (shown in Table S4, Fig. S4, and Fig. S5). Based on the product analysis and previous studies (Wang et al., 2020a; Li et al., 2018), BPAF degradation mechanisms are proposed during BPAF degradation (Fig. 7). These mechanisms mainly include (i) the oxidation by radicals forming the hydroxylated derivative, (ii) the scission of CeC between the hexafluoro-isopropyl and benzene rings, (iii) the multi-hydroxylation of the aromatic ring via electrophilic attack, and (iv) polymerizing between two compounds via carbon-carbon (CeC) or carbon-oxygen (CeO) forming dimers (Yang et al., 2019b; Li et al., 2018; Saroyan et al., 2019; Du et al., 2016). Further, the possible degradation pathways of BPAF underwent three different pathways (as shown in Fig. 7).

Pathway 1: the nucleophilic attack of phenolic radicals by water molecules resulted in the mono or multi-hydroxylation of the aromatic rings (Saroyan et al., 2019). The hydroxylated BPAF then transformed into pyrocatechol (P5) and phthalic acid (P6) via aldehyde-carboxylation, CeC bond splitting (formed the intermediates TP1, P1, P2, P3, P4).

Pathway 2: BPAF was oxidized and coupled into TP2, which can be further decomposed into phenol (P7), P8 and P9 by hydrogenation and the break and oxidation of ${ \mathsf { C } } { - } { \mathsf { C } }$ between the hexafluoroisopropyl and benzene rings. Finally, the intermediates P8 and P9 transformed into 4-hydroxybenzoic acid and 4-hydroxyisophthalic acid.

Pathway 3: the sulfate/hydroxyl radicals generated from the PMS activation initially attacked the phenol moiety (electron-rich moiety) of BPAF and acquired one electron. The BPAF was transformed into phenoxy radicals (TP3) and other resonance forms (TP4) due to the delocalization of the unpaired electrons. The radicals with high electron density at the para position would undergo the b-scission process (Yang et al., 2019b), with the formation of radicals (TP5) and cations (TP6). Subsequently, these compounds would transform into the products P12 and hydroquinone (P13) via hydroxylation. In addition, the chemical structure of hydroquinone and di-hydroxy (ortho-position) products is not stable and would be oxidized into ring-cleavage and hydrogen-atom-transfer products (Xie et al., 2003; Han et al., 2015). The compound P12 could further convert into 3-(hydroxymethyl)-phenol (P14).

# 4. Conclusions

In this study, the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ catalyst was applied for PMS activation to achieve efficient BPAF degradation. The experimental results demonstrated that the BPAF degradation increased rapidly with the increase of the catalyst dosage, and the PMS concentration. The highest BPAF removal efficiency of $9 0 . 0 \%$ was achieved in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system in $9 0 \ \mathrm { m i n }$ , with a kinetic constant of 0.024 $\mathrm { m i n } ^ { - 1 }$ . The BPAF degradation efficiency slightly decreased in the presence of ${ \mathrm { H C O } } _ { 3 } ^ { - }$ and ${ \mathsf { N O } } _ { 3 } ^ { - }$ , while the efficiency was enhanced by $\mathtt { C l } ^ { - }$ in aqueous solution. The water matrix of JW accelerated the degradation rate up to $4 5 \ \mathrm { \ m i n }$ , and hindered the degradation process after $4 5 \ \mathrm { m i n }$ . Moreover, the $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ possessed excellent stability even after reuse. TOC analysis showed that the BPAF could be efficiently mineralized to ${ \mathrm { C O } } _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ in the $\mathrm { M n _ { 3 } O _ { 4 } / P M S }$ system. Exploration of the mechanism found that sulfate and hydroxide radicals were produced by PMS activation via the redox pairs of Mn (III)/Mn (II) in $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ . In addition, three degradation pathways of BPAF in the $\mathrm { M n } _ { 3 } 0 _ { 4 } / \mathrm { P M S }$ system were determined.
