Magnetic particles (MPs) coated with humic acid (HA) prepared under anoxic atmosphere were tested as heterogeneous photo-Fenton catalyst for the activation of hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ and persulfate $( \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } )$ using Bisphenol A (BPA) as a model pollutant. The role of HA coating, $\mathsf { p H }$ value and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ concentration were investigated. A positive contribution of HA coating on $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and ${ \mathsf { S } } _ { 2 } { \mathsf { O } } _ { 8 } { } ^ { 2 - }$ activation was found. The highest BPA degradation rates were achieved at acidic conditions $\mathrm { ( p H ~ 3 ) }$ with both $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and ${ S _ { 2 } } { O _ { 8 } } ^ { 2 - }$ , however persulfate showed a significant efficiency even at $\tt p H 6$ , interesting feature in the light of decreasing the wastewater treatment costs. By the addition of selective quenching agents, % OH and $\ S O _ { 4 } \cdot -$ were identified as the main reactive species involved in the BPA abatement. An important contribution of the ${ \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } } ^ { 2 - }$ photolysis on the overall BPA transformation was highlighted. The reuse of the catalyst was investigated and similar efficiency using $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and ${ \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } } ^ { 2 - }$ activation was observed until the third catalytic cycle. Experiments carried out using real wastewater samples, showed a good, even if less efficient compared to pure water, BPA removal.

# 1. Introduction

Among the advanced oxidation processes (AOPs), Fenton, photoFenton and Fenton-like processes have been attracting wide attention to degrade organic pollutants in water [1–3] due to their ability to generate highly reactive species able to abate biorecalcitrant species [4–6]. In the “classic” thermal Fenton process, the highly reactive species, mainly hydroxyl radical (% OH), but also superoxidized iron species [7] are generated by the reaction between Fe(II) ions and hydrogen peroxide. $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ forms an hydrated Fe(II)- $\mathrm { \cdot H } _ { 2 } \mathrm { O } _ { 2 }$ complex through the ligand exchange of a water molecule located in the first ligand sphere, then an inner-sphere two-electron-transfer gives an intermediate Fe(IV) complex which reacts with a molecule of water giving $\mathrm { F e } ^ { 3 + }$ and % OH [8].The reaction rate strongly depends on the $\mathtt { p H }$ with a maximum at $\mathrm { p H } 3$ , subsequently the treated solution has to be neutralized before its releasing, with sludge formation and increase of the overall cost of the process [9]. During the process the formation of hypervalent iron species ${ ( \mathrm { F e } ^ { 4 + } }$ , as well as $\mathsf { F e } ^ { 5 + }$ and $\mathsf { F e } ^ { 6 + }$ ) has been proven by stopped-flow experiments and UV/Vis spectroscopy [10]. The $\mathrm { F e } ^ { 3 + }$ can be reduced to $\mathrm { F e } ^ { 2 + }$ closing the cycle and making the process catalytic by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (with slow kinetics) or through an external energy input (e.g. photo-reduction of $\mathrm { F e } ^ { 3 + }$ complexes in the so-called photo-Fenton process). A way to avoid the formation of useless and costly to be dismissed iron sludge at the end of the process is using iron-based catalyst easily to be recovered. In heterogeneous Fenton and photo-Fenton reactions the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ is activated by iron supported in a solid matrix at acidic or even circumneutral $\mathsf { p H }$ . The catalyst recovery and the low amount of iron released in solution avoid the sludge formation and simplifies the process [11,12].

Similarly to the % OH, the sulfate radical $\mathrm { ( } S 0 _ { 4 } \mathrm { ) ^ { - } } \mathrm { ^ { - } } )$ has a high oxidation potential $( \mathrm { E } _ { 0 } ( \mathrm { S O } _ { 4 } ^ { \cdot - } / \mathrm { S O } _ { 4 } ^ { 2 - } ) = 2 . 4 3 \mathrm { V }$ vs NHE [13], being investigated for oxidation of recalcitrant pollutants [14–16]. The activation of persulfate and peroxymonosulfate $( \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } ^ { 2 - } / \mathrm { S } \mathrm { O } _ { 5 } ^ { 2 - } )$ to generate $\mathrm { { \le { O } _ { 4 } } ^ { \cdot - } }$ can be promoted by reactions of these precursors with iron both in the dark and under irradiation [17,18], in the presence and absence of ligands [19,20]. Additionally, the persulfate is described as less subject than % OH to constituents of the real water samples, presenting an higher selectivity toward some pollutants [17,21]. Considering the usual low cost and quite high reactivity of the most common proposed iron-based catalysts, the activation of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ by these catalysts is raising growing interest in water treatment for emerging contaminant abatement [15,17]. The mechanism behind these heterogeneous processes has not been fully assessed yet, and it is worth to be studied in deeper details.

$\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ magnetic particles (MPs) have been investigated as ironsource due to their Fenton catalytic activity, negligible toxicity, lowcost, facile recovery and recycling by means of a magnetic field [22]. Magnetite structure features a mixture of $\mathrm { F e ( I I ) / F e ( I I I ) }$ oxide and it is well established the importance of $\mathrm { F e ( I I ) }$ ions for an active heterogeneous Fenton-like system [5,6,23]. Bare $\mathrm { F e } _ { 3 } { \cal O } _ { 4 } \mathrm { M P s }$ are susceptible to air oxidation and aggregation in aqueous systems. The stabilization with organic coating can reduce the oxidation of the magnetic phase (magnetite/maghemite) to hematite. Additionally, the introduction of humic(-like) substances, in both Fenton and photo-Fenton conditions appears to significantly enhance the pollutant degradation capacity [24,25], even though the effective role played by humic(-like) substances in the oxidation mechanism has not been already fully solved [26]. As an example, Aparicio and co-workers observed recently that core-shell magnetite-humic acids nanoparticles operate on the one hand as heterogeneous photosensitizers and on the other hand as catalysts in the photo-Fenton treatment for the oxidation of psychiatric drug carbamazepine. The MPs were excellent iron source promoting hydroxyl radical generation in the photo-Fenton process [27].

In this study, humic acid (HA) coated $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ magnetic particles $\mathrm { ( F e _ { 3 } O _ { 4 } / H A ) }$ prepared by co-precipitation method under controlled conditions, were tested for $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ activation under UVA/ UVB irradiation in aqueous media using bisphenol A (BPA) as a model pollutant. Both processes, with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 \cdot }$ , are compared and the reactive species involved in the degradation were investigated through kinetic competition experiments using selective quenchers. The role of HA coating on the reactive species activation is also explored comparing the BPA abatement obtained with the hybrid catalyst with that observed with pristine MPs.

# 2.2. Preparation of MPs/HA

Humic coated magnetite particles were prepared by co-precipitation method under nitrogen atmosphere to avoid the $\mathrm { F e } ^ { 2 + }$ oxidation, as previously reported [28]. Briefly, $3 5 \mathrm { m L }$ of a solution of $\mathrm { F e C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ $0 . 6 8 \mathrm { M }$ and $\mathrm { F e S O } _ { 4 } { \cdot } 7 \mathrm { H } _ { 2 } \mathrm { O } \ 0 . 4 3 \mathrm { M }$ (molar ratio $\mathrm { F e ( I I I ) } / \mathrm { F e ( I I ) } = 1 . 5 )$ were added to $6 5 \mathrm { m L }$ of deoxygenated water at $9 0 ^ { \circ } \mathrm { C } ,$ , under vigorous mechanic stirring and $\Nu _ { 2 }$ continuous flow. Then $1 0 \mathrm { m L }$ of ammonium hydroxide $( 2 5 \% )$ and $5 0 \mathrm { m L }$ of $0 . 5 \mathrm { w t . } \%$ HA solution was added rapidly and sequentially. The mixture was dried for $3 0 \mathrm { m i n }$ at $9 0 ^ { \circ } \mathbf { C } ,$ , and then kept to cool to r.t. under continuous nitrogen flow. The obtained MPs $( \mathrm { F e _ { 3 } O _ { 4 } } / 0 . 5 \mathrm { H A } )$ were centrifuged and washed with $4 0 \mathrm { m L }$ water five times. The MPs were then dried in a Tube Furnace under nitrogen flow at $8 0 ^ { \circ } \mathrm { C }$ for $^ { 1 5 \mathrm { h } }$ and manually crumbled. The bare $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ MPs were prepared with the same procedure without the addition of HA solution. The selected loading of HA demonstrated the best reactivity both in the dark and under irradiation. For the in-depth characterization of these

MPs refer to [28].

# 2.3. Methods

# 2.3.1. Degradation experiments under UVA/UVB irradiation

Irradiations were performed in a cylindrical Pyrex reactor, placed in a rectangular box equipped on the top with four lamps (Sankio denki G15T8E) emitting mainly in the UVA and UVB region. The emission spectrum was recorded using an optical fiber coupled with a CCD spectrophotometer (Ocean Optics USD 2000) calibrated with a Deuterium Tungsten Halogen reference lamp. A total irradiance between 265 and $4 0 0 \mathrm { n m }$ of $2 1 5 0 ~ { \mu \mathrm { W } } ~ \mathrm { c m } ^ { - 2 }$ was measured (see Fig. S1).

The experiments were performed at room temperature using a circulation cooling system. $5 0 \mathrm { m L }$ of $1 0 0 \mathrm { m g / L }$ MPs suspension and $2 0 \mu \mathrm { M }$ BPA at adjusted $\mathsf { p H }$ with $\mathrm { H } _ { 2 } S 0 _ { 4 }$ were sonicated for $2 0 \mathrm { { m i n } }$ , then the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ or $\mathrm { N a } _ { 2 } S _ { 2 } O _ { 8 }$ solutions were added. The suspension was magnetically stirred and placed under irradiation. At defined time interval $3 \mathrm { m L }$ were sampled and the reaction immediately quenched with $2 0 0 \mu \mathrm { L }$ of methanol. The samples were filtered using a $0 . 4 5 \mu \mathrm { m }$ filter before the analysis.

The catalyst reusability experiments were performed by recovering the catalyst after $^ { 3 \mathrm { h } }$ under irradiation using a magnet. The recovered catalyst was 3 times washed and then dried at room temperature before being used in the next run.

The experiments with STPW were performed on BPA-spiked solutions. STPW samples had $1 4 . 2 5 \mathrm { ~ m g _ { C } \ L ^ { - 1 } }$ of total organic carbon (TOC), $3 4 . 1 6 \mathrm { m g _ { C } } \mathrm { L } ^ { - 1 }$ of inorganic carbon (IC), $7 . 7 4 \mathrm { m g _ { N } } \mathrm { L } ^ { - 1 }$ of total nitrogen (TN) and pH value of 7.3.

# 2.3.2. Analysis

The concentration of BPA was measured through an ultra-performance liquid chromatography (UPLC) AQUITY (Waters, USA) equipped with photodiode array detector and by using a C18 AQUITY UPHLC BEH column $( 2 . 1 \times 1 0 0 \mathrm { m m }$ , $1 . 7 \ \mu \mathrm { m } )$ . The flow rate was $0 . 3 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ and the mobile phase was a mixture water methanol $( 6 0 / 4 0 , \mathrm { v / v } )$ . The BPA concentration was quantified at $2 2 0 \mathrm { n m }$ .

TOC, IC and TN were measured using a Shimadzu TOC-5000 analyzer (catalytic oxidation on $\mathrm { P t }$ at $6 8 0 ^ { \circ } \mathrm { C } )$ ).

The determination of Fe released in solution was evaluated by a spectrophotometric procedure as reported in the Supplementary material (hereafter SM).

# 3. Results and discussion

# 3.1. $H _ { 2 } O _ { 2 }$ and $S _ { 2 } O _ { 8 } { } ^ { 2 - }$ activation

In order to evaluate the role of HA coating on the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ activation during the degradation of BPA, experiments were run by comparing the BPA degradation in the presence of both the hybrid $\bf { M P s }$ and the bare magnetite at different $\mathtt { p H }$ values. In all cases the BPA disappearance followed a pseudo-first order kinetics with an exponential decay $( C / C _ { O } ~ = ~ \exp ( - k \times t ) .$ , where $C$ and $C _ { O }$ are the BPA concentration at the irradiation time t and before irradiation, $k$ is the pseudo-first order kinetic constant). Fig. 1a shows the BPA disappearance in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ . It was observed an enhancement of the activity promoted by the HA coating for all pH. In detail, at $\mathrm { p H } 3$ the complete abatement of BPA was observed after $^ { 2 \mathrm { h } }$ in the presence of ${ \tt M P s } / { \tt H A }$ $( k = 0 . 0 3 4 ~ \pm ~ 0 . 0 0 3 \mathrm { { m i n } ^ { - 1 } ) }$ , while with the bare $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ only $8 0 ~ \%$ abatement was achieved $( k = 0 . 0 1 5 ~ \pm ~ 0 . 0 0 1 \mathrm { { m i n } ^ { - 1 } ) }$ ), in agreement with results previously described [28]. In the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ the BPA abatement was considerably slower for $\mathsf { p H }$ higher than 4, while the effect on the persulfate system was less significant. In fact, even at $\mathtt { p H } 6$ after $^ { 2 \mathrm { h } }$ under irradiation, $8 0 ~ \%$ of BPA degradation was achieved using $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ (despite $\sim 1 5 ~ \%$ with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ . # 3.2. Contribution of homogeneous catalysis

It has been reported that the contribution of homogenous (photo)- Fenton promoted by Fe(II) and $\mathrm { F e ( I I I ) }$ ions released in solution by magnetite-based materials can have a not negligible effect in the abatement of organic substrates [30]. In this work the influence of irradiation on the iron release (concentration and redox speciation) was evaluated by determining the concentration of iron in solution, keeping the solution in the dark or under irradiation at $\mathrm { p H } 3$ , 4 and 6. Fig. 2 shows the Fe(II) and Fe(III) concentration spectrophotometrically determined. At time zero (after the sonication period) it was observed a higher amount of $\mathrm { F e ( I I ) }$ with respect to Fe(III) in agreement with the absence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ - able to oxidize $\mathrm { F e ( I I ) }$ to $\mathrm { F e ( I I I ) }$ - and the higher solubility of Fe(II) with respect to $\mathrm { F e ( I I I ) }$ $( \mathrm { p K } s _ { \mathrm { F e ( O H ) 3 } } = 3 8 . 8 ,$ , $\mathrm { p K s } _ { \mathrm { F e ( O H ) 2 } } = 1 5 . 1$ [31]). In the dark it was not observed any increase of the released Fe(II) over time, while under irradiation the release of Fe (II) and Fe(III) (less marked, and only at $\mathrm { p H } 3$ ) was more obvious. The photo-dissolution of the magnetite-based materials under irradiation has been largely reported as a consequence of the formation of surface complexes which may trap ${ \tt e } _ { \mathrm { C B } } { } ^ { - }$ and (or) ${ \mathrm { h } _ { \nabla B } } ^ { + }$ efficiently, thus enhancing the photodissolution. Spinel type oxides (as the catalyst here tested), such as $\gamma { \mathrm { - F e } } _ { 2 } { \mathrm { O } } _ { 3 }$ (maghemite) or $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } ,$ (magnetite) are known to be more easily photocorroded than hematite [32]. The solubility decrease of iron (hydr)oxides can explain the lower $\mathrm { F e ( I I ) }$ and $\mathrm { F e ( I I I ) }$ ions concentration observed for the systems at higher pH in the absence of effective ligands for both Fe(II) and Fe(III).

The mechanism of the photodissolution of the catalyst is ultimately quite complex and the data here reported can only partially clarify it. The organic coating has an active role in the process especially because the carboxylic moieties at the surface are effective ligands for $\mathrm { F e } ^ { + 2 }$ and $\mathrm { F e } ^ { + 3 }$ . Moreover, these iron complexes at the surface are not only redox active species able to react with hydrogen peroxide or persulfate, but they are also photoactive species. Note that, the spectrophotometric method used to determine the iron concentration in solution was carried out on filtered solutions and consequently is silent on the concentration and speciation of the iron complexed by organic ligands at the surface of the catalyst.

The contribution of the iron released in solution on the initial BPA degradation was evaluated as follows: BPA and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ were added to the supernatant solution after removing the heterogeneous catalyst by filtration. To evaluate the effect of the iron photo-dissolution, degradation experiments were performed with supernatant at time zero, but also with the solution after $2 \mathrm { h }$ under irradiation. Fig. 3 shows the BPA degradation on supernatant at $\mathtt { p H 3 }$ after adding $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (Fig. 3a) and on supernatant at $\mathtt { p H } 6$ after $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ addition (Fig. 3b). For both systems it was observed the BPA degradation in the homogenous phase. The addition of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ to the $\mathrm { p H } 3$ supernatant obtained after $^ { 2 \mathrm { h } }$ under irradiation allows to achieve a higher BPA degradation comparing with the corresponding supernatant at $\mathbf { t } _ { 0 }$ . The higher concentration of iron resulted from the photo-dissolution of the catalyst. This tendency was not observed with persulfate. In fact, the supernatant at $\mathbf { t } _ { 0 }$ allowed to obtain higher BPA degradation than the supernatant after $^ { 2 \mathrm { h } }$ under irradiation. The low and stable over the time concentration of iron observed at $\mathtt { p H } 6$ (Fig. 2), suggested an equal production of reactive species during the experiments with the two supernatants. The decreased rate of transformation observed with the supernatants obtained after $^ { 2 \mathrm { h } }$ of irradiation, can be explained considering the quenching effect of the HA that were partially released in solution from the organic coating, as previously reported with similar materials [33,34]. This was sustained by the negative effect observed on the BPA degradation when the direct photolysis of persulfate was carried out in solution containing HA $\scriptstyle ( 0 . 4 \mathrm { m g / L }$ - the same HA amount added with $1 0 0 \mathrm { m g / L }$ of catalyst – considering the HA loading equal $0 . 4 ~ \%$ w/w) which acted as efficient scavengers of reactive species (see Fig. 3).

# 3.4. Effect of $H _ { 2 } O _ { 2 }$ and $S _ { 2 } O _ { 8 } { } ^ { 2 - }$ concentration

To elucidate the effect of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration on the catalytic system, experiments were performed by adding different $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration (0.5, 1, 2, 3, 5 and $1 0 \mathrm { m M } )$ at $\mathrm { p H } ~ 3$ (Fig. 5a) and $\tt p H 4$ (Fig. 5b) in the presence of $1 0 0 \mathrm { m g / L }$ of catalyst. The inset of Fig. 4a shows a quite complex behavior for the BPA initial transformation rate at $\mathrm { p H } 3$ , with an increment of the BPA degradation rate up to $1 \mathrm { m M }$ , then a sharp decrease and for $\mathrm { [ H _ { 2 } O _ { 2 } ] } > 3 \mathrm { m M }$ a further increase. While at $\tt p H 4$ the highest degradation was achieved at $2 \mathrm { m M }$ , but similar rates were observed for higher concentrations (see inset of Fig. 5a). This tendency can be only partially explained by the scavenging effect of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (Eq. 9) as often reported in the literature [38,39], because the decrease of the initial rate as a consequence of the increment of the oxidant concentration can justify a bell-profile and not a profile with a maximum and a minimum as that observed at $\mathrm { p H } ~ 3 .$ . At high concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ a further process different to the photo-Fenton one (e.g. the direct photolysis of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ which is a first order process with respect to hydrogen peroxide, and consequently increased linearly with the increase of the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ concentration) might sustain the overall transformation compensating the scavenge of the % OH, formed through the reactions 4 and 7, by $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ .

The BPA degradation was performed as well at different persulfate concentration (0.5, 1, 2, 3, 5 and $1 0 \mathrm { m M }$ ). Contrary of data obtained on $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ experiments, it was observed a monotonic increase of the rate rising the $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ concentration (Fig. 5a). To split the contribution of the catalyst from that of the persulfate photolysis, the same experiments were carried out in the absence of the catalyst. The comparison among the rate is reported in Fig. 5b. We observed a different behavior at $[ \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } ^ { 2 - } ]$ higher and lower than $2 \mathrm { m M }$ . At $[ \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } ] < 2 \mathsf { m } \mathsf { M }$ we recorded a positive effect of the presence of the iron-based catalyst, while at $[ \mathsf { S } _ { 2 } \mathsf { O } _ { 8 } { } ^ { 2 - } ] > 2 \mathsf { m M }$ the presence of $\mathrm { F e } _ { 3 } 0 _ { 4 } / 0 . 5 \mathrm { H A }$ had a negative effect, being the degradation rate higher without catalyst. This trend could be attributed to a scavenger effect from the HA acid coating, competing with the generated reactive species (see Section 3.2) and to the screening effect of the catalyst for the photons activating the photolysis of $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ (the humic acid that can compete for the absorption of photons with the active iron-based species at the surface or in solution). In any case the behavior of the BPA transformation rate using different concentration of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } ^ { 2 - }$ reported in Figs. 4 and 5 cannot be explained considering only the scavenging effect of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } ^ { 2 - }$ .

# 3.5. Catalyst recover and reuse

The catalyst reusability was tested by magnetically recovering the catalyst at the end of the BPA degradation. The catalyst was washed with water and dried before use for the next run. Fig. S4 shows the BPA abatement in 3 consecutive runs in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ at $\mathrm { p H } 3$ and $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ at pH 6. At pH 6 in the presence of ${ \mathsf { S } } _ { 2 } { \mathsf { O } } _ { 8 } { } ^ { 2 - }$ no decrease of activity was observed, while at $\mathrm { p H } 3$ in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ a very slight decrease on BPA abatement was observed. In both cases the tested catalyst did not show a significant deactivation/poisoning with the use.

# 4. Conclusions

Coating $\mathrm { F } _ { 3 } \mathrm { O } _ { 4 }$ with HA efficiently induced higher $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and persulfate activation for the BPA removal at different $\mathrm { p H } .$ , comparing with the pristine magnetite. The $\mathrm { F e } _ { 3 } 0 _ { 4 } / 0 . 5 \mathrm { H A }$ showed high capability to activate $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ at $\mathrm { p H } 3$ with a substantial decrease of activity at $\mathtt { p H }$ higher than 4, while in the presence of persulfate even at $\mathtt { p H } 6$ the system was still able to efficiently remove BPA. Both with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $S _ { 2 } { \mathrm O } _ { 8 } { } ^ { 2 - }$ , the heterogeneous photo-Fenton process here investigated was operational in real wastewater, even if with lower kinetics than in ultrapure water.

The main reactive species involved in the process catalyzed by $\mathrm { F e } _ { 3 } 0 _ { 4 } / 0 . 5 \mathrm { H A }$ were % OH (in the presence of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ) and $S O _ { 4 } \mathrm { ^ { - } - }$ (in the presence of $S _ { 2 } O _ { 8 } { } ^ { 2 - } )$ .

The recovery experiments highlighted no significant loss of activity with the reuse of the material both with $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ at $\mathrm { p H } 3$ and $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ at pH 6.

With $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ (at $\mathrm { \tt p H } 3 .$ ) the photo-Fenton process in the presence of $\mathrm { F e } _ { 3 } 0 _ { 4 } / 0 . 5 \mathrm { H A }$ gave always better results than the “pure” photolysis of hydrogen peroxide, while with $S _ { 2 } { 0 _ { 8 } } ^ { 2 - }$ the presence of the catalyst gave a positive effect in comparison with the persulfate photolysis at $[ { \bf S } _ { 2 } { \bf O } _ { 8 } ^ { ~ 2 - } ] < 2 \mathbf { m } \mathbf { M }$ (note that $[ { \cal S } _ { 2 } { \cal O } _ { 8 } { } ^ { 2 - } ] > 5 \mathrm { m M }$ have to be avoided to prevent the production of final water with a sulfate concentration exceeding the law limits). At the same time, the photo-Fenton process at $\mathrm { p H } 3$ can give after the final neutralization very salted water that must be further treated before the discharge.
