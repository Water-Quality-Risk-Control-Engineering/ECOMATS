# . Introduction

Paracetamol, one of the most effective analgesics, has been widely used for mild to moderate pain relief. Due to its physicochemical properties, paracetamol and other contaminants of emerging concern (CEC) are very hard to degrade below the $\mu \mathrm { g } \mathrm { L } ^ { - 1 }$ concentration range by conventional methods, or by some efficient techniques such as reverse osmosis, turning this pharmaceutical into a persistent pollutant in water [1,2]. Advanced oxidation processes (AOPs), which are traditionally based on hydroxyl radical generation, have been considered to be effective methods for destroying recalcitrant organics in water. However, novel approaches, namely sulfate radical-based advanced oxidation processes (SR-AOPs) are increasingly drawing attention due to the higher oxidation potential (2.53.1 eV), wider operative pH range (39) and higher half-life $( 3 0 { - } 4 0 ~ \mu s )$ of the sulfate radical. The generation of radicals is promoted via the activation of peroxymonosulfate (PMS) by heating, ultra violet light irradiation, transition metal-containing compounds and so on [3,4]. Among all transition metal activators used, Co based catalysts have been proven to be the most efficient [5,6]. In this sense, a huge variety of compounds, crystallizing in different structures, have been tested to include cobalt cations in different coordination [710].

Layered double hydroxides (LDHs), also known as hydrotalcite-like compounds, are a class of ionic lamellar compounds, that comprise positively charged brucite-like layers and charge compensating anion interlayers. The generic formula is $\mathrm { \Delta [ M _ { 1 - x } ^ { 2 + } M _ { x } ^ { 3 + } ( O H ) _ { 2 } ] [ A ^ { n - } ] _ { x / n } { \cdot } z H _ { 2 } O }$ where M2+/3+ present metal cations and ${ \mathsf { A } } ^ { { \mathfrak { n } } - }$ could be the interlayer gallery anion [11,12]. LDH-derived oxides, namely, layered double oxides (LDOs), have a large surface area, high structural stability and excellent metal oxide dispersion [1315]. Moreover, LDOs exhibit the synergistic effects of various metal oxides [16,17]. Recently, LDOs containing transition metal elements such as CoCuAl LDOs [17], CoMgAl LDOs [18], CoMnAl LDOs [19] and MnFe LDOs [20] have been reported as PMS activators in SR-AOPs. However, the efficiency of AOPs is limited by the short-lived radicals (half-life is $3 0 { - } 4 0 ~ { \mu \mathrm { s } }$ for sulfate radicals and less than $1 \mu s$ for hydroxyl radicals) and the reduced number of PMS activation sites occupied by nonreactive cations such as Mg and Al [21]. To make the radicals and organic pollutions more accessible, approaches to construct catalysts with both adsorption and catalytic activity are highly desirable. Graphitic carbon nitride $( g \mathrm { - C _ { 3 } N _ { 4 } ) }$ , extensively used as an environmentally friendly semiconductor, is studied here as the activator support in SR-AOPs [2224]. Transition metal-doped $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ has recently been investigated as an efficient PMS activator [2527]. This behavior can be attributed to the six nitrogen lone pairs in $\mathrm { g - C _ { 3 } N _ { 4 } }$ serving as electron donors, thus providing sites for the transition metal ions [28]. In addition, the abundant pyrrolic N present in $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ affords absorption sites for organic pollution [27,29]. Although various $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ -based composites have been reported to be efficient PMS activators [2127], understanding the role of $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ and the synergistic effect remain unexplained.

Herein, a series of CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ with different compositions were synthesized using LDH and melamine as precursors. The asprepared catalysts were systematically characterized and their degradation performances were evaluated under different experimental conditions. CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ demonstrates superior PMS activation capability and benefits from the reduced oxidation state of Co and Fe due to the covalence effect induced by $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ . A combined radical and electron-donor PMS activation pathway is revealed and a possible mechanism is proposed.

# 2.4. Experimental procedure

Catalytic degradation batch experiments were carried out in $2 5 0 \mathrm { m L }$ beakers, containing $1 0 0 \ \mathrm { m L }$ of $1 0 \mathrm { \ m g / L }$ paracetamol solutions at a constant $2 5 \pm 0 . 5 ^ { \circ } \mathrm { C }$ temperature and $3 0 0 \mathrm { r p m }$ stirring speed. To study the effect of PMS and catalyst amounts on the degradation process, the desired amounts of PMS and catalyst were added into the target pollutant solution. One milliliter of solution sample was regularly withdrawn at given time intervals and filtered through a $0 . 4 5 ~ \mu \mathrm { m }$ cellulose filter. Afterward, the samples were mixed with $0 . 5 ~ \mathrm { m L }$ MeOH to quench the degradation reaction and analyzed by high-performance liquid chromatography (HPLC) to determine the residual paracetamol concentrations. To test the reusability of the catalyst, the solution after the experiment was filtered through a $0 . 4 5 ~ { \mu \mathrm { m } }$ cellulose filter, washed and dried at $8 0 ~ ^ { \circ } \mathrm { C }$ overnight for the next cycle. # 3.2.Catalytic performance of CoFe LDO/g-C3N4

Fig. 3 shows the effect of CoFe LDO content on catalytic performance for PMS activation toward paracetamol degradation. # 3.3.3. Effect of the initial pH

# 3.4. Reusability and stability test

High reusability of heterogeneous catalysts is desired for practical applications. On the other hand, the reusability of CoFe LDO is not as good as CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ as it can be seen from the consecutive removal cycles, with incomplete paracetamol removal being especially noticeable after the 4th run. As shown in Fig. 5c, the CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ shows a much lower metal leaching than CoFe LDO in the whole studied pH range (from pH 3 to 9). Degradation and leaching tests demonstrated the higher reusability and stability of CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ compared with CoFe LDO.

# 3.5. ROS identification and proposed PMS activation mechanism

To identify the major ROS responsible for the degradation of paracetamol, a chemical probe method was used with MeOH, TBA and FFA as scavengers. Methanol, an alpha hydrogen containing alcohols, can react with both $S O _ { 4 } { ^ { \bullet } } ^ { - }$ and ·OH at similar high rates, herein used as scavenger for both radicals [58]. On another hand, TBA, without $\alpha$ -hydrogen in its molecule, will react faster with ·OH $( k ^ { \bullet } \mathrm { o H } = ( 3 . 8 – 7 . 6 )$ $\times \ 1 0 ^ { 8 } \ \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ rather than $S O _ { 4 } { } ^ { \bullet ^ { - } }$ $( k _ { \mathrm { S O 4 } } \bullet ^ { - } = ( 4 . 9 \ – 9 . 1 ) \times 1 0 ^ { 5 } \ \mathbf { M } ^ { - 1 } s ^ { - 1 } )$ [59]. Considering that both alcohols have negligible reactions with PMS [60], MeOH and TBA were employed to quench both $S O _ { 4 } { } ^ { \bullet ^ { - } }$ and ·OH [61,62]. As shown in Fig. 6a, $5 3 . 3 \%$ and $4 8 . 8 \%$ of the paracetamol was removed in $6 0 \ \mathrm { m i n }$ when $1 0 0 ~ \mathrm { m M }$ and $5 0 0 ~ \mathrm { m M }$ MeOH were added, respectively. The negligible inhibition from $1 0 0 ~ \mathrm { { m M } }$ and $5 0 0 ~ \mathrm { m M }$ TBA suggested that •OH is not the dominant ROS based on the TBA greediness in trapping ·OH radicals. Previous studies also suggested that singlet oxygen $( ^ { 1 } 0 _ { 2 } )$ may play an important role in PMS-based catalytic oxidation processes [63,64]. The most commonly compound as a $^ 1 0 _ { 2 }$ scavenger is FFA however, it must be taken into account that PMS can also react directly with FFA [60,65]. The results showed that paracetamol removal was not complete even after $6 0 \ \mathrm { m i n }$ when a moderate concentration $\mathbf { \Gamma } ^ { ( 1 \ m M ) }$ of FFA was added. As shown in Fig. 6b, FFA did not significantly enhance PMS decomposition with or without catalyst. Thus, the inhibition of paracetamol degradation by FFA was most likely due to the direct reaction of FFA with $^ 1 0 _ { 2 }$ rather than the decomposition of PMS. To confirm the preliminary conclusions obtained from the chemical probe method, we performed further ESR measurements. DMPO was used as a spin trapping agent to mainly identify $S O _ { 4 } { ^ { \bullet } } ^ { - }$ and •OH radicals through the formation of DMPO- $S O _ { 4 }$ or DMPO-OH adducts [66], and TEMP was used to follow $^ 1 0 _ { 2 }$ generation. As shown in Fig. 6c, no characteristic signals were observed with solo PMS when DMPO was added as a spin trapping agent. However, the characteristic signal of DMPOX (1:2:1:2:1:2:1) adducts appeared concomitantly in the presence of PMS and the catalyzer CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } .$ , which can be attributed to the direct oxidation of DMOP or the overoxidation of ${ \bf D M P O - S O _ { 4 } }$ or DMPO-OH adducts by the ROS produced after PMS activation via the catalyzer [6770]. It is worth mentioning that the DMPOX signal is dominant even in the 2-minute ESR spectrum, indicating the high PMS activation efficiency shown by the catalyzer. The typical TEMPO signal (triplet signal with intensity of 1:1:1 depicted in Fig. 6c bottom part) can be observed when TEMP was used as spin trapping agent with PMS alone, which was due to the PMS self-decomposition. However, there was no significant intensity increase when catalyst was added, indicating that $^ 1 0 _ { 2 }$ generation could not account for the catalyst mediation.

It is well known that pollutant removal can be accounted for by oxidant radicals but also by a direct electron transfer process from the pollutant to PMS mediated by the catalyzer [65]. Therefore, further electrochemical experiments must be performed to shed light on the electron-transfer process. Chronoamperometric measurements with catalyst-modified glassy carbon electrodes were conducted by following the current responses to sequentially added PMS and paracetamol. As shown in Fig. 7a, adding the first PMS and second paracetamol had a negligible effect on the current when the working electrode was solo $g \cdot$ $\mathrm { C _ { 3 } N _ { 4 } } ,$ indicating that there was no electron transfer when neither PMS nor paracetamol was added. However, when the working electrode consisted of CoFe LDO, the current suddenly dropped when PMS was added, suggesting the existence of an electron transfer process due to PMS reduction with the subsequent oxidation of transition metal active sites and the generation of oxidant radicals. The subsequent addition of paracetamol led to a further and more noticeable current decrease, attributed to the electron transfer from paracetamol to PMS mediated by CoFe LDO. The presence of a current response on the electrode material when paracetamol is added is a clear indication of an electron transfer process that also confirms paracetamol degradation via the electron transfer pathway. Interestingly, a higher current response to PMS and paracetamol additions was observed for the CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ catalyst, which exhibited better PMS reduction as well as electron transfer mediated capabilities. In addition, the decomposition rate of PMS increased in the presence of paracetamol, suggesting that the CoFe LDO/ $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ may enable electron transfer from paracetamol to PMS (Fig. 6b). These results are also in agreement with the higher degradation rate performance of CoFe $\mathrm { L D O } / \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ rather than CoFe LDO. # 4. Conclusion

In summary, we have revealed that the influence of $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ on lowering Co and Fe valence states in CoFe LDO compounds stimulates PMS activation and concomitantly paracetamol degradation. By combining ESR and XPS tests with XAS and electrochemical measurements, the enhanced degradation was attributed to the contribution of two existing mechanisms: radical mediated and electron transfer processes. Detailed degradation conditions $_ { ( 0 . 2 ~ g / \mathrm { L } }$ CoFe $\mathrm { L D O } / \mathrm { g C _ { 3 } N _ { 4 } }$ ,0.5 mM PMS, pH 7) were derived from the variation of catalyst and PMS dosage, and pH and coexistent anions further revealed the crucial roles of $S O _ { 4 } { ^ { \bullet } } ^ { - }$ radicals and electron transfer process, which acted synergistically to promote paracetamol degradation in scarcely $1 0 \ \mathrm { m i n }$ in darkness. Furthermore, cycling experiments and metal leaching tests verify the excellent reusability and stability of the catalyzer. These findings pioneer a new method for the mechanism coupling of radical and electron transfer processes and could have significant implications for the development of materials for wastewater treatments.
