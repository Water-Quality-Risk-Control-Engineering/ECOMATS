# A B S T R A C T

Developing low-cost, sustainable catalysts is critical to meet the green-transition goal in water treatments. Herein, a low-cost, common metal modified ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ material (FeMg-O-g- $\mathrm { . C _ { 3 } N _ { 4 } ) }$ was designed to improve electron mobility and peroxymonosulfate (PMS) utilization. Likewise, surface acidification of $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ has introduced extra porous structure, anchor sites for metals, and activate sites. This new catalyst free of expensive rare-earth metals creates numerous surface micro-electric fields through: 1) large difference in electronegativity for Fe (1.83) and Mg (1.31); 2) cation-π effect formed between metals and benzene-like ring structure of $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 } ;$ and 3) added PMS and pollutant (tetracycline (TC)) as electron provider promoting the transfer of electrons to the electron-rich Fe sites. Both non-radical $( ^ { 1 } 0 _ { 2 } )$ and radical (surface-bound ⋅OH and $S O _ { 4 } ^ { - }$ ) pathways contribute to the pollutant degradation. Given the promising results and stability of the catalyst, this study opens new horizons to apply common metals over expensive, toxic rare metals in PMS-based water treatments.

# 1. Introduction

The advanced oxidation process (AOP) powered by highly reactive oxygen species (ROSs) is considered to effectively eliminate antibiotics in wastewater systems [1]. Hydrogen peroxide $\left( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } \right)$ , peroxydisulfate (PDS), and peroxide monosulfate (PMS) are widely used oxidant precursors. While the molecular structures of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and PDS are symmetric, PMS exhibits a unique asymmetric structure imposing an easier activation pathway [2]. Recently, carbon-based catalysts gained momentum in PMS activation compared with metal-based catalysts, owing to the cheaper price, larger surface area, and fairly better stability; furthermore, non-free radical production such as $^ 1 0 _ { 2 }$ also enriches the yield of ROSs in the system [3–5]. For example, graphite carbon nitride $( g \mathrm { - C _ { 3 } N _ { 4 } ) }$ as a carbon-based catalyst for PMS activation features low cost, adjustable electronic structure, and environmentally friendly characteristics [6,7]. In addition, the N atoms in triazine units are able to donate electrons for the cleavage of peroxy bond [8]. However, given the slow electron migration for pure $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ [9], many modification strategies have been practiced to optimize its activation performance [10]. For example, recent studies have included the covalent modification of $g \cdot$ $\mathrm { C _ { 3 } N _ { 4 } }$ by carbon quantum dots (CQDs) [11], Fe single atoms (Fe-SA) anchored on $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ [12], and nitrogen atom doping modification [13].

Constructing surface polarization is an efficient means to improve electron transfer on the catalyst surface of $\mathrm { g - C _ { 3 } N _ { 4 } }$ for PMS activation [14,15]. This process induced by metal doping (e.g., Fe, Co, Cu, etc.) enlarges the polarity difference of elements on the catalyst, creating a surface micro-electric field involving electron transfers [16]. Specifically, when metals connect with the benzene-like ring structure of $g \cdot$ - $\mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ , a cation- $\cdot \pi$ effect is formed, facilitating the transfer of electron from $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ to metals. Additionally, the cation- $\textstyle \pi$ effect effectively mitigates catalyst deactivation issues stemming from the accumulation of highvalent metals [17]. On the other hand, this dopping approach induces the original $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ material to form defects, disrupting its periodic structure with tweaked electronic structure for enhanced electron

# transfer [18].

Compared to single metal doping, bimetallic doping was anticipated to induce a greater polarity difference due to their varying electronegativity. This leads to the construction of local, numerous surface microelectric fields, further enhancing the electron migration on catalyst g$\mathrm { C _ { 3 } N _ { 4 } }$ . Previous reports also established that strong surface polarization (e.g., positive sites) could boost the adsorption-activation of PMS anions, significantly advancing utilization rates of PMS [19]. While current activation catalysts heavily rely on rare, expensive, and toxic metals (Co, Mn, and Cu), combinations of abundant earth elements such as iron (Fe) and magnesium (Mg) have been rarely explored for $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ modification following sustainable principles. Notably, the substantial electronegativity difference between Fe (1.83) and $\mathbf { M } \mathbf { g }$ (1.31) is advantageous for the formation of surface polarization on $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ .

However, pure $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ has limited anchor sites for metal atoms which inhibits the generation of active metal sites and surface polarity. Acidification with $\mathrm { H N O } _ { 3 }$ or $\mathrm { H _ { 2 } S O _ { 4 } }$ has shown to oxidize $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ surface and increase oxygen-containing functional groups at the material surface, which can complex metal ions to improve the doping process [20]. In addition, the etching effect of acidification also increases the specific surface area by creating a porous structure, which can further increase the exposure of reaction sites [21–23]. The surface acidification strategy is crucial to populate the surface micro-electric fields on catalysts.

In this work, Fe and $\mathbf { M } \mathbf { g }$ co-doped $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ catalysts under $\mathrm { H N O _ { 3 } }$ acidification $\left( \mathrm { F e M g - O - g - C _ { 3 } N _ { 4 } } \right)$ were prepared to activate PMS for degrading a model antibiotics, tetracycline (TC). First, the catalysts’ structure and morphology were analyzed by different characterization methods. Then, effects of water chemistry on the TC degradation by FeMg-O- $\mathbf { \partial } _ { \cdot } \mathbf { g } _ { - } \mathbf { C } _ { 3 } \mathbf { N } _ { 4 }$ activated PMS were investigated. Likewise, specific ROSs produced were screened to identify the radical and non-radical degradation pathway for TC. Following experimental verification, DFT calculations were executed to examine the functions of Fe, $\mathbf { M } \mathbf { g }$ and O in the catalytic process, as well as the adsorption and charge transfer process between FeMg-O- ${ \cdot } g { \cdot } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ and PMS, confirming the constructed surface micro-electric fields. Finally, LC-MS analysis revealed the degradation byproducts and pathways of TC. The surface modification with low-cost common mentals proves to be a promising strategy to induce local polarization difference promoting the PMS activation and the catalysts’ stability.

# 2. Methods

# 2.1. Catalyst preparation

Information of chemicals, reagents, and materials is provided in Text S1. Under the assistance of ultrasound, $_ { 3 g }$ melamine, $\mathrm { F e S O } _ { 4 } ,$ , and $\mathrm { M g } { \bf S } { \bf O } _ { 4 }$ (fixed at 1 w.t. $\%$ for both metal loading) were added into 20 mL $\mathrm { H N O _ { 3 } }$ solution (8 M). The mixture was agitated for $1 2 0 \ \mathrm { m i n }$ at $7 5 ~ ^ { \circ } \mathrm { C }$ in a temperature-controlled magnetic stirrer until the water was removed. After drying, the solid mixture was ground and heated at $5 5 0 ^ { \circ } \mathrm { C }$ for 240 min in a muffle oven. After annealing, the dried sample was rinsed with deionized water and diluted $\mathrm { H N O _ { 3 } }$ solution $\left( 1 \mathrm { m M } \right)$ to remove metal ions or other organic residual impurities remaining on the surface of the material during the calcination process, thereby improving the purity of the catalyst. The rinsed samples were then re-dried at $6 5 ~ ^ { \circ } \mathrm { C }$ for $^ { 5 \mathrm { ~ h ~ } }$ to obtain the final product $\mathrm { F e _ { x } M g _ { y } { - } O { - } g { - } C _ { 3 } N _ { 4 } }$ (x:y represents the molar ratio of $\mathrm { F e S O } _ { 4 }$ and $\mathrm { M g S O _ { 4 } ) }$ . Meanwhile, $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ and single metal doped $g _ { - }$ $\mathrm { C _ { 3 } N _ { 4 } }$ were prepared following the same steps. Details of the used characterization methods for those catalysts are provided in Text S2.

# 2.2. Degradation experiments

In order to confirm the high catalytic degradation efficiency, $1 0 ~ \mathrm { m g }$ of catalyst was weighted and transferred into $1 0 0 ~ \mathrm { { m L } }$ TC solution (40 $\mathrm { m g / L } )$ , followed by shaking in an oscillation box (dark) at constant temperature $( 2 5 ^ { \circ } \mathrm { C } )$ for $6 0 \mathrm { { m i n } }$ until adsorption–desorption equilibrium.

The solution pH was adjusted using concentrated HCl and NaOH before degradation experiments. Following, PMS $\mathbf { ( 1 . 0 ~ \ m M ) }$ was added to initiate the reaction. At different time intervals, $1 . 0 \ \mathrm { m L }$ sample was taken and filtered by 0. $4 5 ~ { \mu \mathrm { m } }$ syringe filter, quenched by methanol immediately, and measured in a high-performance liquid chromatography (Vanquish Duo). The sampling interval of the adsorption stage was $2 0 \mathrm { { m i n } }$ , and the interval sampling time of the degradation stage was $1 0 \ \mathrm { m i n }$ (the first $6 0 \ \mathrm { m i n }$ of degradation) and $3 0 \ \mathrm { m i n }$ (60–120 min of degradation).

The pseudo-first-order rate constant was calculated using $\mathrm { l n C / C _ { 0 } = }$ $- k _ { \mathrm { o b s } } \mathrm { t }$ to fit the TC degradation data [24,25].

To identify the roles of ROSs, methanol (MeOH) was selected to scavenge aqueous $\mathrm { \cdot { O H / S O _ { 4 } ^ { - } } }$ , tert-butanol (TBA) for aqueous ⋅OH, nitrobenzene (NB) for surface-bound ⋅OH, phenol for surface-bound $\mathrm { \partial { \cdot } { O H } / { S O _ { 4 } ^ { - - } } }$ , benzoquinone (BQ) for aqueous $\dot { 0 _ { 2 } } \mathrm { ^ - }$ , and furfuryl alcohol (FFA) for $^ 1 0 _ { 2 }$ [26–30]. In order to fully quench the radicals, we set the molar ratio of scavengers to oxidants at 100 [26,31]. All degradation experiments were repeated three times and error estimates were provided.

# 2.3. Theoretical calculations

In Materials Studio software, CASTEP module was used for DFT calculations. To obtain geometric optimization, all atoms in the $\mathrm { F e } _ { \mathrm { x } } \mathrm { M g } _ { \mathrm { y } } .$ $\mathrm { O - g - C _ { 3 } N _ { 4 } }$ structure are allowed to relax until the maximum displacement, and the convergence threshold of maximum energy is set below 0.001 Å, $0 . 0 3 \mathrm { e V } / \mathring { \mathrm { A } }$ and $1 . 0 \times 1 0 ^ { - 5 }$ eV/atom. The electron exchange and correlation effects are described via generalized gradient approximation (GGA) with Perdew-Burke-Ernzerhof (PBE) function [32].

# 3. Results and discussion

# 3.1. Catalyst characterization

First, SEM and TEM images were captured to unveil the morphology and structure of those $\mathrm { g - C _ { 3 } N _ { 4 } }$ based catalysts. As revealed in Fig. 1a, the $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ samples show a typical layered structure consistent with the literature [33]. According to Fig. 1b, the doping of $\mathbf { M } \mathbf { g }$ and Fe breaks the layered structure of the $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ,$ exhibiting irregular granular morphology. The layered structure (Fig. 1c and d) of $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ shows a stacked bulk porous structure after acid oxidation. As shown in Fig. 1e, EDS measurements demonstrate that five elements (C, N, Fe, Mg, and O) were evenly distributed on the $\mathrm { F e _ { 1 } M g _ { 1 } . O - g { \mathrm { - } } C _ { 3 } N _ { 4 } }$ surface. The mass fractions of Fe, $\mathbf { M } \mathbf { g }$ and O elements in the prepared catalyst were measured to be $1 . 1 2 ~ \%$ , $1 . 1 0 ~ \%$ and $1 0 . 6 ~ \%$ , respectively. From TEM imaging, the original $\mathrm { g - C _ { 3 } N _ { 4 } }$ sample presents a nano-flake structure (Fig. 1f and g). For $\mathrm { F e _ { 1 } M g _ { 1 } . O - g { \mathrm { - } } C _ { 3 } N _ { 4 } }$ (Fig. 1h), abundant porous structures can be observed and intertwined, showing obvious worm-like structures etched on the material surface by acid oxidation. From the high-resolution image (Fig. 1i), the average size of worm holes is about $2 0 \mathrm { n m }$ ; however, no obvious lattice stripes are observed in the image. As shown in BET (Brunauer-Emmett-Teller) analysis (Fig. 2a), the three curves are type IV with an obvious H3 hysteresis loop, i.e., a mesoporous structure for the material [34]. The specific surface area of $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ increases with the doping of Fe and $\mathbf { M } \mathbf { g }$ , and the composite $\mathrm { F e } _ { 1 } \mathrm { M g } _ { 1 }$ -O-g$\mathrm { C _ { 3 } N _ { 4 } }$ after acidification exhibits the largest specific surface area (53.204 $\mathbf { m } ^ { 2 } / \mathbf { g } )$ , which corroborates the worm-like pore structure seen in Fig. 1h. The acidification induced pore structure would increase the exposure of active sites to activate PMS for pollutant degradation.

The X-ray diffraction (XRD) was analyzed to characterize the catalysts’ crystal structures (Fig. 2b). All catalysts showed two typical diffractions at $1 3 . 1 ^ { \circ }$ and $2 7 . 6 ^ { \circ }$ , which correspond to (1 0 0) and (00 2) planes in $\mathrm { g - C _ { 3 } N _ { 4 } }$ structure [35]. The strong peak at $2 7 . 6 ^ { \circ }$ is mainly triggered by the interlayer stacking of the conjugated system [36], whereas the low reflection peak at $1 3 . 1 ^ { \circ }$ indicates an in-plane structure of $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ [37]. As comparison, the characteristic peak near the $2 7 . 6 ^ { \circ }$ of the stacked motifs in the (0 0 2) plane of $\mathrm { F e _ { 1 } M g _ { 1 } . O - g { \mathrm { - } } C _ { 3 } N _ { 4 } }$ is much weaker, indicating decreased crystallinity. In addition, the peak was observed to shift to a higher angle attributed to the copious oxygencontaining groups or the Metal–N bonds on the $\mathrm { F e _ { 1 } M g _ { 1 } . Such interaction could lead to the deformation of the carbon nitride skeleton [40]. No apparent characteristic peak of $\mathrm { F e } / \mathrm { M g }$ oxide was found in $\mathrm { F e } _ { 1 } \mathrm { M g } _ { 1 } { \cdot } \mathrm { O } { \cdot } \mathrm { g } { \cdot } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ,$ indicating that the loading amount of $\mathrm { F e } / \mathrm { M g }$ is relatively low or most $\mathrm { F e } / \mathrm { M g }$ in the composites may exist in the form of Metal–N/O bond [41].

# 3.2.2. Operational optimization

The operational parameters were next optimized in the $\mathrm { F e _ { 1 } M g _ { 1 } . 0 { - g } . }$ - $\mathrm { C _ { 3 } N _ { 4 } }$ system. The increased catalyst dose from 0.05 to $0 . 1 0 \mathrm { ~ } \ g / \mathrm { L }$ improved TC degradation from $8 1 . 4 ~ \%$ to $9 2 . 6 ~ \%$ within $1 2 0 \ \mathrm { m i n }$ (Fig. 5a). Therefore, $0 . 1 0 ~ \ g / \mathrm { L }$ was selected as the best dosage of catalyst. Moreover, by increasing the PMS concentration from

0.1 to $1 . 0 ~ \mathrm { m M }$ , the TC degradation rate increased sharply, and the $k _ { \mathrm { o b s } }$ increase is almost doubled from 0.0191 to $0 . 0 3 3 6 \ \mathrm { m i n } ^ { - 1 }$ (Fig. 5b). # 3.3.3. The proposed mechanism for TC degradation

Combined with the experimental and characterization results, the mechanisms for TC degradation were projected. Initially, the co-doping of Fe and $\mathbf { M } \mathbf { g }$ onto $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ framework influenced PMS activation by altering the polarization difference on the surface; the substantial electronegativity difference between the two metals is advantageous for creating the surface micro-electric fields. Thus, the electron transfer ability between catalyst and PMS is upgraded, as the EIS test and DFT calculation confirmed (Figs. 3, 8 and 9). In summary, that the following micro-electric fields may occur: 1) the difference in electronegativity and polarity between the two metals leads to the accumulation of electrons near Fe; 2) TC is directly oxidized at the electron-deficient site of Mg; 3) electron-rich site of Fe transfers electrons to PMS for producing ${ \mathrm { S O } } _ { 4 } ^ { \cdot - }$ and ⋅OH that degrade TC into $\mathrm { C O } _ { 2 }$ and $_ \mathrm { H _ { 2 } O }$ . In addition, the etching effect caused by acidification increases the surface area by creating a porous structure, which can further enhance the exposure of active sites for both metal anchoring and TC/PMS adsorption.

In the non-radical pathway, the $^ 1 0 _ { 2 }$ can originate from the autooxidation of PMS and the recombination of $\dot { 0 _ { 2 } } ^ { - }$ (Eq. 8–10). The molecular charge distribution and Fukui index of TC can verify the degradation pathway of TC. Generally, three Fukui exponents, $\mathbf { f } ^ { + } ( \mathbf { r } )$ , $\mathbf { f } ^ { - } ( \mathbf { r } )$ and $\mathsf { f } ^ { 0 } ( \mathbf { r } )$ , indicate local nucleophilic, electrophilic and radical attacks, respectively; the high level of Fukui index corresponds to high reactivity [92]. From our previous calculation results of Fukui index, it appears that the keto groups, hydroxyl moieties, amino functionalities, and N within TC are the vulnerable sites attacked first by ROSs. From the optimized molecular configuration of the TC molecule, calculated energies for the Highest Occupied Molecular Orbital (HOMO) and Lowest Unoccupied Molecular Orbital (LUMO) are –0.1765 a.u and –0.0826 a.u, respectively [93]. The computed energy gap, measuring 0.0939 a.u., suggests the presence of intramolecular charge transfer (ICT) phenomenon. Specifically, the HOMO predominantly localizes at O(26), O(32), and C(17), indicative of potential oxidation sites, whereas the LUMO exhibits distribution across O(21), O(24), C(1–4), C(6–7), and C(11) (Fig. 9c), as sites preferentially attacked by reducing radicals. Both the Fukui index and HOMO/LUMO distribution point to some common sites such as O(24), O(26), and O(32) (Fig. 9c).

To verify the calculation results, the TC degradation byproducts were identified by LC-MS/MS (Fig. S7). Depending on both the active sites and bond energy, different degradation pathways of TC are proposed (Fig. 11) [94]. Specifically, when attacked by $S O _ { 4 } ^ { - }$ or ⋅OH, the amino groups from TC were removed to form P2 $( m / z = 4 3 0 . 1 4 9 6 4 )$ ), and then P5 $( m / z = 4 0 2 . 1 5 4 7 3 )$ was formed after losing ketone group. Meanwhile, P1 as a product formed by demethylation was also detected, since the bond dissociation energy (BDE) of C–N in N-methyl $( 2 8 4 \mathrm { k J } \mathrm { m o l } ^ { - 1 } ;$ is relatively low [93]. Nevertheless, P3 $( m / z \ = \ 4 6 1 . 1 5 5 4 6 )$ ) through oxidation of hydroxyl to ketone group, along with hydrolylation, was among the detected byproducts. Due to intramolecular dehydration, the product P1 $( m / z = 4 1 7 . 1 2 9 2 4 )$ is transformed to P4 $( m / z = 3 9 9 . 1 1 8 6 8 )$ and P7 $( m / z = 3 7 2 . 1 7 0 9 3$ ). From P2 $( m / z = 4 3 0 . 1 4 9 6 4 )$ , the product P5 $( m / z = 4 0 2 . 1 5 4 7 3 )$ is produced by removing the ketone group and further oxidized to P8 $( m / z = 3 4 4 . 1 1 2 8 6 )$ . Afterwards, the product P7- P9 are further oxidized to form ring-opening products P10-P15, which is finally decomposed into $\mathrm { C O _ { 2 } }$ and $_ \mathrm { H _ { 2 } O }$ . The reaction routes P2-5–8 and P3-6–9 agree well with the HOMO distribution on O(26), O(32), and C (17) where radical oxidation is the dominant reaction.

# 4. Conclusion

To sum up, the bimetallic co-doped $\mathrm { g - C _ { 3 } N _ { 4 } }$ catalyst $( \mathrm { F e _ { 1 } M g _ { 1 } } { \cdot } \mathrm { O } { - } \mathbf { g } { - }$ $\mathrm { C _ { 3 } N _ { 4 } } )$ under $\mathrm { H N O } _ { 3 }$ acidification was fabricated to effectively activate PMS for TC degradation. The doping of Fe and $\mathbf { M } \mathbf { g }$ common metals with distinct electronegativity in the $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ skeleton enhances the polarization difference on the catalyst surface, and the metals connected to the benzene-like ring structure of $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 4 }$ form a cation- $\cdot \pi$ effect, leading to numerous surface micro-electric fields. The catalyst characterization results and DFT calculations confirmed the surface modification. Acidification introduces abundant oxygen-containing functional groups to favor the anchoring of metals and promote the exposure of reaction sites. As confirmed, the TC degradation was mainly through non-radical pathway driven by $^ 1 0 _ { 2 }$ and radical pathway governed by surface-bound $\mathrm { S O } _ { 4 } ^ { - }$ and ⋅OH. With excellent stability, easy preparation steps, and low cost, the common metals-based $\mathrm { F e _ { 1 } M g _ { 1 } . O - g { \mathrm { - } } C _ { 3 } N _ { 4 } }$ is a favorable material for activating PMS to remove toxic pollutants from water.
