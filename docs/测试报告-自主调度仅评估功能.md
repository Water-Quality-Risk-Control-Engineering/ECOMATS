## 功能特性

### 1. 智能关键词检测

系统现在可以识别以下关键词组合,触发"仅评估"模式:

**中文关键词**:
- `仅评估`、`只评估`
- `不总结`、`不要总结`、`不需要总结`
- `只要评分`、`仅评分`
- `三个ASA`、`3个ASA`、`三个评分`
- `三位专家`、`三位评估专家`
- `ABC评估`、`ABC专家`、`ABC评价`
- `给出ABC`、`只需要ABC`、`仅ABC`
- `分别打分`

**英文关键词**:
- `only evaluation`、`evaluation only`
- `no summary`、`without summary`
- `three experts`、`ABC experts`
- `separately score`

### 2. 智能材料设计判断

系统会自动判断是否需要材料设计步骤:

**不需要设计的情况** (只评估):
- 明确说明"不需要设计"、"不要设计"
- 提到"已有材料"、"现有材料"
- **包含化学式** (如 PbS, Fe2O3, TiO2)
- 明确给出材料名称

**需要设计的情况** (设计+评估):
- 要求"设计材料"
- 描述性需求(如"用于处理XX的材料")
- 没有指定具体材料

### 3. 工作流程差异

#### 仅评估模式 (evaluation_only)
```
用户需求 → ABC三位评估专家打分 → 结束
(不包含最终总结专家)
```

#### 完整评估模式 (evaluation + final_validation)
```
用户需求 → 材料设计 → ABC三位评估专家打分 → 最终总结专家 → 结束
```
