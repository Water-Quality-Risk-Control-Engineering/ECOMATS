While sulfate radical $\left( \mathsf { S } 0 _ { 4 } ^ { \bullet ^ { - } } \right)$ -based processes are useful to degrade acetaminophen (ACE), studies of using peroxymonosulfate (PMS) to degrade ACE are quite limited. In addition, although Co is validated as the most effective metal for activating PMS, very few Co catalysts have been developed and investigated for activating PMS to degrade ACE. Since carbon is a promising substrate to support Co nanoparticles (NPs) to form ${ \mathsf { C o } } /$ carbon composite catalysts, most existing carbon substrates require delicate fabrications. As biochar is an easy-to-obtain but versatile carbon material, pyrolysis of Co/lignin affords an advantageous Co-impregnated biochar (CoIB) as an attractive catalyst for PMS activation. Specifically, as ${ \mathrm { C O } } _ { 2 }$ substitutes $\Nu _ { 2 }$ as a reaction medium for pyrolysis of Co/lignin, the syngas production from pyrolysis can be substantially improved and a magnetic CoIB is afforded. This CoIB consists of evenly-distributed Co nanoparticles (NPs) impregnated in carbon matrices of biochar, and possesses several superior characteristics, such as high porosity, large surface area and magnetism, enabling CoIB a promising catalyst for activating PMS to degrade ACE. CoIB also shows a much higher catalytic activity of PMS activation than CoIBe ${ \bf \cdot N } _ { 2 }$ , and $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ for degrading ACE. CoIB is also recyclable for activating PMS to effectively degrade ACE for multiple cycles. The ACE degradation pathway by this CoIB-activated PMS is proposed according to the degradation products. These findings validate that CoIB is assuredly an advantageous heterogeneous catalyst, which can be easily prepared from pyrolysis of Co/lignin in ${ \mathsf { C O } } _ { 2 }$ with concomitant enhanced syngas production for effectively activating PMS to degrade ACE.

# 1. Introduction

Acetaminophen (ACE) represents one of the most common emerging contaminants detected in water bodies as ACE is an extensively-consumed non-prescription drug to relieve pain (Dao et al., 2018). While removal of ACE from these water bodies, especially municipal wastewater, is critical, conventional water and wastewater treatments are ineffective to degrade ACE (Tan et al., 2014). Therefore, a number of intense approaches have been proposed to degrade ACE in water, such as ozonation (Gomes et al., 2017), UV irradiation (Zhu et al., 2018a), and Fenton's reactions (Su et al., 2012; de Luna et al., 2014; Bellotindos et al., 2015). In addition to these approaches, recently sulfur radical $( \mathrm { S O } _ { 4 } { } ^ { \bullet } )$ -based processes are also increasingly explored for degrading ACE because $( \mathrm { S O } _ { 4 } { \cdot } ^ { - } )$ exhibits several advantages, including high oxidation potentials (i.e., 2.5e3.1 V), high selectivities towards unsaturated and aromatic structures (Neta et al., 1988; Antoniou et al., 2010), and long half-life $\left( \sim 4 0 ~ \mu s \right)$ (Neta et al., 1988; Janzen and KotakeHinton, 1992; Yang et al., 2019).

For generating $\left( \mathsf { S 0 4 } ^ { - 1 } \right)$ , peroxymonosulfate (PMS) is commonly employed as PMS is inexpensive, and environmentally friendly (Hu and Long, 2016). However self-decomposition of PMS is quite slow; therefore PMS must be “activated” to produce $( 5 0 _ { 4 } { } ^ { \bullet ^ { - } } )$ rapidly. Even though many methods have been developed to “activate” PMS, using transition metals as catalysts to activate PMS is a relatively efficient approach (Anipsitakis et al., 2005; Wei et al., 2015; Lin et al., 2015a; Zhu et al., 2018b, 2019). Therefore, a few materials of transition metals have been evaluated for activating PMS to degrade ACE, such as Mn-doped $\mathrm { g - C _ { 3 } N _ { 4 } }$ (Fan et al., 2019), ${ \mathrm { C o F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ (Tan et al., 2017), ${ \tt M n F e } _ { 2 } { \tt O } _ { 4 }$ (Tan et al., 2017), $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ (Tan et al., 2014), etc.

While Mn and Fe are capable of activating PMS, Co has been well-proven as the most transition metal to activate PMS (Yang et al., 2009; Cai et al., 2015). Therefore, it would be more promising to develop Co-based heterogeneous catalysts for PMS activation to degrade ACE. Although Co nanoparticles (NPs) have been developed and evaluated for PMS activation (Chen et al., 2008; Wang et al., 2016), Co NPs are easily aggregated in water, decreasing catalytic activities and also they are still quite hard to collect from water (Chen et al., 2008). To address these issues, lately many efforts are made to/immobilize Co NPs on substrates, such as silica (Shukla et al., 2011), metal oxides (Du et al., 2016; Wang et al., 2017), and carbon (Lin et al., 2015b; Yao et al., 2012a; Shi et al., 2013; Zhou et al., 2015). Carbon is the most favorable among these substrates for supporting Co NPs as carbon is abundant and highly-accessible with intriguing physical/chemical characteristics. More importantly, combining Co NPs with carbon is validated to enhance PMS activation owing to accelerated electron mobility and better dispersion of active species over supports (Yao et al., 2012a, 2012b; Chen et al., 2017a). Thus, many carbon substrates have also used to support Co NPs such as carbon nanotube (Wu et al., 2018), graphene (Lin et al., 2015b; Jha et al., 2014), and carbon fibers (Lin et al., 2017). However, these carbon supports must be delicately prepared with complex procedures, rendering these carbon supports less attractive.

On the contrary, recently biochar is increasingly employed as a carbon substrate because biochar is highly-accessible, versatile and environmentally benign (Ghaffar et al., 2015; Chen et al., 2014). Moreover, biochar can be generated from pyrolysis of a broad spectrum of biomass, and highly valuable gaseous products (i.e., syngas of $\mathrm { H } _ { 2 }$ and CO) can be also obtained (Cho et al., 2017). Therefore, biochar has been employed as a support for immobilizing several metal oxides, including Mn and Fe, as catalysts for activating PMS (Wang and Wang, 2019; Fu et al., 2019; Huang et al., 2018; Jiang et al., 2019; Chen et al., 2018). Accordingly, it would be also advantageous to use biochar, particularly with high porosity and large surface area, to support Co NPs.

Even though pyrolysis of biomass usually occur in $\Nu _ { 2 }$ , lately a number of studies reported that replacement of $\Nu _ { 2 }$ by ${ \mathsf { C O } } _ { 2 }$ as a reaction medium can improve gas production from pyrolysis and, more importantly, the resultant biochar can be more porous with much higher surface areas via increasing conversion of condensable hydrocarbons of biomass (Kim et al., 2016; Kwon et al., 2013, 2015).

In addition, while traditional carbon-support Co catalysts are synthesized through complicated post-modification methods, Coimpregnated biochar (CoIB) actually can be obtained using onestep pyrolysis of a mixture of Co and biomass (Cho et al., 2017). By combining cobalt salts with biomass, Co can also catalytically improve gas production from pyrolysis of biomass. More interestingly, the resultant solid biochar would be also modified with Co species to form Co-impregnated biochar (CoIB). Hence, CoIB is anticipated as an advantageous carbon-supported Co catalyst for activating PMS to degrade ACE. Thus, the aim of this study is to investigate catalytic activities of this CoIB for activating PMS to degrade ACE. In particular, lignin is chosen as a representative biomass for pyrolysis as lignin is a ubiquitous biomass.

# 2. Experimental

# 2.1. Materials

In this study, all reagents were commercially available and employed directly without purification. Acetaminophen $( \mathsf { A C E } \geq 9 9 . 0 \% )$ , lignin (alkali) (sulfur content $= 4 \%$ ), cobalt chloride $( \mathsf { C o C l } _ { 2 } > 9 8 \% )$ , PMS, $C o _ { 3 } 0 _ { 4 }$ nanoparticles $( 5 0 { - } 8 0 \mathrm { n m } , > 9 9 \% )$ & surface area $= 1 0 \mathrm { m } ^ { 2 }$ , tert-butyl alcohol $( \mathrm { T B A } > 9 9 \% )$ and 5,5-dimethyl1-pyrroline N-oxide $\left( \mathrm { D M P O } > 9 8 \% \right)$ were purchased from SigmaAldrich (USA). Ethanol and methanol $( > 9 9 \% )$ were obtained from Echo Chemicals (Taiwan). Deionized (DI) water was prepared to less than 18 MU-cm.

# 2.2. Preparation and characterization of CoIB

Fabrication of CoIB from pyrolysis of Co/lignin in ${ \bf C } { \bf O } _ { 2 }$ can be demonstrated by Fig. 1. Firstly, $_ { 0 . 5 } ^ { } \mathbf { g }$ of $\mathsf { C o C l } _ { 2 }$ was added to $1 0 0 \mathrm { m L }$ of DI water, followed by addition of $_ { 1 2 . 5 \mathrm { g } }$ of lignin. The resultant ${ \mathsf { C o } } /$ lignin mixture was then stirred at $4 0 0 \mathrm { r p m }$ and $1 2 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ and then further dried at conventional oven at $8 0 ^ { \circ } \mathsf C$ for $^ { 1 2 \mathrm { h } }$ in order to eliminate water completely. Subsequently, the mixture was placed on a ceramic crucible for pyrolysis in $\Nu _ { 2 }$ or ${ \bf C O } _ { 2 }$ at a ramping rate of $1 0 ^ { \circ } \mathrm { C } / \operatorname* { m i n }$ to $7 2 0 ^ { \circ } \mathrm { C }$ with a high gas flow rate of $6 0 0 \mathrm { m L } / \mathrm { m i n }$ for maintaining the desired atmosphere environment for pyrolysis (Cho et al., 2017). The solid product of pyrolysis was pulverized to yield CoIB powder. Meanwhile, gaseous products from pyrolysis were analyzed using a gas chromatography equipped with a TCD detector. CoIB generated from pyrolysis of Co/lignin in $\Nu _ { 2 }$ was also fabricated based on the aforementioned protocols with the flowing gas of $\Nu _ { 2 }$ , and the corresponding CoIB was abbreviated as $\mathsf { C o I B { - } N _ { 2 } }$ . The morphology of CoIB was determined by transmission electronic microscopies (TEM) (JEOL, Japan). The XRD pattern of CoIB was measured by an X-ray diffractometer (Bruker, USA). X-ray photoelectron spectroscopy (XPS) was also adopted to analyze surface chemistry of CoIB (PHI 5000, ULVAC-PHI, Japan). Surface areas and porosities of CoIB were characterized by a volumetric gas adsorption analyzer (Quantachrome Auto $\scriptstyle { \mathrm { I Q } } ,$ USA). Magnetic properties of CoIB were analyzed by a Vibrating Sample Magnetometer (Quantum Design, USA).

# 2.3. Degradation of acetaminophen by PMS activated using CoIB

Degradation of ACE using PMS activated by CoIB was evaluated via batch-type ACE degradation experiments. In a typical experiment, $4 0 \mathrm { m g }$ of PMS was first added into $_ { 0 . 2 \mathrm { L } }$ of ACE solution with an initial concentration $C _ { 0 }$ of $5 \mathrm { m g / L }$ . Next, $1 0 \mathrm { m g }$ of CoIB was poured into the ACE solution immediately. After pre-set intervals, sample aliquots were withdrawn and filtrated through syringe filters to remove CoIB from the ACE solution. Filtrates were then analyzed by a UVeVis spectrophotometer at $2 4 3 \mathrm { n m }$ to measure the residual concentration of ACE $( C _ { t } )$ . Experiments of investigating the effects of radical scavengers were conducted by adding $0 . 5 { \sf M }$ of TBA or methanol to ACE solutions. In addition, electron paramagnetic resonance (Bruker EMX-P, Germany) was adopted to identify radical species derived from CoIB-activated PMS using DMPO as a radical-trapping agent. The recyclability of CoIB for activating PMS to degrade ACE was examined by reusing CoIB over multiple cycles of ACE degradation experiments. Degradation products of ACE were determined using a liquid chromatograph mass spectrometer (Thermo TSQ Quantum, USA). Total organic carbon (TOC) variation of ACE degradation was determined by a TOC analyzer (Shimadzu,

Japan). Co ions in aqueous solutions were determined using inductively coupled plasma-optical emission spectrometry (ICPOES) (PerkinElmer Optima, USA).

# 3. Results and discussion

# 3.1. Syngas production from pyrolysis of Co/lignin

Before evaluating pyrolysis of Co/lignin using ${ \mathrm { C O } } _ { 2 }$ as a reaction medium, it was critical to analyze pyrolysis of Co/lignin in $\Nu _ { 2 }$ as a baseline. Hence, gas evolution from pyrolysis of Co/lignin in $\Nu _ { 2 }$ was characterized. Fig. 2(a) reveals that $\mathrm { H } _ { 2 }$ generated from pyrolysis of Co/lignin in $\Nu _ { 2 }$ followed a very typical profile of gas evolution from biomass pyrolysis because the concentration of $\mathrm { H } _ { 2 }$ became higher at increasing temperatures via dehydrogenation. Since the pyrolysis in $\Nu _ { 2 }$ was a process of carbonization, the concentration of resulting CO (Fig. 2(b)) was lower than that of $\mathrm { H } _ { 2 }$ owing to the fact that a huge fraction of carbonaceous content was preserved in biochar. Nevertheless, while $\Nu _ { 2 }$ was substituted by ${ \mathrm { C O } } _ { 2 }$ , the gas evolutions from pyrolysis of Co/lignin were relatively different because the concentration of resulting CO became tremendously higher, especially at temperature higher than $5 5 0 ^ { \circ } C$ . This feature was owing to the reason that when ${ \bf C } { \bf O } _ { 2 }$ was used as a reaction medium, thermal cracking of volatile organic compounds (VOCs) was significantly enhanced (Kim et al., 2016). Besides, condensable hydrocarbons (e.g., VOCs and tar) could be also consumed for producing syngas in the presence of ${ \mathrm { C O } } _ { 2 }$ (Kwon et al., 2015; Cho et al., 2015). As the resulting CO increased considerably from pyrolysis of Co/lignin in ${ \mathrm { C O } } _ { 2 }$ , the corresponding $\mathrm { H } _ { 2 }$ became much less because of dilution effects in the presence of CO.

Moreover, Fig. 2(c) shows ratios of $\mathrm { C O } / \mathrm { H } _ { 2 }$ of pyrolysis of ${ \mathsf { C o } } /$ lignin in $\Nu _ { 2 }$ and ${ \mathrm { C O } } _ { 2 }$ , and the ratio of $\mathsf { C O } / \mathsf { H } _ { 2 }$ from pyrolysis in ${ \mathrm { C O } } _ { 2 }$ was noticeably larger than that from pyrolysis in $\Nu _ { 2 }$ especially at temperature exceeding $5 0 0 ^ { \circ } C$ . As CO is a critical component of syngas (Lee et al., 2017), these results validate that CO production was certainly enhanced from pyrolysis of Co/lignin in ${ \bf C O } _ { 2 }$ in comparison to $\Nu _ { 2 }$ atmosphere. This also suggests that the syngas was improved when $\mathbf { C O } _ { 2 }$ was employed as a reaction medium and $\mathbf { C O } _ { 2 }$ was a more favorable medium for pyrolysis of Co/lignin.

# 3.2. Characterization of CoIB

While usage of ${ \bf C } { \bf O } _ { 2 }$ as a reaction medium could enhance syngas production from pyrolysis of lignin, more importantly the solid product CoIB could be also acquired. The resultant CoIB (Fig. 3(a)) seemed a microscale irregular granule and a higher-solution image (Fig. 3(b)) further shows that many dark-colored particles were distributed over light-colored matrix in CoIB.

![](images/54862bbfdcb4a15edcae3c0dc49730c63700ae707a410390acec2137d554b627.jpg)  
Fig. 3. Characteristics of CoIB: (a), (b) TEM images and (c) size distribution of Co NPs; (d) XRD pattern.

Fig. 3(c) reveals that these dark-colored particles were nanoscale with sizes ranging from 8 to $1 7 \mathrm { n m }$ . Since CoIB was generated from the thermal treatment of Co/lignin, the light-colored matrix might be the resultant carbon from pyrolysis of lignin, while the dark-colored nanoparticles (NPs) were generated from Co salts.

To further realize compositions of CoIB, its XRD was determined and displayed in Fig. 3(d), in which a number of obvious peaks can be found. Particularly, the peaks labelled by blue circles are ascribed to cobalt pentlandite $( \mathsf { C o g S } _ { 8 } )$ (JCPDS $\# 0 2$ -1459), whereas the peaks labelled by red squares are attributed to Co (JCPDS #05-0727). Therefore, these dark-colored NPs were comprised of Co and $\mathsf { C o g S 8 }$ , which might be produced via reduction of $C 0 ^ { 2 + }$ and reactions of Co with sulfur from the alkali lignin, respectively. Besides, the peaks labelled by black triangles were assigned to carbon (JCPDS $\# 4 6 -$ 0945), confirming that the light-colored matrix was comprised of carbon. The existence of carbon in CoIB can be also validated by Raman spectroscopy to identify its conjugated carbon structures. Fig. S1 displays that the Raman spectrum of CoIB contained two obvious peaks at 1355 and 1595 Raman shift $( \mathsf { c m } ^ { - 1 } )$ , attributed to the D band and G band of carbon, respectively, which are typically detected in carbonaceous materials derived from biomass (Alcaraz et al., 2018). The D band was attributed to disordered carbon atoms, corresponding to defects in the crystalline structure of carbon matrices of CoIB. On the other hand, the G band resulted from the graphitic structure of carbon. As the D band exhibited a higher intensity than the G band, suggesting that the carbon matrices of CoIB consisted of a larger fraction of disordered carbon atoms than the graphitic structure (Alcaraz et al., 2018; Pereira et al., 1999).

In addition, the surface chemistry of CoIB was determined using XPS and its full-spectrum survey can be seen in Fig. 4(a), in which noticeable signals of Co and C were observed, validating Co species and carbon matrices discussed in the XRD. Moreover, a signal of S could be also noticed, derived from $\mathsf { C o g S 8 }$ . Fig. 4(b) then reveals the C1s core-level spectrum, which was mainly ascribed to CeC, confirming the existence of carbon in CoIB (Li et al., 2016). Furthermore, Fig. 4(c) displays the Co2p core-level spectrum, which could be deconvoluted to reveal several significant peaks. In particular, the peaks at 780.2 and 795.1 eV were derived from ${ \mathsf { C o } } ^ { 3 + }$ , whereas the peaks at 781.8 and $7 9 6 . 9 \mathrm { e V }$ could be corresponding to from $C 0 ^ { 2 + }$ . These specific Co species were primarily attributed to Co9S8 (Feng et al., 2016); nevertheless metal Co on the surface could be also oxidized, thereby generating these oxidation states of Co (Lin et al., 2016).

As textural properties are critical for catalytic reactions, $\Nu _ { 2 }$ sorption/desorption isotherms of CoIB were then measured (Fig. 5(a)). The corresponding isotherm of CoIB can be considered as an IUPAC type I isotherm, indicating that CoIB was assuredly a highly-porous material. The inset in Fig. 5(a) confirms that CoIB consisted of many small pores $< 1 0 \mathrm { n m }$ ) with a total pore volume of $0 . 0 3 0 \mathrm { c m } ^ { 3 } / \mathrm { g }$ and the surface area was determined to be $4 0 0 \mathrm { { m } } ^ { 2 } / \mathrm { { g } } .$ In this study, CoIB prepared by pyrolysis in $\Nu _ { 2 }$ was also fabricated and thus its corresponding $\Nu _ { 2 }$ sorption isotherm was also measured. Nevertheless, the $\Nu _ { 2 }$ adsorption amount seemed tremendously low and no obvious pores were detected with a very low total pore volume of $0 . 0 0 2 \mathrm { c m } ^ { 3 } / \mathrm { g }$ and a very low surface area of $7 \mathrm { m } ^ { 2 } / \mathrm { g }$ . These comparisons confirm that CoIB (prepared from pyrolysis in ${ \bf C } { \bf O } _ { 2 }$ ) was indeed much more porous than $\mathsf { C o I B { - } N _ { 2 } }$ . This special feature has been also mentioned in several recent studies that porosities of biochar could be noticeably increased as ${ \bf C } { \bf O } _ { 2 }$ was used as a reaction medium for pyrolysis (Kwon et al., 2013; Butterman and Castaldi, 2009). When ${ \bf C O } _ { 2 }$ was employed as a reaction medium, ${ \mathrm { C O } } _ { 2 }$ could react with more condensable hydrocarbon (e.g., tar) originally trapped in pores (Kwon et al., 2013; Butterman and Castaldi, 2009) and transform it to gaseous products to excavate pores (Kwon et al., 2013). This comparison also confirmed that usage of ${ \mathrm { C O } } _ { 2 }$ as a reaction medium for pyrolysis could favorably modify important physical properties, including surface areas and pore volumes.

![](images/d2312b3532556ded0bfaeeb3e58f418db35c7a788e99d807d7fb0e293d4c0e26.jpg)  
Fig. 5. (a) $\Nu _ { 2 }$ sorption/desorption isotherms of CoIB and $\mathsf { C o I B { - } N _ { 2 } } ,$ and (b) saturation magnetization of CoIB prepared from pyrolysis of Co/lignin in ${ \mathrm { C O } } _ { 2 }$ .

On the other hand, since CoIB was comprised of metal Co, CoIB was supposed to be magnetic. Thus, its magnetic properties were then measured as shown in Fig. 5(b). As the magnetic field was varied between 20 and $- 2 0 \mathrm { k O e }$ , the saturation magnetization reached $1 5 \mathrm { \ e m u } / \mathrm { g }$ , validating the magnetism of CoIB. Fig. 5(b) illustrates that CoIB can be evenly dispersed in water and then collected conveniently by a permanent magnet, demonstrating that CoIB can be readily applied in aqueous solutions and easily separated from solutions.

# 3.3. Acetaminophen degradation by PMS activated using CoIB

Before examining ACE degradation by PMS activated using CoIB, it was necessary to clarify whether ACE could be eliminated merely through adsorption to CoIB. Fig. 6(a) shows that the concentration of ACE was unchanged in $3 0 \mathrm { { m i n } }$ , indicating that CoIB was not able to adsorb ACE.

Fig. 4. XPS analyses of CoIB: (a) Full-survey spectrum; (b) C1s and (c) Co2p core-level spectra.

![](images/392328ac10916d345c1d8c5c9c7f586e9dda8627d00658b456188896e4c60db3.jpg)

(a) Comparison of ACE degradation by PMS alone, adsorption to CoIB, CoIBactivated PMS, CoIBe ${ \bf - N } _ { 2 }$ -activated PMS and ${ \cal C } _ { 0 _ { 3 } } 0 _ { 4 }$ -activated PMS; (b) effect of CoIB dosage (catalys $= 5 0 \mathrm { m g / L }$ , $\mathrm { A C E } = 5 \mathrm { m g } / \mathrm { L } ,$ $\mathrm { P M S } = 2 0 0 \mathrm { m g / L } ,$ , and $\mathrm { T } = 3 0 ^ { \circ } \mathrm { C } )$ .

Additionally, PMS alone was also evaluated for ACE degradation without introduction of CoIB; nevertheless ACE was barely degraded in $3 0 \mathrm { { m i n } }$ . This suggests that PMS (if not activated) was incapable of degrading ACE. However, when CoIB and PMS were both present in the ACE solution, the concentration of ACE was quickly decreased and $C _ { t } / C _ { 0 }$ approached below 0.1 in $3 0 \mathrm { { m i n } }$ demonstrating that CoIB coupled with PMS was able to degrade ACE. Fig. S2 also demonstrates that TOC of ACE was substantially reduced during ACE degradation in the presence of CoIB and PMS, validating that the combination of CoIB and PMS certainly oxidized ACE.

Since CoIB and PMS were unable to degrade ACE separately, this fast degradation of ACE by CoIB and PMS indicates that PMS was activated by CoIB.

As CoIB was comprised of cobaltic species such as ${ \mathsf { C o } } ^ { 0 }$ , and $C 0 ^ { 2 + }$ and ${ \mathsf { C o } } ^ { 3 + }$ from $\mathrm { C o } _ { 9 } \mathrm { S } _ { 8 }$ , these Co species can react with PMS for generating $( 5 0 _ { 4 } \cdot ^ { - } )$ as follows (Yao et al., 2012a; Muhammad et al., 2012; Ahmadi and Ghanbari, 2019; Zazouli et al., 2017; Huang et al., 2009):

$$
\begin{array} { r l } & { \mathsf { C o ^ { 0 } @ C o I B } \to \mathsf { C o ^ { 2 + } @ C o I B } + 2 \mathsf { e ^ { - } } } \\ & { } \\ & { \mathsf { H S O _ { 5 } ^ { - } } + \mathsf { e ^ { - } } \to \mathsf { S o _ { 4 } } ^ { \bullet ^ { - } } + \mathsf { O H ^ { - } } } \\ & { \mathsf { C o ^ { 2 + } @ C o I B } + \mathsf { H S O _ { 5 } ^ { - } } \to \mathsf { C o ^ { 3 + } @ C o I B } + \mathsf { S O _ { 4 } ^ { - } } + \mathsf { O H ^ { - } } } \\ & { } \\ & { \mathsf { C o ^ { 3 + } @ C o I B } \to \mathsf { C o ^ { 2 + } @ C o I B } + \mathsf { S O _ { 5 } ^ { \bullet ^ { - } } } + \mathsf { H ^ { + } } } \end{array}
$$

Moreover, the resultant $S O _ { 5 } { ^ \bullet } ^ { - }$ can further transform to $S O _ { 4 } { ^ { \bullet } } ^ { - }$ as follows:

$$
2 S O _ { 5 } { ^ { - } }  2 S O _ { 4 } { ^ { - } } + 0 _ { 2 }
$$

As a result, $S O _ { 4 } { ^ { - } }$ can be continuously produced via these cyclic reactions to degrade ACE.

On the other hand, since carbonaceous materials may also exhibit catalytic activities for activating PMS (Zhu et al., 2018b; Zhou et al., 2015; Zhang et al., 2013; Wang et al., 2014; Peng et al., 2013), the pristine biochar was then prepared by pyrolysis of lignin through the same preparation method without introduction of Co salts, and evaluated for activating PMS. Nevertheless, the concentration of ACE remained almost the same in the presence of biochar (from lignin) and PMS, indicating that this resultant biochar did not exhibit noticeable catalytic activities for PMS. This result inferred that the main contribution to PMS activation was attributed to Co

species of CoIB.

Furthermore, even though CoIB prepared from pyrolysis of ${ \mathsf { C o } } /$ lignin in $\mathbf { C O } _ { 2 }$ was assuredly able to activate PMS, it was insightful to verify whether $\mathsf { C o I B { - } N _ { 2 } }$ , fabricated from pyrolysis in $\Nu _ { 2 }$ , could also activate PMS. Fig. 6(a) shows that the combination of $\mathsf { C o I B { - } N _ { 2 } }$ with PMS certainly degraded ACE, validating that $\mathsf { C o I B { - } N _ { 2 } }$ was also able to activate PMS because pyrolysis in $\Nu _ { 2 }$ of Co/organics could also result in Co/carbon composites which are also capable of activating PMS (Lin et al., 2015a, 2016, 2017; Lin and Chen, 2017a, 2017b, 2017c). However, the degradation extent by $\mathsf { C o I B { - } N _ { 2 } }$ was tremendously lower than that by CoIB (the one prepared in ${ \bf C O } _ { 2 }$ ). This huge difference between $\mathsf { C o I B { - } N _ { 2 } }$ and CoIB could be ascribed to the obviously distinct textural properties between $\mathsf { C o I B { - } N _ { 2 } }$ and CoIB. As mentioned in the earlier section, CoIB showed a significantly higher surface area and pore volumes than CoIBe ${ \bf \cdot N } _ { 2 }$ because of the enhancement in porosity using $\mathbf { C O } _ { 2 }$ as the reaction medium. Because $\mathsf { C o I B { - } N _ { 2 } }$ was almost non-porous with a very low surface area, the reaction between Co species of $\mathsf { C o I B { - } N _ { 2 } }$ and PMS was constrained, leading to the inefficient ACE degradation.

Moreover, despite the fact that CoIB was able to activate PMS, it was critical to compare it with the most typical catalyst for PMS activation, $C o _ { 3 } 0 _ { 4 }$ . Therefore, $C 0 _ { 3 } 0 _ { 4 }$ NPs were then selected and employed here for comparisons. As revealed in Fig. 6(a), while ${ C o } _ { 3 } { 0 } _ { 4 }$ NPs was also capable of activating PMS for degrade ACE, the degradation extent was noticeably less than that by CoIB. This verifies that although $C o _ { 3 } 0 _ { 4 }$ NPs were also comprised of $C 0 ^ { 2 + }$ , the corresponding catalytic activity was lower than that of CoIB. In fact, CoIB was a composite of Co species and carbon; the carbon matrices could be not only the substrate to embed Co NPs but also a promotor for improving catalytic activity of Co NPs via synergies, such as facilitating electron transfer and protecting Co NPs (Yao et al., 2012b; Chen et al., 2017a). These synergistic effects from combining Co and carbon have been also reported for other ${ \mathsf { C o } } /$ carbon composites for improving PMS activation (Lin et al., 2015a, 2016, 2017; Lin and Chen, 2017a, 2017b, 2017c).

# 3.4. Effects of catalyst and PMS dosages on ACE degradation

While the combination of CoIB and PMS was able to degrade ACE, it was important to distinguish their respective contributions. Therefore, effects of CoIB and PMS dosages on ACE degradation were investigated. Fig. 6(b) shows ACE degradation by CoIB at different dosages and CoIB at the three dosages were able to degrade ACE effectively within $3 0 \mathrm { { m i n } }$ . This result also assures that CoIB was highly catalytic active to activate PMS because the very low dosage of CoIB at $2 5 \mathrm { m g / L }$ was still capable of activating PMS, leading to ACE degradation. However, the degradation kinetics appeared quite different when the catalyst dosage was changed. To compare the degradation kinetics, the pseudo first order equation, which is typically adopted for quantify kinetics of pollutant degradation by PMS, was thus used here as follows (Wang et al., 2017):

$$
C _ { t } = C _ { 0 } \exp ( - k _ { a p p } t )
$$

where $k _ { a p p }$ is the apparent pseudo first order rate constant. As CoIB increased from 25 to $5 0 \mathrm { m g } / \mathrm { L } , \ k _ { a p p }$ increased from 0.050 to $0 . 0 8 2 \mathrm { m i n } ^ { - 1 }$ (Table S1, see the supporting information) and further changed to $0 . 2 0 2 \mathrm { m i n } ^ { - 1 }$ at ${ \mathrm { C o I B } } = 2 0 0 { \mathrm { m g / L } } .$ . This confirms that a higher CoIB dosage expedited ACE degradation by facilitating production of sulfate radicals from PMS in the presence of more active sites.

On the other hand, ACE degradation by PMS at different dosages was investigated in Fig. 7(a). As PMS dosage rose up from 200 to $4 0 0 \mathrm { { m g / L } , }$ ACE degradation was obviously expedited as $k _ { a p p }$ changed from 0.082 to $0 . 1 0 6 \operatorname* { m i n } ^ { - 1 }$ . However, when PMS dosage became lower to $1 0 0 \mathrm { m g / L } ,$ not only the degradation kinetics was decelerated to $0 . 0 3 2 \mathrm { m i n } ^ { - 1 }$ but the degradation extent of ACE also became significantly lower. This suggests that the lower dosage of PMS led to ineffective ACE degradation possibly because of insufficient $S O _ { 4 } { ^ { \bullet } } ^ { - }$ . These comparisons also demonstrate that the degradation extent of ACE was more associated with PMS dosages as $S O _ { 4 } { ^ { \bullet } } ^ { - }$ was derived from PMS rather than CoIB. In contrast, CoIB served as a catalyst to influence the kinetics. A number of previous studies have also observed similar respective contributions of catalysts and PMS to degradation of pollutants (Chen et al., 2017a; Pi et al., 2018).

While dosages of catalyst and PMS were varied, pH of the ACE solution was also monitored. # 3.5. Effects of temperature and initial $p H$ on ACE degradation

The effect of temperature on ACE degradation by CoIB-activated PMS was examined. Fig. 7(b) demonstrates ACE degradation by CoIB-activated PMS at 30, 45 and $6 0 ^ { \circ } \mathsf C$ When the solution temperature increased, the ACE degradation was significantly accelerated. For instance, as temperature rose from 30 to $4 5 ^ { \circ } \mathsf C$ $k _ { a p p }$ correspondingly increased from 0.082 to $0 . 3 6 8 \operatorname* { m i n } ^ { - 1 }$ and then further changed to $2 . 2 8 0 \mathrm { m i n } ^ { - 1 }$ at $6 0 ^ { \circ } \mathsf C ,$ , validating that higher temperatures considerably expedited ACE degradation by CoIBactivated PMS.

Since higher $k _ { a p p }$ values were obtained at higher temperatures, $k _ { a p p }$ values were further associated with to temperatures through the Arrhenius equation as follows:

$$
\mathrm { L n } k _ { a p p } = \ln { A } - E _ { a } / R T
$$

where A denotes the temperature-independent factor; R means the universal gas constant; $E _ { a }$ represents the activation energy $( E _ { a } , \mathrm { k J } /$ mol) of ACE degradation; and T denotes the solution temperature in Kelvin (K). According to Eq. (7), a plot of $1 / T$ vs. Ln $k _ { a p p }$ was then shown as the inset in Fig. 7(b) and the data points were well fit by the linear regression with $R ^ { 2 } = 0 . 9 9$ and then corresponding $E _ { a }$ was determined as $9 0 \mathrm { k J } / \mathrm { m o l }$ .

On the other hand, as ACE degradation by CoIB-activated PMS was an aqueous reaction, solution $\mathsf { p H }$ is an essential parameter. Fig. 8(a) shows ACE degradation by CoIB-activated PMS at different $\mathsf { p H }$ values. While pH was further lowered to 3, the degradation of ACE was negatively influenced as $k _ { a p p }$ dropped to $0 . 0 1 \bar { 1 } \operatorname* { m i n } ^ { - 1 }$ and $C _ { t } / C _ { 0 }$ only approached 0.7. This was because PMS tends to be much more stable under strongly acidic conditions (Guo et al., 2013), thereby causing PMS relatively difficult to activate. In addition, the excessive amount of proton at low pH values might also cause scavenging effects on radicals, thereby hindering PMS activation and ACE degradation. While ACE solution was basic at $\mathsf { p H } = 1 1$ , ACE degradation was also noticeably influenced as $k _ { a p p }$ decreased to $0 . \dot { 0 3 } 6 \operatorname* { m i n } ^ { - 1 }$ and $C _ { t } / C _ { 0 }$ reached 0.4 in $3 0 \mathrm { { m i n } }$ . This ineffective ACE degradation at $\mathsf { p H } = 1 1$ was probably due to the fact that PMS tends to decompose without production of $S O _ { 4 } { } ^ { \bullet ^ { - } }$ in highly alkaline conditions (Guo et al., 2013; Rastogi et al., 2009) and thus $S O _ { 4 } { ^ { \bullet } } ^ { - }$ could be not generated efficiently to degrade ACE. Besides, the alkaline condition might also cause CoIB surface to be highly negativelycharged by the deposition of $\mathrm { O H ^ { - } }$ as displayed in Fig. S3. The highly negatively-charged surface of CoIB at $\mathsf { p H } = 1 1$ $( - 9 5 \mathrm { m V } )$ led to a stronger electrostatic repulsion between ACE and CoIB, restricting the approach of peroxymonosulfate anions to CoIB. As a result, the ACE degradation became ineffective at $\mathsf { p H } = 1 1$ .

# 3.6. The recyclability of CoIB to activate PMS for ACE degradation

As CoIB was developed to be a heterogeneous catalyst for activating PMS to degrade ACE, it was important to examine whether CoIB could be reused to activate PMS to degrade ACE. Fig. 8(b) displays that ACE was effectively degraded using PMS activated by used CoIB over four cycles. This demonstrates that CoIB was a recyclable, stable and effective catalyst for activating PMS to ACE. To further investigate whether Co species would be leached out from CoIB in aqueous solutions, the concentration of Co leached out from CoIB in the end of the ACE degradation experiment was analyzed using ICP and found to be merely $0 . 0 1 \mathrm { m g / L }$ This concentration of Co derived from Co species leached out from CoIB was far lower than the dosage of CoIB, indicating that CoIB was relatively stable in aqueous solutions and PMS activation was attributed to heterogeneous catalytic activities of CoIB.

# 3.7. A proposed mechanism of ACE degradation by CoIB-activated PMS

To elucidate the mechanism of ACE degradation by CoIBactivated PMS, EPR analysis was performed as shown in Fig. 9(a). When DMPO was employed as a spin-trapping agent (Verstraeten et al., 2009), there was almost no signal present in the presence of PMS alone. However, when PMS and CoIB were both present, significant signals were observed, ascribed to the hyperfine splitting of oxidation adduct products of DMPO- $S O _ { 4 }$ and DMPO-OH (Indrawirawan et al., 2015; Khan et al., 2018; Peng et al., 2018; Xia et al., 2017). This suggests that ACE degradation was attributed to both $S O _ { 4 } { ^ { \bullet } } ^ { - }$ and OH , generated from PMS activated by CoIB. Moreover, $S O _ { 4 } { ^ { \bullet } } ^ { - }$ in water could evolve to OH via the following reaction (Ahmadi and Ghanbari, 2019; Zazouli et al., 2017; Xu et al., 2015):

Thus, it was important to examine respective contributions of these potential radicals to ACE degradation. To this end, two particular radical scavengers were employed, including TBA and methanol. Fig. 9(b) reveals that ACE degradation by CoIBactivated PMS in the presence of TBA was considerably influenced by TBA with $k _ { 1 }$ of $0 . 0 \dot { 2 } 3 \operatorname* { m i n } ^ { - 1 }$ , signifying that the ACE degradation was involved with OH .

On the other hand, as methanol consists of $\alpha$ -hydrogen, methanol can react with both OH and $S O _ { 4 } { ^ { \bullet } } ^ { - }$ in a similar fashion (Huang et al., 2014). # 3.8. A potential degradation pathway for ACE by CoIB-activated PMS

Even though ACE could be effectively degraded by CoIBactivated PMS, it was essential to investigate the degradation pathway of ACE. Fig. S4 shows spectra of degradation products detected by LC-MS-MS. Based on these degradation products, a possible degradation pathway of ACE by CoIB-activated PMS is depicted in Fig. 10 (Villota et al., 2016; Chen et al., 2017b).

At first, ACE might be oxidized to become an intermediate as P1 (Chen et al., 2017b), which could be also further oxidized to form P2. Subsequently, ACE together with the potential intermediates, P1 and P2, would be degraded to generate P3 (Villota et al., 2016), which was possibly transformed to P4 and P5. Next, P4 could be continuously oxidized to become P7 and P8 molecules (Villota et al., 2016), whereas P3 might be also oxidized to result in P5, which might then evolve to P6 and later to P7. These relatively simple aromatic compounds (i.e., P7 and P8) would be further oxidized to open rings and decomposed to generate low-molecular weight compounds. Degradation of aromatic pollutants typically involves three mechanisms, including radical adduct formation, hydrogen atom abstraction and single electron transfer (Luo et al., 2017, 2018; Ye et al., 2017). In view of the intermediates from ACE degradation detected in this study, the degradation of ACE might also involve these typical mechanisms, especially the single electron transfer, as the phenyl intermediates could be observed during degradation (Luo et al., 2017).

# 4. Conclusions

In this study, $\mathbf { C O } _ { 2 }$ was used as a useful reaction medium for pyrolysis of Co/lignin to improve the syngas production and, simultaneously, also led to the formation of a functionalized biochar, CoIB, which was a composite of Co NPs evenly distributed over carbon matrices. The resulting CoIB possessed several advantageous features, including high porosity, large surface area and magnetism, enabling it a promising catalyst for activating PMS to degrade the emerging contaminant, ACE. CoIB was found to show a much higher catalytic activity of PMS activation than CoIBeN2, and ${ C o } _ { 3 } { 0 } _ { 4 }$ for degrading ACE, validating its promising advantages. CoIB was also recyclable for activating PMS to effectively degrade ACE for multiple cycles. ACE degradation was validated to associate with both sulfate and hydroxyl radicals through examining effects of radical scavengers. The ACE degradation pathway by this CoIBactivated PMS was proposed according to the degradation products. These findings validate that CoIB is assuredly an advantageous heterogeneous catalyst, which can be easily prepared from pyrolysis of Co/lignin in ${ \mathrm { C O } } _ { 2 }$ with concomitant enhanced syngas production for effectively activating PMS to degrade ACE.
