# ABSTRACT

The persistence and wide dispersion of antibiotics have a severe impact on the ecological environment. Developing an effective method with universal applicability to remove pollutants is pretty necessary. Herein, a bimetallic oxides $\left( \mathsf { C o } _ { 3 } \mathsf { V } _ { 2 } \mathsf { O } _ { 8 } \right)$ heterogeneous material was successfully prepared and used to activate the persulfate (PS) for purification of tetracycline (TC) wastewater. By exploring the reaction conditions and influencing factors, the removal rate of $5 0 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ TC reached $8 7 . 1 \%$ by $\mathrm { C o _ { 3 } V _ { 2 } O _ { 8 } / P S }$ system, and the reaction rate constant was up to $0 . 0 2 7 1 \ \mathrm { m i n } ^ { - 1 }$ . As a highly efficient catalyst for the activation of PS, ${ \mathrm { C o } } _ { 3 } { \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 8 } / { \mathrm { P S } }$ system produces radicals of $S O _ { 4 } ^ { \bullet - }$ , OH, $\bullet 0 _ { 2 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ in the reaction process due to the ${ \mathsf { C o } } ( \mathrm { I I } )$ and V(IV) exchange electrons with $S _ { 2 } O _ { 8 } ^ { 2 - }$ and $0 _ { 2 }$ . Simultaneously, the internal electron exchange occurs between $\mathrm { C o ( I I ) } / \mathrm { C o ( I I I ) }$ and $\mathsf { V } ( \mathbb { N } ) / \mathsf { V } ( \mathsf { V } )$ , which stabilizes the content of ${ \mathsf { C o } } ( \mathrm { I I } )$ and V(IV). This work provides a novel activator for PS activation to degrade contaminants and contributes to a better understanding of the PS activation mechanism by transition compound.

# 1. Introduction

Refractory organics usually refer to the substances that are difficult to decompose and mineralize under natural conditions, such as synthetic detergent [1], pesticide [2], heavy metals [3], azo dyes and antibiotics [4]. Antibiotics including tetracycline and penicillin have a severe impact on the ecological environment [5]. In the production and use of antibiotics, they will enter the environmental medium in diverse forms and gradually concentrate through the food chain, which is a vital link that causes environmental pollution [6]. The treatment methods for antibiotics include biodegradation, anaerobic degradation, photocatalytic degradation, electrocatalytic degradation, etc. [7–9]. However, strict environmental requirements [10], high cost of materials [11], low degradation rate [12], and strong selectivity limited [11] the practical application of these methods [13]. Fenton-like advanced oxidation processes (AOPs) based on persulfates are considered as a promising method for the purification of organic wastewater [14,15]. A large number of studies about applying AOP to degrade pollutants have emerged, showing that AOP has excellent prospects in eliminating refractory pollutants [16]. Due to the wide application of antibiotics in the pharmaceutical industry [17], as well as their refractory biodegradability [18] and microbial resistance [19], more and more scholars are focusing on the application of AOP technology in antibiotics degradation [20].

The chemical oxidants applied in the AOP method include Fenton’s reagent $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ and $\mathsf { F e } ^ { 2 + }$ ), permanganate $( \mathrm { M n O } _ { 4 } ^ { - } .$ , persulfate (PS), ozone $\left( 0 _ { 3 } \right)$ and so on [21]. Among them, the radicals generated by the activation of PS, including sulfate radical $( \mathrm { S O } _ { 4 } ^ { \bullet - } )$ , hydroxyl radical $( \bullet 0 \mathsf { H } )$ , oxygen anions $( \bullet 0 _ { 2 } ^ { - } )$ and single oxygen $( ^ { 1 } 0 _ { 2 } )$ which can efficiently oxidize various organic pollutants into small molecules $\mathrm { C O } _ { 2 }$ and $\mathrm { H } _ { 2 } \mathrm { O }$ ), which has aroused widespread interest. Over the past 20 years, researchers have developed many techniques to activate PS, such as heating, transition metal, basic group, and light source [22,23]. Recently, transition metal ions with various valence states have been widely applied to activate PS [24]. The electron exchanges between bimetallic material and PS can generate radicals to degrade pollutants. In this process, with a high redox potential $( \mathrm { E _ { v } } = 2 . 5 \substack { - 3 . 1 \mathrm { ~ V } } )$ ), the $S 0 _ { 4 } ^ { \bullet - }$ produced by activating PS, which have a wide working pH range and a longer half-life. Meanwhile, OH with a redox potential of $1 . 8 \substack { - 2 . 7 \mathrm { ~ V ~ } }$ shows nonselective oxidation for organic substances. The coexistence of the $S O _ { 4 } ^ { \bullet - }$ and OH with high redox potential has attracted more attention [25]. In addition, $0 _ { 2 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ also play an essential role in the decomposition of pollutants [26].

Among transition metals, cobalt has an excellent activation performance for persulfate. For example, Xu et al. [27] prepared a composite catalyst with low cobalt content $( 0 . 4 5 ~ \mathrm { a t . \% } )$ , activating peroxymonosulfate (PMS) to produce radicals and has good degradation performance for various organic pollutants. Further, recent studies have shown that vanadium embodies various valence states, providing more electrons exchange opportunities, meaning a better activation effect on PS [28–30]. For example, Chen et al. [31] studied the process of vanadium oxide $( \mathsf { V } _ { 2 } \mathsf { O } _ { 3 } )$ degrading polycyclic aromatic hydrocarbons (PCB) in aqueous systems. The electron exchange between V(IV) and V(V) can activate PS to produce $S O _ { 4 } ^ { \bullet - }$ and OH, which has a good degradation effect on the PCB. However, homogeneous transition metals materials have the shortcoming of leaching ions during the degradation process [32]. It is essential to modify the homogeneous material into a heterogeneous one to retain the properties of transition metal and keep good stability [33,34]. Zhang et al. [35] synthesized a $\mathrm { C u B i } _ { 2 } 0 _ { 4 }$ bimetallic compound to activate PMS to degrade pharmaceuticals and personal care products (PPCP). The synchronous conversion of valence states between $\mathsf { B i } ( \mathrm { I I I } ) / \mathsf { B i } ( \mathsf { V } )$ and $\mathsf { C u } ( \mathrm { I I } ) / \mathsf { C u } ( \mathrm { I } )$ can promote the generation of electrons, further increasing the degradation rate of PPCP. Therefore, the design of a material containing various transition metals means that the compound has various valence states, which is beneficial to activate PS and improve the ability to degrade pollutants. According to the above analysis, bimetallic compounds containing Co and $\mathsf { V }$ are likely to activate PS efficiently.

Herein, a cobalt vanadate $\left( \mathsf { C o } _ { 3 } \mathsf { V } _ { 2 } \mathsf { O } _ { 8 } \right)$ heterogeneous material was synthesized by a one-step hydrothermal method and used as an activator of PS for efficient purifying tetracycline (TC) wastewater. The influence factors for $\mathrm { C o _ { 3 } V _ { 2 } O _ { 8 } / P S }$ system were investigated. Through the EPR test, the signals of $S 0 _ { 4 } ^ { \bullet - }$ , OH, $\bullet 0 _ { 2 } ^ { - }$ and ${ } ^ { 1 } 0 _ { 2 }$ appeared when $\mathrm { C o } _ { 3 } \mathrm { V } _ { 2 } \mathrm { O } _ { 8 }$ and PS coexist. The quenching experiment confirmed that radicals contributed significantly to the degradation of TC. The XPS analysis results determined that internal electron exchange between the ${ \mathsf { C o } } ( \mathrm { I I } )$ and $\mathsf { V } ( \mathbb { W } )$ exist in $\mathrm { C o } _ { 3 } \mathrm { V } _ { 2 } \mathrm { . }$ - $0 _ { 8 }$ , and surface electrons exchange occurs between the ${ \mathrm { C o } } _ { 3 } { \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 8 }$ and PS, which activates the PS to generate potent oxidizing radicals.

# 2.2. The synthesis of $C o _ { 3 } V _ { 2 } O _ { 8 }$

The hydrothermal method was used to synthesize cobaltvanadium bimetallic composites. This method was based on the research of Tao et al. [36] and modified in this work (Fig. 1a). Firstly, $2 \ \mathrm { m m o l }$ of ${ \bf N a V O } _ { 3 }$ was weighed into $4 0 ~ \mathrm { m L }$ of water, and $1 \ \mathrm { m m o l }$ of $\mathrm { C o } ( \mathrm { C H } _ { 3 } \mathrm { C O O } ) _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } \mathrm { O }$ was weighed into $4 0 ~ \mathrm { m L }$ of anhydrous ethanol. The two solutions were placed under ultrasonic conditions for $1 0 \ \mathrm { m i n }$ to form a transparent solution. Then, the $\mathrm { C o } ( \mathrm { C H } _ { 3 } \mathrm { C O O } ) _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } \mathrm { O }$ solution was slowly added into the ${ \bf N a V O } _ { 3 }$ solution, stirring for $1 0 \ \mathrm { m i n }$ until the two solutions were thoroughly mixed. Next, $2 \ \mathrm { m L }$ of hydrazine hydrate was added to the mixed solution drop by drop and stirred for another $1 0 \ \mathrm { m i n }$ to get an evenly dispersed solution. Finally, the obtained solution was poured into a clean Teflon reactor $\mathrm { 1 0 0 m L ) }$ to start a hydrothermal reaction with the condition of $1 6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 8 \mathrm { ~ h ~ } }$ . After cooling down, the solution was extracted and filtered with water and ethanol several times, and then dried in an oven at $6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ (denoted as $\mathsf { V } : \mathsf { C o } ( 2 : 1 ) )$ . The yield of preparation of the bimetallic oxides (Co3V2O8) was about $_ { 0 . 2 \ \mathrm { g } }$ per preparation. Different samples were obtained by changing the dosage of ${ \bf N a V O } _ { 3 }$ and $\mathrm { C o } ( \mathrm { C H } _ { 3 } \mathrm { C O O } ) _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } \mathrm { O }$ . The performance of the sample was further improved by adjusting the temperature and time of the hydrothermal reaction. The samples in different proportions were named ${ \sf V } { : } { \sf C o } ( { \bf x } { : } { \bf y } )$ , where x:y was the molar of $\mathsf { N a V O } _ { 3 }$ and Co $( \mathrm { C H } _ { 3 } \mathrm { C O O } ) _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } \mathrm { O }$ .

# 3.2. The influence of reaction conditions on degradation of TC

Catalyst plays an essential role in providing reaction sites, the amount of which directly affects the reaction rate [38,39]. The influence of ${ \mathrm { C o } } _ { 3 } { \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 8 }$ dosage on the degradation of TC was explored, as shown in Fig. 3a. # 4. Conclusions

In summary, the exploration of temperature and time of the hydrothermal reaction contributed to the successful preparation of ${ \mathrm { C o } } _ { 3 } { \mathsf { V } } _ { 2 } { \mathsf { O } } _ { 8 }$ , thus helping construct a new type of $\mathrm { C o _ { 3 } V _ { 2 } O _ { 8 } / P S }$ catalytic oxidation tetracycline (TC) system. By adjusting the ${ \mathrm { C o } } _ { 3 } { \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 8 }$ dosage, PS dosage, and the initial $\mathsf { p H }$ , the optimal conditions for ${ \mathrm { C o } } _ { 3 } { \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 8 } / { \mathrm { P S } }$ system were determined, with the degradation rate of $8 7 . 1 \%$ for $5 0 \ \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$ TC. The radicals quenching experiments and EPR test further confirmed that $\bullet 0 _ { 2 } ^ { - }$ contributed the most to the degradation of TC, followed by $S O _ { 4 } ^ { \bullet \bullet }$ -, ${ } ^ { 1 } 0 _ { 2 }$ and OH, which only generated when ${ \mathrm { C o } } _ { 3 } { \mathrm { V } } _ { 2 } { \mathrm { O } } _ { 8 }$ and PS existed at the same time. Furthermore, the internal electronic exchange occurred between ${ \mathsf { C o } } ( { \mathrm { I I } } ) / { \mathsf { C o } }$ (III) and $\mathsf { V } ( \mathsf { I V } ) / \mathsf { V } ( \mathsf { V } ) ,$ , and surface electronic exchange occurred with PS, which accelerated the generation of radicals and thus promoted the degradation of pollutants. The identification of the intermediate formed in the reaction process laid the foundation for the proposal of a four-pathway of TC degradation in the system.
