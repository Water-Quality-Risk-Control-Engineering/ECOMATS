# Peroxymonosulfate Activation by Rice-Husk-Derived Biochar (RBC) for the Degradation of Sulfamethoxazole: The Key Role of Hydroxyl Groups

Abstract: In this work, rice-husk-derived biochar (RBC) was synthesized by using simple one-step pyrolysis strategies and served as catalysts to activate peroxymonosulfate (PMS) for degrading sulfamethoxazole (SMX). When the annealing temperature $( \mathrm { T } ) = 8 0 0 ~ ^ { \circ } \mathrm { C } ,$ $\mathrm { R B C } _ { 8 0 0 }$ exhibits the typical hardwood structure with several micropores and mesoporous. Furthermore, ${ \mathrm { R B C } } _ { 8 0 0 }$ obtains more defect sites than ${ \mathrm { R B C } } _ { 6 0 0 }$ , ${ \mathrm { R B C } } _ { 7 0 0 }$ , and $\mathrm { R B C } _ { 9 0 0 }$ . In the $\mathrm { R B C } _ { 8 0 0 } / \mathrm { P M S }$ system, the removal rate of the SMX reached $9 2 . 0 \%$ under optimal conditions. The kinetic reaction rate constant $( k _ { \mathrm { o b s } } )$ of the $\mathrm { R B C } _ { 8 0 0 } / \mathrm { P M S }$ system was $0 . 0 0 9 \mathrm { ~ m i n } ^ { - 1 }$ , which was about 1.50, 1.28, and 4.50 times that of the $\mathrm { R B C } _ { 6 0 0 } / \mathrm { P M S }$ $( k _ { \mathrm { o b s } } = 0 . 0 0 6 \operatorname* { m i n } ^ { - 1 }$ ), $\mathrm { R B C } _ { 7 0 0 } / \mathrm { P M S }$ $( k _ { \mathrm { o b s } } = 0 . 0 0 7 \ : \mathrm { m i n ^ { - 1 } } )$ , and $\mathrm { R B C } _ { 9 0 0 } / \mathrm { P M S }$ $( k _ { \mathrm { o b s } } = 0 . 0 0 2$ $\operatorname* { m i n } ^ { - 1 }$ ) systems, respectively. In the $\mathrm { R B C } _ { 8 0 0 } / \mathrm { P M S }$ system, sulfate radical $( \mathrm { S O _ { 4 } } ^ { \bullet - } )$ ) is the main active species. Compared with other active sites, the hydroxyl group (C-OH) on the surface of $\mathrm { R B C } _ { 8 0 0 }$ interacts more strongly with PMS, which is more likely to promote the stretching of the O-O bond of the PMS, thus breaking into the activated state and significantly reducing the activation energy required for reaction. The degradation intermediates of SMX were speculated, and the toxicity analysis was conducted. Generally, this work reveals in depth the interaction between reactive sites of biochar-based catalysts and PMS at the molecular level.

# 1. Introduction

Recently, pharmaceuticals and personal care products (PPCPs) have been widely adopted to treat a variety of human and animal diseases [1]. Among them, sulfamethoxazole (SMX) as a typical PPCPs can effectively prevent coccidiosis, diarrhea, gastroenteritis, and other bacterial diseases [2]. SMX is first consumed by humans or animals and enters the wastewater treatment system with excreta. However, most conventional treatment processes cannot degrade SMX effectively, so residual SMX enters the natural water environment with treated municipal wastewater [3]. Residual SMX in aquatic environments may increase the resistance of pathogenic microorganisms, causing negative effects on aquatic life [4]. Therefore, it is important to develop an effective method for eliminating residual SMX in the aquatic environment.

The hydroxyl radical-based advanced oxidation processes (HR-AOPs) are the effective method for degrading emerging contaminants, and their mechanisms are largely dependent on the hydroxyl radical $( { } ^ { \bullet } \mathrm { O H } )$ [5]. However, HR-AOPs also have many shortcomings, such as the difficulty of transporting and storing hydrogen peroxide $( \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } )$ , a narrow $\mathrm { p H }$ application range, and higher energy consumption [6]. Recently, persulfate-based advanced oxidation processes (PS-AOPs) have been favored by researchers due to higher oxidizability and wider applicability under the environments $( \mathrm { p H } = 2 . 0 \ – 8 . 0 )$ [5]. There are lots of methods for peroxydisulfate (PDS) and peroxymonosulfate (PMS) activation to generate reactive oxygen species (ROSs), such as ultraviolet irradiation, heat, and transition metals [7]. However, these activation methods often have problems such as extensive energy consumption, high cost, metal leaching, etc., which limits their application prospects in actual wastewater [8].

Biochar (BC) has become a research hotspot recently [9]. Biomass feedstock, such as sludge, corncob, wood chips and shrimp shell, is rich and cheap [10]. Besides, BC has abundant functional groups as well as well-developed porous structure, which obtains significant advantages for the synthesis of carbonaceous catalysts [11]. Qi et al. reported that the Enteromorpha based graphene-like biochar (EGB) was synthesized as a PDS activator for the SMX removal [12]. Liu et al. reported that boron-doped graphitic porous biochar (BKBC) was synthesized and used as catalysts to activate PDS for removing SMX [13]. Besides, Zhao et al. systematically reported the research progress of the PMS activation by biocharbased catalysts [11]. Although some studies have been carried out on the degradation of micropollutants via activating PS by pristine BC, the interaction mechanism between surface active sites of BC and PS is still unclear. In addition, the pyrolysis temperature (T) largely determines the structure and physicochemical properties of catalysts, while the specific surface area (SSAs), micropore structure and graphitization degree of BC will affect the removal rate of organic micropollutants in PS-AOPs [11]. Herein, the structure-activity relationship between the physicochemical properties of catalysts and the catalytic activity needs to be further revealed.

Herein, raw biochar (RBCT) derived from rice husk was prepared as a PMS activator for the elimination of SMX. The difference of physicochemical properties of ${ \mathrm { R B C } } _ { \mathrm { T } }$ at different pyrolysis temperatures was investigated, and the structure-activity relationship between physicochemical properties and catalytic activity was established. Then, the ROSs in the $\mathrm { R B C } _ { 8 0 0 }$ /PMS system were identified. The degradation pathway of SMX was predicted, and the interaction mechanism between active sites and PMS was revealed by density functional theory (DFT) calculation. The study proposes a deep understanding of PMS activation mechanism and demonstrates great potential of the biochar-based catalysts toward sewage treatment.

# 2.1. Characterization of $R B C _ { 8 0 0 }$

The morphology of ${ \mathrm { R B C } } _ { \mathrm { T } }$ were observed by scanning electron microscopy (SEM). As displayed in Figure 1a–d, ${ \mathrm { R B C } } _ { 6 0 0 }$ shows the clumpy structure and incomplete porous structure. When the pyrolysis temperature is $7 0 0 ^ { \circ } \mathrm { C } ,$ ${ \mathrm { R B C } } _ { 7 0 0 }$ shows a plate structure, and the pore structure has initially developed. $\mathrm { R B C } _ { 8 0 0 }$ derived from rice husks exhibits a typical hardwood structure, with lots of micropores and mesoporous. When the pyrolysis temperature is $9 0 0 ^ { \circ } \mathrm { C } ,$ the carbon network collapses. It can be seen that the porous structure of RBC is relatively developed when the pyrolysis temperature is $8 0 0 ^ { \circ } \mathrm { C } ,$ which is conducive to the catalytic oxidation process. However, excessive pyrolysis temperature $( \mathrm { T } \geq 9 0 0 ^ { \circ } \mathrm { C } )$ may destroy the well-developed porous structure.

As depicted in Figure 1e,f, energy-dispersive $\mathsf X$ -ray spectroscopy (EDS) analyzed the elemental content of ${ \mathrm { R B C } } _ { 8 0 0 }$ , in which C content accounted for $6 5 . 3 \%$ , O content accounted for $2 4 . 0 \%$ , Si content accounted for $5 . 5 \%$ , N content accounted for $0 . 2 \%$ and Fe content accounted for $5 . 0 \%$ . To further explore the wide applicability of ${ \mathrm { R B C } } _ { 8 0 0 }$ , the degradation experiments of different pollutants were carried out (Figure S6c). In the $\mathrm { R B C } _ { 8 0 0 }$ /PMS system, the degradation rates of CEX, CIP, CMP and TCS within $2 0 0 \mathrm { m i n }$ were $8 7 . 3 \%$ , $9 1 . 1 \%$ , $9 0 . 2 \%$ and $8 9 . 6 \%$ , respectively, and the mineralization rates were $6 7 . 4 \%$ , $7 2 . 3 \%$ , $7 3 . 7 \%$ and $7 6 . 1 \%$ respectively. These results showed that the admirable universality of $\mathrm { R B C } _ { 8 0 0 }$ as an efficient PMS activator to remove a broad array of typical PPCPs. As displayed in Figure S6d, the $\mathrm { R B C } _ { 8 0 0 } / \mathrm { P M S }$ system had a satisfactory mineralization performance on SMX with a TOC elimination rate of $7 9 . 0 \%$ within $2 0 0 \mathrm { m i n }$ .

# 2.3. Mechanism Discussion

# 2.3.1. Identification of ROSs

Quenching tests were conducted to first to determine the dominant ROSs responsible for SMX degradation process [13,29]. Methanol $\left( { \mathrm { M e O H } } \right)$ was regarded as a scavenger of $\textstyle \cdot _ { \mathrm { O H } }$ $[ \ : ( ( 1 . \dot { 6 } – 7 . 7 ) \times 1 0 ^ { 7 } \ : \mathrm { M } ^ { - 1 } s ^ { - 1 } )$ and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ $( ( 1 . 2 – 2 . 8 ) \times 1 0 ^ { 7 } \ : \mathrm { M } ^ { - \ddot { 1 } } \mathrm { s } ^ { - 1 } )$ [30]. In contrast, Tert-butanol (TBA) was used as a scavenger to quench $\textstyle \cdot _ { \mathrm { O H } }$ $( 6 . 0 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 } )$ ) [31]. $p$ -benzoquinone $( p \mathrm { - B Q ) }$ was used to inhibit $\mathrm { O } _ { 2 } { } ^ { \bullet - }$ $( 9 . 6 \times 1 0 ^ { 8 } \mathrm { M } ^ { - 1 } \mathrm { s } ^ { - 1 } )$ [24]. The SMX elimination rates decreased from $9 2 . 0 \%$ to $3 7 . 0 \%$ , $7 0 . 0 \%$ , $8 4 . 0 \% ,$ and $5 2 . 0 \%$ within $2 0 0 \mathrm { { m i n } }$ after adding MeOH $( 0 . 5 \mathbf { M } )$ , TBA $( 0 . 5 \mathrm { M } )$ , $p$ -BQ ( $2 0 . 0 \mathrm { m M } )$ , and FFA $( 0 . 5 \mathbf { M } )$ , respectively (Figure 5). The results showed that MeOH had an obvious inhibitory effect on SMX degradation in the $\mathrm { R B C } _ { 8 0 0 }$ /PMS system, while TBA had a mild inhibitory effect on SMX degradation. Therefore, $\mathrm { S O _ { 4 } ^ { \bullet - } }$ may be the main ROSs, leading the degradation process of SMX. In addition, $\mathrm { O } _ { 2 } { } ^ { \bullet - }$ had little effect on the degradation of SMX, while $\textstyle \cdot _ { \mathrm { O H } }$ and $^ 1 \mathrm { O } _ { 2 }$ were also involved in the degradation of SMX.
