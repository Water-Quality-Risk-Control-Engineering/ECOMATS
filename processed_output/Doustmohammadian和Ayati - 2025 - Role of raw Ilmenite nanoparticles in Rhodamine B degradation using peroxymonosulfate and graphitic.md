# Role of raw Ilmenite nanoparticles in Rhodamine B degradation using peroxymonosulfate and graphitic carbon nitride

Elmira DoustMohammadian & Bita Ayati

In this study, raw ilmenite nanoparticles (ILM) were used as a photocatalyst with peroxymonosulfate (PMS) and graphitic carbon nitride $( g \mathbf { \cdot C _ { 3 } N } _ { 4 } )$ to remove rhodamine B dye from wastewater. The synthesized $\mathsf { g } { \mathsf { - C } } _ { 3 } \mathsf { N } _ { 4 }$ was characterized by X-ray diffraction (XRD), field emission scanning electron microscopy (FESEM), and Brunauer-Emmett-Teller (BET) analysis. ILM nanoparticles were characterized by XRD, FESEM, and energy-dispersive X-ray (EDX). The experiments were carried out in a rectangular Plexiglas pilot reactor with a practical volume of 3 L. The OFAT method (One Factor at a Time) optimized the influencing parameters. At $\mathsf { p H } = 3$ , after $\mathbf { 1 8 0 } \mathrm { m i n }$ of treatment, $9 9 . 7 \%$ removal of $5 0 \mathsf { m g } / \mathsf { L }$ dye was achieved in the presence of $5 0 0 \mathsf { m g } / \mathsf { L }$ ILM, $3 0 0 \mathsf { m g } / \mathsf { L }$ PMS, and $2 0 0 \mathrm { m g } / \mathsf { L } \mathsf { g } / \mathsf { - C } _ { 3 } \mathsf { N } _ { 4 }$ . Mineralization results showed $8 3 . 2 \%$ COD and $7 5 . 8 \%$ TOC removal after 180 min of treatment. Kinetic analysis of the reactions indicated a pseudo-first-order dependence. According to the results of the scavenger study, sulfate radicals $( \mathsf { S } \dot { O } _ { 4 } ^ { - } ) ,$ hydroxyl radicals $( { \dot { O } } H ) ,$ and superoxide radicals $( { \dot { O } } _ { 2 } ^ { - } )$ were the main active species for dye removal. The ICP-MS analysis revealed that the leached concentrations of iron, magnesium, and calcium ions were 2.6, 1.62, and $5 . 4 1 \mathrm { m g } / \mathrm { L } ,$ respectively, lower than the permissible limits for wastewater discharge.

Keywords OFAT, Sulfate radical, Mineralization, ICP, Scavenger, Nanomaterial

Dyes are a class of environmentalcontaminants that are widely used in industries such as textile, leather, paper, and plastics1 . These toxic and enduring compounds may lower dissolved oxygen levels and have an impact on aquatic life as well as human health2 . Wastewater-containing dyes must be treated before discharge due to their adverse environmental effects3 . Conventional wastewater treatment technologies cannot remove all pollutants despite the development of wastewater treatment plants worldwide4 .

One of the methods for treating complex organic pollutants in wastewater is advanced oxidation processes. Advanced oxidation processes are a group of technologies that produce active species to break down hazardous industrial wastewater and organic pollutants5 . Advanced light-driven oxidation technologies are called photocatalytic processes. When exposed to radiation, photocatalysts become active and generate electron-hole pairs, which are very reactive charge carriers that react with the pollutants. Removing pollutants at ambient temperature and pressure can solve the problem of high energy consumption of conventional methods. When a photocatalyst is exposed to light, it creates electron-hole pairs in its valence and conduction bands. These photoelectrons and photoholes then take part in reduction and oxidation reactions, respectively6 . Recently, sulfate radical-based technologies have attracted interest due to their high efficiency, wider $\mathrm { p H }$ range of operation7 , longer half-life, and greater oxidation potential than hydroxyl radicals8 .

Hydroxyl radicals have a shorter half-life than sulfate radicals, suggesting that sulfate radicals are more stable and have a longer interaction period with organic contaminants. Typically, high temperatures, UV light, or contact with certain transition metals activate substances such as persulfate (PS) and peroxymonosulfate (PMS), leading to the formation of sulfate radicals9,10, Among the various activation methods, transition metals are considered one type of low-cost and effective method11. PMS is a strong oxidizing agent with a high oxidation potential, which is also stable and efficient over a wide pH range12, As a strong oxidant, it participates in advanced oxidation processes by generating active species (sulfate and hydroxyl radicals)9 . In general, the activation of PMS can be achieved by a transition metal ion acting as a catalyst. Since iron is a relatively nontoxic and inexpensive transition metal catalyst, various forms of it, including natural polycrystalline ilmenite, are widely used for chemical activation of PMS. Ilmenite (ILM), with the formula ${ \mathrm { F e T i O } } _ { 3 } ,$ is one of the most abundant titanium minerals in the earth’s crust and is used as a raw material for $\mathrm { T i O } _ { 2 }$ 3production13. One of 2the main disadvantages of this mineral is the large band gap compared to other materials. By photoreducing Fe(III) to $\mathrm { F e ( I I ) }$ on the ilmenite surface, UV irradiation can be used to improve the efficiency and overcome this problem14.

Graphitic carbon nitride $( \mathbf { g } \mathrm { - C } _ { 3 } \mathbf { N } _ { 4 } )$ is a non-metallic semiconductor that is becoming more well-known for its ability to treat wastewater and water contamination15. Numerous attributes, including a low band gap, resistance to heat and chemicals, and a porous structure, are responsible for its allure16,17. $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ is also cost-effective, 3 4environmentally benign, and has a useful electronic structure, all of which increase its allure18.

$\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ is suitable for various applications, including photocatalysis, sensors, and energy storage. Certain drawbacks exist, though, including the low specific surface area of bulk $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ produced using conventional 3 4techniques and the high rate of electron-hole pair recombination, which may restrict efficiency. Water splitting, $\mathrm { C O } _ { 2 }$ reduction, and the degradation of organic pollutants are just a few of the numerous applications for $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ . In addition to supercapacitors and batteries for energy storage, it is used in sensors that detect various chemicals and gases19.

Contemporary $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ modification methods include doping, in which metals or non-metals are added to increase photocatalytic efficiency; surface functionalization to increase light absorption and charge separation; and heterojunction formation, in which $\mathbf { g }$ -C3N4 is paired with other materials, such as metal oxides, to increase photocatalytic performance20. When $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ and TiO2 are compared, it is evident that $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ can absorb visible light, whereas TiO2 primarily absorbs ultraviolet (UV) light. $\mathrm { g } – \mathrm { C } 3 \mathrm { N } 4$ is more efficient under visible light because its band gap $( 2 . 7 \mathrm { e V } )$ is smaller than $\mathrm { T i O } _ { \gamma } \mathrm { \dot { \bf s } }$ $( 3 . 2 \mathrm { e V } ) ^ { 2 1 }$ .

Findings from Jiang, L. et al. $( 2 0 2 2 ) ^ { 2 \tilde { 2 } }$ highlight strategies to improve the near-infrared (NIR) light capture of $\mathrm { T i O } _ { 2 }$ -based photocatalysts. Using up-conversion materials to convert NIR light into visible light for photocatalysis, hybridization with narrow optical gap semiconductors to improve NIR light absorption, and band gap engineering to alter the band gap and improve light absorption properties are some of these strategies. Moreover, plasmonic materials enhance light absorption through localized surface plasmon resonance, and photosensitizers expand the range of light absorption.

In comparison to traditional photocatalysts like $\mathrm { T i O } _ { 2 } , \mathrm { g } { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ demonstrates greater potential for efficiently 2 3 4harnessing solar energy and treating wastewater. These qualities make $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ a compelling choice for ongoing and future research in the field of photocatalysis, promising more sustainable and effective solutions for environmental applications.

Many studies have been conducted on the use of ilmenite, $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 } ,$ and PMS to remove different kinds of pollutants. For example, Silveira et al. (2017) removed $9 5 \%$ of the $8 \bar { 0 } \mathrm { m g / L }$ dispersed blue dye in $1 8 0 \ \mathrm { m i n }$ using PS and ${ \mathrm { F e T i O } } _ { 3 }$ . C. X. Xu et al. $( 2 0 2 2 ) ^ { 2 3 }$ used S-scheme 2D/2D F $\mathrm { \nabla _ { \ z } T i O _ { \it 3 } / g  – C _ { \it 3 } N _ { \it 4 } }$ hybrid architectures as visiblelight-driven photo-Fenton catalysts for tetracycline hydrochloride degradation, and this system with optimal photo-Fenton activity showed excellent recyclability for five photo-Fenton cycles. Le et al. $( 2 0 2 3 ) ^ { 2 4 }$ used PDS and $\mathrm { g } { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } \mathrm { i n }$ another study to remove $8 4 \%$ of $1 0 \mathrm { m g / L }$ tetracycline and HCl contaminants in $6 0 \mathrm { { m i n } }$ . Ammar et al. $( 2 0 \dot { 2 } 4 ) ^ { 2 5 }$ used Z-scheme FeTiO /Fe-doped $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ photocatalytic heterojunctions for antibiotic removal, and the photodegradation rates of ibuprofen, ciprofloxacin, bisphenol A, and rhodamine B were $9 0 . 9 \%$ , $9 3 . 4 \%$ , $8 0 . 6 \%$ , and $8 6 . 2 \%$ , respectively, after $1 2 0 \mathrm { m i n }$ . Redouane-Salah et al. $( 2 0 2 4 ) ^ { 2 6 }$ used PMS, $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ and ${ \mathrm { F e T i O } } _ { 3 }$ to remove a $1 0 \mathrm { m g / L }$ tartrazine contamination in less than $1 2 0 \mathrm { m i n }$ .

By using $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ in the system, this study aims to improve the photocatalytic process and activate PMS through ILM nanoparticles to remove wastewater dyes. This study exploits the inherent potential of raw ilmenite to develop an economical and environmentally friendly dye removal technique. The use of unrefined raw ilmenite represents a pragmatic method of material selection that reduces costs, energy consumption, and processing time. When PMS is combined with UV light, $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ and ilmenite nanoparticles, the study exploits a powerful oxidation process that produces extremely reactive species such as superoxide, sulfate, and hydroxyl radicals. These species efficiently break down complex organic pollutants, indicating the system’s potential for useful wastewater treatment. By providing a practical, economical, and environmentally friendly solution, the study addresses the disadvantages of traditional wastewater treatment technologies. This method is more sustainable and useful because it uses inexpensive, naturally occurring materials such as $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ and raw ilmenite.

# Preparation of Ilmenite nanoparticles

Using a planetary ball mill, ILM particles with the chemical formula ${ \mathrm { F e T i O } } _ { 3 }$ and a molar mass of $1 5 1 . 7 1 \ \mathrm { g / m o l }$ were prepared at the nanoscale. A mixture of $5 0 \ \mathrm { g }$ of water, $_ { 1 0 0 \mathrm { \ g } }$ of rock powder, and 12 steel balls was placed in four ball mill jars and milled at $5 0 0 \mathrm { r p m }$ for $^ { 4 \mathrm { h } }$ . The resulting paste-like mixture was dried at $8 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 5 \mathrm { h } }$ in an oven.

# Synthesizing $\mathsf { g } { \mathsf { - C } } _ { 3 } \mathsf { N } _ { 4 }$

Urea was used for the synthesis of $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ . First, $1 0 \mathrm { g }$ of urea was heated in a furnace under an argon atmosphere with a $2 ~ { ^ { \circ } C } / { \mathrm { m i n } }$ rate up to $5 5 0 ~ ^ { \circ } \mathrm { C }$ and held at that temperature for $^ { 4 \mathrm { ~ h ~ } }$ . The resulting yellow fluffy product was collected and ground into a powder, then washed with deionized water and ethanol to remove residual impurities. The obtained $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ was dried under vacuum at $6 0 { } ^ { \circ } \mathrm { C } ^ { 2 7 }$ .

# Methods

The experiments used a pilot-scale, rectangular reactor constructed from Plexiglas. The reactor had dimensions of $2 0 \mathrm { c m }$ in length, $1 5 \mathrm { c m }$ in width, $1 2 \mathrm { c m }$ in depth, and a practical volume of $_ { 3 \mathrm { ~ L ~ } }$ (Fig. 1).

This pilot-scale setup was used to study the treatment of a synthetic wastewater sample containing Rhodamine B dye dissolved in deionized water. The reactor contained four 6 W UVC lamps. The system was mixed using an aeration pump at a flow rate of $4 ~ \mathrm { L / m i n }$ . All experiments were performed at ambient temperature with three repetitions and a maximum error rate of $5 \%$ . The main parameters affecting the reaction, including $\mathrm { p H }$ (2, 3, 5, 7, and 9), dye concentration (10, 20, 50, and $\mathrm { 1 0 0 ~ m g / L }$ ), the ILM nanoparticles dosage (50, 250, 500, and 1000 $\mathrm { m g / L } )$ , the PMS dosage (50, 100, 150, 200, 300, and $4 0 0 ~ \mathrm { { m g / L } }$ ), and $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ dosage (100, 150, 200, and 300 $\mathrm { m g / L }$ ), were optimized by the One Factor-at-a-Time method (OFAT).

In advanced oxidation processes, calculating energy consumption is a fundamental basis for estimating economic costs. For the system used in this study, due to the use of aeration for mixing and UV light radiation by the lamps, calculating energy consumption is particularly important. The energy consumption $( \mathrm { \bar { k } W h / k g ) }$ for the removal of each kilogram of dye was calculated using Eq. 1 for the parameters that had a significant impact on energy consumption, including dye concentration, aeration, and UV light intensity28.

# Optimization of main operational parameters

Effect of initial $p H$

To find the optimum initial $\mathrm { p H }$ of the solution while keeping other reaction parameters constant, values of 2, 3, 5, 7, and 9 were examined. Figure 6 displays the results; after $1 8 0 ~ \mathrm { m i n }$ , the dye removal efficiencies for the mentioned $\mathrm { p H }$ levels were 94.7, 99.1, 83.3, 74.4, and $6 9 \%$ , respectively. As shown in Fig. 6, $\mathrm { p H } = 3$ yielded a maximum percentage of dye removal. It can be noticed that dye removal was higher under acidic conditions. This may be explained because, under acidic conditions, the presence of protons can readily generate hydroxyl radicals, resulting in dye degradation. On the other hand, at higher $\mathrm { p H }$ levels, the hydroxide ions could form stable and complex compounds with the dye and metal ions. This prevented the dye from breaking down effectively and reduced the overall efficiency of removing the dye from the wastewater38. In alkaline conditions, concentrations of PMS decompose without generating active radicals. Additionally, under alkaline conditions, the standard redox potential of sulfate and hydroxyl radicals is lower than in acidic conditions. Moreover, when the solution is alkaline, the catalyst surface carries negative charges, repelling PMS anions. Thus, less PMS can be activated on the catalyst surface39. Also, as the $\mathrm { p H }$ increases, the surface charge of $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ becomes negative, reducing the electrostatic repulsive force interaction between PMS and $\mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ^ { \ 4 0 }$ 3 4. These findings are consistent with Xu et al. (2020)41and Huang et al. $( 2 0 2 0 ) ^ { 4 2 }$ studies.

Effect of initial dye concentration

To determine the optimal initial dye concentration, 10, 20, 50, and $1 0 0 ~ \mathrm { { m g / L } }$ of dye were examined using the optimized pH from the previous step while keeping other parameters constant (Fig. 7a). According to the results, the dye removal efficiency decreased as the dye concentration increased from 10 to $1 0 0 ~ \mathrm { { m g / L } }$ . After $1 8 0 ~ \mathrm { m i n }$ , the removal efficiencies for the mentioned concentrations were 99.1, 93, 84.7, and $5 9 . 4 \%$ , respectively. Based on the results, the removal efficiency decreases with an increase in the initial dye concentration. This phenomenon occurs because more time is required to achieve the same efficiency with the active species’ concentration remaining constant and the dye concentration increasing43. Increasing the dye concentration leads to reduced UV light penetration and the occupation of active sites on the surface of nanoparticles. These factors result in fewer active species and, thus, a reduced dye removal efficiency30,38. Di et al. (2020) investigated the removal of Rhodamine B dye using an advanced oxidation process. They observed that with an increase in dye concentration, the removal efficiency decreased, which is consistent with the findings of this study.

Since energy consumption is one of the crucial parameters evaluated in advanced oxidation processes, the energy consumption (Fig. 7b) was calculated to achieve 60, 70, and $8 0 \%$ removal efficiencies at various dye concentrations. Based on the results, it can be observed that energy consumption decreases as the concentration increases up to $5 0 ~ \mathrm { m g / L }$ , after which it begins to increase. Based on the results, a concentration of $5 0 ~ \mathrm { m g / L } ,$ , with the lowest energy consumption of $1 0 0 8 . 8 \mathrm { \ k W h / k g }$ for an $8 0 \%$ removal rate, was considered the optimal pollutant concentration for further experiments. These findings are consistent with the study by Ghalebizade & Ayati (2019).

# Effect of ILM concentration

To determine the optimal ILM concentration, 50, 250, 500, and $\mathrm { 1 0 0 0 ~ m g / L }$ ILM were examined using the optimized $\mathrm { p H }$ and dye concentration from the previous steps, keeping other parameters constant. The results are presented in Fig. 8. According to the results, after $1 8 0 \ \mathrm { m i n }$ , the removal efficiencies for the mentioned concentrations were 56.5, 73.7, 84.7, and $6 1 . 5 \%$ , respectively. Based on the results, it can be concluded that increasing the ILM concentration up to $5 0 0 ~ \mathrm { m g / L }$ enhances the removal efficiency due to the photocatalytic activity of ilmenite. Irradiating ILM with UVC light generates electron-hole pairs, leading to the production of superoxide radicals (Reaction 5) and hydroxyl radicals (Reaction $6 ) ^ { 3 2 }$ . Increasing the amount of ILM produces more active species, enhancing dye removal efficiency44. In addition to its ability as a photocatalyst, ILM also functions as a catalyst that can activate PMS when exposed to UV light and PMS (Reactions 2 to 9)8 .

Effect of PMS concentration

To determine the optimal PMS concentration, PMS concentrations of 50, 100, 150, 200, 300, and $4 0 0 \mathrm { m g / L }$ were examined at $\mathrm { p H } = 3$ , with a dye concentration of $5 0 \mathrm { m g / L }$ , ILM concentration of $5 0 0 \mathrm { m g / L }$ , and other parameters kept constant (Fig. 9). According to the results, the dye removal efficiency improved as the PMS concentration increased from 50 to $3 0 0 ~ \mathrm { m g / L }$ . After $1 8 0 \ \mathrm { m i n }$ , the removal efficiencies for 50, 100, 150, 200, and $3 0 0 ~ \mathrm { m g / L }$ PMS concentrations were 64.6, 84.7, 88.6, 93.4, and $9 9 . 7 \%$ , respectively. PMS, when irradiated with UVC light, produces hydroxyl and sulfate radicals. Therefore, increasing the PMS concentration enhances the concentration of active species and subsequently improves the dye removal efficiency8,45. On the other hand, increasing the PMS concentration from 300 to $4 0 0 ~ \mathrm { { m g / L } }$ led to a slight decrease in dye removal efficiency since higher PMS concentrations can act as scavengers, trapping free radicals generated from secondary reactions46. Based on the results, a concentration of $3 0 0 \mathrm { m g / L }$ was selected as the optimal amount.

Effect of $\partial { - } C _ { 3 } N _ { 4 }$ concentration

To determine the optimal concentration of $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 } ,$ concentrations of 100, 150, 200, and $3 0 0 \mathrm { m g / L }$ were examined at $\mathrm { p H } = 3$ , with a dye concentration of $5 0 \mathrm { m g / L }$ , ILM concentration of $5 0 0 ~ \mathrm { m g / L }$ , and PMS concentration of 300 $\mathrm { m g / L }$ . According to the results shown in Fig. 10, after $1 8 0 \mathrm { m i n }$ , the removal efficiencies for $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ concentrations of 100, 150, and $2 0 0 ~ \mathrm { m g / L }$ were 88.7, 95.4, and $9 9 . 7 \%$ , respectively. The results indicate that the degradation increases with the increasing concentration of $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ and reaches an optimal $2 0 0 ~ \mathrm { m g / L }$ value. As the $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ concentration increases, not only are more active species produced, but also the number of active sites increases, leading to a higher dye degradation rate. On the other hand, increasing the $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ concentration from 200 to $3 0 0 ~ \mathrm { m g / L }$ resulted in a decrease in removal efficiency $( 9 5 . 7 \% )$ because a higher catalyst concentration causes turbidity in the system, preventing UVC light penetration47. Considering the high removal rate, a concentration of $2 0 0 \mathrm { m g / L }$ was selected as the optimal amount.

# Analysis of the impact of individual factors on the process

This step examined the separate and combined effects of parameters influencing the reaction, including aeration, UV light, photocatalysts, and oxidants, under optimal dye removal conditions. The obtained results are presented in Fig. 11. Aeration only, PMS only, $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ only, and ILM exhibited dye removal efficiencies of around 0.8, 2.0, 4.9, and $6 . 9 \%$ , respectively, within $1 8 0 ~ \mathrm { m i n }$ . As shown by the results, aeration, PMS, $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 } ,$ and ILM in the absence of UVC light exhibited a negligible (near zero) effect on dye removal. This indicates the importance of UVC light in this photocatalytic process. Then, the effects of PMS, $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 } ,$ and ILM in the presence of UVC light were considered, and their respective removal efficiencies were found to be 67.7, 24.5, and $2 9 . 2 \%$ . Finally, the combined factors were considered. From the figure, it can be seen that the combination of PMS and $\mathsf { g } \mathrm { - C } _ { 3 } \mathrm { N } _ { 4 } ,$ PMS and ILM, and ILM and $\mathsf { g } – \mathsf { C } _ { 3 } \mathrm { N } _ { 4 }$ resulted in removal efficiencies of $7 8 . 4 \%$ , $8 8 . 0 \%$ , and $3 6 . 9 \%$ , respectively, in the presence of UVC light and aeration. Comparing the results to the complete process shows that the interaction of all these factors improves system efficiency.

# Mineralization

Since decolorization does not necessarily mean complete degradation of the pollutant, as only the functional bonds are broken and environmental risks may still exist after optimizing the parameters affecting the reaction, COD and TOC analyses were conducted to evaluate mineralization and changes in the total organic carbon content in the solution. COD analysis is widely used to evaluate the organic strength of dye-contaminated wastewater and the degree of mineralization48. According to Fig. 12, the removal efficiencies for COD and TOC with initial values of 60 and $3 0 \mathrm { m g / L }$ , respectively, were $8 3 . 2 \%$ and $7 5 . 8 \%$ after $1 8 0 \ \mathrm { m i n }$ . Based on the results, it can be observed that the color reduction was more significant compared to COD and TOC. Despite the removal of dye within $1 8 0 \ \mathrm { m i n }$ , complete mineralization has not occurred, and a longer duration is needed for the removal of COD and TOC due to the more difficult decomposition of intermediate products49. Fluctuations in the COD removal chart can be attributed to the production and degradation of intermediate compounds with varying COD levels during the reaction. Additionally, the breaks observed in the COD chart are likely due to the breaking of benzene rings in dye molecules50.

# Reaction kinetics

After COD and TOC analyses, the reaction kinetics were examined. For this purpose, zero-order, pseudo-firstorder, and pseudo-second-order kinetic models were used, and the results are shown in Fig. 13. According to the results, dye removal from the solution follows the pseudo-first-order kinetic model more closely, given its higher correlation coefficient (0.9673).

# Effect of various scavengers on dye degradation

Various scavengers were used to identify the main active species in the photocatalytic degradation process and determine the free radical driving the process. For this purpose, potassium iodide (KI) was employed as a hole scavenger51,52and hydroxyl radical scavenger3 , p-Benzoquinone (PBQ) was used as a superoxide radical scavenger1 , tert-butyl alcohol (TBA) as a hydroxyl radical scavenger3 , ethanol as a hydroxyl and sulfate radical scavenger40, and phenol as a hydroxyl, sulfate, and singlet oxygen radical scavenger53. These were selected in a 10:1 ratio of scavenger to oxidant8 , and the results are shown in Fig. 14. Adding KI resulted in a $7 7 . 5 \%$ reduction in removal efficiency. This scavenger contains I−ions that react with hydroxyl radicals and holes, reducing dye removal efficiency1 . Adding TBA resulted in a $5 6 . 9 1 \%$ reduction in removal efficiency, highlighting the role of hydroxyl radicals in the removal process. Adding ethanol and phenol led to reductions of $4 5 . 3 9 \%$ and $4 0 . 2 0 \%$ in removal efficiency, respectively. Since ethanol scavenges sulfate and hydroxyl radicals, the difference in inhibition results between TBA and ethanol indicated the impact of sulfate radicals. Since phenol is a scavenger for sulfate, hydroxyl, and singlet oxygen radicals, comparing the results of these three scavengers (TBA, ethanol, and phenol) revealed the impact of singlet oxygen radicals on the system. Adding PBQ (a superoxide radical scavenger) reduced the removal efficiency to $5 1 . 9 \%$ , indicating that superoxide radicals play a crucial role in dye removal efficiency. Based on the results, it can be concluded that sulfate, hydroxyl, and superoxide radicals are the three dominant active species in dye removal within this system. Tang et al. (2019) also found similar results in their study.

Determination of iron, magnesium, and calcium ion leaching

An ICP-MS analysis was conducted to determine the leaching of iron, magnesium, and calcium ions from the ILM photocatalyst into the solution. This analysis revealed that $2 . 6 \mathrm { m g / L }$ of iron, $1 . 6 2 \mathrm { m g / L }$ of magnesium, and $5 . 4 1 ~ \mathrm { m g / L }$ of calcium had leached into the solution. It should be mentioned that the allowable amounts of iron, magnesium, and calcium in wastewater for discharging to surface water bodies are limited to 3, 100, and $7 5 \mathrm { m g / L }$ , respectively, by Iranian wastewater discharge standards according to Article 5 of the Iranian Water Pollution Prevention Regulations (Department of 457 Environment, 1994). Therefore, the levels of iron, magnesium, and calcium in the solution are lower than the standard limits, and there is no need for further wastewater treatment to reduce the concentrations of these elements.

# Conclusion

The degradation of rhodamine B by a photocatalysis process using raw ilmenite nanoparticles as a photocatalyst that helps activate the peroxymonosulfate was investigated. Experiments were performed in a pilot-scale, rectangular reactor constructed from Plexiglas with four 6 W UVC lamps, and the system was mixed using an aeration pump. After $1 8 0 \mathrm { m i n }$ , $9 9 . 7 2 \%$ removal was obtained under optimal conditions at $\mathrm { p H } = 3$ , with an initial dye concentration of $5 0 ~ \mathrm { m g / L }$ with a concentration of $5 0 0 ~ \mathrm { m g / L }$ ILM, $3 0 0 ~ \mathrm { m g / L }$ PMS, and $2 0 0 \ \mathrm { m g / L } \ \mathrm { g } – \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } .$ Under optimal conditions, COD and TOC removal efficiency reached $8 3 . 2 \%$ and $7 5 . 8 \%$ , respectively. The kinetic analysis of the reactions indicated a pseudo-first-order dependence. Scavenger’s experiments demonstrated that hydroxyl, sulfate, and superoxide radicals played a prominent role in the degradation of the dye. The amounts of leached iron, magnesium, and calcium in the solution were less than the values of the wastewater discharge standard. As a result, due to the excellent decolorization and mineralization of dye by the photocatalysis process and using natural stone powder without purification, this process is environmentally friendly and significant from economic aspects.
