# Zinc oxide@citric acid‑modified graphitic carbon nitride nanocomposites for adsorption and photocatalytic degradation of perfluorooctanoic acid

# Abstract

Perfluorooctanoic acid (PFOA) is a highly persistent organic pollutant of global concern. A novel nanocomposite composed of ${ \mathrm { Z n O } }$ nanoparticles and citric acid-modified ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ was synthesized by ball milling process. The synthesized nanocomposite was more efficient than pure ball-milled ${ \mathrm { Z n O } }$ nanoparticles for PFOA elimination under visible light irradiation. The optimal hybrid photocatalyst, produced by the addition of $5 \mathrm { w t } \%$ of citric acid-modified ${ \bf g } – { \bf C } _ { 3 } { \bf N } _ { 4 }$ , demonstrated significantly better performance for PFOA removal than pure ${ \mathrm { Z n O } }$ nanoparticles under UV irradiation, with the apparent rate constants of $0 . 4 6 8 \mathrm { h } ^ { - 1 }$ and $0 . 0 9 7 \mathrm { h } ^ { - 1 }$ , respectively. The addition of peroxymonosulfate $( 0 . 5 3 \ \mathrm { g } \ L ^ { - 1 } )$ significantly increased PFOA removal, clarifying the crucial effect of sulfate radicals on PFOA photodegradation. In comparison, citric acid-modified $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ was not effective for PFOA elimination under visible light irradiation, even with the addition of peroxymonosulfate. Further experiments under dark conditions identified surface adsorption on hybrid photocatalyst as a key process in total PFOA removal. In summary, PFOA removal by ${ \mathrm { Z n O } } @$ citric acid-modified graphitic carbon nitride nanocomposites is due to the combined action from adsorption and photodegradation, with adsorption as the dominating mechanism.

Keywords Adsorbent $\cdot$ Modified ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ · Perfluorooctanoic acid $\cdot$ Peroxymonosulfate $\cdot$ Photocatalysis $\cdot$ ZnO

# 1 Introduction

The carbon-fluorine bond is considered the most stable and strongest bond in organic chemistry; therefore, the effective dissociation of the C-F bond could be the main challenge in the total remediation of per- and polyfluoroalkyl substances (PFAS) from the polluted water [1]. PFAS residues have been reported in human, plants, and wild animals [2]. Perfluorooctanoic acid (PFOA) is among well-known PFAS widely detected in aquatic environments with concentrations of nanograms per liter to milligrams per liter [3]. Although adsorption technologies are considered a promising remediation process for PFAS removal, their extensive application could suffer from the economic burden of costly adsorbents, regeneration issues after treatment, and mere transfer from water to solid phase [2]. Among advanced oxidation processes, photocatalysis technology has received great attention for the removal of organic pollutants [4]. Various metal oxides including $\mathrm { T i O } _ { 2 }$ [4], $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ [5], $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ [6], $\mathrm { C e O } _ { 2 }$ [3], and CdS [3] have been recently used for the photocatalytic decomposition of PFOA. Fu et al. [3] used five commercial powders $\mathrm { T i O } _ { 2 }$ , $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ , $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ , $\mathrm { C e O } _ { 2 }$ , and CdS) for PFOA photocatalytic degradation under UV irradiation $( 3 2 ~ \mathrm { W } , 1 7 . 1 ~ \mathrm { W } \mathrm { m } ^ { - 2 } )$ ). They found that the photodegradation efficiency increased as $\mathrm { C d S } < \mathrm { I n } _ { 2 } \mathrm { O } _ { 3 } < \mathrm { C e O } _ { 2 } < \mathrm { T i O } _ { 2 } <$ ${ \mathrm { G a } } _ { 2 } { \mathrm { O } } _ { 3 }$ , while the price of these photocatalysts increased as $\mathrm { T i O } _ { 2 } { < } \mathrm { C d S } { < } \mathrm { C e O } _ { 2 } { < } \mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } { < } \mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ . The efficiency of catalysts relies on numerous factors such as catalyst properties (particle size, specific surface area $( S _ { \mathrm { B E T } } ) )$ , catalyst dosage, solution properties (e.g., pH), and the operating conditions (type of reactor, source of light). For instance, Lopes da Silva et al. [7] used commercial $\mathrm { T i O } _ { 2 }$ , $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ , and ${ \mathrm { G a } } _ { 2 } { \mathrm { O } } _ { 3 }$ powders for the photodegradation of PFOA under UVB irradiation $( 3 6 ~ \mathrm { W } , ~ 1 2 ~ \mathrm { W } \mathrm { m } ^ { - 2 } )$ . Considering their findings, catalysts dosage could highly affect the photocatalytic activity of semiconductors, where the orders of the efficiency at catalyst dosages of 0.1, 0.2, 0.5, and $_ { 1 \mathrm { ~ g ~ } }$ $\mathrm { L } ^ { - 1 }$ were $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } < \mathrm { I n } _ { 2 } \mathrm { O } _ { 3 } < \mathrm { T i O } _ { 2 }$ , $\mathrm { T i O } _ { 2 } < \mathrm { I n } _ { 2 } \mathrm { O } _ { 3 } < \mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ , $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 } { < } \mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } { < } \mathrm { T i O } _ { 2 }$ , and $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 } \approx \mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } < \mathrm { T i O } _ { 2 }$ , respectively. In addition, self-made $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ showed higher photocatalytic activity than commercial $\mathrm { T i O } _ { 2 }$ , $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ , and $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ catalysts. Overall, $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ or ${ \mathrm { G a } } _ { 2 } { \mathrm { O } } _ { 3 }$ has been suggested to be more promising than $\mathrm { T i O } _ { 2 }$ for the photocatalytic decomposition of PFOA in several cases [6, 8–10], but $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ and $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ could suffer from the lack of cost-effectiveness. In addition, ${ \mathrm { Z n O } }$ has been effectively used for such a purpose [11]. Notably, ${ \mathrm { Z n O } }$ is not toxic and could reap the benefits of its chemical inertness and availability [12]. Besides, its electron mobility is superior than $\mathrm { T i O } _ { 2 }$ , and its lower refractive index than $\mathrm { T i O } _ { 2 }$ offers ${ \mathrm { Z n O } }$ as a highly transparent material with good light harvest and low light scattering [13]. Furthermore, compared with $\mathrm { T i O } _ { 2 }$ , wurtzite ${ \mathrm { Z n O } }$ could take advantage of its great thermal stability even at high temperatures caused by plasma spraying [12]. Overall, ${ \mathrm { Z n O } }$ , which is considered an n-type semiconductor [14], has been used for various applications such as photocatalysis [15], solar cells [16], photoelectrochemical properties [17], and resistive sensors [18].

Despite its advantages, ${ \mathrm { Z n O } }$ has a wide band gap energy, restricting its visible light harvest. Designing and preparation of visible light-activated photocatalysts are of high interest, to maximize the use of solar power [19]. Hence, graphitic carbon nitride $( \mathrm { g } \mathrm { - C } _ { 3 } \mathrm { N } _ { 4 }$ or GCN) has been used for environmental remediation [20]. Notably, ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ is considered a cost-effective and light-responsive support semiconductor owing to the presence of various anchoring sites, unique optical properties, layered structure, and the feasibility of chemical modification of surface defects [21]. Besides, GCN has the advantages of facile synthetic process and high stability [20] and is of current interest for photocatalytic applications [22]. It has seven phases including pseudocubic $\mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ , g-o-triazine, ${ \bf { \alpha } } { \bf { { \alpha } } } { \bf { { C } } } _ { 3 } { \bf { { N } } } _ { 4 }$ , g-hheptazine, cubic $\mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ , $\mathrm { g }$ -h-triazine, and ${ \beta } – { \mathrm { C } } _ { 3 } { \mathrm { N } } _ { 4 }$ where triazine and tri-s-triazine/heptazine rings are the basic tectonic units to construct GCN allotropes [21]. Among the various methods used for the synthesis of GCN, thermal condensation is considered a cost-effective method to scale it up for commercialization in which different materials are used as GCN precursors (i.e., dicyanamide, urea, melamine, thiourea, and cyanamide) [23]. Despite its numerous advantages, bulk GCN suffers from major shortcomings including the inefficient solar spectrum harvesting and fast recombination of charge carriers, necessitating the modification of GCN to achieve high photocatalytic activity [20]. Several strategies have been used to modify the chemical and physical properties of pristine ${ \bf g } – { \bf C } _ { 3 } { \bf N } _ { 4 }$ . Element doping (metal or non-metal) is among the methods widely used to improve the photocatalytic activity of GCN [22]. The addition of citric acid (CA) to urea has been effectively used to modify GCN [24, 25]. As reported by Zhou et al. [24] and Zhu and Zhou [25], the addition of CA to urea could play an important role in the significantly improved photocatalytic activity, and CA to urea mass ratio of 0.001 yielded the best efficiency in both studies.

Overall, the application of ${ \mathrm { Z n O } }$ and $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ for PFOA photodecomposition is important, yet GCN has not been widely used for such a purpose. Hence, this study aimed to synthesize a novel hybrid photocatalyst, containing ${ \mathrm { Z n O } }$ nanoparticles and CA-modified GCN, using the mechanical milling process (as a cost-effective method used to produce different heterostructures) for the photocatalytic removal of PFOA under both UV and visible light irradiation. Importantly, to the best of our knowledge, the application of ${ \mathrm { Z n O } }$ in PFOA photodegradation under visible light irradiation has not been investigated. Various strategies are used to generate $\mathrm { S O _ { 4 } } ^ { \bullet - }$ radicals, of which peroxymonosulfate (PMS)-assisted photocatalysis has been effectively employed to increase PFOA removal over metal oxides [4, 6, 26]. Hence, PMS was used to improve PFOA removal over the optimal hybrid photocatalyst.

# 3 Results and discussion

# 3.1 Characterization of GCN

XRD patterns of bulk ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ synthesized by urea are shown in Fig. S1(a), and GCN could be evidenced by the appearance of two sharp XRD peaks at around $1 3 ^ { \circ }$ and $2 7 ^ { \circ }$ [27, 28]. The ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ was synthesized at annealing temperatures from 450 to $5 3 0 ~ ^ { \circ } \mathrm { C }$ , while the annealing time was $^ { 4 \mathrm { ~ h ~ } }$ in all cases. Notably, increasing the annealing temperature to $5 3 0 ~ ^ { \circ } \mathrm { C }$ enhanced the intensity of the peak at $\sim 2 7 ^ { \circ }$ which could be attributed to the improved crystallinity at high calcination temperatures. The peaks at $\sim 1 3 ^ { \circ }$ and $\sim 2 7 ^ { \circ }$ correspond to (100) and (002) diffraction planes, respectively, attributing to the in-planar structural packing and inter-planar stacking peaks of the aromatic system [29]. Paul et al. [30] synthesized GCN using urea at different calcination temperatures of 350, 400, 450, 500, 550, 600, and $6 5 0 ^ { \circ } \mathrm { C }$ . Considering their XRD results, raising the annealing temperature increased the intensity of the peak related to the inter-planar stacking of GCN which has been attributed to the improved crystallinity. The optimized range of annealing temperature has been reported to be $4 5 0 – 5 5 0 \ ^ { \circ } \mathrm { C }$ .

The FTIR spectra of bulk ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ synthesized by urea (Fig. S1(b)) showed three characteristic bands in all samples. The adsorption peak at $\sim 8 0 8 ~ \mathrm { c m } ^ { - 1 }$ is associated with the breathing mode of triazine units. The strong band in the range of $\sim 1 2 0 0 { - } 1 6 0 0 ~ \mathrm { c m ^ { - 1 } }$ corresponds to the stretching vibration of C-N and $\mathrm { C } { = } \mathrm { N }$ heterocycles. The wide absorption peak at $\sim 3 0 0 0 { - } 3 5 0 0 ~ \mathrm { c m ^ { - 1 } }$ is related to the stretching vibration of the terminal either $\mathrm { N } { \cdot } \mathrm { H } _ { 2 }$ or N-H and is the result of uncondensed amino groups [31, 32]. Notably, the wide absorption peak at $3 0 0 0 { - } 3 5 0 0 ~ \mathrm { c m ^ { - 1 } }$ could also be attributed to the stretching vibration of $\mathrm { O - H }$ originating from the absorbed water molecule [31]. The photo-absorption ability of bulk ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ synthesized by urea at different annealing temperatures is compared in Fig. S1(c), which shows that increasing the annealing temperature increased the photoabsorption ability. The redshift caused by increasing the annealing temperature could be attributed to the improvement of polymerization degree [33]. The band gap energies of bulk $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ synthesized by urea were calculated using the Tauc method (Fig. S1(d)), which were reduced by increasing the calcination temperature which could be attributed to the higher degree of polymerization. In addition, the formation of defects and improved polymerization could widen and narrow the band gap energy, respectively [33]. $S _ { \mathrm { B E T } }$ and pore volume of bulk ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ synthesized by urea at different annealing temperatures are presented in Table 1.

As evident, increasing the calcination temperature significantly enhanced the $S _ { \mathrm { B E T } }$ of GCN synthesized by urea which can be attributed to the improved polymerization and emission of larger amounts of gases during the condensation and polymerization processes. The presence of oxygen in urea could facilitate the formation of $\mathrm { C O } _ { 2 }$ during the polymerization process, taking into account the enlarged $S _ { \mathrm { B E T } }$ of GCN synthesized by urea [34]. Table 1 signifies that using the high calcination temperature of $5 3 0 ^ { \circ } \mathrm { C }$ remarkably increased the pore volume of GCN, consistent with the results of $S _ { \mathrm { B E T } }$ reported in the literature. For example, Paul et al. reported the $S _ { \mathrm { B E T } }$ of GCN synthesized by urea at calcination temperatures of 450, 550, and $6 5 0 ~ ^ { \circ } \mathrm { C }$ (calcination time $= 3$ h and heating rate ${ \bf \Lambda } = 2 \mathrm { \Lambda } ^ { \circ } { \bf C } \mathrm { m i n } ^ { - 1 } ,$ ) to be 37.8, 73.7, and $6 5 . 6 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$ respectively [30]. Li et al. [35] synthesized GCN using urea, where the $S _ { \mathrm { B E T } }$ of $6 3 . 4 6 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$ was obtained at $5 5 0 ^ { \circ } \mathrm { C }$ (calcination time $= 4$ h and heating rate $\ d = 2 \ ^ { \circ } \mathrm { C } \ \operatorname* { m i n } ^ { - 1 } .$ ). In another study, Xia et al. [36] synthesized GCN using urea with the $S _ { \mathrm { B E T } }$ of $1 0 8 . 8 3 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$ being obtained at $5 5 0 ^ { \circ } \mathrm { C }$ (2-h calcination time, $5 ~ { } ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 }$ heating rate). Noteworthy, a significantly high $S _ { \mathrm { B E T } }$ $( 1 2 2 . 8 2 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 } )$ was achieved at $5 3 0 ~ ^ { \circ } \mathrm { C }$ (4-h calcination time) where the heating rate was not fixed but was greater than $1 0 \ ^ { \circ } \mathbf { C } \ \operatorname* { m i n } ^ { - 1 }$ . Overall, it is concluded that the $S _ { \mathrm { B E T } }$ value strongly depends on the synthesis procedure of GCN, in terms of calcination time, calcination temperature, and heating rate.

# 3.2 Characterization of CA‑modified GCN

The optimum annealing temperature $( 5 3 0 ~ ^ { \circ } \mathrm { C } )$ was used to synthesize CA-modified GCN, while the annealing time was $^ { 4 \mathrm { h } }$ . As shown in Fig. S2(a), the XRD pattern of CA-modified GCN is identical to that of bare GCN, clarifying that the addition of CA did not significantly affect the molecular framework of bare GCN, which is consistent with other studies [24, 25]. The FTIR spectra of pristine and CA-modified GCN are compared in Fig. S2(b), where the peaks observed for CA-modified GCN are similar to those for pristine GCN which could be assigned to triazine units (1), C-N and $\mathrm { C } { = } \mathrm { N }$ heterocycles (2), and N-H, $\mathrm { N } { \cdot } \mathrm { H } _ { 2 }$ , and O-H groups (3) as discussed previously. In addition to the XRD patterns, FTIR spectra also confirm that the molecular structure of GCN is retained after CA modification. The marginal shift in the location of peaks could be attributed to element doping by CA, which will be clarified by XPS analysis in the following sections. The photo-absorption ability and band gap energy of bare GCN and CA-modified GCN are compared in Fig. S2(c), (d), respectively. Interestingly, CA-modified GCN showed a remarkably higher photo-absorption ability than bare GCN in wavelengths from 250 to $8 0 0 ~ \mathrm { { n m } }$ . Moreover, modification by CA addition significantly reduced the band gap energy of GCN from 2.69 to $2 . 3 3 \ \mathrm { e V } .$ , which could be of high importance when using GCN-based catalysts for the photocatalytic decomposition of pollutants (especially under visible light irradiation). It should be noted that CA-modified GCN showed a higher photo-absorption ability than pristine GCN in the wavelength range $3 0 0 { - } 8 0 0 ~ \mathrm { n m }$ ) in a study by Zhou et al. [24]. The significant redshift of absorption edge and reduced band gap energy could be specifically related to the modified structure by CA addition.

The XPS analysis was used to record the surface chemical composition of bare GCN and CA-modified GCN. XPS survey and high-resolution C 1s and N 1s spectra of bare GCN and CA-modified GCN are compared in Fig. S3. The similar spectra of bare GCN and CA-modified GCN signify that both samples were mainly composed of nitrogen and carbon elements [24, 25]. Notably, the minor peak located at ${ \sim } 5 3 2 \ \mathrm { e V }$ is assigned to O element originated from thermal annealing in air at high temperature [37]. As evident in Fig. S3(c), (d), both pristine and CA-modified GCN showed similar C 1s spectra, which could be divided into three peaks with different binding energies. The peak at $2 8 4 . 8 \mathrm { e V }$ of both samples can be assigned to C-C bonds of graphitic C impurities or adventitious C and $\mathrm { s p } ^ { 2 }$ -hybridized C-N, and the peaks at $2 8 8 . 4 3 \ \mathrm { e V }$ (GCN) and $2 8 8 . 3 5 ~ \mathrm { e V }$ (CA-modified GCN) could be attributed to $\mathrm { s p } ^ { 2 }$ -hybridized C bonded to N in a triazine ring $( \mathrm { N - C } = \mathrm { N } )$ ) [24, 25]. The minor peaks at $2 8 6 . 3 7 \mathrm { e V }$ (GCN) and $2 8 6 . 5 0 \ \mathrm { e V }$ (CA-modified GCN) could be assigned to either the bonds of C and amino groups $\left( \mathrm { C } \mathrm { - N H } _ { 2 } \right)$ [37] or C-OH bonding [38]. The peaks at $2 8 4 . 8 \ \mathrm { e V }$ $( 3 . 7 \% )$ and $2 8 6 . 5 0 ~ \mathrm { e V }$ $( 1 . 3 \% )$ of the CA-modified GCN sample were stronger than those of GCN sample $2 . 1 9 \%$ at $2 8 4 . 8 \mathrm { e V } .$ $0 . 9 2 \%$ at $2 8 6 . 3 7 \mathrm { e V }$ ), while the peak at $2 8 8 . 3 5 \mathrm { e V }$ $( 3 7 . 3 2 \% )$ of CA-modified GCN sample was weaker than that of GCN sample $( 3 8 . 3 8 \% )$ . As shown in Fig. S3(e), (f), N 1s spectra of bare GCN and CA-modified GCN samples were also similar, which could be divided into three major peaks with different binding energies. The main peaks at $3 9 8 . 9 1 \mathrm { e V }$ (GCN) and $3 9 8 . 8 4 \mathrm { ~ e V }$ (CA-modified GCN) are usually assigned to the $\mathrm { s p } ^ { 2 }$ -hybridized N in a triazine ring $\mathrm { ( C - N = C ) }$ ; the peaks at $4 0 0 . 1 8 \mathrm { e V }$ (GCN) and $4 0 0 . 1 4 \mathrm { e V }$ (CA-modified GCN) correspond to $\mathrm { N - C } _ { 3 }$ groups; and the peaks at $4 0 1 . 3 \mathrm { e V }$ (GCN) and $4 0 1 . 2 6 \ \mathrm { e V }$ (CA-modified GCN) correspond to the uncondensed amino groups (C-N-H) [25, 37]. Noteworthy, all three peaks at $3 9 8 . 9 1 \ \mathrm { e V }$ $( 4 1 . 5 3 \% )$ , $4 0 0 . 1 8 ~ \mathrm { e V }$ $( 8 . 9 \% )$ , and $4 0 1 . 3 \ \mathrm { e V }$ $( 6 . 3 9 \% )$ of GCN sample are stronger than those of CA-modified GCN sample at $3 9 8 . 8 4 \mathrm { e V }$ $( 4 1 . 1 5 \% )$ $4 0 0 . 1 4 \ : \mathrm { e V } \ : ( 8 . 8 1 \% )$ , and $4 0 1 . 2 6 \mathrm { e V }$ $( 6 . 0 6 \% )$ . Considering the XPS results, the C/N atomic ratios of GCN and CA-modified GCN samples were 0.73 and 0.76, respectively. Overall, no remarkable binding-energy shift was observed on C 1s and N 1s between bare GCN and CA-modified GCN samples, clarifying that CA addition did not significantly affect the dominant structure of GCN except with the incorporation of C. Although CA has been used by other researchers to modify the structure of GCN, a unique modification mechanism has not accounted for the improvement. For instance, in preparing a mixture of $2 0 \mathrm { m g }$ each of CA and urea which was heated at $5 5 0 ~ ^ { \circ } \mathrm { C }$ in the air for $^ { 4 \mathrm { h } }$ at $2 { } ^ { \circ } { \bf C } \operatorname* { m i n } ^ { - 1 }$ , Zhou et al. [24] showed that CA addition resulted in the formation of N-doped graphitic carbon-incorporated GCN from XPS results. In another research, Zhu and Zhou [25] mixed $5 0 \mathrm { m g }$ each of CA monohydrate and urea, with the mixture being heated at $5 5 0 ~ ^ { \circ } \mathrm { C }$ in the air for $^ { 4 \mathrm { h } }$ at $2 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 }$ . The XPS results showed that CA addition resulted in the formation of N-doped GCN. As evident in Fig. S4 (despite similar CA to urea ratio, annealing time and temperature, and heating rate), the XPS spectra reported by Zhou et al. [24] and Zhu and Zhou [25] are remarkably different, signifying the occurrence of different modification mechanisms although condensation is considered the dominant mechanism of the formation of GCN in the thermal annealing process. Furthermore, a semi-closed system was used to synthesize GCN in such a process. Hence, the formation of GCN using thermal annealing could be considered a non-equilibrium process in which several parameters, even the type of the crucible used for condensation, could affect the final product. Considering the XPS results reported by Zhu and Zhou [25], the C/N atomic ratios of GCN and CA-modified GCN were 1.99 and 0.92, respectively, compared with values of 0.73 and 0.76 in this research (using $1 0 ~ \mathrm { m g }$ each of CA and urea). Notably, the ratio of CA to urea in this research is similar to that used by Zhou et al. [24] and Zhu and Zhou [25], but the amount of urea $( 1 0 \ \mathrm { g } )$ is considerably lower than that used by Zhou et al. $( 2 0 \ \mathrm { g } )$ [24] and Zhu and Zhou $( 5 0 \ \mathrm { g } )$ [25]. In addition, the heating rate $( > 1 0 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 } )$ ) and annealing temperature $( 5 3 0 ^ { \circ } \mathrm { C } )$ were different from those used by Zhou et al. [24] and Zhu and Zhou [25] (annealing temperature $= 5 5 0 ~ ^ { \circ } \mathrm { C }$ , heating rate ${ \bf \Lambda } = 2 \mathrm { ~ } ^ { \circ } \mathrm { C ~ m i n ^ { - 1 } }$ ). Hence, it can be concluded that the modification mechanism by CA addition to urea strongly relies on the synthetic process of GCN.

As shown in Fig.  S5, CA-modified GCN showed extremely lower photoluminescence (PL) intensity than pristine GCN which could be assigned to the introduction of the C element to the GNC framework [39]. Meanwhile, the emission peak maximum moved from 459 (pristine GCN) to $4 6 7 \ \mathrm { n m }$ (CA-modified GCN), exhibiting a redshift which is consistent with the redshift of the absorption edge of DRS spectra (Fig. S2(c)), and could be attributed to C doping. It has been suggested that attaching aromatic heterocycles and replacement of N with C in triazine units may promote the delocalization of $\mathrm { e ^ { - } }$ in the $\pi$ -conjugation system, improving light harvest and boosting transfer and separation of charge carriers [40]. Overall, the lower the PL intensity, the higher the efficiency of charge carrier transfer and a higher photocatalytic activity could be expected [19]. Hence, CA-modified GCN with its higher photo-absorption ability, lower band gap energy, and lower recombination rate of charge carriers than those obtained by bare GCN was used to synthesize ZnO-CA-modified GCN nanocomposites for the effective PFOA elimination.

The SEM images of pristine and CA-modified GCN at different magnifications of 10,000, 40,000 and 70,000 (Fig. S6) showed that both samples were fluffy and contained several thin sheets. By using urea as the precursor of GCN, a large amount of gas is released during the annealing process, acting as a pore forming agent and favoring the formation of $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ with a large specific surface area and fluffy nanostructure [36]. Hence, the production of ultrathin sheets in bare GCN using the facile one-step synthetic process could be responsible for the outstanding $S _ { \mathrm { B E T } }$ of $1 2 3 ~ \mathrm { m } ^ { 2 } ~ \mathrm { g } ^ { - 1 }$ . To clarify the distribution of elements in pristine and CA-modified GCN, EDX analysis (Fig. S7) showed that C and N elements were uniformly distributed in both samples. Notably, the Al element was also detected since the samples were mounted on a piece of Al foil. The C/N atomic ratio of bare and CA-modified GCN was also measured by EDX analysis at 30 different points (Fig. S8), with a higher C/N atomic ratio of CA-modified GCN (0.65) than that of pristine GCN (0.61). The same trend was observed by the results of XPS analysis though with different corresponding values (0.76 and 0.73, respectively), which could be related to the higher accuracy of XPS than EDX analysis.

# 3.3 Synthesis of ZnO@CA‑modified GCN nanocomposites

The XRD patterns of ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposites and ball-milled ${ \mathrm { Z n O } }$ nanoparticles were compared (Fig. 1a) which presented no significant difference and followed the pattern of wurtzite ${ \mathrm { Z n O } }$ as the main phase in all samples. Notably, the main peak of CA-modified GCN (around $2 7 ^ { \circ }$ ) was not observed in any of the nanocomposites. Wang et al. synthesized ${ \mathrm { Z n O } }$ hybridized with GCN using different mass ratios of GCN to ${ \mathrm { Z n O } }$ ( $1 \%$ , $2 \%$ , $3 \%$ , $4 \%$ , $6 \%$ , and $8 \%$ ), where the main peak of GCN was observed only in samples with high mass ratio of $\mathrm { G C N } / \mathrm { Z n O }$ $( \geq 4 \% )$ [41]. More recently, in synthesizing hybrid ZnO-GCN using ball milling with different GCN/ZnO mass ratios of $5 \%$ , $1 0 \%$ , $1 5 \%$ , and $2 0 \%$ , Chen et al. [42] did not detect the main peak of GCN. They suggested that vigorous mechanical force initiated by the milling process could result in the uniform distribution of GCN on the surface of ${ \mathrm { Z n O } }$ particles, which could not be easily achieved by other synthetic techniques. Hence, the disappearance of the main peak of GCN, even at the high mass ratio of $\mathrm { G C N / Z n O }$ (i.e., $2 0 \%$ ), was attributed to the mechanical milling process to produce hybrid structures [42]. Meanwhile, the main peak of GCN has not been detected in other studies (GCN/ZnO nanocomposites), due to the high dispersion of GCN [43].

The significant redshift of absorption edge and reduced band gap energy of nanocomposites could be specifically related to the formation of a hybrid nanostructured material composed of ${ \mathrm { Z n O } }$ nanoparticles and CA-modified GCN.

The SEM morphology of ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite $( 5 \mathrm { ~ w t \% ~ } )$ at different magnifications (Fig. 2) demonstrates that ${ \mathrm { Z n O } }$ nanoparticles were extensively embedded in the sheet structures. The formation of a hybrid nanostructure could be evidenced by SEM images at high magnifications (Fig. 2c).

The EDX analysis was performed to study the distribution of elements in the hybrid nanostructured material produced by mixing $5 0 ~ \mathrm { m g }$ of CA-modified GCN and $_ { 1 \mathrm { ~ g ~ } }$ of ${ \mathrm { Z n O } }$ nanoparticles. Notably, EDX mapping analysis was carried out in two different areas (Fig. S9), which shows that the graphitic phase is mainly composed of C (rather than N). Unexpectedly, the C/N atomic ratio throughout the analyzed areas was 12.6 and 5, offering the possibility of nitrogen removal from the GCN framework during the 5-h ball milling process followed by the annealing treatment at $4 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ . Nitrogen removal from the GCN framework has also been reported by Paul et al. [46] in the synthesis of $Z _ { \mathrm { { n O } } } .$ - modified GCN composite for the photocatalytic degradation of methylene blue, whereas zinc carbonate basic dehydrate $( [ \mathrm { Z n C O _ { 3 } } ] _ { 2 } . [ \mathrm { Z n ( O H ) _ { 2 } } ] _ { 3 } )$ and urea were used as ${ \mathrm { Z n O } }$ and GCN precursors, respectively. The C/N atomic ratio of pure GCN and GCN- ${ \cdot } Z \mathrm { n O }$ composite (0.4 mmol $[ Z \mathrm { n C O } _ { 3 } ] _ { 2 }$ . $[ Z \mathrm { n ( O H ) } _ { 2 } ] _ { 3 }$ in $1 0 \ : \mathrm { g }$ of urea) was 0.85 and 1.5, consecutively. Deamination during thermal polymerization, caused by the addition of $\mathrm { [ Z n C O _ { 3 } ] _ { 2 } . [ Z n ( O H ) _ { 2 } ] _ { 3 } }$ , has been accounted for the probable nitrogen removal from the GCN framework. The creation of nitrogen vacancy has also been reported by Lee et al. [47], where the post-solvothermal treatment of $\mathbf { M } \mathbf { g }$ -doped GCN resulted in the production of nitrogen vacancy-rich GCN which has been related to the formation of numerous amine sites in GCN during urea polycondensation with the addition of $\mathbf { M g }$ precursor. Our findings confirm that even using chemically inert ${ \mathrm { Z n O } }$ nanoparticles, unlike $\mathrm { [ Z n C O _ { 3 } ] _ { 2 } . [ Z n ( O H ) _ { 2 } ] _ { 3 } }$ which was used as the ${ \mathrm { Z n O } }$ precursor [46], could result in nitrogen removal from the GCN framework during the milling process. Hence, the milling process in the presence of ${ \mathrm { Z n O } }$ nanoparticles followed by annealing could facilitate nitrogen removal due to the probably damaged GCN framework, although further research is required to clarify the mechanism. Although nitrogen removal was not expected, point-defect engineering by the creation of nitrogen vacancy is considered a promising approach to improve the photocatalytic activity of GCN by mitigating the recombination rate of electron-hole pairs [47].

Some CA-modified GCN powder was milled for $^ { 5 \mathrm { h } }$ and annealed at $4 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ and then analyzed by XPS to clarify the effect of ball milling on the stability of CA-modified GCN. XPS survey and high-resolution C 1s and N 1s spectra of CA-modified and ball-milled CA-modified GCN are compared (Fig. S10), with no significant difference between samples. The C/N atomic ratio of CA-modified GCN (0.76) and ball-milled CA-modified GCN (0.84) was similar, suggesting that the milling process (for $5 \mathrm { h }$ ) followed by annealing treatment $4 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ ) did not remarkably affect the chemical composition of CA-modified GCN (without the addition of ${ \mathrm { Z n O } }$ nanoparticles). Hence, nitrogen removal from the GCN framework could be mainly related to the presence of ${ \mathrm { Z n O } }$ nanoparticles in the milling process followed by the annealing treatment. Although ball milling was performed at room temperature, the temperature inside the grinding jar could increase considerably during milling due to the frequent and severe collision of zirconia balls.

For screening, the performance of the synthesized nanocomposites for PFOA elimination under visible light irradiation was compared to that of pure ball-milled ${ \mathrm { Z n O } }$ nanoparticles (for control) and bare CA-modified GCN. As shown in Fig. S11, the synthesized nanocomposites remarkably improved PFOA removal, whereas CA-modified GCN was approximately inert to PFOA degradation. As mentioned previously, bulk GCN could suffer from inefficient solar spectrum harvest and fast recombination of charge carriers [20]. Although GCN was significantly modified by CA addition, it was not efficient for PFOA removal due to the weak oxidation potential of $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ which is a more suitable photocatalyst for reduction applications (Fig. S12). Notably, compared with pure ball-milled ${ \mathrm { Z n O } }$ nanoparticles, ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite produced by the addition of $5 0 ~ \mathrm { m g }$ of CA-modified GCN to $_ { 1 \mathrm { ~ g ~ } }$ of ${ \mathrm { Z n O } }$ nanoparticles showed the highest efficiency which was attributed to its superior photo-absorption ability and lower recombination rate of charge carriers. To confirm the promising performance of ${ \mathrm { Z n O } }$ for PFOA removal under visible light irradiation, the photocatalytic activities of initial ${ \mathrm { Z n O } }$ nanoparticles, $\mathrm { T i O } _ { 2 } \mathrm { P } 2 5$ , and $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ nanoparticles were compared (Fig. S13). ${ \mathrm { Z n O } }$ nanoparticles showed significantly higher performance than $\mathrm { T i O } _ { 2 }$ P25 and $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ , inducing PFOA removal of $6 4 \%$ , $1 0 \%$ , and $5 \%$ , respectively, within $^ { 6 \mathrm { h } }$ under visible light irradiation.

The energy of photons was calculated by Eq. (2) [4]:

$$
E _ { 0 } = h \nu = \frac { h c } { \lambda }
$$

where $E _ { 0 } , \ h , \ c .$ , and $\lambda$ are the energy of one photon, Plank’s constant (i.e., $6 . 6 3 \times 1 0 ^ { - 3 4 }$ Js), light speed (i.e., $3 \times 1 0 ^ { 8 } \mathrm { m ~ s ^ { - 1 } }$ ), and wavelength, respectively. By considering the minimum wavelength of visible light (i.e., $4 0 0 \mathrm { n m }$ ), $E _ { 0 }$ is $5 . 0 \times 1 0 ^ { - 1 9 } \mathrm { J }$ . The band gap energy of initial ${ \mathrm { Z n O } }$ nanoparticles is $\sim 3 . 2 3 \ \mathrm { e V }$ $( \sim 5 . 2 \times 1 0 ^ { - 1 9 } \mathrm { ~ J } )$ ) which is very close to $E _ { 0 }$ . Therefore, using a powerful visible light source as in this study could provide photons with sufficient energy to activate ${ \mathrm { Z n O } }$ even under visible light illumination despite its wide band gap energy. The same finding has been reported by $\mathrm { X u }$ et al. [4] using $\mathrm { T i O } _ { 2 }$ under visible light irradiation.

The photocatalytic activity of initial ${ \mathrm { Z n O } }$ nanoparticles was also compared to that of $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN (5 $\mathrm { w t } \%$ ) nanocomposite under UV irradiation (Fig. 5c, d). As evident, the synthesized nanocomposite showed superior efficiency than initial ${ \mathrm { Z n O } }$ nanoparticles for PFOA elimination which could be related to the formation of a potential heterojunction in the synthesized nanocomposite. The large band gap energy of the synthesized nanocomposite necessitates using UV irradiation to produce sufficient photons. Overall, ${ \mathrm { Z n O } } @$ CA-modified GCN $( 5 \mathrm { w t \% } )$ nanocomposite is considered highly promising for PFOA removal especially under UV irradiation.

# 3.4.1 Effect of PMS on PFOA elimination

$Z _ { \mathrm { n O } } @ { \mathrm { C A } } .$ -modified GCN nanocomposite $( 5 \mathrm { ~ w t \% ~ } )$ with its superior efficiency than other nanocomposites was used to evaluate the effect of PMS addition on PFOA removal. As shown in Fig. S14, the addition of PMS $( 0 . 2 7 \ \mathrm { g } \ \mathrm { L } ^ { - 1 }$ and $0 . 5 3 \ \mathrm { g } \ L ^ { - 1 } )$ yielded similar PFOA removal, whereas using the high concentration of $1 . 0 6 \ \mathrm { g ~ L ^ { - 1 } }$ remarkably reduced PFOA removal. The cleavage of PMS could result in the production of $\mathrm { S O _ { 4 } } ^ { \bullet - }$ and $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ radicals (Eq. (3)) [51]:

$$
H S O _ { 5 } ^ { - } + h \upsilon  S O _ { 4 } ^ { - } + O H ^ { \bullet }
$$

However, on the downside, high concentrations of PMS could quench the photocatalytic activity due to the selfcombination reaction of $\mathrm { S O _ { 4 } } ^ { \bullet - }$ radicals, leading to the production of $\mathrm { S } _ { 2 } \mathrm { O } _ { 8 } { } ^ { 2 - }$ , or some other side reactions [52]. Furthermore, high concentrations of PMS could facilitate ${ \mathrm { Z n O } }$ corrosion [26]. The apparent rate constants of PFOA elimination by the addition of PMS (0.27 and $0 . 5 3 \ \mathrm { g \ L ^ { - 1 } } ,$ were also similar. However, as evident in Fig. S14(a), PFOA removal at the initial stages (first $4 0 \mathrm { { m i n } } ,$ ) by using $0 . 5 3 \mathrm { g L } ^ { - 1 }$ PMS was remarkably higher than that obtained by $0 . 2 7 \ \mathrm { g } \mathrm { L } ^ { - 1 }$

PMS. Hence, the PMS concentration of $0 . 5 3 \mathrm { ~ g ~ L ^ { - 1 } }$ was chosen for further experiments.

Compared with UV irradiation, the stronger effect of ${ \mathrm { Z n O } }$ structural changes/defects from milling on PFOA removal under visible light irradiation could be related to the wide band gap of ${ \mathrm { Z n O } }$ which is not a visible light-activated semiconductor.

Overall, the synthesis of an efficient hybrid photocatalyst for PFOA removal is of high importance. Firstly, this hybrid nanomaterial was produced by ${ \mathrm { Z n O } }$ and ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ which are both among the most economical semiconductors used for photocatalytic applications. Secondly, ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite was highly promising for PFOA elimination under visible light irradiation (even without PMS), compared to $\mathrm { T i O } _ { 2 }$ [4, 8, 9]. More importantly, $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ with its certain solar light absorption is not efficient for PFOA removal under visible light irradiation (without PMS) which has been attributed to its fast recombination rate of charge carriers [5]. Although $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ has been introduced to be very promising for PFOA degradation, its application was restricted to UV irradiation due to its very large band gap energy. Hence, it was not efficient for PFOA removal under visible light irradiation without the addition of PMS [6]. The performance of $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposite for PFOA elimination is compared to that of main oxide semiconductors (Table 2). By far, ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite showed a higher efficiency than other oxide semiconductors under visible light irradiation (with and without PMS). The superior efficiency of the synthesized nanocomposite over $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ under visible light irradiation was predictable due to the large band gap energy of $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ [3], restricting its visible light harvest, but the findings were more exciting where the performance of the hybrid photocatalyst was considerably higher than that of $\mathrm { T i O } _ { 2 }$ . Notably, the band gap energy of ${ \mathrm { Z n O } }$ and $\mathrm { T i O } _ { 2 }$ is similar, but ${ \mathrm { Z n O } }$ could take advantage of its higher visible light harvest than $\mathrm { T i O } _ { 2 }$ [12], making ${ \mathrm { Z n O } }$ more attractive than $\mathrm { T i O } _ { 2 }$ for photocatalytic applications under visible light irradiation. Under UV irradiation, the synthesized nanocomposite again showed good performance compared with other main oxide semiconductors, but PMS addition can make several oxide semiconductors more proficient than the ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite for PFOA elimination. Meanwhile, catalyst morphology can highly affect the photocatalytic activity, e.g., different $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ morphologies (nanostructures) showed significantly different performances (Table 2). Overall, considering cost-effectiveness and efficiency, ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite is promising for PFOA removal under UV and especially visible light irradiation. Further improvement of the performance of these nanocomposites should be studied in future by using different ${ \mathrm { Z n O } }$ morphologies and crystal structures.

# 3.4.2 Probable mechanism of photocatalytic degradation of PFOA

The main active species responsible for the photocatalytic degradation of PFOA over the $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposite were studied by the addition of BQ, BuOH, and EDTA- $\mathbf { N a } _ { 2 }$ to the initial PFOA solution to scavenge ${ \mathrm { O } } _ { 2 } ^ { \bullet - }$ , $\mathrm { \bullet _ { O H } }$ , and the photogenerated holes $\left( \mathrm { h } ^ { + } \right)$ , respectively, and the results are shown in Fig. 7a.

The performance of ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite was suppressed by adding BQ and EDTA- $\mathbf { \cdot N a } _ { 2 }$ , signifying the vital role of $\mathrm { O } _ { 2 } ^ { \bullet - }$ and $\mathrm { h ^ { + } }$ in PFOA removal. In addition to $\mathrm { O } _ { 2 } ^ { \bullet - }$ and $\mathrm { h ^ { + } }$ , sulfate radicals played an important role in PFOA elimination over the hybrid photocatalyst as confirmed previously (Fig. 6). The probable production of sulfate radicals has accounted for the considerably improved PFOA degradation in PMS-assisted photocatalysis in several studies [4, 6, 26]. Unlike BQ and EDTA- $\mathbf { \cdot N a } _ { 2 }$ , $\mathrm { \ t { - } B u O H }$ did not quench PFOA removal over the hybrid catalyst. Noteworthy, $\mathrm { \ t { - } B u O H }$ could boost PFOA decomposition due to its less polarity than water, resulting in the higher reactivity of superoxide radicals [53].

It is suggested that PFOA photodegradation over the $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposite follows a stepwise manner which has been reported in other studies [4, 6, 11]. Considering our findings, the primary PFOA decomposition mechanism could be explained by the following stages. Firstly, PFOA could dissociate to become an anionic compound $( \mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { C O O ^ { - } } )$ and adsorbed on the surface of the hybrid photocatalyst as shown in Eq. (4) [54]:

$$
C _ { 7 } F _ { 1 5 } C O O H + H _ { 2 } O  C _ { 7 } F _ { 1 5 } C O O ^ { - } + H _ { 3 } O ^ { + }
$$

$\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { C O O ^ { - } }$ could react with $\mathrm { h ^ { + } }$ and/or $\mathrm { S O _ { 4 } } ^ { \bullet - }$ to generate $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { C O O } ^ { \bullet }$ (perfluoroperoxy radicals) according to Eqs. (5) [11] and (6) [55], respectively:

$$
h ^ { + } + C _ { 7 } F _ { 1 5 } C O O ^ { - }  C _ { 7 } F _ { 1 5 } C O ^ { * }
$$

$$
S O _ { 4 } ^ { - - } + C _ { 7 } F _ { 1 5 } C O O ^ { - }  C _ { 7 } F _ { 1 5 } C O O ^ { - } + S O _ { 4 } ^ { 2 - }
$$

Notably, the photogenerated holes could drive the oxidation of water, leading to the production of $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ radicals, and the photogenerated electrons could react with ${ \mathrm { H S O } } _ { 5 } { } ^ { - }$ , enabling the production of both $\mathrm { S O _ { 4 } } ^ { \bullet - }$ and $\mathrm { \bullet _ { O H } }$ radicals (Eq. (3)).

After the production of $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { C O O } ^ { \bullet }$ , the Kolbe decarboxylation (by the collapse of C-C bonds between $\mathrm { C } _ { 7 } \mathrm { F _ { 1 5 } } ^ { - }$ and $- \mathrm { C O O ^ { \bullet } } )$ could result in the formation of $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } { } ^ { \bullet }$ (perfluoroalkyl radicals), as shown in Eq. (7) [4, 56]:

$$
C _ { 7 } F _ { 1 5 } C O O ^ { * }  C O _ { 2 } + C _ { 7 } F _ { 1 5 } ^ { * }
$$

Perfluoroalkyl radicals could also be produced in the presence of superoxide radicals [6]:

$$
O _ { 2 } ^ { * - } + C _ { 7 } F _ { 1 5 } C O O H  C O _ { 2 } + C _ { 7 } F _ { 1 5 } \nonumber ^ { * }
$$

Then, $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } { } ^ { \bullet }$ could react with $\mathrm { H } _ { 2 } \mathrm { O }$ , generating $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { O H }$ according to Eq. (9) [4]:

$$
H _ { 2 } O + C _ { 7 } F _ { 1 5 } \cdot  C _ { 7 } F _ { 1 5 } O H + H ^ { + }
$$

The conversion of $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { O H }$ to $\mathrm { C } _ { 6 } \mathrm { F } _ { 1 3 } \mathrm { C O F }$ , due to the instability of $\mathrm { C } _ { 7 } \mathrm { F } _ { 1 5 } \mathrm { O H }$ , followed by hydrolysis could finally yield $\mathrm { C } _ { 6 } \mathrm { F } _ { 1 3 } \mathrm { C O O H }$ (PFHpA) as shown in Eqs. (10) and (11), respectively [11, 57]:

$$
C _ { 7 } F _ { 1 5 } O H  F ^ { - } + H ^ { + } + C _ { 6 } F _ { 1 3 } C O F
$$

$$
H _ { 2 } O + C _ { 6 } F _ { 1 3 } C O F  2 H ^ { + } + F ^ { - } + C _ { 6 } F _ { 1 3 } C O O ^ { - }
$$

Other shorter-chain PFAS including PFHxA, PFPeA, PFBA, PFPrA, and TFA could be produced during the process. It has been suggested that PFOA could be thoroughly mineralized in such a stepwise manner to generate fluoride ions and $\mathrm { C O } _ { 2 }$ as the final products [4].

The interfacial contact of at least two semiconductors could result in the construction of a heterostructure, facilitating the effective separation of charge carriers [58]. The VB of CA-modified GCN (before mechanical milling) and the VB of initial ${ \mathrm { Z n O } }$ nanoparticles (before mechanical milling) are compared in Fig. 7b. As evident, the VB of initial ${ \mathrm { Z n O } }$ nanoparticles seems to be lower than that of CA-modified GCN. It should be noted that the band structure of ${ \mathrm { Z n O } }$ nanoparticles and CA-modified GCN could vary by the ball milling process. Noteworthy, the color of ${ \mathrm { Z n O } }$ changed from white to yellowish after the milling process, leading to a decrease of the band gap energy from 3.23 (initial ${ \mathrm { Z n O } }$ nanoparticles) to $3 . 0 7 \mathrm { e V }$ (ball-milled ${ \mathrm { Z n O } }$ nanoparticles). For CA-modified GCN, its nitrogen content was significantly reduced after the milling process, leading to the probable change of VB and CB positions. Overall, it is not accurate to consider the VB and CB positions of CA-modified GCN and initial ${ \mathrm { Z n O } }$ nanoparticles (before milling) to infer the mechanism of the separation of charge carriers in the hybrid photocatalyst produced after milling. However, by considering the probable positions of VB and CB of CA-modified GCN and ${ \mathrm { Z n O } }$ (in the synthesized nanocomposite), the schematic of the possible mechanisms of the separation of charge carriers (type I and type II) is provided in Fig. 7c. In both mechanisms, the transfer of the photogenerated holes from VB of ${ \mathrm { Z n O } }$ to VB of CA-modified GCN is required, which could not be expected due to some reasons. Importantly, the photogenerated holes were considered among the main active species responsible for PFOA removal over the synthesized nanocomposite under UV irradiation (Fig. 7a). Meanwhile, CA-modified GCN with/without PMS addition was efficient for PFOA elimination under visible light irradiation (Figs. S11 and S16), whereas ball-milled ${ \mathrm { Z n O } }$ nanoparticles were efficient for PFOA removal under UV and visible light irradiation (Fig. 6). The hybrid photocatalyst produced by the addition of $5 0 \mathrm { m g }$ of CA-modified GCN to $_ { 1 \mathrm { ~ g ~ } }$ of ${ \mathrm { Z n O } }$ nanoparticles showed promising performance where the apparent rate constant of PFOA removal significantly increased from 0.097 (ball-milled ${ \mathrm { Z n O } }$ nanoparticles) to $0 . 4 6 8 \mathrm { h } ^ { - 1 }$ $\mathrm { \ Z n O } @ \mathrm { C A }$ -modified GCN nanocomposite) and from 0.046 (ball-milled ${ \mathrm { Z n O } }$ nanoparticles) to $0 . 4 4 7 ~ \mathrm { h } ^ { - 1 }$ $Z \mathrm { n O } @$ CA-modified GCN nanocomposite) under UV and visible light irradiation, respectively. Determination of VB and CB positions of ${ \mathrm { Z n O } }$ and nitrogen vacancy-rich CAmodified GCN, which are essential to infer the mechanism of the separation of photogenerated $\mathrm { e ^ { - } / h ^ { + } }$ pairs, needs further deep investigations. However, considering our findings, the probable separation mechanism of charge carriers is estimated to follow an S-scheme heterojunction rather than type I and type II heterojunctions (Fig. 7c). The formation of S-scheme heterojunction has been recently reported when using numerous hybrid photocatalysts composed of ${ \mathrm { Z n O } }$ and ${ \bf g } – { \bf C } _ { 3 } { \bf N } _ { 4 }$ [59–62]. Noteworthy, S-scheme heterojunctions can take advantage of the simultaneous effects of reduced recombination rate of charge carriers and retained redox potential of the photogenerated electrons and holes [59, 60]; and they are generally composed of two n-type semiconductors, representing oxidation and reduction photocatalysts [63]. Both ${ \mathrm { Z n O } }$ [14] and ${ \bf g } { \bf - C } _ { 3 } { \bf N } _ { 4 }$ [22] are among n-type semiconductors. In the S-scheme heterojunction, an internal electric field is generated between semiconductors after their contact [61, 62]. Then, the photogenerated electrons of the oxidation photocatalyst are combined with the photogenerated holes of the reduction photocatalyst, retarding the recombination of charge carriers itself [62]. To show the contact between ${ \mathrm { Z n O } }$ nanoparticles and the graphitic phase, the TEM image and EDX mapping analysis of the hybrid photocatalyst are provided in Fig. 8.

For control, $Z _ { \mathrm { n O } } @ \mathrm { G C N }$ nanocomposite $( 5 \mathrm { w t } \% )$ ) was also produced by mixing $5 0 \mathrm { m g }$ of GCN and $1 \mathrm { g }$ of ${ \mathrm { Z n O } }$ nanoparticles, which was milled for $^ { 5 \mathrm { h } }$ and annealed at $4 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { ~ h ~ } }$ . The efficiencies of bare GCN, $Z _ { \mathrm { n O } } @ \mathrm { G C N }$ nanocomposite $( 5 \mathrm { w t \% } )$ , and ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite $( 5 \mathrm { ~ w t \% ~ } )$ for PFOA removal under visible light irradiation are compared (Fig. S17). The bare GCN was ineffective for PFOA removal, clarifying that neither degradation nor adsorption occurred on GCN surface. The same result was also observed for CA-modified GCN (Figs. S11 and S16). In addition, ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite (5 $\mathrm { w t } \%$ ) was more effective than $Z _ { \mathrm { n O } } @ \mathrm { G C N }$ nanocomposite $( 5 \mathrm { w t \% } )$ for PFOA elimination under visible light irradiation that was related to the superior properties of CA-modified GCN than GCN. The $S _ { \mathrm { B E T } }$ of the initial ${ \mathrm { Z n O } }$ nanoparticles and ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite $( 5 \mathrm { \ w t \% } )$ ) is compared in Table 3.

The significantly reduced $S _ { \mathrm { B E T } }$ of $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposite $( 5 \mathrm { \ w t \% } )$ than initial ${ \mathrm { Z n O } }$ nanoparticles was related to the milling process used to synthesize the nanocomposite, resulting in the compression of particles. PFOA removal over initial ${ \mathrm { Z n O } }$ nanoparticles and ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite $( 5 \mathrm { \ w t \% } )$ was investigated under dark condition. As shown in Fig. S18, the ratio of $C / C _ { 0 }$ reduced considerably over both samples, signifying the high adsorption of PFOA on both ${ \mathrm { Z n O } }$ and ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposite $( 5 \mathrm { \ w t } \% )$ . Besides, the addition of CA-modified GCN to ${ \mathrm { Z n O } }$ did not remarkably affect the amount of PFOA adsorption. Wu et al. [11] also showed that the addition of reduced graphene oxide (0.2–2 $\mathrm { w t } \%$ ) to ${ \mathrm { Z n O } }$ did not considerably affect PFOA adsorption; however, the amount of PFOA adsorption on the surface of the photocatalysts $( 8 . 1 \mathrm { - } 1 0 . 2 \% )$ is remarkably lower than that observed in this research. It could be related to the different experimental conditions (catalyst dosage, initial PFOA concentration) and using catalysts with different morphology, particle size, specific surface area, and surface properties.

By comparing the experiments carried out in the dark and under light irradiation, it is concluded that PFOA adsorption on the surface of ${ \mathrm { Z n O } }$ nanoparticles and nanocomposites played the dominant role in total PFOA removal under light irradiation. Noteworthy, adsorption has been considered an unavoidable topic in photocatalytic experiments [64]. Although there was not a significant difference between the amount of PFOA removal over initial ${ \mathrm { Z n O } }$ nanoparticles and $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposite $( 5 \mathrm { w t \% } )$ under dark condition, the amount of PFOA elimination over these photocatalysts was considerably different under visible light irradiation especially at the initial stages (Fig. 5a) and under UV irradiation (Fig. 5c). Besides, the efficiency of ballmilled ${ \mathrm { Z n O } }$ and $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposite $( 5 \mathrm { ~ w t \% ~ } )$ for PFOA elimination was significantly different under UV and visible irradiation (Fig. 6). The reason of such a significant difference should be further studied, but likely related to the synergy of high adsorption and photocatalysis of PFOA over the synthesized hybrid nanocomposite. Notably, it has been suggested that such a synergy could improve the efficiency of pollutant elimination [65].

Interestingly, PFOA removal over initial ${ \mathrm { Z n O } }$ nanoparticles in the dark (Fig. S18) was higher than that under UV irradiation (Fig. 5). The water temperature could remarkably affect PFOA removal. For instance, Wu et al. [64] evaluated the effect of temperature on PFOA degradation by ${ \mathrm { Z n O } }$ assisted-photocatalytic ozonation, where the minor increase of temperature from 298 to $3 0 8 ~ \mathrm { K }$ markedly reduced PFOA removal from 70.9 to $5 2 . 9 \%$ in $^ { 4 \mathrm { ~ h ~ } }$ (under UV irradiation). Wu et al. [11] studied the effect of temperature on PFOA decomposition using persulfate-assisted photocatalytic ozonation over ${ \mathrm { Z n O } }$ -reduced graphene oxide, where increasing the temperature from 298 to $3 1 8 \ \mathrm { K }$ reduced PFOA elimination from 99.2 to $8 7 . 1 \%$ in $^ { 4 \mathrm { h } }$ under UV. It has been stated that the adsorption capacity of ${ \mathrm { Z n O } }$ could be reduced at high temperatures [64]. Therefore, the heat input from light irradiation to the solution could decrease PFOA adsorption on ${ \mathrm { Z n O } }$ surface, subsequently reducing its efficiency for PFOA removal under light irradiation. In addition to the effect of temperature, the mechanism of adsorption in the dark could be different from that under light irradiation. The determination of the mechanism of adsorption and the proportion of adsorption in total PFOA removal over ${ \mathrm { Z n O } }$ nanocomposite under light irradiation should be further studied by experiments at constant temperatures over long reaction time to reach the adsorption-desorption equilibrium.

# 4 Conclusions

The removal of PFOA as one of the most persistent organic pollutants has been studied using ${ \mathrm { Z n O } }$ , GCN, and ${ \mathrm { Z n O } } @$ CA-modified GCN nanocomposites, under both UV and visible irradiation. ${ \mathrm { Z n O } }$ nanoparticles showed promising PFOA removal of up to $6 4 \%$ within $^ { 6 \mathrm { ~ h ~ } }$ of visible light irradiation, which is significantly better than $\mathrm { T i O } _ { 2 }$ P25 and $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 }$ nanoparticles with PFOA elimination up to $1 0 \%$ and $5 \%$ , respectively. CA was effectively used to modify ${ \bf g } – { \bf C } _ { 3 } { \bf N } _ { 4 }$ synthesized by thermal condensation at $5 3 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 4 \mathrm { ~ h ~ } }$ . Importantly, PFOA removal was not effective by CAmodified GCN but was substantially improved over the $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposites under visible light irradiation, where a remarkable amount of nitrogen vacancy was introduced in the GCN framework. In addition, the optimal hybrid photocatalyst produced by mixing $5 0 \mathrm { m g }$ of CA-modified GCN with $1 \mathrm { g }$ of ${ \mathrm { Z n O } }$ nanoparticles showed a significantly higher efficiency $\left( k = 0 . 4 6 8  \ \mathrm { h } ^ { - 1 } \right)$ ) than pure ball-milled ${ \mathrm { Z n O } }$ nanoparticles $\left( k = 0 . 0 9 7 \mathrm { h } ^ { - 1 } \right)$ ) within $^ { 2 \mathrm { h } }$ of UV irradiation, which could be explained by the formation of a probable S-scheme heterojunction. Furthermore, the addition of $0 . 5 3 \ \mathrm { g } \ L ^ { - 1 }$ PMS considerably improved PFOA removal under both UV and visible irradiation, confirming the vital role played by sulfate radicals in PFOA removal. In comparing the results between the dark and under light irradiation, it can be concluded that the adsorption of PFOA over ${ \mathrm { Z n O } }$ surface played a dominant role, surpassing photodegradation, in PFOA elimination under light irradiation. Therefore, $Z _ { \mathrm { n O } } @ { \mathrm { C A } }$ -modified GCN nanocomposites could effectively facilitate the photocatalytic degradation of PFOA by PMS addition or could function as effective adsorbents for PFOA removal in the absence of light.
