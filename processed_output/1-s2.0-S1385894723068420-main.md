# . Introduction

Electrochemical advanced oxidation processes have proven effective in eliminating non-biodegradable pollutants from wastewater [13]. The application of electrochemical oxidation with boron-doped diamond anodes (EO-BDD) to treat nitrogen-containing organic pollutants in wastewater, such as pharmaceuticals, dyes, food products, and pesticides, has attracted interest in recent years. Other advanced oxidation processes (AOPs) that count on similar principles of oxidation, i.e., the in-situ generation of hydroxyl radicals or other reactive oxygen species, such as photocatalysis, have been extensively applied for the same purpose [4,5]. Previous research shows that ammonia/ammonium $\mathrm { ( N H _ { 3 } / N H _ { 4 } ^ { + } ) }$ , nitrogen gas $\left( \mathrm { N } _ { 2 } \right)$ , and nitrate $\left( \mathrm { N O } _ { 3 } ^ { - } \right)$ invariably appear as the major nitrogen products of nitrogenous organic pollutants degradation using EO-BDD and other AOPs. The aqueous products $\mathrm { N H } _ { 3 } / \mathrm { N H } _ { 4 } ^ { + }$ and $\mathrm { N O } _ { 3 } ^ { - }$ are of particular concern because they can harm aquatic life when discharged into the environment above regulatory limits. Moreover, the possibility of generating nitrogen oxides rather than $\Nu _ { 2 }$ as gaseous products should be carefully assessed [6,7].

Understanding the distribution of these N-products in EO-BDD and, more broadly, AOPs is essential to minimise the release of harmful products upon degradation of nitrogenous organic pollutants. To date, the available literature on other AOPs (e.g., $\mathrm { T i O _ { 2 } }$ photocatalysis and ozone treatment) reflects the efforts in advancing this understanding, providing valuable lessons related to organic nitrogen degradation via reactive oxygen species. In these studies, common factors that arguably influence the fate of nitrogen in oxidative degradation processes are the pH and the structure of the parent compound [4,5,812].

The pH can remarkably impact nitrogen speciation because it can significantly modify the reactivity and physical properties of relevant species. Notable examples are nitrite $( \mathrm { N O } _ { 2 } ^ { - }$ ) and $\mathrm { N H } _ { 3 }$ due to their acidbase equilibrium with nitrous acid (HONO, $\mathrm { \ p K a } = 3 . 6 5 $ and $\mathrm { N H } _ { 4 } ^ { + }$ $( \mathrm { { p K a } } = 9 . 2 5 )$ , respectively [13]. $\mathrm { N O } _ { 2 } ^ { - }$ is a relatively stable intermediate in the formation of $\mathrm { N O } _ { 3 } ^ { - }$ from more reduced forms of N, which may accumulate in solution under basic conditions, as opposed to its reactive conjugate HONO [11]. $\mathrm { N H } _ { 4 } ^ { + }$ is resistant to oxidation, whereas $\mathrm { N H } _ { 3 }$ can more easily undergo stepwise oxidation to $\mathrm { N O } _ { 2 } ^ { - }$ and $\mathrm { N O } _ { 3 } ^ { - }$ [11,1416]. Furthermore, $\mathrm { N H } _ { 3 }$ can partition to the gas phase depending on the concentration and hydrodynamic conditions in place (Henry's law constant $\mathrm { H _ { s } ^ { c p } } | _ { 2 9 8 \mathrm { K } } \cong 6 2 \mathrm { M a t m ^ { - 1 } }$ , i.e., $\mathrm { P _ { N H _ { 3 } } } = 3 . 2 2 \times 1 0 ^ { - 4 }$ atm at $[ \mathrm { N H } _ { 3 ( \mathrm { a q ) } } ] = 2 0 \mathrm { m M } )$ . Amines may also change their reactivity at different $\mathsf { p H }$ values, so it is important to know the pKa of the target compounds

and the working pH conditions [4].

The position of the nitrogen atoms and the oxidation state of the carbon and nitrogen involved in the $\mathrm { C - N }$ bond in the parent molecule affect the distribution of N products in AOPs [5,8,10,11]. For instance, when treating N-heterocyclic compounds (NHCs), the final N products depend on the intermediate N species generated upon the ring cleavage, e.g., amines, amides, or nitro-compounds. It has been observed that primary aliphatic amines predominantly yield $\mathrm { N H } _ { 3 } / \mathrm { N H } _ { 4 } ^ { + }$ , especially at acidic pH, whereas nitroso- or nitro-compounds can easily yield $\mathrm { N O } _ { 2 } ^ { - }$ and $\mathrm { N O } _ { 3 } ^ { - }$ upon their oxidative fragmentation [4,5,11,17]. Presumably, compounds containing single or double $\Nu - \Nu$ bonds generate more $\Nu _ { 2 }$ , as is the case of organic hydrazines and azo- or diazo-compounds upon anodic or photocatalytic oxidation [5,8,10].

Nevertheless, despite the fundamental similarities with other AOPs, some features of the EO-BDD process can affect the N speciation, such as the use of supporting electrolytes. Although their primary function is to boost the electrical conductivity of the water sample, the supporting electrolytes seem to play an important part in the N speciation during organic nitrogen degradation in EO-BDD. The predominant electrolytes used in EO-BDD are chloride and sulphate salts usually at concentrations ranging from 0.01 to $0 . 1 \mathrm { { M } }$ , It has been observed in EO-BDD studies that chloride and sulphate can form oxidising species, e.g., active chlorine, chlorine oxyanions, and peroxydisulphate, that may, in turn, interact with other components of the water matrix [1821]. Several studies of organic nitrogen degradation via EO-BDD have observed an enhanced $\Nu _ { 2 }$ selectivity in chloride media compared to sulphate media, which is ascribed to the formation of chloramines that can recombine to yield $\Nu _ { 2 }$ [8,22,23]. In sulphate electrolytes, the fundamentals of $\Nu _ { 2 }$ formation from organic nitrogen have received little attention due to the observed predominant production of $\mathrm { N H _ { 3 } } / \mathrm { N H _ { 4 } ^ { + } }$ , $\mathrm { N O } _ { 3 } ^ { - }$ and, sometimes, $\mathrm { N O } _ { 2 } ^ { - }$ .

Most works with EO-BDD of organic nitrogen only report the temporal evolution of $\mathrm { N H _ { 3 } } / \mathrm { N H _ { 4 } ^ { + } }$ , $\mathrm { N O } _ { 3 } ^ { - }$ , and less frequently, $\Nu _ { 2 }$ and $\mathrm { N O } _ { 2 } ^ { - }$ yields under selected conditions without further analysis of the associated data. The influence of the operating regime, i.e., current or diffusion control, and the chemistry in the anodic reaction zone are rarely taken into consideration concerning N speciation. Frequently, the evolution of N species or the pH values throughout the experiments are not reported, limiting the generality of conclusions regarding N reactions [2428]. Furthermore, while the importance of cathodic processes in electro-oxidation processes in undivided electrolytic cells has been raised, this issue is usually overlooked [17, 29].

In our previous work, we applied EO-BDD to treat real nitrogen-rich aqueous phase co-product from the hydrothermal liquefaction (HTLACP) of microalgae Chlorella sp. [30]. The EO-BDD process mineralised the organic nitrogen mostly to $\mathrm { N O } _ { 3 } ^ { - }$ and $\mathrm { N H } _ { 4 } ^ { + }$ , with efficient carbon removal and apparent minor production of $\Nu _ { 2 }$ . The complex composition of the real HTL-ACP made it difficult to understand the main factors governing the fate of nitrogen. The HTL-ACP has a high organic nitrogen content $( 3 0 0 0 ~ \mathrm { ~ m g ~ N ~ L ^ { - 1 } } .$ with pyrazine and derivatives identified amongst the organic nitrogen species, which form by the interaction of carbohydrates with amino acid decomposition products [31]. Other NHCs, such as pyrroles and pyridines, could also be present in the HTL wastewater, as reported by previous investigators [3234].

The present study reveals the distribution of the major carbon and nitrogen products during the EO-BDD of selected HTL-ACP pollutants while expanding the current knowledge of nitrogen reactions during EOBDD. Pyrazine is used as the main model compound at a wide range of initial concentrations, allowing a closer examination of the carbon and nitrogen distribution under different operating regimes. Chemical analyses of the intermediates and final degradation products in the liquid and gas phases are reported and discussed, and reaction pathways are then suggested based on the experimental data.

# 2. Materials and methods

# 2.1. Electrochemical oxidation

A filter-press micro flow cell electrochemical reactor (MFC, ElectroCell North America, USA) operated in a batch recirculation mode was used for all decomposition reactions. Boron-doped diamond (BDD) on niobium was used as the anode, and stainless steel 316 was used as the cathode. The planar electrodes each had a $1 0 \mathrm { c m } ^ { 2 }$ geometric surface area and were separated by a $4 \ \mathrm { m m }$ gap. Our previous work describes the reactor in more detail [30]. A BioLogic SP-300 potentiostat supplied a constant current of $3 0 0 \mathrm { m A }$ to the system resulting in a current density of $3 0 \mathrm { \ m A \ c m ^ { - 2 } }$ . The constant current experiments typically resulted in a cell voltage between 5.5 and $6 . 5 ~ \mathrm { V } _ { \cdot }$ , depending on the initial concentration of pyrazine. A representative chronopotentiogram at each pyrazine concentration level is provided in Fig. S1 in the Supplementary Material.

In all experiments, a $6 0 ~ \mathrm { m L }$ batch solution of aqueous electrolyte (0.07 M $\mathrm { N a } _ { 2 } \mathrm { S O } _ { 4 }$ ) was loaded initially with the chemical compound to be studied. Most runs were conducted with pyrazine (3.6, 14.5, 35.1, or $7 0 . 0 \ \mathrm { m M }$ initial concentration); some additional experiments employed pyrrole or methyl-pyrazine with nitrogen concentrations equivalent to $1 4 . 5 ~ \mathrm { m M }$ pyrazine $( { \sim } 2 9 \ \mathrm { m M } \ \mathrm { N } )$ . The solution was circulated continuously at a steady flow rate of $5 0 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ through the electrochemical reactor. Sample aliquots (less than $1 . 0 \mathrm { m L }$ were withdrawn at scheduled intervals for product analysis. The reservoir containing the aqueous solution was generally open to the atmosphere but was closed and had an argon gas sweep for runs with analysis of the gas composition by gas chromatography. The temperature in the sample reservoir was maintained between ${ 2 4 ~ ^ { \circ } \mathrm { C } }$ and ${ } ^ { 2 7 } \ { } ^ { \circ } \mathrm { C } ,$ and the pH was allowed to vary naturally with the generation of products.

Liquid samples were analysed in detail to determine the progress of the decomposition process. # Discussion

# 4.1. Operating regime considerations

The pyrazine decay curves in Fig. 1 range from being apparently exponential and close to first-order at the lower values of $c _ { p y r , 0 }$ to more nearly linear at higher $c _ { p y r , 0 }$ . This transition from mass-transfer control (first-order decay) to current-limited (linear) decay curves is characteristic of galvanostatic electrochemical processes operated over a wide range of conditions. The present results, therefore, provide insight into reaction behaviour under different conditions. Following [35], at low COD, the rate of mass transfer to the oxidation zone close to the electrode controls the rate of oxidation of COD

$$
- C O D _ { 0 } ^ { ' } = - { \frac { d c _ { C O D } } { d t } } { \bigg | } _ { C O D  0 } = { \frac { A { \cdot } k _ { M T } } { V } } c _ { C O D }
$$

where $k _ { M T }$ is the mass transfer coefficient. In this limit, the current goes essentially entirely to inefficient processes such as $\mathrm { O } _ { 2 }$ formation, and the kinetics are first-order. On the other hand, at high COD, its electrochemical rate of removal is related to the current $( I )$ , which is entirely consumed in the process and the kinetics are zero-order:

$$
- C O D _ { \infty } ^ { ' } = - \frac { d c _ { C O D } } { d t } \bigg | _ { C O D  \infty } = \frac { I } { V \cdot \mathcal { F } \cdot n _ { e , a p p } }
$$

where $\mathcal { F } = 9 6 , 4 8 5 \mathrm { A } s \mathrm { m o l } ^ { - 1 }$ is the Faraday constant. The definition of COD assumes that nitrogen occurs in the oxidised products as $\mathrm { N H } _ { 3 }$ , in which case we would have $n _ { e , o p p } = n _ { e , C O D } = 4$ (the number of moles of electrons required to produce one mole of $\mathrm { O _ { 2 } } .$ . In the present experiments, however, the nitrogen products are not only $\mathrm { N H } _ { 3 }$ but also the more highly oxidised $\Nu _ { 2 }$ and $\mathrm { N O } _ { 3 } ^ { - }$ whose formation requires additional electrons. At the same time, the formation of CO instead of $\mathrm { C O } _ { 2 }$ (Fig. 5) consumes fewer electrons than assumed in the definition of COD. The apparent electron demand can therefore be expected to differ from the ideal value of 4.

# 4.2. Identified products

The major stable intermediate products expected from the oxidative fragmentation of pyrazine are C1 and C2 carboxylic acids, amines, or amides. These compounds can be formed through a reaction network involving additions, H-abstraction, and radical interactions driven by the strong electrophile HO\* in the anodic reaction zone [38]. The species identified by GCMS (Fig. 2) are, therefore, plausible intermediates in the HO•-driven oxidation of pyrazine. Some have been reported in one study of the photocatalytic decomposition of pyrazine and related compounds in aqueous $\mathrm { T i O } _ { 2 }$ dispersions [10]. In that study, formamide was found to be one of the main organic nitrogen intermediates of pyrazine oxidative degradation. In contrast, the authors identified acetic acid as an intermediate, which was not detected in the present study. Oxamic acid has been previously identified as a relevant intermediate of organic nitrogen decomposition, and its apparently slow degradation has been the subject of previous investigations [6,39,40]. Oxalic and formic acids are also commonly reported as intermediates in the oxidation of organics by EO-BDD [37].

Hydantoin and parabanic acid (Fig. 2) can potentially stem from the recombination of smaller products. For instance, the molecular structure of hydantoin contains glycine and carbamic acid moieties, and we speculate that hydantoin could be a product of their interaction, e.g., intermolecular dehydration. Likewise, parabanic acid may be formed from the intermolecular dehydration of oxamic and carbamic acids. Scheme S1 in the Supplementary Material shows the hypothetical reactions for forming hydantoin and parabanic acid. In addition, the detection of pyrazine derivatives (Fig. S2) suggests that radical recombination involving the pyrazine ring also occurs.

The organic hydrazines, in turn, show evidence of $\Nu - \Nu$ bond formation by recombination of N-containing organic molecules, for example, N-radicals of amides or amines. The $\Nu - \Nu$ bond formation is further evidenced by the ultimate apparent production of $\Nu _ { 2 }$ during pyrazine degradation (Fig. 4a). In fact, the unselective nature of HO\* can lead to radical formation at the N atom of amides $( \mathrm { \mathbf { R } - \mathbf { C O N ^ { \bullet } H } ) }$ as demonstrated in a study on the sites of attack of HO• on amides in aqueous solutions [41]. Therefore, $\Nu - \Nu$ bond formation through the rapid recombination of amide radicals at the N-position is a plausible hypothesis, considering their concentration becomes sufficiently high to increase the likelihood of these interactions in the reaction zone. The higher total nitrogen losses observed at higher $c _ { p y r }$ values seem to support this hypothesis (see Figs. 4a, S6a, ${ \mathrm { S 7 a } } ,$ and S8a).

To gain more insights into the decomposition pathways of pyrazine, it is useful to interpret the possible correlations between the removal rates for pyrazine, TOC, and COD.

Consider the notional reaction

$$

Taking the samples before and after a time increment, from which we know the concentrations [Pyr], [TOC], and $\left[ \mathrm { C O D } \right]$ , we can calculate the differences $\Delta [ \mathrm { P y r } ] , \Delta [ \mathrm { T O C } ]$ ,and $\Delta [ \mathrm { C O D } ]$ and write:

The quantity in Eq. (22) informs the apparent stoichiometric relationship between the rates of loss of pyrazine and TOC. # .. Gaseous products

The observation of CO among the gaseous products (Fig. 5a) at nonnegligible levels suggests a decarbonylation pathway in the reaction system. Moreover, the profile of the $\mathrm { C O } / \mathrm { C O } _ { 2 }$ ratio (Fig. 5b) suggests that there could be a minor pathway for $\mathrm { C O } _ { 2 }$ formation involving CO as an intermediate, as in Eq. The oxidation of CO to $\mathrm { C O } _ { 2 }$ using EO-BDD has been examined by other investigators, who argued that CO oxidation via HO\* addition followed by a direct electron transfer to the anode is favoured [45].

$$
\mathrm { R } + \mathrm { H O ^ { \bullet } } {  } \mathrm { C O } + \mathrm { H O ^ { \bullet } } \xrightarrow { - H ^ { + } , - e ^ { - } } \mathrm { C O } _ { 2 }
$$

The detection of CO in the gaseous products of the EO-BDD process, even though in amounts several times smaller than $\mathrm { C O } _ { 2 }$ , has implications in the moles of electrons involved in the removal of TOC from solution, and, therefore, in the current efficiency for carbon removal. Importantly, this may help to explain reports of current efficiencies (CE) above $1 0 0 \%$ ; the assumed number of electrons per mol of COD removal in CE calculations is 4, which is only true if $\mathrm { C O } _ { 2 }$ is the sole carbon oxidation product partitioning to the gas phase.

It also indicates that there could be opportunities to optimise the process for higher CO selectivity, which would involve fewer electrons in TOC removal and, therefore, result in energy savings. For instance, a previous study of the EO of methanol has indicated the presence of CO when the contact time of methanol and the electro-catalytic surface was shortened by increasing the flow rate in the flow cell [46]. From an environmental perspective, there are today effective catalysts that can convert CO into $\mathrm { C O } _ { 2 }$ in the gas phase, and that approach could be used to avoid the release of CO into the atmosphere [47].

# 5. Conclusions

The present study on the electro-oxidation of pyrazine and related Nheterocyclic compounds with BDD anode has shown that the operating regime, i.e., whether the oxidation of organics is controlled by the applied current or by mass transfer, can impact the C and N product profiles.

The pyrazine decay curves range from being apparently exponential and close to first-order at the lower initial values of concentration to more nearly linear at higher initial concentration showing a transition from mass-transfer control (first-order decay) to current-limited control (linear decay) curves.

Analysis of the removal rates of pyrazine, TOC, and COD indicate that the mineralisation to $\mathrm { C O } _ { \mathrm { x } }$ and inorganic N products $( \Nu _ { 2 }$ $\mathrm { V } _ { 2 } , \mathrm { N H } _ { 4 } ^ { + } / \mathrm { N H } _ { 3 }$ , $\mathrm { N O } _ { 3 } ^ { - }$ , and minor product $\mathrm { N O } _ { 2 } ^ { - }$ ) can be represented by the general reaction mechanism $\mathbf { A }  \mathbf { B }  \mathbf { C } ,$ with intermediates including formamide, oxamide, and oxamic, carbamic, oxalic, and formic acids. CO, which was directly measured in the gas phase, could also be an intermediate in $\mathrm { C O } _ { 2 }$ formation, suggesting a decarbonylation pathway in addition to the decarboxylation of small carboxylic acids.

The examination of N yields as a function of COD removal showed that the release of an apparent $\Nu _ { 2 }$ and $\mathrm { N H _ { 4 } ^ { + } / N H _ { 3 } }$ correlates linearly with carbon removal. The apparent $\Nu _ { 2 }$ formation seems to initiate from the interaction of organic N intermediates to form moieties containing $\mathrm { N - N }$ bonds, such as in organic hydrazines. When carbon oxidation is diffusion-limited, $\mathrm { N O } _ { 3 } ^ { - }$ yields significantly increase and become higher than the apparent $\Nu _ { 2 }$ and $\mathrm { N H } _ { 3 }$ yields. We suggest that, at lower C and N radicals' availability, the multi-step $\mathrm { H O ^ { \bullet } }$ -driven oxidation of C-bound nitrogen is favoured, and the subsequent release of nitro groups directly from organics give rise to $\mathrm { N O } _ { 3 } ^ { - }$ .

The formation of peroxydisulphate and a substantial rise in pH in the sulphate electrolyte can be observed once the carbon oxidation becomes limited by mass transfer. The rise in pH at this stage seems to trigger the oxidation of $\mathrm { N H } _ { 3 }$ to $\mathrm { N O } _ { 3 } ^ { - }$ , which further contributes to the increased $\mathrm { N O } _ { 3 } ^ { - }$ yields under this operating condition.

This research has shown that the electrochemical operating regime has a significant impact on the rate, pathways and product distributions obtained in the destruction of organic nitrogen pollutants using EOBDD. In practice, by selecting appropriate operating regimes, it may therefore be possible to tailor the final product distribution from an EO process for remediation and recovery of waste waters such as those from the hydrothermal liquefaction of nitrogenous biomass. This fundamental observation holds promise for potential applications in realworld wastewater treatment plants utilizing electro-oxidation techniques. Future work could focus on improving the gas phase analysis so that gaseous N products can be directly and precisely quantified under diverse conditions.
