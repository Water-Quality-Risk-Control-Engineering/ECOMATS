# . Introduction

By utilizing highly reactive short-lived oxidants, the use of advanced oxidation processes (AOPs) is considered a viable strategy for the abatement of refractory organic contaminants [13]. In situ generation of reactive radicals is enabled, for example, by developing novel electrochemical or photoactive catalysts capable of converting radical precursors (e.g., hydrogen peroxide and ozone) to important reactive oxygen species (ROS) such as hydroxyl (OH, $E ^ { 0 } ( { ^ \bullet } \mathrm { O H } / \mathrm { O H } ^ { - } ) = + 1 . 8 -$ $+ 2 . 7 \mathrm { V } _ { \mathrm { N H E } } )$ radicals [4,5]. As an alternative to conventional AOPs that rely on the oxidizing power of $\cdot _ { \mathrm { O H } }$ , persulfate (PS)-based AOPs that utilize sulfate radicals as the primary oxidant $( S O _ { 4 } ^ { \bullet - }$ , $E ^ { 0 } ( \mathrm { S O } _ { 4 } ^ { \bullet - } / \mathrm { S O } _ { 4 } ^ { 2 - } ) =$ $+ 2 . 5 \mathrm { ~ - ~ } + 3 . 1 \mathrm { ~ V _ { N H E } ) }$ offer several technical advantages, including the following: (i) high treatment efficiency with low sensitivity toward variations in operational parameters such as $\mathtt { p H }$ and background organic/inorganic matters, (ii) availability of PS precursors in salt forms to mitigate cost and safety issues associated with chemical storage and transportation, and (iii) diverse options for PS activation (e.g., treatments based on heat, ultrasound, transition metal, electrocatalyst, and photo-irradiation)[68].

Over the last few years, an increasing number of studies on PS activation have been conducted using electrocatalytic (EC) or photocatalytic (PC) systems or a combination of these two systems (namely, photoelectrocatalytic (PEC) system). The PEC system, in particular, offers the synergetic properties of EC and PC systems, thus facilitating high oxidative degradation performance [9,10]. A PEC system destroys organic contaminants by transferring photogenerated charge carriers to produce ROS (e.g., 'OH, $\mathbf { O } _ { 2 } ^ { \bullet - }$ and to allow direct oxidation/reduction reactions at the electrode surface via photon absorption.

Additionally, PS addition could enhance the performance of a PEC system by enhancing charge separation and radical formation via PS activation, primarily upon ultraviolet (UV) irradiation and electron transfer at the anode [10,11]. Numerous studies have been conducted to allow the use of a cathode in the reductive PS conversion to $S O _ { 4 } ^ { \bullet - }$ as an alternative to an inert counter electrode. For example, transition-metal-based (e.g., Cu) and surface-modified electrodes (e.g., $\mathrm { C o } _ { 3 } \mathrm { O } _ { 4 }$ ${ \mathrm { C u F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ $\mathrm { M n F e } _ { 2 } \mathrm { O } _ { 4 } .$ )have been used to facilitate reductive PS activation at the cathode, resulting in increased formation yields of both $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ and $S O _ { 4 } ^ { \bullet - }$ for the degradation of a variety of organic pollutants [1215]. However, prolonged use of these electrodes inevitably results in a gradual decrease in treatment performance and secondary contamination caused by metal component dissolution [16,17].

$\mathrm { T i O } _ { 2 }$ is a non-toxic, low-cost, and environmentally friendly material for PEC systems [18]. Additionally, it can be easily fabricated into an immobilized electrode by growing a passive layer of $\mathrm { T i O } _ { 2 }$ nanotube arrays (TNA) on the surface of a Ti metal substrate. The primary advantage of using TNA is that their electronic and optical properties can be enhanced via the self-doping of $\mathrm { T i } ^ { 3 + }$ through cathodic polarization under ambient conditions, which eliminates the need for external metal-based dopants that are prone to reductive or oxidative dissolution. It has been demonstrated that the self-doped TNA (referred to as bl-TNA due to its dark-blue colored surface) outperforms the pristine TNA in terms of photoelectrocatalytic activity, electrical conductivity, and charge transfer rate [19]. Undoubtedly, the exclusive anodic performance of the bl-TNA is superior to that of conventional anodes such as boron-doped diamond and dimensionally stable anodes due to its significantly lower energy consumption during oxidative degradation and PS activation in EC systems [20,21]. Additionally, the photoelectrocatalytic degradation of organic pollutants, including methylene blue, $p$ -nitrosodimethylaniline, and 4-chlorophenol, has been demonstrated using the bl-TNA as the photoanode [18,19], and treatment efficiency has been improved by coupling with PS compounds such as peroxydisulfate (PDS) [11]. Recently, numerous studies have demonstrated the viability of using $\mathrm { T i O } _ { 2 }$ -based materials as an effective cathode in photocatalytic fuel cells [22] and for carbon dioxide reduction [23,24] and nitrate reduction [25,26], illustrating the distinguished reductive activities. Although the bl-TNA can act as a cathode owing to its reductive ability for the formation of $\cdot _ { \mathrm { O H } }$ in an EC system [27], the majority of $\mathrm { T i O } _ { 2 }$ -based studies on PEC oxidative treatment have used the bl-TNA as a photoanode, overlooking its photocathode potential.

With the knowledge gained about the bl-TNA, it is anticipated that reductive PS activation could occur actively when the bl-TNA is used as a photocathode. Additionally, periodic cathodization enables the reactivation of the bl-TNA following repeated use in an EC/PEC system. This leads to the idea of constructing a symmetric PEC system with a simple cell configuration in which the bl-TNA simultaneously serves as the photoanode and photocathode to avoid photoelectrocatalytic activity deterioration due to prolonged exposure to redox reactions [28]. In particular, the potential benefits of the proposed symmetric PEC system include the following: (i) no release of harmful heavy metals such as Mn, Fe, Co, and Cu from metal-based cathodes [1215,29], (ii) higher photoelectrocatalytic performance in terms of photoresponsivity and reductive activities than that of an asymmetric PEC system equipped with an inert cathode (e.g., Ti cathode); this performance would be improved upon PDS addition, and (iii) increased overall stability and usability of the bl-TNA through periodic polarity reversal (PPR).

To exploit these advantages, we constructed a symmetric PEC/PDS system using two identical $\mathrm { T i } ^ { 3 + }$ self-doped TNAs and investigated its performance toward the oxidation of organic contaminants such as bisphenol-A (BPA). The photoelectrochemical characterization and determination of the activities of the bl-TNA as the photoanode and photocathode are conducted under various process conditions (e.g., UVA photolysis and use of PEC and PEC/PDS systems). Scavenger tests and electron spin resonance (ESR) spectroscopy were conducted, and probe compounds (e.g., nitrobenzene (NB) and benzoic acid (BA)) were used to investigate the mechanism of PDS activation. Additionally, the major ROS and plausible mechanistic roles of the photoanode and photocathode toward BPA removal are elucidated using a custom-made cell (referred to as the divided cell). Finally, a PPR strategy was used to enhance the long-term stability of the proposed symmetric PEC system. Thus, this study provided new insights into the use of the bl-TNA as an efficient Janus photoelectrode in conjunction with PDS activation, which has not been emphasized so far in the photoelectrocatalytic degradation of organic contaminants.

# 2.1. Materials

# 2.2. Fabrication of self-doped TNA

The self-doped TNA was prepared using the sequential anodization method described in a previous study [11]. The Ti mesh (referred to as Ti) and Pt foil with a working area of $9 . 5 \mathrm { c m } ^ { 2 }$ were used as the anode and cathode, respectively. The Ti was anodized for $^ \textrm { \scriptsize 5 h }$ at $4 5 . 0 \mathrm { ~ V ~ }$ in an ethylene glycol solution containing $0 . 2 ~ \mathrm { w t } \% ~ \mathrm { N H } _ { 4 } \mathrm { F }$ and $2 . 5 ~ \mathrm { w t \% }$ $_ \mathrm { H _ { 2 } O }$ . Subsequently, additional anodization was performed for $1 0 \mathrm { m i n }$ at 10.0 V using the same electrolyte. To obtain the anatase TNA, the anodized samples were annealed at $4 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 \mathrm { ~ h ~ } }$ in air. Subsequently, cathodic polarization at $1 6 . 7 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ for $9 0 \ : s$ in 0.1 M $\mathrm { K H _ { 2 } P O _ { 4 } }$ solution resulted in the fabrication of the dark-blue-colored bl-TNA.

# 2.3. Physicochemical and electrochemical characterization

The surface morphology of the bl-TNA was observed through field emission scanning electron microscopy (FE-SEM, FEI, Inspect F, USA). The phase composition and reduction level of the bl-TNA were determined through Raman spectroscopy (Renishaw, invia Raman Microscope, United Kingdom) conducted using $5 3 2 . 0 ~ \mathrm { n m }$ laser light at room temperature.

Except photocurrent response analysis, electrochemical impedance spectroscopy (EIS), and long-term stability experiments, all electrochemical analyses were carried out using a potentiostat in a threeelectrode configuration (Biologic, SP-150, France). The working electrode was composed of the bl-TNA; the counter electrode was made of Ti, the bl-TNA, and Pt mesh; and the reference electrode was made of $\mathbf { A g / A g C l }$ . The distance between the working and counter electrodes was maintained at $1 . 0 \ \mathrm { c m }$ ,and 0.1 M $\mathrm { N a } _ { 2 } S 0 _ { 4 }$ was used as a supporting electrolyte.

Cyclic voltammetry (CV) was performed to determine the electrochemical properties of the bl-TNA and Ti in the potential range of $^ { - 2 . 0 }$ to $+ 3 . 0 \mathrm { V }$ (vs. Ag/AgCl, sat'd KCl, equivalent to $- 1 . 4 6$ to $+ 3 . 5 4 \mathrm { V }$ VS. RHE) at a scan rate of $1 0 . 0 \mathrm { m V } / s$ . The possibility of reductive PDS activation at the bl-TNA and Ti upon using the EC and PEC systems was investigated through linear sweep voltammetry (LSV) at a scan rate of $1 0 . 0 ~ \mathrm { m V / s }$ . The light source was a 4.0 W black light blue UVA lamp (Sankyo, F4T5, Japan) with a wavelength (Zλ) range of $3 1 5 { - } 4 0 0 \mathrm { n m }$ and a light intensity of $0 . 0 8 \mathrm { m W / c m ^ { 2 } }$ [as determined by a UVX radiometer (UVP, USA)]. # 2.4. Photoelectrochemical degradation experiments

Unless otherwise specified, degradation experiments were carried out using a three-electrode configuration (Section 2.3) in the undivided cell (working volume: $9 0 ~ \mathrm { m L }$ ). The target compound was $1 0 . 0 \mu \mathrm { M }$ BPA, and the electrolyte was $0 . 1 \mathrm { M N a _ { 2 } } \mathrm { S O _ { 4 } }$ . Additionally, the divided cell was used to investigate the reaction between the anode and cathode chambers during BPA oxidation. The divided cell was composed of two identical chambers separated by an Alfa Aesar Nafion 117 proton exchange membrane. At each chamber, NB and BA with varying reactivities toward $\cdot _ { \mathrm { O H } }$ and $S O _ { 4 } ^ { \bullet - }$ were used to investigate the primary ROS produced by the PEC and PEC/PDS systems. Additionally, $2 . 0 \ \mathrm { M }$ tert-butanol (TBA), methanol (MeOH), and $0 . 1 \mathrm { ~ M ~ }$ sodium oxalate (SO) were used as scavengers to further elucidate the major ROS in the PEC/ PDS system with divided cells.

Additionally, a two-electrode configuration equipped with the blTNA as both the anode and cathode was used to investigate the viability of the PPR strategy for increasing the stability of the symmetric PEC systems. Sequential $\pm \ 2 . 0 \ \mathrm { V }$ was applied to the symmetric PEC system devoid of target compounds. Before analysis, sample aliquots were removed from the reactor and filtered through a $0 . 2 ~ { \mu \mathrm { m } }$ polytetrafluoroethylene filter membrane (Whatman, Germany).

# 3. Results and discussion

# 3.1.Photoelectrocatalytic activity of bl-TNA

On the Ti substrate, vertically aligned open-end nanotube arrays with an inner diameter and length of approximately 85.9 and $1 1 . 2 \ \mathrm { n m }$ were grown (Fig. S1a and b). The CV curves of bare Ti and the bl-TNA revealed significant differences in their electrochemical properties (Fig. 1a). The bl-TNA exhibited a significant increase in capacitance and a decrease in overpotentials for water splitting reactions (oxygen and hydrogen evolution reactions), indicating a significant increase in electrocatalytic activity via cathodic polarization [3032]. Proton intercalation occurred at a potential near $- 0 . 7 \ : \mathrm { V }$ vs. Ag/AgCl, sat'd KCl (equivalent to $- 0 . 1 6 \mathrm { ~ V ~ }$ vs. RHE), during cathodic polarization, as illustrated in the inset of CV (Fig. 1a), which initiated the electrochromism of the anatase TNA from gray to dark-blue color due to the formation of oxygen vacancies and charge compensation, which partially changed the oxidation state of $\mathrm { T i } ^ { 4 + }$ to $\mathrm { T i } ^ { 3 + }$ Fig. S1c) [33,34]. Additionally, Raman spectroscopy was conducted to monitor the crystalline structure and the formation of $\mathrm { T i } ^ { 3 + }$ on the bl-TNA (Fig. S2). As illustrated in Fig. S2, the active modes at approximately $1 4 5 ~ \mathrm { c m } ^ { - 1 }$ $\mathrm { ( E _ { g } ) }$ , $1 9 6 ~ \mathrm { c m } ^ { - 1 }$ $( \mathrm { E _ { g } } ) , 3 9 6 \mathrm { c m } ^ { - 1 } ( \mathrm { B } _ { \mathrm { g } } ) , 5 1 7 \mathrm { c m } ^ { - 1 } ( \mathrm { A } _ { \mathrm { g } } )$ ,and $6 3 6 \mathrm { c m } ^ { - 1 } ( \mathrm { E } _ { \mathrm { g } } )$ correspond to the anatase $\mathrm { T i O } _ { 2 }$ characteristic [35,36]. After cathodic polarization, the blue shift and broadening of the full-width half maxima (FWHM) of the $\mathrm { E _ { g } }$ peak near $1 4 5 ~ \mathrm { c m } ^ { - 1 }$ in the bl-TNA were observed. This is due to the removal of oxygen atoms from the $\mathrm { T i O } _ { 2 }$ lattice and the formation of $\mathrm { T i } ^ { 3 + }$ [37,38].

Due to the simultaneous increase in anodic and cathodic currents over a wide range of potentials (Fig. 1a), the versatile use of the bl-TNA as an effective anode and cathode could be anticipated, as previously demonstrated [28]. Fig. 1b and 1c illustrate the LSV characterization of Ti and bl-TNA under various process conditions. Although the distinct redox signal for cathodic PDS activation was unnoticeable, Ti exhibited low cathodic current from a point of no flow to a slight increase in current under both EC and PEC systems in the presence of PDS. In comparison, a higher cathodic current was observed in the LSV profile of the bl-TNA, implying that UVA irradiation enhanced the electrocatalytic activity and photoresponsive current. Furthermore, the addition of PDS increased the cathodic current peaks near $_ { 0 . 2 \mathrm { ~ V ~ } }$ VS. $\mathbf { A g / A g C l } _ { \mathrm { . } }$ ,sat'd KCl, which is consistent with the results of a previous study [39]. The cathodic current increased linearly with the concentration of PDS, indicating a strong interaction between the bl-TNA and PDS (Fig. 1c).

When composed of an electrochemical cell, the high electrocatalytic properties of the bl-TNA were more apparent. While using the bl-TNA as an anode, two distinct PEC systems were designed using Ti and the blTNA as the cathode, referred to as asymmetric B-T and symmetric B-B pairs, respectively. The Nyquist plot (Fig. 1d) of the B-T and B-B pairs could be obtained through EIS performed in a two-electrode configuration under the EC system. At high frequencies, the series resistances of the B-T and B-B pairs, such as electrolyte and electrode resistance, were comparable (Fig. S3). However, when the cathode material was changed from Ti to the bl-TNA, an order of magnitude difference in charge transfer resistance was observed at low frequencies. The reduced charge transfer resistance is due to the oxygen vacancies in the bl-TNA, which act as reaction sites and shallow donors, facilitating charge transfer in the bl-TNA crystal structure [40]. Moreover, PDS addition resulted in a significantly reduced semi-circle corresponding to charge transfer resistance, indicating that the B-B pair activates PDS more efficiently than the B-T pair. Additionally, the performance of the two systems was evaluated by comparing the magnitudes of their photoresponsive currents (Fig. 1e). The UVA irradiation increased the photocurrent to 0.20 and $0 . 3 4 ~ \mathrm { m A } / \mathrm { c m } ^ { 2 }$ for B-T and B-B pairs, respectively. The increased photocurrent obtained with the B-B pair can be attributed to the increased charge carrier transport capacity and the decreased interfacial resistance at the electrode/electrolyte interface [38]. The enhanced photoelectrochemical properties eventually resulted in the B-B pairs degrading BPA more efficiently than the B-T pairs (Fig. 1f). The B-B pair had a $6 4 . 0 \%$ higher pseudo first-order kinetic constant $( k _ { o b s } )$ than the B-T pair, which facilitated the removal of $9 3 . 4 \%$ BPA, indicating that appropriate cathode selection can significantly improve the overall PEC performance. This finding is consistent with previous research indicating that the performance of the PEC/PDS system can be improved through cathodic and photo-irradiation activation, resulting in an increased radical formation yield [29].

# 3.3. BPA degradation performance at anode and cathode

# 3.3.1.Effect of process conditions on BPA degradation performance

The divided cell was used to investigate the role of the bl-TNA photoelectrodes as the anode and cathode in the symmetric PEC/PDS system. Each chamber was equipped with a Janus bl-TNA, as schematically depicted in Fig. S5. The low efficiency of BPA removal under various process conditions (Fig. 3) indicated that BPA was barely removed via adsorption and was only marginally decomposed $( < 6 . 3 \%$ after $^ { 1 \mathrm { { h } } }$ ) in each chamber using inactivated PDS and direct UVA photolysis. In comparison, as illustrated in Fig. 3c, the PEC system had a 7.5:1 ratio of $k _ { o b s }$ between the anode and cathode chambers (anode: cathode). The high BPA degradation in the anode chamber is consistent with the results of a previous study, which stated that 'OH is produced when photogenerated holes react with water and hydroxyl ions [44]. Interestingly, although a lower BPA removal efficiency was observed at the cathode than at the anode, it had a slightly higher removal efficiency of BPA than that achieved by UVA photolysis alone. Because BPA is barely degraded via electro-reduction at the cathode, we can surmise that BPA degradation is due to the generation of additional reactive oxidants. The 'OH is also produced via the photochemical reaction at the surface of the photoactive bl-TNA cathode, as indicated by the ESR spectrum in Fig. S6. To confirm further that the bl-TNA can act as a photocatalyst and even as a cathode in a PEC system, ESR spectra were observed under various conditions. The ESR spectral feature obtained from the PC system was almost identical to that obtained from the PEC system in both chambers, indicating that, unlike other inert electrodes, the bl-TNA can act as a photoactive cathode under PEC conditions (Fig. S7a). The large performance difference between the anode and cathode chambers in a PEC system may be attributed to the two photoelectrodes having an unequal degree of charge separation. Specifically, by transferring photoexcited electrons from the anode to the cathode via the applied potential bias, the bl-TNA photoanode enhanced charge separation. In contrast, as the cathode accepts electrons from the potential bias, the bl-TNA photocathode may experience charge recombination, reducing the overall photoactivity. Thus, an electron acceptor such as PS should be injected to reduce charge recombination at the photoelectrodes.

Thus, the significant improvement in BPA degradation performance of both chambers was influenced not only by the activation of PDS, which was primarily accomplished via UVA irradiation, but also by the increased PEC performance of the bl-TNA electrodes due to charge recombination mitigation via PDS addition [11]. The bl-TNA cathode, in particular, has demonstrated a notable improvement in the performance as PDS undergoes a reductive transformation with excited electrons, which may enable enhanced charge separation that is not possible in the conventional PEC system using a non-photoreactive cathode.

The ESR spectra of the PEC and PEC/PDS systems were analyzed to determine the distinct roles of the anode and cathode chambers in the two systems (Fig. 4). In comparison to the PEC system, in the PEC/PDS system, the intensities of both DMPO-'OH and $\mathrm { D M P O - S O _ { 4 } ^ { \bullet - } }$ adducts increased in both chambers when PDS was present, confirming the aforementioned trend of BPA degradation via PDS activation and supplementary formation of 'OH due to improved charge separation. Additionally, Fig. S6 illustrates the ESR spectral characteristics of the PEC and PEC/PDS systems as a function of reaction time. In the PEC system, the peak intensities of the DMPO-'OH adduct increased gradually with reaction time at the anode, whereas the peak intensities remained constant at the cathode (Fig. S6a). Although the anodic reaction remains dominant in the PEC/PDS system, the contribution of the cathode to ROS generation has been determined experimentally by observing the increased intensities of reactive radical assigned peaks (Fig. S7b). After $3 0 \mathrm { { m i n } }$ , the ESR detection peaks of $S O _ { 4 } ^ { \bullet - }$ were no longer visible at the anode, indicating high \*OH production [45]. In contrast, at the cathode, DMPO. $S O _ { 4 } ^ { \bullet - }$ adducts were still present, indicating that the anode and cathode chambers follow distinct ROs generation mechanisms.

# 3.4. Mechanistic evaluation of symmetric PEC/PDS system

To confirm the presence of the major ROS species in the proposed system, BPA, BA, and NB with varying reactivity toward $\cdot _ { \mathrm { O H } }$ and $S O _ { 4 } ^ { \bullet - }$ were chosen as organic probe compounds (Table S3). The $k _ { o b s }$ of organic compounds ranked in the order $\mathrm { N B } < \mathrm { B A } < \mathrm { B P A }$ in both the anode and cathode chambers of the PEC and PEC/PDS systems, with preferential oxidation occurring at the anode (Fig. 6). This substrate-dependent degradation behavior was consistent with $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ and $S O _ { 4 } ^ { \bullet - }$ reactivities toward various organic compounds (Table S3).

In contrast, NB had the highest removal efficiency in the cathode chamber of the PEC system. This is because the electrocatalytically active bl-TNA cathode facilitated the reductive degradation of NB via direct electro-reduction [50]. Additionally, a significant amount of NB degradation occurred in the PEC/PDS system, indicating that the assistance of PDS activation resulted in a significant amount of \*OH formation in both the photocathode and photoanode.

To determine the predominant ROS in the symmetric PEC/PDS system using bl-TNA photoelectrodes, BPA oxidation experiments were performed with the addition of radical scavengers such as TBA, MeOH, and SO, which are used to specify the proportions of \*OH, $S O _ { 4 } ^ { \bullet - }$ and hole, respectively (Fig. 7). With the addition of TBA, which has a high reactivity toward •OH, the BPA removal efficiencies at the anode and cathode chambers decreased abruptly to $3 2 . 4 \%$ and $9 . 9 \%$ ,respectively. Particularly, in the presence of MeOH, there was no further decrease in BPA removal efficiency at the anode, whereas it decreased to $2 . 1 \%$ at the cathode. The results demonstrated unequivocally that $\cdot _ { \mathrm { O H } }$ was the dominant ROS in both the anode and cathode chambers, while a trace of $S O _ { 4 } ^ { \bullet - }$ was detected in the cathode chamber. This result is consistent with the ESR spectra (Fig. 4 and Fig. S6b), which demonstrate a sharp increase in the peaks assigned to the DMPO. $\mathrm { \bullet _ { O H } }$ adduct. Moreover, an additional reduction of $1 4 . 7 \%$ in the removal efficiency was attributed to the absence of direct BPA oxidation at the anode surface in the presence of SO as a hole scavenger. The remainder of BPA degradation could be due to surface-bound oxidizing species [51].

# 3.5. Investigation on long-term stability

Finally, another advantage of constructing a symmetric PEC/PDS system is that both the anode and cathode can be switched easily by reversing the polarity of the system, as suggested by Yang et al., who extended the cyclability of electrocatalytic oxidation cells by reversing the direction of the applied current [28]. It is believed that such a PPR strategy will increase the stability of the symmetric PEC system by periodically reversing the polarity of electrodes and thereby mediate partial restoration to the initial polarized state. The viability of the PPR strategy was determined over a $6 4 \ \mathrm { h }$ period in a two-electrode configuration with a sequential voltage bias of $\pm 2 . 0 \ : \mathrm { V }$ every $^ { 2 \mathrm { ~ h ~ } }$ . As illustrated in Fig. 8a, after $^ { 6 4 \mathrm { h } }$ of operation, the PPR operation retained a higher PEC current than that with the non-PPR operation. Finally, the difference in total charge transferred during $^ { 6 4 \mathrm { h } }$ was approximately $2 4 . 0 \%$ between operations with and without PPR. The difference between the two operating modes was more clearly demonstrated in the undivided cell under PEC conditions (Fig. 8b and c). Additionally, the charge transfer in the PEC system with and without PPR was reduced to 3.0 and $2 . 3 \mathrm { \ m A h }$ , respectively, corresponding to $k _ { o b s }$ of 0.024 and $0 . 0 2 1 \ \mathrm { m i n } ^ { - 1 }$ . Subsequently, the PPR operation reduced $k _ { o b s }$ by only $2 . 4 \%$ , whereas the non-PPR operation reduced $k _ { o b s }$ by more than $1 4 . 5 \%$ .

The Raman spectra of bl-TNA before and after $^ { 6 4 \mathrm { ~ h ~ } }$ of operation (Fig. 8d and e) demonstrated the extent of surface changes at the anodes in relation to the operating modes. The assignable peaks at $1 4 5 ~ \mathrm { c m } ^ { - 1 }$ $\mathrm { ( E _ { g } ) }$ , $1 9 6 ~ \mathrm { c m } ^ { - 1 }$ $\mathrm { ( E _ { g } ) }$ , $3 9 6 ~ \mathrm { c m } ^ { - 1 }$ $\mathrm { ( B _ { g } ) }$ $5 1 7 \mathrm { c m } ^ { - 1 }$ $\mathrm { ( A _ { g } ) }$ ,and $6 3 6 \mathrm { c m } ^ { - 1 } \ : ( \mathrm { E } _ { \mathrm { g } } )$ indicated that the TNA crystalline structure remained in the anatase phase throughout the PPR operation. However, after $^ { 6 4 \mathrm { h } }$ , there were signs of red shift and narrowing of the FWHM of the peak near $1 4 5 ~ \mathrm { c m } ^ { - 1 }$ , indicating the loss of oxygen vacancies at the bl-TNA surface during the oxidation reaction. As evidenced by the smaller extent of the red shift from 146.5 to $1 4 6 . 1 \mathrm { c m } ^ { - 1 }$ when compared to the non-PPR operation, such oxidation of bl-TNA was mitigated by PPR. Overall, the results of the PPR operation with Janus photoelectrodes provide a novel insight into the mechanism to improve the stability of the PEC system.

# 4. Conclusions

The symmetric PEC system with bl-TNA photoelectrodes was investigated in this study to see if it could promote the degradation of organic contaminants. This system effectively decreased the interfacial charge transfer resistance and increased the photoresponsive current, resulting in a higher rate of oxidation of organic contaminants than the asymmetric PEC system. The applied potential bias and the concentration of injected PDS had a significant effect on the performance of this system. In comparison to the asymmetric PEC system (B-T pair), the symmetric PEC system (B-B pair) increased the pseudo first-order-reaction rate constant for BPA at the photoanode and photocathode by 3.5 and 36.4 times, respectively, with the addition of $4 . 0 \mathrm { m M }$ PDS. This significant enhancement at both photoelectrodes, particularly at the photocathode, was attributed to the additional radical formation driven by PDS activation, which resulted in intensifying the photocatalytic activity of blTNA through the improvement of charge separation caused by PDS serving as an electron acceptor. Together with the ESR results, the observations from the experiments using organic probe compounds and radical scavengers comprehensively indicated that $\cdot _ { \mathrm { O H } }$ was the predominant ROS in this system, with direct oxidation/reduction and $S O _ { 4 } ^ { \bullet - }$ generated at both photoelectrodes contributing to the removal of organic contaminants. After $^ { 6 4 \mathrm { ~ h ~ } }$ of PPR operation, the symmetric PEC system demonstrated superior performance with a decrease in the BPA removal rate constant of only $2 . 4 \%$ , compared to a reduction of $1 4 . 5 \%$ for the non-PPR operation. These findings indicate that the PPR operation may be a viable strategy for stably extending the lifespan of the symmetric PEC system. Further studies are required to determine the optimal PPR condition, which is dependent on operating parameters, such as applied voltage, switching cycle duration, and electrode distance and size. Overall, this study emphasizes the critical importance of judicious electrode pair selection for optimizing PEC performance, which will ultimately accelerate the practical application of the PEC/ PDS system toward water treatment.
