# a b s t r a c t

A novel $\mathsf { A g } / \mathsf { g } { - } \mathsf { C } _ { 3 } \mathsf { N } _ { 4 } /$ kaolinite composite photocatalyst was fabricated for the first time through a two-step assembly strategy by employing in situ calcination and a photodeposition process. The synthesized $\sf { A g } / \sf { g } \mathrm { - }$ $\mathsf { C } _ { 3 } \mathsf { N } _ { 4 } /$ kaolinite composite reached a higher degradation rate of ibuprofen (IBP) with a reaction rate constant of $0 . 0 1 1 3 \mathrm { m i n } ^ { - 1 }$ at an $\mathsf { A g }$ content of $7 \%$ under visible-light irradiation, which was approximately 1.87 times that of the $\sf A g / g \mathrm { - } C _ { 3 } N _ { 4 }$ composite. Based on the physicochemical properties, the enhanced photocatalytic activity was attributed to the stronger adsorption property, wider photoresponse range and more efficient separation and transfer of electron-hole pairs. Furthermore, the incorporation of monodispersed $\mathsf { A g }$ nanoparticles onto the $\bf { g } { - } \bf { C } _ { 3 } \mathbf { N } _ { 4 } /$ kaolinite sheets provided more reactive sites for the IBP degradation. In addition, according to the EPR study and trapping experiments, it was demonstrated that holes $( \mathrm { h ^ { + } } )$ should be the key reactive species. A possible pathway of IBP degradation was also proposed based on the detected intermediates. Overall, the results of this work may facilitate the design of a novel visible-light-driven photocatalyst with a high efficiency that is derived from a natural mineral for environmental remediation.

# 1. Introduction

Recently, many researchers have devoted considerable effort towards remediating normal pollutants, particularly carcinogenic organic dyes and highly toxic pesticides. Some rewarding and prominent achievements have been accomplished [1e4]; nevertheless, the treatment of pharmaceutical and personal care product (PPCP) contamination still remains a major and thorny challenge [5e7]. PPCPs can enter the water circulation system through such means as sewage treatment plants, houses, and hospitals [8]. With the continuous high-frequency use of pharmaceuticals, a considerable portion of PPCPs cannot be degraded naturally or decomposed effectively. Furthermore, PPCPs can accumulate chronically in aquatic organisms and plants, thereby causing harmful effects on human health through the food chain [9e13]. As a typical drug of PPCPs, ibuprofen (IBP) has remarkable effects in the therapy of rheumatoid arthritis, muscle ache, inflammation and fever. However, due to the stable physicochemical properties and long half-life of IBP, and especially those of its metabolized products, it may interfere with not only the normal physiological functions of environmental organisms but also the physiological functions of human beings. Therefore, IBP is widely regarded as a persistent pollutant [14e16]. In light of such hazards and urgency, it is significant to develop an efficient technology to remove IBP from the aqueous phase.

Generally, advanced oxidation processes, such as $\mathrm { U V } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [17], ozone with/without UV [18], UV-LED/peroxymonosulfate (PMS) [19] and Fe-containing solid catalysts [20,21], have been reported to remove the IBP. However, these processes have the drawbacks of high energy consumption, high cost and even secondary pollution [15], which detrimentally restricts their large-scale application. Photocatalysis, as a green technology utilizing solar light as the power source, could produce certain kinds of highly oxidized species, i.e., the hydroxyl radical ( OH), the superoxide radical $( ^ { \bullet } 0 _ { 2 } ^ { - } )$

and photogenerated holes $( \mathsf { h } ^ { + } )$ , which could efficiently mineralize the pollutants into innocuous small molecules during the photocatalytic processes [22,23]. Accordingly, semiconductor photocatalysts have attracted extensive attention because of the abovementioned advantages, which could be applied in various fields, such as ${ \mathrm { C O } } _ { 2 }$ reduction [24], hydrogen production [25], organic synthesis [26], the disinfection of bacteria and the degradation of organic pollutants [6]. Among various photocatalysts, graphitic carbon nitride $\left( { { \bf { g } } { - } { \bf { C } } _ { 3 } { \bf { N } } _ { 4 } } \right)$ has become one of the most attractive options. The structure of $\mathrm { g - C _ { 3 } N _ { 4 } }$ is a two-dimensional framework of tri-s-triazines connected via tertiary amines, which guarantees its high thermal (up to $6 0 0 ~ ^ { \circ } \mathrm { C }$ in air) and chemical stability (against acids, bases, and organic solvents) [27e32]. This material exhibits promise with a suitable band gap (ca. $2 . 7 \ \mathrm { e V } ,$ ), numerous preparative methods, low cost and environmental friendliness [33e35]. Nevertheless, the drawbacks of serious aggregation, low visible-light response and high recombination of electron-hole pairs have seriously limited its practical application [36]. To address these issues, our group proposed to introduce minerals as a support of $\mathrm { g - C _ { 3 } N _ { 4 } }$ to solve the problem of aggregation (i.e., kaolinite [37], wollastonite [38], mullite [39] and montmorillonite [40]). Although the photocatalytic performance was improved to a certain extent, the photocatalytic activity of the above-mentioned composites remained at a low level due to the high recombination of electron-hole pairs. It has been reported that noble metal deposition is a good option for constructing a plasmonic nanostructure, which could efficiently facilitate the electronhole pairs’ separation and transport. Generally, $\mathsf { A g }$ nanoparticles can be deposited on the surface plane of $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 } ,$ , and because of the surface plasmon resonance (SPR) effect [25,26], they could induce an intense local electromagnetic field, thereby increasing the release rate of charge carriers. In addition, Ag nanoparticles could act as electron sinks accelerating the electron transfer on the catalyst surface [41]. Hence, it is significant and suitable to develop the composite through the combination of ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 } ,$ , mineral and Ag nanoparticle for the enhancement in photocatalytic activity. It is noteworthy that kaolinite is a typical clay mineral endowed with a 1:1 layered structure (i.e., one tetrahedral sheet and one octahedral sheet form a layered structural unit). In addition, kaolinite has usually been used to synthesize macro-micro (adsorption-photocatalytic) composite materials with high efficiency because of its high adsorption capacity, low cost, stable physicochemical properties, abundant reserves and non-secondary pollution. Therefore, the layered structure of kaolinite seems to be an attractive option as a catalyst carrier to synthesize a 2D/2D hierarchical structure.

In this work, we report that $\mathsf { A g }$ nanoparticles anchored on the surface of ${ \bf g - C } _ { 3 } { \bf N } _ { 4 } ,$ kaolinite to serve as a high-efficiency photocatalyst for IBP degradation under visible-light illumination via a two-step assembly strategy. The crystal phase, micromorphology, specific surface area, pore structure and surface chemical states of as-prepared samples were systematically investigated. The photoactivity enhancement mechanisms of the as-synthesized composites were explored as well. The pathway of IBP degradation was also proposed based on the detected intermediate products.

# 2. Experimental

# 2.1. Materials

Ibuprofen (IBP), dicyandiamide $\left( \mathsf { C } _ { 2 } \mathsf { H } _ { 4 } \mathsf { N } _ { 4 } \right)$ , ethanol $\left( \mathsf { C } _ { 2 } \mathsf { H } _ { 5 } \mathsf { O } \mathsf { H } \right)$ glycol $( ( \mathrm { C H } _ { 2 } \mathrm { O H } ) _ { 2 }$ ), potassium bichromate $( \mathrm { K } _ { 2 } \mathrm { C r } _ { 2 } 0 _ { 7 } ) ,$ , polyvinylpyrrolidone (PVP), ammonium oxalate $( ( \mathrm { N H } _ { 4 } ) _ { 2 } C _ { 2 } 0 _ { 4 } )$ , 1,4- benzoquinone (BQ), and tert-butyl alcohol (t-BuOH) were purchased from Beijing Reagent Co. (Beijing, China). All reagents were of analytical reagent grade without any further purification. HPLCgrade formic acid, methanol and acetonitrile were obtained from Merck Co. The kaolinite was provided by Suzhou City, Jiangsu Province. Deionized water was used throughout the experiments.

# 2.2. Composite preparation

Bulk $\mathrm { g - C _ { 3 } N _ { 4 } }$ powder was fabricated according to the previously reported method [37]. Typically, $1 0 . 0 { \mathrm g }$ of dicyandiamide was added to an alumina crucible that was heated with a heating rate of $2 . 3 \ \mathrm { ^ { \circ } C \ m i n ^ { - 1 } }$ to $5 5 0 ~ ^ { \circ } C$ for $^ \textrm { \scriptsize 4 h }$ . The final yellow product was collected for further use.

The ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ /kaolinite (KCN) was prepared by a facile impregnation-calcination process. First, $1 . 0 \mathrm { ~ g ~ }$ of kaolinite was dispersed into $6 0 ~ \mathrm { m L }$ of deionized water with continuous stirring for $1 0 \mathrm { m i n }$ in a water bath at $6 0 ^ { \circ } C$ . Second, $4 . 0 \ : \mathrm { g }$ of dicyandiamide was added to the kaolinite suspension under stirring for $^ { 1 2 \mathrm { ~ h ~ } }$ . The suspension was then dried in an oven at $1 0 5 ~ ^ { \circ } \mathrm { C }$ for $1 0 \ \mathrm { h }$ and then heated at $5 5 0 ^ { \circ } C$ for $^ { 4 \mathrm { h } }$ . Finally, the resultant product was milled to powder for further use.

The $\sf A g / g \mathrm { - } \sf C _ { 3 } \mathrm { N } _ { 4 } |$ kaolinite composites were synthesized as illustrated in Fig. 1. First, $_ { 0 . 2 \ \mathrm { g } }$ of KCN was added to $2 0 ~ \mathrm { m L }$ of a glycol solution. Then, the obtained suspension was dispersed through ultrasonication for 30 min. Afterwards, $_ { 0 . 2 \mathrm { ~ \scriptsize ~ g ~ } }$ of polyvinylpyrrolidone and different volumes of the ${ \sf A g N O } _ { 3 }$ solution $. 1 \% .$ , $3 \%$ , $5 \%$ , $7 \%$ and $9 \%$ mass ratios of Ag content) were mixed with the suspension. Then, the suspensions were exposed to the ultraviolet irradiation of a 300 W mercury arc lamp (CEL-HXF300, Ceaulight, Beijing) with stirring for $3 0 \ \mathrm { m i n }$ . The final gray suspension was centrifuged and washed with deionized water three times for purification, and the products were subsequently dried in a vacuum drying oven at $6 0 ~ ^ { \circ } \mathsf C$ for $^ { 4 \mathrm { ~ h ~ } }$ . The $\mathsf { A g } / \mathsf { g } { - } \mathsf { C } _ { 3 } \mathsf { N } _ { 4 } /$ kaolinite composites were marked as $\sf { A g / K C N - X }$ , where $\mathsf X$ represented the theoretical mass ratio of $\sf { A g / K C N }$ in the preparation (i.e., $1 \%$ , $3 \%$ , $5 \%$ , $7 \%$ and $9 \%$ ). The actual Ag contents of the different $\sf { A g / K C N - X }$ photocatalysts and the analysis method are provided in Text S1. The average $\mathsf { A g }$ loadings in $\sf A g / K C N - 1 \%$ , $\mathrm { A g / K C N - 3 \% }$ , $A g / \mathrm { K C N } { - 5 \% }$ , $A g / \mathrm { K C N - 7 \% }$ , and $\sf { A g / K C N - 9 \% }$ were measured to be $0 . 2 7 \%$ , $1 . 8 3 \%$ , $2 . 3 \%$ $2 . 9 7 \%$ and $3 . 9 7 \%$ , respectively. Furthermore, $\mathrm { A g / g { - } C _ { 3 } N _ { 4 } { - } } 7 \%$ $( \mathsf { A g } / \mathsf { C N } { - } 7 \% )$ was prepared according to above-mentioned procedure by using $\mathrm { g - C _ { 3 } N _ { 4 } }$ instead of KCN.

# 2.3. Characterization

X-ray powder diffraction (XRD) was measured on a D8 advance X-ray diffractometer (Bruker, Germany) equipped with $\mathrm { C u - K } \mathfrak { a }$ radiation $\left( \lambda = 0 . 1 5 4 0 5 6 \mathrm { n m } \right.$ ). The range of 2q was from $5 ^ { \circ }$ to $8 0 ^ { \circ }$ with a scanning rate of $4 ^ { \circ } / \mathrm { m i n }$ . The surface morphology of the asprepared composites was examined via scanning electron microscopy (SEM) (S-4800, Hitachi, Japan) with energy dispersive spectrum analysis (EDS) at $5 . 0 \ \mathrm { k V } .$ . In addition, TEM images were obtained on a Tecnai G2 F20 field-emission transmission electron microscope. Photoluminescence (PL) spectra were recorded with a fluorescence spectrophotometer (F-7000, Hitachi, Japan) at an excitation wavelength of $3 6 0 ~ \mathrm { \ n m }$ . UVevis diffuse reflectance spectroscopy (DRS) was used to detect the reflectance spectra of the composites over the range of $2 0 0 { - } 8 0 0 \ \mathrm { n m }$ on a UVevis spectrophotometer (UV-9000s, Shanghai Metash Instruments Co.). The specific surface areas were determined by JW-BK (JWGB Sci. & Tech., Beijing) at liquid nitrogen temperature (77 K), and the poresize distributions were calculated from the adsorption branch of the isotherm based on the Barrett-Joyner-Halenda (BJH) model. # 2.4. Evaluation of photocatalytic activity

Ibuprofen (IBP) was chosen as the model pollutant to evaluate the photocatalytic performance of as-prepared composites under a 500 W xenon lamp (Beijing Pulinsaisi plant, China) with a $4 0 0 \ \mathrm { n m }$ cut-off filter. First, $5 0 \mathrm { m g }$ of photocatalyst was dispersed in $5 0 \mathrm { m L }$ of an aqueous solution of IBP (5 ppm) with ultrasonic treatment for $5 ~ \mathrm { m i n }$ . Then, the stabilized suspension was transferred to a cylindrical reactor with a magnetic agitator. Before the visible-light irradiation, $_ { 0 . 5 \mathrm { ~ h ~ } }$ of dark reaction was conducted to achieve the adsorption-desorption equilibrium on the surface of the composite. At a given time interval, $1 . 5 ~ \mathrm { m L }$ of suspension was sampled and filtered via a $0 . 2 2 ~ { \mu \mathrm { m } }$ filter. The remaining IBP was determined by an HPLC (LC-2030C Shimadzu, Japan) equipped with a C18 reversed-phase column $( 4 . 6 \times 2 5 0 ~ \mathrm { m m }$ , $5 ~ { \mu \mathrm { m } } \dot { \mathrm { \Omega } }$ ). The mobile phase was composed of acetonitrile $1 0 . 1 \%$ acetic acid (70/30). The flow rate of the mobile phase was $1 . 0 \ \mathrm { m L / m i n }$ (injection volume: $1 0 \ \mu \mathrm { L } ,$ column temperature: $3 0 3 \mathrm { K } ,$ , and the wavelength for UV detection: $2 2 3 { \mathrm { ~ n m } }$ ). The degradation byproducts of the pollutant were tested by the liquid chromatography-mass spectrometry (LC-MS, Agilent 1100-Thermos TSQ Quantum Ultra).

# 2.5. Photoelectrochemical measurement

The photoelectrochemical properties of the as-prepared composites were recorded via an electrochemical workstation. The working electrodes were prepared similar to our previous report: $3 0 ~ \mathrm { m g }$ of as-prepared composite was added into $1 \ \mathrm { m L }$ of ethanol and ultrasonicated for $1 5 ~ \mathrm { m i n }$ to obtain a stable suspension. Then, the suspension was spread out on an ITO slide with a fixed area of $2 \mathrm { c m } ^ { 2 }$ and dried naturally. Afterwards, the ITO slide was placed into an oven for $^ { 4 \mathrm { ~ h ~ } }$ at $8 0 ~ ^ { \circ } \mathrm { C } .$ A standard three-electrode system was prepared by the composite as the working electrode, a Pt wire as the counter electrode, and $\mathsf { A g } / \mathsf { A g C l }$ as a reference electrode. A 500 W Xe arc lamp with a $4 0 0 \ \mathrm { n m }$ cut-off filter was utilized to provide visible light. The photocurrent measurement and electrochemical impedance spectroscopy (EIS) were performed in a $0 . 1 \mathrm { ~ M ~ }$ ${ \Nu } _ { 4 } { \tt S O } _ { 4 }$ aqueous solution.

# 3. Results and discussion

# 3.1. Morphology and structure of the photocatalysts

The morphology and microstructure of the as-prepared composites were revealed by SEM and TEM images. As presented in Fig. 2 (a) and Fig. S2 (a), the kaolinite displayed a typically smooth 2D sheet structure. The layered structure might have provided enough surface area to not only adsorb pollutants but also attach exfoliated $\mathrm { g - C _ { 3 } N _ { 4 } }$ sheets. As seen from Fig. 2 (c) and Fig. S2 (c), g$\mathrm { C } _ { 3 } \mathrm { N } _ { 4 }$ was uniformly attached on the surface of kaolinite, which preferably solved the agglomeration situation and provided more attachment sites for Ag nanoparticles. Fig. 2 (d) indicates that the Ag nanoparticles were unevenly dispersed on the surface of $g { \mathrm { - } } { \mathsf { C } } { \mathrm { 3 N } } _ { 4 }$ . For $A g / C N { - } 7 \%$ , which is shown in Fig. 2 (e), the Ag nanoparticles were dispersed on the surface of KCN more uniformly, suggesting more reactive sites could be exposed. The sizes of the $\mathsf { A g }$ nanoparticles (inserted in Fig. 2 (e)) on the $A g / \mathrm { K C N - 7 \% }$ surface was measured and analyzed as well. Obviously, with the help of PVP, the size of the Ag nanoparticles in $A g / \mathrm { K C N - 7 \% }$ mainly ranged from 3 to $5 \mathrm { n m }$ . Since PVP is a multidentate ligand, it could combine with the $\mathsf { A g }$ nanoparticles via coordinating with its ${ \sf N - C } mathrm { = } 0$ groups, which also played the role of mechanical inhibition. On the other hand, its long molecular chains could coat the surface of Ag particles to restrain agglomeration and control the formation of $\mathsf { A g }$ nanoparticles [42]. Furthermore, the elemental distribution of the $\mathsf { A g } /$ KCN- $. 7 \%$ composite was observed by energy-dispersive $\mathsf { X }$ -ray spectroscopy (EDS) mapping for Si, Al, O, N, C and Ag. As shown in Fig. 2 (g), the uniform distribution of Si, Al, O, N, C and Ag elements demonstrated the good distribution of Ag nanoparticles on the surface of KCN.

# 3.2. Phase and chemical bonding of photocatalysts

The phase structures of as-prepared composites were further explored by XRD. As shown in the XRD patterns (Fig. 3 (a)), the peak at $1 2 . 2 8 ^ { \circ }$ was indexed as the (001) crystal plane of kaolinite (JCPDS No.14e0164). Additionally, the diffraction peaks at $2 4 . 8 2 ^ { \circ }$ , $3 8 . 3 4 ^ { \circ }$ and $6 2 . 2 6 ^ { \circ }$ corresponded well with the (002), $( - 2 0 2 )$ and (060) planes of kaolinite [43]. No obvious characteristic peaks of kaolinite were observed in the patterns of KCN and the $A g / C N { - } 7 \%$ and $\mathsf { A g } /$ KCN-X composites, which might have been caused by the decrease in the stacking of kaolinite layers during the calcination, as well as the proceeding dehydroxylation reaction [44]. Two characteristic peaks at $1 2 . 7 4 ^ { \circ }$ and $2 7 . 7 0 ^ { \circ }$ could be indexed as the $\mathrm { g - C _ { 3 } N _ { 4 } }$ (100) and (002) planes (JCPDS No.87e1526), respectively, which appeared in the $A g / C N { - } 7 \%$ and $\sf { A g / K C N - X }$ composites. For the $\mathsf { A g } /$ KCN-X composites (Fig. 3 (b)), the peak at $2 7 . 7 0 ^ { \circ }$ was slightly shifted to a lower angle, which might have been due to the introduction of Ag nanoparticles on the surface of KCN. For all $\sf { A g / K C N }$ composites, no obvious diffraction peaks could be detected for crystalline Ag, which perhaps was the result of the small-size and uniform distribution of Ag nanoparticles.

The FTIR spectra were obtained to evaluate the chemical bonding of the composites. Fig. S3 shows an absorption peak of kaolinite at the range of $3 6 0 0 { - } 3 7 0 0 \mathrm { c m } ^ { - 1 }$ , which could be assigned to the O-H stretch of Al-O-H groups. Furthermore, the peaks in the range of $7 0 0 { - } 1 2 0 0 ~ \mathrm { c m } ^ { - 1 }$ could correspond to the Si-O stretches [45,46]. For the Ag/KCN-X composites, the slight peak located in the scope of $9 0 0 { - } 1 1 0 0 \ \mathrm { ~ c m } ^ { - 1 }$ could be associated with the Si-O stretches of kaolinite, indicating the formation of a tight connection between kaolinite and $\mathrm { g - C _ { 3 } N _ { 4 } }$ . For the $\mathrm { g - C _ { 3 } N _ { 4 } }$ catalyst, the broad peak between 3000 and $3 5 0 0 ~ \mathrm { c m } ^ { - 1 }$ was interpreted as the stretching vibrations of N-H and surface adsorbed water molecules.

# 3.3. Surface chemical composition and status of photocatalysts

The surface chemical composition and status of $g { - } C _ { 3 } \Lambda _ { 4 } ,$ , KCN and $A g / \mathrm { K C N - 7 \% }$ were evaluated by XPS. As shown in Fig. 4 (a) and Fig. S4 (a), the survey spectra indicated that $\mathrm { g - C _ { 3 } N _ { 4 } }$ was composed of C and N elements, and KCN was constituted by C, N, O and Si elements, while the $A g / \mathrm { K C N - 7 \% }$ composite was made up by C, N, O, Si and Ag elements. Fig. 4 (b) shows the C 1s spectrum of the composite, which revealed three main peaks centered at 284.7 eV, 285.8 eV and $2 8 8 . 1 \mathrm { e V } .$ . The peak at $2 8 4 . 7 \mathrm { e V }$ was related to the $\mathsf { s p } ^ { 2 } \mathsf { C } \mathsf { - C }$ bonds, while the peaks at $2 8 5 . 8 \ : \mathrm { e V }$ and 288.1 eV were associated with the C-N and $C \mathrm { - } ( \mathsf { N } ) _ { 3 }$ bonds of $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ , respectively [49]. However, in the C 1s spectra of $\mathrm { g - C _ { 3 } N _ { 4 } }$ and KCN (Fig. S4 (b)), the peak of the $C \mathrm { - } ( \mathsf { N } ) _ { 3 }$ bond, at binding energies of $2 8 8 . 5 \ \mathrm { e V }$ and $2 8 8 . 3 \ \mathrm { e V }$ , was higher in energy than the corresponding peak in $A g / \mathrm { K C N - 7 \% }$ . This result might have been due to the introduction of kaolinite and Ag nanoparticles. As shown in Fig. 4 (c) and Fig. S4 (c), the N 1s spectra of $\mathrm { g - C _ { 3 } N _ { 4 } }$ , KCN and the $A g / \mathrm { K C N - 7 \% }$ composite could be divided into three peaks. The peak at 398.6 eV was assigned to the $\mathsf { s p } ^ { 2 } \mathsf { C } { = } \mathsf { N }$ bond, the peak at $3 9 9 . 4 \mathrm { e V }$ was ascribed to $\mathsf { s p } ^ { 3 }$ -hybridized nitrogen N- $( \mathsf { C } ) _ { 3 }$ bonds, and the peak at $4 0 0 . 5 \mathrm { e V }$ was indicative of the C-N-H groups of $\mathrm { g - C _ { 3 } N _ { 4 } }$ [50,51]. The Si 2p spectra (Fig. 4 (d) and Fig. S4 (d)) were fitted with three peaks, which corresponded to Si-O-Si, Si-OH and Si-O-C bonds. The formation of Si-O-C bonds demonstrated the reaction between kaolinite and $\mathrm { g - C _ { 3 } N _ { 4 } }$ during the calcination at $5 5 0 ~ ^ { \circ } C$ [52]. In the O 1s spectrum (Fig. 4 (e)), three peaks were detected at $5 3 1 . 3 \mathrm { e V }$ (Si-O-Si), 532.2 eV (Si-O-H) and $5 3 3 . 2 \mathrm { e V }$ (Si-OC), respectively [53]. After $\mathsf { A g }$ nanoparticles were loaded on the surface of KCN, the Ag 3d (Fig. 4 (f)) revealed two main peaks located at 368.1 eV and $3 7 4 . 1 \ \mathrm { e V }$ with a spin-orbital energy separation of $6 . 0 \mathrm { e V } ,$ , which was consistent with the metallic silver $( \bar { \mathsf { A g } } ^ { 0 } )$ peaks of the $A g / \mathrm { K C N - 7 \% }$ composite [54].

# 3.4. Pore structure and specific surface area of photocatalysts

The nitrogen adsorption-desorption isotherms of the asprepared composites were obtained to further analyze the porous structure. According to Fig. S5, all composites exhibited the type-IV curves with a hysteresis loop, representing their typical mesoporous structures. As presented in Table S1, compared with $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } ,$ the specific surface area of KCN $( 2 7 . 4 0 ~ \mathrm { m } ^ { 2 } ~ \mathrm { g } ^ { - 1 } \mathrm { . }$ ) showed significant improvements, suggesting that abundant microporous and mesoporous pores derived from interfacial interaction were generated after introducing kaolinite. The results were of benefit to the attachment of Ag nanoparticles and the incorporation of monodispersed Ag nanoparticles on the surface of KCN sheets. $\sf { A g / K C N - }$ $7 \%$ $( 3 5 . 9 6 \ \mathrm { \Large ~ m } ^ { 2 } \ \mathrm { \bf ~ g } ^ { - 1 } ) \nonumber$ possessed the largest specific surface area owing to the uniform dispersion of Ag nanoparticles on the surface of KCN. Seen from the pore distributions of all composites (insert in Fig. S5 and Table S1), $\mathrm { g - C _ { 3 } N _ { 4 } }$ exhibited the smallest pore volume $( 0 . 0 3 6 \mathrm { c m } ^ { 3 } \mathrm { g } ^ { - 1 } .$ ), which might have been caused by the agglomeration of $\mathrm { g - C _ { 3 } N _ { 4 } }$ nanosheets. However, the $A g / \mathrm { K C N - 7 \% }$ showed the maximum pore volume $( 0 . 0 8 0 ~ \mathrm { c m } ^ { 3 } ~ \mathrm { g } ^ { - 1 } )$ which could have contributed to the dynamic adsorption, desorption and diffusion of IBP on the surface of $A g / \mathrm { K C N - 7 \% }$ .

# 3.5. Optical properties of photocatalysts

UVevis diffuse reflectance spectroscopy (DRS) was employed to explore the optical properties of the as-prepared composites. As seen in Fig. 5 (a), all composites absorbed UV and visible light with an absorption edge at approximately $4 5 0 ~ \mathrm { { n m } }$ [55]. The enhanced absorption performance promoted the generation of more electrons so that the $\mathsf { A g } / \mathsf { C N }$ and $A g / \mathrm { K C N - 7 \% }$ composites exhibited better photocatalytic performance than that of $\mathrm { g - C _ { 3 } N _ { 4 } }$ . The band gap of the composites was presented in Fig. 5 (b). No significant change was found among these composites, indicating the kaolinite and Ag nanoparticles had no significant effect on the band gap of $\mathrm { g - C _ { 3 } N _ { 4 } }$ .

# 3.7. Photoelectrochemical performance of photocatalysts

As shown in Fig. S7 (a), the photocurrent response of $A g / \mathrm { K C N - 7 \% }$ was significantly enhanced under visible-light irradiation, which was more than twice that of $A g / C N { - } 7 \%$ . The migration and interface reaction ability of the charges in the photocatalytic catalysts could be evaluated by EIS as well. The Nyquist plots are exhibited in Fig. S7 (b). The arc radius of the EIS plot for the $A g / \mathrm { k C N - 7 \% }$ composite was smaller than that of the other composites, revealing that the separation and transfer efficiency of electron-hole pairs was greatly increased. As shown in Fig. 7 (b), the Mott-Schottky plots were obtained to study the relation between the capacitance of the space charge region and the applied potential. # 3.9. Main active species in the photodegradation process of IBP

During the photocatalytic degradation of IBP, the hydroxyl radicals $( ^ { \bullet } \mathrm { O H } )$ and superoxide radical anions $( ^ { \bullet } 0 _ { 2 } ^ { - } )$ were identified as the representative reactive oxidative species. EPR spectroscopy of the $A g / \mathrm { K C N - 7 \% }$ composite was performed using DMPO as the species trapper. As shown in Fig. 9 (a), no obvious signal was observed in the dark. However, after irradiation for $6 0 \ s .$ , six characteristic peaks were detected, indicating that $\cdot _ { 0 _ { 2 } }$ was produced in the process of the reactions. The appearance of $\cdot _ { 0 _ { 2 } }$ could be attributed to the process of ${ { 0 } _ { 2 } }$ being reduced to $\cdot _ { 0 _ { 2 } }$ by electrons $( \mathsf { e } ^ { - } )$ . As shown in Fig. 9 (b), no obvious signals could be detected under dark or visible-light conditions, demonstrating that no $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ was generated in the $A g / \mathrm { K C N - 7 \% }$ dispersions. Since the VB of $\mathsf { A g } /$ $K C N - 7 \%$ was approximate $2 . 2 0 ~ \mathrm { { \ e V } }$ , lower than $\mathsf { E } ^ { \theta }$ $( { \mathrm { O H } } ^ { - } / { ^ { \bullet } \mathrm { O H } } )$ (2.40 eV vs NHE), $\mathrm { h ^ { + } }$ could not oxidize $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ and change $\mathrm { O H ^ { - } }$ into  OH [62].

Generally, $\mathtt { e } ^ { - }$ and $\mathrm { h ^ { + } }$ were considered as the reactive species. Therefore, the most important role in the photocatalytic process was evaluated by the trapping experiments. The scavengers employed in this study were $\mathrm { C r } ( \mathsf { V I } )$ , $t { \mathrm { - B u O H } }$ , $( \mathrm { N H } _ { 4 } ) _ { 2 } C _ { 2 } 0 _ { 4 }$ and benzoquinone to snare $\mathtt { e } ^ { - }$ ,  OH, $\mathrm { h ^ { + } }$ and $\cdot _ { 0 _ { 2 } }$ , respectively. As shown in Fig. 9 (c), after adding $( \mathrm { N H } _ { 4 } ) _ { 2 } C _ { 2 } 0 _ { 4 } ,$ , the photocatalytic degradation of IBP was significantly depressed, while the degradation efficiency was weakly inhibited by adding $\mathrm { C r } ( \mathsf { V I } )$ . The above results demonstrated that $\mathrm { h ^ { + } }$ was the key species and $\mathtt { e } ^ { - }$ acted as the secondary active species during the whole degradation reaction. However, the scavengers of $t { \mathrm { - B u O H } }$ and benzoquinone had less effects on the degradation of IBP, indicating that $\cdot _ { \mathrm { O H } }$ and $\cdot _ { 0 _ { 2 } }$ were not the crucial reactive species in the photocatalytic process. In addition, the $\mathsf { A g }$ nanoparticles could be excited to form electrons under visible-light irradiation, further promoting the transformation from ${ { 0 } _ { 2 } }$ to $\mathbf { \bar { \rho } } _ { \mathbf { 0 } _ { 2 } ^ { - } }$ .

According to the above results, the proposed mechanism for the $A g / \mathrm { K C N - 7 \% }$ composite in the photocatalytic degradation of IBP is illustrated in Fig. 10. Therefore, the $\mathsf { A g }$ nanoparticles could evenly distribute on the surface of KCN, leading to the exposure of more reactive sites, and further improve the electron transport efficiency. Furthermore, the carrier effect of kaolinite enhanced the photocatalytic activity, including an enhanced spectral absorption capacity and a regulation of the surface negative electricity on photogenerated carriers’ migration.

# 4. Conclusion

A series of $\sf A g / g \mathrm { - } \sf C _ { 3 } \mathrm { N } _ { 4 } |$ kaolinite composites with different Ag contents were successfully prepared via a two-step assembly strategy by employing an in-situ calcination and photodeposition process. The as-prepared composite possessed a higher specific surface area $( 3 5 . { \overset { \cdot } { 9 } } 6 \ { \overset { \cdot } { \mathrm { m } } } ^ { 2 } \ \mathbf { g } ^ { - 1 } ) .$ and pore volume $( 0 . 0 8 0 \mathrm { c m } ^ { 3 } \mathrm { g } ^ { - \bar { 1 } } \cdot$ ). The photogenerated current densities, EIS spectra and Mott-Schottky plots showed that the $\sf A g / g \mathrm { - } \sf C _ { 3 } N _ { 4 } /$ kaolinite composite was endowed with an efficient separation and transfer of electron-hole pairs. The $\mathsf { A g } / \mathsf { g }  – \mathsf { C } _ { 3 } \mathsf { N } _ { 4 } /$ kaolinite composite exhibited a superior photocatalytic activity towards ibuprofen (IBP) compared with that of bulk $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ , $\mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } /$ kaolinite and $\sf A g / g \mathrm { - } \sf C _ { 3 } N _ { 4 }$ . After $^ { 5 \mathrm { ~ h ~ } }$ irradiation, the removal efficiency of IBP reached $9 9 . 9 \%$ , and its reaction rate constant was $0 . 0 1 1 2 8 \mathrm { \ m i n } ^ { - 1 }$ , which was 1.87 times that of the $\sf A g / g \mathrm { - } C _ { 3 } N _ { 4 }$ composite. The enhanced photocatalytic activity was attributed to the decreased recombination rate of electron-hole pairs. Furthermore, monodispersed Ag nanoparticles, with a diameter ranging from 3 to $5 \textrm { n m }$ , on the surface of KCN provided more reactive sites. After five successive cycles, the removal efficiency of the $\sf A g / g \mathrm { - } \cal C _ { 3 } \mathrm { N } _ { 4 } |$ kaolinite composite was still above $9 0 \%$ . The proposed oxidation products were also analyzed by LC-MS, and the results suggested that decarboxylation and hydroxylation were the major reaction mechanisms during the degradation processes of IBP. In addition, according to the EPR study and trapping experiments, it was demonstrated that $\mathrm { h ^ { + } }$ was the key species, while the $\mathtt { e } ^ { - }$ acted as the secondary active species during the IBP degradation process. Based on the overall analysis, this work provides certain new insights into the preparation of a highly efficient visible-light-driven photocatalyst for practical application in environmental remediation.
