# Unraveling the Fundamentals of Axial Coordination FeN4+1 Sites Regulating the Peroxymonosulfate Activation for Fenton-Like Activity

Sijia Jin, Wenxian Tan, Xiaofeng Tang, Mengxuan Li, Xinyi Yu, Haiyan Zhang, Shuang Song, and Tao Zeng\*

Precise modulation of the axial coordination microenvironment in single-atom catalysts (SACs) to enhance peroxymonosulfate (PMS) activation represents a promising yet underexplored approach. This study introduces a pyrolysis-free strategy to fabricate SACs with well-defined axial- $\cdot F e N _ { 4 + 7 }$ coordination structures. By incorporating additional out-of-plane axial nitrogen into welldefined $\mathsf { F e N } _ { 4 }$ active sites within a planar, fully conjugated polyphthalocyanine framework, $\mathsf { F e N } _ { 4 + 1 }$ configurations are developed that significantly enhance PMS activation. The axial $\cdot F e N _ { 4 + 7 }$ catalyst excelled in activating PMS, with a high bisphenol A (BPA) degradation rate of $2 . 2 5 6 \ : \mathrm { m i n ^ { - 1 } }$ , surpassing planar$\mathsf { F e N } _ { 4 } / \mathsf { P M S }$ systems by 6.8 times. Theoretical calculations revealed that the n $\mathsf { F e N } _ { 4 + 1 }$ structure, disrupting the electron distribution symmetry of Fe and optimizing the electron distribution of the Fe 3d orbital (increasing the d-band center from —1.231 to —0.432 eV). Consequently, this led to an enhanced perpendicular adsorption energy of PMS from $- 1 . 7 9$ to −1.82 eV and reduced energy barriers for the formation of the key reaction intermediate $( \mathbf { O } ^ { * } )$ that generates $\mathbf { \bar { \rho } } _ { \mathbf { O _ { 2 } } }$ . This study provides new insights into PMS activation through the axial coordinated engineering of well-defined SACs in water purification processes.

# 1. Introduction

Celebrated for their unparalleled atom utilization efficiency and tunable electronic structure, single-atom catalysts (SACs)

represent a pivotal bridge between homogeneous and heterogeneous catalysis.[1] Within the domain of peroxymonosulfate (PMS)-based advanced oxidation processes (AOPs), SACs have emerged as compelling alternatives poised to replace conventional heterogeneous nanoparticle counterparts.[2] This transition offers a dual advantage in this Fenton-like catalysis: not only does it mitigate intrinsic issues like particle detachment and agglomeration, but it also overcomes the sluggish reaction kinetics and limited catalytic selectivity commonly encountered with traditional heterogeneous catalysts.[3] For instance, a singlesite Fe catalyst demonstrates the ability to achieve $100 \%$ generation of singlet oxygen $( ^ { 1 } { \mathsf { O } } _ { 2 } )$ via PMS activation, resulting in ultrahigh p-chlorophenol degradation efficiency, with rate constant measuring 5.4 times higher than that of Fe nanoparticles (NPs).[4] Additionally, the elucidation of PMS activation by Co single-atom sites also reveals a nonradical pathway, wherein the rate constant of Co SACs surpasses that of Co NPs and Co atomic clusters by factors of 10.55 and 6.27, respectively.[5]

Among all SACs, discrete metal (M) sites coordinated with multiple nitrogen atoms $( \mathrm { M N } _ { x } )$ on carbon-based supports $( \mathrm { M N } _ { x } / \mathrm { C } )$ stand as focal points of investigation.[3b,6] While substantial progress has been made, most research on modified $\mathrm { F e N } _ { 4 }$ focuses on tuning the metal center $[ \mathsf { M } = \mathsf { F e }$ , Co, Cu, Mn),[7] the nitrogen coordination number $( \mathrm { M N } _ { x }$ , $x = 1 - 6$ ),[8] and substituting nitrogen with other non-metallic elements (e.g., O, S, and P).[9] However, the majority of studies have concentrated on optimizing in-plane coordination configurations,[10] with relatively little attention given to the role of out-of-plane axial coordination in PMS activation. Despite considerable efforts, a significant gap remains in understanding the precise reactive sites and mechanisms governing $\mathrm { M N } _ { x } / \mathrm C$ -mediated PMS activation, limiting insights into structure-activity relationships. Since PMS interacts with the central metal atom in a perpendicular orientation, axial charge redistribution at the metal centers plays a key role in modulating binding affinities between SACs and PMS molecules or intermediates.[11] This is particularly crucial as the $\mathrm { M } - \mathrm { O }$ bonding between PMS species and $\mathrm { M N } _ { x }$ sites entails orbital overlap in the axial direction relative to the $\mathrm { M N } _ { x }$ plane.[12] Nonetheless, the deliberate engineering of axial coordination $\mathrm { M N } _ { x }$ units within a carbon matrix poses significant challenges, largely due to the inherent structural uncertainties arising from uncontrolled hightemperature pyrolysis synthesis $( > 7 0 0 ^ { \circ } \mathrm { C } )$ , which often result in metal site aggregation and uncontrolled structural outcomes.[13] These limitations obscure the precise understanding of the active sites and reaction mechanisms involved in PMS activation. Overcoming these challenges requires the development of welldefined model catalyst systems that allow for the precise investigation of the regulatory mechanisms behind the axial coordination of SACs.

Precisely defined $\mathrm { M N } _ { 4 }$ macrocyclic molecules, like metal phthalocyanines (MPcs), offer an attractive platform for elucidating reaction mechanisms owing to their readily adjustable sites.[14] Nonetheless, conventional monomolecular MPcs often suffer from sluggish kinetics during PMS activation, attributed to their limited charge transport capabilities. Additionally, their inherent $\mathrm { D } _ { 4 \mathrm { h } }$ symmetry (a point group with a fourfold rotational axis and a horizontal mirror plane) configuration with localized electrons poses challenges for axial coordination with metal centers, impeding a comprehensive understanding of axial modulation mechanisms in PMS activation.[15] Addressing these limitations, the concept of metal polyphthalocyanine (MPPc) frameworks arises, wherein MPcs units are covalently linked to form extended $\pi$ -conjugated architectures.[16] Leveraging the enhanced electron delocalization facilitated by the conjugated $\pi$ bonds within $\mathrm { P c }$ motifs, MPPc exhibits improved charge transport properties and diminished electron density around the $\mathrm { M N } _ { 4 }$ center, thereby affording enhanced axial coordination capabilities.[17] Consequently, MPPc emerges as an effective model catalyst for precisely modulating the axial coordination environment of SACs and elucidating structure-property relationships during PMS activation mechanisms, a realm hitherto scarcely explored.

In this investigation, we have synthesized well-defined $\mathrm { F e N } _ { 4 }$ active-site configurations within a two-dimensional (2D) planar fully conjugated PPc framework (denoted as planar- $\mathrm { \cdot F e N _ { 4 , } }$ , thereby presenting a tunable atomic model for subsequent axial coordination. Through the facile introduction of nitrogen-doped graphene (NG) as a supporting matrix, we have achieved additional axial nitrogen coordination with $\mathrm { F e N } _ { 4 }$ sites, leading to the formation of a $\mathrm { F e N } _ { 4 + 1 }$ site structure (denoted as axial- $\mathrm { F e N } _ { 4 + 1 }$ , within the 2D/2D face-to-face contact interfaces between PPc and NG. This out-of-plane coordination has resulted in the modification of the electronic structure of the Fe sites, characterized by an asymmetrical charge density distribution, consequently impacting the central Fe atoms and influencing the subsequent adsorption and activation of PMS. In comparison to planar- $\mathrm { F e N } _ { 4 }$ , the axial $\mathrm { F e N } _ { 4 + 1 }$ demonstrated significantly enhanced PMS activation for bisphenol A (BPA) degradation, with a pseudo firstorder rate constant $( k _ { \mathrm { o b s } } )$ of $2 . 2 5 6 \operatorname* { m i n } ^ { - 1 } - \mathrm { a } 6 . 8 \cdot$ fold increase over planar $\mathrm { \cdot F e N _ { 4 } }$ A mechanistic investigation has revealed the crucial role of axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ coordination in modulating electron distribution within the Fe 3d orbital. Furthermore, it significantly led to an enhanced adsorption energy of PMS and reduces the energy barrier associated with the formation of the key reaction intermediate $[ 0 ^ { * }$ intermediate), thereby facilitating the highly selective generation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ . The combination of axial- $\mathrm { F e N } _ { 4 + 1 }$ with membrane technology consistently achieves above $9 3 \%$ BPA removal with negligible iron leakage during $1 5 \mathrm { h }$ of continuous operation, indicating promising practical applications for water decontamination. This study presents a well-definedmodel for investigating the functionality of axial coordination engineering and provides insights into the underlying PMS activation mechanisms.

# 2. Results and Discussion

# 2.1. Axial Coordinated Engineering of Fe SACs

In contrast to traditional methodologies for the synthesis of M-N. C catalysts, our approach obviates the necessity for intricate pyrolysis procedures, while concurrently preserving the integrity of active-site architecture throughout subsequent processing steps (Figure 1a). The inherent constraints imposed by the PPc framework facilitate the integration of transition metal species within its inner cavity, yielding a contiguous arrangement wherein the $\mathrm { F e N } _ { 4 }$ moiety serves as the central catalytic motif. Leveraging the advantages conferred by electron-delocalized conjugated systems, coupled with its 2D planar morphology, this framework maximizes the utilization of active sites, thereby facilitating the introduction of a carbon matrix to achieve axial coordination. Our selection of NG, characterized by an abundance of N sites conducive to axial coordination with the Fe atom via Fe—N interactions, occurs at the 2D/2D face-to-face contact interfaces between PPc and NG.

# 2.3. Reactive Species Identification and Characterization

The generation of active species involves a combination of radical pathways, encompassing superoxide radical $( \mathrm { O } _ { 2 } ^ { \bullet - } )$ , hydroxyl radical $( \bullet \mathrm { O H } )$ , and sulfate radical $( \mathrm { S O _ { 4 } } ^ { \bullet - } )$ , as well as nonradical pathways such as ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , high-valence metal oxidation, and electron transfer processes. The identification of the reactive oxygen species (ROS) involved was first achieved through the utilization of quenching experiments. The radical quenching experiments show that different concentrations ${ \approx } 0$ to $1 0 0 ~ \mathrm { m M }$ of methanol (MeOH) had negligible effects on BPA degradation (Figure $\pmb { 4 } \mathbf { 2 }$ ;

Figure S17, Supporting Information), suggesting that both •OH and $\mathrm { S O _ { 4 } ^ { \bullet - } }$ were limited in the axial- $\mathrm { . F e N _ { 4 + 1 } / P M S }$ system. Furthermore, the addition of dimethyl sulfoxide, which serves as an effective scavenger for high-valence Fe, had minimal impact on BPA degradation (Figure S18, Supporting Information). This finding excludes the involvement of high-valence Fe in the degradation of BPA. Additional quenching experiments were performed using p-benzoquinone $( p$ -BQ) as a quencher of ${ \mathrm { O } } _ { 2 } ^ { \bullet - }$ and tetramethylpiperidine (TEMP) as a quencher of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ . The results show that the addition of $p$ -BQ and TEMP resulted in the inhibition of BPA degradation. Notably, in the presence of TEMP, BPA degradation was nearly completely halted, with only $1 1 \%$ removal observed within 6 min. This level of inhibition was significantly higher compared to the effect of $p$ -BQ, which resulted in $70 \%$ removal. As a consequence, ${ \mathrm { O } } _ { 2 } ^ { \bullet - }$ could potentially serve as a partial source for the generation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , considering its redox potential of $- 0 . 3 3 \mathrm { ~ V ~ }$ (versus NHE), which inherently limits its theoretical efficacy in BPA degradation.[24] Likewise, $\beta$ -carotene and furfuryl alcohol, serving as additional quenchers of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , exhibited a comparable inhibitory effect (Figure 4a). These observations strongly imply the dominant role of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ in the degradation mechanism.

Notably, the EPR signals corresponding to $\mathrm { D M P O - S O _ { 4 } ^ { \bullet - } }$ and DMPO•OH were absent (Figure 4b). The addition of MeOH induced negligible alterations in signal intensity, implying a restricted presence of •OH or $\mathrm { S O _ { 4 } ^ { \bullet - } }$ radicals. Figure $_ { 4 \mathrm { c } }$ illustrates a notable augmentation in the intensity of the distinctive triplet pattern associated with $\mathrm { T E M P - } ^ { 1 } \mathrm { O } _ { 2 }$ when axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ and PMS are concurrently present, in contrast to the planar- $\mathrm { { F e N _ { 4 } / P M S } }$ and NG/PMS system. # 2.4. Insights into the Axial- $\mathsf { F e N } _ { 4 + 1 }$ -Dependent Activation Mechanism

To investigate the significant role of single-atom Fe in the generation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ , an experimental study was conducted using potassium thiocyanate (KSCN) poisoning.[29] The introduction of KSCN resulted in a noticeable decrease in the degradation rate of BPA (Figure S23, Supporting Information), which is catalyzed by axial- $\mathrm { \cdot F e N } _ { 4 + 1 }$ . This decrease is reflected in the observed $k _ { \mathrm { o b s } }$ value, which decreased from 2.256 to $0 . 0 1 9 \ \mathrm { m i n ^ { - 1 } }$ . These results unequivocally establish the dominant influence of single-atom Fe sites in activating PMS. To unravel the modulation of electronic structure at Fe active sites for PMS activation, density functional theory (DFT) calculations were conducted using established planar- $\mathrm { F e N } _ { 4 }$ and axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ theoretical models. As depicted in Figure 5a,b, the density of states (DOS) intensity at the Fermi level exhibits a non-zero value, indicating a metallic property that facilitates electron transfer to PMS in both planar $\mathrm { \cdot F e N _ { 4 } }$ and axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ system.[30] Notably, the overlapping of Fe d-orbitals and total density of states around the Fermi level signifies the prominent promotion of Fe introduction in enhancing the ability of electron transfer.[31]

The electronic interactions between PMS and Fe sites involve the coupling of oxygen's $2 \mathrm { p }$ orbitals with the $\mathtt { d } z ^ { 2 }$ orbital of the transition metal, causing energy levels to split into bonding and antibonding orbitals.[21,32] In both the examined planar$\mathrm { F e N } _ { 4 }$ and axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ models, the population of antibonding states depended on the Fe 3dz2 orbital levels on the catalysts. The close proximity of the d band to the Fermi level suggests a reduced electronic occupancy in the antibonding states, consequently enhancing the adsorption of PMS.[33] The partial density of states (PDOS) for the Fe centers and oxygen of PMS adsorbed on the Fe sites were assessed (Figure 5c,d). Furthermore, the incorporation of an additional axial N ligand in axial$\mathrm { F e N } _ { 4 + 1 }$ resulted in a shift of the occupied d-orbital distribution towards higher energy levels, thereby reducing the antibonding energy state. Consequently, the more intense and closer Fermilev vi $\mathrm { \cdot F e N } _ { 4 + 1 }$ is stronger than that of planar- $\mathrm { \cdot F e N _ { 4 } }$ in interacting with PMS, thereby promoting the generation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ for further pollutant oxidation.[34]

Subsequently, adsorption energies $\left( E _ { \mathrm { a d s } } \right)$ were computed, aligning with the PDOS analysis. Notably, planar- $\mathrm { F e N _ { 4 } }$ exhibited a relatively lower adsorption energy of $- 1 . 7 9 \mathrm { e V } _ { \mathrm { i } }$ while axial$\mathrm { F e N } _ { 4 + 1 }$ demonstrated a stronger binding affinity for PMS, with an adsorption energy of $- 1 . 8 2 \ \mathrm { e V } .$ These findings indicate that the axial N ligand regulates the electron distribution of the Fe 3d orbital, rendering axial- $\mathrm { F e N } _ { 4 + 1 }$ more responsive to PMS. Additionally, Bader charge analysis revealed a significant impact of the additional axial N ligand on electron distribution, particularly concerning the Fe centers. As depicted in Figure S24 (Supporting Information), the charge of Fe in axial- $\mathrm { F e N } _ { 4 + 1 }$ (1.17 esurpasses that in planar- $\mathrm { F e N } _ { 4 }$ (1.12 e), and the charge transfer from the axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ site to PMS (0.77 e) exceeding that of the planar$\mathrm { F e N } _ { 4 }$ site (0.74 e) (Figure 5ef). This heightened Bader charge transfer of Fe in axial- $\mathrm { F e N } _ { 4 + 1 }$ aligns with the greater electronegativity of the axial N ligand and its robust electrostatic adsorption potential energy for PMS. Further substantiating these findings, the charge density difference confirms the electron-transfer ability between axial- $\mathrm { F e N } _ { 4 + 1 }$ /planar $\mathrm { F e N } _ { 4 }$ and PMS (Figure 5ef). A notable disparity in bonding charge distribution is observed between the Fe atom and surrounding $_ \mathrm { N }$ atoms at the planar$\mathrm { F e N } _ { 4 }$ and axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ sites, elucidating the distinct charge transfer properties in the PMS activation process. Further evidence for the enhanced charge transfer interactions between axial $\mathrm { F e N } _ { 4 + 1 }$ and PMS is provided by electrochemical impedance spectroscopy and chronoamperometry analysis.[35] As illustrated in Figure S25a (Supporting Information), axial- $\mathrm { F e N } _ { 4 + 1 }$ displays the smallest semicircle diameter compared to NG and planar$\mathrm { F e N } _ { 4 }$ , indicating enhanced charge transfer efficiency. The current responses observed at axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ electrode exhibits significant current spikes followed by an increase in current intensity upon PMS injection (Figure S25b, Supporting Information). This phenomenon can be attributed to the introduction of axial coordination, which induces electron rearrangement. These outcomes collectively affirm the pivotal role of the axial N ligand in optimizing the electron distribution of the Fe 3d orbital and modulating the charge density of the Fe centers, ultimately influencing the cavs $\mathrm { \cdot F e N } _ { 4 + 1 }$ system.

DFT calculations were also undertaken to explore potential reaction pathways leading to the formation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ in the axial$\mathrm { F e N } _ { 4 + 1 } / \mathrm { P M S }$ system. The free energy of the optimized imperative intermediates was calculated, as illustrated in Figure 6a-c, delineated the sequential steps involved in ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation: PMS → PMS\* → OH\* → O\* → 00H\* → O2\*→102. These theoretical insights underscore that the incorporation of an additional axial N ligand into the coordination environment of single Fe atoms optimizes the electron distribution of the Fe 3d orbital, reduces the electron density at the Fe center, enhances the adsorption of PMS molecules, and lowers the energy barrier for the generation of the key reaction intermediate, thereby facilitating selective generation of ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ .

# 2.6. Axial $\mathsf { F e N } _ { 4 + 1 }$ /PVDF Membrane Application

The impressive catalytic efficiency exhibited by the axial$\mathrm { F e N } _ { 4 + 1 } / \mathrm { P M S }$ system has driven its utilization in real-world situations. Integrating AOPs with polyvinylidene fluoride (PVDF) membrane confinement has notably reduced the diffusion distance of organic pollutants, leading to the development of catalytic membranes with self-cleaning properties. This innovative approach holds great promise for water treatment applications. Figure 8a depicts a continuous flow device utilized in the wastewater treatment process, employing the axial- $\mathrm { \cdot F e N } _ { 4 + 1 }$ /PVDF membrane, characterized by its good elasticity and malleability (Figure $^ { 8 \mathrm { l } _ { 0 , \mathrm { C } } ) }$ . Initially, we evaluated the transfer mass characteristics and pollutant rejection efficiency for BPA effluents in both PVDF and axial $\mathrm { \cdot F e N _ { 4 + 1 } / P V D F }$ membranes. Performance assessment involved 25 repetitive tests conducted over a span of $1 5 \mathrm { { h } }$ . The pristine PVDF membrane demonstrated a water flow rate of $9 4 5 . 4  { \mathrm { ~ L ~ m ~ } } ^ { - 2 }  { \mathrm { ~ h ~ } } ^ { - 1 }$ with ${ \approx } 3 . 0 \%$ rejection over $1 5 \mathrm { ~ h ~ }$ . In comparison, the axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ /PVDF membrane exhibited a similar water flow rate of $9 0 7 . 2 \mathrm { ~ L ~ m } ^ { - 2 } \mathrm { ~ h } ^ { - 1 }$ with nearly $5 . 8 \%$ rejection. The superior catalytic performance of the axial $\mathrm { \cdot F e N } _ { 4 + 1 }$ /PVDF membrane is evident in Figure 8d. Following the passage of a mixed solution containing $4 0 ~ \mu \mathrm { M }$ BPA and $0 . 1 \mathrm { \ m M }$ PMS through the reactor, the BPA removal efficiency in the axial$\mathrm { F e N } _ { 4 + 1 } / \mathrm { P V D F } / \mathrm { P M S }$ system consistently exceeded $9 3 \%$ after 15 h of operation. In contrast, the PVDF/PMS system only achieved removal efficiencies below $10 \%$ , highlighting the pivotal role of axial $\mathrm { F e N } _ { 4 + 1 }$ in activating PMS for BPA degradation in the continuous flow process. Subsequently, we evaluated the leaching resistance and mineralization capacity of the axial $\mathrm { \cdot F e N _ { 4 + 1 } / P V D F }$ membrane. The axial- $\mathrm { \cdot F e N _ { 4 + 1 } / P V D F / P M S }$ system demonstrated only minor reductions in BPA removal rate when applied to Deionized water, surface water and treated effluent water (Figure S28, Supporting Information), demonstrating relatively high performance in BPA removal from these real water samples. These findings provide strong evidence for the potential implementation of axial- $\mathrm { F e N } _ { 4 + 1 }$ in real-world water treatment applications.

# 3. Conclusion

The adjustment of coordination environments and the tailored design of axial coordination shells represent innovative principles for SACs toward PMS activation. In this investigation, we developed a model catalyst featuring a precisely defined axial$\mathrm { F e N } _ { 4 + 1 }$ active center using a pyrolysis-free approach, leveraging the customizable nature of phthalocyanine frameworks. The axial $\mathrm { F e N } _ { 4 + 1 }$ configuration offers significant advantages in PMS activation and selective ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation while maintaining robust stability. It achieved a high specific activity per active site of $6 8 . 3 6 { \times } 1 0 ^ { 2 } \ \mathrm { m i n ^ { - 1 } L } \ \mathbf { g } ^ { - 1 }$ . Experimental results and theoretical calculations revealed that the enhanced PMS activation is associated with the incorporation of axial N into Fe sites, which optimizes electron distribution in the Fe 3d orbital (shifting the d-band center from -1.231 to $- 0 . 4 3 2 \ \mathrm { e V } _ { \cdot }$ , increases PMS adsorption energy (from $- 1 . 7 9$ to $- 1 . 8 2 \ \mathrm { e V } )$ , and reduces the activation barriers for the formation of the key reaction intermediate $( \mathrm { O ^ { * } } )$ responsible for ${ } ^ { 1 } { \mathsf { O } } _ { 2 }$ generation (from 1.07 to $0 . 6 5 \ \mathrm { e V } _ { \cdot }$ Subsequently, the axial $\mathrm { F e N } _ { 4 + 1 }$ was immobilized on a PVDF membrane and implemented in a continuous flow device, achieving consistent and efficient pollutant removal $( > 9 3 \%$ degradation efficiency after $1 5 \mathrm { h }$ of operation). Additionally, the axial $\mathrm { \cdot F e N _ { 4 + 1 } / P M S }$ system demonstrates selective pollutant removal capabilities and broadspectrum efficacy in oxidizing emerging contaminants across diverse real-world aqueous matrices. This study provides valuable insights into the relationship between local atomic environments and the properties of SACs in PMS-driven water purification processes.
